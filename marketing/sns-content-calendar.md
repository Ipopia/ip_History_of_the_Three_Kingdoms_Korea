## 바이럴 캠페인

### 「왕국을 선택하라」챌린지

```
방식:
①「나는 ○○왕국 사람입니다」선언 게시
② 이유 + 좋아하는 캐릭터 태그
③ 5명 이상 태그 → 확산

참여 보상:
추첨 20명: 왕국별 굿즈 키트

왕국별 선택 문구:
고구려: 「나는 기억하겠다 #고구려인」
백제: 「나는 기록하겠다 #백제인」
신라: 「나는 두려워하지 않겠다 #신라인」
가야: 「나는 노래하겠다 #가야인」
```

### 「강은 기억한다」릴레이

```
방식:
오늘 기억하고 싶은 한 가지 + 강 이미지 = #강은기억한다
→ 역사 테마로 참여

참여 예시:
「#강은기억한다 — 오늘 살수대첩 공부했습니다」
「#강은기억한다 — 경주 다녀왔어요. 첨성대가 진짜 있어요!」

AI 챗봇 연동:
참여자 DM → 니문 AI 자동 답장
```
