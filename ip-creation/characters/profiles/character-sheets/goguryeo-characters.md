# 고구려 캐릭터 프로필

## 주몽(朱蒙) — 고구려 시조

| 항목 | 내용 |
|------|------|
| 생몰 | BC 58~BC 19 |
| 신분 | 고구려 초대 왕 |
| 출신 | 부여 — 금와왕의 양자 (실은 해모수의 아들) |
| 별칭 | 동명성왕(東明聖王), 추모왕(鄒牟王) |

**외형**
- 키 크고 균형 잡힌 체형 — 기마·궁술 최적화
- 날카로운 눈매 — 사냥꾼의 집중력
- 소박한 복장 (부여 시절) → 왕관·용포 (건국 후)
- 활을 쥔 오른손에 굳은살

**성격**
- 핵심: 생존 본능 + 리더십의 자연스러운 결합
- 불의에 굴복하지 않는 강단
- 말보다 행동 — 증명하는 사람
- 약자를 자연스럽게 이끄는 카리스마
- 고독을 견디는 힘 (어린 시절 왕따 경험)

**핵심 갈등**
- 부여에서의 박해 vs. 탈출 결심
- 예소(첫사랑)와의 이별 vs. 새 나라 건설
- 신화화되는 자신 vs. 인간으로서의 한계

**대사 색깔**
> "활은 거짓말을 하지 않는다. 나도 그렇다."
> "도망치는 것이 아니다. 내가 설 자리를 찾아가는 것이다."

**아크**: 박해받는 영웅 → 건국자 → 신화 (완성형 영웅 아크)

| 출신 | 부여 — 주몽의 친아들 |

**서사적 역할**
- 주몽 사후 아버지의 나라에 합류 — "아버지를 찾아온 아들"
- 이복형제들과의 갈등 — 왕위 계승 정당성 투쟁
- 황조가(黃鳥歌) 작자: "훨훨 나는 꾀꼬리는 암수 서로 정다운데, 외로울사 이 내 몸은 뉘와 함께 돌아가리"
- 치희(雉姬)와 화희(禾姬) 두 왕비 사이의 갈등

**IP 포인트**: 아버지의 신화적 그늘 아래 자신의 정체성을 찾는 서사

## 을파소(乙巴素) — 고구려의 개혁 재상

| 항목 | 내용 |
|------|------|
| 생몰 | ?~203 |
| 신분 | 고구려 국상(國相) — 수상 |
| 업적 | 진대법(賑貸法) 실시 (194년) |

**외형**
- 중년의 단단한 체형 — 농부 출신의 몸
- 화려하지 않은 관복 — 실용을 중시하는 복장
- 조용하고 깊은 눈빛

**성격**
- 핵심: 민심이 나라의 기반이라는 확고한 신념
- 말수 적고 논리적 — 필요할 때만 말함
- 귀족에게 굴복하지 않는 강단
- 백성의 삶을 직접 보고 정책을 만드는 현장주의자

**핵심 갈등**
- 진대법 도입 vs. 기득권 귀족의 반대
- 왕의 신임 vs. 귀족들의 음해

**대사 색깔**
> "봄에 굶는 백성이 있다면, 그 나라의 곡식 창고가 무슨 소용입니까."
> "법이 강자를 위해 존재한다면, 그것은 법이 아니라 폭력입니다."

**아크**: 야인 출신 재상 → 진대법 실현 → 고구려 복지 제도의 아버지

## 광개토대왕(廣開土大王)

| 항목 | 내용 |
|------|------|
| 생몰 | 374~412 (재위 391~412) |
| 신분 | 고구려 19대 왕 |
| 즉위 연령 | 18세 |
| 별칭 | 담덕(談德), 호태왕(好太王) |
| 업적 | 64성 1,400촌 정복, 동아시아 최대 판도 |

**외형**
- 18세 즉위 — 날카롭고 젊은 얼굴, 이미 전사의 눈빛
- 장신 + 건장한 체격 — 직접 전투에 참여하는 왕
- 갑옷 위에 왕의 상징 — 전사왕의 이미지
- 나이가 들며 점점 더 깊어지는 눈빛

**성격**
- 핵심: 행동하는 비전가 — 말하면 반드시 실행
- 두려움이 없음 — 18세에 즉위 당일부터 정복 계획 세움
- 정복된 민족에게 잔혹하지 않음 — 복속시키되 문화 존중
- 신하들에게 자신의 전략을 설명하지 않고 실행으로 증명
- 약점: 후계자 교육 소홀 — 39세 사망으로 미완

**핵심 갈등**
- 정복의 영광 vs. 정복지 민중의 고통
- 짧은 재위 기간의 압박 — "더 많이 해야 한다"
- 장수왕(아들)에게 무엇을 남길 것인가

**대사 색깔**
> "넓히는 것이 지키는 것이다. 고구려가 멈추면 썩는다."
> "그 땅의 백성이 고구려를 두려워하게 하라. 그 다음에 존경하게 하라."

**아크**: 어린 왕 → 정복자 → 동아시아의 제왕 (상승형)

## 장수왕(長壽王)

| 항목 | 내용 |
|------|------|
| 생몰 | 394~491 (재위 412~491) |
| 신분 | 고구려 20대 왕 |
| 재위 기간 | 79년 — 한국사 최장 재위 |
| 향년 | 97세 — 한국사 최장수 왕 |
| 업적 | 평양 천도 (427), 한성 함락 (475) |

**외형**
- 즉위 시: 18세 청년 → 사망 시: 97세 노왕
- 긴 재위만큼 복잡한 표정의 변화
- 아버지(광개토대왕)와 달리 내면에 계략을 숨기는 얼굴
- 노년: 주름 가득하지만 눈빛은 여전히 날카롭다

**성격**
- 핵심: 아버지가 칼로 이룬 것을 외교로 완성
- 전략적 인내 — 수십 년을 기다릴 수 있음
- 남조와 북조 모두에 조공하며 이이제이(以夷制夷)
- 겉으로는 온화, 속으로는 냉정한 계산가
- 백제 개로왕에게 도림 스님을 보낸 첩보 작전의 설계자

**핵심 갈등**
- 아버지(광개토대왕)의 위대함 vs. 자신만의 방식으로 증명해야 함
- 97년 장수의 고독 — 자신이 아끼는 신하들을 먼저 보내다

**대사 색깔**
> "급하게 먹는 밥이 체한다. 나는 서두르지 않는다."
> "아버지는 칼로 땅을 넓혔다. 나는 그 땅을 지킬 것이다."

## 연개소문(淵蓋蘇文)

| 항목 | 내용 |
|------|------|
| 생몰 | ?~666 |
| 신분 | 고구려 대막리지(大莫離支) — 최고 실권자 |
| 사건 | 영류왕 시해 (642), 천리장성 건설 주도 |

**외형**
- 장신 + 압도적 체격 — 입장만으로 분위기 장악
- 허리에 칼 5자루 — 과시적 무력 선언
- 서슬 퍼런 눈빛 — 아무도 시선을 마주치지 못함
- 화려하지 않은 갑옷 — 실용적 전사

**성격**
- 핵심: 나라를 구하겠다는 신념 + 권력욕의 경계가 모호
- 타협을 모름 — 옳다고 믿으면 왕도 죽인다
- 카리스마 있는 연설 — 사람을 움직이는 능력
- 아들들에게 후계를 제대로 준비하지 못한 약점
- "혁명가인가, 독재자인가" — 역사적 논란의 핵심 인물

**핵심 갈등**
- 당나라 위협 vs. 고구려 귀족 정치의 부패
- 강력한 집권 vs. 민중의 희생 (천리장성 강제 노역)
- "내가 없으면 나라가 망한다" vs. "내가 있어도 나라가 망할 수 있다"

**대사 색깔**
> "나라가 썩어가는데 예의를 따질 여유가 없다."
> "왕이 나라를 망치면, 나라를 구할 자가 왕을 대신해야 한다."
> "나는 권력을 원한 것이 아니다. 살아남기를 원했을 뿐이다."

**아크**: 혁명가 → 독재자 → 멸망의 씨앗 (하강형 비극)

## 을지문덕(乙支文德)

| 항목 | 내용 |
|------|------|
| 생몰 | 불명 (6~7세기) |
| 신분 | 고구려 장군·전략가 |
| 업적 | 살수대첩 (612) 설계 |

**외형**
- 평범한 외모 — 눈에 띄지 않는 것이 장점
- 학자의 손 + 군인의 눈 — 지략가의 이중성
- 조용하고 단정한 복장 — 화려함 거부

**성격**
- 핵심: 전략가 — 전쟁터보다 머릿속에서 먼저 싸움
- 극단적 냉정함 — 감정을 전략에 개입시키지 않음
- 유머 감각: 수 장수에게 시를 보내는 여유
- 명예보다 승리가 중요 — "이겨야 의미가 있다"
- 7번 패퇴하면서 병사들의 사기 유지가 가장 어려운 과제

**핵심 갈등**
- 7번 의도적 패퇴 — 부하들의 신뢰 vs. 전략적 필요
- 시(詩) 한 편으로 적 장수를 조종하는 심리전
- 역사에 이름을 남기는 것 vs. 이름 없이 나라를 구하는 것

**대사 색깔**
> "지는 것도 전략이다. 단, 마지막에 이겨야 한다."
> "적이 내가 약하다고 생각하게 하는 것이 가장 강한 무기다."

**아크**: 무명의 전략가 → 살수대첩 → 역사상 가장 유명한 지략가

## 양만춘(楊萬春) — 안시성 성주 (추정)

| 항목 | 내용 |
|------|------|
| 생몰 | 불명 (7세기) |
| 신분 | 안시성 성주 |
| 업적 | 당 태종 88일 저지 (645) |
| 비고 | 삼국사기에 이름 없음 — 후대 기록에 양만춘으로 전함 |

**외형**
- 중년의 단단한 몸 — 성을 지키는 사람
- 화려하지 않은 갑옷 — 실전형 장수
- 피로가 쌓인 눈 — 88일의 포위를 버텨낸 얼굴
- 당 태종이 철수할 때 성벽 위에서 읍(揖)하는 장면

**성격**
- 핵심: 맡은 것을 끝까지 지키는 사람
- 화려한 야망 없음 — 이 성을 지키는 것이 전부
- 병사들을 가족처럼 대함 — 신뢰 기반 리더십
- 불가능한 상황에서도 패닉 없음
- 88일 포위 동안 하루하루 버티는 전략 창의성

**핵심 갈등**
- 항복 vs. 수성 — 매일 반복되는 선택
- 병사들의 죽음에 대한 책임감
- 연개소문의 명령 vs. 자신의 판단

**대사 색깔**
> "당 태종이 직접 왔다. 그것은 우리가 중요하다는 뜻이다."
> "성이 살아있는 한, 고구려는 살아있다."

## 연남생(淵男生) — 비극의 장자

| 항목 | 내용 |
|------|------|
| 생몰 | 634~679 |
| 신분 | 연개소문의 장남 — 고구려 대막리지 계승 |
| 사건 | 당에 투항 (667) → 고구려 멸망 기여 |

**서사적 역할**
- 아버지(연개소문)의 가장 큰 실패 — 후계자 교육
- 동생 연남건과의 권력 투쟁 → 당 투항
- "강한 아버지의 약한 아들" 서사
- 고구려 멸망의 내부적 원인 — 외적보다 내분

**아크**: 권력 계승자 → 형제 갈등 → 배신자 → 멸망의 씨앗 (하강형)
