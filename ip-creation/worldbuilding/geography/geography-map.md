## 4~7세기 한반도 지리 개요

```
삼국시대 한반도 영토 범위:
북: 만주 요동 지역 (고구려 최대 영토)
동: 동해안
남: 남해안 + 낙동강 유역 (가야·신라)
서: 서해안 (백제 해양 거점)

주요 지형:
산맥: 태백산맥 (한반도 척추) / 소백산맥 / 낭림산맥
평야: 요동 평야 / 한강 유역 / 금강 유역 / 낙동강 유역
강: 대동강·압록강·청천강 (고구려) / 금강·한강 (백제)
    낙동강·형산강 (신라·가야) / 두만강 (고구려 북방)
해: 서해 (황해) / 남해 / 동해
```

## 왕국별 핵심 지역

### 고구려 영토

```
핵심 지역:
평양성 (平壤城):
  위치: 대동강 중류 (현 북한 평양)
  지형: 대동강이 성을 감싸는 천연 해자
  기후: 대륙성 — 여름 덥고 겨울 매우 추움
  IP 의미: 고루의 본거지, 대동강 = 강은 기억한다 핵심

국내성 (國內城):
  위치: 압록강 중류 (현 중국 길림성 집안시)
  지형: 산으로 둘러싸인 분지
  의미: 광개토대왕릉비 위치 — 고구려 초기 수도

안시성 (安市城):
  위치: 요동 지역 (현 중국 요양 인근 추정)
  지형: 요동 평야 위 험준한 구릉
  IP 의미: 시즌 2 클라이맥스 — 고루의 결전지

살수 (薩水):
  위치: 청천강 추정 (현 북한 평안남도)
  지형: 평야를 가로지르는 강 — 댐 형성 가능 지형
  IP 의미: 살수대첩 무대 — 고루의 첫 전투

압록강 (鴨綠江):
  위치: 고구려-중국 경계
  지형: 빠른 유속, 넓은 강폭
  의미: 수나라·당나라 침략 루트 — 요충지

지형 특성 (고구려):
산악 + 고원 — 기병 전술 최적
겨울 혹한 — 당나라 철수의 주요 원인
요동 평야 — 농업·교역 거점
```

### 백제 영토

```
핵심 지역:
사비성 (泗沘城):
  위치: 백마강 (금강 하류) 북안 (현 충남 부여)
  지형: 백마강이 3면을 감싸는 천연 방어선
  기후: 온화한 중부 내륙 기후
  IP 의미: 아랑의 본거지, 낙화암 = 백제 최후의 상징

웅진성 (熊津城):
  위치: 금강 상류 (현 충남 공주)
  의미: 사비 천도 이전 백제 수도 (475~538년)
  무령왕릉 위치 — 아랑 배경 역사 공간

한성 (漢城):
  위치: 한강 하류 (현 서울 일대)
  의미: 백제 최초 수도 (BC 18~475년)
  고구려 장수왕에 의해 함락 (475년) — IP 역사 복선

서해 (西海, 황해):
  백제 해군 지배 해역
  중국·왜국 교역 루트
  섬 거점 네트워크

지형 특성 (백제):
평야 지대 많음 — 농업 생산력 우수
강 수계 발달 — 내륙 교통망
서해 접근 — 해양 교역 강점
```

### 신라 영토

```
핵심 지역:
서라벌 (徐羅伐):
  위치: 경주 분지 (현 경북 경주)
  지형: 분지형 — 4면이 산으로 둘러싸임
  기후: 온화한 동남해 기후 (비교적 따뜻)
  IP 의미: 하린의 본거지, 첨성대·황룡사

형산강 (兄山江):
  위치: 경주 분지를 가로지르는 강
  지형: 완만하고 투명한 흐름
  IP 의미: 니문의 12번째 곡 장면 — 강변 감성 씬

소백산맥 (小白山脈):
  위치: 신라-백제 경계
  지형: 험준한 분수령 — 자연 방어선
  의미: 대야성 전투 — 백제의 신라 내륙 침투 루트

한강 (漢江):
  김춘추의 한강 확보 기획 → 나당 연합 동기
  신라 삼국통일 핵심 전략 거점

지형 특성 (신라):
경주 분지 — 농업 생산 안정
동해 접근 — 어업 발달
소백산맥 — 천연 방어선
```

### 가야 영토

```
핵심 지역:
김해 (金海, 금관가야):
  위치: 낙동강 하류 (현 경남 김해)
  지형: 낙동강 삼각주 + 남해 접근
  기후: 온난한 남해 기후
  IP 의미: 니문의 고향, 구지봉 위치

함안 (咸安, 아라가야):
  위치: 남강 유역 (현 경남 함안)
  지형: 구릉성 분지
  의미: 아라가야 중심 — 도항리 고분군

고령 (高靈, 대가야):
  위치: 가야산 인근 (현 경북 고령)
  지형: 산악 분지 — 가장 늦게 신라에 흡수 (562년)
  의미: 가야 마지막 중심 세력

낙동강 (洛東江):
  위치: 경상도 전역을 흐르는 대강
  지형: 넓고 느린 흐름 — 교역 루트
  IP 의미: 니문의 강 — 가야 기억의 핵심

구지봉 (龜旨峰):
  위치: 김해 (현 김해 구지봉)
  지형: 낮은 구릉 — 김해 평야 조망
  IP 의미: 가야 건국 신화 — 수로왕 탄생지

지형 특성 (가야):
낙동강 수계 — 교역 + 제철 운반
남해 접근 — 왜국 교역
분열된 소국 연합 — 단일 통일 왕국 미형성
```

## 핵심 전장 지리

### 살수대첩 (612년)

```
전장 위치: 살수 (청천강 추정, 현 북한 평안남도)

지형 분석:
- 살수: 평야를 가로지르는 강 폭 수백m
- 상류: 댐 건설 가능한 협곡 (지류)
- 하류: 넓어지는 평야 → 군대 이동 용이

을지문덕 전술과 지형:
1. 평야에서 수나라 유인 (지형 이용)
2. 상류 댐 건설 (지형 이용)
3. 살수 건너는 타이밍에 방류 (완벽한 타이밍)
4. 패주하는 수나라 기병 추격 (평야 이용)

IP 활용:
드라마: 살수 전경 + 강물 위 전투 장면
게임: 살수 맵 — 강 지형 전술 보너스
웹툰: 물결 이펙트 + 패주 수나라 실루엣
```

### 안시성 전투 (645년)

```
전장 위치: 안시성 (현 중국 요양 인근 추정)

지형 분석:
- 안시성: 요동 평야 위 구릉 위 성채
- 서쪽: 평야 지대 (당나라 진영)
- 동쪽: 산악 — 배후 차단 불가

당 태종 토산 전술과 지형:
- 서쪽 평야에서 흙 채취 용이
- 성 서벽이 상대적으로 낮은 지형
- 그러나 토산 무게중심 — 서쪽 기단이 취약

고구려 야습과 지형:
- 야음 이용 — 당나라 시야 차단
- 서쪽 기단 파기 → 토산 고구려 쪽 도산 (설계 오류 이용)

IP 활용:
드라마: 요동 평야 전경 + 토산 CGI
게임: 안시성 맵 — 공성 비대칭 전투
```

## 주요 교통로

```
육상 교통로:
① 평양~개성~한강 루트 (한반도 서해안 종단)
② 요동 교통로 (고구려~중국 대륙)
③ 소백산맥 고갯길 (신라~백제 경계)
④ 낙동강 강변 루트 (가야~신라 교역)

해상 교통로:
A. 서해 남북 루트 (백제~중국)
B. 남해 동서 루트 (가야~왜국)
C. 동해 연안 루트 (신라~고구려)

교통로와 전쟁:
수나라 침략 루트: 요동 → 압록강 → 살수 → 평양
당나라 침략 루트: 요동 → 안시성 → 평양 (안시성에서 좌절)
나당 연합 루트: 당 = 고구려 북방 / 신라 = 백제 남방

IP 게임 적용:
교통로 = 유닛 이동 경로
강 = 도하 시 이동력 -1 (지형 패널티)
산악 = 이동력 -2 / 방어 +2 (요새 지형)
평야 = 이동력 기본 / 기병 이동력 +1
```

## 기후 특성

```
고구려 기후:
대륙성 기후 — 혹한과 무더위 교차
겨울 (11~3월): 평균 -10~-20℃ (요동 기준)
여름 (6~8월): 30℃+ 습한 더위
→ IP 적용: 안시성 당나라 철수 = 겨울 보급 한계
→ 살수대첩 여름 물 풍부 → 댐 방류 조건 충족

백제 기후:
온화한 중서부 기후
겨울 크게 춥지 않음
봄·여름 풍부한 강수 → 농업 유리
→ IP 적용: 사비성 봄꽃 = 백제 정체성 배경

신라 기후:
온화한 동남해 기후
경주 분지 — 따뜻하고 건조
→ IP 적용: 서라벌 맑은 하늘 = 하린 화랑 훈련 배경

가야 기후:
온난 다습 — 낙동강 + 남해 영향
풍부한 수량 → 제철 수력 이용
→ IP 적용: 니문 강변 장면 = 온화한 가야 기후
```

## 게임 지도 구현

```
전략 맵 구성:
한반도 + 요동 전략 맵 (육각형 타일)

지형 종류:
평야: 이동력 1 / 방어 0 / 기병 보너스
언덕: 이동력 2 / 방어 +1
산악: 이동력 3 / 방어 +2 / 기병 페널티
강: 도하 이동력 +1 소비
해안: 해군 유닛 이동
삼림: 이동력 2 / 방어 +1 / 시야 차단

역사 지형 보너스:
살수 강 지형: 고구려 유닛 공격 +25%
안시성 성: 방어자 방어 +3
구지봉: 가야 유닛 문화 생산 +30%
황룡사: 신라 유닛 사기 +2

시즌별 지도 변화:
시즌 1 (530~612년): 가야 영토 포함
시즌 2 (613~645년): 가야 없음 (신라 흡수)
시즌 3 (646~668년): 나당 연합 → 지도 급변
```
