# 삼국 도성(都城) 설계

## 도성 계획의 원칙

삼국의 도성은 **중국 도성제 수용 + 지역 지형 적응**의 결합이었다.

**공통 원칙**
- 배산임수(背山臨水): 산을 등지고 물을 앞에 두는 입지
- 남향 배치: 궁궐 정문은 남향
- 방어+행정+종교 복합 공간
- 왕궁 + 관청 + 귀족 거주지 + 시장 + 사원 구성

## 고구려 도성

### 졸본성(卒本城, BC 37~AD 3년경)
- 위치: 현 중국 환인(桓仁) — 혼강(渾江) 유역
- 특징: 초기 건국 거점 — 자연 산성 활용
- 오녀산성(五女山城): 천연 절벽 요새 — 주몽의 거점
- 규모: 소규모 — 건국 초기 임시 수도 성격

### 국내성(國內城, 3~427년)
- 위치: 현 중국 집안(集安) — 압록강 중류
- 구조:
  - 평지성(平地城): 행정·거주 — 장방형 석축
  - 환도산성(丸都山城): 유사시 피난 산성 — 인근 산에 건설
  - 평지성+산성 이중 체계 — 고구려 도성 전형
- 규모: 동서 2.7km × 남북 2.7km (추정)
- 주요 시설: 왕궁지·귀족 묘군(墓群)·태왕릉·장군총

### 평양성(平壤城, 427~668년)
- 위치: 현 북한 평양 — 대동강 유역
- 장수왕 427년 천도 — 남진 정책의 상징
- 4개 구역 구성:
  - 북성(北城): 왕궁 + 핵심 방어
  - 내성(內城): 관청 + 귀족
  - 중성(中城): 사원 + 시장
  - 외성(外城): 평민 거주 + 방어
- 규모: 전체 둘레 약 23km — 동아시아 대도시 수준
- 안학궁(安鶴宮): 평양 최대 왕궁 — 동서 622m × 남북 620m

## 백제 도성

### 한성(漢城, BC 18~475년)
- 위치: 현 서울 — 한강 남안
- 구조:
  - 하남위례성: 초기 왕성 (풍납토성 추정)
  - 북한산성: 피난 산성
- 풍납토성(風納土城): 현 재발굴 — 둘레 3.5km, 높이 11m 토성
- 475년 장수왕 침공으로 함락 → 천도

### 웅진성(熊津城, 475~538년)
- 위치: 현 공주(公州) — 금강 유역
- 한성 함락 후 긴급 천도 — 방어 중심 선택
- 공산성(公山城): 자연 지형 활용 산성형 왕성
- 규모 축소 — 국력 약화 반영

### 사비성(泗沘城, 538~660년)
- 위치: 현 부여(扶餘) — 백마강(금강 하류)
- 성왕 538년 천도 — 국가 재건의 상징
- 구조: 중국 남조 도성제 적극 수용
  - 나성(羅城): 외곽 방어 토성 — 둘레 약 8.6km
  - 왕궁: 부소산성 남쪽 평지
  - 5부(部) 행정 구역 분할
  - 정림사지: 도심 5층 석탑 — 도시 랜드마크
- 660년 나당 연합군 공격으로 함락

## 신라 도성

### 서라벌(徐羅伐, BC 57~935년)
- 위치: 현 경주(慶州) — 형산강·남천 합류부
- 신라 건국부터 멸망까지 단 한 번도 천도 없음
- 구조:
  - 월성(月城, 반월성): 왕궁 — 초승달 모양 토성
  - 황룡사(皇龍寺): 최대 사원 — 동서 약 288m, 9층 목탑
  - 동시(東市)·서시(西市): 공설 시장
  - 분황사·천왕사 등 주요 사원
- 규모: 통일 후 인구 약 100만 명 추정 — "당시 세계 4대 도시 중 하나"

**서라벌 도시 구획**
- 방리제(坊里制): 바둑판식 구획 — 중국 장안성 모방
- 귀족 구역: 월성 주변
- 평민 구역: 외곽
- 불국사·석굴암: 도시 외곽 산지 — 종교 복합 공간

## 가야 도성

### 김해(金海) — 금관가야
- 구지봉(龜旨峰): 김수로왕 강림 신화의 땅
- 봉황동 유적: 대형 창고+주거 복합 시설
- 수로왕릉: 왕릉 중심 도시 구조
- 철 생산·교역 거점으로서의 항구 도시 성격

### 고령(高靈) — 대가야
- 지산동 고분군: 대가야 왕족 고분 — 산 능선 따라 배치
- 주산성(主山城): 방어 산성
- 규모: 금관가야보다 내륙 — 농업+철 생산 복합

## 캐릭터별 도시 동선

> 병합 출처: `city-design.md` (deprecated)

### 고루의 동선 (평양성)

```
안학궁 → 을지문덕 군사 회의실 → 살수 출진

주요 장면 배경:
  성벽 위: 수나라 대군 접근 관망
  대동강 선착장: 출정 전 아침
  안학궁 내정: 을지문덕과 고루의 마지막 대화
```

### 아랑의 동선 (사비성)

```
기록관 → 미래사 → 백마강변 → 낙화암

주요 장면 배경:
  미래사 9층 목탑 앞: 연등 행사 밤
  기록관 창가: 매일 죽간 기록 작업
  낙화암 절벽: 백제 멸망 장면 (S2 클라이맥스)
  백마강 선착장: 교역선 도착 장면
```

### 하린의 동선 (서라벌)

```
화랑 훈련장 → 황룡사 → 월성 → 첨성대

주요 장면 배경:
  황룡사 마당: 화랑 입단식 대규모 행사
  첨성대 아래: 선덕여왕과 하린 단독 만남
  동시 골목: 하린의 일상 (소년 시절)
  월성 성문: 출정 장면
```

### 니문의 동선 (가락국)

```
갈대밭 강변 → 철 단조장 (아버지 일터) → 수릉왕묘

주요 장면 배경:
  낙동강 갈대밭: 가야금 연주 (일상 장면)
  수릉왕묘: 가야 유민 제사 (니문 정체성 확인)
  철 단조장: 어린 니문 기억 (아버지 장면)
  가야 멸망 후 폐허: 에필로그 배경
```

## 건축 미학 프레임워크

> 병합 출처: `city-design.md` (deprecated)

```
고구려 미학:
  흑색·청색 기와 (고구려 왕국 색)
  삼족오 처마 장식
  돌 성벽 + 흙 다진 내부 구조
  좁은 골목 → 기마 제한 (적군 진입 차단)

백제 미학:
  황금빛 기와 (백제 황금색)
  섬세한 목각 처마 장식
  금동 문고리·장식
  연꽃 문양 타일 (미래사 경내)
  창문 너머 백마강이 보이는 기록관 구조

신라 미학:
  황금빛 기와 (신라 금색)
  금박 처마 장식
  황룡사 목탑 실루엣 = 서라벌 스카이라인
  돌계단 + 기와담장 (귀족 저택)

가야 미학:
  황토색 기와·흙벽 (가야 황토색)
  철제 문고리·장식 (철 문화)
  소박한 목재 건물
  용광로 붉은 빛 = 가야 도시의 아이콘
```
