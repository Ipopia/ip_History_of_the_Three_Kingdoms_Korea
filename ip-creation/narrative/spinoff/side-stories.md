## 스핀오프 1 — 「을지문덕의 젊은 날」

```
주인공: 을지문덕 (청년기, 30대)
시대: AD 580~610 (살수대첩 이전)
포맷: 웹소설 단편 시리즈 (20화)
분량: 화당 6,000자

서사 개요:
  살수대첩(612) 전략가로 알려진 을지문덕의
  청년 시절 — 어떻게 그 지략이 형성되었는가

핵심 에피소드:
  1화~5화: 요동 변방 하급 무관 시절
  6화~10화: 수나라 사신 방문 대응 (양견 시대)
  11화~15화: 고구려 내부 권력 암투 목격
  16화~20화: 살수대첩 계획의 씨앗 — 강물을 처음 전략적으로 바라보다

메인 시리즈 연계:
  고루와의 첫 만남 복선 (시즌 1 연계)
  「기다려라」말버릇 기원 설명
  을지문덕 오언시 창작 배경

특징:
  1인칭 시점 (을지문덕 내면 독백 중심)
  청년기 미성숙함 → 점진적 성장
  역사 기록 공백 → 창작 자유도 높음
```

## 스핀오프 2 — 「우륵의 12곡」

```
주인공: 우륵 (于勒, 가야 음악가)
시대: AD 540~562 (가야 멸망 전후)
포맷: 애니메이션 단편 (30분 × 6편)
특징: 가야금 연주 장면 비중 높음 — 음악 중심 서사

서사 개요:
  가야금 12곡을 작곡한 우륵의 이야기
  멸망하는 나라에서 음악을 남기려는 한 예술가의 사명

에피소드 구성:
  1편: 「첫 번째 현」— 우륵의 가야금 입문
  2편: 「12곡의 시작」— 작곡 결심
  3편: 「왕의 명령」— 가야 왕이 음악으로 나라를 지키려 함
  4편: 「신라행」— 562년 가야 멸망 전 신라로 귀화 결심
  5편: 「낯선 왕국」— 신라에서 음악으로 인정받기
  6편: 「니문에게」— 니문의 정신적 선조로서의 유산 전달

메인 시리즈 연계:
  니문 시리즈와 직접 연결 (우륵 = 니문의 정신적 스승)
  가야금 12곡의 의미 서사적 심화

음악:
  우륵 12곡 모티프를 OST로 재해석
  가야금 솔로 중심 사운드트랙
  SND-MUSIC과 긴밀 협력 필수
```

## 스핀오프 3 — 「아랑의 기록」

```
주인공: 아랑
시대: AD 641~660 (메인 시리즈 평행 서사)
포맷: 웹툰 (20화)
관점: 메인 드라마에서 보이지 않는 아랑의 시점

서사 개요:
  드라마 본편에서 생략된 아랑의 일상·기록·내면
  백제 문서관에서 역사를 기록하는 자의 고독

에피소드 구성:
  1~4화: 사비성 문서관 — 오늘 기록한 것들
  5~8화: 641년 의자왕 즉위 — 왕의 변화를 기록하다
  9~12화: 타 왕국 사신들과의 교류 (고루·하린 단편 만남)
  13~16화: 나당연합 소문을 처음 접하다
  17~20화: 660년 — 마지막 죽간을 준비하다

특징:
  드라마 본편 스포일러 없는 독립 감상 가능
  역사 기록의 의미 + 지식인의 책임 주제
  아랑 시점 = 독자에게 역사 해설 기능 겸비

포맷 장점:
  웹툰 = 죽간 기록 시각화 최적
  아랑 캐릭터 카드 + 역사 인포그래픽 결합 가능
```

## 스핀오프 4 — 「관창의 하루」

```
주인공: 관창 (官昌, 16세 화랑)
시대: AD 660년 황산벌 전투 당일
포맷: 단편 웹소설 (1회 완결, 15,000자)

서사 개요:
  황산벌 전투 당일 아침부터 전사까지
  16세 소년의 내면 — 공포·용기·결단

구조:
  아침: 어머니를 생각하다
  출전 전: 하린에게 마지막 말 건네기
  첫 돌격: 백제 진영에 혼자 뛰어들다
  포획: 계백과의 대면 (두 영웅의 짧은 교감)
  귀환: 계백이 살려 보내다 — 두 번째 돌격 결심
  최후: 침묵 속에서

메인 시리즈 연계:
  시즌 3 황산벌 에피소드의 사전 콘텐츠
  관창의 죽음이 신라군 사기에 미친 영향 서술

주제:
  「가장 작은 용기가 가장 큰 역사를 만든다」
  16세의 눈으로 본 전쟁의 의미

발행 시점:
  시즌 3 황산벌 에피소드 방영 D-3 (티저 효과)
```

## 스핀오프 5 — 「선덕여왕의 별」

```
주인공: 선덕여왕 (善德女王)
시대: AD 632~647 (재위 기간)
포맷: 오디오 드라마 (팟캐스트 6편, 편당 25분)

서사 개요:
  신라 최초 여왕의 통치 — 안팎의 도전과 지혜
  하린과의 관계 심화 서사

에피소드 구성:
  1편: 「첫 번째 조회」— 여왕 즉위 첫날
  2편: 「첨성대를 세우다」— 지식으로 권위 세우기
  3편: 「당나라 사신」— 외교 협상
  4편: 「하린에게」— 경호무관 임명과 신뢰
  5편: 「647년 봄」— 마지막 예언
  6편: 「별이 지는 날」— 임종

포맷 특징:
  1인칭 독백 중심 (여왕의 내면 독백)
  배경음: 경주 앰비언스 + OST 파편
  청각 이미지: 첨성대 별소리 시각화

활용:
  드라마 방영 전 팟캐스트 선공개 (관심 환기)
  스포티파이·애플팟캐스트·네이버 오디오클립 동시 배포
  여성 역사 인물 콘텐츠 → 여성 팬덤 적극 유입
```

## 스핀오프 6 — 「기벌포 이후」(시즌 3 후속)

```
주인공: 하린 (노년기, 60대)
시대: AD 710~720 (676년으로부터 40년 후)
포맷: 단편 소설 (단행본 1권, 200쪽)

서사 개요:
  삼국통일 후 40년 — 하린은 늙어 경주에 살고 있다
  니문이 남긴 가야금 소리, 고루의 기억, 아랑의 죽간
  「강은 여전히 기억하는가」라는 질문

핵심 씬:
  하린이 가야금 소리를 듣다 — 니문을 떠올리다
  아랑이 남긴 죽간을 처음 읽다
  고루에 대한 전설이 과장되어 전해지는 것을 바로잡다
  새로운 세대에게 역사를 전하다

주제:
  「역사는 살아남은 자가 만든다」
  메인 시리즈 전체 테마 완결

발행:
  시즌 3 완결 후 6개월 (팬덤 이탈 방지)
  소설 단행본 출판 + 전자책 동시
```
