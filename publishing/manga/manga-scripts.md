## 스크립트 작성 원칙

```
웹툰 스크립트 3원칙:

1. 시각 우선:
   모든 감정·상황은 그림으로 표현 가능해야 함
   대사보다 그림이 먼저 — 대사는 보조

2. 스크롤 리듬:
   웹툰 = 세로 스크롤 매체
   긴장 → 반전 → 여운의 리듬 설계
   클리프행어: 스크롤 멈추는 컷 (세로 긴 컷)

3. 컷 경제:
   1컷 = 1정보
   불필요한 설명 컷 금지
   배경 없는 캐릭터 컷 ≤ 30% (분위기 손실 방지)
```

## 컷 분류 기준

```
컷 유형:
  [BG] — 배경 컷 (장소 소개)
  [ACT] — 액션 컷 (움직임·전투)
  [EMO] — 감정 컷 (표정 클로즈업)
  [DIA] — 대화 컷 (캐릭터 + 말풍선)
  [SFX] — 효과음 컷 (음향 시각화)
  [TITLE] — 타이틀 컷 (챕터 제목)

구성 비율 권장 (1화 기준):
  BG: 10~15%
  ACT: 25~30%
  EMO: 15~20%
  DIA: 30~35%
  SFX: 5~10%
  TITLE: 1~2컷
```

## 시즌 1 — 웹툰 스크립트 샘플

### 1화: 「강은 기억한다」

```
[TITLE 컷]
  이미지: 청천강 부감 (새벽 안개)
  텍스트: 「삼국(三國)」/ 제1화 「강은 기억한다」
  분위기: 장중·웅장

--- PAGE 1 ---

[BG-001]
  배경: AD 612년 / 살수(청천강) 강변 / 새벽 4시
  묘사: 짙은 안개, 강물 소리만 들림
  자막: 「AD 612. 살수(薩水). 고구려」

[ACT-002]
  묘사: 안개 속에서 발소리
  발 클로즈업 — 고려군 갑옷 하단
  SFX: 「콰직」 (진흙 밟는 소리)

[EMO-003]
  고루 전신 등장 (뒷모습)
  강 쪽을 바라봄
  시선: 원거리 강 건너편 (안개 속)
  대사 없음

[DIA-004]
  고루 얼굴 (측면)
  표정: 무표정·냉정
  독백 말풍선: 「강이 불었다.」
  ※ 마침표 필수 — 고루 독백 스타일

--- PAGE 2 ---

[BG-005]
  배경 전환: 고구려 진영 내부 (천막)
  을지문덕 장군 앉아 지도 봄
  촛불 하나 (어두운 분위기)

[DIA-006]
  을지문덕 클로즈업
  표정: 깊이 생각하는 눈빛
  대사: 「수나라는 아직 강을 건너지 않았다.」

[DIA-007]
  고루 진입 컷
  자세: 한쪽 무릎 꿇고 보고
  대사: 「선생. 수군(水軍) 30만이 강 북안에 집결했습니다.」

[EMO-008]
  을지문덕 눈 클로즈업
  미묘한 미소 (보이지 않는 계획)
  대사: 「기다려라.」

[ACT-009]
  SFX 전용 컷
  「기다려라」말풍선 = 공중에 울림
  배경: 강물 소리 시각화 (파문 이펙트)
  이 컷은 세로 길게 (스크롤 멈춤 유도)
```

### 2화: 「사비성의 등불」

```
[TITLE 컷]
  이미지: 사비성 야경 (연등 수천 개)
  텍스트: 제2화 「사비성의 등불」

--- PAGE 1 ---

[BG-001]
  배경: AD 659년 / 사비성 / 연등 행사 밤
  묘사: 백마강 위 등불들이 흘러감
  색감: 따뜻한 황금빛 (백제 테마)
  자막: 「AD 659. 사비성(泗沘城). 백제」

[ACT-002]
  아랑 등장 (군중 속)
  손에 등불 하나 들고 있음
  위를 올려다보는 시선

[EMO-003]
  아랑 얼굴 클로즈업
  표정: 복잡한 감정 (아름다움 + 불안)
  독백: 「아름답다.」

[DIA-004]
  아랑 시점: 강 위 등불들
  묘사: 등불 수천 개가 강물에 비침
  독백 (작은 말풍선): 「...다 기억해야 해.」

--- PAGE 2 ---

[ACT-005]
  아랑, 품에서 죽간 꺼냄
  어두운 구석에서 붓 꺼내는 손 클로즈업

[DIA-006]
  아랑 정면 컷
  표정: 결의
  대사: 「기록하지 않으면 사라진다.」
  ※ 아랑 스타일 — 주체적·지적

[BG-007]
  배경: 미래사 9층 목탑 (배경 장식)
  아랑의 작은 실루엣 (대비 — 웅장함 표현)
  SFX: 「스윽」 (붓이 죽간 위를 긁는 소리)

[EMO-008]
  죽간에 쓴 글자 클로즈업:
  「AD 659년 연등 행사. 사비성 백마강.
   강이 기억하듯 나도 기억한다.」
  (이 컷은 독자가 텍스트를 읽도록 세로 긴 컷)
```

## 전투 씬 스크립트 가이드

```
황산벌 전투 씬 (660년):

원칙:
  - 컷당 1~2명 집중 (전체 컷 최소화)
  - 소리 SFX 적극 활용
  - 관창의 마지막 돌격: 세로 긴 컷 × 3 연속

샘플 스크립트:

[ACT-BAT-001]
  묘사: 황산벌 전체 조감 (먼지·혼전)
  SFX: 「콰콰콰콰」 (말발굽)
  규모감 표현 컷 (작은 캐릭터들)

[ACT-BAT-002]
  하린 클로즈업 (말 위)
  표정: 결의·땀
  대사: 「다시 간다!」
  SFX: 「히힝」 (말 울음)

[ACT-BAT-003 — 세로 길게]
  관창의 단독 돌격
  묘사: 작은 인물이 적진 향해 달림
  배경: 적군 무수히 많음
  대사 없음
  분위기: 침묵의 용기

[EMO-BAT-004]
  하린 눈 클로즈업
  눈빛: 충격·눈물 참음
  대사 없음 (그림만)

[SFX-BAT-005]
  관창의 낙마 SFX 컷
  「쾅」+ 흙먼지 이펙트
  색감: 붉은빛 (전투의 격렬함)
```

## 표준 말풍선 사용 기준

```
캐릭터별 말풍선 디자인:
  고루: 사각형 말풍선 (각지고 단호)
        선 굵기: 2pt
        폰트: 명조 Bold

  아랑: 타원형 말풍선 (부드러운 곡선)
        선 굵기: 1.5pt
        폰트: 명조 Regular

  하린: 불규칙 말풍선 (에너지 표현)
        선 굵기: 2.5pt
        폰트: 고딕 Bold

  니문: 점선 말풍선 (몽환적·흐린)
        선 굵기: 1pt (점선)
        폰트: 명조 Light

특수 말풍선:
  독백: 구름형 말풍선 (작고 흐림)
  내레이션: 박스형 (배경 박스)
  SFX: 말풍선 없음 (효과음만 텍스트)
```

## 화면 분할 기준

```
단일 컷: 감정·중요 장면
2분할 (세로): 두 캐릭터 대화
3분할 (가로): 시간 경과·연속 동작
4분할 (격자): 빠른 전개·혼전
전페이지 컷 (풀페이지):
  - 역사적 결정 순간
  - 전투 클라이맥스
  - 감동적 재회

세로 긴 컷 (2배 높이):
  - 건물·자연 웅장함 표현
  - 충격·공포 연출
  - 클리프행어 마지막 컷
```

## QA 체크리스트 (스크립트 완성 전)

```
□ 고루 대사에 물음표 없는가
□ 아랑이 직접 전투 참여하는 컷 없는가
□ 역사 날짜·지명 연표와 일치하는가
□ 왕국별 색채 테마 지시 포함했는가
□ 클리프행어 컷 (세로 긴) 화당 1개 이상인가
□ 컷 수 50~70컷 범위인가
□ 대사 1말풍선 40자 이내인가
□ 배경 컷 비율 10~15% 범위인가
```
