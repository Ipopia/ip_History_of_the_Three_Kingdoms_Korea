## 복식 고증 원칙

```
삼국(三國) 복식 3원칙:

1. 역사 고증 우선 (History First)
   삼국사기·삼국유사·고분벽화·출토 유물 기반
   무용총·삼실총(고구려), 무령왕릉(백제), 금관총(신라) 참조

2. 왕국별 차별화 (Kingdom Identity)
   색채·재질·문양·장신구로 즉각적 왕국 식별 가능
   5초 이내 왕국 식별 가능한 시각적 특징 필수

3. 현대적 가독성 (Modern Readability)
   고증 기반이되 현대 시청자/독자가 아름답다고 느낄 것
   과도한 고증 집착보다 시각적 임팩트 우선 (단, 기본 고증 준수)
```

## 고구려 복식

### 기본 구성

```
남성 기본 복식 (무관 기준):
상의: 유(襦) — 짧은 상의, 겉섶 오른쪽 여밈 (우임)
하의: 고(袴) — 폭 넓은 바지 (기마 편의)
허리: 혁대(革帶) — 과대(鈍帶) 형식 금속 버클
겉옷: 포(袍) — 소매 좁은 직령포
신발: 화(靴) — 가죽 장화 (기마용)

여성 기본 복식:
상의: 단유(短襦) — 짧고 몸에 밀착
하의: 상(裳) — 주름치마, 발끝까지
허리: 세腰帶 — 가는 허리띠
겉옷: 천(川)자형 선 장식

색채 기준:
주색: 암청 #2F4F7F (군복·공식 의례)
보조색: 철회 #708090 (무구·장식)
금속: 청동·철 (장신구)
장식: 삼족오 문양 필수 포함

무관 전투 복식:
찰갑(札甲): 소형 철판 연결 갑옷
투구: 종정형(縱頂形) — 세로 능선 특징
각반: 가죽 각반 (다리 보호)
보호: 어깨·상완 철판 보호대
```

### 계급별 복식 코드

```
대막리지·대장군:
- 금제 투구 장식 (삼족오 금 부조)
- 홍색 겉포 (전투용 붉은 망토)
- 금동제 허리띠 버클

중급 장교 (고루 기준):
- 철제 찰갑 (은도금 요소 포함)
- 청색 깃발 문양 의복
- 실용적 기마용 바지

일반 병사:
- 가죽 갑주 또는 경량 철갑
- 단순 문양 포
- 전투 목적 최소 장식

궁중 문관:
- 복두(幞頭) — 검은 모자
- 단령포(團領袍) — 둥근 깃 장포
- 비단 재질, 계급별 색상 차등
```

### 고구려 복식 고증 출처

```
주요 참조 유물:
무용총 벽화 (길림성 집안):
  - 수렵도: 기마 궁수 복식 상세
  - 무용도: 여성 복식 주름 스커트
  - 씨름도: 남성 기본 유고 확인

삼실총 벽화:
  - 행렬도: 관료·장군 의복 계급 차이

안악 3호분 벽화 (황해도):
  - 귀족 가족 초상 — 상류층 복식
  - 시녀·무사 복식 세부

창작 허용 요소:
고루의 「살수의 창」고정 소지
연개소문 오도 — 역사 기록 기반 창작
```

## 백제 복식

### 기본 구성

```
남성 기본 복식 (귀족 문관 기준):
상의: 유(襦) — 고구려보다 길고 우아한 라인
하의: 고(袴) — 비단 재질, 좁은 직선형
겉옷: 포(袍) — 직령교임포 (사선 여밈)
모자: 관(冠) — 백제 특유의 금동 관식
신발: 이(履) — 비단 신발, 금동 장식

여성 기본 복식:
상의: 반비(半臂) — 소매 없는 조끼형 상의
하의: 군(裙) — 긴 치마, 풍성한 실루엣
장신구: 금제 귀걸이·목걸이·팔찌

색채 기준:
주색: 왕실금 #B8960C (왕실·귀족 공식)
보조색: 백자백 #F5F5DC (의례·고급 의복)
보조색: 봉황홍 #C41E3A (왕실 행사)
장식: 봉황·연꽃 문양 필수

아랑 기본 복식:
- 남색 포에 금색 봉황 선 장식
- 문서관 인장 허리띠 장식
- 실용적 소매 (문서 작업용)
```

### 계급별 복식 코드

```
왕·왕실:
- 금동관(金銅冠) — 꽃잎 형태 관식
- 황금 허리띠 버클 (과대)
- 비단 옥색·금색 포

귀족 문관:
- 오라관(烏羅冠) — 검은 비단 관
- 계급별 색 포 (1품=자/2품=단/3품=비색)
- 금동·은동 장식 차등

하급 문관 (아랑 기준):
- 검은 복두 + 회색 단령포
- 붓·먹 항상 소지
- 실용적 문서관 복식

무장:
- 찰갑 경량형
- 환두대도 (고리 손잡이 도)
- 비늘갑주 (鱗甲)
```

### 백제 복식 고증 출처

```
주요 참조 유물:
무령왕릉 (충남 공주, 1971년):
  - 금제 관식 (왕·왕비)
  - 금동제 신발
  - 유리 장신구 (목걸이·팔찌)
  - 대도 (환두대도 실물)

백제 금동대향로 (충남 부여):
  - 봉황 장식 형태
  - 인물상 74인 복식 묘사

창작 허용 요소:
아랑의 봉황 단검 (문서관 호신 — 창작)
왕실 서신 봉인 방식 (세부 창작)
```

## 신라 복식

### 기본 구성

```
남성 기본 복식 (화랑 기준):
상의: 유(襦) — 몸에 밀착, 활동 편의
하의: 고(袴) — 중간 폭, 기동성 우선
겉옷: 포(袍) — 화랑 색 (자·적)
모자: 화랑 상투 (금 비녀) — 귀족 금관 가정
신발: 이(履) — 가죽 실용화, 장화 없음 (경무장)

장신구 (신라 특유):
금관(金冠): 왕족 전용 — 출자형 나뭇가지
금귀걸이: 귀족 일반 착용 — 심엽형·태환식
금팔찌: 여성 필수 장신구
금제 허리띠: 과대(銙帶) — 금판 연결형

색채 기준:
주색: 황금 #FFD700 (금관·장신구)
보조색: 자주 #800080 (화랑·귀족 의복)
보조색: 옥색 #40826D (여성 상류층)
장식: 금관·금관 나뭇가지·자작나무 문양

하린 기본 복식:
- 자색 화랑 포 + 금색 선
- 화랑 상징 금 비녀
- 쌍검 허리 착용 (좌우 양쪽)
- 경무장형 — 기동성 최우선
```

### 계급별 복식 코드

```
왕족·왕:
- 금관(金冠) — 출자형 세움 장식
- 금동제 전신 장신구
- 비단 포 (황색·자색)

화랑 정식:
- 자색 포 (화랑 색)
- 금 비녀 (신분 표시)
- 쌍검 또는 단검 + 활
- 원형 소형 방패 (기동성)

여왕 (선덕여왕):
- 금관 변형형 (여성 형태)
- 옥 장신구 조합
- 비단 자색 장포

일반 귀족 여성:
- 금귀걸이 필수
- 자작나무 껍질 문양 장식 (천마도 기반)
```

### 신라 복식 고증 출처

```
주요 참조 유물:
금관총 금관 (경주, 1921):
  - 국보 제87호
  - 출자형 나뭇가지 세움 장식

천마총 천마도 (경주, 1973):
  - 국보 제207호
  - 자작나무 껍질 + 천마 그림

교동 금관 / 서봉총 금관:
  - 다양한 금관 형태 참조

경주 금제 장신구:
  - 심엽형 금귀걸이
  - 누금 기법 금팔찌

창작 허용 요소:
화랑 귀걸이 비밀 무기 (역사 기록 없음 — 창작 명기)
하린의 쌍검 착용 (역사 사례 창작 해석)
```

## 가야 복식

### 기본 구성

```
남성 기본 복식 (장인·무사 기준):
상의: 유(襦) — 실용적, 활동 편의 우선
하의: 고(袴) — 작업용 폭 넓은 바지
겉옷: 없거나 간단한 포 (장인 작업 환경)
신발: 가죽 신 (강변 생활 대응)

장신구:
철제 팔찌·목걸이 (가야 특유 — 금 아닌 철)
토기 문양 장식 (가야 특유 도질 토기 문양)

색채 기준:
주색: 토황 #C8A96E (흙·철·자연)
보조색: 강청 #5F9EA0 (강물 연상)
보조색: 철흑 #2F2F2F (제철 작업 환경)
장식: 철 문양, 구지봉 봉황 (간략화)

니문 기본 복식:
- 토황색 기본 포 (가야 유민 전통)
- 가야금 운반용 보자기 천
- 철정 방패 (가야 철판 최고급)
- 악사의 긴 소매 (연주 시 소매 걷음)

가야 멸망 이후 (신라 편입 2세대):
- 기본 신라 복식 채택
- 가야 전통 장신구 유지 (정체성 표현)
- 신라 복식 + 가야 액세서리 혼합 = 니문 특유 스타일
```

### 계급별 복식 코드

```
가야 왕족 (수로왕 시대 참조):
- 금관 형태 (신라와 유사하되 단순형)
- 금제 장신구 (대성동 고분군 출토)
- 비단 포 (교역품)

가야 장인 계층:
- 실용적 작업복
- 철제 장신구 (금보다 철 선호)
- 두꺼운 가죽 보호대 (제철 작업)

가야 악사 (니문 계층):
- 중간 신분 복식
- 가야금 케이스 (전통 보자기)
- 정제된 포 (공연 시)
```

### 가야 복식 고증 출처

```
주요 참조 유물:
대성동 고분군 (경남 김해):
  - 금관가야 지배층 복식 관련 유물
  - 철기·금제 장신구 대거 출토

도항리·말산리 고분군 (경남 함안):
  - 아라가야 중심 유적
  - 판갑(板甲) 실물 — 가야 특유 철판갑

국립김해박물관 소장 유물:
  - 가야 철기 제작 기법
  - 토기 문양 참조

창작 허용 요소:
니문의 「강의 기억(江憶)」가야금 전래품
가야 유민 2세대 혼합 복식 (역사적 추정 + 창작)
```

## 미디어별 복식 적용 기준

### 드라마

```
제작 기준:
- 고증 90% + 현대 미감 10%
- 실제 제작 가능한 재질 우선
- 비단·가죽·철 소재 구현
- 세탁·내구성 고려한 의상 복수 제작

주의:
- 촬영 시 색 재현: 조명별 색 테스트 필수
- 황금색 → 촬영 시 over-exposure 주의
- 금관 무게: 실제 착용 가능 레플리카 제작 (3kg 이하)

연출 규칙:
왕국 전환 장면: 복식 색채 변화로 즉각 식별 가능
전투 씬: 갑주 손상 = 캐릭터 드라마투르기 반영
감정 씬: 장신구 탈착 (공식 → 비공식 자아)
```

### 애니메이션

```
제작 기준:
- 선의 복잡도 최소화 (애니 작화 효율)
- 색상 수 제한: 복식 당 최대 5색
- 문양 단순화 (원화·중간 동화 효율)

왕국별 실루엣 차별화 (애니 기준):
고구려: 넓은 어깨·투구 실루엣
백제: 우아한 곡선·긴 소매
신라: 금색 액센트·직선
가야: 땅딸막한 실용형
```

### 게임

```
제작 기준:
- 3D 모델 기준 복식 LOD (Level of Detail) 3단계
- 스킨 시스템: 기본 복식 + 고증 대안 + 창작 특별 스킨

스킨 카테고리:
HISTORICAL: 역사 고증 복식 (기본)
FESTIVAL: 명절·축제 의상 (창작)
LEGENDARY: 역사 LEGENDARY 유닛 전용
COLLABORATION: 타 IP 콜라보 한정
```

### 피규어·굿즈

```
1/7 스케일 피규어 복식:
- 최고 정밀도 — 드라마 의상 1:1 재현
- 금속 도장: 금관·갑주 메탈릭 처리
- 직물: 실제 천 사용 (섬유 파츠)

머천다이즈 복식 응용:
- 티셔츠: 복식 실루엣 그래픽
- 에코백: 각 왕국 문양 (삼족오/봉황/금관/철)
- 포스터: 복식 세부 일러스트
```

## 복식 금지 요소 (고증 오류 방지)

```
절대 금지:
① 고구려 복식에 봉황 문양 → 백제 전용
② 신라 복식에 삼족오 → 고구려 전용
③ 가야 복식에 금관 (고급형) → 가야는 철 중심
④ 왜(倭) 복식 영향 표현 → IP 방침 금지
⑤ 중국 한족 복식 직접 차용 → 반드시 한국화
⑥ 이질적 시대 복식 혼용 (조선시대·현대 요소)

주의 요소:
- 불교 관련 복식 (승복 등): ADV-HISTORY 자문 필수
- 왜국 사절단 복식: 일본서기 기반이되 정치적 민감성 검토
- 가야 복식: 임나일본부 연상 금지 — 독립적 가야 양식 강조

상류층 직물:

서민 직물:

  갈포(葛布): 칡 섬유 — 여름용
  면(棉): 삼국시대 미사용 (고려 말 1364년 문익점 도입)

창작 허용:
  소재 질감 묘사 시 과도한 면 강조 금지

```

### 특수 복식 (의례·전투)

```
의례복:
  제사(祭祀) 복식: 백색 기반 + 왕국별 포인트 색
  혼례: 대례복 — 왕족은 금관+풀 세트
  상례(喪禮): 백색·회색 (삼베 상복)

전투 완전무장:
  고구려: 전신 철갑(鎧甲) — 중장기병
  백제: 경갑(輕甲) — 기동성 우선
  신라: 소철찰갑 + 방패
  가야: 철갑 + 장창(長槍) 조합
```

### 창작 인물별 복식 상세

```
고루 (고구려 무관):
  기본: 철갑 (鐵甲) — 소찰갑(小札甲) 형식, 가죽 + 쇠 조각 연결
  투구: 종형 투구 (縱形兜) — 정수리 솟음
  색: 철회색·감청 기본 (초반) → 적색 장식 추가 (성장 후)

아랑 (백제 기록관):
  의: 담청색 포 (기록관 직책 색)
  하의: 치마 + 겉치마 (이중 착장)
  소지품: 붓통, 죽간(竹簡) 보관함
  색 변화: 초반 밝은 청색 → 후반 청흑 (비극성 표현)

하린 (신라 화랑):
  복: 화랑복 — 청·녹색 계통 무관복
  갑옷: 소철찰갑 + 가죽 어깨보호구
  특징: 고구려 갑옷보다 경쾌·기동적

니문 (가야 악사):
  의: 가야 전통 — 백색·황금색 배합
  바지: 넓은 고(袴) — 앉아 연주하기 편한 형태
  장신구: 가야 특유의 철제 장신구 (철의 왕국)
  색 변화: 초반 백색(가야 색) → 후반 회색·흑색 혼합 (정체성 혼란)
  머리: 가야 전통 상투 → 신라 동화 후 신라식 관 쓰기 (갈등 장면 활용)
```
