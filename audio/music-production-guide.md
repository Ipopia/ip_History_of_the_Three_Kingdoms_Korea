## 음악 제작 철학

```
삼국(三國) IP 음악 3원칙:

1. 역사 악기 우선:
   가야금·거문고·해금·피리·장구 = 핵심 음색
   현대 오케스트라와 층위를 분리하여 배합

2. 왕국별 음악 정체성:
   각 왕국마다 고유 조성·악기·리듬 체계 유지
   혼용 금지 (고구려 악기가 백제 장면에 나오면 안 됨)

3. 주제 통일성:
   「강은 기억한다」메인 테마가 전 매체 관통
   캐릭터 테마가 주제 테마의 변형으로 연결
```

## 메인 테마

### 「강은 기억한다 / THE RIVER REMEMBERS」

```
조성: D단조 → D장조 (비극에서 희망으로)
빠르기: ♩=72 (느린 물의 흐름)
구조: 서주(16마디) → 주제(32마디) → 발전(64마디) → 재현(32마디) → 코다

편성:
  서주: 가야금 독주 (니문 테마 연결)
  주제: 가야금 + 현악 4중주
  발전: 풀 오케스트라 + 한국 타악 (장구·북)
  코다: 가야금 + 합창 (무가사 허밍)

음악적 특징:
  살수 모티프: 하행 5도 (물이 흐르는 느낌)
  전투 모티프: 부점 리듬 (갑주 소리)
  기억 모티프: 반복 오스티나토 (기억의 집요함)

버전:
  Full (5분 30초): 영화·애니메이션 타이틀
  Short (1분 30초): 게임 메인 메뉴
  Piano Solo: 뮤지컬·콘서트
  가야금 Solo: 니문 개인 테마 연주
  Choral: 뮤지컬 피날레
```

## 왕국별 음악 정체성

### 고구려 음악

```
핵심 악기:
  거문고 (玄琴): 두껍고 낮은 현 소리
  대금 (大笒): 날카롭고 힘찬 관악
  북 (鼓): 군사 타격음
  징 (鉦): 진군 신호

조성·음계:
  주 조성: B♭단조
  음계: 한국 전통 계면조 (슬픔·웅장)
  특징: 낮은 음역대, 느리고 무거운 리듬

리듬:
  기본: 3박 (세마치) → 전투: 2박 (엇박)
  빠르기: 느림 (♩=60~80)

대표 테마: 「살수의 전략가 — 고루 테마」
  거문고 낮은 선율 + 대금 고음 → 전략가의 이중성
  고요한 시작 → 점진적 고조 (살수 범람처럼)
```

### 백제 음악

```
핵심 악기:
  가야금 (백제 버전): 섬세하고 화려
  해금 (奚琴): 서정적 현악
  단소 (短簫): 청아한 소음
  소고 (小鼓): 경쾌한 박자

조성·음계:
  주 조성: G장조 / E♭장조
  음계: 평조 (밝고 우아)
  특징: 밝은 음역, 화성 풍부

리듬:
  기본: 12박 (타령) → 의례: 6박 (중모리)
  빠르기: 중간 (♩=90~110)

대표 테마: 「사비성의 기록 — 아랑 테마」
  해금 + 가야금 이중주 (기록자와 기억의 조화)
  연등 장면: 단소 솔로 + 오케스트라 crescendo
  낙화암 장면: 해금 고음 + 피치카토 현악
```

### 신라 음악

```
핵심 악기:
  향비파 (鄕琵琶): 화려하고 힘찬 현악
  피리 (篳篥): 날카롭고 긴박한 관악
  장구 (杖鼓): 역동적 타악
  요령 (搖鈴): 화랑 의례용

조성·음계:
  주 조성: D장조 / A장조
  음계: 평조 변형 (밝고 역동)
  특징: 빠른 템포, 상승 선율

리듬:
  기본: 4박 (동살풀이) → 전투: 8분음표 연속
  빠르기: 빠름 (♩=120~140)

대표 테마: 「화랑의 검 — 하린 테마」
  향비파 빠른 아르페지오 + 피리 선율
  입단식: 요령 + 장구 행진 리듬
  황산벌: 오케스트라 포르티시모 + 피리 고음
```

### 가야 음악

```
핵심 악기:
  가야금 (12현): IP 핵심 악기
  철현금 (鐵絃琴): 가야 특유의 금속 현 [창작]
  소금 (小琴): 소형 관악
  철 타악: 철 단조 소리 → 음악화

조성·음계:
  주 조성: E단조 / A단조
  음계: 계면조 (슬픔·그리움)
  특징: 중간 음역, 여백 많은 선율

리듬:
  기본: 5박 (가야 독자 박자 [창작]) → 연주: 자유박
  빠르기: 다양 (♩=50~120, 감정에 따라)

대표 테마: 「가야금 소리 — 니문 테마」
  가야금 독주 (다른 악기 최소화)
  철 타악 + 가야금: 「철이 소리가 되다」
  마지막 연주 「676」: 가야금 솔로 → 서서히 사라짐
```

## 레코딩 가이드

### 악기 연주 고증

```
가야금:
  12현 정간보 기반 연주
  현대 개량 가야금 사용 가능 (단 음색 고증 확인)
  추천 주법: 살갱이·뜯기·오른손 압현

거문고:
  술대 주법 (술대 = 대나무 채)
  낮은 음역 강조
  현대 사용 시 마이크 포지션 주의

대금:
  청공법 (청 떨림음) 활용
  고음역 날카로움 = 고구려 장군 이미지

해금:
  활 주법 특성상 지속음 가능
  백제 서정적 선율에 최적
```

### 레코딩 환경

```
세션:
  녹음실: 한국음악 전용 어쿠스틱 공간
  오케스트라: 60~80인 (전투 씬)
  전통 악기: 별도 세션 (혼합 후 합성)

마스터링:
  드라마: Dolby Atmos 7.1.4
  스트리밍: 44.1kHz / 24bit
  게임: OGG Vorbis (Q6~8)
  뮤지컬: 48kHz / 24bit (공연용)

납품 포맷:
  원본: WAV 96kHz/32bit
  스트리밍: FLAC 44.1kHz/24bit
  게임 루프: 정확한 루프 포인트 표시
```
