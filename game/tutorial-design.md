## 튜토리얼 철학

```
핵심 원칙:
  「역사를 플레이하면서 배운다」

3원칙:
  ① 역사 서사 = 튜토리얼 내러티브 (별도 설명창 최소화)
  ② 점진적 복잡도: 쉬운 메커닉 → 복잡한 전략 순서
  ③ 실패 허용: 튜토리얼 전투 패배 시 재시도 가능

튜토리얼 목표:
  완료 시간: 15~20분
  학습 완료: 기본 전투 + 왕국 선택 + 자원 관리
  감성 연결: 캐릭터 첫 만남 → 감정 이입 유발
```

## 튜토리얼 플로우

### 단계 0: 프롤로그

```
씬 구성:
  [씬 1] 살수 강물 흐름 — 카메라 클로즈업
    텍스트: 「612년, 고구려. 살수의 강은 모든 것을 기억한다.」
    인터랙션: 화면 탭 → 물결 이펙트

  [씬 2] 4왕국 심벌 등장
    각 심벌 탭 → 왕국 소개 영상 3초
    「어느 왕국의 이야기를 시작하시겠습니까?」

  [씬 3] 고루(고구려) 등장 (첫 플레이 고정)
    대사: 「내 이름은 고루. 나는 살아남는 자가 아니라
           기억되는 자가 되려 한다.」
```

### 단계 1: 첫 전투 (1:1 전투 튜토리얼)

```
배경: 살수 강변 소규모 교전
적군: 수나라 선발대 (단일 유닛 5기)
아군: 고루 + 고구려 보병 3기

학습 목표:
  □ 유닛 선택 (탭)
  □ 이동 명령 (드래그)
  □ 공격 명령 (적 유닛 탭)

안내 방식:
  반투명 손가락 가이드 → 첫 행동 유도
  실패 시 → 부드러운 힌트 재표시

전투 종료:
  승리 연출: 「살수를 지켰다!」
  보상: 「살수의 병사」유닛 획득
```

### 단계 2: 지형 활용

```
배경: 좁은 협곡 매복 포인트
적군: 수나라 궁병 4기
아군: 고루 + 보병 + 「고구려 기병」1기

학습 목표:
  □ 지형 효과 (숲=방어+, 고지=공격+, 강=이동--)
  □ 포위 공격 (측면 공격 보너스)
  □ 유닛 조합 (보병+기병 협력)

고루 대사: 「지형을 알면 절반은 이긴 것이다.」
보상: 전술 포인트 50 + 「협곡 전술」스킬 해제
```

### 단계 3: 성 관리

```
배경: 고구려 소형 성곽 (침공 전 준비)
시간: 3턴 제한

학습 목표:
  □ 자원 수집 (농장 탭 → 식량 획득)
  □ 건물 업그레이드 (병영 강화)
  □ 유닛 생산 (보병 2기)
  □ 방어 배치 (성벽 유닛 배치)

3턴 후:
  소규모 수나라 공격 → 방어 전투
  보상: 「강화된 성벽」레벨 2 획득
```

### 단계 4: 캐릭터 스킬

```
학습 목표:
  □ 고루 고유 스킬 「살수 전략」사용
    (적 이동 저지 + 공격력 +30% 1턴)
  □ 스킬 쿨다운 관리
  □ 장군 유닛 우선 격파

스킬 발동 연출:
  살수 강물 이펙트 전장 확산
  고루 대사: 「강은 기억한다. 그리고 나도 기억한다!」

보상: 고루 레벨 3 + 「을지문덕의 가르침」아이템
```

### 단계 5: 외교

```
형식: 대화형 선택지

선택지:
  「가야 소국에 어떻게 접근하겠습니까?」
  ① 동맹 제안 → 외교 포인트 20 소모, 관계 +30
  ② 무역 제안 → 식량 50 소모, 철 30 획득
  ③ 군사 위협 → 관계 -20, 단기 복종 획득

힌트: 「외교는 전쟁보다 강하다. 때로는.」
보상: 외교 포인트 100
```

### 단계 6: 완료

```
완료 씬:
  고루 독백:
  「강이 기억하듯, 이 땅도 기억할 것이다.
   이제 진짜 전쟁이 시작된다.」

완료 보상:
  □ 「살수의 영웅」칭호
  □ 고루 전용 갑옷 스킨
  □ 골드 500 + 식량 200 + 전술 포인트 100
  □ 왕국 선택 해제 (백제·신라·가야 플레이 가능)
```

## 왕국별 별도 튜토리얼 (2회차+)

```
백제 튜토리얼 (아랑):
  외교·무역 집중 + 해군 전투 시스템 소개
  「서해 교역로를 열어라」미션

신라 튜토리얼 (하린):
  화랑 스킬 시스템 집중
  「화랑 훈련 완성」미션

가야 튜토리얼 (니문):
  자원 관리 + 외교 + 음악 미니게임 포함
  「철의 나라 유지」미션
```
