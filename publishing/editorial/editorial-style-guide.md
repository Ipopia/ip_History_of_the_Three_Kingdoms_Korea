## 출판 매체별 스타일 기준

### 1. 정통 소설 (Novel)

#### 문체 기준
| 항목 | 기준 |
|------|------|
| 시제 | 과거형 기본 ("했다" "이었다") |
| 시점 | 3인칭 전지적 작가 시점 (단, 파트별 주인공 시점 변환 가능) |
| 문장 길이 | 단문·중문 혼합 — 평균 25~40자 |
| 단락 길이 | 3~7문장 권장 |
| 대화 비율 | 전체 텍스트의 30~40% |
| 한자 표기 | 고유명사 첫 등장 시 한자 병기: 광개토대왕(廣開土大王) |

#### 금지 표현
- 현대 신조어·인터넷 용어 (단, 웹소설은 허용)
- "~했어요" 체 (소설 내 대화 제외)
- 과도한 형용사 중첩 ("아름답고 빛나고 찬란한")
- 날짜·연도 현대식 표기 (서기 대신 왕력 사용 권장)

#### 시대 표기 기준
```
❌ "612년 7월"
✅ "영양왕 23년, 여름이 기울어 갈 무렵"
또는 ✅ "수 양제 대업 8년의 일이었다"
필요 시 각주: *서기 612년
```

#### 대화 스타일

**왕족 대화**
```
❌ "어서 오시오, 장군."
✅ "경이 왔는가." (간결·위엄)
✅ "짐이 명하노니, 살수로 나아가라." (전통 어투)
```

**장군·귀족 대화**
```
✅ "전하, 적의 선봉이 압록을 건넜습니다."
✅ "신이 감히 아뢰옵니다."
```

**민중 대화**
```
✅ "이봐, 저기 봐. 적군이다!"
✅ "나리, 이 철정을 얼마에 드리오리까?"
```

### 2. 웹소설 (Web Novel)

#### 문체 기준
| 항목 | 기준 |
|------|------|
| 시제 | 과거형 기본, 일부 현재형 허용 (긴장감 연출) |
| 시점 | 1인칭 주인공 시점 권장 |
| 문장 길이 | 단문 우선 — 평균 15~25자 |
| 단락 길이 | 1~3문장 (스마트폰 가독성) |
| 회차 길이 | 2,000~4,000자 (A4 1~2장) |
| 회차 끝 | 반드시 훅(hook) — 다음 화 유인 |

#### 웹소설 특화 요소
```
[시스템 요소 (선택)]
- 스탯 표시: [전투력: 9,800 / 지력: 8,200]
- 스킬 획득: [새 스킬 습득: 수공(水攻) Lv.1]
- 역사 달성: [달성: 살수대첩 완료 — 수나라 격퇴]

[현대 감성 요소]
- 독자 친화적 내면 독백 허용
- 이탤릭체 내면 독백: *이게 말이 되나. 113만이라고.*
```

#### 회차 구조 공식
```
오프닝 훅 (100자): 이전 회차 요약 + 긴장감 유지
전개 (1,500~3,000자): 사건·대화·액션
클리프행어 (100자): 다음 회차 유인 문장
```

### 3. 웹툰 스크립트

#### 컷 분배 기준
| 페이지 유형 | 컷 수 | 비고 |
|------------|------|------|
| 일반 페이지 | 4~6컷 | 표준 |
| 액션 페이지 | 2~4컷 | 컷 크게 |
| 감정 클로즈업 | 1~2컷 | 임팩트 |
| 파노라마 | 1컷 (전면) | 배경 강조 |

#### 스크립트 작성 포맷
```
[화: 01] [페이지: 01] [컷: 01]
장소: 압록강 절벽
시간: 새벽 (어둠 + 여명)
구도: 부감 — 절벽 위 주몽 실루엣
대사: "이 강만 건너면 된다."
효과음: (없음 — 침묵 강조)
연출 메모: 다음 컷 복사 구도로 대비 효과
```

#### 효과음 표기 기준
| 상황 | 한국어 | 영어 버전 |
|------|--------|---------|
| 검 교차 | 챙! / 쨍! | CLANG! |
| 말 달림 | 타닥타닥 | THUD THUD |
| 폭발·충격 | 쾅! | BOOM! |
| 침묵 강조 | (무음 컷) | — |
| 화살 | 슝! | SWOOSH! |

## 캐릭터별 문체 상세 가이드

### 고루 (高婁) — 서술·대사

```
서술 시점 (고루 시점 장면):
  문장 길이: 짧고 단호 (10~15자)
  감정 서술: 최소화 → 행동으로 감정 표현
  시제: 현재형 선호 (긴박감)

  예시:
  ○ 「강물이 불어있었다. 을지문덕 선생의 말이 맞았다.」
  × 「고루는 강물이 불어있는 것을 보고 을지문덕 선생의 예측이 적중했음을 깨달았다.」

대사 어조:
  경어체 사용 (을지문덕·연개소문에게)
  반말 없음 (모두에게 존중)
  의문형 금지 — 고루는 질문하지 않는다
  감탄사 금지 (「아!」「이런!」류)

  확정 어조 예시:
  「강은 기억한다.」(마침표 필수 — 물음표 금지)
  「따라오라.」「기다려라.」(명령형 허용)
  「알겠다.」(단답 허용)
```

### 아랑 (阿郞) — 서술·대사

```
서술 시점 (아랑 시점 장면):
  문장 길이: 중간~긴 (20~40자)
  감정 서술: 풍부하게 → 기억·기록의 감각
  묘사: 시각적 세밀함 (붓글씨·자수·향기)

  예시:
  ○ 「등불 하나가 꺼졌다. 아랑은 그것을 바라보며 죽간의 여백을 생각했다. 기록되지 않은 것들은 어디로 가는가.」

대사 어조:
  정중하지만 지적
  스스로 생각하는 문장 (주체적)
  침묵보다 말로 표현하는 성격
  「…기억해야지」「…기록해두어야겠어」류 내면 독백 가능

금지:
  울음·히스테리 직접 표현 금지 (절제된 감정)
  전투 참여 대사 금지
```

### 하린 (夏麟) — 서술·대사

```
서술 시점 (하린 시점 장면):
  문장 길이: 짧고 빠름 (7~12자)
  감정: 직접적 표현 (분노·기쁨·슬픔 즉각 서술)
  리듬: 행동 중심 (생각보다 움직임이 먼저)

  예시:
  ○ 「검을 뽑았다. 적이 셋이었다. 아무래도 좋았다.」
  × 「하린은 세 명의 적을 보았고, 자신이 불리하다는 것을 알았지만 두렵지 않았다.」

대사 어조:
  직접적·충동적 (S1)
  절제·성숙 (S3 — 문장 조금 길어짐)
  동료에게 반말 가능 (같은 화랑)
  선덕여왕에게만 경어

  S1 예시: 「가자!」「해치워!」
  S3 예시: 「지금은 아니야. 때를 봐야 해.」
```

### 니문 (尼文) — 서술·대사

```
서술 시점 (니문 시점 장면):
  문장 길이: 불규칙 (3자~30자 혼용)
  감정: 간접 표현 → 자연·음악으로 감정 치환
  여백: 「…」활용 많음 (불완전한 문장 허용)

  예시:
  ○ 「강이 흘렀다. 가야금 줄이 울렸다. 가야는 여기에 있었다.」
  ○ 「나라는 사라졌다. 소리는… 아직.」

대사 어조:
  최소화 → 가야금으로 감정 표현
  말할 때: 시적·단편적
  감탄사: 없음
  반말·경어: 상황별 (기본 경어, 친밀한 경우 반말)

  예시:
  「강이 기억해. 내가 사라져도.」
  「…가야금 소리 들어봐.」
```

## 문장부호 캐릭터별 사용 규칙

```
마침표:
  고루 대사: 마침표 필수 (「강은 기억한다.」)
  니문 대사: 「…」 적극 활용

느낌표:
  하린 전용 (S1 집중)
  남용 금지 (3개/페이지 이내)

물음표:
  고루: 사용 금지
  아랑: 독자에게 던지는 질문 가능
  하린: S1에서 가능
  니문: 사용 최소화

줄임표 「…」:
  니문: 적극 활용
  고루: 사용 가능 (단 1~2회/장)
  남용 금지 (아랑·하린은 절제)

인용부호:
  대사: 「」(겹낫표)
  생각·독백: 〔〕또는 이탤릭체
  강조어: 『』(쌍겹낫표) — 핵심 대사만
```

## 편집 완료 전 QA 체크리스트

```
캐릭터 연속성:
  □ 각 캐릭터 어조가 가이드와 일치하는가

  □ 아랑이 직접 전투하는 장면이 없는가
  □ 니문이 전투에 참여하는 장면이 없는가

역사 고증:
  □ 날짜·연도 역사 연표와 일치하는가
  □ 관등·지명 표기가 glossary.md 기준인가
  □ 창작 요소에 표시가 있는가

문체:
  □ 분량 기준 준수 여부
  □ 한자 표기 기준 준수 여부
  □ 문장부호 가이드 준수 여부

크로스미디어 일관성:
  □ continuity-checklist.md 항목 충족 여부
  □ 타 매체와 상충되는 내용 없는가
```
