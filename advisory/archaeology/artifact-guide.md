## 고구려 유물

### 고분벽화 (주요 참조)

```
핵심 벽화 (창작 참조 필수):

무용총(舞踊塚):
  소재: 중국 지린성 집안
  내용: 수렵도·무용도 — 고구려 귀족 생활 묘사
  활용: 복식·건물·생활 장면 참조
  특징: 선명한 붉은·검정·노랑 채색

수산리 고분:
  소재: 평안남도 (북한)
  내용: 귀족 행렬·생활 장면
  활용: 귀족 복식·마차·건물 참조

쌍영총:
  내용: 전차·기마 행렬
  활용: 군사 장면·무기·갑옷 참조

삼실총:
  내용: 다양한 인물·동물
  활용: 고구려 신화 생물 참조

IP 창작 적용:
  고루·을지문덕 복식 = 무용총 인물 비율 기반
  성벽·성문 묘사 = 안악 3호분 벽화 건물 참조
```

### 고구려 유물 목록

```
무기·갑옷:
  소찰갑(小札甲): 쇠판을 연결한 갑옷 (출토 예 다수)
  환두대도(環頭大刀): 손잡이 고리형 대도 (다수 출토)
  철촉(鐵鏃): 쇠화살촉 (여러 형태)
  등자(鐙子): 말 발판 (고구려 개발 추정)

생활·장식:
  금동 관장식: 귀족 관모 장식
  금귀고리: 세환이식(細環耳飾) 형태
  유리 구슬: 교역품 (서역·중국 수입)

건축:
  기와: 연꽃·수막새·암막새 문양
  고구려 기와 특징: 선명한 문양, 두꺼운 두께

IP 적용 주의:
  고구려 고분 상당수 북한 소재 → 직접 실측 불가
  중국 집안(集安) 출토품으로 보완 연구
```

## 백제 유물

### 무령왕릉 (武寧王陵) — 최중요

```
소재: 충남 공주 (국립공주박물관)
발굴: 1971년 — 삼국시대 유일 피장자 확인 능

주요 출토품:
  ① 금동관모(金銅冠帽):
     화염 문양 + 달개(영락) — 백제 왕실의 상징
     IP 적용: 의자왕·아랑 주변 귀족 묘사 기준

  ② 금제 귀걸이:
     금 세공 기술 = 동아시아 최고 수준
     IP 적용: 백제 귀족 여성 장신구

  ③ 목관 장식:
     동아시아 최고급 목재 + 금·은 장식

  ④ 지석(誌石):
     「영동대장군 백제 사마왕...」기록
     무령왕 생몰년 확인 → 백제 연대 기준

창작 활용:
  ✅ 아랑의 화려한 장신구 = 무령왕릉 기준
  ✅ 의자왕 의관 = 무령왕릉 관모 발전형
```

### 백제 금동대향로 (百濟金銅大香爐)

```
소재: 충남 부여 (국립부여박물관)
발굴: 1993년 — 백제 최고 예술품

묘사:
  뚜껑: 74명 인물 + 12종 동물 조각
  봉황 정상 장식
  높이 61.8cm

의의:
  백제 불교·도교·신선 사상 종합
  백제 금속 공예 최고 걸작

IP 적용:
  아랑 기록관 배경 = 금동대향로 복제품 배치
  백제 문명의 화려함 상징 오브제
  게임 내 백제 특수 건물 「대향로 제작소」 기반
```

### 백제 도기·토기

```
백제 흑색 마연 토기:
  특징: 검고 윤기 있는 표면
  용도: 귀족 식기·제사용기
  IP 적용: 사비성 연회 장면 식기 묘사

백제 연꽃 문양 기와:
  사비 도성 출토
  섬세한 연꽃 문양 = 불교 영향
  IP 적용: 사비성 건물 지붕 묘사
```

## 신라 유물

### 신라 금관 (金冠)

```
출토지: 경주 금관총·천마총·황남대총 등
소재: 국립경주박물관·국립중앙박물관

특징:
  세움 장식: 나뭇가지·사슴뿔 형태
  영락(瓔珞): 금판 + 옥 장식 수십 개
  높이: 약 27~32cm
  무게: 약 1kg 이하 (의례용, 일상 착용 불가)

IP 적용:
  선덕여왕 왕관 = 신라 금관 기반 (창작 발전형 허용)
  화랑 의식 장면 = 금관 착용 의례
  일상 착용 장면 = 금관 미착용 (의례 시만)
```

### 천마도 (天馬圖)

```
출토: 경주 천마총 (155호 고분)
소재: 자작나무 껍질 채화판

내용:
  날아오르는 흰 말 그림
  삼국시대 회화 실물 희귀 사례

IP 적용:
  하린의 전투마 = 천마도 이미지 연상
  신라 기병 묘사 참조
  신라 정체성 상징으로 활용
```

### 첨성대 (瞻星臺)

```
소재: 경북 경주 (현존)
건립: 선덕여왕 재위 중 (632~647)
높이: 9.17m — 동아시아 최고(最古) 천문대 추정

구조:
  362개 돌 (1년 날수 연상)
  27단 (선덕여왕 27대 왕)
  기단 12단 (12달)

IP 적용:
  선덕여왕 씬 배경 = 첨성대 건설 중 묘사
  하린과 선덕여왕의 대화 장소 (창작)
  신라 지식·천문의 상징
```

## 가야 유물

### 가야 철기 유물

```
출토지: 김해 대성동 고분, 함안 말이산 고분

주요 유물:
  철정(鐵鋌): 덩이쇠 — 가야의 수출 통화
    판상 + 도끼형 2종
    IP 적용: 니문 가야 묘사, 게임 가야 자원 시스템

  철제 갑옷: 소찰갑 (고구려와 유사)
    판갑(板甲) — 대형 판 연결형 특수 형식

  가야 철모(鐵矛): 대형 창촉
    삼국 중 가장 길고 날카로운 철모

IP 적용:
  가야 = 철의 왕국 → 모든 무기 고품질
  니문 조부 세대 전사 = 철제 전신 갑옷
```

### 가야 토기

```
특징:
  고화도 소성 (灰靑色 또는 黑色)
  각종 동물 장식 (오리형·새형 토기)
  복잡한 부가물 장식

대표 유물:
  가야 기마인물형 토기: 말+기사 형태 도상
  가야 수레바퀴형 토기: 정교한 바퀴 문양
  가야 배형 토기: 선박 형태 → 해상 교역 반영

IP 적용:
  가야 일상 생활 묘사 참조
  니문의 가야 고향 씬 배경 참조
```

## IP 창작 활용 체크리스트

### 유물 등장 시 확인 사항

```
□ 실존 유물 사용 시 ADV-ARCH 확인
□ 연대 고증: 해당 유물이 그 시대에 존재하는지 확인
□ 왕국별 유물 혼용 금지 (신라 금관을 백제 왕이 착용 불가)
□ 창작 유물: 「창작」표기 + 시대 고증 범위 내 설계

연대 오류 방지:
  ✅ 무령왕릉 유물: 6세기 초 고증 (이후 시대에도 유사형 사용 가능)
  ✅ 신라 금관: 5~6세기 집중 출토 (7세기 하린 시대에도 의례용 사용 가능)
  ❌ 고려청자: 삼국시대 등장 절대 금지 (10세기 이후)
  ❌ 조선백자: 삼국시대 등장 절대 금지 (14세기 이후)
```

## 박물관 협력 계획

```
협력 기관:
  국립중앙박물관: 유물 사진 협력 + IP 전시 협약
  국립경주박물관: 신라 고증 자문
  국립부여박물관: 백제 고증 자문
  국립김해박물관: 가야 고증 자문

활용 방법:
  드라마 소품 = 유물 복제품 제작 (허가 필요)
  게임 내 「유물 도감」= 실제 유물 정보 연동
  AI 챗봇 지식 베이스 = 박물관 공식 데이터

공동 기획 가능:
  「삼국(三國) IP × 국립박물관」특별전
  드라마 방영 연계 유물 전시회
  교육 프로그램: 초중고 역사 체험
```
