## 스핀오프 개요

### 프로젝트명
**"가야(伽耶) — 잊혀진 왕국"**
*영문: GAYA — The Forgotten Kingdom*

### 컨셉 선언
> "고구려·백제·신라의 이야기 뒤에, 520년 동안 존재했던 또 하나의 왕국이 있었다. 철을 녹이고, 음악을 만들고, 바다를 건넌 사람들. 그들은 역사에 지워졌지만, 가야금 소리는 오늘도 울린다."

### 핵심 주제
1. **망각과 기억**: 역사에서 지워진 왕국의 이야기
2. **철과 음악**: 가야의 두 정체성 — 물질(철)과 정신(음악)
3. **패배의 품위**: 강한 자가 이기는 것이 아니라, 기억되는 자가 남는다
4. **이방인의 통합**: 허황옥의 이야기 — 다름이 강점이 되는 서사

## 시즌 구조 (3시즌 계획)

### 시즌 1: "구지봉의 노래" (건국 — 42~100 AD)

**핵심 서사**: 김수로왕과 허황옥의 건국 이야기

**주요 에피소드 아크**

```
아크 1: 알의 탄생 (E01~E03)
- 구지봉에서 황금 알 여섯 개 등장
- 가락국 백성들의 구지가(龜旨歌)
- 수로왕의 현신과 첫 통치

아크 2: 바다를 건넌 왕비 (E04~E07)
- 허황옥, 인도 아유타국에서 출발
- 파사석탑과 항해
- 수로왕과의 만남·혼인
- 두 문화의 충돌과 융합

아크 3: 철의 왕국 (E08~E11)
- 금관가야 제철 산업 확립
- 철정(鐵鋌)을 화폐로 한 동아시아 교역
- 왜·중국·신라와의 관계
- 가야 연맹 형성

아크 4: 왕의 노년 (E12~E14)
- 수로왕의 후계 고민
- 허황옥과의 이별
- 가야의 미래에 대한 성찰
```

**시즌 1 핵심 장면**

*구지가 장면*:
```
백성들이 구지봉에 모여 노래한다.
"거북아 거북아 머리를 내밀어라
내밀지 않으면 구워서 먹으리"
그 순간 하늘에서 황금빛 상자가 내려온다.
→ 가야 IP의 가장 상징적 오프닝 장면
```

*허황옥 도착 장면*:
```
붉은 돛의 배가 낙동강 하구에 닿는다.
파사석탑이 빛난다.
수로왕이 해변에 서서 기다린다.
두 사람의 시선이 만나는 순간 — 대사 없음
→ 동양과 서양, 두 문명이 만나는 순간의 침묵
```

### 시즌 2: "철과 가야금" (전성기 — 3~5세기)

**핵심 서사**: 가야 연맹의 전성기와 균열

**주요 에피소드 아크**

```
아크 1: 연맹의 균열 (E01~E04)
- 금관가야 vs. 대가야 주도권 다툼
- 고구려·신라·백제 사이의 외교 줄타기
- 가야의 전략적 선택들

아크 2: 우륵의 청년 (E05~E08)
- 가야금 탄생 이야기
- 우륵과 대가야 왕실의 관계
- 12악곡 창작 과정
- "음악이 있는 한 가야는 죽지 않는다"

아크 3: 고구려의 남하 (E09~E11)
- 400년 광개토대왕의 가야 원정
- 금관가야의 급격한 쇠퇴 시작
- 가야 연맹의 재편

아크 4: 선택의 기로 (E12~E14)
- 신라와의 관계 변화
- 일부 가야 소국의 신라 병합 시작
- 대가야의 독자 생존 전략
```

**시즌 2 핵심 장면**

*우륵의 첫 가야금 연주*:
```
우륵이 새로 만든 현악기를 처음 연주한다.
왕궁이 조용해진다.
왕이 눈을 감는다.
"이 소리가 우리 가야다."
→ 가야금 창제의 순간 — 이 IP 전체의 감동적 피크
```

### 시즌 3: "소리는 사라지지 않는다" (멸망 — 6세기)

**핵심 서사**: 가야 연맹의 소멸과 우륵의 귀화

**주요 에피소드 아크**

```
아크 1: 금관가야 멸망 (E01~E03)
- 532년 금관가야, 신라에 병합
- 마지막 왕 김구해의 항복 결단
- "백성이 사는 것이 왕국보다 중요하다"

아크 2: 우륵의 결단 (E04~E07)
- 대가야의 쇠락을 목격하는 우륵
- 가야금과 악곡을 신라로 전하는 선택
- 신라 진흥왕과의 만남
- "나는 가야를 버린 것인가, 지킨 것인가"

아크 3: 신라에서의 우륵 (E08~E10)
- 계고·법지·만덕에게 음악 전수
- 가야 음악이 신라 음악이 되는 과정
- 타향에서 느끼는 고향 가야의 부재

아크 4: 대가야의 최후 (E11~E14)
- 562년 이진아시왕의 마지막 항전
- 신라 이사부·사다함의 공격
- 대가야 함락
- 우륵이 멀리서 고향 방향으로 마지막 연주
```

**시즌 3 피날레 장면**:
```
[562년, 신라 경주]
우륵이 언덕에 앉아 있다.
서쪽을 바라본다 — 대가야가 있는 방향.
가야금을 꺼낸다.
연주를 시작한다.

[동시 편집]
대가야 왕궁 — 이진아시왕의 최후.
금관가야 터 — 갈대밭에 바람만 분다.
김해 제철장 터 — 식어버린 용광로.

[우륵의 내레이션]
"가야는 사라졌다. 그러나 이 소리는 내가 있는 한 사라지지 않는다.
 그리고 나 또한 언젠가 사라질 것이다.
 하지만 소리는 — 소리는 영원하다."

[엔딩]
현재의 가야금 연주 소리로 전환.
자막: "가야금은 오늘도 울린다."
```

## 제작 포인트

### 가야 스핀오프의 차별점
```
메인 IP (삼국): 전쟁·정복·통일 서사
가야 스핀오프: 문화·음악·소멸의 서사

→ 대비 효과: "강한 자가 이기는 이야기"와
              "아름다운 것이 사라지는 이야기"의 공존
```

### 음악의 역할
```
가야 스핀오프에서 음악은 단순한 배경이 아니다.
- 가야금 소리 = 가야의 생명력
- 연주가 계속되는 한 가야는 살아있다
- 마지막 연주 = 가야의 공식적 소멸

OST 컨셉: 가야금 솔로 중심 — 다른 악기 최소화
          멸망할수록 연주가 순수해진다
```
