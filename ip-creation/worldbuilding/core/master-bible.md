# 마스터 바이블 (Master Bible)

> **프로젝트**: 한국 삼국시대 IP — 삼국사기(三國史記) 기반
> **문서 성격**: 전체 IP의 뼈대 문서. 모든 세부 문서의 상위 참조점.
> **핵심 콘셉트**: "세 왕국, 하나의 운명" (Three Kingdoms, One Destiny)
> **최종 수정**: 2026-02-18
> **버전**: 1.0

## 1. 프로젝트 정의

### 1-1. 한 줄 요약

> 한반도와 만주를 무대로 700년간 경쟁하고 충돌하며 하나가 되어간 세 왕국의 이야기 — 역사 서사시이자 인간 드라마.

### 1-2. 핵심 콘셉트

**"세 왕국, 하나의 운명"** (Three Kingdoms, One Destiny)

고구려, 백제, 신라는 같은 뿌리에서 나왔으나 다른 길을 걸었다. 서로를 가장 잘 아는 존재이면서 가장 격렬한 적이었다. 그 700년의 여정은 결국 하나의 질문으로 수렴한다:

> *"우리는 왜 싸웠는가, 그리고 그 싸움은 무엇을 남겼는가?"*

이 질문은 과거의 것이 아니다. 분열과 통합, 자존심과 실리, 전통과 혁신 — 이 갈등은 모든 시대, 모든 문화에서 반복된다. 삼국시대는 그 보편적 질문에 대한 한국적 답이다.

### 1-3. 톤 & 무드 (Tone & Mood)

| 요소 | 정의 |
|------|------|
| **장르** | 역사 서사시 (Historical Epic) |
| **톤** | 영웅담과 비극의 교차. 장엄하되 인간적. 웅장하되 섬세 |
| **무드** | 대하(大河)적 흐름 — 역사의 거대한 물결 속에서 개인이 어떻게 빛나고 스러지는가 |
| **감정 스펙트럼** | 경외 → 감동 → 비장 → 카타르시스 |
| **비주얼 톤** | 고구려 고분벽화의 역동성 + 백제 금동대향로의 우아함 + 신라 금관의 신비 |
| **금지 톤** | 희화화, 과도한 판타지화, 특정 왕국의 일방적 미화/폄하 |

### 1-4. 타겟 오디언스

| 구분 | 상세 |
|------|------|
| **1차 타겟** | 18~35세 청년·성인. 역사·판타지에 관심 있는 콘텐츠 소비자 |
| **2차 타겟** | 35~50세 성인. 깊이 있는 서사를 원하는 독자/시청자 |
| **글로벌 타겟** | 한국 역사에 관심 있는 해외 K-콘텐츠 팬. 서사시·전쟁 드라마 팬 |
| **지역별 전략** | 한국(원작), 일본(역사적 연결성), 중국(공유된 역사), 서양(새로운 세계관) |

### 2-2. 문서 참조 규칙

1. **모든 고유명사는 `glossary.md`의 표기를 따른다.** 표기 분쟁 시 glossary.md가 최종 권위.
2. **세부 문서는 반드시 상위 문서(이 마스터 바이블)와 정합성을 유지한다.**
3. **문서 간 참조는 상대 경로 링크로 연결한다.**
4. **변경 이력은 각 문서 상단에 기록한다.**

### 아크별 핵심 요약

#### ARC-1: 주몽의 길 (The Road of Jumong)
- **로그라인**: 부여의 서자(庶子) 주몽이 죽음의 위협을 피해 남하하여 새로운 나라를 세우기까지의 여정
- **핵심 갈등**: 운명 vs 선택, 고향 vs 새 땅, 신화 vs 현실
- **감정선**: 고난 → 탈출 → 도전 → 건국의 감격
- **클라이맥스**: 비류수를 건너는 장면 — 물고기와 자라가 다리를 놓는 신화적 순간

#### ARC-2: 광개토, 천하를 밟다 (Gwanggaeto Conquers the World)
- **로그라인**: 18세에 즉위한 젊은 왕 담덕이 사방의 적을 무찌르고 대제국을 건설하는 정복 서사
- **핵심 갈등**: 팽창 vs 안정, 전쟁의 영광 vs 전쟁의 대가, 아버지(고국양왕) vs 아들
- **감정선**: 즉위 → 첫 전쟁 → 연전연승 → 제국의 절정 → 39세의 이른 죽음
- **클라이맥스**: 5만 기병의 신라 구원 — 광개토대왕릉비에 새겨진 역사적 순간

#### ARC-3: 살수의 노래 (Song of Salsu)
- **로그라인**: 수 양제의 113만 대군이 몰려오는 절체절명의 위기에서, 을지문덕이 지략 하나로 제국을 구하는 전쟁 서사
- **핵심 갈등**: 압도적 수적 열세, 정면 대결 vs 전략적 후퇴, 군인 vs 정치인(영양왕과의 긴장)
- **감정선**: 공포 → 위장 후퇴 → 긴장 → 살수의 대반격 → 카타르시스
- **클라이맥스**: 살수에서 물을 막았다 터뜨리는 순간 — 30만 5천 중 2,700만 돌아감

#### ARC-4: 서동의 노래 (Song of Seodong)
- **로그라인**: 백제의 미천한 청년 서동이 노래 하나로 신라 공주의 마음을 사고, 마침내 왕이 되는 이야기
- **핵심 갈등**: 신분 차이, 적국 간의 사랑, 사랑 vs 정치적 야심
- **감정선**: 동경 → 모험 → 사랑 → 시련 → 왕위 등극 → 미륵사 창건
- **클라이맥스**: 선화공주가 서동의 정체를 알게 되는 순간

#### ARC-5: 바보와 공주 (The Fool and the Princess)
- **로그라인**: "바보 온달"이라 불리던 남자가 평강공주의 가르침으로 고구려 최고의 장군이 되기까지
- **핵심 갈등**: 내면의 잠재력 vs 세상의 편견, 사랑과 성장, 전쟁과 죽음
- **감정선**: 조롱 → 만남 → 변화 → 승리 → 아단성 전사의 비극
- **클라이맥스**: 아단성 전투에서 온달이 전사하고, 관이 움직이지 않다가 평강공주가 와서 어루만지자 비로소 움직이는 장면

#### ARC-6: 춘추의 도박 (Chunchu's Gamble)
- **로그라인**: 대야성에서 딸과 사위를 잃은 김춘추가 복수와 통일을 위해 고구려·왜·당을 순방하는 외교 스릴러
- **핵심 갈등**: 복수 vs 대의, 동맹의 대가, 자존심 vs 실리
- **감정선**: 분노 → 고구려 실패(감금 위기) → 왜 실패 → 당 성공 → 나당동맹의 빛과 그림자
- **클라이맥스**: 당 태종 앞에서 동맹을 쟁취하는 순간 — 그러나 그 대가는...

#### ARC-7: 계백, 마지막 전장 (Gyebaek, The Last Stand)
- **로그라인**: 백제 멸망의 날, 장군 계백이 가족을 직접 처단하고 5천 결사대로 마지막 전투에 나서는 비극
- **핵심 갈등**: 나라 vs 가족, 죽음 앞의 존엄, 의리 vs 대세
- **감정선**: 결의 → 가족과의 이별 → 출정 → 4번의 승리 → 최후의 패배
- **클라이맥스**: 관창의 두 번째 돌격과 전사 → 이에 감화된 신라군의 총공격 → 계백의 전사. 적과 아군 모두의 장렬함.

#### ARC-8: 하나의 운명 (One Destiny)
- **로그라인**: 백제 멸망(660)부터 신라의 당군 축출(676)까지 — 삼국의 운명이 수렴하는 최종 서사
- **핵심 갈등**: 통일의 의미, 동맹국 당과의 필연적 결별, 옛 적국 유민과의 통합
- **감정선**: 백제 멸망의 슬픔 → 고구려 멸망의 충격 → 당의 배신 → 최종 결전 → 쓸쓸한 승리
- **클라이맥스**: 문무왕의 유언 — "내 뼈를 동해에 묻어라. 죽어서 용이 되어 이 나라를 지키겠다"

## 5. 캐릭터 설계 원칙

### 5-1. 캐릭터 분류 체계

| 등급 | 정의 | 캐릭터 수 | 예시 |
|------|------|----------|------|
| **S급 (주역)** | 스토리 아크의 중심인물. 풀 캐릭터 바이블 필요 | 약 15명 | 주몽, 광개토대왕, 을지문덕, 연개소문, 김춘추, 김유신, 계백, 선덕여왕 |
| **A급 (핵심)** | 주역의 상대역·조력자. 독립 서사 가능 | 약 25명 | 온달, 성왕, 근초고왕, 원효, 관창, 허황옥, 평강공주 |
| **B급 (주요)** | 시대를 대표하는 인물. 에피소드 중심 | 약 40명 | 을파소, 이차돈, 흑치상지, 연남생, 문무왕, 의자왕 |
| **C급 (배경)** | 시대의 분위기를 만드는 인물 | 필요에 따라 | 일반 병사, 귀족, 승려, 상인 등 |

### 5-2. 캐릭터 설계 5원칙

1. **역사적 사실을 존중하되, 인간적 깊이를 부여한다.** 영웅을 신격화하지 않고, 악인을 단순화하지 않는다.
2. **모든 주요 캐릭터는 '결핍'을 가진다.** 광개토대왕의 짧은 생(39세 사망), 김춘추의 잃어버린 가족, 연개소문의 정통성 결핍.
3. **적에게도 정의를 부여한다.** 계백은 신라의 적이지만 가장 숭고한 인물 중 하나다. 연남생은 배신자이지만 그의 고통도 진실이다.
4. **관계가 캐릭터를 만든다.** 주몽-유화부인(모자), 김춘추-김유신(동지), 계백-관창(적이자 경의의 대상), 온달-평강공주(부부이자 스승과 제자).
5. **시대가 캐릭터를 시험한다.** 같은 인물이라도 다른 시대에 태어났다면 다른 선택을 했을 것이다. 캐릭터의 선택은 시대적 맥락 안에서 이해되어야 한다.

### 5-3. 캐릭터 바이블 항목 (S급 캐릭터용)

각 S급 캐릭터에 대해 다음 항목을 작성한다:

```
1. 기본 정보 (이름, 생몰년, 소속, 관직)
2. 외모 설정 (체형, 인상, 특징적 복식/무기)
3. 성격 프로파일 (MBTI 참고, 핵심 성격 3가지, 결핍)
4. 핵심 동기 (무엇을 원하는가?)
5. 내면 갈등 (무엇과 싸우는가?)
6. 관계도 (주요 인물 관계 5개 이상)
7. 캐릭터 아크 (변화의 궤적)
8. 대표 대사 (캐릭터를 정의하는 한마디)
9. 사망/퇴장 장면 (어떻게 끝나는가?)
10. 비주얼 레퍼런스 키워드
```

> 상세: → `characters/character-bible.md`

## 6. 세계관 설계 원칙

### 6-1. 역사와 창작의 경계

| 원칙 | 설명 |
|------|------|
| **역사 우선** | 삼국사기·삼국유사에 기록된 사실은 최대한 존중한다 |
| **빈 곳은 채운다** | 기록이 없는 부분(인물의 내면, 일상, 대화)은 고증에 기반한 상상력으로 채운다 |
| **논쟁은 선택한다** | 학계에서 의견이 나뉘는 부분(가야-왜 관계, 광개토대왕릉비 해석 등)은 하나를 선택하되, 선택의 근거를 문서화한다 |
| **신화는 존중한다** | 건국 신화의 초자연적 요소는 그 자체로 존중한다. "합리적 해석"을 강요하지 않되, 판타지 수위는 프로젝트 내 일관성을 유지한다 |
| **현대적 시각은 넣되 투사하지 않는다** | 현대적 가치관(젠더, 인권 등)을 의식하되, 당시 시대상을 왜곡하지 않는다 |

### 6-2. 신화적 요소 처리 기준

본 IP에서는 신화적 요소를 **3단계 스펙트럼**으로 처리한다:

| 레벨 | 정의 | 예시 | 사용 맥락 |
|------|------|------|----------|
| **Lv.1 — 서사적 사실** | 역사적 사실 그대로 | 살수대첩, 안시성 전투 | 모든 미디어 공통 |
| **Lv.2 — 경이(wonder)** | 설화적 요소를 자연스럽게 녹임 | 온달의 관이 움직이지 않은 이야기, 이차돈의 흰 피 | 소설, 드라마, 애니메이션 |
| **Lv.3 — 판타지** | 초자연적 요소를 시각적으로 표현 | 주몽의 알 탄생, 삼족오의 비상, 해모수의 천강 | 애니메이션, 게임, 웹툰 |

> 미디어별로 어떤 레벨까지 허용할지는 각 미디어 기획 문서에서 정의한다.
