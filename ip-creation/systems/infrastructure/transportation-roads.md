## 삼국시대 교통 개요

```
교통 수단:
  육상: 도보 / 우마차 / 기마
  수상: 강선(江船) / 연안선 / 원양선
  전령: 봉화(烽火) / 파발(擺撥) / 서신

도로 발달 배경:
  군사: 병력·보급 신속 이동
  행정: 지방 통치, 세금 수납
  교역: 물자 유통, 시장 연결

왕국별 도로 발달도:
  고구려: 군사 도로 최발달 (요동~평양 대로)
  백제: 해상 교통 우위 + 내륙 도로
  신라: 왕경 중심 방사형 도로
  가야: 낙동강 수운 중심
```

## 고구려 도로망

### 주요 간선도로

```
요동대로(遼東大路):
  경로: 평양 → 안시성 → 요하 → 요동성
  길이: 약 600km
  용도: 군사 보급, 요동 방어선 유지
  폭: 군용 대로 약 6~8m (4마리 말 병렬 가능)

평양~국내성 도로:
  경로: 평양 → 성천 → 국내성 (집안)
  길이: 약 450km
  특이: 고구려 2개 수도 연결 핵심 도로

살수 도하 지점:
  살수(청천강) 주요 도하처 3곳
  도하 시설: 나루(津) + 선착장
  군사 도하: 조각배 50척 이상 준비 상시 유지
```

### 고구려 도로 건설 기술

```
기반 공사:
  노반(路盤): 모래·자갈 다짐층 30cm
  표면: 판석 or 작은 돌 깔기 (도심부)
  배수: 도로 양측 측구(側溝) 설치

교량 기술:
  소규모: 통나무 다리 (계곡·소하천)
  중규모: 석조 아치 교량 (주요 강)
  대규모: 부교(浮橋) — 배를 이어 만든 임시 다리

동절기 대책:
  결빙 강 → 겨울 도하로 활용
  평양~안시성 겨울 보급로: 결빙 대동강 + 청천강

IP 서사 연계:
  살수대첩 = 수나라 군 도하 중 공격
  도하 지점 선택 = 을지문덕 전략 핵심
  「다리 위에서 싸우는 자는 진다」— 고루 대사
```

## 백제 도로 및 해상 교통

### 내륙 도로망

```
웅진~사비 대로:
  경로: 공주(웅진) → 부여(사비)
  길이: 약 50km
  특이: 천도(538년) 이후 왕실 이동 주요 경로
  현재 충남 지역 도로 원형 추정

사비성 내부 도로:
  방격형(格子形) 도로 계획
  주요 대로: 폭 10~15m (왕궁~남문)
  이면 도로: 폭 3~5m

한강 수운:
  한산성~하구 수운 체계
  백제 초기 수도 한강 하구 활용
  한강 = 내륙 교통 + 해상 연결 핵심
```

### 백제 해상 교통

```
동아시아 항로:
  서해 횡단로: 사비 → 산둥반도 (중국)
  남해 항로: 사비 → 규슈 (일본)
  연안 항로: 한반도 서해안 연안 항행

항구 시설:
  사비 금강 하구 항구: 주요 무역항
  시설: 부두 + 창고 + 관세 징수소

항해 기술:
  계절풍 활용: 여름 남서풍(일본행) / 겨울 북동풍(귀항)
  항로 안내: 연안 봉화 + 섬 경유 방식
  소요 시간: 사비~규슈 약 3~5일 (계절풍 순풍)

IP 서사 연계:
  아랑: 사비성 금강 부두에서 교역품 구경
  백제 교역품: 금동대향로 → 일본 수출 가능성
  백강 전투: 이 해상 교통로에서 발생
```

## 신라 도로망

### 왕경(경주) 도로 체계

```
왕경 도로 계획:
  방격형 도로망 (당나라 장안성 참고)
  주작대로: 왕궁~남문 중심 대로 (폭 20m 추정)
  격자 도로: 100m × 100m 블록 단위

경주~요충지 간선:
  경주~부산 방향: 해안 연안 도로
  경주~대구 방향: 낙동강 경유 도로
  경주~충주 방향: 한반도 횡단 내륙 도로

화랑 수련 이동:
  화랑 집단: 명산대천 순례 수련
  주요 경로: 경주 → 금강산 → 묘향산 (고구려 경계)
  이동 방식: 도보 + 기마 혼합

IP 서사 연계:
  하린: 화랑 순례 중 고구려·백제 접경 체험
  선덕여왕: 경주 왕경 첨성대에서 하늘 관측
```

## 봉화·전령 통신 체계

### 봉화(烽火) 시스템

```
봉화 기능:
  낮: 연기 신호 (봉수 — 연기 개수로 위급도)
  밤: 불빛 신호 (봉화 — 횃불 개수)

신호 코드:
  1개: 평상시 이상 없음
  2개: 적 출현
  3개: 적 접근
  4개: 적 교전 중
  5개: 적 침입 (최고 긴급)

봉화대 간격:
  가시 거리: 10~15km
  평양~요동: 약 40개 봉화대 (릴레이)
  전달 시간: 평양~요동 약 2~3시간

IP 서사 활용:
  안시성 88일: 봉화 신호 = 지원 요청
  살수대첩 전야: 봉화 2연속 = 댐 방류 신호
  게임: 봉화 시스템 조기 경보 메커니즘
```

### 파발(擺撥) 전령 체계

```
파발 방식:
  기발(騎撥): 기마 전령 — 빠르고 상세 정보
  보발(步撥): 도보 전령 — 느리지만 짐 운반 가능

파발 역(驛) 시스템:
  역(驛): 전령 교체·말 교체 거점
  간격: 약 30~50리 (12~20km)
  시설: 말 10두 이상 + 전령 대기 숙소

속도:
  기발: 1일 200~300리 (80~120km)
  긴급: 1일 400리 이상 (継走 방식)

IP 서사 연계:
  을지문덕의 첩보망: 파발 활용 정보 수집
  니문: 소식 전달자 역할 (파발과 동행)
```

## 교통 인프라의 서사 기능

```
장소 이동 = 서사 전환 포인트:

살수 도하:
  수나라 113만 군 → 살수 도하 시작
  절반이 건넜을 때 = 을지문덕의 신호
  도하 지점 = 드라마 S1 클라이맥스 무대

백마강 (사비 앞 강):
  사비성 해자 역할 + 수운 교통로
  낙화암 = 백마강 절벽 (자연+도시 인프라 교차)
  「강이 흐른다」= 백마강도 포함

낙동강 수운:
  가야 12국 연결 수운 대동맥
  가야금 소재 오동나무 = 낙동강 상류 운반
  니문의 유랑 경로 = 낙동강 따라 이동

경주 왕경 대로:
  하린의 일상 공간
  화랑 집합 훈련 장소
  첨성대 → 왕궁 → 남문 일상 동선
```
