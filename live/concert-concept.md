## 공연 구성 (미디어 아트 콘서트 — 120분)

### 1막: "탄생 — 강이 흐르다" (35분)

**오프닝**
```
[암전 — 가야금 단선율]
무대: 완전한 어둠 속에서 단 하나의 조명이 가야금 위에
연주: 우륵 테마 — 느리고 서정적
영상: 한강·압록강·백마강·낙동강의 새벽 풍경

[메인 테마 "강은 기억한다"]
무대: 서서히 오케스트라 등장 (100명)
     스크린에 삼국 지도 펼쳐짐
연주: 가야금 솔로 → 오케스트라 합류 → 폭발적 절정
영상: 삼국시대 고분 벽화 · 유물 · 현재의 유적지
```

**1막 수록곡**

| 순서 | 곡명 | 악기 구성 | 영상 |
|------|------|---------|------|
| 1 | 메인 테마 "강은 기억한다" | 풀 오케스트라 + 가야금 | 삼국 지도 |
| 2 | 고구려 테마 "쇠와 바람" | 거문고 + 오케스트라 | 광개토대왕 정복 |
| 3 | 주몽 테마 | 독주 거문고 | 주몽 탄생 신화 |
| 4 | 구지가 변주 (가야) | 가야금 5중주 | 구지봉 신화 |
| 5 | 백제 테마 "흰 꽃이 지다" (1) | 가야금 + 피리 | 백마강 |

### 2막: "전쟁 — 강이 붉어지다" (40분)

**전투 음악 메들리**
```
[살수대첩 조곡]
연주: 오케스트라 전체 + 대북 20개
     점진적 템포 상승 → 수문 개방 순간 → 폭발
영상: 살수대첩 드라마 하이라이트 (E07 예고편)
무대 이펙트: 무대 전체 물 안개 + 파란 조명

[황산벌 조곡]
연주: 거문고 + 저음 현악 + 타악
영상: 계백 결사대 출정 · 4번의 전투
무대 이펙트: 붉은 조명 + 안개
```

| 8 | 화랑 행진곡 | 빠르고 젊은 에너지 |

### 3막: "소멸과 기억 — 강은 흐른다" (45분)

**비극과 감동의 피날레**

```
[백제 멸망 조곡]
연주: 가야금 + 현악 5중주 (실내악 스케일)
     무대 조명: 점점 어두워짐
영상: 낙화암 · 백마강 황혼
무대 이펙트: 꽃잎 낙화 (무대 위 꽃잎 투하)

[우륵의 마지막 연주]
연주: 가야금 솔로 — 전통 연주자 무대 중앙
     오케스트라 침묵
     가야금 소리만 공연장 채움
영상: 가야의 흥망성쇠 · 현재 가야금 연주자들
무대 이펙트: 단 하나의 조명 → 점점 어두워짐

[피날레 "강은 기억한다" 재현]
연주: 전체 합주 (1막보다 더 웅장하게)
     + 합창단 100명
영상: 현재의 유적지 → 아름다운 한반도 풍경
무대 이펙트: 풀 조명 + 컨페티
```

**3막 수록곡**

| 순서 | 곡명 | 특징 |
|------|------|------|
| 12 | 백제 멸망 조곡 | 실내악·서정 |
| 13 | 낙화암 | 해금 솔로 |
| 14 | 신라 통일가 | 합창 추가 |
| 15 | 우륵의 마지막 연주 | 가야금 솔로 |
| 16 | 피날레 "강은 기억한다" | 전체 합주+합창 |
| 앙코르 | 메인 테마 리프라이즈 | 관객 기립 |

## 무대 기술 사양

### 무대 구성

```
메인 스테이지: 40m × 25m
  - 센터 스테이지: 오케스트라 피트 (100명)
  - 가야금·전통 악기 솔로 구역: 무대 중앙 앞
  - 합창단: 오케스트라 뒤 계단식

LED 스크린:
  - 메인: 폭 40m × 높이 12m (무대 후면 전체)
  - 사이드: 각 8m × 6m (2개)
  - 플로어: 무대 바닥 LED (영상 반영)
```

### 특수 효과

| 이펙트 | 사용 장면 |
|--------|---------|
| 안개 머신 | 살수대첩·낙화암 |
| 꽃잎 투하 | 낙화암 장면 |
| 불꽃 (파이로) | 고구려 전투 씬 |
| 컨페티 | 피날레 |
| 레이저 | 신라 황금 테마 |
| 드론 라이트쇼 | 야외 공연 전용 |
