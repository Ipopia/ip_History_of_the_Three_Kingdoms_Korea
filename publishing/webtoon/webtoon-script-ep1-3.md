# 웹툰 스크립트 — 삼국(三國): 1~3화

## 웹툰 기본 설정

| 항목 | 내용 |
|------|------|
| 형식 | 세로 스크롤 웹툰 (네이버 / LINE Webtoon) |
| 컷 수 | 회당 60~80컷 |
| 색채 | 풀컬러 — 왕국별 팔레트 적용 |
| 연령 | 15세 이상 |
| 업데이트 | 주 1회 |

## 제1화 — 하늘의 아들

### 표지 컷

```
[컷 1 — 표지]
구도: 전신 세로 — 주몽이 활을 당긴 자세
배경: 하늘+구름, 역광으로 실루엣 강조
텍스트: "삼국(三國)" 타이틀 + "제1화 — 하늘의 아들"
색채: 토갈+새벽청 (건국기 팔레트)
```

### 씬 1: 압록강 (BC 38년 봄)

```

[컷 3 — 클로즈업]

[컷 4 — 미디엄샷]

표정: 냉정
대사: (없음)

```

## 웹툰 아트 디렉션 노트

### 컷 연출 원칙

| 상황 | 컷 크기 | 효과 |
|------|---------|------|
| 액션 클라이맥스 | 빅컷 (2컷 분량) | 속도선+폭발 효과 |
| 감정 클로즈업 | 작은 컷 연속 | 빠른 표정 변화 |
| 장소 소개 | 와이드 빅컷 | 세밀한 배경 |
| 대화 | 미디엄 교차 | 인물 양쪽 번갈아 |
| 침묵 | 큰 컷 + 효과음 없음 | 여백 강조 |

### 세로 스크롤 특화 연출

- 중요 대사: 컷 하단에 배치 → 스크롤 속도 조절 유도
- 반전 컷: 긴 여백 후 등장 → 충격 극대화
- 챕터 엔딩: 항상 세로로 긴 빅컷 + 여운

### 색채 적용

- 고구려 장면: 철흑+토갈 계통
- 부여 장면: 회색+차가운 청 (대비)
- 회상: 탈포화+세피아 처리
