# 시즌 3 아웃라인 — 삼국(三國) IP

**시리즈**: 삼국(三國) — 강은 기억한다
**시즌 3 부제**: 황혼의 전쟁 (黃昏의 戰爭)
**시대 배경**: 6세기 후반~7세기 (562~668년)
**에피소드**: 14부작
**핵심 사건**: 가야 멸망 · 살수대첩 · 안시성 전투 · 황산벌 · 나당 연합 · 삼국 통일

---

## 시즌 3 개요

삼국시대 최대의 격변기. 가장 많은 영웅이 빛났고, 가장 많은 나라가 사라졌다. 시즌 3는 **비극과 숭고함이 동시에 폭발하는 시즌**이다.

**핵심 테마**: *"사라지는 것들이 남기는 것들 — 땅은 빼앗겨도 이야기는 남는다"*

```
시즌 3 서사 구조:
Act 1 (E01~E04): 가야의 황혼 + 살수대첩
Act 2 (E05~E07): 안시성의 기적
Act 3 (E08~E11): 백제의 황금과 낙화
Act 4 (E12~E14): 통일의 빛과 그림자
```

## 에피소드 구성

### E01 — 가야의 마지막 봄 (562년)

```
씬 구성:
- 오프닝: 대가야 왕도. 봄꽃 피는 날. 철장 망치 소리.
- 이진아시왕의 고독 — "금관가야·아라가야가 모두 무너졌다"
- 우륵과 이진아시왕의 마지막 대화
  우륵: "대왕, 저는 신라로 가야 합니다."
  이진아시왕: "그대만은 가야를 살려라."
- 우륵의 귀화 결단 — 가야금을 등에 지고 국경을 넘는 장면

클라이맥스: 우륵이 국경에서 뒤를 돌아보는 장면
            가야 방향에서 연기가 피어오름 — 신라 침공 시작

핵심 대사 (우륵): "가야가 사라진다. 그러나 소리는 사라지지 않는다."

OST: 가야금 독주 + 제철 리듬 — 점점 사라지는 소리
```

### E02 — 대가야의 최후 (562년 하반기)

```
씬 구성:
- 신라 이사부·사다함의 대가야 총공격
- 이진아시왕의 최후 저항 — 성 안의 백성과 함께
- 사다함의 내면: "이기고 있다. 그런데 왜 이기는 것이 슬픈가."
- 대가야 함락 — 이진아시왕 최후 (투항 또는 전사 — 두 버전)
- 에필로그: 철장이 텅 비어있음 / 망치 소리 멈춤

핵심 대사 (이진아시왕):
"신라는 가야의 땅을 가져갔다. 그러나 가야의 혼은 가져가지 못한다."

사다함 에필로그:
"전쟁이 끝났다. 공로를 받기 싫다. 나는 그들의 눈을 잊을 수 없다."
→ 사다함 16세 요절 (역사 기록) — 화랑의 허망한 영광
```

### E03 — 을지문덕의 비(詩) (612년)

```
시간 점프: 562년 → 612년 (50년)
씬 구성:
- 수나라 양제 113만 대군 고구려 침략
- 고구려 영양왕과 을지문덕 — 전략 회의
- 을지문덕의 위계 외교: 적진에 홀로 들어가다
- 적장 우중문(于仲文)에게 시 전달 장면
  "전승공기고 지족원운지" — 붓으로 쓰는 전쟁

클라이맥스: 을지문덕이 적진에서 돌아오는 장면
            "이제 저들은 스스로 무너질 것입니다"

핵심 대사:
"칼보다 붓이 날카롭다는 것을 적에게 가르쳐주어야 했다."

OST: 고구려 거문고 테마 — 날카롭고 지적인 선율
```

```
씬 구성:
```

```
클라이맥스: 당 태종 철수 / 성주에게 비단 100필 하사

핵심 감정: 역사가 이름을 기억 못해도 강은 기억한다
```

### E14 — 강은 기억한다 (시즌 3 피날레)

```
씬 구성:
[4개 강의 에필로그]

압록강 (고구려):
- 텅 빈 평양성 / 강만 흐름
- 고구려 유민들이 만주로, 발해로 흘러감

백마강 (백제):
- 낙화암에서 꽃이 핌 / 강은 여전히 흐름
- 일본에서 가가쿠(雅楽) 연주 — 백제 음악이 살아있음

낙동강 (가야):
- 우륵의 마지막 연주 — 신라 경주에서
- 가야 방향 바라보며 / 제철 망치 소리 환청
- "가야금 소리는 사라지지 않았다"

형산강 (신라):
- 문무왕이 동해를 바라봄
- "삼국이 하나가 되었다. 그러나 무엇을 얻었고 무엇을 잃었는가."

최종 내레이션:
"강은 기억한다.
 고구려의 웅장함을. 백제의 아름다움을.
 신라의 지혜를. 가야의 소리를.
 그리고 이름 없이 싸우다 사라진 모든 이들을.
 강은 멈추지 않는다."

엔딩 OST: 메인 테마 "강은 기억한다" — 4왕국 테마 선율이 하나로 합쳐지는 풀 오케스트라
```
