## 시장 개요

### 북미 (미국·캐나다)

```
K-콘텐츠 현황:
- 넷플릭스 K-드라마: 오징어게임 이후 급성장
- K-팝 한류: BTS·블랙핑크로 한국 문화 인지도 상승
- 한국 역사 콘텐츠: 아직 미개척 — 「킹덤」공포 장르 성공 사례

목표 타겟:
① K-콘텐츠 팬덤 (기존 K-드라마 시청자)
② 역사 드라마 팬 (Game of Thrones·The Last Kingdom 팬층)
③ 게임 마니아 (전략 RPG·역사 게임 유저)
④ 아시아계 미국인 (한인·동아시아계)
⑤ 대학생·지식인층 (역사·세계문화 관심)

시장 규모:
미국 OTT 시장: 세계 1위
게임 시장: 세계 2위
피규어·콜렉티블: 세계 3위 (북미)
```

### 유럽

```
주요 시장:
프랑스: K-팝·K-드라마 팬덤 강함, 만화(BD) 문화
독일: 역사 IP 강세, 보드게임·피규어 시장
영국: K-콘텐츠 성장, 역사 드라마 팬층 탄탄
스페인·이탈리아: K-팝 한류, 중소규모 시장

유럽 특이사항:
GDPR 준수 필수 (데이터 처리)
각국 언어 현지화 비용 높음 → 영어 우선, 단계적 확장
```

## 미디어별 진출 전략

### 드라마·OTT

```
플랫폼 우선순위:
1. 넷플릭스 글로벌 — 최우선 (190개국 동시 공개)

3. Apple TV+ — 3차
4. HBO Max / Disney+ — 장르 적합성 검토

넷플릭스 협력 전략:
오징어게임·킹덤·무빙 성공 경로 분석
「한국 역사 서사」장르 개척 포지셔닝

성우: 영국 억양 (Game of Thrones 레퍼런스)

마케팅:
SDCC (샌디에이고 코믹콘) 패널 참가
NYCC (뉴욕 코믹콘) 부스
할리우드 리포터·버라이어티 광고
```
