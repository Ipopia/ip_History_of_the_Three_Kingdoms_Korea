## 종교 체계 개요

```
삼국시대 신앙 구조:
  중층적 신앙 체계 — 단일 종교 아님

Layer 1: 무속(巫俗) — 가장 오래된 기층 신앙
  샤머니즘 기반, 무당(巫)이 신과 소통
  자연신·조상신·지역신 숭배
  모든 왕국 공통 (공식 종교와 병존)

Layer 2: 불교(佛敎) — 4~6세기 공식 도입
  고구려: 372년 / 백제: 384년 / 신라: 527년
  왕권 강화 이념으로 활용
  사원 건축 + 불상 제작 + 승려 제도

Layer 3: 유교(儒敎) — 중국 영향 관료 이념
  고구려: 태학(太學) 372년 설립
  백제·신라: 점진적 도입
  국가 예법·관료 윤리 기반

Layer 4: 도교(道敎) — 귀족·왕실 중심
  불로장생·연금술 추구
  고구려 연개소문: 도교 국교화 시도 (642년~)
```

## 고구려 신앙 체계

### 무속 기층

```
시조 신화 기반:
  주몽 = 천제(天帝) 아들 → 고구려 왕 = 천자(天子)
  삼족오 = 태양 상징 → 왕실 수호신

무당(巫) 역할:
  전쟁 전 점복(占卜) — 출전일·전략 자문
  사망자 장례 의식 — 천도 의례
  가뭄·홍수 시 기우제·기청제

고구려 벽화 신앙 증거:
  사신도(四神圖): 청룡·백호·주작·현무
  → 방위 수호신 체계 = 고구려 우주관
  태양·달 신격화 그림
```

### 불교 도입 (372년)

```
전래:
  372년 전진(前秦) 순도(順道) 스님 → 소수림왕 환영
  375년 초문사·이불란사 창건 (최초 사찰)

국가 불교:
  왕권 = 불법 수호자 (轉輪聖王)
  고구려 후기: 평양 대사찰 건설
  연개소문의 역설: 도교 우선 정책 vs 불교 사찰 존속

창작 활용:
  을지문덕: 전투 전 불사(佛事) 거행 설정 가능
  안시성 수비대: 불상 앞 결사 맹세 장면
  고루: 무속 기원 + 불교 수용의 이중 신앙 표현
```

### 도교 (연개소문 정책)

```
역사 기록 (삼국사기):
  642년 연개소문: 보장왕에게 도교 진흥 건의
  당나라에서 도사(道士) 8명 초빙
  → 불교 사찰을 도관(道館)으로 전환 압박
  → 고구려 승려 반발 (보덕화상 백제로 망명)

창작 활용:
  고루 딜레마: 연개소문의 도교 정책 vs 무속·불교 신앙
  도교 도사 캐릭터: 권력 옆 기이한 조언자 역할
```

## 백제 신앙 체계

### 무속 기층

```
마한 기원 무속:
  소도(蘇塗): 마한의 성역 — 솟대 세우고 귀신 섬김
  천군(天君): 종교 지도자 (왕과 분리된 제사장)
  → 백제 초기 정치-종교 분리 전통

금강 수신 신앙:
  백마강 용신(龍神): 강에 제물 던지기
  낙화암 전설 배경 (용신 분노)
```

### 불교 (384년, 3국 중 최초 도입)

```
전래:
  384년 동진(東晉) 마라난타(摩羅難陀) → 침류왕 환영

백제 불교 특성:
  가장 정교한 불교 문화 → 일본 전파
  미륵신앙(彌勒信仰): 미래불 미륵 숭배 강세
  익산 미륵사: 당시 동아시아 최대 목탑

창작 활용:
  아랑: 미륵사에서 기도하는 장면 (시즌 2)
  「미륵이 오는 세상은 전쟁이 없다」— 아랑의 신앙
  의자왕의 타락: 불교 의례 형식화 → 아랑의 환멸
```

## 신라 신앙 체계

### 무속 기층 (가장 강인하게 유지)

```
화랑도 기원:
  원화(源花): 여성 무당 집단 → 화랑 제도 전신
  「낭도(郎徒)」— 무격(巫覡) 전통에서 발전

천신 신앙:
  박혁거세 = 태양신 자손
  신라 왕 = 사제왕 (제사+정치 겸직)
  알영정 용녀 신화 → 수신(水神) 숭배
```

### 불교 (527년, 가장 늦은 도입)

```
역사 기록:
  이차돈(異次頓) 순교: 527년
  법흥왕 앞에서 목 베이자 흰 피 + 하늘에서 꽃비
  → 신라 왕 불교 공인

신라 불교 특성:
  호국불교(護國佛敎): 국가 수호 기원
  황룡사 9층 목탑: 주변 9국 항복 기원 (645년)
  원광법사 세속오계 → 화랑 불교 윤리

창작 활용:
  하린: 세속오계를 몸에 새긴 화랑
  선덕여왕: 「불법이 나라를 지킨다」신앙
  황룡사 씬: 하린의 화랑 맹세 장면
```

## 가야 신앙 체계

```
수로왕 신화 기반:
  구지봉 천강(天降) 신화 → 천신 신앙
  허황옥 = 인도 아유타국 → 불교 이전 도입설 (학술 논쟁)
  → IP에서 허황옥의 신앙: 남방 불교 원형 요소

철신(鐵神) 숭배:
  가야 = 철의 나라 → 대장간 = 신전
  철 제련 의식: 달빛 아래 첫 철 녹이기
  창작: 니문의 가야금 = 철신의 소리를 담은 악기

가야 멸망 후 신앙:
  구지봉 비밀 의례: 가야 유민 → 연 1회 구지가 제창
  창작: 니문이 이 의례에 참여하는 씬 (시즌 2)
```

## 신앙과 서사 연계 지침

```
드라마 신앙 묘사 원칙:
  ① 특정 종교 우월성 표현 금지
  ② 신앙 = 캐릭터 내면 상태 표현 도구
  ③ 기적·초자연 현상: 최소화 (역사 사실주의 유지)
  ④ 무속·불교·유교의 공존 = 삼국시대 실제 모습

4인 캐릭터 신앙:
  고루: 무속 기층 + 불교 의례 형식 수용
    → 「강의 신이 나를 지켜본다」 (무속적 세계관)

  아랑: 불교 미륵신앙 (아름다운 세상 미래 희망)
    → 「미륵이 오는 날 전쟁이 끝난다」

  하린: 화랑 불교 윤리 (세속오계) + 천신 신앙
    → 「나는 별의 자손이다」(신라 천신 기원)

  니문: 가야 무속 + 철신 신앙 (음악 = 신과 소통)
    → 가야금 연주 = 기도 행위

금지 묘사:
  × 불교 = 미신으로 폄하
  × 무속 = 야만으로 묘사
  × 특정 종교인 악역 독점
```
