## 2. 주요 동맹 관계

### 2.1 나제동맹 (羅濟同盟, Naje Alliance)

신라와 백제가 **고구려의 남하에 대항**하기 위해 맺은 동맹.

| 항목 | 내용 |
|------|------|
| 성립 | 433년 — 비유왕(백제)·눌지왕(신라) |
| 배경 | 고구려 장수왕의 적극적 남하 정책으로 양국 모두 위협 |
| 기간 | 약 120년 (433~553) |
| 성격 | 군사 방어 동맹. 혼인 동맹 포함 |
| 결렬 | 553년 — 신라 진흥왕의 **한강 유역 독점** |

**동맹의 전개**:

| 연도 | 사건 |
|------|------|
| 433 | 동맹 성립. 상호 사신 교환 |
| 455 | 고구려의 백제 공격 시 신라 원군 파견 |
| 475 | 고구려 장수왕, **백제 한성(漢城) 함락**. 개로왕(蓋鹵王) 전사. 신라 원군 도착 지연 |
| 493 | 동성왕(백제)-신라 왕녀 혼인. 동맹 재확인 |
| 551 | **나제연합군의 한강 유역 탈환**. 백제 하류 6군 + 신라 상류 10군 확보 |
| 553 | 신라 진흥왕, **백제가 차지한 한강 하류마저 빼앗음**. 동맹 파탄 |
| 554 | **관산성 전투** — 성왕 전사. 동맹 완전 결렬, 적대 관계 전환 |

> **동맹 결렬의 의의**: 신라의 한강 유역 확보는 **중국과의 직접 교통로** 확보를 의미. 이후 나당동맹의 물리적 기반이 됨.

### 2.2 여제동맹 (麗濟同盟, Yeoje Alliance)

고구려와 백제가 **신라에 대항**하기 위해 맺은 동맹.

| 항목 | 내용 |
|------|------|
| 성립 | 642년경 — 연개소문(고구려)·의자왕(백제) |
| 배경 | 나제동맹 결렬 후 신라의 성장, 당과의 접근에 대한 위기감 |
| 성격 | 반(反)신라·반(反)당 연합 |
| 결과 | 신라를 남북으로 압박했으나, 나당동맹에 의해 각개격파 |

**주요 사건**:

| 연도 | 사건 |
|------|------|
| 642 | 백제 의자왕, **대야성(大耶城) 공격**. 신라 김춘추의 딸·사위 전사 → 김춘추의 복수심 |
| 642~ | 고구려·백제, 신라의 당 조공로 차단 시도 |
| 648 | 김춘추, 당에 군사 동맹 요청 (나당동맹 추진) |
| 655 | 고구려·백제·말갈 연합군, 신라 북변 30여 성 공격 |

### 2.3 나당동맹 (羅唐同盟, Silla-Tang Alliance)

신라와 당이 **백제·고구려를 멸망**시키기 위해 맺은 동맹.

| 항목 | 내용 |
|------|------|
| 성립 | 648년 — 김춘추(金春秋)의 당 방문, 당 태종과 회담 |
| 조건 | 백제·고구려 멸망 후 **대동강 이남을 신라에 귀속** (당의 약속) |
| 결과 | 백제(660)·고구려(668) 멸망 달성 |
| 파탄 | 당이 약속 불이행 → **나당전쟁(670~676)** |

**동맹의 전개**:

| 연도 | 사건 |
|------|------|
| 648 | 김춘추, 당 태종과 동맹 체결. 당식 관복·연호 채택 약속 |
| 654 | 김춘추 즉위(태종 무열왕). 당과의 관계 강화 |
| 660 | **백제 멸망**: 당 소정방 13만 수군 + 신라 김유신 5만 육군 |
| 661~668 | **고구려 공격**: 당군 정면 + 신라군 측면. 668년 평양성 함락 |
| 669~ | 당, **안동도호부(安東都護府)** 설치. 한반도 직접 지배 기도 |
| 670 | 신라, 백제 부흥군 지원 → 사실상 나당전쟁 개시 |
| 675 | **매소성 전투**: 신라 대승 |
| 676 | **기벌포 전투**: 신라 수군 승리. 당 세력 축출 |

> **나당동맹의 역설**: 동맹을 통해 백제·고구려를 멸했으나, 결국 당과 전쟁을 치러야 했다. 신라의 외교적 능란함과 군사적 결단이 모두 필요했던 과정.

## 4. 중국과의 관계

### 4.1 조공·책봉 체제 (朝貢·冊封)

삼국 모두 중국 왕조와 **조공-책봉 관계**를 유지했다. 이는 실질적 종속이 아닌 **외교적 의례이자 국제적 지위 인정** 수단이었다.

| 왕조 | 시기 | 삼국과의 관계 |
|------|------|---------------|
| 한(漢) | ~220 | 낙랑·대방군을 통한 간접 접촉 |
| 위(魏)·진(晉) | 220~420 | 조공·책봉 시작 |
| 남조(南朝) | 420~589 | **백제와 밀접**. 문화·군사 교류 |
| 북조(北朝) | 386~581 | **고구려와 접촉** |
| 수(隋) | 581~618 | **고구려와 전쟁** (4차례 침략) |
| 당(唐) | 618~907 | 고구려 전쟁, 나당동맹, 나당전쟁 |

### 4.2 수(隋) vs 고구려

수 양제(隋煬帝)의 고구려 원정은 **동아시아 역사를 바꾼 전쟁**.

| 차수 | 연도 | 병력(추정) | 결과 |
|------|------|-----------|------|
| 1차 | 598 | 30만 | 고구려 승리. 수군 폭풍 피해 |
| 2차 | 612 | **113만(호위 포함 200만+)** | **살수대첩. 고구려 대승** |
| 3차 | 613 | 수십만 | 양현감의 반란 → 철수 |
| 4차 | 614 | 수만 | 형식적 화친 |

> 수 양제의 무리한 고구려 원정은 **수(隋) 멸망(618)의 직접적 원인**. 민심 이반, 각지 반란 → 당(唐) 건국

### 4.3 당(唐) vs 고구려

당 태종·고종의 고구려 원정.

| 연도 | 사건 | 결과 |
|------|------|------|
| 645 | 당 태종 직접 원정 | **안시성 전투에서 퇴각** |
| 647 | 소규모 원정 | 성과 없음 |
| 648 | 소규모 원정 | 성과 없음 |
| 655 | 당·신라 연합 공격 | 부분적 성과 |
| 661 | 대규모 원정 | 평양 포위 실패 |
| 667~668 | 최종 원정 | 고구려 내분 이용. **668년 평양성 함락, 고구려 멸망** |

**고구려 멸망의 원인**: 외부 침략보다 **연개소문 사후 아들들의 내분**이 결정적.
- 연남생(장남): 동생들과 갈등 → **당에 투항, 길잡이 역할**
- 연남건(차남): 최후까지 항전
- 연남산(삼남): 당에 투항

### 4.4 각국의 대중국 외교 전략

| 국가 | 전략 | 특징 |
|------|------|------|
| 고구려 | 실리 외교 + 군사 대결 | 조공하면서도 군사적 독립 고수. 수·당과 정면 대결 |
| 백제 | 남조 중심 다원 외교 | 남조(宋·齊·梁·陳)와 밀접. 문화·군사 교류 활발 |
| 신라 | 당 집중 외교 | 6세기 이후 당과 밀착. 나당동맹으로 삼국통일 |
| 가야 | 제한적 교류 | 남제(南齊)에 조공 기록 (479, 대가야) |

## 5. 왜(倭, 일본)와의 관계

### 5.1 백제-왜 관계 (우호·동맹)

삼국시대를 통틀어 가장 긴밀한 **한일 관계**.

| 시기 | 내용 |
|------|------|
| 4세기 | 근초고왕, 왜왕에게 **칠지도(七支刀)** 하사 (369 또는 372) |
| 5세기 | 백제 학자·승려·기술자의 왜 파견. 한자·불교·유교 전파 |
| 6세기 | 오경박사(五經博士)·역박사(曆博士)·의박사(醫博士) 파견 |
| 660 | 백제 멸망 시 왜에 구원 요청 |
| 663 | **백강 전투(白江/白村江 戰鬪)**: 왜 수군 800척 vs 당 수군 170척 → **왜 대패** |

**백제의 왜 문화 전파**:
- 아직기(阿直岐)·왕인(王仁) — 한자·논어·천자문 전파
- 노리사치계(怒利斯致契) — 불교 전파
- 관륵(觀勒) — 역법·천문학 전파

### 5.2 고구려-왜 관계

| 시기 | 내용 |
|------|------|
| 5세기 | 광개토대왕, 왜구 격퇴 (400년 남정) |
| 6세기 | 승려 혜자(惠慈) 파견 → 쇼토쿠 태자(聖德太子)의 스승 |
| 7세기 | 간접적 교류. 직접 군사 충돌은 드묾 |

### 5.3 신라-왜 관계

| 시기 | 내용 |
|------|------|
| 초기 | 왜구의 신라 해안 침략 빈발 |
| 4세기 | 왜의 가야·신라 방면 군사 활동 (광개토대왕비 기록) |
| 6세기~ | 관계 개선 시도, 사신 교환 |
| 통일 후 | 대체로 평화적 교역 관계 |

### 5.4 가야-왜 관계

| 시기 | 내용 |
|------|------|
| 3~4세기 | 철 교역을 매개로 밀접한 관계 |
| 4~5세기 | 왜의 가야 지역 군사 활동 (성격 논쟁) |
| 6세기 | 대가야-왜 교류 지속 |

### 5.5 임나일본부(任那日本府) 문제

| 항목 | 내용 |
|------|------|
| 일본측 주장 | 왜가 가야 지역에 통치 기관(임나일본부) 설치. 4~6세기 한반도 남부 지배 |
| 한국측 반론 | 가야는 독립적 연맹 국가. 왜의 지배 증거 부재. 가야→왜 문화 전파가 더 현저 |
| 현대 학계 | 임나일본부는 가야에 거주한 **왜계 교역·외교 집단**으로 보는 견해가 유력 |
| IP 처리 방침 | 가야의 독립성과 주체성을 존중하되, 가야-왜 간 교류·교역의 실재는 반영 |

### 6.2 거란 (契丹, Khitan)

| 항목 | 내용 |
|------|------|
| 분포 | 요서(遼西), 시라무렌강 유역 |
| 고구려와 | 고구려 서쪽 국경과 접촉. 때로 충돌, 때로 복속 |
| 영향 | 고구려 멸망 후 요(遼) 건국(916). 고려와 대결 |

### 6.3 돌궐 (突厥, Turkic Khaganate)

| 항목 | 내용 |
|------|------|
| 분포 | 몽골 초원~중앙아시아 |
| 고구려와 | 수·당 견제를 위한 **원거리 연합** |
| 사례 | 612년 수 양제의 고구려 원정 시 돌궐이 수의 후방 위협 |

### 6.4 실위 (室韋)·해 (奚)

| 민족 | 고구려와의 관계 |
|------|-----------------|
| 실위(室韋) | 만주 북부. 고구려 북방 변경 접촉 |
| 해(奚) | 요서. 고구려·거란·당 사이에서 활동 |

## 7. 시기별 국제 관계 상세

### 7.1 제1기: 형성기 (1~3세기)

```
[한(漢) 제국]
    │ 낙랑·대방군
    ▼
[고구려] ←→ [백제] ←→ [신라]
                        ↕
                     [가야] ←→ [왜]
```

- 중국 군현(낙랑·대방)과의 관계가 핵심
- 삼국 간 본격 대결 이전

### 7.2 제2기: 고구려-백제 대결 (4세기)

```
[고구려] ←전쟁→ [백제]
   │              │
   ▼              ▼
 (북방 확장)    [왜와 동맹]
                   │
                [가야] ←→ [왜]
                   │
                [신라] (성장 중)
```

- **371년**: 백제 근초고왕, 고국원왕 전사시킴
- **396년**: 광개토대왕, 백제 공격. 58성 700촌 점령

### 7.3 제3기: 고구려 전성·나제동맹 (5세기)

```
        [고구려 — 최강]
       ↙      ↓      ↘
  [거란]   [말갈]   [남하 압박]
                        ↓
              [백제] ═동맹═ [신라]
                │        (나제동맹)
              [왜]
```

- **433년**: 나제동맹 성립
- **475년**: 장수왕, 한성 함락. 개로왕 전사

### 7.4 제4기: 삼국 각축 (6세기)

```
[고구려]
   ↕ 대치
[백제] ═동맹═ [신라] → 553 동맹 파탄
   │              │
   │         [한강 유역 확보]
   │              │
[왜]         [당과 접근]

[가야] → 562 신라에 멸망
```

- **553년**: 신라 진흥왕, 한강 유역 독점
- **554년**: 관산성 전투. 성왕 전사. 나제동맹 결렬
- **562년**: 가야 멸망

### 7.5 제5기: 대제국 전쟁 (7세기 전반)

```
[수(隋)/당(唐)] ←전쟁→ [고구려]
                           │
                    [백제]═동맹═[고구려]
                      │    (여제동맹)
                    [왜]

[신라] → 당(唐)에 동맹 요청
```

- **612년**: 살수대첩
- **642년**: 여제동맹 성립. 대야성 전투
- **645년**: 안시성 전투
- **648년**: 나당동맹 성립

### 7.6 제6기: 삼국통일 (7세기 후반)

```
[당(唐)] ═동맹═ [신라]
   │      (나당동맹)
   ▼
[백제 멸망 660] ← 왜 구원군 실패 (663 백강)
[고구려 멸망 668] ← 내분(연씨 형제)

─── 이후 ───

[당(唐)] ←전쟁→ [신라]
              (나당전쟁 670~676)
   │
   ▼
[신라 승리] → 대동강 이남 확보 → 삼국통일
```

## 8. 외교 수단과 방식

### 8.1 조공·책봉 (朝貢·冊封)

| 의미 | 내용 |
|------|------|
| 조공(朝貢) | 삼국이 중국에 토산물·공물 헌상 |
| 책봉(冊封) | 중국이 삼국 왕에게 관작·칭호 수여 |
| 실질 | 형식적 상하 관계. 실제로는 **독립국 간 외교 의례** |
| 이점 | 국제적 정통성 확보, 교역 기회, 선진 문물 수입 |

### 8.2 혼인 외교

| 사례 | 내용 |
|------|------|
| 나제동맹 | 백제 동성왕-신라 왕녀 혼인 (493) |
| 고구려-돌궐 | 고구려 왕녀의 돌궐 혼인 기록 |
| 고구려-북조 | 왕실 간 혼인 외교 |

### 8.3 인질 외교

| 사례 | 내용 |
|------|------|
| 신라→고구려 | 눌지왕의 동생 복호(卜好), 고구려에 인질 (392) |
| 신라→왜 | 눌지왕의 동생 미사흔(未斯欣), 왜에 인질 |
| 백제→왜 | 백제 왕자의 왜 체류 (인질 겸 외교관) |

### 8.4 군사 원조 요청

| 사례 | 내용 |
|------|------|
| 신라→고구려 | 400년, 왜구 격퇴 요청 → 광개토대왕 남정 |
| 백제→왜 | 660년, 멸망 직전 왜에 구원군 요청 |
| 신라→당 | 648년, 김춘추의 나당동맹 체결 |
