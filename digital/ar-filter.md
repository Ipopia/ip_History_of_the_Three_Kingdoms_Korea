## 필터 카탈로그

### F-001: 「나의 왕국은?」왕국 선택 필터

```
유형: 얼굴 인식 + 성격 분석
작동 방식:
  1. 카메라 켜면 4왕국 로고 회전
  2. 멈추면 해당 왕국 배경·왕관·의상 오버레이
  3. 결과 텍스트: 「당신은 [왕국명]의 [직위]」

왕국별 AR 결과:
  고구려: 삼족오 문양 투구 + 암청 의상 + 「당신은 고구려의 전사」
  백제: 금동 왕관 + 크림 의상 + 「당신은 백제의 기록자」
  신라: 금관 + 황금 갑옷 + 「당신은 신라의 화랑」
  가야: 가야금 오버레이 + 토황 의상 + 「당신은 가야의 악사」

시각 효과:
  왕국별 파티클: 고구려(철 파편) / 백제(금 광채) / 신라(황금 빛) / 가야(음악 파동)
  배경: 왕국별 배경 (평양성·사비성·금성·가야 강가)

SNS 공유:
  해시태그 자동 삽입: #삼국TV #나의왕국 #TheRiverRemembers
  결과 이미지 저장 + 스토리 공유 최적화

기술 스펙:
  플랫폼: Instagram + TikTok
  얼굴 추적: ARKit (iOS) / ARCore (Android)
  파일 크기: 5MB 이하
```

### F-002: 「캐릭터 변신」코스프레 필터

```
유형: 얼굴+상반신 AR 코스프레
캐릭터 4종:

고루 변신:
  투구 + 갑옷 상반신 오버레이
  색상: 고구려 암청 #2F4F7F
  효과: 철 파편 파티클 + 바람 효과
  포즈 감지: 팔 교차 시 「강인한 전사」

아랑 변신:
  머리 쪽 머리 + 저고리 오버레이
  색상: 백제 비단 크림
  효과: 금빛 글씨 파티클 (죽간 문자)
  소품 AR: 귀 뒤 붓 오버레이

하린 변신:
  화랑 머리띠 + 황금 갑옷 상반신
  색상: 신라 황금 #FFD700
  효과: 황금 파티클 + 화랑 검 오버레이
  포즈 감지: 검 들기 포즈 시 황금 빛 폭발

니문 변신:
  반묶음 헤어 + 가야 의상
  색상: 가야 토황 #C8A96E
  효과: 가야금 현 파동 시각화 + 음악 노트 파티클

기술 스펙:
  상반신 추적 (BodyPose API)
  의상 실시간 렌더링 60fps
  카카오톡 + 인스타그램 동시 지원
```

### F-003: 「살수대첩」전투 씬 필터

```
유형: 배경 교체 + 이펙트
연동: 드라마 EP07 방영 주간 한정 공개

배경:
  살수강 전장 배경 (물·전장·군기)
  실시간 물 파동 애니메이션

이펙트:
  화살 날아오는 효과 (상단 → 하단)
  갑옷 튕기는 파티클
  승리 시 삼족오 날아오르는 엔딩

인터랙션:
  손 제스처로 「방어」포즈 시 방패 AR 오버레이
  「공격」포즈 시 환두대도 AR 오버레이

한정 공개:
  기간: EP07 방영 당일 ~ 1주일
  이후: 특별 이벤트 기간만 재공개
```

### F-004: 「가야금 연주」음악 AR 필터

```
유형: 손 추적 + 음악 인터랙션

작동:
  카메라 앞 두 손 펼치면 가야금 AR 오버레이
  손가락 움직임 = 실제 가야금 소리 재생
  12현 각각 다른 음 배정

음악 라이브러리:
  니문 테마 멜로디 12음
  「12번째 악곡」미리듣기 버전

시각 효과:
  현 진동 파동 시각화
  음 높이별 색상 변화 (낮은 음: 토황 → 높은 음: 황금)

공유:
  연주 영상 15초 클립 저장 가능
  #가야금챌린지 해시태그 캠페인 연동

기술 스펙:
  MediaPipe HandTracking (21 키포인트)
  Web Audio API + 가야금 사운드 샘플
  틱톡 Duet 기능 연동
```

### F-005: 「강은 기억한다」시네마틱 필터

```
유형: 시네마틱 효과 + 슬로건 오버레이
용도: 고품질 사진·영상 촬영

효과:

  하단 「강은 기억한다 / THE RIVER REMEMBERS」텍스트
  강물 물결 애니메이션 오버레이 (하단)
  Letterbox 시네마틱 비율 (2.39:1)

왕국 선택:
  화면 상단 4왕국 아이콘 탭으로 전환
  각 왕국 색조 즉시 변환

공유:
  인스타그램 피드 최적화 (4:5)
  유튜브 썸네일 활용 가능

## AR 기술 스택

```
개발 환경:
  Instagram/Facebook: Meta Spark AR Studio
  TikTok: TikTok Effect Creator
  Snapchat: Lens Studio
  카카오: 카카오 AR SDK

3D 에셋:
  캐릭터 3D 모델: Blender → 플랫폼별 최적화
  폴리곤 제한: 모바일 실시간 5,000~15,000 폴리곤
  텍스처: 512×512 ~ 1024×1024 (플랫폼별)

성능 최적화:
  iOS: Metal / Android: Vulkan
  목표 프레임: 30fps (구형) / 60fps (최신)
  배터리 효율: 필터 사용 10분 이내 과열 없음

접근성:
  조명 다양성 대응 (어두운 환경·역광 테스트)
  피부톤 다양성 테스트 (다양한 인종 기기 테스트)
```

### 백제 귀족 변신 필터 (#03)

```
유형: 의상 오버레이 + 화관 착용
효과:
  머리: 백제 귀족 화관 (황금빛 봉황 장식)
  얼굴: 백제 귀족 화장 (분홍 볼터치, 붉은 입술)
  배경: 사비성 후원 + 연꽃 연못
  파티클: 금빛 꽃잎 + 봉황 날개짓

인터랙션:
  미소 → 봉황이 날아오름
  고개 기울이기 → 화관 흔들림 물리 시뮬레이션
```

### 신라 화랑 변신 필터 (#04)

```
효과:
  머리: 신라 화랑 투구 (금색)
  손 감지: 손 위에 화랑 검 생성 (손바닥 위로 올리면)
  배경: 황산벌 석양 배경
  파티클: 금빛 스파클

인터랙션:
  주먹 쥐기 → 검 꽉 쥐는 모션
  손 펼치기 → 검 사라짐 + 꽃잎 산포
```

### 고루와 함께 필터 (#05)

```
유형: 캐릭터 AR 동반자
작동 방식:
  고루 캐릭터 3D 모델 → 사용자 옆에 등장
  고루가 사용자를 바라보며 포즈 변경

  손 흔들기 → 고루가 손 흔들기
  고개 숙이기 → 고루가 절 반응
  카메라 가까이 → 고루가 뒤로 물러남 (공간 인식)

사운드:
  고루 VO 랜덤 대사 (드라마 성우):
  「강은 기억한다」/「함께 싸우자」/「고구려를 잊지 말라」
```

결과 화면:
  격침 수 표시: 「X척 격침! 기벌포의 영웅」

#### PRT-002 「백제 기록관」(아랑 변신)

```
기술:
  얼굴 → 아랑 스타일 의상·헤어 오버레이
  손 감지 → 죽간·붓 손 위 렌더링

효과:
  ① 헤어: 백제 여인 수식 (비녀·장신구)
  ② 의상: 담청색 저고리 상단
  ③ 배경: 사비성 문서관 흐릿한 배경
  ④ 손: 죽간 + 붓 AR 오버레이

인터랙션:
  화면 터치 → 붓이 죽간에 글씨 쓰는 애니메이션
  「기억한다」텍스트 흩어지며 등장

특별 효과:
  연등 파티클 (화면 주변부 흩날림)
  금동대향로 소형 홀로그램 (코너)
```

#### PRT-004 「가야 음악가」(니문 변신)

```
효과:
  ① 배경: 낙동강 황혼 + 대나무 숲
  ② 손: 가야금 AR 오버레이 (손 앞에 공중 투영)
  ③ 의상: 황토색 가야 의상 상단
  ④ 파티클: 가야금 소리 파동 시각화

인터랙션:
  손 동작 감지 → 가야금 현 뜯는 모션 → 실제 가야금 소리 출력
  「676」숫자 타이핑 → 특별 이펙트 해금

배경음:
  기본: 낙동강 물소리 루프
  상호작용 시: 가야금 멜로디 시작
```

### WORLD 필터 카테고리 (환경 변환)

#### WLD-002 「사비성 연등」

```
배경:
  실내 배경 → 사비성 연등 야경으로 교체
  백마강 수면 반사 이펙트
  연등 파티클 (100개+) 실시간 흩날림

인터랙션:
  손을 들면 → 연등 하나가 손 위에 올라옴
  걸으면 → 연등들이 따라 움직임

향기 연동 (AR+현실):
  체험관 Zone 3 연동 — 향 디퓨저 + 필터 동시 사용 안내

드라마 연계:
  아랑 필터와 결합 시 특별 효과 해금
  「사비성의 밤 / 659」텍스트 오버레이
```

#### WLD-003 「기벌포 바다」

```
배경:
  배경 → 기벌포 서해 새벽 바다
  당나라 함선 격파 잔해 (배경 소품)
  676 해전 깃발 + 바다 안개

특별 구성:
  「AD 676 기벌포」역사 날짜 UI
  22연승 카운터 애니메이션 (1→22)
  마지막 22에서 폭죽 이펙트

시리즈 완결 기념:
  드라마 시즌 3 완결 시 한정 공개
```

### GAME 필터 카테고리 (인터랙티브)

#### GAME-002 「화랑 과녁 맞추기」

```
기능:
  AR 과녁 화면에 등장
  고개 움직임으로 조준
  입 벌리면 발사 (또는 화면 탭)

게임 구성:
  10개 과녁 → 맞춘 수 기록
  7개+: 「화랑 인증」배지 발급
  10개: 「하린 급」칭호 + 특별 스티커 해금

점수 공유:
  결과 화면: 화랑 스코어카드 스타일
  「#화랑도전」해시태그
```

#### GAME-003 「가야금 연주」

```
기능:
  화면 하단 12개 현 AR 표시
  손가락으로 현 튕기면 → 실제 가야금 소리
  멜로디 학습 모드: 「기억의 강」멜로디 순서 알려줌

미션:
  「기억의 강」한 소절 완주 → 니문 스티커 획득
  풀 연주 → 「니문 급」칭호 해금

연동:
  완주 시 OST 앱 스트리밍 링크 표시
  음악 교육 기관 파트너 광고 노출 (선택)
```

### SEASONAL 필터 (한정 이벤트)

```

여름 한정 (6~8월):
