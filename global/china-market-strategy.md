## 중화권 시장 개요

### 시장 구분

```
중국 본토 (Mainland China):
- 인구: 14억
- OTT: 아이치이(愛奇藝)·텐센트비디오·유쿠
- 게임: 텐센트·넷이즈 퍼블리싱
- 콘텐츠 규제: 최고 수준 (판호 필수)
- K-콘텐츠: 한한령 이후 제한적, 점진적 완화 중

대만 (Taiwan):
- 인구: 2,400만
- OTT: 넷플릭스·KKTV·LINE TV
- K-콘텐츠: 강한 팬덤, 규제 없음
- 우선순위: 중화권 1순위

홍콩 (Hong Kong):
- OTT: viuTV·넷플릭스
- K-콘텐츠: 안정적 소비

화교권:
- 동남아 화교: 싱가포르·말레이시아·태국
- 글로벌 플랫폼 접근 가능
```

### 전략 우선순위

```
1순위: 대만 — 규제 없음, 즉시 진출 가능
2순위: 홍콩 + 동남아 화교 — 규제 최소
3순위: 중국 본토 — 규제 복잡하나 시장 규모 압도적

본토 진출 전략:
단기: 대만·홍콩 성과 구축 → 협상력 확보
중기: 판호 취득 경로 탐색 (한중 공동제작 검토)
장기: 본토 시장 진입
```

## 역사 민감 이슈 대응

### 고구려 영토 귀속 논쟁

```
배경:
중국 동북공정(東北工程): 「고구려는 중국 지방 정권」주장
→ 한국 학계·정부 강력 반박

삼국 IP 방침:
1. 고구려 = 한국 고대 왕국 — 일관된 입장
2. 불필요한 역사 논쟁 유발 표현 회피
3. 학술 논쟁 직접 언급 금지 (콘텐츠 내)

실용적 접근:
「4~7세기 한반도 고대 왕국」표현 일관 사용
현재 영토 귀속과 연결짓는 표현 금지
고구려 수도 「평양」= 현재 북한 영역 명확히

중국어 표기:
高句丽 표기 시 「古代朝鲜半岛王国」병기
```

### 가야 전략 (정치적 민감도 낮음)

```
가야 콘텐츠 우선 배치:
- 고구려 역사 논쟁 회피 → 가야로 진입 유도
- 가야 = 철기·음악·교역 → 문화적 흥미 중심
- 허황옥(許黃玉) 인도 왕녀 설화 — 국제 교류 강조
```

### 백제-중국 관계 활용

```
역사적 사실:
백제 = 중국 남조와 활발한 외교·교역
「백제의 국제성」— 중국과의 우호 교류 측면 강조

마케팅:
백제 콘텐츠 → 중화권 우선 노출
「古代朝鲜半岛与中国的交流史」프레임
```

```

  플랫폼: Netflix (영어·중문 자막) + Viu
  언어: 간체자 (싱가포르) / 번체·간체 혼용 (말레이시아)

  동남아 전략 (SEA)과 통합 — 한국어+중문 자막 동시 제공
```

### 주인공 4인 중문 번체자 표기

```
인물명:
  고루 (高婁) → 高婁 (高娄 간체)
  아랑 (阿郞) → 阿郞 (阿郎 간체)
  하린 (夏麟) → 夏麟
  니문 (尼文) → 尼文

콘텐츠 조정 (중화권 판):
유지:
  4인 주인공 캐릭터 서사
  전투·역사 이벤트 (살수·황산벌·기벌포)
  음악·비주얼 아이덴티티

조정 (대만·홍콩):
  고구려 vs 수나라 전투 → 한국 관점 그대로 유지
  역사 설명 자막: 번체자 + 현지 역사 교육 연계

조정 (중국 본토 검토 시):
  「고구려 = 한국 역사」직접 표현 → 중립적 서술로 변경
  수나라 패전 장면 → 축소 또는 중립화 검토
  법무본부 (IP-LEGAL) 최종 검토 필수
```
