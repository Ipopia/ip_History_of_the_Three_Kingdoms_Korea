## 시즌 2 개요

### 제목 및 슬로건

```
시즌 2 제목: 삼국(三國) — 강은 흐른다 (The River Flows)

시즌 1: 「강은 기억한다」— 기원과 갈등의 씨앗
시즌 2: 「강은 흐른다」— 전쟁과 선택의 시간
시즌 3 (예정): 「강은 말한다」— 통일과 소멸, 무엇이 남는가

핵심 테마 전환:
S1: 기억 / 정체성 / 왕국의 탄생
S2: 선택 / 희생 / 동맹과 배신
S3: 소멸 / 유산 / 무엇이 살아남는가
```

### 시간 배경

```
시즌 2 시대: 612년(살수대첩) ~ 645년(안시성 전투)
핵심 사건:
- 612년: 살수대첩 — 을지문덕의 기적 (시즌1 말미 ~ 시즌2 초)
- 618년: 수나라 멸망, 당나라 건국 → 동아시아 판도 재편
- 632년: 선덕여왕 즉위 — 신라 최초 여왕
- 641년: 의자왕 즉위 — 백제 마지막 황금기
- 645년: 안시성 전투 — 당 태종의 침략 격퇴

창작 타임라인:
고루(고구려): 살수대첩 전후 을지문덕 참모 → 안시성 수성전 참전
아랑(백제): 의자왕 즉위 관료 → 나당 동맹의 징조를 목격
하린(신라): 선덕여왕 직속 화랑 → 김춘추·김유신과의 만남
니문(가야): 가야 멸망 후세 → 신라에 흡수된 정체성 회복 투쟁
```

## 주요 서사 구조

### 3막 구조

```
1막 (1~4화): 폭풍 전야
- 수나라의 4차 침략 이후 동아시아 재편
- 4왕국 주인공들의 현재 위치 확립
- 당나라 부상 — 새로운 위협의 등장
- 선덕여왕 즉위 에피소드

2막 (5~10화): 선택의 갈림길
- 고구려 vs 당: 고루, 수성 vs 외교 사이에서
- 백제 의자왕의 팽창 정책: 아랑, 내부 갈등 목격
- 신라 하린: 당과의 동맹 논의 → 도덕적 딜레마
- 니문: 신라 내 가야계의 역할과 정체성
- 4인의 운명이 처음으로 직접 교차

3막 (11~16화): 안시성의 빛
- 당 태종 30만 대군의 고구려 침략
- 안시성 성주 양만춘의 수성 전략
- 고루의 최대 위기와 결단
- 아랑·하린·니문: 각자의 전쟁
- 안시성 승리 → 그러나 무엇이 남았는가?
- 시즌 3 포석: 나당 동맹의 씨앗
```

## 에피소드별 서사

### EP.1 — 「새로운 강이 흐른다」

```
시간: 618년, 수나라 멸망 직후
장소: 고구려 평양성

핵심 사건:
- 살수대첩 6년 후, 고루는 을지문덕의 참모로 성장
- 수나라 멸망 소식 — 고구려의 잠시 안도
- 그러나 당나라 건국 → 이세민의 야망이 동쪽을 향한다
- 니문의 신라 정착, 우륵의 가야금 계보를 잇는 음악가로 살아감

오프닝 시퀀스:
「6년이 지났다. 살수는 여전히 흐르고,
강은 그날의 피를 기억한다.
그러나 강은 멈추지 않는다.」
```

### EP.2 — 「황금 궁궐의 새벽」

```
시간: 618~620년
장소: 백제 사비성

핵심 사건:
- 백제 무왕(武王) 치세 — 미륵사 창건의 꿈
- 아랑: 왕실 문서 관리관으로 성장, 국제 외교 문서 접촉
- 왜국·수나라 외교 문서에서 '당나라'의 위협을 먼저 감지
- 아랑의 경고 → 조정은 무시

캐릭터 발전:
아랑: 지식인 관료 → 위기 감지자로 성장
서브플롯: 미륵사 금제사리봉영기 — 실제 역사 유물 연동
```

### EP.3 — 「별이 뜨는 경주」

```
시간: 630년대 초
장소: 신라 서라벌

핵심 사건:
- 화랑 하린, 김유신 부대에서 활약
- 진평왕 노년 — 후계 문제 (선덕女왕 즉위 포석)
- 첨성대 건설 현장에서 하린과 어린 선덕 공주의 만남
- 「별은 거짓말하지 않는다」— 선덕의 예언 능력 복선

핵심 대사:
선덕: 「저 별들은 각자 다른 속도로 움직이지만, 우리 눈엔 같이 움직이는 것처럼 보여.
      왕국도 마찬가지야, 하린. 함께 가는 것처럼 보이지만... 각자 다른 길을 가고 있어.」
```

### EP.4 — 「가야의 아들」

```
시간: 618~625년
장소: 신라 하지(下旨) — 가야계 거주 구역

핵심 사건:
- 니문: 가야 출신 음악가 집단에서 우륵 음악 전수
- 신라 내 가야계 차별 — 이등 시민의 현실
- 가야금 12곡 중 3곡 복원 성공 → 신라 왕실 공연
- 니문의 정체성: 「나는 신라인인가, 가야인인가?」

주제 발전:
문화 생존 테마 — 나라는 사라져도 문화는 남는다
가야금 음악 = 가야의 기억 = IP 핵심 주제와 연결
```

### EP.5 — 「이세민의 눈」

```
시간: 626~627년
장소: 당나라 장안 + 고구려 접경

핵심 사건:
- 당 태종 이세민 즉위 — 현무문의 변 이후
- 고구려 영류왕의 외교 전략 vs 연개소문의 강경파
- 고루: 영류왕 외교 사절단에 포함 → 장안 방문
- 당 태종을 직접 목격 — 두려움과 경외감

중국 측 시점:
이세민 묘사: 야망과 예민함의 공존
장안의 국제적 풍요 vs 고구려의 상대적 고독감
```

### EP.6 — 「연개소문」

```
시간: 642년
장소: 고구려

핵심 사건:
- 연개소문의 쿠데타 — 영류왕 시해
- 고루: 연개소문과의 첫 충돌
  → 고루는 영류왕의 외교 노선을 지지했던 인물
- 「전쟁으로 나라를 지킬 수 있다」vs「외교로 시간을 벌어야 한다」
- 고루의 이념적 위기: 강경파 연개소문 하에서 복무할 것인가?

캐릭터 위기:
고루의 최대 도덕적 딜레마 — 조국을 위해 신념을 굽힐 것인가?
연개소문: 악당이 아닌 복잡한 인물로 묘사
```

```
시간: 632년
장소: 신라 서라벌

핵심 사건:

첨성대 건설 (632~647년 추정)
황룡사 9층 목탑: 선덕왕 14년(645년) 완공
자장율사: 당 유학 후 탑 건설 건의
```

하린: 「강은 선택하지 않는다. 다만 앞으로 갈 뿐이다.」

→ 시즌 3 티저: 「660년, 강은 피로 붉어진다.」

## 캐릭터 아크 시즌 2

### 고루 (고구려)

```
시즌 1: 소년병 → 을지문덕의 제자
시즌 2: 외교관·전략가 → 가치관의 위기
시즌 3 예고: 연개소문 vs 당 사이에서 최후의 선택

시즌 2 핵심 갈등:
- 외교(평화) vs 전쟁(자존) 이념 갈등
- 영류왕 지지 → 연개소문 쿠데타 후 좌절
- 안시성에서 전사의 본능 회복
- 결론: 「나라는 칼로 지킨다. 그러나 칼만으로는 살 수 없다.」

성장 지표:
S2 초: 외교를 믿는 이상주의자
S2 중: 쿠데타로 이상 좌절 → 실의
S2 말: 안시성에서 다시 일어서는 현실주의자
```
