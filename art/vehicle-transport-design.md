# 운송 수단 & 교통 디자인 가이드

## 개요

삼국시대의 이동 수단은 크게 육상(말·마차·도보)과 해상(선박)으로 나뉜다. 각 수단의 디자인은 왕국별 특성과 사용 계층을 즉시 반영해야 한다.

---

## 육상 운송

### 말(馬)

**삼국시대 말 품종**

| 왕국 | 품종 | 특성 |
|------|------|------|
| 고구려 | 과하마(果下馬) + 북방 대형마 | 작은 조랑말~대형 전투마 혼재 |
| 백제 | 중형 한국재래마 | 균형적 — 기마+운반 겸용 |
| 신라 | 한국재래마 | 천마총 천마도 기준 — 희고 날렵 |
| 가야 | 한국재래마 | 교역마 — 강인한 체력 |

**왕국별 말 디자인 원칙**

| 왕국 | 색상 | 장식 | 마구 |
|------|------|------|------|
| 고구려 왕 | 흑마·적갈마 | 금동 마구 | 종장판갑 덮개 |
| 백제 왕 | 백마·회마 | 섬세한 금동 | 비단 안장 |
| 신라 왕 | 백마 우선 | 금제 마구 | 금관 모티프 |
| 장군 | 전투마 — 강건한 체형 | 실용적 철제 | 전투용 |
| 민중 | 소형 조랑말 | 장식 없음 | 목·가죽 |

**말 행동 설계**
- 왕의 말: 훈련된 절제 — 흥분하지 않음
- 전투마: 전장에서 발걸음 불안 — 코 벌름거림
- 짐말: 느리고 묵직한 이동
- 정예 기병마: 기수와 호흡 맞춘 움직임

### 수레 (車輛)

**왕실 어거(御車)**
```
고구려식:
- 구조: 4륜 목재 차체 + 천막형 지붕
- 외관: 흑색+주홍 칠 + 금동 장식
- 바퀴: 바퀴살 10~12개 — 견고함
- 끄는 말: 2~4두 — 권위 표시

백제식:
- 구조: 보다 낮고 우아한 선
- 외관: 백토+비취록 칠 + 봉황 문양
- 내부: 비단 쿠션 + 향로

신라식:
- 구조: 황금 장식 강조
- 외관: 금동 장식 + 신라 문양
```

**군수 마차**
```
구조:
- 2륜 또는 4륜 무개(無蓋) 화물차
- 목재 기본 — 철제 보강
- 적재: 군량미·무기·갑옷

외관:
- 장식 없음 — 완전 실용 위주
- 왕국별 색 표시는 깃발로만
```

**민간 수레**
```
구조:
- 2륜 단순 목재 수레
- 1두 또는 인력으로 이동
- 시장 물자 운반용

외관:
- 무칠(無漆) 또는 단순 갈색
- 짚·마포로 화물 덮기
```

---

### 가마 (輿)

**왕·왕비 가마**
```
구조:
- 4인 또는 8인이 앞뒤 장대로 메는 방식
- 사방에 비단 천 드리움
- 상단: 지붕형 덮개

왕국별 특성:
- 고구려: 흑·주 계통, 무거운 장식
- 백제: 백토·비취록, 봉황 자수
- 신라: 황금 장식, 신라 문양
```

**귀족 가마**
```
구조: 왕 가마 축소판
외관: 관등에 따른 장식 차등
색상: 계층에 따라 규정 (골품제·관등제)
```

## 해상 운송

### 고구려 선박

**군선(軍船)**
```
형태: 평저(平底) 전함 — 강·연안 운항 특화
규모: 길이 20~30m, 노 12~16개
갑판: 궁수 배치 공간
추진: 노 + 사각 돛
색채: 철흑+주홍 — 고구려 전함
무장: 선수 충각(衝角) + 궁수 배치
```

**수군 장면 연출**
- 대동강 수군: 강 위 전열 배치
- 요하 도하: 부교(浮橋)+선박 조합

---

### 백제 선박 (가장 발달)

**백제 외양선(外洋船)**
```
역사 근거: 백제는 동아시아 최고 수준 해상 교역국
형태: 첨저(尖底) — 외양 항해 가능
규모: 길이 30~50m, 대형 돛
갑판: 2층 — 하부 화물창, 상부 인원
색채: 백토+비취록 — 백제 상선 정체성

교역 노선 시각화:
중국 남조 방향: 서쪽 대양 항로
일본 방향: 동쪽 연안 항로
가야 방향: 남해안 단거리
```

**백제 전함**
```
형태: 교역선보다 낮고 빠름
무장: 궁수 배치 + 충각
규모: 20~40m
역사 장면: 복신의 수군 저항 (660년)
```

---

### 신라 선박

**신라 연안선**
```
형태: 평저 — 동해안 연안 특화
규모: 중소형 — 15~25m
색채: 청+황금 — 신라 색
역사 장면: 나당연합군 해상 수송 (660~668년)
```

---

### 가야 선박

**가야 교역선**
```
역사 근거: 가야는 낙동강+남해안 교역 핵심
형태: 평저 강선(江船) + 연안선 혼합
규모: 소~중형 — 철 운반 특화
색채: 철색+토적 — 가야 정체성
특이: 철정(鐵鋌) 적재 모습 — 교역 증거

항로:
왜(일본) 방향: 남해 → 대한해협
낙랑 방향: 낙동강 북상
백제 방향: 서해 연결
```

---

### 당나라 선박 (외국)

**당 대형 전함**
```
규모: 백제·신라보다 대형
형태: 당식 누선(樓船) — 다층 구조
색채: 당 황색+적색 — 확연히 다른 정체성
등장: 나당연합 수군 (660·668년)

시각적 대비:
당군 함대: 압도적 규모 → 신라·백제 선박이 작아 보임
```

## 군사 공성 장비

### 투석기 (拋石機)

**당·수나라 투석기**
```
형태: 회회포(回回砲) 전신 형태
크기: 높이 5~8m
운용: 10명+ 필요
투사체: 돌덩이·불화살

연출 포인트:
- 투석 시: 레버 작동 → 투사체 고속 이동
- 착탄: 성벽 파괴 VFX 연동
```

**고구려 수비용 장치**
```
- 방패벽: 목제+가죽 이동 방패 배열
- 기름 솥: 성벽 위 끓는 기름
- 돌 굴리기: 성벽에서 직하 투하
- 화공(火攻): 불화살+기름 화공
```

### 공성 사다리 (攻城梯)

```
형태: 대형 목제 이동 사다리
높이: 성벽 높이 + 여유분
운용: 이동식 바퀴 달린 대형 버전
역사: 안시성 전투 — 당군 사용

연출: 성벽 위 고구려 병사 vs. 사다리 타고 오르는 당군
```

## 왕국별 수송 수단 빠른 참조

| 수단 | 고구려 | 백제 | 신라 | 가야 |
|------|--------|------|------|------|
| 전마(戰馬) | 대형 북방마 | 중형 | 백마 선호 | 강건한 재래마 |
| 왕 수레 | 흑·주 4륜 | 우아한 목선 | 황금 장식 | 단순 |
| 주력 전함 | 강·연안 전함 | 외양 대형선 | 연안선 | 교역 평저선 |
| 교역선 | 제한적 | 최고 발달 | 중간 | 철정 전용 |
| 민간 이동 | 도보+조랑말 | 도보+수레 | 도보 | 도보+강선 |

## 제작 주의사항

1. **역사 고증 우선**: 동아시아 고대 선박·수레 형태 기반 — 유럽·중동 양식 혼용 금지
2. **왕국 정체성 반영**: 색채·장식이 해당 왕국 DNA와 일치
3. **계층 차등**: 왕과 민중의 이동 수단 시각적 격차 유지
4. **실사 불가능한 구조 금지**: 현대 공학으로도 불가능한 형태 배제
5. **사용 흔적 표현**: 항상 사용감 있는 상태 — 새것 금지
