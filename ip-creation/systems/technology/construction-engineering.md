## 건축 기술 개요

```
시대 배경: 4~7세기 한반도
기술 수준: 동아시아 최고 수준 (중국·일본과 교류)

건축 분류:
  군사 건축: 성곽·망루·방어 시설
  왕실 건축: 왕궁·종묘·사당
  종교 건축: 불교 사찰·신사·제단
  민간 건축: 가옥·창고·시장
  수리 건축: 관개·저수·배수

기술 수준 차이:
  고구려: 군사 건축 최강 (석축 성곽 기술)
  백제: 왕실·종교 건축 최고 (목조 기술)
  신라: 수리·관측 건축 특화 (첨성대 등)
  가야: 제철·용광로 건축 특화
```

## 고구려 — 석축 성곽 기술

### 산성 축조법

```
고구려 산성 특징:
  지형 활용: 산 능선을 따라 성벽 구축
  석재: 현무암·화강암 장방형 가공
  축성법: 내탁법(內托法) — 안쪽을 흙으로 채움

성벽 구조:
  외벽: 가공 돌 층층이 쌓기 (들여쌓기)
  내벽: 잡석·흙 혼합
  두께: 기저부 4~6m / 상부 2~3m
  높이: 평균 8~12m / 중요 구간 15m

안시성 특이 사양:
  방어선 3중 구성: 외성·내성·최후 거점
  해자: 성벽 외부 수로 (천연 강물 유도)
  함정 구역: 성문 앞 허위 통로
  저수지: 성내 독립 수원 3개소
```

### 치(雉) 시스템

```
치(雉): 성벽에서 돌출된 방어 구조물
  기능: 성벽에 붙어 기어오르는 적 측면 공격
  간격: 60~80m 등간격
  크기: 폭 6m × 길이 8m × 성벽 동일 높이

안시성 치 배치:
  북쪽: 12개 (주 공격 방향)
  남쪽: 6개
  동·서: 각 4개
  총 26개 치 → 전체 성벽 방어 가능

IP 활용:
  안시성 88일 — 치 시스템이 방어 핵심
  게임: 치 건설 전략 요소화
  전시: 1:100 안시성 모형에 치 상세 재현
```

### 고구려 주요 성 목록

```
수도 방어:
  국내성: 고구려 두 번째 수도 (현 지안)
  평양성: 고구려 마지막 수도 (3중 성곽)

방어 거점:
  안시성: 살수 북방 (88일 수성 현장)
  백암성: 요동 방어 전진기지
  오골성: 요하 서쪽 최전방

평양성 특이 구조:
  내성·중성·외성·북성 4중 구조
  대동강 천연 해자 활용
  총 둘레 23km
```

## 백제 — 목조 건축 기술

### 목탑 건축법

```
백제 목탑 특징:
  소재: 금강송(金剛松) — 결이 단단하고 곧음
  연결법: 철못 없는 결구(結構) 방식
  기초: 1m+ 지하 초석 매립

미래사 9층 목탑 (서기 634년):
  높이: 80m 이상 추정
  층 구조: 1층 폭 27m → 상층으로 좁아짐
  내부: 나선형 계단 구조
  특이: 각 층 독립 지붕 구조 (낙수 처리)

건축 기법:
  공포(栱包): 지붕 하중 분산 브래킷 시스템
  귀솟음: 모서리 기둥 약간 높게 세움 (착시 교정)
  배흘림: 기둥 중간 부분 약간 볼록 (착시 교정)
```

### 사비성 왕궁

```
위치: 충남 부여 (백마강 인근)
구조:
  정전(正殿): 4면 회랑 둘러싼 중심 건물
  동궁(東宮): 왕세자 거처
  후원: 연못 + 정자 + 화원

수로 시스템:
  백마강 → 해자 → 궁내 연못 → 배수로
  총 길이 4km 이상 수로 계획

백제 건축 미학:
  色彩: 단청 — 적·청·녹 3색 기본
  비율: 황금비 1:1.618 적용 (추정)
  장식: 봉황·연꽃·당초문

IP 활용:
  아랑 캐릭터 공간 = 사비성 후원
  금동대향로 보관실 = 왕궁 내 특별 창고
  낙화암 = 백마강 절벽 (자연 지형)
```

## 신라 — 수리·관측 건축

### 첨성대 (善德女王, 632~647년)

```
구조:
  형태: 원통형 하부 + 정방형 상부
  높이: 9.17m
  소재: 화강암 362개 (1년 날수 상징 설)
  창문: 남쪽 중간 높이 1개

기능 (학계 논쟁):
  관측설: 직접 천문 관측
  상징설: 왕권 상징 구조물
  역법설: 그림자로 절기 측정

IP 세계관 설정:
  선덕여왕의 예언 능력 연계
  하린이 첨성대에서 별 관측 → 전쟁 예측
  「하늘을 읽는 자가 땅을 다스린다」

경주 도시 설계:
  왕경(王京): 방격형 도로망 (중국 당나라 참고)
  황룡사·분황사·첨성대 남북 축선 일치
  월성 중심 방사형 도로
```

### 저수지·수리 기술

```
벽골제(碧骨堤) — 삼국 최대 저수지 (330년):
  제방 길이: 3km
  저수 면적: 약 10㎢
  관개 농지: 5,000결 이상

수리 기술 특징:
  여수로(餘水路): 홍수 시 자동 배수
  수문: 수위 조절 목제 수문
  제방 구조: 외부 돌 쌓기 + 내부 흙 다짐
```

## 가야 — 철 제련·용광로 건축

### 제철 시설

```
가야 제철 특징:
  원료: 낙동강 사철(砂鐵) 최고 품질
  연료: 경상도 목탄 (참나무·소나무)

용광로 구조:
  노(爐) 형태: 지상형 원통 + 지하형 수혈
  내화재: 내화토·짚·유기물 혼합
  송풍: 풀무질 (인력) → 수력 풀무 (발전)
  1회 처리: 철광석 200~300kg
  생산 철정: 약 50~80kg

고령 대가야 제철단지 (추정):
  용광로 20기 이상 집중 운영
  전업 장인 집단 거주
  제품: 철정·철검·철갑·농기구

IP 활용:
  니문 캐릭터 — 가야 철정 굿즈 연계
  게임: 철 생산 건물 트리 최초 개방
  머천다이즈: 가야 철정 레플리카 (ROYAL LINE)
```

## 건축 기술의 서사 연계

```
서사 포인트:

「안시성이 버텼다」(고구려):
  치 시스템 + 3중 방어선 → 88일 수성 근거
  당 태종 토산(土山) 전술 vs 고구려 반격
  고루 캐릭터: 성벽 위에서 전투 지휘

「사비성이 무너졌다」(백제):
  나당 연합 공격 vs 백제 방어 미비
  미래사 목탑 방화 — 아랑의 상실 상징
  「나무로 지은 아름다움은 불에 약하다」

「철로 지배한다」(가야):
  철정 = 화폐 = 권력
  니문: 가야 철 공방에서 태어남
  가야금 현(絃) = 가야 철사 기술의 예술화
```
