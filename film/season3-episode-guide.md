## 시즌 3 개요

```
부제: 「강은 말한다 (THE RIVER SPEAKS)」

시간대: 660년~676년
  황산벌 전투 → 백제 멸망 → 고구려 멸망 → 기벌포 전투

에피소드: 총 16화 (각 75분)
목표 방영: 2027 Q3 (티빙 독점 + 넷플릭스 글로벌)

주제:
  「모든 것이 무너진 자리에 무엇이 남는가」
  나라는 사라져도 사람의 이야기는 남는다

서사 구조: 4인 교차 서사 최고조
  고루: 고구려 최후의 방어
  아랑: 백제 기록자로서의 최후 증언
  하린: 통일의 승리자이지만 그 대가
  니문: 가야금으로 시대를 기록
```

## Arc 1 「황산벌의 하루」 (EP01~EP04)

### EP01 「결사」 (660년 7월)

```
주요 장면:
  오프닝: 황산벌 전경 — 새벽 안개 속 신라군 5만
  계백 5천 결사대 출진 장면 — 가족 결단 씬
  아랑: 사비성에서 신라군 북상 소식 기록
  하린: 신라 선봉대 지휘 — 내면 독백 「이것이 끝인가」

핵심 씬:
  계백의 칼 — 결단의 상징 (직접 묘사 최소화, 암시로 처리)
  아랑 시점: 먼 곳에서 봉화 바라보기

클리프행어:
  신라군 첫 돌격 — 계백에게 격퇴됨
  하린: 「세 번 졌다. 어떻게 돌파하느냐」
```

### EP02 「관창」 (660년 7월)

```
주요 장면:
  관창(官昌) — 16세 화랑의 돌격·전사
  하린 시점: 관창을 말리다 실패하는 장면
  신라군 사기 반전 — 관창의 죽음이 불꽃이 됨
  고루 시점 (회상): 살수에서 을지문덕이 했던 말 연결

핵심 씬:
  관창 대사: 「화랑은 물러서지 않습니다.」
  하린 독백: 「나는 그를 막았어야 했다. 아니면 함께 나아갔어야 했다.」

클리프행어:
  계백 최후의 진용 — 5천 vs 5만
  백제 진영 붕괴 시작
```

### EP03 「계백 전사」 (660년 7월)

```
주요 장면:
  황산벌 전투 클라이맥스 — 계백 최후의 돌격
  계백 전사 씬 — 영웅적 최후 (과도한 유혈 자제)
  백제군 잔존 병력 도주·항복
  아랑: 사비성 외곽에서 전투 소리 듣기

핵심 씬:
  계백 마지막 대사:
  「백제의 이름으로 싸웠다. 그것으로 충분하다.」
  하린: 쓰러진 계백 앞에서 묵례 (적장에 대한 예의)

아랑 서사:
  기록지에 「계백, 전사」 한 줄 적기
  손이 떨리는 클로즈업
```

### EP04 「사비성 함락」 (660년 8월~9월)

```
주요 장면:
  나당 연합군 사비성 포위
  의자왕 측근들의 탈출·배신
  성충의 경고가 현실이 되는 장면 (아랑 회상)
  아랑: 마지막 기록물 은닉 → 탈출

핵심 씬:
  아랑 독백 (내레이션):
  「선생님은 옳으셨다. 탄현을 지켰더라면.
   기벌포를 막았더라면. 하지만 역사는
   '만약'을 기록하지 않는다.」

의자왕 항복:
  사비성 성문 열리는 장면 — 백제 660년 멸망

시즌 3 중대 전환점:
  아랑: 이제 혼자다 (성충·흥수 모두 사망)
  백제 = 기억 속에만 존재하게 됨
```

## Arc 2 「고구려의 마지막 날들」 (EP05~EP08)

### EP05 「연개소문 이후」 (666년)

```
주요 장면:
  연개소문 임종 씬 — 고루에게 마지막 명
  아들 3형제 내전 시작 (연남생·연남건·연남산)
  연남생, 당나라에 투항 — 고루의 충격
  고구려 방어선 내부에서 무너지기 시작

핵심 씬:
  고루 독백:
  「선생은 '강은 기억한다'고 하셨다.
   하지만 강을 막아야 할 사람들이 서로 싸우고 있다.」

연개소문 마지막 대사 (회상):
  「내가 잘못한 것이 있다면 — 아들들에게
   나라를 어떻게 사랑해야 하는지 가르치지 못한 것이다.」
```

### EP06 「평양성 포위」 (667~668년)

```
주요 장면:
  나당 연합군 평양성 포위 (35만+)
  고루: 성벽 방어 지휘 — 살수대첩 전략 재현 시도
  하린: 신라군 북상 — 고루와의 첫 대면·대립
  니문: 평양성 내에서 가야금 연주 — 마지막 공연

핵심 씬:
  고루 vs 하린 대면:
  고루: 「신라는 왜 당나라 군대를 끌어들였소.」
  하린: 「고구려가 먼저 우리를 공격했습니다.」
  고루: 「...강은 기억할 것이오.」

니문 가야금:
  포위된 성안에서 연주 — 가야 멸망 연상
  「완성하지 못할 수도 있습니다.」
```

### EP07 「668년 9월」

```
주요 장면:
  평양성 내부 항복 세력 vs 항전 세력
  고루: 마지막 결전 준비 — 살수대첩과 다른 상황
  보장왕 항복 결정 — 고루의 절망
  성문 열리는 장면 — 고구려 멸망

핵심 씬:
  고루의 마지막 전투 — 부상, 생존
  보장왕이 당나라 군대에 항복하는 장면 원경
  고루, 성벽에서 내려다보며 무릎 꿇음

고구려 멸망 직후:
  당: 안동도호부 설치 선포 (한반도 직할)
  고루: 「700년이 오늘로 끝났다.」
```

### EP08 「강은 기억한다」

```
주요 장면:
  고구려 멸망 후 — 유민들의 이동
  고루, 처음으로 울다 (단 한 번)
  아랑과 고루의 재회 — 두 기록자
  하린: 승리했지만 공허함

핵심 씬:
  고루 최후 독백 (시즌 3 핵심 대사):
  「을지문덕 선생은 말씀하셨다.
   강은 기억한다. 나라가 사라져도
   이 강은 우리를 기억할 것이라고.
   나는 이제 그 말의 무게를 안다.」

아랑, 기록지에 쓰기:
  「668년 9월. 고구려 멸망.
   그러나 살수는 아직 흐른다.」
```

## Arc 3 「부흥의 불꽃」 (EP09~EP12)

### EP09 「백제 부흥군」 (661~663년)

```
주요 장면:
  백제 부흥 운동 — 흑치상지·복신·도침
  아랑: 부흥군과 합류 — 기록 사명
  왜군(일본) 지원 도착
  하린: 신라군으로서 부흥군 진압 명령

핵심 씬:
  아랑과 하린의 대립:
  아랑: 「당신들이 백제를 죽였다.」
  하린: 「나도 알고 있다.」

아랑의 기록:
  부흥군의 마지막 희망을 기록하는 씬
```

### EP10 「백강 전투」 (663년)

```
주요 장면:
  백강구(白江口) 해전 — 백제+왜 연합 vs 나당
  아랑: 해안에서 전투 목격·기록
  백제 부흥 완전 실패
  마지막 백제 깃발이 내려지는 씬

핵심 씬:
  아랑, 바다를 바라보며 마지막 기록:
  「663년. 백강. 백제의 이름이
   역사에서 마지막으로 울렸다.
   나는 이 순간을 기록한다.
   누군가는 읽을 것이다.」
```

### EP11 「고구려 부흥 세력」 (670년대)

```
주요 장면:
  고구려 유민 부흥 운동
  고루: 부흥군 합류 vs 신라와 협력 딜레마
  신라, 당나라에 반격 시작 (나당 전쟁)
  고루와 하린의 연대 — 공동의 적 = 당나라
```

### EP12 「나당 전쟁」 (670~676년)

```
주요 장면:
  신라, 고구려 부흥 세력 지원
  고루: 고구려 유민으로서 신라와 함께 싸우는 아이러니
  아랑: 기록자로서 두 나라 전쟁 목격
  니문: 가야금 새 악장 완성 — 「기억의 강」
```

## Arc 4 「기벌포」 (EP13~EP16)

### EP13 「676년 기벌포 전야」

```
주요 장면:
  신라 수군, 금강 하구 집결
  4인 주인공 마지막 집결 씬
  고루: 고구려 유민으로서 이 전쟁의 의미
  아랑: 모든 것을 기록할 준비
  하린: 「이것이 끝이길 바란다」
  니문: 가야금 연주 — 네 왕국의 테마

핵심 씬:
  4인 최후 동행 씬 (시리즈 최대 감동 포인트)
  니문이 네 왕국 테마를 하나의 악장으로 연결
```

### EP14 「기벌포 전투」

```
주요 장면:
  신라 수군 vs 당 수군 — 대해전
  하린: 최전선 지휘
  전투 중 니문의 가야금 소리 몽타주

핵심 씬:
  전투 도중 하린 독백:
  「선덕 여왕은 이 날을 보셨을까.
   살아남아야 지킬 수 있다고 하셨다.
   나는 지금 그것을 지키고 있다.」

당 수군 격퇴 — 한반도에서 당나라 완전 철수
```

### EP15 「이제야 끝났다」

```
주요 장면:
  기벌포 승전 — 신라 통일 선언
  하린: 처음으로 눈물 (선덕여왕 생각)
  고루: 「고구려가 없는 통일.
         하지만 이 땅은 남았다.」
  아랑: 기록 완성 — 죽간 묶기
  니문: 마지막 악장 완성 연주

핵심 씬:
  하린 마지막 대사:
  「이제야 끝났다.
   하지만 이것이 끝이 아닐 것이다.
   다음 세대가 이 강 위에 또 역사를 쓸 것이다.」
```

### EP16 「강은 말한다」 (피날레)

```
주요 장면:
  에필로그: 각 인물의 최후
  고루: 고구려 유민 마을 — 아이들에게 이야기 전하기
  아랑: 기록물 후대에 전달 (삼국사기 집필자 연결)
  하린: 말 위에서 강을 바라봄
  니문: 가야금 12곡 + 신작 전수 장면

최후 씬 (시리즈 엔딩):
  압록강·살수·한강·금강 — 4개의 강이 차례로 흐름
  나레이션 (고루):
  「강은 기억한다.
   나라가 사라져도, 사람이 사라져도,
   강은 흐르며 기억한다.
   우리가 여기 있었다는 것을.」

엔딩 크레딧:
  니문의 가야금 「기억의 강」 완전판 연주
  실제 삼국시대 유물 사진·영상 몽타주
```
