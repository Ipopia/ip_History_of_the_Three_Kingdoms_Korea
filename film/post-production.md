## 후반 제작 개요

```
적용 매체:
  드라마: 시즌 1 — 16화 × 60분
  영화: 극장판 120분 (시즌 완결 후)
  애니메이션 TVA: 시즌 1 — 24화 × 23분
  OVA 특별편: 살수대첩·황산벌·기벌포 각 45분

  1. 편집 (Editing)

## 1. 편집 (Editing)

### 편집 원칙

```
기본 철학:
  「역사의 무게 + 감정의 흐름」
  과도한 컷 남발 금지 — 숏 당 최소 2~3초 유지
  전투 씬: 빠른 컷 허용 (0.5~1초)
  감정 씬: 롱 테이크 우선 (5~15초)

편집 소프트웨어:
  오프라인: DaVinci Resolve 19 / Avid Media Composer
  온라인: DaVinci Resolve (컨폼)
  애니메이션: Adobe Premiere Pro (타임라인 조립)

프록시 워크플로:
  촬영 원본: 6K RAW (ARRI ALEXA 35) / 4K ProRes (보조 카메라)
  프록시: 1080p H.264 (오프라인 편집용)
  컨폼: 원본 RAW → DaVinci Resolve 온라인
```

### 왕국별 편집 톤

```
고구려 씬:
  컷 속도: 중간~느림
  전환: 하드 컷 위주 (깔끔·단호)
  전투: 충돌 순간 스피드 램프 (슬로→빠름→슬로)
  특수: 살수대첩 — 수문 개방 3초 슬로모션 후 정상 속도 복귀

백제 씬:
  컷 속도: 느림
  전환: 디졸브·페이드 허용 (서정적)
  감정: 롱 테이크 우선 (아랑 독백 — 컷 없이 2분)
  특수: 낙화암 — 수직 틸트 후 페이드 투 화이트

신라 씬:
  컷 속도: 빠름
  전환: 하드 컷 + 매치 컷 (활동적)
  전투: 기마 씬 빠른 교차 편집 (1초 미만 컷)
  특수: 기벌포 22전 — 라운드별 카운터 인서트

가야 씬:
  컷 속도: 매우 느림
  전환: 롱 디졸브 (3~5초)
  감정: 무음 롱 테이크 (니문 가야금 — 풀 연주 편집 금지)
  특수: 강 도하 — 1숏 롱 테이크 (3분)
```

### 시퀀스 편집 기준

```
에피소드 구조 (드라마 60분):
  티저: 2분 (전 화 회상 or 과거 플래시백)
  Act 1: 15분 (상황 설정·갈등 제시)
  Act 2: 25분 (갈등 심화·전개)
  Act 3: 15분 (클라이맥스·해결)
  엔딩: 3분 (다음 화 떡밥 + ED)

전투 에피소드 (살수대첩 3화):
  전투 비율: 60% 전투 / 40% 드라마
  전투 컷 속도: 평균 1.2초/컷
  드라마 컷 속도: 평균 4초/컷
  교차 편집: 전장 ↔ 후방(아랑 기록) ↔ 전략(을지문덕)
```

## 2. VFX (Visual Effects)

### VFX 카테고리

```
A급 VFX (대규모 — 외주 + 인하우스):
  살수대첩 수문 장면: 유체 시뮬레이션 (Houdini)
  대규모 군중: 디지털 더블 (10,000명 이상)
  성곽·도시 확장: 세트 익스텐션 (Nuke)
  해전 (기벌포): CG 전함 + 해수면 시뮬레이션
  화재 (사비성 함락): 대규모 화염 시뮬레이션

B급 VFX (중규모 — 인하우스):
  봉화 이펙트: 파티클 + 합성
  화살 비: CG 화살 + 실사 합성
  혈흔·먼지: 파티클 합성
  계절 환경: 눈·비·안개 합성
  연등 (백제): 발광 합성

C급 VFX (소규모 — 일상):
  와이어 제거: 스턴트 씬
  소품 CG: 금관·칠지도 클로즈업 보정
  배경 정리: 현대 건물·전선 제거
  화면 안정화: 핸드헬드 촬영 보정
```

### VFX 파이프라인

```
소프트웨어:
  3D: Houdini (유체·파티클) + Maya (모델링·애니메이션)
  합성: Nuke (메인) + After Effects (보조)
  텍스처: Substance 3D Painter
  렌더: V-Ray / Arnold
  트래킹: SynthEyes / PFTrack

워크플로:
  1. 프리비즈 (Previs): Unreal Engine 실시간 프리비즈
  2. 온셋 데이터: LIDAR 스캔 + HDR 환경맵 + 카메라 트래킹 데이터
  3. 매치무브: 3D 카메라 트래킹
  4. 레이아웃: CG 에셋 배치
  5. 애니메이션: 군중·이펙트 시뮬레이션
  6. 라이팅: 실사 조명 매칭
  7. 렌더링: 멀티 패스 렌더
  8. 합성: Nuke 최종 합성
  9. 리뷰: ShotGrid / ftrack 리뷰 시스템

숏 수 추정 (드라마 시즌 1):
  A급 VFX: 약 200숏 (주요 전투·도시)
  B급 VFX: 약 500숏 (이펙트·환경)
  C급 VFX: 약 800숏 (와이어·정리)
  합계: 약 1,500 VFX 숏 / 시즌
```

### 핵심 VFX 시퀀스

```
살수대첩 수문 시퀀스 (시즌 1 클라이맥스):
  길이: 약 90초
  숏 수: 25~30숏
  핵심 기술:
    유체 시뮬레이션 (Houdini FLIP solver)
    대규모 군중 (Golaem / Massive)
    지형 파괴 (RBD 시뮬레이션)
    카메라: 크레인 숏 → 드론 숏 (CG 합성)
  제작 기간: 8~12주
  예산 비중: 전체 VFX 예산의 15%

안시성 88일 시퀀스:
  성벽 세트 익스텐션: 실제 세트 (높이 5m) + CG 확장 (높이 15m)
  공성 기구: CG 공성탑·투석기
  토산 축조: 흙 쌓기 시뮬레이션 (타임랩스)
  제작 기간: 6~8주

기벌포 해전:
  CG 전함: 신라 전선 30척 + 당 전선 50척 모델링
  해수면: Houdini Ocean 시뮬레이션
  화공: 불 + 물 동시 시뮬레이션
  제작 기간: 10~14주
```

## 3. DI (Digital Intermediate — 색보정)

### 색보정 원칙

```
기본 방향:
  자연광 기반 — 인공적 색감 금지
  왕국별 색조 톤 차별화 (color-palette.md 준수)
  계절·시간대별 자연광 정확성

소프트웨어: DaVinci Resolve (메인 그레이딩)
마스터: DCI-P3 색공간 (극장) / Rec.709 (방송·OTT)
HDR: Dolby Vision (OTT 배급용)
```

### 왕국별 LUT (Look-Up Table)

```
고구려 LUT — 「철의 빛」:
  기조: 차갑고 강한 콘트라스트
  하이라이트: 청백색
  미드톤: 청람 (#2F4F7F) 쉬프트
  섀도: 깊은 남색~검정
  채도: 중간 (과포화 금지)
  특수: 살수대첩 — 물 장면 청록 강조

백제 LUT — 「연등의 빛」:
  기조: 따뜻하고 부드러운 톤
  하이라이트: 크림·황금
  미드톤: 황토 + 따뜻한 갈색
  섀도: 따뜻한 암갈색 (차가운 섀도 금지)
  채도: 중간~높음 (연등 장면 포화도 상승)
  특수: 멸망 후 — 채도 급격 하락

신라 LUT — 「황금의 빛」:
  기조: 밝고 선명한 톤
  하이라이트: 황금빛 (#FFD700 방향)
  미드톤: 선명한 자연색
  섀도: 적갈색
  채도: 높음 (금관·황룡사 장면 극대화)
  특수: 기벌포 해전 — 석양 오렌지 강조

가야 LUT — 「흙의 빛」:
  기조: 저채도·자연적
  하이라이트: 부드러운 백색
  미드톤: 황토·녹갈색
  섀도: 안개 같은 회색
  채도: 낮음 (의도적 저채도)
  특수: 강 도하 — 달빛 블루 모노톤
```

### 시간대별 그레이딩

```
새벽 (인시~묘시): 블루 아워 — 청색 + 저콘트라스트
아침 (진시): 골든아워 — 따뜻한 역광
낮 (사시~미시): 자연광 — 뉴트럴 (왕국 LUT 적용)
석양 (유시): 골든아워 — 오렌지·적색
밤 (술시~해시): 달빛 블루 + 횃불 오렌지 (혼합광)
  → 밤 씬 완전 암흑 금지 (관객 가시성 확보)

특수 시간:
  일식: 급격한 노출 감소 + 코로나 하이라이트
  월식: 적색 달빛 (blood moon)
  폭풍: 녹회색 하늘 + 저콘트라스트
```

## 4. 사운드 디자인 & 믹싱

### 사운드 포스트 프로덕션

```
참조: ../audio/sound-design.md (전체 SFX 기준)

포스트 사운드 공정:
  1. 대사 편집 (Dialogue Edit)
  2. ADR (Automated Dialogue Replacement)
  3. 폴리 (Foley)
  4. SFX 디자인 & 편집
  5. 앰비언스 레이어링
  6. 음악 편집 (Music Edit)
  7. 프리믹스 (Pre-Mix)
  8. 파이널 믹스 (Final Mix)
  9. 프린트 마스터 (Print Master)

소프트웨어:
  DAW: Pro Tools Ultimate (업계 표준)
  플러그인: iZotope RX (노이즈 리덕션) + Waves + FabFilter
  서라운드: Dolby Atmos Renderer
```

### 믹싱 기준

```
출력 포맷:
  극장: Dolby Atmos 7.1.4 (극장판)
  OTT: Dolby Atmos 5.1.4 (넷플릭스·웨이브)
  방송: 5.1 서라운드 (KBS/EBS)
  모바일: 스테레오 다운믹스

라우드니스 기준:
  OTT: -27 LKFS (넷플릭스 기준)
  방송: -24 LKFS (한국 방송 기준)
  극장: 85 dB SPL 기준

레이어 밸런스:
  대사: -12 ~ -6 dBFS (항상 최우선)
  음악: 대사 대비 -6 ~ -12 dB
  SFX: 장면별 동적 (전투 시 음악과 동등)
  앰비언스: -18 ~ -24 dBFS (배경 레이어)

특수 믹싱:
  살수대첩 물소리: LFE 채널 강조 (극장 진동)
  가야금 솔로: 센터 채널 집중 + 리버브 서라운드
  전투 함성: 서라운드 채널 분산 (공간감)
  고요한 씬: 거의 무음 → 갑작스러운 SFX (동적 범위 극대화)
```

## 5. 음악 편집

```
참조: ../audio/ost-tracklist.md

음악 편집 원칙:
  OST 원곡 구조 존중 — 무분별한 커팅 금지
  씬 길이에 맞춘 편곡 버전 별도 제작 (사운드본부 협업)
  감정 클라이맥스 = 음악 클라이맥스 동기화

왕국 테마 사용 규칙:
  해당 왕국 씬에서만 왕국 테마 사용
  왕국 전환 씬: 두 테마 크로스페이드 (3~5초)
  4왕국 동시 등장: 메인 테마 「기억의 강」사용

무음 연출:
  니문 가야금 씬: 모든 음악·SFX 제거 → 가야금만
  을지문덕 한시 씬: 무음 → 한시 낭독 → 서서히 음악 진입
  낙화암 씬: 음악 정지 → 바람 소리만 → 페이드 아웃
```

## 6. 자막 & 그래픽

```
한자 자막 규칙:
  역사 인물 첫 등장 시: 이름(한자) + 직위 (하단 자막 3초)
    예: 을지문덕(乙支文德) — 고구려 대신(大臣)
  지명 첫 등장: 한글 + 한자 (하단 자막)
    예: 살수(薩水), 현재 청천강

시간·장소 자막:
  폰트: 세리프 계열 (전통적 느낌)
  배치: 화면 좌하단
  형식: 「AD 612년 가을 — 살수(薩水)」

전투 정보 자막 (게임적 연출 — 선택적):
  병력 수: 양측 병력 표시
  예: 고구려 30,000 vs 수나라 305,000
  → 드라마 본편에서는 제한적 사용 (다큐멘터리 느낌 방지)
  → 전투 시작 시 1회만 표시

엔딩 크레딧:
  왕국 테마 컬러 배경 (에피소드별)
  역사 후기: 실제 역사와 창작의 경계 안내 텍스트
```

## 7. 마스터링 & 납품

### 마스터 규격

```
영상:
  해상도: 4K (3840×2160) 마스터
  코덱: Apple ProRes 4444 XQ (마스터) / H.265 (배급)
  프레임: 24fps (극장) / 24fps (OTT) / 29.97fps (한국 방송)
  색공간: DCI-P3 (극장) / Rec.709 (방송) / Rec.2020 PQ (HDR)
  비트 뎁스: 10-bit (HDR) / 8-bit (SDR 방송)

오디오:
  극장: Dolby Atmos IAB (96kHz/24bit)
  OTT: Dolby Atmos ADM BWF (48kHz/24bit)
  방송: 5.1 PCM WAV (48kHz/24bit)
  M&E: Music & Effects 분리 트랙 (더빙용)

자막:
  한국어: SRT / STL (방송)
  영어: SRT (넷플릭스 Timed Text)
  일본어: SRT
```

### 납품 체크리스트

```
□ 4K 마스터 파일 (ProRes 4444 XQ)
□ HDR 그레이딩 (Dolby Vision)
□ SDR 다운컨버전
□ Dolby Atmos 파이널 믹스
□ 5.1 서라운드 다운믹스
□ 스테레오 다운믹스
□ M&E 트랙 (더빙용)
□ 한국어 자막 (SRT + STL)
□ 영어 자막 (SRT)
□ QC 리포트 (화질·음질·자막 동기화)
□ 메타데이터 (에피소드 정보, 크레딧)

  고구려: 낮고 묵직한 발화 (울림 있게)

  신라: 밝고 또렷한 발화
  가야: 따뜻하고 소박한 발화
