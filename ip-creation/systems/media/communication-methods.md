# 삼국시대 통신·소통 방법

## 언어 소통

### 삼국의 언어

**공통 기반**
- 삼국 언어는 알타이어계로 상호 이해 가능한 수준
- 방언 차이 존재 — 지역별 발음·어휘 차이
- 한자(漢字) 공통 문어(文語): 공식 문서는 모두 한자

**왕국별 언어 특성**
| 왕국 | 특징 |
|------|------|
| 고구려 | 부여계 언어 — 북방 어휘 다수 |
| 백제 | 초기 고구려계 + 마한 토착 혼합 |
| 신라 | 진한계 언어 — 이두(吏讀) 발전 |
| 가야 | 변한계 언어 — 신라와 근접 |

**이두(吏讀)**
- 한자의 음(音)과 훈(訓)을 빌려 한국어 표기
- 신라에서 가장 발전 — 설총(薛聰) 체계화
- 실용: 공문서·행정 기록에 적용
- 의의: 한글 창제 전 한국어 표기의 선구

### 통역관(通譯)

**외교 통역**
- 대중국 교섭: 한자 문서 교환 (필담筆談) 기본
- 구두 통역: 언어 능통자 필수
- 삼국 간 통역: 유사하나 방언 차이 존재

**통역의 전략적 가치**
- 당 언어 능통 신라 외교관 → 나당동맹 핵심 역할
- 잘못된 통역 = 외교 실패 위험

## 비언어 소통

### 의례·의식 소통

**왕의 행차**
- 행렬 규모: 왕의 권위 시각적 표현
- 의장(儀仗): 깃발·악기·호위병 구성으로 신분 전달
- 북소리·나팔: 행차 알림 + 군중 통제

**복식 신호**
- 관(冠)·색상·장신구 → 신분 즉각 인식
- 고구려: 관등에 따른 조우관(鳥羽冠) 깃털 수 차별화
- 백제: 관등에 따른 대(帶) 색상 차별화
- 신라: 골품에 따른 복색 법제화

**수결(手決, 도장)**
- 왕의 인장: 외교 문서 신뢰 보증
- 관리 수결: 문서 승인 표시
- 위조 방지: 개인별 고유 문양

### 음악·소리 신호

**군사 신호**
| 신호 | 의미 |
|------|------|
| 북(鼓) 연타 | 전진 명령 |
| 징(金) 한 번 | 정지 |
| 징 두 번 | 후퇴 |
| 나팔 | 기병 돌격 |

**의례 음악**
- 아악(雅樂): 궁중 의례 — 중국 수입
- 향악(鄕樂): 토착 음악 — 가야금·거문고·향피리
- 가야금: 가야 우륵이 개발 → 신라 전파

## 문자·기록 소통

### 한자 문화권

**공식 문어**
- 삼국 모두 한자로 공문서 작성
- 왕의 교서, 외교 문서, 역사 기록 전부 한자

**역사 기록**
- 고구려: 《유기(留記)》100권 → 이문진의 《신집(新集)》5권 (600년)
- 백제: 《서기(書記)》 (고흥 편찬, 4세기)
- 신라: 《국사(國史)》 (거칠부 편찬, 545년)

**불교 경전 유통**
- 필사(筆寫): 사원에서 경전 손으로 베낌
- 목판 인쇄: 후기 도입 — 다량 복제 가능
- 경전 보급 = 불교 정보망 = 사원 간 통신망

### 서간(書簡) 문화

**사적 편지**
- 귀족·왕족 간 서신 왕래
- 운문(韻文) 서신: 시(詩) 형식 — 을지문덕의 시
- 비밀 서신: 은닉·암호화

## 종교·문화 통신망

### 불교 사원 네트워크

**사원 간 연결**
- 승려의 이동: 삼국 경계 비교적 자유 이동
- 경전·소식 전달: 사원 방문 승려가 뉴스 전파
- 왕실 정보 유통: 왕실 원찰 → 지방 사원 연결

**유학승(留學僧)**
- 중국 유학 후 귀국: 최신 정보·기술 운반자
- 혜자(惠慈): 고구려 → 일본 (쇼토쿠 태자 스승)
- 원광(圓光): 신라 → 당 → 귀국 (세속오계 제정)

### 무속 네트워크

**무당(巫堂) 정보망**
- 마을 굿 → 지역 정보 집산
- 무당이 왕래하며 소문 전달
- 민중 여론의 실질적 창구

## 시각 소통

### 깃발(旗)·표식

| 표식 | 의미 |
|------|------|
| 왕기(王旗) | 왕 친임 표시 |
| 군기(軍旗) | 부대 식별 |
| 봉수기(烽燧旗) | 봉화 보조 — 낮 시간 깃발 신호 |
| 사찰기(寺刹旗) | 사원 영역 표시 |

### 건축물 배치의 소통

- 궁궐 위치 + 규모: 왕권 강도 시각 표현
- 황룡사 9층탑: "신라는 9개국을 복속시킬 것이다" 선언
- 광개토대왕릉비: 왕의 업적 = 공개 기록 = 정치 메시지

## 소통의 장벽

### 정보 통제

- 왕의 명령 없는 정보 유출 → 중죄
- 역병·전쟁 정보: 민심 안정 위해 은폐 가능
- 왕의 사망: 후계 확정 전 비밀 유지 — 권력 공백 방지

### 소통 왜곡

- 통역 오류: 외교 실패 원인
- 봉화 오독: 거짓 경보 → 불필요한 전쟁 동원
- 소문(謠言): 민심 동요 수단 — 첩보전에 활용

## IP 활용 포인트

| 소통 요소 | 스토리 활용 |
|-----------|-----------|
| 을지문덕의 시 | 시가 외교 도구이자 유인 함정 — 문학의 전략화 |
| 왕의 사망 비밀 | 왕이 죽었지만 3일간 비밀 — 권력 암투의 72시간 |

| 이두 개발 | 설총이 한국어를 표기하려는 집념 — 지식인 서사 |
| 군사 북소리 | 전투 개시 북소리 — 청각적 긴장감 |

## 왕국별 통신망 상세

> 병합 출처: `communication-systems.md` (deprecated)

### 고구려 통신망

```
군사 봉화 체계:
  안시성~평양성 봉화선: 약 300km
  봉화 단계:
    1화 (낮 연기 / 밤 불빛): 적 접근
    2화: 적 접근 확인
    3화: 적 공격 시작
    4화: 긴급 지원 요청
    5화: 최고 위기 — 수도 방어 발령

전령 체계:
  역참(驛站) 간격: 약 30리 (12km)
  말 교체 방식: 릴레이 승마
  평양성~압록강: 약 2일 (긴급)
  평양성~안시성: 약 4일 (긴급)

삼족오 깃발 신호: 왕명 전달 전용
  적색: 전투 명령
  청색: 철수 명령
  백색: 협상 신호
  흑색: 상(喪) 발생

기록 체계:
  왕실 사관: 「유기(留記)」100권 (현존 불가)
  군사 기록: 작전 개요 죽간 보관
```

### 백제 통신망

```
해상 통신:
  황해 교역선 = 정보 운반선 겸용
  백제 항 → 중국 산동: 약 3~5일 (순풍)
  백제 항 → 왜 규슈: 약 2~3일

내륙 전령:
  금강 수로 활용 (배로 이동)
  사비성~웅진: 약 1일 (수로)
  사비성~한강 하류: 약 3일

아랑의 기록 활동:
  죽간 필사: 살아남은 자의 증언 기록
  자수 부호: 비밀 정보 암호화 가능성 (창작 설정)
```

### 신라 통신망

```
화랑 정보망:
  화랑도 = 군사 + 정보 수집 조직 겸용
  전국 순행(巡行): 지형·민심 정보 수집
  화랑 서신망: 경주 ↔ 지방 거점

봉화 체계:
  동해안선: 왜 침입 감지
  낙동강선: 가야·백제 방면
  북방선: 고구려·백제 연합 감지

당나라와의 통신:
  648년 김춘추 입당: 직접 외교 통신
  당항성(黨項城): 대당(對唐) 통신 전용 거점
```

### 가야 통신망

```
연맹 통신:
  연맹 회의: 대가야 주도 소집
  통신 한계: 단일 왕권 없음 → 연맹 내 정보 공유 느림
  철정(鐵鋌) 교역선: 정보 운반 겸용

가야 기록:
  기록 극히 희소 (멸망 후 소실)
  가야금 악보: 구전 전수 (문자 기록 없음)
  니문의 죽간: 창작 설정 — 사라져가는 가야 기록
  「소리가 곧 기록이다」— 니문의 창작 신념
```

## 정보 전달 매체 상세

> 병합 출처: `communication-systems.md` (deprecated)

### 죽간 (竹簡)

```
재료: 대나무 쪽 (폭 1~2cm, 길이 20~30cm)
용도: 군사 명령·외교 문서·일상 기록
한계: 무게·부피 큼, 습기에 약함
IP 활용:
  아랑의 죽간: 사건 기록 + 감정 일기
  죽간 분실 사건: 극적 긴장
  죽간 발굴: 현대 고고학 에필로그 가능
```

### 봉화 (烽火) 상세

```
봉화대 간격: 20~30리 (약 8~12km)
신호 도달 시간: 수도 ↔ 변경 약 2~4시간 (이론상)
한계: 날씨 영향 (비·안개 시 불통), 신호 단순
IP 활용:
  살수대첩 직전: 봉화 오신호 → 긴장 고조
  고구려 봉화 장면: 「5화(火)」발령 — 전쟁 시작
```

### 전령 (傳令) 상세

```
말 전령: 하루 약 150~200리 (60~80km)
도보 전령: 하루 약 50~60리 (20~25km)
비둘기 사용: 7세기 한반도 확인 기록 없음 → IP 미사용 (고증 준수)
IP 활용:
  전령 포획 → 적에게 정보 노출 (긴장)
  전령 사망 → 지원군 불통 (비극)
```

## 정보 비대칭 — 창작 활용 포인트

> 병합 출처: `communication-systems.md` (deprecated)

```
1. 지연된 정보:
   「황산벌 패배」소식이 아랑에게 닿기까지 5일
   → 아랑은 승리를 기다리다 결국 진실과 마주침

2. 차단된 정보:
   당나라와의 밀약을 고루는 모른다
   → 동맹인 줄 알았던 당이 적이 된 순간

3. 잘못된 정보:
   「고루 전사」오보 → 하린의 잘못된 판단
   → 실제로 살아있던 고루와 재회 시 극적 반전

4. 기록된 정보:
   아랑의 죽간 = 미래를 위한 시간 캡슐
   현대 고고학자 발굴 에필로그 연결 가능

5. 음악으로 전달된 정보:
   니문의 가야금: 「676」한 음 = 모든 것의 끝과 시작
   → 언어를 초월한 정보 전달
```
