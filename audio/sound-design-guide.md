## 사운드 디자인 철학

```
삼국(三國) 사운드 원칙:
「들리는 순간 어느 왕국인지 알 수 있어야 한다」

3가지 사운드 원칙:
1. 왕국 즉각 식별 (Kingdom Audio Identity)
   BGM·환경음·효과음 모두 왕국별 음색 차별화

2. 역사적 음향 재현 (Historical Sound Accuracy)
   7세기 악기·환경 기반 — 현대 전자음 최소화

3. 감성 레이어 (Emotional Layering)
   이야기 감정과 사운드가 일치 — 음악이 서사를 이끈다
```

## 왕국별 앰비언트 사운드

### 고구려 앰비언트

```
평양성 성벽 (낮):
  - 바람: 강한 북풍 (고주파 윙윙 + 저주파 울림)
  - 대동강: 빠른 물소리 (회청색 차가운 강)
  - 인물: 병사 발소리 (무거운 철갑 발걸음)
  - 원경: 말 울음소리 + 훈련장 함성

평양성 성벽 (밤·겨울):
  - 바람: 눈보라 (고주파 날카로운 휘파람)
  - 횃불: 불꽃 타닥 소리
  - 침묵: 순찰 사이 고요 (긴장감)
  - 간헐적: 소나무 가지 꺾이는 소리

살수 전투 앰비언트:
  - 전투 전: 저주파 긴장 드론 (베이스 울림)
  - 물 방류: 폭포 소리 → 점진적 폭발
  - 전투 중: 금속 부딪힘 + 함성 + 말발굽
  - 전투 후: 강물 + 빗소리 + 침묵
```

### 백제 앰비언트

```
사비성 문서관:
  - 등불: 은은한 불꽃 타닥
  - 붓소리: 종이 위 붓 스치는 소리 (2~3kHz)
  - 백마강: 창문 너머 잔잔한 강물 (저주파 부드럽게)
  - 두루마리: 종이 펼치는 서걱 소리

사비성 궁중:
  - 음악: 가야금+피리 앙상블 (BGM 전환)
  - 발소리: 비단 신발 (부드럽고 가볍게)
  - 자연: 연꽃 정원 새소리

백마강변:
  - 강물: 느리고 잔잔 (0.5Hz 물결)
  - 버드나무: 봄바람에 흔들리는 소리
  - 낙화암: 먼 거리 물소리 + 절벽 메아리
```

### 신라 앰비언트

```
서라벌 전경:
  - 도시 소음: 시장 인파 + 마차 + 물장수
  - 황룡사 종소리: 낮은 종 (8~12Hz 공명)
  - 화랑 훈련: 목검 소리 + 함성

첨성대 내부:
  - 돌 공명: 화강암 울림 (낮고 건조한 에코)
  - 별 관측: 완전한 고요 + 바람 소리
  - 선덕여왕 예언 씬: 공명 잔향 증가

화랑 훈련장:
  - 말발굽: 경쾌한 기마 소리
  - 활 시위: 탱! 소리 + 화살 날아가는 소리
  - 함성: 화랑 결의 구호
```

### 가야 앰비언트

```
낙동강변:
  - 강물: 넓고 느린 유속 (저주파 웅장)
  - 자갈: 물가 자갈 구르는 소리
  - 새: 갈대밭 새소리 (왜가리·물새)
  - 멀리: 제철 소리 들릴 듯 말 듯

제철 공방:
  - 용광로: 쇳물 끓는 소리 + 화염
  - 망치: 단조 소리 (규칙적 금속음 2~3Hz)
  - 풀무: 바람 밀어 넣는 소리
  - 쇳물 냉각: 물 + 쇳물 반응 소리 (쉭!)

니문 가야금 씬:
  - 환경음 제거 → 가야금만 남는 구조
  - 강물 소리가 가야금 선율과 레이어
  - 클라이맥스: 4강 물소리 동시 + 가야금 포르테
```

## 효과음 카탈로그 (주요 SFX)

### 전투 SFX

```
무기 SFX:
환두대도 발도: 금속 슬라이드 + 공명 (1.2초)
칼 부딪힘: 고주파 금속 충돌 (0.3초)
창 찌르기: 공기 가르는 소리 + 충격
화살 발사: 시위 소리 (90ms) + 날아가는 소리
화살 충돌: 플레쉬 (나무/금속에 따라 다름)
철창 타격: 무거운 금속 충돌 + 낮은 여진

갑옷 SFX:
찰갑 이동: 소찰 금속 마찰 (0.5Hz 규칙적)
찰갑 충격: 금속 타격 + 변형음
판갑 (가야): 단단한 철판 충돌 (더 건조하고 묵직)
비단 복식: 부드러운 직물 소리

기마 SFX:
말발굽 (흙길): 규칙적 4/4 타격 (BPM 연동)
말발굽 (돌바닥): 청명한 금속음
기마 돌격: 점진적 BPM 가속 + 저주파 진동
말 울음: 다양한 감정 버전 (6종)
```

### 환경 SFX

```
건축 SFX:
성문 열림: 무거운 목재 마찰 + 쇠 경첩
봉화 점화: 불꽃 퍼지는 소리 + 바람
황룡사 탑 건설: 목재 + 석재 + 인부 소리
안시성 토산: 흙 다지는 소리 + 삽 소리

자연 SFX:
살수 방류: 댐 붕괴 소리 → 폭포 폭발
폭우: 여름 강우 (삼국 전투 배경 多)
겨울 눈: 발자국 + 눈보라
봄꽃: 바람에 꽃잎 날리는 소리 (신라·백제)

생활 SFX:
두루마리 펼침: 종이 서걱 소리
붓글씨: 붓 + 종이 (아랑 씬 전용)
가야금 조율: 현 조여 음 확인 (니문 씬)
밥상 소리: 토기·나무 식기 소리
```

## 게임 사운드 시스템

```
FMOD Studio 적용:

상태 기반 음악 전환:
평화 → 전투: 크로스페이드 3초
전투 → 승리: 즉시 전환 + 팡파레 1초
전투 → 패배: 슬로우 페이드 5초

다이나믹 믹싱:
레이어 1 (기본): 왕국 테마 BGM
레이어 2 (전투): 타악 추가 (전투 강도에 따라 볼륨 자동)
레이어 3 (긴장): 현악 트레몰로 (HP 30% 이하 시 자동 활성화)
레이어 4 (영웅): 금관 팡파레 (LEGENDARY 유닛 등장)

3D 사운드:
강 타일: 강에서 거리에 따라 물소리 볼륨 자동
전투 SFX: 거리 감쇄 (원거리 전투 소리 작게)
캐릭터 발소리: 지형별 다른 음색 (흙·돌·목재·물)

모바일 최적화:
OGG 포맷 (MP3 대비 고품질+소용량)
BGM 압축: 128kbps (모바일 배터리 최적화)
SFX 압축: 96kbps
총 사운드 용량: 150MB 이내
```

## 전투 사운드 시퀀스 (SEQ)

### 살수대첩 사운드 세트

```
SEQ-001: 수나라 군 진군
  소리: 북(鼓) 대형 앙상블 + 갑옷 금속음 + 발소리
  레이어: 저음 북 4겹 + 발소리 레이어 32채널
  BPM: 84 (느리고 위압적)
  길이: 루프 가능 (전진 장면)

SEQ-002: 을지문덕 7번 후퇴
  소리: 북소리 약해짐 + 발소리 후퇴 방향 전환
  특이: 공간음(리버브) 증가 → 거리감 연출
  감성: 긴장 + 의심 (수나라 군 관점)

SEQ-003: 살수 댐 개방
  소리: 목재 수문 삐걱 + 물 방류 초기 소리 + 수위 상승
  타임라인:
    0.0s: 수문 목재 삐걱
    0.5s: 물 흘러내리기 시작
    2.0s: 급류 폭발 (전체 볼륨 최고조)
    4.0s: 함성 + 물소리 혼합
  길이: 6초 (비루프)

SEQ-004: 수나라 군 수몰
  소리: 물소리 압도 + 갑옷 침수음 + 단말마 소리 절제
  주의: 단말마·비명 직접 묘사 최소화 (감성적 접근)
  대신: 갑옷 금속음이 물속에 잠기는 소리 (거품·압력)
  배경: 고구려 함성이 물소리와 교차

SEQ-005: 살수대첩 승리
  소리: 고구려 북소리 + 군사 함성 + 멀어지는 물소리
  감성: 해방감 + 엄숙함 (승리이지만 죽음의 강)
  트랜지션: 강물 소리만 남음 → OST 고루 테마 진입
```

### 황산벌 전투 사운드 세트

```
SEQ-011: 계백 결사대 출진
  소리: 백제 북 + 발소리 + 갑옷 마찰음
  특이: 고구려 전투음보다 경량 (결사대 500명 규모)
  감성: 장엄함 + 비장함

SEQ-012: 화살 교환
  소리: 시위 당김 + 발사 휙 + 표적 명중 둔탁음
  레이어: 화살 4방향 공간음 (5.1ch 서라운드)
  밀도: 전투 초반 성김 → 클라이맥스 밀도 최대

SEQ-013: 관창 돌격
  소리: 단기 기마 질주 + 함성 + 충격음
  특이: 단독 말발굽 소리 → 다수 소리와 대비
  감성: 고요 속 단독 용기

SEQ-014: 황산벌 패배 후
  소리: 전장 정리 소리 + 바람 + 까마귀 소리
  배경: 멀리 신라군 개선 북소리 (약하게)
  아랑 반응: 여기서 소식 전달하는 특사 발소리
```

## 캐릭터 사운드 시그니처

```
고루 (고구려):
  악기: 해금 저음 + 북 저음
  발소리: 무거운 철갑 발소리 (무겁고 단단)
  검 소리: 장검 금속음 (중저음)
  감성 모티프: 안시성 바람 소리 (회상 장면)

아랑 (백제):
  악기: 가야금 중음 + 피리
  발소리: 비단 의상 스침 소리
  특이 소리: 자수 바늘 소리 (집중 장면)
  감성 모티프: 봉황 날갯짓 소리 (금동대향로 연관)

하린 (신라):
  악기: 대금 고음 + 징
  발소리: 경쾌한 말발굽 소리
  검 소리: 단검 경쾌한 금속음
  감성 모티프: 황산벌 바람 소리

니문 (가야):
  악기: 가야금 솔로 (전 감성)
  발소리: 가벼운 짚신 소리
  특이 소리: 가야금 현 뜯는 소리 (집중 장면)
  감성 모티프: 낙동강 물소리 + 가야금
```

## 전시·AR 사운드 기준

```
전시 사운드:
  Section 5 (살수 몰입관): 5.1ch 서라운드 필수
  가야금 앰비언스: 전 섹션 배경음 공통
  볼륨 기준: 최대 75dB (청력 보호 기준)
  섹션 간 음향 차단: 방음벽 + 지향성 스피커

AR 필터 사운드:
  압축 형식: AAC 128kbps (용량 최적화)
  루프 포인트: 끊김 없는 루프 설계
  왕국 필터: 왕국별 테마 8초 루프
  가야금 필터: 실제 녹음 가야금 12현 샘플

라이브 공연 사운드:
  뮤지컬: 오케스트라 생음악 원칙 (MR 병행 옵션)
  마이크: 배우 개인 핀 마이크 + 공간 마이크
  모니터: 개인 이어모니터 (IEM) 시스템
```
