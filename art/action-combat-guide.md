# 액션·전투 연출 가이드 — 삼국(三國) IP

**참조 문서**: `art-bible.md`, `vfx-style-guide.md`, `warfare-doctrine.md`, `weapons-armor.md`

## 전투 연출 철학

```
핵심 원칙:
  「전투는 서사다 — 이기는 것이 아니라 무엇을 위해 싸우는가」
  화려함보다 역사적 사실감 우선
  전투 = 캐릭터 내면을 드러내는 순간

삼국 IP 전투 스타일:
  현실 기반 고대 전투 (판타지 마법 없음)
  집단전 + 개인 결투 혼합 구성
  전략 전투 (도주·매복·기만) = 클라이맥스

금지 연출:
  현대 영화 무술 (쿵푸·닌자 액션 스타일)
  사무라이 검술 (일본풍 절대 금지)
  초인적 점프·비행 (역사극 리얼리즘 파괴)
  1명 vs 100명 무쌍 (비현실적)
  과도한 슬로모션 남용
```

## 왕국별 전투 스타일

### 고구려 전투 스타일

```
집단전:
  개마무사(鎧馬武士) 돌격: 철갑 기병 쐐기 대형
  보병 창 진형: 장창 밀집 (홉라이트 유사)
  매복전: 지형 활용 측면 기습
  청야전술: 후퇴하며 모든 물자 소각

개인 전투 (고루):
  무기: 장검 (환두대도)
  스타일: 힘과 묵직함 — 최소 동작 최대 효과
  특기: 검 막기 + 반격 (방어 → 공격 전환)
  움직임: 느리고 확실 (노련한 장수)
  회피: 몸 전체보다 최소 이동 회피
  금지: 빠른 발놀림·아크로바틱 동작

고루 전투 철학:
  「싸우지 않고 이기는 것이 최선」(을지문덕처럼)
  직접 전투 최소화 → 전략 강조
  전투 장면보다 명령·판단 장면 더 많음
```

### 백제 전투 스타일

```
집단전:
  외교 병용: 전투 직전까지 협상 시도
  방어 중심: 성곽 수성 + 반격
  기병: 적지만 정예 (귀족 기마대)

계백 결사대 특수 연출:
  규모: 5,000명 → 황산벌 500명 (숫자 감소 강조)
  전투 스타일: 필사즉생(必死則生) — 죽을 각오의 공격
  4번의 패퇴 → 5번째 최후: 점점 지쳐가는 연출
  색감: 백제 황금 갑옷 → 점점 피와 먼지로 탁해짐

아랑 전투 불개입:
  아랑 = 전사 아님 — 직접 전투 장면 없음
  전투를 원거리에서 보는 관찰자 시점
  전쟁의 공포·비극을 관객에게 전달하는 역할
```

### 신라 전투 스타일

```
집단전:
  외교 우선 후 전투: 나당연합 = 외교 전략 산물
  화랑 선봉: 젊은 화랑이 선두 돌격 (사기 고양)
  기마 + 보병 혼합: 유연한 전술

하린 개인 전투:
  무기: 단검 + 활 (원거리→근거리 전환)
  스타일: 역동적·빠름 — 젊음의 에너지
  특기: 기마 궁사 (말 위에서 활 사격)
  이동: 빠른 발놀림·방향 전환 (경쾌한 화랑)
  성장 표현: 시즌 1 = 충동적 / 시즌 3 = 절제된

관창 돌격 특수 연출:
  16세 소년의 단기 돌격
  카메라: 하린 시점 — 「저 아이가 앞으로 간다」
  슬로모션: 이 장면만 제한적 사용 허가
  감성: 충격·죄책감·경외감 혼재
```

### 가야 전투 불개입

```
니문 = 전사 아님 — 전투 회피 캐릭터

드문 위기 상황:
  가야금 케이스로 공격 막기 (1회 허용)
  빠른 도주 (전투 아닌 생존 본능)
  무기 없음 — 유일한 「무기」는 가야금 소리

니문의 전쟁 참여 방식:
  전쟁터 인근에서 부상자 기록
  전사자 이름 죽간에 기록
  생존자 증언 수집
  → 「기억 수집」= 니문의 전투
```

## 주요 전투 장면 연출 가이드

### 살수대첩 전투

```
규모: 대규모 (디지털 군중 최대 활용)
무대: 강가 + 매복 지형

Phase 1 — 수나라 진군 (웅장):
  카메라: 수나라 대군 조감 + 행진 소리
  연출: 위압감 (고구려가 얼마나 불리한지)

Phase 2 — 7번 후퇴 (전략):
  카메라: 고루 부대 후퇴 반복 (같은 장면 반복 변주)
  연출: 관객도 「왜 계속 지는가」의문 갖도록

Phase 3 — 도하 시작 (긴장 고조):
  카메라: 수나라 군 강을 건너는 모습
  삽입: 고루 신호 준비 장면 교차편집
  음악: 점점 긴장 고조

Phase 4 — 댐 개방 (클라이맥스):
  신호: 봉화 2개 연속
  수문 열림: 고루 얼굴 클로즈업 → 수문 디테일
  물 방류: 최대 VFX 예산 투입
  결과: 수나라 군 수몰 (간접 연출 위주)

Phase 5 — 승리 (여운):
  조용해지는 강
  고루 홀로 강을 바라봄
  「강은 기억한다」첫 등장 모티프
```

### 황산벌 전투

```
규모: 중규모 (집단전 + 개인 결투 병행)
무대: 광활한 평야 + 석양

계백 결사대 출전:
  카메라: 500명이 넓은 평야에 서 있는 광각
  연출: 압도적 열세 시각화 (넓은 벌판 = 소수 고립)

전투 진행:
  1~4차 교전: 백제가 신라군 격퇴 (작은 승리)
  하린 시점: 「왜 이기지 못하는가」답답함
  관창 돌격: 특수 연출 (상기 참조)
  5차 최후: 백제 결사대 전멸

하린·아랑 교차편집:
  하린 (전장): 승리의 순간
  아랑 (사비성): 패배의 소식
  같은 타임라인 — 다른 감정 대비
  마지막: 같은 하늘 아래 두 인물 동시 컷
```

## 웹툰·만화 전투 연출

```
칸 구성:
  전투 시작: 와이드 컷 (전장 전체)
  전투 중: 빠른 소컷 연속 (속도감)
  클라이맥스: 페이지 전체 1컷 (임팩트)
  결과: 조용한 컷 (여백 활용)

효과선:
  속도선: 타격·이동 방향 표현
  집중선: 긴장·클로즈업 강조
  충격파: 강한 타격 순간
  금지: 과도한 빛 효과선 (현실적 범위)

혈흔 표현:
  웹툰 (전체이용가): 혈흔 최소화 · 색 없이
  웹툰 (15세이용가): 소량 적 표현 허용
  만화 (성인판): 사실적 표현 가능
  과도한 고어: 전 등급 금지
```

## 게임 전투 애니메이션

```
캐릭터별 기본 모션 세트:
  이동: 걷기·달리기·기마 (왕국별 스타일 차별화)
  공격: 기본 3콤보 + 강공격 + 스킬 5종
  방어: 막기·회피·반격
  피격: 경상·중상·사망
  특수: 전술 스킬 (왕국 고유 모션)

고루 모션 특징:
  느리고 묵직한 모션 (헤비 워리어)
  검 동작: 큰 스윙 + 강한 찌르기
  방어: 검으로 막기 (방패 없음)

하린 모션 특징:
  빠르고 가벼운 모션 (어쌔신/스카우트)
  단검 + 활 전환 메커니즘
  기마 전투 전용 모션 세트 (말 위 궁사)

모션 품질 기준:
  주인공: 60fps 전 모션
  일반 유닛: 30fps
  컷씬: 60fps + 페이셜 캡처
```
