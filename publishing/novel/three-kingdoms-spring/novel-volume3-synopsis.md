# 소설 3권 시놉시스 — 삼국(三國): 강은 흐른다

**참조 문서**: `novel-volume2-synopsis.md`, `master-plot.md`, `main-characters.md`

**시리즈**: 삼국(三國): 강은 기억한다 3권 (완결)

---

## 3권 개요

```
제목: 삼국(三國): 강은 흐른다
부제: 강은 기억한다 — 세 번째 이야기 (완결)
시간 배경: 660년 ~ 676년
핵심 사건:
  - 백제 부흥 운동 (660~663년)
  - 고구려 최후 항전 (661~668년)
  - 고구려 멸망 (668년)
  - 신라의 당나라 축출 (기벌포 전투, 676년)
  - 한반도 통일 (676년 대동강 이남)

3권 주제:
  「강은 흐른다 — 나라가 망해도 기억은 흐른다」
  완결 주제: 기억의 영속성·문화의 생명력

완결 구조:
  3권 = 4인 각자의 최후를 향한 여정
  하지만 최후 = 끝이 아닌 흐름의 시작
```

---

## 챕터 구성

### 1부: 부흥의 불꽃 (1~6장)

```
21장: 아랑의 길
  시간: 660년 가을. 백제 멸망 직후.
  아랑: 두루마리를 품에 안고 떠남
  목적지: 당나라도 신라도 모르는 곳
  내레이션: 「기록이 살아있는 한, 백제는 죽지 않는다」
  여정 중 백제 부흥군 조직 소식 전해 들음

22장: 백강 전투 (白江口 戰鬪)
  시간: 663년. 백강(白江).
  사건: 백제 부흥군 + 왜군 vs 나당 연합군
  아랑 시점: 멀리서 전투 결과를 기록
  백제 부흥 완전 실패 → 백제 역사 공식 종결
  아랑 독백:
    「이것이 마지막이다.
     이제 백제는 없다.
     하지만 이 기록이 있다.
     강이 듣는다.」

23장: 고루의 선택
  시간: 661~666년. 고구려 평양성.
  연개소문 사망 (666년) → 아들들 내전
  고루의 선택: 누구 편에 설 것인가?
  고루 결심: 「왕을 따르지 않는다. 나라를 따른다.
               하지만 나라가 내전 중이라면...」
  답: 「강을 따른다. 강은 기억한다.」

24장: 니문의 결심
  시간: 663~668년. 신라 경주.
  니문: 12번째 악곡을 완성해야 할 이유를 찾음
  경주 형산강가에서 혼자 연주
  처음으로 12번째 현 바로 앞까지 도달
  멈추지 않으려 했지만... 또 멈춤
  니문: 「아직 아니다. 아직 끝나지 않았다.」

25장: 하린의 무게
  시간: 661~668년. 신라.
  하린: 나당 연합군의 북진에 참여
  고구려 방면 진군 — 적국을 향해
  하린: 「고루가 저기 있다. 나는 그를 향해 간다.」
  도덕적 고통: 「이것이 통일인가? 이것이 신라의 승리인가?」

26장: 668년의 봄
  시간: 668년 봄. 고구려 국경.
  4인의 시점이 처음으로 교차 (같은 장소 근처)
  고루: 평양성 방어
  하린: 평양성 밖 신라군
  아랑: 멀리서 기록
  니문: 경주에서 연주 중
```

### 2부: 마지막 항전 (7~12장)

```
27장: 평양성의 가을
  시간: 668년 가을. 평양성.
  나당 연합군 포위 완성
  고루: 성벽 위에서 압록강 방향을 바라봄
  을지문덕 회상: 「강은 기억한다. 우리가 여기 있었음을.」
  고루: 처음으로 두렵다고 느낌

28장: 내부의 적
  사건: 연개소문 아들 연남산 항복
  고루: 동료가 항복하는 것을 봄
  고루 내면: 「을지문덕 선생은 내부의 적을 경험하지 않았다」
  연개소문이 두려워했던 것 = 내부 붕괴
  연개소문의 예언이 맞았다는 씁쓸함

29장: 668년 9월
  사건: 고구려 멸망
  핵심 씬:
    고루: 강가에 홀로 앉음
    을지문덕의 목소리 회상
    강이 흐른다 — 멈추지 않는다
  고루 독백:
    「강아. 너는 기억하느냐.
     우리가 여기서 싸웠음을.
     이긴 날도, 진 날도.
     강은 기억한다.
     나는 지금 졌다.
     하지만 강은 흐른다.」

30장: 살아남은 자들
  사건: 멸망 직후 각자의 현재
  고루: 강가에서 하린을 만남 (처음이자 마지막)
  하린: 「이겼는가?」
  고루: 「...모르겠다.」
  하린: 「나도 모르겠다.」
  두 사람 사이의 침묵 — 강물 소리
  아랑: 기록물을 숨기는 장소 도달
  니문: 처음으로 12번째 현 앞에서 멈추지 않을 준비
```

### 3부: 강은 흐른다 (13~18장)

```
31장: 676년 — 기벌포
  사건: 신라, 당나라 군대 축출 성공 (기벌포 전투)
  하린: 이제 진정한 통일 = 외세 없는 통일
  하린: 「이제야 끝났다.」
  형산강가에서 관창의 머리띠를 매며 걷는 씬
  하린 독백:
    「관창아. 우리가 이겼다.
     네가 원하던 통일이 됐다.
     하지만 네가 없다.
     강은 기억한다. 너를.」

32장: 아랑의 두루마리
  시간: 668년 이후. 어딘가.
  아랑: 두루마리를 땅속 깊이 봉인
  표면에 작은 표시만 남김
  아랑: 「언젠가 누군가 찾을 것이다.
           강이 기억하듯 이것도 기억될 것이다.」
  아랑의 마지막 기록:
    「668년 9월. 고구려 멸망.
     이제 삼국은 없다.
     하지만 이 두루마리가 있다.
     강이 듣는다. 강은 기억한다.」

33장: 니문의 완성
  시간: 668년 이후 어느 날. 낙동강.
  니문: 혼자 낙동강가에 앉음
  할아버지 기억, 우륵 선생 이야기
  12번째 현에 손을 올림
  멈추지 않는다
  1음 — 2음 — 3음 — 4음 — 5음
  완성
  니문 독백:
    「할아버지. 완성했습니다.
     가야는 없어졌습니다.
     하지만 12번째 악곡이 완성됐습니다.
     음악은 나라보다 오래 삽니다.
     강처럼.」
  현대 낙동강 영상으로 전환 (현재까지 흐르는 강)
```

### 에필로그 (19~20장)

```
34장: 고루의 강
  시간: 고구려 멸망 이후. 압록강.
  고루: 노년, 혼자 강가에 앉음
  을지문덕의 말이 처음으로 완전히 이해되는 순간
  고루 독백 (소설 전체의 결론):
    「강은 기억한다.
     을지문덕 선생이 여기 서 있었음을.
     내가 여기 서 있었음을.
     고구려가 여기 있었음을.
     백제가 있었음을.
     가야가 있었음을.
     그리고 앞으로도 누군가
     이 강가에 서서 우리를 기억할 것이다.
     강은 흐른다.
     언제나.」

35장: 강은 흐른다 (완결)
  현재 시점: 21세기 한반도
  4개 강의 현재 모습 묘사 (산문)
  압록강 — 북한/중국 국경 (여전히 흐른다)
  금강 — 충남 (여전히 흐른다)
  낙동강 — 경남·경북 (여전히 흐른다)
  형산강 — 경주 (여전히 흐른다)

  마지막 문장:
    「1,300년이 흘렀다.
     고구려는 없다. 백제는 없다.
     신라는 없다. 가야는 없다.
     하지만 강은 흐른다.
     강은 기억한다.
     우리가 여기 있었음을.
     지금도.
     언제까지나.」
```

## 3권 핵심 감정 곡선

```
1부: 부흥의 꿈과 좌절
2부: 돌이킬 수 없는 멸망
3부: 비극 속의 완성·지속
에필로그: 1,300년 후의 희망

완결 메시지:
  고루: 기억은 행동으로 남는다
  아랑: 기억은 기록으로 남는다
  하린: 기억은 감정으로 남는다
  니문: 기억은 음악으로 남는다
  → 모든 기억이 강처럼 흐른다

독자 감정 목표:
  2권 마지막: 슬픔
  3권 마지막: 슬프지만 아름다운 위안
  에필로그: 조용한 희망 + 눈물
```

## 3권 집필 노트

```
3권의 위치:
  1권: 시작 (저항)
  2권: 성장 (상실)
  3권: 완결 (지속)

강 이미지 3권 변화:
  1권: 강은 기억한다 (과거)
  2권: 강도 잊는 것이 있다 (비극)
  3권: 강은 흐른다 (현재·미래)

에필로그 현대 장면:
  소설에서 드물게 허용되는 현대 시점
  독자에게: 「이 강이 지금 당신 옆에 있다」
  역사와 현재를 연결하는 장치

역사 고증:
  기벌포 전투 (676년): 신라·당나라 마지막 전투
  이후 한반도: 신라 통일 (대동강 이남)
  압록강: 현재도 북한·중국 국경 (역사 연속성 강조)
```
