## 설계 원칙

```
「악역 없는 대립 구도」
삼국(三國) IP의 핵심 원칙:
  ❌ 절대악 존재 금지
  ❌ 단순 악당 묘사 금지
  ✅ 모든 대립 인물은 자신의 논리가 있다
  ✅ 대립 인물도 「기억될 존재」로 묘사
  ✅ 주인공과 대립 인물의 차이 = 가치관·선택·운

서사 구조:
  대립 인물 = 주인공의 선택과 가치관을 시험하는 존재
  주인공이 대립 인물을 이해하는 순간 = 성장의 증거
  시즌 마지막 = 대립 인물도 기억된다
```

## 역사 대립 인물

### 수 양제 (隋煬帝) — 외부 위협의 상징

```
실존 인물: 수나라 2대 황제 양광(楊廣)
재위: 604~618년
역사적 평가: 무리한 원정·대운하 건설로 수나라 멸망 초래

삼국(三國) 서사 내 역할:
  시즌 1 최대 위협
  고루·을지문덕의 주적
  직접 등장은 최소화 (원거리 존재감)

캐릭터 설계:
  단순 폭군이 아닌 「야망의 화신」
  중화 통일의 꿈 → 고구려를 속국으로 만들려는 욕망
  패배 후 역으로 수나라 멸망의 씨앗

서사적 의미:
  113만 대군 = 탐욕이 실패하는 이야기
  을지문덕의 한시: 「神策究天文 妙算窮地理 戰勝功旣高 知足願云止」
  → 「이제 만족을 알고 멈추시오」라는 조롱
  수 양제: 멈추지 못함 → 멸망

대사 설계 (간접):
  수나라 장수 우중문이 을지문덕 한시 받고 고민하는 씬
  우중문: 「철군하자.」(역사 사실 — 실제로 철군)
  의미: 지략이 군사력을 이긴 순간
```

### 의자왕 (義慈王) — 내부 붕괴의 상징

```
실존 인물: 백제 31대 왕
재위: 641~660년
역사적 평가: 초반 명군 → 말년 방탕 → 나당 연합에 패망

삼국(三國) 서사 내 역할:
  아랑·성충의 직접 갈등 상대
  「왕이 듣지 않는」이야기의 핵심
  등장은 최소화하되 부재(不在)가 더 강조됨

캐릭터 설계:
  초반: 용맹한 왕 (실제로 고구려 침략 성공)
  말년: 성충의 말을 무시하는 왕
  멸망 직전: 낙화암 전설 (직접 묘사 없음)

서사적 의미:
  「좋은 출발도 나쁜 끝을 막지 못한다」
  성충·아랑이 경고를 해도 듣지 않는 비극
  아랑의 기록 = 후세를 위한 것, 의자왕을 위한 것이 아님

아랑과의 관계:
  의자왕이 아랑을 직접 아는 것은 아님
  하지만 의자왕의 선택이 아랑의 삶 전체에 영향
  의자왕이 성충의 말을 들었다면 → 아랑의 기록이 필요 없었을지도
```

## 창작 대립 인물

### 연개소문 (淵蓋蘇文) — 고루의 거울

```
실존 인물 + 창작 확장
생몰년: ?~666년
역사 직위: 대막리지(大莫離支) — 고구려 최고 실권자

역사적 행적:
  642년 쿠데타로 영류왕 시해 + 귀족 100여명 처단
  보장왕 옹립 (허수아비 왕)
  당 태종 침략 → 안시성 전투에서 사실상 방어 성공
  아들들 내분으로 고구려 약화

삼국(三國) 서사 내 역할:
  시즌 2 고루의 핵심 갈등 상대
  고루의 거울 = 같은 목적(나라 수호), 다른 방법(폭력 vs 원칙)

성격 설계:
  확신의 남자: 자신의 방법이 옳다는 절대적 신념
  목적 > 수단: 나라를 위해서라면 무엇이든
  카리스마: 5자루 칼 → 두려움이면서 동시에 신뢰의 상징
  외로움: 방법을 지지하는 자도, 반대하는 자도 모두 적

고루와의 관계:
  처음엔 적대 → 점차 복잡한 동료 관계
  고루: 「나라를 위한다면서 나라를 망치고 있다」
  연개소문: 「원칙을 지키다 나라를 잃는 것이 낫냐?」
  둘 다 맞고 둘 다 틀리다 = 서사의 핵심 딜레마

대사 예시:
  연개소문 → 고루:
    「을지문덕 장군이 수나라를 막았다.
     나는 내부의 적부터 막는다.
     방법이 다를 뿐 목적은 같다.」
  고루 → 연개소문:
    「방법이 다르면 목적도 달라진다.
     당신이 지키려 한 나라가 당신 때문에 무너진다.」

결말 처리:
  666년 연개소문 사망 (역사 사실)
  고루의 반응: 「그가 없어서 슬픈 게 아니다.
                 그의 방법이 옳았을지도 모른다는 게 슬프다.」
  의미: 고루가 연개소문을 완전히 부정할 수 없음

서사적 의미:
  「좋은 목적이 나쁜 방법을 정당화하는가?」
  연개소문의 비극 = 답이 없는 질문
```

### 보량(寶良) — 아랑의 그림자 (창작 인물)

```
역할: 아랑의 라이벌 기록자
소속: 백제 왕실 어용 기록관

설정:
  나이: 아랑보다 10년 선배
  직위: 왕실 공식 기록관 (아랑의 스승 성충과 경쟁 관계)
  특성: 왕이 듣고 싶은 것만 기록하는 어용 지식인

아랑과의 관계:
  보량: 「기록은 왕을 위해 있다. 진실을 위해 있는 것이 아니다.」
  아랑: 「진실을 기록하지 않으면 왕도 결국 망한다.」
  대립: 어용 기록 vs 진실 기록

서사적 의미:
  「지식인의 역할」에 대한 질문
  보량 = 현실에 타협한 지식인
  아랑 = 이상을 지키는 지식인
  둘 다 살아남았지만 → 역사는 아랑의 기록을 기억한다

결말:
  백제 멸망 시 보량은 당나라에 협력
  보량의 기록은 왕조와 함께 소각됨
  아랑의 기록만 살아남음
  의미: 「진실을 기록한 자의 기억이 남는다」
```

### 다야(多耶) — 니문의 시련 (창작 인물)

```
역할: 니문의 음악적 대립자
소속: 신라 궁중 악관(樂官)

설정:
  나이: 니문과 동년배
  직위: 신라 공식 악관 수석
  특성: 음악은 왕을 즐겁게 하는 도구라는 신념

니문과의 관계:
  다야: 「음악은 나라의 것이다. 사라진 왕국의 음악은 불필요하다.」
  니문: 「음악은 나라보다 오래 산다.」
  다야가 가야금 12번째 악곡 연주를 금지하려 함 (가야 음악 금지령)

서사적 의미:
  「문화 정체성」에 대한 질문
  정복당한 민족의 음악을 지울 권리가 있는가?
  니문의 저항 = 음악으로 하는 저항

결말:
  다야는 니문을 막지 못함
  12번째 악곡 완성 → 신라 왕도 감동
  의미: 문화는 금지로 사라지지 않는다

역사 연결:
  실제 가야금이 신라에 전해진 것 = 우륵의 귀화
  신라도 가야금을 수용 (역사 사실)
  다야의 패배 = 역사적 필연
```

## 외부 세력 인물

### 당 태종 (唐太宗) — 문명의 충돌

```
실존 인물: 당나라 2대 황제 이세민(李世民)
재위: 626~649년
역사적 평가: 동아시아 최강 군주, 안시성에서 패배

삼국(三國) 서사 내 역할:
  시즌 2 안시성 파트의 외부 위협
  연개소문·고루·양만춘의 공통 적

캐릭터 설계:
  단순 악당 아님 → 「문명과 문명의 충돌」
  당나라 = 동아시아 최선진 문명 (당시 기준)
  고구려 = 그 문명의 복속을 거부하는 나라
  「어느 쪽이 옳은가?」= 답 없는 질문

안시성 전투 서사:
  당 태종 30만 대군 vs 안시성 수만 명
  당 태종의 오만: 「고구려는 한 달 안에 무너진다」
  양만춘의 88일 → 당 태종 철수
  야사: 양만춘 화살에 당 태종 눈 맞음 (야사로 명시)

대사 설계 (간접):
  당나라 장수의 보고: 「폐하, 저 성은 함락되지 않습니다.」
  당 태종: 「저 성주는 이름도 없는 자인데.」
  → 이름 없는 영웅이 역사를 만드는 메시지
```

## 대립 인물 관계 지도

```
고루의 갈등:
  을지문덕 (스승) ←→ 고루 ←→ 연개소문 (적대적 동료)
  수 양제 (원거리 위협) ←→ 고루 ←→ 당 태종 (안시성 위협)

아랑의 갈등:
  성충 (스승) ←→ 아랑 ←→ 의자왕 (무관심한 왕)
  아랑 ←→ 보량 (어용 지식인)

하린의 갈등:
  선덕여왕 (정신적 지주) ←→ 하린 ←→ 계백 (존경하는 적)
  하린 ←→ 나당 연합 결정 (자신의 왕국의 선택)

니문의 갈등:
  우륵 (먼 스승) ←→ 니문 ←→ 다야 (음악 대립자)
  니문 ←→ 12번째 현 (자신의 내면과의 갈등)
```

## 서사 활용 지침

```
대립 인물 묘사 원칙:
  ✅ 대립 인물의 논리 = 완전히 이해 가능해야 함
  ✅ 독자/시청자가 대립 인물에게 공감하는 순간 필요
  ✅ 대립 인물도 자신만의 「강의 기억」을 가짐

금지 사항:
  ❌ 연개소문을 단순 폭군으로 묘사
  ❌ 의자왕을 처음부터 나쁜 왕으로 묘사
  ❌ 수 양제·당 태종을 악마화
  ❌ 보량·다야를 악인으로 묘사 (현실의 선택으로)

창작 대립 인물 (보량·다야):
  역사 사실과 충돌하지 않는 범위에서 창작
  주인공의 성장을 위한 「거울」로 활용
  결말은 역사적 흐름(진실이 남는다)과 일치
```
