## 성장 시스템 개요

```
핵심 철학: 「역사적 성장 — 선택이 캐릭터를 만든다」

시스템 구성:
  ① 레벨 시스템 — 경험치 기반 기본 성장
  ② 스킬 트리 — 분기형 능력 특화
  ③ 왕국 신뢰도 — 외교·관계 성장
  ④ 역사 이벤트 성장 — 특정 전투 참여 시 특별 성장
  ⑤ 장비 강화 — 고증 기반 무기·갑옷 업그레이드

목표:
  - 플레이어마다 다른 성장 경로
  - 역사 사건 참여가 직접 성장으로 연결
  - 4인 캐릭터 각자의 고유한 성장 방향성
```

## 레벨 시스템

### 기본 성장 구조

```
레벨 범위: 1 ~ 50
경험치 획득:
  전투 승리: 50~500 XP (난이도 비례)
  역사 이벤트 완료: 1,000~5,000 XP
  외교 성공: 200~800 XP
  탐험·발견: 100~300 XP

레벨업 효과:
  기본 스탯 증가 (캐릭터별 상이)
  스킬 포인트 지급 (레벨당 2점)
  새로운 이벤트·대화 잠금 해제

레벨 구간:
  1~10: 입문 (각 캐릭터 기본기 습득)
  11~25: 성장 (분기 시작)
  26~40: 전문화 (고유 능력 개화)
  41~50: 전설 (역사적 위업 달성)
```

### 캐릭터별 성장 특성

```
고루 (高婁) — 전략형:
  주요 스탯: 지휘력·인내·분석
  레벨업 보너스: 지휘 범위 +1칸/5레벨
  특화 방향: 방어 전술 vs 공격 전술
  전설 레벨(50): 「살수의 전략가」칭호 해금

아랑 (阿郞) — 지원형:
  주요 스탯: 기억력·외교·치료
  레벨업 보너스: 정보 네트워크 +1거점/5레벨
  특화 방향: 외교 강화 vs 정보 수집
  전설 레벨(50): 「사비의 기록관」칭호 해금

하린 (夏林) — 전투형:
  주요 스탯: 속도·무력·용기
  레벨업 보너스: 행동력 +1/5레벨
  특화 방향: 기마 궁사 vs 근접 전사
  전설 레벨(50): 「황산벌의 화랑」칭호 해금

니문 (尼文) — 버프형:
  주요 스탯: 음악·집중·유연성
  레벨업 보너스: 가야금 효과 범위 +1칸/5레벨
  특화 방향: 전투 버프 vs 회복 지원
  전설 레벨(50): 「기억의 연주자」칭호 해금
```

## 스킬 트리

### 고루 스킬 트리

```
[1계통] 전략 (기본):
  Lv.1: 「기다려라」— 아군 다음 행동 지연, 적 함정 유도
  Lv.5: 「살수 계획」— 지형 이용 2배 데미지 (강·협곡)
  Lv.10: 「을지문덕의 가르침」— 전체 아군 방어력 +20%

[2계통 — 방어 특화]:
  Lv.15: 「철벽」— 성곽 방어 시 피해 50% 감소
  Lv.20: 「지연 전술」— 적 전진 3턴 지연
  Lv.30: 「강은 기억한다」궁극기 (방어) — 강 지형에서 적 전멸 확률

[2계통 — 공격 특화]:
  Lv.15: 「개마돌격」— 기병 돌격 피해 2배
  Lv.20: 「포위 섬멸」— 적 후방 차단 전술
  Lv.30: 「고구려의 창」궁극기 (공격) — 전군 돌격 명령
```

### 아랑 스킬 트리

```
[1계통] 기록 (기본):
  Lv.1: 「죽간 기록」— 적 정보 획득 (스탯 노출)
  Lv.5: 「기억의 지도」— 탐험 맵 정확도 +50%
  Lv.10: 「연등 신호」— 아군 사기 +15%

[2계통 — 외교 특화]:
  Lv.15: 「백제 사절」— 타국 우호도 +20
  Lv.20: 「삼국 네트워크」— 타국 정보 자동 수집
  Lv.30: 「강이 잇는다」궁극기 (외교) — 일시적 삼국 동맹 성립

[2계통 — 정보 특화]:
  Lv.15: 「비밀 문서」— 적 계획 사전 탐지
  Lv.20: 「이중 첩자」— 적 진영 내 정보원 설치
  Lv.30: 「낙화암의 진실」궁극기 (정보) — 적 전략 완전 노출
```

### 하린 스킬 트리

```
[1계통] 화랑 (기본):
  Lv.1: 「가자!」— 이동력 +2칸
  Lv.5: 「세속오계」— 전투 시 사기 저하 면역
  Lv.10: 「기마 궁사」— 이동 중 공격 가능

[2계통 — 기마 특화]:
  Lv.15: 「관창의 용기」— 적진 돌입 시 사기 전체 +30%
  Lv.20: 「황산벌 기사」— 기병 지휘 능력 +50%
  Lv.30: 「임전무퇴」궁극기 (기마) — 전군 돌격, 후퇴 불가 3턴

[2계통 — 근접 특화]:
  Lv.15: 「신라 검술」— 연속 공격 2회
  Lv.20: 「단독 돌파」— 포위 상태서 탈출 능력
  Lv.30: 「기벌포의 검」궁극기 (근접) — 단독 적장 처치 확률
```

### 니문 스킬 트리

```
[1계통] 가야금 (기본):
  Lv.1: 「가야의 선율」— 아군 회복 +10

  Lv.15: 「치유의 선율」— 전체 아군 HP 30% 회복
  Lv.20: 「가야의 기억」— 사기 완전 회복
  Lv.30: 「나라는 사라졌어도」궁극기 (회복) — 전사 아군 전원 부활
```

## 왕국 신뢰도 시스템

```
4왕국 신뢰도 게이지 (각 0~100):
  고구려: 고루 기본 최대, 타 캐릭터 외교로 획득
  백제: 아랑 기본 최대
  신라: 하린 기본 최대
  가야: 니문 기본 최대

신뢰도 효과:
  25: 교역로 개방 (물자 이동 가능)
  50: 정보 공유 (자동 정찰)
  75: 군사 지원 요청 가능
  100: 완전 동맹 (공동 전투 가능)

신뢰도 변화:
  + 외교 성공·선물·구원 요청 응답
  - 전투 시 피해·배신·약속 불이행
  특이 이벤트: 나당연합 = 당나라 신뢰도 +50 / 고구려·백제 신뢰도 -30
```

```
  조건: 아랑 Lv.15 이상 + 사비성 연등 행사 완료
  보상: 「기억의 죽간」아이템 (정보 저장 능력 +50%)

        엔딩 크레딧 전용 연주 장면 해금
```

## 장비 강화 시스템

```
강화 단계: 0→+10 (최대)
필요 재료:
  철광석 (가야 낙동강 지역 생산)
  동(銅) (백제 교역로)
  황금 (신라 금관총 지역)
  목재 (고구려 산악 지역)

강화 효과 (예: 고루의 환두대도):
  +0: 공격력 50
  +3: 공격력 65 (+30%)
  +5: 공격력 80 + 지휘력 +5
  +7: 공격력 95 + 역사 특효 (수군 vs 육군)
  +10: 「살수대첩의 검」명칭 부여 + 특수 이펙트

강화 실패 없음 (역사 IP — 스트레스 배제 원칙)
```

## 칭호 시스템

```
획득 가능 칭호 예시:
  「강의 전략가」 — 강 지형 전투 10회 승리
  「기억하는 자」 — 아랑 정보 스킬 100회 사용
  「임전무퇴」 — 하린 후퇴 0회로 전투 완료
  「가야의 마지막 소리」 — 니문 모든 곡 연주 완료

  역사 칭호:
  「을지문덕의 후계자」— 살수대첩 만점 완료
  「낙화암의 증인」— 백제 멸망 이벤트 전 완료
  「삼국통일의 증인」— 기벌포 해전 완료

표시:
  캐릭터 이름 위 표시 (선택)
  랭킹 시스템 연동
```
