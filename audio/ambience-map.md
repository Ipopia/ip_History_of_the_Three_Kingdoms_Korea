# 앰비언스 맵 — 삼국(三國) IP

**참조 문서**: `sfx-catalog.md`, `ost-concept.md`, `scenic-environment-design.md`, `color-palette-guide.md`
**원칙**: 앰비언스는 대사 없이도 관객이 "어디에 있는지"를 느끼게 한다.

---

## 앰비언스 설계 철학

> "침묵도 소리다. 고구려의 요새는 바람만 분다. 백제의 강변은 물소리가 말을 한다. 신라의 사원은 향 연기가 소리를 머금는다."

### 앰비언스 레이어 구조 (3레이어)
```
Layer 1 (Base): 지속적 환경음 — 항상 재생
Layer 2 (Mid): 간헐적 자연음 — 불규칙 트리거
Layer 3 (Top): 인물/사건 반응음 — 장면 맞춤
```

## 왕국별 기본 앰비언스

### 고구려 앰비언스 팔레트

**핵심 정서**: 거칠고 광활한 북방의 냉기

| 장소 | Layer 1 (Base) | Layer 2 (Mid) | Layer 3 (Top) |
|------|--------------|-------------|-------------|
| 평양성 왕궁 | 북방 바람 (저강도) | 까마귀 간헐 | 갑옷 이동음 |
| 요동 변방 요새 | 강한 북풍 | 늑대 울음 (원거리) | 병사 순찰 발소리 |
| 고구려 초원 | 바람+풀 마찰 | 말 울음 (원거리) | 없음 |
| 안시성 전장 | 전장 앰비언스 | 화살·함성 (원거리) | 성벽 타격 반응 |
| 동굴·지하 | 물방울·에코 | 없음 | 횃불 |

**고구려 앰비언스 색온도**: 차갑고 건조 (2000~2800K 연동)

**고구려 시그니처 사운드**: 멀리서 들리는 뿔나팔(각적) — 장면 전환 시그널

---

### 백제 앰비언스 팔레트

**핵심 정서**: 서정적이고 아름다운 강변·궁중

| 장소 | Layer 1 (Base) | Layer 2 (Mid) | Layer 3 (Top) |
|------|--------------|-------------|-------------|
| 사비성 왕궁 | 백마강 물소리 (원거리) | 새 울음 (두루미) | 비단 옷 마찰음 |
| 백마강변 | 강물 흐름 | 바람+갈대 | 뱃소리 |
| 궁중 연회장 | 실내 정적 | 가야금 선율 (원거리) | 잔 부딪힘 |
| 낙화암 절벽 | 강바람 | 물 소용돌이 | 없음 |
| 웅진 (공주) 산성 | 산바람 | 폭포 (원거리) | 없음 |

**백제 앰비언스 색온도**: 따뜻하고 습윤 (4000~4500K 연동)

**백제 시그니처 사운드**: 강변 갈대 바람 — 백제의 서정적 정체성

---

### 신라 앰비언스 팔레트

**핵심 정서**: 신성하고 황금빛인 종교적 공간

| 장소 | Layer 1 (Base) | Layer 2 (Mid) | Layer 3 (Top) |
|------|--------------|-------------|-------------|
| 서라벌 왕도 | 도시 생활음 | 범종 여운 (원거리) | 화랑 발소리 |
| 황룡사 | 사원 정적 | 범종·목탁 | 독경 (원거리) |
| 첨성대 | 밤바람 | 별빛 (음향적 침묵) | 천문 관측 도구음 |
| 경주 들판 | 자연 앰비언스 | 봄새 울음 | 없음 |
| 금관가야 합병 현장 | 전장 잔여음 | 슬픈 바람 | 없음 |

**신라 앰비언스 색온도**: 맑고 황금빛 (3800~6500K 연동)

**신라 시그니처 사운드**: 황룡사 범종 울림 — 에피소드 시작·종료 시그널

---

### 가야 앰비언스 팔레트

**핵심 정서**: 역동적인 제철과 열린 해양

| 장소 | Layer 1 (Base) | Layer 2 (Mid) | Layer 3 (Top) |
|------|--------------|-------------|-------------|
| 김해 제철장 | 풀무·망치 앰비언스 | 쇠 단조 간헐음 | 장인 지시 목소리 |
| 구지봉 | 자연 정적 | 바람 | 신화적 SFX (구지가) |
| 항구 (낙동강 하구) | 파도·갈매기 | 배 삐걱임 | 교역 상인 목소리 |
| 대가야 왕도 | 산간 바람 | 가야금 (원거리) | 없음 |
| 가야 멸망 전야 | 긴장된 정적 | 멀리서 신라 북소리 | 없음 |

**가야 앰비언스 색온도**: 뜨겁고 어두운 불꽃색 (1800~2500K 연동)

**가야 시그니처 사운드**: 제철 망치 리듬 + 가야금 단선율 — 가야 정체성

## 특수 장면 앰비언스

### 살수대첩 (612년)
```
[전투 전 정적]
Layer 1: 살수 강물 흐름 (보통 강도)
Layer 2: 수나라 군 원거리 행군 소리
Layer 3: 을지문덕 군 숨죽인 대기

[수문 개방 순간]
Layer 1: 급격한 물 폭발음 (NAT-002 최대)
Layer 2: 수나라 군 혼란 함성
Layer 3: 고구려 돌격 북소리

[전투 후]
Layer 1: 강물 흐름 + 전장 잔여음
Layer 2: 없음
Layer 3: 바람만 남음
```

### 낙화암 (660년)
```
[도성 함락 전야]
Layer 1: 백마강 물소리
Layer 2: 멀리서 신라·당 군 북소리
Layer 3: 궁녀들 소곤거림

[낙화암 순간]
Layer 1: 강풍
Layer 2: 물 소용돌이
Layer 3: 정적 (음향적 충격 처리)

[이후]
Layer 1: 백마강 물소리만 남음 — 단조로운 슬픔
```

### 황산벌 전투 (660년)
```
[계백 결사대 출정]
Layer 1: 황산벌 들판 바람
Layer 2: 말 발굽 (계백 결사대)
Layer 3: 결사대 비장한 침묵

[1~4차 전투]
Layer 1: 전장 앰비언스
Layer 2: 화살·함성·충돌음
Layer 3: 계백 지휘 목소리

[5차 전투·최후]
Layer 1: 전장 잔여음
Layer 2: 서서히 사라지는 소리들
Layer 3: 바람만 남음
```

## 확장 레이어 구조 (4레이어)

```
기본 3레이어에 추가:
  Layer 4 — EVENT: 상황 발생 음 (전투·축제·의식)

레이어별 기술 명세:
  Layer 1 (BASE): 지속 환경음 — 항상 재생
  Layer 2 (ACTIVITY): 인간 활동음 (시장·공방·훈련) — 불규칙 랜덤 트리거 (반복감 방지)
  Layer 3 (SPECIFIC): 장소 특정 음 (사원·성곽·항구) — 장소 진입 시 페이드인 (2~5초)
  Layer 4 (EVENT): 전투·축제·의식 발생 음 — 이벤트 트리거
```

## 주파수 & 시간대 상세 가이드

### 고구려 주파수 상세

```
평양성 성벽:
  대동강 물소리: 강한 유속 (북방 강 특성)
  까마귀 울음: 간헐적 (삼족오 연상)
  ACTIVITY — 대장간 쇠 단조 / 말발굽 석판 / 갑옷 마찰 / 한자 낭독 (태학)
  SPECIFIC — 안학궁: 고요 + 깊은 실내 공명 + 비단 스침 + 궁녀 맨발
  SPECIFIC — 성곽 위: 강바람 (강도 강) + 깃발 펄럭임 + 원거리 정찰 신호음

살수 전장 주파수:
  BASE: 물소리 주파수 150~400Hz (긴박감)
  아침 안개 소리: 새소리 없음 (전투 전)
  PRE-BATTLE:
    수나라군 원거리 진군 소리
    말 울음·북소리 (멀리서)
    고구려군 침묵 (대조 효과)
  BATTLE EVENT:
    수문 개방: 기계 삐걱 → 물 폭발
    범람음: 강물 3D 서라운드
    함성: 한국어·중국어 혼재
  POST-BATTLE:
    강물 흐르는 소리만 남음
    바람 (모든 소리 소멸 후)
```

### 백제 주파수 상세

```
사비성:
  ACTIVITY — 도자기 굽는 소리 (가마 불) / 베 짜는 소리 (직조) / 상인 부드러운 톤 / 불경 낭독
  SPECIFIC — 미래사 9층 목탑: 범종 + 목탁 + 향 크래클 + 독송 잔향
  SPECIFIC — 왕궁: 비단 커튼 + 궁인 소곤소곤 + 붓 긁는 소리

백마강변:
  붓글씨: 붓 + 종이 (2~3kHz)
  백마강: 창문 너머 잔잔한 강물 (저주파 부드럽게)
  축제 연등: 등불 바람 소리 (촛불 흔들림) + 웅성임 + 노래 (멜로디 없음)
  멸망 이후: 모든 소리 제거 → 바람 + 강물만 → 비극적 공허감
```

### 신라 주파수 상세

```
서라벌:
  황룡사 종소리: 8~12Hz 공명
  ACTIVITY — 화랑 훈련장: 목검 + 함성 + 발소리 / 시장 큰 목소리 / 첨성대 관측 기기
  SPECIFIC — 첨성대 내부: 화강암 울림 (낮고 건조한 에코) + 완전 고요 + 바람
  SPECIFIC — 화랑 훈련장: 활 시위 「틱」→「휙」+ 나무 표적 + 구령

기벌포:
  BASE: 서해 파도 + 강한 해풍
  BATTLE: 목선 충돌 (목재 파열) + 당 수군 함성 (원거리) + 신라 북소리 (가까이) + 불타는 목선
  결말 (22승): 파도 소리만 남음 + 갈매기 + 해풍 + 멀리 승전 북소리 (페이드 아웃)
```

### 가야 주파수 상세

```
낙동강 유역:
  철 단조 소리: 규칙적 리듬 2~3Hz (가야 정체성)
  ACTIVITY — 가야금 원거리 연주 + 도기 가마 + 선착장 배 흔들림·노 소리
  SPECIFIC — 수릉왕묘: 완전 고요 + 바람 + 대나무 잎 + 향 타는 소리 + 멀리 니문 연주
  SPECIFIC — 철기 공방: 망치·화로·물 담금질 + 규칙적 금속 리듬 + 풀무 에어 블로우

멸망 후 가야 땅:
  BASE: 낙동강 그대로 흐름 (변하지 않음)
  새소리: 줄어듦 / 철 단조: 없음
  가야금 소리 하나 (니문의 기억) → 오래되고 희미하게 → 강물과 합류
  「나라는 사라졌어도 소리는 남는다」
```

## 시간대별 베이스 변화

```
새벽 (04:00~06:00):
  새벽 새소리 시작 / 안개 느낌 (고주파 억제) / 닭 울음 (취락지)

아침 (06:00~09:00):
  활동 소리 점진 증가 / 새소리 최대 / 인간 활동 시작

낮 (09:00~17:00):
  최대 활동 앰비언스 / 왕국별 특색 완전 가동

황혼 (17:00~20:00):
  활동 감소 / 새소리 → 곤충 소리로 전환 / 등불·불 소리 시작

밤 (20:00~04:00):
  귀뚜라미·매미 (계절별) / 야간 경비 발소리 (조용) / 강물만 지속
```

## 기술 사양 확장

```
포맷:
  게임 앰비언스: WAV 44.1kHz 24bit Stereo
  VR/AR: Ambisonics B-format (3D 공간음)
  영상: Stereo + 5.1 서라운드 병행
  스트리밍: AAC 320kbps

볼륨 기준:
  BASE: -18 ~ -12 dBFS
  ACTIVITY: -24 ~ -18 dBFS
  SPECIFIC: -20 ~ -15 dBFS
  이벤트: -12 ~ -6 dBFS (피크 -3 dBFS)

납품 구조:
  Layer별 개별 파일 (믹싱 유연성 확보)
  통합 믹스 버전 병행 납품
```
