## 건축 고증

### 고구려 건축

```
평양성 (平壤城):
구조: 내성(內城)·중성(中城)·외성(外城) 3중 성벽
소재: 화강암 + 강회 (석회) 몰탈
특징:
  - 성벽 높이: 약 8~10m (추정)
  - 성문: 쌍궐형 (좌우 문루) — 안학궁 복원 참조
  - 치(雉, 성벽 돌출부): 방어 사각지대 제거

궁실 건축:
안학궁 (평양 대성구역 발굴):
  - 중축선 기준 대칭 배치 (중국 영향)
  - 목조 단층~2층 건물
  - 기둥 간격 좁고 처마 길음 (북방 강설 대비)

고분 건축:
천장 구조: 말각조정형 (모줄임 천장) — 점차 궁형
벽화: 황토+석회 미장 위 채색
강서대묘 현무암 석실: 국내성 시대 → 평양 시대 변화

IP 적용:
드라마 평양성 세트: 안학궁 복원 도면 기준
게임 고구려 성: 3중 성벽 방어 시스템
웹툰 배경: 성벽 위 고루 장면 — 안학궁 외관 참조
```

### 백제 건축

```
사비성 (泗沘城):
사비성 나성 (羅城): 외곽 토성+목책
왕궁 추정지: 부여 관북리 발굴 — 정림사지 인근
주요 건물:
  - 능산리 사찰군 (금동대향로 발굴지)
  - 왕흥사지: 창왕(威德王) 577년 창건
  - 정림사지 5층 석탑: 백제 석탑 대표 (現 국보 제9호)

백제 건축 특징:
목탑 형식 → 석탑으로 전환 (백제식 석탑)
연꽃 기단 사용 (불교 건축)
기와: 수막새에 연꽃·봉황 문양
색채: 단청(丹靑) — 적·녹 중심 (중국과 다른 배합)

일본 전파:
백제 기술자가 일본 아스카 건축 담당
호류지(法隆寺) 등 일본 고대 건축에 백제 영향 확인

IP 적용:
드라마 사비성 왕궁: 관북리 발굴 성과 + 정림사지 참조
아랑의 문서관: 목조 단층 건물, 연꽃 기와
```

### 신라 건축

```
서라벌 (徐羅伐):
황룡사 (皇龍寺): 진흥왕 553년 착공, 9층 목탑 (선덕왕 645년 완성)
  - 추정 높이: 약 80m (동아시아 최고)
  - 1238년 몽골 침입 소실
  - 발굴 성과: 심초석·기단 확인, 복원 연구 진행 중
첨성대 (瞻星臺): 선덕왕 재위 중 (632~647년) 건립
  - 높이 9.17m, 圓筒形
  - 화강암 362개 돌 + 규칙적 배열
  - 기능: 천문 관측 (학설 논쟁)

신라 건축 특징:
분황사 모전석탑: 돌을 벽돌처럼 쌓은 독자 양식
고분: 적석목곽분(積石木槨墳) — 황남대총·금관총 형식
서라벌 도시 계획: 격자형 가로 구획 (시가지)

IP 적용:
드라마 첨성대 공사 씬: 화강암 운반·쌓기 과정 묘사
하린 씬 배경: 황룡사 9층 목탑 실루엣 (완공 전 공사 중)
게임 신라 건물: 첨성대·황룡사 랜드마크
```

### 가야 건축

```
가야 도시 (김해):
금관가야 도성: 봉황동 유적 — 소형 판축 토성
건물: 주혈 건물지 (기둥 구멍 흔적)
수혈 주거: 반지하형 — 서민 주거 형태

가야 건축 특징:
고분: 목곽묘(木槨墓) → 수혈식석곽묘
  - 대성동 고분군: 대형 목곽 + 다량 철기·금제 유물
  - 도항리·말산리: 아라가야 고분군
제철 시설: 단야 도구·슬래그 출토 → 대장간 배치 추정

IP 적용:
드라마 가야 장터: 봉황동 유적 기반 주거 배치
니문의 집: 강변 목조 소형 주거 (악사 계층)
게임 가야 시설: 제철소·대장간 핵심 건물
```

## 미술·공예 고증

### 고분벽화 (회화)

```
고구려 고분벽화 4대 주제:
① 생활 풍속도: 수렵·음식·무용·씨름 (무용총)
② 초상화: 묘주 인물 (안악3호분)
③ 사신도: 청룡·백호·주작·현무 (강서대묘)
④ 천문도: 별자리·해·달 (덕흥리 벽화분)

회화 기법:
황토+석회 미장 → 건조 전 채색 (프레스코 유사)
윤곽선: 철선묘 (가는 선) + 면 채색
색채: 주(朱)·황(黃)·녹(綠)·청(靑)·흑(黑) 5색 기본

IP 활용:
게임 로딩 화면: 무용총 수렵도 스타일 일러스트
아트북: 각 화 시작 수묵화 컷 (벽화 오마주)
체험관: 강서대묘 사신도 대형 벽화 복제
```

### 금속공예

```
고구려:
청동 항아리·거울 — 기마 민족의 실용 금속
금동 투구 장식 — 삼족오 부조

백제:
무령왕릉 금제 관식:
  - 인동당초문(忍冬唐草文) — 넝쿨 문양 정교 표현
  - 투조(透彫) 기법 — 금판을 뚫어 문양 만듦
  - 최고 수준 장인 기술 (동아시아 비교 최고급)
칠지도(七支刀):
  - 백제 왕이 왜왕에게 선물 (일본서기)
  - 가지 7개가 달린 검 — 현존 이소노카미 신궁 소장

신라:
금관: 출자형 세움 장식 + 곱은옥 장식
  - 금관총·서봉총·황남대총·금령총·교동 금관 5점
  - 누금(鏤金) 기법: 금 실로 세부 장식
금귀걸이: 심엽형(心葉形) — 중간 주환 + 하단 수식

가야:
철제 판갑: 도항리 출토 — 철판 직접 이어 붙임
금제 관: 단순 형태 — 신라보다 간략
동경(銅鏡): 거울 — 교역품으로 왜에 수출

IP 활용:
머천다이즈: 무령왕릉 금제 관식 패턴 → 주얼리 라인
체험관: 신라 금관 착용 체험 (레플리카)
드라마 소품: 무령왕릉 대도(大刀) 실물 크기 복제
```

## 음악 고증

### 삼국시대 악기

```
현악기 (絃樂器):
가야금 (伽倻琴):
  - 구조: 오동나무 몸통 + 12현 (명주실)
  - 연주: 오른손 발현, 왼손 농현(弄絃)으로 음색 변형
  - 우륵 12악곡: 고증 곡명 11개 + 미상 1 (IP 핵심)

거문고 (玄琴):
  - 고구려 왕산악이 중국 악기 개량
  - 6현, 술대(棒)로 연주
  - 고구려 고분벽화 「무용총」에 연주 장면 묘사

관악기 (管樂器):
단소 (短簫): 세로 단관 — 맑은 고음
피리 (觱篥): 쌍관 — 사막 기원, 한반도 전래
대금 (大笒): 횡적 — 신라 세 가지 악기(三竹) 중 하나

타악기 (打樂器):
장고 (長鼓): 삼국 이전부터 존재 추정 — 고분벽화 확인
북 (鼓): 전쟁 신호용 + 제의용 — 크기별 다양

IP 음악 적용:
가야금: 니문 전용 악기 (고증 충실)
거문고: 고구려 궁중 음악 배경 (고루 씬)
단소+피리: 백제 궁중 앰비언스 (아랑 씬)
북: 전투 신호 SFX (살수대첩, 안시성)
```

### 음악 이론 고증

```
삼국시대 음악 이론:
음계: 5음계 기본 (궁·상·각·치·우)
중국 영향 + 고유 변용
가야금: 개방현 + 농현 기법으로 반음 표현

삼국사기 악지(樂志) 기록:
「가야국 가실왕이 당나라 악기를 보고 가야금을 만들었다…
 나라마다 언어가 다른데 음악도 어찌 같겠는가」
→ 가야의 독자 음악 문화 강조

우륵 악곡 창작 배경:
가야 12현 → 12곡 → 각 고을 음악 정리
신라 투항 후 진흥왕 보호 → 신라 음악으로 전승
현재: 정간보에 기록된 가야금 악보 참조 가능

IP 음악 창작 기준:
OST 가야금 테마: 5음계 기반 현대 편곡
니문의 12번째 곡: 5음계 + 현대 화음 해석
사운드 고증: ADV-ARTS 승인 후 AUDIO팀 사용
```

## 공연예술 고증

### 무용

```
고구려 무용:
무용총 「무용도」기반:
  - 긴 소매 휘두르기 (장수무 형태)
  - 5~7명 열 지어 춤
  - 배경에 악사 (거문고·비파·북)
  - 복식: 긴 치마 + 짧은 상의

신라 무용:
처용무 (處容舞) — 후대 기록이지만 신라 기원 전통
화랑 무예 무용: 검무 계통 (창작 확장)

가야 무용:
가야금 반주 + 단순한 강변 춤 (IP 창작)
구지가 노래와 춤 — 건국 신화 제의 춤

IP 활용:
드라마 무용 씬: 무용총 기반 고구려 무용
뮤지컬: 살수대첩 장면 무용+전투 결합 안무
체험관: 화랑 무예 체험 프로그램
```

### 제의·의식

```
왕실 제의:
고구려: 동맹(東盟) — 10월 수렵 제천 행사
백제: 교천(郊天) — 국가 제의
신라: 팔관회(八關會) — 불교 + 토속 혼합 제의

점술·예언:
선덕여왕 예언 3가지: 역사적 사실 + 신화적 의미
무당(巫堂): 국가 결정에 무격(巫覡) 참여
  → IP에서 선덕여왕 '예언' 씬에 고대 예지 문화 반영

IP 활용:
선덕여왕 예언 씬: 제의 공간 설정
연개소문 쿠데타: 고구려 샤머니즘적 결단 장면 (은유)
```

## 의복·생활문화 고증

### 식생활

```
삼국시대 주식:
고구려: 북방 → 조·기장·콩 + 수렵(사슴·멧돼지)
백제: 농업 중심 → 쌀·콩·보리 + 어업(서해)
신라: 경주 분지 → 쌀 농업 발달
가야: 낙동강 → 어업 발달 + 쌀 농업

음주 문화:
삼국사기: 각 왕국 음주 기록 존재
막걸리 전신: 탁주(濁酒) — 농경 사회 일상 음료
제례·혼례: 술 필수

IP 활용:
드라마 식사 씬: 왕국별 식기·음식 차별화
백제 식사: 금동 식기 (무령왕릉 참조)
고구려 식사: 철기 식기 + 수렵 음식
가야 식사: 강변 어식 강조
```

### 예절·풍속

```
인사 예법:
맞절: 왕에게 복종 (跪拜)
읍례(揖禮): 귀족 간 상호 예절
군례(軍禮): 무관 경례 방식

시간 관념:
12지신 시각 사용 (자시~해시)
계절 제의: 봄·가을 농경 제의

주거 문화:
바닥 생활: 온돌(溫突) — 고구려에서 시작
  - 고구려 온돌: 발굴 고고학 확인 (고구려 황해도 유적)
  - 백제·신라: 온돌 보급 후진 (IP 드라마 공간 반영)

IP 활용:
고루 방: 온돌 + 바닥 좌식 문화
아랑 문서관: 좌식 문서 작업 (경상·붓·먹)
드라마 인사 씬: 계급별 예법 차별화
```

## 자문 적용 우선순위

```
HIGH (반드시 고증):
- 주요 건물 외관 (성벽·궁궐·탑)
- 복식 색채·형태
- 실존 악기 연주 방식
- 실존 유물 묘사

MEDIUM (고증 기반 창작):
- 일상 생활 공간 내부
- 음식·식기 세부
- 제의·의식 절차

LOW (창작 자유):
- 캐릭터 전용 소품 (고루의 창·아랑의 단검)
- 신화적 존재 비주얼
- 음악 작곡 (5음계 기반 자유 창작)

자문 요청 프로세스:
창작팀 → ADV-ARTS 자문 요청서 → 5영업일 이내 회신
긴급: 2영업일 이내 구두 자문 가능
```
