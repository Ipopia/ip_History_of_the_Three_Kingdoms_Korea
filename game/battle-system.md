## 전투 시스템 개요

```
게임 장르: 전략 RPG (턴제 전략 + 실시간 액션 혼합)

전투 레이어:
  레이어 1 — 전략 맵 전투 (거시):
    왕국 vs 왕국 병력 충돌
    유닛 배치·이동·공성 (헥사곤 그리드)
    턴제 (각 플레이어 순서 명확)

  레이어 2 — 전술 전투 (중시):
    전장 내 부대 전술 운용
    지형 활용·포위·기습
    반실시간 (일시정지 명령 가능)

  레이어 3 — 영웅 액션 (미시):
    주인공 4인 직접 조작
    실시간 액션 전투 (콤보·스킬)
    전략 맵 전투 중 선택적 개입
```

## 레이어 1 — 전략 맵 전투

### 유닛 시스템

```
유닛 종류:
  보병 (步兵):
    이동: 2칸/턴
    공격: 근접 1칸
    강점: 도시·요새 방어
    약점: 기병에 취약

  기병 (騎兵):
    이동: 4칸/턴 (평야), 2칸(산악)
    공격: 돌격 시 +50% 데미지
    강점: 평야 기동·추격
    약점: 산악·요새 진입 패널티

  궁병 (弓兵):
    이동: 2칸/턴
    공격: 원거리 2칸
    강점: 성벽 위 방어 +30%
    약점: 근접 전투 취약

  공성 (攻城):
    이동: 1칸/턴
    공격: 요새 전용 (일반 유닛 공격 불가)
    강점: 성벽 공략 유일 수단
    약점: 기병 공격 시 즉시 파괴

  수군 (水軍):
    이동: 강·해안 전용
    공격: 함선 충돌·투석기
    강점: 강 통제·해상 교역로 차단
    약점: 육상 이동 불가

  화랑 (신라 전용):
    이동: 3칸/턴
    공격: 영웅 유닛 (1인 = 보병 10인 전투력)
    특수: 「임전무퇴」— 후퇴 불가 옵션 활성화 가능
```

### 전투 해결 공식

```
기본 공식:
  전투력 = 유닛 수 × 유닛 등급 × 지형 보너스 × 사기

지형 보너스:
  산악 방어: +40%
  요새 방어: +60%
  강 도하 공격: -20%
  평야 기병: +25%

사기 시스템:
  사기 100: 전투력 +20%
  사기 50 (기본): 보너스 없음
  사기 0 (붕괴): -30% + 후퇴 확률 50%

사기 변화 요인:
  +승리: +10 / +지휘관 생존: +5 / +가야금 연주: +15 (특수)
  -패배: -15 / -지휘관 전사: -25 / -겨울 장기전: -5/턴
```

### 역사 이벤트 전투

```
살수대첩 (612년) — 특별 전투 메커닉:
  전제 조건: 고구려 캠페인 진행 중
  트리거: 수나라 부대 살수 도하 시
  이벤트 선택:
    A) 수문 개방 (역사 선택) → 강물 범람 자동 승리
    B) 정면 전투 (창작 선택) → 일반 전투 (난이도 높음)
  역사 선택 보상: 「을지문덕의 검」+ 칭호 「살수의 영웅」
  창작 선택 결과: 가능하나 보상 감소

황산벌 (660년) — 수적 열세 전투:
  백제 5,000 vs 나당 50,000
  자동 패배 조건 없음 → 기적 승리 가능
  관창 특공 이벤트:
    선택 A) 관창 돌격 허용 → 사기 최대치 (+30) + 관창 전사
    선택 B) 관창 저지 → 사기 유지 + 관창 생존
    역사 고증: A 선택이 실제 역사 (관창 전사)
  결말: A 선택 시 더 강한 엔딩 해금

기벌포 (676년) — 연속 해전:
  22라운드 연속 전투 (신라 수군 vs 당나라 함대)
  각 라운드: 전술 선택 3가지 (정면·우회·화공)
  22승 모두 달성 시: 최고 엔딩 해금
  도중 패배: 재시도 가능 (역사 수정 불가 설정)
```

## 레이어 2 — 전술 전투

### 전장 시스템

```
전장 크기:
  소규모 전투: 12×12 그리드
  중규모 전투: 18×18 그리드
  대규모 전투 (살수·황산벌): 24×24 그리드

지형 오브젝트:
  강 (River): 도하 시 1턴 소모 + 방어력 -20%
  숲 (Forest): 은신 가능 + 기병 이동 제한
  언덕 (Hill): 원거리 공격 범위 +1칸
  성벽 (Wall): 방어 +60% + 공성 전용 공략
  수문 (Floodgate): 살수대첩 전용 — 조작 가능

시간 압박:
  공격 측: X턴 내 목표 달성 필수
  방어 측: X턴 버티기 = 승리
  살수: 수나라 군이 강 절반 도하 전 수문 개방 필요
```

### 포위 시스템

```
포위 조건: 적 부대 3방향 이상 아군 부대 배치
포위 효과:
  피포위 부대: 사기 -20/턴
  도주 시: 체력 -50% + 전투력 최저
  포위 유지 X턴: 항복 이벤트 발생

포위 돌파:
  지휘관 영웅 유닛 직접 돌파 가능
  비용: 영웅 유닛 체력 -30%
  고루 특수 능력: 포위 돌파 체력 비용 면제
```

## 레이어 3 — 영웅 액션 전투

### 고루 전투 조작

```
기본 공격: 환두대도 강타
  입력: □ (가벼운 타) / △ (강타)
  강타 후: 적 스턴 1초

회피: R1 + 방향키 (구르기)
  고루 특성: 회피 속도 느리나 무적 판정 길이 긺

콤보 체계:
  □□□: 3타 기본 연속
  □□△: 2타 후 강타 피니시
  ←+□: 역방향 후퇴 강타 (을지문덕 전술 재현)
  (아무것도 안 함) 3초: 「기다림」자세 → 적 공격 자동 카운터

스킬:
  L1+□: 「살수 차단」— 적 공격선 차단 + 카운터
  L1+△: 「한 방」— 긴 준비 후 1타 필살 (데미지 300%)
  R2: 「지휘」— 근처 아군 유닛 사기 +20 (전략 맵 연동)
```

### 하린 전투 조작

```
기본 공격: 단검 연속 타격
  입력: □ 연타 (빠른 콤보)
  특성: 1타 데미지 낮음, 연속 타격으로 보완

이동:
  ×: 점프 (장애물 도약)
  ×× : 이단 점프
  □ + × : 점프 공격

콤보 체계:
  □×5: 5타 속공 콤보
  ↑+×+□: 점프 기습 강타
  →→+□: 돌격 타격 (기마 재현)

스킬:
  L1+□: 「화랑 돌격」— 전방 직선 고속 돌진 + 데미지
  L1+△: 「관창의 기억」— 분노 상태 발동 (데미지 +50%, 30초)
  R2: 「임전무퇴」— 30초간 후퇴 불가 + 방어 무시 공격
```

### 아랑 전투 조작

```
전투 불가 캐릭터:
  아랑: 직접 전투 조작 없음
  역할: 서포트·정보 제공

서포트 스킬:
  L1: 「기록의 힘」— 적 정보 공개 (약점·남은 HP 표시)
  L1+□: 「외교 설득」— 적 부대 전투 이탈 확률 30%
  R2: 「연등 신호」— 아군 전체 사기 +15

생존 메커닉:
  아랑 피격 시: 자동 회피 (은신 지형으로 이동)
  아랑 전사 금지: 시나리오 패배 조건
  보호 모드: 근처 영웅이 아랑 공격 자동 차단
```

### 니문 전투 조작

```
전투 불가 캐릭터:
  니문: 아랑과 동일 (직접 전투 없음)

서포트 스킬:
  L1: 「가야금 연주」— 아군 전체 사기 최대치 (10초)
  L1+□: 「676」— 최종 결전 전용 스킬 (사기 MAX + 방어 무적)
  R2: 「기억의 소리」— 전사한 아군 유닛 1회 부활

니문 연주 이벤트:
  특정 전투 전날 밤: 니문 가야금 장면 자동 재생
  사기 +20으로 전투 시작
  살수대첩·황산벌·기벌포 전투 전 필수 이벤트
```

## 난이도 시스템

```
역사 모드 (History Mode):
  역사 결과 고정 (살수 승리·황산벌 패배·기벌포 승리)
  전략 자유도 있으나 결말 변경 불가
  추천: 역사 학습 목적 플레이어

전략 모드 (Strategy Mode):
  역사 변경 가능 (백제 황산벌 승리 등 가능)
  파나믹 이벤트: 역사 변경 시 세계 반응 변화
  엔딩: 역사 선택에 따라 멀티 엔딩

시뮬레이션 모드:
  역사 시뮬레이션 전용 (스토리 없음)
  자유로운 왕국 선택 + 자유 전략

난이도:
  입문 (초등생 대상): 전략 맵 자동 조언
  일반: 표준 게임플레이
  역사가 (전문): 역사 고증 수치 강화, 보급·기후 시스템 활성
```

## 보상 시스템

```
전투 평가:
  S등급: 손실 없이 승리 + 역사 선택
  A등급: 소수 손실 승리
  B등급: 일반 승리
  C등급: 가까스로 승리

등급별 보상:
  S: 전설 아이템 + 히스토리 카드
  A: 희귀 아이템 + 경험치 150%
  B: 일반 아이템 + 경험치 100%
  C: 경험치 70% (아이템 없음)

히스토리 카드 시스템:
  전투 승리 시 역사 인물 카드 수집
  수집 완성 시: 역사 다큐 영상 해금
  을지문덕·계백·선덕여왕·관창 카드 희귀도 최고
```

### 전투 시스템 철학 (상세)

```
핵심 원칙:
  「역사를 체험하는 전략」
  ① 실제 역사 전투 재현 가능
  ② 전략의 다양성 (무력·지략·외교 3원칙)
  ③ 쉬운 진입, 깊은 숙련
  ④ 을지문덕의 「7번 물러서라」전략 = 실제로 유효한 플레이

전투 유형:
  A. 야전(野戰): 평야 전투 — 병력 수·편성이 중요
  B. 공성(攻城): 성 공격·방어 — 지형과 보급이 중요
  C. 수전(水戰): 강·해전 — 기동력과 기상이 중요
  D. 매복(埋伏): 협곡·산지 — 기습과 정보가 중요
```

### 전투 흐름 (턴 기반 전략)

```
1단계 — 전투 시작:
  지형 확인 → 병력 배치 → 진형 선택

2단계 — 명령 입력 (동시 입력):
  각 부대 명령 입력 (이동·공격·방어·후퇴·특수)
  제한 시간: PvP 60초 / PvE 무제한

3단계 — 해결 순서:
  ① 이동 처리 (기동력 순)
  ② 원거리 공격 (弓兵→弩兵→投石)
  ③ 근접 충돌 (騎兵→步兵→)
  ④ 특수 능력 발동
  ⑤ 사기·보급 체크

4단계 — 결과 처리:
  피해 계산 → 사기 변동 → 퇴각 판정 → 다음 턴

승리 조건:
  야전: 적 사령부 괴멸 or 적 병력 50% 이하 + 사기 붕괴
  공성(공격): 성문 돌파 or 성주 포획
  공성(방어): 10턴 버티기 or 적 보급 차단
  수전: 기함 격파 or 수로 장악
```

### 병종 시스템 (상세)

#### 기본 병종 6종

```
① 보병(步兵) — 기본 전투력
  공격: 중간 / 방어: 높음 / 기동: 낮음
  특기: 진형 유지 (대열 깨지지 않음 +20%)
  반격: 기병 돌격 시 장창(長槍) 모드 전환 가능

② 기병(騎兵) — 돌격과 기동
  공격: 높음 / 방어: 낮음 / 기동: 매우 높음
  특기: 돌격 (첫 충돌 +50% 공격)
  고구려 특화: 중장기병(重裝騎兵) = 방어도 높음

③ 궁병(弓兵) — 원거리 공격
  사거리: 3칸
  특기: 집중사(集中射) — 한 부대에 3배 피해 (쿨다운 3턴)

④ 노병(弩兵) — 강력한 원거리 (백제 특화)
  사거리: 5칸
  특기: 관통(貫通) — 방어 무시 30%

⑤ 공성병(攻城兵) — 성 공격 전문
  특기: 성벽 파괴, 성문 공격
  방어 전환: 역으로 성벽 위에서 투석 가능

⑥ 척후병(斥候兵) — 정찰·기습
  기동: 최고
  특기: 매복 설치, 봉화 방해, 적 정보 수집
  고구려 특화: 스텔스 이동
```

#### 특수 병종 (왕국별)

```
고구려 전용:
  - 개마무사(鎧馬武士): 중장기병 최강 변형
    스킬: 「철갑 돌격」— 전방 3칸 관통 이동 + 공격
  - 성곽부대(城郭部隊): 성벽 방어 특화 (+100% 방어)

백제 전용:
  - 수군(水軍): 강·해전 특화
    스킬: 「화공(火攻)」— 강에서 불화살 투하
  - 기록대(記錄隊): 아랑 스토리 연동

### 보급 & 사기 시스템

```

  원정 거리 ↑ → 보급 소모 ↑
  보급 0% → 전투력 50% 감소 → 자연 붕괴

  적 장수에게 서신 보내기 (을지문덕 한시 연동)
