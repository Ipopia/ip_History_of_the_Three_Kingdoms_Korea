# 삼국시대 의학과 치료

## 의료 체계 개요

삼국시대 의료는 **전통 본초 의학 + 무속 치료 + 불교 의료**가 공존하는 복합 체계였다. 국가 차원의 의관(醫官) 제도와 민간 치유 문화가 병행했다.

---

## 의학 지식 체계

### 중국 의학의 수용

**황제내경(黃帝內經)**
- 음양오행론 기반 의학 이론
- 기(氣)·혈(血)·경락(經絡) 개념
- 삼국 모두 수용 — 의관 교육 텍스트

**신농본초경(神農本草經)**
- 약재 분류 체계 — 상·중·하 품 365종
- 한반도 자생 약재 추가 적용

**상한론(傷寒論)**
- 열병·감염성 질환 처방
- 전쟁터 역병 치료에 핵심 텍스트

### 한반도 독자 의학

**향약(鄕藥)**
- 중국 약재 대신 국내 자생 약초 활용
- 삼국~통일신라 시대 향약 체계 형성
- 대표 향약재: 인삼·쑥·창포·당귀·천궁

**인삼(人蔘)**
- 고구려·신라 특산 — 대중국 수출 최고 교역품
- 원기 회복·강장 효과 — 귀족·왕실 전용
- 전쟁 후 피로 회복·부상 치료 보조

## 의료 전문직

### 국가 의관(醫官) 제도

| 왕국 | 제도 | 역할 |
|------|------|------|
| 고구려 | 의박사(醫博士) | 왕실·귀족 전담 |
| 백제 | 의박사(醫博士) | 일본에 파견 — 의학 수출 |
| 신라 | 의학(醫學) | 국학 내 의학 교육 과정 운영 |

**백제 의박사의 일본 파견**
- 덕솔 왕유능타(王有陵陀) 등 일본 파견
- 일본 고대 의학 체계 형성에 결정적 기여
- 침구술·약재 지식 동반 전파

### 민간 의원

- 약사(藥師): 약재 판매 + 처방
- 침사(針師): 침술 전문가
- 산파(産婆): 출산 전담 여성 의료인
- 고승(高僧): 불교 승려 — 의료 겸업 다수

## 치료 방법

### 본초 약물 치료

**내복약**
- 탕약(湯藥): 약재 달인 물 복용 — 기본 치료법
- 환약(丸藥): 분말 압축 — 휴대 가능, 전쟁터 보급
- 산약(散藥): 가루 형태 — 외상 소독에도 활용

**외용약**
- 고약(膏藥): 상처 부위 도포
- 침수(浸水): 약초 물에 환부 담금
- 훈증(燻蒸): 약초 연기 흡입 — 호흡기 치료

**주요 처방 약재**
| 증상 | 약재 |
|------|------|
| 해열 | 황금(黃芩)·시호(柴胡) |
| 지혈 | 쑥(艾葉)·지황(地黃) |
| 소독 | 창포(菖蒲)·황련(黃連) |
| 강장 | 인삼(人蔘)·황기(黃芪) |
| 통증 | 오두(烏頭, 독성 주의)·천궁(川芎) |
| 설사 | 황련(黃連)·복령(茯苓) |

### 침구(鍼灸) 치료

**침술(鍼術)**
- 경락(經絡) 12개 노선의 경혈(經穴) 자침
- 금침(金針)·은침(銀針): 왕실용
- 철침(鐵針): 일반용
- 전쟁 부상자 통증 완화에 실전 적용

**뜸(灸)**
- 쑥을 태워 경혈 가열 자극
- 관절·냉증·소화기 질환 치료
- 전쟁터에서도 간편 적용 가능

### 외과적 처치

**전상(戰傷) 응급 처치**
- 지혈: 쑥잎 압박 + 고약 도포
- 화살 제거: 역갈고리 화살촉은 절개 후 제거
- 골절 부목(副木): 대나무·나무 고정

**절개 수술**
- 고름 제거: 종기·농양 절개
- 제한적 수준 — 마취 기술 부재로 대수술 불가

**마취 대용**
- 술(酒): 통증 감각 둔화 목적
- 독초 혼합 환약: 일부 마취 효과 (위험 동반)

## 무속 치료 (巫俗醫療)

### 무당(巫堂)의 의료 역할

삼국시대 민중의 제1 의료 창구는 무당이었다.

**치료 절차**
1. 병인 진단: 귀신·악령·조상 노여움으로 규정
2. 굿(巫祭): 정화 의례로 귀신 퇴치
3. 약초 처방: 무당이 동시에 약초 지식 보유
4. 주술 부적: 회복 촉진 상징 의례

**역병(疫病) 대처**
- 마을 단위 동제(洞祭) — 집단 정화 의례
- 환자 격리: 귀신 전파 개념으로 격리 실시 → 효과적 방역

### 전쟁과 무속 의료

- 출전 전 무당의 정화 의례 필수
- 부상병 치료에 무당+의관 협력
- 전사자 영혼 달래는 진혼굿

## 불교 의료

### 사원의 의료 기능

**자비 의료**
- 병원 기능 겸비한 사원
- 기근·전쟁 후 민중 구제소 역할
- 승려가 약초 재배 + 치료

**불교 의학 경전**
- 《불설의경(佛說醫經)》 등 수입
- 인도 아유르베다 의학 지식 일부 유입

**승의(僧醫)**
- 고승이 의술 겸비한 경우 다수
- 의덕(義德)·혜자(慧慈) 등 고구려 승려 — 의술로 명성

## 전장 의료 (Military Medicine)

### 전투 전 준비

- 의관(醫官) 종군: 대규모 전투에 의관 동행
- 약재 보급: 지혈약·고약·붕대 역할 마(麻) 천
- 들것(擔架): 부상병 후송 수단

### 전투 중 응급

- 화살 상처: 지혈 → 화살 제거 → 봉합
- 칼상처: 지혈 고약 + 쑥 압박
- 골절: 부목 고정 후 후방 이송

### 주요 전투병 사망 원인

1. 직접 전상 (45%)
2. 감염·패혈증 (30%)
3. 역병·이질 (20%)
4. 기아·탈수 (5%)

**역병의 공포**
- 대규모 군 집결 = 역병 창궐 위험
- 고구려 vs. 수나라 전쟁: 수군 역병 사망자가 전사자보다 多
- 군 의관의 최우선 임무: 역병 차단

## IP 활용 포인트

| 의료 요소 | 스토리 활용 |
|-----------|-----------|
| 전장 의관 | 후방에서 부상병을 돌보는 여성 의관 캐릭터 |
| 무당 치료 | 과학(의학) vs. 무속 — 왕의 병을 두고 벌어지는 논쟁 |
| 역병 공포 | 군 내 역병 창궐 → 전략적 철수 결정의 드라마 |
| 인삼 교역 | 인삼 밀수로 생계 잇는 고구려 상인 캐릭터 |
| 승의(僧醫) | 전쟁 반대하는 승려가 양측 부상병 모두 치료하는 휴머니즘 |
| 화살 제거 | 마취 없이 진행되는 생생한 전장 의료 장면 |
