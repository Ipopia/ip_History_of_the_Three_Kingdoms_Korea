## VFX 철학

```
핵심 원칙:
  「VFX는 보이지 않을 때 성공한다」
  실사와 CG의 경계 = 관객이 인식 불가 목표

삼국 IP VFX 특성:
  역사 재현: 사라진 도성·성곽·전장 복원
  자연 현상: 살수 수공·황산벌 먼지·화공
  군중 확장: 소수 엑스트라 → 대규모 군대
  신화적 요소: 삼족오·봉황 등 상징 이미지

금지 VFX:
  SF·판타지 이펙트 (폭발·빛기둥·마법 등)
  물리 법칙 무시 (현실적 범위 내)
  시대착오 기술 표현
  과도한 CG 티나는 장면 (uncanny valley)
```

## 주요 VFX 카테고리

### 카테고리 1: 도성 복원 VFX

```
평양성 풀샷:
  기법: 실사 촬영분 + CG 도성 합성
  규모: 4중 성곽 + 대동강 반영 전체 조감
  레이어:
    L1: 실사 전경 (배우·세트)
    L2: CG 중경 (민가·시장)
    L3: CG 원경 (성벽·왕궁 스카이라인)
    L4: CG 하늘 + 구름
  퀄리티 기준: 항공 사진 수준 사실감

사비성 복원:
  기법: 부여 실제 지형 + CG 건물 합성
  특징: 미래사 9층 목탑 랜드마크 (CG)
  조명: 황금빛 낮 + 횃불 야경 2종

경주 왕경 복원:
  기법: 경주 평야 드론 촬영 + CG 합성
  황룡사 9층 목탑: 전체 CG (실물 없음)
  첨성대: 실물 존재 — 배경만 CG 확장
```

### 카테고리 2: 전투 군중 VFX

```
군중 시뮬레이션 (매스 시뮬레이션):
  소프트웨어: Golaem or Massive (군중 에이전트)
  단위: 1,000명 → 10만명 확장
  행동 AI: 전진·후퇴·전투·낙마 등 행동 패턴

고구려 군사:
  디지털 더블: 철갑 고구려 병사 기본 3종
  색상: 군청·철흑 조합
  행동: 방어 진형·매복·기마 돌격

수나라 군사 (적):
  디지털 더블: 중국식 철갑 병사 기본 4종
  색상: 붉은 병사 표식 (적군 구별)
  규모: 살수대첩 장면 최대 10만 표현

황산벌 군중:
  신라군: 금빛 화랑 + 일반 병사 혼합
  백제군: 황금·백색 500결사대 (소규모 강조)
  연출: 백제 결사대 소규모 vs 신라 대군 대비

LOD (Level of Detail) 기준:
  원경 (50m+): 저폴리 실루엣
  중경 (20~50m): 중폴리 + 기본 텍스처
  근경 (20m 이내): 고폴리 + 전체 텍스처
```

### 카테고리 3: 자연 현상 VFX

```
살수 수공:
  물 시뮬레이션: Houdini FLIP Solver
  규모: 강폭 200m 전체 유체
  타임라인:
    0~2초: 댐 수문 열림
    2~5초: 물 방류 시작 (급속 유속 증가)
    5~15초: 전면 홍수 (최고 볼륨)
  물 특성: 탁류 (모래·진흙 혼합) — 맑은 물 아님

황산벌 먼지:
  기법: 파티클 시뮬레이션 (먼지·흙)
  트리거: 기마 돌격 → 먼지 구름 상승
  색상: 황토 #C8A96E 황색 먼지
  규모: 지평선까지 펼쳐지는 먼지

백강 화공:
  기법: 연소 시뮬레이션 (Houdini Pyro)
  선박 화재: 목재 선박 연소 (오렌지·검정 연기)
  수면 반영: 화염이 수면에 반영

낙화암 꽃잎:
  기법: 파티클 + 크로스 시뮬레이션
  꽃잎: 흰 꽃잎 (간접 표현)
  물리: 바람에 흩날려 강물로 떨어짐
  금지: 낙화 직접 묘사 아닌 꽃잎만
```

### 카테고리 4: 신화·상징 VFX

```
삼족오 (고구려 상징):
  등장: 고루 시점 + 고구려 정체성 장면
  형태: 세 발 까마귀 — 해 안에 존재
  VFX: 빛나는 실루엣 + 날갯짓 파티클
  색: 군청 #2F4F7F + 금빛 #8B7355 윤곽
  빈도: 과도 사용 금지 — 클라이맥스 한정

봉황 (백제 상징):
  등장: 금동대향로 관련 장면 + 아랑 감성 절정
  형태: 봉황 이미지 — 꼬리 깃털 화려
  VFX: 황금빛 연기·꽃잎 변환 표현
  색: 황금 #B8960C + 주홍 #CC4E00
  실체 없음 — 아랑의 상상·감성 표현

가야금 소리 시각화 (가야 특유):
  등장: 니문 연주 장면
  형태: 소리 파동이 황토빛 물결로 시각화
  색: 황토 #C8A96E 반투명 파동
  물리: 가야금 현 진동 → 공기 파동 확산
  배경: 물 위·강가에서 특히 효과적
```

## VFX 품질 기준

```
최종 납품 해상도:
  드라마 방송: 1920×1080 25fps
  OTT 4K: 3840×2160 25fps
  VFX 마스터: 4096×2304 (DCI 4K)

렌더링 기준:
  광원: HDRI 기반 물리 기반 렌더링 (PBR)
  그림자: 레이트레이싱 소프트 섀도우
  반사: 물리 기반 반사 (메탈·물·유리)

합성 품질 기준:
  엣지 매팅: 머리카락·갑옷 가장자리 정밀
  색 매칭: 실사 촬영분 ±2% 이내
  그레인 매칭: 실사 필름 그레인 CG에 적용

VFX 검수 프로세스:
  1차: VFX 수퍼바이저 내부 검수
  2차: ART-DIR 비주얼 스타일 검수
  3차: FILM-DIR 연출 의도 검수
  최종: CEO 주요 장면 승인 (살수·낙화암·기벌포)
```

## 애니메이션 VFX 스타일

```
2D 애니 이펙트:
  불: 손으로 그린 느낌 (Kyoto Animation 참고)
  물: 유동적 라인 + 반투명 레이어
  먼지: 도트 파티클 + 선묘 혼합

특수 이펙트:
  가야금 소리: 음표 파티클 + 황토 물결
  삼족오 등장: 빛 섬광 + 깃털 파티클
  살수 수공 (애니): 2D 유체 + 속도선 강조

애니 VFX 금지:
  DBZ식 에너지 폭발 이펙트
  현대 게임 스킬 이펙트 스타일
  네온·홀로그램 이펙트
```
