# 액션 & 스토리보드 가이드

## 액션 연출 철학

> "삼국시대의 전투는 와이어 액션이 아니다. 흙먼지와 피로, 두려움과 결의가 뒤섞인 인간의 폭력이다."

**핵심 원칙**
- 역사적 전투 방식 기반 — 실제 삼국시대 전술·무기·대형
- 영웅적 묘사와 현실적 묘사의 균형
- 개인 전투 + 집단 전술의 교차
- 전투 전·중·후 감정 흐름 설계

**금지 연출**
- 중국 무협식 경공·와이어 점프 액션
- 일본 사무라이 영화식 정제된 검술 대결
- 할리우드식 개인 영웅의 수백 명 제압

## 개인 전투 안무

### 삼국시대 실전 전투 기반

**근접 전투 원칙**
```
현실 기반:
- 무기: 검·창·도끼 — 방패 조합이 기본
- 자세: 낮고 안정적 — 낭창거리지 않음
- 움직임: 빠르고 짧은 — 에너지 낭비 없음
- 결정타: 한 번 — 계속되는 화려한 공방 금지

심리 표현:
- 전투 전: 呼吸 — 두려움 숨기기
- 전투 중: 본능 — 생각 없는 반응
- 전투 후: 震顫 — 흥분+공포의 잔재
```

**환두대도(環頭大刀) 전투**
| 동작 | 설명 | 연출 포인트 |
|------|------|-----------|
| 베기 | 어깨에서 대각선 — 강하고 단순 | 갑옷 관통 여부에 따라 달라짐 |
| 찌르기 | 갑옷 틈 겨냥 | 정밀함 — 전문 전사만 |
| 방어 | 방패 우선, 검은 보조 | 검으로 검 받기는 최후수단 |
| 이동 | 옆으로 — 정면 돌진 금지 | 전술적 이동 |

**창(槍) 전투**
| 동작 | 설명 | 연출 포인트 |
|------|------|-----------|
| 찌르기 | 2~3m 자루 활용 | 사거리 — 검보다 유리 |
| 쓸기 | 낮게 쓸어 발 노리기 | 말과 인간 동시 위협 |
| 버티기 | 함께 밀어붙이는 진형 | 개인이 아닌 집단 동작 |

### 주요 캐릭터 전투 스타일

**을지문덕 — 전략가형**
```
특성: 본인 전투보다 지휘 중심
드문 직접 전투 시: 냉정하고 효율적
- 관찰 → 약점 파악 → 단 한 번의 결정타
- 화려한 무술 없음 — 경험과 판단력
카메라: 클로즈업 눈빛 + 원거리 결과 교차
```

**계백 — 맹장형**
```
특성: 정면 돌파, 압도적 체력
- 방패 없이 쌍수도 선택 가능
- 부상 입어도 멈추지 않음
- 황산벌: 4번 충돌 후 4번 후퇴 신라군 → 5번째 무너짐
카메라: 와이드로 압도감 → 점점 클로즈업 → 마지막 피로감
```

**김유신 — 화랑형**
```
특성: 체계적 훈련, 장기 지구전
- 화랑 훈련 기반 — 정제된 기본기
- 말 위에서의 궁술+검술
- 전장 전체를 보는 위치 선호
카메라: 말 위 이동 시 트래킹 롱숏
```

**연개소문 — 다검형**
```
특성: 5자루 칼 — 상황별 선택
- 좌우 허리칼: 근거리 기습
- 등 칼: 접근전 반격
- 압도적 위협감이 전투력
카메라: 칼 꺼내는 손 클로즈업 → 상대 반응 클로즈업
```

## 집단 전투 연출

### 삼국 전술 기반 대형 전투

**고구려 기병 충격 전술**
```
구성: 중장기병(철갑)+경기병 혼합
연출 단계:
1. 집결: 말 발굽 소리 — 카메라는 땅 진동 표현
2. 가속: 점차 빠른 커팅 — 긴장감 구축
3. 충격: 슬로우 모션 순간 + 폭발적 사운드
4. 혼전: 빠른 커팅 — 전장의 혼돈
5. 돌파: 원샷 — 진형 뚫리는 순간

카메라: 측면 트래킹 → 정면 충돌 → 위에서 내려다보기
```

**백제 방진(防陣) 전술**
```
구성: 방패병 전면 + 창병 후면 + 궁수 후방
연출 단계:
1. 포진: 질서 있는 대형 — 백제의 군사력 시각화
2. 진격: 보조 맞춘 이동 — 북소리 리듬
3. 충돌: 방패 충격 — 물리적 밀어붙임
4. 내부 전투: 진형 붕괴 후 혼전
```

**신라 화랑 선봉대**
```
특성: 화랑 소규모 정예 + 대규모 군 조합
연출: 화랑 5~10명 선봉 → 뒤따르는 대군
- 화랑: 말 위 돌격 — 용기의 상징
- 관창 장면: 단독 돌격 → 포획 → 재돌격
```

## 카메라 연출 원칙

### 액션 장면별 카메라 가이드

| 장면 유형 | 카메라 | 이유 |
|----------|--------|------|
| 개인 결투 | 핸드헬드+클로즈업 | 긴장·현장감 |
| 기병 돌격 | 측면 트래킹 | 속도감·규모 |
| 성벽 전투 | 수직 앵글 교차 | 상하 공간 활용 |
| 왕 전략 회의 | 고정+천천히 줌인 | 권위·무게감 |
| 비극 절정 | 슬로우 클로즈업 | 감정 집중 |
| 전장 전체 | 익스트림 와이드 | 스케일 강조 |

### 편집 리듬 원칙

```
전투 전: 긴 숏 → 긴장 구축
전투 시작: 점차 빠른 커팅
전투 절정: 최고속 커팅 (2초 이내 숏)
전투 결말: 갑작스러운 긴 숏 → 침묵
감정 장면: 시퀀스 내 가장 긴 숏
```
