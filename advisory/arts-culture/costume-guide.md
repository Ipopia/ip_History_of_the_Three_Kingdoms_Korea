# 복식 고증 가이드 | Costume Reference Guide

> **문서 분류**: 예술/문화사 자문 — 복식
> **작성**: CREATE-ADV-ARTS (예술/문화사 자문위원)
> **대상 시대**: 삼국시대 (기원전 1세기 ~ 668년)

---

## 1. 삼국 공통 기본 구조

### 1-1. 기본 복식 체계
삼국시대 복식은 **북방 호복(胡服) 계통**으로, 유목민족의 기마 생활에 적합한 구조를 기본으로 한다.

- **유(襦, Jeogori)**: 저고리 — 상의. 좌임(左衽, 왼쪽 여밈)에서 우임(右衽, 오른쪽 여밈)으로 변화
- **고(袴, Baji)**: 바지 — 통이 좁은 형태(세고/細袴)가 기본
- **상(裳, Chima)**: 치마 — 주로 여성용, 주름치마
- **포(袍, Po)**: 겉옷/두루마기형 긴 옷
- **대(帶,띠)**: 허리띠, 신분 표시 기능
- **이(履, 신발)**: 화(靴, 목이 긴 신), 혜(鞋, 목이 짧은 신)

### 1-2. 소재
- **삼베(麻布)**: 서민층 기본 소재
- **명주(絹, 비단)**: 상류층 소재
- **모직(毛織)**: 방한용, 북방 교역품
- **가죽(皮革)**: 군복, 신발, 갑옷
- **모피(毛皮)**: 방한용, 고급품
- **금속(金屬)**: 장식, 관모, 대대(帶)

## 2. 고구려 복식 (Goguryeo Costume)

### 2-1. 사료 근거
**고분벽화**가 가장 중요한 1차 사료. 무용총, 쌍영총, 안악3호분, 수산리 고분 등에서 다양한 계층의 복식 확인 가능.

### 2-2. 남성 복식

#### 왕·귀족
- **관모**:
  - **절풍(折風, Jeolpung)**: 고깔형 관모, 고구려 남성의 대표 관모
  - **조우관(鳥羽冠, Jo-u-gwan)**: 절풍에 새 깃털 장식 — 신분이 높을수록 화려
  - **책(幘)**: 두건형 관모, 중국 영향
- **저고리**: 둥근깃(圓領) 또는 곧은깃(直領), 좌임→우임
  - 소매폭이 비교적 좁음
  - 선(緣, 가장자리 장식띠) — 깃, 소맷부리, 도련에 색 대비 선 장식
- **바지**: 통이 좁은 세고(細袴), 발목에서 묶음
- **대(帶)**: 가죽 또는 천 허리띠, 금은 장식 과대(銙帶)
- **포(袍)**: 의례용 긴 겉옷, 무릎~발목 길이
- **신발**: 목이 긴 화(靴)

#### 서민·농민
- 짧은 저고리 + 바지
- 삼베 소재, 장식 최소화
- 머리에 건(巾, 두건) 착용

### 2-3. 여성 복식
- **저고리**: 엉덩이까지 내려오는 긴 저고리
  - 깃, 소맷부리, 도련에 색선(色線) 장식
- **치마**: 주름치마, 발목까지 내려오는 길이
  - 벽화에서 다양한 색상 확인 (황, 청, 적, 녹)
- **포(袍)**: 겉에 걸치는 긴 옷 — 귀족 여성
- **머리**: 얹은머리(높이 올려 쪽찜), 비녀 사용

### 2-4. 무관·군복
- **찰갑(札甲, Lamellar Armor)**: 작은 철편을 끈으로 엮은 갑옷
  - 고구려 갑옷의 주류, 기마전에 적합
  - 인갑(鱗甲, 비늘갑옷) 형태도 존재
- **투구(冑, 兜鉢)**: 철제, 차양 달린 형태
  - 삼실총, 쌍영총 벽화에서 확인
- **개마무사(鎧馬武士, Armored Cavalry)**: 말에도 마갑(馬甲) 장착
  - 고구려 중장기병의 상징
  - 안악3호분 행렬도에서 확인
- **무기 패용**: 환두대도(環頭大刀), 활·화살통

### 2-5. 색상 체계
| 신분 | 색상 |
|------|------|
| 왕 | 황(黃)·백(白) |
| 고위 귀족 | 자(紫, 자주)·청(靑) |
| 귀족 | 적(赤)·비(緋) |
| 일반 | 무문(無紋) 자연색 |

- 고구려인은 **흰옷(白衣)**을 즐겨 입었다는 기록(《수서》, 《북사》)

## 3. 백제 복식 (Baekje Costume)

### 3-1. 사료 근거
- 무령왕릉 출토 유물 (금제관식, 장신구)
- 《주서(周書)》, 《수서(隋書)》 등 중국 사서 기록
- 능산리·송산리 고분 출토품

### 3-2. 총론
백제 복식은 고구려 복식의 기본 구조를 공유하면서도 **중국 남조(南朝)의 영향**을 강하게 받아 보다 세련되고 유연한 스타일을 보인다. 직물 기술이 뛰어나 **고급 비단** 생산에 능했다.

### 3-3. 관모 체계 — 관등별 색 구분
백제는 **16관등제(十六官等制)**에 따라 관모(冠帽)의 색을 엄격히 구분했다.

| 관등 | 관모 색 | 해당 관직 |
|------|---------|----------|
| 1~6품 | **은화(銀花) 장식** | 좌평(佐平) 등 |
| 7~11품 | **자(紫, 자주)** | — |
| 12~16품 | **비(緋, 붉은색)** | — |

- 관모 형태: 고깔형 관(冠) 또는 건(巾)
- **금제관식(金製冠飾)**: 무령왕릉 출토, 꽃과 불꽃 형태의 금 장식
  - 왕의 위엄을 상징, 인동문(忍冬紋)·연화문(蓮花紋) 모티프

### 3-4. 남성 복식
- 기본 구조는 고구려와 유사 (저고리+바지)
- 귀족: 넓은 소매의 포(袍) 착용, 중국 남조풍
- 관인(官人): 관복 제도 정비 — 색상으로 품계 구분
- **금은 장식 활용**: 금제 귀걸이, 금동 신발, 옥(玉) 패용

### 3-5. 여성 복식
- 저고리 + 주름치마 기본
- 고구려보다 소매가 넓고 치마 실루엣이 부드러움
- 장신구: 금·은 귀걸이(수하식 귀걸이/垂下飾), 목걸이, 팔찌

### 3-6. 군복·갑옷
- 고구려와 유사한 찰갑(札甲) 사용
- 단갑(短甲, 판갑/板甲) 형태도 출토 — 가야 영향
- 횡렬판갑(橫列板甲) 계통
- 투구: 종장판주(縱長板冑) 형태

### 3-7. 백제 복식 특징
> 고구려의 북방 기마 전통 + 중국 남조의 세련미 = **"우아한 절충"**

## 4. 신라 복식 (Silla Costume)

### 4-1. 사료 근거
- 고분 출토 금속 장신구(금관, 금귀걸이, 금허리띠)
- 토우(土偶) — 토기 위의 인물상
- 《삼국사기》 색복조(色服條) 기록
- 경주 용강동 고분 출토 직물편

### 4-2. 골품제와 복식 규제 (Bone-rank & Dress Code)
신라의 복식은 **골품제(骨品制)**에 의해 엄격히 규제되었다. 《삼국사기》 색복조에 상세히 기록됨.

| 골품 | 사용 가능 소재·색상·장식 |
|------|------------------------|
| **성골(聖骨)** | 제한 없음 — 금관, 최고급 비단 |
| **진골(眞骨)** | 금·은·비단·자색(紫色) 사용 가능 |
| **6두품** | 비단 일부, 자색 불가 |
| **5두품** | 비단 제한, 비색(緋色)까지 |
| **4두품** | 비단 불가, 청색(靑色)까지 |
| **평민** | 삼베·무문 |

- 차·관·의·대·이·기거(車·冠·衣·帶·履·器居) 전반에 걸친 규제
- 법흥왕 대(520년) 공복(公服) 제정, 진덕여왕 대(649년) 당나라식 관복 도입

### 4-3. 금속 장신구 — 신라의 특징적 표현
- **금관(金冠, Gold Crown)**:
  - 출자형(出字形) + 녹각형(鹿角形) 세움 장식
  - 곡옥(曲玉, 굽은옥)과 금판 달개 장식 부착
  - **유라시아 초원 양식(Steppe Style)**과의 연관성 논의
  - 대표: 금관총 금관, 서봉총 금관, 천마총 금관, 황남대총 금관
- **금귀걸이(金製耳飾)**: 태환식(太環式) + 세환식(細環式)
  - 정교한 수하식(垂下飾) — 누금세공(鍊金細工/Filigree) 기법
- **금허리띠(金製過帶)**: 과판(銙板)에 여러 가닥의 수하식 부착
  - 장식 기능 > 실용 기능 — 의례용으로 추정
- **유리구슬(琉璃玉)**: 로만 글라스 등 서역 교역 흔적

### 4-4. 남성 복식
- 기본 구조: 저고리+바지 (삼국 공통)
- 관모: 골품에 따른 규제
- 포(袍): 당 관복 도입 이후 변화 뚜렷
- 토우에서 확인되는 일상복: 짧은 저고리+바지, 허리띠

### 4-5. 여성 복식
- 저고리 + 치마 기본
- 토우 자료에서 다양한 치마 형태 확인
- 장신구: 금귀걸이, 목걸이(경식/頸飾), 팔찌(천/釧)
- 머리: 얹은머리, 비녀

### 4-6. 군복·갑옷
- **판갑(板甲)**: 큰 철판을 연결 — 신라·가야 공통
  - 종장판갑(縱長板甲): 세로 방향 긴 철판
  - 횡장판갑(橫長板甲): 가로 방향 긴 철판
- **찰갑(札甲)**: 고구려 영향으로 후기에 증가
- **투구**: 종장판주(縱長板冑), 소찰주(小札冑)
- **마갑·마주(馬甲·馬冑)**: 가야·신라 공통 출토

## 5. 갑옷 비교 — 삼국+가야

| 항목 | 고구려 | 백제 | 신라 | 가야 |
|------|--------|------|------|------|
| **주력 갑옷** | 찰갑(札甲) | 찰갑+판갑 혼용 | 판갑(板甲) → 찰갑 | 판갑(板甲) |
| **특징** | 기마전 최적화 | 절충적 | 보병 중심→변화 | 철의 왕국 |
| **마갑** | 개마무사(O) | 일부 확인 | 일부 확인 | 출토 다수 |
| **투구** | 차양 달린 형태 | 종장판주 | 종장판주 | 종장판주 |
| **시대 변화** | 비교적 일관 | 고구려→독자 | 가야→고구려 영향 | 판갑 특화 |

## 6. 소재 상세

| 소재 | 용도 | 계층 | 비고 |
|------|------|------|------|
| **삼베(麻)** | 일상복 전반 | 서민~귀족 | 가장 보편적 소재 |
| **모시(苧麻)** | 여름 의복 | 중류 이상 | 한산모시 전통의 원류 |
| **명주(絹)** | 예복·관복 | 귀족 | 뽕나무 재배 기반 |
| **능(綾)** | 고급 의복 | 상위 귀족 | 문양 직조된 비단 |
| **라(羅)** | 여름 고급복 | 상위 귀족 | 얇은 비단 |
| **금(錦)** | 최고급 의복 | 왕족·최상위 | 다색 문양 비단 |
| **모직(毛)** | 방한복 | 북방 교역품 | 고구려에서 특히 활용 |
| **가죽(革)** | 군복·신발·갑옷 | 전 계층 | 사슴·소·말 가죽 |

## 7. 작품 적용 시 유의사항

1. **시기 특정**: 삼국시대 전기(1~4세기)와 후기(5~7세기)의 복식은 상당히 다르다. 작품 내 시점을 먼저 확정할 것
2. **골품제 반영**: 신라 캐릭터는 골품에 따른 복식 규제를 반드시 적용
3. **색상 상징**: 각 나라의 신분별 색상 체계를 캐릭터 디자인에 활용
4. **장식 차이**: 고구려(깃털·모피), 백제(금은 세공), 신라(금관·곡옥)로 차별화
5. **일상 vs 의례**: 평상복과 의례복의 차이를 명확히 구분
6. **기후 반영**: 고구려(북방, 방한 강조), 백제·신라(중남부, 계절별 변화)
7. **전투복**: 개마무사(고구려), 판갑 보병(신라·가야), 혼합(백제)로 차별화
