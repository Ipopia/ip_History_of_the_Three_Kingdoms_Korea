## 게임 컨셉

### 핵심 판타지 (Core Fantasy)

> "나는 고구려의 왕이다. 나의 결정 하나가 수만 명의 운명을 바꾼다."

플레이어는 삼국 중 하나를 선택해 건국부터 통일까지의 역사를 경험한다. 역사적 결과는 바꿀 수 없다 — 그러나 **그 과정**은 플레이어가 만든다.

### 3대 핵심 기둥

1. **역사 고증**: 실제 삼국사기 기반 — 역사를 배우며 즐기는 경험
2. **전략 깊이**: 외교·경제·군사·문화의 4축 통합 운영
3. **서사 몰입**: 역사 인물들과의 관계가 게임 결과에 영향


### 왕국 선택 시스템

플레이어는 게임 시작 시 왕국과 시대를 선택:

| 왕국 | 시작 시대 | 난이도 | 특기 |
|------|---------|--------|------|
| 고구려 | BC 37년 (건국) | 중 | 기병·정복 |
| 백제 | BC 18년 (건국) | 하 | 외교·교역 |
| 신라 | BC 57년 (건국) | 상 | 생존·동맹 |
| 가야 | AD 42년 (건국) | 최상 | 철·교역 (약소국) |

**가야 난이도 설명**: 역사적으로 562년 멸망 — "살아남기" 자체가 목표. 가야가 멸망을 막으면 히든 엔딩.

---

### 4대 자원 시스템

| 자원 | 획득 방법 | 용도 |
|------|---------|------|
| 양식(糧食) | 농지 개간·조세 | 군대 유지·민심 |
| 철(鐵) | 가야 교역·광산 | 무기·갑옷 제작 |
| 비단(絹) | 수공업·외교 선물 | 외교·무역 |
| 인삼(人蔘) | 북방 채취·교역 | 교역 고가 물자 |

**가야 철 독점**: 초기에는 가야만 철 생산 → 삼국이 가야를 통해 철 구매 → 가야 병합 후 각국 직접 생산

---

### 외교 시스템

**관계 단계**
```
적대(-100) → 경계(-50) → 중립(0) → 우호(+50) → 동맹(+100) → 혼인동맹(+150)
```

**동맹 이벤트 예시**
- 나제동맹(433년): 신라-백제 자동 이벤트 발생
  - 플레이어 선택: 동맹 수락 / 거부 / 조건 협상
  - 역사적 선택(수락): 고구려 압박 완화, 그러나 553년 배신 이벤트 예고

**외교 배신 시스템**
- 553년 신라의 백제 한강 점령: 역사적 사건
- 플레이어(신라)가 선택: 역사대로 배신 / 동맹 유지 (비역사 분기)
- 비역사 선택: 단기 손해, 장기 관계 이득 — 다른 엔딩 경로

---

### 전투 시스템

#### 전략 지도 전투 (매크로)

```
턴 기반 전략 맵:
- 육각형 타일 기반 이동
- 지형 효과: 산악(수비+3), 강(이동-2, 방어선)
- 성(城) 공성: 3턴 포위 → 공성 전투
- 보급선: 거리 멀수록 군 효율 저하
```

#### 핵심 전투 (마이크로)

```
실시간 전술 전투 (선택 시):
- 유닛 유형: 기병(속도)·보병(방어)·궁수(원거리)·공성(특수)
- 대형(陣形): 어린진·방진·학익진·어부진 등 삼국시대 기록 기반
- 지형 활용: 강 이용 수비, 산악 매복 등
```

#### 왕국별 특수 유닛

| 왕국 | 특수 유닛 | 능력 |
|------|---------|------|
| 고구려 | 철기(鐵騎) — 중장기병 | 충격 공격 +50%, 평지 최강 |
| 백제 | 수군(水軍) | 해상·강 전투 최강 |
| 신라 | 화랑(花郞) — 정예 | 사기 +30%, 전투 지속력 |
| 가야 | 철공(鐵工) — 장인병 | 무기 자체 제작, 공성 +40% |

### 역사 인물 시스템

**영웅 카드 방식**
- 역사 인물을 카드로 획득 → 군사·내정·외교 배치
- 인물별 고유 능력치 + 특성

**주요 인물 카드 예시**

```
[을지문덕 카드]
역할: 군사 참모
희귀도: 전설
능력:
- 수성(守城) +50%: 방어전 보너스
- 살수 전략(패시브): 물 지형 전투에서 적 이동 제한
- 지략(知略): 첩보 성공률 +30%
특수 이벤트: 612년 살수대첩 이벤트 활성화 가능

[선덕여왕 카드]
역할: 군주 (신라 전용)
희귀도: 전설
능력:
- 3대 예언: 매 시즌 시작 시 무작위 이벤트 예측
- 황룡사탑 건립 가속 (-2턴)
- 외교 마스터: 동맹 유지 비용 -20%
특수: 신라 내 반란 사전 진압 패시브
```

**관계 시스템**
- 인물 간 호감도: 김유신↔김춘추 — 역사적 우정 반영
- 인물 갈등: 연개소문↔영류왕 — 쿠데타 이벤트 트리거

---

### 건설 시스템

**인프라 트리**
```
기본 건물:
├── 농지(農地) → 관개(灌漑) → 대규모 농장
├── 시장(市場) → 교역로 → 해외 항구
├── 성벽(城壁) → 산성 → 천리장성
├── 사원(寺院) → 황룡사 → 불교 문화권 영향력
└── 학당(學堂) → 국학 → 인재 풀 확대
```

**역사적 건물 특수 효과**
| 건물 | 효과 |
|------|------|
| 황룡사 9층탑 | 신라 전국 사기 +20%, 외교 위신 +30 |
| 천리장성 | 고구려 북쪽 방어선 자동 완성 |
| 첨성대 | 매 시즌 이벤트 1개 사전 예측 |
| 안학궁 | 고구려 왕실 위신 +50, 인구 유입 |

---

### 분기 역사 시스템

**역사 사건 처리 방식**
1. **필수 사건**: 반드시 발생 (살수대첩·황산벌·백제 멸망 등)
2. **조건 사건**: 플레이어 행동에 따라 발생 여부 결정
3. **비역사 분기**: 역사와 다른 선택 → 대안 역사 엔딩

**비역사 엔딩 예시**
```
[가야 생존 엔딩 조건]
- 562년 이전까지: 철 생산량 2배 확보
- 신라와 혼인동맹 유지
- 가야 연맹 통합 (금관·대·소가야)
결과: 가야가 신라 병합을 막고 독립 유지
특별 업적: "역사를 바꾼 자"
```

## UI/UX 디자인 원칙

### 지도 디자인

```
메인 전략 맵:
- 한반도 + 주변 지역 (만주·일본·중국 일부)
- 시대별 국경 자동 업데이트
- 색채: 왕국별 팔레트 그대로 적용
  고구려: 철흑, 백제: 비취록, 신라: 황금, 가야: 철색

지형 표현:
- 산악: 화강암 텍스처 + 높이감
- 강: 청회색 흐름 + 계절별 색상 변화
- 평야: 계절별 녹색~황색~설원 변화
```

### 인터페이스 철학

- **고증 UI**: 삼국시대 목간·죽간·두루마리 모티프
- **최소화 원칙**: 게임 세계 몰입 우선 — HUD 최소화
- **한/영 병기**: 고유명사는 한국어 원어 + 영어 번역 병기

### 왕국 시스템 (모바일)

```
왕국 선택 (게임 시작 시 1회):
  고구려: 「기억하는 왕국」— 기병 강화 / 방어 전술 / 장기전 유리
  백제: 「기록하는 왕국」— 외교 강화 / 정보 수집 / 자원 효율
  신라: 「두려워하지 않는 왕국」— 화랑 강화 / 크리티컬 / 단기 결전
  가야: 「노래하는 왕국」— 철갑 강화 / 지원·힐 / 방어형

왕국 변경: 게임 시작 7일 후 1회 한정
왕국 레벨 1~50 (건물 건설 + 전투 승리 누적)
레벨업 보상: 새 건물 해금 + 유닛 강화 슬롯 확장
```

### 스토리 시스템 (모바일)

```
총 10챕터 × 10스테이지 = 100스테이지
클리어 등급: S (사망 0 + 10턴 이내) / A (사망 2 이하) / B (클리어)

스토리 분기 (선택지):
  각 챕터 종료 시 1회 선택지
  예: 「살수에 댐을 막겠습니까?」
  → ① 막는다 (역사대로) → 수공 전술 발동
  → ② 막지 않는다 (대체 루트) → 야습 루트 활성화

역사 팝업 시스템:
  스테이지 시작 전 역사 사실 1개 (3초 팝업)
  50개 수집 시: 「역사 박사」칭호 + 특별 보상
```

### 경제 시스템 (모바일)

```
게임 내 화폐:
  기본 석: F2P 기본 재화 — 미션·로그인 획득
  프리미엄 석: 유료 결제 재화 — 가챠·특수 상점
  왕국 주화: PvP 보상 전용
  역사 기록: 이벤트 재화

소환 비용:
  일반 소환: 100석 (10연속 900석)
  한정 소환: 150석 (10연속 1,350석)
  천장: 100회 내 5성 미등장 시 다음 소환 5성 확정

Anti-P2W 원칙:
  스토리 전체 클리어: 순수 F2P 가능
  PvP: 등급별 매칭 (과금 유닛 ≠ 자동 승리)
```
