## LINE 1 — 왕 시리즈 (KING SERIES)

### KS-001 광개토대왕(廣開土大王)

```
스케일: 1/6 (약 30cm)
소재: PVC + ABS 혼합, 금속 부품 일부
도색: 수작업 도색 + 에어브러시

구성:
- 본체: 광개토대왕 갑옷 착용 전신상
- 표정: 2종 교체 (결의형 / 명령형)
- 손: 3종 교체 (칼 쥔 손 / 지도 펼친 손 / 권법 주먹)
- 무기: 고구려식 환두대도(環頭大刀) 금속 재질
- 받침대: 광개토대왕릉비 문양 각인 원형 대좌
- 배경카드: 릉비 원문 한자 인쇄

색채: color-palette-guide.md 고구려 파트 기준
      갑옷 — 암청(#2F4F7F) + 혈홍(#8B0000) 포인트
      금 장식 — 왕실금(#B8960C)

특전 포함:
- 광개토대왕릉비 미니어처 (10cm, 수지 재질)
- 인증서 (한/영 병기)
- 작품 번호 각인 (1~5,000 한정)

소비자가: 89,000원
한정 수량: 5,000개 (글로벌 동시 발매)
```
