## 교역 체계 개요

삼국시대 교역은 단순한 물물교환이 아닌 **외교·군사·문화의 혈관**이었다. 고구려의 북방 육로, 백제의 황해 해상로, 가야의 남방 해로, 신라의 동해 및 내륙로가 서로 경쟁·공존하며 한반도 경제망을 형성했다.

```
교역 레이어:
Layer 1 — 국내 교역: 왕도↔지방 조세·공납
Layer 2 — 삼국 간 교역: 외교품·밀무역
Layer 3 — 대외 교역: 중국·왜·북방 유목민
Layer 4 — 문화 교역: 불교·한자·기술 전파
```

## 핵심 교역 루트 5개

### 루트 A — 북방 육로 (고구려 주도)

```
노선: 평양(平壤) → 요동(遼東) → 부여(夫餘) → 선비(鮮卑)
별칭: 「북방의 길」/ Northern Road
방향: 양방향 (고구려↔중원·북방)

주요 중계지:
- 환도성(丸都城): 압록강 유역 중계 거점
- 요동성(遼東城): 대륙 진입 관문
- 현도(玄菟): 고구려-한사군 교역지

교역품:
고구려 수출: 철기(鐵器)·모피·말(馬)·약재(인삼·오미자)
고구려 수입: 비단(絲)·도자기·서적·불교 경전·금은

루트 특성:
- 계절성: 겨울 눈길로 인해 봄~가을 집중
- 위험도: 북방 유목민 습격 위험
- 군사 연계: 병참로 겸용 (광개토대왕 원정 시 활용)
- 거리: 평양~요동 약 600리

드라마 연출 포인트:
→ 광개토대왕 친정 전 물자 집결 장면
→ 북방 상인과 고루(창작)의 밀약 장면
→ 요동 관문 수비대 뇌물 장면
```

### 루트 B — 황해 횡단로 (백제 주도)

```
노선: 사비성(泗沘城) → 덕적도(德積島) → 산둥(山東) → 남조(南朝)
별칭: 「황해의 길」/ Yellow Sea Road
방향: 백제↔남중국 (남조: 동진·송·제·양·진)

주요 기항지:
- 미두(彌頭): 백제 서해안 출항 거점
- 덕적도: 항해 중간 기착지
- 등주(登州): 산둥 반도 입항지
- 건강(建康, 현 난징): 남조 수도 최종 목적지

교역품:
백제 수출: 공예품·금동불상·칠기·직물·인삼
백제 수입: 불교 경전·문물·서적·사신 왕래·책봉

특수 교역:
- 칠지도(七支刀): 4세기 백제→왜 외교품
- 기술 이전: 야금·건축 기술자 왜로 파견
- 불교 전파: 384년 인도 승려 마라난타 경로

루트 특성:
- 항해 거리: 약 800~900km
- 항해 기간: 순풍 시 5~7일
- 위험: 황해 폭풍·해적
- 최적 시기: 봄·가을 계절풍 활용

드라마 연출 포인트:
→ 사비성 항구 출항 전날 밤 장면
→ 황해 폭풍 속 외교사절 위기
→ 남조 건강 도착, 화려한 궁정 장면
```

### 루트 C — 남해 교역로 (가야 주도)

```
노선: 김해(金海) → 대마도(對馬島) → 규슈(九州) → 야마토(大和)
별칭: 「철의 길」/ Iron Road / 「가야의 바다」
방향: 가야↔왜 (양방향)

주요 항구:
- 김해 관문항: 가야 교역 중심 (낙동강 하구)
- 고성(固城): 소가야 교역 거점
- 대마도: 한반도↔규슈 중계지
- 하카타(博多): 규슈 최대 입항지

핵심 교역품:
가야 수출: 철정(鐵鋌)·철기·도기·곡물
가야 수입: 식량·목재·왜 공예품·용병(병력)

철정(鐵鋌) 경제:
- 형태: 덩이쇠 (화폐 기능 겸용)
- 규격: 길이 30~40cm, 무게 약 1kg
- 거래 단위: 10정·50정·100정 묶음
- 용도: 무기·농기구 원료 + 교환 매개

루트 특성:
- 항해 거리: 김해~대마도 약 60km
- 항해 기간: 하루 이내 (쾌청 시)
- 빈도: 연중 수시 (삼국 중 가장 활발)
- 가야 멸망 후: 신라가 루트 장악

드라마 연출 포인트:
→ 우륵이 가야금을 싣고 철 교역선 탑승 장면
→ 김해 항구 철정 거래 장면 (저울·흥정)
→ 가야 상인과 왜 상인 술자리 협상
```

### 루트 D — 내륙 조공로 (신라 중심)

```
노선: 경주(慶州) → 소백산맥 → 계립령(鷄立嶺) → 한강 유역
별칭: 「신라의 길」/ Silla Road
방향: 신라↔고구려·백제·당나라

주요 경유지:
- 계립령: 소백산맥 핵심 고개 (현 문경새재 인근)
- 죽령(竹嶺): 소백산맥 북부 고개
- 한강 유역: 삼국 각축 핵심 지역
- 당항성(黨項城): 삼국통일 후 대당 교역 거점

교역품:
신라 수출: 금(金)·은·직물·말·황금 공예품
신라 수입: 불교 승려·경전·기술·외교 경험

삼국통일 후 변화:
- 당항성→대당 직통 해로 개설
- 초기 대당 교역 급성장
- 신라방(新羅坊): 당나라 산둥 지역 신라인 집단 거주지

루트 특성:
- 초기 내륙 중심 → 통일 후 해상 전환
- 소백산맥 고개: 군사·교역 동시 통제
- 한강 유역 지배 = 교역로 장악

드라마 연출 포인트:
→ 죽령에서 고구려군과 마주친 신라 상인 긴장
→ 선덕여왕의 대당 외교 사절 파견
→ 신라 금관 완성 후 교역 선물로 사용
```

### 루트 E — 북방 유목 교역 (고구려 북쪽)

```
노선: 평양 → 고구려 북부 → 말갈(靺鞨) → 숙신(肅愼) → 초원
별칭: 「북방의 은밀한 길」
방향: 고구려↔북방 유목민 (말갈·선비·거란)

주요 교역 민족:
- 말갈: 여진족 선조 / 금속·모피 교환
- 선비(鮮卑): 기마 기술·말 공급원
- 거란(契丹): 이후 고구려 압박 세력

교역품:
고구려 제공: 철기·곡물·직물
고구려 수취: 말(馬)·모피·식량(부족 시)·병력(용병)

군사적 의미:
- 말갈 병사: 고구려군 편입 (개마무사 이외 경보병)
- 말 공급: 고구려 기마 전력 유지의 핵심
- 외교 완충: 북방 유목민 달래기 = 남쪽 집중 가능

드라마 연출 포인트:
→ 광개토대왕과 말갈 추장 회맹(會盟) 장면
→ 말갈 병사 고구려 군영 합류 장면
```

## 교역 물자 상세

### 전략 물자 (국가 통제)

```
1. 철(鐵) — 삼국 공통 핵심 자원
   생산지: 가야(김해·고령) > 고구려 > 신라
   용도: 무기·농기구·교역 매개
   통제: 왕실 직할 생산 (民 사적 거래 제한)

2. 말(馬) — 군사력 직결
   공급처: 북방 유목민·고구려 목마장
   전략 가치: 개마무사 = 고구려 군사력의 상징
   수출 제한: 교전국에 말 판매 금지 (조약)

3. 비단(絲) — 외교·신분 상징
   공급: 중국에서 수입 → 국내 재분배
   용도: 귀족 의복·외교 선물·화폐 대용

4. 불교 경전·불상
   경로: 인도→중국→백제→신라·고구려
   의미: 종교 이상 = 문화적 헤게모니
```

### 일반 교역품

```
농산물: 쌀·콩·기장 (남부 → 북부 유통)
수산물: 건어물·젓갈 (해안 → 내륙)
임산물: 목재·약재·숯 (산악 → 평야)
공예품: 도기·칠기·직물 (왕도 → 지방·해외)
사치품: 유리·향료·상아 (대외 교역으로만 입수)
```

## 교역 제도

### 공무역 vs. 사무역

```
공무역 (官貿易):
- 주체: 국왕·귀족 대리 상단
- 형식: 사신 왕래 + 조공·답례품 교환
- 예: 백제→남조 사신단 (정기적)
- 특권: 면세·왕실 보호

사무역 (私貿易):
- 주체: 호족·상인 집단
- 형식: 비공식 교역 (경우 밀무역)
- 규모: 공무역 이상 추정 (기록 부족)
- 위험: 해적·약탈·관세 부과
```

### 교역 단위 (화폐 이전)

```
현물 화폐:
- 철정(鐵鋌): 가야·신라 주요 매개
- 포(布, 麻布): 삼국 공통 교환 수단
- 미(米): 곡물 기준 단위
- 비단(絹): 고급 교환 매개

단위 기준:
- 포 1필 = 성인 1명 1개월 식비
- 철정 10정 = 소 1마리 (근사치)
- 미 1석 = 교역 기본 단위
```

## 게임 경제 시스템 연동

### 왕국별 특화 자원

```
고구려:
- 주 자원: 철광석·모피·말
- 교역 우위: 북방 루트 독점
- 특수 자원: 「개마」(철갑 말) — 최고가
- 경제 패시브: 북방 교역 수입 +20%

백제:
- 주 자원: 금동공예·도자기·칠기
- 교역 우위: 황해 횡단로 (남중국 직통)
- 특수 자원: 「백제금동」— 외교 선물로 최고 효율
- 경제 패시브: 남중국 외교 보너스 +25%

신라:
- 주 자원: 황금·은·황금 공예품
- 교역 우위: 통일 후 대당 직통로
- 특수 자원: 「신라금(金)」— 고가 수출품
- 경제 패시브: 외교 포인트 교역 전환 가능

가야:
- 주 자원: 철정·가야 도기
- 교역 우위: 남해 루트 (왜 시장 독점)
- 특수 자원: 「가야 철정」— 범용 화폐
- 경제 패시브: 왜 교역량 무제한 (타 왕국 제한 있음)
```

### 게임 교역 이벤트

```
랜덤 이벤트:
1. 해적 습격 — 교역선 손실 위기
2. 폭풍 — 해상 루트 차단 (시즌)
3. 흉작 — 식량 교역 급등
4. 외교 사절 → 특산품 요청
5. 밀무역 발각 → 외교 패널티

전략 선택:
- 루트 봉쇄: 적국 교역 차단 (전쟁 카드)
- 중계 거점 점령: 교역 수입 가로채기
- 상단 파견: 능동적 교역로 개척
```
