```

「드라마·게임 팬을 공연 관객으로 전환」
「한국 역사 뮤지컬의 새로운 표준」

① 메인 뮤지컬: 「강은 기억한다」(3막, 160분)
```

## 메인 뮤지컬 — 「강은 기억한다」

### 작품 개요

```
제목: 강은 기억한다 / THE RIVER REMEMBERS
형식: 대형 뮤지컬 (빅뮤지컬)
구성: 3막, 총 160분 (인터미션 2회 포함)
초연: 세종문화회관 대극장 (목표)
공연 기간: 3개월 (드라마 시즌 방영 연동)

무대 규모:
폭: 20m / 깊이: 15m / 높이: 12m
회전 무대: 왕국 전환 씬 (360도 회전)
물 효과: 살수 방류 장면 — 무대 바닥 물 장치

등장인물:
주인공 4인: 고루·아랑·하린·니문
역사 인물: 을지문덕·연개소문·선덕여왕·광개토대왕 (앙상블)
앙상블: 30명 (병사·귀족·평민·무용수)
```

### 3막 구성

```
1막 (50분) — 「살수」

오프닝 넘버: 「강의 문이 열린다」
  - 4인 각자의 강가에서 동시 노래
  - 4왕국 동시 소개

장면 1: 고루와 을지문덕 (평양성)
  곡: 「기억하는 자 / He Who Remembers」
  내용: 출전 전야, 스승의 마지막 가르침

장면 2: 아랑과 성충 (사비성)
  곡: 「기록의 언어 / Language of Records」
  내용: 문서관 밤, 기록하는 자의 사명

장면 3: 살수 전투 클라이맥스
  곡: 「살수여 흘러라 / Flow, Salsu」
  내용: 전투 + 무용 결합 스펙터클 씬
  특수효과: 물 장치 + 조명 파도 효과

1막 엔딩: 「살수 이후 / After Salsu」
  고루 솔로 — 살수 강가 독백 뮤지컬

2막 (55분) — 「기억」

오프닝: 「시간이 흘렀다 / Time Has Passed」
  앙상블 — 612년→642년 시간 점프 연출

장면 4: 니문의 가야금 (신라 궁중)
  곡: 「망국지가 / Song of a Fallen Kingdom」
  내용: 니문 솔로 — 가야금 반주 + 성악 결합
  특수효과: 가야 유적 홀로그램

장면 5: 연개소문 쿠데타
  곡: 「칼의 논리 / Logic of the Blade」
  내용: 연개소문 듀엣 (고루와)
  분위기: 정치 스릴러, 그림자 조명

장면 6: 선덕여왕의 예언
  곡: 「아는 것의 무게 / Weight of Knowing」
  선덕여왕 솔로 — 3가지 예언 회상 씬

2막 엔딩: 「당나라가 온다 / Tang Comes」
  4인 콰르텟 — 각자의 두려움과 결의

3막 (45분) — 「안시성」

오프닝: 「안시성 / Ansi-seong」
  앙상블 군무 — 당나라 30만 표현

장면 7: 토산 야습
  곡: 「오늘 밤 / Tonight」
  고루 솔로 → 앙상블 합창
  특수효과: 회전 무대 + 흙더미 무너지는 효과

장면 8: 아랑의 마지막 기록
  곡: 「기억하여라 / Remember」
  아랑 솔로 — 백제 멸망 예감 (복선)

장면 9: 니문의 12번째 곡 완성
  곡: 「12번째 / The Twelfth」
  니문 솔로 + 오케스트라 가야금 협연
  하이라이트 씬 — 가야금 실연주 배우

피날레: 「강은 기억한다 / The River Remembers」
  4인 + 앙상블 전체 합창
  무대: 4왕국의 강이 하나의 바다로 합류하는 홀로그램
```

## 음악 구성

### 주요 넘버 목록

```
총 곡수: 22곡 (솔로 9 / 듀엣 4 / 앙상블 6 / 합창 3)

넘버별 악기 구성:
가야금 포함 넘버: 5곡 (니문 씬 전용 가야금 실연주)
오케스트라: 25인 피트 오케스트라
  - 현악 12인 (가야금 1 포함)
  - 관악 8인 (피리·대금 포함)
  - 타악 3인 (북·장고 포함)
  - 건반 2인

음악 감독:
국악 + 현대 뮤지컬 음악 결합 전문가
가야금·거문고·단소 실연주 기반 편곡

핵심 테마:
메인 테마 「강은 기억한다」: 전 넘버에 라이트모티프로 변주
고루 테마: 강하고 단순한 선율 (거문고 기반)
아랑 테마: 우아하고 복잡한 화음 (가야금+피리)
하린 테마: 빠르고 용감한 리듬 (타악 강조)
니문 테마: 가야금 독주 + 서서히 쌓이는 오케스트라
```

### 대표 넘버 상세

```
「망국지가 / Song of a Fallen Kingdom」(니문 솔로):
장르: 한국 전통 + 뮤지컬 발라드 결합
가사 첫 줄: 「나라는 사라졌다 / 강은 아직 흐른다」
가야금 실연주 + 성악 → 하이라이트
영어 버전: 글로벌 공연 대비

「살수여 흘러라 / Flow, Salsu」(앙상블):
장르: 마치(March) 형식 + 한국 타악 리듬
특수효과 연동 넘버
수중 댄서 가능성 검토 (물 무대 활용)

「아는 것의 무게 / Weight of Knowing」(선덕여왕 솔로):
장르: 소프라노 아리아 형식 (클래식 뮤지컬)
선덕여왕 최고 음역 활용
예언 3가지 각각 다른 조성으로 표현
```

## 무대·연출 계획

### 무대 디자인

```
무대 핵심 요소:
① 회전 무대: 4왕국 전환 (고구려→백제→신라→가야)
② 강 효과 무대: 실제 물 (살수 씬) + 조명 (감성 씬)
③ 4면 LED 스크린: 홀로그램·배경 영상
④ 승강 무대: 토산 붕괴 씬 고저 변화

조명 컨셉:
왕국별 색온도:
  고구려: 쿨 블루 (#2F4F7F)
  백제: 웜 골드 (#B8960C)
  신라: 브라이트 옐로 (#FFD700)
  가야: 어스 앰버 (#C8A96E)
전투 씬: 강렬한 붉은 역광
감성 씬: 단일 스포트라이트 + 수면 반영

의상:
고구려: 찰갑 + 암청 포 (무대용 경량화)
백제: 비단 + 금색 봉황 자수
신라: 황금 장신구 + 자색 화랑 복식
가야: 토황 포 + 철 장신구

특수효과:
살수 물 장치: 무대 바닥 수조 (15cm) + 폭포 효과
토산 붕괴: 모래+흙 도구 + 승강 무대 조합
홀로그램: 광개토대왕·가야 왕도 홀로그램
```

## 캐스팅 계획

```
주인공 4인 (더블 캐스팅 기준):
고루 A/B: 테너 + 무예 능숙 배우
아랑 A/B: 메조소프라노 + 댄스 능숙
하린 A/B: 테너 + 무술 퍼포먼스
니문 A/B: 가야금 실연주 가능 배우 (우선 조건)

니문 특별 조건:
가야금 실연주 필수 → 국악 전공 배우 또는 집중 훈련
오디션: 가야금 + 성악 통합 오디션

역사 인물:
을지문덕: 바리톤 (노장의 무게)
연개소문: 바리톤 (위압적)
선덕여왕: 소프라노 (서정적)
광개토대왕: 베이스 (웅장) — 3막 앙상블 등장

앙상블 (30명):
무용수 10명 + 성악 배우 20명
한국 전통 무용 + 현대 뮤지컬 무브먼트
```

## 글로벌 공연 계획

```
일본 (도쿄):
극장: 제국극장·시아터 오르브 검토
언어: 일본어 번역 + 한국어 자막 (또는 역)
기간: 3개월 (애니 방영 연동)
특화: 일본 성우 캐스팅 가능성 (화제성)

미국 (뉴욕):
극장: 오프-브로드웨이 → 브로드웨이 진입 목표
언어: 영어 버전 (새 번역·편곡)
마케팅: K-문화 + 역사 뮤지컬 결합 포지셔닝

영국 (런던):
극장: 웨스트엔드 파트너 검토
언어: 영어 버전 공용
```
