## 삼국시대 수전 개요

```
수전(水戰) 정의:
  강·하천에서의 전투 (내수전)
  해안·연해에서의 전투 (연해전)
  원양 해상에서의 전투 (원해전)

삼국 수전 능력 비교:
  고구려: 내수전 최강 (살수·압록강·대동강 활용)
  백제: 연해전 경험 풍부 (중국·일본 교역로)
  신라: 후기 해전 능력 급성장 (기벌포 해전)
  가야: 연안 어업·교역 (군사 수전 미발달)

주요 수전 사건:
  살수대첩 (612년): 수(隋) 113만 vs 고구려
  백강 전투 (663년): 백제 부흥군+왜 vs 나당
  기벌포 해전 (676년): 신라 vs 당나라
```

## 살수대첩 — 수공(水攻) 전술 분석

### 전략 배경

```
수(隋) 양제 2차 원정 (612년):
  병력: 113만 3,800명 (실질 30~40만 추정)
  목표: 요동 → 평양 직공
  문제: 보급선 과도한 연장

을지문덕의 판단:
  「적의 식량이 다했다 — 스스로 후퇴할 것이다」
  7번 후퇴 전술로 수나라 군 평양 근처까지 유인
  평양성 앞에서 거짓 항복 제안 → 시간 벌기
```

### 살수 수공 메커니즘

```
살수(薩水) 현재 위치: 청천강 (추정)

수공 준비:
  상류 댐(제방) 사전 건설
  댐 위치: 살수 상류 협곡
  저수량: 강 전체 수위 상승 (수 미터)

수공 실행:
  수나라 군 강 절반 도하 시 댐 개방
  물이 한꺼번에 방류 → 도하 중 병사 대량 수몰
  고구려 매복대 동시 공격 (양면 협공)

피해 규모 (삼국사기 기록):
  수나라 군 30만 5,000명 중
  살아 돌아간 자 2,700명
  → 사실상 전멸 수준

IP 서사 활용:
  고루 캐릭터 = 살수 댐 조작 담당
  댐 개방 명령 장면 = 드라마 S1 클라이맥스
  SAGA LINE 디오라마: 「강물이 내려온다」
```

### 수공 전술의 한계와 위험

```
위험 요소:
  아군 피해: 강 하류 아군 진지 피해 가능
  타이밍 오류: 도하 전/후 방류 시 효과 없음
  지형 의존: 댐 가능한 협곡 지형 필수

고구려 해결:
  아군 사전 철수: 강 북안 고지대 배치
  타이밍 신호: 봉화 2연속 = 방류 명령
  댐 위치: 아군 진지보다 상류 → 영향 최소화

역사 고증 주의:
  「댐」= 고대 토제(土製) 제방, 현대식 댐 아님
  방류 장치 = 목제 수문 개방 방식
  단, 규모와 정확한 위치 = 고증 불확실
  → IP에서는 「물을 막았다 열었다」수준으로 표현
```

## 백강 전투 (663년) — 수군 대결

### 전투 개요

```
배경:
  백제 멸망(660) 후 백제 부흥 운동
  왜(倭, 일본) = 백제 지원 군사 파견
  나당연합 = 부흥군 진압

전투 규모:
  백제+왜 연합: 수군 1,000척 이상
  나당연합: 수군 170척 (당나라)

결과:
  나당 수군 압도적 승리
  백제+왜 400여 척 불태워짐
  백제 부흥 운동 사실상 종료

전술 분석:
  나당 수군: 화공(火攻) 전술 — 불화살·화선
  백제+왜: 수적 우세 불구 전술 열세
  교훈: 수 > 전술 패배 사례
```

### 백강 전투 IP 주의사항

```
한일 역사 민감성:
  왜(倭)의 참전 = 일본 교과서 서술과 다를 수 있음
  「임나일본부」관련 해석 충돌 가능

IP 처리 방침 (IP-LEGAL 확인 사항):
  백강 전투 = 「백제 부흥전의 비극」으로 초점
  왜 군사 = 「우방의 지원」(적대 묘사 최소화)
  결과 = 백제의 비극으로 수렴, 왜 비판 배제
  일본 수출본: 이 전투 장면 편집 검토 필요

아랑 캐릭터 처리:
  백강 전투 시점 아랑 = 이미 백제 통치 아래 없음
  백강 전투 = 아랑에게 「끝나지 않은 백제의 마지막 불꽃」
  원거리에서 소식 듣는 방식으로 서술
```

## 기벌포 해전 (676년) — 삼국 통일 완성전

### 전투 배경

```
나당전쟁 (670~676):
  신라 vs 당나라 — 한반도 지배권 쟁탈
  당나라 목표: 한반도 전체를 당 영토화
  신라 전략: 고구려·백제 유민 포섭 + 항전

기벌포 위치:
  충남 서산 부근 (금강 하구 인근 추정)
  당나라 수군 한반도 상륙 루트

신라 수군 준비:
  김유신 사후 → 신라 해군 독립 강화
  선박: 병선(兵船) 100여 척
  전술 연구: 백강 전투 교훈 반영
```

### 기벌포 해전 22연승

```
전투 경과 (삼국사기):
  1차~22차: 신라 22전 22승
  당나라 수군 4,000명 이상 전사
  선박 다수 격침·노획

신라 승리 요인:
  ① 지형 활용: 금강 하구 좁은 수로 → 당 대형 무효화
  ② 화공: 사전 준비한 화선(火船) 돌격
  ③ 기동력: 소형 경쾌선 + 대형 당 전함 대비

전술 세부:
  신라 소형 선 → 당 대형 선 포위
  「벌떼 전술」: 다수 소선이 1~2 대형 선 집중 공격
  화공 타이밍: 해류·바람 방향 사전 계산
```

### IP 서사 연계

```
하린의 기벌포:
  김유신의 후배 → 기벌포 실전 지휘관
  22전 중 10차전 = 하린 개인 선봉 전투
  부상 입지만 격침 1척 달성

고루의 시점:
  언덕에서 기벌포 바라보는 노장
  「고구려는 살수에서 이겼다 — 신라도 이긴다」
  고구려 전술 전수 → 신라 해전에 간접 기여

드라마 최종화:
  기벌포 해전 = 시즌 3 최종화 대전투
  CGI 예산 집중: 수면 화공 + 선박 격침
  4인 각자의 기벌포 장면 교차 편집
```

## 고대 선박 기술

### 삼국 선박 유형

```
고구려 선박:
  주력: 평저선(平底船) — 강·연안용
  군선: 누선(樓船) — 상부 구조물 있는 대형선
  특기: 압록강·대동강 수군 운용

백제 선박:
  주력: 첨저선(尖底船) — 원양 항해 가능
  교역선: 대형 목조 돛배
  항로: 중국 양쯔강 하구, 일본 규슈
  특기: 동아시아 최고 조선 기술 (일본 전수)

신라 선박:
  초기: 소규모 연안 어선 수준
  후기 발전: 기벌포 전후 급성장
  기벌포 주력: 경쾌한 중형 병선

가야 선박:
  어선·교역선 중심
  소형 목선, 군사 목적 미발달
```

### 선박 구조 (고증)

```
목재:
  소나무 (선체) + 참나무 (용골·늑골)
  방수: 송진·어유 혼합 도포

추진:
  노(櫓): 인력 좌우 배치 (전투 기동)
  돛(帆): 사각돛 1~2개 (순풍 항해)

무기:
  투석기: 돌·화염 항아리 투사
  불화살: 화공 주 수단
  충각(衝角): 선수 충돌 무기 (일부 선박)

항해 도구:
  나침반 未사용 (시대 이른 편)
  → 별자리·해류·조류 경험 의존
  → 니문 세계관: 가야금 소리가 파도 소리 읽기
```

## 수전 장면 연출 가이드

```
드라마 수전 촬영 고증:
  선박 재현: 세트 병선 2~3척 + CG 합성
  물 이펙트: 실제 수조 + CG 워터
  화공 장면: 안전 통제 + CG 불꽃

금지 표현:
  현대 폭탄·화약 무기 (시대착오)
  잠수 다이빙 전투 (당시 없음)
  나침반 사용 항해 (삼국시대 불확실)

권장 표현:
  별자리·조류 읽기로 항해
  노 젓기 + 돛 병행
  화공은 불화살·화선 기반
  수공은 제방 방류 방식

살수대첩 장면 특별 주의:
  「113만 대군」= 과장 수치 가능성 → 극 내 「대군」으로만 표현
  수몰 묘사 = 잔혹도 조절 필수 (익사 장면 직접 묘사 최소화)
```
