**포맷**: 총 3시즌 / 시즌당 14부작 / 편당 65~75분
**제작 방식**: 국내 제작사 + OTT 공동 제작

```
시즌 구성:

시즌 2 — 패권의 시대 (3~5세기) — 광개토·근초고왕·선덕
시즌 3 — 황혼의 전쟁 (562~668년) — 계백·우륵·문무왕
```

## 1. 연출 방향

### 전체 연출 철학

```
핵심 키워드: "역사의 무게 + 인간의 온도"

삼국은 영웅들의 이야기지만, 그 영웅들도 인간이었다.
전쟁은 장엄하되 전쟁의 비용(인명)을 외면하지 않는다.
왕국은 아름답되 그 아름다움이 무너지는 과정도 보여준다.

연출 3원칙:
1. 공간이 감정을 말한다 — 강·산·성·하늘 적극 활용
2. 침묵이 대사다 — 말 없는 장면의 힘
3. 역사는 알고 있다 — 시청자가 결말을 알아도 과정이 울린다
```

### 왕국별 연출 톤

```
고구려:
- 카메라: 낮은 앵글 → 인물 거대하게
- 색조: 차갑고 단단한 블루-그레이
- 속도: 빠른 컷 편집 (전투) / 긴 침묵 (독백)
- 빛: 북방 직사광 — 강하고 그림자 깊음

백제:
- 카메라: 유려한 트래킹 샷
- 색조: 따뜻한 황금·호박 팔레트
- 속도: 중간 — 우아하되 늘어지지 않음
- 빛: 간접광 위주 — 부드럽고 아름다움

신라:
- 카메라: 높은 앵글 (하늘 많이 담음) + 첨성대 수직 샷
- 색조: 밤 장면 많음 — 별빛·촛불
- 속도: 느린 편 — 여운 강조
- 빛: 달빛·별빛 활용 — 신비로운 분위기

가야:
- 카메라: 핸드헬드 부분 허용 — 살아있는 느낌
- 색조: 따뜻한 토황·철적
- 속도: 음악 리듬에 맞춘 편집
- 빛: 황혼·새벽 — 사라져가는 것의 아름다움
```

## 2. 촬영 가이드

### 주요 로케이션

```
국내:
- 경주 (신라): 첨성대·불국사·감은사지·대왕암 해변
- 부여 (백제): 낙화암·백마강·능산리고분군
- 공주 (백제): 무령왕릉·공산성
- 고령 (가야): 지산동고분군 + 합천댐 일대
- 임진강 (고구려): 강변 + 북방 분위기
- 강원 산간: 고구려 북방 성채 대역

해외 (협의):
- 중국 집안(吉林省): 광개토대왕릉비 실물 촬영
  (관광·다큐멘터리 목적, 드라마 재현은 세트)
- 몽골 초원: 고구려 기마 장면 (광활한 평원)

세트 건립:
- 평양성 세트: 오픈 세트 (3,000평 규모)
- 사비성 세트: 실내 궁중·외부 성벽 분리
- 서라벌 세트: 황룡사 1/10 스케일 외관
```

### 시즌 1 주요 장면 연출 메모

```
[S1-E01] 주몽 탈출 시퀀스
- 야간 추격전 — 핸드헬드 + 빠른 컷
- 강 건너는 장면: 슬로모션 + 물 스프레이
- 압박감: 클로즈업 연속 → 갑작스런 풀샷

[S1-E03] 비류수 협약
- 두 사람 강 사이에 두고 대화
- 카메라: 강 수면 반사 활용
- 마지막 컷: 강 전경 — 두 사람이 작게

[S1-E06] 모에 임종
- 실내 장면 — 촛불 빛만 사용
- 대사 최소화 — 표정·호흡 클로즈업
- 눈 내리는 창밖 — 인서트 컷 반복

[S1-E12] 소서노의 남하
- 새벽 출발 — 역광 실루엣
- 주몽 혼자 남는 장면: 후방 고정 샷
- 소서노 돌아보는 컷: 슬로모션 + 음악 없음
```

### 시즌 2 주요 장면 연출 메모

```
[S2-E04] 개마무사 행진
- 드론 + 지면 동시 촬영
- 철갑의 소리: 현장 녹음 + 후반 음향 강화
- 황금빛 평원 + 푸른 하늘 대비

[S2-E08] 광개토대왕 임종
- 最小 조명 — 거의 어둠
- 음악: 없음 → 호흡 소리만
- 마지막 시선: 창밖 → 지평선

[S2-E11] 선덕여왕 첨성대 독백
- 수직 앙각 + 별 합성
- 대사: "별은 거짓말하지 않는다. 사람이 거짓말한다."
- 연출: 대사 후 긴 침묵 + 카메라 천천히 하강
```

### 시즌 3 주요 장면 연출 메모

```
[S3-E05] 계백 가족 장면
- 가장 조용하고 친밀한 촬영 — 가정적 따뜻함
- 다음 화 전쟁과 극적 대비 의도

[S3-E06] 황산벌 전투
- 1:1 스케일 재현 불가 → 선택적 확대 촬영
- 5,000 vs 13만: 신라군 규모는 암시 (전부 표현 불가)
- 계백 최후: 슬로모션 + 가야금 배경음

[S3-E10] 우륵 귀화 결단
- 가야금 연주 중 결심
- 연주가 끝나는 순간 = 결심의 순간
- 마지막 줄 소리 → 페이드 아웃

[S3-E14] 피날레
- 4개 강(한강·대동강·백마강·낙동강) 동시 편집
- 현재의 강 영상 + 과거 재현 오버랩
- 마지막: 강물 소리만 — 음악 없음
```

## 3. 의상 가이드

### 왕국별 의상 원칙

```
고구려:
- 기본: 어두운 계열 (암청·철회·흑)
- 왕복: 갑옷 위주 — 화려함보다 위엄
- 무기 소품: 환두대도 필수
- 소재: 가죽·철 질감 강조
- 두식(頭飾): 조우관(鳥羽冠) — 새 깃털 장식

백제:
- 기본: 따뜻한 계열 (황금·호박·비단백)
- 왕복: 화려한 비단 — 아름다움 강조
- 소재: 실크·비단 질감 — 빛 반사
- 두식: 금제 관모 + 장식품
- 여성 의상: 색동 계열 허용

신라:
- 기본: 황금·보라 계열
- 왕복: 금관 + 예복
- 소재: 황금 장식 많음
- 선덕여왕: 왕복이되 여성적 요소 — 토론 필요
- 화랑: 화려한 색상 + 무기

가야:
- 기본: 토황·철적·녹청
- 의상: 실용적 — 장인·무인 기질
- 소재: 두꺼운 면·마 질감
- 철 장식: 팔찌·허리띠
- 우륵: 항상 가야금 소지 — 의상보다 악기가 정체성
```

### 시대별 의상 변화

```
BC 37~1세기 (건국기):
- 소박하되 기능적
- 전쟁 의상 위주
- 화려함 자제 (아직 국력 약함)

3~5세기 (전성기):
- 각 왕국 최고 전성기 의상
- 국제 교류 영향 (중국·왜 요소 일부)
- 왕복의 화려함 최고조

6~7세기 (황혼기):
- 전쟁 의상 비율 증가
- 백제 후기: 멸망 직전의 마지막 화려함
- 고구려 후기: 더욱 강인한 무인 스타일
```

## 4. 특수효과 가이드

### VFX 우선순위

```
시즌 1 VFX 예산 배분:
HIGH (40%): 전투 시퀀스 — CG 병력 증원
MED  (30%): 성채 확장 — 실물 세트 + CG
LOW  (20%): 자연 환경 — 계절 변화
기타 (10%): 파티클 효과·마법적 요소

핵심 VFX 장면:
- 살수대첩 (S2): 강물 방류 + 병력 CG
- 개마무사 행진 (S2): 수백 기마병 CG 증원
- 황산벌 전투 (S3): 13만 신라군 CG
- 낙화암 (S3): 꽃잎 파티클 + 절벽 재현
```

### 전투 연출 규칙

```
폭력 수위:
- 목표: 15세 이상 관람가 기준
- 피 묘사: 있되 과도하지 않음
- 신체 절단 묘사: 금지
- 전사 장면: 슬로모션 + 명예로운 죽음 연출

전투 사실성:
- 고증 감수: ADV-MILITARY 필수
- 무기 사용법: 환두대도·장창·활 실제 방식
- 전투 대형: 삼국시대 진법 반영
- 기마전: 몽골 기마 전문가 자문

전투 감정:
- 장엄함보다 비극 — 전쟁의 비용 표현
- 적군도 인간으로 — 일방적 학살 금지
- 계백 황산벌: 특히 신라군 장졸의 고통도 표현
```

## 5. 음악·사운드 가이드

### 음악 방향

```
메인 테마: "강은 기억한다"
- 편성: 현악 4중주 + 가야금 + 타악
- 변주: 왕국별 4가지 버전
  고구려 — 낮은 현악 + 북
  백제   — 현악 + 가야금 아르페지오
  신라   — 높은 현 + 첼레스타
  가야   — 가야금 솔로 + 약한 현

에피소드 규칙:
- 전투 전: 타악 중심 긴장감
- 전투 중: 타악 + 금관
- 임종 장면: 악기 하나씩 빠짐 → 무음
- 마지막 컷: 무음 or 자연음만
```

### 사운드 디자인

```
왕국별 앰비언스:
고구려: 바람 소리 + 철 부딪히는 소리
백제: 강물 소리 + 새소리 + 궁중 악기
신라: 밤 풀벌레 + 멀리서 범종(梵鐘)
가야: 가야금 소리 + 낙동강 물소리

전투 사운드:
- 개마무사 돌격: 말발굽 + 철갑 소리
- 화살: 공기 가르는 소리 강조
- 칼 충돌: 무거운 금속음 (현실적)
- 성벽 공격: 투석기·운제 소리 재현
```

## 6. 후반 작업 가이드

### 색보정 (DI)

```
시즌 1 (건국기):
- 전반적: 따뜻한 호박 + 일부 차가운 대비
- 겨울 장면: 블루-그레이 강화
- 강 장면: 반사광 강조

시즌 2 (전성기):
- 고구려: 차갑고 강한 대비
- 백제: 황금 시간대 (golden hour) 최대 활용
- 신라: 밤 장면 — 청색 계열

시즌 3 (황혼기):
- 전반적: 채도 낮춤 — 황혼의 느낌
- 계백 장면: 탁한 황토색
- 낙화암: 분홍+청 — 아름다움과 비극
```

### 편집 원칙

```
기본:
- 에피소드 편집점: 항상 감정 절정 직전 또는 직후
- 훅(hook): 첫 5분 내 핵심 장면 배치
- 클리프행어: 매 화 마지막 2~3분

대사 편집:
- 침묵 자르지 말 것 — 침묵도 연기
- 겹치는 대사: 의도적인 경우 유지
- 반응 컷: 대사만큼 반응 컷 중요

자막 정책:
- 한자 병기: 고유명사 첫 등장 시 자막
  예) "광개토대왕(廣開土大王)"
- 한문 대사: 번역 자막 필수
- 릉비 비문: 원문 + 해석 동시 표시
```
