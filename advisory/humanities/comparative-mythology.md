## 비교 신화학 활용 목적

```
목적:
  삼국 IP 서사를 세계적 공감대와 연결
  글로벌 관객이 직관적으로 이해하는 서사 원형 활용
  한국 고유 신화의 독창성 부각

원칙:
  한국 신화 = 출발점, 세계 신화 = 참조
  유사점: 보편성 강화 근거
  차이점: 한국적 독창성 마케팅 포인트

경고:
  세계 신화 패턴을 한국 신화에 덮어씌우기 금지
  「한국판 ○○」식 포지셔닝 지양
  → 삼국 IP는 그 자체로 독립적 신화 체계
```

## 영웅 신화 비교

### 주몽 vs 세계 영웅 신화

```
Joseph Campbell「영웅의 여정」패턴 비교:

① 일상 세계: 부여의 왕자 (주몽) — 특별한 능력 가진 자
② 소명: 부여 왕자들의 탄압
③ 길의 입문: 부여 탈출
④ 시련: 강을 건너는 과정 (자라·물고기 다리 신화)
⑤ 변환: 졸본에서 건국
⑥ 귀환: 없음 → 새 나라가 곧 귀환지

비교:
  그리스 헤라클레스: 탄압 → 12과업 → 신격화
  이집트 오시리스: 죽음 → 부활 → 왕권 상징
  주몽 고유성: 「새로운 나라 건국」= 귀환이 아닌 창조
              → 기존 세계 복귀 아닌 새 세계 창조가 목표

IP 서사 적용:
  고루: 복수에서 시작 → 새로운 의미 창조로 완결
  고루 = 주몽 여정의 현대적 변주 (건국 → 기억 수호)
```

### 을지문덕 전략 vs 세계 전략가 신화

```
비교 대상:
  손자(孫子): 「지피지기 백전불태」
  오디세우스: 트로이 목마 (기만 전술)
  제갈량: 적벽대전 (기상 + 지리 활용)

을지문덕 고유성:
  ① 시(詩)로 적을 기만 — 문학 = 무기 (세계 전략가 유일)
  ② 7번 후퇴: 적의 자만심을 키워 패배시킴
  ③ 청야전술: 나라를 불태워 나라를 지킴
  → 「소멸로 생존하는 역설」= 한국 고유 전략 철학

IP 활용:
  드라마 해설: 을지문덕의 전술 = 세계 전쟁사 최고 전략 중 하나
  게임 스킬명: 「지족원운지(知足願云止)」— 을지문덕 고유 전술
```

## 비극 신화 비교

### 계백 비극 vs 세계 비극

```
비교:
  스파르타 레오니다스: 300명 테르모필레 수비 → 전사
  일본 사이고 다카모리: 세이난전쟁 최후 항전
  로마 호라티우스: 다리 하나로 적군 저지

계백 고유성:
  처자 결단: 비극의 선택을 전투 전에 완성
  「죽음 자체」가 아니라 「선택」이 핵심
  5번째 전투에서 패배: 불굴이 아닌 한계의 비극

IP 서사 적용:
  아랑: 계백의 죽음을 보며 「아름다운 것의 종말」체험
  「아름다운 것도 불의에 무릎 꿇는다」— IP 핵심 비극
  비교 마케팅: 「한국의 300」(레오니다스 병행 마케팅 가능)
  단, 「한국판 300」식 포지셔닝 아닌 독립적 비극으로 제시
```

### 선덕여왕 예언 vs 세계 예언 신화

```
비교:
  그리스 카산드라: 예언하지만 믿어지지 않음
  오이디푸스: 예언에서 도망치다 결국 성취
  선덕여왕: 예언하고, 믿어지고, 자신도 수용

선덕 고유성:
  카산드라와 반대: 왕이 예언하고 신하가 믿음
  오이디푸스와 반대: 피하지 않고 받아들임
  「알면서 두려워하지 않는 지혜자」= 세계 신화 드문 패턴

IP 서사 적용:
  하린: 선덕여왕의 죽음 예언을 들음 → 받아들이지 못함
  하린의 성장: 선덕처럼 「알면서 두려워하지 않는 자」가 됨
```

## 강(江) 신화 비교

### 살수 vs 세계 강 신화

```
세계 강 신화:
  스틱스(Styx): 죽음과 생의 경계, 저승 강
  황하(黃河): 중국 문명의 어머니
  갠지스(Ganga): 인도 정화의 강
  라인강: 게르만 신화 보물 수호

살수 고유성:
  경계의 강 (스틱스): 살수 = 생사의 경계 (살수대첩)
  기억의 강 (독창 요소): 「강은 기억한다」= 세계 신화 없는 개념
  → 강이 목격자이자 기억 보관자

IP 핵심 차별성:
  「강은 기억한다」= 삼국 IP만의 신화 개념
  세계 어느 신화에도 없는 「기억하는 강」
  → 글로벌 마케팅 독점 가능 개념
```

## 멸망과 부활 신화 비교

### 가야 멸망 vs 세계 멸망 신화

```
세계 멸망 서사:
  아틀란티스: 바다에 잠긴 문명 (플라톤)
  트로이: 불타는 도시 (호메로스)
  폼페이: 화산재에 묻힌 도시

가야 멸망 고유성:
  물리적 파괴 아닌 「흡수」에 의한 소멸
  가야 문화 → 신라 + 일본으로 전파
  가야금이 가야의 유일한 살아있는 유산

IP 서사 가치:
  「사라진 나라, 남은 소리」= 기억 = 아틀란티스보다 서정적
  니문의 역할: 문명의 최후 기억자
  글로벌 보편 감성: 「무엇이 진정으로 살아남는가」질문
```

## 서사 원형 활용 가이드

```
보편적 원형 → 삼국 IP 적용:

원형: 스승과 제자 (멘토의 죽음)
  삼국 적용: 을지문덕(스승) + 고루(제자)
  유사 서사: 오비완+루크, 아루키미데스+아서왕

원형: 멸망하는 왕국의 마지막 충신
  삼국 적용: 계백 (백제)
  유사 서사: 레오니다스(그리스), 조조 최후 충신들

원형: 예언자 여왕
  삼국 적용: 선덕여왕
  유사 서사: 카산드라, 시빌라

원형: 기억 수호자
  삼국 적용: 니문 (가야)
  유사 서사: 호메로스(구전 서사 보존), 조선 사관

활용 원칙:
  유사점: 「당신이 아는 그 이야기, 한국 버전」접근
  차이점: 「하지만 이 부분은 완전히 다르다」강조
  목표: 친숙함(접근성) + 새로움(차별성) 동시 확보
```
