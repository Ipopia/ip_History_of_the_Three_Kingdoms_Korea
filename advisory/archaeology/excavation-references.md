## 고고학 자문 목적

```
활용 목적:
  실제 발굴 유물 → IP 세계관 물질 문화 근거
  드라마·게임 소품·배경의 고증 기반 제공
  글로벌 시장 「진짜 역사」신뢰도 강화

자문 원칙:
  발굴 사실 = 고증 최우선 근거
  미발굴·불확실 항목 = 창작 허용 범위 명시
  시대착오 소품 = 즉시 수정 지시
```

## 고구려 주요 발굴 유적

### 고분벽화 (집안·평양 일대)

```
주요 발굴지:
  중국 지린성 지안(集安): 국내성 터 + 광개토왕릉 일대
  북한 평양·황해도: 안악 3호분 등

대표 유물·유적:
  안악 3호분 (4세기):
    벽화: 묘주 초상·주방·마구간·행렬도
    의복 고증: 고구려 귀족 복식 직접 근거
    무기: 철갑·장검·활 형태 확인
    IP 활용: 고루 의상·갑옷 디자인 1차 근거

  덕흥리 고분 (408년):
    벽화: 사신도·군사 행렬·묘주 초상
    색채: 적·청·황 3색 기반 (IP 고구려 색채 참고)

  강서대묘 (7세기):
    사신도 최고 걸작 (청룡·백호·주작·현무)
    IP 활용: ROYAL LINE 「고구려 사신도 아트 패널」원형

고증 포인트:
  고구려 투구: 소찰갑(小札甲) 형식 — 미늘갑 아님
  철갑 색상: 산화 처리 검은빛 + 간혹 붉은 옻칠
  무기: 장검·창·활 (단검은 보조 무기)
```

### 고구려 성곽 유적

```
안시성 (추정지 논쟁 중):
  중국 랴오닝성 하이청·가이저우 일대 추정
  정확한 위치 미확정 → IP에서 「살수 북방」으로만 처리

국내성 (지안):
  성벽 발굴 완료 — 들여쌓기 석축 확인
  왕궁터 추정 구역 발굴 중
  IP 활용: 고구려 도성 건축 고증 근거

장군총 (광개토왕 or 장수왕릉 추정):
  계단식 석조 왕릉 — 웅장한 규모
  IP 활용: 고구려 왕릉 배경 장면 참고
```

## 백제 주요 발굴 유적

### 공주·부여 발굴

```
무령왕릉 (1971년 발굴 — 공주):
  온전한 백제 왕릉 최초 발굴 (도굴 피해 없음)
  주요 유물:
    금제 관식(冠飾): 백제 왕관 장식
    금동 신발: 정교한 금속 공예
    석수(石獸): 지석묘 수호 동물상
    목관 출토: 백제 목공 기술 증거
  IP 활용:
    아랑 의상·장신구 고증 핵심 근거
    백제 금 장신구 = 아랑의 황금 비단 의상 배경

능산리 고분군 (부여):
  백제 사비 시대 왕릉군
  1993년 금동대향로 출토 → 국보 287호
  IP 핵심 소품: 「백제 금동대향로」= 아랑의 집착 대상
  실물 크기: 높이 61.8cm / 무게 11.8kg

금동대향로 고증:
  상단: 봉황 + 연꽃 덮개
  중단: 74명 인물상·동물·산봉우리 (박산향로)
  하단: 용이 받치는 연꽃
  → ROYAL LINE 레플리카 설계 근거
```

### 사비성 유적

```
부여 관북리 유적:
  백제 사비 왕궁터 추정
  발굴: 건물지·우물·수로 흔적
  IP 활용: 사비성 왕궁 CG 복원 근거

부소산성:
  사비 왕도 방어 산성
  낙화암 위치 확인 → IP 낙화암 장면 배경
  성벽 구조: 토축(土築) + 일부 석축

정림사지 5층 석탑:
  백제 유일 남은 석탑 (부여)
  「대당평백제국비명」새겨짐 (당나라 침략 기록)
  IP 활용: 아랑의 사비성 풍경 배경
```

## 신라 주요 발굴 유적

### 경주 고분 발굴

```
천마총 (1973년 발굴):
  신라 금관 출토 (국보 188호)
  금관 구조: 나뭇가지형 + 곡옥 장식
  IP 활용: ROYAL LINE 「신라 금관 소형 복제품」근거
  하린 캐릭터: 금색 화랑 갑옷 디자인 참고

황남대총:
  신라 최대 고분 (남분·북분 연결형)
  금관·유리구슬·금 장신구 대량 출토
  고증: 신라 귀족 복식 + 장신구 체계

금관총:
  금관 최초 출토 (1921년)
  이사지왕 명문 환두대도 출토
  IP 활용: 하린 장검 디자인 참고
```

### 경주 왕경 발굴

```
황룡사지:
  9층 목탑 추정 위치 발굴 완료
  기단 크기: 80m × 80m (목탑 규모 확인)
  IP 활용: 신라 Section 3 전시 1:20 모형 근거

첨성대:
  현존 유일 — 실물 직접 고증 가능
  건축 방식: 화강암 362개 쌓기
  IP 전시: 첨성대 1:20 모형 + AR 체험

월성 해자 발굴 (진행 중):
  신라 왕궁 월성 인근 해자 정밀 발굴
  목간(木簡) 다수 출토 — 신라 문서 행정 증거
  IP 활용: 신라 문서·행정 장면 소품 근거
```

## 가야 주요 발굴 유적

### 김해 가야 발굴

```
대성동 고분군 (김해):
  금관가야 왕릉급 고분군
  출토 유물:
    철갑·철정 다량 출토
    통형동기(筒形銅器): 일본 야마토와 교류 증거
    순장(殉葬) 흔적: 사람·말 함께 매장

철정(鐵鋌) 실물:
  가야 특유 판상 철 (두께 0.5cm, 길이 30cm 내외)
  IP 활용:
    ROYAL LINE 「가야 철정 미니 레플리카」원형
    니문 캐릭터 굿즈 핵심 소재

봉황동 유적 (김해):
  금관가야 왕도 추정 생활 유적
  목책·수혈 건물지·우물 출토
  IP 게임: 가야 초기 도시 건설 배경
```

### 고령 대가야 발굴

```
지산동 고분군 (고령):
  대가야 왕릉급 고분 44기
  출토: 금동관·금귀걸이·유리구슬
  순장 최대 규모: 40인 이상 순장 확인

대가야 박물관 소장품:
  가야금 관련 유물: 악기 부속품 추정 출토물
  IP 활용: 니문 가야금 고증 참고

창녕 비화가야:
  비화가야 권역 출토 마갑(馬甲) — 말 갑옷
  가야 기마 문화 증거
  IP 게임: 가야 기마 유닛 역사 근거
```

## 발굴 미확인 항목 (창작 허용 범위)

```
불확실 항목 (IP 창작 허용, 단 고지 필요):
  안시성 정확 위치
  을지문덕 외모·생애 세부 사항
  계백의 처자 관련 세부 기록
  가야금 우륵 작곡 12곡 원형 악보
  고구려 복식 색채 (일부 추정)

완전 창작 항목 (역사 근거 없음, 명시 필요):
  4인 주인공 고루·아랑·하린·니문 전 생애
  살수 댐 조작 담당자 실명
  안시성 성주 실명 및 활동

고고학자문 승인 프로세스:
  소품·의상·건물: ADV-ARCH 사전 승인 필수
  유물 복제 상품: 실물 치수·형태 대조 확인
  전시 모형: 발굴 도면 기반 제작 권고
```
