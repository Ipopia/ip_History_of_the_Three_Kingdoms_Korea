## 고구려 내부 관계망

### 왕실 계보
```
주몽(시조)
├── 유리왕(2대) — 부여에서 온 친아들
│   └── 대무신왕(3대)
│       └── ...
│           └── 고국원왕(16대) — 근초고왕에게 전사
│               └── 소수림왕(17대) — 불교 공인, 제도 정비
│                   └── 고국양왕(18대)
│                       └── 광개토대왕(19대) — 374~412
│                           └── 장수왕(20대) — 394~491
│                               └── ...
│                                   └── 영류왕(27대)
│                                       └── [연개소문에게 시해]
│                                           보장왕(28대, 마지막)
└── 온조(백제 건국) — 별도 왕통
```

### 핵심 관계
| 인물 A | 관계 | 인물 B | 서사적 의미 |
|--------|------|--------|-----------|
| 광개토대왕 | 아버지→아들 | 장수왕 | 정복→외교로의 전략 전환 |
| 영류왕 | 왕→신하 | 연개소문 | 신하가 왕을 죽인 역전 |
| 연개소문 | 아버지→장남 | 연남생 | 강한 아버지의 약한 후계자 |
| 연남생 | 형→동생 | 연남건 | 형제 내전 → 고구려 멸망 |
| 을파소 | 재상→왕 | 고국천왕 | 개혁가와 왕의 신뢰 관계 |

## 백제 내부 관계망

### 왕실 계보 (주요)
```
온조(시조)
├── 비류(형, 미추홀) — 실패 후 사망
└── ...
    └── 근초고왕(13대) — 전성기
        └── ...
            └── 개로왕(21대) — 한성에서 전사
                └── 문주왕(22대) — 웅진 천도
                    └── ...
                        └── 무령왕(25대) — 중흥
                            └── 성왕(26대) — 관산성 전사
                                └── 위덕왕(27대)
                                    └── ...
                                        └── 의자왕(31대, 마지막)
                                            └── 부여융(태자)
```

### 핵심 관계
| 인물 A | 관계 | 인물 B | 서사적 의미 |
|--------|------|--------|-----------|
| 근초고왕 | 정복자→피정복자 | 고국원왕(고구려) | 100년 원한의 시작 |
| 개로왕 | 신뢰→배신당함 | 도림(고구려 스파이) | 우정으로 포장된 첩보 |
| 성왕 | 동맹→배신당함 | 진흥왕(신라) | 나제동맹 붕괴 |
| 의자왕 | 왕→신하 | 계백 | 마지막 왕의 마지막 충신 |
| 복신 | 동지→갈등 | 부여풍 | 부흥운동 내부 분열 |

## 신라 내부 관계망

### 주요 계보
```
박혁거세(시조, 박씨)
└── ...
    내물마립간(김씨 세습 확립)
    └── ...
        └── 법흥왕(불교 공인)
            └── 진흥왕(24대) — 한강+가야 정복
                └── ...
                    └── 진평왕(26대)
                        └── 선덕여왕(27대, 딸)
                            └── 진덕여왕(28대, 사촌)
                                └── [성골 단절]
                                    무열왕 김춘추(29대, 진골)
                                    └── 문무왕(30대)
```

### 핵심 관계
| 인물 A | 관계 | 인물 B | 서사적 의미 |
|--------|------|--------|-----------|
| 선덕여왕 | 왕→신하 | 비담 | 여왕을 공격한 신하의 반란 |
| 김춘추 | 평생 동반자 | 김유신 | 외교가+장군의 완벽한 조합 |
| 김유신 | 장군→왕 | 무열왕 | 군사력으로 왕권을 뒷받침 |
| 무열왕 | 아버지→아들 | 문무왕 | 설계자→완성자 |
| 관창 | 화랑→순국 | 김유신 | 죽음이 전략이 된 비극 |

## 삼국 간 주요 관계

### 고구려-백제 관계
```
근초고왕(백제) [371년 고국원왕 전사] → 100년 원한 시작
장수왕(고구려) [475년 한성 함락, 개로왕 전사] → 원한 청산
성왕(백제) [554년 관산성, 신라에 전사] → 신라가 새 원한
```

**정서**: 불구대천지원수 → 후기 공동 멸망

### 백제-신라 관계
```
433년: 나제동맹 체결 — "공동의 적(고구려)이 만든 우정"
553년: 신라 한강 탈취 — 동맹 파기
554년: 관산성 — 성왕 전사, 백제-신라 불구대천
660년: 신라가 당과 협력해 백제 멸망
```

**정서**: 가장 복잡한 관계 — 동맹, 배신, 원한, 공멸

### 고구려-신라 관계
```
400년: 광개토대왕이 신라 구원 → 신라 종속적 관계
5세기: 신라 고구려 영향권
6세기: 신라 성장 → 경쟁
7세기: 나당동맹 → 고구려 멸망
```

**정서**: 은인→종속→경쟁→적대→공멸

### 신라-가야 관계
```
400년: 고구려의 신라 구원 → 가야 타격 → 신라-가야 관계 악화
562년: 신라 가야 완전 병합
우륵: 가야 음악가가 신라에 가야금 전수
```

**정서**: 흡수와 문화 통합 — 패자가 승자에게 남긴 유산

## 당·왜·수와의 관계

### 고구려-수·당 관계
```
598~614: 고구려-수 전쟁 4차례 — 고구려 승리
645: 당 태종 안시성 포위 — 고구려 승리
668: 고구려 멸망 — 당 최종 승리
```

### 백제-왜 관계
```
4세기: 왕인 박사, 아직기 → 일본 한자·유교 전파
538/552년: 불교 공식 전파
588년: 백제 기술자 집단 도일 → 아스카 문화 기반
663년: 백강 해전 — 왜군 백제 부흥 지원 → 패배
```

### 신라-당 관계
```
648년: 나당동맹 체결
660~668년: 공동으로 백제·고구려 멸망
670~676년: 나당전쟁 — 신라 승리
```

## 세대 간 관계 테마

### "아버지와 아들"

| 아버지 | 아들 | 관계의 의미 |
|--------|------|-----------|
| 주몽 | 온조 | 아들이 다른 나라를 세우다 |
| 광개토대왕 | 장수왕 | 칼의 유산을 외교로 전환 |
| 연개소문 | 연남생 | 강한 독재자의 약한 후계자 |
| 무열왕(김춘추) | 문무왕 | 아버지의 설계를 아들이 완성 |
| 의자왕 | 부여융 | 아버지의 왕국을 아들이 당에 바치다 |
