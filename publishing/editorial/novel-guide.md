## 소설 시리즈 구조 (두 시리즈 병행)

### 시리즈 1 — 「삼국(三國): 천하의 봄」 (정통 장편 소설)

```
시리즈명: 삼국(三國): 천하의 봄
영문: THREE KINGDOMS: SPRING OF HEAVEN
형식: 정통 역사 소설 — 3인칭 제한 시점, 4인 교차 서술
총 분량: 본편 5권 + 스핀오프 11권 (총 16권)
출판: 정가제 단행본 + 전자책 동시 출간
판형: 신국판 (152×225mm) / 각 권 350~450페이지
작업 파일: publishing/novel/three-kingdoms-spring/
현재 상태: 1권 12화 draft 완성 (60-70%)
```

**권별 구성**:
```
본편:
  1권 「철의 성벽」— 고구려 (시즌 1 전반: 598~612)  ← 진행 중
  2권 「살수의 노래」— 고구려 (시즌 1 후반: 612~645)
  3권 「연등과 황금」— 백제·신라 (시즌 2: 632~660)
  4권 「전쟁의 계절」— 삼국 (시즌 3 전반: 660~668)
  5권 「강은 기억한다」— 통일 (시즌 3 후반: 668~676)

스핀오프:
  고구려 외전 「철의 성벽」3권
  백제 외전 「연등은 꺼지지 않는다」3권
  신라 외전 「황금의 죄」3권
  가야 외전 「12번째 현」2권
```

### 시리즈 2 — 「강은 기억한다」 (옴니버스 단편집)

```
시리즈명: 강은 기억한다
영문: THE RIVER REMEMBERS
형식: 옴니버스 단편집 — 4인 복수 시점, 각 장이 독립된 에피소드
총 분량: 24장 (장당 8,000~15,000자)
특징: BC37년(건국)~676년(통일) 700년 전 시간대 아우름
작업 파일: publishing/novel/river-remembers/
현재 상태: 4~24장 완성 (1~3장 재집필 필요)
```

**장별 구성** (대표):
```
1~3장: (재집필 필요) — 주몽 건국기 서사
4~6장: 비류수의 맹세 — 건국 로맨스
7~9장: 온조와 비류 — 백제 건국 복선
10~15장: 살수와 평양 — 612~642년
16~24장: 안시성~백제 멸망 — 645~660년
```

## 문체 기준

### 기본 문체

```
시점: 3인칭 제한 시점 (본편) / 1인칭 (스핀오프)
시제: 과거형 기본 (현재형 금지 — 역사물 톤 유지)
문장 길이: 평균 15~25자 (짧은 문장 선호)
단락 길이: 3~7문장 (과도한 묘사 지양)

톤:
  전투 씬: 짧고 역동적 — 동사 중심
  감정 씬: 절제된 서정 — 여백 활용
  정치 씬: 건조하고 날카로운 — 대사 중심
  일상 씬: 따뜻하고 감각적 — 오감 묘사
```

### 왕국별 문체 변주

```
고구려 챕터:
  문장: 굵고 직선적
  묘사: 거대함·무게감 강조 (성벽·군대·겨울)
  예시: 「성벽이 흔들렸다. 고루는 칼을 뽑았다.
        바람이 차가웠다. 그것은 바람이 아니었다.」

백제 챕터:
  문장: 유려하고 섬세
  묘사: 문화·빛·소리 강조 (연등·서고·향)
  예시: 「아랑은 죽간 위에 먹을 찍었다.
        기록한다는 것은 기억한다는 것이었다.
        기억한다는 것은 사라지지 않는다는 것이었다.」

신라 챕터:
  문장: 날카롭고 빠른
  묘사: 속도·결단·금빛 강조 (말·활·금관)
  예시: 「하린은 말에 올랐다.
        화살 세 개를 동시에 뽑았다.
        생각할 시간은 없었다.」

가야 챕터:
  문장: 짧고 시적
  묘사: 소리·자연·여백 강조 (가야금·강·바람)
  예시: 「현이 울렸다.
        강이 대답했다.
        아무도 듣지 않았다.」
```

## 챕터 구조

### 표준 챕터 포맷

```
챕터 헤더:
  제N장 — 「챕터 부제」
  에피그래프: 역사 기록 인용 또는 캐릭터 독백 1~2줄

챕터 길이: 8,000~12,000자 (원고지 40~60매)
씬 구성: 2~4씬 / 챕터
씬 전환: *** (별표 3개) 또는 공백 2줄

챕터 종결:
  클리프행어 (긴장 유지) — 전체의 60%
  감정 여운 (서정적 마무리) — 전체의 30%
  시간 점프 암시 — 전체의 10%
```

### 권별 챕터 수

```
각 권: 20~25챕터
프롤로그: 각 권 필수 (시점 인물의 핵심 장면 플래시포워드)
에필로그: 각 권 필수 (다음 권 연결 또는 회고)
인터루드: 1~2개 (다른 시점 인물의 단독 챕터)
```

## 대사 작성 기준

### 역사 인물 대사

```
원칙:
  삼국사기·삼국유사 기록 대사: 원문 유지 (한자 병기)
  예시: 을지문덕 한시 — 「神策究天文 妙算窮地理…」

  기록 없는 대사: 인물 성격·시대 어투 반영 창작
  기준: 현대 한국어 기반 + 고어적 뉘앙스
  금지: 완전한 고어 (독자 접근성 저해)
  금지: 현대 유행어·속어

대사 비율: 전체 분량의 25~35%
독백: 최소화 (1인칭 스핀오프 제외)
```

### 인물별 어투

```
고루: 짧고 단호한 문장. 경어 사용 적음.
  예: 「가겠습니다.」 「됐다.」 「그건 내가 한다.」

아랑: 정중하고 관찰적. 기록자의 시선.
  예: 「기록하겠습니다.」 「제가 본 것은 이렇습니다.」

하린: 직설적이고 감정적. 질문이 많음.
  예: 「이게 옳습니까?」 「왜 그래야 합니까?」

니문: 말이 적고 감각적. 은유가 많음.
  예: 「소리가 달라졌습니다.」 「강이 슬퍼하고 있어요.」

을지문덕: 위엄 있고 시적.
  예: 「물은 높은 곳에서 낮은 곳으로 흐른다. 전쟁도 마찬가지다.」

계백: 비장하고 간결.
  예: 「검을 들어라.」 「돌아갈 곳은 없다.」
```

## 전투 씬 작성법

```
원칙:
  개인 전투: 동작 하나하나 묘사 (슬로모션 효과)
  대규모 전투: 전체 → 부분 → 개인 줌인 구조
  잔혹성: 15세 등급 — 과도한 유혈 금지, 암시적 표현
  소리: 전투 SFX 의성어 활용 (검격·화살·함성)

구조:
  1. 전투 직전 정적 (긴장)
  2. 첫 충돌 (충격)
  3. 혼전 (속도감)
  4. 전환점 (전술·영웅적 행동)
  5. 결과 (승패 + 감정)

금지:
  ✗ 영웅 1인이 수백 명 격파 (과장)
  ✗ 전투 중 긴 대사 (비현실)
  ✗ 상세한 고어 묘사 (등급 위반)

예시 (살수대첩 — 수문 개방):
  「고루는 레버에 손을 얹었다.
   떨리지 않았다.
   당겼다.
   처음에는 아무 일도 일어나지 않았다.
   그리고 소리가 왔다.
   산이 움직이는 것 같았다.
   물이 아니었다. 세상이 무너지는 소리였다.」
```

## 역사 고증 표기법

```
본문 내 역사 주석:
  금지: 각주·미주 (소설 몰입 저해)
  허용: 작가 후기에서 역사 해설 (각 권 말미 10~15페이지)

작가 후기 구성:
  1. 역사적 사실과 창작의 경계 설명
  2. 주요 역사 인물 실제 기록 소개
  3. 참고 문헌 목록
  4. 다음 권 예고

고유명사 표기:
  첫 등장 시: 한글(한자) — 예: 을지문덕(乙支文德)
  이후: 한글만
  glossary.md 표기 절대 준수
```

## 제작 프로세스

```
1단계 — 시놉시스: 권별 전체 줄거리 (5,000자)
2단계 — 챕터 아웃라인: 전 챕터 요약 (챕터당 200자)
3단계 — 초고: 1일 원고지 30매 목표
4단계 — 자체 교정: 작가 1차 수정
5단계 — 편집: 편집자 구조·문체·팩트 체크
6단계 — QA: QA-RESEARCH 역사 고증 / QA-STYLE 문체 검토
7단계 — 교열·교정: 오탈자·문법·표기 통일
8단계 — 최종 확인: 작가 + 편집자 최종 승인
9단계 — 조판: 디자인팀 조판·표지
10단계 — 인쇄·출간

일정 (권당):
  시놉시스~아웃라인: 2주
  초고: 8~10주
  편집~QA: 4주
  교열~출간: 4주
  합계: 약 5개월/권
```
