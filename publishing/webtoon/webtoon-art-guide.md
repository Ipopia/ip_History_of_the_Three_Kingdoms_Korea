## 웹툰 아트 방향

```
스타일: 세미 리얼리스틱 (극화체)
톤: 역사 대하 + 인물 감정 중심
참조 작품 (스타일 레퍼런스):
  「바른연애 길잡이」수준 인체 비율 + 「나 혼자만 레벨업」배경 퀄리티
  역사물 톤: 「킹덤: 아신전」웹툰 + 「삼국지 톡」고증 수준

핵심 원칙:
  ① 역사 고증 기반 비주얼 (art-bible.md 준수)
  ② 왕국별 색채 일관성 (color-palette.md 기준)
  ③ 감정 표현 > 액션 묘사 (인물 중심)
  ④ 세로 스크롤 최적화 (모바일 퍼스트)
```

## 인체 비율 & 캐릭터 작화

### 기본 인체 비율

```
주인공 4인: 8등신 (이상화된 리얼리스틱)
역사 인물 (을지문덕·계백 등): 8~8.5등신 (위엄 강조)
일반 조연: 7.5등신
배경 인물(엑스트라): 7등신 (간략화 허용)

얼굴 비율:
  눈: 사실적 크기 (일본 만화식 과장 금지)
  코·입: 사실적 묘사 유지
  표정: 미세 표정 변화 중시 (눈썹·입꼬리 디테일)
```

### 캐릭터별 작화 포인트

```
고루 (高婁):
  체형: 넓은 어깨 + 탄탄한 근육 (과장 금지)
  얼굴: 날카로운 턱선 + 깊은 눈매
  특징 디테일: 살수대첩 이후 좌측 관자놀이 작은 흉터
  표정 범위: 무표정~결의 (웃음 매우 드물게)
  의상 핵심: 고구려 청람 갑옷 + 환두대도

아랑 (阿郞):
  체형: 가녀린 체형 + 긴 손가락 (붓 작업 강조)
  얼굴: 둥근 이마 + 지적인 눈매 + 얇은 입술
  특징 디테일: 귀 뒤 항상 붓 꽂음
  표정 범위: 침착~걱정~비통 (감정 변화 섬세)
  의상 핵심: 백제 크림색 저고리 + 죽간 소지

하린 (夏麟):
  체형: 탄탄한 운동 체형 (여성 전사)
  얼굴: 강한 눈매 + 의지 넘치는 입매
  특징 디테일: 화랑 머리띠 + 활 항상 소지
  표정 범위: 자신감~분노~후회 (폭넓은 감정선)
  의상 핵심: 신라 황금빛 경갑 + 붉은 끈

니문 (尼文):
  체형: 마른 체형 + 긴 손가락 (가야금 연주자)
  얼굴: 부드러운 인상 + 깊은 눈동자 (슬픔 내재)
  특징 디테일: 반묶음 머리 + 가야금 항상 등에 짊어짐
  표정 범위: 고요~슬픔~결의 (표정 변화 느리고 깊게)
  의상 핵심: 가야 황토색 간소한 의상
```

## 배경 작화

### 왕국별 배경 스타일

```
고구려 배경:
  색조: 청람 (#2F4F7F) 기조 + 회색 석조
  건축: 거대한 성벽·석조 요새 (디테일 높음)
  자연: 넓은 평원 + 강·산악 + 안개
  분위기: 장엄하고 무거운 공기

백제 배경:
  색조: 황금 (#B8960C) + 크림 (#F5E6C8)
  건축: 정교한 목조 건축 + 처마 장식 + 연등
  자연: 금강·백마강 수면 + 꽃잎 + 연등 야경
  분위기: 따뜻하고 문화적인 공기

신라 배경:
  색조: 황금 (#FFD700) + 청동
  건축: 황룡사·첨성대 + 왕궁 + 화랑 훈련장
  자연: 황금빛 들판 + 역광 + 경주 분지
  분위기: 밝고 역동적

가야 배경:
  색조: 황토 (#C8A96E) + 녹색
  건축: 소박한 토성·목조 + 대장간
  자연: 낙동강 황혼 + 대나무 숲 + 고분
  분위기: 서정적이고 쓸쓸한 공기
```

### 배경 디테일 등급

```
A등급 (풀 렌더링):
  주요 랜드마크 첫 등장 (안시성·사비성·황룡사)
  역사 이벤트 배경 (살수·황산벌·기벌포)
  캐릭터 감정 절정 씬 배경
  → 배경 단독 컷 허용 (세로 풀스크린)

B등급 (표준 렌더링):
  일반 대화·이동 씬 배경
  반복 등장 장소 2회차 이후

C등급 (간략 배경):
  긴박한 전투 중 배경 (스피드 라인·효과선)
  감정 내면 묘사 (배경 생략 → 단색 or 그라데이션)
```

## 컬러링 기준

```
컬러 방식: 풀 컬러 (전 화 기본)

색상 규칙:
  왕국별 공식 팔레트 (color-palette.md) 엄격 적용
  주야간: 주간 씬 = 기본 / 야간 씬 = 명도 30% 감소 + 블루 쉬프트
  전투 씬: 채도 올리고 대비 강화

특수 컬러링:
  플래시백: 채도 50% 감소 + 세피아 톤
  니문 가야금 씬: 배경 단색 처리 (황토 그라데이션)
  살수대첩 물: 파란색 → 붉은색 점진 변화 (혈흔 표현)

하이라이트 효과:
  금관·갑옷: 반사광 하이라이트 (백색 점)
  연등: 발광 효과 (주변 오렌지 글로우)
  가야금 현: 진동 표현 (블러 + 속도선)
```

## 레이아웃 & 연출

### 세로 스크롤 기준

```
캔버스:
  폭: 690px (네이버 웹툰 기준) / 800px (레진 등)
  화당 세로 길이: 15,000~25,000px
  해상도: 72dpi (웹 최적화) / 300dpi (인쇄판 별도)

컷 구성:
  화당 평균: 60~80컷
  대화 씬: 소형 컷 + 클로즈업 위주
  액션 씬: 대형 컷 (풀폭 사용) + 세로 롱컷
  감정 절정: 풀스크린 1컷 (세로 전체 화면)
```

### 연출 기법

```
살수대첩 전투 연출:
  세로 롱컷: 수문 개방 → 물 흐름 → 군사 휩쓸림
  → 스크롤 자체가 물 흐름 체감

가야금 연주 연출:
  현 진동: 가로 속도선 + 음파 파동 시각화
  연주 중 배경: 점진적 배경 변화 (현실 → 가야 과거)
  무음 컷: 빈 말풍선 (소리 없는 표현)

황산벌 전투 연출:
  5,000 결사대 행진: 세로 대형 컷 (인물 군상)
  계백 가족 장면: 소형 컷 교차 (감정 대비)
  전투 결과: 흑백 전환 → 천천히 컬러 복귀

감정 절정 연출:
  고루 결의: 눈 클로즈업 → 동공 반사에 강물 비침
  아랑 비통: 눈물 한 방울 → 죽간 위에 떨어짐 → 잉크 번짐
  니문 마지막 연주: 가야금 현 끊어짐 → 화면 백색 전환
```

## 효과음 & 텍스트

```
효과음 표기:
  한국어 의성어 기본: 쿠과광! / 철컥! / 찰랑~
  전투: 굵은 고딕 + 왕국 ACCENT 색상
  자연: 가는 손글씨체 + 연한 색상

대사 말풍선:
  일반 대사: 둥근 사각형 (흰색 배경)
  독백·내레이션: 사각형 (왕국 색상 테두리)
  역사 해설: 죽간 모양 상자 (갈색 텍스처)
  감정 강조: 말풍선 테두리 두껍게 + 진동 효과

폰트:
  대사: 나눔명조 또는 전용 웹툰 폰트
  효과음: 전용 손글씨 폰트
  역사 해설: 궁서체 또는 서예 느낌 폰트
  영문판: Noto Serif (대사) / 커스텀 (효과음)
```

## 제작 파이프라인

```
주간 1화 제작 공정:
  Day 1: 콘티 작성 (작가) → 편집팀 검토
  Day 2~3: 펜선 작업 (메인 작화가)
  Day 3~4: 배경 작업 (배경 작화가)
  Day 4~5: 컬러링 (컬러리스트)
  Day 5: 효과음·말풍선·텍스트 삽입 (편집)
  Day 6: QA-CONTINUITY 검수 + ADV-HISTORY 고증 확인
  Day 7: 최종 수정 → 업로드

인력:
  메인 작화가: 1명 (캐릭터)
  배경 작화가: 1~2명
  컬러리스트: 1명
  편집·레터링: 1명
  합계: 4~5명 (주간 1화 기준)
```
