# 캐릭터 언락 가이드 — 삼국(三國) 게임

**참조 문서**: `game-design-document.md`, `battle-system-detail.md`, `unit-design-guide.md`
**작성**: 게임본부 기획팀 (GAME-DESIGN)
**적용**: 삼국(三國) 전략 RPG — 캐릭터 획득·성장 전체 가이드

## 캐릭터 획득 시스템

```
획득 방식 4종:
  A. 스토리 클리어 (무료): 스토리 진행 시 자동 획득
  B. 역사 미션 (무료): 역사 재현 미션 완료 시 보상
  C. 뽑기 (가챠): 확률형 아이템 (유료·무료 혼합)
  D. 교환소: 조각 모으기 → 캐릭터 교환

무과금 플레이어 보장:
  S급 역사 인물 1명: 스토리 완주 시 선택 획득
  A급 주인공 4인: 스토리 진행 중 100% 무료 획득
  B급 조연: 역사 미션 클리어로 대부분 획득 가능

유료 아이템:
  추가 스킨·의상: 왕국별 특별 외형
  가속 아이템: 성장 촉진 (시간 단축)
  추가 가챠: 한정 캐릭터·스킨
```

## A급 주인공 4인 — 획득 경로

### 고루 (고구려 전사)

```
기본 획득: 고구려 캠페인 1화 시작 시 자동 지급
등급: A급 → 스토리 진행으로 S급 승급 가능

성장 단계:
  Lv.1~20: 「을지문덕의 제자」— 기초 전투
  Lv.21~40: 「살수의 전사」— 살수대첩 클리어 시 해금
  Lv.41~60: 「안시성의 방벽」— 안시성 미션 클리어 시
  Lv.61~80: 「고구려의 마지막」— 시즌 2 스토리 진행
  Lv.Max: 「강의 기억」— S급 승급 완료

S급 승급 조건:
  1. Lv.80 달성
  2. 을지문덕 S급 카드 획득
  3. 「을지문덕의 가르침」퀘스트 완료
  4. 승급 재료 (삼족오 결정석 × 5)

S급 고루 고유 스킬:
  「강은 기억한다」: 전투 종료 후 사기 전체 회복
  「을지문덕의 유언」: 패퇴 불가 (영구 지속)

특별 스킨:
  기본: 고구려 경갑 (찰갑)
  ★ 한정: 「살수대첩 기념」— 강물 효과 갑옷 (드라마 방영 이벤트)
  ★ 한정: 「30년 후」— 중년 고루 (시즌 2 연동)
```

### 아랑 (백제 기록자)

```
기본 획득: 백제 캠페인 2화 시작 시 자동 지급
등급: A급 (비전투 특화 캐릭터)

역할: 전투보다 정보·지원 특화
  - 전투 중 적 정보 자동 수집
  - 아군 전체 명중률 +10% (「기록대」스킬)
  - 외교 교섭 씬에서 성공률 +30%

성장 단계:
  Lv.1~20: 「서생의 붓」— 기초 정보 수집
  Lv.21~40: 「성충의 제자」— 백제 내정 미션 클리어
  Lv.41~60: 「비밀 기록자」— 성충 사망 이벤트 후
  Lv.61~80: 「역사의 증인」— 시즌 2 스토리
  Lv.Max: 「강이 듣는다」— 전 캠페인 기록 완료

아랑 전용 시스템:
  「아랑의 일지」: 전투 중 수집한 적 정보 영구 저장
  이미 클리어한 스테이지 재도전 시 보너스 정보 제공
  「역사 아카이브」: 특정 역사 이벤트 씬 해금 (컬렉션)

특별 스킨:
  기본: 백제 문관 관복 (왕실금)
  ★ 한정: 「금강의 기록」— 금강 야경 배경 (서고 씬 재현)
```

### 하린 (신라 화랑)

```
기본 획득: 신라 캠페인 3화 시작 시 자동 지급
등급: A급 → 스토리 진행으로 A+ 강화 가능

성장 단계:
  Lv.1~20: 「화랑 수련생」— 기초 검술
  Lv.21~40: 「선덕여왕의 화랑」— 선덕여왕 임명 이벤트
  Lv.41~60: 「황산벌의 전사」— 황산벌 미션 클리어
  Lv.61~80: 「통일을 묻는 자」— 시즌 2 스토리
  Lv.Max: 「검의 의미」— 전 화랑 미션 완료

하린 전용 시스템:
  「세속오계(世俗五戒)」버프:
    ① 사군이충(事君以忠): 아군 사기 +20%
    ② 사친이효(事親以孝): 보급 소모 -10%
    ③ 교우이신(交友以信): 동맹군 강화 +15%
    ④ 임전무퇴(臨戰無退): 패퇴 저항 +50%
    ⑤ 살생유택(殺生有擇): 포로 생존율 +30%
  조건: 스테이지별 하나씩 해금

특별 스킨:
  기본: 신라 화랑 황금 갑옷
  ★ 한정: 「선덕여왕의 검」— 하사검 특별 이펙트
  ★ 한정: 「황산벌 결전」— 피 묻은 전투 스킨 (시즌 2)
```

### 니문 (가야 악사)

```
기본 획득: 가야 캠페인 4화 시작 시 자동 지급
등급: A급 (지원·사기 특화)

역할: 직접 전투보다 아군 사기·강화 특화
  - 「악대(樂隊)」유닛 지휘 → 아군 사기 회복
  - 전투 중 「12번째 악곡」연주 → 강화 효과
  - 가야 유닛 공격력 +20% (자국 부대 시너지)

성장 단계:
  Lv.1~20: 「가야금의 학생」— 1~11번째 악곡 해금
  Lv.21~40: 「우륵의 후계자」— 가야 역사 미션 클리어
  Lv.41~60: 「신라 궁중 악사」— 가야 멸망 이벤트 후
  Lv.61~80: 「사라진 왕국의 노래」— 시즌 2 스토리
  Lv.Max: 「12번째 완성」— 최종 이벤트 클리어

니문 전용 시스템:
  「12악곡 시스템」:
    전투 클리어 시 악곡 조각 수집
    12개 악곡 완성 시 최강 버프 「가야금의 완성」해금
    악곡 1~11개: 단계별 사기 보너스
    악곡 12개 완성: 아군 전체 공격·방어 +30% (3턴)

특별 스킨:
  기본: 가야 악사 토황 의상
  ★ 한정: 「낙동강의 연주」— 강가 연주 이펙트
  ★ 한정: 「완성의 순간」— 12번째 현 튕기는 엔딩 이펙트
```

## S급 역사 인물 — 획득 경로

### 을지문덕 (고구려 명장)

```
획득: 「살수대첩 재현」역사 미션 S등급 클리어
등급: S급 (최고 등급)

스탯: 통솔96 / 무력78 / 지략99 / 정치85 / 매력88

고유 스킬:
  「7번 물러서라」: 고의 후퇴 시 아군 피해 0%
  「한시(漢詩)」: 적 장수 혼란 (2턴, 지략 대결)
  「강의 가르침」: 고루 동행 시 고루 전 능력 +30%

획득 불가 루트:
  가챠에서는 나오지 않음 (역사 미션 전용)
  이유: 역사 인물 존중 → 돈으로 살 수 없는 캐릭터

스토리 연동:
  을지문덕 획득 후 고루와 함께 출전 시 특별 대화 발생
  EP01~07 스토리 씬 재감상 가능 (아카이브 해금)
```

### 연개소문 (고구려 대막리지)

```
획득: 시즌 2 고구려 캠페인 완주 후 선택 보상
등급: S급

스탯: 통솔95 / 무력97 / 지략90 / 정치70 / 매력82

고유 스킬:
  「5자루 칼」: 근접 5연속 공격 (매 턴)
  「철혈 통치」: 아군 탈영 불가 (부정적 특성: 사기 -5)

획득 조건: 고구려 시즌 2 스토리 완주 (의무 스토리 포함)
복잡한 캐릭터 포지션: 「악역이 아닌 고구려의 마지막 희망」으로 묘사

### 계백 (백제 장군)

```
획득: 「황산벌 결사전」역사 미션 S등급 클리어
등급: S급

스탯: 통솔88 / 무력95 / 지략82 / 정치65 / 매력90

고유 스킬:
  「결사 (決死)」: 아군 패배 불가 (최후 5턴)
  「5,000 vs 50,000」: 병력 열세 시 공격력 증가 (최대 +100%)

특별 기록:
  계백 획득 시 「황산벌 역사 해설」자동 해금
  계백으로 황산벌 미션 재도전 가능
  계백 팀으로 신라군 격퇴 달성 시 「역사 변경」업적

### 양만춘 (안시성주)

```
획득: 「안시성 88일 방어」미션 완료
등급: A+급

스탯: 통솔90 / 무력85 / 지략88 / 정치80 / 매력85

고유 스킬:
  「성벽의 주인」: 방어전 +50% (공성전 특화)
  「이름 없는 영웅」: 아군 부대장 전사 시 사기 유지
```

## 캐릭터 관계 시스템

```
시너지 관계:
  을지문덕 + 고루: 「스승과 제자」+30% 모든 스탯
  성충 + 아랑: 「기록의 사명」정보 수집 속도 2배
  선덕여왕 + 하린: 「왕의 화랑」사기 +40%
  우륵(가야금 악성) + 니문: 「음악의 계승」악곡 완성 가속

적대 관계:
  고루 + 연개소문: 동일 팀 편성 시 사기 -10% (서사 반영)
  하린 + 계백: 황산벌 미션에서 특별 대화 발생

4인 동시 출전:
  고루+아랑+하린+니문 4인 동시 편성:
  「삼국의 기억」특별 버프 발동
  → 전 아군 사기 +50%, 전 적군 사기 -20%
  → 메인 테마 OST 자동 재생
```

## 컬렉션 & 도전 과제

```
역사 탐험 컬렉션:
  역사 인물 전원 획득: 「삼국 역사가」칭호
  4인 주인공 S급 승급: 「강의 증인」칭호
  역사 미션 전 S등급: 「삼국사기의 기록」칭호

스킨 컬렉션:
  한 캐릭터 스킨 3개 이상: 「왕국의 수집가」
  전 왕국 한정 스킨 획득: 「4왕국 보물」칭호

특별 도전:
  계백으로 황산벌 신라 격퇴: 「역사는 다를 수 있었다」
  니문 12악곡 완성: 「가야의 마지막 선율」
  수나라 113만 대군 보급 차단으로 격파: 「을지문덕의 전략」
```
