## 브랜드 코어

### 브랜드 에센스

```
브랜드 에센스 (Brand Essence):
「사라지지 않는 것들에 대한 이야기」

핵심 슬로건:
한국어: 「강은 기억한다」
영어:   「THE RIVER REMEMBERS」
일본어: 「川は記憶する」
중국어: 「江河銘記」

브랜드 약속 (Brand Promise):
역사는 지나가지만 이야기는 남는다.
삼국(三國)은 4~7세기 한반도를 살았던 모든 사람들의 기억이다.
우리는 그 기억을 되살린다.

브랜드 개성 (Brand Personality):
① 서사적 (Epic): 역사의 무게와 장엄함
② 감성적 (Emotional): 인간의 이야기, 보편적 감동
③ 지적 (Intellectual): 역사에 충실, 배움의 즐거움
④ 역동적 (Dynamic): 전쟁·음악·외교의 긴장감
```

### 브랜드 포지셔닝

```
포지셔닝 스테이트먼트:
「역사에 충실하되 현대적인, 장엄하되 인간적인,
 한국의 것이되 세계가 공감할 수 있는 — 삼국(三國)」

경쟁 포지셔닝:
- vs. 일반 사극: 역사 고증 + 현대 감성 + 글로벌 포맷
- vs. 판타지 IP: 역사 기반 현실감 + 고증 권위
- vs. 해외 역사 드라마: 한국 고유 정서 + K-콘텐츠 파워

태그라인 (용도별):
드라마: 「네 왕국, 하나의 강」
게임: 「역사가 당신의 손 안에」
뮤지컬: 「천 년이 지나도 음악은 남는다」
글로벌: 「Korea's Epic — For the World」
```

## 시각 아이덴티티

### 로고 시스템

```
메인 로고:
한자 「三國」— 서예체 기반 현대 리디자인
영문 「SAMGUK」— 세리프 + 산세리프 조합
한글 「삼국」— 현대 고딕 + 붓글씨 혼합

로고 변형:
풀 로고: 한자+영문 수평 배치 (공식 문서)
아이콘 로고: 「三」자 단독 + 삼족오 통합 (앱·아이콘)
엠블럼: 삼족오+봉황+금관+철 4요소 원형 배치 (공식 인장)

로고 보호 공간:
로고 높이의 1/2 이상 여백 확보
최소 크기: 인쇄 20mm / 디지털 80px

사용 금지:
로고 회전·변형·왜곡
공식 색상 외 적용
배경 색상 명도 차이 40% 미만
```

### 브랜드 모티프 라이브러리

```
공식 모티프 (사용 우선순위):

① 삼족오 (三足烏): 고구려·IP 전체 대표 심볼
   - 추상화 버전: 세 선으로 단순화
   - 사실화 버전: 세부 묘사 (프리미엄 굿즈)

② 봉황 (鳳凰): 백제·문화·예술
   - 날개 펼친 봉황 (동적)
   - 앉은 봉황 (정적, 고급)

③ 금관 (金冠): 신라·왕권·황금
   - 출자형 실루엣 (아이콘화)
   - 전체 관 (풀 일러스트)

④ 철정 (鐵鋌): 가야·강인함
   - 납작한 철판 형태
   - 제철 불꽃 조합

⑤ 강 (江): IP 공통 핵심 모티프
   - 수묵화 물결 패턴
   - 한 줄 직선 흐름 (미니멀)

모티프 조합 규칙:
단일 왕국 콘텐츠: 해당 왕국 모티프만
전체 IP 콘텐츠: 삼족오 (대표) 또는 4모티프 조합
```

- 과도한 민족주의 표현
- 타 국가 역사 비하 표현

## 캠페인 아이덴티티

### 론칭 캠페인 — 「강이 기억하기 시작했다」

```
캠페인 컨셉:
「당신이 잊었던 역사가 기억을 되찾는다」

핵심 카피:
한국어: 「천 년이 지났다. 강은 기억하고 있었다.」
영어: 「A thousand years have passed. The river still remembers.」

비주얼 컨셉:
현대 도시 (서울·경주·부여) + 삼국 역사 장면 오버레이
강물이 흐르며 현재와 과거를 연결하는 이미지

미디어 믹스:
OOH (옥외광고): 경복궁·경주·부여 주요 지점
디지털: 유튜브 마스트헤드 + 틱톡 트렌드
TV: 지상파 + 넷플릭스 예고편
SNS: 인스타그램 스토리 AR 필터 연동

```

### 시즌 캠페인 — 「왕국을 선택하라」

```
캠페인 컨셉:
게임·굿즈 발매 연동 — 팬이 왕국 소속감 선택

핵심 카피: 「당신은 어느 왕국의 사람입니까?」

4왕국 캠페인 각각:
고구려: 「나는 기억하겠다 — 고구려인」
백제: 「나는 기록하겠다 — 백제인」
신라: 「나는 두려워하지 않겠다 — 신라인」
가야: 「나는 노래하겠다 — 가야인」

활용:
왕국 키트 박스 (굿즈)
SNS 왕국 프레임 필터
게임 왕국 선택 캠페인 연동
```
