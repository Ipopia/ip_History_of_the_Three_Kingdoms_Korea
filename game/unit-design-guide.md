## 유닛 설계 철학

삼국 IP 게임의 유닛은 **역사적 고증 + 게임플레이 재미 + 왕국 정체성** 세 요소의 균형이다. 단순한 스탯 숫자가 아닌, 각 왕국의 문화·전술·미학이 유닛 디자인에 반영된다.

```
유닛 설계 원칙:
1. 왕국 차별화 — 고구려·백제·신라·가야가 각각 뚜렷이 다르다
2. 역사 고증 — 실존 병과·전술·무기 기반
3. 레전더리 > 영웅 > 일반 계층 구조
4. 비주얼 일관성 — 왕국 색상 팔레트·문양 적용
5. 카운터 시스템 — 상성이 명확해 전략성 확보
```

---

## 유닛 등급 체계

```
등급 구조 (5단계):
★★★★★ LEGENDARY — 역사적 영웅 (광개토대왕·선덕여왕·계백·우륵)
★★★★  HERO       — 명장·창작 인물 (고루·아랑·니문)
★★★   ELITE      — 정예 병과 (개마무사·화랑·결사대)
★★    ADVANCED   — 숙련 병사 (기마병·수군·궁수)
★     BASIC      — 기본 병사 (보병·창병·향토병)

획득 방법:
LEGENDARY: 스토리 완료 보상 + 가챠 (0.5%)
HERO: 캠페인 보상 + 가챠 (3%)
ELITE: 레이드 보상 + 가챠 (15%)
ADVANCED: 일반 가챠 (30%) + 직접 제작
BASIC: 자동 지급 + 훈련소
```

### 고구려 유닛

#### LEGENDARY

```
[유닛명] 광개토대왕 (廣開土大王)
등급: ★★★★★ LEGENDARY
병과: 전략 군주
역할: 전방 돌파형 + 버프

스탯:
- HP: 15,000 / 공격: 850 / 방어: 600 / 속도: 55
- 사거리: 근거리

스킬:
1. 「호태왕의 호령」(패시브)
   — 고구려 유닛 전체 공격력 +25%
   — 조건: 아군 영토 내 전투 시

2. 「요동 원정」(액티브, 쿨타임 4턴)
   — 대상: 적 유닛 3×3 범위
   — 효과: 지형 무시 이동 + 연속 타격 3회
   — 시각: 광개토릉비 비문이 황금빛으로 빛남

3. 「삼족오의 가호」(궁극기, 쿨타임 8턴)
   — 효과: 아군 전체 HP 30% 회복 + 공격력 50% 상승 (2턴)
   — 시각: 하늘에서 삼족오가 내려와 불꽃을 뿌림

비주얼:
- 색상: 암청(#2F4F7F) + 혈홍 자수
- 갑옷: 개마무사 전신 철갑
- 무기: 환두대도 + 창
- 특징: 등에 삼족오 문양 망토
- 높이: 일반 유닛 대비 1.3배
```
