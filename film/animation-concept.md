# 애니메이션 콘셉트 — 삼국(三國) IP

**참조 문서**: `art-bible.md`, `drama-production-guide.md`, `character-sheets/`

## 애니메이션 전략 개요

삼국(三國) IP 애니메이션은 **드라마 IP의 확장**이자 **독립적 글로벌 콘텐츠**다. 드라마가 성인 타겟이라면, 애니메이션은 10대~30대까지 폭넓게 공략하며 특히 **일본·동남아 시장 선점**을 목표로 한다.

```
애니메이션 라인업:
TYPE A — 메인 시리즈: 삼국 TVA (12화×2쿨)
TYPE B — 단편 OVA: 왕국별 스핀오프 (각 45분)
TYPE C — 웹 애니: 유튜브 숏폼 (5분×24편)
TYPE D — 극장판: 살수대첩 (90분)
```

## TYPE A — 메인 TVA 시리즈

### 시리즈 개요

```
제목: 삼국 (三國) — 강은 기억한다
장르: 역사 액션 판타지
타겟: 13~30세 / 전 성별
화수: 시즌1 12화 + 시즌2 12화
러닝타임: 화당 23분 (ED 포함)
방영 포맷: TV방영 + OTT 동시 (크런치롤·넷플릭스 목표)

제작 방식:
국내 스튜디오 + 일본 협업 스튜디오
(일본 배급 및 품질 기준 충족)

언어:
원본: 한국어
더빙: 일본어·영어·중국어
자막: 10개 언어
```

### 아트 스타일

```
주요 레퍼런스:
- 「진격의 거인」— 전투 긴박감·무게감
- 「귀멸의 칼날」— 화려한 전투 이펙트
- 「모노노케 히메」— 역사 판타지 분위기
- 「바람의 검심」— 검투 액션 리듬

차별화 요소:
- 한국 전통 문양의 이펙트화 (삼족오·봉황·금관)
- 수묵화 기법 배경 (전통 한국화 감성)
- 철기 질감 표현 (가야 특화)
- 역사 유물 오마주 (금동대향로·첨성대 등)

캐릭터 디자인:
- 머리: 한국 전통 상투·쪽머리 (현대적 재해석)
- 의상: 역사 고증 기반 + 애니 가독성 조정
- 눈: 왕국별 아이 컬러 구분
  고구려 — 적갈색 / 백제 — 황금색
  신라 — 보라색 / 가야 — 토황색
```

### 시즌 1 구성

```
주인공: 고루 (창작 인물, 고구려 청년 장교)
서사 틀: 살수대첩 전후 고구려 중심 서사
서브 플롯: 백제·신라·가야 각 왕국 교차

에피소드 구성:
1화 「비류수의 아들」
   — 고루의 탄생과 고구려 훈련 장면
   — 을지문덕과의 첫 만남
   — 삼족오 전설 도입

2화 「요동의 바람」
   — 요동 원정 참전
   — 수나라의 위협 첫 등장
   — 아랑(창작, 백제 첩자) 등장 복선

3화 「사비성의 봉황」
   — 백제 사비성 시점 전환 (EP1)
   — 아랑 중심 서사
   — 의자왕 즉위 전야

4화 「황산벌 전야」
   — 백제 시점 (EP2)
   — 계백 등장·훈련 장면
   — 대야성 전투 전야

5화 「서라벌의 별」
   — 신라 시점 전환 (EP1)
   — 선덕여왕 등장
   — 첨성대 별 관측 장면

6화 「가야의 노래」
   — 가야 시점 (단독)
   — 우륵 중심 서사
   — 철정 교역과 남해의 풍경

7화 「강이 붉어지다」
   — 수나라 대군 침입
   — 고구려 방어선 위기
   — 고루와 을지문덕 작전 회의

8화 「살수의 결단」
   — 살수대첩 1부
   — 방류 작전 준비
   — 각 왕국 소식 교차편집

9화 「물이 기억하다」
   — 살수대첩 2부 (클라이맥스)
   — 수나라 군 전멸 장면
   — 을지문덕 시 낭독

10화 「넷의 강」
   — 고구려·백제·신라·가야 동시 진행
   — 각 왕국 현재 상황·긴장감
   — 시즌2 복선 배치

11화 「흐르는 것들」
   — 우륵 신라 귀화 결단
   — 소서노 계열 서사 완결
   — 선덕여왕 즉위 준비

12화 「강은 기억한다」
   — 시즌 1 피날레
   — 메인 테마 풀버전 재생
   — 시즌 2 예고 (황산벌·통일 전야)
```

### 오프닝·엔딩

```
오프닝 (OP):
제목: 「삼족오 (SAMJOKO)」
아티스트: K-POP 그룹 협업 (미정)
길이: 90초
비주얼:
- 메인 캐릭터 4명 각각 왕국 상징과 함께
- 삼국 지도 위 사건 하이라이트
- 클라이맥스: 삼족오·봉황·금관·가야금 결합 이미지

엔딩 (ED):
제목: 「강가에서 (By the River)」
아티스트: 한국 인디 발라드 (가야금 편곡 버전)
길이: 90초
비주얼:
- 각 화의 주역 캐릭터 수채화 스타일
- 해당 화의 강(江) 풍경
- 마지막: 강물이 흐르는 단순 배경
```

## TYPE B — 왕국별 OVA

### OVA-G 「삼족오의 하늘」(고구려)

```
부제: Eagle in the Sky
러닝타임: 45분
초점: 광개토대왕 원정 서사 집중
시점: 고루 시점 (TVA 보완)

줄거리:
광개토대왕 재위 17년, 백제 원정.
고루는 선봉대로 참전한다.
전장에서 삼족오 환상을 본다.
삼족오가 이끄는 방향으로 돌격 → 승리.

핵심 장면:
- 광개토대왕 직접 진두지휘 장면
- 고루와 광개토대왕의 단 한 번 대화
- 삼족오 환상 시퀀스 (3분, 가장 화려한 이펙트)

스타일: 고구려 벽화 애니메이션 기법 부분 활용
```

### OVA-B 「금동대향로의 향기」(백제)

```
부제: Fragrance of Bronze
러닝타임: 45분
초점: 의자왕 즉위 ~ 대야성 전투
시점: 아랑 시점

줄거리:
아랑은 백제 궁정의 내관이다.
의자왕의 신임을 얻지만 백제의 쇠락을 감지한다.
금동대향로 앞에서 홀로 기도하는 의자왕을 본다.
대야성 승전 소식이 오지만 아랑은 기뻐할 수 없다.

핵심 장면:
- 금동대향로 근접 3D 회전 시퀀스 (2분)
- 아랑과 의자왕의 밤 대화
- 사비성 황혼 파노라마

스타일: 따뜻한 황금빛 조명 / 느린 카메라 / 수채화 배경
```

### OVA-S 「첨성대의 밤」(신라)

```
부제: Night of Cheomseongdae
러닝타임: 45분
초점: 선덕여왕 즉위·예언
시점: 선덕여왕 직접 시점

줄거리:
선덕이 왕이 된 첫 밤, 첨성대에 오른다.
별을 보며 미래를 읽는다.
가뭄, 전쟁, 황룡사 건설을 예언한다.
그리고 삼국 통일도 — 자신이 아닌 후대에서.

핵심 장면:
- 첨성대 플라네타리움 시퀀스 (5분, 별자리 가득)
- 선덕의 독백 — 「나는 향기 없는 모란꽃이 아니다」
- 금관 착용 순간 황금빛 폭발 이펙트

스타일: 야경·별빛 특화 / 딥퍼플+골드 색채 / 신비로운 분위기
```

### OVA-Y 「가야금 열두 줄」(가야)

```
부제: Twelve Strings of Gayageum
러닝타임: 45분
초점: 우륵 신라 귀화 전후
시점: 우륵 + 니문

줄거리:
우륵과 제자 니문이 낙동강을 건넌다.
신라에서 가야금을 처음 연주하는 날.
진흥왕이 듣고 눈물 흘린다.
열두 번째 악곡 「낙동강」 완성.

핵심 장면:
- 가야금 연주 시퀀스 — 음악과 화면의 완전 동기화
- 낙동강과 신라 강의 교차 편집
- 가야 건국 신화 삽화 (수채화 스타일)

스타일: 자연음 중심 / 최소 대사 / 음악이 서사를 대체
```

## TYPE C — 유튜브 웹 애니 「삼국 단편」

### 시리즈 개요

```
형식: 5분 숏 애니메이션 × 24편
채널: 유튜브 공식 채널 (한국어·영어·일본어)
스타일: 2D 플래시 애니 + 전통 문양 이펙트
목적: 바이럴·팬덤 형성·IP 입문용

에피소드 라인업 (샘플):
EP01 「광개토대왕이 말했다」— 광개토대왕 명언 애니
EP02 「선덕의 모란꽃」— 선덕여왕 지혜 일화
EP03 「우륵의 하루」— 우륵 일상 코믹터치
EP04 「계백의 밥」— 계백 가족 이야기 (감동)
EP05 「삼족오를 찾아라」— 숨은그림찾기 인터랙티브
EP06 「철정 100개의 가치」— 가야 경제 교양
...
EP24 「강은 기억한다」— 시리즈 총결산 뮤직비디오

업로드 주기: 격주 1편 (TVA 방영 연동)
목표 조회수: 편당 100만+ (누적 2,400만)
```

## TYPE D — 극장판 「살수대첩」

### 극장판 개요

```
제목: 삼국: 살수대첩 (三國: 薩水大捷)
부제: The Battle That Remembered
러닝타임: 90분
개봉: TVA 시즌1 종료 후 6개월
포맷: 극장 + IMAX (전투 시퀀스)

스토리:
TVA의 살수대첩을 극장판 스케일로 재구성.
TVA와 시점·장면이 다른 완전히 새로운 접근.
을지문덕 주인공 시점.

3막 구조:
1막 (0~30분): 을지문덕의 전략 — 수나라군 유인
2막 (30~65분): 살수 전투 — 대규모 전투 시퀀스
3막 (65~90분): 승리 이후 — 을지문덕 시 낭독·고루 재회

핵심 시퀀스:
- 수나라 30만 행군 파노라마 (5분, IMAX 전용)
- 살수 방류 순간 (3분, 물 시뮬레이션 최고 품질)
- 을지문덕 vs 우중문 지략 대결 (20분)

음악:
메인: 「살수의 기억」— 오케스트라 풀 스코어
엔딩: 을지문덕 시 가야금·오케스트라 편곡
```

## 제작 파이프라인

### 제작 체계

```
총괄 감독: 1명 (총감독)
감독: TVA 2명·OVA 4명·극장판 1명
캐릭터 디자이너: 2명
배경 디자인팀: 5명
원화팀: 12명
동화팀: 외주 (국내 + 베트남)
CG팀: 3명 (전투 이펙트·3D 배경)
음향: 사운드본부 협업
```

### 글로벌 배급 전략

```
크런치롤: 애니 전문 플랫폼 (일본·북미)
넷플릭스: OVA·극장판 라이선싱
웨이브·티빙: 국내 독점 선방영
유튜브: 웹 애니 공개 (무료)
일본 TV방영: 지상파 또는 BS채널 협상

일본 공략 전략:
- 일본어 더빙: 인기 성우 캐스팅 필수
- 일본 현지 캐릭터 상품 동시 출시
- 애니메재팬·코미케 출품
- 니코니코 동화 특별 배포

중화권 전략:
- 빌리빌리 우선 협의
- 중국 본토: 심의 고려한 버전 별도 편집
- 대만·홍콩: 정식 방영
```
