## 삼국시대 전쟁의 본질

```
전쟁 성격:
  단순 영토 쟁탈 × → 국가 생존과 문명 존속의 싸움
  삼국 전쟁은 동시에:
    ① 왕권 강화 수단 (전쟁 승리 = 왕의 정통성)
    ② 경제 자원 쟁탈 (농경지·인구·철·소금)
    ③ 이념 충돌 (불교·유교·무속 국가 정체성)
    ④ 외세 개입 (수·당·왜 개입 → 국제전)

전쟁 주기:
  3~5년 주기로 국경 분쟁
  10~20년 주기로 대규모 전면전
  항상 전쟁 대비 상태 유지 (상비군 체제)
```

## 고구려 전쟁 교리

### 핵심 철학: 「방어의 예술」

```
고구려 군사 철학:
  「적이 오면 막고, 막으면 소진시키고, 소진되면 섬멸한다」

전략 삼원칙:
  ① 종심방어(縱深防禦): 수도 직접 방어 × → 다층 방어선
     요동성 → 오골성 → 평양성 → 3단계 방어
  ② 청야전술(淸野戰術): 적의 현지 조달 차단
     식량·가축·주민 후퇴 → 적군 보급 붕괴
  ③ 기동전(機動戰): 정면 충돌 회피 → 기병 측면 공격

살수대첩 교리 구현:
  수나라 1차~6차 공격: 요동성 방어선 고수
  7차 퇴각: 의도적 후퇴 → 수나라 군 과신 유도
  살수 매복: 지형 활용 → 강물로 적 섬멸
  → 고구려 방어 교리의 완성형
```

### 고구려 전술 체계

```
기병 운용:
  개마무사(鎧馬武士): 철갑 중기병 (벽화 확인)
  역할: 전선 돌파 + 적 후방 차단
  약점: 보급·기동성 (철갑 무게)

보병 운용:
  성벽 수성: 고구려 성곽 수비대
  활쏘기: 고구려 궁술 최강 정평
  야간 기습: 수나라 진영 야간 공격 기록

축성 전략:
  산성(山城) 중심: 평지성 ×, 산 정상·능선 활용
  평양성: 내성·중성·외성·북성 4중 구조
  안시성: 88일 방어 (645년 당 태종 원정 격퇴)

지휘 체계:
  을지문덕 전술 특징:
    - 적의 심리 교란 (한시 전달 — 「계략이 하늘을 찌르고...」)
    - 7번 후퇴 → 적군 교만 유도
    - 최적 지점에서 일격
```

## 백제 전쟁 교리

### 핵심 철학: 「외교와 전쟁의 병용」

```
백제 군사 철학:
  「전쟁보다 외교가 먼저, 외교가 실패하면 전쟁」
  문화적 우위를 전략 자산으로 활용

전략 삼원칙:
  ① 동맹 외교: 왜(倭)·당·신라 이간 → 고구려 고립
  ② 해상 전력: 서해 해상권 장악 → 무역로 보호
  ③ 결사 방어: 최후 방어선에서 계백식 결사전

근초고왕 교리:
  371년 고구려 평양성 공격 → 고국원왕 전사
  백제 최전성기 군사 교리: 기동 공세
  황해도까지 영토 확장 → 공세적 팽창

성왕~의자왕 교리 변화:
  성왕 전사 (554년 관산성) → 신라와 결전 패배
  이후: 방어 중심 전환 + 왜 동맹 강화
  의자왕 초기: 공세 재개 (대야성 40여 성 함락)
  말기: 왜 원군 기다리며 방어 → 나당연합에 패배
```

### 백제 전술 체계

```
해군 전력:
  서해 선단: 중국·일본 교역 노하우 → 수군 기술 최고
  군선: 판옥선 원형 (대형 목선)
  역할: 보급 차단 + 해상 기습

기병:
  금강 유역 평야 → 기병 운용 유리
  중기병 + 경기병 혼합

계백 교리:
  「살아서 치욕당하느니 죽어서 영예롭자」
  황산벌: 5,000 결사대 vs 나당연합 50,000
  4번 전투에서 물리침 (5번째 패배)
  → 이 정신이 백제 부흥운동(663년)으로 이어짐
```

## 신라 전쟁 교리

### 핵심 철학: 「외교로 이기는 전쟁」

```
신라 군사 철학:
  「우리 힘만으로 이길 수 없다면, 강자와 손잡아라」
  외교 지향 → 당과 동맹 → 삼국 통일

화랑 교리:
  세속오계(世俗五戒, 원광법사):
    ① 사군이충(事君以忠): 충성으로 임금 섬기기
    ② 사친이효(事親以孝): 효도로 부모 섬기기
    ③ 교우이신(交友以信): 믿음으로 벗 사귀기
    ④ 임전무퇴(臨戰無退): 전쟁에서 물러서지 않기
    ⑤ 살생유택(殺生有擇): 살생에 가림이 있을 것

전략 삼원칙:
  ① 당(唐) 외교: 660년 나당연합 완성 → 백제·고구려 협공
  ② 화랑 정예화: 귀족 자제 엘리트 전사 → 사기 최강
  ③ 황산벌 전략: 계백 격파 → 당군 상륙 지원
```

### 신라 전술 체계

```
화랑 전투:
  개인 용맹 + 집단 규율의 결합
  관창(16세 화랑): 황산벌 결사 돌격 → 사기 전환점
  「죽음을 두려워하지 않는 전사」

기병:
  경주 분지 → 기병 훈련 공간
  화랑 기마 훈련 고도화

당군 연합:
  나당 작전 분담:
    당: 서해 수군 + 백강구 상륙
    신라: 황산벌 육상 진격 + 사비성 포위
  660년 백제 멸망: 나당 합동 작전 완성형

기벌포 해전 (676년):
  당군 잔류 세력 격퇴 → 신라 단독 통일
  수군 역량 성장: 원래 해전 약세 → 학습·성장
```

## 가야 전쟁 교리

```
가야 군사 특성:
  소국 연맹체 → 통합 군사 교리 부재
  각 가야국 독립 방어

금관가야 멸망 (532년):
  법흥왕 신라에 항복 → 무혈 복속
  전쟁보다 외교·복속 선택 (문화적 흡수 조건)

대가야 멸망 (562년):
  진흥왕 이사부·사다함 공격
  결사 항전 → 패배
  전략적 오판: 신라와의 단독 방어 불가

가야 군사 유산:
  철제 무기·갑옷: 3국 중 최고 품질
  철갑 수출 → 왜에 기술 전파
  가야 기마 전술 → 신라 흡수
```

## 외세 군사 교리 (참조)

```
수나라 원정 교리:
  「수양제의 야망」: 고구려 정복 = 천하 지배자 선언
  113만 대군 (실제 추산 30~40만)
  중앙 집권적 대규모 병력 운용
  약점: 보급선 과장, 현지 지형 무시

당나라 교리:
  태종 이세민: 645년 고구려 원정 (안시성에서 격퇴)
  고종 시대: 나당연합 → 보급·외교 해결 후 원정
  전략적 유연성: 실패 후 재조정 → 최종 성공

왜(倭) 교리:
  백강구 전투 (663년): 백제 부흥 지원 → 당·신라에 패배
  수군 위주, 육전 경험 부족
  패배 후 일본 열도 방어 전환 (왜성 축조)
```

## 서사 활용 지침

```
전쟁 묘사 3원칙:
  ① 전략적 문맥 제시: 단순 전투 묘사 × → 왜 싸우는가
  ② 인간적 고통 병기: 영웅 서사 + 민중의 피해
  ③ 역사적 인과 연결: 이 전투가 다음 역사를 어떻게 바꿨나

드라마 전투씬 교리 반영:
  살수대첩: 을지문덕의 청야전술·기만·매복 순서
  황산벌: 계백의 결사전 + 관창의 돌격 + 신라의 승리
  안시성: 88일 수성 + 을지문덕 전술 유전
  기벌포: 신라 최종 통일 → 4인 각자의 반응

금지 묘사:
  전쟁 미화: 살육을 영웅화만 하는 묘사 지양
  현대 전쟁 개념 소급: 총기·폭발물 등 시대착오 표현
```
