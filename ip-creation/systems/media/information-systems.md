# 삼국시대 정보 체계

## 정보의 종류와 흐름

삼국시대 정보 전달은 **속도·신뢰도·비밀성**이 국가 존망을 결정하는 핵심 변수였다.

---

## 공식 정보 전달 체계

### 1. 문서 행정

**기록 매체 변천**
- 목간(木簡): 나무 조각에 먹으로 기록 — 초기 주요 매체
- 죽간(竹簡): 대나무 조각 — 중국에서 수입 개념
- 종이(紙): 고구려·백제에서 생산 시작 → 점차 확산
  - 고구려 담징: 일본에 종이·묵 제조법 전파 (610년)

**문서 종류**
| 문서 | 내용 |
|------|------|
| 교서(敎書) | 왕의 명령서 |
| 주청(奏請) | 신하 → 왕 보고서 |
| 첩보(牒報) | 군사 정보 보고 |
| 외교 문서 | 사신 왕래 시 교환 |
| 호적(戶籍) | 인구·토지 파악 |

### 2. 봉화(烽火) 시스템

**신호 체계**
| 봉화 수 | 의미 |
|---------|------|
| 1개 | 평시 이상 없음 |
| 2개 | 적 출현 |
| 3개 | 적 접근 |
| 4개 | 전투 발생 |

**봉화대 배치**
- 주요 산 정상 — 시야 확보 우선
- 인접 봉화대 간격: 약 10~20km (육안 확인 범위)
- 전국망: 수도-변경 직결 가능

**한계**
- 안개·비·눈: 시야 차단 → 봉화 불가
- 적의 선제 점령: 봉화대 탈취 → 정보 차단
- 세부 정보 전달 불가: "적이 왔다" 수준만 전달

### 3. 역참(驛站) + 파발(擺撥)

**역참 체계**
- 주요 도로에 역(驛) 설치 — 약 25~30리(10~12km) 간격
- 각 역에 말·인원 상주
- 공문서·물자·사신 중계

**파발 속도**
- 말 릴레이: 하루 약 300km 전달 가능
- 인간 릴레이: 하루 약 100km

**비밀 문서 전달**
- 밀서(密書): 왕의 개인 인장(印章) 봉인
- 구두 전달: 극비 정보는 문서 없이 구전
- 암호화: 사전 약속된 기호·비유 사용

## 첩보(諜報) 체계

### 삼국의 간첩 운용

**간첩 종류**
| 종류 | 방법 |
|------|------|
| 향간(鄕間) | 적국 현지인 포섭 — 내부 정보 수집 |
| 내간(內間) | 적 관리 포섭 — 고위급 내통자 |
| 반간(反間) | 적 간첩 역이용 — 역정보 공작 |
| 사간(死間) | 허위 정보 전달 후 희생 — 적 혼란 유도 |
| 생간(生間) | 살아 돌아오는 정보원 — 장기 잠복 |

**고구려의 첩보 사례**
- 을지문덕: 수나라 군 내부 정보를 활용해 살수대첩 설계
- 연개소문: 당과의 내부 협력자 색출로 천리장성 건설 정당화

**신라의 첩보 사례**
- 나당동맹 교섭: 당 내부 정세 파악 후 협상 시점 결정
- 나당전쟁: 당군 동향 사전 파악으로 매소성 방어 준비

### 첩보 방법

**위장 신분**
- 상인: 가장 흔한 위장 — 교역 이유로 국경 왕래
- 승려: 종교 명목 — 삼국 경계 자유 이동
- 사신 수행원: 외교 사절단 내 잠입
- 의원(醫員): 귀족 치료 명목 접근

**정보 전달**
- 비밀 문서: 옷 속·신발 바닥 은닉
- 구두 암호: 사전 약속 문구
- 서신 위장: 일반 편지 속 숨김 기법

## 외교 정보 채널

### 사신(使臣) 외교

**정보 수집 기능**
- 공식 목적: 조공·외교 협의
- 비공식 목적: 상대국 국력·군사·정치 정보 수집
- 사신 수행원: 사실상 정보 요원 역할

**사신 경로**
- 고구려 → 중국: 요동 육로 + 서해 해로
- 백제 → 중국: 서해 해로 (남조)
- 신라 → 중국: 초기 고구려 경유, 후기 직항

### 혼인 동맹과 정보

- 왕족 혼인 = 상대국 내부 정보 채널 확보
- 공주·왕비가 사실상 정보 연락책 역할
- 이중 첩자 위험: 혼인한 왕비가 친정 이익 우선

## 정보전 실제 사례

### 살수대첩 (612) — 정보전의 승리

1. 을지문덕이 수 장수 우문술 진영 방문 → 직접 정보 수집
2. 수군 식량·보급 상황 파악 → 고갈 임박 확인
3. 고의로 7번 패퇴 → 수군 추격 유도
4. 살수에서 반격 타이밍 정확히 계산

→ **정보 우위가 전투 승리를 결정한 전형적 사례**

### 나당동맹 성사 (648) — 외교 정보전

1. 김춘추 당 방문 — 표면상 구원 요청
2. 실제: 당 태종 의도·고구려 대응 계획 탐색
3. 당이 원하는 조건(전후 대동강 이남 신라 영토) 파악
4. 최적 조건 협상 → 동맹 성립
