## 스핀오프 개요

```
타이틀: 삼국(三國) 외전 — 「황금의 죄」
영문: THREE KINGDOMS Side Story — THE PRICE OF GOLD
형식: 소설 (3권 완결) + 웹툰 (시즌 1, 50화)
시대: AD 632~676 (선덕여왕 즉위~삼국통일)
주인공: 하린 (河璘) + 김유신 + 김춘추
톤: 정치 서사 + 전쟁 윤리 + 승리의 대가

슬로건:
  「통일의 대가를 아는 자만이 통일을 이룬다.」
  "ONLY THOSE WHO KNOW THE PRICE CAN PAY IT."
```

## 서사 구조

### 제1부 — 「화랑의 길」(AD 632~648)

```
Chapter 1~5: 하린의 화랑 입문
  배경: 신라 금성(경주) — 선덕여왕 즉위 (632년)
  하린 (14세): 화랑도 입문
  화랑 세속오계: 하린이 외우는 장면
    事君以忠 (사군이충 — 충성)
    事親以孝 (사친이효 — 효도)
    交友以信 (교우이신 — 신의)
    臨戰無退 (임전무퇴 — 용기)
    殺生有擇 (살생유택 — 정의)
  → 하린: 「다섯 번째 계율이 가장 어려울 것 같습니다.」

Chapter 6~12: 선덕여왕과의 만남
  선덕여왕: 하린의 재능을 인정 → 경호무관 발탁
  여왕의 3대 예언:
    모란꽃에 향기가 없다 → 남편이 없는 여왕의 고독
    첨성대 건설 지시: 「별은 미래를 알려준다」
  하린의 충성: 「여왕 폐하를 지키겠습니다.」
  선덕여왕: 「나를 지키는 것보다 신라를 지키는 것이 먼저다.」

Chapter 13~20: 나당연합의 씨앗
  642년 대야성 함락: 백제 의자왕 공격 → 신라 40성 상실
  김춘추: 딸·사위 사망 → 복수 결심
  김춘추의 고구려 방문 실패 (연개소문 거절)
  648년: 김춘추 당나라 방문 → 나당연합 체결
  하린의 시점: 김춘추를 호위하며 당나라로 동행
    당태종 면전: 신라의 존엄을 지키면서 동맹 요청
    하린의 갈등 시작: 「외세를 끌어들이는 것이 옳은가?」
```

### 제2부 — 「전쟁의 계절」(AD 655~668)

```
Chapter 21~28: 백제 정복 (660년)
  나당연합군 결성: 당 13만 + 신라 5만
  황산벌 전투:
    계백 5,000 결사대 vs 김유신 5만
    하린의 위치: 선봉 기마대
    관창(16세 화랑)의 특공: 하린이 목격
      → 하린: 「16세가 저렇게 죽어야 하는가?」
    계백 패배: 하린이 전장에서 계백의 검을 줍는다
  사비성 함락: 의자왕 항복
  하린의 기록: 「우리는 이겼다. 왜 기쁘지 않은가.」

Chapter 29~35: 고구려 정복 (668년)
  평양성 공격: 나당연합 vs 고구려 잔여 세력
  고구려 멸망: 보장왕 항복
  하린의 갈등 심화:
    당나라 장군들의 행태 목격 (약탈·포로)
    「동맹이 아니라 점령이다.」
  김유신과의 대화:
    하린: 「장군, 우리가 한 것이 옳습니까?」
    김유신: 「옳고 그름은 후세가 판단한다. 우리는 살아남았다.」
```

### 제3부 — 「황금의 대가」(AD 670~676)

```
Chapter 36~42: 나당전쟁
  당나라의 본색: 안동도호부·웅진도독부 설치
  → 한반도 전체를 당 영토로 편입 시도
  신라의 결단: 배신한 동맹에 맞서 싸우기
  하린: 「내가 우려한 것이 현실이 되었다.」
  나당전쟁 발발 (670년):
    신라 vs 당나라 — 이전 동맹국과 전쟁

Chapter 43~48: 기벌포 해전 (676년)
  서해 기벌포: 신라 수군 vs 당 수군(설인귀)
  22회 연속 해전: 하린 직접 참전
    1~5전: 신라 우세
    6~15전: 치열한 공방
    16~21전: 당 수군 약화
    22전: 최종 승리 — 당 수군 완전 격파
  하린의 승전 후 독백:
    「22번 싸웠다. 22번 이겼다.
     그러나 나는 얼마나 많은 것을 잃었는가.」

Chapter 49~50: 에필로그 — 676
  삼국통일 완성: 대동강 이남 신라 영토 확정
  하린 (58세): 경주 외곽 은거
  화랑 세속오계를 다시 읊는다:
    「殺生有擇 — 살생유택.
     죽일 때를 가려라.
     나는 가렸는가?
     ……모르겠다.」
  마지막 씬: 황산벌에 다시 서다
    황금빛 들판. 바람. 아무도 없다.
    하린은 계백의 검을 황산벌 땅에 꽂는다.
    절을 한다.
    강이 흐른다.
    끝.
```

## 캐릭터 상세

### 하린 (이 작품에서)

```
나이: 14세 (632) → 58세 (676)
역할: 1인칭 시점 화자 / 주인공
성장 아크:
  이상주의 화랑 소년 → 전쟁의 현실 목격자 →
  동맹의 모순 인식자 → 통일의 대가를 짊어진 자

핵심 갈등:
  화랑 정신(臨戰無退) vs 전쟁 윤리(殺生有擇)
  나당연합의 필요성 vs 외세 의존의 수치
  승리 vs 승리의 대가

본편 연결:
  이 하린 = 본편 시즌 1~3 하린과 동일 인물
  나당연합 체결 과정 목격이 하린의 「죗값」의식 형성
```

### 김유신

```
역할: 하린의 상관 + 멘토 → 후반 갈등 대상
성격: 실용주의 전략가 / 감정을 숨기는 리더
핵심 관계: 하린에게 「신라를 위해 무엇이든 하라」가르침
  → 하린: 「무엇이든이라는 말이 두렵습니다.」
```

### 김춘추

```
역할: 나당연합의 설계자 / 정치적 천재
성격: 복수심 + 지략 + 개인적 비극
핵심 씬: 당태종과의 협상 — 하린이 호위하며 목격
  → 하린: 「저분은 신라를 위해 무릎을 꿇었다.
            나는 저것을 배신이라 해야 하는가, 충성이라 해야 하는가.」
```

## 제작 기준

```
소설:
  1권: 제1부 (400페이지) / 2권: 제2부 (380페이지) / 3권: 제3부 (350페이지)
  문체: 1인칭 하린 시점 — 직접적·행동적 문체
  특징: 화랑 세속오계가 각 부의 에피그래프

웹툰:
  시즌 1: 50화
  톤: 전쟁 서사 + 정치 드라마 (전투 씬 40%)
  액션: 기마·해전 씬 강화

역사 고증 필수:
  □ 화랑도 제도 상세 (ADV-HISTORY)
  □ 선덕여왕 3대 예언 (삼국유사)
  □ 나당연합 체결 과정 (ADV-POLIECON)
  □ 황산벌·기벌포 전투 상세 (ADV-MILITARY)
  □ 나당전쟁 경과 (ADV-HISTORY)
  □ 관창 특공 사건 (삼국사기)
```
