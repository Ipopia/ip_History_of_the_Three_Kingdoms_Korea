# 게임 UI/UX 디자인 가이드 — 삼국(三國) IP

**참조 문서**: `game-design-document.md`, `art-bible.md`, `brand-identity.md`, `glossary.md`
**작성**: 게임본부 아트팀 (GAME-ART)
**적용**: 삼국(三國) IP 공식 게임 UI/UX 전체 기준

---

## UI 디자인 철학

```
핵심 원칙:
  「역사의 질감 — 현대적 가독성」
  고대 한국 미감 + 현대 모바일 UX 최적화

UI 목표:
  첫 5분 안에 직관적으로 이해 가능
  왕국별 차별화된 UI 테마
  역사 고증 소품 활용 (인장·죽간·봉화 등)
  과도한 판타지 UI 금지 (빛나는 마법 효과 등)

금지 사항:
  네온·홀로그램 UI (시대 부적합)
  유럽 중세 기사단 UI (문화 혼용)
  과도한 황금 배경 (게임성 저하)
```

## 왕국별 UI 테마

### 고구려 UI

```
색채:
  기본: 청람 #2F4F7F + 철회 #4A4A4A
  강조: 금속 은빛 #C0C0C0
  배경: 어두운 석벽 질감

소재 모티프:
  버튼: 현무암 질감 사각형
  패널: 철갑 판금 느낌
  구분선: 칼 문양 라인
  아이콘: 삼족오 + 환두대도

폰트 스타일:
  한국어: 굵고 힘찬 고딕체
  숫자: 굵은 획 (자원 수량 가독성)

사운드:
  버튼 클릭: 금속 타격음 (약하게)
  선택: 검 소리 단음
  경고: 북소리 강타
```

### 백제 UI

```
색채:
  기본: 황금 #B8960C + 연지 #C0392B
  강조: 비취 #1ABC9C
  배경: 황금빛 목재 질감

소재 모티프:
  버튼: 금동 공예 느낌 (곡선형)
  패널: 백제 단청 문양 테두리
  구분선: 봉황 날개 라인
  아이콘: 봉황 + 금동대향로

폰트 스타일:
  한국어: 부드럽고 우아한 명조 계열
  숫자: 세련된 서체

사운드:
  버튼 클릭: 가야금 단음 (부드럽게)
  선택: 피리 단음
  경고: 종 소리 (낮게)
```

### 신라 UI

```
색채:
  기본: 금빛 #FFD700 + 주황 #E67E22
  강조: 백 #FFFFFF
  배경: 화강암 + 금빛 빛살 효과

소재 모티프:
  버튼: 신라 금관 문양 (나뭇잎형)
  패널: 첨성대 원통형 요소
  구분선: 화랑 띠 문양
  아이콘: 금관 + 각궁

폰트 스타일:
  한국어: 밝고 명확한 고딕체
  숫자: 굵고 선명

사운드:
  버튼 클릭: 대금 단음 (밝게)
  선택: 징 단음
  경고: 나팔 단음
```

### 가야 UI

```
색채:
  기본: 황토 #C8A96E + 적갈 #8B4513
  강조: 철 은빛 #A8A8A8
  배경: 황토·흙 질감

소재 모티프:
  버튼: 가야 토기 질감 (둥글고 따뜻함)
  패널: 죽간 + 목재 질감
  구분선: 가야금 현 라인 (수평선)
  아이콘: 가야금 + 철정

폰트 스타일:
  한국어: 소박하고 자연스러운 서체
  숫자: 중간 굵기, 따뜻한 색

사운드:
  버튼 클릭: 가야금 현 뜯음 (가볍게)
  선택: 가야금 단음
  경고: 가야금 단음 (낮게)
```

## 주요 화면 UX

### 메인 메뉴

```
구성:
  배경: 4강 (살수·백마강·낙동강·기벌포) 로테이션 일러스트
  음악: 가야금 첫 음 + 왕국 선택 테마

메뉴 항목:
  [새 게임] — 죽간 펼치는 애니메이션
  [이어하기] — 봉화 점화 애니메이션
  [왕국 선택] — 4왕국 지도 펼침
  [설정] — 인장 문양 아이콘
  [역사 백과] — 삼국사기 책 아이콘

왕국 선택 화면:
  지도 기반 선택 (한반도 4세기 지도)
  왕국 선택 시: 해당 왕국 색상으로 화면 전환
  왕국 테마 BGM 3초 자동 재생

  고구려 선택 애니메이션: 삼족오 날아오름
  백제 선택: 봉황 날개 펼침
  신라 선택: 금관 빛남
  가야 선택: 가야금 현 울림
```

### 왕국 경영 화면 (메인 게임플레이)

```
레이아웃:
  상단: 자원 바 (식량·철·목재·포 + 민심 게이지)
  중앙: 왕국 지도 (건물·부대·지형)
  하단: 행동 메뉴 (건설·군사·외교·탐색)
  우측: 캐릭터 패널 (4인 초상화 + 상태)

자원 아이콘:
  식량: 벼이삭 (황금색)
  철: 철정 (철회색)
  목재: 나뭇가지 (갈색)
  포: 비단 (연지색)
  민심: 사람 실루엣 (왕국 색상)

빌딩 선택 UI:
  건물 탭 선택 시: 죽간 펼치는 효과
  건물 정보: 목간 형태 팝업
  업그레이드: 가야금 상행 음계 효과음

턴 종료 버튼:
  형태: 봉화 아이콘
  클릭 시: 봉화 점화 애니메이션
  확인: 「다음 날로 넘어가시겠습니까?」(죽간 팝업)
```

### 전투 화면

```
레이아웃:
  배경: 실제 역사 전장 재현 (황산벌·살수·안시성 등)
  전투 필드: 헥사그리드 (전략적 이동)
  상단: 아군/적군 HP 게이지 + 턴 수
  하단: 부대 선택 + 스킬 버튼

부대 아이콘:
  기병: 말 실루엣
  창병: 창 아이콘
  궁병: 활 아이콘
  공성: 공성기 아이콘
  특수: 왕국별 고유 아이콘

스킬 버튼:
  왕국 고유 스킬: 대형 원형 버튼 (왕국 색상)
  고구려: 삼족오 아이콘 (청야전술/개마무사 돌격)
  백제: 봉황 아이콘 (결사대/수군 강화)
  신라: 금관 아이콘 (화랑 선봉/나당연합)
  가야: 가야금 아이콘 (철갑 제조/철정 외교)

전투 결과 화면:
  승리: 왕국 깃발 게양 + 테마 음악
  패배: 봉화 꺼짐 애니메이션 + 조용한 음악

역사 사건 컷씬:
  특별 전투 전후: 풀 애니메이션 컷씬 팝업
  살수대첩 댐 개방: 전체 화면 VFX
```

### 역사 백과 (인게임)

```
형식: 삼국사기 책 레이아웃 (두루마리→페이지 전환)
구성:
  인물 도감: 역사 인물 + IP 캐릭터 분리
  사건 기록: 역사 사건 연대기 (플레이 진행 시 잠금 해제)
  문화 사전: 용어·문화 설명
  유물 갤러리: 실제 발굴 유물 사진 + 설명

잠금 해제:
  해당 역사 사건 플레이 완료 → 자동 해금
  특별 미션: 숨겨진 역사 사실 해금

  예: 살수대첩 클리어 → 을지문덕 한시 원문 + 해석 해금
```
