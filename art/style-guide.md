```
목적:
전 미디어(드라마·애니·게임·굿즈·마케팅)에서
삼국(三國) IP의 비주얼 아이덴티티를 일관되게 유지

사용 범위:
- 드라마 타이틀 시퀀스·포스터
- 애니메이션 스타일 적용

- 굿즈 패키지·의류 프린트
- SNS·마케팅 비주얼
- 공연 포스터·프로그램북
```

## 로고 시스템

```
메인 로고:
한자: 三國 (삼국)
한글 부제: 강은 기억한다
영문 부제: THE RIVER REMEMBERS

로고 형태:
三國 — 세로 배열 또는 가로 배열 2종
三 (삼): 고구려 삼족오 날개 모티프
國 (국): 성곽 윤곽 모티프
글꼴 베이스: 붓글씨 + 현대 세리프 결합체

로고 색상 버전:
① 풀컬러: 4왕국 그라데이션 (암청→골드→황금→토황)
② 다크: 검정 배경 + 황금 로고
③ 라이트: 흰 배경 + 암청 로고
④ 모노: 단색 (굿즈 인쇄 대응)

금지 변형:
❌ 로고 비율 변형
❌ 로고 회전
❌ 로고 색상 임의 변경
❌ 로고에 외곽선 추가
❌ 로고 반투명 처리 (50% 이하)
```

## 타이포그래피 시스템

```
주요 서체:

한국어:
헤드라인: Noto Serif KR Bold
  - 역사성·무게감 표현
  - 포스터·제목·대형 텍스트
본문: Noto Serif KR Regular
  - 장문 텍스트·소설·웹툰 대사
  - 가독성 최우선
캡션: Noto Sans KR Medium
  - UI·설명 텍스트·자막

영어:
헤드라인: Playfair Display Bold
  - 글로벌 포스터·영문 제목
본문: EB Garamond Regular
  - 영문 장문
캡션: Source Sans Pro Medium

서체 사용 원칙:
- 1개 레이아웃에 최대 2개 서체족
- 한국어+영어 혼용 시: Noto 계열로 통일
- 게임 UI: 가독성 최우선 (산세리프 허용)

금지:
❌ 고딕체 단독 헤드라인 (역사 분위기 훼손)
❌ 손글씨 폰트 남용
❌ 3종 이상 서체 혼용
```

## 이미지 스타일 기준

### 일러스트레이션 스타일

```
캐릭터 일러스트:
선 스타일: 가변 두께 아웃라인
  - 주선 2~3px (강조 부분)
  - 보조선 1px (세부 묘사)
채색: 평면+그라데이션 혼합
  - 피부: 따뜻한 베이스 + 콜드 섀도우
  - 의상: 소재별 질감 표현 (비단·철갑·가죽)
하이라이트: 강한 포인트 하이라이트 1~2개

배경 일러스트:
스타일: 세미-리얼 + 대기 원근감
색조: 왕국별 LUT 적용 (art-bible.md 기준)
디테일: 전경 고해상도 → 원경 단순화

키 비주얼 포스터 스타일:
구도: 캐릭터 중심 + 왕국 배경
시점: 앙각(우러러보기) — 웅장함 강조
강 요소: 모든 포스터에 강 물결 또는 반영 포함
슬로건: 하단 중앙 「강은 기억한다 / THE RIVER REMEMBERS」
```

### 사진·실사 스타일 (드라마·마케팅)

```
색보정 (Color Grading):
왕국별 LUT 필수 적용 (color-palette.md 기준)
콘트라스트: 중상 (역사 드라마 분위기)
채도: 왕국별 차별화 (신라 높음 / 가야 낮음)

촬영 스타일:
조명: 자연광 기반 + 단일 광원 강조
구도: 황금비율 or 삼분법
인물: 아이레벨 or 약간 앙각 (인물 존엄성)
원경: 항상 강·산·성벽 중 하나 포함

금지:
❌ 렌즈 플레어 과다 사용
❌ 과도한 HDR 처리
❌ 과포화 (채도 +50 이상)
❌ 현대 건물·자동차 노출
```

## UI 디자인 기준 (게임·앱)

```
UI 스타일:
기반: 목재+금속+돌 질감 재현
테두리: 왕국별 문양 (삼족오·봉황·금관·가야금)
버튼: 나무 질감 + 금속 테두리
아이콘: 평면 + 한국 전통 문양 기반

색상 사용:
메인 UI (중립): 어두운 갈색 (#3D2B1F) + 금색
왕국별 UI: 선택한 왕국 컬러 테마 자동 적용
경고: 심홍 (#8B0000)
성공: 황금 (#FFD700)
정보: 강청 (#5F9EA0)

폰트 크기:
제목: 24~32pt
본문: 14~16pt
캡션: 11~12pt
최소 가독 크기: 10pt (모바일 기준)

아이콘 시스템:
크기: 24×24px (최소) / 48×48px (권장)
스타일: 라인 아이콘 (테두리 2px)
왕국 아이콘: 4왕국 심볼 전용 (삼족오·봉황·금관·가야금)
```

## 소셜미디어 비주얼 기준

```
인스타그램:
피드 비율: 1:1 (정방형) 또는 4:5 (세로)
스토리: 9:16
컬러 일관성: 왕국별 톤 유지 (월별 1왕국 집중)

유튜브:
썸네일: 1280×720px
구성: 캐릭터 클로즈업 + 제목 텍스트 + 왕국 컬러 배경
텍스트: 최대 5단어 (한국어 기준)

X (트위터):
이미지: 16:9 or 1:1
인포그래픽: 한 눈에 읽히는 구조 (3~5 포인트)

공통 규칙:
로고 위치: 우하단 (항상)
해시태그 폰트: Noto Sans KR (본문 서체와 구분)
워터마크: @samguk_official 표기 필수
```
