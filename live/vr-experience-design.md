## 체험 프로그램 상세

### 프로그램 1: "광개토대왕의 정복" (STANDARD)

**컨셉**: 광개토대왕의 기마 정복대에 합류하여 요동 전투를 체험

**체험 구성**:
```
[오프닝 — 2분]
- 평양성 성문 앞에 선다
- 광개토대왕이 말을 타고 등장, 플레이어에게 말을 건넴
- "그대도 함께 가겠는가?"

[기마 전투 — 8분]
- 가상 말(물리 시뮬레이터 의자) 탑승
- 요동 벌판 기마 진격 체험
- 적 성벽 공략 — 간단한 인터랙션 (활 조작)
- 64번째 성 함락 순간

[에필로그 — 5분]
- 광개토대왕릉비 앞에 선다
- 비문 내용이 한글·영어로 번역되어 나타남
- "우리가 지나간 자리에 역사가 남는다"
```

**물리 장치**:
- 말 시뮬레이터 의자 (상하·전후 진동)
- 바람 머신 (기마 속도감)
- 적외선 활 컨트롤러
- 진동 조끼 (전투 충격 피드백)

---

### 프로그램 2: "낙화암의 밤" (PREMIUM — 성인 전용)

**컨셉**: 660년 사비성 함락 전야, 궁녀의 시점으로 마지막 밤을 경험

**주의사항**: 강렬한 감정적 체험 — 15세 이상 / 심리적 예민자 주의 안내 필수

**체험 구성**:
```
[도입 — 3분]
- 사비성 궁중 내부에 선다
- 멀리서 신라·당 군의 북소리 들림
- 다른 궁녀들이 서로를 위로함

[긴장 고조 — 7분]
- 성벽에서 불길이 보임
- 왕의 항복 소식이 전해짐
- 궁녀들의 결의 — 적에게 잡히지 않겠다

[낙화암 — 5분]
- 절벽 끝에 서는 360° 시점
- 백마강이 내려다보임
- 바람, 별빛, 동료들의 손
- 선택: 떠나보낼 것인가, 기억할 것인가

[에필로그 — 5분]
- 현재의 낙화암으로 돌아옴
- "낙화암(落花巖) — 꽃이 떨어진 바위"
- 역사 해설 + 묵념
```

**물리 장치**:
- 바람 시스템 (절벽 바람)
- 향기 시스템 (강물·꽃향기)
- 음향 시스템 (심리적 몰입)
- 출구 전 심리 안정 공간 (2분 휴식 필수)

---

### 프로그램 3: "황룡사 9층탑" (BASIC)

**컨셉**: 선덕여왕 시대 완성된 황룡사 9층탑 내부를 관람

**체험 구성**:
```
[입장 — 2분]
- 신라 서라벌 전경 — 하늘에서 내려다보는 부감
- 황룡사 전체 조감

[탑 내부 관람 — 6분]
- 층별 이동 (1층~9층)
- 각 층마다 삼국 역사 장면 벽화
- 9층 전망 — 서라벌 전경

[선덕여왕 만남 — 2분]
- 탑 꼭대기에 선덕여왕 등장
- "이 탑은 9개 나라의 침략을 막을 것이다"

[에필로그 — 가상 복원]
- 1238년 몽골 침입 소실 → "만약 남아있었다면"
```

---

### 프로그램 4: "첨성대 야간 천문" (STANDARD — 가족)

**컨셉**: 선덕여왕과 함께 첨성대에서 별을 관측

**체험 구성**:
```
[도입 — 3분]
- 신라 경주 야경 — 별이 쏟아지는 밤
- 첨성대 앞에 선다

[천문 관측 — 10분]
- 선덕여왕이 별자리를 가리키며 해설
- 플레이어가 별자리를 찾는 인터랙션
- 삼국시대 천문학 지식 습득

[예언 — 2분]
- "저 별들이 무엇을 말하는지 들려줄게요"
- 선덕여왕의 3대 예언 재현

[에필로그 — 현재 첨성대]
- 현재의 첨성대 모습으로 전환
```

**가족 특화**: 아동을 위한 간단한 별자리 인터랙션 / 부모와 함께 별자리 찾기

---

### 프로그램 5: "황산벌 전투" (GROUP — 15세 이상)

**컨셉**: 팀으로 나뉘어 황산벌 전투 재현 — 계백 결사대 vs. 신라군

**인원**: 12명 (백제 6명 + 신라 6명)

**체험 구성**:
```
[브리핑 — 5분]
- 팀 배정 및 역사 배경 설명
- 백제팀: "계백 결사대 — 4번을 이겨라"
- 신라팀: "김유신 — 5번째에 이겨라"

[전투 체험 — 20분]
- 라운드 1~5: 각 라운드별 전술 선택
- 실제 결과와 비교하며 역사 실감
- 물리 진동·바람·음향 최대 활용

[결말 — 5분]
- 역사와 동일한 결말 (백제 패배)
- 그러나 계백의 이야기로 마무리
- "몇 명이 싸웠는지보다, 왜 싸웠는지가 중요하다"
```

**물리 장치**:
- 방향성 진동 조끼 (팀 구분)
- 적외선 무기 컨트롤러
- 팀 점수판 실시간 표시
- 전투 후 역사 결과 대조 화면

---

### 프로그램 6: "우륵의 가야금" (BASIC)

**컨셉**: 가야 멸망 직전, 우륵의 마지막 연주를 목격

**체험 구성**:
```
[도입 — 2분]
- 가야 대가야 왕도 — 황혼
- 우륵이 가야금을 준비함

[연주 — 6분]
- 우륵의 가야금 연주 (실제 연주 녹음 사용)
- 연주 중 가야의 역사가 배경에 펼쳐짐
- 건국 → 번영 → 소멸의 시각화

[이별 — 2분]
- 우륵이 가야금을 등에 지고 신라로 출발
- "소리는 사라지지 않는다"

[에필로그]
- 현재 가야금 연주 영상으로 전환
```

### VR 체험 콘텐츠 #1 — 「살수대첩의 전장」(상세 시나리오)

```
등급: 기본 코스 (20분) / 시점: 1인칭 고루 시점

체험 흐름:

  [0~3분] 프롤로그 — 압록강 새벽
    612년 7월 압록강 새벽
    을지문덕: 「강은 기억한다. 오늘 이 강이 우리 편이다.」
    체험자: VR 속에서 강물 내려다보기 (수면 반사 효과)

  [3~8분] 출진 — 7번의 후퇴
    후퇴 명령에 따라 달리는 체험 (방향 전환 인식)
    수나라 병사 추격 → 회피 동작

  [8~15분] 살수 결전 — 댐 개방
    인터랙션: 을지문덕 신호 확인 → 댐 개방 레버 당기기
    강물이 밀려오는 VR 시각 효과
    BGM: 살수대첩 전투 OST 풀 버전

  [15~20분] 에필로그 — 강가에서
    을지문덕: 「강은 기억한다. 오늘을. 우리를.」
    화면 전환: 현대 압록강 (드론 영상)
    자막: 「612년 살수대첩. 이 강은 아직 흐릅니다.」

인터랙션 요소:
  ① 을지문덕에게 고개 끄덕이기 (인식)
  ② 달리는 체험 (러닝 패드 권장)
  ③ 댐 레버 당기기 (VR 컨트롤러)
  ④ 강물 손 담그기 (햅틱 글러브 지원)
```


### VR 체험 콘텐츠 #4 — 「4왕국 시간여행」(프리미엄 풀코스)

```
등급: 프리미엄 코스 (45분) / 시점: 3인칭 관찰자

구성:
  ① 고구려 평양성 (10분): 을지문덕·고루
  ② 백제 사비성 (10분): 아랑·성충
  ③ 신라 경주 (10분): 하린·선덕여왕
  ④ 가야 낙동강 (10분): 니문
  에필로그 (5분): 4왕국 강 동시 화면

인터랙션:
  각 왕국에서 주인공과 대화 선택지
  역사 퀴즈 (선택 보상: 가상 굿즈 증정)
  사진 찍기 모드 (VR 내 셀카 → 실제 출력 가능)

특별 요소:
  4개 강(압록강·금강·낙동강·형산강)이 동시에 화면에 등장
  메인 테마 풀 오케스트라 + 코러스
  자막: 「강은 기억한다. 우리가 여기 있었음을.」
```

```
운영 기준:
  일일 최대 수용: 300명/일
```
