# 전투 메커니즘 설계 — 삼국(三國) IP 게임

**참조 문서**: `game-design-document.md`, `ui-ux-design.md`, `military-organization.md`, `tactics-guide.md`
**작성**: 게임본부 기획팀 (GAME-DESIGN)
**적용**: 삼국(三國) IP 전략 RPG 전투 시스템 전체 기준

---

## 전투 시스템 개요

```
게임 장르: 전략 RPG (실시간 전략 + 턴제 혼합)
전투 규모: 소규모(1:1~10:10) ~ 대규모(1000:1000)
시점: 아이소메트릭 (전략) + 클로즈업 (영웅 전투)

핵심 설계 원칙:
  역사 고증 전술 반영 (산성·기병·보급)
  캐릭터 개성이 전투 스타일에 반영
  지형·날씨가 전술 결정에 영향
  「영웅의 활약 > 수적 우위」체감
```

## 전투 유형

### 1. 야전 전투 (Field Battle)

```
발동 조건: 평원·丘陵 지형에서 양군 조우

진형 시스템:
  방진 (方陣): 보병 정사각 → 방어 +20%, 이동 -30%
  어린진 (魚鱗陣): 전면 집중 → 공격 +30%, 측면 취약
  학익진 (鶴翼陣): 양익 포위 → 포위 성공 시 섬멸
  장사진 (長蛇陣): 종대 행군 → 이동 +40%, 교전 불리

기병 돌격:
  개마무사 (고구려): 철기 기병 특수 돌격
    → 보병 진형 1회 관통 가능
    → 재사용 대기: 3턴
  화랑 기마 궁사 (신라): 이동 사격
    → 이동 중 원거리 공격 가능
    → 사거리 ×1.5, 명중 -20%

보급선 시스템:
  원정군: 매 5턴 보급 소모
  보급 0% 도달 시: 이동력 -50%, 전투력 -30%
  보급선 차단: 적이 후방 루트 점령 시 차단
  → 을지문덕 전술 재현 가능
```

### 2. 공성 전투 (Siege Battle)

```
발동 조건: 성곽 지형 공격 시

공성 단계:
  Phase 1 포위 (1~10턴):
    성 봉쇄 → 적 보급 차단 시작
    공성 장비 건설 가능
  Phase 2 공격 (11~30턴):
    투석기·충차 배치 → 성벽 내구도 감소
    성문 파괴 목표
  Phase 3 돌파 (성문 HP 0):
    성문 돌파 → 시가전 전환

수성 시스템:
  성벽 보너스: 방어 +50%, 원거리 사거리 +30%
  끓는 기름 (특수): 성문 접근 시 데미지 3배
  역습 타이밍: 공성군 분산 시 성문 역습 가능
  저수지: 수성 중 보급 자동 유지 (10턴)

안시성 특수 룰 (역사 재현):
  양만춘 성주 능력: 「88일의 의지」
    → 성 내구도 30% 이하에서 발동
    → 수비대 전 유닛 전투력 +50%, 사기 MAX
  토산 메커니즘:
    당군 5턴 연속 투자 → 토산 완성
    토산 완성 시 성벽 높이 이점 상실
    카운터: 수성군 역토산 구축 (4턴)
```

### 3. 해상 전투 (Naval Battle)

```
발동 조건: 해안·강 지형 교전

선박 유형:
  전함 (戰艦): 공격 특화, 이동 느림
  누선 (樓船): 원거리 공격 (궁병 탑승)
  쾌선 (快船): 빠른 이동, 공격 약함
  보급선: 전투 불가, 보급 전달

해전 특수 규칙:
  날씨 영향 극대화 (태풍: 전 유닛 이동 불가)
  화공 (火攻): 바람 방향 고려 → 역풍 시 자군 피해
  도강 전술: 강 도강 중 → 전투 불능 상태 2턴

기벌포 해전 재현:
  22연승 메커니즘:
    신라 수군 홈 지형 보너스 +30%
    나당 연합 분리: 당 수군 별도 이동 필요
    문무왕 능력: 「기벌포의 바람」
      → 풍향 임의 조작 1회
```

## 영웅 캐릭터 전투

### 고루 전투 스타일

```
분류: 중장기병 → 중보병 (말 전사 후)
역할: 탱커 + 돌파

스탯:
  공격: ★★★★☆ (85/100)
  방어: ★★★★★ (95/100)
  속도: ★★☆☆☆ (45/100)
  사거리: 근거리 (1칸)

스킬:
  기본 공격 「환두대도」:
    단일 적 강타, 높은 피해
    쿨다운: 1턴

  스킬 1 「철벽 방어」:
    3턴 동안 받는 피해 -40%
    주변 1칸 아군 방어도 +20% 공유
    쿨다운: 4턴

  스킬 2 「살수의 전략」:
    아군 1유닛에게 「유인 태세」부여
    유인 태세: 적이 해당 유닛 우선 공격
    유인 성공 시 적 유닛 위치 노출
    쿨다운: 5턴

  궁극기 「강은 기억한다」:
    살수 전투 재현 — 전장 내 강 타일에 범람 발동
    범람 구역 적 유닛: 이동 불가 2턴, 피해 대폭
    사용 조건: 강 타일 인접, 살수대첩 이벤트 이후 해금
    쿨다운: 10턴

성장:
  레벨업 시 방어 중심 성장
  「기벌포 생존」업적: 방어 +15% 영구 보너스
```

### 아랑 전투 스타일

```
분류: 비전투 영웅 (서포터)
역할: 정보·사기 지원

스탯:
  전투 참여: 불가 (직접 공격 없음)
  지원 범위: 아군 전체

스킬:
  스킬 1 「기록의 힘」:
    아군 유닛 1기에 전투 기록 부여
    해당 유닛: 사기 +30%, 전투 로그 저장
    사망 시 부활 1회 가능 (기록=불멸)
    쿨다운: 6턴

  스킬 2 「소도의 보호」:
    반경 2칸 「신성 구역」설정
    구역 내: 아군 피해 -25%, 적 추가 공격 불가
    쿨다운: 8턴

  스킬 3 「자수의 문양」:
    전장 일부 지역 백제 문양 설치
    아군 이동 시 체력 회복 + 사기 회복
    쿨다운: 5턴

  궁극기 「낙화암의 기억」:
    전장 내 아군 전체 사기 MAX 달성
    3턴 동안 아군 전체 피해 -30%, 공격 +10%
    사용 조건: 아군 유닛 3기 이상 전사 후 발동 가능
    설명: 「희생을 기억하는 자만이 이 힘을 발동할 수 있다」

게임 내 연출:
  아랑 전사 시: 자수 조각 바닥에 남음 → 아군 사기 영구 +5
  직접 전투 시: 「아랑은 전사가 아닙니다」안내 팝업
  예외: 바늘 방어 (1회) — 적 근접 공격 1회 무효화
```

### 하린 전투 스타일

```
분류: 경기병 + 기마 궁사
역할: 기동 딜러 + 정찰

스탯:
  공격: ★★★★☆ (80/100)
  방어: ★★☆☆☆ (40/100)
  속도: ★★★★★ (95/100)
  사거리: 2칸 (기마 궁사)

스킬:
  기본 공격 「단검 연격」:
    동일 적 2회 연속 공격 (각 60% 피해)
    쿨다운: 1턴

  스킬 1 「기마 사격」:
    이동 후 원거리 공격 가능
    이동 거리 최대 사용 시 사거리 +1
    쿨다운: 2턴

  스킬 2 「화랑의 돌격」:
    전방 직선 3칸 관통 이동 + 공격
    관통 경로 적 유닛 모두 피해
    쿨다운: 4턴

  궁극기 「관창의 이름으로」:
    관창 전사 이벤트 이후 해금
    아군 전체 공격 +40%, 이동 +1 (3턴)
    하린 자신: 무적 1턴 + 최대 속도 달성
    발동 시 음성: 「관창, 나 이길게.」
    쿨다운: 8턴

시즌별 성장:
  S1 하린: 충동적 — 스킬 쿨다운 단축, 자체 방어 감소
  S3 하린: 절제 — 스킬 피해 증가, 쿨다운 증가
  플레이어가 S1·S3 중 선택 가능 (스킨 시스템)
```

### 니문 전투 스타일

```
분류: 비전투 영웅 (기억·기록 특화)
역할: 전장 정보 + 사후 유산

스탯:
  전투 참여: 불가 (직접 공격 없음)
  특수 능력: 「기억」시스템 전용

스킬:
  스킬 1 「기억의 가야금」:
    전장 내 사망한 유닛의 전투 데이터 기록
    기록된 유닛 수 × 2% 아군 전체 경험치 보너스
    쿨다운: 없음 (패시브)

  스킬 2 「죽간의 기록」:
    전투 종료 후 전사한 유닛 목록 보관
    다음 전투에서 해당 유닛 「기억 소환」가능
    소환: 유닛의 50% 전투력으로 1턴 재참전
    쿨다운: 1전투 1회

  스킬 3 「가야금 선율」:
    근처 3칸 아군 공포·혼란 상태 해제
    피해 입은 아군 사기 회복 +50
    쿨다운: 4턴

  궁극기 「676 — 마지막 연주」:
    니문의 마지막 가야금 곡 연주
    전 아군 유닛: 마지막 1턴 동안 모든 능력 +100%
    니문 자신: 이후 전투에서 에필로그 버전으로 변경
    사용 조건: 최종 전투 (기벌포) 한정 1회
    설명: 「소리는 사라지지 않는다」
```

## 전략 레이어 시스템

### 보급·경제

```
보급 계산:
  기본 보급: 도시·마을 점령 수 × 100 (1턴)
  원정 소모: 아군 유닛 수 × 5 (1턴)
  보급 과잉: +20% 사기 / 보급 부족: -30% 전투력

교역 시스템:
  가야 철: 보급 +50%, 무기 업그레이드 가능
  백제 비단: 외교 옵션 확대
  신라 금: 용병 고용 가능
  고구려 모피: 혹한 페널티 면제
```

### 외교·동맹

```
동맹 시스템:
  나당연합: 신라 + 당 합동 작전 가능
  여제동맹: 고구려 + 백제 연대
  혼인 동맹: 귀족 혼인 → 영구 동맹 옵션

배신 메커니즘:
  동맹 신뢰도: 0~100
  신뢰도 30 미만: 배신 이벤트 발생 가능
  나당전쟁 이벤트: 당 동맹 → 적대 전환
```

## 역사 이벤트 시스템

```
자동 발동 이벤트 (역사 고증):

E-001 살수대첩 (612년):
  조건: 수나라 침공 → 고구려 영토 진입
  을지문덕 합류 + 살수 댐 설치 선택지 등장
  선택: 댐 개방 (역사 루트) / 정면 대결 (역사 외 루트)

E-002 안시성 전투 (645년):
  조건: 당 태종 직접 침공 이벤트
  양만춘 성주 합류 + 88일 카운트 시작
  특수 목표: 88턴 이상 버티기 → 역사 재현 달성

E-003 황산벌 전투 (660년):
  조건: 나당연합 백제 공격
  관창 이벤트: 16세 화랑 돌격 선택 (승인/거절)
  승인 시: 신라군 사기 +50, 관창 전사
  거절 시: 사기 보너스 없음, 관창 생존

E-004 기벌포 해전 (676년):
  조건: 나당전쟁 최종전
  22연승 목표 달성 시 삼국통일 진정한 완성 엔딩
  목표 미달성 시: 불완전한 통일 엔딩
```
