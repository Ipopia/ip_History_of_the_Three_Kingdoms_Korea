## 콘서트 개요

```
공연명: 삼국(三國) OST 콘서트 — 「강은 기억한다」
부제: THE RIVER REMEMBERS IN CONCERT

형식: 영상 + 라이브 오케스트라 + 국악 앙상블
규모: 풀 오케스트라 (60인) + 국악 섹션 (12인) + 코러스 (20인)
러닝타임: 2시간 (인터미션 20분 포함)

초연: 2027년 3월 (세종문화회관 대극장)
추가 공연:
  서울: 세종문화회관 (5회)
  부산: 벡스코 오디토리움 (2회)
  일본: 도쿄 국제포럼 (3회), 오사카 페스티벌홀 (2회)
  해외: 싱가포르 + 뉴욕 (2027 하반기)

음악 감독: 사운드본부 OST팀 (AUDIO-OST)
지휘: 초청 지휘자 (세계적 명성의 동아시아 전문 지휘자)
```

## 1부 셋리스트 (55분)

### 오프닝 시퀀스

```
#01: 「강의 서막 (Prelude of the River)」
  편성: 가야금 솔로 → 현악 추가 → 풀 오케스트라
  영상: 한반도 강물 4K 파노라마 (압록강·청천강·금강·낙동강)
  시간: 5분
  의미: 4왕국 모두가 시작되기 전의 고요함

#02: 「고구려 — 삼족오의 노래 (Song of the Three-Legged Crow)」
  편성: 해금 + 아쟁 유니즌 → 금관 + 타악
  영상: 고구려 평양성 + 압록강 새벽 CG
  시간: 4분 30초
  특이사항: 무대 조명 — 고구려 암청 (#2F4F7F)

#03: 「고루 테마 — 철의 의지 (Iron Will)」
  편성: 해금 솔로 → 현악 전체 + 저음 타악
  영상: 고루 캐릭터 하이라이트 클립 (시즌 1~2)
  시간: 4분
  클라이맥스: 안시성 장면에서 풀 오케스트라

#04: 「살수대첩 (Battle of Salsu)」
  편성: 7/8박자 타악 → 현악 폭발 → 풀 오케스트라
  영상: 살수대첩 전투 씬 하이라이트
  시간: 6분
  연주 특이사항: 7/8박자 → 4/4박자 전환 (클라이맥스)
```

### 백제 섹션

```
#05: 「백제 — 금강의 노래 (Song of the Geum River)」
  편성: 가야금 아르페지오 + 대금 선율
  영상: 금강 일몰 + 사비성 궁궐 CG
  시간: 4분
  조명: 백제 왕실금 (#B8960C)

#06: 「아랑 테마 — 기록하는 손 (Writing Hands)」
  편성: 가야금 + 플루트 → 첼로 솔로 (비극 전환)
  영상: 아랑 서고 씬 + 성충과의 대화 클립
  시간: 4분 30초
  특이사항: 죽간 쓰는 소리 = 타악 서브 리듬 효과

#07: 「성충의 서간 (Seongchung's Letter)」
  편성: 피아노 솔로 → 현악 (세피아 조명)
  영상: 성충 투옥 씬 + 아랑의 눈물 씬
  시간: 3분 30초
  분위기: 콘서트 전체에서 가장 조용한 곡
```

### 신라 섹션

```
#08: 「신라 — 황금의 빛 (Golden Light of Silla)」
  편성: 태평소 + 편경 → 트럼펫 + 황금 심벌즈
  영상: 경주 황금 유물 + 화랑 훈련 씬
  시간: 4분
  조명: 신라 황금 (#FFD700) + 스포트라이트 폭발

#09: 「하린 테마 — 화랑의 빛 (Light of the Hwarang)」
  편성: 트럼펫 → 금관 풀 섹션 + 타악
  영상: 하린 전투 씬 + 선덕여왕과의 장면
  시간: 5분
  클라이맥스: 황산벌 전투 장면에서 코러스 추가

#10: 「선덕여왕 (Queen Seondeok)」
  편성: 바이올린 솔로 + 가야금
  영상: 선덕여왕 사망 씬 + 하린의 울음
  시간: 3분
  조명: 따뜻한 황금 → 서서히 어두워짐
```

### 가야 섹션

```
#11: 「가야 — 사라진 왕국의 노래 (Song of the Lost Kingdom)」
  편성: 가야금 솔로 (단독)
  영상: 낙동강 + 가야 터 유적지 영상
  시간: 4분
  특이사항: 오케스트라 전체 침묵 — 가야금만
  조명: 가야 토황 (#C8A96E) + 아주 희미한 조명

#12: 「니문 테마 — 12번째 악곡 (The 12th Melody)」
  편성: 가야금 솔로 → 점점 현악 추가
  영상: 니문 연주 씬 + 12번째 현 앞에서 멈추는 장면들
  시간: 5분
  구성: 4음 반복 → 5음 → 점점 가까워지는 완성
  클라이맥스: 12번째 완성 직전에서 인터미션 암시로 끊김

→ INTERMISSION (20분)
```

## 2부 셋리스트 (55분)

### 전쟁 섹션

```
#13: 「전운 (Clouds of War)」
  편성: 저음 현악 + 타악 (오스티나토)
  영상: 3국 전쟁 전야 장면들
  시간: 4분
  분위기: 긴장과 예감

#14: 「황산벌 (Battle of Hwangsanbeol)」
  편성: 7/8박자 → 완전한 4/4 전투 리듬
  영상: 황산벌 전투 편집 (계백 vs 하린)
  시간: 7분
  특이사항: 관창 장면에서 코러스 투입
  클라이맥스: 가장 큰 타악 폭발

#15: 「계백 (Gyebaek)」
  편성: 금관 비장한 코랄 → 현악 유니즌
  영상: 계백 전사 씬 (하린의 눈빛으로만 묘사)
  시간: 4분
  조명: 붉은 조명 → 암전 → 흰 조명
```

### 멸망 섹션

```
#16: 「사비성의 불 (Fire of Sabi-seong)」
  편성: 피아노 + 첼로 솔로
  영상: 백제 멸망 아랑 시점 씬
  시간: 3분 30초
  분위기: 콘서트 전체 감정의 바닥

#17: 「고구려 최후 (The Last Stand of Goguryeo)」
  편성: D 도리아 선율 — 해금 솔로 → 현악 카논
  영상: 고루 평양성 방어 씬
  시간: 5분
  클라이맥스: 코러스 「여기 있었다 (We Were Here)」

#18: 「668년 (Year 668)」
  편성: 현악 피치카토 (침묵 암시) + 대금 독주
  영상: 고구려 멸망 순간 — 고루의 눈
  시간: 4분
  특이사항: 가장 조용한 대목에서 가야금 단음 삽입
```

### 피날레

```
#19: 「니문의 12번째 (Nimun's 12th)」
  편성: 가야금 솔로 → 현악 → 풀 오케스트라 + 코러스
  영상: 니문이 마지막 현을 치는 장면 (시즌 1 피날레)
  시간: 6분
  구성:
    0~2분: 가야금 솔로 — 1~11음
    2~4분: 현악 합류 — 점점 상승
    4~5분: 12번째 음 — 전체 오케스트라 + 코러스 폭발
    5~6분: 완성 → 모달 전환 F#m → F#M (단조→장조)
  클라이맥스: 콘서트 전체 최고조

#20: 「강은 기억한다 — 메인 테마 (Main Theme)」
  편성: 가야금 V1 → 현악 V2 → 풀 오케스트라 V3 → 코러스 V5
  영상: 4인 각자의 강 장면 교차 → 현대 강물 에필로그
  시간: 8분
  코러스 가사 (한국어):
    「강은 기억한다
     우리가 여기 있었음을
     싸웠음을, 기록했음을
     노래했음을, 살아있었음을」
  마지막: 강물 영상 + 서서히 암전

앙코르 #1: 「4왕국 메들리 (Four Kingdoms Medley)」
  4왕국 테마 메들리 — 5분

앙코르 #2: 「강이 흐른다 (The River Flows)」
  메인 테마 어쿠스틱 버전 — 가야금 + 피아노
  3분 30초
```
