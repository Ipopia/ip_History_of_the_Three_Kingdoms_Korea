## 삼국시대 이름 체계 개요

### 역사적 배경

삼국시대(BC 57~668 AD)의 이름은 크게 세 층위로 구성된다:

1. **고유 한국어 이름**: 순수 한국어 발음 기반 — 주몽(朱蒙), 소서노(召西奴)
2. **한자 이름**: 중국 한자 문화 영향 — 유리명왕(琉璃明王), 광개토(廣開土)
3. **칭호·직함**: 왕호·관등으로 구성된 복합 이름

## 왕호(王號) 작명 원칙

### 고구려 왕호 체계

| 왕호 유형 | 특징 | 예시 |
|---------|------|------|
| ~왕(王) | 기본형 | 동명왕·유리왕 |
| ~태왕(太王) | 대왕급 존칭 | 광개토태왕 |
| 시호(諡號) | 사후 추증 | 고국천왕·산상왕 |
| 별칭 | 업적 기반 | 광개토(廣開土: 넓은 땅을 개척한) |

**고구려 왕호 명명 패턴**:
```
지명 + 왕: 동천왕(東川王), 서천왕(西川王)
업적 + 왕: 광개토왕(廣開土王)
시기 + 왕: 고국원왕(故國原王)
```

### 백제 왕호 체계

| 왕호 유형 | 특징 | 예시 |
|---------|------|------|
| ~왕(王) | 기본형 | 온조왕·다루왕 |
| 한자 미칭 | 덕목 강조 | 근초고왕(近肖古王) |
| 지명 연결 | 수도 연관 | 사비왕 |

**백제 왕호 특징**: 고구려보다 한자 미칭 비중 높음 — 중국 문화권 친화성 반영

### 신라 왕호 체계

신라는 시기별로 왕호 체계가 변화:

| 시기 | 호칭 | 의미 |
|------|------|------|
| 초기 | 거서간(居西干) | 지도자 (고유어) |
| 중기 | 이사금(尼師今) | 연장자·지혜로운 자 |
| 후기 | 마립간(麻立干) | 대수장 |
| 통일 전후 | 왕(王) | 한자 왕호 채택 |

**신라 작명 특징**: 고유 한국어 호칭을 가장 오래 유지한 왕국

## 인물 이름 작명 가이드 (창작 인물용)

### 왕국별 이름 DNA

**고구려 창작 인물 이름**
```
특징: 강하고 짧은 발음, 北방 기운
자음 선호: ㄱ·ㅂ·ㄷ·ㄹ (강한 파열음)
모음: ㅏ·ㅜ·ㅡ (어둡고 깊은 음)

예시 패턴:
- 남성: 무덕(武德)·강수(剛守)·철웅(鐵雄)
- 여성: 부여(扶餘)·단아(端雅)·설화(雪花)
- 창작 예시: 뇌성(雷聲), 북진(北振), 암벽(岩壁)
```

**백제 창작 인물 이름**
```
특징: 우아하고 부드러운 발음, 문화적 세련미
자음 선호: ㅅ·ㄴ·ㅎ·ㅁ (부드러운 음)
모음: ㅣ·ㅔ·ㅓ (밝고 맑은 음)

예시 패턴:
- 남성: 해명(海明)·백선(白善)·금정(金貞)
- 여성: 설비(雪飛)·연화(蓮花)·옥선(玉善)
- 창작 예시: 비류(沸流), 청강(淸江), 화미(花美)
```

**신라 창작 인물 이름**
```
특징: 황금·하늘·신성 연상, 고유어 잔재
자음 선호: ㅈ·ㅊ·ㅅ (청명한 음)
모음: ㅛ·ㅑ·ㅕ (높고 밝은 음)

예시 패턴:
- 남성: 유신(庾信)·진춘(眞春)·하늘 (고유어)
- 여성: 선화(善花)·야명(夜明)·별이 (고유어)
- 창작 예시: 금강(金剛), 천명(天命), 화랑(花郞)
```

**가야 창작 인물 이름**
```
특징: 역동적이고 실용적, 바다·철 연상
자음 선호: ㄱ·ㅈ·ㅂ
모음: ㅏ·ㅗ·ㅜ

예시 패턴:
- 남성: 철웅(鐵雄)·수로(首露)·강철
- 여성: 황옥(黃玉)·가야(伽耶)·모래
- 창작 예시: 쇠불(쇠+불), 해풍(海風), 동야(銅也)
```

## 계층별 이름 규칙

### 왕족 이름
```
규칙:
- 반드시 한자 이름 병기
- 2~3음절 (단음절 불허)
- 덕목·자연·지명에서 차용
- 시호(사후 추증명)와 생전 이름 구분

예시: 광개토(廣開土)·문무(文武)·선덕(善德)
금지: 너무 평범한 이름, 현대적 감각의 이름
```

### 귀족·장군 이름
```
규칙:
- 한자 이름 권장 (고유어도 허용)
- 성씨 + 이름 구조 가능
- 직위·출신지 반영 가능

예시: 을지(乙支)문덕·김(金)유신·계(階)백
성씨: 김·박·석(신라) / 해·진·사·연(고구려) / 부여(백제)
```

### 민중 이름
```
규칙:
- 고유 한국어 이름 비중 높음
- 직업·외모·특징 반영
- 단음절~2음절 선호

예시: 쇠돌이(대장장이), 봄이, 돌쇠, 강이
가야 장인: 철웅·불씨·망치손
```

### 승려 법명
```
규칙: 불교 한자 2음절
예시: 원효(元曉)·의상(義湘)·혜통(惠通)·자장(慈藏)
패턴: 덕목(德·慈·惠·元) + 방위·자연(曉·湘·空·明)
```

## 지명 작명 원칙

### 왕국 지명 패턴

**고구려 지명**
```
성(城)·곡(谷)·원(原) 결합이 많음
예: 평양성·안시성·요동성·졸본(卒本)
작명 시: 지형 + 방위 + 성/곡/원
예시 창작지명: 북령성(北嶺城)·철곡(鐵谷)
```

**백제 지명**
```
강(江)·벌(伐)·촌(村) 결합
예: 사비성·웅진·한성·백마강
작명 시: 자연물 + 문화적 미칭
예시 창작지명: 금강촌·연화벌
```

**신라 지명**
```
벌(伐)·라(羅)·야(野) 고유어 잔재
예: 서라벌·계림·금성
작명 시: 고유어 음차 + 한자 이중 표기
예시 창작지명: 황금벌·별빛야
```

**가야 지명**
```
가야(伽耶)·포(浦)·진(津) 결합 — 해상 교역 반영
예: 금관가야·김해·대가야
작명 시: 철·해양 관련 어휘
예시 창작지명: 철포(鐵浦)·쇠진(津)
```

## 로마자 표기 작명 기준

### 창작 인물 로마자 표기 원칙
```
기준: 국립국어원 로마자 표기법
성+이름 분리: Kim Yu-sin (성과 이름 사이 공백)
이름 내 하이픈: Yu-sin (2음절 이름)

예외:
- 국제적으로 이미 알려진 표기 우선: Jumong (주몽)
- 단음절 이름: 하이픈 불필요
```

### 창작 지명 로마자 표기
```
성(城) → -seong: 평양성 → Pyeongyang-seong
강(江) → River: 백마강 → Baengma River
벌(伐) → -beol / Plain: 황산벌 → Hwangsanbeol
```

## 금지 사항

### 이름 작명 금지 항목
```
❌ 현대 한국어 신조어 이름 (예: 수빈·지원·유나 등 현대 감각)
❌ 일본식 한자 독음 이름 (한국 IP이므로 한국 독음 준수)
❌ 중국 역사 인물과 동일한 이름 (혼동 방지)
❌ 고구려 인물에 백제 성씨 사용 (김·박은 신라 성씨)
❌ 뜻 없이 발음만 화려한 이름 (의미 없는 한자 나열)
```

### 역사 인물 이름 사용 금지
```
주요 역사 인물의 이름을 창작 인물에 그대로 사용 금지:
❌ 광개토대왕·을지문덕·계백·선덕·김유신 등 실명 직접 사용
→ 창작 인물은 유사하되 다른 이름 사용

허용: 역사 인물의 한자를 재조합하여 새 이름 창작
예: 을지(乙支) + 다른 한자 → 을지강(乙支剛)
```

## 자문 활용 가이드

이름·지명 작명 시 다음 순서로 검토:
```
Step 1: 해당 왕국 이름 DNA 확인
Step 2: 계층에 맞는 규칙 적용
Step 3: 한자 의미 검증 (의도하지 않은 부정적 의미 제거)
Step 4: 발음 테스트 (대사 속 자연스러움 확인)
Step 5: 로마자 표기 확정
Step 6: glossary.md 등재
```
