# 용어사전 (Glossary)

> **프로젝트**: 한국 삼국시대 IP — 삼국사기(三國史記) 기반
> **문서 성격**: 전체 프로젝트의 **절대 기준 문서**. 모든 팀원은 이 문서의 표기를 따른다.
> **최종 수정**: 2026-02-18
> **버전**: 1.0

## 범례

- 한글 표기를 **정본(正本)**으로 한다.
- English 표기는 Revised Romanization을 기본으로 하되, 국제적 관용 표기가 있는 경우 병기한다.
- 漢字는 원전(삼국사기·삼국유사) 표기를 따른다.
- 분류 약어: **왕국**(Kingdom) / **인물**(Person) / **관직**(Title) / **지명**(Place) / **문화**(Culture) / **신화**(Myth) / **군사**(Military) / **외교**(Diplomacy) / **종교**(Religion) / **유물**(Artifact)

```
  1. 서동요 (薯童謠) — 아랑 관련 민요 장면 참조
  2. 혜성가 (慧星歌) — 신라 화랑 관련 노래
  3. 모죽지랑가 (慕竹旨郞歌) — 화랑 추모, 하린 씬 참조
  4. 찬기파랑가 (讚耆婆郞歌) — 화랑 찬미, 하린 묘사 참조
  5. 제망매가 (祭亡妹歌) — 이별·슬픔, 니문 장면 참조

인용 기준:
  원문 인용 시: 향찰 원문 + 현대어 번역 병기
  창작 변용 시: 「향가 참조」표시
```

### 번역·표기 금지 사항

```
절대 금지:
  「임나일본부(任那日本府)」표현 — 역사 왜곡 방지
  고대 한국어를 일본어 계통과 동일시하는 표현
  동북공정(東北工程) 관점 반영 (고구려 = 중국사 주장 금지)

주의 요망:
  가야-왜 관계: 「교역 거점」으로만 표현
  백제-왜 관계: 「문화 전파」+ 「선택적 군사 협력」
  한자 사용: 한국식 음독 기준 (일본식 음독 금지)
```

### 작명 원칙

```
핵심 3원칙:
  ① 역사적 정확성 우선: 실존 인물·지명은 삼국사기·삼국유사 표기 기준
  ② 왕국별 음운 정체성: 각 왕국 고유 언어 특성 반영
  ③ 현대적 가독성 확보: 과도한 고어 회피, 독자 친화성

표기 우선순위:
  1순위: 삼국사기 한자 표기
  2순위: 삼국유사 표기 (삼국사기 누락 시)
  3순위: 중국 정사 (魏書·隋書·唐書) 외래 표기
  4순위: 창작팀 신조 (역사적 공백 창작 시)
```

### 왕국별 이름 체계 (작명 기준)

```
고구려 이름 패턴:
  어두 자음: ㄱ·ㅁ·ㄴ·ㅂ 계열 선호 / 두 음절~세 음절
  「고루(高婁)」: 高(고) + 婁(루) = 높은 태양별 / 하늘 높이 빛나는 자
  역사 인명: 을지문덕(乙支文德)·연개소문(淵蓋蘇文)·양만춘(楊萬春)

백제 이름 패턴:
  어두: ㅅ·ㅇ·ㅎ 부드러운 자음 / 한자: 花·玉·雅·智 선호
  「아랑(雅朗)」: 雅(아) + 朗(랑) = 우아하고 맑은 풍모
  역사 인명: 의자왕(義慈王)·계백(階伯)·흑치상지(黑齒常之)

신라 이름 패턴:
  불교식: 선(善)·진(眞)·명(明) 계열 / 화랑: 郎(랑) 접미
  「하린(霞麟)」: 霞(하) + 麟(린) = 노을빛 기린 / 황금빛 신수 기개
  역사 인명: 김유신(金庾信)·관창(官昌)·선덕여왕(善德女王)

가야 이름 패턴:
  부드러운 유성음: ㄴ·ㄹ·ㅁ / 음악·자연·슬픔·아름다움 뉘앙스
  「니문(尼文)」: 尼(니) + 文(문) = 예악을 아는 자 / 소리로 기억하는 자
  역사 인명: 수로왕(首露王)·우륵(于勒)·허황옥(許黃玉)
```

### 지명 표기 및 로마자 기준

```
고구려 지명 형성소:
  「홀(忽)」: ~성 (평양홀) / 「나(那)」: ~강·~땅 / 「달(達)」: ~산

주요 지명 로마자:
  평양성 → Pyeongyang Fortress
  안시성 → Ansi Fortress
  황산벌 → Hwangsanbeol Plains
  사비성 → Sabi Fortress
  살수 → Salsu River (Cheongcheon-gang)

주요 인명 로마자:
  고루 → Goru / 아랑 → Arang / 하린 → Harin / 니문 → Nimun
  을지문덕 → Eulji Mundeok / 연개소문 → Yeon Gaesomun
  계백 → Gyebaek / 김유신 → Kim Yusin

왕국명 로마자:
  고구려 → Goguryeo / 백제 → Baekje / 신라 → Silla / 가야 → Gaya
```
