## 신화 생물 묘사 원칙

```
원칙:
1. 한국 고대 문헌 기반 (삼국사기·삼국유사·동국이상국집)
2. 불교·도교·무속 교차 참조
3. 서사적 기능 부여 — 단순 배경 존재 아님
4. 왕국별 신화 생물 차별화 — 세계관 풍부화

등장 방식:
  실재형: 서사 내 실제 등장·상호작용
  상징형: 문양·이야기·예언 속 등장
  비전형: 주인공만 목격 (신뢰성 모호)
```

## 고구려 신화 생물

### 삼족오 (三足烏) — 태양의 새

```
기원: 고구려 고분 벽화 (삼실총·오회분 등) 다수 확인
    동아시아 공통 — 태양 속 세 발 까마귀
사료 근거: ★★★ (고분 벽화 직접 확인)

외형:
  형태: 까마귀 + 세 번째 발 (가운데 발 하나 추가)
  크기: 성인 남성 팔 길이 (IP 창작 기준)
  색상: 검정 + 붉은 눈 + 발톱 황금
  특이: 날개 끝 불꽃 효과

서사적 의미:
  고구려의 국가 상징 — 태양·하늘·힘
  고루의 수호 존재 (꿈·예언 형태로 등장)
  을지문덕과의 관계: 을지문덕 EP07 퇴장 씬에서 삼족오 1마리 날아오름

IP 설정:
  등장 형식: 비전형 (고루만 목격)
  의미: 「아직 끝이 아니다」의 신호
  드라마 연출: 중요한 전투 전후 하늘에 짧게 등장
  고분 벽화 연결: 고구려 유적지 배경 씬에서 문양으로 상징형 등장

금기:
  삼족오를 악으로 묘사 금지
  타 왕국 상징으로 혼용 금지
```

### 현무 (玄武) — 북방 수호신

```
기원: 사신 (四神) — 현무·청룡·백호·주작
    고구려 고분 벽화 (강서대묘) 확인
사료 근거: ★★★

외형:
  형태: 거북 + 뱀이 엉킨 형상
  크기: 성채 규모 (상징적 거대함)
  색상: 검정·남색·회색

서사적 의미:
  북방 방어 — 고구려 북부 수호
  을지문덕 관련: 살수대첩 전야 현무 꿈 (을지문덕 비전)
  강과 연결: 압록강 수호 — 강이 기억하는 존재

IP 설정:
  등장 형식: 상징형 (고분 벽화·꿈 속)
  드라마 연출: 음악 + 물 이펙트로 현무 암시
  게임: 고구려 최상위 수호 스킬 시각화
```

## 백제 신화 생물

### 봉황 (鳳凰) — 왕실의 새

```
기원: 중국·한국 공통 상서로운 새
    백제 금동 대향로 상단 봉황 확인
사료 근거: ★★★ (유물 직접 확인)

외형:
  형태: 오색 빛 새 — 공작·학·독수리 합성
  크기: 독수리 3배 (왕실 전용 크기)
  색상: 오색 (붉음·청·황·흰·검정) — 백제 왕실금 강조

서사적 의미:
  백제 왕실 권위·축복의 상징
  성충과의 관계: 성충이 옥중 마지막 날 봉황 환시
  아랑의 기록: 봉황 문양이 아랑 두루마리 표식

IP 설정:
  등장 형식: 비전형 (성충 환시) + 상징형 (문양)
  의미: 「백제의 혼은 사라지지 않는다」
  드라마: 백제 멸망 씬 직후 봉황 문양 클로즈업 (아랑의 두루마리)
```

### 백룡 (白龍) — 백마강의 수호자

```
기원: 백마강 (白馬江) 전설 — 龍이 사는 강
    「의자왕이 백마강에서 용을 보았다」유사 기록
사료 근거: ★☆☆ (창작 비중 높음)

외형:
  형태: 흰 비늘 용
  서식: 백마강 수면 아래
  색상: 흰색 + 금빛 비늘 테두리

서사적 의미:
  백마강 = 백제의 기억 저장소
  백제 멸망 씬: 백마강에서 흰 안개 피어오름 (백룡의 슬픔 암시)
  아랑의 마지막 장면: 백마강 건너며 물 속 움직임 감지 (독자 해석 여지)

IP 설정:
  등장 형식: 비전형 (해석 모호)
  드라마 연출: 실체 미확인 — 물 움직임·흰 안개만 표현
  의미: 「강은 살아있다」의 시각적 은유
```

## 신라 신화 생물

### 해태 (獬豸) — 정의의 수호자

```
기원: 한국 전통 신수 — 선악 판별 능력
    경복궁 해태상 등 전국 유적 확인
사료 근거: ★★☆

외형:
  형태: 사자 + 뿔 하나 (이마 중앙)
  크기: 성인 남성 어깨 높이
  색상: 회백색 + 눈 황금

서사적 의미:
  신라 법과 정의 — 화랑 세속오계의 수호자
  하린과의 관계: 화랑 입단 의식 시 해태 형상 환시
  선덕여왕 예언 씬: 해태가 조용히 나타나 사라짐

IP 설정:
  등장 형식: 비전형 (하린·선덕여왕 비전)
  의미: 「올바른 길을 가고 있다」
  뮤지컬: 정의 갈등 장면 해태 형상 조명 연출
```

### 이무기 — 용이 되지 못한 자

```
기원: 한국 전통 — 천 년 수련 후 용이 되는 큰 뱀
    이무기 관련 설화 다수 전래
사료 근거: ★★☆

외형:
  형태: 거대한 뱀 (용에 가깝지만 뿔 없음)
  서식: 큰 강·깊은 연못
  색상: 검청·회색 비늘

서사적 의미:
  「완성되지 못한 것들에 대한 이야기」
  가야 니문 연결: 12번째 악곡 = 이무기의 여의주
                 (완성 = 용이 됨 = 진정한 계승)
  대조: 삼족오(완성된 힘) vs 이무기(미완성 가능성)

IP 설정:
  등장 형식: 상징형 (니문의 꿈·음악 속 이미지)
  의미: 아직 완성되지 않은 것들의 희망
  드라마: 니문의 연주 중 물에 비치는 이무기 형상 (1컷)
```

## 가야 신화 생물

### 하얀 물고기 (白魚) — 낙동강의 안내자

```
기원: 가야 건국 신화 (수로왕 관련 설화)
    낙동강 관련 토속 신앙
사료 근거: ★☆☆ (창작 비중 높음)

외형:
  형태: 보통 물고기 크기 → 특별한 순간 발광
  색상: 흰색 + 비늘 금빛 발광

서사적 의미:
  가야 유민의 길 안내자
  니문이 방황할 때 낙동강에서 발광하는 흰 물고기 목격
  「아직 가야가 이 강에 살아있다」의 상징

IP 설정:
  등장 형식: 비전형 (니문 목격, 독자는 해석 여지)
  의미: 사라진 것들의 안내
  드라마: 니문의 낙동강 씬 — 짧은 발광 물고기 1컷
```

### 구미호 (九尾狐) — 금기와 유혹

```
기원: 한국·중국·일본 공통 신화
    삼국유사 등에 간접 언급
사료 근거: ★★☆

외형:
  형태: 황금 여우 + 꼬리 9개
  크기: 성인 여성 정도
  색상: 황금 + 여우 주황

서사적 의미:
  경계 넘기·금기·변신의 상징
  삼국 경계 지역 = 구미호가 사는 곳 (4왕국 어디에도 속하지 않는 존재)
  니문과의 연결: 가야 유민 = 어느 나라에도 속하지 않는 존재 은유

IP 설정:
  등장 형식: 상징형 (이야기 속, 직접 등장 없음)
  의미: 「경계에서 사는 것들의 이야기」
  용도: 마케팅 비주얼 서브 요소 (굿즈 등)
```

```
왕국 연계: 신라
```

### 하백 (河伯) — 강의 신

```
기원: 삼국사기 고구려본기 (주몽 신화)
분류: 신(神) / 수신(水神)
연계: 고구려·강 전체
사료 근거: ★★★ (삼국사기 직접 기록)

외형 (현현 시):
  형태: 노인 + 물고기 비늘 갑옷
  크기: 강물 위에 서 있음 (반투명)
  색상: 청록 + 은빛

  주몽의 외조부
  강을 지배하는 존재 = 강을 건너는 자들을 심판
  해모수와의 대결에서 패배했으나 딸 유화를 통해 고구려를 낳음

IP 설정:
  등장 형식: 상징형 (꿈·강물 반사 속 환시)
  드라마 연출: 살수 방류 장면에서 하백의 얼굴이 물에 보임 (환상)
  을지문덕이 강물에 들어갈 때 하백의 존재감
  게임: 강 타일 내 적 유닛 행동력 -50%, 도하 저지/지원

금기:
  하백을 단순 적 NPC로 묘사 금지
  주몽 신화와의 서사적 연결 유지 필수
```

### 청룡 (靑龍) — 동방 수호신

```
기원: 사신 (四神) — 동쪽 수호
    고구려 강서대묘 사신도 벽화 확인
사료 근거: ★★★

외형:
  형태: 비늘 청록색, 뿔 1쌍, 발톱 5개, 구름 속 비행
  강서대묘 원본 벽화 기반 → 유연하고 역동적

서사적 의미:
  동쪽·봄·목(木)기운
  고구려의 수호 상징
  사신도 4방위 체계의 핵심 존재

IP 설정:
```
