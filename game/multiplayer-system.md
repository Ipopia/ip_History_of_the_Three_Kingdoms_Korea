# 멀티플레이어 시스템 — 삼국(三國) IP

**참조 문서**: `gdd-three-kingdoms.md`, `pvp-system.md`, `battle-system-detail.md`, `unit-design-guide.md`
**작성**: 게임본부 기획팀 (GAME-DESIGN)
**적용**: 삼국(三國) IP 게임 멀티플레이어 모드 설계 기준

---

## 멀티플레이어 전략 개요

```
포지셔닝:
  솔로 캠페인 = 역사 서사 몰입
  멀티플레이어 = 지속 플레이·커뮤니티 형성

핵심 가치:
  「역사의 재연」— 실제 역사 전투 구도 재현
  「왕국의 자존심」— 왕국별 팬덤 경쟁 구조
  「전략의 깊이」— 단순 클리커 ×, 전술 격차 유의미

멀티플레이어 모드:
  MODE A: 1v1 전략 대전 (랭크)
  MODE B: 2v2 동맹전 (협력)
  MODE C: 4왕국 대전 (4플레이어)
  MODE D: 살수대첩 재현전 (PvE 협력)
  MODE E: 왕국 길드전 (주간 리그)
```

---

## MODE A: 1v1 전략 대전

```
기본 규칙:
  각자 왕국 1개 선택
  동일 왕국 선택 가능 (거울 매칭)
  승리 조건: 상대 수도 점령 또는 항복

밴픽 시스템:
  각 플레이어: 1개 왕국 금지 + 1개 왕국 선택
  특수 유닛 각 1개 금지 가능

턴 구조:
  실시간 전략 (RTS) 기반
  명령 입력 3초 딜레이 → 동시 실행 (전략 사고 강제)
  최대 매치 시간: 20분 (초과 시 점수제)

랭크 시스템:
  하급: 보병 / 중급: 기병 / 상급: 장수 / 최상급: 대장군
  시즌 리셋: 3개월 / 시즌 보상: 전용 스킨·칭호

왕국별 특성 (밸런스):
  고구려: 방어 +20%, 기동 -10% — 수성 유리
  백제: 외교 포인트 +30%, 해군 전력 +25%
  신라: 영웅 스킬 쿨다운 -20%, 기병 +15%
  가야: 철 생산 +40%, 병력 수 -15% — 소수 정예
```

---

## MODE B: 2v2 동맹전

```
팀 구성:
  팀 A (2인) vs 팀 B (2인)
  같은 팀: 자원 공유 가능
  다른 왕국끼리 동맹 가능 (역사 재현 또는 역사 역전)

협력 메커닉:
  동맹 지원: 아군 영토에 증원 파견
  공동 외교: 중립 소국에 공동 제안
  역할 분담: 한 명 경제, 한 명 군사 특화

역사 동맹 보너스:
  나당연합 (신라+당 대역): 공격력 +10%
  여제동맹 (고구려+백제): 방어력 +10%
  가야-백제 동맹: 철 교역 보너스
```

---

## MODE C: 4왕국 대전

```
구성: 4명 각자 다른 왕국 (고구려·백제·신라·가야)

승리 조건:
  단독 승리: 다른 3왕국 모두 점령
  동맹 승리: 2왕국 연합 → 나머지 2왕국 점령
  생존 승리: 마지막 수도 보유 왕국

외교 시스템:
  비밀 협약: 2:2 분열 유도
  배신 가능: 협약 파기 → 신뢰도 하락 (다음 매치 외교 페널티)
  대화창: 실시간 채팅 (전략 소통 + 심리전)

역사 시나리오 모드:
  「667년 — 나당연합의 압박」
  신라+당(AI): 고구려·백제 협공
  플레이어: 고구려 또는 백제 선택
  역사 역전 도전: 삼국 통일 저지
```

## MODE D: 살수대첩 재현전 (PvE 협력)

```
구성: 1~4인 협력 vs AI 수나라

역사 설정:
  612년 살수대첩
  수나라 AI: 113만 병력 (단계적 증원)
  플레이어: 고구려 방어

단계별 미션:
  Stage 1: 요동성 방어 (10턴)
  Stage 2: 7번 후퇴 수행 (청야전술 실행)
  Stage 3: 살수 매복 설치 (지형 활용)
  Stage 4: 살수 방류 + 섬멸전

특수 규칙:
  역사 충실도 보너스: 실제 전략 선택 시 +20% 보상
  을지문덕 영웅 유닛: 모든 플레이어가 공유

클리어 보상:
  노멀: 「살수의 병사」칭호
  역사 충실 클리어: 「을지문덕의 계승자」칭호 + 전용 스킨
  하드: 「강은 기억한다」한정 배경화면
```

## MODE E: 왕국 길드전

```
구조:
  플레이어 → 왕국 선택 (영구) → 길드 가입
  고구려 길드 vs 백제 길드 vs 신라 길드 vs 가야 길드

주간 리그:
  월요일: 시즌 시작
  월~금: 개인 포인트 축적 (일일 전투)
  토~일: 왕국 대항 결전 (길드 vs 길드)

포인트 시스템:
  개인 전투 승리: +10 왕국 포인트
  길드 결전 승리: +100 왕국 포인트
  주간 1위 왕국: 전 주간 이벤트 보상 2배

시즌 결산 (3개월):
  1위 왕국: 전용 깃발 아이콘 + 칭호
  MVP 플레이어 (왕국별): 개발자 감사 편지 + 전용 아이템

왕국 자존심 시스템:
  현재 순위 실시간 표시 (메인 화면)
  왕국별 팬덤 경쟁 유발 → 장기 플레이 동기
  공식 SNS: 주간 순위 발표 → 팬덤 반응 유도
```

## 반칙·어뷰징 방지

```
페어플레이 시스템:
  봇 탐지: 반복 패턴 AI 감지 → 자동 신고
  스매핑(Smurfing): 하위 랭크 어뷰징 감지 → 랭크 조정
  채팅 금지어: 혐오·차별·스포일러 자동 필터

신고 시스템:
  매치 중 신고: 3회 이상 → 자동 검토
  검토 결과: 24시간 내 처리
  허위 신고 반복: 신고 권한 임시 정지

밸런스 패치 주기:
  격월 밸런스 업데이트
  왕국별 승률 5% 이내 목표
  커뮤니티 피드백 공식 반영 창구
```

## 수익화 연계

```
멀티플레이어 전용 굿즈:
  시즌 패스: 9,900원/시즌
    포함: 전용 스킨 3종 + 칭호 + 경험치 1.5배
  왕국 깃발 스킨: 1,500원 (코스메틱)
  영웅 테마 배경음악: 2,900원

무과금 보장:
  스킨·BGM = 순수 코스메틱 (전투력 영향 없음)
  모든 영웅·유닛 = 게임 플레이로 해금 가능
  유료 아이템 = 빠른 획득 경로 (Pay-to-Fast)
```
