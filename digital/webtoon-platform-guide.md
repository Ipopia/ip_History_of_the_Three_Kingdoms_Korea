# 웹툰 플랫폼 운영 가이드 — 삼국(三國) IP

**참조 문서**: `publishing-plan.md`, `platform-streaming-guide.md`, `editorial-style-guide.md`
**작성**: 디지털콘텐츠본부 웹툰팀 (DIG-WEBTOON)
**적용**: 삼국(三國) IP 웹툰 플랫폼 연재·운영 기준

---

## 웹툰 서비스 전략

```
서비스 방식: 플랫폼 우선 연재 → 단행본 후속 출간
연재 시작: 드라마 방영 3개월 전 (2026 Q2)
연재 목표: 총 200화 (시즌 3까지)

메인 플랫폼: 네이버 웹툰 (국내 최우선)
글로벌 플랫폼: 네이버 웹툰 글로벌(LINE Manga)·타파스(영어)·픽코마(일본)
수익 모델: 유료 미리보기 (3화 선독) + 기다리면 무료
```

## 플랫폼별 전략

### 네이버 웹툰 (국내)

```
연재 정보:
  요일: 목요일 (경쟁 작품 분석 후 결정)
  분량: 회당 60~80컷 (세로 스크롤 최적화)
  업로드 시간: 매주 목요일 00:00

콘텐츠 구성:
  정규 연재: 주 1회 (60컷 이상)
  스페셜 에피소드: 역사 이벤트 연계 (살수대첩 기념일 등)
  외전: 시즌 2 드라마 방영 시 스핀오프 추가

네이버 특화 기능 활용:
  댓글 소통: 작가 주1회 댓글 참여
  베스트 댓글 캡처 → 공식 SNS 공유
  추천 시스템: 초기 100화 분석 → 알고리즘 최적화

목표 지표:
  연재 1개월: 구독자 10만
  연재 3개월: 구독자 30만
  연재 1년: 구독자 100만 (TOP 10 진입)
```

### 네이버 웹툰 글로벌 / LINE Manga

```
서비스 지역: 일본·동남아·북미·유럽
언어: 영어·일본어·중국어·태국어·인도네시아어

일본 (LINE Manga) 특화:
  연재 요일: 화요일 (일본 웹툰 소비 패턴)
  번역: 일본어 정식 번역 (GLB-LOC 감수)
  표지: 일본 취향 반영 (캐릭터 대비 강조)
  주의: 역사 표기 감수 (일본 우익 시각 배제)

영어권 (글로벌) 특화:
  연재 요일: 토요일
  번역: 영어 정식 번역 (자연스러운 구어체)
  용어집: 첫 화 삼국시대 배경 설명 페이지 삽입
  독자 배려: 역사 각주 팝업 시스템

동남아 특화:
  태국·베트남: K-웹툰 소비 고속 성장
  무료 공개 기간 확장 (첫 10화 무료)
  현지 SNS 연계 바이럴 마케팅
```

### 카카오웹툰 (2차 플랫폼)

```
전략: 네이버 연재 3개월 후 동시 업로드
독점 콘텐츠: 카카오 전용 외전 1편 (협상 조건)
가격: 카카오 코인 기본가 적용

카카오 특화:
  카카오톡 알림 연동 (구독자 푸시)
  카카오 이모티콘 연계 (캐릭터 이모티콘 선출시)
```

### 타파스 (북미 영어권)

```
전략: 북미 웹툰 시장 진입
연재 형식: 에피소드 단위 (20~30컷)
가격: 타파스 잉크 기반 유료화

북미 시장 특화:
  히스토리컬 판타지 태그 강조
  「Inspired by true Korean history」명시
  Reddit r/webtoons 홍보 연계
```

## 웹툰 콘텐츠 기준

### 화면 구성 (세로 스크롤)

```
기본 구성:
  1컷 평균: 폭 690px × 높이 300~800px (세로 가변)
  회당 총 높이: 약 30,000~50,000px
  컬러: RGB 풀컬러

연출 원칙:
  세로 스크롤 흐름 = 영화적 연출
  전환 컷: 여백·검정 페이드 활용
  클라이맥스: 전폭 와이드 컷 (2~3컷 대형)

대사 박스:
  대사: 흰 배경 둥근 모서리 말풍선
  독백: 회색 배경 + 이탤릭
  나레이션: 상단 배너형 (세피아 톤)
  효과음: 한국어 의성어 기본 (글로벌판 = 영어)
```

### 화별 구성 템플릿

```
표지: 해당 화 핵심 인물·장면 (썸네일용)
도입 (5~10컷): 직전 화 요약 or 새 장면 시작
전개 (30~50컷): 메인 서사
클라이맥스 (5~10컷): 와이드 컷 + 감정 절정
마무리 (5컷): 다음 화 예고 or 여운
총 60~80컷
```

### 역사 고증 표시

```
역사 사실 기반 컷:
  화면 하단 작은 글씨:「※ 역사 사실 기반」

야사·전설 컷:
  「※ 야사 기반 (확인 불가)」

창작 컷:
  별도 표시 없음 (독자 이해 전제)

역사 오류 방지:
  ADV-HISTORY 교열: 월 1회 정기 검토
  오류 발견 시 수정 업로드 공지 필수
```

## 독자 관리 시스템

### 댓글·소통 정책

```
작가 소통 기준:
  주 1회 댓글 참여 (업로드 후 48시간 내)
  스포일러 댓글: 신고 처리 협조
  역사 오류 지적 댓글: 감사 표시 + ADV-HISTORY 전달

독자 서비스:
  분기별 독자 Q&A (작가·역사 자문 참여)
  팬아트 공식 소개 (월 1회)
  독자 이름 넣기 이벤트 (엑스트라 등장인물)
```

### 유료화 전략

```
「기다리면 무료」모델:
  업로드 후 7일: 유료 (100코인 = 약 100원)
  7일 후: 무료 공개
  최신 3화: 항상 유료

미리보기:
  다음 화 3컷 무료 공개 → 구매 유도
  시즌 피날레: 미리보기 없음 (스포 방지)

번들 판매:
  시즌 1 묶음 (50화): 정가 대비 20% 할인
  글로벌 구독권: 월정액 서비스 연동
```

## 단행본 출판 연계

```
단행본 출간 계획:
  1권 (1~25화): 드라마 시즌 1 방영 시
  2권 (26~50화): 드라마 시즌 2 방영 시
  시즌 완결 후: 전집 출판 (오너클로즈 한정판)

단행본 특전:
  작가 코멘터리 (역사 설명 포함)
  미공개 스케치·컬러링 페이지
  역사 용어 미니 사전 (부록)
  특전 포스터 (한정판)

글로벌 단행본:
  일본: 쇼가쿠칸·코단샤 등 현지 출판사 협상
  북미: VIZ Media·Yen Press 협상
  프랑스·유럽: 망가 전문 출판사
```

## 수익 계획

```
웹툰 수익 구성:
  플랫폼 유료 수입 (네이버·카카오 수익 분배)
  글로벌 플랫폼 라이선스 수입
  단행본 출판 수입
  2차 저작물 수입 (드라마·게임 연동 광고)

수익 목표:
  연재 1년: 15억원 (국내)
  글로벌 플랫폼: 10억원 (1년차)
  단행본: 5억원 (1년차)
  합계: 약 30억원 (연재 1년차)

누적 목표 (3년):
  국내 + 글로벌 웹툰: 80억원
  단행본 + 전집: 20억원
  웹툰 총계: 100억원
```
