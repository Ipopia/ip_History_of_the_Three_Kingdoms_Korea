## ACT 1 — 오프닝 (676년)

### SCENE 001. 기벌포 바다 — 새벽

```
[INT/EXT — 기벌포 해상 — 새벽 — AD 676]

광각: 서해 기벌포. 새벽빛이 수면을 붉게 물든다.
부서진 전선들이 파도 위에 흔들린다.
당나라 깃발이 바닷물 속으로 가라앉는다.

[나레이션 — 노년 니문의 목소리]
V.O. 니문: 「676년 겨울이었다.
           나라가 셋이었다가 하나가 된 해.
           강이 마침내 조용해진 해.」

해안가에 선 네 인물의 실루엣.
역광 — 얼굴은 보이지 않는다.

V.O. 니문: 「그러나 강은 기억하고 있었다.
           처음부터.
           모든 것을.」

[암전]
[타이틀: 삼국(三國) — 강은 기억한다]
```

## ACT 2 — 612년 (살수)

### SCENE 002. 살수 강변 — 새벽

```
[EXT — 살수(청천강) 강변 — 새벽 4시 — AD 612]

자막: 「AD 612. 살수(薩水). 고구려」

안개가 강을 덮고 있다.
고루(22세), 강변에 홀로 서 있다.
갑옷 아래 손을 쥐었다 편다.

고루: (혼자말, 낮게)
     「물이 불었다.」

강 건너편 — 어둠 속에서 무언가 움직인다.
수나라 척후병의 횃불이 하나씩 켜진다.

[고루 눈 클로즈업]
두려움은 없다. 그러나 고요하지도 않다.

고루: (같은 음량)
     「선생. 시간입니다.」

---

[INT — 고구려 작전 천막 — 연속]

을지문덕(50대), 지도 앞에 서 있다.
고루가 들어온다.

을지문덕: 「수군 전면 배치 완료됐나.」
고루: 「예. 강 상류 수문도 대기 중입니다.」

을지문덕, 지도에서 시선을 거두고 고루를 본다.
오랜 침묵.

을지문덕: 「두렵지 않으냐.」
고루: (잠시 생각 후)
     「이길 것이기 때문입니다.」

을지문덕, 미세하게 웃는다.
을지문덕: 「기다려라.」

[외부 — 강물 소리가 점점 커진다]
```

## ACT 3 — 병렬 도입

### SCENE 003. 사비성 (659년)

```
[INT — 사비성 문서관 — 새벽 — AD 659]

자막: 「AD 659. 사비성(泗沘城). 백제」

아랑(19세), 창가에 앉아 죽간을 쓰고 있다.
창문 밖 — 백마강에 연등이 흐른다.

[죽간 위 글씨 클로즈업]
「기록하지 않은 것은 존재하지 않는다.
 그러나 나는 기억한다. 기록되지 않은 것까지.」

아랑, 붓을 멈추고 강을 바라본다.
표정: 고요하지만 무언가를 감지한 눈빛.

아랑: (혼자말)
     「이 불빛들이 얼마나 더 켜질 수 있을까.」

[연등 하나가 꺼진다]
[아랑, 그것을 바라본다 — 대사 없음]
```

### SCENE 004. 경주 화랑 훈련장 (655년)

```
[EXT — 신라 경주 화랑 훈련장 — 아침 — AD 655]

자막: 「AD 655. 금성(金城). 신라」

하린(15세), 동료들과 활쏘기 훈련 중.
과녁을 향해 집중한다.

[슬로우모션 — 활 시위가 당겨지는 순간]
[하린의 눈 — 과녁에 고정]

화살 발사.
과녁 정중앙.

동료: 「또 1등이야, 하린.」
하린: (웃으며)
     「당연하지. 가자, 다음!」

[훈련장 한쪽 — 8세 소년 관창이 하린을 바라보고 있다]
[하린, 관창에게 손짓]
하린: 「뭐 해? 너도 와.」

[관창, 뛰어온다 — 미소]
```

### SCENE 005. 낙동강 (640년)

```
[EXT — 낙동강 변 대나무 숲 — 황혼 — AD 640]

자막: 「AD 640. 낙동강(洛東江). 가야 유민 거주지」

니문(25세경 — 여기서는 조부 세대가 등장, 또는 회상),
강변에 앉아 가야금을 연주한다.

[가야금 소리 시작 — 테마 멜로디 「기억의 강」]

니문: (연주하며, 혼자)
     「우륵 선생의 12번째 곡.
      아직도 모른다.」

[강물 소리와 가야금 소리가 섞인다]
[하늘 — 저녁 별 하나가 켜진다]

니문, 연주를 멈추고 강을 바라본다.
니문: 「가야는 여기에 있다.」
     (손을 가슴에 얹으며)
     「강이 기억하듯, 나도.」
```

## ACT 4 — 살수대첩 클라이맥스

### SCENE 006. 살수 — 수문 개방

```
[EXT — 살수 상류 수문 — 낮 — AD 612]

수문 담당 고구려 병사들. 대기.
멀리서 신호 봉화 2개.

병사 1: 「신호다!」

[수문 개방 — 기계 삐걱임 — 물 압력]

[CUT — 강 하류 — 수나라 군 진영]
수나라 장수: 「물이 — !」

[범람 — 강물 폭발적 방류]
[수나라 군 혼란 — 아우성]

---

[작전 천막 — 고루]

고루, 밖의 소리를 듣는다.
함성. 물소리. 절망적 외침.

[고루, 천막 밖으로 나간다]
[강이 범람하는 것을 바라본다]
[을지문덕이 옆에 선다]

을지문덕: 「끝났다.」
고루: (강을 보며, 낮게)
     「강은 기억한다.」

[을지문덕, 고루를 바라본다 — 의미심장한 눈빛]
[강물 소리만]

[첫 화 END]
```

## 연출 지침

```
색채 코드 (씬별):
  612년 살수: 청람 + 회색 (고구려)
  659년 사비: 황금 + 주황 (백제 연등)
  655년 경주: 금빛 + 초록 (신라 화랑)
  640년 낙동강: 황토 + 갈색 (가야)

음악:
  오프닝: 주제가 오케스트라 버전
  살수 씬: 타악기 중심 (긴박)
  사비성 씬: 가야금 + 해금 (서정)
  화랑 씬: 관악 + 타악 (활기)
  낙동강 씬: 가야금 솔로 (고요)

편집 리듬:
  병렬 편집 씬: 1.5~2초/컷 (빠름)
  감정 씬: 4~8초/컷 (느림)
  클라이맥스: 0.5초/컷 (최고조)
```
