## 프로덕션 디자인 총괄 비전

### 핵심 철학
삼국(三國) 드라마의 물리적 세계는 다음 세 원칙으로 설계된다:

1. **고증 우선**: 발굴 유물·고분 벽화·문헌 기록 기반
2. **시각적 차별성**: 관객이 세트만 보고도 어느 왕국인지 인식
3. **기능적 아름다움**: 배우의 동선·연기를 지원하는 공간 설계

### 왕국별 프로덕션 DNA

| 왕국 | 건축 재료 | 공간감 | 빛의 특성 |
|------|---------|--------|---------|
| 고구려 | 화강암·목재·철 | 높고 웅장·수직성 강조 | 차갑고 날카로운 측광 |
| 백제 | 목재·기와·흙벽 | 수평적·우아한 비례 | 따뜻하고 확산된 빛 |
| 신라 | 화강암·금박·옻칠 | 성스럽고 개방적 | 황금빛 정면광 |
| 가야 | 철·목재·흙 | 실용적·낮고 역동적 | 불꽃·열기 중심 |

## 세트 설계 상세

### 고구려 평양성 왕궁 세트

**규모**: 3,000m² (실내 세트 + 외부 성벽 파사드)

**주요 공간**

| 공간 | 규모 | 특징 |
|------|------|------|
| 왕좌 홀 | 400m² | 화강암 기둥 12개·높이 8m·전면 개방 |
| 왕의 집무실 | 150m² | 지도·서책·철제 소품 |
| 귀족 회의실 | 200m² | 원형 배치·각 귀족 좌석 구분 |
| 왕비 침전 | 120m² | 상대적으로 부드러운 소재 |
| 성벽 통로 | 파사드 80m | 전투·파수 씬 전용 |

**재료·마감 기준**
```
바닥: 화강암 슬레이트 (실제 돌 또는 고품질 복제)
벽면: 회색 화강암 질감 + 고구려 문양 부조
기둥: 목재 기반 + 철제 밴딩
조명: 측면 횃불 거치대 (전기 횃불 + 실제 불꽃 병행)
소품: 삼족오 깃발·철제 무기 거치대·전쟁 지도
색채: 철흑(#1C1C1E) 기조 — 혈홍(#8B0000) 포인트
```

**왕좌 디자인**
```
재료: 흑색 화강암 기반 + 철제 장식
형태: 높은 등받이·광개토대왕릉비 문양 참조
크기: 일반 왕좌보다 1.5배 (압도적 위압감)
위치: 3단 단상 위 — 배우가 내려다보는 구조
조명: 왕좌 위 천창(天窓) — 단독 집중광
```

### 백제 사비성 왕궁 세트

**규모**: 2,500m²

**주요 공간**

| 공간 | 규모 | 특징 |
|------|------|------|
| 접견실 | 300m² | 백마강 전망 창호·비단 장식 |
| 연회장 | 250m² | 낮은 좌식 배치·음악 무대 |
| 왕의 정원 | 200m² (야외 세트) | 연못·정자·계절 꽃 |
| 귀족 숙소 | 120m² | 고급 목재·칠기 |

**재료·마감 기준**
```
바닥: 흰 화강암 + 나무결 (백토 느낌)
벽면: 밝은 회벽 + 비취록 채색 장식
기둥: 세련된 목재·붉은 옻칠
조명: 넓은 창호를 통한 자연광 모방 (확산 조명)
소품: 청자·칠기·비단·악기 (가야금·피리)
색채: 백토(#F5F0E8) 기조 — 비취록(#3D7A5B) 강조
```

### 신라 서라벌 황룡사 세트

**규모**: 2,000m² (사원 내부 중심)

**주요 공간**

| 공간 | 규모 | 특징 |
|------|------|------|
| 대웅전 | 400m² | 황금빛 불상·향 연기 시스템 |
| 선덕여왕 집무실 | 150m² | 천문 도구·별자리 지도 |
| 화랑 수련장 | 야외 300m² | 경주 화강암·자연 소재 |
| 금관 봉안실 | 80m² | 금빛 장식·강한 역광 |

**특수 요소**
```
향 연기 시스템:
- 실제 향 연기 + 드라이아이스 안개 조합
- 사원 전체 몽환적 분위기 연출
- 카메라 앵글에 따른 연기량 조절 시스템

황룡사 9층탑 파사드:
- 1~3층까지만 실물 제작 (6m 높이)
- 4층 이상은 VFX 합성
- 실물 부분은 최고급 재료로 제작
```

### 가야 제철장 세트

**규모**: 800m² (주로 야외)

**주요 공간**

| 공간 | 특징 |
|------|------|
| 용광로 구역 | 실제 소형 용광로 + 가스 화염 시스템 |
| 대장간 | 모루·망치·철기 소품 완비 |
| 교역 창고 | 철정 더미·교역품 |
| 항구 파사드 | 배 선수 + 낙동강 배경 |

**안전 기준**
```
실화재 사용 구역: 5m 안전 반경·소화기 상시 대기
가스 화염: 안전 관리자 2명 상시 배치
배우 진입: 화재 안전 교육 이수 후 허가
```

## 조명 설계 가이드

### 왕국별 기본 조명 설정

**고구려**
```
주 광원: 측광 (30~45° 각도) — 음영 극대화
색온도: 2800K (차갑고 강렬)
보조: 횃불 효과 (오렌지 플리커)
금지: 정면 평면광·확산 소프트박스
```

**백제**
```
주 광원: 창호 자연광 (4000~4500K)
색온도: 따뜻하고 골든
보조: 반사 bounce 확산광
금지: 강한 단일 포인트광·차가운 톤
```

**신라**
```
주 광원: 황금빛 정면·상향 (3800K)
색온도: 황금·신성
보조: 역광 (금관·금 소품 강조)
특수: 향 연기 + 산란광 조합
```

**가야**
```
주 광원: 용광로 불빛 (1800~2500K)
색온도: 극도로 따뜻·불꽃
보조: 탄흑 배경 대비
금지: 부드럽고 확산된 빛
```
