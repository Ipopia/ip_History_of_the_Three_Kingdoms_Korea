## 로컬라이제이션 원칙

```
핵심 원칙:
  「한국 역사의 정체성을 지키되, 세계 독자가 공감할 수 있게」

3대 원칙:
  ① 역사적 고유명사 보존 (한국식 로마자 표기 우선)

  중국·일본 역사 프레임으로 재해석 금지
  (예: 고구려를 중국 역사로 표기 절대 금지)

## 언어별 로컬라이제이션

### 영어 (EN) — 글로벌 공용

```
표기 기준: 국립국어원 매큔-라이샤워 수정안 (Revised Romanization)

주요 고유명사:
  고구려 → Goguryeo (not "Koguryo")
  백제 → Baekje (not "Paekche")
  신라 → Silla
  가야 → Gaya
  을지문덕 → Eulji Mundeok
  살수대첩 → Battle of Salsu
  안시성 → Ansi Fortress
  화랑 → Hwarang

슬로건 번역:
  KR: 「강은 기억한다」
  EN: "THE RIVER REMEMBERS"
  (직역·의역 동일, 이미 확정)

문화 용어 처리:
  직책: 원어 유지 + 각주
    예: Daemakrijji (大莫離支, Supreme Minister of Goguryeo)
  음식: 원어 유지 + 설명
    예: gochujang (fermented chili paste) — 단, 7세기 시대 고증 주의
  의례: 설명 삽입
    예: Hwarang oath (花郞 誓), the sacred vow of elite warrior youth

번역 톤:
  소설: 서사시적 (epic literary)
  웹소설: 현대적 구어체
  드라마: 자막 최적화 (간결)
  게임: 간결·임팩트 중심
```

### 일본어 (JA)

```
표기 기준: 한국어 원음 기반 가타카나

주요 고유명사:
  고구려 → 高句麗 (こうくり / Kōkuri)
  백제 → 百済 (くだら / Kudara) — 일본 전통 표기 병용
  신라 → 新羅 (しらぎ / Shiragi) — 일본 전통 표기 병용
  가야 → 伽耶 (かや / Kaya)
  을지문덕 → ウルジ·ムンドク
  살수대첩 → 薩水の大捷 (さっすいのたいしょう)
  화랑 → 花郞 (ファラン)

주의 사항:
  백제·신라 일본식 표기(くだら·しらぎ) 허용
  단, 가야를 일본 속국으로 암시하는 표현 금지
  역사 서술: 한국 학계 주류 입장 기반
  임나일본부 관련 표현 전면 금지

슬로건:
  KR: 「강은 기억한다」
  JA: 「川は記憶する」

번역 톤:
  소설: 시대극 문체 (時代劇調)
  웹소설: 현대 라이트노벨 스타일
  게임: 게임 UI 최적화
```

### 중국어 간체 (ZH-CN) — 중국 본토

```
표기 기준: 한국어 원음 → 중국어 음차 + 한자 원문 병기

주요 고유명사:
  고구려 → 高句丽 (Gāojùlí)
  백제 → 百济 (Bǎijì)
  신라 → 新罗 (Xīnluó)
  가야 → 伽耶 (Jiāyē)
  을지문덕 → 乙支文德 (Yǐzhī Wéndé)
  살수대첩 → 萨水大捷 (Sàshuǐ dàjié)
  연개소문 → 渊盖苏文 (Yuān Gàisūwén)

주의 사항:
  고구려 = 한국 역사 명확히 표기
  중국 동북공정 프레임 반영 금지
  고구려를 중국 왕조로 표기 절대 금지
  역사 서술 주석: 「삼국사기(三国史记) 기준」 명시

슬로건:
  KR: 「강은 기억한다」
  ZH-CN: 「江河铭记」(강하명기)

번역 담당: GLB-LOC + 현지 번역사 (역사 전문가 필수)
법무 검토: 중국 출판 규정 확인 필수 (IP-LEGAL)
```

## 문화 용어 현지화 가이드

### 음식·생활 용어

```
시대 고증 우선:
  7세기 음식 ≠ 현대 한국 음식
  고추 (16세기 전래) — 등장 금지
  된장·간장류 — 등장 가능 (삼국시대 존재)
  막걸리 계열 — 등장 가능

번역 시 처리:
  원어 유지 + 짧은 설명
  예: doenjang (fermented soybean paste, similar to miso)
  예: makgeolli (milky rice wine)
```

### 신화·종교 용어

```
불교 용어:
  한자 원문 유지 권장
  예: Bosal (菩薩, Bodhisattva)

무속 용어:
  설명 삽입 필수
  예: mudang (무당, shaman/spirit medium)
  예: samshin (삼신, deity of birth and life)

도교 개념:
  도 → Dao / Tao (국가별 선택)
```

### 가야금 설명

```
영문:
  gayageum — a 12-stringed Korean zither
  used in state ceremonies and as a cultural symbol of Gaya kingdom
  comparable to: Japanese koto, Chinese guqin (distant relatives)

일문:
  伽耶琴 (かやきん) — 12弦の韓国の弦楽器
  ガヤクム — 現代表記

중문:
  伽倻琴 — 朝鲜半岛传统12弦弹拨乐器
```

### 드라마·영상

```
자막 기준:
  한 줄 최대 20자 (한국어 기준)
  화면 노출 시간: 1초당 10자 기준
  고유명사: 영문 자막 첫 등장 시 한자 병기

더빙 기준 (일본·중국):
  입 모양 일치 우선
  극적 톤 유지 (감정선 보존)
  역사 용어: 현지 역사 전문가 감수

넷플릭스 표준:
  넷플릭스 한국어 드라마 자막 가이드라인 준수
  SDH 자막 (청각장애인용) 별도 제작
```

### 소설·출판

```
번역 등급:
  A등급: 정식 출판 (완전 번역 + 현지 편집자 검토)
  B등급: 디지털 출판 (AI 번역 + 전문가 교정)
  C등급: 팬 번역 지원 (가이드라인 제공 + 감수)

각주 정책:
  소설: 하단 각주 (역사 용어 설명)
  웹소설: 팝업 툴팁 또는 별도 용어집 페이지
  최대 각주: 챕터당 5개 (독서 방해 최소화)
```

### 게임

```
UI 텍스트 우선:
  버튼·메뉴: 간결 번역 (5자 이내 권장)
  아이템명: 원어 유지 + 설명 분리
  스킬명: 임팩트 있는 현지어 번역

음성 더빙:
  주인공 4인: 현지어 더빙 A등급 (일본·중국·영어)
  조연: 자막 처리 허용
  역사 나레이션: 현지 역사 전문 성우 우선
```

```

  ✗ 구글 번역·AI 번역 단독 사용 금지

  소설·웹툰: XLSX (원문/번역문 대조표)

```

### 일본어 번역 주의사항 (translation-guide.md 기준)

```
주의:
  「임나(任那)」: 일본어판 사용 금지
    → 「가야(加耶)」로 통일
  임나일본부설 관련 표현: 완전 제거
