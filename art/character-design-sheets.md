## 디자인 시트 구성 기준

```
각 캐릭터 시트 구성:
  A. 정면 전신 (기본 의상)
  B. 측면 전신 (비율 확인용)
  C. 후면 전신 (등 디테일)
  D. 표정 시트 (16종 — 기본·분노·슬픔·결의·웃음·놀람 등)
  E. 손 디테일 (고유 특징 — 흉터·굳은살·장신구)
  F. 머리카락 디테일 (앞·옆·뒤)
  G. 의상 부분 확대 (문양·장신구)

  원본 아트: 5000×7000px (300dpi)
  웹 배포용: 2000×2800px (72dpi)
  굿즈 제작용: 별도 파일 요청
```

## 고루 캐릭터 디자인 상세

### 기본 신체 비율

```
신장: 185cm 기준 (8등신)
체형 키워드: 장대·단단·역전된 삼각형 실루엣
나이 변화:
  시즌 1 (35세): 젊은 장군 — 예리한 눈빛
  시즌 2 (45세): 중년 — 약간 굵어진 선
  시즌 3 (55~67세): 노장 — 굽은 등·흰 머리카락

헤어:
  기본: 상투 (búnjeon-style) — 장수 고구려 형식
  전투 시: 투구 착용 (상투 가림)
  색상: 짙은 흑발 → 시즌 3 흰 줄기 증가

얼굴 특징:
  눈: 깊은 쌍꺼풀 · 검은 눈동자
  흉터: 왼쪽 눈 아래 가로 3cm (살수 전투 이전부터)
  턱선: 각지고 강인함
  수염: 시즌 2부터 짧은 수염
```

### 의상 디자인

```
기본 의상 (전투복):
  갑옷: 소찰갑(小札甲) — 미늘 조각 연결 형식
  색상: 철흑 #1A1A1A (산화 처리) + 군청 #2F4F7F 안감
  어깨: 삼족오 문양 양각 (금빛 #8B7355)
  장갑: 철제 손등 보호대
  신발: 가죽 군화

일상복:
  상의: 군청 #2F4F7F 직령포(直領袍)
  하의: 짙은 회색 바지 + 가죽 대
  허리: 철제 버클 혁대
  신발: 가죽 화

특이 소품:
  장검: 총 길이 110cm (날 90cm) · 날 은빛 · 손잡이 철흑
  검집: 흑칠 목제 + 삼족오 은제 장식
```

### 표정 가이드

```
기본 (중립): 무표정·날카로운 눈빛·입 닫음
결의: 눈빛 강렬·입 굳게 닫음·눈썹 약간 내림
분노: 눈 크게·미간 찌푸림·입 굳게
슬픔: 눈동자 아래로·입꼬리 미세하게 아래로
놀람: 눈 크게·미간 위로·입 살짝 열림
온화: 눈가 주름·입꼬리 미세하게 위로 (드문 표정)

금지 표정:
  과도한 미소 (고루 캐릭터성과 불일치)
  눈물 자주 (절제된 감정 표현 원칙)
  코믹한 과장 표정 (진지한 캐릭터)
```

## 아랑 캐릭터 디자인 상세

### 기본 신체 비율

```
신장: 163cm (7.5등신 — 우아한 비율)
체형 키워드: 섬세·유연·S라인 실루엣
나이 변화:
  시즌 1 (25세): 젊은 귀족 여성
  시즌 2 (35세): 성숙한 여인
  시즌 3 (40대): 단아한 중년

헤어:
  기본: 가체(加髢) 올림머리 (백제 귀족 여성 형식)
  장신구: 봉황 금비녀 + 꽃 장식
  색상: 짙은 흑발 + 기름 광택
  일상: 반 올림머리 (가체 없이)

얼굴 특징:
  눈: 가늘고 긴 봉황안 · 따뜻한 눈빛
  입술: 자두빛 #8B1A1A 연지
  피부: 백옥같은 밝은 피부 (귀족 여성)
  볼터치: 자연스러운 분홍 (과하지 않게)
```

### 의상 디자인

```
기본 의상 (귀족 예복):
  상의 (저고리): 크림 #F5E6C8 비단 + 봉황 자수 (금색·주홍)
  하의 (치마): 황금 #B8960C 비단 주름치마
  깃: 봉황 문양 금박 처리
  허리띠: 비취색 옥 장식 비단 띠
  신발: 흰 비단 코 들린 당혜(唐鞋)

장신구:
  귀걸이: 봉황 형 금귀걸이 (무령왕릉 양식 참고)
  목걸이: 가야 수입 곡옥(曲玉) 목걸이 (서사 포인트)
  팔찌: 가는 금 팔찌 2개 (양 손목)

핵심 소품:
  자수틀 + 어머니의 자수 한 조각
    → 사비성 탈출 시 유일하게 지닌 것
  봉황 문양 자수 (30cm × 30cm 크기)
  낡아있지만 정교한 백제 자수
```

## 하린 캐릭터 디자인 상세

### 기본 신체 비율

```
신장: 178cm (8등신 — 균형·역동)
체형 키워드: 탄탄·역동·활동적 실루엣
나이 변화:
  시즌 1 (20세): 젊은 화랑 — 패기 넘침
  시즌 2 (30세): 중견 장교 — 단단해진 근육
  시즌 3 (37세): 장수 — 흉터+카리스마

헤어:
  기본: 화랑 형식 반상투 (앞머리 내려옴)
  전투 시: 전두 두른 투구
  색상: 짙은 흑발 + 활동으로 약간 윤기 덜함

특이 표식:
  왼팔 화랑 문신: 곡옥(曲玉) + 태양 문양
  오른팔 흉터: 기벌포 전투 후 (시즌 3)
```

### 의상 디자인

```
기본 의상 (화랑 전투복):
  갑옷: 가죽 + 철판 혼합 (고구려보다 경량)
  색상: 금색 #FFD700 (도금 장식) + 흰 안감
  가슴: 신라 왕실 태양문 금박
  어깨: 곡옥 문양 양각
  신발: 가죽 전투화 (발목까지)

일상복:
  상의: 흰 #FFFEF0 화랑 도복
  허리띠: 금색 비단 띠 (화랑 계급 표식)
  신발: 흰 가죽 화

핵심 소품:
  화랑 단검: 길이 45cm · 금색 손잡이 · 경주 출토 환두대도 참고
  활 + 화살통: 화살 20발 기본 장비
  말: 흰 말 (하린 전용 — 이름: 「별」)
```

## 니문 캐릭터 디자인 상세

### 기본 신체 비율

```
신장: 170cm (7.5등신 — 서정적 비율)
체형 키워드: 가늘고 유연·예술가 실루엣
나이 변화:
  시즌 1 (25세): 유랑 악사 — 맑은 눈빛
  시즌 2 (35세): 방랑 기억자
  시즌 3 (40세 + 에필로그 70대): 노년 기억자

헤어:
  기본: 느슨하게 묶은 반상투 (흘러내리는 머리카락)
  여행 중: 두건 착용
  색상: 갈색빛 도는 흑발 → 노년 흰 머리

손 디테일 (가장 중요한 신체 특징):
  긴 손가락 + 가야금 줄 굳은살 (오른손 손끝)
  왼손: 깨끗함 (짚는 손)
  오른손: 살짝 굳은 피부 (튕기는 손)

얼굴 특징:
  눈: 크고 맑음 · 관찰하는 눈빛
  입: 자주 미소 (4인 중 가장 표정 풍부)
```

### 의상 디자인

```
기본 의상 (유랑 악사):
  상의: 황토 #C8A96E 삼베 직령포
  하의: 갈색 삼베 바지 + 가죽 대
  외투: 낡은 갈색 여행 망토 (계절 대응)
  신발: 짚신 or 맨발 (상황 따라)
  단, 과도하게 초라하지 않게 — 「가난하지만 단정」

핵심 소품:
  가야금: 전통 12현 가야금
    전체 길이: 150cm / 오동나무 몸체 / 12현
    케이스: 낡은 삼베 가방 (등에 멤)
    특이: 12현 중 1현이 끊겨있다
           → 「끊어진 한 현 = 가야의 소멸」
    끝내 소설 에필로그에서 새 현을 맨다
  여행 필기구: 대나무 죽간 묶음 (기억 기록용)
```

## 시즌별 의상 변화 가이드

```
시즌 1:
  4인 = 각자의 왕국 정체성 최고조
  가장 화려하고 온전한 상태

시즌 2:
  전쟁 피해 반영 — 의상 낡아짐·수선 흔적
  고루: 갑옷 일부 손상 → 수리된 흔적
  아랑: 귀족 의상 → 단순한 의상으로 변화

시즌 3:
  상실과 생존 반영 — 더 단순하고 실용적
  고루: 갑옷 없이 일상복 위주 (노장)
  니문: 옷 더 낡아짐 → 여행 연수 반영

에필로그 (니문):
  노년 의상: 가장 단순 + 가장 온화한 색
  황토 #C8A96E → 바래서 더 밝아진 색조
  가야금만 변하지 않음 (유일한 새것)
```
