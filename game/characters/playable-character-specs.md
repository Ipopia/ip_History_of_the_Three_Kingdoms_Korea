## 시스템 전제

```
스탯 기준:
  모든 수치는 레벨 1 (캠페인 시작 시) 기준값
  최대 레벨: 30 (캠페인 완료 기준)
  성장 방식: 레벨업 + 스킬 포인트 + 장비 보너스 + 유대 보너스

표기 단위:
  HP    : 생명력 (기본 100~300)
  ATK   : 공격력 (기본 10~60)
  DEF   : 방어력 (기본 5~40)
  SPD   : 행동 속도 — 높을수록 먼저 행동 (기본 5~15)
  MP    : 스킬 자원 — 스킬 사용 시 소모, 턴마다 일부 회복 (기본 50~120)

스킬 구분:
  일반 스킬 (Active): MP 소모, 쿨타임 있음
  패시브 스킬 (Passive): 상시 발동, 조건부
  궁극기 (Ultimate): MP 전량 소모 또는 게이지 소모, 쿨타임 없음 (1회성 게이지)

4인 설계 원칙:
  고루  — 탱커 + 단일딜러 (전면)
  아랑  — 서포터 + 정보전 (후방)
  하린  — 어쌔신 + 기동형 딜러 (측면)
  니문  — 힐러 + 버퍼 + 음향 정찰 (후방)
```
