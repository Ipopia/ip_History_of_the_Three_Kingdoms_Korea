# 대사 집필 가이드 — 삼국(三國) IP

**참조 문서**: `master-plot.md`, `character-development-arcs.md`, `glossary.md`, `dialogue-style-guide.md`
**작성**: IP창작본부 서사팀 (IP-PLOT)
**적용**: 삼국(三國) IP 드라마·소설·뮤지컬 전 매체 대사 집필 기준

## 대사 철학

```
핵심 원칙:
  「대사는 행동이다」— 말하는 순간 무언가 바뀐다
  정보 전달이 아닌 감정·의지·관계 표현 수단

삼국 IP 대사의 특징:
  현대어 기반 + 고어 뉘앙스 혼합
  지나치게 어렵지 않되, 현대 드라마 구어체도 아닌
  「품위 있는 현대 한국어」목표

금지 사항:
  「~했잖아요」「~거든요」등 극도 현대 구어체
  한자어 과용 (고루함)
  영어 차용어 (완전 금지)
  현대 유행어·밈 (완전 금지)
  설명 대사 (보여주기 대신 말로 설명) 지양
```

## 캐릭터별 대사 스타일

### 고루 (고구려 무장)

```
기본 톤: 과묵하고 절제된 — 말보다 행동
문장 길이: 짧고 단호 (평균 10단어 이하)
어조: 명령형보다 평서형 — 「~한다」「~이다」
감정 표현: 직접 감정 표현 드뭄 → 행동·침묵으로

좋은 대사 예시:
  「강은 기억한다.」
  「나는 고구려를 지키는 자다.」
  「물러서라. 아직 때가 아니다.」
  「죽어서도 이 땅을 잊지 않겠다.」

나쁜 대사 예시 (금지):
  ✗ 「나는 지금 많이 슬프고 힘들어. 고구려가 걱정돼.」
  ✗ 「우리가 이렇게 열심히 싸우는 이유가 뭔지 알아?」

내면 독백 (소설·드라마 VO):
  3인칭 거리를 두는 자기 관찰
  「나는 무엇을 지키는가. 나라인가. 기억인가.」
```

### 아랑 (백제 귀족 여성)

```
기본 톤: 섬세하고 시적 — 아름다움으로 세상을 본다
문장 길이: 중간 (평균 15~20단어)
어조: 관찰하고 묘사하는 문장이 많음
감정 표현: 직접적이되 우아하게

좋은 대사 예시:
  「봉황이 잡혔다. 날개를 펼치지 못하고.」
  「아름다운 것이 사라지면, 나는 무엇이 되는가.」
  「이것만은 빼앗기지 않겠다. 기억만은.」
  「꽃이 졌다. 하지만 향기는 남는다.」

나쁜 대사 예시 (금지):
  ✗ 「백제가 망했네. 정말 슬프다.」
  ✗ 「금동대향로 진짜 예쁘지 않아?」

은유·비유 활용:
  아랑의 대사 = 사물을 통해 감정 표현
  금동대향로 = 백제의 아름다움
  봉황 = 자유·왕실·소멸
  꽃잎 = 낙화암 기억
```

### 하린 (신라 화랑)

```
기본 톤: 직설적이고 열정적 — 행동하는 자
문장 길이: 짧고 빠름 (행동 지향)
어조: 의문형 多 — 끊임없이 질문하는 청년
감정 표현: 솔직하고 직접적

좋은 대사 예시:
  「왜 싸웁니까? 무엇을 지키려고?」
  「이기겠다. 반드시 이긴다.」
  「16세 아이가 앞으로 갔다. 나는 왜 멈추었나.」
  「이것이 승리인가.」

나쁜 대사 예시 (금지):
  ✗ 「저는 신라 화랑 하린입니다. 열심히 싸우겠습니다.」
  ✗ 「형님들 파이팅!」

성장 표현:
  시즌 1: 의문형 多 (끊임없이 묻는 청년)
  시즌 2: 평서형 증가 (확신 생기는 중년)
  시즌 3: 고루처럼 짧고 단호 (완성된 장수)
```

### 니문 (가야 악사)

```
기본 톤: 관찰하고 기록하는 자 — 가장 시적
문장 길이: 가변적 (혼자 있을 때 가장 길다)
어조: 서술형·회고형 — 이미 일어난 일을 기억처럼
감정 표현: 가장 감성적이지만 절제된 방식

좋은 대사 예시:
  「나는 기억합니다.」
  「강이 흐릅니다. 나라가 사라진 뒤에도.」
  「소리가 있으면 기억이 있다. 기억이 있으면 가야가 있다.」
  「이것이 나의 전쟁이었다.」

나쁜 대사 예시 (금지):
  ✗ 「가야가 망해서 너무 슬퍼요.」
  ✗ 「음악으로 세상을 바꾸겠어!」

편지·독백 형식 (에필로그 특화):
  니문 = IP의 최종 화자
  「고루에게, 아랑에게, 하린에게.」
  과거를 회고하는 노년의 목소리
```

## 역사 인물 대사 기준

### 을지문덕 대사

```
역사 기록 참고:
  우중문에게 보낸 한시 (원문):
  「神策究天文 妙算窮地理
   戰勝功旣高 知足願云止」

  번역: 「신묘한 계책은 천문을 다하고
         기묘한 셈은 지리를 통했도다
         싸워 이긴 공이 이미 높으니
         만족함을 알아 그칠 것을 원하노라」

드라마 대사 활용:
  한시 → 극 중 대화에서 인용 (현대어 해석 첨부)
  을지문덕 = 말을 아끼지만 말할 때 핵심만
  「적을 알고 나를 알라. 그리고 기다려라.」

주의:
  을지문덕에게 과도한 감성 대사 금지
  「조국을 위해 목숨을 바친다」류 과장 금지
  역사 기록에서 벗어난 과도한 영웅화 지양
```

### 계백 대사

```
비극적 선택의 대사:
  처자 결단 장면: 직접 서술 최소화
  「나라가 없으면 가족도 없다」식 명분 대사
  단, 과도한 당위성 설명 금지 — 침묵 더 효과적

황산벌 출전:
  「다섯 번이면 된다. 그 이상은 없다.」
  「지는 싸움도 싸워야 할 때가 있다.」

주의:
  계백을 단순 충신으로만 묘사 금지
  처자 관련 장면 = 관객이 판단하도록
  비극의 무게는 대사보다 행동으로
```

## 대사 작성 실무 기준

```
씬 단위 대사 점검:
  이 대사로 씬의 목표가 달성되는가?
  캐릭터 고유 목소리인가?
  더 짧게 할 수 있는가?
  행동으로 대체 가능한가?

설명 대사 교정법:
  Before: 「나는 살수에서 수나라 군을 무찌른 고구려 장군이오.」
  After: 「살수를 기억하시오?」 (관객이 이미 안다는 전제)

침묵의 활용:
  대사 없는 장면 = 가장 강력한 대사
  4인 재회 장면: 대사 최소화 → 표정·공간·음악
  고루 마지막 장면: 「강은 기억한다」한 마디로 충분

언어 수위:
  욕설: 금지 (역사극 품격)
  폭력 대사: 전투 지시 수준 (「전진」「막아라」)
  감성 대사: 절제와 여운 — 과잉 감정 금지
```

## 번역 대사 기준 (글로벌 배급)

```
영문 번역 원칙 (GLB-LOC 연계):
  직역보다 감성 번역
  「강은 기억한다」→ "THE RIVER REMEMBERS" (공식 번역)

일본어 번역 주의:
  고어체 대사 = 일본 고전 어투 참고 (적절한 품격)
  고구려·백제 인물 → 도쿄 사투리 금지

한자어 대사 처리:
  드라마 자막: 한자 병기 선택 사항
  소설: 초출에만 한자 표기 (이후 한글만)
  게임 UI: 한자 표기 없음 (접근성)
```
