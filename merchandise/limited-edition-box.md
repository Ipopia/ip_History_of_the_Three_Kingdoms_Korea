```

  희소성 → 2차 시장 가치 형성

  ① 「4왕국 컬렉터 박스」(메인 한정판)

  ③ 「살수대첩」시즌 1 기념 박스 (드라마 방영 기념)
  ④ VIP 시그니처 박스 (초초한정)

가격대:
  메인 박스: 98,000원
  왕국별 개인 박스: 68,000원 (각)
  시즌 1 기념 박스: 128,000원
  VIP 시그니처: 298,000원

수량 제한:
  메인 박스: 10,000세트
  왕국별 개인: 5,000세트 (왕국별)
  시즌 1 기념: 3,000세트

판매 채널:
  당사 공식 쇼핑몰 (선점 예약제)
  티빙 제휴 이벤트 (시즌 구독자 특가)
  일본: 라쿠텐·아마존재팬
  글로벌: 당사 공식 글로벌샵
```

## 「4왕국 컬렉터 박스」— 메인 한정판

```
수량: 10,000세트 (전 세계)
가격: 98,000원 (약 $73)
출시: 드라마 방영일 (2026 Q3)

패키지 외관:
  크기: 35×25×10cm (슬립케이스 포함)
  재질: 두꺼운 하드보드 + 무광 코팅 + 부분 UV (로고)
  디자인:
    표면: 4왕국 그라데이션 (암청→왕실금→황금→토황)
    슬립케이스: 강물 물결 엠보싱 처리
    뒷면: 4왕국 심볼 + 「강은 기억한다」슬로건

구성품 (총 12종):
  ① 아트북 (64페이지, A5):
     - 4왕국 콘셉트 아트·캐릭터 일러스트
     - 감독·작가 코멘터리 포함
  ② 캐릭터 아크릴 스탠드 4종 (고루·아랑·하린·니문, 9cm)
  ③ 4왕국 엽서 8종 (왕국별 2장, 15×10cm)
  ④ 왕국 인장 스탬프 4개 세트 (삼족오·봉황·금관·가야금)
  ⑤ 강물 패턴 패브릭 포스터 (B2, 51×73cm)
  ⑥ 캐릭터 금속 배지 4종 (직경 38mm, 에나멜)
  ⑦ 왕국 문양 직물 스티커 2장 (20종 수록)
  ⑧ 미니 가야금 키링 (금속 소재, 7cm)
  ⑨ 「삼국 연대기」미니북 (32페이지, 역사 가이드)
  ⑩ 이모티콘 코드 카드 (카카오 기본 세트)
  ⑪ OST 선공개 QR 카드 (메인 테마 + 4왕국 테마)
  ⑫ 수집용 넘버링 카드 (10,000/10,000 형식)

특별 봉투 내용물:
  - 감독 친필 사인 엽서 (랜덤 1종 / 4종 중)
  - 번호별 추첨: 100명 → 배우 사인 폴라로이드
```

```

```

  샘플 심의: ART-DIR + MERCH-HEAD 승인
  파손 테스트: 낙하 1.2m × 3회
  내용물 고정: 이동 중 파손 없음 보증
