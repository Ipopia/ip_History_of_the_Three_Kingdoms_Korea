## 연대기 주요 테마 (IP 활용 관점)

### 반복되는 서사 패턴
1. **배신과 동맹**: 나제동맹 120년 유지 → 진흥왕의 배신 → 관산성 비극
2. **원수의 후손이 동맹**: 고구려에 아버지를 잃은 백제 → 세대를 넘은 복수전
3. **외세 끌어들이기의 대가**: 김춘추의 나당동맹 → 통일 후 당과 전쟁
4. **영웅의 비극적 최후**: 을지문덕의 지략, 계백의 결사, 연개소문 사후 자식 내분

### IP 핵심 갈등 구조
- **고구려**: 대륙을 향한 웅지 vs 내부 권력 다툼
- **백제**: 문화 강국의 자부심 vs 끝없는 영토 상실
- **신라**: 후발주자의 끈질긴 생존 → 최후의 승자
- **가야**: 연맹체의 한계, 강대국 사이에서의 비극
