## 1. 기본 외형 사양

### 신체 정보

```
이름     : 하린 (河璘, Harin)
나이     : 16세 (시즌 1 기준, 612년)
성별     : 남성 (소년)
신장     : 173cm
체중     : 약 60kg (화랑 훈련생 체형)
체형     : 균형 잡힌 소년 체형 — 아직 성장 중
           탄탄하되 고루처럼 완성되지 않은 어깨 너비
           날렵한 허리 / 장거리 달리기 적합한 하체
체지방   : 매우 낮음 (화랑 훈련 강도)
손       : 손가락이 길고 민첩 — 활 시위 당기기로 단련된 세 손가락 (오른손 검지·중지·약지 안쪽 굳은살)
```

### 얼굴 특징

```
전체 인상  : 밝고 개방적인 신라 소년 — 나이보다 에너지가 넘치는 인상
얼굴형     : 역 삼각형에 가까운 부드러운 윤곽 — 아직 어린 턱선
피부       : 야외 훈련으로 건강하게 그을린 황갈색 피부 (#C8954A 담황동색)
눈         : 쌍꺼풀 있는 크고 맑은 눈 / 홍채색 밝은 갈색에 황금빛 광채
             태양을 정면으로 바라보는 듯한 눈빛 — 두려움 없는 직선성
눈썹       : 짧고 강한 굵기 — 자연스럽게 올라간 각도 (활력 인상)
코         : 작고 오뚝한 코 — 소년다운 부드러운 형태
입         : 크고 시원한 입 — 자주 활짝 열린 형태 (웃음, 고함)
턱         : 부드럽고 좁은 턱선 — 성장 중인 소년

식별 특징:
  - 오른쪽 볼에 활 훈련 중 생긴 작은 타원형 점 (어린 시절부터)
  - 머리카락이 항상 약간 헝클어져 있음 (에너지 넘치는 특징)
  - 웃을 때 오른쪽 볼에 보조개 (감정 표현이 솔직한 증거)
  - 눈빛이 항상 빛을 향함 — 어두운 방향보다 밝은 쪽을 본능적으로 향함
```

### 머리카락

```
색       : 따뜻한 흑갈색 (#2A1A08)
질감     : 약간 굵고 거칠며 자연스럽게 삐침 — 정돈이 안 된 활력

스타일 기준:
  기본    : 짧게 자른 훈련병 스타일 — 앞머리가 이마 중간까지
            귀 옆 머리카락이 자연스럽게 뻗침 (묶지 않는 에너지)
  고정    : 화랑 훈련 시 이마띠 착용 (흰색 비단 / 금색 태양 문양 소형 자수)
  잔머리  : 귀 뒤와 이마 위로 솟은 가닥들 (통제 불가한 생동감)

시즌별 변화:
  S1      : 짧은 소년 머리 — 이마띠로 정돈
  S2      : 조금 더 자란 머리, 반 묶음 시도 (화랑 선배처럼 되려는 노력)

화랑 이마띠 규격:
  색      : 흰 비단 (#FFFEF0) — 신라 화랑 공통
  문양    : 금색 태양 문양 중앙 소형 자수 (하린 개인화)
  착용    : 훈련 · 전투 시 전두부 고정 / 예복 시 제거
```

## 3. 복식 상세 사양

### A. 화랑 훈련복 (기본 / 일상)

```
상의    : 순백 (#FAFAF5) 유(襦) — 소매 좁은 활동적 형태
          소매 끝 담황 단 장식 (금색 줄 1줄 / 화랑 등급 표시)
          앞섶 여밈 오른쪽 (우임) / 달리기·활 사용 편의 재단
하의    : 순백 고(袴) — 활동적인 폭 / 무릎 아래 각반(脚絆) 착용
          각반 색: 담황 (#F5D77A) 비단 / 황금 버클 고정
허리    : 황금 (#FFD700) 가죽 혁대 — 태양 문양 황금 버클
          소품홀더 2개 (활 관련 장비 / 단검 칼집)
겉옷    : 훈련 시 없음 / 이동 시 담황 짧은 반포(半袍) 착용
신발    : 순백 가죽 단화 — 경량 / 달리기 최적화
          발목 각반으로 고정
장신구  : 이마띠 (흰 비단 + 태양 문양) — 훈련 시 상시 착용
         : 황금 화살 모양 소형 귀걸이 (오른쪽 귀 — 화랑 표시)
```

### B. 전투 복식 (경갑 착용)

```
갑옷 본체:
  종류    : 경찰갑 (輕札甲) — 경량 소년용 / 기동성 우선
  재질    : 얇은 철판 + 가죽 연결 / 황금 리벳
  색처리  : 순백 가죽 기조 (#FAFAF5) + 황금 테두리 (#FFD700)
  어깨    : 얇은 철판 어깨 보호대 — 소년 체형 맞춤 (고루보다 경량)
            → 오른쪽 어깨: 신라 해 문양 양각 (화랑 표식)
  흉갑    : 가죽 기반 경량 흉갑 + 소형 철판 추가
  팔      : 전완 가죽 보호대 (금색 버클)

투구:
  종류    : 소형 원통형 투구 — 정수리 낮은 형태 (소년 체형)
  재질    : 철제 / 황금 테두리 장식
  이마    : 투구 아래 이마띠 유지 (훈련복 이마띠와 동일)
  목보호  : 경량 찰갑 라멜라 후면 (2단)

무기 착용 위치:
  주무기  : 활(弓) — 등 대각선 착용 (우측 어깨~좌측 허리)
            화살통: 오른쪽 등 허리 위치 (24발)
  보조    : 단검 — 왼쪽 허리 (빠른 발도용)
  전투 자세: 활 사격이 주전술 — 기마보다 지상 사격 특화

망토 (전투 시 미착용 — 활 사격 방해):
  색      : 순백 (#FAFAF5) — 예복·이동 시만 착용
  길이    : 어깨~허리 (짧은 형태 / 소년 체형)
  고정    : 왼쪽 어깨 태양 버클
```

### C. 예복 (의례·화랑 공식 행사)

```
포(袍)   : 고급 비단 순백 직령포 — 소매 넓음 / 금색 운문(雲紋) 자수 하단
관모     : 화랑 공식 관모 — 검은 비단 기저 / 황금 태양 장식 전면
허리띠   : 금동제 과대 — 태양 문양 버클 (화랑 등급 표시)
신발     : 순백 비단 이(履) — 황금 버클
장신구   : 오른쪽 귀 황금 화살 귀걸이 (예복 시도 유지)
         : 이마띠 제거 (예복 시)
특이사항 : 활은 예복 시 소지 불가 → 단검만 허리 소지
```

## 4. 특징적 소품 상세

### 전용 무기 — 「빛의 활 (弓)」

```
공식명칭 : 빛의 활 (弓, Light Bow)
전수자   : 화랑 스승 → 하린 (S1 화랑 정식 입문 시 수여)
길이     : 130cm (복합궁 / 소년 체형 맞춤형)
소재     : 뽕나무·물소 뿔·힘줄 복합재
           겉면: 자작나무 껍질 마감 — 순백 기조
장식     : 자루 중앙: 황금 태양 문양 상감
           시위 끝단: 황금 버클 / 신라 양식
시위     : 연백색 마실 (麻絲) — 날카롭게 튕김
사거리   : 훈련 기준 180m / 정밀 사격 80m
화살통   : 순백 가죽 / 황금 버클 / 24발 수용
무게     : 약 1.1kg (경량 복합궁)

시각적 포인트:
  - 활 겉면: 태양빛이 비칠 때 자작나무 껍질이 흰빛 발산
  - 시위를 당길 때 팽팽해지는 라인이 하린의 집중을 가시화
  - 화살 깃: 주황 (#FF8C00) + 흰색 교차 줄무늬 (식별용)
  - 사격 직전 눈을 가늘게 뜨는 하린의 유일한 집중 표정
```

### 보조 소품

```
단검 (短劍):
  색     : 순백 가죽 칼집 / 황금 버클
  길이   : 전장 40cm (날 27cm) — 근접 전투용
  재질   : 날 철제 / 손잡이 황금 장식 + 가죽 그립
  문양   : 날 기저 「河璘」 한자 소형 음각
  의미   : 화랑 입문 시 자신이 선택한 무기 (주무기 활과 세트)
  상태   : 날 광택 유지 (사용 흔적은 최소 — 주력은 활)

화랑 이마띠:
  재질   : 흰 비단 (#FFFEF0) / 폭 3cm
  문양   : 중앙 황금 태양 소형 자수 (하린 개인 자수 — 직접 새김)
  의미   : 화랑 입문의 증표 / 하린의 정체성 = 빛을 향하는 자
  상태   : 약간 구겨지고 마모됨 (매일 착용, 훈련의 흔적)

황금 화살 귀걸이:
  위치   : 오른쪽 귀만 (왼쪽 없음 — 비대칭 의도)
  재질   : 금 / 화살 형태 수직 방향
  길이   : 2.5cm (귀 아래로 내려오는 형태)
  의미   : 신라 화랑 화살 표식 — 활 전사 증표
  상태   : 반짝거림 유지 (하린이 닦는 습관)
```

## 5. 표정·감정 스펙 (5종)

### 기본 표정 규칙

```
하린의 얼굴은 항상 열려 있다.
감정이 바로 얼굴에 나타난다 — 필터가 없는 것이 특징.
분노도 기쁨도 슬픔도 즉각적으로 표정에 올라온다.
이것이 하린의 강점이자 약점 — 적에게 읽히나 동료에게 신뢰를 준다.
```

### 표정 1 — 활력 (Vitality) ★기본값

```
눈      : 크게 뜬 눈 — 항상 무언가를 발견하는 눈빛
          홍채 황금빛 광채가 빛에서 가시화
눈썹    : 자연스럽게 올라간 아치 — 관심과 흥미 항시 표현
입      : 약간 열린 입 — 말하려는 준비 상태
          또는 씩 웃는 입꼬리 (보조개 가시화)
자세    : 고개 5-10° 앞으로 기울임 — 상대에게 가까워지려는 본능
전체    : 「이 사람과 이야기하면 재미있겠다」는 자연스러운 끌림

아트 디렉션:
  눈빛에 항상 「다음 순간에 대한 기대」유지
  태양 아래 선 것처럼 빛을 흡수하는 밝음
```

### 표정 2 — 집중 (Focus) ★핵심 표정 (활 사격)

```
눈      : 가늘게 좁혀진 눈 — 목표물만 보는 레이저 시선
          평소의 크고 밝은 눈과 대비 극명 (전환 임팩트)
눈썹    : 살짝 안으로 모임 — 적당한 긴장
입      : 굳게 다문 직선 / 입술 안으로 약간 말림
호흡    : 내려가는 흉곽 — 숨 참기 직전 상태
팔      : 오른팔 활 당김 / 어깨~팔 근육 긴장 가시적
전체    : 「활 시위를 떠나기 직전 0.5초」

대표 장면: 화랑 훈련 사격 / 전투 첫 화살 / 결정적 순간 사격
아트 디렉션:
  눈빛에만 집중하는 컷 — 하린의 평소와 완전히 다른 얼굴
  이 표정이 나올 때 캐릭터가 진짜임을 보여주는 순간
```

### 표정 3 — 분노 (Open Anger) ★솔직한 분노

```
주의    : 하린의 분노는 숨기지 않는다. 바로 드러난다.
          단, 충동적 행동으로 이어지되 후회를 한다.

눈      : 완전히 뜬 눈 + 눈썹이 확 올라감
눈썹    : 위로 치솟음 — V자 아닌 역V자 (분노한 소년)
입      : 크게 벌어진 입 / 고함치는 상태 또는 이를 악문 상태
볼      : 붉게 달아오름 (분노 혈색 — 하린 특유)
손      : 주먹 쥠 / 활 자루 꽉 쥠
전체    : 숨기지 않는 솔직한 분노 — 뜨겁고 정직하다

금지    : 차가운 분노 표현 — 그것은 고루·아랑의 영역
아트 디렉션:
  볼 붉어짐 연출 필수 (분노 혈색)
  뜨겁게 터지되 비열하지 않은 순수한 열기
```

### 표정 4 — 슬픔 (Expressed Grief) ★감추지 못하는 슬픔

```
눈      : 크게 열리다 금방 눈물이 맺힘 — 참으려 하나 실패
눈썹    : 중앙 위로 강하게 모임 — 슬픔이 바로 올라옴
입      : 굳게 다물려 하나 입꼬리가 무너짐 — 턱이 떨림
코      : 살짝 붉어짐
전체    : 「참으려 하지만 얼굴이 먼저 배신하는」순간

대표 장면: 전우 부상 / 스승 질책 / 신라의 고난 목격 씬
아트 디렉션:
  눈물 표현 S2부터 허용 (소년이라 성숙한 절제가 없음)
  S3에서는 대성통곡 1회 허용 (성장 통과의례)
  슬픔이 바로 얼굴에 올라오는 것이 하린의 인간미
```

### 표정 5 — 기쁨 (Bright Joy) ★자주 등장

```
빈도    : 전체 에피소드에서 40회 이상 (하린의 핵심 감정)
          단, 진짜 기쁨(20회)과 작은 기쁨(20회) 구분

진짜 기쁨:
  눈      : 반달 눈 — 눈꼬리 완전히 내려감 / 홍채 황금빛 폭발
  보조개  : 오른쪽 볼 보조개 최대 가시화
  입      : 활짝 열린 웃음 — 이가 보임
  전체    : 태양 같은 웃음 — 주변을 밝게 만드는 효과

작은 기쁨:
  입꼬리 : 자연스럽게 3-4mm 올라감 / 보조개 은은하게
  눈      : 부드럽게 빛남

대표 장면: 화살 명중 순간 / 동료와 훈련 / S3 고루와의 전우애 씬
```

## 6. 캐릭터 포즈 스펙 (기본 3종)

### 포즈 1 — 정면 기본 (Standard Front)

```
용도    : 캐릭터 카드 / 피규어 정면 기준 / 프로필

자세    :
  발    : 어깨 너비보다 약간 좁게 벌림 (20°-20°) — 소년의 경쾌함
  무릎  : 곧게 — 에너지 충만한 직립
  허리  : 곧되 살짝 앞으로 기댄 느낌 (적극적 자세)
  어깨  : 수평 — 약간 앞으로 나온 어깨 (다가오려는 자세)
  팔    : 오른팔 — 활을 수직으로 쥠 (자루 바닥이 오른발 옆)
          왼팔 — 자연스럽게 내려 엄지가 허리띠 근처
  시선  : 정면 응시 / 카메라를 보며 환하게 응시하는 눈빛
  턱    : 자연스럽게 수평 (위압적이지 않게 — 소년)
  표정  : 활력 (표정 1번) / 또는 집중 (표정 2번) 버전 제작

배경 기준 색: 황금 (#FFD700) 그라디언트 → 순백 (#FAFAF5)
```

### 포즈 2 — 측면 사격 준비 (Profile Draw)

```
용도    : 캐릭터 시트 측면 / 실루엣 확인 / 하린 핵심 이미지

자세    :
  방향  : 왼쪽 측면 (90° — 왼쪽이 카메라)
  발    : 오른발 뒤 / 왼발 앞 — 궁사 기본 자세
  무릎  : 왼 무릎 약간 굽힘 (안정 자세)
  허리  : 살짝 왼쪽으로 비틀림 (활 당김 준비)
  팔    : 왼팔 — 활 수평 쥠 (앞으로 뻗음)
          오른팔 — 시위 당기는 동작 직전 (귀 옆)
  고개  : 정면 (목표물 응시) — 눈 가늘어짐
  표정  : 집중 (표정 2번)

실루엣 체크포인트:
  활의 곡선이 측면 실루엣에서 선명하게 구분
  어깨~팔~활 라인이 하나의 당기는 에너지 흐름
  화살통이 등에서 보이는 위치 확인
```

### 포즈 3 — 전투 동작 (Combat Dynamic)

```
용도    : 액션 씬 키아트 / 게임 스플래시 / 웹툰 전투 컷

자세    :
  기본  : 오른발 뒤 고정, 왼발 앞 / 활을 당겨 사격 직전
  무릎  : 왼 무릎 150° / 오른 무릎 약간 굽힘 (안정 기반)
  허리  : 오른쪽 후방으로 비틀림 (활 당기는 장력 전달)
  어깨  : 왼어깨 앞 / 오른어깨 뒤로 당겨짐
  팔    : 왼팔 — 활 수평 최대 뻗음 (지면과 수평)
          오른팔 — 시위 귀 높이까지 당김 (최대 장력)
  활    : 수평 (어깨 높이 / 목표 궤적)

전투 모드 비주얼 추가:
  이마띠 : 약간 흐트러진 상태 허용 (전투 열기)
  경갑   : 움직임에 따라 가죽 부분 펄럭임
  눈빛   : 집중 (표정 2번) — 평소와 완전히 다른 차분함
  배경   : 신라 산지 또는 전장 초원
  효과   : 화살 깃 부분에 주황 빛 강조 이펙트

카메라 앵글 제안:
  메인키아트: 측면 낮은 앵글 (무릎 높이) → 활의 장력 강조
  웹툰 컷   : 정면 또는 약간 측면 (눈 집중 컷)
  게임 스플래시: 3/4 앵글 (오른쪽 뒤 45°) → 활 당기는 근육 강조
```
