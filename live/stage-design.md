## 무대 설계 철학

```
핵심 원칙:
  「강은 무대 위를 흐른다」

  공간 언어:
    무대 = 한반도 그 자체
    중앙: 강 (시간·역사·기억의 상징)
    좌: 고구려 / 우: 백제 / 후: 신라 / 전면: 가야
    조명 = 왕국의 색 (왕국 전환 시 조명 색 변화)

  역사극 미학:
    실제 고증 + 상징적 추상화 균형
    유물·유적 모티브 → 무대 조형으로 재현
    불필요한 리얼리즘 배제 (관객 상상력 존중)
```

## 무대 구조

### 주 무대 (Main Stage)

```
프로시니엄 아치형 (Proscenium Arch):
  개구부: 폭 18m × 높이 10m
  무대 깊이: 16m
  좌우 윙: 각 6m (조명·세트 대기)
  오케스트라 피트: 30인 편성 (뮤지컬 표준)

가변 무대 요소:
  리프트 A (중앙): 지하 → 무대 상승 (6m × 6m)
    → 수문 개방 장치 (살수대첩 연출)
    → 고분 등장 장치 (가야 장면)
  리프트 B (후방): 성벽 등장 (3m × 12m)
    → 평양성·사비성 성벽 세트 상승
  턴테이블 (직경 8m): 왕국 전환 회전 무대
    → 45° 회전 = 장면 전환 (약 8초)
```

### 연장 무대 (Extended Stage)

```
런웨이 (Runway):
  객석 중앙 통로 런웨이 (폭 2m, 길이 15m)
  용도: 4인 행진 장면 / 전투 돌격 장면
  하린 기마 대체 연출 (실제 말 대신 조명+사운드)

오버헤드 장치:
  플라잉 리그: 배우 최대 4인 동시 비행 가능
  투명 막 (Scrim): 전장 연기·안개 효과
  드롭 커튼: 왕국별 2세트 (총 8개 드롭)
```

## 왕국별 무대 룩

### 고구려 장면

```
색조: 청람 (#2F4F7F) + 흑색 조명 기조
세트 요소:
  안학궁 성벽: 거친 돌 질감 패널 (3m × 8m) × 4
  살수 강: 무대 전면 수조 설치 (실제 물, 폭 1m)
  봉화 장치: 양 사이드 실제 불꽃 봉화 (방화 처리)

조명:
  주조명: 차가운 청백색 (6500K)
  역광: 강한 후방 청람 빔 → 실루엣 강조
  살수 장면: 블루 레이저 + 물 반사

사운드:
  고구려 테마 「철의 북쪽 바람」라이브 연주
  타악 강조 (북·징 생음향)
  풍향기 (체험형 바람 연출)
```

### 백제 장면

```
색조: 황금 (#B8960C) + 따뜻한 앰버 조명
세트 요소:
  미래사 목탑 미니어처 (높이 4m, 황금빛)
  연등 300개 오버헤드 (LED 실제 등 형태)
  죽간 서가 (아랑 기록관 배경)

조명:
  주조명: 따뜻한 앰버 (3000K)
  연등 야경: 실제 전구 등 + 디밍 제어
  낙화암 장면: 달빛 모노 스팟

사운드:
  가야금 + 대금 앙상블 (라이브 2인)
  연등 바람 소리 (서라운드)
  강물 흐름 사운드
```

### 신라 장면

```
색조: 금빛 (#FFD700) + 고대비 조명
세트 요소:
  황룡사 9층탑 실루엣 드롭커튼 (뒷면 투영)
  화랑 훈련장 목책 (이동식 4세트)
  황산벌 평야: 낮은 안개 머신 (드라이아이스)

조명:
  주조명: 골든 앰버 (2700K)
  전투 장면: 고대비 스트로브 사용 (주의 고지)
  승리 장면: 전체 황금빛 플러드

사운드:
  화랑 테마 「임전무퇴」현악 버전
  전투 타악 (서라운드 멀티채널)
  관창 장면: 완전한 음악 중단 → 침묵 3초
```

### 가야 장면

```
색조: 황토 (#C8A96E) + 노을 조명
세트 요소:
  낙동강 갈대 (실물 크기 인공 갈대 군락)
  고분 언덕 (리프트 활용, 황토색 경사면)
  가야금 연주대 (무대 중앙 홀로 배치)

조명:
  주조명: 황혼 주황-자주 (2200K)
  「676」마지막 장면: 서서히 밝아지는 새벽 빛
  니문 연주: 단독 핀스팟 (나머지 완전 암전)

사운드:
  가야금 솔로 라이브 (니문 역 배우 직접 연주 또는 옆무대 연주자)
  낙동강 물소리 + 바람 (극도로 낮은 볼륨)
  「676」피날레: 오케스트라 전체 합류
```

## 핵심 장면 무대 연출

### 살수대첩 (1막 피날레)

```
진행:
  1. 고구려 성벽 세트 상승 (리프트 B)
  2. 수나라 군 배우 100명 런웨이 + 객석 진입
  3. 을지문덕 등장 — 성벽 최상부 (플라잉)
  4. 「기다려라」노래 → 클라이맥스
  5. 리프트 A 하강 → 수문 개방 효과
  6. 무대 전면 수조 범람 (실제 물 15cm 범람)
  7. 블루 레이저 + 안개 → 강물 범람 시각화
  8. 암전 → 「강은 기억한다」테마 오케스트라

안전:
  수조 범람: 방수 처리 + 배우 방수 의상
  관객석 최전열 물 보호막 설치
  스트로브 사용 시 사전 고지
```

### 황산벌 결전 (2막 클라이맥스)

```
진행:
  1. 턴테이블 회전 → 황산벌 평야 전환
  2. 드라이아이스 안개 전체 무대
  3. 관창 배우 런웨이 돌격
  4. 조명 전체 꺼짐 → 단독 핀스팟만
  5. 계백과의 결투: 슬로모션 연출 (배우 동작 느리게)
  6. 관창 전사: 완전 암전 + 침묵 3초
  7. 하린 독창 「너는 기억된다」
  8. 조명 서서히 복귀

특수 효과:
  무대 전체 안개: 시야 1m 이하
  소리 없는 전투: 효과음 없이 배우 움직임만
```

### 기벌포 피날레 「676」

```
진행:
  1. 바다 세트 등장 (턴테이블 + 블루 조명)
  2. 4인 함선 뱃머리 동시 등장
  3. 니문 가야금 솔로 시작
  4. 오케스트라 한 악기씩 합류 (크레셴도)
  5. 고루 속삭임 「강은 기억한다」(마이크 없이)
  6. 무대 서서히 밝아짐 → 새벽 빛
  7. 전체 투명 막 내림 → 강물 영상 투영
  8. 커튼콜: 전체 조명 + 4인 런웨이 인사

감동 포인트:
  고루 대사: 마이크 없이 — 관객이 귀 기울여야
  니문 가야금: 배우 직접 연주 (진정성 극대화)
  새벽 빛: 30초에 걸쳐 서서히 밝아짐
```

## 기술 사양

```
조명:
  LED 무빙헤드: 120대
  컨벤셔널 조명: 80대
  레이저: 블루·청람 레이저 2세트
  조명 콘솔: ETC Eos (프로그래밍 기반)

음향:
  L-ACOUSTICS K2 라인어레이 시스템
  서라운드 4채널 (전·후·좌·우)
  오케스트라 피트 30인 라이브 연주
  마이크: 배우 헤드셋 마이크 + 무대 마이크

특수효과:
  드라이아이스 머신: 4대
  안개 머신: 8대
  풍향기: 좌·우 각 2대
  실제 불꽃: 봉화 2대 (소방 허가 필수)
  수조: 무대 전면 50cm 깊이 (실제 물)
```

## 안전 기준

```
배우 안전:
  플라잉 장면: 안전 와이어 2중화
  수조 장면: 방수 의상 + 논슬립 처리
  스트로브 사용: 간질 발작 주의 고지 필수

관객 안전:
  수조 범람: 최전열 물 차단막 설치
  레이저: 눈 높이 이상 조사 금지
  비상 탈출구: 전 방향 조명 확보
  실제 불꽃: 소방차 대기 (옥외) / 실내 금지
```
