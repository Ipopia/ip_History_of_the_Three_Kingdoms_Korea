## 촬영 철학

```
핵심 원칙:
  「역사의 무게를 렌즈에 담는다」

3대 촬영 원칙:
  1. 자연광 우선 — 인공조명은 자연광 보조로만
  2. 인물 중심 — 역사가 배경, 인간이 주인공
  3. 강물 = 시간 — 강물 샷은 항상 의미를 가진다

참조 작품:
  「마지막 결투」(리들리 스콧): 역사극 카메라 무게감
  「겨울왕국」vs 「킹덤」: 드라마 vs 판타지 균형점
  「미나리」(이삭 정): 한국적 공간 활용
  「아가씨」(박찬욱): 역사 공간 + 감정 클로즈업
```

## 카메라 설정 기준

### 포맷

```
촬영 포맷:
  주 카메라: ARRI Alexa 35 (영화급 화질)
  보조: Sony VENICE 2 (저조도·수중 촬영)
  액션 카메라: Sony FX3 (경량·기동성)
  드론: DJI Inspire 3 (항공 조감)

해상도:
  촬영: 4.6K RAW (후반 4K 마스터)
  납품: UHD 4K (OTT 기준)
  IMAX 버전: 6.5K 오버샘플링 옵션

화면비:
  드라마 본편: 2.39:1 (시네마스코프 — 스케일감)
  인물 집중 씬: 1.85:1 전환 가능
  모바일 세로 클립: 9:16 리프레이밍 버전 별도 편집
```

### 렌즈

```
주 렌즈: ARRI Signature Prime 세트
  18mm — 환경 광각·위압적 군중
  25mm — 표준 환경
  35mm — 인물+배경 균형 (전투·대화)
  50mm — 인물 클로즈업 (감정 장면)
  75mm — 역사 인물 클로즈업 (주인공 결의)
  135mm — 원거리 망원·군중 속 인물

조리개:
  기본: T2.8~T4 (심도감 유지)
  감정 절정: T1.5~T2 (배경 흐림, 인물 집중)
  전장 광각: T5.6~T8 (전체 선명)
```

## 왕국별 촬영 스타일

### 고구려 — 「대지와 철의 카메라」

```
카메라 움직임:
  슬라이더 + 짐벌 조합 (안정적·묵직한 이동)
  급격한 핸드헬드 최소화
  롱 테이크 선호 (5~10초 컷)

구도:
  저앙각(Low Angle): 인물 위압감 (고루·을지문덕)
  수평선 강조: 광활한 고구려 평야 스케일
  대칭 구도: 요새·성벽 장면

조명:
  자연광 청람 톤 (새벽·황혼 선호)
  인공광: 모닥불·봉화 활용
  겨울 장면: 자연 역광 → 실루엣 강조

대표 샷:
  고루 클로즈업: 75mm T2.0 → 눈빛 최대 강조
  살수 강변 광각: 드론 + 18mm → 강물 전체
  을지문덕 지시 씬: 저앙각 + 역광 → 신화적 존재감
```

### 백제 — 「금빛과 연등의 카메라」

```
카메라 움직임:
  크레인 업/다운 (연등·목탑 스케일)
  느린 달리 트래킹 (아랑 시점)
  회전 달리 (연등 야경 포위 장면)

구도:
  따뜻한 황금 프레임 (촛불·등불 자연 광원 활용)
  죽간 필사 씬: 극단적 클로즈업 (손·붓·글자)
  사비성 전경: 크레인 하이앵글

조명:
  연등 야경: 기존 조명 최소화 → 등불 자연광
  문서관 씬: 촛불 배치 + 소프트박스 보조
  낙화암 씬: 백마강 달빛 + 최소 인공광

대표 샷:
  아랑 죽간 씬: 50mm T1.8 → 손·붓·표정 포커스 이동
  연등 야경: 25mm + 크레인 → 연등 바다 조감
  금동대향로 인서트: 매크로 렌즈 → 문양 클로즈업
```

### 신라 — 「황금빛과 역동의 카메라」

```
카메라 움직임:
  핸드헬드 허용 (화랑 전투·훈련 씬)
  빠른 팬·틸트 (하린 기마 액션)
  드론 추적 (기마 달리기 시퀀스)

구도:
  역동적 대각선 구도 (액션)
  황금 비율 선호 (하린 클로즈업)
  황산벌 전장: 하이앵글 + 로우앵글 교차

조명:
  황금 시간대(골든 아워) 촬영 최우선
  전투 씬: 높은 대비 (강렬한 명암)
  선덕여왕 씬: 소프트 황금빛 후광 효과

대표 샷:
  하린 말 달리기: 드론 추적 + 저앙각 (스피드감)
  화랑 훈련 활쏘기: 핸드헬드 과녁 추적
  황산벌 클라이맥스: 슬로모션 240fps → 감정 강조
```

### 가야 — 「황혼과 소멸의 카메라」

```
카메라 움직임:
  최소한의 움직임 (정적·명상적)
  서서히 줌인 (가야금 연주 집중)
  수평 슬라이드 (낙동강 변 풍경)

구도:
  니문 중앙 배치 → 주변 빈 공간 강조 (고독감)
  가야금 현: 극단적 클로즈업 (손가락·현 진동)
  낙동강 황혼: 수평선 + 실루엣

조명:
  황혼 황토빛 자연광 극대 활용
  가야금 씬: 사이드 조명 → 현 반짝임 강조
  「676」마지막 씬: 새벽 빛 서서히 밝아짐

대표 샷:
  니문 연주 클로즈업: 135mm T2.0 → 얼굴+손 포커스 이동
  낙동강 황혼 광각: 18mm → 니문 실루엣 + 강물
  가야금 현 매크로: 현 진동 사운드 비주얼라이즈
```

## 특수 촬영 기법

### 슬로모션

```
장비: Phantom Flex4K (1,000fps)
용도:
  황산벌 전투 클라이맥스: 120~240fps
  살수 수문 개방 물 범람: 500fps (물 입자 시각화)
  가야금 현 진동: 1,000fps (소리를 눈으로)
  관창 특공 마지막 순간: 240fps

편집 지침:
  슬로모션 = 감정 절정 전용 (남용 금지)
  1에피소드당 3회 이내
```

### 수중 촬영

```
장비: Sony VENICE 2 + 수중 하우징
용도:
  살수대첩 강물 범람 수중 시점
  기벌포 해전 함선 침몰 수중
  아랑 낙화암 장면 (창작 — 강물 아래 시점)

조명:
  수중 LED 패널 사용
  수면 반사광 자연 활용
```

### 드론 촬영

```
장비: DJI Inspire 3 + Zenmuse X9
주요 드론 샷 목록:
  살수 전경 조감 (612년 전장)
  사비성 연등 야경 조감
  황산벌 전투 조감 (전장 규모 표현)
  기벌포 해전 함선 조감
  한반도 강 조감 (오프닝·엔딩 타이틀)

비행 제한:
  문화재 구역: 비행 허가 필수
  야간 비행: 법적 허가 취득
```

## 편집 리듬 가이드

```
전투 씬 컷 리듬:
  도입부: 5~8초/컷 (긴장 빌드업)
  클라이맥스: 1~2초/컷 (긴박감 최고조)
  결말부: 8~15초/컷 (여운·침묵)

감정 씬 컷 리듬:
  인물 대화: 4~6초/컷
  독백·내면: 8~15초/컷 (롱 테이크)
  침묵 장면: 10~20초/컷 (배우 연기 신뢰)

왕국별 평균 컷 길이:
  고구려 씬: 평균 6초 (무게감)
  백제 씬: 평균 7초 (서정적)
  신라 씬: 평균 3~4초 (역동)
  가야 씬: 평균 9초 (정적·명상)
```

## 왕국별 컬러 코드/DI 상세 + 60fps 슬로모션 전투 기준 (cinematography-guide.md 병합)

> 원본: `cinematography-guide.md` — 왕국별 HEX 컬러·DI 상세 + 전투 슬로모션 기준

### 왕국별 색조·DI 상세

```
고구려 — 군청 세계:
  색조: 군청 #2F4F7F / 회색 / 검정
  조명: 저조도 + 강한 대비 (키아로스쿠로)
  렌즈: 망원 (70~200mm) — 공간 압축, 힘과 밀도감
  카메라 움직임: 느리고 묵직한 달리 + 안정된 크레인
  색보정 (DI):
    청색 채도 UP + 붉은 채도 DOWN
    콘트라스트 HIGH
    섀도우: 짙은 파란빛

백제 — 황금 세계:
  색조: 황금 #B8960C / 따뜻한 오렌지 / 상아
  조명: 자연광 + 부드러운 필 라이트 (따뜻함)
  렌즈: 표준~광각 (35~50mm) — 자연스럽고 친밀한 공간
  카메라 움직임: 우아한 트래킹 + 부드러운 핸드헬드 (소폭)
  색보정 (DI):
    황색·주황 채도 UP
    전체 밝기 약간 UP (밝고 아름다운 느낌)
    멸망 후: 점차 탈색 (잿빛으로 전환)

신라 — 금빛 세계:
  색조: 금색 #FFD700 / 밝은 하늘색 / 흰색
  조명: 고조도 + 밝고 선명한 (황금시간대 적극 활용)
  렌즈: 표준 (50mm) — 균형 잡힌 자연스러운 시각
  카메라 움직임: 역동적 달리 + 드론 (전투·이동 장면)
  색보정 (DI):
    황색 채도 최대
    하이라이트 따뜻하게
    전체: 밝고 화려함 유지

가야 — 황토 세계:
  색조: 황토 #C8A96E / 갈색 / 자연색
  조명: 황혼빛 + 모닥불·용광로 불빛 (따뜻하지만 외로운)
  렌즈: 광각~중망원 (28~85mm) — 넓은 자연 공간
  카메라 움직임: 정적인 고정 숏 + 느린 패닝
  색보정 (DI):
    황토·갈색 채도 강조
    전체: 약간 탈색 (소멸 직전 느낌)
    니문 에필로그: 가장 따뜻한 색온도 (노년의 평화)
```

### 60fps 슬로모션 전투 기준

```
고구려 전투 씬 기법:
  안시성 성벽 위: 와이드 앵글 + 하늘 공간 활용
  전투 장면: 60fps 슬로모션 + 정상 속도 교차
  고루 클로즈업: 고정 숏 (움직임 없이 눈빛으로)

살수대첩 클라이맥스:
  댐 개방 순간: 수문 열리는 순간 고속 촬영 (120fps)
  물 방류 시작: 수중 카메라 + 지상 카메라 동시
  수몰 장면: 슬로모션 50% + 수중 영상 합성 (CG 보조)

낙화암 장면:
  촬영 원칙: 직접 묘사 최소화 — 소리·이펙트 위주
  아랑 시점: 클로즈업 → 반응으로 서술
  금지 촬영: 낙화 직접 장면 촬영 없음
  ADV-HISTORY + 방송심의 기준 준수

현장 촬영 규정:
  골든 아워 관리:
    일출·일몰 30분 = 모든 스태프 대기 완료
  안전 기준:
    수중 촬영: 수상 안전 요원 2명 이상 상시
    전투 장면: 스턴트 팀 + 안전 감독 필수
    낙화암 장면: 심리 지원 상담가 현장 대기
  기상 기준:
    강풍 20m/s 이상: 야외 촬영 중단
```
