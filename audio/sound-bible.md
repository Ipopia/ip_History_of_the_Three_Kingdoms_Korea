# 사운드 바이블 — 삼국(三國) IP

**참조 문서**: `ost-concept.md`, `sfx-catalog.md`, `ambience-map.md`
**사운드 디렉터 원칙**: "삼국의 소리는 현대 오케스트라로 연주되지만, 영혼은 반드시 한국 전통 악기에서 나와야 한다."

---

## 사운드 디자인 철학

### 3대 원칙

1. **역사적 진정성**: 삼국시대 실존 악기 우선 — 가야금·거문고·해금·피리·대금·장구·북
2. **감정적 보편성**: 서양 오케스트라로 글로벌 감성 연결
3. **왕국별 음향 정체성**: 소리만으로 어느 왕국 장면인지 식별 가능

### 왕국별 사운드 DNA

| 왕국 | 주 악기 | 음계 | 템포 | 음색 |
|------|--------|------|------|------|
| 고구려 | 거문고·북·뿔나팔 | 단조·5음계 | 느림~폭발 | 어둡고 웅장 |
| 백제 | 가야금·피리·해금 | 장조·서정 | 중간·유려 | 우아하고 서정적 |
| 신라 | 향비파·대금·범종 | 청명·신성 | 다양 | 황금빛·종교적 |
| 가야 | 가야금·북·철 타악 | 힘차고 리드미컬 | 빠름 | 역동적·원시적 |

## 음악 총괄 구조

### 메인 테마 "강은 기억한다" — 전체 IP 시그니처

```
구성: 가야금 솔로 → 거문고·해금 화음 → 오케스트라 빌드업 → 전체 합주

조성: D단조 → D장조 전조 (비극에서 희망으로)
길이: 4분 20초 (완전판) / 45초 (트레일러) / 15초 (로고 스팅)

사용: 각 시즌 오프닝·엔딩, 트레일러, 이벤트
```

### 왕국 테마 모음

**고구려 테마 "쇠와 바람"**
```
주 악기: 거문고 + 오케스트라 타악부
조성: E♭단조
특징: 점강(crescendo) 구조 — 침묵에서 폭발로
변주: 광개토대왕 버전 (웅장) / 을지문덕 버전 (냉철) / 연개소문 버전 (반항적)
```

**백제 테마 "흰 꽃이 지다"**
```
주 악기: 가야금 + 피리 + 현악 앙상블
조성: G장조 → 멸망 시 Gm 전조
특징: 아름다운 선율 → 비극적 해체
변주: 서정 버전 (백마강) / 비극 버전 (낙화암)
```

**신라 테마 "황금의 나라"**
```
주 악기: 대금 + 향비파 + 합창 + 범종
조성: A장조
특징: 상승하는 선율 — 통일을 향한 야망
변주: 선덕여왕 버전 (지혜) / 김유신 버전 (전쟁) / 통일 버전 (공허한 승리)
```

**가야 테마 "불꽃과 소리"**
```
주 악기: 가야금 + 타악 (철 소재) + 리드미컬 북
조성: F#단조
특징: 원시적 에너지 → 소멸로 수렴
변주: 건국 버전 (희망) / 우륵 버전 (서정) / 멸망 버전 (단조)
```

## 장면 유형별 사운드 가이드

### 전투 장면

| 단계 | 사운드 처리 | 악기 |
|------|----------|------|
| 전투 전 긴장 | 낮은 드론음 + 심박 북 | 거문고 저음 + 북 |
| 전투 개시 | 폭발적 타악 | 북·징·뿔나팔 |
| 전투 중 | 빠른 오케스트라 + 전투 SFX | 현악+타악 |
| 전세 역전 | 조성 전환 | 전 악기 |
| 전투 종료 | 급격한 음량 감쇄 | 솔로 악기만 |
| 전투 후 | 비극 또는 승리 테마 | 상황별 |

### 정치·외교 장면

| 장면 유형 | 사운드 | 특성 |
|---------|--------|------|
| 왕의 등장 | 해당 왕국 테마 웅장 버전 | 느린 빌드업 |
| 외교 협상 | 두 왕국 테마 대위법 | 긴장·조화 병존 |
| 음모·배신 | 반음계 불협화음 | 낮은 현악 |
| 동맹 체결 | 두 테마 합주 | 조화로운 해결 |

### 감정·내면 장면

| 감정 | 악기 | 처리 |
|------|------|------|
| 슬픔·이별 | 해금 솔로 | 느린 비브라토 |
| 결의·각오 | 거문고 + 북 | 점진적 강세 |
| 사랑·그리움 | 가야금 + 피리 | 서정적 선율 |
| 분노·복수 | 타악 + 낮은 현악 | 불규칙 리듬 |
| 죽음·희생 | 전 악기 소멸 → 침묵 | 디미누엔도 |
| 기쁨·축제 | 대금 + 장구 + 합창 | 밝고 빠른 |

## 더빙 & 보이스 디렉션

### 왕국별 대사 톤 가이드

**고구려**
- 왕족: 낮고 무거운 흉성(胸聲) 기반
- 장군: 간결하고 명령적
- 병사: 거칠고 직접적
- 금지: 높은 음역의 가성, 과도한 감정 표현

**백제**
- 왕족: 우아하고 부드러운 발음, 정확한 한자어
- 귀족: 세련되고 약간 느린 속도
- 민중: 따뜻하고 감성적
- 금지: 거친 발음, 군사적 억양

**신라**
- 왕족: 신성하고 권위 있는 억양
- 화랑: 젊고 열정적, 이상적 발음
- 승려: 낮고 평온한 독경 억양
- 선덕여왕: 소크라테스식 — 질문하듯 끝 올림

**가야**
- 왕족: 힘차고 실용적
- 장인: 간결·자신감
- 상인: 다국어 억양 혼재 (교역 특성)
- 우륵: 시적이고 느린 — 음악가 특유의 리듬감

### 보이스 캐스팅 원칙

```
고구려 왕족: 50~60대 중후한 남성 (극적 파급력)
백제 왕족: 40~50대 세련된 성우 (발음 명료성)
신라 여왕: 40대 여성 — 지성·권위·따뜻함 3합
화랑: 20~30대 남성 — 이상·열정·청춘
가야 장인: 40~50대 — 거칠고 진실된 목소리
우륵: 40~50대 남성 — 시인 같은 발성
```

## 레코딩 계획

### 전통 악기 레코딩 세션

```
Session 1: 현악기 (가야금·거문고·해금·향비파)
- 장소: 국립국악원 녹음실 (협력 추진)
- 악기: 정악용·창작음악용 혼합
- 방식: 솔로 + 앙상블 각각 레코딩

Session 2: 관악기 (대금·피리·태평소·뿔나팔)
- 특수 마이킹: 공간 울림 극대화

Session 3: 타악기 (장구·북·징·꽹과리)
- 전투 SFX 겸용 레코딩
- 철 타악: 가야 제철 현장음 현지 레코딩

Session 4: 오케스트라 세션
- 서울 필하모닉 협력 추진 (또는 해외 녹음)
- 전통 악기 레이어링 병합
```
