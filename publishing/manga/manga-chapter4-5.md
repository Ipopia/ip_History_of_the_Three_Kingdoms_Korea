### p.100~101 — [원광법사 등장 / 더블 페이지]

**배경**: 수련원 강당, 오전
**레이아웃**: 더블 페이지 캐릭터 소개

**패널 1 (좌 페이지 전체, p.100)**:
  - 화랑들이 강당 마루에 정좌해 있음. 원광법사(圓光法師)가 앞에 앉아있음
  - 원광법사: 노승. 백발. 온화하나 눈이 깊음. 법복
  - 원광법사: 「세속오계(世俗五戒)를 다시 읽는다.」
  - 두루마리를 펼침

**패널 2 (우 페이지 상단 1/2, p.101)**:
  - 두루마리 클로즈업. 한자 선명하게:
    ```
    一. 事君以忠 — 사군이충 (임금을 충성으로 섬겨라)
    二. 事親以孝 — 사친이효 (어버이를 효도로 섬겨라)
    三. 交友以信 — 교우이신 (벗을 믿음으로 사귀어라)
    四. 臨戰無退 — 임전무퇴 (싸움에 임해 물러서지 마라)
    五. 殺生有擇 — 살생유택 (생명을 죽임에 가림이 있어라)
    ```

**패널 3 (우 페이지 하단 1/2, p.101)**:
  - 화랑들이 눈을 내리깔고 듣고 있음
  - 하린만 원광법사를 똑바로 봄. 그 눈에 의문이 있음
  - 원광법사, 하린의 눈빛을 알아챔
  - 원광법사: (미소) 「하린. 물어보고 싶은 게 있느냐.」

**SFX**: (없음)
**연출 노트**: 두루마리의 한자는 독자가 읽을 수 있게 크고 선명하게. 하린의 시선 방향을 통해 그의 성격(직설적, 의문을 참지 못함)을 드러낼 것.
