## 피규어 라인 개요

```
라인 구성:
  STANDARD LINE: 보급형 (PVC, 18cm)
  DELUXE LINE: 중급형 (ABS+PVC, 25cm, 도색 정밀)
  ROYAL LINE: 프리미엄 (레진, 30cm+, 한정판)
  CHIBI LINE: 미니 데포르메 (PVC, 7cm)

제조 파트너:
  국내: 국내 완구사 (OEM 우선 협상)
  해외: 일본 굿스마일/코토부키야급 협력사 검토
  품질 기준: 해외 선진 피규어 공정 기준 적용

가격대:
  STANDARD: 35,000~50,000원
  DELUXE: 80,000~120,000원
  ROYAL: 200,000~350,000원
  CHIBI: 15,000~25,000원
```

## 주인공 4인 피규어

### 고루 (高婁) — 고구려 장군

```
STANDARD LINE:
  자세: 환두대도 수직으로 들고 서 있는 자세
  의상: 고구려 흑철 찰갑 + 삼족오 문양 투구
  표정: 정면을 응시하는 굳은 표정
  소품: 환두대도 + 방패 (탈착 가능)
  색상 기준: 청람 #2F4F7F + 철회 #4A4A4A

DELUXE LINE:
  자세: 전투 중 검 내려치는 동세
  의상: 완전 찰갑 + 개마무사 스타일 갑옷
  표정: 교체 가능 (결단/냉정/분노 3종)
  소품: 환두대도 + 살수 댐 배경 베이스
  특이: 갑옷 금속 질감 특수 도색

ROYAL LINE (한정판):
  자세: 살수 언덕 위 — 승리 후 강을 바라보는 장면
  연출: 바람에 날리는 망토 + 발아래 물 흐름
  베이스: 살수강 레진 투명 제작
  부속: 교체 가능 손 3종 + 작은 봉화 소품
  수량: 3,000개 한정
```

### 아랑 (阿郞) — 백제 귀족 여성

```
STANDARD LINE:
  자세: 자수 작업 중 앉아있는 모습
  의상: 백제 비단 포 — 연지색
  표정: 집중하는 표정 (부드러운)
  소품: 자수 바늘 + 비단 조각
  색상 기준: 황금 #B8960C + 연지 #C0392B

DELUXE LINE:
  자세: 금동대향로 앞에 서서 바라보는 모습
  의상: 왕실 예복 (단청 문양 직물)
  표정: 교체 가능 (평온/슬픔/결의 3종)
  소품: 금동대향로 미니 레플리카 + 봉황 자수 천
  특이: 비단 의상 반투명 레진 표현

ROYAL LINE (한정판):
  자세: 낙화암 절벽 끝 — 뒤를 바라보는 모습
  연출: 바람에 날리는 긴 소매 + 발아래 강물
  베이스: 낙화암 절벽 레진 표현
  조명: LED 내장 (황금빛 조명 연출)
  수량: 2,500개 한정
```

### 하린 (夏麟) — 신라 화랑

```
STANDARD LINE:
  자세: 말 위에서 활 겨누는 기마 궁사 자세
  의상: 신라 금동 경갑 + 화랑 띠
  표정: 집중하는 표정 (눈빛 날카롭게)
  소품: 각궁 + 화살통 + 말 조형물
  색상 기준: 금빛 #FFD700 + 주황 #E67E22

DELUXE LINE:
  자세: 단검 + 활 동시 소지, 전투 준비 자세
  의상: 완전 전투 화랑 갑옷
  표정: 교체 가능 (전투/성찰/청년 3종)
  소품: 단검·각궁·방패 탈착 세트
  특이: 금빛 갑옷 메탈릭 도색

ROYAL LINE (한정판):
  자세: 황산벌 — 계백 시신 앞 무릎 꿇는 장면
  연출: 석양 빛 조명 효과 + 석양 컬러 베이스
  부속: 계백 투구 미니어처 (별도 소품)
  수량: 2,000개 한정 (가장 드라마틱)
```

### 니문 (尼文) — 가야 음악가

```
STANDARD LINE:
  자세: 앉아서 가야금 연주하는 모습
  의상: 황토 삼베 포 + 짚신
  표정: 눈 감고 연주하는 평온한 표정
  소품: 가야금 (12현 정밀 재현)
  색상 기준: 황토 #C8A96E + 자연갈

DELUXE LINE:
  자세: 낙동강 변 서서 가야금 들고 있는 모습
  의상: 여행자 차림 (천 다발 배낭)
  표정: 교체 가능 (연주/슬픔/노년 3종)
  소품: 가야금 + 죽간 다발 + 노년 버전 얼굴
  특이: 가야금 현 금속선 실제 사용

ROYAL LINE (한정판):
  자세: 노년 니문 — 강가 홀로 서서 연주
  연출: 달빛 조명 + 발아래 강물 반사
  베이스: 강물·모래사장 정밀 레진 제작
  부속: 「기억의 강」악보 미니 죽간 세트
  수량: 1,500개 한정 (전체 라인 최소 수량)
```
