# 서사 아크 구조

## 메인 아크: 삼국의 흥망성쇠

```
건국 (BC) → 성장 (1~3C) → 전성 (4~6C) → 격변 (6~7C) → 멸망/통일 (660~676)
희망         갈등          영광          비극           결말
```

## 왕국별 운명 곡선

| 왕국 | 정점 | 전환점 | 결말 |
|------|------|--------|------|
| 고구려 | 광개토대왕 (391~412) | 연개소문 사후 내분 (666) | 멸망 668 |
| 백제 | 근초고왕 (346~375) | 관산성 전투 성왕 전사 (554) | 멸망 660 |
| 신라 | 삼국통일 (676) | 나당동맹 체결 (648) | 통일 달성 |
| 가야 | 철 교역 황금기 (3~5C) | 고구려 남정 (400) | 소멸 562 |

## 10대 캐릭터 아크

1. **주몽**: 박해받는 영웅 → 건국자 → 신화 (완성형 영웅 아크)
2. **광개토대왕**: 어린 왕 → 정복자 → 제왕 (상승형)
3. **근초고왕**: 야망가 → 전성기 군주 → 동아시아 강자 (상승형)
4. **연개소문**: 혁명가 → 독재자 → 멸망의 씨앗 (하강형)
5. **계백**: 충성스러운 장군 → 불가능한 임무 → 장렬한 최후 (비극형)
6. **김춘추(무열왕)**: 외교가 → 동맹 체결자 → 삼국통일 설계자 (성장형)
7. **김유신**: 이방인 혈통 → 시련 → 통일의 검 (극복형)
8. **선덕여왕**: 편견 속 즉위 → 지혜로운 통치 → 고독한 죽음 (비극형)
9. **온달**: 바보 → 사랑으로 성장 → 전사 (성장형+비극)
10. **의자왕**: 현명한 왕 → 타락 → 멸망 (하강형)

## 관계 아크

- **나제(신라-백제)**: 동맹(5C) → 배신(553) → 적대 → 멸망
- **고신(고구려-신라)**: 협력(4C) → 경쟁 → 전면 적대
- **나당(신라-당)**: 동맹(648) → 공동 정복 → 배신 → 전쟁 → 신라 승리

## 시즌별 서사 구조

### 시즌 1: 건국의 시대 (BC 37~AD 1C)
**주제**: 혼돈 속 질서, 영웅의 탄생
**중심 사건**:
- 주몽의 고구려 건국 (BC 37)
- 온조의 백제 건국 (BC 18)
- 신라(사로국) 박혁거세 즉위 (BC 57)
- 김수로의 금관가야 건국
**드라마 엔진**: 형제 갈등(주몽-온조), 건국의 정당성 투쟁, 토착 세력과의 충돌
**시즌 피날레**: 온조와 비류의 갈라섬 — 한반도 남부 분열의 기원

### 시즌 2: 성장의 시대 (2~4C)
**주제**: 국가의 틀을 세우다
**중심 사건**:
- 고구려 남하 및 낙랑 축출 (313)
- 백제 근초고왕 전성기 (346~375)
- 신라의 내물마립간 왕권 강화
**드라마 엔진**: 3국의 외교·혼인 동맹과 배신, 중국 세력과의 줄다리기
**시즌 피날레**: 근초고왕의 고국원왕 전사 — 고구려-백제 백년 원한의 시작

### 시즌 3: 전성의 시대 (4~5C)
**주제**: 제국의 꿈, 정복의 영광과 대가
**중심 사건**:
- 광개토대왕 즉위 및 정복 전쟁 (391~412)
- 고구려의 신라 구원 → 가야 타격 (400)
- 장수왕 평양 천도 (427)
- 나제(羅濟) 동맹 체결
**드라마 엔진**: 광개토대왕의 팽창과 그 그늘, 정복지 민중의 저항
**시즌 피날레**: 장수왕의 한성 함락, 개로왕 전사 (475) — 백제의 치욕

### 시즌 4: 격변의 시대 (6C)
**주제**: 동맹의 배신, 운명의 전환점
**중심 사건**:
- 성왕 사비 천도, 백제 중흥
- 신라 진흥왕 한강 탈취 — 나제동맹 붕괴 (553~554)
- 관산성 전투 성왕 전사 (554)
- 연개소문 집권 쿠데타 (642)
**드라마 엔진**: 동맹을 배신한 신라의 고독한 생존 전략, 연개소문 독재의 명암
**시즌 피날레**: 대야성 함락, 김춘추의 딸과 사위 전사 — 나당동맹의 씨앗

### 시즌 5: 전쟁의 시대 (7C 전반)
**주제**: 수·당과의 전면전, 살수대첩과 안시성
**중심 사건**:
- 고구려-수 전쟁, 살수대첩 (612)
- 을지문덕의 전략 승리
- 당 태종의 고구려 친정, 안시성 전투 (645)
- 김춘추의 당 방문, 나당동맹 체결 (648)
**드라마 엔진**: 고구려의 절정과 내부 분열의 시작, 신라의 생존을 위한 선택
**시즌 피날레**: 나당 연합군 편성 완료 — 백제를 향한 포위망

### 시즌 6: 멸망의 시대 (655~668)
**주제**: 모든 것이 끝난다
**중심 사건**:
- 황산벌 전투, 계백 전사 (660)
- 백제 멸망, 의자왕 항복 (660)
- 백제 부흥운동 — 복신·도침 (660~663)
- 백강 해전 (663)
- 고구려 멸망 (668)
**드라마 엔진**: 계백의 비장한 최후, 의자왕의 굴욕, 연남생-연남건 형제 내전
**시즌 피날레**: 고구려 평양성 함락 — 700년 왕국의 소멸

### 시즌 7: 통일의 시대 (668~676)
**주제**: 승리인가, 상처인가
**중심 사건**:
- 나당전쟁 (670~676)
- 매소성 전투, 기벌포 해전
- 신라의 삼국 통일 완성 (676)
- 문무왕의 유언 — 호국룡 전설
**드라마 엔진**: "통일"의 의미 질문 — 신라가 얻은 것과 잃은 것
**최종화**: 동해 바다를 바라보는 문무왕의 뒷모습, 가야금 소리 페이드인

## 크로스 시즌 테마 아크

### 테마 1: 한강의 주인
- 시즌1: 백제가 한강 유역에 터를 잡다
- 시즌3: 고구려가 한강을 빼앗다 (475)
- 시즌4: 신라가 한강을 차지하다 (553)
- 시즌7: 신라가 한강을 완전히 지키다
→ "한강 = 패권" 공식 완성

### 테마 2: 동맹의 배신
- 나제동맹(5C) → 신라의 배신(553)
- 나당동맹(648) → 당의 배신 시도 → 신라의 역배신(670~676)
- "삼국 시대에 영원한 동맹은 없었다"

### 테마 3: 아버지와 아들
- 주몽-온조: 아들이 다른 나라를 세우다
- 연개소문-연남생: 아들의 반역이 나라를 망치다
- 김춘추-법민(문무왕): 아버지의 유지를 아들이 완성하다
- 의자왕-부여융: 아버지의 왕국을 아들이 당에 바치다

### 테마 4: 승자와 패자의 반전
- 백제가 멸망했지만 그 문화는 일본(야마토)에서 꽃피다
- 고구려가 멸망했지만 그 정신은 발해로 부활하다
- 신라가 통일했지만 골품제로 스스로 붕괴하다
- "역사에는 완전한 승자도 완전한 패자도 없다"

### 핵심 주제 인문학적 분석

#### 주제 1: 「기억」

```
이론적 배경:
  모리스 알박스(Maurice Halbwachs) — 집단 기억 이론
  개인 기억 ≠ 집단 기억: 공동체가 기억을 구성
  왕국의 멸망 = 집단 기억의 소멸

IP 연계:
  고구려 멸망 → 고루의 기억 = 마지막 증인
  가야 소멸 → 니문 = 유일한 기억 보존자
  「강은 기억한다」= 비인간적 기억의 영속성 (강 = 물질적 기억 매개)

아스만(Jan Assmann) 문화 기억 이론:
  소통 기억 (3세대 내): 구전·개인 기억
  문화 기억 (300년+): 텍스트·의례·기념물
  아랑 = 소통 기억 → 문화 기억으로 전환하는 행위자
  아랑의 죽간 = 문화 기억 생산

창작 적용:
  아랑이 기록하는 이유 = 집단 기억의 무의식적 수행
  니문의 음악 = 구술 문화의 기억 저장 (쓰기 없는 기억)
  고루의 침묵 = 외상 기억 (Traumatic Memory)의 언어화 거부
```

#### 주제 2: 「애도」

```
이론적 배경:
  지그문트 프로이트 (Sigmund Freud): 「애도와 우울」(1917)
  정상 애도: 상실 인정 → 리비도 분리 → 새 대상 투여
  병적 우울: 상실 인정 거부 → 자아 내면화

IP 캐릭터 분석:

니문 — 정상 애도 진행형:
  가야 멸망 = 2세대 전 상실 (직접 경험 아님)
  니문은 「가야」라는 대상에 대한 집단적 애도를 수행
  가야금 연주 = 애도 의식의 반복
  676년 마지막 연주 = 애도 완성 (상실 수용)

아랑 — 선행적 애도 (Anticipatory Grief):
  백제 멸망을 예감하면서도 기록
  「이미 잃어버린 것처럼」쓰는 행위
  낙화암 생존 = 애도자로서의 생존 의무

고루 — 억압된 애도:
  고구려 멸망 = 68년간 함께한 나라의 소멸
  침묵 = 프로이트적 억압 (Repression)
  676년 「강은 기억한다」최종 발화 = 억압 해제

창작 가이드:
  니문의 성장 = 개인 애도 → 집단 애도 → 문화적 승화
  아랑의 비극 = 예견된 상실의 고통 (선행 애도의 역설)
  고루 S3 감정 표현 증가 = 억압된 애도의 언어화
```

#### 주제 3: 「정체성」

```
이론적 배경:
  에릭슨(Erik Erikson) 자아 정체성 이론
  정체성 = 연속성·독특성·사회적 인정의 삼각 형성

4인 정체성 분석:

고루 — 국가 정체성:
  나 = 고구려 = 나라
  나라가 멸망한다는 것 = 자아 해체 위기
  을지문덕 사후 정체성 위기 → 「강은 기억한다」= 새 정체성 선언
  고구려 없는 나 = 「기억하는 자」로 재구성

아랑 — 지식인 정체성:
  알지만 막지 못하는 자의 실존적 고통
  사르트르(Sartre) 참여 지식인 개념 연결:
  「알면서 침묵하는 것 = 공모」vs 「기록으로 증언」
  아랑의 선택 = 행동 대신 기록 = 지식인의 한계와 사명

하린 — 전사 정체성:
  화랑 정체성 = 규범적 정체성 (제도가 부여한 정체성)
  나당연합 = 화랑 정체성과의 충돌
  「적과 손 잡음 = 화랑이 아닌가?」
  S3: 화랑 정체성 → 국가 수호자 정체성으로 확장

니문 — 디아스포라 정체성:
  스튜어트 홀(Stuart Hall) 문화적 정체성 이론:
  정체성 = 고정된 것이 아닌 계속 생산되는 것
  「가야인 니문」vs「신라인 니문」→ 이분법 거부
  니문의 해답 = 「나는 강의 사람이다」(강 = 가야와 신라를 잇는 메타포)
```

#### 주제 4: 「전쟁의 윤리」

```
이론적 배경:
  마이클 왈저(Michael Walzer) 「정전론」(Just War Theory)
  정전 조건: 정당한 원인·비례성·최후 수단·선전 포고

IP 적용:

살수대첩 — 정당 방어전:
  수나라 침략에 대한 방어 → 정전론 기준 충족
  을지문덕의 전략 = 「최소 인명 피해로 최대 효과」비례성 준수
  고루의 내면 = 「이 전쟁은 옳은가?」→ 답: 옳다 (방어)

나당연합 — 도덕적 딜레마:
  하린: 당나라를 끌어들여 삼국 통일
  왈저: 「불의한 수단으로 정의로운 목적」→ 도덕적 오염
  하린의 갈등 = 현대적 군사 윤리 질문의 역사적 투영

황산벌 계백 — 영웅 윤리:
  계백의 가족 살해 = 극단적 결단
  칸트 의무론: 의무에 따른 행동 (죽음의 의무)
  결과주의: 5,000명의 희생이 역사에 미친 영향
  극에서 계백 = 영웅이자 비극적 존재 (양면 표현)

창작 가이드:
  전쟁 장면 = 스펙터클만이 아닌 윤리적 질문을 포함
  캐릭터들이 전쟁의 정당성을 스스로 묻는 장면 필요
  답을 강요하지 않는다 — 독자가 판단
```

```
삼국(三國) 핵심 주제:
「사라지는 것들과 기억하는 것들에 대한 이야기」

부제: 나라는 사라진다. 강은 남는다.

주제 3층:
① 표면 주제: 삼국시대 전쟁과 영웅들의 이야기
② 중간 주제: 개인이 역사 앞에서 무엇을 할 수 있는가
③ 심층 주제: 기억과 정체성 — 사라진 것들이 어떻게 살아남는가

서사 모티프:
강 (江): 기억과 시간의 흐름
기록 (記錄): 존재의 증명
노래 (歌): 언어 없는 기억 — 음악은 민족의 영혼
칼 (劍): 선택의 무게 — 무엇을 위해 싸우는가
```
