# PvP 시스템 설계 — 삼국(三國) IP

**참조 문서**: `game-design-document.md`, `weapons-technology.md`, `character-profiles/main-characters.md`
**작성**: 게임본부 시스템팀 (GAME-SYS)
**적용**: 삼국(三國) 전략 RPG PvP 모드 전체 설계 기준

---

## PvP 시스템 개요

```
삼국(三國) PvP 컨셉:
「역사적 전쟁을 플레이어 대 플레이어로 재현」

PvP 3원칙:
1. 왕국 정체성 유지 (Kingdom Identity)
   PvP에서도 4왕국 특성 차별화 — 플레이 스타일 다양화

2. 역사 기반 균형 (Historical Balance)
   역사적 강약 관계 반영 (가야=방어, 고구려=기병, 백제=해군)
   단, 게임 균형을 위한 조정 허용

3. 전략 > 과금 (Skill-Based, Not Pay-to-Win)
   과금 유닛이 전략 판단을 압도하지 않도록
   LEGENDARY 유닛 PvP 제한 존 별도 운영
```

## PvP 모드 종류

### 1. 영토 전쟁 (Territory War)

```
모드명: 삼국지도(三國地圖)
인원: 4왕국 각 플레이어 커뮤니티 대항
주기: 실시간 상시 운영 (공방 시간대 별도)
맵: 한반도 + 요동 전략 맵

규칙:
- 각 왕국 소속 플레이어가 협력하여 영토 확장
- 영토 = 자원 생산 + 점수
- 주 1회 결산 (가장 많은 영토 왕국 보너스)

전략 요소:
동맹: 2왕국 일시 동맹 가능 (역사적 나당 연합 재현)
배신: 동맹 파기 시 외교 페널티 (다음 왕국과 동맹 불가 2주)
제3국 견제: 1강이 독주 시 나머지 3왕국 공동 대응 유도 설계

역사 이벤트 트리거:
특정 전략 맵 조건 달성 시 역사 이벤트 발생
예: 고구려가 요동 전체 점령 → 「광개토대왕의 진군」이벤트
    신라가 한강 유역 점령 → 「삼국통일의 서막」이벤트
```

### 2. 결전 PvP (Ranked Battle)

```
모드명: 결전(決戰)
인원: 1v1, 2v2
형식: 6×6 육각형 타일 맵
목표: 상대 수도 함락 또는 총사령관 유닛 처치

시즌 구조:
시즌 기간: 3개월
티어: 나그네 → 병사 → 장군 → 대장군 → 대막리지
보상: 시즌 종료 시 티어별 한정 스킨·유닛

맵 종류 (역사 기반):
살수 맵: 강 지형 많음 → 고구려 유리
황산벌 맵: 평야 지형 → 대규모 기병전
안시성 맵: 공성 맵 → 방어자 유리
백강 맵: 해전 맵 → 백제 해군 특성 발휘

밸런스 패치 주기:
매 시즌 초 대규모 패치
중간 핫픽스: 2주마다 소규모 조정
```

### 3. 길드 전쟁 (Guild War — 연합전)

```
모드명: 연합(聯合)
인원: 길드 (최대 30명) vs 길드
주기: 주 2회 (화·금)
형식: 다중 거점 동시 공방

규칙:
- 5개 거점 중 3개 이상 점령 시 승리
- 각 거점 다른 전략 맵 적용
- 길드 내 왕국 혼합 허용 (역사적 연합 재현)

역사 연합 보너스:
나당 연합 (신라+고구려 or 신라+당 NPC): 외교 수치 +20%
백제-왜 연합 (백제+특정 캐릭터): 해전 공격 +15%
```

### 4. 실시간 공성전 (Siege Assault)

```
모드명: 안시성(安市城) — 역사 재현 모드
형식: 공격(5명) vs 방어(5명)
맵: 안시성 고정 맵

역사 기반 비대칭 전투:
공격팀: 병력 수 우위, 공성 무기 보유
방어팀: 요새화된 성벽, 토산 반격 스킬

역사 이벤트:
토산 건설/파괴: 타이머 기반 이벤트
야습 발동: 방어팀 특수 행동 (야간 공격)
성문 격파: 공격팀 최후 목표

전적 기록:
안시성 방어 성공/실패 기록 — 「역사 속 고루」패 비교
```

## 왕국별 PvP 특성

### 고구려 (공격·기동 특화)

```
PvP 강점:
기병 유닛: 이동력 최고, 배후 공격 가능
강 지형: 공격력 +25% (살수 보너스 반영)
야습: 야간 전투 공격 +20%

PvP 약점:
장기 농성: 자원 소모 빠름
평야 방어: 기병은 성 방어 불리
해전: 해전 맵 불리

LEGENDARY 유닛 (PvP 제한 존):
광개토대왕: 이동력 +2 전체, 압도적 스탯
을지문덕: 적 배치 전 턴 정보 공개 (지략 스킬)

PvP 플레이 스타일:
빠른 기동으로 배후 차단 → 포위 섬멸
살수 강 지형 유도 → 공격력 극대화
```

### 백제 (외교·해전 특화)

```
PvP 강점:
해전 맵: 공격·방어 모두 +20%
외교 유닛: 상대 유닛 1기 일시 중립화 (협상 스킬)
비밀 정보: 상대 덱 구성 일부 공개 (아랑 계열 유닛)

PvP 약점:
육전 평야: 기병 부족
북방 지형: 고구려 대비 불리

LEGENDARY 유닛:
무령왕: 외교 수치 최고, 유일한 외교 승리 조건 가능
계백: 절멸 직전 공격력 3배 (황산벌 최후 방진)

PvP 플레이 스타일:
외교 동맹 활용 → 수적 열세 극복
해전 맵 유도 → 백제 해군 특성 발휘
```

### 신라 (기동·크리티컬 특화)

```
PvP 강점:
화랑 유닛: 크리티컬 확률 +25%
연속 행동: 킬 시 추가 행동 1회 (화랑 속전속결)
야간 전투: 화랑 야습 보너스

PvP 약점:
중장기병: 고구려보다 방어력 낮음
공성전: 공성 무기 부족

LEGENDARY 유닛:
김유신: 전체 아군 연속 공격 활성화
선덕여왕: 예언 스킬 — 상대 다음 행동 1회 미리 공개

PvP 플레이 스타일:
크리티컬 연쇄 콤보 → 순식간 섬멸
김유신 배치 → 전체 아군 연속 행동 폭발
```

### 가야 (방어·자원 특화)

```
PvP 강점:
철판갑 유닛: 방어력 전 왕국 최고
철정 버프: 아군 전체 무기 강화 +1단계
견고한 방어선: 성 방어 최고 효율

PvP 약점:
공격력: 전 왕국 중 최하
기동성: 이동력 낮음
장기전 자원: 자원 생산 높지만 소모도 빠름

LEGENDARY 유닛:
수로왕: 가야 철 생산 2배 + 아군 전체 방어 +3
우륵: 음악 스킬 — 상대 1유닛 행동 불능 1턴 (가야금 소리)

PvP 플레이 스타일:
방어선 구축 → 자원 우위 → 장기전 승리
우륵 행동 불능 + 철벽 방어 = 저비용 버티기
```

## PvP 밸런스 시스템

### 왕국 상성

```
1:1 상성표:
고구려 >> 신라 (기병 vs 화랑 경무장)
신라 >> 가야 (크리티컬 vs 방어 특화)
가야 >> 백제 (철벽 방어 vs 외교·해전)
백제 >> 고구려 (외교·해전 vs 기동 특화)

삼각 밸런스:
(가위바위보 구조로 단일 최강 왕국 방지)
고구려 ← 백제 ← 가야 ← 신라 ← 고구려

2v2 상성:
나당 연합형 (신라+고구려): 기동+크리티컬 콤보
백제-가야 연합: 방어+외교 장기전
```

### Anti-P2W 설계

```
과금 유닛 PvP 제한:
LEGENDARY 유닛 (5성): 일반 결전 PvP 참여 불가
별도 「LEGENDARY 리그」운영 (과금 유저 전용)

랭크 매칭:
동 티어 ±1단계 내 매칭
덱 전력 점수 기준 보조 매칭

전략 > 덱 강화:
최고 스탯 덱 vs 전략적 카운터 덱 = 전략 우세 설계
5성 덱도 2성 카운터 전략에 패배 가능한 밸런스 목표
```

## PvP 보상 시스템

```
일일 PvP 보상:
- 결전 3전 완료: 일반 소환권 1장
- 영토전 기여도: 왕국 특산 자원

시즌 보상:
나그네 티어: 기본 스킨 1개
병사 티어: 프레임 + 타이틀
장군 티어: 한정 유닛 스킨 1개
대장군 티어: 3D 전용 스킨 + 이름 명예 등재
대막리지 티어 (상위 1%): LEGENDARY 애니메이션 스킨

길드 전쟁 보상:
우승 길드: 길드 전원 한정 문장(紋章) + 자원 보상
준우승: 자원 보상 + 기본 타이틀

역사 이벤트 보상:
안시성 방어 성공 100회: 「안시성의 수호자」칭호
살수 강 지형 50회 승리: 「살수의 후예」칭호
```

## e스포츠 연동 계획

```
삼국(三國) PvP 챔피언십:
시즌 1 종료 후 상위 32명 토너먼트
중계: 트위치·유튜브 라이브
해설: 삼국 역사 전문가 + 게임 해설자 협업

왕국 챔피언십:
왕국별 상위 플레이어 8명 팀 구성
「삼국 왕국 대항전」연 1회
우승 왕국 = 해당 시즌 IP 이벤트 우선 혜택

글로벌 확장:
한국 → 일본 → 동남아 → 북미 순 e스포츠 확장
지역 예선 → 글로벌 결선 구조
```

## PvP UI/UX 기준

```
전투 UI:
왕국별 UI 색채 (고구려=암청, 백제=왕실금, 신라=황금, 가야=토황)
타이머: 모래시계 형태 (고증 감성)
행동 확인: 안시성 북소리 SFX

전적 화면:
「강은 기억한다」슬로건 + 전적 통계
역사 어록 랜덤 표시 (매 전투 후)
주요 플레이 하이라이트 자동 클립 (15초)

관전 모드:
실시간 관전 가능 (상위 1% 전투)
관전자 투표 기능 (어느 쪽이 이길지)
관전 이벤트 보상 (매주 관전 미션)
```
