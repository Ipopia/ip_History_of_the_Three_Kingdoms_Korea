## 모바일 게임 전략 개요

```
게임 타이틀: 삼국(三國): 강은 기억한다
영문 타이틀: THREE KINGDOMS: THE RIVER REMEMBERS
플랫폼: iOS / Android
장르: 역사 전략 RPG (수집형 + 전략 배틀)
타깃: 드라마 팬 + 역사 게임 유저
등급: 12세 이상

포지셔닝:
  「역사 고증 + 스토리 깊이」차별화
  기존 수집형 RPG와 차별: 역사 스토리 = 핵심 콘텐츠
  IP 팬 유입 → 게임 신규 유저로 전환 목표
```

## 게임 컨셉

### 핵심 루프

```
메인 루프:
  스토리 퀘스트 클리어
  → 캐릭터(영웅) 획득·강화
  → 전투력 상승
  → 다음 챕터 진행

서브 루프:
  역사 이벤트 참여 (시즌별)
  → 한정 캐릭터·아이템 획득
  → 길드(왕국) 활동
  → 리더보드 경쟁

소셜 루프:
  왕국 길드 가입 (고구려/백제/신라/가야)
  → 왕국 전쟁 (PVP)
  → 왕국 통합 포인트 → 역사 이벤트 결과 영향
```

## 캐릭터 시스템

### 영웅 등급

```
등급 체계:
  ★★★★★ (5성): 전설 — 역사 주요 인물·4주인공
  ★★★★ (4성): 영웅 — 역사 조연·창작 무장
  ★★★ (3성): 무관 — 일반 역사 인물·창작 병사장
  ★★ (2성): 병사 — 소모형 유닛 (강화 재료)
  ★ (1성): 졸병 — 강화 재료

5성 캐릭터 목록 (출시 시):
  고루 「살수의 전략가」(고구려/전사)
  아랑 「사비성의 기록자」(백제/지원)
  하린 「화랑의 기세」(신라/돌격)
  니문 「가야금의 악사」(가야/버퍼)
  을지문덕 「살수의 영웅」(고구려/전설)
  계백 「황산벌의 결사」(백제/전설)
  선덕여왕 「예언의 여왕」(신라/지원)

캐릭터 획득 방법:
  스토리 진행: 3성 이하 기본 획득
  가챠(소환): 4~5성 확률 획득
  이벤트: 한정 4~5성 직접 획득
  상점: 조각 교환 → 완성
```

### 캐릭터 강화 시스템

```
레벨업:
  최대 레벨: 100
  경험치: 퀘스트·전투 보상

돌파 (각성):
  같은 캐릭터 중복 획득 → 성장치 영구 상승
  5성 기준: 6회 돌파 가능 → 최종 「전설 각성」

스킬 업그레이드:
  스킬 레벨: 1~10
  재료: 왕국별 고유 스킬 북

장비 시스템:
  무기·갑옷·장신구 3슬롯
  왕국 세트 효과: 같은 왕국 장비 3종 → 세트 보너스
  역사 유물 아이템: 금동대향로·환두대도 등 고증 아이템
```

```
  Chapter 17~24: 나당연합 형성

시즌 3 스토리 (업데이트):
  Chapter 33~40: 백제·고구려 멸망

스토리 연출:
```

### 사이드 퀘스트

```

  백제 별전: 아랑이 기록한 백제 문화
  신라 별전: 화랑도 훈련 일지
  가야 별전: 우륵과 가야금 12곡

역사 에피소드 (Historical Episodes):
  실제 역사 사건 기반 단편 스토리
  예) 「광개토대왕의 정복」「안시성의 영웅」
  → ADV-HISTORY 전면 감수
  → 교육적 설명 포함 (역사 메모 아이템)
```

## 전투 시스템 (모바일 최적화)

```
배틀 형식:
  자동 전투 기본 + 스킬 수동 발동
  3열 × 3열 = 9슬롯 편성
  왕국 편성 보너스: 같은 왕국 3인 → 왕국 시너지

터치 조작:
  스킬 탭: 화면 하단 스킬 버튼 터치
  타겟 변경: 적 캐릭터 직접 터치
  속도 조절: ×1 / ×2 / ×3 배속

전투 특화 모드:
  자동 완료: 이미 클리어한 챕터 즉시 완료 (스태미나 소모)
  도전 모드: 수동 조작만 허용 (고난이도 전용)

살수대첩 특별 전투 (Ch.13~15):
  3연속 전투 (수나라 3개 군단)
  체력 이월 (전투 간 회복 없음)
  클리어 시: 살수대첩 전용 5성 아이템 획득
```

### 주인공 4인 스킬 상세

```
고루 (★★★★★ — 고구려): 야습 기술 보유

  - 스킬2: 「기마 역습」— 아군 기병 공격력 30% 버프
  - 패시브: 「안시성 수비대」— 성 방어 시 방어력 +50%

아랑 (★★★★★ — 백제): 외교·정보 특화
  - 스킬1: 「6개국의 기록」— 적 버프 해제 + 아군 버프
  - 스킬2: 「사비성의 등불」— 아군 전체 체력 회복

  - 스킬2: 「황산벌의 결의」— 전열 적 단일 대타격
  - 패시브: 「임전무퇴」— 체력 30% 이하 시 공격력 +80%

니문 (★★★★★ — 가야): 지원·음악 특화
  - 스킬1: 「12번째 악곡」— 아군 전체 스킬 쿨타임 즉시 리셋

```
