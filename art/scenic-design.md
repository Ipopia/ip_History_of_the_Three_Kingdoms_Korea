## 환경 디자인 철학

```
핵심 원칙:
  「풍경이 왕국의 성격을 말한다」

3대 기준:
  ① 역사 고증 기반 — 유적·유물 참조 건축 재현
  ② 왕국 색채 일관 — color-palette.md 환경광 적용
  ③ 감정 증폭 — 환경이 캐릭터 내면 상태 반영

참조:
  고구려: 안악3호분 벽화·장군총·안시성지
  백제: 무령왕릉·금동대향로·사비 도성지
  신라: 황룡사지·첨성대·경주 왕경
  가야: 대성동 고분군·김해 봉황동 유적
```

## 왕국별 건축 디자인

### 고구려 건축

```
건축 양식:
  기초: 대형 석조 기단 (화강암)
  벽체: 석조 하부 + 목조 상부 혼합
  지붕: 기와 (암막새·수막새 문양 복원)
  장식: 삼족오 문양·연꽃 문양·용 문양
  특징: 규모가 크고 군사적·위압적

주요 건축물 설계:
  평양성 왕궁:
    규모: 대형 석조 궁전 + 목조 정전
    기단: 3단 석조 기단 (화강암 대형 블록)
    정전: 기둥 20개 이상 대형 전각
    색상: 청람 기와 + 회색 석조 + 붉은 주칠 기둥
    장식: 삼족오 금동 장식 (용마루)

  안시성:
    규모: 높이 6~8m 석조 성벽 + 방어 시설
    성벽: 화강암 블록 적층 (고구려 축성법)
    성문: 대형 목조 성문 + 철제 보강
    망루: 4면 감시 망루 (봉화 설비)
    내부: 병사 숙소·무기고·식량 창고·우물

  봉화대:
    구조: 석조 원형 기단 + 상부 화구
    높이: 5~6m
    위치: 산 정상 연결 (시각 통신망)

고구려 환경 앰비언스:
  시간대: 새벽·아침 선호 (안개·강물)
  날씨: 흐림·눈·바람 다수 (북방 기후)
  자연: 요동 평원·대동강·압록강·산악 지형
  계절: 겨울 설경 장면 중요 (고구려 = 추위의 나라)
```

### 백제 건축

```
건축 양식:
  기초: 목조 중심 (석조 기단 위)
  벽체: 목조 격자 + 흙벽 + 회칠
  지붕: 정교한 기와 (연꽃·봉황 막새)
  장식: 봉황·연꽃·인동문 세밀 장식
  특징: 정교하고 우아 — 일본 건축에 영향

주요 건축물 설계:
  사비성 왕궁:
    규모: 중규모 목조 궁전 (정교함 중시)
    기단: 2단 석조 기단
    정전: 섬세한 단청 + 금동 장식
    색상: 황금빛 단청 + 크림색 벽 + 연등 조명
    특이: 궁전 내 연못 + 정원 (조경 문화)

  사비성 문서관 (아랑 작업실):
    규모: 중형 목조 건물
    내부: 죽간 보관 선반·서안(書案)·붓·벼루
    조명: 연등 + 촛불 (따뜻한 야경)
    색상: 크림색 벽 + 황금빛 연등 반사광
    소품: 죽간 수백 개·먹·붓·벼루·인장

  낙화암:
    자연 지형: 백마강 절벽 (높이 30m 추정)
    식생: 절벽 위 소나무·풀
    분위기: 비극적 장면 전용 — 석양·역광 강조

백제 환경 앰비언스:
  시간대: 황혼·밤 선호 (연등 야경)
  날씨: 맑음·봄비 다수
  자연: 금강·백마강·서해안·평야
  계절: 봄·가을 장면 중심 (꽃·단풍)
```

### 신라 건축

```
건축 양식:
  기초: 대규모 석조 기단
  벽체: 석조 + 목조 혼합 (불교 사찰 영향)
  지붕: 웅장한 기와지붕
  장식: 금관 문양·불교 문양·화랑 상징
  특징: 웅장하고 화려 — 황금빛 강조

주요 건축물 설계:
  황룡사(皇龍寺):
    규모: 동아시아 최대급 사찰 (9층 목탑 80m)
    목탑: 9층 (각 층 처마·난간·금동 장식)
    금당: 대형 불상 안치
    색상: 금빛 단청 + 황금색 장식
    주변: 넓은 광장 + 석등 + 보리수

  첨성대:
    구조: 원형 석조탑 (높이 9.17m)
    재현: 실물 크기 + 내부 구조 상상 복원
    분위기: 밤하늘 별자리와 함께 묘사
    색상: 회색 석조 + 밤하늘 남색 + 별빛

  화랑 훈련장:
    구조: 야외 광장 + 사방 목조 관람석
    지면: 황토 + 모래
    시설: 과녁·말뚝·무기 거치대
    분위기: 밝고 역동적 (골든아워 역광)

신라 환경 앰비언스:
  시간대: 낮·골든아워 선호 (황금빛)
  날씨: 맑음 다수 (경주 분지 온난)
  자연: 경주 분지·토함산·동해 해안
  계절: 여름·가을 (황금빛 들판)
```

### 가야 건축

```
건축 양식:
  기초: 토축(土築) 성벽 + 목조
  벽체: 목조 + 흙벽 (소박함)
  지붕: 초가 + 기와 혼합
  장식: 철기 장식·가야금 문양
  특징: 소박하고 자연 친화적

주요 건축물 설계:
  금관가야 왕궁:
    규모: 소규모 목조 궁전
    기단: 1단 토축 기단
    색상: 황토색 벽 + 갈색 목조
    정원: 낙동강변 대나무 숲
    분위기: 소박하지만 품격 있는

  가야 대장간:
    구조: 열린 구조 목조 (통풍)
    시설: 단야로(鍛冶爐)·풀무·모루·수조
    소품: 철정(鐵鋌)·도검·갑옷 반제품
    분위기: 붉은 화염 + 철 냄새 (시각 표현)

  가야 고분군:
    구조: 구릉 위 원형 봉토분
    분위기: 서정적 — 황혼·안개·풀밭
    니문 씬: 고분 위 앉아 가야금 연주

가야 환경 앰비언스:
  시간대: 황혼·새벽 선호 (서정적)
  날씨: 안개·미세한 비 다수
  자연: 낙동강·대나무 숲·구릉·남해안
  계절: 가을·초겨울 (소멸 분위기)
```

## 전장 환경

```
살수 전장:
  지형: 강 상류 협곡 + 하류 평야
  수문: 대형 목조·석조 수문 시설 (창작 복원)
  강물: 맑은 물 → 탁류 → 핏빛 (전투 진행에 따라)
  주변: 강변 갈대 + 상류 소나무

황산벌 전장:
  지형: 넓은 평야 (시야 확보)
  토질: 황토 + 마른 풀
  분위기: 뜨거운 여름 햇살 + 먼지
  특수: 5,000 결사대 행진 먼지 구름

기벌포 전장:
  지형: 서해 해안 + 바다
  해안: 갯벌 + 암초 + 해안 절벽
  바다: 파도 + 안개 + 전함
  분위기: 안개 속 긴장 + 해전 혼란
```

## 자연 환경

```
강:
  대동강 — 폭 넓고 안정적, 안개 잦음
  금강 — 완만한 유속, 야경 반사
  낙동강 — 넓고 느린 유속, 황혼 반사
  살수(청천강) — 협곡 급류

산:
  요동 산맥 — 거대한 능선, 안개
  토함산 — 불국사·석굴암 연계
  계룡산 — 백제 풍수 상징

계절 표현:
  봄: 벚꽃·매화 (백제·신라 장면)
  여름: 녹음·폭우 (전투 시즌)
  가을: 단풍·억새 (감정 절정)
  겨울: 설경·얼음 (고구려 장면)
```
