# 파일럿 연출 노트 — 삼국(三國) 시즌1

## 연출 비전

> "카메라는 역사가다. 우리가 찍는 모든 프레임이 삼국시대를 증언한다."

### 레퍼런스 방향성

| 참조 작품 | 활용 요소 | 주의사항 |
|---------|---------|---------|
| 왕좌의 게임 S1 | 정치 드라마 밀도, 다중 시점 | 폭력·선정 과잉 금지 |
| 쇼군(SHOGUN 2024) | 문화적 자존심, 역사 고증 태도 | 직접 모방 금지 |
| 킹덤(Kingdom) | 긴장감, 한국적 감성 | 장르 혼합 방지 |
| 정도전 | 역사 인물의 입체성 | 국내 사극 한계 극복 |

**차별화**: 위 작품들의 장점을 취하되 — 철저한 삼국시대 고유 미학 구축

---

## 연출 기술 가이드

### 카메라 운용 원칙

**왕·귀족 장면**
```
- 움직임: 느리고 안정적인 카메라
- 앵글: 살짝 낮은 앙각 — 권위 강조
- 초점: 심도 얕음 — 배경 아웃포커스로 권력자 고립감
- 이동: 달리·크레인 — 웅장함
```

**전투 장면**
```
- 움직임: 핸드헬드 — 혼돈과 현장감
- 앵글: 눈높이 — 병사 POV
- 초점: 깊은 심도 — 배경까지 선명, 전장 전체 표현
- 이동: 스테디캠 추적 + 드론 교차
```

**민중·일상 장면**
```
- 움직임: 조용한 핸드헬드 — 관찰자 느낌
- 앵글: 눈높이 기본
- 초점: 자연스러운 심도
- 이동: 슬로우 패닝 — 일상의 흐름
```

**감정 절정 장면**
```
- 움직임: 완전 정지 — 고정 프레임
- 앵글: 캐릭터에 따라 — 굴욕은 낮게, 각오는 높게
- 초점: 극도로 얕은 심도 — 얼굴만
- 지속: 최소 10초 — 침묵 유지
```

### 촬영 계획

#### 주요 촬영지 가이드

**세트 촬영 (스튜디오)**
- 왕궁 내부: 안학궁·사비 왕궁·서라벌 궁궐 실내 세트
- 규모: 회당 2~3개 주요 실내 세트 로테이션
- 요건: 역사 고증 건축 + 세트 재활용 가능 구조

**로케이션 촬영 (야외)**
| 장소 | 목적 | 시즌 |
|------|------|------|
| 경주 남산·불국사 주변 | 신라 야외 장면 | S4·S7 |
| 충남 부여 부소산성 | 사비성 외곽 | S4·S6 |
| 평양성 유적 (대안) | CG 보완 | S1~S3 |
| 강원 산악지대 | 고구려 산악 | S1~S3 |
| 경기 임진강 | 국경 강 장면 | S3~S5 |

**CG 보완 대상**
- 황룡사 9층탑 전체 (소실됨 — CG 필수)
- 안학궁 규모 (출토 기반 복원)
- 고구려 기병 대규모 장면 (실제 + CG 혼합)
- 살수대첩 물 이펙트

### 조명 플랜

#### 자연광 활용 원칙

**황금 시간대 (Magic Hour)**
- 주 전투 결말 장면: 황혼 30분 내 촬영
- 신라 금관 클로즈업: 황금 시간대 자연광 필수
- 낙화암 장면: 보름달+횃불 조합 (달 조명은 CG 보완)

**흐린 날 활용**
- 백제 일상 장면: 흐린 날 자연스러운 산란광
- 전략 회의: 창문 통한 비스듬한 자연광
- 장례·비극 장면: 흐린 날 우선 촬영

#### 인공 조명 설계

**왕궁 내부**
```
기본 설정:
- 주광원: 창문 방향 조명 (자연광 모방)
- 촛불: 실제 촛불 + 플리커 조명 보완
- 화덕: 오렌지 리밍 라이트 (하부)
- 그림자: 강하고 방향성 있음 — 공간의 드라마
```

**야간 야외**
```
기본 설정:
- 횃불: 실제 횃불 주 광원 + 보완 조명
- 달빛: 냉색 LED 탑조명 (45도각)
- 배경 암부: 완전 암흑 — 인물만 부각
```

## 시즌1 핵심 장면 연출 상세

### 장면 A: 주몽의 탈출 (1~2화)

**사전 감정 구축** (촬영 1일 전 배우 워크숍)
- 배우들과 '탈출의 공포'를 직접 경험하는 즉흥 훈련
- 말 다루기 실제 훈련 (최소 2주)

**촬영 순서**
```
Day 1: 강변 도착 장면 (정적인 장면 먼저)
Day 2: 물고기 다리 (CG 베이스 실사 촬영)
Day 3: 추격대 장면 (역방향 촬영)
Day 4: 강 건너편 도착 + 표정 클로즈업
```

**핵심 디렉팅 노트**
- 주몽 배우에게: "이 장면에서 당신은 두렵지 않다. 이미 뒤는 포기했다. 앞만 있다."
- 오이 배우에게: "당신은 이 기적을 믿지 않는다. 그러나 기적이 일어났다."

---

### 장면 B: 고구려 건국 (3화 엔딩)

**연출 원칙**: 웅장함보다 고독함

**촬영 구성**
```
숏 1: 와이드 — 소박한 제단 + 주몽 홀로
숏 2: 클로즈업 — 주몽 얼굴 (표정: 기쁨이 아닌 무게)
숏 3: 신하들의 절 — 주몽 POV
숏 4: 주몽이 홀로 하늘을 보는 미디엄샷
숏 5: 하늘 — 구름 사이 빛 (과잉 아닌 절제)
숏 6: 아래 백성들의 불빛 — 주몽이 내려다봄
숏 7: 익스트림 클로즈업 — 주몽의 눈에 맺힌 빛
```

**금지 연출**
- 환호성 치는 군중 — 삼국시대 건국은 조용한 것이었다
- 음악 과잉 — 침묵 구간 필수
- 화려한 불꽃·축제 — 역사 기록에 없음

---

### 장면 C: 소서노와 주몽의 마지막 (14화)

**연출 원칙**: 배우에게 최대한의 자유

**촬영 환경**
- 황혼 시간대 로케이션 촬영 (단 1회)
- 카메라 2대 동시 (두 배우 동시 포착)
- BGM: 촬영 중 없음 — 배우의 자연스러운 감정 유도

**디렉팅 노트**
- 주몽 배우에게: "당신은 지금 인생 최초로 사과하고 있다. 그러나 말이 나오지 않는다."
- 소서노 배우에게: "당신은 이미 결정을 했다. 슬프지만 흔들리지 않는다."
- 두 배우 모두에게: "대사보다 침묵이 더 많아도 된다."

## 촬영 전 필수 준비사항

1. **고증 워크숍**: 전 스태프 삼국시대 역사 교육 (2일)
2. **참조 자료 패키지**: 고분 벽화·출토 유물 사진집 배포
3. **배우 역사 캐릭터 연구**: 캐릭터별 역사 기록 심층 연구
4. **말 훈련**: 기마 장면 배우 전원 최소 4주 승마 훈련
5. **무술 훈련**: 삼국시대 실전 무술 기반 안무 (6주)
6. **의상 착용 훈련**: 갑옷·관복 실제 착용 움직임 적응 (2주)
