## 게임 세계 지도 개요

```
배경 시대: AD 600년 ~ 676년 (주 무대)
지도 범위: 한반도 전역 + 만주 남부 + 왜 해안 일부

지도 구성:
  레이어 1 — 정치 지도: 왕국 영토, 수도, 주요 거점
  레이어 2 — 지형 지도: 산맥, 강, 해안, 평야
  레이어 3 — 전략 지도: 전선, 교역로, 주요 요새
  레이어 4 — 문화 지도: 각 지역 특성, 지역 이벤트

지도 스케일:
  전략 맵: 한반도 전체 (거시적 전략)
  지역 맵: 왕국별 주요 지역 (중거리 탐색)
  전술 맵: 전투·탐험 구역 (미시적 전투)
```

## 왕국별 영토 설계

### 고구려 영토

```
수도: 평양성 (平壤城)
  위치: 대동강 유역
  규모: 게임 내 최대 도시
  특성: 방어 요새 + 군사 훈련 중심
  주요 건축: 대성산성, 안학궁

핵심 지역 (5개 구역):
  1. 요동 평원 — 제철·군사 생산 중심
  2. 압록강 유역 — 국경 요새 방어선
  3. 대동강 중류 — 농업 중심지
  4. 살수(薩水/청천강) — 살수대첩 이벤트 지역
  5. 안시성 지역 — 당나라 침공 방어 최전선

지형 특성:
  산악 비율: 70% (방어 유리)
  강 수: 압록강·대동강·살수 등 주요 3개
  요새 수: 15개+ (게임 내 최다)

왕국 보너스:
  산악 지형 이동 패널티 없음
  요새 방어력 +30%
  겨울 전투 패널티 없음
```

### 백제 영토

```
수도: 사비성 (泗沘城 / 부여)
  위치: 금강 하류 유역
  규모: 문화·교역 중심 도시
  특성: 항구 + 문화 허브
  주요 건축: 미래사 목탑, 금동대향로 안치소

핵심 지역 (5개 구역):
  1. 사비 도성 — 행정·문화 중심
  2. 금강 유역 — 농업 생산 최고
  3. 황해 해안 — 대중국 교역로
  4. 황산벌 — 결전의 지역 (S3 이벤트)
  5. 웅진(공주) — 구도성, 긴급 피신 거점

지형 특성:
  평야 비율: 60% (농업 생산 유리)
  해안선: 황해 접안 (교역 유리)
  강 수: 금강·한강 하류

왕국 보너스:
  교역 수입 +25%
  선박 건조 속도 +20%
  외교 협상 성공률 +15%
```

### 신라 영토

```
수도: 금성 (金城 / 경주)
  위치: 경상도 분지
  규모: 왕권 강화된 정치 중심
  특성: 불교 문화 + 화랑 훈련소
  주요 건축: 황룡사, 첨성대, 월성

핵심 지역 (5개 구역):
  1. 경주 분지 — 정치·종교 중심
  2. 한강 유역 — 전략적 요충지 (백제에서 탈취)
  3. 낙동강 동쪽 — 농업·철기 생산
  4. 황산벌 접근로 — S3 결전 루트
  5. 기벌포(서해 입구) — 676년 최종 결전 지역

지형 특성:
  분지형 지형 (방어·농업 균형)
  동해 접안: 왜 방어선
  서해 접근: 나당연합 보급로

왕국 보너스:
  화랑 영웅 유닛 능력치 +20%
  불교 사원 인구 행복도 +20%
  동맹 유지 기간 +30%
```

### 가야 영토 (멸망 전 역사 재현)

```
마지막 거점: 대가야 (고령)
  상태: 562년 멸망 — 게임에서 플래시백/역사 이벤트로 등장
  주요 지역: 낙동강 유역 가야 연맹 권역

가야 관련 특별 지역:
  낙동강 유역 — 가야금 소리 이벤트 (니문 주요 무대)
  고령 대가야 유적 — 탐험 가능 고분 지역
  금관가야(김해) — 철정 교역 역사 유적

게임 내 구현:
  일반 영토가 아닌 특별 역사 구역으로 설정
  니문 캐릭터 전용 퀘스트 지역
  가야 멸망 타임라인 재현 미니 캠페인
```

## 전략 지도 — 주요 거점

### 군사 요새 (Fortresses)

```
고구려 요새:
  ★★★ 안시성 — 645년 당 태종 막은 전설의 요새
  ★★★ 평양성 — 수도 방어 최종 요새
  ★★  국내성 구도성 지구 — 후방 요충
  ★    요동성 — 전선 최전방

백제 요새:
  ★★★ 사비성 — 금강 방어선 핵심
  ★★  웅진성 — 긴급 피신 거점
  ★    주류성 — 부흥운동 근거지 (660년 이후)

신라 요새:
  ★★★ 금성(경주) — 방어 불가침 수도
  ★★  당항성 — 대중국 통신 직결 요새
  ★    황산벌 방어선 — S3 이벤트
```

### 교역 거점 (Trade Nodes)

```
황해 교역로:
  백제 사비 항 ↔ 중국 산동 ↔ 왜 규슈
  교역품: 도기·비단·금속 ↔ 비단·향료 ↔ 금·쌀

낙동강 교역로:
  가야·신라 ↔ 왜 규슈
  교역품: 철정·도기 ↔ 금

압록강 교역로:
  고구려 ↔ 돌궐 ↔ 중국 북방
  교역품: 철기·모피 ↔ 말

게임 교역 시스템:
  교역 거점 장악 → 자동 수입 획득
  교역로 차단 가능 (해전 승리 시)
  계절별 교역량 변동 (겨울 -30%)
```

## 지형 시스템

### 지형 유형 & 전투 효과

```
산악 (Mountain):
  이동 비용: 2배
  방어 보너스: +40%
  고구려 패널티 없음
  기마 유닛 사용 불가

숲 (Forest):
  이동 비용: 1.5배
  매복 확률: +50%
  정찰 범위: -30%

평야 (Plain):
  이동 비용: 1배 (기본)
  기마 보너스: +25%
  백제 생산 보너스 적용

강 (River):
  도하 시 방어 불리 (-20%)
  도하 방어 시 유리 (+20%)
  살수 특별 이벤트 발동 조건

해안 (Coast):
  선박 이동 전용
  해전 모드 전환
  기벌포 특별 이벤트 지역

요새 (Fortress):
  방어 보너스: +60%
  공성 전용 유닛 필요
  보급선 차단 시 자동 함락 가능
```

### 계절 시스템

```
봄 (3~5월):
  이동 패널티 없음
  강 도하 용이
  화랑 훈련 이벤트

여름 (6~8월):
  북방 이동 최적
  살수 강 수위 상승 (살수대첩 이벤트 조건)
  전염병 위험 +10%

가을 (9~11월):
  전투 최적 시즌
  황산벌 결전 이벤트
  수확 보너스

겨울 (12~2월):
  북방 이동 패널티 (고구려 제외)
  보급 소모 2배
  당나라 원정 중단 이벤트
```

## 역사 이벤트 지역

### 살수(薩水) — 612년

```
위치: 청천강 중류
이벤트: 「살수대첩」
트리거: 고구려 캠페인 특정 조건

시나리오:
  수나라 대군 113만 → 살수 도하 시도
  고루 + 을지문덕 전략 발동
  수문 개방 → 강물 범람 → 대승

게임 메커닉:
  수문 조작 미니게임
  강물 범람 타이밍 판단
  2,700명 귀환 달성 목표

보상:
  「살수의 영웅」칭호
  고구려 왕국 사기 최대치
  특별 무기 「을지문덕의 검」해금
```

### 황산벌 — 660년

```
위치: 논산 황산벌 평야
이벤트: 「황산벌 결전」
트리거: S3 백제 캠페인 클라이맥스

시나리오:
  나당연합군 vs 백제 계백 5,000 결사대
  관창 특공 이벤트 발동
  하린과 계백의 대결

게임 메커닉:
  수적 열세 방어 전투 (백제 시점)
  관창 돌격 이벤트 선택지
  결사대 사기 유지 미니게임

보상:
  「황산벌을 기억하라」아이템
  계백 영웅 카드
  슬픔의 에필로그 언락
```

### 기벌포 — 676년

```
위치: 금강 하구 서해
이벤트: 「기벌포 해전」
트리거: S3 최종 결전 (나당전쟁 클라이맥스)

시나리오:
  신라 수군 vs 당나라 함대
  22연승 연속 해전

게임 메커닉:
  연속 해전 22라운드
  각 라운드 전술 선택
  최종 22승 달성 = 엔딩 언락

보상:
  「기벌포의 승자」최고 칭호
  676 특별 엔딩 영상
  니문 최후 가야금 씬 해금

### 게임 세계 개요

```
게임 타입: 4X 전략 + 턴 기반 전술 RPG
시대 배경: 612년 ~ 676년 (기본) / BC 57년 ~ 676년 (확장팩)

지도 범위:
  메인 맵: 한반도 + 요동 반도 + 서해 해역
  확장 맵: 중국 동부 해안 (수·당 본토) + 일본 열도 (백제 교역 루트)

지도 스타일:
  헥사곤(HEX) 타일 기반
  전략 지도 (거시) + 전술 지도 (미시) 전환
  고분벽화 스타일 일러스트 오버레이
```

### Zone 구분 (7개)

```
Zone 1 — 요동 (遼東) 지역
  주요 거점: 요동성, 안시성, 백암성, 개모성
  지형: 구릉·평야 혼합, 요하(遼河) 수계
  특수 지형: 천리장성 구간 (방어 보너스)

Zone 2 — 고구려 본토
  주요 거점: 평양성 (수도), 국내성, 환도성
  지형: 산악 위주 + 대동강 수계
  특수 지형: 고구려 산성 네트워크 (방어 특화)

Zone 3 — 한반도 중부
  주요 거점: 한성(漢城), 한강 유역
  특수 지형: 한강 도하 포인트 (병목 전략)

Zone 4 — 백제 영역
  주요 거점: 사비성 (수도), 웅진성
  특수 지형: 금강 하구 (수전 특화)

Zone 5 — 신라 영역
  주요 거점: 금성/경주 (수도), 황산벌, 기벌포
  특수 지형: 화랑 훈련 성지 (사기 보너스)

Zone 6 — 가야 영역 (초반 플레이어블)
  주요 거점: 금관가야 (김해), 대가야 (고령), 아라가야 (함안)
  특수 지형: 가야 제철소 (자원 생산 보너스)

Zone 7 — 해상 루트
  주요 거점: 서해 도서, 남해 도서
  특수 지형: 조류 타일 (이동 보너스/페널티)
```

### 주요 거점 설계

```
평양성 (고구려 수도) — 성벽 레벨 5 (최대)
  구조: 내성(왕궁) + 외성(주민) + 차성(추가 방어) + 대동강 수군 기지
  함락 조건: 3중 성벽 돌파 OR 내부 항복 이벤트 (668년)
  특수: 「안시성 정신」발동 가능 (방어 +30%)
