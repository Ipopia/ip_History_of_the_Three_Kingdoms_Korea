# 로컬라이제이션 가이드 — 삼국(三國) IP

## 로컬라이제이션 원칙

> "번역은 언어가 아니라 문화를 옮기는 것이다. 삼국의 이야기가 세계 어디서나 '우리 이야기'처럼 느껴져야 한다."

### 3대 원칙

1. **한국어 원어 존중**: 고유명사는 가능한 한 원어 발음 유지
2. **문화적 설명 충실**: 낯선 개념은 각주·자막으로 설명
3. **감정의 보편성**: 번역보다 감정 전달 우선

## 언어별 로컬라이제이션 가이드

### 영어 (English)

**주요 타깃**: 미국·영국·캐나다·호주·글로벌 영어권

**번역 방향성**
- 문어체(文語體) 기피 — 현대 영어의 자연스러운 흐름
- 역사 용어: 설명 괄호 첨가 (처음 등장 시만)
- 존댓말: 영어에 없으므로 문맥으로 권위 표현

**대사 번역 예시**

```
원문: "나는 하백의 외손이다. 길을 열어라."
직역: "I am the grandson of Habaek. Open the way."
로컬라이즈: "I am the grandson of the River God. Make way."
→ Habaek → "River God" (첫 등장 시 "Habaek, the River God" 전체 표기)

원문: "전하, 살수의 물길을 열었습니다."
로컬라이즈: "Your Majesty, we've opened the floodgates at Salsu."
```

**자막 가이드라인**
- 최대 42자/줄 (영어)
- 화면 표시: 2줄 이하
- 문화 용어 첫 등장 시: 하단 작은 글씨 설명 (3초)

### 일본어 (日本語)

**주요 타깃**: 일본 본토 + 재일 한국문화 팬

**번역 방향성**
- 역사 드라마 선호 국가 — 일본 사극 톤 참조
- 경어 체계: 한국어 존댓말을 일본어 경어(敬語)로 자연스럽게
- 고유명사: 한국어 발음 가나 표기 (한자 병기)

**표기 기준**

| 한국어 | 일본어 표기 |
|--------|-----------|
| 주몽 | チュモン (朱蒙) |
| 고구려 | 高句麗 (コグリョ) |
| 백제 | 百済 (ペクチェ) |
| 신라 | 新羅 (シルラ) |
| 가야 | 伽耶 (カヤ) |
| 광개토대왕 | 広開土大王 (クァンゲトデワン) |
| 을지문덕 | 乙支文徳 (ウルジムンドク) |

**문화적 주의사항**
- 한일 관계 역사 장면 (왜 관련): 사실 기반 중립 서술
- 일본어 번역팀: 한국사 전공자 + 원어민 작가 협업 필수

### 중국어 (中文)

**주요 타깃**: 대만·홍콩·싱가포르 우선, 중국 본토 별도 전략

**번역 방향성**
- 번체자(繁體字): 대만·홍콩
- 간체자(簡體字): 중국 본토 (별도 심의 버전)
- 고구려 영토 관련: "고구려는 한반도 북부와 만주를 중심으로 한 한국의 고대 왕국" 명확 표기

**표기 기준**

| 한국어 | 중국어 (번체) | 중국어 (간체) |
|--------|------------|------------|
| 고구려 | 高句麗 | 高句丽 |
| 백제 | 百濟 | 百济 |
| 신라 | 新羅 | 新罗 |
| 주몽 | 朱蒙 | 朱蒙 |
| 광개토대왕 | 廣開土大王 | 广开土大王 |
| 살수대첩 | 薩水大捷 | 萨水大捷 |

**중국 본토 전략 주의사항**
- 고구려 귀속 논쟁: "한국의 역사" 명확 표기
- 당나라 장면: 당나라를 악으로만 묘사 금지 — 다면적 서술
- NRTA 심의: 별도 버전 제작 검토

### 동남아시아 (베트남·태국·인도네시아)

**번역 방향성**
- K-드라마 팬덤 기반 — 친숙한 한류 콘텐츠 톤
- 역사 용어: 현지어 + 한국어 원어 병기
- 자막 우선 (더빙은 2차)

**베트남어 (Tiếng Việt)**
```
Goguryeo → Cao Câu Ly (高句麗 한자 발음)
Baekje → Bách Tế
Silla → Tân La
자막 스타일: 노란색 → 흰색 그림자 (베트남 자막 선호)
```

## 문화적 민감 사항 체크리스트

| 항목 | 처리 방법 |
|------|---------|
| 중국 영토 표시 | 고구려 최대 영토 지도 — 학술 기준 표기 |
| 일본(왜) 묘사 | 사실 기반 — 현대 정치 연계 표현 금지 |
| 불교 의식 | 종교적 존중 — 해당 국가 불교 자문 |
| 순장 풍습 | 역사적 사실 인정 + 윤리적 맥락 제공 |
| 전쟁 폭력 | 각국 심의 기준 준수 — 편집본 별도 제작 |
| 샤머니즘 | 한국 전통 문화로 존중있게 묘사 |
