## UI 디자인 철학

삼국(三國) IP의 UI는 **"시대와 현대의 경계"**에 있다. 삼국시대 미학을 현대 사용자가 직관적으로 사용할 수 있게 번역한다. 화려하되 무겁지 않고, 역사적이되 고리타분하지 않다.

```
UI 설계 4원칙:
1. 시대적 진정성 — 고대 한국 미술 언어 사용
2. 현대적 가독성 — 현대 UX 패턴 준수
3. 왕국별 차별화 — 고구려/백제/신라/가야 각각 고유 UI
4. 감성적 일관성 — 색채·서체·아이콘이 하나의 세계관
```

## 타이포그래피

### 서체 체계

```
한국어:
- 제목/헤딩: 나눔 명조 ExtraBold (세리프 — 고전미)
- 본문: 나눔 스퀘어 (현대적 가독성)
- 고유명사/한자 강조: 나눔 명조 Bold + 왕실금 색상
- UI 버튼: 나눔 스퀘어 Bold

영문:
- 제목: Cinzel (라틴 세리프 — 시대극 느낌)
- 본문: Noto Serif KR (한영 통합 대응)
- UI: Raleway SemiBold

일본어:
- 제목: 源ノ明朝 (원노 밍쵸)
- 본문: Noto Serif JP
```

### 텍스트 크기 체계 (모바일 기준)

```
h1 — 28px / 왕국 이름, 대화면 제목
h2 — 22px / 섹션 제목
h3 — 18px / 카드 제목
body — 14px / 일반 본문
caption — 11px / 보조 설명
button — 15px / 버튼 텍스트
chat — 13px / 대화창 텍스트
```

## 아이콘 시스템

### 왕국 심볼 아이콘

```
고구려 — 삼족오(三足烏): 세 발 달린 까마귀
  크기: 24×24px (소) / 48×48px (중) / 96×96px (대)
  선 두께: 2px (소) / 3px (대)
  색상: 단색 혈홍 또는 왕실금

백제 — 봉황(鳳凰): 불사조 형태
  스타일: 유선형 — 백제 미술 곡선 차용
  색상: 왕실금 주 + 호박 음영

신라 — 금관(金冠): 신라 금관 실루엣
  스타일: 나뭇가지 3개 + 녹각 2개 상징화
  색상: 황금 + 보라 포인트

가야 — 가야금(伽倻琴): 열두 줄 현악기 실루엣
  스타일: 단순화 — 줄 7개로 표현
  색상: 철적 + 토황
```

### 공통 기능 아이콘

```
전투 — 환두대도(環頭大刀) 실루엣
외교 — 사신(使臣) 깃발
건설 — 정자(亭子) 윤곽
연구 — 죽간(竹簡) + 붓
교역 — 교역선 측면 실루엣
종교 — 연꽃(蓮花) 심볼
인물 — 갓(笠) 실루엣
지도 — 고지도 스타일 위치 핀
설정 — 동경(銅鏡) 원형 프레임
알림 — 북(鼓) 심볼
```

├─────────────────────────────────┤
│                                 │
│         [메인 맵 뷰]            │
│         (지도/전장)             │
│                                 │
│                                 │
├─────────────────────────────────┤
│ [전투] [건설] [외교] [인물] [더보기] │  ← 하단 네비

색상 적용:

## 화면별 UI 상세

### 메인 메뉴

```
배경: 해당 왕국 랜드마크 (애니메이션 배경)
고구려 — 안시성 + 북방 하늘
백제   — 사비성 + 백마강 석양
신라   — 황룡사 + 별이 가득한 밤하늘
가야   — 김해 항구 + 가야금 선율 비주얼

메뉴 버튼:
[원정 시작] — 주색 버튼 (왕국 메인 컬러)
[왕국 관리] — 보조 버튼
[캐릭터]    — 보조 버튼
[업적]      — 보조 버튼
[설정]      — 아이콘 버튼 (우상단)

로딩 화면:
- 배경: 물결 애니메이션
- 로딩바: 강물이 채워지는 형태
- 팁 텍스트: 역사 사실 한 줄 (매번 랜덤)
```

### 대화창 (스토리 모드)

```
┌─────────────────────────────────┐
│ [배경 일러스트]                 │
│                                 │
│                                 │
├─────────────────────────────────┤
│ [캐릭터 이름]    (왕국 색상 네임태그)
│ "대사 텍스트가 여기 들어갑니다.│

│                          [▶ 다음]│
└─────────────────────────────────┘

이름 태그 색상:
주몽     — 고구려 암청
소서노   — 호박색
광개토   — 혈홍 + 암청
선덕여왕 — 황금
계백     — 철회
우륵     — 가야 토황
```

### 지도 화면

```
지도 스타일: 고지도(古地圖) 감성 — 수채화 + 양피지 텍스처
왕국 영역 색상:
- 고구려 영토: 반투명 암청 오버레이
- 백제 영토: 반투명 호박 오버레이
- 신라 영토: 반투명 황금 오버레이
- 가야 영토: 반투명 토황 오버레이
- 중립/미점령: 회색 + 흰색

성(城) 마커:
- 주요 도성: 왕관 아이콘
- 일반 성: 성벽 아이콘
- 전략 요충지: 검 아이콘
- 항만: 배 아이콘

지형 표현:
- 강(江): 파란 곡선 + 이름 표기
- 산(山): 산봉우리 실루엣 반복
- 평야: 옅은 녹색
- 바다: 파란 수채화 + 파도 패턴
```

## 애니메이션 가이드

### 트랜지션 (전환 효과)

```
화면 전환:
- 기본 전환: 강물 흐름 와이프 (좌→우)
- 전투 진입: 검 그어지는 효과
- 왕국 테마 전환: 해당 왕국 색 페이드

버튼 인터랙션:
- 탭: 잔물결(ripple) 효과 — 왕국 메인 컬러
- 홀드: 봉화(烽火) 불꽃 효과
- 슬라이드: 족자(族子) 펼쳐지는 효과

카드 획득:
1. 어두운 화면에 카드 등장
2. 등급별 빛 효과 (별 등급별 다른 색)
3. 캐릭터 보이스 한 마디
4. 이름 + 왕국 로고 등장

전설 카드 (5성) 연출:
- 특별 BGM 전환
- 왕국별 상징 이펙트 (삼족오/봉황/금관/가야금)
- 3D 회전 카드 연출
```

### 전투 이펙트

```
고구려 스킬:
- 색상: 암청 + 혈홍
- 형태: 직선·예리·확산
- 사운드: 낮고 강한 타격음

백제 스킬:
- 색상: 왕실금 + 호박
- 형태: 곡선·우아·퍼짐
- 사운드: 맑고 울리는 음

신라 스킬:
- 색상: 황금 + 보라
- 형태: 빛·별·반짝임
- 사운드: 높고 신비로운 음

가야 스킬:
- 색상: 토황 + 녹청
- 형태: 현(弦) 진동·물결
- 사운드: 가야금 현 튕기는 음
```

## 반응형 디자인 기준

```
모바일 (기준):
- 해상도: 375~428px 폭
- 터치 타겟 최소: 44×44px
- 텍스트 최소: 11px

태블릿:
- 해상도: 768~1024px
- 좌측 사이드바 추가
- 지도 화면 확장

PC:
- 해상도: 1280~1920px
- 멀티 패널 레이아웃
- 마우스 호버 효과 추가
- 키보드 단축키 지원

콘솔 (TV):
- 해상도: 1920×1080 기준
- 컨트롤러 포커스 UI
- 텍스트 크기 1.3× 확대
- 원거리 가독성 최우선
```

## 접근성 가이드

```
색맹 대응:
- 적록색맹: 혈홍↔녹색 쌍 사용 금지
  → 혈홍(위험) + 비색(안전) 대신
    혈홍 + 파란색 조합 사용
- 색상만으로 정보 전달 금지
  → 아이콘 + 색상 + 텍스트 병행

폰트 크기:
- 설정에서 텍스트 크기 3단계 조절
- 최대 150% 확대 지원

대비 비율:
- 일반 텍스트: WCAG AA (4.5:1 이상)
- 대형 텍스트: WCAG AA (3:1 이상)
- 현재 심청 #1A3A5C + 흰색: 대비 12:1 ✓

진동 피드백:
- 중요 알림: 더블 진동
- 전투 히트: 짧은 진동
- 레벨업: 길고 부드러운 진동
```

## QA 체크리스트 (UI)

```
시각적 일관성:
□ 왕국별 색상이 모든 화면에서 통일
□ 서체 체계 준수 (헤딩/본문/버튼 구분)
□ 아이콘 스타일 통일 (선 두께, 라운딩)

기능적 검증:
□ 터치 타겟 44px 이상
□ 로딩 화면 3초 이내
□ 애니메이션 60fps 유지
□ 반응형 레이아웃 전 해상도 확인

접근성:
□ 색대비 WCAG AA 통과
□ 색맹 시뮬레이션 테스트
□ 텍스트 크기 조절 정상 작동

다국어:
□ 한국어 텍스트 길이 기준 레이아웃
□ 일본어 세로쓰기 대응
□ 영어 텍스트 확장 여유 (20% 여백)
```
