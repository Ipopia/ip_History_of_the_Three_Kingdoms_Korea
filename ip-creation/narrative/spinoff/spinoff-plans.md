# 스핀오프 계획

## 스핀오프 전략 개요

본편(삼국 드라마/애니) 흥행 후 IP 세계관을 확장하는 미디어 믹스 전략.
각 스핀오프는 본편을 보지 않아도 독립적으로 즐길 수 있도록 설계한다.

---

## 스핀오프 미니시리즈

### 1. 《낙화암(落花巖)》 — 백제 궁녀들의 마지막 밤

| 항목 | 내용 |
|------|------|
| 형식 | 6화 미니시리즈 (OTT) |
| 시점 | 660년 7월, 사비성 함락 당일 |
| 주인공 | 이름 없는 백제 궁녀 3인 — 각기 다른 신분·성격 |
| 핵심 질문 | "그들은 왜 뛰어내렸는가?" — 낙화암 전설의 인간적 재해석 |
| 톤 | 조용하고 내밀한 비극 |

**에피소드 구조**
- 1화: 사비성 함락 72시간 전 — 세 궁녀의 일상
- 2화: 나당 연합군 접근 소식 — 도망칠 것인가, 남을 것인가
- 3화: 의자왕 항복 당일 — 궁중의 혼란
- 4화: 밤이 깊어지다 — 각자의 선택
- 5화: 절벽 앞에서 — 침묵과 결단
- 6화: "꽃처럼 떨어지다" — 그 후 세상이 기억하는 방식

**핵심 테마**: 역사에 이름 없이 사라진 여성들의 자기결정권

---

### 2. 《화랑(花郞)》 — 황산벌의 청년들

| 항목 | 내용 |
|------|------|
| 형식 | 12화 시즌제 |
| 시점 | 무열왕 시대, 황산벌 전투 전까지 |
| 주인공 | 관창·반굴·김흠순의 아들 등 화랑도 청년들 |
| 핵심 질문 | "영웅은 만들어지는가, 태어나는가?" |
| 톤 | 청춘 서사 + 전쟁의 현실 |

**스토리 연결**: 본편 황산벌 전투 직전 상황을 다루고, 전투 당일 본편에 합류

**화랑도 시스템**
- 원화(源花): 여성 지도자 제도 → 남성 화랑으로 전환
- 풍류도(風流道): 유·불·도 합일 정신
- 낭도(郎徒): 화랑을 따르는 집단 — 다양한 신분 혼재

### 3. 《을지문덕(乙支文德)》 — 살수의 설계자

| 항목 | 내용 |
|------|------|
| 형식 | 8화 미니시리즈 |
| 시점 | 612년 고구려-수 전쟁 전후 |
| 주인공 | 을지문덕 — 고구려 전략가·장군 |
| 핵심 질문 | "천재는 어떻게 불가능한 승리를 설계하는가?" |
| 톤 | 전략 스릴러 |

**에피소드 핵심**
- 을지문덕의 수군 진영 잠입 — 정보 수집
- 7번의 의도적 패퇴 — 수군 추격 유도
- 시(詩) 한 편으로 수 장수를 조종하다
- 살수 반격 — 30만 궤멸

| 시점 | 645년 6~9월 |

## 추가 스핀오프 기획

> 아래 항목은 `spinoff-plan.md`(deprecated)에만 존재하던 고유 콘텐츠를 병합한 것입니다.

### 「소서노」— 고구려·백제 건국 여인

```
형식: 웹소설 + 웹툰 동시 연재
설정: BC 37년 이전 — 고구려 건국 시대
주인공: 소서노 (召西奴) — 주몽의 아내, 백제 건국의 어머니

역사 배경:
소서노는 주몽의 두 번째 아내 (삼국사기 기록)
주몽 사후 자신의 아들과 함께 남하 → 백제 건국 기여
고구려의 어머니이자 백제의 어머니 — 두 왕국에 걸친 여인

테마: 「두 나라의 어머니」
  - 사랑과 야망 사이
  - 정체성 — 나는 어느 나라의 여인인가

연결: 고루·아랑 두 캐릭터의 먼 선조 이야기 (서사 연결)
포맷: 웹소설 50화 + 웹툰 20화

목표 독자: 역사 로맨스 팬 + 여성 주인공 선호층
```

### 「광개토」— 고구려 전성기 OVA

```
형식: 애니메이션 OVA 3편 (각 45분)
설정: 391~413년 — 광개토대왕 재위기
주인공: 광개토대왕 (廣開土大王)

역사 배경:
영토 64성 1,400촌 정복 (광개토대왕릉비)
동북아시아 최강국 고구려 전성기
후연·백제·왜·거란 상대로 연전연승

테마: 「정복자의 꿈」
  - 더 많은 땅, 더 많은 기억
  - 강은 어디까지 흐르는가

연결: 고루 메인 IP와 「고구려 기억」의 원형으로 연결
포맷: OVA 3편 (ost-composition-guide.md OVA 음악 연동)

목표 독자·시청자: 역사 액션 팬 + 고구려 팬층
```

### 「니산(尼山, 니문의 할아버지)」— 가야 유민 스핀오프

```
형식: 단편 소설 1편 (100~120페이지)
설정: 562년 — 가야 멸망 직전·직후
주인공: 니산(尼山, 니문의 할아버지) (창작 인물) — 전직 가야 병사

역사 배경:
562년 대가야 멸망
가야 유민의 신라 편입 과정
철장인·악사·일반 서민의 삶

테마: 「사라진 나라에서 살아가는 법」
  - 정체성 없이 살아가는 사람들
  - 가야금 = 유일한 고향

연결: 니문 메인 IP의 배경 설명
포맷: 단편 소설 (디지털 출판 + 실물 소장본)
```

### 「선덕」— 선덕여왕 미니시리즈

```
형식: 드라마 미니시리즈 (6화 × 45분)
설정: 647년 — 선덕여왕 마지막 해
주인공: 선덕여왕 (善德女王)

내용:
3가지 예언의 진실 — 예언하는 것이 짐이 되는 삶
비담의 난 (647년 반란)
마지막 예언: 자신의 죽음 날짜

테마: 「아는 것의 무게」
  - 미래를 보는 자의 고독
  - 왕이기 이전에 한 인간으로서

하린과의 연결: 하린 메인 IP 전후 관계 보완
포맷: OTT 미니시리즈 (티빙 or 넷플릭스)
```

### 「발해」— 대조영 건국 소설 시리즈

```
형식: 소설 시리즈 (3권)
설정: 668~698년 — 고구려 멸망 후 발해 건국까지
주인공: 대조영 (大祚榮) + 고구려 유민 캐릭터

역사 배경:
668년 고구려 멸망 → 유민 저항
698년 대조영 발해 건국
고구려 문화·전통 계승

테마: 「사라진 것들의 귀환」
  - 강은 흘러 다시 나라가 된다
  - 메인 IP의 희망적 결말 연장선

연결: 고루 에필로그 이후 세계
포맷: 장편 소설 3권 (출판 + 웹소설 병행)
```

### 「4왕국의 아이들」— 어린이 애니 시리즈

```
형식: 단편 애니 시리즈 (12화 × 11분)
대상: 초등학생 (전 연령 접근성)
설정: 어린 시절 고루·아랑·하린·니문 (창작)

내용:
어린 4인이 4왕국에서 각자 성장하는 이야기
역사 교육 + 캐릭터 친밀감 형성
「왜 강이 기억하는가」를 어린이 눈높이로

포맷: 유튜브 키즈 + OTT 어린이 채널
목표: 어린이 관객 진입 → 성인이 된 후 메인 IP 소비
```
