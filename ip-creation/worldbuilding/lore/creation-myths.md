## 신화 체계 개요

삼국의 건국 신화는 단순한 기원 이야기가 아니다. 각 왕국의 **정체성·가치관·세계관**이 농축된 우주론이다. 고구려는 하늘에서 내려온 태양의 아들, 백제는 강에서 솟아난 봉황의 후예, 신라는 땅에서 태어난 금란의 자손, 가야는 바다에서 온 황금 알의 나라.

```
신화 구조:
Layer 1 — 우주 창생: 세상이 어떻게 시작됐는가
Layer 2 — 천지신명: 어떤 신들이 있는가
Layer 3 — 건국 신화: 왕조는 어떻게 탄생했는가
Layer 4 — 영웅 전설: 왕국을 만든 영웅들
Layer 5 — 창작 신화: IP 오리지널 확장 신화

원칙:
- 삼국사기·삼국유사 원문 최대 존중
- 창작 요소는 명확히 [창작] 표기
- 다른 미디어(소설·게임)에서 자유롭게 활용
```

## 우주 창생 신화

### 태초의 혼돈

```
[원전 기반 + 창작 확장]

태초에 하늘과 땅은 하나였다.
어둠과 빛이 섞여 있었고, 물과 불이 분리되지 않았다.
그 혼돈의 중심에 「한 강(江)」이 있었다.

강은 기억했다.
아무것도 없었을 때부터, 강은 흘렀다.
흐름이 세상의 첫 번째 의지였다.

하늘이 열리던 날, 강물이 하늘로 솟구쳤다.
솟구친 물이 구름이 되었고,
구름이 비를 내렸다.
비가 다시 강이 되었다.

이렇게 세상의 순환이 시작되었다.

[해설]
강의 순환 신화는 삼국 전체를 관통하는 창작 우주론.
「강은 기억한다」 주제의 신화적 근거.
게임에서 강은 모든 왕국을 연결하는 매개.
```

### 천신과 지신

```
[창작]

하늘에는 「천신(天神)」이 있었다.
땅에는 「지신(地神)」이 있었다.

천신은 빛과 불을 다스렸다.
지신은 물과 흙을 다스렸다.

두 신은 사랑했고, 그 사랑에서 인간이 태어났다.
그러나 하늘과 땅은 멀었다.
천신의 자식은 하늘을 그리워했고,
지신의 자식은 땅을 그리워했다.

왕국들은 그 그리움에서 태어났다.
고구려는 하늘을 향한 왕국,
백제는 강을 따라 흐르는 왕국,
신라는 땅에 뿌리내린 왕국,
가야는 바다를 건너 온 왕국.

[활용]
드라마: 오프닝 나레이션
게임: 각 왕국 선택 화면 배경 텍스트
소설: 우륵의 노래 가사
```

## 고구려 건국 신화

### 주몽 신화 (朱蒙神話)

```
[원전: 삼국사기 고구려본기, 광개토왕릉비]

해모수(解慕漱)는 하늘의 아들이었다.
오룡거(五龍車)를 타고 하늘에서 내려왔다.
머리에는 오우관(烏羽冠)을 썼으니,
까마귀 깃털로 만든 관이었다.

해모수는 강의 신 하백(河伯)의 딸,
유화(柳花)를 보았다.
압록강 변의 버들 아래.

하백은 노했다. 천신의 아들이 딸을 유혹했다고.
그러나 해모수는 돌아가지 않았다.

유화는 아이를 가졌다.
하백은 딸을 가두었다.
유화는 방 안에 갇혀 빛을 따라다녔다.
햇빛이 그녀를 따랐다. 피했지만 햇빛은 더 따랐다.

그렇게 주몽이 태어났다.
알(卵)이었다.
왕은 알을 버렸다. 짐승들은 먹지 않았다.
말이 피해갔다. 새들이 품었다.

부화한 아이는 활을 잘 쐈다.
주몽(朱蒙) — 고구려 말로 「활을 잘 쏘는 자」.

[해설]
천신의 피(하늘) + 수신의 딸(물) = 주몽
→ 하늘과 물의 교점이 고구려
삼족오: 해모수의 오우관 → 태양-까마귀 신화로 발전
```

### 삼족오 신화 (三足烏神話)

```
[원전 + 창작 확장]

태양 안에 새가 산다.
발이 세 개인 까마귀 — 삼족오(三足烏).

고구려 사람들은 믿었다.
삼족오는 태양의 전령.
하늘과 땅과 물을 잇는 존재.

세 발의 의미:
첫 번째 발 — 하늘을 딛는다
두 번째 발 — 땅을 딛는다
세 번째 발 — 물을 딛는다

주몽의 어머니 유화는 말했다.
"네 아버지는 하늘이고, 네 어머니는 강이다.
너는 그 사이에 있다. 삼족오처럼."

[창작 확장]
삼족오는 고구려 왕가의 수호신.
왕이 위기에 처하면 나타난다고 전해짐.
광개토대왕 원정 시 하늘에 삼족오 출현했다는 전설 [창작].

게임 연동:
삼족오 소환 능력 — 고구려 고유 스킬
태양 이펙트 + 세 개의 불꽃 발
```

### 비류수의 기적

```
[원전: 삼국사기 + 창작 확장]

부여를 탈출한 주몽은 길을 막는 강을 만났다.
뒤에서는 추격대가 왔다.

주몽이 강에 외쳤다.
"나는 천제의 아들이요, 하백의 외손이다.
오늘 도망하는 몸인데 추격자가 곧 닥칠 것이니
어찌하면 좋겠소."

물고기와 자라들이 떠올라 다리를 이루었다.
주몽이 건너자 다리가 사라졌다.
추격자들이 강가에서 멈추었다.

이 강이 비류수(沸流水).
고구려의 첫 번째 기적.

[창작 확장]
소서노는 이 강에서 주몽을 처음 보았다 [창작].
그날 이후 소서노는 주몽이 하늘의 아들임을 믿었다.
비류수는 훗날 「기적의 강」으로 불렸다.

소설 연동:
10장에서 고루가 꿈에 비류수를 보는 장면의 신화적 배경.
```

## 백제 건국 신화

### 온조 신화 (溫祚神話)

```
[원전: 삼국사기 백제본기]

주몽에게는 아들이 둘 있었다.
비류(沸流)와 온조(溫祚).
그러나 부여에서 온 유리가 태자가 되었다.

형 비류가 말했다. "우리가 있을 곳이 아니다."
두 형제는 남쪽으로 내려갔다.
신하 오간·마려 등 열 명이 따랐다.

비류는 미추홀(彌鄒忽, 현 인천)에 터를 잡았다.
온조는 위례성(慰禮城, 현 서울)에 터를 잡았다.

미추홀의 땅은 습하고 물이 짰다.
비류는 백성이 편히 살지 못했다.
위례성은 풍요로웠고 백성이 안락했다.

비류는 뉘우쳤으나 이미 늦었다.
비류가 죽자 그의 백성이 온조에게 왔다.
온조는 나라 이름을 백제(百濟)라 했다.
백 명의 백성이 건너와서(百濟).

[해설]
강의 선택: 비류=짠물(실패) / 온조=맑은 물(성공)
백제의 출발 = 형의 실패에서 얻은 기회
강물 테마: 어떤 강을 선택하느냐가 운명을 바꾼다
```

### 봉황 신화 (鳳凰神話)

```
[창작]

온조가 위례성을 세우던 날,
하늘에서 봉황이 내려왔다.

봉황은 오색 빛이었다.
붉은 머리, 황금 날개, 흰 몸, 푸른 꼬리, 검은 발.
다섯 색은 오행(五行)이었다.

봉황이 궁 앞 오동나무에 앉았다.
온조는 알았다. 하늘이 이 땅을 허락했다.

봉황의 노래가 울려 퍼졌다.
그 소리가 멈추자 봉황은 사라졌다.
하지만 이후 백제 왕들은 말했다.
"봉황은 떠나지 않았다. 우리 안에 있다."

[활용]
백제 왕실의 봉황 문양 근거 신화.
금동대향로의 봉황 꼭대기 = 신화적 의미.
백제가 예술·공예 강국인 신화적 설명.

드라마 연동:
소서노가 온조에게 봉황 문양 반지를 주는 장면.
백제 왕실 의식 때 봉황 노래 낭창.
```

### 소서노 신화 (召西奴神話)

```
[원전 + 창작 확장]

소서노(召西奴)는 역사 기록에 실재한다.
졸본 부여의 유력자 연타발의 딸.
주몽의 아내, 온조·비류의 어머니.

[창작 신화화]
소서노는 「강의 딸」로 불렸다.
비류수의 여신이 현현한 존재 [창작 신화].

강을 보면 미래를 안다는 전설.
소서노가 비류수에서 주몽을 본 순간,
강이 속삭였다 — "저 사람이 하늘을 가져올 것이다."

소서노는 재산을 내어 주몽의 나라를 도왔다.
주몽이 부여의 아들(유리)에게 자리를 내주었을 때,
소서노는 두 아들을 데리고 남쪽으로 떠났다.

백제의 진짜 건국자는 소서노라는 말이 있다.
온조가 왕이 되었지만,
그 뒤에는 어머니의 의지가 있었다.

[게임 연동]
소서노: 백제 고유 레전더리 유닛 카드
"강의 딸" 칭호 — 물/교역 관련 능력 강화
```

## 신라 건국 신화

### 박혁거세 신화 (朴赫居世神話)

```
[원전: 삼국사기 신라본기, 삼국유사]

서라벌(徐羅伐)에 여섯 마을이 있었다.
어느 날, 양산(楊山) 기슭 나정(蘿井) 우물가에
기이한 기운이 내려왔다.

흰 말이 절을 하고 있었다.
달려가 보니 자줏빛 알이 있었다.
알을 깨니 사내아이가 나왔다.
몸에서 빛이 났다.

이름을 혁거세(赫居世)라 했다.
「밝게 세상을 다스린다」는 뜻.
성은 박(朴) — 알이 박처럼 생겼으므로.

같은 날, 알영정(閼英井) 우물에서
용이 나타나 오른쪽 겨드랑이에서 계집아이를 낳았다.
이름을 알영(閼英)이라 했다.

혁거세와 알영은 함께 자랐다.
열세 살에 혁거세가 왕이 되었다.
알영이 왕후가 되었다.

[해설]
알에서 태어난 신화: 하늘+땅의 경계 존재
빛나는 몸 = 태양과 연결 (고구려와 다른 방식)
우물(井): 신라는 땅에서 솟아난 왕국
```

### 금관 신화 (金冠神話)

```
[창작]

박혁거세가 왕이 된 날,
하늘에서 별이 하나 내려왔다.

별이 땅에 닿자 황금이 되었다.
황금이 녹아 형태를 갖추었다.
그것이 첫 번째 금관이었다.

금관에는 나뭇가지가 세 개 솟아 있었다.
나뭇가지마다 곡옥(曲玉)이 달렸다.
곡옥은 하늘의 별이었다.

왕이 금관을 쓰는 순간 별빛을 본다.
별빛 속에서 미래를 읽는다.

선덕여왕은 이 능력이 가장 뛰어났다.
모란꽃씨에서 향기 없음을 알았고,
첨성대에서 가뭄을 예언했다.

[해설]
신라 금관 = 하늘과 연결되는 안테나
왕의 천문 지식이 신화화된 것
선덕여왕의 예언 능력에 신화적 정당성 부여

드라마 연동:
선덕여왕 즉위 장면 — 금관 착용 시 별빛 이펙트
```

### 처용 전설 (處容傳說)

```
[원전: 삼국유사]

신라 헌강왕 때, 처용(處容)이 동해에서 왔다.
동해 용왕의 아들이었다.

처용은 사람처럼 생겼지만 사람이 아니었다.
서라벌에서 살았고, 아름다운 아내를 얻었다.

어느 날 역신(疫神)이 처용의 아내를 탐내었다.
밤에 처용이 돌아와 보니 역신이 아내 곁에 있었다.

처용은 노래를 불렀다.
춤을 추었다.
노여워하지 않았다.

역신이 처용 앞에 무릎을 꿇었다.
"당신의 관대함에 감동했습니다.
이후 당신의 얼굴을 그린 곳에는 들어가지 않겠습니다."

처용의 얼굴을 문에 붙이는 풍속이 생겼다.

[게임 연동]
처용: 신라 고유 영웅 유닛 (디버프 해제·역병 방어)
처용 가면: 강력한 방어 아이템
```

## 가야 건국 신화

### 수로왕 신화 (首露王神話)

```
[원전: 삼국유사 가락국기]

가야의 땅에 사람이 살았지만 왕이 없었다.
아홉 부족의 우두머리가 있었을 뿐.

하늘에서 소리가 들렸다.
"이곳에 내려가 나라를 세우라."
구지(龜旨) 봉우리에 사람들이 모였다.

또 소리가 들렸다.
"구지가(龜旨歌)를 불러라."

거북이여 거북이여 머리를 내밀어라
내밀지 않으면 구워 먹으리라.

춤을 추며 노래를 불렀다.
하늘에서 붉은 보자기가 내려왔다.
보자기 안에 황금 알이 여섯 개.

맏이가 수로(首露)였다.
나머지 다섯이 각 가야의 왕이 되었다.

[해설]
황금 알 신화: 고구려 주몽과 유사하나 여섯 왕국 동시 탄생
구지가: 한국 최초의 노래 (주술적 성격)
철 문명과의 연결: 황금 알 = 철의 빛남

[창작 확장]
우륵은 이 구지가의 리듬에서 가야금 첫 악곡을 만들었다.
황금 알 여섯 개 = 가야금 여섯 현의 기원 [창작].
```

### 허황옥 신화 (許黃玉神話)

```
[원전: 삼국유사 가락국기]

수로왕이 즉위하자 신하들이 왕후를 권했다.
수로왕이 말했다. "하늘이 정해줄 것이다."

바다에서 배가 왔다.
붉은 돛, 붉은 깃발.
아유타국(阿踰陀國)에서 온 허황옥(許黃玉).

신하들이 막으려 하자 허황옥이 말했다.
"나는 하늘의 명을 받았다."

수로왕은 맞이했다.
허황옥은 인도에서 왔다.
(아유타국은 인도 아요디아로 추정)

가야에 불교가 먼저 왔다는 전설이 여기서 온다.
허황옥이 가져온 것 중 파사석탑(婆娑石塔)이 있었다.

[해설]
가야의 대외 교역 활발함을 신화화
인도↔가야 직접 연결: 해상 실크로드의 끝
철정(鐵鋌) 교역로의 신화적 기원

[창작 확장]
허황옥이 가져온 음악이 가야금의 기원 [창작].
12현 = 12개월 = 인도 음계에서 왔다는 설 [창작].
우륵의 스승이 허황옥의 후손이었다 [창작].
```

## 신화 공통 모티프 분석

### 알(卵) 신화

```
고구려 — 주몽이 알에서 탄생
신라 — 박혁거세가 알에서 탄생
가야 — 수로왕을 포함한 여섯 왕이 알에서 탄생

해석:
알 = 하늘과 땅 사이의 존재
알에서 태어남 = 신성한 탄생 + 완전한 독립성
알은 모든 것을 품는 용기 = 세상을 담는 그릇

[창작 로어]
강이 알을 품었다. 강물이 흐르지 않았더라면,
알은 차가워져 부화하지 못했을 것이다.
강이 왕국을 기억하는 이유 — 강이 왕들을 낳았으므로.
```

### 강(江) 모티프

```
고구려 — 비류수, 대동강, 압록강
백제 — 백마강(금강), 한강
신라 — 형산강, 낙동강
가야 — 낙동강, 황강

모든 왕국이 강 옆에서 태어났다.
강은 경계이자 통로이자 기억.

[창작 우주론]
강은 모든 왕국의 어머니.
왕국이 강을 통치한다고 생각했지만,
사실은 강이 왕국을 품고 있었다.

강은 기억한다:
- 주몽이 건넌 비류수를 기억한다
- 소서노가 건넌 한강을 기억한다
- 계백이 울었던 금강을 기억한다
- 우륵이 떠난 낙동강을 기억한다
```
