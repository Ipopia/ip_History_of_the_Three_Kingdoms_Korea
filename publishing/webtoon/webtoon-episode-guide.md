## 웹툰 시리즈 개요

```
시리즈명: 삼국 (三國)
부제: 강은 기억한다
플랫폼: 네이버웹툰 (국내 주력) + 카카오페이지 동시 연재
연재 형식: 세로 스크롤 (스마트폰 최적화)
화수 구성: 시즌 1 — 총 100화 (주 1회 연재, 약 2년)
화당 분량: 60~80컷 (세로 스크롤 기준 약 70~90장)
등급: 15세 이상 (전투·역사 묘사 기준)
언어: 한국어 (영·일·태·인니어 동시 번역 연재)
```

## 시즌 1 에피소드 구조 — 「만남과 연대」(AD 600~612)

### 1부 — 「네 개의 새벽」 (1~20화)

```
주제: 4인 개별 소개 — 각자의 왕국에서 시작

1화 「강이 말한다」
  주인공: 니문 (가야)
  내용: 562년 가야 멸망 76년 후 — 낙동강 변 갈대밭
  장면: 니문이 가야금 연주 → 강에 비친 사라진 왕국
  마지막 컷: 「강은 기억한다」강물에 새겨진 글자
  목적: IP 슬로건 + 가야의 부재 = 시리즈 감성 확립

2화 「평양성의 아침」
  주인공: 고루 (고구려)
  내용: 고루 20대 초반 — 군사 훈련 첫 장면
  장면: 을지문덕 등장 → 고루에게 말 한마디
  대사: 「기다릴 줄 아는 자가 이긴다」
  목적: 고루·을지문덕 관계 확립

3화 「사비의 등불」
  주인공: 아랑 (백제)
  내용: 미래사 기록관 — 아랑의 일상
  장면: 죽간 필사 → 창밖 백마강 → 교역선 도착
  목적: 아랑의 학구적 성격 + 백제 문화 소개

4화 「황룡사의 소녀」
  주인공: 하린 (신라)
  내용: 하린 10대 — 화랑 입단 전날
  장면: 황룡사 마당에서 혼자 활 연습
  등장: 관창 (어린 시절, 하린 친구)
  목적: 하린·관창 우정 + 화랑 세계 소개

5~8화 「각자의 시련」
  구성: 4인 각자 첫 위기 에피소드
  고루: 요동 국경 분쟁 첫 전투
  아랑: 왕실 기록 분실 사건 (외교 문서)
  하린: 화랑 입단 시험 탈락 위기
  니문: 가야금 현 끊김 — 조용한 절망

9~12화 「첫 만남」
  주제: 4인 처음으로 한 공간에 모임
  배경: 백제 사비성 외교 대회 (AD 602)
  고루: 고구려 외교 사절 수행
  아랑: 기록관으로 대회 기록 담당
  하린: 신라 화랑 대표 선수로 참가
  니문: 가야계 음악인으로 연주 담당
  클라이맥스: 4인 처음 눈 마주침 (대화 없음)

13~16화 「충돌」
  주제: 첫 만남 후 오해와 갈등
  고루 vs 하린: 고구려·신라 국경 분쟁 감정 충돌
  아랑 vs 고루: 역사 기록 관점 차이 (고구려 vs 백제 시각)
  니문: 관찰자 — 갈등 중에도 가야금 연주 (무언의 중재)
  결말: 갈등 미해소 — 각자 왕국으로 귀환

17~20화 「공통의 적」
  주제: 수나라 위협 가시화
  내용: 수 문제의 고구려 압박 사신 도착
  4인 각 왕국의 반응 (교차 편집 구성)
  마지막 컷: 수나라 100만 대군 행군 실루엣
```

### 2부 — 「연대의 강」 (21~50화)

```
주제: 4인 공동 위기 대응 + 연대 형성

21~30화 「수나라가 온다」
  내용: 수나라 제1차 침공 준비 (AD 612 이전)
  고루: 을지문덕과 함께 방어 전략 수립
  아랑: 외교 기록에서 수나라 약점 발견
  하린: 화랑 결사대 조직 제안
  니문: 3국 연대의 음악적 상징 — 「함께 흐르는 강」연주
  클라이맥스: 4인 재회 — 이번엔 적을 앞에 두고

31~40화 「살수로 향하다」
  내용: 살수대첩 준비 과정
  을지문덕의 전략 공개: 후퇴 전술 + 수문 작전
  고루의 역할: 선발대 지휘
  아랑의 역할: 수나라 보급선 정보 수집 (간첩 루트)
  하린의 역할: 신라 지원군 선발대
  니문의 역할: 고구려 병사들에게 가야금 연주 (전날 밤)

41~50화 「살수대첩」(전투 집중 화)
  41화: 수나라 113만 도하 시작
  42화: 을지문덕 7전 7퇴 — 후퇴 전술
  43화: 수나라군 살수 한복판 진입
  44화: 수문 개방 — 강물 범람 (풀페이지 연출)
  45화: 혼란 속 고루 전투 (개인 액션)
  46화: 아랑 — 기록하는 손 (전투를 기록)
  47화: 하린 기마 돌격 지원
  48화: 니문 — 강변에서 혼자 연주 (전투 교차)
  49화: 2,700명 귀환 — 수나라 대패
  50화: 전투 후 — 4인 살수 강변에서 첫 진심 대화
```

### 3부 — 「기억의 무게」 (51~80화)

```
주제: 승리 이후 — 각자의 상처와 선택

51~60화 「전쟁 이후」
  내용: 살수대첩 이후 5년 (AD 617)
  각 왕국의 변화: 고구려 강화 / 백제 외교 전환 / 신라 성장
  4인의 관계: 서신 교환으로 연결 유지
  갈등의 씨앗: 나당연합 소문 → 하린의 갈등 시작

61~70화 「아랑의 기록」
  주제: 아랑 중심 에피소드
  내용: 아랑이 발견한 가야 멸망 기록
  니문에게 기록 전달 — 처음으로 깊이 대화
  아랑 vs 백제 왕실: 불편한 역사 기록 공개 압박
  클라이맥스: 아랑의 결단 — 기록은 지워지지 않는다

71~80화 「화랑의 맹세」
  주제: 하린 중심 에피소드
  내용: 화랑 수련 완성 — 정식 화랑 서임
  관창 등장: 하린의 후배, 15세 화랑
  선덕여왕 알현 — 신라의 운명 예고
  복선: 황산벌에서 관창이 어떻게 될지 암시
```

### 4부 — 「676을 향하여」 (81~100화)

```
주제: 시즌 1 결말 + 시즌 2 복선

81~90화 「갈림길」
  내용: 나당연합 협상 소식 공개
  4인의 반응: 고루(반대)·아랑(기록)·하린(딜레마)·니문(침묵)
  갈등 폭발: 고루와 하린 처음으로 진심 충돌
  대사: 고루 「연합은 또 다른 침략이다」
  대사: 하린 「살아남아야 변할 수 있다」

91~95화 「니문의 노래」
  주제: 니문 중심 클로징 에피소드
  내용: 니문이 가야 고분 앞에서 마지막 연주
  플래시백: 562년 가야 멸망 당시 (흑백 처리)
  현재: 니문 혼자 가야금 — 관객을 위한 연주
  대사 없음 — 순수 비주얼 + 음악 묘사

96~99화 「살수는 흐른다」
  내용: 4인 마지막 만남 (이별 예고)
  각자의 결단 선언
  고루: 고구려를 지킨다
  아랑: 기억을 지킨다
  하린: 신라를 살린다
  니문: 소리를 남긴다

100화 「676」— 시즌 1 피날레
  내용: 미래 시점 플래시포워드
  노년 니문 — 676년 기벌포 해변에서 가야금
  「강은 기억한다」대사 — 시리즈 제목 회귀
  마지막 컷: 강물 위에 4인 실루엣
  시즌 2 예고: 「우리는 왜 갈라지는가」
```

## 연재 운영 기준

### 화별 구성 표준

```
오프닝 (1~5컷):
  전 화 회상 또는 현재 장면 진입
  표지컷: 해당 화 주인공 + 배경 (세로 전면)

본문 (55~70컷):
  장면 전환 신호: 검은 컷 + 왕국 색상 테두리
  대사 박스: 왕국별 색상 (고구려-청람, 백제-황금, 신라-금, 가야-황토)
  풀페이지: 화당 1~2회 (클라이맥스 장면)

클리프행어 (마지막 3~5컷):
  다음 화 기대감 유발 필수
  종류: 반전·등장·대사·시각 충격
  댓글 유도 문구: 선택적 (과도한 상업적 문구 금지)
```

### 연재 일정

```
연재 요일: 토요일 오전 11시 (국내 기준)
번역 동시 연재:
  영어: 토요일 동시 (Naver Webtoon Global)
  일본어: 토요일 +2시간 (piccoma)
  태국어: 일요일 (LINE Webtoon TH)
  인도네시아어: 일요일 (Webtoon ID)

휴재 정책:
  작가 건강/역사 고증 검토: 최대 월 1회
  공지 필수 (최소 1주 전)
  연속 휴재 2회 이상 금지
```
