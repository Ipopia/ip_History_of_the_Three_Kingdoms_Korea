## VFX 전략 총괄

### 제작 방향성

삼국(三國) 드라마의 VFX는 세 가지 목적으로만 사용한다:

1. **역사 복원**: 사라진 건축·도시·전장 복원 (황룡사·평양성·사비성)
2. **규모 확장**: 실제 촬영 인원의 한계를 넘는 전투 규모 구현
3. **신화적 표현**: 삼족오·신화·제천 의식의 시각화

**금지 원칙**: 스펙터클을 위한 VFX 남용 금지 — 감정 장면에 CG 의존 불가

### VFX 예산 배분

| 카테고리 | 예산 비중 | 예산 |
|---------|---------|------|
| 전투 씬 군중 확장 | 35% | 17.5억 원 |
| 역사 건축 복원 | 30% | 15억 원 |
| 자연환경 확장 | 15% | 7.5억 원 |
| 신화·특수효과 | 12% | 6억 원 |
| 기타·수정 | 8% | 4억 원 |
| **합계** | **100%** | **50억 원** |

### 황룡사 9층탑 복원 VFX 상세

```
복원 자료:
- 경주 황룡사지 발굴 보고서
- 삼국사기·삼국유사 기록 (높이 225척 = 약 68m)
- 일본 호류지 5층탑 참조 (백제 기술 전수 사찰)
- 현대 건축학적 복원 시뮬레이션

VFX 처리:
- E08 신라 황룡사 씬: 완전 CG 황룡사 + 서라벌 배경
- 참조: 뉴질랜드 Weta Digital 수준의 디테일
- 목표: 마치 실제 촬영한 것처럼 자연스러운 합성

승인 프로세스:
  1. 역사 자문팀 고증 검토
  2. 역사학자 자문 (경주시·문화재청 협력)
  3. VFX 프리비즈 승인 후 제작 착수
```

## 군중 VFX 파이프라인

### 사용 소프트웨어

| 소프트웨어 | 용도 |
|---------|------|
| Massive (SideFX) | 군중 AI 시뮬레이션 |
| Houdini | 유체·폭파·파티클 |
| Maya | 캐릭터 리깅·애니메이션 |
| Nuke | 합성·컴포지팅 |
| Unreal Engine 5 | 배경 환경 (Virtual Production) |

### 버추얼 프로덕션 활용

일부 씬은 버추얼 프로덕션(LED 월) 방식으로 촬영:
```
대상 씬:
- 을지문덕 전략 회의실 (역사 지도 배경)
- 선덕여왕 첨성대 장면 (밤하늘 LED 배경)
- 우륵 귀화 장면 (신라 풍경 배경)

장점:
- 배우 실시간 반응 조명 자연스러움
- 재촬영 비용 절감
- 날씨 리스크 제로
```

## 신화·특수효과 VFX

### 삼족오 VFX

```
등장 씬: 광개토대왕 즉위 / 고구려 승전 / 고구려 멸망
처리:
  - 완전 CG 삼족오 (깃털 시뮬레이션 포함)
  - 고구려 삼족오 = 검붉은 깃털 (고구려 색채 DNA)
  - 등장 시: 하늘이 붉어지는 조명 VFX 연동
  - 멸망 장면: 삼족오가 불에 타는 장면 (상징적)
```

### 구지가 신화 VFX (가야 스핀오프)

```
구지봉 하늘에서 황금 알 등장:
  - 금속성 빛 파티클
  - 하늘 개방 + 빛줄기
  - 알 내부에서 아기 수로왕 탄생
참조: 오프닝 신화 장면 — 동양적 신비감 극대화
```

### 환경 VFX 프레임워크

#### 세트 확장 (Digital Set Extension)

```
평양성 전체:
  실 세트: 성문 + 앞 광장 300평
  CG 확장: 내성·외성·차성·배경 산악 전체
  참조: 고구려 산성 벽화 + ADV-ARCH 자문

사비성:
  실 세트: 왕궁 내부 + 앞 뜰
  CG 확장: 금강 유역 + 도시 전체
  특징: 백제 특유의 섬세한 기와 문양 CG

경주 금성:
  신라 황금 색감 (일출·일몰 황금빛)
  첨성대 CG 재현 (실물 기반)
  황룡사 9층 목탑 CG 재현 (역사 복원)
```

#### 자연 환경 VFX

```
계절 표현:
  봄: 벚꽃·연두빛 새잎 파티클
  여름: 장마 빗줄기 시뮬
  가을: 단풍 낙엽 파티클
  겨울: 눈 시뮬레이션 (안시성 겨울 씬)

황사·먼지:
  전투 전후 황토 먼지 파티클
  고구려 기마대 이동 시 먼지 구름
```

#### 애니메이션 VFX 기준

```
애니메이션 시리즈 VFX:

스타일: 고구려 벽화 → 현대 애니 혼합
  2D 애니 기본 + 3D CG 전투 씬

전투 씬:
  2D/3D 하이브리드 (전통 일본 애니 스타일 참조)
  핵심 전투: 3D CG (살수·안시성·황산벌)

특수 연출:
  가야금 소리 = 시각화 (음파 곡선 VFX)
  을지문덕 전략 = 지도 위 선 그리기 애니메이션
  선덕여왕 예언 = 별자리 빛 효과

TV 규격:
  해상도: 4K (마스터) / 1080p (배포)
  프레임: 24fps (영화적 감성)
```

#### VFX 파이프라인 (전 시즌 공통)

```
1단계 — 프리프로덕션:
  Previz (사전 시각화) — 핵심 액션 씬
  스토리보드 VFX 컨펌
  VFX 슈퍼바이저 현장 참여

2단계 — 프로덕션:
  그린스크린 촬영 프로토콜
  LED 볼륨 스테이지 활용 (배우 합성)
  레퍼런스 마커 설치 기준

3단계 — 포스트프로덕션:
  로토스코핑 → 합성
  색보정 (DI): 왕국별 LUT 적용
```
