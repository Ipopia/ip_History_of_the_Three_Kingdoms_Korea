## 개요

612년의 고구려는 전시(戰時) 국가다. 수 양제의 113만 대군이 북쪽 국경을 압박하는 상황에서, 일반 백성의 일상은 전쟁의 그림자 아래 재편되고 있었다. 그러나 전쟁은 갑자기 오지 않는다 — 607년 수나라 1차 침략부터 이미 징집과 부역, 식량 수탈이 시작되었으며, 평양성 이남 농촌 지역은 전시 경제로 전환된 상태였다.

이 문서는 고루(高流)의 어머니가 살고 있는 평양성 인근 농촌을 기준으로 작성되었다. 귀족·무관·승려 등 특수 계층이 아닌, **전체 인구의 85%를 차지하는 농민·장인·소상인 계층**의 실제 삶을 다룬다.

## 1. 주거 (Housing)

### 1-1. 온돌 구조

고구려의 가옥은 **부분 온돌(쪽구들)**을 기본으로 한다. 방 전체가 아닌 한쪽 벽면을 따라 긴 구들장을 놓고, 부뚜막(아궁이)에서 생긴 열기가 구들 아래 연도(煙道)를 통해 흘러 돌을 달구는 방식이다.

```
[구조 상세]
- 구들장: 납작한 편암 또는 점판암 사용
- 연도(煙道): 아궁이 → 구들 아래 → 굴뚝으로 이어지는 열기 통로
- 부뚜막: 주방 겸 난방 겸 조리 공간 (3 기능 통합)
- 바닥: 황토 다짐 + 삿자리(갈대 또는 부들로 짠 돗자리)
- 벽체: 통나무 수평 쌓기(귀틀집) 또는 황토 다짐벽
- 지붕: 볏짚 또는 억새 이엉, 귀족 이상은 기와
```

612년 기준, 평양성 이북 군사 지대 가옥은 구들 범위를 넓히는 추세다 — 긴 겨울을 이겨내야 하는 북방 생활의 적응이자, 전시 부상자를 눕혀 회복시키는 야전 병원 기능도 겸했다.

### 1-2. 집 크기와 구조

| 계층 | 규모 | 구조 | 특징 |
|------|------|------|------|
| 농민 (소농) | 1칸~2칸 | 주방+침실 통합, 외양간 별채 | 총 면적 15~25평 이하 |
| 농민 (중농) | 2칸~3칸 | 주방/침실 분리, 창고 별채 | 총 면적 25~40평 |
| 장인/상인 | 3칸~4칸 | 작업장/주거 분리 | 작업장이 살림집보다 큰 경우 多 |
| 하급 무관 | 3칸~5칸 | 사랑채/안채 분리 시작 | 기와지붕 가능 |
| 귀족/고위 무관 | 5칸 이상 | 사랑채/안채/행랑채 분리 | 기와, 담장, 문루 |

### 1-3. 마을 구조

고구려 농촌 마을(**촌락, 村落**)의 기본 단위는 **자연촌**으로, 20~50가구가 하천 또는 구릉을 따라 집중 배치된다.

```
[전형적인 평양 인근 농촌 마을 배치]
- 중심: 공동 우물 + 제당(祭堂) — 토착신 제사 공간
- 거주 구역: 우물을 중심으로 방사형 배치
- 공동 창고: 마을 외곽, 반지하 구조 (서늘함 유지)
- 경작지: 마을 외곽 계단식 밭 + 논 (논은 평야부만)
- 방어 시설: 마을 입구 목책(木柵), 봉화대 (평양 인근 군사 마을 한정)
```

마을 내 의사결정은 **촌장(村長)**이 담당하나, 실제 권한은 마을에서 가장 토지를 많이 가진 **豪家(호가)**가 장악하는 경우가 대부분이었다.

## 2. 식생활 (Food and Diet)

### 2-1. 주식과 부식

```
[주식 곡물 — 612년 기준 비율 추정]
조(粟)     ····· 45% → 북방 기후에 가장 적합한 1등 작물
기장(稷)   ····· 20% → 척박지에서도 재배 가능
콩(大豆)   ····· 15% → 단백질 공급원 + 된장·메주 원료
보리(大麥) ····· 10% → 봄 겨울 이모작 가능, 전시 비축 중요
밀(小麥)   ·····  5% → 귀한 작물, 주로 귀족·군 배급
쌀(水稻)   ·····  5% → 평양 인근 하천 평야부에서만 소량 생산
```

**주요 조리법**:
- **죽(粥)**: 쌀/조/기장 죽. 일반 백성의 아침 식사 기본형.
- **시루떡**: 곡물 가루를 시루에 찐 것. 제사·축제 음식이나 612년 군량 대체식으로도 사용.
- **된장국(醬湯)**: 콩된장 + 야채. 매일 먹는 국의 기본형.
- **소금절임(醢)**: 채소류를 소금에 절인 발효식. 오늘날 김치의 직접 전신. 겨울 비축의 핵심.

### 2-2. 주요 농작물과 생산 환경

| 작물 | 재배 시기 | 주산지 | 용도 |
|------|----------|--------|------|
| 조 | 5월 파종 ~ 9월 수확 | 산간 밭 전역 | 주식, 조청, 술 원료 |
| 기장 | 5월 ~ 8월 | 북부 척박지 | 주식, 제사 공물 |
| 콩 | 5월 ~ 10월 | 밭 전역 | 된장·두부·콩기름 원료 |
| 삼(麻) | 봄 ~ 여름 | 밭 전역 | 천(삼베) 제조, 씨앗(삼씨) 식용 |
| 마늘/파 | 연중 | 텃밭 | 조미, 약용 (감기·기생충 치료) |
| 순무 | 가을 | 밭 | 겨울 저장 채소 (소금절임) |

### 2-3. 전시 식생활 변화 (612년)

607년 수나라 위협이 본격화되면서 고구려 조정은 **군량 비축 의무**를 각 촌락에 부과했다.

```
[612년 식량 부족의 구체적 양상]
- 수확량의 30~40%를 군량으로 징발 (종래 세율 10~15%에서 급등)
- 평양 이북 지역 남성 대부분 징집 → 경작 인력 급감
- 대안 식량: 도토리 가루(橡粉) 죽, 소나무 껍질(松皮) 죽
- 소와 말의 징발 → 경작용 역우(役牛) 부족
- 어획 증가: 대동강·청천강 어업이 식량 보완 핵심 수단으로 부상
```

**고루의 어머니 환경 적용**: 평양성 외곽 2~3리 거리 농가. 남편(고루의 아버지)은 614년 이미 을지문덕 막하에 배속된 상태. 어머니는 밭 경작 + 이웃 3가구와 공동 경작 협력체 구성.

## 3. 의복 (Clothing)

### 3-1. 신분별 복식 차이

**기본 복식 구조** (삼국 공통, 고구려 변형):
- **저고리(襦)**: 상의. 고구려는 깃이 좁고 소매가 통소매(넓음)
- **바지(袴)**: 풍성한 통바지 (기마 문화의 영향 — 말 타기에 적합한 구조)
- **포(袍)**: 겉옷. 계절과 신분에 따라 소재·색상 차별

| 계층 | 상의 | 하의 | 겉옷 | 머리 | 신발 |
|------|------|------|------|------|------|
| **귀족 남성** | 비단 저고리, 선(線) 장식 | 비단 통바지 | 대수포(大袖袍), 금동 허리띠 | 조우관(鳥羽冠) 또는 절풍건 | 가죽화 |
| **무관/병사** | 삼베 저고리, 철릭 | 삼베 바지 | 갑주(甲胄) + 겉포 | 투구 또는 두건 | 가죽화 또는 짚신 |
| **농민 남성** | 삼베 저고리 | 삼베 통바지 | 삼베 겉옷 (여름 無) | 두건 또는 맨머리 | 짚신 또는 맨발 |
| **귀족 여성** | 비단 저고리, 화문(花文) | 주름 치마 | 긴 포(袍) | 높은 뒤꽂이 비녀 | 비단 화 |
| **농민 여성** | 삼베 저고리 | 삼베 치마 | 두루마기 (겨울) | 두건 또는 낮은 쪽진 머리 | 짚신 |

**612년 전시 변화**: 삼베 공급도 군수용 우선 배정으로 농민 의복 질이 저하. 일부 지역에서는 사슴·노루 가죽 가공한 피혁 의류 증가.

### 3-2. 색채와 신분

| 색상 | 허용 계층 | 염색 원료 |
|------|----------|----------|
| 보라 (紫) | 최상위 귀족, 왕족 | 자초(紫草) 뿌리 |
| 붉은색 (緋) | 고위 귀족, 5品 이상 관료 | 꼭두서니 뿌리 |
| 황색 (黃) | 중간 귀족, 군 장교 | 황벽나무 껍질 |
| 청색 (靑) | 하급 관료, 상인 | 쪽(藍) |
| 흰색/황갈색 | 농민·천민 | 무염색 (삼베 원색) |

## 4. 직업과 사회 구성 (Occupations)

### 4-1. 직업별 인구 비율 추정 (612년)

```
전체 고구려 인구 추정: 300~350만 명

농민           ···········  70% (약 210~245만)
군인/부역      ···········  12% (약 36~42만, 전시 급증)
장인/공인      ···········   8% (약 24~28만)
상인           ···········   4% (약 12~14만)
승려/무속인    ···········   3% (약 9~10만)
귀족/관료      ···········   2% (약 6~7만)
기타(노비 등)  ···········   1%
```

### 4-2. 주요 직업 상세

**농민(農民)**:
- 봄(3~5월): 쟁기질, 파종, 논두렁 정비
- 여름(6~8월): 제초, 관개 (수리 시설 공동 관리)
- 가을(9~10월): 수확, 탈곡, 군량 납부
- 겨울(11~2월): 집 수리, 농기구 정비, 부역 동원 (성곽·도로 건설)

**장인(工人)**:
- **철장(鐵匠)**: 고구려의 핵심 전략 자원. 612년 전시에는 무기 생산 우선. 농기구는 후순위.
- **목장(木匠)**: 가옥·성곽·전차·공성 기구 제작. 전시 군수 동원.
- **도공(陶工)**: 일상 용기(항아리, 시루, 독) 제작. 614년 이후 급격 수요 감소.
- **직조공(織造工)**: 삼베·비단 생산. 여성 주도 가내 수공업.

**상인(商人)**:
- 고구려 상인은 국내 교역 중심. 수도 평양과 지방 촌락을 잇는 행상(行商) 활동.
- 612년 전시: 식량 사재기 금지 명령 발동. 군수물자 유통 담당 관상(官商) 제도 강화.
- 대외 무역: 수나라와 교역 단절. 신라·백제 방면 교역도 전시 제한.

**군인(軍人)**:
- 612년 기준 고구려 상비군: 약 10~15만 추정 (전시 동원 포함 30~40만)
- 징집 기준: 남성 16세 이상 ~ 60세 미만. 장자(長子) 1인은 경작 지속 허용.
- 보급: 각 병사는 자기 식량의 일부를 직접 조달 (군량 부족 시 현지 징발)

## 5. 종교와 신앙 (Religion and Beliefs)

### 5-1. 불교와 토착신앙의 혼합

고구려는 소수림왕 372년 공식 불교를 수용했으나, 612년 시점에도 **불교(佛敎)와 토착신앙은 병존**하며 서로 섞인 상태였다.

```
[계층별 신앙 패턴]
왕실/귀족  → 불교 우세 (사찰 건립, 승려 후원이 지위 과시 수단)
무관/병사  → 불교 + 전쟁신(天帝) 혼합 (살수 출전 전 불사(佛事) + 군신제(軍神祭) 병행)
농민       → 토착신앙 우세 (마을 제당, 산신, 수신, 조상신)
승려       → 불교 교리 + 고구려 토착 요소 융합 (주술적 불교)
```

**토착신앙의 구체적 양상**:
- **산신(山神)**: 각 마을이 의지하는 뒷산의 신. 음력 1월 15일, 3월 3일, 10월 상달 제사.
- **수신(水神)**: 강과 우물의 신. 살수(청천강) 인근 마을은 강신(江神)에 특별한 제의.
- **조상신(祖上神)**: 가족 단위. 조상 위패를 모시고 음식 공양.
- **삼족오(三足烏)**: 고구려 신화의 핵심 신성 동물. 왕실 상징이나 민간 신앙에도 존재.

**612년 전시 불교의 역할**:
- 을지문덕은 살수 출전 전 평양 대사원에서 국왕과 함께 호국기도(護國祈禱) 주관.
- 전몰자 위령재(慰靈齋)가 전쟁 기간 내내 이어짐.
- 승려들이 부상병 치료와 군량 운반에 동원 — 불교 사원이 야전 병원화.

## 6. 가족 구조 (Family Structure)

### 6-1. 대가족 체계

고구려의 기본 가족 단위는 **부계(父系) 대가족**이다. 이상적 형태는 조부모-부모-자녀 3세대가 같은 가옥 또는 인접 가옥에 거주하는 구조였으나, 612년 전시에는 남성 구성원 대부분이 징집되어 **여성 중심 가족**이 실제 운영 단위가 된 경우가 많았다.

```
[612년 고구려 농촌 가족 실태]
- 표준 농가 구성: 祖母 + 어머니 + 아이들 (남성 가장 부재)
- 경작 인력: 여성 + 60세 이상 노인 + 10세 이상 아동
- 공동 경작 조직: 인근 3~5가구 연합 (노동력 공유)
- 남성 부재 기간: 봄 징발 ~ 가을 이후 귀환 (또는 불귀)
```

### 6-2. 결혼과 가족 제도

- **결혼 연령**: 남성 18~22세, 여성 14~18세 (귀족은 더 이름)
- **데릴사위제(服婿制)**: 고구려 독특 관습. 혼인 후 남성이 처가에서 일정 기간 거주. 자녀 출산 후 독립 또는 부가(父家)로 귀환.
- **서옥제(壻屋制)**: 처갓집 옆에 작은 집(서옥)을 짓고 사는 과도기 형태.
- **재혼**: 전시 전사자 속출로 과부 재혼이 사회적으로 허용(권장)되는 분위기.

## 7. 전시(戰時) 영향 — 612년 특수 상황

### 7-1. 징집과 부역

```
[607~612년 고구려 민간의 전시 부담 연표]
607년 : 천리장성 북부 보수 공사 → 성인 남성 부역 동원 시작
609년 : 수나라 1차 침략 대비 → 요동 방어선 강화 징집
611년 : 전국 군량 비축 명령 → 수확량 30% 국가 징발
612년 봄 : 전면 징집 → 16세~60세 남성 요동·살수 방면 집결 명령
612년 여름 : 살수 일대 전투 → 농촌 인력 최저점
612년 가을 : 살수대첩 승리 → 부분 귀환, 그러나 전사자 다수
```

### 7-2. 피난과 이동

- **평양 이북 주민 이동**: 요동 방면 전투 지역 인근 촌락은 평양성 방향으로 이주 권고.
- **피난민 문제**: 평양성 성문 안 피난민 급증 → 식량 배급 위기.
- **징발 도망**: 일부 남성이 산속 은거. 발각 시 군법 처벌 (가족 연좌 포함).

### 7-3. 고루의 어머니 — 구체적 일상 (서사 적용)

> **설정 적용**: 평양성 동쪽 10리 거리, 대동강 지류 인근 마을. 인구 약 40가구. 612년 봄 남성 절반 징집.

```
새벽 4시   : 기상. 아궁이 불 피우기 (땔감은 전날 준비한 잡목)
새벽 5시   : 조죽(粟粥) 준비. 시어머니 식사 수발.
오전 6~10시 : 밭 경작. 이웃 두 명과 공동 작업.
오전 11시  : 집 귀환. 점심 = 죽 + 소금절임 채소.
오후 1~5시 : 삼베 짜기 (군수 납품 할당량 있음). 또는 마을 공동 작업.
오후 6시   : 저녁 = 된장국 + 조밥 (쌀 없음).
저녁 7~9시 : 등잔불 아래 삼베 작업 지속. 또는 아이 교육.
밤 9시     : 취침. 구들 위 삿자리.
```

### 7-4. 식량 부족과 사회 변화

- **공동체 강화**: 전쟁이 역설적으로 마을 공동체 결속을 강화. 서로의 밭을 함께 경작하는 **두레** 형태 협력 조직 발달.
- **여성 리더십 부상**: 남성 부재로 촌락 의사결정에 여성(특히 호가 아내)이 실질 권한 행사.
- **아동 노동 확대**: 10세 이상 아동이 경작·물 긷기·땔감 수집에 투입.
- **종교 의존 강화**: 불확실성 증가 → 마을 제당 참배 빈도 급증, 무당(巫堂) 수요 증가.
