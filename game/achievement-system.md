## 업적 시스템 철학

삼국(三國) 게임의 업적은 **"역사를 기억하는 방식"**이다. 단순 달성 수치가 아닌, 플레이어가 삼국시대를 깊이 이해하고 경험할수록 열리는 구조다.

```
업적 설계 원칙:
1. 역사 학습 — 업적 달성 시 실제 역사 해설 제공
2. 서사 몰입 — 캐릭터 심화 스토리 언락
3. 전략 깊이 — 다양한 플레이 스타일 보상
4. 감정 공명 — 비극적 역사 순간을 의미있게 경험
5. 크로스미디어 연동 — 웹소설·웹툰 콘텐츠 언락
```

## 메인 업적 카테고리

### 1. 정복자의 길 (征服者之路)

**고구려 캠페인 전용**

```
[동] 첫 번째 성벽
→ 졸본성 첫 성벽 건설 완료
→ 해설: "주몽은 비류수에서 나라를 시작했다..."

[동] 살수의 기적
→ 살수대첩 전투 승리
→ 해설: "612년, 수나라 113만 대군이 살수에서 무너졌다..."

[은] 광개토의 꿈
→ 광개토대왕 캠페인 10챕터 완료
→ 보상: 광개토대왕 역사 코스튬 (갑옷 착용 버전)

[은] 64성의 정복자
→ 광개토대왕 캠페인 모든 성 점령
→ 해설: "광개토릉비에 기록된 64개성, 1400개 촌락..."

[금] 천하의 주인
→ 영락대왕 칭호 획득 — 모든 조공 세력 복속
→ 보상: 광개토대왕 전설 무기 세트

[비색] 릉비의 목소리
→ 광개토대왕릉비 비문 모든 조각 발견 (숨겨진 수집)
→ 보상: 릉비 전문 스크롤 아트워크 + 역사 해설

[적석] 고구려의 영광
→ 고구려 캠페인 모든 결말 달성 (3가지 분기 완주)
→ 보상: 역사 해설집 '고구려 편' PDF
```

### 2. 아름다운 왕국 (美麗王國)

**백제 캠페인 전용**

```
[동] 한강의 터전
→ 위례성 건설 첫 완성
→ 해설: "온조는 한강 유역에서 나라의 기틀을 잡았다..."

[동] 칠지도의 외교
→ 왜국에 칠지도 하사 이벤트 완료
→ 해설: "칠지도는 현재 일본 이소노카미신궁에 소장되어 있다..."

[은] 근초고왕의 전성기
→ 근초고왕 캠페인 완주 + 고구려 격퇴
→ 보상: 근초고왕 황금 의장 코스튬

[은] 백제의 미소
→ 외교 수치 최대치 달성 (문화 외교 루트)
→ 보상: 백제 금동대향로 미니어처 인게임 아이템

[금] 의자왕의 결단
→ 계백 황산벌 결전 — 5천 결사대 선택 분기 완료
→ 보상: 계백 비장 코스튬

[금] 낙화암의 기억
→ 백제 멸망 엔딩 감상 (모든 대화 선택지 확인)
→ 보상: '낙화암의 꽃' OST 언락

[비색] 사비성의 꽃
→ 사비성 문화 수치를 최대치로 달성한 뒤 멸망
→ 보상: 백제 감성 아트북 파트 PDF

[적석] 강물은 기억한다
→ 백제 캠페인 모든 결말 + 역사 문서 100% 수집
→ 보상: 역사 해설집 '백제 편' PDF
```

[적석] 삼한일통의 완성
→ 신라 캠페인 삼국 통일 엔딩 달성

### 4. 가야금 소리 (伽倻琴 소리)

**가야 DLC 전용**

```
[동] 철의 나라
→ 가야 제철 시스템 첫 완성
→ 해설: "가야의 철기는 한반도 최고 품질이었다..."

[동] 우륵의 선율
→ 우륵 가야금 연주 미니게임 첫 완료
→ 보상: 가야 테마 BGM 언락

[은] 12곡의 완성
→ 우륵 12악곡 미니게임 전부 클리어
→ 보상: 가야금 소리 OST 앨범 인게임 리스너

[금] 신라에 심은 가야
→ 우륵 귀화 결단 — '신라에 가야를 심겠다' 선택
→ 보상: 우륵 '두 나라' 스페셜 코스튬

[비색] 가야가 사라진 날
→ 가야 멸망 모든 엔딩 감상 + 우륵 독백 완청
→ 보상: '가야의 강' 애니메이션 클립 언락

[적석] 사라지지 않는 소리
→ 가야 DLC 100% 완료 + 은닉 유물 전부 발견
→ 보상: 역사 해설집 '가야 편' PDF
```

## 업적 보상 체계

### 누적 포인트 시스템

```
업적 등급별 포인트:
동: 10P / 은: 30P / 금: 100P / 비색: 200P / 적석: 500P

누적 보상:
100P  → '삼국의 학도' 칭호
300P  → 역사 테마 UI 스킨
500P  → '강의 기억자' 칭호 + 특별 아바타
1000P → '삼국통달' 칭호 + 개발팀 감사 엔딩 크레딧 등재
2000P → '삼국의 영웅' 칭호 + 오프라인 굿즈 당첨 기회 (월 1회 추첨)
```

### 칭호 시스템

```
달성 기반 칭호 (선택 장착):
- 정복자 (광개토 캠페인 금 이상 전부)
- 외교관 (외교 금 이상 전부)
- 탐구자 (역사 탐구자 금 이상 전부)
- 비운의 장군 (계백 황산벌 달성)
- 가야금의 음 (우륵 전 업적)
- 별을 읽는 자 (선덕 전 업적)
```

## QA 기준

```
업적 설계 검증:
□ 역사적 사실 오류 없음
□ 스포일러 업적은 숨김 처리
□ 달성 난이도 밸런스 확인 (동:은:금 = 40:35:25)
□ 보상 가치 인플레이션 없음
□ 크로스미디어 연동 오류 없음
□ 다국어 번역 완료 (한/영/일)
□ 접근성 고려 (색맹 사용자 아이콘 구분)
```
