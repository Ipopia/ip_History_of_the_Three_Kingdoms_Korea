## 드라마 개요

```
제목: 삼국(三國): 강은 기억한다
영문: THREE KINGDOMS: THE RIVER REMEMBERS
형식: 대하 역사 드라마 (Epic Historical Drama)
시즌 1: 20화 × 60분 (총 1,200분)
방영: 티빙 오리지널 + 넷플릭스 글로벌 동시 or 6개월 후

제작 방향:
「사극의 스펙터클 + 현대 드라마의 감성」
대규모 전투 씬 + 4인 주인공 개인 드라마 병행
역사 고증 최우선 + 현대 시청자 몰입 균형
```

## 시즌 1 에피소드 구성

```
EP 01~03: 「4강의 시작」(오프닝 아크)
EP 01: 4왕국 동시 소개 — 4인의 봄
EP 02: 수나라 침략 정보 + 을지문덕 등장
EP 03: 4인의 첫 조우 — 고구려·백제·신라·가야

EP 04~07: 「살수여 흘러라」(살수대첩 아크)
EP 04: 수나라 113만 진격 개시
EP 05: 을지문덕 전략 — 7번 패배
EP 06: 살수 방류 준비 + 긴장 고조
EP 07: 살수대첩 클라이맥스 (전투 대규모 씬)

EP 08~10: 「연개소문의 시대」(내부 갈등 아크)
EP 08: 642년 쿠데타 — 영류왕 시해
EP 09: 아랑의 예언 기록
EP 10: 선덕여왕의 3가지 예언

EP 11~16: 「안시성의 밤」(안시성 아크)
EP 11: 당 태종 10만 원정
EP 12: 안시성 포위 시작
EP 13: 토산 축조 — 당나라 작전
EP 14: 고루의 야습 작전 준비
EP 15: 토산 붕괴 클라이맥스 (2회차 대규모 전투 씬)
EP 16: 당 태종 철수 — 승리의 여운

EP 17~20: 「강은 기억한다」(피날레 아크)
EP 17: 전후 4왕국 각자의 일상
EP 18: 아랑 — 백마강에 기록을 감추다
EP 19: 니문 — 12번째 악곡 두 번째 시도
EP 20: 4인 재회 + 강변 에필로그 (시즌 2 훅)
```

## 촬영 계획

### 주요 로케이션

```
고구려 씬:
평양성 성벽: 강원도 DMZ 인근 야산 + 세트 합성
대동강변: 경기 북부 실제 강변 로케이션
살수 전장: 한강·임진강 유역 촬영 + CG 확장

백제 씬:
사비성: 충남 부여 백마강 실제 로케이션
문서관: 전용 세트 (미술부 제작)
낙화암: 부여 낙화암 협의 촬영 (부여군청 허가)

신라 씬:
서라벌: 경북 경주 협의 촬영
첨성대: 경주 첨성대 인근 + 세트 합성
황룡사 목탑: CG 100% (실물 없음 — 발굴 기단만 존재)

가야 씬:
낙동강변: 경남 김해 낙동강 하류 실제 로케이션
제철 공방: 기능성 세트 제작 (실제 소품)
구지봉: 김해 구지봉 협의 촬영

세트 건설:
평양성 내부: 5,000m² 세트 (공사 기간 6개월)
사비성 왕궁: 3,000m² 세트
문서관: 200m² 미술 세트
안시성 성벽 일부: 실물 축조 세트 (높이 6m, 폭 30m)
```

### 전투 씬 촬영

```
살수대첩 전투 (EP07):
촬영 기간: 30일 (대규모 전투 씬)
엑스트라: 2,000명+ (병사 역)
기마: 말 150두 (마상 전투)
특수효과: 물 방류 실물 세트 (10m×50m 수조)
CG: 수나라 30만 군대 군중 CG (후반 작업)

안시성 클라이맥스 (EP15):
촬영 기간: 25일
특수효과: 토산 붕괴 (흙+모래 특수효과 팀)
야간 촬영: 횃불 조명 (실제 횃불 안전 관리)
CG: 당나라 진영 CG + 흙먼지 파티클
```

## 캐스팅 방향

```
주인공 4인 캐스팅 기준:

고루 (고구려 장군):
나이대: 실제 나이 28~38세 배우
신체: 185cm+ / 근육질
조건: 무술 퍼포먼스 + 기마 가능 (또는 6개월 훈련)
이미지: 강인하되 인간적 — 김우빈·유아인 계열

아랑 (백제 사관):
나이대: 실제 나이 22~30세 배우
이미지: 총명·우아·내면 강함
조건: 붓글씨 연습 6개월 (씬 직접 연기)
이미지: 정유미·김고은 계열

하린 (신라 화랑):
나이대: 실제 나이 26~35세 배우
신체: 180cm+ / 날렵한 체형
조건: 검술 퍼포먼스 + 화랑 무예 훈련
이미지: 활기차고 카리스마 — 강하늘·송강 계열

니문 (가야 악사):
나이대: 실제 나이 30~42세 배우
조건: 가야금 실연주 가능 (국악 전공자 우선)
이미지: 조용하고 깊은 내면 — 조승우·이준기 계열
특별 조건: 씬 內 가야금 라이브 연주 필수

역사 인물 캐스팅:
을지문덕: 60대 베테랑 배우 — 정진영·최민식 계열
연개소문: 40~50대 카리스마 배우
선덕여왕: 40대 지적 우아함 — 김혜수·전도연 계열
의자왕: 카리스마+비극성 겸비
```

## 후반 작업 (Post-Production)

```
CG·VFX:
담당사: 국내 A급 VFX 스튜디오 (매드맨 CG 수준)
CG 씬:
  - 수나라 30만 군중 CG (EP04~07)
  - 황룡사 9층 목탑 완공 씬 (EP10)
  - 살수 강물 대규모 CG (EP07 클라이맥스)
  - 안시성 전경 + 당나라 진영 CG (EP12~15)
  - 4왕국 수도 원경 파노라마 (전 에피소드)

색보정 (Color Grading):
왕국별 LUT 적용:
  고구려 씬: 쿨 블루 LUT (#2F4F7F 기조)
  백제 씬: 웜 골드 LUT (#B8960C 기조)
  신라 씬: 브라이트 옐로 LUT (#FFD700 기조)
  가야 씬: 어스 앰버 LUT (#C8A96E 기조)

사운드:
음악: ost-composition-guide.md OST 적용
효과음: sound-design-guide.md SFX 적용
ADR: 로케이션 소음 재더빙 (전투 씬 전량)
믹싱: 돌비 애트모스 5.1.4 (극장 상영 대비)
```
