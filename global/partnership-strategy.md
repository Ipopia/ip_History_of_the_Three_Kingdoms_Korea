# 글로벌 파트너십 전략 — 삼국(三國) IP

**참조 문서**: `global-strategy.md`, `localization-guide.md`, `legal-framework.md`, `brand-identity.md`
**작성**: 글로벌사업본부 (GLB-BIZ)
**적용**: 삼국(三國) IP 해외 파트너십·공동 제작·라이선싱 전략 기준

---

## 글로벌 파트너십 전략 개요

```
목표:
  IP 가치 최대화: 단순 수출 → 공동 제작 격상
  현지화 품질: 파트너 현지 역량 활용
  수익 다각화: 라이선싱 + 공동 투자 + 로열티

파트너십 유형:
  TYPE A: 방송·스트리밍 배급 파트너
  TYPE B: 공동 제작 파트너 (드라마·애니·게임)
  TYPE C: 상품 라이선싱 파트너 (머천다이즈)
  TYPE D: 문화기관·박물관 파트너 (전시·교육)
  TYPE E: 플랫폼·테크 파트너 (AR/AI/게임 퍼블리싱)

우선 시장:
  1순위: 일본 (한류 팬덤 + 고대사 관심)
  2순위: 동남아 (태국·베트남·인도네시아)
  3순위: 미국·유럽 (OTT 프리미엄 시장)
  4순위: 중국 (장기 검토 — 역사 민감성 고려)
```

## 일본 파트너십

### TYPE A: 방송·스트리밍 배급

```
타깃 플랫폼:
  Netflix Japan: OTT 동시 배급 우선 협상
  NHK: 공영방송 파트너십 (교육적 가치 강조)
  Amazon Prime Japan: 독점 배급 옵션 검토
  Crunchyroll: 애니메이션 배급 (애니화 시)

협상 포인트:
  동시 방영: 한국 방영과 동일 날짜 일본 자막 배급
  전 시즌 패키지: 시즌 1~3 묶음 선구매 유도
  극장 이벤트 상영: 일본 팬 이벤트 연계

수익 구조:
  라이선싱 피: 에피소드당 $50,000~200,000 (규모별)
  수익 분배: 70% 국내 / 30% 일본 파트너
```

### TYPE B: 일본 공동 제작

```
애니메이션 공동 제작:
  파트너 후보: 매드하우스, 클로버웍스, 본즈
  형식: 한국 원작 IP + 일본 애니메이션 스튜디오
  수익 분배: 50:50 (일본 시장) / 70:30 (기타)
  주의: 역사 왜곡 방지 조항 계약서 명문화 (필수)

만화 공동 출판:
  파트너: 슈에이샤, 고단샤, 쇼가쿠칸
  형식: 한국 원작 → 일본 만화가 작화 협업
  시리즈: 메인 30권 + 일본 독자 특전 단편

역사 민감 항목 처리:
  임나일본부설 관련 서술 금지 조항
  가야-야마토 교역 = 「대등한 교역」표현 한정
  계약서 부속 문서: 「역사 묘사 가이드라인」첨부 필수
```

### TYPE C: 일본 상품 라이선싱

```
파트너 후보:
  굿스마일컴퍼니 (피규어)
  반다이남코 (완구·게임)
  유니클로 (의류 콜라보)
  무인양품 (라이프스타일 굿즈)

라이선싱 조건:
  기간: 3년 (갱신 옵션)
  로열티: 소매가 8~12%
  품질 승인: 전 상품 ART-DIR + IP-LEGAL 사전 승인
  역사 오류 상품 즉시 회수 조항 포함

특별 제한:
  「임나일본부」연상 디자인 금지
  가야 = 일본 속국 암시 표현 전면 금지
  위반 시 계약 즉시 해지 조항
```

## 미국·유럽 파트너십

### OTT 글로벌 배급

```

  목표: 글로벌 동시 배급 (190개국)
  협상 형태: 공동 제작 투자 or 구매 계약
  콘텐츠 요구: 영어 더빙 + 자막 (Netflix 기준)
  레퍼런스: 킹덤, 이상한 변호사 우영우 글로벌 성공

  차별화 포인트: 역사 다큐멘터리 연계 패키지
  「삼국」드라마 + 「삼국의 진실」다큐 2편 세트 제안

Amazon Prime Video:
  아시아 콘텐츠 확장 전략 연계
  인도·동남아 동시 배급 패키지
```

```

  삼국 IP 전시 공동 기획

  신라 관련 콘텐츠 역사 감수

  백제 관련 모든 고증 공인 파트너
  낙화암·금동대향로 콘텐츠 협력
```

## 파트너십 관리 기준

```
계약 승인 프로세스:
  $10만 이하: GLB-BIZ 팀장 승인
  $10만~$100만: 본부장 + IP-LEGAL 공동 승인
  $100만 이상: CEO 직결 보고

필수 계약 조항:
  역사 왜곡 방지 조항 (일본 계약 모두 포함)
  IP 품질 통제: 전 상품·콘텐츠 사전 승인
  재계약 우선권: 성과 달성 시 자동 우선협상
  분쟁 해결: 한국 중재원 or 국제상사중재원 (ICAC)

성과 관리:
  분기별 파트너 리뷰 (매출·품질·이슈)
  미달성 파트너: 6개월 개선 기간 후 재검토
  우수 파트너: 독점권·신규 IP 우선 협상권 제공
```
