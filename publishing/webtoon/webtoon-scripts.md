## 웹툰 개요

```
제목: 삼국(三國): 강은 기억한다
플랫폼: 네이버 웹툰 (국내) + Webtoon (글로벌)
연재 형식: 세로 스크롤 (Webtoon 표준)
화당 분량: 60~80컷 (A4 환산 약 30~40페이지)
연재 주기: 주 1회 (매주 토요일)
예상 총 화수: 150~200화

시즌 구성:
  시즌 1: 1~60화 (살수대첩 ~ 안시성)
  시즌 2: 61~120화 (황산벌 ~ 고구려 멸망)
  시즌 3: 121~180화 (나당전쟁 ~ 기벌포)
```

## 스크립트 작성 기준

### 컷 구성 원칙

```
세로 스크롤 최적화:
  독자 스크롤 속도 = 서사 리듬
  빠른 장면: 세로 긴 컷 → 빠른 스크롤 유도
  감정 장면: 여백 넓은 컷 → 자연 정지 유도
  클라이맥스: 페이지 전체 1컷 → 임팩트

컷 배치 패턴:
  전투 시작: 와이드샷 1컷 (전장 전체)
  전투 중: 소컷 3~5개 연속 (속도감)
  감정 절정: 전체 1컷 (여백 충분히)
  마무리: 조용한 1~2컷 (여운)
```

### 대사·지문 기준

```
대사 길이:
  말풍선 1개: 최대 40자 (한국어 기준)
  감정 고조 장면: 최대 20자 (임팩트)
  설명 내레이션: 최대 60자

지문 형식:
  [장소] [시간] [기상]
  예: [살수강 북쪽 / 612년 여름 / 새벽]

효과음:
  전투: 콰! 쾅! 쉿! (단음절 집중)
  자연음: 콸콸 / 쏴아 / 윙윙
  감성: 효과음 없음 (침묵이 더 강함)
```

## EP01 스크립트 — 「강이 흐른다」

```
[컷 001~005] — 오프닝 세로 파노라마
  001: 살수강 전경 (드론 시점 재현) — 새벽 안개
  002: 강물 클로즈업 — 물결 디테일
  003: 강 건너편 실루엣들 (수나라 군)
  004: 고루 뒷모습 — 강을 바라봄
  005: 고루 눈 클로즈업

  내레이션 (005컷 여백):
  「강이 흐른다.
   612년 여름 — 이 강이 역사를 바꿀 것이다.」

[컷 006~015] — 고루 첫 등장
  006: 부하: 「장군! 수나라 군이…끝이 없습니다.」
  007: 광각컷 — 지평선 가득 수나라 진영
  008: 고루 (뒤돌아 부하 봄): 「숫자가 중요한 게 아니다.」
  009: 부하: 「그럼 무엇이 중요합니까?」
  010: 고루 클로즈업 (눈빛): 「지형이다. 그리고—」
  011: 고루 손가락 → 살수강 방향
  012: 「—물.」
  013: 살수강 광각 (고루 시점)
  014: 강물 흐름 클로즈업
  015: 타이틀컷: 「삼국(三國): 강은 기억한다 EP.01」

[컷 016~030] — 아랑 파트
  016: 장소 전환: [사비성 왕궁 후원 / 같은 날 / 맑음]
  017: 금동대향로 전신샷 (디테일)
  018: 아랑 손 클로즈업 — 자수 바늘
  019: 아랑 얼굴 — 집중한 표정
  020: 어머니 (OS): 「자수는 기록이야—」
  021: 아랑 고개 듦
  022: 어머니 얼굴: 「잊지 않기 위해 새기는 것.」
  023: 아랑: 「…잊으면 사라지나요?」
  024: 어머니 미소: 「사라지지.」
  025: 「기억하는 사람이 없으면.」
  026: 아랑 다시 자수 시작 — 봉황 날개 패턴
  027: 시녀 등장 (멀리서): 「아랑 아씨! 수나라가—」
  028: 아랑 자수 멈춤 — 손 정지
  029: 아랑 정면 클로즈업: 「고구려가…」
  030: 창밖 바라봄 — 시선 멀어짐 (여백)

[컷 031~045] — 하린 파트
  031: 장소 전환: [신라 왕경 화랑 훈련장 / 같은 날]
  032: 말 달리는 하린 — 동세
  033: 활시위 당기는 하린 (표정 집중)
  034: 화살 발사 → 과녁 명중
  035: 동료들: 「오!」 함성
  036: 관창 (어린 소년): 「하린 형! 저도요!」
  037: 하린 웃으며 착지: 「10년 후에 물어봐라, 관창아.」
  038: 관창 팔짱 끼고 뾰로통한 표정
  039: 하린 웃음 — 밝은 장면
  040: 김유신 등장 (멀리서 걸어옴)
  041: 김유신 진지한 표정: 「하린.」
  042: 하린 자세 바로 잡음
  043: 김유신: 「북쪽에서 소식이 왔다.」
  044: 하린 눈빛 변화 — 진지해짐
  045: 먼 곳 바라보는 하린

[컷 046~060] — 니문 파트 + 4인 교차
  046: 장소 전환: [낙동강 변 / 같은 날 / 황혼]
  047: 낙동강 전경 — 노을 (황토색)
  048: 니문 — 강가 돌 위 가야금 연주 (눈 감음)
  049: 가야금 현 클로즈업
  050: 어부 지나가다 멈춤: 「젊은 사람이 뭘 하는 거요?」
  051: 니문 눈 뜨지 않고: 「기억하는 중입니다.」
  052: 어부: 「뭘요?」
  053: 니문 연주 멈춤, 눈 뜸
  054: 니문 표정 (잠깐 생각): 「…아직 모르겠습니다.」
  055: 가야금 현 하나 끊어짐
  056: 니문 끊어진 현 바라봄
  057: 니문 혼잣말 (작은 글씨): 「나라는 없지만 소리는 있다.」

  058: 4인 교차 편집 시작
    [좌상] 고루: 강을 바라봄
    [우상] 아랑: 자수 한 땀
    [좌하] 하린: 활 당기기
    [우하] 니문: 끊어진 현 묶기

  059: 내레이션: 「그날 밤, 네 개의 강이 흘렀다.」
  060: 살수강 야경 + 내레이션: 「그들은 아직 서로를 몰랐다.」
       다음 화 예고: 「EP.02 — 을지문덕의 명령」
```

## 시각 연출 가이드

```
왕국별 칸 테두리:
  고구려 씬: 철회색 굵은 테두리
  백제 씬: 황금색 얇은 테두리
  신라 씬: 금빛 중간 테두리
  가야 씬: 황토색 자연스러운 테두리

색보정 톤:
  고구려: 차갑고 어두운 청회 톤
  백제: 따뜻하고 황금빛 톤
  신라: 밝고 금빛-주황 톤
  가야: 황토·자연 온도

효과선 사용:
  전투 타격: 속도선 + 충격파
  감정 클로즈업: 집중선
  자연 장면: 효과선 없음 (여백)
  금지: 번쩍이는 빛 효과 남발
```
