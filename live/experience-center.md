## 체험관 전략 개요

```
삼국(三國) 체험관 목표:
「역사를 보는 것이 아니라, 역사 속에 들어가는 경험」

체험관 라인업:
① 플래그십 체험관: 「삼국(三國) 월드」— 서울 (메인)
② 지역 체험관: 부산·대전·경주 (순회)
③ 팝업 체험관: 이벤트 연동 (드라마 방영·게임 출시 시즌)
④ 해외 팝업: 도쿄·방콕·뉴욕 (글로벌 확장)

운영 형태:
티켓 입장 (예약제 + 현장 판매)
왕국별 테마 존 + VR/AR 인터랙티브
체험관 내 굿즈 샵 + 왕국별 테마 카페
```

## 플래그십 체험관 — 「삼국(三國) 월드」

### 시설 개요

```
위치: 서울 (용산·강남·잠실 후보지 검토)
규모: 연면적 3,000m² (약 900평)
층수: 2층 구성
수용 인원: 회차당 최대 300명
운영 시간: 10:00~21:00 (연중무휴)
입장료:
  성인: 28,000원
  청소년: 22,000원
  어린이: 16,000원
  가족 패키지 (4인): 80,000원
```

### 존 구성 (Zone Map)

```
1층:
[A] 오프닝 홀 — 「강이 시작되는 곳」
[B] 고구려 존 — 「평양성·살수」
[C] 백제 존 — 「사비성·문서관」

2층:
[D] 신라 존 — 「서라벌·첨성대」
[E] 가야 존 — 「낙동강·가야금」
[F] 메인 이벤트 홀 — 「강은 기억한다」
[G] 굿즈 샵 + 왕국 카페
```

---

### Zone A — 오프닝 홀

```
콘셉트: 「4강이 하나의 바다로 흐른다」

시설:
메인 스크린: 15m × 6m LED 파노라마 월
  - 4강(대동강·백마강·형산강·낙동강) 흐르는 영상 (루프)
  - 입장 시 4왕국 테마 음악 오케스트라 버전 재생

왕국 선택 키오스크:
4개 터치스크린 → 「나의 왕국 선택」
입장 팔찌: 왕국별 컬러 LED 팔찌 (체험관 내 상호작용)
  - 고구려: 암청 (#2F4F7F)
  - 백제: 웜 골드 (#B8960C)
  - 신라: 황금 (#FFD700)
  - 가야: 토황 (#C8A96E)

인터랙션:
팔찌 → 각 존 진입 시 자동 인식
  해당 왕국 존에서 보너스 콘텐츠 활성화
  타 왕국 존에서도 기본 체험 가능
```

---

### Zone B — 고구려 존

```
콘셉트: 「안시성 수비대가 되어라」

주요 체험 시설:

① 살수대첩 VR 체험 (최대 인원 8명):
장비: 오큘러스 Quest Pro 개조 기기
경험: 612년 살수 강변 → 수나라 군대 접근 → 물 방류 순간
시간: 8분
가격: 별도 8,000원

② 성벽 등반 체험:
실제 화강암 질감 인공 암벽 (높이 4m)
안전 장비 착용 후 안시성 성벽 재현 구조물 등반
완등 시: 「안시성 수비대」디지털 배지 발급

③ 개마무사 코스튬 포토존:
실제 찰갑 재현 코스튬 착용 (경량화)
고구려 성벽 배경 포토 포인트
즉석 인화 서비스 (5,000원)

④ 고루 AI 챗봇 스탠드:
터치스크린 + 스피커
고루 AI와 역사 대화 (ai-chatbot.md 연동)
게임 가챠 쿠폰 교환 기능
```

---

### Zone C — 백제 존

```
콘셉트: 「아랑의 문서관에서 기록하라」

주요 체험 시설:

① 문서관 재현 방:
실제 두루마리·붓·먹 체험
족자 직접 쓰기 (한자 1구절 필사)
완성 족자: 롤 포장 선물 (굿즈 포함)

② 백마강 AR 체험:
스마트폰 AR 앱 → 백마강 수면 파노라마 활성화
낙화암 절벽 원경 + 봄꽃 AR 이펙트
SNS 공유 기능 내장

③ 백제 음식 체험 카페 (Zone G 연동):
백제 고증 음식: 쌀밥·어물·쑥차 세트
식기: 백제 토기 복원 재현 용기
아랑 메뉴: 「사관의 밥상」세트 (18,000원)

④ 아랑 기록 챌린지:
터치패드로 아랑 필체 모사 게임
상위 10% → 「백제 사관」칭호 + 쿠폰
```

---

### Zone D — 신라 존

```
콘셉트: 「첨성대에서 별을 읽어라」

주요 체험 시설:

① 첨성대 1/5 스케일 재현 구조물:
외부: 화강암 질감 재현 원통 구조물 (높이 6m)
내부: 나선형 계단 등반 가능
정상: 돔형 천장 — 별자리 프로젝션 (선덕여왕 예언 연출)

② 화랑 무예 체험:
원형 도장 (지름 10m)
폼 검 + 무예 기본 동작 30분 클래스
체험 후: 화랑 수료증 발급

③ 황금 유물 복원 전시:
신라 금관·금귀걸이·금팔찌 복원 레플리카 전시
AR 안경으로 착용 시뮬레이션
금관 기념 사진 (포토 서비스)

④ 선덕여왕 홀로그램 쇼:
10분짜리 홀로그램 공연
선덕여왕 3가지 예언 드라마타이즈
회차: 1시간마다 (별도 예약 필요)
```

---

### Zone E — 가야 존

```
콘셉트: 「니문의 가야금을 울려라」

주요 체험 시설:

① 가야금 체험 레슨:
전문 국악 강사 상주
기초 연주 30분 클래스 (4인 소그룹)
곡: 「강의 노래」기초 버전
완료 후: 가야금 픽 기념품 증정

② 제철 공방 체험 (미니):
실제 단조(鍛造) 시연 + 간이 체험
철제 키링 만들기 (15분 소요)
즉석 완성품 증정

③ 낙동강변 포토존:
자갈·갈대 재현 세트
니문 코스튬 착용 + 가야금 소품
에폭시 물결 바닥 포토 포인트

④ 12번째 악곡 감상 부스:
1인 개인 부스 (방음)
니문 AI 가야금 솔로 영상 4분 감상
감상 후: 음악 감상 노트 작성 → 전시 (원할 시)
```

### Zone F — 메인 이벤트 홀

```
콘셉트: 「4강이 하나의 바다로」

시설:
크기: 500m² (이벤트 홀)
수용: 최대 200명 착석

정기 공연 (1일 3회 — 11:00 / 14:00 / 17:00):

  - 4왕국 대표 씬 하이라이트 (영상 + 라이브 댄스)
  - 니문 가야금 라이브 연주 (국악 연주자 상주)
  - 피날레: 관객 참여 합창 「강은 기억한다」
입장: 체험관 입장권 포함 (무료 관람)

특별 이벤트 (월 1회):

### Zone G — 굿즈 샵 + 왕국 카페

```
굿즈 샵:
공식 굿즈 전 라인업 판매
체험관 독점 굿즈:
  - 왕국 팔찌 세트 (체험관 착용 기념)
  - 아랑 족자 (체험관 필사 완성품 공식화)
  - 안시성 성벽 미니어처 (체험관 한정)
  - 4왕국 도장 도서 스탬프 세트

왕국 카페 (4존 테마):
고구려 메뉴: 「북방의 기억」블루 라테 (암청 색)
백제 메뉴: 「사관의 밥상」전통 도시락 세트
신라 메뉴: 「황금의 빛」골드 에이드 + 경주법주 모형 병
가야 메뉴: 「강의 노래」낙동강 블루 스무디

포토 스팟: 각 왕국 메뉴 배경 포토 포인트 전용 공간
```

### 이머시브 존 상세 설계 (7존 구성안)

```
명칭: 삼국(三國) 이머시브 체험관
부제: 「강은 기억한다 — 7세기 한반도로의 여행」

규모 (상설관 기준):
  총 면적: 2,000㎡
  구성: 7개 존 (Zone 1~7)
  동시 수용: 150명
  관람 시간: 90~120분 권장

위치 전략:
  1호관: 서울 (국내 팬덤 핵심)
  2호관: 부산 (관광 연계)
  팝업: 경주·부여·고령 (역사 현지 연계)
  해외: 도쿄·방콕·LA (글로벌 순회)
```

#### Zone 1 — 「강의 시작」(입장 로비)

```
면적: 200㎡
테마: 한반도 강 조감 + 시대 소개

설치물:
  ① 대형 LED 강물 바닥 (관람객이 강 위를 걷는 느낌)
  ② 천장 미디어아트 — 612~676년 타임라인 시각화
  ③ 4인 주인공 실루엣 캐릭터 홀로그램 (2m 높이)

인터랙티브:
  입장 시 팔찌 지급 → 왕국 배정 (RFID 연동)
  배정 왕국에 따라 이후 존 일부 내용 달라짐

BGM: 「기억의 강」가야금 버전 앰비언스
조명: 은청빛 강물 반사 조명
```

#### Zone 2 — 「고구려의 철」

```
면적: 280㎡ / 테마: 요동 평야 + 살수 전장

공간 구성:
  ① 안시성 성벽 재현 세트 (실물 크기 일부)
  ② 살수대첩 파노라마 — 270도 스크린
  ③ 고구려 철기 전시 (고증 복원품)
  ④ 을지문덕 전략실 재현

체험:
  살수 수문 개방 체험 (미니 수력 시뮬레이션)
  삼족오 도장 찍기 (참여형 공예)
  철기 제작 영상 VR 체험 (5분)

색채 & 조명: 청람 (#2F4F7F) 기조 + 봉화 불빛 연출
BGM: 「철과 하늘」고구려 테마
```

#### Zone 3 — 「백제의 연등」

```
면적: 300㎡ / 테마: 사비성 + 연등 야경

공간 구성:
  ① 사비성 연등 터널 (실물 연등 300개+ 설치)
  ② 백마강 미니어처 (3m 규모 디오라마)
  ③ 아랑 죽간 기록실 재현
  ④ 금동대향로 복원품 전시 (국립박물관 협력)

체험:
  죽간에 소원 글씨 쓰기 (털붓 + 먹 체험)
  연등 직접 점등 및 띄우기 (소형 LED 연등)
  백제 문양 탁본 체험

향기 연동:
  존 전체 백합·향나무 향기 디퓨저 운영
  「연등의 향기」컨셉 — AR 필터(WLD-002)와 연동

색채 & 조명: 황금 (#B8960C) + 연등 오렌지 따뜻한 조명
BGM: 「연등과 죽간」백제 테마
```

#### Zone 4 — 「신라의 황금」

```
면적: 280㎡ / 테마: 경주 황룡사 + 화랑 훈련장

공간 구성:
  ① 황룡사 9층 목탑 미니어처 (5m 높이)
  ② 화랑 훈련장 세트 (활터 미니 사이즈)
  ③ 신라 금관 복원품 전시 (국보급 고증)
  ④ 첨성대 모형 + 별자리 천장

체험:
  화랑 활쏘기 체험 (어린이용 소프트 화살)
  신라 금관 착용 포토존
  「화랑 오계」암송 인터랙티브 패널

색채 & 조명: 금색 (#FFD700) + 황금빛 스포트라이트
BGM: 「황금 들판」신라 테마
