## 삼국시대 해상 개요

```
삼국 해상 활동 범위:
  고구려: 서해 북부 + 요동 해안 (방어적)
  백제: 서해 전역 + 남해 + 왜(일본) 항로 (교역 주도)
  신라: 동해 + 남해 동부 (점진적 확장)
  가야: 남해 + 대한해협 + 왜 교역 (철정 수출)

핵심 해상 루트:
  백제-왜 항로: 사비(부여) → 남해 → 대한해협 → 규슈(九州)
  당-신라 항로: 산동반도 → 서해 → 서해안 상륙
  고구려-당 항로: 요동 해안 → 발해만 (전략 요충)
```

## 삼국시대 선박 종류

### 고구려 선박

```
주요 용도: 방어·병력 수송 (교역 비중 낮음)

① 병선(兵船):
  길이: 약 15~25m 추정
  구조: 평저선(平底船) — 강·하구 운항 적합
  노: 양현 8~16개 노
  무장: 선수 충각(衝角) + 궁수 배치
  특징: 압록강·대동강 수계 특화

② 수군 전술:
  강을 방어선으로 활용 (바다 전투 비선호)
  수상 요새 = 강변 성곽 + 수군 연계
```

### 백제 선박

```
주요 용도: 교역·외교·군사 (해양국가 성격)

① 교역선(交易船) — 백제의 특기:
  길이: 약 20~35m
  구조: 첨저선(尖底船) — 먼 바다 항해 적합
  돛: 사각 돛 (중국식) + 삼각 돛 (왜식) 혼용
  적재량: 약 20~50톤
  특징: 도기·비단·불교 문물 수송

② 사신선(使臣船):
  외교 사절단 전용
  화려한 장식 (백제 문화 과시)
  길이: 약 25m, 속도 우선

③ 수군 전선(戰船):
  660년 기벌포 전투 참전 함선
  무장: 투석기 + 불화살 장비
  당나라 수군에 격파됨 (역사 사실)
```

### 신라 선박

```
초기: 해상 활동 제한적
후기 (나당 전쟁 이후): 급격한 수군 강화

① 기벌포 전투 함선 (676년):
  신라 수군, 당 수군 격파에 사용
  형태: 백제 조선 기술 흡수 + 자체 발전
  특징: 금강 하구 지형 활용 → 기동전

② 해상 척후선:
  작고 빠른 배 → 정보 수집
  동해 연안 초계 (왜구 방어)
```

### 가야 선박

```
해양 교역 왕국 = 조선 기술 높은 수준

① 철정 수출선:
  길이: 약 15~20m
  특징: 무거운 철 적재 → 넓고 안정적 선체
  항로: 김해 → 대한해협 → 규슈(博多)

② 소형 연안 어선:
  낙동강 하류 연안 활동
  교역·어업 겸용

가야 조선 특기:
  철제 못(釘) 사용 → 선체 내구성 강화
  일본 조선 기술에 영향 (야마토 선박 발전 기여)
```

## 항해 기술

### 항법

```
천문 항법:
  북극성 기준 위치 파악
  별자리·달 위치로 방향 확인
  삼국시대 천문 관측 수준 = 높음 (첨성대 존재)

연안 항법:
  주요 항로: 육지 시야 범위 내 항해
  랜드마크: 특징적 해안 지형 기억
  봉수대 연계: 해안 봉화망으로 위험 신호

조류·바람 활용:
  서해: 북서풍 (겨울) → 남하 유리
         남동풍 (여름) → 북상 유리
  백제-왜 항로 계절 운항:
    왕래 최적기: 봄(5월)·가을(9월)
    위험기: 태풍 시즌 (7~9월)
```

### 항구·포구

```
주요 항구:
  백제:
    사비 포구 (금강 하구) — 대왜 교역 허브
    탄현 포구 — 서해 수군 기지
  가야:
    금관가야 포구 (현 김해) — 대한해협 교역
    아라가야 포구 (현 함안) — 남해 교역
  신라:
    울산 포구 — 동해 거점
    기벌포 (현 서천) — 서해 수군 기지 (후기)

항구 시설:
  목재 잔교 (棧橋) — 선박 계류
  조선소: 대형 함선 건조·수리
  창고: 교역품·군수물자 보관
  봉수대: 함선 입출항 신호
```

## 해상 전투 전술

### 삼국시대 수전(水戰) 방식

```
① 충각전(衝角戰):
  선수 철제 충각으로 적선 충돌·파괴
  고속 접근 → 충격 → 이탈 반복
  한계: 속도 느린 대형 선박에 비효율

② 접현전(接舷戰):
  두 선박 붙인 후 백병전
  삼국시대 주류 수전 방식
  궁수·창병 선제 제압 후 돌격

③ 화공(火攻):
  불화살·불항아리 투척
  풍향 파악 필수 (역풍 시 역효과)
  백제 수군 화공 기술 발전

④ 기동전:
  수로 지형 활용 — 좁은 수로에서 적 분리
  기벌포 전투 핵심 전술 (신라)
  조류·바람 맞춤 타이밍 공격

⑤ 보급 차단:
  적 함선 보급선 분리 → 고립
  을지문덕 육상 전략과 유사 원리
```

### 기벌포 전투 분석 (676년)

```
배경:
  금강(錦江) 하구 — 신라가 주요 지형 활용
  당 수군: 대형 선박 중심 (서해 외해에서 유리)
  신라 수군: 소형·기동성 선박 (내수 지형 유리)

신라 전술:
  ① 금강 하구 수로 복잡한 지형 활용
  ② 썰물 시 당 대형선 기동력 저하 유인
  ③ 소형 선박으로 포위·화공
  ④ 22전 22승 — 압도적 승리 (삼국사기 기록)

의의:
  당나라 한반도 진출 최종 저지
  신라 삼국통일 완성의 마지막 전투
```

## 창작 활용 가이드

### 드라마·소설 묘사

```
고증 허용 묘사:
  ✅ 백제 교역선 — 금강에서 출발하는 장면
  ✅ 가야금 악사 니문 = 가야 교역선 동승 (역사적 자연스러움)
  ✅ 아랑 = 백제 수군 출항 장면 기록
  ✅ 기벌포 전투 = 하린 수군 참전 장면

금지 묘사:
  ❌ 대형 갤리선 (지중해식) — 동아시아 비해당
  ❌ 돛 없는 순수 노젓기 대형 전선 (역사 과소)
  ❌ 나침반 항법 (삼국시대 미도입 — 송대 이후)
  ❌ 화약 무기 선박 탑재 (삼국시대 화약 없음)

아랑 서사 연결:
  성충의 경고: 「기벌포를 지켜라」
  = 금강 하구 수군 방어선의 전략적 중요성
  = 아랑 기록물 + 하린 실행 → 역사 연결
```

### 게임 연동

```
수군 유닛 설계:
  백제 교역선 → 교역 수입 생성 유닛
  신라 척후선 → 정보 수집 특화 유닛
  가야 철정선 → 자원 수송 특화 유닛
  고구려 수군 → 강 방어 특화 (Zone 2)

기벌포 해전 이벤트:
  676년 자동 발동
  금강 하구 특수 지형 타일
  썰물 타이밍 시스템 연동
```
