# 게임 아트 바이블 — 삼국(三國) IP

**참조 문서**: `gdd-three-kingdoms.md`, `mobile-game-design.md`, `character-design-guide.md`, `color-palette-guide.md`
**게임 아트 디렉터 원칙**: "게임 속 삼국은 역사 교과서가 아니라 살아있는 세계여야 한다. 디테일이 몰입을 만든다."

---

## 게임 아트 총괄 방향

### 비주얼 스타일 정의

**스타일**: 역사 고증 기반 세미-리얼리즘
- 드라마 비주얼과 통일성 유지 (같은 IP의 같은 세계)
- 게임 가독성을 위한 적절한 양식화 (과장·단순화)
- 모바일 최적화: 소형 화면에서도 왕국별 식별 가능

**참조 스타일**:
```
캐릭터: 총력전 삼국지·라이즈 오브 킹덤즈 (역사 세미리얼)
환경: 어쌔신 크리드: 오리진 (역사 환경 고증)
UI: 클래시 오브 클랜 (직관적·화려한 게임 UI)
이펙트: 원신 (화려한 스킬 이펙트·동양적 감성)
```

## 캐릭터 아트 가이드

### 영웅 카드 아트 규격

| 등급 | 아트 스타일 | 배경 | 이펙트 |
|------|-----------|------|--------|
| ★★★★★ 전설 | 풀 일러스트 (드라마틱 포즈) | 왕국 시그니처 배경 | 빛 파티클 + 에픽 프레임 |
| ★★★★ 영웅 | 반신 일러스트 | 단색 그라데이션 | 소형 이펙트 |
| ★★★ 희귀 | 흉상 일러스트 | 질감 배경 | 없음 |
| ★★ 고급 | 픽토그램 스타일 | 왕국 색상 배경 | 없음 |
| ★ 일반 | 아이콘 스타일 | 회색 배경 | 없음 |

### 전설 영웅 아트 디렉션

**광개토대왕**
```
포즈: 말 위에서 검을 앞으로 내뻗는 정복자 포즈
의상: 최고급 철갑 + 삼족오 문양 망토
배경: 요동 벌판·석양·먼지 구름
색조: 철흑·혈홍·황금 (소량)
표정: 냉철하고 절대적인 자신감
이펙트: 붉은 에너지 파동 + 삼족오 실루엣
```

**선덕여왕**
```
포즈: 첨성대 앞 별을 가리키는 우아한 자세
의상: 신라 왕족 예복 + 금관
배경: 밤하늘·별자리·황룡사 실루엣
색조: 황금·청·밤하늘
표정: 신비롭고 지혜로운 미소
이펙트: 별빛 파티클 + 황금 오라
```

**계백**
```
포즈: 피 묻은 검을 든 채 홀로 서있는 뒷모습
의상: 손상된 백제 장군 갑옷
배경: 황산벌·황혼·불길
색조: 황혼주·탄흑·혈홍
표정: (뒷모습이므로) 어깨의 무게로 감정 전달
이펙트: 비장한 불꽃 + 황혼 역광
특이사항: 전설 영웅 중 유일한 뒷모습 — 비극성 극대화
```

**우륵**
```
포즈: 앉아서 가야금을 연주하는 평화로운 자세
의상: 가야 악사 복식·소박하고 단정
배경: 멸망한 가야의 폐허·가야금 선율 시각화
색조: 탄흑·해변사·청동
표정: 슬픔과 평온이 공존
이펙트: 가야금 현에서 흘러나오는 음표·빛
```

## 환경 아트 가이드

### 왕국 도시 비주얼

**고구려 평양성**
```
전체 톤: 어둡고 웅장·수직성 강조
건축: 화강암·목재·철제 장식
랜드마크: 대성산성·안학궁
특이 요소: 성벽 위 불꽃·봉화
계절 기본: 늦가을~겨울 (황엽+설경)
앰비언스: 바람 파티클 + 낙엽
```

**백제 사비성**
```
전체 톤: 밝고 우아·수평적 배치
건축: 목재·흰 회벽·기와
랜드마크: 정림사지 5층석탑·부소산성
특이 요소: 백마강 반영·연꽃 연못
계절 기본: 봄~여름 (녹색 풍요)
앰비언스: 물 반짝임 + 꽃잎 파티클
```

**신라 서라벌**
```
전체 톤: 황금빛·성스럽고 열린
건축: 화강암·금박 장식
랜드마크: 황룡사 9층탑·첨성대·대릉원
특이 요소: 무덤 실루엣·금관 장식
계절 기본: 맑은 여름·황금 들판
앰비언스: 황금 빛 파티클 + 반딧불 (야간)
```

**가야 금관가야**
```
전체 톤: 역동적·낮고 실용적
건축: 목재·철제·흙벽
랜드마크: 수로왕릉·제철장·항구
특이 요소: 용광로 불빛·철정 쌓인 창고
계절 기본: 뜨거운 여름·항구 풍경
앰비언스: 연기 파티클 + 불꽃 반짝임
```

## UI/UX 아트 가이드

### 메인 화면 디자인

```
배경: 선택한 왕국의 수도 전경 (시간대 변화)
UI 프레임: 왕국별 문양 차별화
  고구려: 삼족오 문양 철제 프레임
  백제: 봉황 문양 금박 프레임
  신라: 금관 문양 황금 프레임
  가야: 철정 문양 철제 프레임
폰트: 전통 한자 기반 커스텀 폰트
색상: 왕국별 팔레트 자동 적용
```

### 전투 UI

| 요소 | 디자인 |
|------|--------|
| HP 바 | 왕국색 + 고증 문양 테두리 |
| 스킬 아이콘 | 각 영웅 전용 한자·심볼 |
| 미니맵 | 삼국 지도 스타일·한지 질감 |
| 전투 로그 | 붓글씨 폰트·세로 쓰기 |
| 승리 화면 | 왕국 시그니처 컬러 폭죽 |

### 영웅 상세 화면

```
레이아웃:
- 좌측: 영웅 풀 일러스트 (터치로 대사·모션)
- 우측: 능력치·스킬·배경 이야기
- 하단: 강화·각성·장비 버튼

배경: 영웅 소속 왕국 배경 (패럴렉스 효과)
대사 트리거: 영웅 터치 시 특유의 대사 재생
  광개토대왕: "더 넓은 땅을 원한다."
  선덕여왕: "이미 알고 있었다."
  우륵: "소리가 전부다."
```

## 이펙트 아트 가이드

### 스킬 이펙트 왕국별 특성

**고구려 스킬 이펙트**
```
색상: 혈홍·철흑·불꽃황
스타일: 폭발적·날카로운 에너지
파티클: 붉은 에너지 파편 + 삼족오 실루엣
사운드 연동: 거문고 저음 + 타악
예시: 광개토대왕 궁극기 — 붉은 기마대 에너지 파동
```

**백제 스킬 이펙트**
```
색상: 비취록·백토·황금
스타일: 우아하고 흐르는 에너지
파티클: 꽃잎·물결·반짝임
예시: 소서노 스킬 — 금빛 교역 네트워크 시각화
```

**신라 스킬 이펙트**
```
색상: 황금·청·별빛
스타일: 신성한 빛·하늘에서 내려오는 에너지
파티클: 별빛 파티클·금관 문양
예시: 선덕여왕 궁극기 — 별빛이 적을 감싸는 예언
```

**가야 스킬 이펙트**
```
색상: 불꽃·철색·토적
스타일: 날것의 에너지·용광로 폭발
파티클: 불꽃 파편·금속 파편
예시: 우륵 스킬 — 가야금 현이 빛의 파동으로 적 관통
```

## 기술 아트 규격

### 모바일 최적화

| 항목 | 기준 |
|------|------|
| 캐릭터 폴리곤 | 영웅: 5,000~8,000 / 병사: 500~1,000 |
| 텍스처 해상도 | 영웅: 1024×1024 / 배경: 2048×2048 |
| 드로우콜 | 화면당 최대 150 |
| 타깃 FPS | 60fps (고사양) / 30fps (저사양) |
| 배터리 최적화 | 열 감지 시 자동 품질 하향 |

### 플랫폼별 그래픽 설정

| 설정 | 저사양 | 중사양 | 고사양 |
|------|--------|--------|--------|
| 해상도 | 720p | 1080p | 1440p |
| 이펙트 | 단순화 | 표준 | 전체 |
| 군중 | 최소 | 중간 | 최대 |
| 그림자 | 없음 | 단순 | 풀 다이나믹 |

## 아트 파이프라인

```
컨셉 아트 → 3D 모델링 → 텍스처링 → 리깅
     ↓              ↓            ↓          ↓
아트 디렉터 검토  역사 자문 검토  색보정   애니메이션
     ↓
게임 엔진 (Unity/Unreal) 임포트
     ↓
인게임 테스트 → 최적화 → QA → 출시
```

**사용 소프트웨어**:
- 컨셉 아트: Photoshop·Procreate
- 3D: Blender·Maya·ZBrush
- 텍스처: Substance Painter
- 엔진: Unity (모바일) / Unreal 5 (PC·콘솔)
- 이펙트: VFX Graph (Unity)·Niagara (Unreal)
