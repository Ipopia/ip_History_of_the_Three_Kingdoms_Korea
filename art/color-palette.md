## 색채 철학

```
핵심 원칙:
  「왕국의 색이 곧 그 왕국의 영혼이다」

색채 역할:
  정체성 — 왕국을 색으로 즉시 식별
  감정 — 장면의 정서를 색으로 전달
  서사 — 색의 변화로 캐릭터 아크 표현
  일관성 — 전 매체·전 팀 동일 팔레트 적용

참조:
  cinematography.md — 드라마 DI 색보정 연동
  character-design-sheets.md — 캐릭터 복식 색상
  brand-identity.md — 마케팅 브랜드 색상
```

## 시즌별 색채 변화

```
시즌 1 「만남과 연대」(AD 600~612):
  전반: 각 왕국 PRIMARY 색상 선명
  후반: 수나라 침략 → 냉색 오버레이 점증
  살수대첩: 고구려 청람 + 강물 + 혈흔 적색

시즌 2 「균열과 선택」(AD 630~655):
  전반: 나당연합 협상 → 신라 황금 강세
  중반: 가야 서사 황토빛 증가 (니문 서사 집중)
  후반: 4인 분열 → 채도 저하 (회색 오버레이)

시즌 3 「완성과 기억」(AD 660~676):
  백제 멸망 씬: 황금 → 재색으로 페이드
  고구려 멸망: 청람 소등 (조명 점진 어두워짐)
  나당전쟁: 신라 황금 + 당나라 추가 적색
  최종 676: 4색 혼합 → 흰빛 (통합·기억)
```

## 매체별 색채 적용 기준

### 드라마·영상

```
DI 색보정:
  소프트웨어: DaVinci Resolve
  마스터: HDR10 (P3 색역)
  납품: SDR (Rec.709) 동시

왕국 씬 룩 (LUT 별도 제작):
  고구려 LUT: 탈채도 + 청람 쉬프트
  백제 LUT: 황금 채도 부스트 + 따뜻한 미드톤
  신라 LUT: 높은 대비 + 황금 하이라이트
  가야 LUT: 낮은 채도 + 황토 쉬프트

교차 씬 (왕국 혼합):
  점진적 LUT 블렌드
  중립 베이스 → 목적지 왕국 색으로 전환
```

### 웹툰·일러스트

```
색공간: sRGB (모니터 최적화)
해상도: 300dpi 인쇄 / 72dpi 웹 동시

웹툰 색채 방침:
  배경: 왕국 색조 유지 (낮은 채도)
  캐릭터: 선명한 왕국 PRIMARY 색상
  액션 이펙트: ACCENT 색상 집중 활용
  흑백 버전: 왕국 구분 명암으로만 표현 가능

인쇄 색상:
  CMYK 변환 시 HEX 직변환 금지
  → art-bible.md CMYK 코드 사용 필수
```

### 게임 UI

```
게임 색상 적용 (게임/art-style.md 연동):
  UI 배경: NEUTRAL-LIGHT (#F0EDE8)
  왕국 선택 화면: 왕국 PRIMARY 색상
  전투 UI: 고대비 + ACCENT 색상
  텍스트: 배경 대비 4.5:1 이상 필수

아이콘 컬러:
  단계별: 비활성 NEUTRAL-MID → 활성 PRIMARY
  경고: #CC2200 (화랑 적)
  성공: #2E7D32 (자연 녹색 — 통합 색상)
```

## 색채 금지 사항

```
절대 금지:
  ① 왕국 메인 컬러 혼용 (고구려 씬에 신라 황금 적용 등)
  ② HEX 근사값 임의 사용 (반드시 공식 코드 사용)
  ③ 채도 과도 부스트 (형광빛 = 역사 IP 무게감 파괴)
  ④ 배경·텍스트 색상 대비 3:1 미만 (가독성 기준 위반)
  ⑤ 4왕국 외 임의 색상 도입 (QA-CONTINUITY 사전 승인 필요)

주의 사항:
  인쇄물: sRGB → CMYK 변환 시 반드시 실물 색교 확인
  모바일: sRGB와 P3 색역 차이 확인 (모바일 디바이스 테스트)
  다크모드: 배경 변경 시 텍스트 색상 재검토
```

## 색상 접근성 (Accessibility)

```
색맹 고려:
  적녹색맹: 고구려 청람 + 신라 황금 → 명도 차이로 구분 가능
  청황색맹: 왕국 아이콘에 텍스트 레이블 병행 필수
  → Coblis 색맹 시뮬레이터로 전 에셋 검증

명도 대비:
  텍스트/배경 최소 4.5:1 (WCAG AA 기준)
  대형 텍스트: 3:1
  UI 경계선: 3:1
```
