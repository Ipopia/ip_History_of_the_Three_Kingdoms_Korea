## 군사 기술 개요

```
시대 범위: AD 580~676 (삼국 말기 ~ 통일 직전)
기술 수준:
  철기 기술: 동아시아 최고 수준 (가야 철정 기반)
  공성 기술: 중국 영향 + 독자 발전
  조선 기술: 백제 황해 교역로 기반 선진 수준
  통신 기술: 봉수 체계 (본 문서 별도 섹션)

고증 기준:
  삼국사기·삼국유사 기록
  ADV-MILITARY 자문 (전쟁·무기)
  ADV-ARTS 자문 (금속공예·조선)
  출토 유물 실측 데이터
```

## 왕국별 철기 기술

### 고구려 — 철의 전사 국가

```
제철 중심지:
  요동 평원 철광 지대 (현 중국 랴오닝성)
  압록강 유역 제철 취락

핵심 철기 생산:
  철갑 (鐵甲):
    개마무사 전신 철갑 — 동아시아 최중장 기병 갑옷
    판갑 + 찰갑 혼용 구조
    말 갑옷(마갑): 머리·목·몸통·엉덩이 분리 제작
    중량: 기병 갑옷 20~25kg + 마갑 15~20kg (추정)

  철검·철모:
    환두대도(環頭大刀): 고구려 상징 도검
      길이 80~100cm / 외날 / 손잡이 환두 문양
    철모(鐵矛): 보병 창 (길이 200~250cm)
    철촉(鐵鏃): 철제 화살촉 (다양한 형태)

  생산 규모:
    안시성 포위전(645년) 시 자체 무기 생산 확인
    철기 수출: 왜(倭)에 제철 기술 전수 기록

IP 서사 활용:
  고루의 환두대도 = 개인 서사 오브젝트
  개마무사 등장 씬: 철갑 무게·소리 상세 묘사
```

### 백제 — 청동과 금속공예의 나라

```
금속공예 특성:
  고품질 청동기 + 금세공 기술
  불교 예술품 제작 (금동대향로 등)
  중국 남조 기술 수용 + 독자 발전

군사 철기:
  백제 단검: 비교적 가벼운 단도 계열
  환두대도: 고구려보다 세련된 장식성
  철화살촉: 대량 생산 체계

수군 관련 기술:
  조선 기술: 황해 교역로 운용 위한 선진 기술
  대형 전함 (평저선 계열): 황해 항행 최적화
  거도(巨刀)형 함선 무장
  투석기 탑재 대형 전함 건조 기록 (백강 전투 관련)

IP 서사 활용:
  아랑의 역할: 백제 무기 제작 기록 보관
  연등 행사 = 청동 장식 문화의 절정 표현
```

### 신라 — 화랑 무장 체계

```
철기 특성:
  가야 합병(562년) 이후 가야 철기 기술 흡수
  낙동강 유역 제철 기반 강화
  중국 당나라 무기 수입 + 자체 생산 병행

화랑 전용 무장:
  화랑 환두대도: 신라 특유 장식 (육두품 이상 착용)
  단궁(短弓): 신라 화랑 필수 무기
    소형 복합궁 구조
    사거리: 150~200m (추정)
    기마 사격에 적합한 경량 설계
    ※ 각궁(角弓)/맥궁(貊弓)은 고구려 고유 무기 — 본 문서 고구려 섹션 참조
  철제 갑옷: 소찰갑 + 찰갑 병용

나당전쟁 무기 업그레이드:
  당나라 전리품 흡수 → 무기 다양화
  매소성 전투(675) 전마 30,380필 노획 = 대규모 기병 전력 강화

IP 서사 활용:
  하린의 단궁: 활쏘기 씬 고증 기반 묘사
  화랑 장비 일관성: 드라마·게임·웹툰 동일 규격
```

### 가야 — 철정(鐵鋌)의 왕국

```
핵심 기술:
  가야 제철: 한반도 최고 품질 순철 생산
  철정(鐵鋌): 화폐·교역 단위로도 기능한 철 덩어리
  단야 기술: 철을 두드려 성형하는 단조 기술 최고 수준

수출 규모:
  낙동강 교역로: 가야 철정 → 왜(倭) 규슈 수출
  황해 교역로: 일부 철기 백제 경유 중국 수출
  가야 멸망 후: 신라·일본이 가야 철기 기술 흡수

무기 특성:
  가야 철제 갑옷: 판갑(板甲) 계열 (고분 출토)
  가야 단검: 독특한 곡선 형태 (고령 출토 유물)
  가야 금관: 금공예 + 제철 기술의 집결

IP 서사 활용:
  니문과 철: 가야금 현(弦) = 금속 + 음악의 결합
  가야 멸망 = 철기 기술 문명의 소멸 상징
```

## 공성 장비

```
공격 측 장비:
  운제(雲梯): 이동식 사다리차 (성벽 등반)
    높이: 10~15m (대형 성벽 대응)
    구조: 목재 바퀴 + 사다리 + 방패 조합
    IP 활용: 안시성 전투 씬 핵심 장비

  충차(衝車): 성문 파괴 목적 충격 장비
    소재: 두꺼운 참나무 + 철제 충격부
    운용: 30~50명 동시 추진
    IP 활용: 살수대첩 배경 수나라 장비로 등장

  투석기(投石機): 돌·불덩이 원거리 발사
    형태: 사초(杆槳式) 투석기 (중국 기원)
    사거리: 100~200m
    탑재체: 석탄·기름 봉 (화공용)

  토산(土山): 성벽 높이까지 흙 쌓기
    안시성 전투(645) 실제 기록 — 당이 토산 축조
    IP 활용: 안시성 씬 핵심 (토산 붕괴 결정적 역전)

방어 측 장비:
  쇠뇌(弩): 기계식 연발 석궁
  기름 가마: 성벽 위 끓는 기름 투하
  투석 요충: 성벽 위 투석 구멍 설계
  목책: 성 외곽 목제 방어선
```

## 해상 군사 기술

```
삼국 함선 유형:

고구려:
  압록강·대동강 강선 (河船) 위주
  해전보다 강 방어 특화

백제:
  황해 항행 대형 전함
  평저선 + 첨저선 혼용
  무장: 투석기·궁병대·철제 충각

신라:
  기벌포 해전(676)에서 22연승 — 수군 최강 증명
  신라 전함: 당 함선보다 기동성 우위 (가설)
  서해·동해 양면 수군 운용

기벌포 해전 분석:
  신라 수군이 당 수군을 22번 연속 격파
  전술: 기습·야간 전투·조류 활용 추정
  IP 게임 활용: 22라운드 연속 해전 메커닉 (game/world-map.md)
```

## 통신 & 정보 기술

```
봉수(烽燧) 체계:
  고구려: 압록강 ~ 평양성 봉수 체계
    낮: 연기 (횟수로 신호)
    밤: 횃불 (횟수로 신호)
    전달 속도: 300km를 수 시간 내 전달 가능

  신라: 남해~경주 봉수망 (가장 조밀)
    당항성 ~ 경주 직통 라인 (당나라 연락용)

파발(擺撥) 체계:
  역참(驛站) 시스템 — 30~40리 간격
  기마 전령: 1일 300~400리 이동 가능
  문서 전달: 왁스 봉인 + 관인(官印) 필수

정보전 기술:
  간첩 (間諜): 타국 왕실 내부 침투
  귀화인 활용: 언어 능통자를 정보원으로
  상인·승려 위장: 공식 신분 활용한 정보 수집

IP 서사 활용:
  봉수 씬: 전쟁 긴박감 표현 핵심 도구
  아랑의 역할: 백제 외교 문서 = 정보 집결지
  communication-systems.md 연동 문서 참조
```
