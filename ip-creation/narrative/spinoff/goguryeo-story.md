## 스핀오프 개요

**제목**: 북방의 매 (北方의 鷹)
**영문 제목**: Eagle of the North
**배경 시기**: 391~413년 (광개토대왕 재위 22년)
**핵심 인물**: 광개토대왕 + 을지문덕 (선조) + 연개소문 (先祖)
**주제**: 정복자의 외로움, 제국의 무게, 강과 하늘 사이

```
스핀오프 포지션:
- 본편: 고구려 건국(주몽) → 전성기 → 멸망 통사
- 스핀오프: 광개토대왕 재위기 집중 서사
  (본편에서 압축 서술된 22년을 완전 전개)

독립 감상 가능:
- 본편 시청 없이도 완결된 서사
- 본편 시청자에게는 심화 콘텐츠
```

## 세계관 설정 (스핀오프 특화)

### 391년의 고구려

```
정치 상황:
- 광개토대왕 즉위 (18세)
- 선왕 고국양왕 급서 — 정치 공백
- 귀족 세력 (고씨·을씨) 견제
- 백제의 북진 압박 (한강 유역)

국제 정세:
- 중국: 동진(東晋) 약화 / 5호16국 혼란기
- 북방: 후연(後燕) — 모용씨 세력
- 남방: 백제 근초고왕 후손들의 팽창
- 왜(倭): 백제-왜 동맹 활성화

군사 역량:
- 고구려 군대: 추정 10~20만
- 주력: 철갑 기마병 (개마무사)
- 전략: 기동전 + 성곽전 병행
```

### 개마무사(鎧馬武士)

```
고구려의 핵심 군사력:
- 사람과 말 모두 철갑 착용
- 동시대 세계 최강 기병 전력 중 하나
- 속도와 충격력 — 적 진영 분쇄

장비:
말갑옷(馬甲): 철판 연결 — 신체 전면 보호
기사갑옷: 투구·흉갑·완갑·경갑 전신
무기: 장창(長槍) 주력 / 환두대도 보조

약점:
- 무게로 인한 기동성 제한
- 보급 의존 (철 소비량 막대)
- 평지 최강, 산악·수전 불리

창작 활용:
- 드라마: 개마무사 행진 장면 — 시각적 압도감
- 게임: 최강 기병 유닛 (제작 비용 최고)
- 웹툰: 평원 전투 클라이맥스 풀페이지
```

## 주요 인물 (스핀오프 전용)

### 광개토대왕 (廣開土大王)

```
본명: 담덕(談德)
생몰: 374~413년 (39세 사망)
재위: 391~413년

성격 설정:
- 겉: 차갑고 단호한 정복자
- 속: 제국의 무게를 홀로 짊어진 인간
- 모순: 전쟁을 혐오하지만 전쟁만이 고구려를 지킬 수 있음을 앎

핵심 대사:
"더 가라. 지평선이 끝날 때까지."
"나는 64개 성을 빼앗았다. 그리고 64개 성의 백성을 얻었다."
"왕이 죽으면 릉비가 남는다. 나는 릉비보다 나라를 남기고 싶다."

내면 갈등:
- 아들 장수왕의 그림자 — '내가 너무 많이 남긴 것인가'
- 고구려가 제국이 되면 고구려가 아닌 것인가
- 정복의 끝이 어디인지 — 지평선은 끝나지 않는다
```

### 고루(高婁) — 창작 인물

> **세계관 참고**: 이 고루(高婁)는 광개토대왕 시대(391~413년)의 인물로,
> 본편 주인공 고루(高流, 594년생, 612년 기준 18세)의 **선조**입니다.
> 고구려에서 무공을 세운 가문의 이름 '고루'가 대를 이어 사용되는 설정입니다.
> 한자가 다릅니다: 선조 高婁(높을 고, 별 루) / 후손 高流(높을 고, 흐를 류).

```
신분: 광개토대왕 직속 부관 (창작)
출신: 고구려 하급 귀족
역할: 대왕의 진심을 가장 가까이 보는 인물

성격:
- 충성스럽되 맹목적이지 않음
- 대왕에게 유일하게 직언
- 전쟁의 실상을 직접 경험하는 시점 인물

서사 기능:
- 광개토대왕의 내면을 독자에게 전달
- 전쟁의 인간적 비용을 보여주는 역할
- 마지막 화 — 대왕 임종 곁에 있는 유일한 인물
```

### 모용희(慕容熙) — 후연 황제

```
역사적 실존 인물
후연(後燕)의 마지막 황제 — 악명 높은 폭군

역할: 스핀오프 1부 주요 대립 인물
고구려-후연 전쟁 서사의 중심

성격 (창작 해석):
- 극단적 자기애 — 아름다움에 집착
- 전쟁을 예술처럼 여김
- 광개토와 대비 — 정복의 서로 다른 목적

역사 결말:
- 408년 부하들에게 살해
- 고구려의 요동 완전 장악
```

## 시즌 구성 (드라마 12부작)

### 1부 (1~3화): 18세의 왕

```
1화 — 즉위의 무게
내용:
- 고국양왕 임종 → 18세 담덕 즉위
- 귀족 세력의 견제
- 첫 정복 계획 — 백제 관미성(關彌城)

핵심 장면:
- 어린 왕이 왕좌에 앉는 순간
- 귀족들의 냉소 → 담덕의 눈
- 고루와의 첫 만남 — "당신은 왜 왕입니까?"

담덕: "왕이어서가 아니라 — 왕이어야 하기 때문이오."

2화 — 관미성의 함락
내용:
- 391년, 백제 관미성 공략
- 수륙 병진 작전
- 첫 대규모 전쟁 경험

역사 기록: "관미성은 사면이 절벽이고 바닷물로 둘러싸였다"
창작 해석: 물과 절벽 — 불가능한 성 → 기상천외한 우회 작전

3화 — 아신왕의 맹세
내용:
- 백제 아신왕 항복 — 영원한 신하 맹세
- 그러나 아신왕은 왜국에 지원 요청
- 광개토의 판단: "이 평화는 오래가지 않는다"
```

### 2부 (4~7화): 제국의 확장

```
4화 — 북방의 적
내용:
- 후연(後燕) 모용씨의 위협
- 광개토 vs 모용희 첫 충돌
- 요동(遼東) 진출 결정

5화 — 신라에서 온 요청
내용:
- 신라 실성왕, 왜구 침략 도움 요청
- 광개토의 판단: 신라를 돕는 대가
- 경자년 남정(南征) 결정 — 400년

6화 — 경자년 남정
내용:
- 5만 고구려군 남하
- 왜군 격퇴 — 신라 구원
- 가야까지 영향권 확대

역사 기록(릉비): "영락 10년 경자, 보병과 기병 5만 보내…"

7화 — 요동의 피
내용:
- 후연과 결전
- 요동성·현도성 탈환
- 모용희와의 대면
```

### 3부 (8~10화): 지평선의 끝

```
8화 — 64개 성
내용:
- 후연 완전 격파 (407년 이후)
- 요동 전체 장악
- 릉비 건립 계획 논의

9화 — 대왕의 병
내용:

고루: "대왕, 후회하십니까."
광개토: "…후회는 없소. 다만 — 지평선이 아직 끝나지 않은 것이 아쉬울 뿐이오."

10화 — 임종
내용:
- 광개토대왕 임종 (39세)
- 릉비 건립 명령
- 장수왕에게의 유언
- 코러스: 강이 흐른다
```

### 에필로그 (11~12화): 릉비가 말하다

```
11화 — 장수왕의 고구려

내용:

- "강은 기억한다" 최종 내레이션

마지막 장면:
비석 앞에 선 사람.
1,600년 된 글자가 아직 거기 있다.
비는 기억한다.
강도 기억한다.
```

## 핵심 에피소드 상세 — 6화: 경자년 남정

### 시놉시스

391년 즉위 이후 광개토대왕은 북방과 남방을 동시에 경영해야 했다. 400년(경자년), 신라 실성왕의 간절한 구원 요청이 도착한다. 왜구가 신라를 침략했다. 광개토는 결단한다 — 5만 대군을 남으로 보낸다.

### 장면 구성

```
오프닝: 신라 도성 — 왜군의 압박
---
장면 1: 평양성 회의실
광개토: "신라가 요청했소."
귀족 A: "남방까지 갈 여력이 없습니다. 후연이—"
광개토: (지도를 가리키며) "신라가 왜에 먹히면 우리 남쪽이 막힙니다."
귀족 B: "신라가 고구려 속국이 되겠다는 조건이라면—"
광개토: (끊으며) "조건은 내가 정하겠소."

장면 2: 고루와 단둘
고루: "대왕, 5만이면 절반입니다."
광개토: "알오."
고루: "후연이 이 틈을 노린다면?"
광개토: "…그래서 빠르게 끝내야 하오."

장면 3: 출정
5만 기마병의 행진 — 풀샷
광개토: (혼잣말) "지평선이 어디서 끝나는지 — 이번에 봅시다."

장면 4: 신라 도착
신라왕: "고구려의 구원에 감사드립니다."
광개토: "감사는 나중에 하시오. 왜군이 어디 있습니까."

장면 5: 전투
왜군 격퇴 — 전투 시퀀스
가야 항구까지 추격
고루: "여기서 멈추십니까."
광개토: (바다를 바라보며) "…멈춘다."
         (바다 너머를 보며 긴 침묵)

장면 6: 귀환
신라왕: "이 은혜를 어찌 갚겠습니까."
광개토: "신라가 오래 사는 것이 답입니다."
         (시선은 이미 북방을 향해 있다)
```
