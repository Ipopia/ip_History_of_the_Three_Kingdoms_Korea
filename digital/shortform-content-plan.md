## 숏폼 전략 개요

```
포지셔닝:
  드라마·게임 본 콘텐츠로 이끄는 「입구」역할
  역사 지식 허들을 낮춤 → 누구나 접근 가능

목표 플랫폼:
  틱톡(TikTok): Z세대 (15~30초)
  인스타그램 릴스: MZ세대 (15~60초)
  유튜브 쇼츠: 전 연령 (60초 이하)
  네이버 클립: 국내 (60초)

KPI:
  드라마 방영 전: 월 500만 뷰 달성
  드라마 방영 중: 주 100만 뷰 유지
  팔로워 전환율: 시청자의 5% 이상 팔로우 유도
```

## 콘텐츠 카테고리

### 카테고리 1: 「오늘의 삼국」(역사 팩트)

```
형식: 15~30초 / 자막 중심 / BGM: 니문 테마
주기: 주 3회 (월·수·금)

콘텐츠 예시:
  #1. 「을지문덕이 적장에게 시를 보낸 이유」
    - 우중문 심리전 한시 이야기
    - 마지막 CTA: 「드라마에서 더 보기 ▶」

  #2. 「살수대첩, 113만 대군은 어떻게 무너졌나」
    - 30초 인포그래픽 애니메이션
    - 7번 후퇴 → 살수 매복 시각화

  #3. 「계백이 황산벌 전에 한 선택」
    - 가장 비극적 역사 사실 소개

제작 포인트:
  첫 3초: 충격적 사실 또는 질문 (이탈 방지)
  마지막: 브랜드 로고 + CTA
```

### 카테고리 2: 「4인 데이리」(캐릭터 콘텐츠)

```
형식: 30~60초 / 캐릭터 일러스트 + VO
주기: 주 2회 (화·목)

시리즈:
  고루: 「장군이 말하는 전략」— 오늘의 전략 명언
  아랑: 「백제의 아름다운 것들」— 백제 유물 소개
  하린: 「화랑의 훈련법」— 고대 신체 훈련 + 현대 연결
  니문: 「가야금 소리」— 실제 연주 15~30초 클립
```

### 카테고리 3: 「역사 vs 드라마」

```
형식: 30~60초 / 분할화면 (역사 | 드라마)
주기: 드라마 방영 기간 주 2회

예시:
  「역사에서의 을지문덕 vs 드라마의 을지문덕」
  「살수대첩 실제 기록 vs 드라마 연출」
  ADV-HISTORY 코멘트 포함 → 신뢰도 강화
```

### 카테고리 4: 「삼국 챌린지」

```
챌린지 예시:
  #가야금챌린지: 니문 테마 BGM + 손동작 챌린지
  #살수전략챌린지: 3가지 전략 중 선택 → 시청자 투표
  #내왕국은챌린지: 4왕국 중 선택 + 왕국별 AR 필터

KPI: 참여 영상 1만 개 / 해시태그 누적 1억 뷰
```

### 카테고리 5: 「메이킹 비하인드」

```
주기: 드라마 제작 중 주 1회
예시:
  「살수대첩 세트장 공개」
  「배우들의 칼 훈련 30일」
  「가야금 솔리스트 레코딩 현장」
  「역사 자문단이 감수하는 법」
```

## 플랫폼별 최적화

```
틱톡:
  포맷: 세로 9:16 / 주력 15~30초
  훅: 첫 3초 = 질문 또는 충격 사실
  완시율 70%+ 목표 / 듀엣·스티치 허용

인스타그램 릴스:
  포맷: 세로 9:16 / 주력 30~60초
  저장률 5%+ 목표
  역사 인플루언서 콜라보 릴스 병행

유튜브 쇼츠:
  제목: 검색 최적화 (한국 역사 키워드 포함)
  영어 자막 추가 (글로벌 유입)
  롱폼 채널과 연동: 쇼츠 → 「전체 영상 보기」
```

## 제작 파이프라인

```
월간 제작 계획:
  역사 팩트 12편 + 캐릭터 8편 + 챌린지 2편 + 비하인드 4편
  총 26편 / 월

제작 팀:
  숏폼 전담 편집자 2인 (DGT-PLATFORM)
  일러스트: 아트본부 지원
  자막·번역: GLB-LOC 지원 (일/영)

승인 프로세스:
  기획안 → 팀장 → MKT-PR 검토 → 배포
  역사 콘텐츠: ADV-HISTORY 1차 확인 필수
  소요 시간: 기획→배포 5영업일
```

## 성과 지표 (KPI)

```
월간 목표 (방영 6개월 전~):
  총 조회수: 500만 이상
  팔로워 증가: 5,000명/월
  외부 유입 (드라마 티저 클릭): 50,000회

방영 중:
  총 조회수: 2,000만/월
  관련 UGC: 5,000개/월

글로벌:
  해외 조회수 비중: 30%+ (일본·태국·미국 순)
  자막 완성율: 95% (한/영/일/태국어)
```
