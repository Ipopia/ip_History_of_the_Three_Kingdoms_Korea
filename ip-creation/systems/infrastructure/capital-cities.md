## 왕도 개요

```
삼국(三國) IP 4대 왕도:
1. 평양성 (平壤城) — 고구려 수도 (427년 천도 ~ 668년 멸망)
2. 사비성 (泗沘城) — 백제 수도 (538년 천도 ~ 660년 멸망)
3. 서라벌 (徐羅伐) — 신라 수도 (BC57년 건국 ~ 935년 멸망)
4. 김해 (金海) — 가야 금관가야 수도 (42년 ~ 562년)

IP 시대 기준: 4~7세기 (삼국 정립기~삼국통일 전야)
역사 고증: 삼국사기·삼국유사·고고학 발굴 성과 반영
창작 확장: 역사 기록의 공백을 세계관에 맞게 보완
```

## 평양성 (平壤城) — 고구려

### 도시 개요

```
실제 위치: 현 평양 일대 (대동강 유역)
건설: 장수왕 15년(427년) 국내성에서 천도
규모: 내성·중성·외성·북성 4중 구조 (추정 40km² 이상)
인구: 전성기 추정 20만~30만

지형 특성:
- 대동강·보통강 두 강의 합류 지점
- 서북쪽 모란봉(牡丹峰) — 천연 방어 거점
- 동쪽 평야 — 농경 + 군사 이동로

전략적 의미:
고구려 최전성기 정복 영토의 행정 중심
수나라·당나라 침략의 최종 목표
살수(청천강)·압록강 방어선 후방 거점
```

### 공간 구조

```
내성 (王城):
- 위치: 모란봉 남쪽 경사면 + 대동강 북안
- 주요 시설:
  ▸ 왕궁 (안학궁 기반) — 동아시아 최대 규모 목조 궁전
  ▸ 종묘·사직: 왕실 제례 시설
  ▸ 창고·무기고: 군사 물자
  ▸ 왕실 정원: 대동강 조망

안학궁 (고구려 왕궁) 상세:
- 실제 고고학 발굴 기반 (1958~60년대 발굴)
- 총 34개 건물지, 총면적 38만 5천㎡
- 중심축: 남북 정렬 (중국 도성 영향)
- 특징: 온돌 + 마루 혼합 (한국 고유 요소)

중성:
- 귀족·관료 거주구
- 6부 행정 관청 (소노부·순노부·절노부·관노부·계루부·연노부)
- 시장·공방 지구
- 사찰 (불교 수용 372년 이후)

외성·북성:
- 일반 백성 거주구
- 군사 주둔지
- 농업·수공업 지구
```

### 건축 스타일

```
고구려 건축 특성:
기단: 석재 기단 (화강암) — 높고 웅장
기둥: 굵은 원형 기둥, 진한 붉은색 도장
지붕: 팔작지붕 우세, 청회색 기와
장식: 도깨비 기와 (귀면와) — 악귀 퇴치

색채 팔레트:
기단: 회백(灰白) — 화강암 자연색
벽체: 주홍(朱紅) #CC3300 — 전통 단청
기와: 청회(靑灰) #708090
목구조: 황토(黃土) #C8A96E

고분벽화 연동:
궁궐 내부 벽화: 사신도·수렵도·연꽃 문양
삼족오: 왕궁 정전 천장 필수 배치
사신 배치: 동청룡·서백호·남주작·북현무
```

### 드라마·게임 핵심 장소

```
대동강 선착장:
- 고구려의 관문 — 사신·상인 도착 장소
- 극적 첫 장면: 고루가 처음 평양을 보는 장면
- 강물 + 모란봉 + 왕성 — 파노라마 샷

안학궁 정전 (영명전):
- 왕 알현 장면 핵심 공간
- 을지문덕·영양왕 회의 장면
- 연개소문 쿠데타 직전 긴장 장면

모란봉 망루:
- 고루의 비밀 사색 공간
- 살수대첩 출전 전 마지막 바라봄
- 안시성 승리 소식을 기다리는 장면

외성 시장:
- 일상적 생활 묘사 공간
- 고구려 다민족 교류 장면
- 을지문덕이 변장하여 민심 파악하는 장면
```

## 사비성 (泗沘城) — 백제

### 도시 개요

```
실제 위치: 현 충남 부여군 일대 (백마강 유역)
건설: 성왕 16년(538년) 웅진에서 천도
규모: 부소산성 + 나성(羅城) + 사비 도성 전체
인구: 전성기 추정 10만~15만

지형 특성:
- 백마강(금강) 대형 만곡부
- 부소산 북쪽 — 천연 방어
- 삼면 강·산으로 둘러싸인 분지
- 남쪽 개방 — 농경지 확보

전략적 의미:
백제 최후 수도 (123년간)
중국·왜국 외교 허브
해상 교역 중심지
660년 나당 연합군 공격으로 함락
```

### 공간 구조

```
왕궁 지구 (관북리):
- 위치: 부소산 남쪽
- 고고학 발굴: 관북리 왕궁지 (2000년대 발굴)
- 규모: 추정 40만㎡ (동서 600m × 남북 700m)
- 주요 건물: 정전·편전·왕실 생활관·정원·연못
- 특징: 인공 연못 (정원 장식) — 백제 미학 표현

도성 내 구역:
6개 구역 (육부六部) 구조:
- 상·전·중·하·후·외 부 (일본 아스카 문화에 영향)
- 각 부별 관청·거주구 분리
- 도로망: 격자형 계획 도시

정림사지 (定林寺址):
- 백제 불교의 상징
- 오층석탑 (현존 — 국보 제9호)
- 드라마 핵심 배경 공간

낙화암 (落花岩):
- 660년 백제 멸망 당시 궁녀들이 몸을 던진 절벽
- 서사 클라이맥스 장소 (시즌 3)
- 백마강과 부소산 경계의 바위절벽
```

### 건축 스타일

```
백제 건축 특성:
기단: 정교한 석재 가공 — 고구려보다 세밀
기둥: 엔타시스(배흘림) 기둥 — 그리스 영향? 자생적 발전?
지붕: 더 낮고 우아한 경사 — 날렵한 처마선
장식: 금동 장식 기와, 연꽃 문양 수막새

색채 팔레트:
기단: 황토(黃土) #C8A96E — 충청 황토
벽체: 상아(象牙) #FFFDD0 — 백제의 우아함
기와: 회록(灰綠) #6B8E6B — 청록빛 기와
장식: 왕실금(王室金) #B8960C — 금동 장식

특수 요소:
- 금동대향로 스타일 향로를 각 방마다 배치
- 백제 유리구슬 조명 효과 (창문 장식)
- 봉황 문양: 정전·왕실 공간 필수
```

### 드라마·게임 핵심 장소

```
관북리 정전:
- 의자왕 알현 장면
- 아랑이 외교 문서를 보고하는 장면
- 나당 동맹 소식이 도달하는 순간

왕실 정원·연못:
- 아랑의 사색 공간
- 무왕-선화공주 로맨스 장면
- 의자왕이 화려한 연회를 여는 장면 (실정 상징)

정림사 앞 광장:
- 일상 묘사 공간
- 미륵사 건설 이야기 나누는 장면
- 승려 자장(신라) 백제 방문 장면

부소산 낙화암:
- 시즌 3 클라이맥스 장소
- 아랑의 최후 결단 공간 (드라마적 해석)
- 백마강 조망 — 파노라마 배경
```

## 서라벌 (徐羅伐) — 신라

### 도시 개요

```
실제 위치: 현 경북 경주시 일대 (형산강 유역)
건국: BC 57년 (신라 건국)
전성기 규모: 7세기~10세기
인구: 통일신라 전성기 100만+ (왕경 기준)

지형 특성:
- 경주 분지: 사방이 산으로 둘러싸인 자연 요새
- 형산강·남천·북천 수계
- 남산(금오산): 신라인의 성지
- 평야 지대: 농경 최적 (왕경 형성 조건)

전략적 의미:
고구려·백제의 직접 침략 어려운 입지
삼국 중 가장 안정적 수도 유지 (935년까지)
삼국통일 후 통일신라 수도로 동아시아 최대 도시
```

### 공간 구조

```
왕경 구획:
- 남북 도로 + 동서 도로 격자 구조 (당나라 장안 영향)
- 6부(部): 양부·사량부·본피부·모량부·한기부·습비부
- 왕궁 (월성月城):
  반달형 토성 기반 궁성
  동쪽: 동궁(東宮) — 태자 거처
  서쪽: 임해전(臨海殿) — 외교 연회 공간 (안압지)

핵심 건물·유적:
첨성대 (瞻星臺):
- 선덕여왕 631~647년 건설 추정
- 동양 최고(最古) 천문관측대
- 높이 9.17m, 27단 화강암 원형 구조
- 드라마 선덕여왕 핵심 배경

황룡사 (皇龍寺):
- 진흥왕 14년(553년) 착공
- 황룡사 9층 목탑: 선덕왕 14년(645년) 완공
- 추정 높이 80m — 당대 동아시아 최고 목탑
- 자장율사 설계, 아비지(백제인 장인) 시공

분황사 (芬皇寺):
- 선덕여왕 3년(634년) 창건
- 현존 분황사 모전석탑 (국보 제30호)
- 선덕여왕의 불심 상징

대릉원 (大陵苑):
- 신라 왕·귀족 고분군
- 천마총·금관총 등 위치
- 드라마 신라 역사의 무게 표현 공간
```

### 건축 스타일

```
신라 건축 특성:
기단: 정교한 가공석 + 자연석 조화
기둥: 세밀하고 균형잡힌 비율
지붕: 4왕국 중 가장 정교한 처마 곡선
장식: 금제 장식 최다 — 금의 나라

색채 팔레트:
기단: 회백(灰白) — 경주 화강암
벽체: 황백(黃白) #F5F0DC — 신라 흙벽 색
기와: 청회(靑灰) #708090
장식: 황금(黃金) #FFD700 — 신라 금의 상징

특수 요소:
- 금관 양식 영락 패턴을 건물 처마 장식에 활용
- 별자리 문양: 첨성대 주변 바닥 문양
- 불교 연꽃 문양: 사찰 건물 지배적
```

### 드라마·게임 핵심 장소

```
첨성대:
- 선덕여왕·하린의 핵심 만남 장소
- 새벽 별 관측 장면
- 「별은 거짓말하지 않는다」— 철학 대화

황룡사 9층 목탑 공사 현장:
- 신라의 국가 의지 표현
- 백제인 장인 아비지 에피소드
- 하린이 자장율사를 만나는 장면

월성 (왕궁):
- 진덕여왕 즉위 장면
- 김춘추·김유신 회의 장면
- 화랑 선발식 배경

남산 (南山):
- 화랑 수련 장소
- 하린의 정신적 귀의처
- 불교 마애불 배경 — 신라 신앙 표현

안압지 (임해전):
- 삼국통일 후 예고 — 시즌 3 공간
- 외교 연회 배경
- 물 위 달빛 반영 — 감성 장면
```

## 김해 (金海) — 가야 (금관가야)

### 도시 개요

```
실제 위치: 현 경남 김해시 일대 (낙동강 하류)
건국: 42년 수로왕 건국 (구지봉 설화)
멸망: 562년 신라에 병합
인구: 전성기 추정 3~5만

지형 특성:
- 낙동강 하구 삼각주
- 김해 평야: 쌀·철 생산
- 해양 접근성: 일본·중국·신라 교역
- 주위 소국 연맹 체제

전략적 의미:
철 생산·수출 중심 (동아시아 철의 허브)
일본 문화 전파의 중간 기지
낙동강 수계 교역 통제
가장 작은 왕도 — 소박하되 실용적
```

### 공간 구조

```
왕궁 지구:
- 봉황동 유적 기반 (발굴 지속 중)
- 추정: 중심 궁전 + 창고·공방 복합
- 특징: 화려함보다 실용성 — 제철 국가의 색깔

수로왕릉 (首露王陵):
- 현존 (경남 김해)
- 주변 허황옥릉 포함 성역 구역
- 드라마 서사 시작점 — 가야 창건 신화

제철 공방 지구:
- 가야의 핵심 산업 지구
- 철정 생산·가공 시설
- 장인 거주 구역 — 니문 아버지 직업 공간

낙동강 선착장:
- 가야 외교·교역 중심
- 일본 왜인 사신 도착 장소
- 철정 적재·출항 장소

구지봉 (龜旨峰):
- 수로왕 강림 설화 장소
- 가야 성지 — 제사·의례 공간
- 「구지가」가 울려퍼지는 장소
```

### 건축 스타일

```
가야 건축 특성:
기단: 자연석 소박한 가공 — 다른 3국보다 단순
```

## 제작 가이드 (드라마·게임)

### 드라마 세트 우선순위

```
필수 세트 건설:
1. 평양성 안학궁 정전 — 고구려 장면 70% 이상
2. 사비성 왕실 정원 + 관북리 정전 — 백제 핵심
3. 서라벌 첨성대 주변 — 신라 아이코닉 장소
4. 김해 구지봉 + 낙동강 선착장 — 가야 감성

CG 보완:
도시 전경 파노라마 → 100% CG
전투 장면 배경 도시 → CG + 실제 세트 합성
안시성 전체 → 대형 세트 + CG
```

### 게임 지형 설계

```
고구려 구역:
- 평양성 공성전 맵: 내성·중성·외성 3단계 공략
- 모란봉 망루: 스나이퍼/정찰 포인트
- 대동강: 수전 특화 지형

백제 구역:
- 사비성 방어전: 백마강 도하 공방
- 부소산 지형 활용: 고지대 방어 이점
- 낙화암 절벽: 특수 이벤트 지형

신라 구역:
- 서라벌 시가전: 격자 도로망 활용

- 김해 방어전: 낙동강 수운 활용

- 구지봉: 신화 이벤트 트리거 포인트
```
