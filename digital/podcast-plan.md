## 팟캐스트 전략 개요

```
포지셔닝:
  역사 교양 + IP 팬덤 = 「들으면서 더 깊어지는」콘텐츠
  드라마·소설 본편으로 유입하는 「깊이 있는 입구」

플랫폼:
  네이버 오디오클립 (국내 주력)
  Spotify (글로벌)
  Apple Podcasts (영어권)
  YouTube 오디오 (영상 병행)

KPI:
  국내: 에피소드당 평균 청취 1만 회
  글로벌 (Spotify): 구독자 5,000명 (1년)
  완청률: 70%+ 목표
```

## 시리즈 구성

### Series A: 「역사탐정 삼국」(역사 교양)

```
형식: 2인 대화 (진행자 + 역사 자문)
길이: 30~40분
주기: 격주 (월 2회)
톤: 흥미롭고 쉬운 역사 이야기

에피소드 예시:
  EP01: 「살수대첩, 113만은 거짓말?」
    을지문덕 전략 + 수 양제 원정 배경
    ADV-HISTORY 자문 참여

  EP02: 「계백은 왜 그랬을까」
    황산벌 전투 + 처자 결단 역사적 맥락
    비극 vs 충의 — 현대 시각 토론

  EP03: 「가야금 이전에 가야가 있었다」
    가야 12국 역사 + 우륵의 가야금
    ADV-ARTS 자문 참여

  EP04: 「선덕여왕의 예언, 진짜인가」
    선덕여왕 3대 예언 검증
    고대 여성 지도자 비교

  EP05: 「고구려는 왜 중국 땅이 아닌가」
    동북공정 반박 + 고구려 정체성
    ADV-HISTORY + ADV-POLIECON 공동 참여

진행자:
  내부 진행자 1명 (MKT-SNS 추천)
  고정 자문: ADV-HISTORY 격주 교체 출연
```

### Series B: 「삼국 IP 비하인드」(팬덤 콘텐츠)

```
형식: 제작팀 인터뷰 + 팬 Q&A
길이: 20~30분
주기: 드라마 방영 중 매주
톤: 친근하고 재미있는 팬 소통

에피소드 구성:
  전반 15분: 해당 주 에피소드 비하인드
    (촬영·편집·VFX 비화)
  후반 10분: 팬 질문 답변
    (소셜 미디어 사전 수집)

특별 에피소드:
  「배우 단독 인터뷰」시리즈 (4인 주연)
  「음악감독이 말하는 삼국 OST」
  「역사 자문단이 틀렸다고 말한 장면들」
  「VFX팀이 공개하는 살수대첩 비밀」
```

### Series C: 「강이 기억하는 소리」(오디오 드라마)

```
형식: 완전 성우 드라마 (오디오 픽션)
길이: 45~60분
주기: 월 1회 (드라마 방영 외 기간)
톤: 드라마와 동일한 세계관 — 독립 에피소드

콘셉트:
  드라마 본편에 없는 사이드 스토리
  4인 캐릭터 어린 시절 이야기
  역사 현장의 이름 없는 인물들

에피소드 예시:
  「고루의 스승 — 살수 전 마지막 밤」
  「아랑의 어머니 — 사비성 이전 이야기」
  「하린의 첫 번째 화랑 시험」
  「니문이 처음 가야금을 배운 날」

성우:
  드라마 성우진 동일 기용 (일관성)
  고급 녹음 스튜디오 (SND-SFX 협력)
  BGM: OST 기반 앰비언스 음악 활용
```

### Series D: 「삼국 글로벌」(영어 팟캐스트)

```
형식: 영어 진행 (한국사 글로벌 소개)
길이: 20~30분
주기: 월 2회
타깃: 한국 역사 관심 외국인

에피소드 예시:
  「Korea's Three Kingdoms: The Basics」
  「The Battle of Salsu: Korea's Greatest Military Victory」
  「Gaya: The Forgotten Kingdom」
  「Why Korean History Matters to the World」

진행자:
  한국인 + 외국인 2인 공동 진행 (다국어 시각)
  ADV-HISTORY 영어 자문 참여 (격주)

배급:
  Spotify 글로벌 우선
  Apple Podcasts 영어권
  영문 스크립트 = 블로그 포스팅 병행
```

## 제작 파이프라인

```
Series A·B 제작 흐름 (30분 기준):
  기획: 주제 선정 + 자문 섭외 (1주)
  사전 조사: ADV-HISTORY 자료 검토 (3일)
  녹음: 2~3시간 (편집 여유 분량)
  편집: 1~2일 (오프닝·클로징·음악 삽입)
  검수: ADV-HISTORY 역사 팩트 확인 (1일)
  배포: 플랫폼 업로드 + SNS 홍보

Series C 제작 흐름 (45분 오디오 드라마):
  대본: IP-PLOT 담당 작가 집필 (2주)
  검수: ADV-HISTORY + QA-RESEARCH (1주)
  녹음: 스튜디오 4~6시간
  편집·믹싱: 1주 (SND-SFX)
  배포: 월 1회 정기

인력:
  전담 PD: 1명 (DGT-PLATFORM)
  편집: 1명 (겸직)
  자문 섭외: MKT-PR 협력
```
