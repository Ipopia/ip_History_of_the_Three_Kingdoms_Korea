## IP의 인문학적 위치

```
삼국(三國) IP가 다루는 핵심 인문학 질문:

1. 기억과 역사:
   「역사는 누가 쓰는가?」
   「패배한 자의 역사는 어디에 남는가?」
   → 니문 캐릭터의 핵심 존재 이유

2. 정체성과 소속:
   「나라가 사라진 뒤 나는 누구인가?」
   「문화가 곧 나라다」
   → 아랑 캐릭터의 핵심 테마

3. 전쟁과 윤리:
   「나는 올바른 편에서 싸우는가?」
   「이기는 것과 옳은 것은 같은가?」
   → 하린 캐릭터의 성장 갈등

4. 생존과 책임:
   「마지막까지 살아남은 자의 의무는 무엇인가?」
   「기억하는 것 자체가 저항이다」
   → 4인 공통 최종 주제
```

## 동아시아 역사 철학 참조

### 유교적 관점

```
삼강오륜 (三綱五倫) 적용:
  군신: 고루와 을지문덕/연개소문 관계
    → 충성 vs 정의 — 연개소문 폭력에 침묵하는 고루의 갈등
  부자: 아랑과 어머니의 유산 계승
    → 효의 의미: 기억을 전하는 것
  붕우: 4인의 우정 (나라 넘어 연대)
    → 가장 순수한 인간관계 = 이 IP의 희망

인의예지신 (仁義禮智信):
  고루: 智 (지혜, 전략) + 信 (신뢰)
  아랑: 仁 (인, 공감) + 禮 (예, 문화 전승)
  하린: 義 (의, 정의 추구) + 勇 (용기)
  니문: 仁 (인, 기억으로 사람 지킴) + 信 (기록의 신뢰)
```

### 노장 (老莊) 철학 적용

```
무위 (無爲) 전략 — 을지문덕:
  「인위를 버리고 자연의 흐름을 따른다」
  7번 후퇴 = 강물이 스스로 흐르듯 적을 유인
  살수 전략 = 인간이 아닌 자연(강)이 싸운다

물 (水) 철학 — 도덕경 8장:
  「上善若水 — 최상의 선은 물과 같다」
  물은 낮은 곳으로 흐르고, 다투지 않는다
  그러나 모든 것을 이긴다 (살수대첩)
  → IP 슬로건 「강은 기억한다」의 철학적 배경

허정 (虛靜) — 니문 캐릭터:
  싸우지 않음 → 가장 오래 살아남음
  비어있음 → 모든 기억을 담을 수 있음
  가야금 = 비어있는 현 → 채워지는 소리
```

### 불교 철학 적용

```
무상 (無常) — Impermanence:
  나라의 소멸 = 무상의 실천
  고구려·백제·가야 멸망 = 모든 것은 사라진다
  IP 주제: 그러나 기억은 남는다

업 (業·Karma):
  계백의 결사 = 전생의 업인가, 선택인가
  하린의 승리 = 진정한 승리인가
  아랑의 생존 = 이유 없는 행운인가 의미 있는 선택인가

자비 (慈悲·Compassion):
  니문이 전사자 이름을 기록하는 행위
  = 불교적 자비의 실천 (적도 아군도 포함)
  죽간에 새긴 이름 = 극락왕생을 비는 기도
```

## 서양 인문학과의 연결

### 그리스 비극과의 비교

```
고구려·백제 멸망 = 고대 그리스 비극 구조:
  하마르티아 (Hamartia, 치명적 결함):
    고구려: 연개소문 사후 내분 (왕조의 약점)
    백제: 의자왕 말기 충신 추방 (판단 착오)

  카타르시스 (Catharsis):
    황산벌 계백 = 오이디푸스적 비극 (피할 수 없는 운명)
    관객은 비극을 보며 감정을 정화함
    → IP 서사 목표: 슬프지만 숙연한 카타르시스

아리스토텔레스 시학 적용:
  통합된 서사 (Unity): 4인의 이야기가 하나로 수렴
  개연성 (Probability): 역사 고증으로 신뢰도 확보
  발견 (Discovery): 하린의 황산벌 후 「승리의 의미」
```

### 기억의 철학 (Memory Philosophy)

```
폴 리쾨르 (Paul Ricoeur) — 기억, 역사, 망각:
  「기억하는 의무」(Obligation to Remember)
  패배한 자의 역사를 기록하는 것은 도덕적 의무
  → 니문의 죽간 = 이 의무의 실천

월터 벤야민 (Walter Benjamin) — 역사 천사:
  「역사의 천사는 폭풍에 등 떠밀려 미래로 날아가면서
   과거의 폐허만 바라본다」
  → 고루 = 벤야민의 역사 천사
     승리했지만 폐허가 되는 것을 보는 자

얀 아스만 (Jan Assmann) — 문화 기억:
  집단 기억 = 의례·예술·이야기로 전승
  가야금 = 가야 집단 기억의 전달 매체
  아랑의 자수 = 백제 문화 기억의 물질화
```

## IP 주제와 인문학적 의미

```
「기억은 소리다」— 니문의 철학:
  철학적 배경: 口傳 (구전) 문화의 힘
  가야금 소리 = 언어를 초월한 기억 전달
  현대적 의미: 음악·예술이 역사보다 오래 생존

「강은 기억한다」— IP 슬로건 철학적 해석:
  강 = 헤라클레이토스의 「같은 강에 두 번 발을 담글 수 없다」
  → 강은 계속 변하지만 강이라는 존재는 기억된다
  → 나라는 사라지지만 그 문화·사람은 기억 속에 남는다

「패배의 아름다움」:
  계백의 4번 승리 후 최후 패배
  = 승리보다 아름다운 패배가 있다
  → 역사의 승자가 아닌 인간으로서의 위대함

역사 vs 기억:
  역사: 기록된 것, 승자 중심
  기억: 살아있는 것, 경험자 중심
  → 이 IP는 「기억의 역사」를 만든다
```

## 창작에의 적용 가이드

```
작가·연출가를 위한 인문학 적용 포인트:

고루 장면 쓸 때:
  노장의 무위 철학 상기
  을지문덕 = 물, 고루 = 그 물을 이해하는 자
  「행동하지 않음으로써 이기는」전략가

아랑 장면 쓸 때:
  기억의 의무 (리쾨르) 적용
  자수 = 물질화된 집단 기억
  아름다움의 창조 = 저항의 형태

하린 장면 쓸 때:
  그리스 비극의 하마르티아 적용
  충동 (S1) → 윤리적 고민 (S2) → 성숙 (S3)
  영웅이 되는 과정 = 의문을 품는 과정

니문 장면 쓸 때:
  벤야민의 역사 천사 이미지
  가장 말 없는 자가 가장 많이 기억하는 자
  비움 → 채워짐의 노장적 역설
```
