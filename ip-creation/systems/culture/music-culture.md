## 삼국시대 음악 문화 개요

### 역사적 배경

삼국시대(BC 57~668 AD)의 음악은 단순한 오락이 아니었다. 음악은 **제천 의식의 핵심**, **전쟁의 신호 체계**, **왕권의 정당성 표현**, **외교의 수단**이었다. 삼국사기·삼국유사에는 음악에 관한 수많은 기록이 남아있으며, 특히 가야금의 창제와 우륵의 귀화는 음악이 왕국의 존망과 직결된 문화 유산임을 보여준다.

## 왕국별 음악 문화

### 고구려의 음악

**특성**: 군사·제의 중심의 웅장한 음악

**주요 악기**
| 악기 | 특징 | 용도 |
|------|------|------|
| 거문고(玄琴) | 6현 발현악기·고구려 기원 | 귀족 음악·제의 |
| 횡취(橫吹) | 가로 피리 | 군악 |
| 각적(角笛) | 짐승 뿔로 만든 나팔 | 전투 신호 |
| 요고(腰鼓) | 모래시계형 북 | 행진·제의 |
| 담(簷)·담(擔) | 대형 북 | 성 방어 신호 |

**음악의 사회적 기능**
```
제천 의식 (동맹, 10월): 하늘에 바치는 노래·춤·음악
전투 신호: 각적·북으로 진격·후퇴·승리 전달
왕권 강화: 즉위·전승 기념 악가(樂歌)
외교: 사신 접대 시 고구려 음악 시연
```

**고구려 음악의 고분 벽화 증거**
- 무용총(舞踊塚): 가무 장면 벽화 — 악기 연주자·무용수 다수
- 각저총(角抵塚): 씨름·음악 장면
- 삼실총: 군악·의장대 행렬

### 백제의 음악

**특성**: 세련되고 국제적인 궁중 음악 — 동아시아 음악 교류의 중심

**주요 악기**
| 악기 | 특징 | 용도 |
|------|------|------|
| 가야금(伽倻琴) | 백제를 통해 일본에 전파 | 궁중 연회 |
| 피리(觱篥) | 대나무 관악기 | 궁중·제의 |
| 횡적(橫笛) | 가로 피리 | 연회·의식 |
| 고(鼓) | 각종 북 | 의식·행사 |

**역사적 의의**
```
일본 문화 전파:
- 백제 음악사(樂師)가 일본 야마토 조정에 음악 전수
- 백제의 아악(雅樂)이 일본 가가쿠(雅楽)의 원류
- 554년 백제 음악인 5인이 일본 파견 (일본서기 기록)
→ 창작 세계관 활용: 백제 음악이 일본으로 건너가는 장면
```

**백제 음악의 특징적 장면**
```
사비성 궁중 연회: 가야금·피리·무용이 조화된 연회 음악
국제 외교 연회: 중국·왜 사신 앞에서 백제 궁중 음악 시연
백마강 뱃놀이: 강 위 선상에서의 풍류 음악
```

### 신라의 음악

**특성**: 불교 음악과 화랑 음악의 융합 — 정신적 고양

**주요 악기**
| 악기 | 특징 | 용도 |
|------|------|------|
| 가야금 | 우륵 귀화 후 신라화 | 궁중·사원 |
| 향비파(鄕琵琶) | 신라 고유화된 비파 | 귀족·화랑 |
| 대금(大笒) | 대나무 대형 피리 | 사원·야외 |
| 해금(奚琴) | 활로 켜는 현악기 | 서정·슬픔 |
| 범종(梵鐘) | 불교 사원 종 | 종교 의식 |

**화랑 음악 문화**
```
화랑들은 산천을 유람하며 노래를 짓고 음악을 연주했다.
- 향가(鄕歌): 신라 고유 시가 — 처용가·제망매가 등
- 화랑 유오(遊娛): 음악·노래·춤을 통한 공동체 결속
- 군영 음악: 출정 전 결의를 다지는 노래

향가 예시 — 제망매가(祭亡妹歌):
"生死 길은 예 있으매 머뭇거리고
나는 간다는 말도 못다 이르고 어찌 갑니까
어느 가을 이른 바람에 이에 저에 떨어질 잎처럼
한 가지에 나고 가는 곳 모르온저
아아, 미타찰(彌陀刹)에서 만날 나는
도(道) 닦아 기다리겠노라"
```

**불교 음악**
```
신라의 불교 공인(528년) 이후 음악의 성격 변화:
- 범패(梵唄): 불경 독송·의식 음악 발달
- 황룡사 대종(大鐘): 범종 소리가 서라벌 전체에 울림
- 원효의 무애가(無礙歌): 불교 대중화를 위한 노래
```

### 가야의 음악

**특성**: 삼국시대 최고의 음악 왕국 — 가야금의 고향

**가야금 창제 이야기**

삼국사기에 따르면 가야국 가실왕(嘉悉王)이 중국 악기를 보고 "여러 나라의 방언이 각각 다른데 어찌 음악이 같을 수 있겠는가"라 하며 우륵에게 가야금 제작과 12악곡 창작을 명했다.

```
가야금(伽倻琴) 제원:
- 현: 12현 (처음에는 다양했을 것으로 추정)
- 재료: 오동나무(桐木) 몸통, 명주실 현
- 음역: 약 3옥타브
- 연주: 손가락으로 현을 뜯거나 퉁기는 발현 방식
```

**우륵의 12악곡**

삼국사기에 기록된 우륵의 원작 12곡:
| 번호 | 곡명 | 추정 내용 |
|------|------|---------|
| 1 | 하가라도(下加羅都) | 금관가야 도읍 |
| 2 | 상가라도(上加羅都) | 대가야 도읍 |
| 3 | 보기(寶伎) | 보배로운 기예 |
| 4 | 달기(達己) | 미상 |
| 5 | 사물(思勿) | 그리움 |
| 6 | 물혜(勿慧) | 미상 |
| 7 | 하기물(下奇物) | 기이한 것 |
| 8 | 사자기(師子伎) | 사자 기예 |
| 9 | 거열(居烈) | 지명 |
| 10 | 사팔혜(沙八兮) | 미상 |
| 11 | 이혜(尔兮) | 미상 |
| 12 | 상기물(上奇物) | 기이한 것 |

## 음악의 사회적 기능 — 크로스 왕국

### 전쟁에서의 음악

```
출정 의식: 북·나팔·징으로 군의 사기 고양
진격 신호: 특정 북 리듬 = 돌격 명령
후퇴 신호: 징 소리 = 후퇴
승리 선포: 북·나팔 조합 = 전승 선언
항복 신호: 무기 내려놓기 + 음악 정지

살수대첩 창작 활용:
을지문덕이 수문 개방 직전 북소리로 신호 — 음악이 전술의 일부
```

### 외교에서의 음악

```
사신 접대: 상대국 음악 연주 = 존중 표시
문화 선물: 악사·악기 파견 = 최고급 외교 선물
음악 교류: 가야 음악 → 신라 / 백제 음악 → 일본
협약 체결: 잔치 + 음악 = 동맹 강화
```

### 제의에서의 음악

```
제천 의식 (고구려 동맹·부여 영고·삼한 천군제):
- 수십 일간 하늘에 노래와 춤 바침
- 공동체 결속 + 신에 대한 경의
- 전쟁 전후 반드시 제천 의식 거행

불교 의식 (신라·백제):
- 범패·독경·범종 — 종교적 음악 체계
- 황룡사 범종: 경주 전체에 들리는 소리
```

## 창작 활용 가이드

### 음악 장면 시나리오 아이디어

```
[고구려]
- 광개토대왕 즉위식: 거문고·북·각적 대편성
- 을지문덕 전야: 혼자 조용히 거문고 연주 (전략 구상 중)
- 연개소문 등장: 각적 소리와 함께

[백제]
- 의자왕 연회: 가야금·피리·무용 — 화려하지만 공허함
- 낙화암 전날 밤: 궁녀들이 마지막으로 함께 노래
- 계백 출정: 아내와 함께 듣던 노래를 홀로 흥얼거림

[신라]
- 선덕여왕 첨성대: 대금 소리와 별빛
- 화랑 수련 중 향가 합창: 공동체 결속
- 문무왕 통일 선포: 범종 + 합창

[가야]
- 우륵 가야금 창제 순간: 처음으로 12현을 뜯는 소리
- 가야 멸망 전야: 제철장의 망치 소리가 멈추고 가야금만 울림
- 신라에서 우륵의 마지막 연주: 가야 방향 바라보며
```
