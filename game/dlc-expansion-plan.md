## DLC 전략 개요

```
기본 방침:
  본편 완성도 유지 → DLC는 확장이지 필수 아님
  역사 스핀오프 중심 (새 시대·왕국·인물)
  팬 요청 기반 콘텐츠 우선 개발

출시 스케줄:
  본편: 2027 Q1 (모바일 + 콘솔 동시)
  DLC1: 2027 Q3 (가야 시대)
  DLC2: 2027 Q4 (고구려 광개토대왕 시대)
  시즌패스: 2027 Q1 출시와 동시 판매
  DLC3: 2028 Q2 (백제 근초고왕 시대)
  DLC4: 2028 Q4 (발해 건국 — 시즌 3 확장)

가격 정책:
  단편 DLC: 5,500원 (모바일) / 9,900원 (콘솔)
  확장팩: 22,000원 (콘솔)
  시즌패스 (DLC1~4): 44,000원 (18% 할인)
```

## DLC 1 — 「가야의 노래」(2027 Q3)

```
부제: 「사라진 나라의 기억 (Memory of the Lost Kingdom)」
시대: 42년 ~ 562년 (가야 건국 ~ 멸망)
주인공: 니문 조부 세대 캐릭터 (창작)
플레이어블 왕국: 6가야 연맹

시나리오:
  가야 연맹의 성립과 번영
  고구려·백제·신라 사이 균형 외교
  532년 금관가야 신라 복속
  562년 대가야 신라 복속 → 가야 멸망

신규 콘텐츠:
  플레이어블 지역: 가야 Zone 완전 확장
    낙동강 유역 + 남해 도서 + 대한해협 해역
  신규 유닛: 가야 중장보병 (철갑), 가야 교역선
  신규 자원: 고품질 철정(鐵鋌) — 수출 수입 +50%
  신규 메커닉: 「6가야 연맹」— 분열·통합 외교 시스템

역사 이벤트:
  수로왕 건국 신화 이벤트
  우륵 가야금 창작 이벤트 (음악 시스템 연동)
  532년: 금관가야 항복 분기 (저항 vs 자진)
  562년: 니문 조부 탈출 이벤트 (스핀오프 연결)

신규 캐릭터 (S급):
  수로왕 (首露王) — 가야 건국
  이진아시왕 — 대가야 말왕 (마지막 저항)
  우륵 (于勒) — 가야금 장인

수익 예상: 5억원 (출시 3개월)
```

## DLC 2 — 「광개토대왕」(2027 Q4)

```
부제: 「정복자 (The Conqueror)」
시대: 391년 ~ 413년 (광개토대왕 재위)
주인공: 광개토대왕 (실존 인물)
플레이어블 왕국: 고구려

역사적 배경:
  광개토대왕 = 고구려 최전성기
  영토 확장: 요동·만주·한반도 북부
  비석: 「광개토대왕릉비」내용 반영

시나리오:
  즉위 후 첫 원정 (백제 공격, 396년)
  왜(倭) 격퇴 사건 (400년) — 신라 구원
  요동 정복 (407년)
  마지막 원정 + 영토 최대화

신규 콘텐츠:
  플레이어블 지역: 만주 + 요동 전체 확장
  신규 유닛: 고구려 중장기병 (철갑 기마대) — 최강 유닛
  신규 메커닉: 「원정」시스템 — 장거리 원정 보급·전략
  신규 건물: 광개토대왕릉비 건설 (영구 보너스)

역사 이벤트:
  396년: 백제 왕 항복 이벤트 (능비 기록 반영)
  400년: 왜군 격퇴 이벤트 (신라 구원)
  영토 최대 달성 시: 특수 엔딩 「동아시아의 패자」

신규 캐릭터 (S급):
  광개토대왕 (廣開土大王) — 본편 최강 유닛
  장수왕 (長壽王) — 아들, 후계 서사 연결

수익 예상: 8억원 (출시 3개월)
```

## DLC 3 — 「근초고왕」(2028 Q2)

```
부제: 「백제의 전성기 (Baekje at its Peak)」
시대: 346년 ~ 375년 (근초고왕 재위)
주인공: 근초고왕 (실존 인물)
플레이어블 왕국: 백제

역사적 배경:
  근초고왕 = 백제 최전성기
  371년: 고구려 고국원왕 전사 (평양 전투)
  일본·중국 남조와 외교 확장

시나리오:
  마한(馬韓) 정복 → 한반도 서남부 통일
  고구려 공격 → 평양 전투 (371년)
  일본·중국 남조 외교 수립

신규 콘텐츠:
  플레이어블 지역: 마한 구역 추가
  신규 유닛: 백제 수군 전선, 기병 궁수
  신규 메커닉: 「문화 전파」시스템 — 일본에 불교·한자 전파 → 수입

역사 이벤트:
  371년: 고구려 고국원왕 전사 — 역사 최초 대역전
  일본 문화 전수 이벤트 (게임 내 교역 시스템)

수익 예상: 6억원 (출시 3개월)
```

## DLC 4 — 「발해」(2028 Q4)

```
부제: 「고구려의 후예 (Heirs of Goguryeo)」
시대: 668년 ~ 698년 (고구려 멸망 ~ 발해 건국)
주인공: 대조영 (大祚榮)
플레이어블 왕국: 고구려 유민 → 발해

역사적 배경:
  668년: 고구려 멸망
  고루 등 고구려 유민 저항 이어짐 (본편 연결)
  698년: 대조영 발해 건국

시나리오:
  고구려 유민 집결 (668~690)
  당나라 지배에 저항
  만주 동부에서 발해 건국
  발해 = 고구려 계승국 선포

본편 연결:
  고루 캐릭터 노년기 등장 (창작)
  고루의 마지막 독백 「강은 기억한다」연결

신규 콘텐츠:
  플레이어블 지역: 만주 동부 + 연해주 확장
  신규 왕국: 발해 (渤海)
  신규 메커닉: 「유민 집결」— 흩어진 고구려 병력 재건

엔딩:
  발해 건국 성공 → 「고구려는 끝나지 않았다」
  드라마 시즌 후속 암시

수익 예상: 7억원 (출시 3개월)
```

## 시즌패스 구성

```
SAMGUK SEASON PASS — 44,000원

포함 내용:
  ① DLC1 「가야의 노래」
  ② DLC2 「광개토대왕」
  ③ DLC3 「근초고왕」
  ④ DLC4 「발해」
  ⑤ 보너스: 시즌패스 전용 캐릭터 스킨 4종
  ⑥ 보너스: 게임 내 OST 전곡 (100곡+)
  ⑦ 보너스: 역사 아카이브 모드 (삼국사기 원문 + 해설)

단품 대비 절약: 약 10,000원 (18%)
얼리버드 (본편 런칭 전 구매): 추가 5% 할인
```
