# 캐스팅 가이드 — 삼국(三國) IP 드라마 시즌1

**참조 문서**: `drama-screenplay-treatment.md`, `character-design-guide.md`, `shooting-schedule.md`
**원칙**: "삼국의 배우는 캐릭터를 연기하는 것이 아니라 역사를 살아야 한다."

---

## 캐스팅 총괄 원칙

### 선발 기준 (우선순위)

1. **연기력 우선**: 외모·인지도보다 연기 깊이
2. **신체적 적합성**: 고대 전사·왕족의 체형과 위압감
3. **역사 이해도**: 캐릭터 역사 배경 학습 의지
4. **액션 소화력**: 무술·승마 훈련 수용 가능 여부
5. **글로벌 인지도**: 해외 OTT 공략 시 플러스 요소

### 캐스팅 프로세스

```
Step 1: 내부 후보 리스트 작성 (제작사)
Step 2: 1차 오디션 (대본 리딩)
Step 3: 2차 오디션 (액션·감정 씬)
Step 4: 캐릭터 테스트 촬영 (화면 테스트)
Step 5: 최종 계약
```

## 주연 캐스팅 기준표

### 주몽 (朱蒙) — 고구려 건국 영웅

| 항목 | 기준 |
|------|------|
| 성별·나이 | 남성 / 25~35세 |
| 신체 | 180cm+, 탄탄한 근육질 체형 |
| 연기 톤 | 야성적 에너지 + 귀족적 품위의 공존 |
| 필수 기술 | 승마 (기본 이상), 액션 씬 소화 |
| 핵심 장면 | 탈출 추격, 건국 선포, 소서노와의 이별 |

**연기 방향성**: 주몽은 태어난 영웅이 아니라 '만들어진' 영웅. 자신의 신성한 혈통에 대한 의심과 현실적 두려움이 공존해야 함. 광기어린 카리스마보다는 깊은 눈빛의 조용한 강인함.

**오디션 지문**:
```
"나는 하백의 외손이다. 그러나 나는 어제 도망쳤다.
 왕이 도망치는 법이 어디 있는가.
 (멈춤)
 살아야 세운다. 살아야 싸운다."
```

### 소서노 (召西奴) — 실용적 파트너·백제 공동 창업자

| 항목 | 기준 |
|------|------|
| 성별·나이 | 여성 / 28~38세 |
| 신체 | 자신감 있는 자세, 귀족적 외모 |
| 연기 톤 | 차갑지 않은 강인함, 지성과 감성 균형 |
| 핵심 장면 | 주몽과의 파트너십, 남하 결단, 백제 건국 |

**연기 방향성**: 소서노는 희생하는 여인이 아니라 계산하는 경영인. 감정보다 판단이 앞서지만 혼자 있을 때 무너지는 인간적 면모. 현대 여성 관객이 "저 사람은 나다"라고 느낄 수 있는 복합성.

**오디션 지문**:
```
"나는 재산을 세었다. 사람을 세었다. 길을 계산했다.
 그래도 답이 나오지 않는 것이 있다.
 (주몽을 바라보며)
 이것은 계산이 아니다."
```

### 광개토대왕 (廣開土大王) — 정복왕

| 항목 | 기준 |
|------|------|
| 성별·나이 | 남성 / 30~42세 |
| 신체 | 185cm+, 압도적 체격과 존재감 |
| 연기 톤 | 절대적 위엄 + 내면의 고독 |
| 필수 기술 | 승마 필수, 검술 기본 |
| 핵심 장면 | 64성 정복 선포, 즉위식, 최후 |

**연기 방향성**: 스크린에 등장하는 순간 공기가 바뀌어야 함. 말보다 침묵이 더 무거운 배우. 정복왕의 냉철함과 "더 넓은 땅을 원하는" 인간적 욕망 사이의 긴장감.

### 을지문덕 (乙支文德) — 냉철한 전략가

| 항목 | 기준 |
|------|------|
| 성별·나이 | 남성 / 40~52세 |
| 신체 | 단단하고 절도 있는 체형 |
| 연기 톤 | 최소한의 감정 표현, 눈빛으로 말함 |
| 핵심 장면 | 살수대첩 전략 수립, 수문 개방 명령 |

**연기 방향성**: 군더더기 없는 배우. 대사 한 마디에 10가지 의미가 담기는 농밀함. 수나라 113만을 상대하는 심리적 압박을 표정 하나로 전달.

### 계백 (階伯) — 비극적 결사대장

| 항목 | 기준 |
|------|------|
| 성별·나이 | 남성 / 38~48세 |
| 신체 | 전사 체형, 무거운 분위기 |
| 연기 톤 | 극도의 내면 절제 + 폭발적 감정 |
| 핵심 장면 | 가족 처형, 4번의 승리, 최후 |

**연기 방향성**: 계백 역할은 이 드라마 최고의 비극 연기를 요구. 가족을 처형하는 장면은 "악인의 냉혹함"이 아니라 "사랑하기 때문에 하는 최후의 선택"으로 전달. 관객이 눈물을 참지 못하는 순간을 만들어야 함.

## 특수 캐스팅 요건

### 아역 배우
- 주몽 아역 (10~12세): 야생적이고 영리한 눈빛

### 무술 대역 배우
- 주몽 대역: 무술+승마 전문
- 광개토대왕 대역: 대형 체급 무술 전문
- 계백 대역: 단체 전투 안무 전문
- 화랑 대역: 젊고 날렵한 무술 전문 5명

## 4대 주인공 캐스팅 기준 (casting-criteria.md 병합)

> 원본: `casting-criteria.md` — 4인 주인공 상세 캐스팅 기준 + 오디션 모놀로그

### 캐스팅 철학

```
핵심 원칙:
  「역사 인물의 무게를 견딜 수 있는 배우」

기준 우선순위:
  1. 연기력 (캐릭터 내면 표현 능력)
  2. 신체 조건 (역할 적합성 + 액션 가능 여부)
  3. 지명도 (마케팅·국제 배급 고려)
  4. 팬덤 (SNS·글로벌 팬베이스)

원칙:
  - 외모보다 연기력 우선
  - 역사 인물 = 존엄성 유지 (희화화 금지)
  - 국적: 한국 배우 우선, 역할상 필요 시 해외 배우
  - 나이: 캐릭터 성장 호를 커버할 수 있는 나이대
```

### 고루 (고구려 전사)

```
캐릭터 개요:
  나이: 20대 초 (시즌 1) → 40~50대 (시즌 2~3)
  외형: 건장한 체격, 날카로운 눈빛, 강인한 인상
  성격: 직접적·무뚝뚝·깊은 내면

배우 조건:
  연기력:
    - 전쟁·고통·상실 표현 가능한 감정 폭
    - 장수와의 사제 관계 표현 (을지문덕-고루)
    - 시즌 2~3 중년 연기 가능 여부 (동일 배우 or 교체)
  신체:
    - 키 178cm 이상 권장
    - 검술·마상술 트레이닝 가능한 체력
    - 갑옷 착용 시 압도감
  특기:
    - 무술 경험자 우대 (격투기·검도·태권도)
    - 저음 목소리 우대 (고루 캐릭터 DNA)

심사 씬 (오디션 지문):
  씬 A: 을지문덕에게 처음으로 강 이야기를 듣는 장면
        → 당황·혼란·점차 이해하는 감정 변화
  씬 B: 살수 전투 후 홀로 남는 장면 (을지문덕 사망 암시)
        → 말 없이 감정을 표현하는 능력 평가

해외 배급 고려:
  Netflix·해외 OTT용 → 한류 팬덤 보유 배우 우대
  일본 시장: 일본 팬클럽 보유 배우 가산점
```

### 아랑 (백제 기록자)

```
캐릭터 개요:
  나이: 10대 후반~20대 (시즌 1) → 30대 후반 (시즌 2)
  외형: 섬세한 손, 총명한 눈빛, 지적인 인상
  성격: 관찰·기록·빠른 말·질문형

배우 조건:
  연기력:
    - 지식인 캐릭터의 내면 표현 (사색·고뇌)
    - 스승(성충)에 대한 존경·슬픔 표현
    - 기록하는 행위 자체를 연기로 표현 (붓 사용)
  신체:
    - 섬세한 손 동작 (붓글씨 특훈 필요)
    - 과도하게 무인 이미지보다는 문인 이미지
  특기:
    - 한자·붓글씨 경험자 우대
    - 말이 빠른 캐릭터 → 딕션·속사(速射) 대사 능력

심사 씬:
  씬 A: 성충에게 「왜 아무도 듣지 않는 말을 씁니까」묻는 장면
        → 진지함 + 약간의 반항심 + 존경
  씬 B: 백제 멸망 불길을 먼 곳에서 바라보며 기록하는 장면
        → 눈물 없이 감정 억제 + 손만 계속 움직임
```

### 하린 (신라 화랑)

```
캐릭터 개요:
  나이: 20대 초 (시즌 1) → 40대 (시즌 2)
  외형: 황금빛 인상, 당당한 체격, 빛나는 눈
  성격: 결의·감성·용기·도덕적 질문

배우 조건:
  연기력:
    - 강인한 전사이면서 섬세한 감성 표현
    - 선덕여왕과의 관계 (존경·모성애적 연결)
    - 도덕적 갈등 표현 (「이 전쟁이 옳은가」)
  신체:
    - 황금빛 인상 (신라 = 황금 이미지)
    - 검술 액션 가능한 민첩성
    - 화랑 복장 소화 가능한 체형
  특기:
    - 검술 or 무용 경험자 우대
    - 선덕여왕 대사 수신 씬 → 감동 표현 능력

심사 씬:
  씬 A: 선덕여왕 화랑 임명식에서 맹세하는 장면
        → 두려움 + 결의 동시 표현
  씬 B: 황산벌에서 계백 전사 직후 독백
        → 「용감한 자였다」— 적에 대한 경의 표현
```

### 니문 (가야 악사)

```
캐릭터 개요:
  나이: 10대 후반~20대 (시즌 1) → 30대 (시즌 2)
  외형: 조용하고 섬세한 인상, 긴 손가락
  성격: 내향·음악·기다림·소박함

배우 조건:
  연기력:
    - 말 없이 음악으로 감정 표현 (대사 적음)
    - 내면의 슬픔·기다림 표현 능력
    - 12번째 현 앞에서 멈추는 씬 — 신체 연기
  신체:
    - 가야금 연주 자세가 자연스러운 손·팔 비율
    - 조용하고 섬세한 인상
  특기:
    - 가야금·현악기 연주 경험자 우대 (연기 훈련 병행)
    - 최소 3개월 가야금 트레이닝 의무화

심사 씬:
  씬 A: 12번째 현 앞에서 멈추는 장면
        → 말 없이 내면의 두려움·경외심 표현
  씬 B: 나라가 망했다는 소식을 듣고 가야금을 다시 드는 장면
        → 침묵 속에서 희망 표현

특별 주의:
  니문은 대사가 상대적으로 적은 캐릭터
  「몸으로 말하는 연기」능력이 가장 중요
  가야금 실제 연주 vs 대역 결정 → 배우 역량 따라
```
