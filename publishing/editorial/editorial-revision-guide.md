## 문체 교정 기준

### 현대어 변환 원칙

```
고어(古語) 사용 기준:
  허용: 역사적 직책·칭호 (대막리지·좌평·화랑 등)
  허용: 역사 인물 호칭 (장군·선생·전하·대왕)
  최소화: 일상 대화에서 고어체 과사용
  금지: 현대 슬랭·영어 직접 대사

예시:
  ❌ 「을지문덕 장군님이 그렇게 말씀하셨잖아요!」
  ✅ 「장군께서 그리 말씀하셨습니다.」

  ❌ 「수나라 군대가 리얼 강해요」
  ✅ 「수나라 군대의 기세가 대단합니다.」

  ❌ 「완전 미침. 113만이라고?」(웹소설 제외)
  ✅ 「...113만이라 했느냐?」
  (웹소설은 현대적 구어체 일부 허용 — 별도 기준 적용)
```

### 한자 표기 원칙

```
한자 병기 기준:
  인물명 첫 등장 시: 한자 병기 필수
    예: 을지문덕(乙支文德)
  지명 첫 등장 시: 한자 병기 권장
    예: 살수(薩水)·압록강(鴨綠江)
  이후 등장: 한글만 사용 (반복 한자 병기 불필요)

한자 표기 오류 교정 목록:
  ✅ 을지문덕 → 乙支文德 (乙巳 아님)
  ✅ 살수대첩 → 薩水大捷
  ✅ 대막리지 → 大莫離支 (大幕 아님)
  ✅ 나당연합 → 羅唐聯合
  ✅ 화랑 → 花郞 (花朗 아님)
  ✅ 세속오계 → 世俗五戒

한시 표기:
  을지문덕 한시 원문 + 현대어 번역 병기
  「神策究天文 妙算窮地理 戰勝功旣高 知足願云止」
  번역: 「신기한 계책은 천문을 궁구하고, 묘한 계산은 지리를 다했도다.
         싸워 이겨 공이 이미 높으니, 만족함을 알고 멈추기를 바라노라.」
```

## 역사 교열 체크리스트

### 필수 확인 사항 (출판 전 필수)

```
연도 확인:
  □ 살수대첩: 612년 (601년·613년 오기 주의)
  □ 안시성 전투: 645년 (644년·646년 오기 주의)
  □ 황산벌 전투: 660년 7월
  □ 백제 멸망: 660년 (661년 오기 주의)
  □ 고구려 멸망: 668년 (669년 오기 주의)
  □ 가야 멸망: 562년 (562년·563년 혼동 주의)

인물 확인:
  □ 을지문덕 = 고구려 장수 (백제·신라 소속 오기 금지)
  □ 성충 = 백제 좌평 (다른 직책 오기 주의)
  □ 계백 = 백제 장군 (5,000 결사대 지휘)
  □ 양만춘 = 안시성 성주 (이름은 야사 — 야사 표기)
  □ 선덕여왕 = 신라 27대 왕 (재위 632~647)

오기 위험 표현:
  ❌ 「임나일본부」관련 표현 (역사적 오류)
  ❌ 고구려를 중국 역사로 암시
  ❌ 가야를 왜(일본) 속국으로 묘사
  ❌ 살수 = 청천강 (현재 통설) vs 대동강 (일부 설) → 清川江 표기 권장
```

### 역사 용어 교열

```
직책·칭호 통일:
  고구려: 대막리지(大莫離支)·태대형(太大兄)·막리지
  백제: 좌평(佐平)·달솔(達率)·은솔(恩率)
  신라: 이벌찬(伊伐飡)·파진찬·각간(角干)
  가야: 한기(旱岐)·수장(首長)

군사 용어:
  봉화(烽火): 연기 신호 (야간은 불, 주간은 연기)
  삼거(三炬): 봉화 3개 = 최대 위기 신호
  파발(擺撥): 긴급 전령 말 네트워크
  환두대도(環頭大刀): 손잡이 끝 고리형 대도

지명 현재 대응:
  평양성(平壤城) = 현재 평양 (북한)
  사비성(泗沘城) = 현재 충남 부여
  경주(慶州) = 현재 경상북도 경주
  안시성(安市城) = 정확한 위치 불명 (요동 일대)
```

## 캐릭터 목소리 일관성

### 인물별 문체 가이드

```
을지문덕:
  특징: 말 적고 무겁다. 비유·철학적 표현 선호
  금지: 감정 노출 과다, 긴 설명 대사
  예시:
    ✅ 「강은 기억한다.」(짧고 여운)
    ✅ 「막으려 하지 말아라. 기다려라.」
    ❌ 「수나라 군대가 113만이라고? 그것은 걱정하지 않아도 된다. 왜냐하면...」

고루:
  특징: 직접적·간결·행동형. 내면 독백은 진지함
  금지: 과도하게 시적인 표현, 추상적 철학 대사
  예시:
    ✅ 「알겠습니다.」/ 「몇 명이냐?」
    ✅ 내면 독백: 「강이 기억한다는 말이 무슨 뜻인지, 이제 알 것 같다.」
    ❌ 「강물처럼 흐르는 운명의 파도 속에서 나는...」

아랑:
  특징: 말이 빠르다. 관찰·분석적. 질문이 많다
  금지: 무뚝뚝한 대답, 짧은 단답형 (아랑답지 않음)
  예시:
    ✅ 「선생님, 이것이 사실입니까? 상인의 말이 맞다면 수나라 병력은...」
    ❌ 「예. 알겠습니다.」(아랑 목소리 아님)

하린:
  특징: 결의 있지만 감성적. 도덕적 질문을 말로 함
  금지: 냉혹한 전사 이미지만 강조
  예시:
    ✅ 「막아라! — 하지만 막을 수 없었다.」
    ✅ 「이것이 옳은 싸움인가.」(독백)
    ❌ 「전사란 생각 없이 싸우는 것이다.」

니문:
  특징: 대사가 적다. 행동·표정·음악으로 표현
  금지: 긴 설명 대사, 감정 직접 표현
  예시:
    ✅ 「...」(침묵 + 가야금 연주)
    ✅ 「완성하지 못할 수도 있습니다.」(짧고 솔직)
    ❌ 「나는 지금 매우 슬프고 두렵습니다. 가야가 없어진 것이...」
```

## 서술 시점 가이드

```
소설 시점:
  기본: 3인칭 제한 시점 (해당 장면 주인공 시점)
  예외: 을지문덕 마지막 장면 = 고루 시점 (을지문덕 내면 직접 노출 금지)

시점 전환 표시:
  각 절(節) 시작 시 명시:
    > 612년 7월. 압록강.
    > 같은 날. 백제 사비성.
  형식: 연도·월·장소 (italics or 인용 블록)

내면 독백 표시:
  소설: 이탤릭체 또는 구분 문단
  웹소설: 『』기호 사용
  웹툰 대본: [독백 박스] 표기
```

## 원고 분량 기준

```
소설:
  1권: 약 400자 원고지 800~1,000매 (단행본 기준)
  각 장: 20~30매
  에필로그: 5~10매

웹소설:
  회당: 약 400자 원고지 50~80매
  주 2~3회 업데이트 기준

웹툰 대본:
  에피소드당: 50~100컷 (화에 따라 조정)
  컷당 대사: 최대 2줄 (가독성)
  지문: 간결하게 (아트 작가에게 해석 여지 제공)
```
