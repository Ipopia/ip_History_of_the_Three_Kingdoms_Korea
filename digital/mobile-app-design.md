## 앱 전략 개요

```
앱명: 「삼국(三國) — 강은 기억한다」
패키지명: com.create.samguk
플랫폼: iOS 16+ / Android 12+
기술 스택: React Native (크로스 플랫폼)

포지셔닝:
  단순 팬덤 앱 × → IP 생태계 허브 ○
  드라마·게임·소설·굿즈·AI 동반자를 하나의 앱에서

  1. 콘텐츠 허브 (드라마·웹툰·OST 연동)

  5. 굿즈·이벤트 (쇼핑·이벤트 정보)
```

```

  └── 스플래시 (애니메이션 로고 + 배경 살수 흐름)

                 └── 메인 탭

  🏠 홈        — 오늘의 콘텐츠, 알림
  📺 콘텐츠    — 드라마·웹툰·소설·OST
  🤖 동반자    — AI 캐릭터 챗봇
  👥 커뮤니티  — 팬덤·게시판·이벤트
  🛒 스토어    — 굿즈·티켓·프리미엄
```

## 화면별 상세 설계

### 1. 홈 화면

```
레이아웃 (스크롤 가능):

[상단 헤더]
  - 앱 로고 (좌) + 알림 벨 + 프로필 아이콘 (우)
  - 왕국 색상 배경 띠

[히어로 배너 (슬라이드)]
  - 최신 드라마 에피소드 배너
  - 이벤트 배너
  - 신규 굿즈 출시 배너
  자동 슬라이드 5초 + 수동 스와이프

[오늘의 역사 (Daily)]
  - 「오늘 이 날의 삼국시대」
  - 날짜별 역사 사건 카드
  - 탭 → 상세 페이지 (AI 해설 포함)

[AI 동반자 퀵 액세스]
  - 선택 왕국 캐릭터 미니 프로필
  - 「안녕, [이름]! 오늘 이야기 시작할까?」
  - 탭 → 동반자 탭으로 이동

[콘텐츠 추천 (가로 스크롤)]
  - 드라마 최신화 카드
  - 웹툰 업데이트 카드
  - OST 신규 트랙 카드

[팬덤 피드 미리보기]
  - 최신 팬 게시글 3개
  - 「더 보기」→ 커뮤니티 탭
```

### 2. 콘텐츠 탭

```
카테고리 탭 (수평 스크롤):
  [드라마] [웹툰] [소설] [OST] [게임]

[드라마] 섹션:
  - 시즌 선택 드롭다운 (시즌1·2·3)
  - 에피소드 목록 (썸네일 + 제목 + 방영일 + 시청 상태)
  - 외부 OTT 연결 (티빙·넷플릭스 딥링크)
  - 에피소드별 「역사 해설」버튼 (AI 설명)

[웹툰] 섹션:
  - 화(話) 목록 (썸네일 + 화수 + 업로드일)
  - 최근 읽은 화 이어보기
  - 네이버웹툰·카카오페이지 연동

[소설] 섹션:
  - 권/회차 목록
  - 앱 내 리더 (epub 뷰어)
  - 북마크·하이라이트 기능

[OST] 섹션:
  - 트랙 목록 (앨범 아트 + 제목 + 길이)
  - 인앱 플레이어 (미니 플레이어 → 풀 플레이어)
  - Apple Music / Spotify 연동

[게임] 섹션:
  - 게임 앱 다운로드 링크
  - 인게임 이벤트 알림
  - 업적 연동 (게임 API)
```

### 3. AI 동반자 탭

```
캐릭터 선택 화면:
  4캐릭터 카드 (세로 스크롤):
    - 고루 (고구려): 전략가·장군 페르소나
    - 아랑 (백제): 문화·외교관 페르소나
    - 하린 (신라): 화랑·탐험가 페르소나
    - 니문 (가야): 음악가·기억자 페르소나

  카드 디자인:
    - 캐릭터 일러스트 (반신상)
    - 왕국 색상 배경
    - 짧은 소개문 (2줄)
    - 「대화 시작」버튼

채팅 화면:
  [상단]
    - 캐릭터 프로필 (소형) + 이름 + 왕국 태그
    - 뒤로가기 + 캐릭터 정보 버튼

  [채팅 영역]
    - AI 메시지: 왕국 색상 배경 말풍선 (좌)
    - 사용자 메시지: 다크 배경 말풍선 (우)
    - 타이핑 인디케이터 (... 애니메이션)

  [입력 영역]
    - 텍스트 입력창
    - 「오늘의 질문」추천 버튼 (3개 제안)
    - 전송 버튼 (왕국 컬러)

  특수 기능:
    - 역사 모드: 실제 역사 질문 → 역사 해설
    - 스토리 모드: 세계관 내 역할극
    - 일기 모드: 하루 기록 → 캐릭터 반응
```

### 4. 커뮤니티 탭

```
왕국 탭 선택:
  [전체] [고구려] [백제] [신라] [가야]

피드 (카드 리스트):
  - 포스트 카드: 왕국 배지 + 닉네임 + 내용 + 이미지 + 좋아요·댓글
  - 팬아트 전용 섹션 (그리드 뷰)
  - 공식 공지 (핀 고정, 금색 배지)

이벤트 배너:
  - 진행 중 이벤트 카드
  - 응모·참여 버튼 직결

글쓰기:
  - 텍스트 + 이미지 + 왕국 태그
  - 팬아트 업로드 (고화질 지원)
  - 스포일러 블러 옵션

알림 설정:
  - 팔로우한 왕국 게시글
  - 댓글·좋아요 알림
  - 공식 공지 알림
```

### 5. 스토어 탭

```
카테고리:
  [굿즈] [티켓] [디지털] [프리미엄]

[굿즈] 섹션:
  - 상품 그리드 (2열)
  - 왕국별 필터
  - 상품 상세 → 외부 쇼핑몰 연동

[티켓] 섹션:
  - 공연·이벤트 목록
  - 판매 현황 + 잔여 좌석
  - 예매 → 티켓팅 사이트 연동

[디지털] 섹션:
  - 앱 내 디지털 굿즈
  - 배경화면·스티커 팩 (유료/무료)
  - 인앱 결제 (IAP)

[프리미엄] 구독:
  월 9,900원 / 연 89,000원
  포함:
    - 드라마 에피소드 사전 공개 (24시간)
    - AI 동반자 무제한 대화 (기본 30회/일)
    - 전용 배경화면·이모티콘
    - 팬아트 업로드 무제한 (기본 5개/월)
```

```
화면 1: 스플래시 → 로고 애니메이션 (2초)

화면 2: 「강은 기억한다」
  - 배경: 살수 강물 흐름 애니메이션
  - 텍스트: 「612년, 살수대첩의 날」
  - CTA: 「이야기 시작하기」

화면 3: 왕국 선택
  - 4왕국 카드 레이아웃
  - 각 왕국 색상 + 상징 + 짧은 소개 (2줄)
  - 「나는 ○○의 편이다」선택

화면 4: 이름 입력 (선택)
  - 앱 내 닉네임 설정
  - 건너뛰기 가능

화면 5: AI 동반자 소개
  - 선택 왕국 캐릭터 첫 인사
  - 기능 하이라이트 (슬라이드 3장)

화면 6: 알림 권한 요청
  → 메인 홈으로 진입
```

## 인터랙티브 스토리 기능

```
「나의 삼국시대」— 선택형 서사

진입: 콘텐츠 탭 > [인터랙티브]

포맷:
  - 텍스트 + 일러스트 비주얼 노벨 스타일
  - 선택지 3개 (매 분기)
  - 선택에 따른 엔딩 분기 (12가지+)

  고구려편: 「살수대첩의 병사」
  백제편: 「황산벌 최후의 날」
  신라편: 「화랑의 맹세」
  가야편: 「가야금의 마지막 노래」

저장 슬롯: 3개
공유 기능: 엔딩 결과 카드 SNS 공유
```
