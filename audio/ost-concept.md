# OST 컨셉 & 사운드 바이블

## 음악 철학

> "삼국의 음악은 사라졌다. 우리는 그 빈자리에 상상력으로 채운다. 단, 상상력의 뿌리는 역사에 있어야 한다."

**핵심 원칙**
1. 한국 전통 악기 기반 — 오케스트라 보조
2. 각 왕국별 고유 악기 조합 → 왕국 정체성 청각화
3. 침묵의 전략적 사용 — 음악 없는 장면의 힘
4. 글로벌 감상 가능성 — 서양 청중도 감동받는 보편적 감정

---

## 왕국별 음악 정체성

### 고구려 음악

**주 악기**
| 악기 | 특성 | 역할 |
|------|------|------|
| 북(鼓) | 강렬한 타격음 | 전쟁·진격 테마 |
| 피리(觱篥) | 날카롭고 관통하는 | 영웅 테마 |
| 공후(箜篌) | 현악의 서정성 | 왕실 내면 |
| 장새납 | 높고 강한 관악 | 전투 신호 |

**음악적 특성**
- 템포: 빠르고 강렬 — 기병 이동의 리듬
- 조성: 단조 기반 — 영웅적 비장함
- 구조: 점층적 빌드업 → 폭발 → 급격한 다운
- 오케스트라: 현악 배제, 타악+관악 중심

**시그니처 모티프**
```
[고구려 메인 테마 — "철의 행진"]
- 리듬: ♩♩♩♩ | ♩♩♩♩ (4/4박, 강박 강조)
- 멜로디: 5음계(궁·상·각·치·우) 기반 단조
- 악기: 북 → 피리 → 전체 합주
- 길이: 3분 (반복 가능한 구조)
- 사용: 고구려 군 등장·전진·승리
```

---

### 백제 음악

**주 악기**
| 악기 | 특성 | 역할 |
|------|------|------|
| 가야금(伽倻琴) | 부드럽고 서정적 | 귀족·궁중 테마 |
| 단소(短簫) | 맑고 청아한 | 자연·평화 |
| 해금(奚琴) | 애절하고 감성적 | 비극 테마 |
| 편종(編鐘) | 금속 타악 | 의례·격식 |

**음악적 특성**
- 템포: 중간 — 우아한 흐름
- 조성: 장·단조 전환 — 표면의 화려함+내면의 슬픔
- 구조: 물처럼 흐르는 선율 — 백마강의 흐름
- 오케스트라: 현악 주도 + 한국 악기 색채

**시그니처 모티프**
```
[백제 메인 테마 — "백마강의 노래"]
- 리듬: 3/4 또는 6/8박 — 물 흐르는 느낌
- 멜로디: 가야금 선율, 넓은 도약음
- 악기: 가야금 솔로 → 해금 → 현악 합류
- 길이: 4분
- 사용: 백마강 장면, 궁중 일상, 멸망 전야
```

**낙화암 전용 변형 테마**
- 백제 메인 테마의 단조 변형
- 해금 솔로 — 극도로 느리게
- 후반부: 음이 사라지며 침묵으로 끝남
- 사용: 낙화암 장면 한정

### 신라 음악

**주 악기**
| 악기 | 특성 | 역할 |
|------|------|------|
| 향비파(鄕琵琶) | 풍성하고 화려 | 왕실·금관 |
| 거문고(玄琴) | 깊고 장중한 | 통일·종교 |
| 대금(大笒) | 맑고 높은 | 신성·하늘 |
| 편경(編磬) | 단단한 석음 | 의례·권위 |

**음악적 특성**
- 템포: 상승하는 느낌 — 중간→빠름
- 조성: 밝은 장조 기반 — 황금의 빛남
- 구조: 나선형 상승 — 황룡사탑처럼 올라감
- 오케스트라: 전체 오케스트라 + 신라 악기

**시그니처 모티프**
```
[신라 메인 테마 — "황금의 나라"]
- 리듬: 4/4박, 업비트 강조 — 상승감
- 멜로디: 대금 고음 도약 → 하강 → 다시 도약
- 악기: 대금 솔로 → 거문고 → 전 오케스트라
- 길이: 3분 30초
- 사용: 경주 장면, 금관 착용, 통일 선포
```

### 가야 음악

**주 악기**
| 악기 | 특성 | 역할 |
|------|------|------|
| 가야금(伽倻琴) | 가야 탄생지 | 정체성 핵심 |
| 북(鼓) | 제철 리듬 | 노동·열기 |
| 피리 | 슬픔의 선율 | 소멸 테마 |

**음악적 특성**
- 템포: 제철 장면(빠름) ↔ 소멸 장면(느림) 극적 대비
- 가야금 솔로가 가야의 목소리
- 소멸 후: 가야금 소리가 신라 음악에 섞여 들어옴

**시그니처 모티프**
```
[가야 메인 테마 — "쇠와 불꽃"]
- 리듬: 불규칙 타악 → 가야금 선율
- 멜로디: 5음계, 단조, 반복되는 한음
- 사용: 제철 장면, 가야 정체성 장면
```

**우륵 테마 (특별)**
```
[우륵의 가야금 — "남은 자의 노래"]
- 악기: 가야금 솔로 (무반주)
- 멜로디: 가야 테마 변주 — 신라 궁중에서 연주
- 의미: 사라진 나라의 음악이 새 나라에 살아남
- 사용: 우륵 등장 장면 전용
```

## 크로스-왕국 메인 테마

### "삼국(三國)" 메인 타이틀 테마

```
구조:
[도입 — 20초]
단 하나의 북소리 → 잔잔해짐 → 침묵

[고구려 모티프 — 30초]
철의 행진 단편 — 강하게 등장

[백제 모티프 — 30초]
백마강의 노래 단편 — 대비되는 서정성

[신라 모티프 — 30초]
황금의 나라 단편 — 상승

[가야 모티프 — 15초]
쇠와 불꽃 단편 — 빠르게 스쳐감

[통합 클라이맥스 — 40초]
세 왕국 모티프가 동시에 — 불협화음에서 화음으로
마지막 음: 전통 악기 + 오케스트라 합주 → 침묵

전체 길이: 약 3분
```

## 시즌별 음악 방향

| 시즌 | 지배 악기 | 음악 톤 | 특이사항 |
|------|---------|--------|---------|
| S1 건국 | 북+피리 | 야성적·희망적 | 오케스트라 최소 |
| S2 성장 | 가야금+편종 | 정제·안정 | 백제 색채 증가 |
| S3 전성 | 전체 합주 | 압도적·황금 | 가장 풍성한 편성 |
| S4 격변 | 해금 | 긴장·애조 | 불협화음 증가 |
| S5 전쟁 | 북+편경 | 격렬·박력 | 타악 중심 |
| S6 멸망 | 해금 솔로 | 극도의 애조 | 극도로 적은 악기 |
| S7 통일 | 거문고 | 공허·장중 | 침묵 > 음악 |

## SFX 카탈로그

### 전투 사운드

| 사운드 | 소재 | 특징 |
|--------|------|------|
| 갑옷 충돌 | 실제 철갑 녹음 | 무게감 있는 낮은 충격음 |
| 화살 발사 | 실제 각궁 녹음 | 팽팽한 시위음 |
| 화살 착지 | 육지·방패·갑옷별 구분 | 3가지 버전 |
| 칼 마찰 | 철+철 | 날카로운 긁힘 |
| 기마 돌격 | 실제 말떼 | 땅 울림 포함 |

### 자연 환경음

| 환경 | 사운드 구성 |
|------|-----------|
| 대동강 | 물소리 + 새소리 + 바람 |
| 백마강 | 잔잔한 물소리 + 갈대 흔들림 |
| 경주 시장 | 사람 소리 + 가축 + 물건 소리 |
| 고구려 산악 | 바람 + 멀리서 매 소리 |
| 제철 현장 | 불 소리 + 망치 + 쇳물 |

### 의례·종교 사운드

| 사운드 | 용도 |
|--------|------|
| 범종(梵鐘) 소리 | 불교 사원 장면 |
| 무당 방울 소리 | 굿 장면 |
| 봉화(烽火) 타는 소리 | 긴박한 신호 장면 |
| 조정 북소리 | 왕 행차·공식 의례 |

## 앰비언스 맵

각 주요 공간의 기본 앰비언스 사운드:

| 공간 | 앰비언스 |
|------|---------|
| 고구려 왕궁 | 바람 + 먼 북소리 + 발소리 |
| 백제 사비 왕궁 | 새소리 + 물 흐름 + 비단 스침 |
| 신라 황룡사 | 범종 여운 + 향 연기 소리 |
| 전장 전투 전 | 말 숨소리 + 갑옷 소리 + 긴장된 침묵 |
| 백마강 야경 | 강물 + 달빛 (시각→청각 전환) |
| 제철 현장 | 불 + 망치 박자 |
