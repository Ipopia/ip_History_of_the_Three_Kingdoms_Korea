## 드라마 제작 개요

```
시리즈명: 삼국 (三國)
부제: 강은 기억한다 / THE RIVER REMEMBERS
형식: 총 3시즌 × 16부작 (시즌당)
편당 분량: 60~70분 (OTT 기준)
촬영 기간: 시즌 1 기준 18개월 (프리 6개월 + 촬영 8개월 + 후반 4개월)
촬영지: 국내 세트 + 로케이션 + 해외 일부
등급: 15세 이상 관람가 (폭력·전투 수위 기준)
언어: 한국어 (한/영 자막 동시 제작)
```

## 시즌 구조

### 시즌 1 — 「만남과 연대」(AD 600~612)

```
에피소드 수: 16부작
핵심 사건: 살수대첩 (612년)
서사 축: 4인 주인공 첫 만남 → 공동 목표 형성

에피소드 구성:
  EP01~04: 4인 개별 소개 (왕국별 서막)
  EP05~08: 만남과 충돌 (이해충돌·갈등)
  EP09~12: 공동 위기 (수나라 침공 전조)
  EP13~15: 살수대첩 전투 시퀀스
  EP16: 결산 + 시즌 2 복선

제작 특기:
  EP01 파일럿: 영화급 예산 집중 (고품질 첫인상)
  EP13~15: 전투 에피소드 — 액션 블록 3개 편성
  EP16: 60분 → 75분 연장 (시즌 피날레)
```

### 시즌 2 — 「균열과 선택」(AD 630~655)

```
에피소드 수: 16부작
핵심 사건: 나당연합 형성 (648년), 4인 이념 충돌
서사 축: 같은 편이었던 4인의 갈라짐

에피소드 구성:
  EP01~04: 시즌 1 이후 5년 경과 — 각 왕국 변화
  EP05~08: 나당연합 협상 — 하린 vs 고루·아랑 대립
  EP09~12: 가야 부흥 운동 — 니문의 마지막 선택
  EP13~15: 4인 결별 시퀀스
  EP16: 「676을 향하여」복선

제작 특기:
  니문 서사 집중 (멸망 왕국 대표성)
  국제외교 씬 스케일 확장
```

### 시즌 3 — 「완성과 기억」(AD 660~676)

```
에피소드 수: 16부작
핵심 사건: 백제 멸망(660), 황산벌(660), 기벌포(676)
서사 축: 한반도 최종 통일 + 4인의 유산

에피소드 구성:
  EP01~04: 백제 멸망 직전 — 아랑의 선택
  EP05~06: 황산벌 결전 (관창 특공 포함)
  EP07~09: 고구려 멸망 — 고루의 최후
  EP10~12: 나당전쟁 — 신라 vs 당
  EP13~15: 기벌포 22연승 해전
  EP16: 「676」— 니문의 마지막 가야금 + 에필로그

제작 특기:
  최종화(EP16): 영화급 90분 스페셜
  4인 클로징 씬: 무대 세트 + VFX 완전체 구현
```

  M2~M3: 세트 설계·건축 착공

  Week 25~32: 해외 로케이션 (만주 지형 참조)

  M3: 색보정 (DI)
  M4: 음향 믹싱 + OST 최종 믹스

### 주요 세트 목록

```
세트 A — 평양성 내부 (고구려)
  규모: 2,000㎡ 대형 세트
  구성: 고구려 궁전 내부, 회의실, 을지문덕 집무실
  촬영 분량: 시즌 1 전체의 25%

세트 B — 사비성 문서관 (백제)
  규모: 800㎡
  구성: 백제 기록 문서관, 죽간 보관소, 연등 회랑
  촬영 분량: 시즌 1 전체의 20%

세트 C — 신라 화랑 훈련장
  규모: 1,500㎡ 야외형 세트
  구성: 활터, 훈련장, 황룡사 외벽 일부
  촬영 분량: 시즌 1 전체의 20%

세트 D — 가야 낙동강 변
  규모: 로케이션 베이스 + 부분 세트
  구성: 가야 고분군 인근 강변, 대나무 숲
  촬영 분량: 시즌 1 전체의 10%

세트 E — 전투 지형 세트
  규모: 5,000㎡ (살수대첩 전용)
  구성: 청천강 일부 재현 (실제 수로 설치)
  촬영 분량: EP13~15 집중
```

```

  중국 만주 지형: 요동 평원 참조 (VFX 합성용)
  몽골 초원: 고구려 기병 훈련 씬 참조
```

## 배우 캐스팅 기준

```
주인공 4인 요구 조건:
  고루 (고구려):
    → 30대 초반 남성 배우
    → 무술 경험 또는 훈련 가능성
    → 카리스마·중후함 + 감정 깊이 공존
    → 영어 인터뷰 가능 (글로벌 홍보)

  아랑 (백제):
    → 20대 후반~30대 초반 여성 배우
    → 지적·학구적 이미지
    → 고전적 우아함 + 현대적 공감력
    → 역사 고증 한자 장면 연기 가능

  하린 (신라):
    → 20대 중반 여성 배우
    → 마상 훈련 또는 액션 연기 가능
    → 역동적·화랑 기상 이미지
    → 활쏘기·무술 트레이닝 수용

  니문 (가야):
    → 20대 여성 배우 또는 남성 배우 (미확정)
    → 가야금 연주 학습 의지 필수
    → 내면 연기 깊이 최우선
    → 침묵 연기 탁월해야 함

조연 역사 인물:
  을지문덕: 50대 이상 남성 배우 (권위·지혜)
  계백: 40대 남성 배우 (비장함)
  선덕여왕: 40대 여성 배우 (여왕 카리스마)
  관창: 10대 후반 남성 배우 (순수한 용기)
```

## 역사 고증 제작 프로세스

```
사전 고증 절차:
  1. 대본 완성 → ADV-HISTORY 검토 (2주)
  2. 의상·소품 설계 → ADV-ARTS 검토 (1주)
  3. 언어·대사 → ADV-LINGUISTICS 검토 (1주)
  4. 군사·전투 씬 → ADV-MILITARY 검토 (3일)
  5. 최종 승인 → QA-RESEARCH 확인 (3일)

현장 고증 지원:
  역사 자문 상주: 전투 씬 촬영 기간 (ADV-HISTORY 1인)
  언어 자문 상주: 한자·고대어 발화 씬 (ADV-LINGUISTICS 1인)

금지 표현 (촬영 현장):
  임나일본부 관련 표현
  동북공정 관점 대사
  역사 왜곡 소품 (고증 미확인 문양 등)
```
