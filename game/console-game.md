## 게임 컨셉

### 핵심 경험

```
「삼국시대를 직접 이끈다」

플레이어 경험:
  왕국을 선택하고 역사를 재현하거나 역사를 바꾼다
  전략 맵에서 왕국 경영 + 전술 전투에서 직접 지휘
  4주인공 시점 스토리 체험 + 자유 전략 모드

차별화:
  역사 고증: 7세기 한반도 정밀 재현 (유적·유물 기반)
  이중 레이어: 대전략(그랜드) + 실시간 전술(택티컬)
  캐릭터 서사: 전략 게임 + RPG 스토리 융합
  교육 가치: 게임 속 역사 백과사전 (ADV-HISTORY 감수)
```

## 게임 모드

### 캠페인 모드 (스토리)

```
구성: 4왕국 × 각 캠페인 = 4개 스토리라인
  고구려 캠페인: 「철의 성벽」— 살수~안시성 (598~668)
  백제 캠페인: 「연등의 기억」— 무왕~멸망 (600~660)
  신라 캠페인: 「황금의 야망」— 선덕여왕~통일 (632~676)
  가야 DLC: 「소멸하는 소리」— 대가야 최후 (530~562)

캠페인 특징:
  챕터별 역사 이벤트 트리거
  선택지: 역사 준수 루트 vs 가상 분기 루트
  역사 준수 시: 「역사 충실도」업적 해금
  가상 분기 시: 「만약의 역사」엔딩 (What-If)

챕터 예시 (고구려):
  Ch.1 수나라 1차 침공 대비 (598)
  Ch.2 을지문덕 영입 이벤트
  Ch.3 살수대첩 (612) — 대규모 전투 시나리오
  Ch.4 당태종 침공 대비 (644)
  Ch.5 안시성 88일 방어전 (645) — 최종 보스 전투
  Epilogue: 고구려의 황혼 (668)
```

### 정복 모드 (자유 전략)

```
시작: 4세기~7세기 임의 시점 선택
왕국 선택: 고구려·백제·신라·가야 + 수·당·왜 (해금)
목표: 한반도 통일 또는 자국 생존

자유도:
  외교: 동맹·조공·혼인·배신 자유
  전쟁: 선제 공격·방어전·해전 자유
  내정: 기술 개발·경제·문화 투자 자유
  역사 이벤트: 역사 조건 충족 시 자동 발생
    (살수대첩·황산벌·기벌포 등)

승리 조건:
  정복 승리: 한반도 전 영토 통일
  문화 승리: 문화 포인트 최고 달성
  외교 승리: 5개국 이상 동맹 체결
  생존 승리: 676년까지 왕국 유지

난이도:
  서생(書生): 쉬움 — AI 약화, 자원 보너스
  무관(武官): 보통 — 표준 밸런스
  장군(將軍): 어려움 — AI 강화, 자원 패널티
  천하(天下): 극한 — 역사 고증 + 최강 AI
```

## 대전략 맵 (그랜드 전략)

```
맵 범위: 한반도 전체 + 만주·요동·산동반도·일본 규슈
스케일: 1턴 = 1계절 (봄·여름·가을·겨울)
해상도: 성 단위 관리 (약 200개 거점)

경영 시스템:
  인구: 징병·농민·장인·상인 비율 관리
  자원: 식량·철·금·목재·석재
  기술: 군사·농업·문화·외교 기술 트리
  건설: 성벽·궁전·사찰·대장간·항구 건설

외교 시스템:
  조공·책봉: 중국 왕조(수·당)와 관계 관리
  동맹: 2국 이상 동맹 체결 (조건부)
  혼인: 왕족 혼인 → 동맹 강화
  스파이: 첩자 파견 → 내부 정보 획득·내란 선동
  사신: 사신 파견 → 외교 이벤트 (을지문덕 한시 이벤트)

계절 효과:
  봄: 농업 수확 + 전투 시즌 시작
  여름: 장마 → 이동 속도 감소 + 수공(水攻) 가능
  가을: 추수 → 식량 확보 + 전투 최적기
  겨울: 식량 소모 증가 + 고구려 방어 보너스
```

## 전술 전투 (택티컬 배틀)

```
전투 방식: 실시간 전술 (일시정지 가능)
규모: 최대 10,000 유닛 동시 전투

유닛 종류:
  보병: 창병·검병·궁병·방패병
  기병: 경기병·중기병 (고구려 개마무사)
  수군: 전선·교역선·화공선
  특수: 공성병기·봉화·첩자

왕국별 특수 유닛:
  고구려 — 개마무사(鎧馬武士): 중장기병, 돌파력 최강
  백제 — 결사대(決死隊): 계백 전용, 사기 불변
  신라 — 화랑 돌격대: 고속 경기병, 사기 회복
  가야 — 철갑 보병: 철정 기반 중보병, 방어력 우수

영웅 시스템:
  4주인공 + 역사 인물 = 전투 영웅 유닛
  영웅 스킬 (살수 전술·화랑 돌격 등) 발동 가능
  영웅 사망 시: 캠페인 분기 변화

지형 효과:
  강: 도하(渡河) 시 이동 속도 50% 감소
  성벽: 방어측 방어력 300% 보너스
  산악: 기병 이동 불가, 보병 유리
  해안: 수군 상륙전 가능
```
