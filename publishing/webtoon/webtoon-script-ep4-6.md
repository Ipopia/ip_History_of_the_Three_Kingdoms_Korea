## 4화: 비류수의 맹세

**부제**: 강은 증인이다
**장르 톤**: 건국 로맨스 + 정치 서스펜스
**핵심 감정**: 약속의 무게

---

### 오프닝 시퀀스 (컷 1~5)

```
[컷 1 — 풀페이지]
배경: 비류수(沸流水). 새벽. 물안개.
강물이 느리게 흐른다.
캡션: "BC 37년, 졸본(卒本)"
캡션2: "강은 모든 것을 기억한다."

[컷 2]
강가 바위 위 — 주몽, 홀로 서 있음.
갑옷 아직 입지 않음. 평복.
발밑에 강물이 스친다.

[컷 3]
주몽의 손 클로즈업.
손바닥에 작은 상처 — 피가 굳어있음.
(전화 이후의 흔적)

[컷 4]
강 건너편 — 소서노(召西奴), 걸어온다.
그녀의 뒤로 졸본성이 보인다.
아직 성벽이 낮다.

[컷 5]
두 사람, 강을 사이에 두고 마주 봄.
대사 없음. 표정만.
```

### 1장 — 소서노의 조건 (컷 6~22)

```
[컷 6]
소서노: "졸본의 재산, 내 군사, 내 아버지의 이름—"
        "전부 당신에게 줄 수 있어요."

[컷 7]
소서노, 강가 돌 위에 앉음.
표정: 냉철하되 무언가를 숨기는 눈.
소서노: "대신 조건이 있습니다."

[컷 8]
주몽, 강 건너에서 그녀를 바라봄.
주몽: "말해보시오."

[컷 9]
소서노 클로즈업.
소서노: "이 나라의 왕후는 나입니다."
         "다른 여자는 없어요."
         "그리고—"

[컷 10]
소서노, 일어서며.
소서노: "동부여에 당신의 아들이 있다는 거,
          나는 알고 있어요."

[컷 11]
주몽, 굳어지는 표정.

[컷 12]
소서노: "그 아이가 오면—"
         "우리 아들들보다 앞에 세울 수 없습니다."

[컷 13]
긴 침묵. 강물 소리만.

[컷 14]
주몽, 천천히 강을 건너기 시작.
발이 물에 잠긴다. 차갑다.

[컷 15]
주몽이 소서노 앞에 선다.
두 사람의 거리 — 한 뼘.

[컷 16]
주몽: "…나는 그 조건을 받아들일 수 없소."

[컷 17]
소서노, 눈이 흔들림.

[컷 18]
주몽: "유리는 내 피다."
       "그 아이의 자리는 내가 정한다."

[컷 19]
소서노, 시선을 내림.

[컷 20]
주몽: "대신—"
       "소서노, 당신이 이 나라를 세우는 데
        가장 큰 공을 세운다면."
       "역사는 그것을 기억할 것이오."

[컷 21]
주몽, 소서노의 손을 잡음.
주몽: "강이 증인이오."

[컷 22]
소서노, 잠시 후 — 손을 빼지 않음.
소서노: "…후회하지 마세요."
```

### 2장 — 성벽을 쌓다 (컷 23~40)

```

[컷 24]

소서노, 현장 한가운데서 지휘.

소서노: "저기 돌 크기가 맞지 않아요.
          다시 깎아요."

[컷 26]

주몽, 혼잣말: "저 사람은 쉬지 않는군."

[컷 27]
모에(母兒), 주몽에게 다가옴.

[컷 28]
주몽: "그렇지."

[컷 31]
저녁 — 성벽 위. 소서노 혼자.
석양이 지는 한강 방향.

주몽: "쉬지 않으면 쓰러집니다."

[컷 33]

         조금 웃음 — 처음으로.

배경: 저무는 하늘.

[컷 35]
소서노: "주몽."
주몽: "…왜 이름을 부릅니까."
소서노: "아직 혼인한 게 아니니까요."

[컷 36]
주몽, 피식 웃음.
주몽: "맞소."

[컷 37]
소서노: "이 성이 다 지어지면—"
         "그때 혼인하죠."

[컷 38]
주몽: "그거면 한참 기다려야겠군."

[컷 39]
소서노, 강 쪽을 바라보며.
소서노: "강이 증인이라고 했죠."

[컷 40]
주몽, 그녀를 바라봄. 대답 없음.
강물 소리.
```

### 3장 — 송양의 항복 (컷 41~60)

```
[컷 41]
캡션: "6개월 후"

[컷 42]
비류국 왕 송양(松讓), 성문 앞에 섬.

[컷 43]
주몽, 기마(騎馬). 뒤에 소서노도 말 위.
주몽: "송양왕. 전쟁보다 나은 것이 있소."

[컷 44]
송양, 비웃음.
송양: "천한 망명자가 어디서—"

[컷 45]
소서노, 말을 앞으로.
소서노: "비류국은 졸본의 재산으로
          세워진 나라에 비해 세금이 두 배요."

[컷 46]
소서노: "내 아버지 연타발이 이 지역 교역로를
          쥐고 있다는 것도 아실 텐데."

[컷 47]
송양, 굳어지는 표정.

[컷 48]
소서노: "전쟁하면 졌을 때—당신은 끝이에요."
         "항복하면 고구려의 신하로 남을 수 있죠."

[컷 49]
긴 침묵.

[컷 50]
송양, 주몽을 봄.
송양: "…그 여인이 당신의 왕후요?"

[컷 51]
주몽: "그렇소."

[컷 52]
송양, 천천히 무릎을 꿇음.
송양: "고구려의 신하가 되겠습니다."

[컷 53]
소서노, 주몽을 봄. 무표정.
그러나 눈에 — 안도.

[컷 54]
주몽, 조용히.
주몽: "비류국 백성들은 고구려 백성으로
        잘 거두겠소."

[컷 55]
배경: 귀환하는 두 사람. 석양.

[컷 56]
주몽: "소서노."
소서노: "말씀하세요."

[컷 57]
주몽: "…고맙소."
       (처음으로 먼저 고마움을 표한다)

[컷 58]
소서노, 앞만 보며.
소서노: "다음엔 더 잘 할 수 있어요."

[컷 59]
주몽, 웃음.

[컷 60 — 풀페이지 엔딩]
두 사람, 말을 타고 나란히 달린다.
뒤로 비류수가 멀어진다.
캡션: "강은 기억한다."
캡션2: "그들이 함께였던 날들을."
```

## 5화: 모에의 겨울

**부제**: 끝나지 않는 전쟁
**장르 톤**: 비극 + 인물 드라마
**핵심 감정**: 상실과 죄책감

---

### 오프닝 (컷 1~4)

```
[컷 1 — 풀페이지]
배경: 겨울. 졸본. 눈.
캡션: "BC 36년, 겨울"
성벽 위 — 눈이 쌓인다.

[컷 2]
모에(오이·摩離의 동생 창작 캐릭터), 말을 타고 전장에서 귀환.
화살을 맞은 채. 흔들린다.

[컷 3]
성문 앞 — 병사들이 달려옴.

[컷 4]
모에, 말에서 떨어진다.
눈 위에 쓰러짐.
```

## 6화: 동명성왕

**부제**: 왕은 혼자 가지 않는다
**장르 톤**: 서사 피날레 (주몽 파트 마무리)
**핵심 감정**: 작별과 계승

---

### 오프닝 (컷 1~5)

```
[컷 1 — 풀페이지]
배경: 봄. 고구려 성.
캡션: "BC 19년"
캡션2: "건국 18년"
성이 높아졌다. 도성이 되었다.

[컷 2]
주몽, 나이 들었다. 40대.
왕좌에 앉아 있음.

[컷 3]
성문 앞 — 소년 하나, 도착.
눈빛이 강하다.

[컷 4]
병사가 안내함.
병사: "동부여에서 왕자가 왔습니다."
      "유리(類利)라 합니다."

[컷 5]
주몽, 천천히 일어남.
```

### 1장 — 아버지와 아들 (컷 6~24)

```
[컷 6]
유리, 입장.
소년의 눈 — 주몽을 보는 눈.
두려움과 기대가 섞인.

[컷 7]
주몽과 유리, 마주 봄.
닮았다. 눈이.

[컷 8]
유리: "…아버지."

[컷 9]
주몽: "왔구나."
       (18년 기다린 말)

[컷 10]
유리, 무릎을 꿇으려 함.

[컷 11]
주몽, 막음.
주몽: "무릎 꿇지 마라."
       "아직 자기 나라에서 왕자였던 아이가
        여기서 무릎을 꿇으면 안 된다."

[컷 12]
유리, 눈물이 글썽함.

[컷 13]
주몽: "부러진 칼 가져왔느냐."
유리, 품에서 꺼냄.

[컷 14]
두 조각 맞춤.
딱 맞다.

[컷 15]
주몽: "내 아들이다."

[컷 16]
뒤편 — 소서노, 지켜봄.
표정 없음. 그러나 눈에—뭔가.

[컷 17]
소서노 독백:
*'저 아이의 눈이 주몽을 닮았다.'*
*'닮았다는 게 무섭다.'*

[컷 18]
연회. 밤.
주몽과 유리, 함께 앉아 이야기.

[컷 19]
유리: "어머니가 말했어요, 아버지가
       많은 것을 포기하고 떠났다고."

[컷 20]
주몽: "포기가 아니다."
       "선택이었다."

[컷 21]
유리: "무엇을 선택한 겁니까."
주몽: "나라를."

[컷 22]
유리: "나라가 사람보다 중요합니까."
주몽: "…"

[컷 23]
주몽, 오래 생각.
주몽: "그 질문은—나도 아직 모른다."

[컷 24]
유리: "정직한 아버지군요."
주몽, 웃음.
```

### 2장 — 소서노의 결심 (컷 25~46)

```
[컷 25]
밤. 소서노와 두 아들 비류(沸流)·온조(溫祚).
비류: 10대 중반 / 온조: 10대 초반.

[컷 26]
비류: "어머니, 저 아이가 태자가 됩니까."
소서노: "…"

[컷 27]
온조: "형님과 저는 어떻게 됩니까."

[컷 28]
소서노, 두 아들을 바라봄.
소서노: "너희들이 나쁜 일을 당하게
          내가 두겠느냐."

[컷 29]
비류: "어머니—"

[컷 30]
소서노, 창밖 강을 봄.
소서노: "강은 막으면 다른 곳으로 흐른다."

[컷 31]
소서노: "우리도 흘러야 할 때가 됐다."

[컷 32]
두 아들, 표정 굳어짐.
온조: "남쪽으로 가자는 겁니까."

[컷 33]
소서노: "한강 유역은 비어있다."
         "땅이 기름지고 사람이 선하다."

[컷 34]
비류: "어머니는 어떻습니까."
소서노, 잠시 멈춤.
소서노: "나는 너희들의 어머니다."

[컷 35]
소서노, 주몽의 방 앞에 선다. 밤.
문을 열지 않는다. 앞에 서 있기만.

[컷 36]
소서노 독백:
*'18년.'*
*'나는 그 시간 동안 이 나라를 세웠다.'*
*'그 나라에 내 자리가 없어진다면—'*

[컷 37]
문이 열린다. 주몽이 나온다.
주몽: "거기 있었소."

[컷 38]
소서노: "드릴 말씀이 있어요."

[컷 39]
실내. 마주 앉은 두 사람.

[컷 40]
소서노: "저는 떠나겠습니다."

[컷 41]
주몽, 굳어짐.

[컷 42]
소서노: "비류와 온조를 데리고.
          한강 유역으로."
주몽: "…"

[컷 43]
주몽: "내가 잡아서는 안 되는 거요."
소서노: "잡지 마세요."
         "강을 막으면 썩어요."

[컷 44]
주몽: "…"

[컷 45]
소서노, 일어서며.
소서노: "당신이 나라를 선택한 것처럼—"
         "나도 내 나라를 선택할게요."

[컷 46]
주몽, 말없이 바라봄.
```

### 3장 — 작별 (컷 47~62)

```
[컷 47]
새벽. 성문 앞.
소서노, 비류, 온조 — 짐을 실은 말들.
따르는 사람들 수백 명.

[컷 48]
주몽, 성문 앞에 서 있음.

[컷 49]
소서노, 주몽 앞에 선다.
두 사람 사이 거리 — 딱 한 걸음.

[컷 50]
소서노: "잘 다스리세요."
주몽: "…소서노."

[컷 51]
소서노: "말하지 마세요."
         "말하면 못 떠나요."

[컷 52]
주몽, 입을 다문다.

[컷 53]
소서노, 돌아서서 말에 오름.

[컷 54]
비류, 온조 — 주몽을 봄.
온조: "…아버지."
주몽: "가서 좋은 나라 세워라."

[컷 55]
온조, 눈물을 참음.

[컷 56]
소서노의 행렬, 천천히 움직이기 시작.

[컷 57]
주몽, 그 뒷모습을 봄.

[컷 58]
소서노, 돌아보지 않는다.

[컷 59]
그러다 — 성문을 막 벗어날 때.
소서노, 딱 한 번 돌아봄.

[컷 60]
두 사람의 눈이 마주침.
거리가 멀어서 표정은 보이지 않음.

[컷 61]
소서노, 다시 앞을 본다.
강을 향해 달린다.

[컷 62 — 엔딩 풀페이지]
주몽, 혼자 성문 앞에 서 있음.
뒤로 성이 있고, 앞으로 비어가는 길.
캡션: "그녀는 남쪽으로 갔다."
캡션2: "그리고 새 강을 찾았다."
캡션3: "강은 언제나 흐른다."

[하단 자막]
"다음 주: [삼국 이야기 2부 — 백제의 강]"
```

## 연출 가이드 (4~6화 공통)

```
색채:
- 고구려 파트: 암청(#2F4F7F) + 혈홍 포인트
- 겨울 장면: 블루그레이 모노크롬 + 흰색
- 소서노 개인 장면: 따뜻한 호박색 반조명

감정 표현:
- 주몽의 눈물: 전체 컷 기준 3개 이하 — 절제
- 소서노의 눈물: 없음 — 그녀는 울지 않는다
  (단, 눈이 흔들리는 컷은 허용)

카메라 워크:
- 작별 장면: 점점 멀어지는 풀샷
- 감정 클라이맥스: 얼굴 클로즈업 → 배경 풀샷 교차
- 강물: 매 화 최소 3컷 등장 (서사 상징)

BGM 지시 (웹툰 앱 사운드 버전):
- 4화: 가야금 소리 — 약하게 지속
- 5화: 겨울 앰비언스 + 침묵
- 6화: 현악 4중주 → 마지막 컷 무음
```
