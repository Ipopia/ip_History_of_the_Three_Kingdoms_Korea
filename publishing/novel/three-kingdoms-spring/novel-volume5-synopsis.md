# 소설 5권 시놉시스 — 삼국(三國) IP

**참조 문서**: `novel-volume4-synopsis.md`, `master-plot.md`, `character-development-arcs.md`
**작성**: 출판본부 소설팀 (PUB-NOVEL)
**적용**: 삼국(三國) IP 소설 5권 (드라마 시즌 3 후반 + 피날레) 기준

---

## 5권 개요

```
권호: 제5권 「강은 기억한다」
시대: 668년~676년 (고구려 멸망~기벌포 해전)
분량: 400~420페이지 (원고지 1,600매)
POV: 4인 복수 시점 + 에필로그 전지적
드라마 대응: 시즌 3 EP09~EP16 (피날레)

핵심 주제:
  「사라진 것들은 기억 속에서 영원하다」
  「기억하는 자가 역사를 만든다」

제목 의미:
  4권의 「잿빛 강」이 흐르고 흘러
  「강은 기억한다」= IP 슬로건으로 귀환
  5권은 1권 프롤로그와 수미상관 구조
```

---

## 구성 개요

```
1부 「흩어진 자들」(1~6장) — 668~670년
  고구려 멸망 후 4인 각자의 방황

2부 「다시 강가에서」(7~12장) — 671~673년
  4인 재회 — 역사의 증언자로 결속

3부 「기벌포의 파도」(13~18장) — 674~676년
  나당전쟁 클라이맥스 — 4인의 마지막 선택

4부 「강은 흐른다」(19~22장) — 676년
  기벌포 해전 후 — 삼국의 통일과 잔상

에필로그 「강이 기억하는 것들」
  수십 년 후 — 니문의 노래가 남다
```

## 1부 「흩어진 자들」

### 제1장: 고루, 668년 겨울

```
POV: 고루
시간: 668년 겨울 — 평양성 함락 직후

고루의 방황:
  평양성 함락 후 — 생존자로 산을 떠돎
  당나라 포로 수용소 탈출
  고구려 유민들과 함께 — 지도자인가, 도망자인가

핵심 내면:
  「나라 없는 장군은 무엇인가」
  「기억하는 자로 살겠다 했지만 — 기억은 고통이다」
  55세의 몸으로 산을 넘는 현실

고루의 선택:
  유민 집단 지도 거부 → 「내 시대는 끝났다」
  단독 남행(南行) 결심
  → 신라 땅으로, 하린을 찾아서
```

### 제4장: 아랑, 670년

```
POV: 아랑
시간: 670년 — 사비성 함락 10년 후

아랑의 현재:
  신라 귀족 여성으로 보호 중 (하린의 도움)
  백제 유민 공동체에서 교사 역할
  자수(刺繡)로 백제 문화 전승

분기점:
  하린이 나당전쟁 참전 통보
  「당신은 이제 무엇을 지키려 하는가?」
  아랑이 처음으로 — 신라를 위해 행동 결심

내면 전환:
  「백제는 사라졌다. 하지만 나는 여기 있다.」
  「내가 기억하는 것이 곧 백제다.」
```

## 2부 「다시 강가에서」

### 제8장: 4인 재회

```
POV: 니문
시간: 671년 — 낙동강 변

재회 경위:
  니문 = 가야 유민 음악 집단 이끌며 여행 중
  고루 남행 → 우연히 니문 집단과 합류
  아랑이 먼저 고루를 알아봄
  하린은 전쟁 준비 중 — 뒤늦게 합류

재회 장면:
  4인이 낙동강 변에서 처음으로 한 자리에
  고루: 「살수에서 살아남았다」
  아랑: 「낙화암에서 살아남았다」
  니문: 「가야에서 살아남았다」
  하린: 「황산벌에서 살아남았다」
  4인 → 각자 다른 패자이자 생존자

핵심 대화:
  고루: 「우리가 기억하지 않으면 누가 기억하겠는가」
  니문: 이미 답을 알고 있었다 — 가야금을 꺼낸다
```

### 제11장: 기억 프로젝트

```
POV: 니문
시간: 672년

니문의 제안:
  「우리 4인이 함께 증언하자」
  고루 = 고구려의 기억 / 아랑 = 백제의 기억
  하린 = 신라의 눈 / 니문 = 음악으로 보존

각자의 기여:
  고루: 구술 — 살수대첩·안시성·연개소문 증언
  아랑: 자수 패턴 — 백제 문양 기록
  니문: 음악 — 「기억의 강」12곡 완성 시작
  하린: 증인 — 역사 현장에 있는 자

서사 의미:
  4인의 기억 = 삼국의 기억 총합
  패배한 자의 역사 = 승자의 역사보다 진실에 가까움
```

## 3부 「기벌포의 파도」

### 제13장: 나당전쟁

```
POV: 하린
시간: 675년 — 매소성 전투 직전

하린의 위치:
  김유신 사후 — 신라군 중진 장교
  나당전쟁: 신라 vs 당나라
  「이번엔 우리가 적이 되었다」

전쟁의 아이러니:
  고구려·백제 멸망시킨 당나라가 이제 신라도 노림
  하린: 「우리가 저들의 도구였구나」
  고루: 「처음부터 알았다. 신라도 당할 줄」

매소성 전투 (675년):
  신라군 vs 당나라 20만
  하린 선봉 출격
  「살수를 기억한다 — 고구려처럼 싸운다」
  → 고루의 전술 적용: 7번 후퇴 → 역습
```

### 제16장: 기벌포 해전 전야

```
POV: 4인 교차
시간: 676년 가을 — 기벌포 해전 전날

고루:
  「마지막 전투를 본다. 하지만 싸우지 않는다.」
  언덕에서 기벌포 바라보기로 함
  「기억하는 것이 내 전투다」

아랑:
  해안가에서 백제 방향 바라봄
  「백마강도 이런 바다였겠지」
  어머니 자수 조각을 풀어놓는다

니문:
  가야금 들고 언덕 위에 올라감
  「내일 전투가 끝나면 마지막 곡을 완성한다」

하린:
  기벌포 출전 준비
  「4인 중 유일한 전사 — 이것이 내 역할」
  「이기면 우리 모두 살아남은 것이다」
```

## 4부 「강은 흐른다」

### 제20장: 기벌포 해전 (676년)

```
POV: 하린 + 고루 교차

기벌포 해전:
  신라 해군 vs 당나라 수군
  22전 22승 — 신라 최후의 승리

하린 시점:
  해상 전투 — 선두 지휘
  「이긴다. 반드시 이긴다.」

고루 시점 (언덕):
  「고구려가 이기지 못한 것을 신라가 이기고 있다」
  눈물 — 적과 아군의 경계가 흐릿한 노인의 눈물
  「강이 기억하듯, 나도 기억한다」

전투 종료:
  당나라 철수 → 신라 삼국 통일 완성
  하린 생환 — 부상 입었지만 살아있다
  4인 모두 676년 겨울에 살아있다
```

### 제22장: 676년 겨울

```
POV: 니문 (1인칭)

마지막 장면:
  기벌포 남쪽 해안
  4인이 모두 모여 있다

고루: 67세 — 등이 굽었지만 눈은 선명하다
아랑: 40대 — 어머니의 자수를 가슴에 품고 있다
하린: 30대 후반 — 오른팔에 흉터 있지만 서 있다
니문: 40대 초반 — 가야금을 무릎에 올려놓다

니문의 행동:
  「기억의 강」마지막 12번째 곡 연주 시작
  곡 이름: 「676」— 완성되지 않은 곡의 완성

4인의 침묵:
  파도 소리 + 가야금 소리
  누구도 말하지 않는다
  말하지 않아도 알고 있다

고루가 먼저 말한다:
  「강은 기억한다.」
  나머지 셋: 「강은 기억한다.」
```

## 에필로그 「강이 기억하는 것들」

```
시간: 수십 년 후 (니문 노년)
POV: 전지적 (니문의 마지막 증언)

「나는 늙었다.
 고루 형은 680년쯤 평양 방향을 바라보다 잠들었다.
 아랑은 백제 유민 아이들을 가르치다 70대에 눈을 감았다.
 하린은 신라 장군으로 살다 자식들에게 둘러싸여 떠났다.

 나는 아직 살아있다.
 가야금이 있기 때문이다.

 강은 지금도 흐른다.
 살수도, 백마강도, 낙동강도, 기벌포의 바다도.

 그들이 나에게 말했다:
 기억해 달라고.

 나는 기억한다.
 이것이 나의 전쟁이었다.

 — 니문, 710년경」
```

## 집필 지침

```
톤:
  5권 = 해소와 완결 (카타르시스)
  4권의 무거움 → 5권의 고요한 슬픔과 수용
  마지막 장면은 슬프지 않다 — 조용하고 아름답다

수미상관:
  1권 프롤로그의 강 이미지 = 5권 에필로그의 강
  1권 「강이 흐른다」→ 5권 「강은 기억한다」
  IP 슬로건이 서사의 결말이 됨

캐릭터 완결:
  고루: 기억하는 자 → 기억된 자
  아랑: 잃은 자 → 전해준 자
  하린: 싸우는 자 → 지킨 자
  니문: 기록하는 자 → 노래가 된 자
```
