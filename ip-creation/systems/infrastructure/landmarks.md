# 삼국시대 핵심 랜드마크

## 고구려

### 광개토대왕릉비(廣開土大王陵碑)
- 위치: 중국 집안(集安)
- 건립: 장수왕 414년 — 부왕 광개토대왕 추모
- 높이: 6.39m — 동아시아 최대 석비
- 내용: 1,775자 한자 — 광개토대왕 정복 기록
- IP 가치: "역사의 돌에 새긴 왕의 전설" — 비문 내용이 삼국 역사 해석의 핵심 논쟁

### 장군총(將軍塚)
- 위치: 중국 집안
- 형태: 피라미드형 계단식 석릉 — "동방의 피라미드"
- 규모: 밑변 31.5m × 높이 12.4m
- 피장자: 광개토대왕 또는 장수왕 추정
- IP 가치: 고구려 왕권의 시각적 상징 — 장엄한 배경 공간

### 안학궁(安鶴宮)
- 위치: 평양
- 규모: 동서 622m × 남북 620m — 동아시아 최대급 왕궁
- 구조: 남궁·중궁·북궁 3중 구성 + 연못·후원
- IP 가치: 고구려 전성기 궁궐 — 화려한 궁중 장면 배경

### 천리장성(千里長城)
- 건설: 연개소문 주도 (631~647년)
- 구간: 부여성(扶餘城, 현 농안) → 비사성(卑沙城, 현 대련) — 약 1,000리
- 목적: 당나라 침공 대비 방어선
- IP 가치: 연개소문의 야망과 고구려의 마지막 저항 — 장벽 건설 에피소드

## 백제

### 정림사지 5층 석탑(定林寺址 五層石塔)
- 위치: 충남 부여
- 건립: 6세기 사비 천도 후
- 높이: 8.33m — 백제 석탑 양식의 완성형
- 660년 기록: 당 장수 소정방이 탑에 "평제비문(平濟碑文)" 새김 → 백제 멸망의 치욕 상징
- IP 가치: 탑에 새겨진 정복자의 글씨 — 패배와 기억

### 무령왕릉(武寧王陵)
- 위치: 충남 공주
- 발굴: 1971년 — 도굴 안 된 완벽 보존 왕릉
- 구조: 중국 남조식 벽돌 전실묘(塼室墓)
- 출토품: 금제 관식·지석(誌石)·청동거울·도자기 등 108종
- 지석 발견으로 무령왕·왕비 신원 확인 — 삼국시대 유일 피장자 특정 왕릉
- IP 가치: "발굴되지 않았다면 잊혔을 왕" — 역사 재발견의 드라마

### 금동대향로(百濟金銅大香爐)
- 발견: 1993년 부여 능산리
- 높이: 61.8cm — 도교적 신선세계 표현
- 구조: 용(받침) + 연꽃(몸체) + 봉황(뚜껑) + 74개 산봉우리+인물
- 백제 공예 기술의 최정점
- IP 가치: 백제 문화의 정수 — 주요 아트 모티프

### 낙화암(落花巖)
- 위치: 충남 부여 백마강 절벽
- 전설: 660년 백제 멸망 시 궁녀들이 뛰어내린 곳
- 역사적 실증 논란 있으나 문화적 상징성 압도적
- IP 가치: 삼국 서사 최대 비극 장면 — "꽃처럼 떨어진 여인들"

## 신라

### 황룡사(皇龍寺)
- 위치: 경주
- 창건: 진흥왕 553년
- 9층 목탑: 높이 약 80m (추정) — 당시 동아시아 최고 목조 건물
- 의미: 신라의 호국(護國) 상징 — "탑이 서면 신라가 번성한다"
- 1238년 몽골 침략으로 소실
- IP 가치: "사라진 최대의 건물" — 황룡사 재건 꿈의 서사

### 첨성대(瞻星臺)
- 위치: 경주
- 건립: 선덕여왕 시대 (632~647년)
- 높이: 9.17m — 현존 동아시아 최고(最古) 천문 관측 시설
- 구조: 362개 돌 + 창문 + 내부 사다리
- IP 가치: 선덕여왕의 과학적 통치 — 여왕과 천문학자의 관계

### 분황사 모전석탑(芬皇寺 模塼石塔)
- 위치: 경주
- 건립: 선덕여왕 634년
- 안산암 벽돌 모양 석재 사용 — 현존 최고(最古) 신라 석탑
- 원래 9층, 현재 3층 잔존
- IP 가치: 선덕여왕 즉위 직후 건립 — 여왕의 정통성 선언

### 금관총 금관(金冠塚 金冠)
- 발굴: 1921년 경주
- 5세기 후반~6세기 초 신라 왕족 금관
- 구조: 출(出)자형 세움 장식 + 곱은 옥(曲玉) + 금 달개
- IP 가치: 신라 황금 문화의 상징 — 캐릭터 왕관 디자인 원형

## 가야

### 대성동 고분군(大成洞 古墳群)
- 위치: 경남 김해
- 금관가야 왕족 고분 — 순장 흔적 발견
- 출토품: 철기·도기·순장 인골
- IP 가치: "함께 묻힌 자들" — 순장 풍습의 윤리적 딜레마 서사

### 지산동 고분군(池山洞 古墳群)
- 위치: 경북 고령
- 대가야 왕족 고분 — 능선 따라 200기 이상
- 순장: 최대 40명 함께 매장 기록
- IP 가치: 대가야 멸망 직전 마지막 왕의 순장 의례

### 구지봉(龜旨峰)
- 위치: 경남 김해
- 김수로왕 강림 신화의 무대
- "구지가(龜旨歌)" 부른 장소 — 한국 최고(最古) 가요
- IP 가치: 가야 건국 신화 — 하늘에서 내려온 황금 알 6개
