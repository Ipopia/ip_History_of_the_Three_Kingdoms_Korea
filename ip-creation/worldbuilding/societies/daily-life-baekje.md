## 개요

612년의 백제는 무왕(武王, 재위 600~641) 치세 13년째다. 수도 사비(泗沘, 현 충남 부여)는 성왕의 천도 이후 약 70년이 지나 안정적 도시 체계를 갖추고 있었다. 백제는 이 시기 고구려-수나라 전쟁을 **관망**하는 입장이었다 — 직접 참전하지 않으면서도 고구려가 약해지기를 바라는 복잡한 지정학적 계산 속에서, 내부적으로는 무왕의 대규모 궁궐 건설 사업(미륵사 창건 추진)으로 백성들의 부역 부담이 컸다.

이 문서는 아랑(雅琅)의 아버지가 일하는 **사비성 왕실 사관 가문**의 생활 반경을 기준으로, 사비성 내 중간 계층(관료·장인·상인)과 사비성 인근 농촌 백성의 실제 삶을 다룬다. 고구려와의 비교를 통해 **백제 문화의 고유성**이 드러나도록 구성한다.

## 1. 주거 (Housing)

### 1-1. 사비성의 도시 주거 구조

사비성은 538년 성왕의 천도로 계획 도시로 건설되었다. 중국 남조(南朝)의 도시 설계를 적극 수용한 백제의 수도는 삼국 중 **가장 정제된 도시 공간**을 갖추고 있었다.

```
[사비성 공간 구조 — 612년 기준]
왕궁지 (북쪽 부소산 기슭)
   └── 왕궁·관아 지구
중앙 대로 (남-북 축)
   ├── 동쪽: 귀족·관료 거주구 (기와집, 담장 있는 저택)
   ├── 서쪽: 장인·상인 거주구 (목조 주거 밀집)
   └── 남쪽: 성문 인근 하층민 거주구
사찰 지구: 정림사지 인근 — 불교 사원 밀집
외곽: 토성 + 금강(백마강) 해자(垓字) 역할
```

### 1-2. 주거 유형별 상세

| 계층 | 구조 | 난방 | 특징 |
|------|------|------|------|
| **귀족/고위 관료** | 기와 저택, 별채 분리, 담장 | 화로(火爐) + 부분 온돌 | 중국식 공간 구성, 정원 있음 |
| **중간 관료/사관** | 기와 또는 초가, 2~3칸 | 화로 + 부뚜막 | 작업 공간(서재·창고)과 주거 통합 |
| **장인/상인** | 초가 2~3칸, 작업장 겸용 | 부뚜막 중심 | 작업장이 가옥 전면 배치 |
| **농민 (사비 인근)** | 초가 1~2칸 | 부뚜막 + 초보적 온돌 | 고구려보다 온돌 발달 덜함 |

**백제 온돌의 특징**: 고구려와 달리 백제는 **온돌이 덜 발달**했다. 한반도 남서부의 상대적으로 온화한 기후 때문에 방 전체를 달구는 구들보다 **화로(移動式 난방)** 를 더 많이 사용했다. 대신 마루 문화가 발달하여 방과 방 사이 목재 마루 공간이 고구려보다 넓었다.

### 1-3. 사비성 인근 농촌 마을

```
[금강변 농촌 마을 — 전형적 구조]
- 마을 중심: 공동 우물 + 사당(社堂)
- 논 중심 경작: 금강 충적평야 → 삼국 중 논농사 비중 최고
- 어촌 겸업: 금강(백마강) 어업 + 농업 복합 생계
- 방어 시설: 부소산성 체계 내 연결, 목책은 간소
- 특징: 고구려보다 마을 규모가 작고 분산되어 있음
```

## 2. 식생활 (Food and Diet)

### 2-1. 주식과 주요 작물

백제는 금강 유역 충적 평야 덕분에 **삼국 중 쌀 생산량이 가장 높은** 왕국이었다.

```
[주식 곡물 — 612년 기준 비율 추정]
쌀(水稻)   ·····  35% → 백제 핵심 작물. 금강·만경강 평야
보리(大麥) ·····  25% → 봄 보리 + 가을 보리 이모작
조(粟)     ·····  15% → 산간 밭, 고구려보다 비중 낮음
콩(大豆)   ·····  15% → 된장·두부·콩기름 원료
밀(小麥)   ·····   5% → 귀족·도성 수요 중심
기장·수수  ·····   5% → 제사·술 원료
```

**고구려와의 차이**: 백제는 쌀밥을 먹을 수 있는 계층이 더 넓다. 사비성 인근 농민은 가을 수확기에 쌀밥을 먹었다. 다만 612년 무왕의 대규모 토목 공사(미륵사 창건)로 부역 부담이 커지면서, 식량 상황이 이전보다 나빠진 상태였다.

### 2-2. 백제의 독특한 음식 문화

**발효식품 발달**: 백제는 해양 네트워크를 통해 중국 남조의 음식 기술을 적극 수용했다. 장류(醬類) 제조 기술이 삼국 중 가장 정교했다.

| 식품 | 설명 | 고구려와 차이 |
|------|------|--------------|
| **젓갈(醢)** | 생선·조개를 소금에 절인 발효식. 금강 인근 어촌이 중심 생산지. | 고구려보다 종류 다양 (새우젓, 조기젓 등) |
| **된장(醬)** | 콩 발효. 백제 사관 가문은 고급 된장 직접 제조. | 발효 기간·방법이 고구려보다 정교 |
| **술(酒)** | 쌀로 빚은 막걸리(濁酒). 제사·공식 연회용 청주(淸酒). | 쌀 풍부 → 술 문화 발달. 고구려는 조/기장 술 중심 |
| **굴·조개** | 금강 하구 인근 어촌의 주요 부식 | 내륙 중심인 고구려에는 없음 |
| **청어·숭어** | 금강 어획 핵심 어종 | 고구려 압록강 어종(연어·잉어)과 다름 |

### 2-3. 아랑 가문의 식탁 — 서사 적용

> **설정**: 사비성 왕실 문서관 사관 가문. 중간 관료 계층. 넉넉하지 않으나 굶지는 않음.

```
아침 : 쌀죽 또는 보리밥. 된장국. 젓갈 반찬.
점심 : 아버지는 관아에서 배급 식사. 아랑은 왕실 문서관 내 공동 식사.
저녁 : 집에서 쌀밥 또는 보리밥. 생선국 또는 된장국. 제철 채소.
특별식 : 축제·제사 때 술 + 떡 + 구운 고기 (주로 돼지고기).
```

**612년 특수 상황**: 무왕의 미륵사 건설 공사 부역 동원으로 도성 인근 농촌 남성들의 부역이 증가. 식재료 가격 상승. 아랑의 아버지는 관료 배급을 받기 때문에 직접적 식량난보다 **주변 민심 악화**를 더 강하게 체감하는 위치.

## 3. 의복 (Clothing)

### 3-1. 백제 복식의 특징 — "문화 강국의 세련됨"

백제 복식은 **중국 남조(南朝) 문화의 영향**을 가장 강하게 받았다. 고구려의 북방 기마 실용 복식과 달리, 백제는 색채·장식·소재에서 더 정교하고 화려한 경향이 있었다. 이 문화는 일본(왜)에 전파되어 일본 고대 복식의 원형이 되었다.

| 계층 | 상의 | 하의 | 겉옷 | 머리/관 | 신발 |
|------|------|------|------|---------|------|
| **왕족/최고 귀족** | 비단 저고리, 금사(金絲) 자수 | 비단 주름 바지·치마 | 대수포, 옥대(玉帶) | 금관식(金冠飾), 관모 | 비단화 |
| **중간 관료/사관** | 모시 또는 얇은 삼베 저고리 | 모시 바지·치마 | 단령(團領) 형태 겉옷 | 건(巾) 또는 두건 | 가죽화 |
| **장인/상인** | 두꺼운 삼베 저고리 | 삼베 바지 | 삼베 포 (계절별) | 두건 또는 망건 | 짚신 |
| **농민** | 무명 또는 삼베 저고리 | 삼베 바지·치마 | 없음 (농번기) 또는 두루마기 | 두건 | 짚신 또는 맨발 |

**백제 복식의 고유 요소**:
- **모시(苧麻)**: 백제 남부 지역(충청·전라 경계) 특산. 여름 고급 직물로 귀족·관료층 애용.
- **색상**: 고구려보다 색채 다양성 높음. 옅은 초록·하늘색·연분홍 사용.
- **자수 장식**: 귀족 의복에 꽃·새·연꽃 자수 발달. 고구려는 기하학 무늬 중심.

## 4. 직업과 사회 구성 (Occupations)

### 4-1. 직업별 인구 비율 추정 (612년)

```
전체 백제 인구 추정: 200~250만 명

농민           ·········  65% → 쌀농사 중심. 금강·만경강 평야
어민           ·········   8% → 금강 하구, 서해안 어촌
장인/공인      ·········   8% → 도자기·금속·목공 발달
상인           ·········   6% → 대외 교역 비중 삼국 중 최고
관료/사관      ·········   4% → 체계적 관료제 (22부제)
승려/사관      ·········   4% → 사비성 내 사찰 밀집
기타           ·········   5%
```

### 4-2. 백제 특유의 직업 집단

**사관(史官) 계층** — 아랑 아버지의 직업:
- 백제는 4세기부터 **서기(書記)** 제도를 발전시켜 왕실 역사 기록 전통이 강함.
- 사관(史官)은 왕의 일거수일투족을 기록하는 전담 관리. 정치적 독립성 부분 보장.
- 아랑 아버지는 왕실 문서관 사관 → 모든 외교 문서, 왕명, 조세 기록 보관.

**해양 상인(海商)**:
- 백제의 핵심 직업 집단. 중국 남조, 일본(왜)과의 교역 담당.
- 612년: 수-고구려 전쟁으로 중국 북부 교역 단절 → 남조(隋 대신 중국 강남 세력) 경유 교역 지속.
- 사비성 금강 나루에는 왜(倭) 상인과 백제 해상인이 공존.

**도공(陶工)과 금속공(金屬工)**:
- 백제 도공은 당대 동아시아 최고 수준. 중국 남조 기법 + 고유 기법 융합.
- 백제 금속공: 금동대향로, 칠지도 같은 수준의 기물 제작. 일본에 기술 전파.
- 612년: 미륵사 건설에 목공·석공·도공 대규모 동원.

## 5. 종교와 신앙 (Religion and Beliefs)

### 5-1. 백제 불교의 특수성

백제는 삼국 중 **불교가 가장 세련된 형태로 정착**한 나라였다. 384년 침류왕이 불교를 공인한 이후, 200년 이상의 시간이 지난 612년 시점에 불교는 백제 사회에 완전히 뿌리내렸다.

```
[백제 불교의 사회적 위치 — 612년]
왕실  → 불교를 왕권 강화 수단으로 적극 활용. 무왕의 미륵사는 정치적 기획.
귀족  → 가문 사찰 운영. 승려 후원이 사회적 지위 과시.
관료  → 불교식 장례·제사가 유교적 관료 의례와 혼합.
농민  → 불교 수용 + 전통 토착신앙 병존. 사찰은 마을의 정신적 중심.
```

**무왕의 미륵사 건설 (익산, 600년 착공 추정)**:
- 미륵신앙(彌勒信仰): 미래의 구원 부처가 세상을 정화한다는 믿음.
- 무왕은 자신을 미륵불의 현현으로 포지셔닝 → 왕권의 신성화.
- 공사 규모: 삼국 최대 사찰. 서동요 설화(무왕과 선화공주 로맨스)와 연결.
- 612년 시점: 공사 진행 중. 인근 농민·장인의 강제 부역 원성 높음.

### 5-2. 토착신앙과 불교의 혼합

| 신앙 유형 | 백제 고유 양상 |
|-----------|--------------|
| **수신(水神)** | 금강(백마강)의 신. 어민·농민 공통 신앙. 봄·가을 강신제. |
| **해신(海神)** | 서해 어민·해상 상인 집단의 핵심 신앙. 출항 전 제의 필수. |
| **산신(山神)** | 부소산 산신. 사비성 수호 기능. 봄 제의. |
| **조상신(祖上神)** | 가족 단위. 불교식 위패와 토착 조상신 제사 혼합. |
| **미륵신앙** | 무왕 이후 급속 확산. "구원의 부처가 온다" — 전쟁·부역에 지친 민심에 호소. |

### 5-3. 아랑과 종교 — 서사 적용

> 아랑의 어머니는 아랑이 어릴 때 사망 → 아버지와 단둘이 살아온 가족.

```
[아랑 가문의 종교 생활]
- 아버지: 유교적 사관 소양 + 불교 의례 참여 (왕실 행사 기록 의무)
- 아랑: 왕실 불교 행사 기록 담당 → 불교 교리에 정통하나 신앙보다 지식으로 접근
- 어머니 기일: 불교식 재(齋) + 전통 조상 제사 혼합
- 아랑의 비밀: 왕실 문서 기록 중 미륵사 건설의 실제 비용(백성 부역)을 알고 있음
  → 기록하는 자의 딜레마: "역사는 승자가 쓴다"
```

## 6. 가족 구조 (Family Structure)

### 6-1. 백제 가족 제도의 특징

백제는 고구려보다 **부계 친족 결속이 약하고, 모계 연결도 중요시**하는 경향이 있었다. 해양 문화와 대외 교류의 영향으로 가족 구조가 다소 유연했다.

```
[612년 백제 중간 계층 가족 실태]
- 표준 구성: 아버지 + 어머니 + 자녀 2~4명 (핵가족 경향 강함)
- 확대 가족: 같은 마을 내 친족 네트워크. 반드시 동거는 아님.
- 여성의 지위: 고구려보다 사회 활동 범위 넓음. 상업 활동 참여.
- 상속: 장남 우선이나 딸에게도 일부 재산 분배 관행 있음.
```

### 6-2. 결혼과 사회

- **결혼 연령**: 남성 20~25세, 여성 16~20세 (귀족은 정략결혼으로 더 이름)
- **혼인 의례**: 불교 사찰에서 승려 축복 + 전통 의례 혼합
- **외국인 결혼**: 백제는 왜(倭) 출신, 중국계 이민자와의 혼인이 삼국 중 가장 개방적
- **아랑의 상황**: 어머니 없는 단출한 가족. 결혼 제안을 여러 번 거절 (기록의 일이 더 중요). 아버지는 딸의 독립심을 존중.

## 7. 전시(戰時) 영향 — 612년 특수 상황

### 7-1. 고구려-수 전쟁의 백제 영향

```
[612년 백제의 전략적 상황]
- 직접 참전: 없음. 관망 전략.
- 내부 계산: 고구려가 약해지면 북방 진출 기회. 그러나 수나라도 견제 필요.
- 외교 방향: 수나라에 우호적 제스처 (조공 지속) + 신라와 긴장 유지 + 왜와 연대.
- 백성 체감: 전쟁 없음. 대신 무왕의 미륵사 공사 부역이 더 큰 고통.
```

### 7-2. 무왕의 토목 사업 부담 (612년)

612년 백제 백성의 가장 큰 고통은 **전쟁이 아닌 국가 토목 공사**였다.

```
[무왕 재위 중 주요 토목 사업 — 610년대]
- 미륵사 건설 (익산): 최대 규모 사찰. 석공·목공·도공·일반 농민 대규모 동원.
- 왕궁 확장 (사비): 왕궁지 확장 공사.
- 익산 왕궁리 유적: 무왕의 제2 수도 기획 추정.
- 도로 정비: 사비~익산 연결 도로 공사.
```

**부역의 실제**:
- 60일/년 부역이 기준이나 실제로는 100일 이상 동원.
- 부역 기간 식사는 자급. 공사장에서 먹는 것도 알아서 해결.
- 도망 시 가족 연좌. 그러나 도망이 꾸준히 발생 — 백제 말기 민심 이반의 씨앗.

### 7-3. 사비성의 일상 풍경 — 서사 적용

> **시간대**: 612년 여름. 살수대첩 소식이 한 달 뒤 사비성에 도달하는 시점.

```
새벽 4시   : 금강 나루 어민 출항. 그물 던지기.
새벽 5시   : 사비성 성문 개방. 시장 상인들 좌판 준비.
오전 6시   : 왕실 문서관 개관. 아랑 아버지 출근.
오전 7시   : 아랑, 왕실 문서관 도착. 전날 미완성 기록 계속.
오전 9시   : 조회(朝會) 관련 기록 업무. 외교 문서 필사.
점심 12시  : 관아 내 공동 식사 (쌀밥 + 된장국 + 젓갈).
오후 1~5시 : 기록 업무 계속. 왜국 사절 방문 기록 담당.
```
