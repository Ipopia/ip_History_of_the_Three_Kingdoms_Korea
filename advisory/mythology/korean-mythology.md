## 7세기 한반도 신앙 체계

### 무속 (巫俗) — 토착 신앙

```
핵심 개념:
  무당(巫堂): 신과 인간 사이 중재자
  강신무(降神巫): 신이 내려오는 무당 (한국 특수)
  세습무(世襲巫): 세습으로 이어지는 무당

삼국시대 무속 역할:
  전쟁 전 길흉 점 (왕이 무당 자문)
  질병 치료 의례
  농사·강우 기원
  망자 천도 (죽은 자의 한 풀기)

주요 의식:
  굿: 신을 불러 문제 해결하는 의례
  고사(告祀): 장소/사물에 감사·기원
  독경(讀經): 경문 외워 재앙 막기

IP 활용 방침:
  무당 캐릭터: 신뢰할 수 있는 지식인으로 표현
  굿 장면: 화려하고 장중 (스펙터클 요소)
  예언: 모호하게 (역사와 충돌 방지)
```

### 불교 (佛敎)

```
삼국 불교 수용 시점:
  고구려: 372년 (전진 순도 스님)
  백제: 384년 (동진 마라난타 스님)
  신라: 528년 (이차돈 순교)

7세기 불교 발전:
  원효(元曉): 617~686년 — 신라 불교 대중화
  의상(義湘): 625~702년 — 화엄종
  자장(慈藏): 590~658년 — 황룡사 9층탑 건립 건의

삼국별 불교 특성:
  고구려: 국방 불교 (호국 기원)
  백제: 예술 불교 (미술·건축 발달)
  신라: 대중 불교 (원효의 무애가)

IP 활용:
  아랑 — 백제 사원 방문 장면:
    연꽃·향·범종 소리 = 백제 불교 분위기
  고루 — 고구려 불교:
    전쟁 전 무운 기원 장면 (간략)
  하린 — 신라 불교:
    황룡사 배경 훈련 장면
```

### 도교 (道敎) 요소

```
도교 수용 (고구려 중심):
  연개소문: 도교 숭배 (삼국사기 기록)
  고구려 고분 벽화: 도교적 우주관 (사신도)

사신(四神):
  청룡(靑龍): 동쪽 수호
  백호(白虎): 서쪽 수호
  주작(朱雀): 남쪽 수호
  현무(玄武): 북쪽 수호

IP 활용:
  고루의 갑옷 문양: 현무(북방 수호) 새김
  고구려 고분 배경 장면: 사신도 벽화 등장
  을지문덕 — 도교적 초연함 (선인(仙人) 이미지)
```

## 한국 신화 존재 사전

### 수신(水神) — 강의 신

```
기본 속성:
  강·호수·바다를 관장하는 신
  형태: 용(龍) 또는 뱀 형태
  성격: 공평하고 기억력 강함

지역별 수신:
  청천강 수신: 살수대첩 전승 도움
  백마강 수신: 백제 기원 대상
  낙동강 수신: 가야 철기 수호

IP 연계:
  「강은 기억한다」= 수신이 증인
  수신은 직접 등장 금지 (암시만)
  강물의 움직임으로 수신의 존재 표현

고증 주의:
  한국 수신 = 용 형태 (중국과 공유)
  단, 한국 용은 여의주 소지·선한 존재
  → 악한 용 묘사 지양
```

### 삼신(三神) — 생명의 신

```
기본 속성:
  출산·수명·운명을 관장하는 세 신
  여성 신격 (삼신할머니)
  아이의 탄생과 죽음 관장

7세기 신앙:
  아이 출산 시 삼신께 기원
  삼신상 차리는 의식
  아이 100일·돌: 삼신께 감사

IP 활용:
  캐릭터 탄생 배경 장면에 삼신 언급
  아랑이 고아 아이를 보며 「삼신할머니가 지켜주셨구나」
  니문의 어머니가 니문에게 삼신 이야기
```

### 도깨비 (鬼)

```
기본 속성:
  한국 토착 귀신 (일본 오니와 다름)
  형태: 인간형 + 뿔 또는 봉 소지
  성격: 장난꾸러기·호기심 많음 (악이 아님)
  능력: 변신·초자연적 힘

삼국시대 도깨비:
  도깨비불 = 야간 길 안내 (민간 믿음)
  철기 관련 도깨비: 가야 철기 장인 수호

IP 활용:
  니문이 밤 강변에서 도깨비불 목격
  가야 철기 공방 주변 도깨비 전설
  도깨비 = 잃어버린 가야 혼의 상징으로 활용

주의:
  도깨비 = 한국 고유 존재 (일본 오니와 구분)
  일본식 뿔 달린 무서운 이미지 사용 금지
```

### 구미호 (九尾狐)

```
기본 속성:
  꼬리 9개 달린 여우 요괴
  형태: 아름다운 여성으로 변신
  목적: 인간의 간·생기 흡수
  유래: 중국 기원 → 한국화

삼국시대 구미호:
  민간 이야기에 등장
  아름다운 여성 = 구미호일 수 있다는 불신 문화

IP 활용 지침:
  직접 등장: 신중 (오리엔탈리즘 주의)
  언급 가능: 적의 첩자를 「구미호」라 부름
  창작 확장: 구미호 = 비극적 존재로 재해석 가능
```

### 해태 (獬豸)

```
기본 속성:
  사자와 유사한 정의의 수호 동물
  옳고 그름 판단 (법의 상징)
  불을 막는 능력

삼국시대 해태:
  궁궐·관청 수호 석상으로 설치
  법·정의의 상징 (재판 시 언급)

IP 활용:
  신라 금성 궁궐 입구 해태 석상 묘사
  하린이 선덕여왕의 판결을 「해태의 눈」으로 비유
```

## 왕국별 신앙 특성 비교

```
고구려:
  지배 신앙: 무속 + 불교 + 도교 (3중)
  수호 존재: 삼족오 (왕실 신화)
  주요 의식: 전쟁 전 점(占), 고분 제사
  사후 세계: 고분 벽화 = 저승 여행 시각화

백제:
  지배 신앙: 불교 (예술적)
  수호 존재: 백제 용 (왕실 상징)
  주요 의식: 사원 연등, 수신 제사 (백마강)
  특징: 불교 미술 최고 수준

신라:
  지배 신앙: 무속 → 불교 (이차돈 이후)
  수호 존재: 화랑 수호신 (미륵보살)
  주요 의식: 화랑 입단 의식, 황룡사 법회
  특징: 원효 이후 불교 대중화

가야:
  지배 신앙: 무속 (철기 신앙 강함)
  수호 존재: 수신 (낙동강), 철의 신
  주요 의식: 제철 의식, 수릉왕묘 제사
  특징: 철기 = 신성한 물건 (거래 의식)
```

## 창작 금지·주의 사항

```
금지:
  ✗ 불교 = 미신으로 묘사 (역사적 오류 + 종교 감정)
  ✗ 무당 = 사기꾼으로 묘사 (무속 비하)
  ✗ 한국 용 = 악한 존재 (중국·서양 용과 혼동)
  ✗ 도깨비 = 일본 오니로 묘사

주의:
  ⚠ 신화 존재 직접 등장: 암시·배경 처리 권장
  ⚠ 종교 의식 장면: 코믹 연출 금지
  ⚠ 실존 종교인 (원효·의상): 역사 고증 필수
  ⚠ 샤머니즘 의식: 오컬트·공포 연출 지양
     → 민중의 삶과 밀착된 문화로 표현

해외 출시 추가 주의:
  일본: 도깨비·구미호 = 일본 캐릭터로 오인 방지
        「한국 고유 신화 존재」명시 자막 권장
  중국: 용 = 중국 문화로 오인 방지
        「한국 신화의 용」표기
```
