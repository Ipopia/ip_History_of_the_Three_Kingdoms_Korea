## VFX 전략 개요

```
컨셉: 「역사의 무게 + 판타지의 숨결」
  과도한 CG 지양 — 실사 베이스 + 절제된 VFX
  역사 고증 최우선 → 현실감 유지
  감정적 순간: VFX가 감정 증폭 도구

예산 배분 원칙:
  전투 시퀀스: 40%
  환경/세계관 구현: 30%
  캐릭터 특수효과: 20%
  타이틀/오프닝: 10%

기술 파이프라인:
  Previs → Concept Art → 3D Modeling
  → Simulation → Compositing → Color Grade
  외주: 국내 VFX사 + 해외 협력 (필요 시)
```

## 시퀀스별 VFX 계획

### SEQ-001 오프닝 — 「강은 기억한다」

```
용도: 드라마 S1 오프닝 (약 3분)
등급: ★★★★★ (최고 품질)

컨셉:
  현대 → 과거 역행 타임랩스
  한반도 위성 뷰 → 7세기 지형으로 변환
  4왕국 수도 플라이오버
  「강은 기억한다」 텍스트 강물 위 부유

VFX 요소:
  ① 3D 지형 재현: 7세기 한반도 디지털 매트
  ② 강물 시뮬레이션: 살수·금강·낙동강 실사급
  ③ 왕국 수도 CG 재건: 평양성·사비성·금성 풀 3D
  ④ 타이틀 텍스트: 수묵화 붓터치 모션그래픽

제작 기간: 12주
추정 샷 수: 45~60샷
```

### SEQ-002 살수대첩 — 수문 개방

```
용도: S1 클라이맥스 (약 8분 시퀀스)
등급: ★★★★★

컨셉:
  을지문덕의 수문 개방 신호 → 살수 강물 범람
  113만 수나라 대군 패퇴 시각화
  고루의 눈에서 바라본 역사의 순간

VFX 요소:
  ① 강물 시뮬레이션 (메인):
     Houdini 기반 대형 물 시뮬
     실사 배경 + CG 물 합성
     5만 병사 군중 시뮬레이션
  ② 군중 시뮬레이션:
     Massive/Houdini Crowds 활용
     수나라 군복 CG 에셋 제작
     실사 촬영 병사 + CG 증폭
  ③ 환경 이펙트:
     새벽 안개 볼류메트릭 렌더링
     화살 비 시뮬레이션 (30만 발)
     전장 먼지·불꽃·연기

제작 기간: 20주 (전체 시퀀스 기준)
추정 샷 수: 180~220샷
핵심 샷:
  「수문 개방」클로즈업: 풀 CG 물 폭발
  「군중 조감」: 드론 실사 + CG 증폭
  「고루 눈빛」인서트: 반사광 특수효과
```

### SEQ-003 황산벌 결전

```
용도: S3 클라이맥스 (약 10분)
등급: ★★★★★

컨셉:
  나당연합군 10만 vs 계백 결사대 5,000
  관창 돌격 → 하린의 결단
  비극적 승리 — 전장 위 침묵

VFX 요소:
  ① 전장 규모 확장:
     실사 촬영 병사 200명 → CG 1만명 증폭
     황산벌 평야 디지털 확장
  ② 관창 특공 시퀀스:
     말 달리기 실사 + 환경 합성
     화살 맞는 순간 합성
     슬로모션 + 색감 조정 (비극성 강조)
  ③ 전투 이펙트:
     검격 광원 이펙트 (과도한 판타지 지양)
     혈흔 표현 (심의 기준 준수)
     황혼 색온도 조정 (비극적 금빛)

제작 기간: 18주
추정 샷 수: 150~180샷
```

### SEQ-004 기벌포 해전 — 22연승

```
용도: S3 피날레 (약 15분)
등급: ★★★★★

컨셉:
  기벌포 서해 새벽 대해전
  신라 수군 vs 당 함대 22연전
  최종 승리 + 니문 가야금 엔딩

VFX 요소:
  ① 해전 시뮬레이션:
     함선 3D 모델링 (신라·당 각 10종+)
     해양 시뮬레이션 (Houdini Ocean)
     함선 충돌·격파 시뮬
  ② 새벽 조명:
     HDR 새벽 하늘 + 수면 반사
     불타는 함선 불꽃·연기
     물보라 파티클
  ③ 22연승 몽타주:
     빠른 컷 편집 + VFX 강도 점층
     마지막 22번째: 슬로모션 클라이맥스

제작 기간: 22주
추정 샷 수: 200~250샷
```

### SEQ-005 수도 재건 — 환경 VFX

```
용도: 에피소드 간 장소 전환
등급: ★★★★

대상 도시 VFX:
  평양성 (고구려):
    성벽·내성·궁궐 3D 재건
    안학궁 항공뷰 CG
    철회색·청람 색조 분위기

  사비성 (백제):
    금동대향로 확대 CG
    연등 파티클 나이트씬
    미래사 목탑 디지털 재건 (약 80m 추정)

  금성/경주 (신라):
    황룡사 9층 목탑 CG (약 82m 재현)
    첨성대 일출 합성
    화랑 훈련장 환경 확장

기술:
  Photo-scan 기반 실제 유적지 스캔
  디지털 인페인팅 (현대 건축물 제거)
  시대 건축 레이어 합성
```

## VFX 에셋 목록

### 3D 에셋 (주요)

```
캐릭터 에셋:
  □ 고루 디지털 더블 (수중·고속 액션용)
  □ 아랑 디지털 더블 (낙화암 장면)
  □ 하린 디지털 더블 (기마 고속 액션)
  □ 니문 디지털 더블 (조감 장면)

군사 에셋:
  □ 수나라 병사 군중 에셋 (5종 변형)
  □ 고구려 갑옷 병사 (3종)
  □ 신라 화랑 기마 (2종)
  □ 당나라 수군 (4종)

함선 에셋:
  □ 신라 전선 (戰船) 3종
  □ 당나라 대형 함선 2종
  □ 가야 교역선 1종

건축 에셋:
  □ 평양성 내성 (풀 3D)
  □ 사비성 미래사 목탑
  □ 황룡사 9층 목탑 (경주)
  □ 황산벌 전장 지형
  □ 기벌포 해안 지형
```

### 파티클/시뮬레이션 에셋

```
물 시뮬레이션:
  □ 살수 강물 범람 (대형)
  □ 기벌포 해전 파도
  □ 금강 연등 야경 수면 반사

불/연기:
  □ 전장 화재 대형
  □ 봉화 화염
  □ 연등 불꽃 (아랑 장면)

파티클:
  □ 화살 비 (30만 발)
  □ 연등 파티클 (사비성 야경)
  □ 벚꽃/눈 날림 (계절 장면)
  □ 수묵화 먹번짐 (오프닝 타이틀)
```

## 제작 일정

```
Pre-Production (12주):
  콘셉트 아트 확정
  에셋 목록 확정
  외주사 계약

Production (40주):
  3D 모델링: 10주
  시뮬레이션: 15주
  합성(Compositing): 15주

Post-Production (8주):
  색보정(Color Grade)
  음향 싱크
  QA 검수

총 제작 기간: 약 60주 (드라마 S1 기준)
```
