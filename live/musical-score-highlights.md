# 뮤지컬 악보 하이라이트 — 삼국(三國) IP

**참조 문서**: `musical-concept.md`, `ost-concept.md`, `character-profiles.md`, `brand-identity.md`
**작성**: 공연&체험본부 공연팀 (LIVE-PERF) + 사운드본부 (SND-MUSIC)
**적용**: 삼국(三國) IP 뮤지컬 「강은 기억한다」주요 넘버 기준

## 뮤지컬 음악 개요

```
뮤지컬 제목: 「강은 기억한다 (THE RIVER REMEMBERS)」
장르: 대형 역사 뮤지컬 (Sung-through 방식)
총 넘버 수: 24곡 (1막 12곡 + 2막 12곡)
오케스트라: 25인조 (한국 전통악기 + 서양 오케스트라 혼합)

음악 감독 목표:
  한국 전통음악 + 서양 뮤지컬 하이브리드
  각 왕국별 독립된 음악 언어
  가야금 = 서사 전체를 관통하는 소리
```

---

## 오케스트라 편성

```
한국 전통악기 섹션 (8인):
  가야금 2 / 해금 2 / 대금 1 / 피리 1 / 장구 1 / 소고 1

서양 악기 섹션 (17인):
  현악: 바이올린 4 / 비올라 2 / 첼로 2 / 콘트라바스 1
  목관: 플루트 1 / 오보에 1 / 클라리넷 1
  금관: 트럼펫 1 / 트롬본 1
  타악: 팀파니 1 / 퍼커션 1

왕국별 음악 색채:
  고구려: 해금 + 트롬본 (어두운 힘)
  백제: 가야금 + 현악 (서정적 아름다움)
  신라: 대금 + 금관 (밝고 웅장)
  가야: 가야금 솔로 (순수하고 외로운)
```

## 1막 주요 넘버

### No.1 「강이 흐른다」— 오프닝 앙상블

```
부르는 자: 전체 앙상블 (니문 솔로 포함)
장면: 프롤로그 — 강가 초입

가사 (일부):
  「강이 흐른다, 오늘도 강이 흐른다
   나라가 사라진 뒤에도, 이름이 흩어진 뒤에도
   강은 기억한다, 강은 기억한다
   우리가 여기 있었다는 것을」

음악 특징:
  박자: 6/8박자 (물 흐름 리듬)
  조성: D단조 → D장조로 전환 (희망의 전환)
  주선율: 가야금 + 첼로 유니즌
  클라이맥스: 전체 합창 + 오케스트라 총주

연출:
  무대 바닥 수면 프로젝션
  앙상블 배우들 강가 돌 위에 서 있는 형상
  니문 중앙 — 가야금 연주하며 노래
```

### No.3 「살수 전야」— 고루 솔로

```
부르는 자: 고루 (바리톤)
장면: 살수대첩 전날 밤, 진영에서 홀로

가사 (일부):
  「이 강을 막겠다 — 내일 새벽
   백만 대군이 절반을 건넜을 때
   나는 문을 열 것이다

   아버지의 원수가 아니다
   이제 나는 고구려를 지키는 자
   두려움이 없다고 말하면 거짓말
   두려움이 있어도 간다 — 그것이 전사다」

음악 특징:
  박자: 4/4박자 → 자유박(아리오소)
  조성: F단조
  편성: 해금 솔로 오블리가토 + 저음 현악
  클라이맥스: 고음 F♯ — 결단의 순간

연기 지침:
  고루 배우: 바리톤, 50대 외모
  움직임 최소화 — 내면에 집중
  마지막 소절: 무릎 꿇었다 일어서는 동작
```

### No.6 「봉황이 날다」— 아랑 솔로

```
부르는 자: 아랑 (메조소프라노)
장면: 사비성에서 금동대향로를 바라보며

가사 (일부):
  「봉황이 날개를 펼친다
   향로 위에서, 연기 속에서
   이것이 우리가 만든 아름다움
   이것이 우리가 사랑한 것들

   빼앗기지 않겠다, 기억만은
   불이 타도 물이 흘러도
   봉황은 내 안에서 날고 있다」

음악 특징:
  박자: 3/4박자 (왈츠풍 — 백제 우아함)
  조성: B♭장조 → G단조 (아름다움→슬픔)
  편성: 가야금 + 현악 5중주
  중간부: 하이음 B♭ — 「빼앗기지 않겠다」

소품 연출:
  금동대향로 레플리카 무대 중앙
  아랑, 향로 주위를 천천히 돌며 노래
  조명: 황금빛 → 점차 붉은빛
```

### No.9 「7번 후퇴」— 고루 + 앙상블

```
부르는 자: 고루 + 군사 앙상블
장면: 살수대첩 — 7번 후퇴 전술 실행

가사 (일부):
  「물러서라, 한 발 물러서라
   후퇴가 패배가 아니다
   물러서면서 끌어들여라
   물러서면서 무너뜨려라

   일곱 번 물러서리라
   여덟 번째는 없다 — 그때 강이 열린다」

음악 특징:
  박자: 2/4박자 (행진곡 리듬)
  조성: D단조
  편성: 타악 + 금관 중심 (군사적)
  카논 구성: 고루 선창 → 앙상블 반복 (메아리 효과)

안무:
  후퇴 동작이 안무화: 뒤로 걸으며 노래
  조명: 무대 앞쪽(수나라 군)에서 뒤쪽으로 이동
  7번 반복 구조 — 실제 7번 반복 편곡
```

## 2막 주요 넘버

### No.13 「황산벌에서」— 하린 솔로

```
부르는 자: 하린 (테너)
장면: 황산벌 전투 후 — 계백의 시신 앞에서

가사 (일부):
  「이긴 것인가, 이것이 승리인가
   16세 소년이 앞으로 갔다
   나는 왜 뒤에 있었나

   계백 장군, 당신은 졌지만
   당신이 진 방식이 나를 이겼다
   이것이 전쟁인가, 이것이 승리인가」

음악 특징:
  박자: 자유박 → 4/4박자
  조성: E♭장조 → E♭단조 (승리→회의)
  편성: 피리 솔로 + 현악
  클라이맥스: 테너 고음 G — 감정 절정

연기 지침:
  하린 배우: 테너, 30대 외모
  계백 시신 앞 무릎 꿇는 동작
  승리한 자의 죄책감 표현
```

### No.17 「가야금의 마지막」— 니문 솔로

```
부르는 자: 니문 (카운터테너 또는 바리톤)
장면: 가야 멸망 후 강가에서

가사 (일부):
  「가야가 사라졌다
   12현이 남았다
   나라는 없지만 소리는 있다

   기억은 소리다
   소리가 있으면 기억이 있다
   기억이 있으면 가야가 있다

   나는 가야다 — 아직 여기 있다」

음악 특징:
  박자: 5/8박자 (가야 전통 리듬 차용)
  조성: A단조
  편성: 가야금 솔로 + 피치카토 현악
  특이사항: 가야금 연주자가 무대 위 등장 (배우 연주 or 별도 연주자)
  클라이맥스: 가야금 고음 현 + 카운터테너 고음 동시

의상:
  황토 #C8A96E 가야 전통 의상
  맨발 또는 짚신 — 유랑자의 상징
```

### No.21 「강은 기억한다」— 4인 + 앙상블 (클라이맥스)

```
부르는 자: 고루 + 아랑 + 하린 + 니문 + 앙상블 전원
장면: 기벌포 해전 후 — 4인 재회 현장

가사 구조:
  각 절: 각 캐릭터 솔로
  후렴: 4인 합창 + 앙상블

고루 절:
  「강을 막고 열었다, 강이 기억한다」
아랑 절:
  「봉황을 품었다, 강이 기억한다」
하린 절:
  「이기고 또 이겼다, 강이 기억한다」
니문 절:
  「소리를 남겼다, 강이 기억한다」

4인 합창:
  「강은 기억한다
   나라가 사라져도
   이름이 흩어져도
   강은 기억한다
   우리가 여기 있었다는 것을」

앙상블 합창:
  「기억한다, 기억한다
   강은 기억한다」

음악 특징:
  박자: 4/4박자 → 6/8박자 (오프닝 주제 귀환)
  조성: D장조 (오프닝의 단조에서 장조로)
  편성: 전 오케스트라 총주
  길이: 약 6분 (뮤지컬 최장 넘버)
  클라이맥스: 모든 배우 무대 위 + 조명 전개
```

### No.24 「에필로그 — 강이 흐른다」— 니문 솔로

```
부르는 자: 니문 (노년, 독창)
장면: 수십 년 후 — 노인이 된 니문, 강가에서

가사 (일부):
  「강은 오늘도 흐른다
   그들이 없어도 강은 흐른다
   나는 기억한다
   그것으로 충분하다

   강이 흐르는 한
   우리는 사라지지 않는다」

음악 특징:
  박자: 자유박 (루바토)
  조성: D장조 (No.1 오프닝 조성으로 귀환)
  편성: 가야금 솔로 only (오케스트라 없음)
  길이: 약 3분 (단순하고 조용하게)
  마지막 음: 가야금 줄 퉁기고 소리 사라질 때까지 침묵

연출:
  무대 완전 어둠 → 조명 하나 (니문만 조명)
  관객 완전 침묵 요구
  커튼콜 전 30초 침묵 유지
```

## 음악 제작 기준

```
악보 저작권:
  작곡: 외부 작곡가 위탁 (공모 또는 지명)
  편곡: 뮤지컬 음악감독 책임
  저작권: IP 프로젝트 귀속 (작곡가 로열티 계약)

녹음 기준:
  오케스트라 녹음: 스튜디오 레코딩 (공연 전)
  Cast 앨범: 초연 후 발매
  OST 연계: 드라마 OST와 멜로디 공유 (No.21 주선율)

배우 음역 기준:
  고루: 바리톤 (F2~E♭4)
  아랑: 메조소프라노 (A3~B♭5)
  하린: 테너 (C3~G4)
  니문: 카운터테너 (E3~E5) 또는 바리톤 투 캐스팅
```
