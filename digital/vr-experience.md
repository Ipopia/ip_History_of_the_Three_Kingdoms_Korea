## 에피소드 구성

### EP.1 — 「안시성의 88일」(고구려)

```
시점: 1인칭 (안시성 병사)
시대: AD 645 — 당태종 침공
체험 시간: 40분

구성:
  Part 1 — 성벽 위 (10분)
    위치: 안시성 성벽 상단
    체험: 봉화 점화 → 원경으로 당나라 대군 관찰
    인터랙션: 봉화 레버 당기기 (핸드 트래킹)
    환경: 요동 평원 파노라마 360도
    NPC: 고루 등장 — 작전 브리핑

  Part 2 — 공성전 방어 (20분)
    체험: 성벽 위 방어전 참여
    인터랙션:
      활 쏘기 (컨트롤러 활시위 당기기)
      끓는 기름 투하 (양손 들어올리기)
      공성탑 격퇴 (횃불 투척)
    3D 오디오: 함성·화살·공성 충돌음 방향별 분리
    난이도: 3단계 (체험/보통/영웅)

  Part 3 — 당태종 퇴각 (10분)
    체험: 성벽 위에서 퇴각하는 당군 관찰
    연출: 골든아워 역광 — 당태종이 성을 올려다보는 씬
    감정: 승리의 안도 + 전쟁의 참상 공존
    NPC 고루: 「우리는 지켰다. 그러나 이 전쟁은 끝나지 않았다.」
```

### EP.2 — 「사비성의 마지막 연등」(백제)

```
시점: 1인칭 (왕실 문서관 견습)
시대: AD 660 — 백제 멸망 전야
체험 시간: 35분

구성:
  Part 1 — 연등 축제 (12분)
    위치: 사비성 중심 거리
    체험: 연등 축제 자유 보행
    인터랙션:
      연등 만들기 (핸드 트래킹 — 종이 접기·촛불 넣기)
      연등 강에 띄우기
    환경: 따뜻한 연등빛, 시장·악사·춤
    NPC 아랑: 연등의 의미 설명

  Part 2 — 사비성 함락 (15분)
    시간 경과: 연등 축제 → 갑작스러운 전쟁 함성
    체험: 나당연합군 진입 목격
    인터랙션:
      문서 보따리 챙기기 (죽간 수집)
      탈출 경로 선택 (분기)
    연출: 연등이 하나씩 꺼지는 연출
    3D 오디오: 축제 음악 → 전쟁 소리 크로스페이드

  Part 3 — 낙화암 (8분)
    위치: 낙화암 절벽
    체험: 절벽에서 강을 바라보는 관조적 시점
    인터랙션: 없음 (관찰·감상 전용)
    연출: 꽃잎이 떨어지는 씬 — 슬로모션
    NPC 아랑 독백: 「기록된 것은 사라지지 않는다.」
```

### EP.3 — 「기벌포의 22번째 파도」(신라)

```
시점: 1인칭 (신라 수군 병사)
시대: AD 676 — 기벌포 해전
체험 시간: 35분

구성:
  Part 1 — 출항 (8분)
    위치: 신라 군항
    체험: 전함 탑승 → 서해 출항
    인터랙션: 노 젓기 (양손 컨트롤러)
    환경: 새벽 바다 — 안개·파도
    NPC 하린: 출전 독백

  Part 2 — 해전 (20분)
    체험: 함상 전투 참여
    인터랙션:
      창 투척 (컨트롤러 스로잉)
      방패 방어 (왼손 컨트롤러)
      화공 발사 (투석기 조준·발사)
    라운드 구성: 22라운드 중 3라운드 체험 (5·15·22라운드)
    환경: 파도·바람 물리 시뮬레이션
    3D 오디오: 파도·함포·전함 충돌

  Part 3 — 승전 (7분)
    체험: 22전 22승 후 갑판 위
    연출: 석양 → 승리의 함성 → 고요
    NPC 하린: 「22번 싸웠다. 22번 이겼다.
               그러나 나는 얼마나 많은 것을 잃었는가.」
```

### EP.4 — 「12번째 현」(가야)

```
시점: 1인칭 (니문)
시대: AD 555~562 — 대가야 말기
체험 시간: 30분

구성:
  Part 1 — 가야금 수업 (12분)
    위치: 대가야 고령 — 우륵의 거처
    체험: 가야금 연주 체험
    인터랙션:
      가야금 12현 각각 터치 (핸드 트래킹)
      현 튕기기 → 실제 가야금 사운드 재생
      12곡 중 3곡 연주 도전 (리듬 게임 요소)
    환경: 대나무 숲·낙동강·새소리
    NPC 우륵: 각 현의 의미 교습

  Part 2 — 가야 멸망 (10분)
    시간 경과: 평화 → 신라군 접근
    체험: 마지막 밤 — 우륵과 탈출 준비
    인터랙션: 가야금 3대 보따리 포장
    연출: 멀리서 봉화·함성 접근
    NPC 이진아시왕: 「가야금을 가져가라. 어디든 좋다.」

  Part 3 — 강을 건너다 (8분)
    체험: 밤에 낙동강 도하
    인터랙션: 뗏목 노 젓기 (느린 속도)
    환경: 달빛·강물 소리·뒤돌아보면 불타는 고령
    NPC 우륵: 「가야금이 있는 곳이 가야다.」
    마지막: 강 건너편 도착 — 니문이 가야금을 연주
```

## 기술 사양

### 하드웨어 기준

```
Meta Quest 3 (스탠드얼론):
  해상도: Eye당 2064×2208
  프레임: 90fps (필수) / 120fps (권장)
  렌더링: Foveated Rendering 적용
  핸드 트래킹: v2.0 지원 (가야금 씬 필수)

PlayStation VR2:
  해상도: Eye당 2000×2040
  프레임: 90fps / 120fps
  Haptic: 컨트롤러 진동 + 헤드셋 진동
  Eye Tracking: 주시 기반 렌더링

PC VR (SteamVR):
  최소: RTX 3060 / RX 6700 XT
  권장: RTX 4070 / RX 7800 XT
  해상도: Eye당 2160×2160 이상
```

### 렌더링 파이프라인

```
엔진: Unreal Engine 5.4+
렌더링:
  Forward Rendering (VR 최적화)
  MSAA 4x (안티앨리어싱)
  Dynamic Foveated Rendering (Eye Tracking 연동)

LOD 전략:
  캐릭터: 3단계 LOD (근거리 50K → 원거리 5K 폴리곤)
  환경: Nanite 활용 (PC VR) / 수동 LOD (Quest)
  파티클: GPU 파티클 (물·불·연등)

최적화:
  Quest: Fixed Foveated Rendering + Application SpaceWarp
  PSVR2: Eye-Tracked Foveated Rendering
  PC: Variable Rate Shading + DLSS/FSR
```

### 3D 오디오

```
오디오 엔진: Steam Audio / Meta Spatial Audio
구현:
  방향성: 모든 SFX 3D 공간 배치
  반사: 실시간 음향 반사 (성벽·실내)
  거리감: 거리 기반 감쇄 + 오클루전
  가야금: HRTF 기반 정밀 방향 (12현 각각 위치)

사운드 레이어:
  앰비언스: 왕국별 환경음 루프 (4채널 이상)
  BGM: 적응형 음악 (체험 진행도 연동)
  SFX: 인터랙션 피드백 (즉각 반응)
  보이스: NPC 대사 3D 배치
```

## 인터랙션 디자인

### 핸드 트래킹 활용

```
활 쏘기 (EP.1·3):
  왼손: 활 몸체 잡기 (그립)
  오른손: 시위 당기기 (핀치)
  조준: 화살 방향 = 손 방향
  발사: 핀치 해제

가야금 연주 (EP.4):
  핸드 트래킹 전용 (컨트롤러 내려놓기)
  12현 각각 터치 인식
  튕기기 강도 = 손가락 속도
  양손 동시 연주 지원
  진동 피드백: 컨트롤러 장착 시 현 진동 재현

붓 쓰기 (특별편):
  핸드 트래킹 / 컨트롤러 양립
  붓 방향: 손목 회전 추적
  획 두께: 이동 속도 반비례
  잉크 효과: 파티클 시뮬레이션
```

### 이동 시스템

```
기본: 텔레포트 이동 (멀미 방지)
옵션: 자유 이동 (부드러운 로코모션)
특수:
  뗏목 탈승 (EP.4): 앉은 자세 + 노 젓기
  함상 (EP.3): 갑판 위 자유 보행 + 배 흔들림 보상
  성벽 (EP.1): 계단 이동 + 성벽 위 자유 보행

멀미 대응:
  비네팅: 이동 시 시야 좁힘 (조절 가능)
  고정 참조점: HUD 코 영역 표시 (옵션)
  텔레포트 기본: 모든 에피소드 텔레포트 기본값
```
