## 4왕국 팬덤 구도 설계

```
핵심 아이디어:
  「어느 왕국이 당신의 왕국인가?」

왕국별 팬덤 DNA:
  고구려 팬덤 (삼족오군):
    색상: 암청 (#2F4F7F)
    응원 구호: 「삼족오가 난다」
    팬덤 특성: 전략·역사 마니아, 을지문덕 팬
    활동: 전투 씬 분석, 역사 고증 토론

  백제 팬덤 (봉황단):
    색상: 왕실금 (#B8960C)
    응원 구호: 「기록은 남는다」
    팬덤 특성: 아랑·성충 중심, 문학·기록 감성
    활동: 팬픽·기록 형식 2차 창작

  신라 팬덤 (황금화랑):
    색상: 황금 (#FFD700)
    응원 구호: 「화랑의 길로」
    팬덤 특성: 하린·선덕여왕 팬, 감성 중심
    활동: 팬아트, 하린 도덕적 딜레마 토론

  가야 팬덤 (낙동강단):
    색상: 토황 (#C8A96E)
    응원 구호: 「12번째 현」
    팬덤 특성: 니문·음악 중심, 음악·예술 관심층
    활동: 가야금 연주 커버, 음악 분석

4왕국 팬덤 균형 원칙:
  특정 왕국 팬덤 과도한 우대 금지
  왕국 간 건전한 경쟁 유도 (악성 팬덤 전쟁 방지)
  모든 왕국이 빛나는 순간 공평하게 콘텐츠 제공
```

## 공식 팬카페 운영 (네이버)

```
카페 구조:
  ① 공지·뉴스: 공식 발표 전용
  ② 왕국별 게시판: 4왕국 각각 (고구려·백제·신라·가야)
  ③ 팬아트 갤러리: 공식 인정 팬아트 전시
  ④ 역사 토론방: 역사 고증 심층 토론
  ⑤ 이벤트 참여: 공모전·이벤트 전용
  ⑥ 굿즈 정보: 공식 굿즈 정보 + 구매 링크
  ⑦ 해외 팬 코너: 영어·일어 게시글 허용 구역

운영 규칙:
  왕국 간 악성 비방 금지 (3회 경고 → 활동 정지)
  배우 사생활 침해 게시물 즉시 삭제
  역사 왜곡 게시물 (임나일본부설 등) 즉시 삭제
  팬아트 무단 상업적 사용 금지 안내

등급 시스템:
  새내기 → 화랑 → 대신 → 장군 → 대막리지
  등급별 특별 혜택 (굿즈 선구매·이벤트 우선권)
```

## 팬 창작 활성화

```
팬아트 공모전 (분기별):
  주제: 각 분기 드라마 주요 장면
  참가: 전 세계 (SNS 해시태그 + 카페 업로드)
  심사: 공식팀 + 팬 투표 (50:50)
  수상작:
    대상 1명: 배우 친필 사인 굿즈 세트
    금상 5명: 왕국 한정판 박스
    입선 50명: 공식 이모티콘 세트

팬픽 (2차 창작) 정책:
  공식 허용:
    비상업적 팬픽·팬아트 전면 허용
    창작자 표기 필수 (원작: 삼국(三國) IP)
  금지:
    상업적 판매 금지 (허가 없이)
    실존 배우 기반 실제 같은 묘사 금지
    역사 왜곡 내용 (임나일본부설 등)

공식 팬픽 공모전 (연 1회):
  주제: 「강은 기억한다」외전 이야기
  대상: 을지문덕 청년 시절 / 우륵 마지막 연주 등
  수상작: 공식 출판 가능성 검토 (웹소설 형식)
```

```
  팬 아트 오프라인 전시
  팬 코스튬 콘테스트 (왕국별 4관왕)
  가야금 팬 연주 무대 (니문 테마 커버)
  수익 일부 역사 교육 기관 기부
```

## 유해 팬덤 관리

```
모니터링 체계:
  24시간 키워드 모니터링 (SNS·커뮤니티)
  전담 모더레이터 5인 (한국·일본·영어권 분담)
  신고 시스템: 모든 채널에 신고 버튼

대응 원칙:
  Level 1 (경고): 개인 DM 경고
  Level 2 (제한): 7일 게시물 제한
  Level 3 (차단): 영구 차단

특별 모니터링 항목:
  왕국 간 악성 비방 → Level 2 즉시 적용
  배우 사생활 침해 → Level 3 즉시
  역사 왜곡 (임나일본부설 등) → 즉시 삭제 + Level 2
  타 IP 비방 → Level 1

팬덤 건강성 지표:
  월간 팬아트 업로드 수
  팬 가입·탈퇴 비율
  신고 건수 추이
  → 분기별 팬덤 건강성 보고서 작성
```

## 팬 커뮤니티 수익 기여

```

  팬카페 유료 등급 (월정액 3,000원): 예상 10만명 = 3억원/월
  디스코드 부스트: 예상 5,000명 = 1억원/년

  팬아트 → SNS 바이럴 → 신규 시청자 유입

KPI:
  팬카페 가입자: 100만명 (방영 1년 내)
  디스코드 멤버: 글로벌 50만명
  팬아트 월간 업로드: 10,000건+
```
