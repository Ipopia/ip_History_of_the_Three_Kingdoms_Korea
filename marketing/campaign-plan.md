## Phase A: 비밀 점화 캠페인 (D-90~D-30)

### 컨셉: "강은 기억한다"

아무 설명 없이 영상·이미지·소리만으로 삼국의 존재감을 알린다. 브랜드명 공개 없이 미스터리로 시작.

### Week 1~4: 티저 영상 시리즈

**티저 #1 — "물소리"** (D-90)
```
내용: 강물 흐르는 영상 + 한국어 내레이션
"강은 기억한다. 1,600년 전의 전쟁을."
길이: 15초
플랫폼: 유튜브·인스타·틱톡 동시
CTA: 없음 — 순수 미스터리
```

**티저 #2 — "삼족오"** (D-75)
```
내용: 어둠 속에서 삼족오 실루엣 등장
배경음: 거문고 저음 + 북소리
길이: 20초
텍스트: "그들이 돌아온다"
```

**티저 #3 — "세 빛"** (D-60)
```
내용: 세 가지 색 빛 충돌 (철흑·백토·황금)
= 고구려·백제·신라 색채
길이: 30초
음악: 메인 테마 10초 발췌
```

**티저 #4 — "이름들"** (D-45)
```
내용: 역사 인물 이름들이 화면에 흩어짐
광개토대왕 / 을지문덕 / 계백 / 선덕여왕 / 우륵...
길이: 45초
처음으로 "삼국(三國)" 로고 5초 노출 후 암전
```

### 미스터리 마케팅 장치

**오프라인 게릴라**
```
- 서울 주요 지하철역 벽면: 삼국 지도 그라피티 (허가 취득)
- 한강변: "강은 기억한다" 물에 써진 글귀 영상
- 경주·부여·공주 역사 유적지: QR코드 스티커 부착
  → QR 접속 시 삼국 미스터리 영상 재생
```

**온라인 ARG (Alternate Reality Game)**
```
- 삼국 관련 수수께끼 계정 @river_remembers 운영
- 팔로워가 단서 조합하면 '삼국' 정체 공개 — 참여 유도
- 역사 퀴즈 형식 + 커뮤니티 협력 해결
- 최초 50명 정답자: VIP 프리미어 초청권
```

## Phase B: 폭발 공개 캠페인 (D-30~D-Day)

**공개 이벤트**
```

동시 이벤트: 역사 인물 일러스트 4종 공개

**트레일러 배포 전략**

### 프레스 오픈 이벤트 (D-20)

**행사 개요**
```
장소: 국립중앙박물관 또는 경복궁 특설 무대

프로그램:
  - 삼국 IP 세계관 프레젠테이션 (30분)
  - 아트 전시: 주요 캐릭터·환경 일러스트
  - OST 미니 라이브: 전통 악기 연주
  - IP 바이블 핵심 발췌 공개
  - Q&A + 네트워킹
