## 1. 기본 외형 사양

### 신체 정보

```
이름     : 고루 (高流, Goru)
나이     : 18세 (시즌 1 기준, 612년)
성별     : 남성
신장     : 181cm
체중     : 약 78kg (무관 근육질 기준)
체형     : 역삼각형 — 넓은 어깨, 단단한 흉근, 좁은 허리
           북방 기마 전사 체형 / 장거리 행군 적합
체지방   : 낮음 (실전 무관)
손       : 크고 각진 손 — 창 훈련의 굳은살 (오른 손바닥)
```

### 얼굴 특징

```
전체 인상  : 묵직하고 신중한 북방 무장 — 나이보다 성숙한 인상
얼굴형     : 각진 윤곽 — 광대뼈 강조, 넓은 턱
피부       : 북방 햇볕에 그을린 구릿빛 (황동색 조)
눈         : 쌍꺼풀 없는 날카로운 눈매 / 홍채색 짙은 갈색
눈썹       : 굵고 직선적 — 고구려 무장 전형
코         : 높고 큰 코 — 북방 체형
입         : 두껍고 굳게 다문 형
턱         : 각지고 강인한 윤곽

식별 특징:
  - 왼쪽 귀 위 오래된 흉터 (어린 시절 훈련 중 부상, 3cm 직선)
  - 시즌 2 이후 눈 아래 얕은 흉터 추가 (안시성 전투 후)
  - 항상 약간 찡그린 듯한 집중 표정이 기본값
```

### 머리카락

```
색       : 칠흑 (#0D0D0D)
질감     : 굵고 직선적

시즌별 변화:
  S1 초반  : 짧게 자른 머리 — 군 훈련병 양식
  S1 후반  : 묶은 상투 시작 (을지문덕 제자 인정 후)
  S2~S3   : 완성된 고구려 무관 상투 — 청동 비녀 고정

고구려 무관 상투 규격:
  위치     : 정수리 중앙
  고정     : 단조 청동 비녀 (삼족오 문양 양각)
  헤어라인 : 이마 위 두 손가락 여백
```

## 3. 복식 상세 사양

### A. 일상 / 일반 복식 (S1 중급 장교)

```
상의    : 암청 (#2F4F7F) 유(襦) — 소매 좁은 직령형
          겉섶 오른쪽 여밈 (우임) / 실용적 면·삼 혼방
하의    : 암청 고(袴) — 기마용 폭 넓은 바지
          허벅지 보강 가죽 패치 내측 (기마 마찰 보호)
허리    : 혁대 (革帶) — 철제 과대 버클 황동 도금
          전투 소품 홀더 4개 (좌 2 / 우 2)
겉옷    : 철회 포(袍) — 소매 좁은 직령포, 무릎 길이
신발    : 암청 가죽 장화 — 기마용 발목 높은 형
장신구  : 청동 비녀 (상투), 손목 가죽 보호대 (양손)
```

### B. 전투 복식 (갑주 완전 착용)

```
갑옷 본체:
  종류    : 찰갑 (札甲) — 소형 철판 2,000+ 연결
  재질    : 단조 철판 / 황동 리벳 고정
  색처리  : 무광 철회 (#708090) + 황동 테두리
  어깨    : 파우르돈형 철판 어깨보호대
            → 오른쪽 어깨: 삼족오 금 부조 문양 (을지문덕 표식)
  흉갑    : 판형 철판 + 찰갑 혼합
  팔      : 전완 철제 보호대 + 가죽 기본 장갑

투구:
  종류    : 종정형 (縱頂形) — 정수리 세로 능선 특징
  재질    : 철제 / 황동 테두리 장식
  뺨보호  : 좌우 양쪽 철판 (볼 절반 가림)
  목보호  : 찰갑 라멜라 후면 하단 (4단)

무기 착용 위치:
  주무기  : 「살수의 창」— 오른손 / 등 대각선 착용 시
  보조    : 환두대도 — 왼쪽 허리 (오른손 발도용)
  투척용  : 단병 (短柄) 도끼 1정 — 오른쪽 허리

망토 (전투 시 선택 착용):
  색      : 암청 (#2F4F7F) 겉면 / 주홍 (#CC3300) 안감
  길이    : 어깨~무릎 (기마 시 뒤로 펄럭)
  고정    : 오른쪽 어깨 삼족오 버클
```

### C. 예복 (궁중·외교·의례)

```
포(袍)   : 고급 비단 암청 직령포 — 소매 넓음 (문관식 변형)
           하단 테두리: 황동색 운문(雲紋) 자수
관모     : 복두(幞頭) — 검은 비단 / 황동 관식 장식
허리띠   : 금동제 과대 — 황동 판 연결형 (계급 표시)
신발     : 흑색 비단 이(履) — 황동 버클
장신구   : 오른쪽 검지 반지 (철제, 을지문덕 유품)
         : 청동 비녀 (상투, 예복 시에도 유지)
특이사항 : 살수의 창은 예복 시 착용 불가 → 단검만 허리 소지
```

## 4. 특징적 소품 상세

### 전용 무기 — 「살수의 창 (槍)」

```
공식명칭 : 살수의 창 (槍, Salsu Spear)
전수자   : 을지문덕 → 고루 (S1 살수대첩 직전 수여)
길이     : 240cm (날 포함)
날       : 철제 삼지창형 날 — 중앙 주날 40cm + 좌우 부날 15cm
자루     : 물푸레나무 — 살수에서 채취한 목재 (서사적 의미)
장식     : 자루 상단 1/4 지점: 황동 삼족오 양각 링
           날 기저: 「살수지창 (薩水之槍)」 한자 음각
손잡이   : 가죽 그립 — 고루의 오른손 굳은살 흔적 (마모)
무게     : 약 3.2kg
보관     : 등 대각선 착용 (전투) / 가죽 케이스 (평시)

시각적 포인트:
  - 자루 하단 1/3: 살수 강물에 담갔던 흔적 (옅은 청록빛 자국)
  - 날 부분: 항상 광택 유지 (고루의 일과)
  - 창 전체: 낡았으나 완벽하게 정비된 상태 (애착 표현)
```

### 보조 소품

```
손목 가죽 보호대:
  색     : 암갈색 (#4A2E0C) 마모된 가죽
  위치   : 양 손목 상시 착용 (예복 제외)
  의미   : 살수대첩 당시 착용품 — 기억의 닻
  상태   : 닳고 수선된 흔적 다수 (7년치 마모)

철제 반지:
  위치   : 오른쪽 검지
  재질   : 철 (금 아님) — 고구려 무인의 소박함
  문양   : 을지문덕 가문 문장 (한자 「乙」 음각)
  의미   : 스승의 유품, S2 이후 착용 시작

청동 비녀:
  재질   : 청동 (은도금 없음)
  문양   : 양 끝 삼족오 양각 (소형)
  상태   : 약간의 녹청 흔적 (진정성)
```

## 5. 표정·감정 스펙 (5종)

### 기본 표정 규칙

```
고루의 얼굴은 항상 절제되어 있다.
감정이 드러날 때는 눈의 미세 변화와 입술 긴장으로만.
눈물은 S3 이전 절대 금지 (캐릭터 일관성 규칙).
```

### 표정 1 — 평온 (Calm) ★기본값

```
눈      : 반쯤 좁혀진 눈 — 경계와 관찰 사이 어딘가
눈썹    : 수평 — 힘이 들어가지 않은 자연 상태
입      : 굳게 다문 직선 — 말하지 않는 침묵
턱      : 가볍게 앞으로 당긴 자세 (경계 자세)
전체    : 주변을 조용히 스캔하는 눈빛 / 정지한 강물

아트 디렉션:
  눈빛에 「먼 데를 보는 듯한 깊이」유지
  표정 근육 최소 활성 — 이완되어 있되 완전히 풀리지 않음
```

### 표정 2 — 결의 (Resolve) ★핵심 표정

```
눈      : 완전히 뜬 눈 — 홍채 최대 노출 / 정면 응시
눈썹    : 약간 안쪽으로 모임 — V자 긴장
입      : 굳게 다문 직선 / 입꼬리 아래로 1-2mm
턱      : 앞으로 내밀림 — 전진 의지
목      : 근육 긴장 가시적
전체    : 「살수의 창을 쥐기 직전」의 순간

대표 장면: 살수대첩 출진 / 을지문덕 유언 수령 / 연개소문 대면
```

### 표정 3 — 분노 (Suppressed Anger) ★절제된 분노

```
주의    : 고루의 분노는 폭발하지 않는다. 내부에서 눌린다.

눈      : 가늘게 좁혀짐 — 눈꼬리 당김
눈썹    : 안쪽 모임 강화 / 눈썹 사이 세로 주름 1-2개
입      : 양 입꼬리 내려감 / 입술 안으로 말림
코      : 콧망울 약간 벌어짐
턱      : 강하게 닫힌 — 어금니 물기 가시적
목      : 목 근육 전체 긴장
손      : 주먹 쥠 (창 없을 때) / 창 자루 꽉 쥠

아트 디렉션:
  눈빛: 뜨겁지 않고 차갑다 — 「차가운 불」
  표정 전체가 안으로 수렴하는 방향성
```

### 표정 4 — 슬픔 (Grief) ★S2 이후 등장

```
눈      : 평소보다 약간 크게 열림 — 방어가 무너지는 순간
눈썹    : 중앙 위로 약간 올라감 — 어린아이 같은 순간적 노출
입      : 굳게 다물려 하나 입꼬리가 아래로 당겨짐
목      : 아래로 약간 고개 숙임
전체    : 보는 이가 「아프다」고 느끼는 미세한 균열

대표 장면: 을지문덕 사망 장면 / 아버지 기일 / 살수 바라볼 때
아트 디렉션:
  눈물은 S3 이전 절대 없음
  슬픔이 눈빛에 번지되 표정 외면으로 완전히 터지지 않음
  보는 이만 느끼는 절제의 슬픔
```

### 표정 5 — 희미한 기쁨 (Restrained Joy) ★드물게 등장

```
빈도    : 전체 에피소드 중 10회 미만 (희소성 = 임팩트)

눈      : 살짝 부드러워진 눈꼬리 — 실낱 같은 따뜻함
눈썹    : 완전히 이완 — 처음으로 풀린 표정
입      : 직선이되 양 끝이 0.5mm 올라감 (웃음이라 부르기 어려운 웃음)
전체    : 마치 「잠깐 얼음이 녹는 순간」

대표 장면: 아랑 첫 서신 수령 / 동료 연장과 농담 / S3 하린과 전우애
```

## 6. 캐릭터 포즈 스펙 (기본 3종)

### 포즈 1 — 정면 기본 (Standard Front)

```
용도    : 캐릭터 카드 / 피규어 정면 기준 / 프로필

자세    :
  발    : 어깨 너비 벌림 (25°-25°) — 안정적 기마 자세
  무릎  : 미세하게 굽힘 (5°) — 항시 전투 준비
  허리  : 곧고 균형잡힘
  어깨  : 완전히 펴짐 — 양어깨 수평
  팔    : 오른팔 — 창 세로 쥠 (자루 바닥이 오른발 옆 바닥에)
          왼팔 — 자연스럽게 내려 엄지가 허리띠 근처
  시선  : 정면 응시 / 카메라를 보되 뚫어보는 눈빛
  턱    : 살짝 앞으로 내밈 (자신감, 위협적이지 않게)
  표정  : 결의 (표정 2번)

배경 기준 색: 암청 (#2F4F7F) 그라디언트 → 흑야 (#1A1A2E)
```

### 포즈 2 — 측면 관찰 (Profile Scan)

```
용도    : 캐릭터 시트 측면 / 실루엣 확인 / 애니 원화 기준

자세    :
  발    : 완측면 (90° 왼쪽이 카메라 향함)
          오른발 약간 앞 / 왼발 뒤 — 이동 준비
  무릎  : 오른 무릎 약간 굽힘
  허리  : 곧음
  어깨  : 왼쪽 어깨가 앞, 오른쪽 뒤
  팔    : 오른팔 — 창을 등에 대각선으로 걸쳐 쥠
          왼팔 — 자연스럽게 내려 좌측 허리 수확체 근처
  시선  : 왼쪽 방향 (무언가를 관찰 중) / 눈 좁혀짐
  표정  : 평온 (표정 1번)

실루엣 체크포인트:
  어깨 넓이 > 허리 (역삼각형 명확)
  투구 착용 시 — 종정형 능선 프로파일 확인
  창 대각선이 실루엣에서 뚜렷이 구분
```

### 포즈 3 — 전투 동작 (Combat Dynamic)

```
용도    : 액션 씬 키아트 / 게임 스플래시 / 웹툰 전투 컷

자세    :
  기본  : 오른발 전방 돌진, 왼발 뒤 고정 (창 찌르기 직전 순간)
  무릎  : 오른 무릎 90° 굽힘 / 왼 무릎 150°
  허리  : 오른쪽 회전 — 상체가 창 방향으로 비틀림 (30°)
  어깨  : 오른어깨 앞 / 왼어깨 뒤
  팔    : 오른팔 — 창 앞으로 쭉 뻗음 (지면과 15° 각도 위)
          왼팔 — 창 자루 중간 잡아 보조
  창    : 수평에서 약간 위 (목 높이 타격 궤적)

전투 모드 비주얼 추가:
  망토    : 뒤로 펄럭임 (암청 겉 / 주홍 안 노출)
  갑옷    : 찰갑 철판이 움직임에 따라 약간 벌어짐
  눈빛    : 결의 + 분노 혼합 (표정 2+3 중간)
  배경    : 살수 강물 또는 전장 먼지
  효과    : 창 날 부분에 미세한 빛 반사 이펙트

카메라 앵글 제안:
  메인키아트: 낮은 앵글 (허리 높이) → 위압감 강화
  웹툰 컷   : 정면 또는 45° 사이드
  게임 스플래시: 3/4 앵글 (왼쪽 앞 45°)
```
