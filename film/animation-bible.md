# 애니메이션 바이블 — 삼국(三國) IP

## 애니메이션 프로젝트 개요

```
형식: TV 애니메이션 시리즈 (2D + 3D 하이브리드)
화수: 시즌 1 = 24화 (드라마 S1 기반)
화당 런타임: 23분 (OP·ED 포함 25분)
목표 등급: 전체이용가 (12세이용가 변형 버전 별도)
타겟: 청소년~성인 (15~35세), 해외 수출 고려

제작 방식:
  주요 캐릭터: 2D 셀 애니메이션 (60fps)
  배경: 3D 환경 + 2D 합성
  전투 VFX: 3D CG + 2D 효과선 합성
  컷씬: 2D 풀 애니메이션

타깃 퀄리티:
  국내: KBS·MBC 애니메이션 이상
  해외: 「귀멸의 칼날」스타일 하이브리드 (참고 방향)
  단, 일본풍 과도한 표현은 배제
```

## 시각 스타일 가이드

### 전체 아트 스타일

```
캐릭터 비율:
  성인: 6.5~7두신 (사실적, 과장 없음)
  아동 (관창 등): 4.5~5두신
  코믹 변형 없음 (개그 장면 비율 유지)

선화 스타일:
  메인 선: 0.5pt (가변 — 굵기 변화로 입체감)
  세밀 묘사: 0.3pt
  실루엣 강조: 1.0pt
  선 색: 검정 or 왕국별 어두운 색조 사용

채색 스타일:
  평면채색 + 다층 그림자 (셀셰이딩 2단계)
  하이라이트: 단순 (과도한 반짝임 금지)
  피부색: 황인계 (황갈색 기준)
  금지: 흰 피부·파란 눈 (아시아 역사 배경)
```

### 배경 스타일

```
기본 방침:
  3D 로우폴리 배경 + 2D 페인팅 오버레이
  사진 참조: 한반도 실제 지형 (강·산성·평야)
  역사 고증: 실제 발굴 유적·고분벽화 참조

배경 디테일 수준:
  주요 장면: HIGH (벽돌·나무결·수면 디테일)
  일반 장면: MID (간략화 가능)
  원경: LOW (실루엣 중심)

왕국별 배경 색온도:
  고구려: 쿨톤 (청회 2700K 느낌)
  백제: 웜톤 (황금 5000K 느낌)
  신라: 밝은 웜톤 (6500K 느낌)
  가야: 황토 웜톤 (3500K 느낌)
```

## 캐릭터 애니메이션 기준

### 고루 모션

```
이동:
  걷기: 느리고 무거운 보폭 (철갑 무게감)
  달리기: 묵직한 가속 (빠르지 않음)
  말 탑승: 직립 자세 (무게감 유지)

전투:
  기본 공격: 큰 스윙 모션 (검 앞으로 내밀기)
  방어: 검으로 받아내기 (방패 없음)
  특수 스킬: 묵직한 단발 강타
  금지: 아크로바틱·빠른 발놀림

표정 애니메이션:
  기본: 무표정 (입 굳게 다문 상태)
  결단: 눈 반쯤 감음 → 뜸
  드문 감정: 극히 미세한 입 꼬리 변화
  눈물: S3 기벌포 1회만 허용

FPS:
  일반 모션: 30fps
  전투 모션: 60fps
  클로즈업 표정: 60fps
```

### 아랑 모션

```
이동:
  걷기: 비단 의상 흔들림 포함 (물리 시뮬)
  앉기·서기: 우아하고 절도 있음
  직접 전투 모션: 없음 (금지)

행동:
  자수 작업: 손 클로즈업 디테일 모션
  가야금 바라보기: 섬세한 손 움직임
  자수 바늘 방어 (1회): 본능적·빠른 모션 (전술 아님)

표정 애니메이션:
  기본: 부드럽고 차분
  슬픔: 눈물 절제 (직접 표현 적음)
  결의: 눈빛 굳어짐 (극적 변화)
  의상 물리: 비단 소매 바람에 흔들림 필수
```

### 하린 모션

```
이동:
  걷기: 경쾌하고 빠른 걸음
  달리기: 가볍고 역동적
  기마: 말과 일체감 (기마 궁사 전용 모션)

전투:
  기본 공격: 단검 경쾌한 다중 타격
  원거리: 기마 중 활 사격 (이동+공격 동시)
  회피: 빠른 방향 전환·구르기 허용
  S3 변화: S1 충동적 → S3 절제된 동작

표정 애니메이션:
  기본: 밝고 결의찬 표정
  전투: 집중+긴장 혼합
  죄책감 (황산벌 후): 입 다물고 눈빛 무거워짐
  성장 표현: 시즌별 동작 성숙도 차이 명확히
```

### 니문 모션

```
이동:
  걷기: 가볍고 조용한 걸음 (짚신 소리 없음)
  앉기: 가야금과 함께 자연스러운 자세
  도주 (위기 시): 빠르지만 전술 아닌 본능

행동:
  가야금 연주: 12현 손동작 정확히 재현
    (실제 가야금 연주 동작 자문 필수)
  죽간 기록: 붓질·새기기 손 동작
  눈 감기: 연주 중 자주 (집중 표현)

표정 애니메이션:
  기본: 조용하고 사색적
  연주 중: 눈 감음 or 반쯤 뜬 상태
  슬픔: 직접 표현 없음 → 연주 소리로 감정 전달
  노년 버전: 주름·백발 별도 캐릭터 시트 필요
```

## OP·ED 콘셉트

```
오프닝 (OP):
  제목: 미정 (OST 주제곡 연계)
  길이: 90초
  구성:
    0~15초: 4강 (살수·백마강·낙동강·기벌포) 영상
    15~60초: 4인 캐릭터 순차 소개 (왕국 배경)
    60~90초: 4인 함께 + 「삼국(三國)」타이틀
  스타일: 수묵화 느낌 + 현대적 애니메이션

엔딩 (ED):
  길이: 60초
  구성: 각 화 기준 해당 왕국 캐릭터 단독 컷
    고구려 화: 고루 ED
    백제 화: 아랑 ED
    신라 화: 하린 ED
    가야 화: 니문 ED
  음악: 각 캐릭터 테마 악기 솔로

ED 비주얼 스타일:
  흑백 수묵화 → 점차 색 채워짐
  「강은 기억한다」자막 마지막
```

## 제작 파이프라인

```
프리프로덕션:
  캐릭터 턴어라운드 시트 (8방향)
  표정 차트 (각 캐릭터 20종 이상)
  소품·의상 디테일 시트
  배경 레이아웃 북

프로덕션:
  레이아웃 → 원화 → 동화 → 촬영 → 색지정 → 채색
  전투씬: 원화·동화 추가 인원 배치

포스트프로덕션:
  컬러 그레이딩 (왕국별 색온도 조정)
  특수 효과 합성 (VFX 팀 협력)
  사운드 믹싱 (SND-SFX 연계)
  최종 QA: QA-CONTINUITY 검토

납품 포맷:
  방송용: 4K UHD / 23.976fps
  스트리밍: 4K + HDR
  해외 수출: DCP 패키지
```
