# 수도·도시 설계 — 삼국(三國) IP

## 도시 설계 원칙

```
삼국시대 도시 설계 역사 기준:
- 중국 당대 도성제(都城制) 영향 + 한반도 지형 적응
- 풍수지리 사상 반영 (산·강 둘러싼 입지)
- 방어 우선 설계 (성벽 필수)
- 종교 시설 (불교 사원·제천 장소) 중심 배치

IP 창작 활용:
- 수도 = 캐릭터의 일상 배경
- 도시 구조 = 사회 계층·정치 구조 시각화
- 건축 = 왕국 미학의 물질적 표현
```

## 고구려 — 평양성 (平壤城)

### 도시 개요

```
위치: 대동강 남안 (현재 북한 평양)
천도: AD 427년 (장수왕, 국내성→평양)
규모: 외성 둘레 약 23km (추정)
인구: 10~20만 (전성기 추정)
지형: 대동강 + 모란봉 언덕 = 천연 방어선
```

### 도시 구조

```
4중 성곽 구조:
  내성 (궁성): 왕궁·최고 관청 (모란봉 정상)
  중성: 귀족·고위 관료 거주
  외성: 일반 평민·상인 거주
  북성: 군사 방어 추가 (안학궁 지역)

주요 시설:
  안학궁 (安鶴宮): 장수왕 건설 왕궁
    → 동서 624m × 남북 622m
    → 5개 궁전 배치 (중국식 영향)
  대동강 수문: 교역·군사 통제 핵심
  동명왕릉: 고구려 건국왕 제사 장소
  외성 시장: 상업 거래 중심
```

### IP 활용 (고루 배경)

```
고루의 동선:
  안학궁 → 을지문덕 군사 회의실 → 살수 출진

주요 장면 배경:
  성벽 위: 수나라 대군 접근 관망
  대동강 선착장: 출정 전 아침
  안학궁 내정: 을지문덕과 고루의 마지막 대화

건축 미학:
  흑색·청색 기와 (고구려 왕국 색)
  삼족오 처마 장식
  돌 성벽 + 흙 다진 내부 구조
  좁은 골목 → 기마 제한 (적군 진입 차단)
```

## 백제 — 사비성 (泗沘城)

### 도시 개요

```
위치: 충남 부여 (금강·백마강 북안)
천도: AD 538년 (성왕, 웅진→사비)
규모: 나성 둘레 약 8.6km
인구: 5~10만 (전성기 추정)
지형: 백마강 3면 + 부소산 북쪽 = 자연 방어
```

### 도시 구조

```
도시 계획 특징:
  바둑판식 도로 (방리제, 坊里制) — 정방형 구획
  남북 대로 중심 → 동서 소로 분기
  남산 전망 도로: 미학적 경관 설계

주요 시설:
  왕궁: 사비 북쪽 (부소산 남록)
  미래사 (彌勒寺): 80m 9층 목탑
    → 사비성 어디서든 보이는 랜드마크
    → 높이: 60~80m 추정 (당대 최고층)
  능산리 사지 (陵山里 寺址): 왕릉 사원
  정림사 (定林寺): 5층 석탑 (현존)
  사비 시장: 남문 외 상업 구역
  기록관: 아랑 근무지 (IP 창작)

나성 (羅城):
  외곽 방어벽 — 도시 전체 둘러쌈
  남문·동문·서문·북문
  낙화암: 북쪽 절벽 + 백마강
```

### IP 활용 (아랑 배경)

```
아랑의 동선:
  기록관 → 미래사 → 백마강변 → 낙화암

주요 장면 배경:
  미래사 9층 목탑 앞: 연등 행사 밤
  기록관 창가: 매일 죽간 기록 작업
  낙화암 절벽: 백제 멸망 장면 (S2 클라이맥스)
  백마강 선착장: 교역선 도착 장면

건축 미학:
  황금빛 기와 (백제 황금색)
  섬세한 목각 처마 장식
  금동 문고리·장식
  연꽃 문양 타일 (미래사 경내)
  창문 너머 백마강이 보이는 기록관 구조
```

## 신라 — 금성·서라벌 (金城·徐羅伐)

### 도시 개요

```
위치: 경북 경주 분지 (형산강 상류)
건국부터 수도 유지: BC 57~AD 935 (약 1,000년)
규모: 추정 약 32km² (신라 전성기)
인구: 20~30만 (통일신라 전성기)
지형: 분지 형태 + 형산강 + 남산 = 자연 보호
```

### 도시 구조

```
독특한 특징:
  성벽보다 자연 지형 방어 의존 (평지 도시)
  불교 사원 다수 (황룡사·분황사·사천왕사 등)
  귀족 저택 밀집 (골품제 계층 반영)

주요 시설:
  황룡사 (皇龍寺):
    → 9층 목탑: 80m (한반도 최고 목탑)
    → 창건: 553년 (진흥왕)
    → 수용 인원: 5,000+ (대법회)
  첨성대 (瞻星臺): AD 632년 선덕여왕 건설
    → 현존 동아시아 최고 천문대
    → 높이 9.17m, 362개 돌
  월성 (月城): 반달 형태 왕궁
    → 해자 (垓字) 둘러싸임
  동시 (東市)·서시 (西市): 국가 관리 시장
  포석정: 귀족 연회장 (아발포 유적)

가로 체계:
  대로 너비: 약 22m (황룡사→월성 남북축)
  소로: 8~10m
  우물: 골목마다 배치
```

### IP 활용 (하린 배경)

```
하린의 동선:
  화랑 훈련장 → 황룡사 → 월성 → 첨성대

주요 장면 배경:
  황룡사 마당: 화랑 입단식 대규모 행사
  첨성대 아래: 선덕여왕과 하린 단독 만남
  동시 골목: 하린의 일상 (소년 시절)
  월성 성문: 출정 장면

건축 미학:
  황금빛 기와 (신라 금색)
  금박 처마 장식
  황룡사 목탑 실루엣 = 서라벌 스카이라인
  돌계단 + 기와담장 (귀족 저택)
```

## 가야 — 가락국 도성 (駕洛國 都城)

### 도시 개요

```
위치: 경남 김해 (낙동강 하구·남해 인접)
건국: AD 42년 (수로왕)
규모: 소규모 읍성 형태 (추정 1~2km²)
인구: 1~5만 (추정)
지형: 낙동강 + 남해 = 교역 최적지
```

### 도시 구조

```
가야 도시 특성:
  계획 도시보다 자연 성장형
  철 생산 시설 + 주거 혼재 (공업 도시)
  항구 기능 강함 (대왜 교역 핵심)

주요 시설:
  수로왕릉: 건국왕 능 (현재까지 보존)
  수릉왕묘 (수로왕 제사 공간): 봄·가을 제사
  철 단조장: 도성 내·외부 다수
  낙동강 선착장: 교역 물자 하역·선적
  우물: 니문 가족 생활 중심 (IP 창작)

가야 고유 특징:
  용광로 연기 = 도시의 상징
  철 두드리는 소리 = 일상 배경음
  강변 갈대밭 = 음악인 거주 구역 (IP 창작)
```

### IP 활용 (니문 배경)

```
니문의 동선:
  갈대밭 강변 → 철 단조장 (아버지 일터) → 수릉왕묘

주요 장면 배경:
  낙동강 갈대밭: 가야금 연주 (일상 장면)
  수릉왕묘: 가야 유민 제사 (니문 정체성 확인)
  철 단조장: 어린 니문 기억 (아버지 장면)
  가야 멸망 후 폐허: 에필로그 배경

건축 미학:
  황토색 기와·흙벽 (가야 황토색)
  철제 문고리·장식 (철 문화)
  소박한 목재 건물
  용광로 붉은 빛 = 가야 도시의 아이콘
```
