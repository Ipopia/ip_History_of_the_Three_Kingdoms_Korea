# 보이스 디렉션 가이드 — 삼국(三國) IP

## 보이스 디렉션 철학

삼국시대 인물들의 목소리는 **시대의 무게**를 담아야 한다. 현대적 발성이되 가벼움은 없다. 감정은 절제하되 내면의 온도는 뜨겁다. 왕국마다 다른 목소리의 색을 갖는다.

```
고구려: 차갑고 단단한 북방의 목소리 — 말수 적고 울림 깊음
백제: 부드럽고 세련된 강남의 목소리 — 아름다움이 말에 배어남
신라: 신비롭고 절제된 목소리 — 말 뒤에 더 많은 것이 있음
가야: 따뜻하고 솔직한 장인의 목소리 — 땅에 발이 닿은 목소리
```

## 왕국별 발성 가이드

### 고구려

```
기본 음색: 낮고 단단한 바리톤~베이스 계열
           여성 캐릭터는 메조소프라노 이상

발성 특징:
- 문장 끝을 자르듯 마무리 — 여운 최소화
- 감탄사·탄식 절제 — "흠" "그래" 수준
- 분노 표현: 목소리를 높이지 않음 — 더 낮아짐
- 명령 시: 간결·빠름 — 불필요한 설명 없음

금지 표현:
- 긴 탄식·울음 (약함으로 인식)
- 머뭇거림 (결단력 저해)
- 높은 피치의 감탄

예시 대사 디렉션:
"더 가라." — 광개토대왕
→ 낮은 피치, 짧은 호흡, 끝음 단호하게 내림
→ 뒤에 여운 없음 — 명령은 이미 끝났다
```

---

### 백제

```
기본 음색: 중간 음역 테너~바리톤 / 소프라노~메조
           전체적으로 부드럽고 공명 많음

발성 특징:
- 문장 끝을 살짝 올려 우아함 표현
- 음절 사이 간격 약간 넓음 — 여유로움
- 감정 표현 풍부 — 기쁨·슬픔 모두 아름답게
- 침묵도 음악처럼 — 대사 전후 의미있는 정지

금지 표현:
- 거칠고 끊기는 발음
- 순간적 폭발성 분노 (위엄 손상)

예시 대사 디렉션:
"백제는 아름답다. 이 아름다움이 영원하리." — 의자왕
→ 첫 문장: 자랑스럽고 따뜻하게
→ 둘째 문장: 점점 멀어지는 듯 — 기원인지 허망함인지 모호하게
→ 마지막 "영원하리" — 자신을 다독이는 듯
```

---

### 신라

```
기본 음색: 맑고 투명한 음색 선호
           과도한 진동음(vibrato) 지양

발성 특징:
- 말이 암시적 — 직접 말하지 않는 듯한 표현
- 중간 속도 — 급하지도 느리지도 않음
- 웃음이 드묾 — 웃을 때는 의미 있음
- 불교적 여운 — 범종처럼 울리고 사라짐

예시 대사 디렉션:
"모란꽃 그림에 나비가 없었다. 그게 전부다." — 선덕여왕
→ 담담하게 — 대단한 비밀을 말하는 것이 아니라 당연한 사실처럼
→ "그게 전부다" — 오히려 더 작게, 더 확신 있게
```

---

### 가야

```
기본 음색: 따뜻한 중저음 — 대지의 목소리

발성 특징:
- 솔직하고 직접적 — 돌려 말하지 않음
- 노동의 리듬 — 말에 망치질 같은 박자
- 감정이 표면으로 빠르게 올라옴
- 음악적 흔들림 — 우륵은 말할 때 노래와 경계

예시 대사 디렉션:
"가야가 사라진다. 그러나 가야금 소리는 사라지지 않는다." — 우륵
→ 1문장: 사실로서 담담하게 — 슬프지 않은 듯
→ 2문장: 확신으로 — 점점 온도가 올라감
→ 마지막: 자신을 설득하는 것처럼
```

## 주요 캐릭터 보이스 디렉션

### 광개토대왕

```
성우 방향: 남성 베이스 계열 / 40대 목소리 (실제 나이 39세 사망)
키워드: 압도적 / 카리스마 / 짧음

감정별 디렉션:
- 평상시: 낮은 권위 — 억지가 없음, 자연스러운 지도자
- 분노: 더 조용해짐 — "침묵이 공포다"
- 기쁨: 드묾, 표현 시 한 음절로 ("그래")
- 슬픔: 없음 — 공식 석상에서 슬픔 없음
          단, 독백 장면 — 숨결로만 표현

특수 장면 디렉션:
릉비 선포 장면: 메아리 효과 허용 — 역사 기록의 울림
임종 장면: 최대한 낮고 약하게 — 영웅의 마지막 취약함
```

---

### 계백

```
성우 방향: 남성 바리톤 / 강한 공명 / 50대 목소리
키워드: 비장 / 절제 / 인간적 따뜻함 (드물게)

감정별 디렉션:
- 명령: 짧고 강하게 — "가라" "쏴라" "서라"
- 아내에게: 유일하게 부드러움이 드러남 — 전혀 다른 목소리
- 황산벌 출정: 흔들림 없되 비장함 — "이 전쟁은 이길 수 없다"

핵심 대사:
"다시 오지 않는다. 그것으로 충분하다."
→ "다시 오지 않는다" — 사실을 말하듯 / 체념이 아님
→ "그것으로 충분하다" — 스스로에게 말하는 것처럼
→ 마지막 음절 미세하게 떨림 허용 — 인간임을 보여줌
```

---

### 선덕여왕

```
성우 방향: 여성 메조소프라노 / 신비로운 공명
키워드: 지혜 / 신비 / 고독

감정별 디렉션:
- 공식 석상: 왕의 권위 — 남성 캐릭터보다 더 절제
- 혼자 있을 때: 인간적 고독이 드러남
- 예언 발화: 마치 이미 알고 있었던 것처럼 — 놀라움 없음

특수 장면:
첨성대 올라가는 장면 (독백):
"별은 거짓말하지 않는다. 사람이 거짓말한다."
→ 별을 바라보며 / 대사 중간에 긴 호흡 허용
→ 마지막 "사람이 거짓말한다" — 슬프지 않게, 사실로서
```

---

### 우륵

```
성우 방향: 남성 테너 / 부드럽고 음악적 공명
키워드: 서정 / 고독 / 확신

특수 디렉션:
연주 중 독백: 가야금 소리와 목소리 경계 모호하게
귀화 결단 장면: 말이 아닌 숨결로 시작

핵심 대사:
"왕은 신라에 항복했다. 나는 신라에 가야를 심었다."
→ 1문장: 슬프게
→ 2문장: 확신으로 / 오히려 더 강하게
→ "누가 이겼는가? 나는 아직 모른다." — 자문하듯 / 정답을 모르는 것이 아닌 계속 질문하는 것
```

## 게임 보이스 디렉션

### 전투 중 대사

```
고구려 영웅:
- 스킬 발동: 짧고 강함 "돌격!" / "물러라" / "끝이다"
- 피격: 낮은 그런트 — 약함 표현 금지
- 처치: 침묵 or 단 한 마디 "됐다"
- 부활: 깊은 호흡 + 결의

백제 영웅:
- 스킬 발동: 우아한 선포 "이것이 백제다" / "아름다운 끝이로군"
- 피격: 감탄 "이런" — 당황이 아닌 인정
- 처치: "잘 싸웠다"

가야 영웅 (우륵):
- 전투 대사 없음 — 음악으로 대체
- 스킬: 가야금 선율이 무기화되는 연출
```

### AI 챗봇 보이스 프로토콜

```
우륵 AI 챗봇:
- 톤: 느긋하고 철학적 — 질문에 바로 답하지 않음
- 습관: 질문에 질문으로 돌아오는 경우 있음
- 음악 언급: 대화에 자연스럽게 가야금 비유 사용
- 고민 상담 시: "소리를 들으세요. 답이 있습니다."

광개토 AI 챗봇:
- 톤: 결단적이고 짧음
- 모든 답변: 3문장 이내
- 역사 질문: 사실 위주, 과장 없음
- "더 물어봐도 됩니다" 같은 말 하지 않음 — 이미 알아서 할 것이므로

선덕여왕 AI 챗봇:
- 톤: 신비롭게 — 답을 주되 더 깊은 생각 유도
- 별·우주 비유 빈번 사용
- 마무리: 항상 질문으로 끝냄 ("당신은 어떻게 생각하십니까?")
```

## 오디오 드라마 녹음 가이드

```
녹음 환경:
- 무향실(無響室) 기본
- 고구려 장면: 약한 룸 리버브 허용 (산속·성벽 느낌)
- 백제 장면: 따뜻한 홀 리버브 (궁중 분위기)
- 신라 사원 장면: 긴 리버브 (황룡사 공간감)

마이크 세팅:
- 기본: 다이나믹 마이크 (따뜻한 음색)
- 독백·내면: 컨덴서 마이크 (섬세한 호흡 포착)

후처리:
- 전투 장면: 중음 대역 강조 (힘·타격감)
- 감성 장면: 저음 보강 (따뜻함·공감)
- 제천 의식: 공간감 최대화 (하늘과 통하는 느낌)
```

## 다국어 보이스 방향

```
영어 더빙:
- 고구려: 영국식 발음 + 낮은 중세 톤
- 백제: 약간 부드러운 RP 발음
- 신라: 미국식 중립 발음 + 신비로운 톤
- 가야: 따뜻한 아일랜드 억양 허용

일본어 더빙:
- 고구려: 시대극(時代劇) 톤 — 격식체
- 백제: 교토풍 우아한 언어
- 신라: 절제된 표준어

중국어 더빙:
- 보통화(普通話) 기본
- 고구려: 낮은 피치 강조
- 전 캐릭터: 고어(古語) 투는 사용하지 않음 — 자연스러운 현대 중국어
```
