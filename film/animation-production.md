## 애니메이션 전략 개요

```
삼국(三國) 애니메이션 목표:
「드라마 시청자 + 애니 팬덤을 동시에 포착」

제작 라인업:
① 메인 시리즈 (Main Series): 26화 × 24분 — 시즌 1
② OVA 스핀오프 3편: 광개토대왕 / 소서노 / 수로왕 (각 45~60분)

타겟:
국내: 15~35세 (애니 팬 + 역사 팬)
해외: 일본 (애니 주 시장) + 동남아 + 글로벌 스트리밍
```

## 메인 시리즈 — 시즌 1

### 시리즈 개요

```
제목: 삼국(三國) THE ANIMATION — 시즌 1
부제: 「강은 기억한다 / THE RIVER REMEMBERS」
화수: 26화 (각 24분)
총 분량: 약 624분 (10.4시간)

시간대: 4~7세기 한반도 (드라마 시즌 1 병행)
스토리: 드라마 시즌 1 기반 — 주요 장면 애니 재해석
주인공: 고루·아랑·하린·니문 4인 병행 서술

방영 전략:
1차: 일본 TV 애니 채널 + 일본 스트리밍 (Amazon Prime/Netflix Japan)
2차: 한국 (드라마 방영 후 6개월) + 글로벌 동시
3차: 동남아 (태국·베트남·인도네시아)
```

### 화수 구성 (26화)

```
1~4화 — 프롤로그 「강이 흐르기 시작할 때」
  1화: 4왕국 소개 (병행 오프닝)
  2화: 고루의 첫 전투 (살수 전야)
  3화: 아랑의 비밀 문서 (사비성)
  4화: 하린의 화랑 입단 + 니문의 가야금

5~10화 — 「살수」
  5화: 수나라 침략 시작
  6화: 을지문덕의 후퇴 전략
  7화: 살수 강가 — 밤의 대화
  8화: 댐 방류 — 전투 클라이맥스
  9화: 살수대첩 이후 — 고루의 눈물 (첫 전투 후)
  10화: 을지문덕과 고루 — 스승의 마지막 가르침

11~16화 — 「기억하는 자들」
  11화: 시간 전환 (618년) — 수나라 멸망
  12화: 니문의 12악곡 도전 시작
  13화: 아랑과 의자왕 — 대야성 원정
  14화: 하린의 화랑 서약
  15화: 니문 신라 궁중 첫 공연
  16화: 당나라 이세민 즉위 소식

17~22화 — 「연개소문의 칼」
  17화: 642년 — 연개소문 쿠데타 전야
  18화: 쿠데타 밤 — 고루의 선택
  19화: 을지문덕의 칼 (연개소문이 건넴)
  20화: 아랑의 예감 — 나당 연합 징조
  21화: 하린과 김유신 첫 만남
  22화: 니문 12번째 곡 완성 직전

23~26화 — 「안시성」
  23화: 당 태종 출정 — 안시성으로
  24화: 안시성 농성 — 성주와 고루
  25화: 토산 역이용 — 밤의 야습 (클라이맥스)
  26화: 안시성 승전 + 니문의 12번째 곡
       엔딩: 「강은 기억한다」— 4인 분할 컷 + OP 반주
```

## 제작 스타일 기준

### 아트 스타일

```
메인 아트 스타일: 「역사 수묵화 + 현대 애니」하이브리드

영감 레퍼런스:
- 고구려 고분벽화 (무용총·안악3호분) — 동적 선화 기법
- 한국 전통 민화 — 색채 패턴
- 현대 일본 애니 — 캐릭터 작화 가독성

핵심 시각 언어:
라인: 굵은 외곽선 + 세필 디테일 (한국화 붓 느낌)
배경: 수묵 담채화 풍경 (뒤 배경) + 정밀 셀화 (앞 배경)
전투: 동세 강조 — 잔상·속도선 적극 활용
감성 씬: 수묵 번짐 효과 레이어 (비·강·눈)

왕국별 작화 차별화:
고구려 씬: 강한 명암 대비, 붓 터치 거칠게
백제 씬: 부드러운 그라데이션, 금색 환경광
신라 씬: 선명한 컬러, 황금 반사광
가야 씬: 자연스러운 따뜻한 톤, 수채화 느낌
```

### 화면 비율 및 기술 사양

```
화면 비율: 16:9 와이드스크린
해상도: 4K 마스터 (1080p 방영)
프레임레이트: 24fps (기본) / 전투 씬 48fps 업스케일
색 공간: DCI-P3 (극장 기준)

제작 파이프라인:
원화: 디지털 (TVPaint / Clip Studio)
배경: 포토그래피 텍스처 + 디지털 페인팅
합성: After Effects + Nuke
3D 보조: Maya (건물·성·대형 구조물)

총 제작비 (시즌 1):
화당 평균: 3~5억원 (고퀄 애니 기준)
시즌 1 총 예산: 80~130억원 (파트너 공동 제작 기준)
공동 제작 파트너: 일본 애니 스튜디오 협업 권장
```

## OVA 스핀오프

### OVA 1 — 광개토대왕 (廣開土大王)

```
제목: 「THE GREAT CONQUEROR」
부제: 「광개토대왕, 천하사방을 정복하다」
러닝타임: 60분
시간: 391~413년 (재위 기간)

스토리:
18세 즉위 → 64개 성 정복 → 신라 구원 (왜구 격파) → 사망
광개토대왕릉비 비문 직접 인용 장면

핵심 씬:
「倭寇新羅」— 왜군 침략 → 광개토대왕 5만 기병 파견
신라 구원 장면 — 압도적 스케일 기병 전투
비문 새기는 장수왕 (아버지 기억 마지막 씬)

아트 스타일: OVA 전용 — 더 사실적, 영화적 화면
BGM: 웅장한 금관악기 + 거문고 협주

수익화:
극장 개봉 (1주) → VOD → 게임 이벤트 연동
피규어: 광개토대왕 LEGEND 스케일 1/7
```

### OVA 2 — 소서노 (召西奴)

```
제목: 「THE QUEEN WHO MADE TWO KINGDOMS」
부제: 「고구려와 백제를 만든 여인」
러닝타임: 50분
시간: BC 37년 전후

스토리:
소서노: 주몽을 도와 고구려 건국 → 이별
남쪽으로 내려와 온조와 함께 백제 건국
가야 교역 루트 개척

역사 의미:
삼국사기 기록 — 소서노의 역할 축소됨
→ IP는 적극적으로 소서노의 역할 부각
「두 나라를 만든 여인」— 여성 역사 인물 재조명

핵심 씬:
주몽과 이별 — 감성 최고조 (OP 테마 변주)
백제 건국 선언 — 서해 앞에서 홀로 서는 소서노
```

### OVA 3 — 수로왕 (首露王)

```
제목: 「THE IRON KING」
부제: 「구지봉에서 시작된 나라」
러닝타임: 45분
시간: 서기 42년 전후 (가야 건국)

스토리:
구지가 — 하늘에서 내려온 황금 알
수로왕 즉위 — 가야 철 문화 확립
허황옥 도래 — 인도 공주와의 결혼 (국제성)

핵심 씬:
구지봉 전체 장면 — 구지가 영상화 (애니 최대 스펙터클)
허황옥 배가 도착하는 장면 — 바다와 배 스펙터클
최초 대장간 — 가야 철 신화 시작

니문 연결:
수로왕 OVA 마지막 씬: 562년 가야 멸망 → 니문 할아버지의 할아버지가 가야금 안고 탈출
→ 메인 시리즈 니문 캐릭터 기원
```

```
제작 방식:
풀 애니보다 단순한 작화 (SNS 최적화)
세로 9:16 + 가로 16:9 동시 제작
```
