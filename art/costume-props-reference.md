## 의상 고증 원칙

```
고증 우선순위:
  1순위: 실물 유물 (무령왕릉·천마총 등 출토품)
  2순위: 고분벽화 (고구려 사신도·생활도 등)
  3순위: 문헌 기록 (삼국사기·삼국유사)
  4순위: 인접 시대·문화 참고 (중국 남북조·당, 일본 아스카)

창작 허용 범위:
  역사 기록 없는 부분 = 고증 원칙 내 창작 가능
  단, ADV-ARCH 검수 후 사용

금지:
  조선 시대 복식 혼용 (가장 흔한 오류)
  일본 기모노·사무라이 복식 혼입
  현대 패션 감각 과도 적용 (슬림핏 등)
  서양 중세 코르셋·플레이트아머 형태
```

## 왕국별 복식 체계

### 고구려 복식

```
왕실·귀족:
  상의: 좌임(左袵) 직령포 — 왼쪽으로 여밈
  하의: 통 넓은 바지 (고리(袴)) — 기마 편의
  색상: 자색(紫色) #800080 최상위 / 청색 귀족
  허리: 각대(角帶) — 뿔 장식 혁대

무관 (장수):
  갑옷: 소찰갑(小札甲) — 미늘 조각 연결 철갑
  투구: 종형(鐘形) 철투구 + 볼 가리개
  어깨: 견갑(肩甲) — 어깨 철판 보호
  팔뚝: 비갑(臂甲) + 장갑

일반 병사:
  갑옷: 가죽 갑옷 (철 부족 병사)
  투구: 가죽 + 철 혼합
  무기: 창·방패 기본 / 일부 활

여성 복식:
  저고리: 짧고 몸에 붙는 형태
  치마: 주름 잡힌 길이 긴 치마
  색상: 청·녹 계열 (남성보다 다채로움)

고증 근거: 안악 3호분·덕흥리 벽화 인물
```

### 백제 복식

```
왕실·귀족 (남성):
  상의: 포(袍) — 길고 우아한 직령포
  하의: 가죽 대 + 주름 바지
  색상: 자색 최상위 / 황금 귀족 / 청색 관리
  특징: 동아시아 최정교 직물 기술

왕실·귀족 (여성 — 아랑 기준):
  저고리: 넓은 소매 + 봉황·연꽃 자수
  치마: 비단 주름치마 (긴 착지)
  색상: 황금 #B8960C + 비단 크림 #F5E6C8
  장신구: 금귀걸이·옥목걸이·금팔찌

장신구 고증 (무령왕릉):
  금제 관식: 화염형 장식 (왕비 기준)
  금동 신발: 정교한 투각 문양
  청동 거울: 수입품 (중국 남조)

복식 특기:
  백제 → 일본 복식 기술 전수 역사적 사실
  백제 비단: 동아시아 최고품 (중국·왜에 수출)
  염색: 자초(紫草)·홍화·쪽 등 천연 염료
```

### 신라 복식

```
왕실·귀족:
  상의: 곡령포(曲領袍) — 둥근 깃
  하의: 통 넓은 바지 + 행전(行纏) 각반
  색상: 자색 최상위 / 금색 화랑 / 흰색 관리
  관모: 금관(金冠) — 왕·귀족 의식용

화랑 복식 (하린 기준):
  갑옷: 가죽 + 철판 혼합 경갑
  색상: 금색 #FFD700 도금 장식 부분 적용
  내의: 흰 면포 또는 삼베
  두구: 금관 형식 투구 (화랑 고급 사양)
  신발: 가죽 전투화

여성 복식:
  상의: 저고리 (약간 긴 형태)
  하의: 비단 치마
  특기: 선덕여왕 = 왕 복식 착용 (남성 관복)

금관 고증 (천마총):
  출(出)자형 가지 3개 + 사슴뿔형 가지 2개
  곡옥(曲玉) 매달림 — 녹색 옥·유리
  재질: 황금 박판 타출 기법
```

### 가야 복식

```
왕실·귀족:
  복식 고증 불충분 → 창작 범위 넓음
  참고: 대성동 고분 출토 금동관

일반인·악사 (니문 기준):
  상의: 황토빛 삼베 직령포 (단순·소박)
  하의: 삼베 바지 + 천연 염색 (황토·쪽)
  신발: 짚신 or 맨발 (유랑 악사)
  외투: 낡은 여행 망토 (다크 갈색)

철 장인:
  앞치마: 두꺼운 가죽 앞치마 (작업용)
  소매: 걷어 올린 상태
  특징: 검댕·철 가루 흔적 의상에 자연스럽게

복식 특기:
  가야 = 직물보다 철 문화 중심
  의상 상대적으로 소박 (문화적 특성)
```

## 주요 소품 카탈로그

### 무기류

```
고루 장검:
  형태: 환두대도(環頭大刀) — 고리 손잡이 직도
  길이: 전체 110cm (날 90cm + 손잡이 20cm)
  재질: 단조 철 (가야제 추정)
  손잡이: 삼족오 금 장식 고리
  칼집: 흑칠 나무 + 가죽 손잡이 끈

하린 화랑 단검:
  형태: 소형 환두대도
  길이: 전체 55cm
  재질: 신라제 단조 철
  손잡이: 금 도금 곡옥 장식

백제 활·화살:
  활: 각궁(角弓) — 복합궁 (짧고 강력)
  화살: 철촉 + 갈대 화살대
  화살통: 가죽 + 옻칠 목제

수나라 무기 (적군):
  창: 장창 (3m) + 철촉
  방패: 원형 목제 방패
  갑옷: 중국식 철갑 (고구려와 차별화 필수)
```

### 핵심 소품 (서사 연계)

```
금동대향로 (백제):
  실물: 국보 287호 (부여 능산리 출토)
  형태: 높이 61.8cm 연꽃 + 봉황 + 신선 세계
  드라마 소품: 정밀 레플리카 제작 (ADV-ARCH 공인)
  서사 기능: 아랑의 집착 대상 = 백제 아름다움 상징
  당나라 반출 장면: 핵심 비극 소품

가야금 (가야):
  실물 참고: 전통 12현 가야금
  니문 전용: 오동나무 몸체 + 12현
  특이: 한 현이 끊겨있음 (서사 장치)
  드라마 소품: 실제 연주 가능한 가야금 제작
  서사 기능: 가야 소멸의 상징 → 마지막에 새 현 연결

어머니의 자수 (백제):
  크기: 30cm × 30cm 삼베 자수
  문양: 봉황 + 연꽃 + 당초문 (백제 문양)
  상태: 낡고 바랬지만 정교함 유지
  색상: 황금·주홍·청색 실 (부분 탈색)
  서사 기능: 아랑이 사비성 탈출 시 유일하게 지닌 것

니문 죽간 묶음 (기억 기록):
  재질: 대나무 죽간 (길이 30cm)
  내용: 고루·아랑·하린의 이야기 기록
  묶음: 20개 묶음 → 시즌 3에 40개
  서사 기능: 「기억 수집」의 물리적 증거
```

## 소품 제작 기준

```
드라마 소품 제작:
  금동대향로 레플리카: 고급 합금 주조 (ADV-ARCH 치수 기반)
  가야금: 실제 연주 가능 (악기 장인 제작)
  의상: 전통 직조·염색 방식 최대한 적용

소품 등급:
  A등급 (클로즈업용): 최고 정밀도 · 실제 소재
  B등급 (중간 거리용): 정밀 레플리카
  C등급 (원거리·배경용): 단순화 버전

저장·관리:
  소품 목록 데이터베이스 유지
  시즌별 소품 상태 기록 (흠집·노화 연속성)
  핵심 소품 보험 가입 (금동대향로 레플리카 등)

머천다이즈 연계:
  공식 레플리카: 드라마 소품 원형 기반
  ROYAL LINE: 금동대향로·철정·가야금 레플리카
  ADV-ARCH 공인 절차 준수
```
