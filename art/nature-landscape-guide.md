# 자연 & 경관 디자인 가이드

## 자연 설계 원칙

> "한반도의 자연은 사계(四季)가 뚜렷하고, 산과 강이 땅을 나눈다. 이 땅의 자연이 삼국의 성격을 만들었다."

삼국시대 자연 환경은 21세기와 다르다. 개간되지 않은 원시림, 야생 동물, 맑은 강물이 기본값이다. 자연은 단순 배경이 아닌 서사의 힘으로 작용한다.

## 한반도 생태 기반

### 4~7세기 한반도 자연 환경

| 지역 | 생태 특성 |
|------|---------|
| 고구려 영토 (북부) | 침엽수림(소나무·잣나무), 혹독한 겨울, 야생 호랑이·곰 서식 |
| 백제 영토 (서남부) | 낙엽활엽수림, 온난한 기후, 백마강 수계, 서해안 갯벌 |
| 신라 영토 (동남부) | 동해안+태백산맥, 상대적으로 온난, 화강암 지형 |
| 가야 영토 (남부) | 낙동강 유역, 철광석 산지, 남해안 항구 |

## 지형별 경관 설계

### 산악 경관

**고구려 산악 — 거칠고 웅장**

```
특성:
- 화강암 절벽 — 수직 단면 드러남
- 원시 소나무림 — 울창하고 어두운 숲
- 협곡과 산성 — 자연 방어선
- 구름과 안개 — 산 허리를 감싸는 운무

대표 경관:
- 백두산 천지 — 고구려 건국 신화 배경
- 요동 산맥 — 정복의 무대
- 안시성 산지 — 험준한 요새 지형
```

**신라 산악 — 신성하고 아름다운**

```
특성:
- 경주 남산 — 불상과 탑이 가득한 성산
- 토함산 — 해 뜨는 산 (석굴암 위치)
- 태백산맥 — 동쪽 장벽 실루엣

대표 경관:
- 남산 일출 — 황금빛 + 불상 실루엣
- 토함산 능선 — 동해 조망점
- 첨성대에서 본 경주 분지
```

---

### 강(江) 경관

**대동강 — 고구려의 강**

```
계절별:
- 봄: 해빙+빠른 물결, 연안 버들 연두색
- 여름: 넓은 수면, 배 왕래 활발
- 가을: 맑고 투명한 수면, 단풍 반사
- 겨울: 결빙 또는 얼음 사이 흐름

촬영 앵글 가이드:
- 대각선 앵글: 강 폭 강조 → 웅장함
- 수면 앵글: 반사 활용 → 서정성
- 공중 앵글: 강이 도시를 나누는 구조
```

**백마강 — 백제의 강 (가장 중요)**

```
특성:
- 부드러운 곡선 — S자 굽이
- 절벽 낙화암 — 강 위 30m 절벽
- 정림사지 탑 반영 — 수면 반사
- 안개 — 새벽 강 안개 특유

핵심 장면 앵글:
1. 낙화암 정면: 절벽을 아래서 올려다보기
2. 강 수면에서 낙화암 바라보기
3. 낙화암 위에서 강 내려다보기 (극적)
4. 달빛+낙화암: 야간 클로즈업
```

**한강 — 패권의 강**

```
특성:
- 넓은 수면 — 삼국 중 가장 넓은 구간
- 강변 평야 — 농경지+군사 요충
- 계절별 극적 변화

서사적 활용:
- 매 시즌 같은 앵글로 한강 재촬영 → 주인이 바뀜을 시각화
- 고구려 점령기: 철흑 깃발+강
- 백제 수복기: 백제색+강
- 신라 통일기: 황금 신라 깃발+강
```

---

### 해안 & 항구 경관

**백제 서해안**

```
특성:
- 갯벌 — 썰물 때 드러나는 광활한 갯벌
- 서해 낙조 — 주홍+황금 수평선
- 항구 — 중국·가야 교역선 정박

대표 장면:
- 백제 무역선 출항 — 서해 낙조 배경
- 외국 사신 도착 — 해상 원거리 뷰
```

**가야 남해안**

```
특성:
- 다도해 — 크고 작은 섬들
- 남해 특유의 따뜻한 색감
- 어항 — 철 교역의 거점

대표 장면:
- 가야 철정 교역선 — 왜·중국과 교역
- 김수로왕 허황후 도래 — 바다에서 배가 오는 신화적 장면
```

## 계절별 경관 상세 설계

### 봄 경관 (시즌1 — 건국의 계절)

**팔레트**
- 하늘: `#B8D8F0` 연한 봄 하늘
- 새잎: `#90C840` 연두
- 진달래: `#E868A8` 진분홍
- 흙: `#A87848` 촉촉한 토색
- 강: `#80B8D0` 봄 강

**연출 포인트**
- 아지랑이 — 원거리 배경에 미세 흔들림
- 꽃비 — 진달래·벚꽃 낙화 (건국 오프닝 활용)
- 새소리 — 시각+청각 연동
- 봄눈 녹는 물 — 계곡 흐름

### 여름 경관 (시즌3~4 — 전성의 계절)

**팔레트**
- 하늘: `#4090D0` 강렬한 파란 하늘
- 숲: `#206820` 짙은 녹음
- 황토: `#C09040` 마른 황토
- 강: `#608090` 탁한 여름 강
- 먹구름: `#304050` 소나기 전

**연출 포인트**
- 폭염 아지랑이 — 전장 황토 위
- 소나기 — 전투 중 갑작스러운 비
- 매미 소리 — 여름 환경 청각 필수
- 뇌우 번개 — 역사적 전환점 연출

### 가을 경관 (시즌5~6 — 쇠락의 계절)

**팔레트**
- 하늘: `#90B0D0` 높고 맑은 가을
- 단풍: `#D04820` `#E09020` 붉고 황색
- 낙엽: `#A06030` 땅에 쌓인 낙엽
- 강: `#708090` 맑고 차가운
- 억새: `#D0B880` 은빛 억새밭

**연출 포인트**
- 낙엽 바람에 흩날림 — 슬로우 모션 연출
- 새벽 서리 — 풀잎 위 얼음
- 기러기 편대 — 하늘 전환 숏
- 붉은 단풍 + 결전 장면 (계백 황산벌)

### 겨울 경관 (시즌6~7 — 멸망의 계절)

**팔레트**
- 하늘: `#A0B0C0` 납빛 또는 눈 내리는
- 설원: `#E8F0F8` 흰 눈
- 나무: `#504030` 앙상한 가지
- 강: `#304858` 어두운 얼음 강
- 연기: `#909898` 차가운 연기

**연출 포인트**
- 눈 내리는 전쟁터 — 조용한 비극
- 얼어붙은 강 — 이동 불가 장벽
- 발자국만 남은 설원 — 고독
- 앙상한 나무 사이 성벽 — 고립감

## 자연 표현 금지 사항

1. 현대적으로 정비된 자연 (잘 깎인 잔디·가로수) — 삼국시대는 야생
2. 한반도에 없는 식물 (열대 식물 등)
3. 계절 무시 식생 — 여름 장면에 단풍 금지
4. 지나치게 깨끗한 강물 (실제는 생활용수 사용으로 탁함)
5. 실제 서식하지 않는 동물 등장 (단, 신화적 존재는 별도 가이드 적용)
