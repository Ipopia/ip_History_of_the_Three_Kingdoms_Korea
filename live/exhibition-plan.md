## 전시 전략 개요

```
컨셉: 「강은 기억한다 — 삼국(三國) 몰입 전시」
형식: 이머시브(몰입형) 체험 전시 + 유물 복제 전시 + 디지털 인터랙티브
타깃: 드라마 시청자 + 역사 관심층 + 가족 단위 + 수학여행
```

## A. 상설 전시관

### 공간 구성

```
총 면적: 3,000~4,000㎡ (약 1,000평)
위치: 서울 (용산·잠실·DDP 협의) 또는 경주 (역사 도시 연계)

존 구성:
  ZONE 1 — 「프롤로그: 강의 시작」(200㎡)
    → 한반도 3D 지형 모형 + 4왕국 영토 프로젝션
    → 입장 시 왕국 선택 (RFID 팔찌)
    → 선택한 왕국 색상으로 팔찌 점등

  ZONE 2 — 「고구려관: 철과 하늘」(600㎡)
    → 안시성 성벽 실물 크기 복원 세트 (높이 6m)
    → 살수대첩 수문 체험: 레버 조작 → 물 효과 + 영상
    → 고구려 갑옷 착용 포토존
    → 을지문덕 한시 서예 체험

  ZONE 3 — 「백제관: 연등과 비단」(600㎡)
    → 사비성 문서관 재현 (아랑 작업실)
    → 금동대향로 실물 크기 복제품 전시
    → 연등 100개 설치 야경 공간 (포토존)
    → 죽간 붓글씨 체험

  ZONE 4 — 「신라관: 황금의 땅」(600㎡)
    → 신라 금관 복제품 전시 (국립중앙박물관 협력)
    → 화랑 훈련장 체험 (활쏘기 시뮬레이터)
    → 첨성대 축소 모형 + 별자리 프로젝션
    → 하린 코스튬 착용 포토존

  ZONE 5 — 「가야관: 소멸하는 소리」(500㎡)
    → 가야금 12현 실제 연주 체험
    → 니문의 기억 — 몰입형 영상 공간 (360도 프로젝션)
    → 가야 철정 주조 체험 (모의)
    → 낙동강 황혼 앰비언스 공간 (명상·휴식)

  ZONE 6 — 「에필로그: 강은 기억한다」(300㎡)
    → 4인 주인공 조형물 (실물 크기)
    → 방명록 디지털 월 (터치스크린 메시지)
    → 굿즈 스토어 연결

  부대시설:
    카페 (왕국 테마 음료)
    굿즈 스토어
    교육 프로그램 교실 (수학여행 단체)
```

### 핵심 체험 콘텐츠

```
① 살수대첩 수문 체험:
  조작: 대형 나무 레버 (2인 협동)
  효과: 바닥 진동 + 물안개 분사 + LED 수면 효과 + 서라운드 SFX
  영상: 정면 대형 스크린 살수 방류 시네마틱
  소요: 5분

② 가야금 연주 체험:
  악기: 실제 가야금 5대 상시 비치
  가이드: 니문 테마 곡 12음 학습 (터치 스크린 가이드)
  녹음: 연주 녹음 → QR 코드로 다운로드
  소요: 10분

③ 왕국 AR 포토존:
  기술: AR 카메라 부스 4대 (왕국별)
  효과: 왕국 배경 + 갑옷·의상 AR 오버레이
  출력: 즉석 사진 인화 (유료) + 디지털 파일 (무료)

④ 역사 퀴즈 랠리:
  RFID 팔찌 연동: 각 존에서 퀴즈 정답 시 포인트 적립
  완주 보상: 왕국 인증서 + 소형 굿즈
  교육 연계: 학교 단체 수학여행 프로그램
```

```

```

```

기념품: 화랑 도장 + 이름 한자 인쇄 카드 즉석 발급
```
