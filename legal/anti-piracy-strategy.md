## 저작권 보호 전략 개요

```
보호 대상:
  1차: 소설·웹툰·드라마 (콘텐츠 저작권)
  2차: 캐릭터·로고·아트워크 (저작권·상표권)
  3차: 굿즈·머천다이즈 (디자인권)
  4차: 게임 코드·음악 (소프트웨어·음반 저작권)

등록 현황 목표:
  한국: 전 저작물 저작권위원회 등록
  일본: J-PlatPat 상표 등록 (캐릭터명·로고)
  미국: USCO 저작권 등록 (드라마·게임)
  EU: EUIPO 상표 등록
  중국: 국가판권국 저작권 등록 (중국 배급 시)

연간 예산: 법무 비용 포함 5,000만원
```

## 온라인 불법 복제 대응

### 모니터링 시스템

```
자동 모니터링 도구:
  Muso.com: 토렌트·P2P 불법 공유 감지
  YouTube Content ID: 드라마·OST 자동 감지
  Google DMCA 모니터링: 검색 결과 불법 링크
  Tencent Video 모니터링: 중국 불법 스트리밍

모니터링 주기:
  드라마 방영 중: 실시간 (24시간)
  방영 종료 후: 주 1회 정기 스캔
  굿즈·이미지: 월 1회 이미지 검색 스캔
  게임: 앱스토어 클론 앱 주 1회 검색

알림 기준:
  불법 스트리밍 1회: 자동 DMCA 발송
  토렌트 시드 10개 이상: IP-LEGAL 즉시 보고
  위조 굿즈 발견: 24시간 내 플랫폼 신고
```

### DMCA 대응 프로세스

```
Step 1: 자동 감지 → 내부 검토 (1영업일)
Step 2: 침해 확정 → DMCA 테이크다운 발송 (1영업일)
Step 3: 플랫폼 처리 대기 (통상 24~72시간)
Step 4: 미처리 시 법적 대응 에스컬레이션

플랫폼별 대응 채널:
  YouTube: Copyright Management Tool 직접 처리
  Facebook/Instagram: IP Report 시스템
  TikTok: 저작권 침해 신고 채널
  네이버/카카오: 저작권 신고 시스템
  국내 포털: 방송통신심의위원회 신고 병행

해외 대응:
  일본: CODA (콘텐츠해외유통촉진기구) 협력
  중국: 텐센트·알리바바 플랫폼 직접 협약
  미국: MPAA 협력 채널 활용
```

## 위조 굿즈 대응

### 위조품 탐지

```
모니터링 채널:
  쿠팡·11번가·G마켓: 월 2회 검색 (캐릭터명 키워드)
  아마존·이베이: 월 1회 (영문 검색)
  라쿠텐·메르카리 (일본): 월 1회
  타오바오·징동 (중국): 주 1회 (중국 시장 고위험)
  인스타그램 샵: 월 1회 이미지 검색

위조품 판별 기준:
  공식 QR 코드 인증 없음
  색상·폰트 오류 (브랜드 가이드라인 불일치)
  공식 인증 마크 없음
  가격 50% 이하 (비정상적 저가)
```

### 위조품 대응 단계

```
LEVEL 1 (플랫폼 신고):
  대상: 온라인 판매 위조품
  방법: 플랫폼 IP 신고 시스템
  처리: 통상 48~72시간 내 삭제

LEVEL 2 (법적 경고장):
  대상: 반복 위반 판매자 or 대량 위조
  내용: 제조·판매 중단 + 재고 폐기 요구
  기한: 수령 후 7일 내 응답

LEVEL 3 (민사 소송):
  대상: 경고장 무시 or 대규모 조직 위조
  청구: 손해배상 + 판매 금지 가처분
  관할: 한국 → 한국 법원 / 해외 → 현지 법원

LEVEL 4 (형사 고발):
  대상: 조직적 대규모 위조 (산업 규모)
  기관: 경찰청 지식재산범죄 수사대 (IPCU)
  해외: Interpol IP Crime 협력
```

## 팬 창작물 가이드라인

```
허용 범위 (Fan Creation Policy):
  개인 비영리 팬아트: 허용 ✓
  팬픽션 (비영리): 허용 ✓
  코스프레: 허용 ✓ (상업 행사 개인 참가 포함)
  팬아트 SNS 공유: 허용 ✓ (출처 명시 조건)

조건부 허용:
  팬아트 굿즈 자가 제작 (소량): 허용
    단, 1회당 50개 이하 / 온라인 판매 금지
  팬 영상 (패러디·리뷰): 허용
    단, 드라마 원본 15분 이상 무편집 업로드 금지

금지 사항:
  상업적 판매 팬아트 (허가 없이 금지)
  캐릭터 명예훼손 콘텐츠 (성인물 포함)
  공식 로고·상표 무단 상업 사용
  AI 생성 + 무단 상업 판매

팬 크리에이터 공식 프로그램:
  「삼국 IP 공식 팬 크리에이터」등록제
  등록 시: 상업적 팬아트 소량 판매 허가
  수익의 10%: IP 프로젝트에 로열티 납부
```

## 역사 고증 관련 법적 리스크

```
명예훼손 리스크:
  실존 역사 인물 창작 묘사 → 후손·단체 이의 가능성
  대응: 「역사적 사실에 기반한 창작」명시
  특히 주의: 의자왕·계백 묘사 (부정적 측면)

일본 관련 법적 리스크:
  임나일본부 관련 내용 → 일본 우익 단체 소송 가능성
  백강 전투 왜군 묘사 → 일본 내 반발
  대응: 사전 법무 검토 후 배급 / 해당 장면 편집 옵션 준비

중국 관련 법적 리스크:
  고구려 = 한국사 주장 → 중국 동북공정 충돌
  중국 배급 시: 고구려 영토 지도 표현 신중 처리
  대응: 중국 배급본 별도 제작 검토

국내 심의:
  드라마: 방송통신심의위원회 사전 심의
  게임: 게임물관리위원회 등급 심사 (전체·12세·15세·18세)
  웹툰: 자율 심의 (네이버·카카오 플랫폼 기준)
```

## 연간 법무 일정

```
1월: 전년도 저작권 침해 연간 보고서
2월: 해외 상표 갱신 점검 (일본·미국·EU)
3월: 신규 시즌 콘텐츠 저작권 등록
4월: 라이선싱 파트너 계약 갱신 점검
6월: 위조품 모니터링 강화 기간 (드라마 방영 시즌)
9월: 글로벌 배급 법적 리스크 점검
12월: 연간 법무 리뷰 + 내년도 전략 수립

긴급 대응 (상시):
  온라인 불법 스트리밍 → 24시간 대응
  위조 굿즈 대량 발견 → 48시간 내 조치
  언론 보도 법적 이슈 → 즉시 법무팀 소집
```
