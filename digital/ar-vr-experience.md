## AR/VR 콘텐츠 전략

삼국(三國) IP의 AR/VR은 **"역사가 살아있는 체험"**을 목표로 한다. 교과서 속 역사가 아닌, 삼국시대 왕국에 직접 발을 딛는 경험. 박물관·학교·가정·테마파크 전 환경에서 접근 가능하도록 설계한다.

```
AR/VR 콘텐츠 분류:
TYPE A — 모바일 AR: 스마트폰 카메라 기반
TYPE B — VR 헤드셋: 몰입형 체험 (Quest·PSVR)
TYPE C — 박물관 AR: 유물 앞 AR 오버레이
TYPE D — 체험관 VR: 고정 설치형 대형 체험
TYPE E — SNS AR 필터: 소셜 공유용
```

## TYPE A — 모바일 AR

### A-1. 삼국 세계 AR 앱

```
앱명: 삼국 AR (三國 AR)
플랫폼: iOS / Android
가격: 무료 (게임 연동 보상)

핵심 기능:
1. 지도 AR
   - 현실 지도 위에 삼국시대 지도 오버레이
   - 한강 → "아리수(阿利水)" 명칭 표시
   - 경주 → "서라벌(徐羅伐)" 명칭 + 신라 영역 색상
   - 부여 → "사비성(泗沘城)" + 백제 영역

2. 유물 AR
   - 실제 유물 사진 촬영 → AR 3D 모델 등장
   - 금동대향로: 연기 피어오르는 애니메이션
   - 신라 금관: 반짝이는 곡옥(曲玉) 효과
   - 칠지도: 금빛 회전 애니메이션

3. 캐릭터 AR
   - 실제 공간에 캐릭터 소환
   - 광개토대왕: 갑옷 착용 + 환두대도 들기
   - 우륵: 가야금 연주 애니메이션
   - 선덕여왕: 금관 착용 + 별빛 이펙트
   - 사진 촬영 기능

4. 전투 AR
   - 실내 공간을 전장으로 변환
   - 개마무사 돌격 AR 체험
   - AR 투석기로 성벽 공격 미니게임
```

### A-2. 역사 유적 AR 가이드

```
연동 실제 유적지:
- 경주: 첨성대·불국사·신라 금관 박물관
- 부여: 낙화암·백마강·능산리고분군
- 공주: 무령왕릉·공산성
- 고령: 지산동고분군

기능:
- GPS 기반 유적지 도착 시 자동 실행
- 유적 앞 카메라 → 삼국시대 복원 모습 오버레이
  예) 황룡사지 → AR로 9층탑 복원
  예) 무령왕릉 입구 → 백제 시대 장식 복원

역사 해설:
- AR 캐릭터(선덕·계백·우륵)가 현장 설명
- 음성 해설 + 자막 (한/영/일)
- 역사 퀴즈 미니게임
```

## TYPE B — VR 헤드셋

### B-1. 삼국 VR: 강을 건너다

```
플랫폼: Meta Quest 2/3, PSVR2, PC VR
가격: 24,900원
러닝타임: 약 60분 (5개 챕터)

콘텐츠:
챕터 1 — 졸본(卒本)의 새벽 (고구려)
  체험: 주몽의 시점으로 졸본성 건설 현장
  특이점: 비류수 강변 걷기 체험
  이벤트: 소서노와의 협약 장면 관찰자 시점

챕터 2 — 사비성(泗沘城)의 황혼 (백제)
  체험: 백제 궁중 연회 참석 체험
  특이점: 금동대향로 앞에서 향 피우기 인터랙션
  이벤트: 의자왕의 마지막 연회

챕터 3 — 서라벌(徐羅伐)의 밤 (신라)
  체험: 첨성대 옥상에서 별 관측
  특이점: 실제 별자리 + 선덕여왕 해설
  이벤트: 선덕여왕의 모란꽃 독백 관찰

챕터 4 — 황산벌(黃山伐)의 새벽 (백제)
  체험: 계백 5천 결사대 출정 의식 참관
  특이점: 전쟁 소리 + 긴장감 최고조
  이벤트: 계백의 비장한 연설

챕터 5 — 가야의 강 (가야)
  체험: 우륵의 가야금 연주 감상 (강변)
  특이점: 공간음향 — 가야금 소리가 공간 가득
  이벤트: 우륵의 귀화 결단 독백
```

### B-2. 삼국 VR: 전장의 기억

```
플랫폼: PC VR (고사양)
가격: 19,900원
장르: 역사 체험형 전투 VR

체험 콘텐츠:
1. 살수대첩 참전 체험
   - 고구려 병사 시점
   - 살수 방류 순간 체험
   - 360도 전장 파노라마

2. 안시성 방어전 체험
   - 성벽 위에서 당나라군 격퇴
   - 투석기 직접 조작
   - 88일 중 최후 결전일 체험

3. 개마무사 돌격 체험
   - 철갑 기병 시점 돌격
   - 말 위에서 장창으로 적진 돌파
   - 속도감·충격감 햅틱 피드백 (지원 기기)

폭력 수위: PG-13 — 전투 있되 잔혹 묘사 없음
교육 모드: 어린이 안전 버전 (12세 이하)
```

## TYPE C — 박물관 AR

### C-1. 국립박물관 연동 AR

```
대상 박물관:
- 국립중앙박물관 (서울)
- 국립경주박물관
- 국립부여박물관
- 국립공주박물관
- 국립김해박물관

연동 방식:
- 박물관 앱 또는 삼국 AR 앱 연동
- 각 유물 앞 QR코드 스캔 → AR 활성화

유물별 AR 콘텐츠:
금동대향로 (부여 박물관):
→ AR: 제작 과정 3D 애니메이션
→ 내부 구조 투시 보기
→ 의자왕 시대 사용 장면 재현

신라 금관 (경주 박물관):
→ AR: 금관 착용 시 내 얼굴에 오버레이
→ 곡옥 흔들리는 소리 재현
→ 선덕여왕 착용 장면 홀로그램

무령왕릉 출토품 (공주 박물관):
→ AR: 무령왕릉 내부 3D 투어
→ 묘지석 비문 해독 인터랙션
→ 왕릉 발굴 과정 타임랩스

광개토대왕릉비 (집안 — 원격):
→ 실물 없는 박물관에서도 AR 모형 소환
→ 비문 1,775자 스크롤 해설
→ 을지문덕 시 전문 낭독
```

```
대상: 중학교 역사 수업 (삼국시대 단원)

교사 도구:
- 수업 진행 대시보드
- 학생 참여도 실시간 확인
- 퀴즈 정답률 통계

가격: 학교 단위 연간 구독 — 학교당 50만원
```

## TYPE D — 체험관 VR

### D-1. 삼국(三國) VR 체험관

```
설치 대상: 테마파크·문화회관·과학관 등
면적: 최소 100평 기준

체험존 구성:
Zone 1 — 광개토대왕의 땅 (고구려)
  장치: 대형 돔 스크린 (직경 8m) + VR 의자
  내용: 개마무사 행진 + 요동 전투 파노라마
  시간: 10분

Zone 2 — 백제의 황금 궁전
  장치: 4D 의자 + 향기 장치
  내용: 사비성 궁중 + 금동대향로 의식
  향기: 백제 향료 재현 (샌들우드·연꽃)
  시간: 8분

Zone 3 — 신라 첨성대의 밤
  장치: 누워서 보는 천장 스크린 (플라네타리움)
  내용: 선덕여왕 별 관측 + 별자리 해설
  시간: 12분

Zone 4 — 가야금 소리의 공간
  장치: 공간음향 방 (360도 스피커)
  내용: 우륵 연주 + 가야 역사 내레이션
  시간: 8분

Zone 5 — 황산벌의 결전 (인터랙티브)
  장치: 모션 플랫폼 + VR 헤드셋
  내용: 계백 결사대 돌격 체험 (PG-13)
  시간: 15분

운영:
- 1세션: 약 60분 (전 Zone 순환)
- 정원: Zone당 8~12명
- 가격: 1인 25,000원 / 학생단체 15,000원
```

## 기술 사양

```
모바일 AR (TYPE A):
- 엔진: Unity + AR Foundation
- 최소 사양: iPhone 12 / Android 10 이상
- ARCore / ARKit 활용

VR 헤드셋 (TYPE B):
- 엔진: Unreal Engine 5
- 타겟 해상도: 각 눈 2064×2208px (Quest 3 기준)
- 프레임: 72fps 이상 (90fps 권장)
- 최적화: 배경 LOD / 캐릭터 최대 폴리곤

박물관 AR (TYPE C):
- 마커 인식: Vuforia / AR Core 마커리스
- 클라우드 연동: 유물 DB 실시간 업데이트
- 다국어: 한/영/일/중 자동 감지

체험관 (TYPE D):
- 메인 서버: 로컬 고성능 PC (RTX 4090 이상)
- VR 헤드셋: 무선 (Wi-Fi 6E)
- 모션 플랫폼: 6-DOF 기준
```
