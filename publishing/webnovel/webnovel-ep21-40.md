## 제2막 개요 — 시험의 시대 (21~40화)

주몽이 고구려를 세웠다. 이제 나라를 지켜야 한다. 제2막은 건국 후 첫 위기들의 연속이다. 외부의 적, 내부의 불신, 그리고 주몽 자신이 왕으로서 성장하는 이야기다.

```
제2막 핵심 갈등:
- 비류국 송양의 재도전
- 행인국·북옥저 편입 과정의 갈등
- 소서노와 예씨(유리 어머니) 사이의 긴장
- 말갈족 충성 문제
- 주몽의 첫 번째 개인적 위기: 아들 유리의 부재
```

---

## 21화 — 소서노의 계산

**클라이맥스**: 소서노가 졸본 부여 왕 연타발에게 추가 지원을 요청한다. 연타발은 딸의 요청을 들어주지만 조건을 건다 — "주몽이 연타발 가문을 왕실 외척으로 인정해야 한다."

```
주요 장면:
- 소서노가 저택 장부를 펼치는 장면 — 남은 재산 계산
- 연타발과의 협상 — 부녀의 냉정한 거래
- 주몽에게 결과를 보고하는 소서노
  주몽: "당신은 항상 내가 모르는 곳에서 싸우고 있소."
  소서노: "그것이 제 역할입니다."

훅: "그런데, 대왕. 유리 왕자 소식을 들으셨습니까?"
```

---

## 22화 — 북쪽에서 온 전사

**클라이맥스**: 말갈족 추장 '돌바위'가 300명의 부족민을 이끌고 졸본에 나타난다. 항복이 아닌 동등한 동맹을 요구한다.

```
주요 장면:
- 돌바위와 주몽의 첫 만남 — 두 강자의 탐색전
- 돌바위: "우리는 신하가 되지 않는다. 형제가 된다."
- 주몽의 결단 — "형제로 받아들인다" (신하 관계 강요 않음)
- 오이의 반발: "대왕, 저들을 믿을 수 없습니다"

훅: 그날 밤 졸본 창고에 불이 난다 — 방화인가 우연인가
```

---

## 23화 — 불의 밤

**클라이맥스**: 창고 화재 범인을 추적한다. 범인은 말갈족이 아닌 졸본 부여 출신 불만 세력이었다.

```
주요 장면:
- 오이의 수사 — 증거 추적
- 범인 자백: "당신들이 오기 전 우리는 평화로웠다"
- 주몽의 판결 — 처형이 아닌 노역형
  오이: "약한 처벌입니다"
  주몽: "두려움으로 다스리면 두려움만 남는다"

훅: 범인이 노역 중 주몽에게 말한다 — "부여에서 사람이 왔습니다"
```

---

## 24화 — 부여의 그림자

**클라이맥스**: 부여에서 온 사람은 대소(帶素)의 밀사였다. "주몽이 돌아오지 않으면 예씨(禮氏)와 아들을 해치겠다"는 협박이었다.

```
주요 장면:
- 밀사를 심문하는 주몽 — 분노를 절제하는 왕
- 주몽의 독백: "나는 두 가지를 택할 수 없다. 왕과 아버지를."
- 소서노에게 진실을 말하는 주몽
  소서노의 반응: 예상보다 담담함 — "그 분은 안전하십니까?"

훅: 소서노가 비류를 안고 밤하늘을 바라보는 장면
    "비류야, 너에게도 형이 있단다. 언젠가 만나게 될 거야."
```

---

## 25화 — 송양(松讓)의 귀환

**클라이맥스**: 비류국 송양이 세 번째로 나타난다. 이번엔 군사 없이 혼자. "협력하자"는 제안을 가져왔다.

```
주요 장면:
- 송양과 주몽의 단독 회담
- 송양: "나는 졌다. 그러나 당신도 혼자서는 살아남을 수 없다."
- 송양의 제안: 혼인 동맹 — 송양의 딸과 주몽의 신하
- 주몽의 결단: "좋소. 단 비류국은 고구려의 일부가 되어야 하오."

훅: 송양이 돌아가며 중얼거린다 — "저 왕은 오래 산다. 그것이 문제다."
```

---

## 26화 — 첫 번째 법

**클라이맥스**: 주몽이 고구려 최초의 성문법(成文法)을 반포한다. 8조항 — 살인·상해·절도·배신에 대한 규정.

```
주요 장면:
- 법 초안 작성 장면 — 주몽과 학자 출신 신하
- 귀족들의 반발: "법이 귀족에게도 적용됩니까?"
  주몽: "왕에게도 적용된다."
- 법 반포 당일: 백성들이 성문 앞에 모여듦
- 첫 재판 — 말갈족 돌바위의 부하가 졸본 상인을 때린 사건
  주몽이 직접 재판장으로

훅: 법정에서 돌바위가 주몽을 바라보는 눈빛 — 이것이 신뢰의 시작
```

---

## 27화 — 행인국(荇人國)

**클라이맥스**: 동쪽 소국 행인국이 자발적으로 귀부를 청한다. 그러나 귀부 조건이 까다롭다.

```
주요 장면:
- 행인국 왕의 조건 목록 — 자치권 유지 요구
- 주몽의 답변: 조건 절반 수락, 절반 수정
- 협상 3일 — 실무 협상은 소서노가 담당
- 타결 장면: 행인국이 고구려의 일원이 됨

훅: 협상 중 소서노가 행인국 왕의 말에서 이상한 점을 발견
    "이들은 다른 누군가의 명령을 받고 있다."
```

---

## 28화 — 배후 세력

**클라이맥스**: 행인국 뒤에 북옥저(北沃沮)가 있었다. 북옥저는 행인국을 통해 고구려를 시험하고 있었다.

```
주요 장면:
- 소서노의 첩보 — 상인 네트워크를 통한 정보 수집
- 주몽의 결단: 북옥저에 직접 사신 파견
- 사신 파견 장면 — 오이가 사신단장
- 오이의 위기: 북옥저에서 인질로 잡힘

훅: "오이를 구해야 한다. 그러나 군사를 보내면 전쟁이다."
```

---

## 29화 — 오이(烏伊)를 구하라

**클라이맥스**: 주몽이 직접 소수의 정예와 함께 북옥저 경계까지 나선다.

```
주요 장면:
- 주몽의 야간 기습 작전 (전면전 아닌 구출)
- 북옥저 지역 지형 돌파
- 오이 구출 장면 — 두 남자의 짧은 재회
  오이: "대왕이 직접 오실 줄 몰랐습니다."
  주몽: "내 사람을 내가 구하지 누가 구하나."
- 북옥저와의 협상: 구출 후 협력 관계 제안

훅: 귀환 중 주몽의 말이 발을 절뚝인다 — 화살에 맞았다
```

---

## 30화 — 왕의 상처

**클라이맥스**: 주몽이 화살에 맞아 쓰러진다. 왕이 쓰러지면 나라가 흔들린다.

```
주요 장면:
- 주몽 부상 — 의식 잃음
- 졸본 내 동요 — 귀족들의 권력 암투 시작
- 소서노가 임시 국사를 처리하는 장면
- 말갈 돌바위가 성문 앞을 지키는 장면 — 무언의 충성

회복 장면:
- 의식 돌아온 주몽 — 소서노의 손을 잡고
  주몽: "당신이 나라를 지켰소."
  소서노: "다음엔 저도 데려가십시오."

훅: 회복 중 주몽에게 꿈이 찾아온다 — 부여의 예씨가 아들 손을 잡고 걸어가는 꿈
```

## 31~35화 요약 — 성장의 계절

```
31화: 고구려 첫 번째 추수 — 백성들의 감사 제천 의식
      소서노의 첫 아이 임신 확인 — 비류·온조 이후 셋째 가능성

32화: 부여 대소의 정식 최후통첩 — "1년 안에 돌아오라"
      주몽의 공개 거부 선언

33화: 부여군 선발대 남침 — 고구려 첫 번째 정규전
      돌바위 말갈 기병 첫 실전 투입

34화: 전투 승리 — 고구려 독립 완성
      부여 대소 굴욕적 철수

35화: 고구려 영토 확장 첫 공식 선언
      "압록강 이남에서 졸본까지 — 이것이 고구려다"
```

## 36화 — 유리(類利)의 소문

**클라이맥스**: 부여에서 도망친 상인에게 뜻밖의 소식이 들어온다. 예씨의 아들 유리가 아버지를 찾아 길을 떠났다는 소식.

```
주요 장면:
- 상인의 증언: "10대 소년이 반쪽 검을 들고 남쪽으로 갔습니다"
- 주몽의 반응 — 즉각 수색대 파견
- 소서노의 내면: "그 아이가 오면 무슨 일이 일어날까"
  그러나 소서노가 말한다: "수색을 도울 사람을 더 붙이십시오"

훅: 수색대가 돌아온다 — "찾았습니다. 그런데 아이가 혼자가 아닙니다."
```

---

## 37화 — 유리의 도착

**클라이맥스**: 유리가 졸본에 도착한다. 반쪽 검과 함께. 아버지를 처음 만나는 장면.

```
주요 장면:
- 성문 앞 유리와 주몽의 첫 대면 (소설 6장 동일 장면 — 웹소설 버전)
- 유리의 눈: 분노인지 그리움인지 모호함
- 검 맞추기 — "딸깍"
- 주몽이 무릎을 꿇음 — "늦게 왔구나"

소서노 시점 추가:
- 멀리서 이 장면을 바라보는 소서노
- 비류가 어머니 손을 잡는 장면
  비류: "어머니, 저 형은 누구예요?"
  소서노: "…고구려의 왕자다."

훅: 유리가 졸본에서 첫 밤을 보낸 후 일기를 쓴다 (삽입 형식)
    "아버지를 만났다. 생각보다 더 크고 생각보다 더 작았다."
```

---

## 38화 — 두 왕자

**클라이맥스**: 유리와 비류·온조의 첫 접촉. 예상 밖의 전개.

```
주요 장면:
- 비류가 유리에게 먼저 말을 건다: "검술 가르쳐줄게"
- 유리의 경계 → 점점 열림
- 온조는 멀리서 관찰 — 전략적 탐색
- 소서노가 주몽에게: "아이들은 어른보다 빠릅니다"
- 주몽의 고민: 세자 책봉 문제

훅: 귀족 회의에서 한 신하가 말한다
    "세자를 결정하셔야 합니다, 대왕."
```

---

## 39화 — 세자 논의

**클라이맥스**: 귀족들이 세자 책봉을 공식 요구한다. 주몽의 결단이 필요한 순간.

```
주요 장면:
- 귀족 회의의 양 파벌:
  "유리는 적자입니다 — 정통성"
  "비류는 공을 세웠습니다 — 현실"
- 주몽이 회의를 중단시킴: "아직 결정하지 않겠다"
- 소서노와의 단독 대화
  소서노: "유리 왕자를 세자로 하십시오"
  주몽: "당신이 그리 말하는 줄 몰랐소"
  소서노: "적자입니다. 그것이 순리입니다. 저는 제 아이들의 길을 다른 곳에서 찾겠습니다."

훅: 소서노가 혼자 방에서 지도를 펼친다 — 한강 이남 지역
```

---

## 40화 — 소서노의 결심

**클라이맥스**: 소서노가 남쪽으로 떠날 준비를 시작한다. 아무도 모르게.

```
주요 장면:
- 소서노가 신뢰하는 상인에게 한강 이남 지형 탐문
- 비류와 온조에게 조심스럽게 의중 타진
  비류: "우리가 새 나라를 세운다는 말입니까?"
  소서노: "아직 아무것도 결정된 것이 없다. 그냥 물어본 것이다."
- 주몽과의 마지막 평온한 저녁 — 두 사람 모두 무언가를 알면서도 말하지 않음
- 소서노의 독백: "강은 기억한다. 내가 여기서 한 모든 것을."

훅: 유리의 세자 책봉식 날짜가 잡힌다
    소서노는 그날 밤 짐을 싸기 시작한다.
    — 2막 종료. "3막: 남쪽으로" 예고
```
