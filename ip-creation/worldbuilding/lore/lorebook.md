## Layer 1 — 신화 (Mythology)

### 천지 창조 — 한반도 신화

```
태초의 세계:
하늘(天)과 땅(地)이 분리되기 전 — 혼돈(混沌)의 시대
빛(光)이 하늘로 올라가고, 어둠(暗)이 땅으로 내려앉음
최초의 강(初江): 천지 경계에서 흐르기 시작

강의 탄생 신화 (IP 핵심 모티프):
「처음 강이 흘렀을 때 하늘이 기억했다.
 처음 인간이 강을 건넜을 때 땅이 기억했다.
 처음 나라가 세워졌을 때 강이 기억했다.」
→ 「강은 기억한다」슬로건의 신화적 근거

IP 활용:
- 드라마 오프닝 내레이션
- 게임 로딩 화면 창조 신화 텍스트
- 뮤지컬 프롤로그
```

### 고구려 건국 신화 — 주몽 (朱蒙)

```
원전: 삼국사기 고구려본기, 광개토대왕릉비 비문
「始祖鄒牟王之創基也 出自北夫餘」

신화 내용:
출생: 하백(河伯)의 딸 유화(柳花)와 천제(天帝)의 아들 해모수의 아들
탄생: 알에서 태어남 (난생 신화)
  「卵生—光照之 後遂剖卵出— 骨表英奇」
능력: 활 솜씨 타의 추종 불허 (「朱蒙」= 활 잘 쏘는 이)
탈출: 부여의 왕자들의 탄압 피해 남하
건국: BC 37년 졸본천에서 고구려 건국

신성 동물:
삼족오 (三足烏): 태양 속에 사는 세 발 까마귀
  - 광개토대왕릉비: 건국 신화 상징
  - 고구려 고분벽화: 일상적 모티프
  - IP 적용: 고구려 왕실 엠블럼, 고루의 갑옷 문양

IP 활용:
드라마 시즌 1 첫 장면: 삼족오가 하늘을 가로질러 날아가며 시작
고루 독백: 「삼족오는 세 발로 태양을 받들었다. 나는 무엇으로 이 땅을 받들 것인가.」
```

### 백제 건국 신화 — 온조 (溫祚)

```
원전: 삼국사기 백제본기
주몽의 아들 온조, 남쪽으로 내려와 위례성(慰禮城)에 건국

신화 내용:
온조 + 비류 형제 남하 → 형 비류는 미추홀, 온조는 위례
비류의 땅은 바닷물이 짜 실패 → 온조의 나라 번성
비류 사망 후 백성 흡수 → 백제 성장

신성 동물:
봉황 (鳳凰): 백제 왕실 상징
  - 백제 금동대향로 꼭대기 봉황
  - 무령왕릉 장식 봉황 문양
  - IP 적용: 아랑의 봉황 단검, 사비성 왕실 문장

강 신화 (백제):
웅진천·백마강 전설:
「백마가 강을 건너면 나라가 평안하고,
 백마가 강물에 잠기면 나라가 위태롭다.」
→ 660년 낙화암 사건과 연결 (IP 드라마 시즌 3)
```

### 신라 건국 신화 — 혁거세 (赫居世)

```
원전: 삼국사기 신라본기, 삼국유사

신화 내용:
탄생: 나정(蘿井) 옆 알에서 출생 (난생 신화)
  「閼英 = 龍이 나타나 오른쪽 갈비뼈에서 여자아이 출산」
      (혁거세의 왕비 알영도 신성 탄생)
건국: BC 57년 서라벌에서 신라 건국
이름: 「赫居世」= 세상을 밝게 함 (혁= 빛)

황금 모티프:
신라 = 황금의 나라
  - 금관, 금귀걸이, 금팔찌 — 전 귀족 착용
  - 「경주는 황금이 나는 땅」
  - IP 적용: 신라 황금 #FFD700 색채, 하린의 금 비녀

박·석·김 3성 교대 왕권:
신라의 독특한 정통성 — IP에서 외교적 복잡성 반영
```

### 가야 건국 신화 — 수로왕 (首露王)

```
원전: 삼국유사 가락국기

구지가 (龜旨歌) — 한반도 현존 최고(最古) 서사시:
「龜何龜何 首其現也
 若不現也 燔灼而喫也」
(거북아 거북아 머리를 내밀어라
 내밀지 않으면 구워서 먹겠다)

탄생 신화:
구지봉에서 9간(九干)이 노래 → 하늘에서 금합이 내려옴
금합 속 황금 알 6개 → 수로왕 + 5가야 왕
허황옥 (許黃玉): 아유타국에서 바다를 건너온 왕비
  - 인도에서 왔다는 전설 (국제적 기원)
  - IP에서 가야의 교역 국제성 반영

철의 신 (鐵神):
가야 = 동아시아 최고 철 생산지
철을 다루는 자가 가야를 다스림
  - 대장간이 가야의 신전
  - 철정(鐵鋌) = 가야의 화폐이자 제물
  - IP 적용: 니문의 철정 방패, 가야 존 「철과 노래의 땅」
```

## Layer 2 — 전설 (Legend)

### 선덕여왕 3예언 전설

```
원전: 삼국유사

예언 1 — 모란꽃:
당나라에서 모란꽃 씨앗과 그림이 도착
선덕: 「이 꽃은 아름다우나 향기가 없다.」
이유: 그림에 나비가 없음 → 향기 없는 꽃
결과: 실제로 향기 없는 꽃
→ IP 적용: 선덕의 첫 번째 예지력 에피소드 (시즌 1)

예언 2 — 개구리:
영묘사 옥문지(玉門池)에서 개구리가 3일간 울음
선덕: 「여근곡(女根谷)에 백제 군사가 숨어있다.」
결과: 여근곡에서 백제 복병 500명 발견
→ IP 적용: 하린이 목격하는 신라 방위 핵심 장면

예언 3 — 자신의 죽음:
선덕: 「내가 ○년 ○월 ○일에 죽을 것이다. 도리천(忉利天)에 묻어라.」
신하들: 「도리천이 어디입니까?」
선덕: 「낭산(狼山) 남쪽이다.」
결과: 예언대로 사망, 낭산 남쪽에 매장
       → 이후 문무왕이 그 아래 사천왕사 건립
       → 도리천(四天王 위 천계)의 상징 완성
→ IP 적용: 시즌 2 최대 감동 에피소드, 하린의 눈물

IP 메시지: 아는 자의 용기 = 선덕은 알면서도 두려워하지 않았다
```

### 을지문덕 시 전설

```
원전: 삼국사기 을지문덕 열전

살수대첩 전, 수나라 장군 우중문에게 보낸 시:
「神策究天文 妙算窮地理 戰勝功旣高 知足願云止」
(신묘한 책략이 천문을 꿰뚫고
 오묘한 계산이 지리를 통달했다.
 전쟁에서 이겼으니 공이 이미 높거늘
 만족함을 알아 이제 그만 물러가시오.)

전설:
이 시를 받은 우중문은 을지문덕의 후퇴가 유인임을 의심
그러나 이미 깊이 들어온 수나라 군대 보급선 끊김
살수에서 방류 → 수나라 30만 섬멸

IP 활용:
고루가 이 시를 암기하고 있음 — 시즌 내내 상황에 따라 인용
게임 을지문덕 스킬 발동 시 시 구절 효과음
드라마 고루 독백: 「지족원운지(知足願云止)— 만족함을 알아 물러가라. 나는 아직 만족하지 못했다.」
```

### 우륵과 가야금 전설

```
원전: 삼국사기 악지(樂志)

「于勒…作十二曲 其後 于勒知加耶亡 攜琴投新羅」
(우륵이 12곡을 지었다.
 그 후 우륵은 가야가 망할 것을 알고
 가야금을 들고 신라에 투항했다.)

전설의 의미:
악기가 나라보다 오래 산다
문화는 정치적 멸망을 초월한다
투항은 굴복이 아니라 음악의 생존 선택

12악곡:
현존하는 11곡 이름: 하가라도(下加羅都)·상가라도·보기·달이·사물·물혜·하기물·사자기·거열·사팔혜·이사
12번째: 이름·내용 전해지지 않음
→ IP 핵심 미스터리: 니문이 12번째 악곡 재창조

IP 활용:
니문 캐릭터의 전체 서사 동력
「12번째 곡」= IP 전체 감성 클라이맥스 상징
```

### 도미 설화 (백제)

```
원전: 삼국사기 열전

백제 평민 도미(都彌)와 그의 아내:
개루왕이 도미의 아내에게 탐욕 → 도미 눈 멀게 하고 유배
아내: 왕의 유혹 거절, 먼 강을 건너 남편 구함
두 사람 고구려에서 재회 → 여생 평안

IP 활용:
아랑 캐릭터 배경 에피소드 — 백제 사관의 기록 소재
백제 왕권의 도덕적 균열 암시 (의자왕 서사 복선)
드라마 시즌 2 삽입 에피소드
```

## Layer 3 — 세계관 설정 신화적 확장

### 강의 신격 (IP 창작 요소)

```
삼국 세계관에서 강은 신격화된 존재:

대동강 신 (고구려):
이름: 「패하신(浿河神)」(창작)
성격: 냉정하고 강인, 북방 바람의 화신
관계: 고구려 왕실 수호신
고루와의 연결: 살수대첩 후 「강이 나를 기억한다」체험

백마강 신 (백제):
이름: 「금강신(錦江神)」(창작)
성격: 우아하고 슬픔을 품은, 봄꽃의 화신
관계: 백제 예술·문화 수호
아랑과의 연결: 낙화암 장면 (시즌 3) 복선

형산강 신 (신라):
이름: 「형하신(兄河神)」(창작)
성격: 맑고 투명, 별빛의 화신
관계: 화랑도 수호신
하린과의 연결: 첨성대 완공 장면

낙동강 신 (가야):
이름: 「낙하신(洛河神)」(창작)
성격: 너그럽고 넓음, 철의 화신
관계: 가야 장인·악사 수호
니문과의 연결: 12번째 곡 완성 순간

IP 규칙:
강의 신은 직접 등장하지 않음 (비가시적 존재)
강물의 소리·움직임·날씨로만 존재 표현
주인공들이 강에서 결정적 계시를 얻는 구조
```

### 삼족오 신화 (고구려 심화)

```
삼족오 (三足烏) 세계관 설정:

원전: 중국·한국 고대 신화, 고구려 벽화 다수 묘사

IP 설정 (역사 기반 + 창작):
삼족오 = 태양의 사자 (使者)
고구려 왕실 = 태양의 후손 (주몽 = 천제 아들)
삼족오가 나타나는 날 = 전쟁 전조 또는 왕의 죽음

고루의 삼족오 환영:
살수대첩 전날 밤 고루가 꿈에서 삼족오를 봄
「세 발 중 하나가 부러진 삼족오」
→ 을지문덕 장군의 죽음 예언으로 해석 (시즌 2)
→ 드라마 씬: 새벽 하늘에 삼족오 실루엣 (CGI)
```

### 가야 구지봉 신화 심화

```
구지봉 (龜旨峰) 세계관 설정:

원전: 삼국유사 가락국기 구지가

IP 설정:
구지봉 = 가야의 배꼽 (세계의 중심)
수로왕 탄강 이후 구지봉은 성지(聖地)
562년 가야 멸망 후 구지봉은 신라 영토가 되었으나
가야 유민들은 매년 비밀리에 구지가를 부름

니문의 구지봉 방문 (시즌 2 에피소드):
니문이 구지봉을 찾아가 구지가를 부름
새로운 언어로, 신라 사람들이 듣는 앞에서
「거북아 거북아— 가야는 아직 기억된다.」

IP 메시지:
사라진 나라도 성지는 남는다
기억하는 자가 있는 한 문화는 지속된다
```

## 신화적 존재 목록

```
실제 한국 신화 기반:
삼족오 (三足烏): 태양의 새 → 고구려
봉황 (鳳凰): 왕권의 새 → 백제
주작 (朱雀): 남방 수호신 → 신라 관련
현무 (玄武): 북방 수호신 → 고구려 관련
청룡 (靑龍): 동방 수호신 → 전반적
백호 (白虎): 서방 수호신 → 신라 관련

강서대묘 사신도 (고구려, 평안남도):
현존 최고 사신도 걸작 → IP 벽화 레퍼런스

창작 신화 존재 (IP 오리지널):
철신(鐵神): 가야 대장간 수호 — 니문의 환영 속 등장
악신(樂神): 우륵이 부른 존재 — 가야금 속에 깃든 것
기억신(記憶神): 강들의 신격 — 직접 등장 없음

사용 규칙:
역사 기반 신화: 그대로 사용, 「원전: 」명기
창작 신화 존재: 「창작 설정」명기
신화 존재가 직접 역사를 바꾸는 설정 금지 (역사 팩트 보호)
```
