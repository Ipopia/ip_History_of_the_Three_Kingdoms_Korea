# 게임 캠페인 스토리 — 삼국(三國) IP

**참조 문서**: `game-design-document.md`, `unit-design-guide.md`, `master-bible.md`
**작성**: 게임본부 시나리오팀 + IP창작본부 서사팀
**장르**: 전략 RPG 「삼국(三國): 강은 기억한다」

---

## 캠페인 개요

```
구조: 4개 왕국 독립 캠페인 + 통합 엔딩 캠페인
총 미션: 약 60개 (왕국별 12~15 + 통합 8)
주인공: 창작 인물 (역사 인물은 NPC·영웅 유닛)
내러티브: 비선형 — 원하는 왕국 캠페인부터 시작 가능
         완주 순서에 따라 통합 엔딩 내용 달라짐

권장 플레이 순서:
1→ 고구려 캠페인 (배경·맥락 이해)
2→ 가야 캠페인 (약자의 관점)
3→ 백제 캠페인 (외교·문화)
4→ 신라 캠페인 (통일 시점)
5→ 통합 엔딩 (「강은 기억한다」)
```

---

## 고구려 캠페인 — 「삼족오의 날개」

### 캠페인 개요

```
주인공: 고루 (창작 — 20대 고구려 청년 장교)
시기: 광개토대왕 재위~영양왕 살수대첩
테마: 전쟁의 영광과 무게 / 기억과 책임

캐릭터 설정:
고루 — 변방 출신 장교. 실력으로 중앙군 편입.
        을지문덕의 부하. 전쟁을 모르다가 알게 됨.
        「강이 기억한다」는 말의 의미를 마지막에 깨달음.

빌런 역할: 수나라 장군 우중문 (실존)
           내부 적: 고루를 시기하는 귀족 장교 (창작)
```

### 미션 구성

```
Chapter 1 — 「졸본의 청년」
미션 1: 변방 수비 훈련 (튜토리얼)
   목표: 말갈 소규모 침입 격퇴
   배움: 기본 전투·이동·지형 효과
   연출: 고루의 첫 전투, 어설프지만 용감

미션 2: 요동 원정 선봉
   목표: 요동성 외곽 적 정찰대 격파
   배움: 척후·정보 수집 시스템
   연출: 광개토대왕을 멀리서 처음 목격

미션 3: 백암성 전투
   목표: 성벽 방어 + 반격
   배움: 성채 전투·농성 시스템
   연출: 을지문덕이 고루를 처음 눈여겨봄

Chapter 2 — 「수나라가 온다」
미션 4: 요하(遼河) 방어선
   목표: 수나라 선봉대 저지
   배움: 병과 상성·교량 전투
   연출: 수나라의 압도적 규모 첫 조우 (공포감)

미션 5: 을지문덕의 계략 (1)
   목표: 의도적 후퇴 + 수나라 유인
   배움: 후퇴 전술·보급선 차단
   특수: 이기지 않는 미션 (후퇴가 정답)
   연출: 지는 것이 전략임을 고루가 배움

미션 6: 을지문덕의 계략 (2)
   목표: 수나라군 분산 유도
   배움: 다중 거점 방어
   연출: 고루가 독립 작전 첫 수행

Chapter 3 — 「살수의 결단」
미션 7: 살수 상류 확보
   목표: 살수 댐 위치 점령·보호
   배움: 핵심 거점 방어 전술
   연출: 고루가 살수 방류 작전 처음 들음

미션 8: 수나라 본진 지연 작전
   목표: 3턴간 버티기 (방어 미션)
   배움: 소수로 다수 저지
   연출: 고루 부대 거의 전멸 위기

미션 9: 「살수대첩」(클라이맥스)
   목표: 방류 신호 보호 + 퇴로 차단
   배움: 타이밍·협동 작전
   특수: 을지문덕이 방류 결정 → 고루가 실행
   연출: 살수 범람 시네마틱 (최고 연출)

Chapter 4 — 에필로그 「강이 기억한다」
미션 10: 수나라 잔병 처리
   목표: 퇴각하는 적 추격 여부 선택
   분기: 추격 → 전멸 / 포기 → 생환
   테마: 끝까지 죽이는 것이 옳은가?

미션 11: 귀환
   목표: 없음 (컷씬 미션)
   연출: 고루가 비류수에서 강물을 봄
         강이 고루에게 말하는 것 같음
         「나는 기억하겠다」

미션 12: 「고구려 수호」
   목표: 다음 수나라 침공 대비 요새 건설
   배움: 건설·방어 시스템
   연출: 을지문덕의 마지막 조언 + 고루 독립

[캠페인 엔딩]
고루는 평양 외곽 수비대 장군이 됨.
강변에서 홀로 있는 장면으로 마무리.
비류수 강물 소리.
「강은 기억한다.」
```

## 백제 캠페인 — 「금빛 황혼」

### 캠페인 개요

```
주인공: 아랑 (창작 — 백제 궁중 외관)
시기: 의자왕 즉위~황산벌 전투
테마: 충성과 의심 / 아름다운 것의 소멸

캐릭터 설정:
아랑 — 소서노 후손이라는 전설을 가진 외관.
        백제 궁중 문화의 아름다움에 빠져있지만
        멸망의 그림자를 먼저 보게 됨.
        「아름다운 것은 반드시 끝난다」는 테마

빌런 역할: 신라 장군 김유신 (실존, 적대 세력)
           내부 갈등: 태자와 충신의 분열 (창작)
```

### 미션 구성

```
Chapter 1 — 「사비성의 봄」
미션 1: 외교 사절 수행 (외교 튜토리얼)
   목표: 남조(중국) 사절 접견 준비
   배움: 외교 시스템·자원 관리

미션 2: 가야 철 교역로 보호
   목표: 교역 상단 습격 격퇴
   배움: 교역 시스템·루트 방어

미션 3: 금동대향로 제작 의뢰 수행
   목표: 장인 구역 보호 + 자재 조달
   연출: 아랑이 금동대향로 완성 목격

Chapter 2 — 「의자왕의 시대」
미션 4: 대야성 공략 지원
   목표: 보급선 확보
   배움: 장거리 원정 보급 시스템
   연출: 승전 소식 — 아랑은 기뻐할 수 없음

미션 5: 신라 반격 저지
   목표: 신라군 진격 3번 막기
   배움: 연속 방어·소모전 전술
   연출: 김춘추의 복수 의지 정보 입수

미션 6: 고구려 외교 시도
   목표: 고구려-백제 동맹 협상 (외교 미션)
   결과: 실패 (역사적 사실)
   연출: 아랑이 고구려 사신과 대화

Chapter 3 — 「황혼이 온다」
미션 7: 나당연합군 첫 접촉
   목표: 신라·당 연합군 정보 수집
   배움: 적 규모 파악·대응 준비
   연출: 수도에서 연회가 계속됨 (비극적 아이러니)

미션 8: 계백 결사대 출정 지원
   목표: 결사대 출정 보급 확보
   연출: 계백과 아랑의 짧은 대화
         「잘 돌아오십시오」「돌아오지 않을 것이다」

미션 9: 황산벌 — 계백의 싸움
   목표: 없음 (관찰자 시점 컷씬)
   연출: 계백 최후 장면
         아랑은 멀리서 봄
         황산벌 석양

Chapter 4 — 에필로그 「기억만이 남아」
미션 10: 사비성 마지막 방어
   목표: 사비성 탈출 루트 확보
   분기: 금동대향로 들고 탈출 / 두고 탈출
   결과: 양쪽 다 멸망. 무엇을 들고 가느냐가 다름.

미션 11: 「낙화암의 강」
   목표: 없음 (컷씬)
   연출: 백마강 장면
         아랑이 강에 연꽃 띄움
         「강은 기억할 것이다」

[캠페인 엔딩]
아랑은 살아남았다.
어딘가에서 백제 문화를 기록하기 시작한다.
금동대향로가 어디 있는지는 알 수 없다.
(부여박물관에 있다 — 메타픽션 힌트)
```

## 신라 캠페인 — 「별의 길」

### 캠페인 개요

```
주인공: 하린 (창작 — 신라 여성 화랑 지망생)
시기: 선덕여왕 재위~삼국통일 직전
테마: 여성의 도전 / 통일의 의미

캐릭터 설정:
하린 — 화랑이 되고 싶은 여성.
        선덕여왕에게 감화받음.
        전쟁에서 이기는 것만이 답이 아님을 깨달음.
```

### 미션 구성

```
Chapter 1 — 「서라벌의 별」
미션 1~3: 화랑 선발 과정 (3개 미션)
   배움: 신라 유닛 시스템
   연출: 선덕여왕 즉위 장면

Chapter 2 — 「위기의 신라」
미션 4~6: 백제·고구려 협공 대응
   배움: 다면 방어·동맹 시스템
   연출: 당나라에 도움 요청 결정

Chapter 3 — 「결전」
미션 7~9: 황산벌 전투 (신라 측)
   연출: 계백 결사대와의 충돌
         하린이 계백의 눈을 보는 장면
         「저들도 각자의 이유로 싸우고 있다」

Chapter 4 — 에필로그
미션 10~12: 삼국통일 과정 시작
   연출: 통일이 끝이 아닌 시작임을 느낌
         신라 첨성대에서 강을 바라봄
```

## 가야 캠페인 — 「사라진 나라의 노래」

### 캠페인 개요

```
주인공: 니문 (창작 — 우륵의 제자, 10대 소년)
시기: 가야 최후~우륵 귀화
테마: 소멸과 계승 / 음악으로 살아남는 것

캐릭터 설정:
니문 — 우륵의 제자. 스승을 따라 신라로 감.
        가야를 잃었지만 가야금으로 기억을 지킴.
        가장 짧고 가장 슬픈 캠페인.
```

### 미션 구성

```
Chapter 1 — 「가야의 봄」(3 미션)
배움: 가야 교역 시스템 특화 플레이
연출: 가야의 아름다운 철 문화 소개

Chapter 2 — 「철이 사라진다」(3 미션)
배움: 방어전·자원 고갈 위기
연출: 신라의 압박 → 가야 분열

Chapter 3 — 「마지막 악곡」(3 미션)
미션 특수: 전투보다 탈출·피신 중심
연출: 우륵과 니문의 신라행 결정

Chapter 4 — 에필로그「낙동강을 건너며」
미션: 1개 (강 건너기)
연출: 강 건너편 = 신라
       뒤를 돌아보는 니문
       낙동강이 흐름
       「강은 가야를 기억한다」

[캠페인 엔딩]
신라에서 진흥왕에게 가야금을 연주하는 니문.
우륵이 옆에 있다.
열두 번째 악곡 「낙동강」이 흐른다.
눈물은 없다.
```

## 통합 엔딩 캠페인 — 「강은 기억한다」

### 개요

```
조건: 4개 왕국 캠페인 모두 완료 후 해금
시기: 모든 캠페인 이후 — 역사 밖의 시간
주인공: 고루·아랑·하린·니문 (4명 동시 조작)
테마: 네 강이 바다에서 만나다
```

### 미션 구성

```
미션 1 — 「강에서」
시작: 4명이 강변에서 우연히 만남
      다른 왕국 사람들, 다른 언어, 같은 강
      공통점: 모두 전쟁에서 살아남았다

미션 2 — 「기억의 강」
특수: 전투 없음
      4명이 각자의 왕국 이야기를 나눔
      (캠페인 주요 장면 회상 몽타주)

미션 3 — 「마지막 싸움」
선택지: 싸움 → 각자 왕국 편에서 싸움
         대화 → 공통점 발견

분기 결과:
A. 싸움 선택: 고루 vs 하린·아랑 vs 니문
   → 모두 상처입음. 강이 그들을 씻겨줌.
B. 대화 선택: 4명이 강변에 앉음
   → 역사상 없었던 대화. 강이 듣고 있음.

미션 4 — 「강은 기억한다」(양쪽 분기 합류)
연출:
- 강물이 각 왕국의 역사를 보여줌
- 고구려 벽화·백제 금동대향로·신라 금관·가야금
- 강이 말함: 「나는 모두를 기억한다」
- 4명이 각자의 방향으로 떠남

최종 컷씬:
현재의 강 — 한강·금강·낙동강·형산강
지금도 흐르고 있다.
메인 테마 「강은 기억한다」 풀버전.
```

### 엔딩 분기 (재플레이 가치)

```
플레이 순서에 따른 엔딩 텍스트 변화:

고구려 먼저 완주:
「고루의 강은 비류수였다. 비류수는 지금도 흐른다.」

가야 먼저 완주:
「니문의 가야금 소리는 낙동강에 남아있다.」

백제 먼저 완주:
「아랑이 기록한 글은 어딘가에 묻혀있을 것이다.」

신라 먼저 완주:
「하린이 본 별들은 아직 첨성대에서 보인다.」

4개 모두 완주 + 대화 분기 선택:
「강은 모두를 기억한다. 삼국도, 가야도, 그리고 당신도.」
```

## 게임 내 역사 자료실

```
각 미션 완료 시 해금:
- 해당 사건 역사 설명 (삼국사기 원문 + 해설)
- 역사 인물 프로필 (실존 자료 기반)
- 시대 유물 AR 뷰 (금동대향로·금관·칠지도)
- 역사 지도 변화 타임라인

교육 가치:
게임을 완주하면 삼국시대 주요 사건 학습 가능.
```
