## 스핀오프 개요

```
타이틀: 삼국(三國) 외전 — 「철의 성벽」
영문: THREE KINGDOMS Side Story — IRON RAMPART
형식: 소설 (3권 완결) + 웹툰 (시즌 1, 50화)
시대: AD 598~645 (고구려-수·당 전쟁 전기간)
주인공: 고루 (高流) + 을지문덕 + 양만춘(安市城主)
톤: 전쟁 서사 + 사제 관계 + 제국의 황혼

슬로건:
  「성벽은 무너지지 않았다. 사람이 지켰으니까.」
  "THE WALL STOOD. BECAUSE PEOPLE HELD IT."
```

## 서사 구조

### 제1부 — 「살수의 제자」(AD 598~612)

```
Chapter 1~5: 고루의 어린 시절
  배경: 고구려 평양성 변방 마을
  고루 (10세): 대동강 변 어촌 소년
  수나라 1차 침략 (598년): 마을 불타다
  → 고루의 전쟁 첫 경험: 강물이 핏빛이 되던 날

Chapter 6~10: 을지문덕과의 만남
  고루 (16세): 평양성 하급 병사로 징집
  을지문덕: 「싸우는 법을 가르쳐줄 수 있다.
              그러나 싸우지 않는 법을 먼저 배워라.」
  사제 관계 시작: 전략·외교·역사 교육
  을지문덕의 교훈: 「전쟁은 최후의 수단이다.
                     강물은 돌을 깎지만 강물이 먼저 바뀐다.」

Chapter 11~20: 살수대첩 (AD 612)
  수양제 113만 대군 침공
  을지문덕의 7전 7패 거짓 후퇴 전략
  고루: 수나라 장수 우중문(于仲文)에게 보내는 시 전달 임무
  → 을지문덕의 시를 직접 필사하는 고루
  살수 수문 개방: 고루가 수문 레버를 작동하는 이
  → 승전, 그러나 고루의 눈에 비친 수만 구의 시체
  → 「승리란 무엇인가」첫 질문

Chapter 20 마무리:
  을지문덕: 「너는 오늘 영웅이 되었다.
              그러나 영웅이 아닌 사람으로 살 수 있겠느냐?」
  고루: 대답하지 못한다. 강만 바라본다.
```

### 제2부 — 「요동의 바람」(AD 620~644)

```
Chapter 21~30: 고구려 내정 변화
  수나라 멸망 → 당나라 건국 (618년)
  고구려 내부: 연개소문(淵蓋蘇文) 쿠데타 (642년)
  고루 (30대): 을지문덕 사후 독자 전략가로 성장
  연개소문과 고루의 갈등:
    연개소문: 「강경만이 고구려를 지킨다.」
    고루: 「을지문덕 장군은 외교를 먼저 시도하셨다.」
  → 고루, 주류에서 밀려남 → 안시성 파견

Chapter 31~40: 안시성과 양만춘
  양만춘(楊萬春): 안시성 성주 — 과묵한 수성 전문가
  고루: 안시성에서 양만춘의 부관이 됨
  양만춘의 철학:
    「성벽은 돌이 아니다. 성벽 위에 선 사람이 성벽이다.」
  안시성 준비: 성벽 보강·식수 확보·민간인 대피 훈련
  당태종 30만 대군 접근 정보 → 88일 방어전 준비

Chapter 41~45: 안시성 전투 (AD 645)
  당태종 이세민 직접 지휘: 30만 대군 vs 안시성 수천 명
  88일간의 공방전:
    Day 1~20: 당군 포위 → 안시성 강한 저항
    Day 21~50: 토산(土山) 축조 — 당군 성벽보다 높은 토성 건설
    Day 51~80: 연일 공격 → 안시성 식량 부족 → 고루의 야습 전략
    Day 81~88: 토산 붕괴 → 안시성 방어 성공
  양만춘: 성벽에서 당태종에게 활 쏘기 (눈 부근 명중)
  당태종 퇴각: 안시성 방향 절 (역사 기록)
    → 양만춘에 대한 경의

Chapter 45 클라이맥스:
  당태종: 「저 성의 이름이 무엇이냐?」
  신하: 「안시성(安市城)입니다, 폐하.」
  당태종: 「잊지 않겠다.」
  양만춘: 성벽 위에서 묵묵히 서 있다.
  고루: 양만춘 옆에 서서 강물을 바라본다.
```

### 제3부 — 「황혼의 제국」(AD 645~668)

```
Chapter 46~50: 고구려의 마지막
  안시성 승전 이후: 당은 재침략 준비
  고구려 내부: 연개소문 사후 아들들 권력 투쟁
  고루의 선택:
    나당연합 형성 소식 → 고구려 멸망 예감
    고루: 「성벽은 지켰으나, 나라를 지킬 수 없었다.」

  668년 평양성 함락:
    고루는 평양성에 있지 않다 (안시성 잔류 설정)
    평양성 함락 소식: 전령이 가져옴
    → 고루, 안시성 성벽에서 대동강 방향을 바라본다
    → 을지문덕의 말이 떠오른다:
      「강은 기억한다. 나라가 사라져도 강은 흐른다.」

  에필로그:
    고루는 강변에 앉아 있다.
    손에는 을지문덕이 쓴 시의 사본.
    강물 소리만 남는다.
    끝.
```

## 캐릭터 상세

### 고루 (이 작품에서)

```
나이: 10세 (598) → 80세 (668 추정)
역할: 1인칭 시점 화자 (소설) / 주인공 (웹툰)
성장 아크:
  소년 → 살수 영웅 → 비주류 전략가 → 안시성 방어자 → 늙은 생존자

이 작품에서의 핵심 갈등:
  전쟁 영웅 vs 평화 추구자
  을지문덕의 유산 vs 연개소문의 현실
  성벽을 지키는 것 vs 나라를 지키는 것

본편 연결:
  이 스핀오프의 고루 = 본편 시즌 1~3 고루와 동일 인물
  살수대첩·안시성 경험이 본편 고루의 성격 형성 배경

  참고: goguryeo-story.md의 광개토대왕 시대 '고루(高婁)'는
  본편 고루(高流)의 선조로, 200년 전 동일 가문의 인물입니다.
```

### 을지문덕 (스승)

```
등장: 제1부 중심
역할: 고루의 스승 + 전략의 화신
성격: 겉은 평온하고 유머러스 / 속은 냉철한 계산가
핵심 대사:
  「시를 쓸 수 있는 장수가 진짜 장수다.」
  「적을 죽이는 건 쉽다. 적이 스스로 물러나게 하는 것이 어렵다.」
```

### 양만춘 (안시성주)

```
등장: 제2부~3부 중심
역할: 고루의 두 번째 스승 + 수성(守城)의 달인
성격: 극도로 과묵 / 행동으로 말하는 사람
핵심 대사:
  「말하지 마라. 서 있어라.」
  (양만춘의 대사는 전체 작품에서 30줄 미만)
```
