## 지역별 라이선스 전략

### 일본 전략

```
현지 파트너: 요시모토흥업 또는 에이벡스
독점 협력사 1곳 선정 → 서브라이선스 권한 부여
우선 카테고리: 출판(만화)·피규어·음악
주의: 한일 외교 상황에 따른 탄력적 계약 조항 삽입
```

### 중화권 전략

```
대만·홍콩·싱가포르: 통합 에이전트 1곳
중국 본토: 별도 파트너 (중국 자본 참여 구조)
고구려 영토 조항: 계약서 내 "한국 고대 왕국" 명시 의무화
```

### 동남아시아

```
태국·베트남·인도네시아 각 현지 에이전트 선정
또는 싱가포르 기반 지역 통합 에이전트 활용
우선: 출판·스트리밍·패션
```

## 팬 창작 정책 (Fan Content Policy)

### 허용 범위 (무료)

```
✅ 허용:
- 비상업적 팬픽션·팬아트
- 유튜브 비상업적 리뷰·해설
- SNS 팬 계정 운영
- 코스프레 (개인 제작·비판매)
- 교육 목적 재편집 (저작권 표시 필수)
```

### 금지 사항

```
❌ 금지:
- 판매 목적 무허가 굿즈 제작
- IP 훼손·왜곡 콘텐츠
- 역사 인물 성적 표현 콘텐츠
- 정치적 목적 사용
- 타 IP와의 무허가 크로스오버 상업화
```

### 팬 크리에이터 지원 프로그램

```
"삼국 크리에이터 파트너" 프로그램:
- 우수 팬 크리에이터 선발 (연 50명)
- 고해상도 공식 자료 제공
- 공식 SNS 채널 리그램·리포스트
- 연간 팬미팅 초청
- 우수 작품: 공식 굿즈화 제안 (수익 배분 계약 전환)
```

## 라이선스 관리 시스템

### 계약 추적

| 항목 | 기준 |
|------|------|
| 계약 데이터베이스 | 전 라이선스 계약 중앙 관리 |
| 로열티 정산 | 분기별 정산·지급 |
| 감사 권한 | 연 1회 라이선시 매출 감사 권한 보유 |
| 갱신 알림 | 만료 6개월 전 자동 알림 |
| 위반 모니터링 | 월 1회 무허가 사용 스캔 |

### 분쟁 해결

```
1차: 서면 경고 (15일 내 시정 요구)
2차: 중재 기관 조정 (대한상사중재원)
3차: 법적 소송 (국내: 서울중앙지법 / 해외: 계약서 지정 법원)
손해배상: 무허가 사용 매출의 300% 청구
```
