# 위기 관리 커뮤니케이션 — 삼국(三國) IP

**참조 문서**: `brand-identity.md`, `press-kit.md`, `pr-media-strategy.md`, `fan-community-guide.md`
**작성**: 마케팅본부 PR팀 (MKT-PR)
**적용**: 삼국(三國) IP 전 콘텐츠·이벤트·SNS 위기 상황 대응 기준

## 위기 관리 총괄 방침

```
기본 원칙:
  ① 선제 대응: 위기 인지 후 2시간 내 초기 대응
  ② 투명성: 사실 확인 전 과도한 해명 금지
  ③ 일관성: 모든 채널 동일 메시지 발신
  ④ 공감: 피해자·비판자 감정 먼저 인정
  ⑤ 빠른 시정: 실수 인정 → 즉각 수정 조치

위기 분류:
  LEVEL 1 (경미): SNS 소수 불만, 단순 오류 지적
    → 담당 팀장 대응 (24시간 내)
  LEVEL 2 (중간): 주요 미디어 보도, 팬 집단 항의
    → 본부장 보고 + PR팀 대응 (4시간 내)
  LEVEL 3 (심각): 역사 왜곡 논란, 법적 분쟁, 대규모 불매운동
    → CEO 직접 대응 + 법무팀 개입 (2시간 내)
  LEVEL 4 (재난): 사망사고, 형사 사건, 국가 간 외교 문제
    → 위기관리위원회 긴급 소집 (즉시)
```

## 위기 시나리오별 대응 매뉴얼

### 시나리오 1: 역사 왜곡 논란 (LEVEL 2~3)

```
발생 유형:
  - 드라마/애니에서 역사적 사실 오류 방영
  - 역사 자문단의 의견을 무시한 묘사 논란
  - 일본 관련 역사 민감 사항 오표현

즉시 조치 (2시간 내):
  □ 해당 콘텐츠 확인 및 문제 구간 특정
  □ ADV-HISTORY 긴급 자문 요청
  □ IP-LEGAL 법무 검토 시작
  □ 초기 입장문 준비 (팩트 확인 전: 「검토 중」)

공식 대응 (24시간 내):
  □ 역사 자문단 검토 의견 수렴
  □ 사실 오류 인정 또는 해석 차이 설명
  □ 공식 사과문 또는 해명문 발표
    채널: 공식 SNS + 보도자료 동시 배포

수정 조치:
  □ OTT 스트리밍: 수정 자막/화면 업데이트
  □ 방송 재방영: 수정본 편집 요청
  □ 역사 해설 영상 추가 제작 (해당 장면 맥락 설명)

모니터링:
  □ 수정 후 72시간 여론 추적
  □ 비판 커뮤니티 반응 확인
  □ 주요 언론사 팔로업 기사 모니터링

대응 금지 사항:
  × 「역사는 해석의 차이」로만 방어 (사실 오류 시 무효)
  × 비판자 개인 공격
  × 무대응 (침묵 = 인정으로 해석될 수 있음)
```

### 시나리오 2: 한일 역사 민감 논란 (LEVEL 3)

```
발생 유형:
  - 일본 팬/미디어: 임나일본부 관련 항의
  - 한국 팬: 일본 파트너 선정 관련 항의
  - 양측 팬덤 충돌

즉시 조치:
  □ IP-LEGAL + 글로벌사업본부(GLB-LOC) 긴급 소집
  □ 일본 현지 홍보사 연락 (현지 반응 파악)
  □ 해당 콘텐츠 국제법·역사학 검토 요청

공식 대응:
  한국어 입장문: 한국 역사 학계 기반 입장 명확히
  일본어 입장문: 일본 현지 홍보사 협력 작성 (현지 뉘앙스 조정)
  영어 입장문: 국제 미디어 대상 중립적 학술 기반

핵심 메시지:
  「삼국(三國) IP는 삼국사기·삼국유사 원전에 기반하며
   한국 역사학계의 검증을 받은 콘텐츠입니다.
   역사적 사실에 대한 다양한 학문적 논의를 존중하나,
   본 IP는 한국 역사 기록을 정본으로 삼습니다.」

에스컬레이션 기준:
  일본 정부/공식 기관 항의 → 외교부 문화관광부 보고
  한국 역사학계 공개 비판 → ADV-HISTORY 즉각 대응
```

### 시나리오 3: 배우·제작진 사생활 논란 (LEVEL 2)

```
발생 유형:
  - 출연 배우 사생활 폭로/스캔들
  - 제작진 갑질·성희롱 의혹
  - 인플루언서 파트너 논란

원칙: IP 자체 ≠ 개인 인물 연결 지양
  「배우는 배역 역할을 수행한 것이며,
   개인의 사생활은 삼국 IP와 무관합니다.」

즉시 조치:
  □ 논란 인물 관련 홍보 활동 즉시 중단
  □ SNS 해당 인물 관련 포스팅 임시 비공개
  □ 사실 확인 + 법적 검토

배우 관련 중대 사건:
  □ 소속사와 즉각 협의
  □ 드라마 재편집/대역 필요성 법무 검토
  □ 팬 커뮤니티 공지: 「콘텐츠 제작 관련 검토 중」

인플루언서 파트너 논란:
  □ 협업 즉시 중단 (계약 해지 조항 적용)
  □ 해당 캠페인 콘텐츠 삭제 요청
  □ 대체 인플루언서 신속 섭외
```

### 시나리오 4: 굿즈/상품 불량·환불 이슈 (LEVEL 1~2)

```
발생 유형:
  - 굿즈 품질 불량 (인쇄 오류, 소재 불량)
  - 배송 지연·오배송 집단 발생
  - 온라인 결제 오류·이중 청구

즉시 조치 (24시간):
  □ 불량 신고 현황 집계 (수량·유형)
  □ 제조사·물류사에 즉각 경위 확인
  □ SNS 공지: 「현황 확인 중, 불편을 드려 죄송합니다」

해결 방안 (48시간):
  □ 전량 교환 or 환불 정책 결정
  □ 특급 배송 대체 발송 (비용 무관)
  □ 추가 보상: 불량 경험자 한정 굿즈 증정

공식 사과문:
  SNS + 공식 홈페이지 동시 게시
  「불량품 발생 경위, 조치 내용, 보상 방안」 3항목 명시

재발 방지:
  □ 제조사 QC 강화 계약 조건 추가
  □ 발송 전 샘플 검수 프로세스 도입
```

### 시나리오 5: 저작권 침해 논란 (LEVEL 2~3)

```
발생 유형 A: CREATE가 피해자 (타인이 삼국 IP 무단 사용)
  □ 증거 수집 (스크린샷, URL, 날짜)
  □ IP-LEGAL 즉각 보고
  □ 내용증명 발송 (침해자에게)
  □ OTT·플랫폼에 저작권 침해 신고
  □ 필요 시 법적 조치 (가처분 신청)

발생 유형 B: CREATE가 가해자 의심 (타인 저작물 무단 사용 주장)
  □ 해당 요소 사용 경위 내부 확인
  □ 디자인팀·음악팀 원본 파일 확인
  □ ADV-ARTS 자문 (시대 고증 디자인 독창성 확인)
  □ 법적 검토: 역사 자료 기반이면 저작권 소재 없음 확인
  □ 합의 가능성 법무 검토 (소송 장기화 방지)
```

## 위기 커뮤니케이션 채널 운영

### SNS 위기 대응

```
속도 기준:
  X(트위터) 트렌딩 진입: 30분 내 초기 반응
  인스타그램 댓글 폭주: 1시간 내 대응
  유튜브 악성 댓글: 2시간 내 검토

대응 원칙:
  공식 계정만 발언 (직원 개인 계정 대응 금지)
  감정적 표현 금지 (중립·공감 어조)
  댓글 삭제: 사실 오류·인신공격에 한정 (비판 삭제 금지)

모니터링 도구:
  Brand24 / Mention 실시간 추적
  네이버 뉴스·커뮤니티 키워드 알림
  담당 PR팀 24시간 온콜 체제 (위기 LEVEL 2 이상)
```

### 미디어 대응

```
언론 문의 대응:
  단일 창구: MKT-PR 팀장 (미디어 담당)
  응답 기준: 확인된 사실만 발언
  오프더레코드: 원칙적 금지 (구두 발언도 기록 가능)

보도자료 발행 기준:
  LEVEL 1: 미발행 (SNS 대응으로 충분)
  LEVEL 2: 선택적 발행 (주요 미디어 직접 발송)
  LEVEL 3 이상: 전 미디어 배포 필수

엠바고 활용:
  중요 해명 시: 주요 언론사에 사전 브리핑 제공
  동시 보도 조율 → 편향 보도 방지
```

## 위기 예방 체계

```
사전 모니터링:
  □ 제작 단계: ADV-HISTORY 역사 고증 전수 검토
  □ 마케팅: 글로벌 문화 감수 (해외 캠페인 시)
  □ 굿즈: 출시 전 QC 체크리스트 완성
  □ 이벤트: 안전 계획 시뮬레이션

내부 교육:
  □ 전 직원 SNS 가이드라인 교육 (연 1회)
  □ 인플루언서 파트너 계약 전 브랜드 가이드 제공
  □ 위기 대응 시뮬레이션 훈련 (연 2회)

레드팀 운영:
  □ 분기 1회: 위기 시나리오 가상 훈련
  □ 참여: MKT-PR + IP-LEGAL + 각 본부장
  □ 결과: 대응 매뉴얼 업데이트
```

## 위기 후 복구 전략

```
단기 복구 (위기 해소 후 1개월):
  □ 팬 신뢰 회복 이벤트 (특별 팬 소통)
  □ 역사 정확성 강화 발표 (전문가 인터뷰 공개)
  □ 긍정 콘텐츠 집중 배포 (빛나는 콘텐츠로 덮기)

중기 복구 (1~6개월):
  □ 시정 조치 결과 공개 (투명성 회복)
  □ 커뮤니티 신뢰도 설문 (개선 측정)
  □ 위기 경험 내부 케이스스터디 작성

장기 브랜드 관리:
  □ 위기 경험을 브랜드 성숙의 계기로 전환
  □ 「삼국 IP는 역사적 책임을 다한다」이미지 구축
  □ ADV-HISTORY 자문단 공개 활동 확대
```
