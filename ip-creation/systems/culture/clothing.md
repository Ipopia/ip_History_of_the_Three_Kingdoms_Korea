## 왕국별 복식 체계

### 고구려 복식

```
기본 구조:
  저고리 (襦): 짧고 여밈이 왼쪽 (左衽 — 고구려 특징)
  바지 (袴): 통이 넓고 발목 묶음
  포 (袍): 겉옷 — 전투복 위 착용
  대 (帶): 허리띠 (가죽·직물)

색채 기준:
  왕족·귀족: 흑색·남색·진청 기조
  무장: 적갈색·흑색 (전투 가시성)
  평민: 회색·연갈색 (염색 제한)

고구려 특징:
  활동성 우선 — 기마·전투에 최적화
  깃털 장식: 모자 (절풍, 折風)에 조우 (鳥羽) 장식
    → 고분 벽화 명확한 근거
  갑옷 (甲): 찰갑 (札甲) — 쇠 조각 연결 형태
    → 삼국 중 갑옷 발달도 최고

계층별:
  대왕: 흑포 + 금 허리띠 + 금관
  장군 (고루 등급): 적갈색 포 + 찰갑 + 조우 모
  평 무관: 남색 저고리 + 회색 바지 + 철 갑옷
  평민 남성: 회백색 저고리·바지 + 가죽 허리띠

IP 주인공 고루:
  기본복: 진청 포 + 흑색 가죽 갑옷 (경장)
  전투복: 찰갑 완전 착용 + 적갈색 비단 소매
  특징: 환두대도 허리 착용 + 조우 없음 (무관 실용파)
```

### 백제 복식

```
기본 구조:
  저고리 (襦): 깃 장식 정교 (백제 공예 수준 반영)
  치마 (裳): 여성 기본 — 풍성한 플레어
  포 (袍): 귀족 기본 겉옷 (비단 자수 장식)
  관 (冠): 계층 구분 핵심 (관등에 따라 재질 차별)

색채 기준:
  왕족: 자색 (紫色) — 당시 최고급 염료
  1등급 귀족: 진홍 (緋色)
  2~3등급: 청색·녹색
  하급 관료: 황색
  평민: 백색·연회색 (흰옷의 나라 근거)

백제 특징:
  정교한 자수: 옷깃·소매·치맛단 자수 장식
  금속 장신구: 금·은·동 브로치·머리핀
  불교 문양: 연꽃·보상화 문양 직물
  일본 전래: 백제 복식 → 일본 아스카 시대 복식 영향

계층별:
  왕: 자색 대포 + 금관 + 금 허리띠
  왕족 여성: 자색 치마 + 금 발찬 (足釧)
  문서관 여성 (아랑 등급): 청색 저고리 + 남색 치마 + 은비녀
  평민 여성: 백색 저고리 + 연청색 치마

IP 주인공 아랑:
  기본복: 옅은 청색 저고리 + 남색 치마 (문서관 등급)
  특징: 소매 끝 금빛 자수 (글씨 문양) + 작은 먹통 허리 장식
  외출복: 연두색 덧포 + 은비녀 1개
  특별 장면: 연등 행사 시 연분홍 복식 (유일한 색 변화)
```

### 신라 복식

```
기본 구조:
  관복 (官服): 골품제에 따른 색·재질 엄격 규정
  화랑복: 활동적 + 상징 장식
  일상복: 저고리·바지 (남성) / 저고리·치마 (여성)

색채 기준 (골품제 연동):
  성골 (왕족): 자색·금색
  진골 (최고 귀족): 비색 (緋色, 진홍)
  6두품: 청색
  5두품: 황색
  4두품 이하: 백색·녹색

신라 특징:
  금 장신구 최다: 금관·금 귀걸이·금 팔찌·금 허리띠
    → 경주 출토 금관 실물 근거
  화랑 상징 장식: 허리 패옥 (佩玉) + 깃털 조우
  불교 영향: 불보살 문양 직물 (황룡사 법회복)

화랑 복식 (하린 등급):
  수련복: 청색 저고리 + 회색 바지 + 가죽 허리띠
  정식 복식: 청색 포 + 은 허리띠 + 화살집
  전투복: 가죽 갑옷 (경장) + 신라 금색 장식 버클
  특징: 왼쪽 어깨 화랑 표식 + 단검 우측 허리

IP 주인공 하린:
  기본복: 짙은 청색 저고리 + 회색·청 바지 (활동형)
  전투복: 가죽 경갑 + 청색 포 뒤 묶음
  특징: 머리 뒤 묶음 (전투용) + 은색 화랑 패옥
  부상 씬: 복식 일부 찢김 → 하린의 상처 표현
```

### 가야 복식

```
기본 구조:
  가야 = 소왕국 연합 → 복식 통일성 낮음
  공통: 철 문화 반영 (장신구 철제 多)
  낙동강 자연 환경 반영 (마직물·삼베 활용)

색채 기준:
  지배층: 황토색·갈색 (토착 염료)
  음악인 계층: 연회색·자연색
  평민: 무염색 마직물 (흰색·베이지)

가야 특징:
  철 장신구: 철 팔찌·허리 장식 (가야 철 문화)
  수입 비단 소량: 왜와 교역 — 일부 왕족만
  실용성 우선: 장식 최소 (멸망 왕국의 검소함)
  가야금 연주복: 긴 소매 → 연주 시 소매 걷어올림 관습

IP 주인공 니문:
  기본복: 황토색 저고리 + 연갈색 치마 (소박)
  특징: 가야금 보호용 천 어깨에 걸침
  장신구: 단 1개 — 어머니의 철 팔찌 (가야 유품)
  676 마지막 장면: 흰색 복식 (정화·순수 상징)
  연주 씬: 소매 걷어올린 팔 + 가야금 현에 집중하는 손
```

## 복식 변화 (드라마 시즌별)

```
시즌 1 (AD 600~612):
  4인 — 각 왕국 기본 복식
  고루: 20대 — 가벼운 군복 (찰갑 미착용)
  아랑: 20대 — 문서관 수습 복식 (단순)
  하린: 10대 후반 — 화랑 수련복
  니문: 20대 초반 — 가야 평민복

시즌 2 (AD 630~655):
  4인 — 지위 상승 반영 복식 변화
  고루: 30대 — 완전 찰갑 + 지휘관 적색 포
  아랑: 30대 — 정식 문서관 청색 포
  하린: 20대 후반 — 화랑 정복 + 은 허리띠
  니문: 20대 후반 — 3국 사이 여행 → 복합 복식

시즌 3 (AD 660~676):
  4인 — 전쟁의 상처·세월 반영
  고루: 50대 — 낡은 찰갑 (수리 흔적) + 회색 포
  아랑: 50대 — 검은 복식 (백제 멸망 후 상복)
  하린: 30대 후반 — 전투 흔적 가득한 가죽 갑
  니문: 30대 후반 — 흰색 복식으로 변화 (676 예고)
```
