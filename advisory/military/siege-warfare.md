# 공성전 자문 — 삼국(三國) IP

## 공성전 개요

```
삼국시대 공성전의 특성:
  성(城) = 국가의 마지막 방어선
  성 하나의 함락 = 지역 전체 통제권 이동
  특히 고구려: 산성(山城) 중심 → 지형 활용 극대화

주요 공성전 (역사 사실):
  ① 안시성 전투 (645년): 당 태종 88일 공방 → 고구려 방어 성공
  ② 백제 사비성 함락 (660년): 나당 연합 → 백제 멸망
  ③ 고구려 평양성 함락 (668년): 나당 연합 → 고구려 멸망
  ④ 백제 한성 함락 (475년): 고구려 장수왕 → 백제 남천(南遷)
```

## 삼국시대 성곽 체계

### 고구려 산성

```
특징:
  고구려 = 산성(山城) 전문 왕국
  험한 산지 지형 활용 → 적의 이동 경로 통제
  강(江)과 연계: 성 근처 강 = 수자원 + 적 진격 방해

주요 성곽:
  안시성: 요동 산지 요새 (정확한 위치 고고학 논쟁 중)
  요동성(遼東城): 요동 평야 최대 거점성
  평양성(平壤城): 대동강·보통강 합류 지점 (최후 방어선)
  백암성(白巖城): 요동 주요 방어 거점

산성 구조:
  내성(內城): 왕궁·지휘부
  외성(外城): 주민·병력 대피
  차성(遮城): 외성 바깥 추가 방어선
  봉수대(烽燧臺): 연락 시스템

안시성 방어 시스템 (창작 활용):
  석벽 + 목책(木柵) 혼합 구조
  성벽 위 투석기 배치 가능
  성문 앞 해자(垓字) 구축
  식량·물 저장 → 장기 농성 준비
```

### 백제 평지성

```
특징:
  백제 = 평지성 + 산성 혼합
  사비성(泗沘城): 금강 연안 평지 → 방어보다 문화·행정 중심
  하지만 부여나성(扶餘羅城)으로 외곽 방어

사비성 방어 취약점 (역사 사실):
  660년 나당 연합 공격 시 단시간에 함락
  이유: 내부 분열 + 방어 준비 미흡 (성충 경고 무시)
  아랑 서사 연결: 성충의 경고 = 방어 체계 구축 촉구

백제 수군 방어:
  금강 해상 방어선 중요
  백제 수군 = 백제의 특기 (왜와의 교류 루트 보호)
  660년 수군 방어 실패 → 사비성 고립
```

## 공성 무기 체계

### 공격 무기

```
① 투석기(投石機) — 포차(抛車)
  사거리: 50~200m (크기에 따라)
  발사체: 돌덩이 (10~100kg)
  당나라 포차: 수레바퀴형 대형 투석기
  고구려 대응: 성벽 두께 강화 + 역투석기

② 충차(衝車) — 성문 파괴
  형태: 통나무 + 철제 선단 + 지붕 (화살 방어)
  사용: 성문 직격 타격
  방어: 성문 내부 통나무 교차 지지 + 해자

③ 운제(雲梯) — 공성 사다리
  높이: 10~20m (성벽 높이 초과)
  당나라 운제: 수레 위 접이식 구조
  고구려 방어: 운제 말뚝 이격 설치, 끓는 기름·돌 투하

④ 토산(土山) — 안시성 전투 핵심
  당 태종 전술: 토산을 쌓아 성벽 높이 초과 → 내부 공격
  역사 사실: 안시성 전투 중 실제로 사용
  고구려 역습: 토산 완성 직전 점령 → 역으로 활용
  안시성 서사의 핵심 장면
```

### 방어 무기·전술

```
① 역투석(逆投石)
  성벽 위 투석기 → 적의 접근 저지
  안시성에서 실제 사용 (기록)

② 불화살·화공(火攻)
  성벽에 접근한 공성 장비 소각
  백제 수군의 화공 기술 (왜 교류로 발전)

③ 끓는 기름·물
  운제·충차 접근 시 투하
  성벽 방어의 기본 수단

④ 해자(垓字)
  성 주위 깊은 구덩이 + 물 채우기
  기병 접근 방해, 충차 접근 불가

⑤ 장기 농성(籠城)
  식량·물 사전 비축 → 적 보급 고갈 전략
  을지문덕 전략과 연결: 7번 물러서며 적 보급 소모
  안시성 88일: 장기 농성의 극치
```

## 주요 공성전 상세 해설

### 안시성 전투 (645년) — 창작 핵심

```
배경:
  당 태종 이세민, 고구려 원정 출발
  요동성·비사성 함락 후 안시성 공략
  안시성주(양만춘 추정): 철저한 방어 준비

전투 경과:
  4월: 당군 안시성 포위 시작
  4~5월: 정면 공격 반복 → 실패
  여름: 토산 쌓기 시작 (수십만 명 동원)
  9월: 토산 완성 직전 → 고구려군 야습·점령
  9월 말: 당 태종 철수 명령 (한파·보급 부족 복합)
  총 공방: 약 88일 (4월~9월)

결과:
  고구려 방어 성공 → 당 태종 굴욕적 철수
  야사: 양만춘 화살에 당 태종 눈 맞음 (사실 여부 불명)
  의의: 당시 세계 최강 당나라 군대 격퇴

창작 활용 포인트:
  토산 전투 → 드라마·게임 핵심 장면
  「이름 없는 영웅」양만춘의 리더십
  고루 시점: 투석기 운용·야습 참여
  고루 대사 연결: 「을지문덕 선생의 전략을 기억한다」
```

### 사비성 함락 (660년) — 비극의 상징

```
배경:
  나당 연합군: 당 13만 + 신라 5만 (합 약 18만)
  백제 방어력: 전력 분산 + 내부 혼란

전투 경과:
  660년 7월: 신라군 황산벌에서 계백 격파
  동시에: 당군 금강 하구 상륙 → 사비성 포위
  의자왕 항복: 급격한 함락 (수일 내)
  이유: 성충·흥수의 경고 무시로 방어 준비 전무

결과:
  660년 9월: 백제 공식 멸망 (의자왕 당나라 압송)
  이후: 백제 부흥 운동 (663년까지)

창작 활용 포인트:
  아랑이 먼 곳에서 불길 바라보는 장면
  성충이 미리 경고한 것 = 역사 사실
  방어할 수 있었던 기회를 놓친 비극
```

## 성곽 묘사 고증 가이드

```
드라마·소설·게임 묘사 기준:

고구려 성벽:
  ✅ 돌 + 흙 혼합 구조 (석성石城)
  ✅ 성벽 높이: 5~10m (안시성 추정)
  ✅ 여장(女牆): 성벽 위 낮은 벽 (방어용)
  ✅ 치성(雉城): 성벽 외측 돌출부 (사각지대 해소)
  ❌ 현대 드라마식 과도하게 높은 성벽 (10m 이상 과장 주의)

성문 구조:
  ✅ 옹성(甕城): 성문 앞 반원형 추가 방어 구조
  ✅ 이중 문: 외문·내문 구조
  ✅ 문루(門樓): 성문 위 지휘 루각

전투 장면 고증:
  ✅ 성벽 위 방어병 = 서서 싸우지 않음 → 여장 뒤에서 은폐
  ✅ 투석기 = 성벽 위 아닌 성내에서 운용 (안전)
  ✅ 야습 = 밤에 성문 열고 기습 (안시성 토산 역습)
  ❌ 성벽 위 칼싸움 = 실제로는 매우 드묾 (낙하 위험)
```
