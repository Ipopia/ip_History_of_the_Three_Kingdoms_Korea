## 농업 도구 체계

### 경작 도구

```
따비 (따비질):
  형태: 나무 손잡이 + 철제 날 (Y자형)
  용도: 단단한 땅 첫 번째 경작
  삼국시대: 철 보급으로 목제 → 철제 전환 중
  지역별: 고구려·백제 철제 우세 / 가야 최고품

쟁기 (犁):
  형태: 소가 끄는 V자형 쟁기
  용도: 논·밭 깊게 갈기
  동물: 소 1~2마리 (우경법 — 삼국시대 보급)
  목제 쟁기 → 철제 보습(鐵製 보습) 전환

호미:
  형태: 짧은 날 + 긴 손잡이
  용도: 잡초 제거·흙 긁기
  재질: 철제 날 + 나무 손잡이
  가야제: 낙동강 사철 → 최고 품질 인정

낫 (鎌):
  형태: 반달형 철제 날
  용도: 벼·보리 수확
  발달: 철 보급으로 돌낫 → 철낫 전환
  생산지: 가야 철정 → 각지 배급
```

### 수리 도구

```
두레박 (桔槹):
  형태: 지렛대 원리 — 물 올리기
  용도: 우물·저수지 물 농경지 공급
  위치: 논 인근 설치

물레방아 (水車):
  형태: 회전 목재 수차
  용도: 물 퍼올리기 + 곡식 도정
  동력: 흐르는 물 (수력)
  삼국 발달: 백제·신라 농경지에 보급

보(洑) 시스템:
  형태: 소규모 저수 + 물 분배 시설
  용도: 논에 물 고르게 공급
  IP 서사: 살수 댐의 소형 버전 = 농업용 보
```

## 수공업 도구

### 직조·방직 도구

```
물레 (紡車):
  형태: 회전 바퀴 + 실 감기 장치
  용도: 섬유(삼·면·견) → 실 뽑기
  동력: 손 + 발 페달

베틀 (織機):
  형태: 수평형 목제 프레임
  용도: 실 → 천 짜기
  특이: 백제 비단 베틀 — 비단 품질 동아시아 최고
  아랑 캐릭터: 자수(刺繡)는 베틀 직물 위에 작업

바늘·실:
  바늘: 뼈바늘(骨針) → 철제 바늘 전환 중
  실: 삼베실·비단실·면실
  염색: 천연 염료 (쪽·꼭두서니·황벽)

IP 캐릭터 연계:
  아랑: 백제 귀족 여성 → 자수·직조 교양 필수
  아랑의 자수 = 백제 문화 기억 매체
  「어머니의 자수 한 조각」= 핵심 소품
```

### 도자·요업 도구

```
물레 (陶車):
  형태: 회전하는 원형 판 (발 페달)
  용도: 점토 성형
  삼국: 고구려·백제·신라 각기 다른 형태

가마 (窯):
  형태: 비탈 이용 등요(登窯) 구조
  온도: 1,200~1,300°C (환원염 소성)
  고구려 특기: 개마무사 철갑 관련 도기 생산

고구려 사신도 도자:
  청자 기법 — 철분 함량 낮은 고령토
  IP 상품: 사신도 아트 패널 (ROYAL LINE) 원형
```

## 제철·금속 도구

### 가야 제철 도구

```
풀무 (鞴):
  형태: 가죽·나무 상자형 송풍 장치
  용도: 용광로에 공기 주입 → 고온 유지
  인력 풀무: 1~2인 발로 밟기
  수력 풀무: 물레방아 연동 (발전된 형태)

집게 (鐵箸):
  형태: 긴 철제 집게
  용도: 용광로에서 뜨거운 철 집기
  재질: 고열 견디는 두꺼운 철

망치·모루:
  형태: 철제 망치 + 돌·철 모루
  용도: 달군 철 두드려 형태 만들기
  단조 기법: 삼국 무기 제작 핵심

가야 제품 품질:
  낙동강 사철(砂鐵): 불순물 적고 단단함
  가야 철검: 당대 최고 품질 → 신라·왜에 수출
  철정(鐵鋌): 가야 화폐 겸 교역품
  IP 굿즈: 가야 철정 미니 레플리카 (ROYAL LINE)
```

## 조리·식품 도구

```
절구·절굿공이:
  형태: 돌 절구 + 나무 공이
  용도: 곡식 도정·약재 분쇄
  위치: 집 마당 또는 공동 절구터

시루 (甑):
  형태: 바닥 구멍 있는 토기
  용도: 쌀·콩 찌기
  삼국시대: 시루떡 = 제례·혼례 필수 음식

토기 (土器):
  형태: 손으로 빚은 민무늬·격자무늬
  용도: 저장·운반·조리
  왕국별 특성:
    고구려: 두껍고 검은 토기 (북방 기후 대응)
    백제: 얇고 정교한 회색 토기
    신라: 굽 높은 고배(高杯)형 토기
    가야: 김해식 토기 (납작한 바닥·세련된 형태)
```

## 서사·게임 활용

```
드라마 소품 목록 (ADV-ARCH 승인 필요):
  고루 캠프: 철검·철갑·죽제 식기·토기 물항아리
  아랑 거처: 베틀·자수틀·비단·동경(銅鏡)
  하린 장비: 화랑 단검·활·철제 투구·말 안장
  니문 물품: 가야금·오동나무 케이스·짚신

게임 자원 연계:
  따비·쟁기: 농지 레벨업 필요 아이템
  가야 풀무: 제철소 업그레이드 조건
  물레방아: 식량 생산 +15% 건물

시대착오 금지 도구:
  유리 용기 (삼국시대 희귀품 → 서양 교역품 한정)
  나침반 (사용 불확실)
  종이 노트 (목간·죽간이 일반적)
  쇠못 대량 사용 (귀중품 — 결구 방식이 일반)
```
