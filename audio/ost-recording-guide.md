## OST 제작 총괄 방침

```
비전: 「소리로 느끼는 삼국시대」

3원칙:
  ① 한국 전통 악기 + 서양 오케스트라 융합
  ② 왕국별 명확한 음악 정체성
  ③ 주제 멜로디 「강은 기억한다」의 일관된 변주

총 트랙 계획:
  드라마 OST: 50트랙 (시즌별 15~20트랙)
  게임 BGM: 80트랙 (전투·탐색·이벤트 분리)
  뮤지컬 넘버: 23곡 (오케스트라 편곡)
  콘서트 편곡: 30트랙
  합계: 183트랙+

레코딩 예산:
  시즌 1 OST: 8억원
  시즌 2~3 OST: 각 6억원
  게임 BGM: 5억원
  합계: 25억원
```

## 왕국별 음악 DNA

### 고구려 테마

```
악기 구성:
  주선율: 대금(大笒) — 낮고 굵은 음색
  부선율: 첼로·콘트라베이스 앙상블
  타악: 장구 (북방 기마 리듬) + 팀파니
  효과: 호른 (장엄함)

음악 특성:
  조성: 단조 (D minor 계열)
  템포: 느리고 장엄함 (전투 시 빠르게)
  특징: 5음계 기반 (동양적) + 서양 화성 보완

시그니처 모티프:
  「고루 테마」: 대금 4음 하강 모티프 (솔-파-미-레)
  「살수 모티프」: 저현 반복 + 수면 파문 효과
  「안시성 테마」: 혼합 박자 (7/8) + 불규칙 리듬

레코딩 메모:
  대금 솔리스트: 한국 최고 대금 연주자 필수
  현악: 50인 풀 스트링
  녹음 공간: 잔향 1.8초 이상 (장엄감)
```

### 백제 테마

```
악기 구성:
  주선율: 거문고(玄琴) — 깊고 따뜻한 현악
  부선율: 바이올린 소편성 (섬세함)
  타악: 소고 + 핸드팬 (이국적 교역 분위기)
  색채: 플루트 (백제 문화 우아함)

음악 특성:
  조성: 장조 계열 (따뜻함) + 단조 전환 (비극성)
  템포: 중간, 흐르는 리듬 (금강 흐름)
  특징: 아름다운 멜로디 라인 (문화 강조)

시그니처 모티프:
  「아랑 테마」: 거문고 3음 상행 + 피아노 응답
  「사비성 테마」: 현악 아르페지오 (강물 흐름)
  「백제 멸망 모티프」: 아랑 테마 → 단조 전환 (비극적 변형)

레코딩 메모:
  거문고 솔리스트: 정악 전문 연주자 우선
  현악: 30인 (소편성 — 섬세함 우선)
```

### 신라 테마

```
악기 구성:
  주선율: 가야금(伽耶琴) + 하프 유니즌
  부선율: 오보에 (황금빛 음색)
  타악: 편종(編鐘) + 글로켄슈필 (황금 울림)
  장엄감: 오르간 (황룡사 느낌)

음악 특성:
  조성: 밝은 장조 (황금빛)
  특징: 빛나는 음색, 황금 질감의 음향

시그니처 모티프:
  「하린 테마」: 가야금 + 하프 상행 스케일
  「선덕여왕 테마」: 오보에 솔로 → 오케스트라 확장
  「화랑 모티프」: 마칭 리듬 + 단호한 금관

레코딩 메모:
  편종: 국립국악원 악기 대여 협의
  오르간: 스튜디오 파이프오르간 또는 샘플 (예산 고려)
```

### 가야 테마

```
악기 구성:
  주선율: 가야금(伽耶琴) 독주 — 12현 전통 연주
  부선율: 비올라 (중간음역, 슬픔)
  타악: 최소화 (소멸 이미지)
  효과: 침묵·페이드 (가야 소멸 표현)

음악 특성:
  조성: 단조 → 무조 경향 (해체 이미지)
  특징: 12현 가야금 표현 한계까지 활용
  감정: 그리움·상실·기억

시그니처 모티프:
  「니문 테마」: 가야금 단독 5음 (솔-라-시-레-미)
  「가야 소멸 모티프」: 테마 → 점점 약해짐 → 침묵
  「기억의 강 (피날레)」: 가야금 테마 + 4왕국 테마 종합

레코딩 특이사항:
  니문 테마 = 가야금 솔리스트 단독 녹음 (반드시)
  마이크: 가야금 근접 + 공간 마이크 (자연스러운 울림)
```

## 주제곡 「강은 기억한다」

```
포지션: 메인 타이틀 + 엔딩 테마

악기 편성 (풀 버전):
  가야금 + 대금 + 거문고 (3 주요 국악기)
  풀 오케스트라 (현악 50 + 관악 30 + 타악 10)
  보컬: 소프라노 솔리스트 (여성, 맑고 투명한 음색)

구조:
  인트로 (0:00~0:30): 가야금 솔로 (8마디)
  A섹션 (0:30~1:30): 테마 첫 제시 (소편성)
  B섹션 (1:30~2:30): 발전 (4왕국 모티프 연계)
  클라이맥스 (2:30~3:30): 풀 오케스트라 (최대 다이나믹)
  코다 (3:30~4:00): 가야금 솔로 회귀 + 페이드 아웃

가사 (한국어 원문):
  「강은 기억한다
   나라가 사라져도
   이름이 흩어져도
   강은 기억한다

   살수에 흐르던 피
   살수에 잠긴 칼날
   강은 모두 기억한다
   우리가 여기 있었다는 것을」

버전 목록:
  풀 버전: 4분 (드라마 엔딩)
  타이틀 버전: 1분 30초 (오프닝 타이틀)
  피아노 버전: 3분 (OST 앨범 수록)
  영어 버전: 4분 (글로벌 앨범)
  가야금 버전: 3분 30초 (니문 솔로 이미지)
```

## 레코딩 세션 계획

### 세션 1 — 국악기 레코딩

```
장소: 국립국악원 녹음 스튜디오 (또는 전문 스튜디오)
기간: 3일

Day 1: 가야금 솔로 트랙 전체
  - 니문 테마, 기억의 강, 강은 기억한다 가야금 파트
  - 솔리스트: 사전 오디션 2~3인 → 최종 선정

Day 2: 대금·거문고·편종
  - 고구려 테마, 백제 테마 국악기 파트
  - 앙상블 트랙

Day 3: 국악 타악기·소고·장구
  - 전투 씬 타악 트랙 전체
  - 의례 씬 제천 타악
```

### 세션 2 — 오케스트라 레코딩

```
장소: 서울 주요 레코딩 스튜디오 (예: 서울스튜디오)
기간: 5일
규모: 90인조 풀 오케스트라

Day 1~2: 현악 섹션 (50인)
  - 주요 테마 현악 파트 전체
  - 살수대첩·안시성·황산벌 전투 테마

Day 3: 관악 섹션 (30인)
  - 금관·목관 파트
  - 시즌별 오프닝 팡파르

Day 4: 타악 섹션 (10인) + 합주
  - 팀파니·심벌즈·퍼커션
  - 전체 합주 밸런스 조율

Day 5: 보컬 솔리스트
  - 「강은 기억한다」보컬 레코딩
  - 3~4회 테이크 → 픽 셀렉션
```

### 세션 3 — 믹싱·마스터링

```
장소: 돌비 아트모스 지원 믹싱 스튜디오
기간: 7일

믹싱 기준:
  드라마: 스테레오 + 5.1 서라운드
  게임: 스테레오 + 공간음향 (모바일 최적화)
  OST 앨범: 스테레오 마스터

마스터링:
  드라마 방송 규격: EBU R128 (-23 LUFS)
  스트리밍 규격: -14 LUFS (Spotify/Apple Music)
  콘서트 오디오: -10 LUFS (라이브 감)
```

## 납품 기준

```
파일 포맷:
  마스터: WAV 48kHz/24bit
  드라마 납품: AAC 320kbps
  스트리밍: FLAC 또는 MP3 320kbps
  게임: OGG (루프 포인트 설정)

메타데이터:
  곡명 (한/영)
  작곡가·편곡가·연주자
  저작권: 삼국(三國) IP / SND-COMPOSE

납품 일정:
  시즌 1 OST: 드라마 방영 D-30 완납
  게임 BGM: 게임 출시 D-60 완납
  OST 앨범: 드라마 방영 후 D+14 (디지털 발매)
```
