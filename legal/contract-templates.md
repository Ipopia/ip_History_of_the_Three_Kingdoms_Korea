# 계약서 기준 템플릿 — 삼국(三國) IP

**참조 문서**: `ip-legal-framework.md`, `licensing-framework.md`, `licensing-matrix.md`
**작성**: IP&법무본부 (IP-LEGAL)
**적용**: 삼국(三國) IP 관련 모든 계약의 기준 조항 및 체크리스트

---

## 계약 총괄 방침

```
기본 원칙:
  ① 모든 계약: IP-LEGAL 최종 검토·서명 필수
  ② 분쟁 준거법: 대한민국 법률 (국내) / 국제계약 별도 명시
  ③ 계약 언어: 한국어 정본 (해외: 해당 언어 병기, 해석 충돌 시 한국어 우선)
  ④ 보관: 모든 서명 계약서 IP-LEGAL 보관 (전자·원본)

계약 분류:
  TYPE A: 제작 파트너 계약 (드라마·게임·애니·음악)
  TYPE B: 라이선싱 계약 (상품화·해외 유통·플랫폼)
  TYPE C: 인재·용역 계약 (성우·작가·스태프)
  TYPE D: 자문 계약 (역사·언어·고고학 자문단)
  TYPE E: 이벤트·공연 계약 (뮤지컬·콘서트·팬페스트)
```

---

## TYPE A — 제작 파트너 계약

### 핵심 조항 체크리스트

```
필수 포함 조항:
  □ 저작권 귀속: 삼국(三國) IP 전체 저작권 = CREATE 소유
    파트너는 제작 참여권만 취득, 저작물 소유권 없음
  □ 제작비 분담: 단계별 지급 일정 명시
    (착수금 30% → 중간 납품 40% → 최종 납품 30%)
  □ 역사 정확성 의무: 파트너는 ADV-HISTORY 지침 준수 의무
  □ 감수권: CREATE = 최종 콘텐츠 수정·거절권 보유
  □ 기밀 유지: 계약 기간 + 종료 후 3년

역사 고증 특별 조항:
  「파트너는 제작 과정에서 역사적 사실을 왜곡하거나
   정치적으로 민감한 해석을 포함할 경우 즉시 CREATE의
   사전 승인을 받아야 하며, 승인 없는 변경은 계약 위반으로 처리한다.」

일본 공동 제작 특별 조항:
  임나일본부(任那日本府) 관련 해석 금지 명문화
  역사 왜곡 시 계약 즉시 해지 + 손해배상 청구 가능
  한국 측 감수권 계약서 명시

콘텐츠 납품 기준:
  최종 납품 전 QA 체크리스트 통과 필수
  QA 거절 3회 → 계약 해지 권리 발생
```

## TYPE B — 라이선싱 계약

### 국내 라이선싱 기준

```
라이선스 범위 명시 의무:
  □ 매체 (드라마·게임·굿즈·웹툰 중 특정)
  □ 지역 (국내 한정 / 해외 포함)
  □ 기간 (시작일~종료일 명시)
  □ 독점 여부 (독점 = 추가 프리미엄 적용)
  □ 2차 저작물 허용 범위

로열티 기준:
  굿즈/상품화: 판매가의 8~15%
  게임: 수익의 5~10%
  출판: 정가의 5~8%
  공연: 티켓 수익의 3~7%

선급금 (Advance):
  대형 파트너: 계약금 = 예상 로열티 6개월치
  소형 파트너: 계약금 = 예상 로열티 3개월치
  선급금 = 추후 로열티 정산 시 공제

정산 주기:
  반기 정산 원칙 (1월·7월)
  회계 감사권: CREATE 보유 (연 1회)
```

### 해외 라이선싱 특별 조항

```
일본 시장:
  준거법: 일본 저작권법 + 대한민국법 이중 적용
  임나일본부 해석 금지 조항 명문화 (MANDATORY)
  번역 권한: CREATE 한국어 원본 = 정본

중국 시장:
  현지 파트너 필수 (외자 제한 업종)
  정치적 민감 콘텐츠: 현지 법무 사전 검토
  수익 송금: 외환 규정 준수 조항

미국/유럽:
  준거법: GDPR 준수 (유럽) / 캘리포니아 법 (미국 선택 시)
  저작권: 베른 협약 기준

글로벌 공통:
  역사 고증 국제 기준 준수 조항
  현지 문화 모욕 금지 조항
  분쟁 해결: ICC 국제중재 (또는 대한상사중재원)
```

## TYPE C — 인재·용역 계약

### 작가·시나리오 계약

```
저작권 귀속:
  「본 계약에 따라 작성된 모든 시나리오·대본·소설은
   최종 납품과 함께 CREATE에 저작재산권이 이전된다.
   단, 작가의 성명표시권은 원저작자에게 귀속된다.」

수정 요청권:
  CREATE = 횟수 제한 없이 수정 요청 가능
  작가 = 요청 방향에 대한 이의 제기 권리 (최종 결정은 CREATE)

원고 납품 일정:
  지연 페널티: 납품일 초과 1일당 계약금의 0.1%
  최대 페널티: 계약금의 10%

이중 계약 금지:
  계약 기간 중 경쟁 IP 유사 프로젝트 참여 금지
  삼국시대·고대 한국 역사 관련 IP 한정
```

### 성우·음악 계약

```
성우 계약 특이사항:
  □ 세션 녹음비 + 부가 사용료 분리 계약
  □ 영어·일어 더빙: 별도 추가 계약 필수
  □ AI 음성 학습 사용 금지: 명문화 (동의 시 추가 계약)
  □ 퍼블리시티권: 캐릭터 홍보 활용 동의 범위 명시

음악 계약 특이사항:
  □ 작곡·편곡·연주 권리 분리 관리
  □ ISRC 코드 등록: CREATE + 작곡가 공동 명의
  □ 실연자 인접권: 연주자 별도 계약
  □ 인세: 스트리밍 수익의 작곡가 배분율 명시
```

## TYPE D — 자문 계약

```
자문단 계약 핵심:
  □ 자문 의견 = 참고 자료 (최종 결정 CREATE)
  □ 이견 발생 시 서면 의견 제출 의무
  □ 기밀 유지: 계약 기간 + 종료 후 5년
  □ 크레딧: 자문단 이름 콘텐츠 엔딩 크레딧 기재 의무

역사 자문 특별 조항:
  「자문위원은 학문적 양심에 따라 의견을 제시하며,
   CREATE가 자문 의견을 채택하지 않더라도 자문위원은
   대외적으로 해당 IP의 역사적 정확성을 부정하는
   발언을 삼가야 한다.」

자문료:
  회당 자문: 50만~200만원 (분야·경력 기준)
  연간 고문 계약: 월 100만~500만원
  크레딧 기재 포함 가격
```

## TYPE E — 이벤트·공연 계약

```
뮤지컬·콘서트 계약:
  □ 공연권 범위: 국내 / 해외 / 영상 촬영 판권 분리
  □ 티켓 수익 배분: CREATE 로열티 + 제작사 배분율
  □ 미니멈 개런티: 예매율 60% 미만 시 제작사 추가 지원 조건
  □ 굿즈 수익: 현장 판매 굿즈 = CREATE 직접 운영

팬이벤트 계약:
  □ 참가자 개인정보: PIPA(개인정보보호법) 준수
  □ 이벤트 영상: CREATE 저작물 → 외부 배포 금지
  □ 안전사고: 행사 보험 필수 (참가자 상해 보험)

해외 이벤트 추가:
  □ 비자·입국 비용: 계약서 부담 주체 명시
  □ 현지 규제 준수 의무: 파트너
  □ 문화적 민감 사항: 현지 법무 사전 검토 의무
```

## 계약 위반 및 분쟁 처리

```
계약 위반 유형별 조치:
  경미한 위반: 시정 요청 → 30일 내 미시정 시 계약 해지
  중대한 위반: 즉시 해지 + 손해배상 청구
    (역사 왜곡, 기밀 누설, 이중 계약, 불법 저작권 사용)

손해배상:
  실손해 + 영업손실 청구 가능
  위약벌: 계약금의 20~100% (위반 유형별)

분쟁 해결 단계:
  1단계: 당사자 협의 (30일)
  2단계: 조정 (대한상사중재원)
  3단계: 중재/소송 (서울중앙지방법원 전속 관할)

긴급 가처분:
  역사 왜곡 콘텐츠 배포 시 → 즉각 배포 금지 가처분 신청 권리
```

## 계약 승인 프로세스

```
계약 체결 전 필수 검토:
  □ IP-LEGAL 법무 검토 (7영업일)
  □ 해외 계약: 현지 법무 검토 (추가 14영업일)
  □ 금액 기준 승인:
    1억원 미만: 본부장 결재
    1억원~10억원: CEO 결재
    10억원 이상: 이사회 보고 후 결재
  □ 역사 민감 조항: ADV-HISTORY 검토 의견 첨부

계약 기록 관리:
  계약 등록: IP-LEGAL 계약 데이터베이스
  갱신 알림: 만료 90일 전 자동 알림
  보관 기간: 계약 종료 후 10년
```
