## 개요

```
삼국시대 재정 구조:
  국가 수입원:
    ① 조(租): 토지세 — 쌀·조 등 곡물 납부
    ② 조(調): 공물세 — 특산품·직물 납부
    ③ 용(庸): 노역세 — 성 수축·도로 공사 노동력
    ④ 조세 외 수입: 전쟁 전리품, 교역 관세

왕권 강화와 조세:
  조세 = 왕국 운영의 물질적 기반
  징세 강화 = 왕권 강화 (귀족 저항)
  과도한 조세 = 민심 이반 → 반란 빌미

삼국시대 조세의 특징:
  중앙집권 미완성 → 귀족의 사적 징세 병존
  골품제(신라)·관등제(고구려)·좌평제(백제) 따라 차등 납부
```

## 고구려 조세 체계

```
토지세(租):
  단위: 석(石) — 1석 = 약 180리터
  세율: 수확량의 1/10 ~ 1/5
  납부자: 농민 (귀족 면세 또는 감세)
  방식: 현물납 (조·수수·보리 등)

공납(調):
  왕국별 특산품 수취:
    평양성 인근: 고구려 철기·마포(麻布)
    북방 변경: 모피·사냥감
    해안 지역: 어물·소금
  귀족 공납: 철갑·무기·말 (군역 대체 가능)

부역(庸):
  연간 60일 노역 의무 (20~60세 남성)
  성 수축 우선 (평양성·요동성 건설 노역 막대)
  전시: 군역으로 전환 (부역 → 군역)
  대체: 현물 납부로 면제 가능 (부유한 농민)

군역 체계:
  귀족: 개마무사 등 중기병 (자비 장비)
  평민: 보병·수비병
  군량: 자급자족 원칙 + 국가 비축분 지원
```

## 백제 조세 체계

```
16관등 조세 차등:
  좌평(1품): 세금 납부 대신 국가 공무 수행
  달솔~나솔(2~6품): 감세 혜택
  평민 이하: 풀 납부

토지세(租):
  세율: 수확량의 1/5
  금강·만경강 유역 수전: 쌀 위주 납부
  서해 해안: 어물·소금 대체 납부 허용

공납(調):
  백제 특산 공납:
    사비성 인근: 도자기·금속 공예품
    서해 염전: 소금 (전국 유통 재원)
    일본 교역 물품: 비단·불교 경전 (역수출)

부역(庸):
  연간 45일 (고구려보다 적음)
  사비성 건설 당시 대규모 부역 동원 (538년 천도)
  황산벌 전투 전: 방어 시설 부역 급증

특이점:
  백제 왕실: 일본 교역 수익 = 왕실 독점 재원
  교역세: 서해 항구 입출항 물품의 1/20 징수
```

## 신라 조세 체계

```
골품제 조세 연계:
  성골·진골: 세금 면제 + 녹읍(祿邑) 수익
  6두품: 감세 (50%)
  5두품 이하: 풀 납부
  평민·천민: 부역·군역 우선 동원

토지세(租):
  세율: 수확량의 1/10 (가장 낮음 — 민심 획득 정책)
  경주 분지: 쌀 납부
  산간 지방: 삼(麻)·콩 납부

공납(調):
  신라 특산 공납:
    경주 인근: 비단·금속 공예
    동해안: 어물·미역·전복

부역(庸):
  연간 30일 (3국 중 가장 적음)
  황룡사 건설 (553~566년): 대규모 부역 동원
  화랑 제도: 귀족 자제의 군역 대체

삼국 통일 후 변화:
  고구려·백제 점령지 편입 → 조세 체계 재편
  통일신라: 중앙집권 강화 → 녹읍 폐지·관료제 도입
```

## 가야 조세 체계

```
소국 연맹 특성:
  통합 조세 체계 부재 → 각 소국 독립 운영
  연맹 내 공동 방위: 각 소국 군사력 분담

금관가야 체계:
  철 생산·유통 = 주요 재원
  철 수출 관세: 왜·백제·신라 수출 시 1/15 징수
  낙동강 수로 통행세: 내륙 교역의 관문

가야 멸망 후:
  562년 → 신라 조세 체계 편입
  가야 철기 생산 기반 → 신라 국유화
```

## 조세와 서사 연계

```
드라마 활용 포인트:

EP03: 수나라 침공 전야
  농민들의 세금 납부 장면 → 국가 재정 준비
  부역 동원 → 성 수축 → 살수대첩 준비

EP07: 청야전술
  비축 식량 소각 → 조세로 모은 국가 재원 파괴
  을지문덕: 「나라가 살려면 이 모든 것을 불태워야 한다」

시즌 2: 연개소문 집권
  과도한 부역 강제 → 민심 이반 묘사

시즌 3: 백제 멸망 전야
  의자왕의 사치 = 과도한 공납 징수 결과
  아랑의 눈으로 본 사비성 민중의 고통

창작 주의사항:
  조세 = 악으로만 묘사 금지
  국가 유지의 필요 요소로 복잡하게 표현
  지배층 착취 ↔ 방어 인프라 유지의 딜레마
```
