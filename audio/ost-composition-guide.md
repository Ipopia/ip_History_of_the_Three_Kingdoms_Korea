# OST 작곡 가이드 — 삼국(三國) IP

**참조 문서**: `sound-design-guide.md`, `art-bible.md`, `character-profiles/main-characters.md`
**작성**: 사운드본부 음악팀 (AUDIO-MUSIC)
**적용**: 드라마·애니·게임·뮤지컬 전 미디어 OST 작곡 기준

---

## OST 전략 개요

```
삼국(三國) OST 목표:
「음악만으로도 왕국이 느껴지는 사운드」

OST 3원칙:
1. 역사적 악기 우선 (가야금·거문고·대금·단소·장고)
2. 왕국별 음악 정체성 차별화 (4왕국 즉각 식별)
3. 현대 오케스트라 + 국악 앙상블 결합

OST 라인업:
① 드라마 OST: 총 20곡 (시즌 1 기준)
② 게임 OST: 총 40곡 (전투·평화·이벤트 분류)
③ 애니 OST: 총 15곡 (OP·ED 포함)
④ 뮤지컬 OST: 총 22곡 (뮤지컬 제작 계획 연동)
⑤ 스탠드얼론 앨범: 「강은 기억한다」메인 앨범
```

## 메인 테마 — 「강은 기억한다」

```
제목: 강은 기억한다 / THE RIVER REMEMBERS
포맷: 메인 테마 + 버전 6종

메인 테마 구조:
도입 (0:00~0:30):
  - 가야금 단음 시작 (니문 연상)
  - 대동강 물소리 레이어 (자연음)
  - 저현악 점진 도입

전개 (0:30~1:30):
  - 4왕국 테마 순서 도입 (각 8마디)
  - 고구려 → 백제 → 신라 → 가야 순
  - 거문고·가야금·대금·단소 각 왕국 테마 악기

클라이맥스 (1:30~2:30):
  - 4 테마 동시 카운터포인트
  - 오케스트라 전체 합류
  - 장고+타악 폭발

에딩 (2:30~3:00):
  - 가야금 단음으로 귀환
  - 강물 소리 페이드아웃

버전 목록:
V1. 드라마 오프닝 풀 버전 (3분)
V2. 드라마 엔딩 감성 버전 (3분 30초)
V3. 게임 타이틀 버전 (2분 루프)
V4. 뮤지컬 피날레 버전 (4분)
V5. 영어 보컬 버전 (글로벌 앨범)
V6. 가야금 솔로 버전 (니문 테마 특별판)

조성: D단조 (주) — 장엄하되 따뜻한 느낌
BPM: 72 (기본) — 강물 흐름처럼 안정적
```

## 왕국별 테마

### 고구려 테마 — 「북방의 기억」

```
제목: 북방의 기억 / Memory of the North
주요 악기: 거문고 (주), 장고·북 (리듬), 금관악기 (부)

음악 특성:
조성: B♭단조 (강하고 어두운)
리듬: 4/4박자 — 행진 리듬 기반
템포: 84 BPM (힘차되 묵직)

선율 특징:
- 거문고의 술대 타주 — 강하고 직선적
- 북 두드리기 리듬 — 기마 발굽 연상
- 금관악기 팡파레 — 광개토대왕 등장 시

고루 개인 테마 (고구려 테마 변주):
- 거문고 단음 시작 → 저현악 도입
- 속전속결 없는 긴 호흡 (오래 버티는 장군)

등장 씬:
살수대첩 전투: 빠른 BPM (120) + 타악 폭발
고루 독백: 느린 BPM (54) + 거문고 솔로
```

### 백제 테마 — 「금빛 강가」

```
제목: 금빛 강가 / Golden Riverside
주요 악기: 가야금 (부드러운 음색), 단소·피리, 현악

음악 특성:
조성: F장조 (밝고 우아한)
리듬: 3/4박자 — 흐르는 왈츠 느낌
템포: 66 BPM (느리고 우아)

선율 특징:
- 가야금 아르페지오 — 강물 흐름
- 피리 멜로디 — 백제 궁중 분위기
- 현악 스트링 — 비단 옷감 연상

아랑 개인 테마:
- 피리 단선율 시작 → 복잡한 화음으로 전개
- 문서 읽는 장면: 조용한 단선율
- 예감 장면: 불협화음 삽입 (복선)

등장 씬:
사비성 궁중: 가야금+피리 앙상블
아랑 긴장 씬: 낮은 현악 불협화음
낙화암 (시즌 3): 피리 솔로 + 강물 소리
```

### 신라 테마 — 「황금의 빛」

```
제목: 황금의 빛 / Golden Light
주요 악기: 대금 (맑은 고음), 현악, 금속 타악기

음악 특성:
조성: D장조 (맑고 밝은)
리듬: 6/8박자 — 기마 질주 리듬
템포: 96 BPM (활기차고 빠름)

선율 특징:
- 대금 높은 음역 — 서라벌 하늘
- 금속 타악기 (탐탐) — 황금 장신구 연상
- 빠른 현악 패시지 — 화랑 속전속결

하린 개인 테마:
- 대금 단독 → 점진적 오케스트라
- 싸움 전: BPM 가속 (72→120)
- 선덕여왕 씬: 부드러운 장조 변주

선덕여왕 개인 테마:
- 현악 합창 (코랄) — 왕의 품위
- 예언 씬: 반음 하강 선율 (신비롭고 서늘)

등장 씬:
서라벌 전경: 대금+현악 앙상블
화랑 훈련: 빠른 타악+관악
선덕여왕 예언: 현악 코랄+단소
```

### 가야 테마 — 「강의 노래」

```
제목: 강의 노래 / Song of the River
주요 악기: 가야금 (독주), 해금, 자연음 레이어

음악 특성:
조성: G장조 → A단조 (밝음에서 슬픔으로)
리듬: 자유 박자 (無장단) → 느린 4/4
템포: 자유 → 60 BPM

선율 특징:
- 가야금 농현(弄絃) — 가야 고유 음색
- 자연음 레이어: 낙동강 물소리 + 새소리
- 해금 비성(悲聲) — 가야 상실감

니문 개인 테마:
- 가야금 단음 시작 (매우 조용)
- 점진적 선율 전개 (기억이 쌓이는 구조)
- 12번째 악곡 씬: 가야금 솔로 4분 풀 연주

12번째 악곡 구성:
A섹션: 낙동강 물소리 기반 가야금 선율
B섹션: 대동강·백마강·형산강 변주
클라이맥스: 4강 선율 동시 (카운터포인트)
코다: 가야금 단음으로 귀환

등장 씬:
강변 연습: 가야금 솔로 + 물소리
궁중 공연: 가야금+해금 앙상블
망국지가: 가야금 독주 + 침묵
```

## 드라마 OST 트랙 리스트 (시즌 1)

```
보컬 트랙 (5곡):
01. 강은 기억한다 (메인 테마, 보컬)
02. 살수의 서약 (고루 테마, 남성 솔로)
03. 봉황의 눈물 (아랑 테마, 여성 솔로)
04. 화랑의 아침 (하린 테마, 혼성 듀엣)
05. 망국지가 (니문 테마, 가야금+보컬)

오케스트라 트랙 (10곡):
06. 북방의 기억 (고구려 테마 풀 버전)
07. 금빛 강가 (백제 테마 풀 버전)
08. 황금의 빛 (신라 테마 풀 버전)
09. 강의 노래 (가야 테마 풀 버전)
10. 살수 (전투 테마)
11. 을지문덕 (역사 인물 테마)
12. 안시성의 밤 (농성 테마)
13. 선덕여왕의 예언 (신비 테마)
14. 연개소문 (정치 스릴러 테마)
15. 나당이 온다 (위기 테마)

국악 솔로 트랙 (5곡):
16. 가야금 독주 — 12번째 악곡
17. 거문고 독주 — 고루의 강
18. 대금 독주 — 서라벌의 하늘
19. 단소 독주 — 사비성의 밤
20. 장고 독주 — 살수대첩

총 재생 시간: 약 70분
포맷: 디지털 음원 + 실물 CD (한정판)
```

## 게임 OST 시스템

```
상태별 음악 (State-Based Music):
평화 상태 (왕국별):
  고구려: 「북방의 기억」배경 루프 (2분)
  백제: 「금빛 강가」배경 루프 (2분 30초)
  신라: 「황금의 빛」배경 루프 (2분)
  가야: 「강의 노래」배경 루프 (3분)

전투 상태:
  전투 시작: 북소리+전투 테마 크로스페이드 (3초)
  전투 중: 다이나믹 BGM (긴장도 레이어 추가)
  전투 승리: 왕국별 승리 팡파레 (8초)
  전투 패배: 슬로우 페이드 + 비가 (5초)

특수 이벤트:
살수대첩 이벤트: 「살수」오케스트라 버전
안시성 이벤트: 「안시성의 밤」긴장 버전
LEGENDARY 유닛 등장: 전용 스팅 5초
광개토대왕: 금관악기 팡파레
선덕여왕: 현악 코랄
계백: 장엄한 비가 (패배의 영웅)

기술 사양:
엔진: FMOD Studio (Unity)
동적 믹싱: 전투 상황별 레이어 자동 추가
모바일: 50MB 이내 압축 최적화
```

## 스탠드얼론 앨범

```
앨범 제목: 「강은 기억한다 — 삼국(三國) OST」
트랙 수: 20곡
버전: 한국어·영어·일본어 보컬 각 1장

특별판 구성:
디럭스 에디션:
  - 실물 CD 2장 (드라마 OST + 국악 솔로)
  - 아트북 (30p — 악보·작곡 노트)
  - 가야금 줄 1세트 (굿즈)
  - 포스터

디지털 전용판:
  - 스트리밍 (멜론·스포티파이·애플뮤직)
  - 고해상도 FLAC 다운로드

K-팝 콜라보 버전:
  - 「강은 기억한다」팝 버전 (K-아티스트 협업)
  - 「망국지가」커버 (국악+R&B 크로스오버)
```
