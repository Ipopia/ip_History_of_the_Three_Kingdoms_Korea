```
ADV-ARTS 전통음악 자문 담당 범위:
  1. 삼국시대 음악 역사 고증 (악기·음계·연주 방식)
  2. OST·사운드디자인 전통음악 요소 검토
  3. 뮤지컬·공연 전통음악 편곡 자문
  4. 게임 BGM 전통음악 참고 자문
  5. 웹툰·드라마 음악 장면 고증 자문

자문 배제 범위:
  현대적 재해석·창작 OST 구체적 작곡 (SND-MUSIC 담당)
  → 자문은 역사 근거 제공, 창작은 SND-MUSIC
```

## 삼국시대 음악 역사 기록

### 문헌 근거

```
삼국사기 (三國史記) 악지(樂志):
  「가야금은 가야국 가실왕이 당나라 악기를 보고 만들었다」
  「우륵이 가야금 12곡을 작곡하여 신라에 전함」
  → 가야금 기원 공식 기록 (AD 6세기 중반)

고구려 음악 기록:
  고구려 고분 벽화 (안악3호분·무용총) → 악기 연주 그림
  현악기·관악기·타악기 합주 장면 다수 확인
  수나라·당나라 문헌에 「고구려 음악」별도 항목 존재

백제 음악 기록:
  일본서기: 백제 음악인·악기 일본 전래 기록
  백제 음악 → 일본 아악(雅樂) 원류 중 하나
  미마지(味摩之): 백제인, 612년 일본에 기악(伎樂) 전수

신라 향가(鄕歌):
  처용가·헌화가 등 향가 다수 존재 (신라 고유 음악)
  「도솔가」(월명사, AD 760): 노래로 재앙 물리침
  향가 = 가사 있는 노래 형식 (선율 추정 어려움)
```

## 왕국별 음악 고증

### 고구려 음악

```
주요 악기 (고분 벽화 근거):
  공후 (箜篌): 세로형 하프 (고구려·중앙아시아 교류)
  횡적 (橫笛): 가로 부는 피리
  거문고 (玄琴): 「왕산악이 중국 칠현금 변형하여 제작」
    → 삼국사기 기록 (AD 고구려 악기)
  북 (鼓): 대형 타악기 (전투·의식용)
  징·요고: 의식·신호용

음악 특성 (추정):
  웅장·장엄 — 군사 국가 특성 반영
  타악 강조 — 전투 신호·사기 고양
  중앙아시아 영향 — 실크로드 교역 경유
  5음계 기반 (궁·상·각·치·우)

IP 활용 기준:
  거문고 + 북 조합 = 고구려 음악 시그니처
  ✓ 거문고: 역사 문헌 근거 있음
  ✓ 전투 북: 고분 벽화 근거 있음
  △ 공후: 고구려 사용 가능성 있으나 고증 보완 필요
```

### 백제 음악

```
주요 악기 (문헌 근거):
  대금 (大笒): 대나무 대형 가로 피리
  소금 (小笒): 소형 가로 피리
  향비파 (鄕琵琶): 한국식 비파 (중국 비파 변형)
  아쟁 (牙箏): 활로 켜는 현악기
  장구: 모래시계형 타악기

음악 특성 (추정):
  우아·서정적 — 예술 국가 특성
  현악 + 관악 균형 — 궁중 음악 발달
  불교 음악 영향 — 불교 국가 특성
  일본 전래 근거 → 외래 영향력 높음

IP 활용 기준:
  대금 + 아쟁 = 백제 음악 시그니처
  ✓ 대금: 삼국 공통 사용 악기
  ✓ 아쟁: 백제 궁중 음악 추정
  △ 향비파: 삼국시대 한반도 유입 시기 고증 필요
```

### 신라 음악

```
주요 악기 (문헌·유물 근거):
  가야금 (伽倻琴): 신라 전래 (우륵 전수)
  향가 반주: 현악기 + 타악 조합 추정
  피리: 「만파식적(萬波息笛)」— 신라 신화 피리
  첨성대 부근 음악 의식: 천문 + 음악 연계 (추정)

음악 특성 (추정):
  역동·화랑 기상 — 군사·청년 문화
  불교 의식음악 발달 — 황룡사 법회
  향가 = 가사 중심 노래 문화

IP 활용 기준:
  피리 + 타악 = 신라 음악 시그니처
  ✓ 향가 형식: 삼국사기·삼국유사 근거
  ✓ 피리: 문헌 신화 근거
  △ 가야금 신라 사용: 우륵 전수 이후 → 가야 원류 명시
```

### 가야 음악

```
주요 악기 (최고 확실 근거):
  가야금 (伽倻琴):
    기원: 가야국 가실왕 창제 (삼국사기 기록)
    현 수: 12현 (현재 가야금 원형)
    재질: 오동나무 공명통 + 명주실 현
    우륵의 12곡: 각 지방 특색 반영한 가야 음악
    → 가야 멸망 후 신라로 전승 (우륵 망명)

  가야 악기 추가 (추정):
    대나무 피리: 낙동강 대나무 활용
    타악기: 제천 의식용 (고고학 유물 추정)

음악 특성:
  서정·애수 — 멸망 왕국의 슬픔
  자연 친화 — 강물·바람 소리와 공명
  가야금 12현 = 가야 12국 상징 (IP 창작 해석)

IP 활용 기준:
  가야금 솔로 = 가야·니문 시그니처 (최고 근거)
  ✓ 가야금: 삼국사기 명시 최강 근거
  ✓ 우륵 12곡 존재: 역사 기록
  ✓ 니문 = 우륵 계보 음악인 설정 (IP 창작, 고증 연계)
```

## 음악 고증 등급 체계

```
★★★ (최고 확실 — 문헌 명시):
  가야금 (가야·신라): 삼국사기 명시
  거문고 (고구려): 삼국사기 왕산악 기록
  향가 (신라): 삼국유사 다수 수록
  백제 → 일본 음악 전수: 일본서기 기록

★★ (높음 — 유물·벽화 근거):
  공후 (고구려): 고분 벽화 확인
  횡적/피리: 삼국 공통 벽화·유물
  대형 타악기 (북·징): 고분 벽화

★ (추정 — 상황 증거):
  향비파 한반도 유입 시기
  아쟁 삼국시대 사용 여부
  구체적 음계·선율 재현 (악보 미존재)

× (금지 — 역사 외 삽입):
  현대 서양 화성 「삼국시대 음악」칭하기
  일본 음악 = 삼국 음악 혼동
  중국 음악 그대로 = 고구려 음악 대체
```

## 자문 체크리스트

```
드라마·뮤지컬 음악 씬 검토:
  □ 등장 악기가 해당 왕국·시대에 존재했는가
  □ 연주 방식이 고증에 부합하는가 (활·손·채)
  □ 음계 구성이 서양 화성 과도하게 반영되지 않는가
  □ 가야금 = 가야·니문 전용 맥락 유지되는가
  □ 음악 장면 역사 정합성 ADV-ARTS 확인 여부

OST 검토:
  □ 전통 악기 명칭이 올바른가
  □ 왕국별 악기 조합이 고증 근거 있는가
  □ 「가야금 = 가야」전용 언급 올바른가
  □ 신라 가야금 사용 시 우륵 전수 맥락 명시 여부

게임 BGM 검토:
  □ 왕국별 대표 악기 BGM 적용 여부
  □ 전투 음악 타악 강조 (고증 부합)
  □ 교역 장면 상이한 문화권 음악 혼재 여부
```
