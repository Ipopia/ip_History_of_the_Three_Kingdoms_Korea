# 사운드 디자인 기획 — 삼국(三國) IP

**참조 문서**: `ost-tracklist.md`, `music-production-guide.md`, `cinematography.md`, `vfx-plan.md`
**작성**: 사운드본부 사운드디자인팀 (SND-SFX)
**적용**: 삼국(三國) IP 드라마·게임·공연 SFX 및 앰비언스 사운드 기준

## 사운드 디자인 철학

```
핵심 원칙:
  「소리가 역사를 살아있게 만든다」

3대 원칙:
  1. 고증 기반 — 7세기 실존 악기·무기·환경음 최우선
  2. 감정 증폭 — SFX가 음악의 연장선
  3. 왕국 정체성 — 각 왕국 고유 음향 언어

기술 포맷:
  드라마: Dolby Atmos (공간음향)
  게임: FMOD 어댑티브 오디오
  공연: L-Acoustics 라이브 시스템
```

## 왕국별 음향 팔레트

### 고구려 — 「철과 바람의 소리」

```
환경음:
  대동강 강물 (빠른 유속, 거친 물소리)
  북방 바람 (날카롭고 강한 바람)
  산악 메아리 (공간감 넓은 잔향)
  봉화 불꽃 소리 (건조한 화염)

무기·전투음:
  고구려 철검 (무겁고 두꺼운 금속음)
  개마무사 갑옷 (두꺼운 철판 마찰음)
  군마 발굽 (단단한 땅, 강한 진동)
  살수 수문 개방 (수공(水攻) 물 범람음)

앰비언스 키워드:
  낮은 주파수 베이스, 철제 공명, 메아리
```

### 백제 — 「연등과 금강의 소리」

```
환경음:
  금강 강물 (완만하고 부드러운 유속)
  사비성 연등 (촛불 타는 소리, 바람에 흔들림)
  목탑 종소리 (불교 범종 — 백제 불교 상징)
  황해 파도 (백제 해상 교역 상징)

무기·전투음:
  백제 청동 단검 (가벼운 금속음)
  수군 노 젓는 소리 (물 저항음)
  낙화암 낙수 (비극적 장면 전용)

앰비언스 키워드:
  따뜻한 중주파수, 부드러운 잔향, 연등 파티클
```

### 신라 — 「황금 들판과 화랑의 소리」

```
환경음:
  경주 분지 바람 (열린 평야, 풍부한 바람)
  황룡사 범종 (신라 불교 대표음)
  첨성대 주변 새소리 (경주 특유의 새)
  황금 시간대 메뚜기 소리 (가을·황산벌 연계)

무기·전투음:
  화랑 궁시 발사 (빠르고 경쾌한 활시위 소리)
  신라 보병 행진 (규칙적·역동적)
  기벌포 해전 함선 충돌 (거대한 목재 파열음)

앰비언스 키워드:
  밝은 고주파, 역동적 리듬, 금속 공명
```

### 가야 — 「낙동강과 가야금의 소리」

```
환경음:
  낙동강 황혼 물소리 (느리고 깊은 유속)
  대나무 숲 바람 (가야 낙동강 변 대나무 군락)
  가야금 공명 (실제 가야금 12현 개방현음)
  고분 동굴 잔향 (가야 고분군 특유의 공간)

특수:
  가야금 현 진동음 (1,000fps 슬로모션 연계)
  「676」날짜 장면: 새벽 정적 → 첫 새소리

앰비언스 키워드:
  극저음 베이스, 긴 잔향, 자연 미니멀리즘
```

## 특수 SFX 목록

### 전투 SFX

```
살수대첩 수공 (水攻):
  소재: 실제 댐 방류 음향 + 스튜디오 워터탱크 녹음
  레이어:
    L1 — 수문 개방 금속음 (삐걱·철컥)
    L2 — 물 압력 방류음 (저주파 럼블)
    L3 — 대량 유수 (폭포급 수량)
    L4 — 수나라 병사 비명·혼란 (원거리 처리)
  최종: Dolby Atmos 7.1.4 공간음 처리

황산벌 5,000 결사대 행진:
  소재: 300명 엑스트라 + 피치 시프트 레이어링
  레이어:
    L1 — 발걸음 (5,000명 군세 표현)
    L2 — 갑옷 마찰음
    L3 — 계백 검 뽑는 소리 (단독 강조)
    L4 — 침묵 (전투 직전 1초 무음 — 긴장감 극대화)

기벌포 해전:
  소재: 실제 해전 음향 + 대형 목선 충돌 foley
  22라운드 연속 전투: 각 라운드 SFX 강도 점층 설계
  최종 22연승: 갑판 위 환호성 + 파도 + 거센 바람
```

### 캐릭터 전용 SFX

```
고루 — 환두대도 발도음:
  소재: 실제 도검 발도 녹음 + 철 공명 강화
  고루 전용 음색: 무겁고 낮은 금속 공명
  (타 캐릭터 검 소리와 구별되는 고유 음색)

아랑 — 죽간 펼치는 소리:
  소재: 실제 대나무 조각 foley
  붓 글씨 쓰는 소리 (섬세한 마찰음)
  특별: 아랑이 마지막 죽간에 쓸 때 — 잉크 방울 소리 강조

하린 — 활시위 발사:
  소재: 전통 각궁 실제 녹음
  슬로모션 씬: 시위 진동 + 공기 저항음 (1,000fps 연계)
  명중 시: 금속·가죽·나무 타격 구별

니문 — 가야금 연주:
  소재: 실제 가야금 12현 마이크 근접 녹음
  1,000fps 슬로모션 현 진동 씬:
    현 별 개별 진동음 분리 녹음
    저주파 공기 진동 레이어 추가
  니문 마지막 연주 (676): 현이 끊어지는 소리 포함
```

## 앰비언스 사운드 맵

```
드라마 각 씬 앰비언스 지정:

실내 씬:
  평양성 회의실 — 석조 공명 + 횃불 바람 + 먼 봉화
  사비성 문서관 — 촛불 + 종이(죽간) + 조용한 밤
  경주 황룡사 — 범종 잔향 + 불경 독송 원거리
  가야금 연주실 — 가야금 공명 + 깊은 실내 잔향

전투 외부 씬:
  안시성 성벽 위 — 강풍 + 당나라 진영 소음 원거리
  황산벌 전장 — 대지 울림 + 기병 진동 + 침묵 교차
  기벌포 해안 — 파도 + 바닷바람 + 함선 삐걱임

자연 씬:
  살수 강변 새벽 — 물안개 + 새소리 시작
  낙동강 황혼 — 풀벌레 + 강물 + 먼 가야금
  대동강 겨울 — 얼음 균열음 + 북방 바람
```

## 무음(Silence) 설계

```
삼국(三國) IP 무음 활용 원칙:
  「침묵도 사운드 디자인이다」

무음 사용 기준:
  ① 감정 절정 직전: 1~3초 완전 무음 → 음악·SFX 폭발
  ② 죽음 장면 직후: 5~10초 점진적 페이드 (잔향만 남음)
  ③ 니문 장면: 무음이 가장 강한 표현 수단
  ④ 역사적 사건 직후: 무음 + 강물 소리만

특별 무음 씬:
  계백 결사대 출전 전 — 1초 완전 무음
  백제 멸망 순간 — 5초 무음 후 강물 소리
  676 니문 마지막 현 — 연주 후 10초 무음 (드라마 엔딩)
```

## 게임 어댑티브 오디오

```
FMOD 시스템 구성:
  전투 강도 레이어 (0~100%):
    0~20%: 환경음 + 먼 전투 소음
    20~60%: 전투 BGM 시작 + SFX 강도 증가
    60~90%: 풀 전투 사운드
    90~100%: 클라이맥스 (오케스트라 최대)

왕국별 BGM 전환:
  고구려 영토 진입 → 철과 바람 앰비언스 자동 전환
  백제 영토 진입 → 연등 앰비언스 자동 전환
  가야 구역 → 가야금 미니멀 앰비언스

이벤트 트리거:
  살수 수문 조작 → 수공 SFX 시퀀스 시작
  황산벌 관창 이벤트 → 특별 SFX 패키지 발동
  676 엔딩 → 니문 가야금 독주 페이드인
```
