## 개요

```
시대 배경: 4~7세기 한반도
농업 기반:
  벼농사 (수전): 백제·신라 중심 (남부 평야)
  밭농사 (한전): 고구려 중심 (북방 고원·산지)
  혼합: 가야 (낙동강 유역 비옥한 충적 평야)

기후 특성:
  온대 몬순: 여름 집중 강우 → 벼농사 유리
  북방 (고구려): 짧은 여름, 긴 겨울 → 보리·조·수수 다작
  한반도 남부: 이모작 시도 (벼+보리)
```

## 왕국별 농업 체계

### 고구려 농업

```
주요 작물:
  1순위: 조(粟) — 고원 기후에 강인, 고구려 주식
  2순위: 수수·기장 — 저장성 높음 (군량 적합)
  3순위: 콩(大豆) — 두부·장류 원료, 단백질 공급
  4순위: 보리 — 이른 봄 파종 가능
  부작물: 삼(麻) — 의류·군용 포승 원료

농업 방식:
  화전(火田): 산림 개간 → 소각 → 경작 (2~3년 후 이동)
  계단식 논: 산지 경사면 개간 (토산 활용)
  관개: 제한적 (대형 저수지 부재)

군사 연계:
  식량 비축: 성마다 1년치 군량 비축 의무
  살수대첩 배경: 청야전술(淸野戰術) — 적 진격 시 식량·시설 소각
    → 수나라 113만 군의 보급 차단 핵심

특산:
  고구려 황금 조밥: 고원산 조의 쫀득한 식감 → 외교 선물
  발효 저장식: 염장·된장·간장 원형 개발
```

### 백제 농업

```
주요 작물:
  1순위: 벼(稻) — 금강·만경강 유역 풍부한 수전
  2순위: 보리 — 이모작 (벼 수확 후 겨울 파종)
  3순위: 콩·팥 — 사비성 귀족 식문화
  4순위: 채소류 — 파·마늘·부추·가지
  특산: 연꽃 재배 (불교 의례용 + 식용)

농업 방식:
  수전(水田): 금강 유역 광활한 평야 개간
  저수지: 벽골제(碧骨堤, 330년경) — 김제 일대
    → 한반도 최초 대형 저수지 (둑 길이 3.3km)
  철제 농기구: 철제 삽·괭이 보급 → 심경(深耕) 가능

생산량:
  3국 중 단위 면적당 최고 생산성 (평야 비율 최대)
  잉여 생산 → 교역 재원, 귀족 문화 자원

특산:
  백제 쌀: 금강산 쌀 → 중국·일본 교역품
  서해 염전: 소금 생산 → 전국 유통
  과일: 배·밤·감 → 왕실 진상품
```

### 신라 농업

```
주요 작물:
  1순위: 벼 — 경주 분지·형산강 유역
  2순위: 콩·팥 — 화랑 식량
  3순위: 삼(麻)·누에 — 직물 원료 (신라 비단 유명)
  특산: 약초 재배 (경주 주변 산지)

농업 방식:
  천방(川防) 관개: 형산강 지류 수로 개발
  두레: 공동 농업 노동 조직 (후대 두레의 원형)
  골품제 토지: 귀족·관료의 녹읍(祿邑) 제도
    → 왕이 관료에게 토지+농민 지배권 부여

특이점:
  철제 농기구 보급 상대적으로 늦음 (백제보다 후발)
  6세기 진흥왕 시기 영토 확장 → 농경지 급증

특산:
  신라 비단: 누에 사육 고도화 → 당나라 교역 주요품
  경주 쌀: 왕실 제사 쌀 (왕기미 — 가장 엄선된 품종)
```

### 가야 농업

```
주요 작물:
  1순위: 벼 — 낙동강 유역 최적 충적 평야
  2순위: 보리·밀 — 이모작 활발
  3순위: 콩 — 발효식품 기반
  특산: 철제 농기구 생산 (철의 왕국 → 자체 농기구 제작)

농업 방식:
  충적 평야: 낙동강 합류부 비옥 토지
  철기 농업: 가야산 철 → 최고 품질 철제 보습·호미·낫
  가야 수리시설: 소규모 보(洑) 다수 → 분산형 관개

가야 멸망 후:
  낙동강 농경지 → 신라 복속
  철제 농기구 기술 → 신라·백제 전파
  562년 대가야 멸망 → 농업 기반 신라 흡수
```

## 식량 생산 수치 (세계관 설정값)

```
추정 인구 (6세기):
  고구려: 300만~350만명
  백제: 250만~300만명
  신라: 200만~250만명
  가야: 50만~70만명

1인당 연간 식량 필요량: 쌀 환산 약 180kg
왕국별 연간 필요 식량:
  고구려: 약 63만 톤
  백제: 약 51만 톤
  신라: 약 40만 톤

군량 비축 기준:
  주요 성: 10,000명 × 180일 = 162만 석(石) 이상
  살수대첩 시 고구려 평양성 비축: 3년치 추정
```

## 농업과 서사 연계

```
핵심 서사 모티프:
  「풍년 = 왕의 덕」: 삼국시대 자연재해 = 왕의 실정
  기근(饑饉): 전쟁·학정의 결과 → 민심 이반
  청야전술: 살수대첩 핵심 전략 (식량 = 무기)

드라마 활용:
  EP03: 수나라 침공 전야 — 고구려 농민들 식량 숨기기
  EP07: 청야전술 결행 — 을지문덕의 명령으로 마을 소각
  EP09: 살수 범람 — 수나라 군 익사, 남겨진 군량 회수

시각적 표현:
  고구려: 황금빛 조밭, 척박하지만 강인한 농지
  백제: 넓고 풍요로운 논, 금강 물줄기
  신라: 경주 분지 녹색 논, 황금색 비단 누에
  가야: 낙동강 충적지, 철기 농기구의 빛남
```

## 식량과 전쟁

```
삼국시대 전쟁 = 식량 쟁탈전:
  ① 영토 전쟁 = 농경지 확보
  ② 인민 이동 = 노동력 확보
  ③ 성 함락 = 비축 식량 탈취

살수대첩 식량 전략:
  수나라 원정군 (113만 병력)
  보급선: 요하(遼河) → 요동성 → 평양
  고구려 전략:
    요동성 함락 저지 → 보급 지연
    청야전술 → 현지 조달 불가
    7번 후퇴 → 수군의 행군 거리·피로 극대화
  결과: 수나라 병사 아사·탈진 (전투 사상 ≠ 아사 사상)

백제 멸망과 식량:
  황산벌 전투 직전 사비성 비축 현황
  나당연합군의 보급: 당 수군 + 신라 육군
  계백의 결사대: 5,000 vs 50,000 — 식량 없는 싸움
```

## 창작 주의사항

```
역사적 유의:
  ① 조선시대 식문화를 삼국시대에 소급 적용 금지
     (김치: 7세기 원형 존재, 고추는 임진왜란 이후 — 절대 사용 금지)
  ② 쌀밥이 주식인 묘사: 귀족·왕족만 가능
     평민 = 잡곡밥 (조·수수·보리)
  ③ 설탕 사용: 7세기 불가 (꿀·엿이 감미료)
  ④ 돼지·소고기: 왕실 제사·잔치 한정 (평소 귀함)

허용 창작:
  발효식품 (된장·간장 원형): 고대 형태로 묘사 가능
  소금: 서해 염전 유통 확인
  술: 막걸리 원형 (쌀·조로 빚은 탁주) 등장 가능
```
