# 천문 (Astronomy)

> 삼국시대 천문 관측, 별자리, 천변(天變) 기록과 작중 활용

## 1. 천문 관측 체계

### 1.1 첨성대(Cheomseongdae, 瞻星臺) — 경주

| 항목 | 상세 |
|------|------|
| 위치 | 신라 서라벌(Seorabeol), 현 경상북도 경주시 |
| 건립 | 선덕여왕(善德女王) 재위기 (632~647년), 약 634년 추정 |
| 구조 | 화강암 362개(일설 365+α), 원통형, 높이 약 9.17m |
| 기능 | 천문 관측대 — 별자리 관찰, 일식/월식 예측, 절기 판정 |
| 상징 | 27단 석축 = 선덕여왕이 신라 제27대 왕임을 상징 |
| 특징 | 남측 창(窓)이 있어 춘분·추분에 빛이 내부를 비춤 |
| 현 상태 | 국보 제31호, 현존 동아시아 최고(最古)의 천문대 |

#### 첨성대의 천문학적 설계
- 기단부 방형(方形, 땅) + 몸체 원형(圓形, 하늘) = **천원지방(天圓地方)** 사상 반영
- 12단 기단 = 12달(月), 24절기 관련 배치 추정
- 꼭대기 정(井)자형 석재 = 사방위(四方位) 표시

### 1.2 각국의 천문 관측

| 왕국 | 천문 기관/시설 | 특징 |
|------|---------------|------|
| 고구려 | 일관(日官) 제도, 천문 벽화 | 고분벽화에 별자리 도상 다수, 체계적 관측 |
| 백제 | 일관부(日官部) | 역법(曆法) 운용, 왜에 천문 전파 |
| 신라 | 첨성대, 일관(日官) | 선덕여왕 대 체계화, 현존 관측대 |

### 1.3 역법(曆法, Calendar System)

삼국은 중국 역법을 수용하여 사용했다:

| 역법 | 시기 | 사용국 | 특징 |
|------|------|--------|------|
| 태초력(太初曆) | 초기 | 삼국 공통 | 한(漢)대 역법 기반 |
| 원가력(元嘉曆) | 5~6세기 | 백제 | 남조 송(宋)에서 도입 |
| 인덕력(麟德曆) | 7세기 | 신라 | 당(唐)에서 도입 |

- 음력(陰曆) 기반, 윤달(閏月) 삽입으로 태양년 보정
- 24절기(二十四節氣) 체계로 농사 시기 결정
- 일관(日官)이 역서(曆書) 편찬, 매년 반포

## 2. 별자리와 천문 체계

### 2.1 동아시아 별자리 — 삼원(三垣)과 이십팔수(二十八宿)

삼국시대 천문학은 중국 천문 체계를 공유했다:

#### 삼원(三垣, Three Enclosures)
| 별자리 영역 | 한자 | 의미 | 대응 |
|-------------|------|------|------|
| 자미원(紫微垣) | 紫微垣 | 천제(天帝)의 궁궐 | 북극 주변, 왕궁 |
| 태미원(太微垣) | 太微垣 | 조정(朝廷), 관리 | 사자자리 부근, 정치 |
| 천시원(天市垣) | 天市垣 | 시장(市場), 백성 | 뱀주인자리 부근, 경제 |

#### 이십팔수(二十八宿, Twenty-Eight Mansions)
28개 별자리를 사방위(四方位)에 7개씩 배치:

| 방위 | 수호신 | 색 | 계절 | 포함 별자리 (대표) |
|------|--------|-----|------|-------------------|
| 동(東) | 청룡(靑龍) | 청(靑) | 봄 | 각(角), 항(亢), 저(氐), 방(房), 심(心), 미(尾), 기(箕) |
| 북(北) | 현무(玄武) | 흑(黑) | 겨울 | 두(斗), 우(牛), 녀(女), 허(虛), 위(危), 실(室), 벽(壁) |
| 서(西) | 백호(白虎) | 백(白) | 가을 | 규(奎), 루(婁), 위(胃), 묘(昴), 필(畢), 자(觜), 삼(參) |
| 남(南) | 주작(朱雀) | 적(赤) | 여름 | 정(井), 귀(鬼), 류(柳), 성(星), 장(張), 익(翼), 진(軫) |

### 2.2 고구려 고분벽화의 별자리

고구려 고분벽화에는 정교한 천문도가 그려져 있다:

| 고분 | 위치 | 천문 내용 |
|------|------|-----------|
| 덕흥리 고분(德興里古墳) | 남포시 | 천장에 별자리 배치, 해·달·별 |
| 진파리 고분(眞坡里古墳) | 평양 | 사신도(四神圖) + 별자리 |
| 강서대묘(江西大墓) | 남포시 | 사신도 — 청룡·백호·주작·현무 |
| 각저총(角抵塚) | 지안(集安) | 해(삼족오)와 달(두꺼비/토끼) |

#### 사신도(四神圖, Four Guardian Deities)
고분 천장과 벽면에 사방위를 지키는 신수(神獸):
- **동벽: 청룡(靑龍, Azure Dragon)** — 봄, 동쪽
- **서벽: 백호(白虎, White Tiger)** — 가을, 서쪽
- **남벽: 주작(朱雀, Vermilion Bird)** — 여름, 남쪽
- **북벽: 현무(玄武, Black Tortoise)** — 겨울, 북쪽

이 사신도는 단순 장식이 아니라, 죽은 자의 세계를 우주적 질서 속에 배치하는 **천문 우주론(天文宇宙論)** 의 표현이다.

### 2.3 북극성과 왕권

- **북극성(北極星, Polaris)**: 하늘의 중심, 천제(天帝)의 자리
- "천자(天子)는 북극성처럼 제자리에 앉아 만물을 다스린다" — 유교 정치 철학
- 왕궁 배치, 도성 설계에 북극성 방향 반영
- **작중 상징**: 왕의 권위, 불변의 중심, 구심점

## 3. 일식(日蝕)과 월식(月蝕) 기록

### 3.1 삼국사기 일식 기록

삼국사기에는 수십 건의 일식 기록이 있으며, 현대 천문학 역산(逆算)으로 대부분 확인된다:

| 연도 | 국가 | 기록 | 현대 확인 |
|------|------|------|-----------|
| 54년 | 신라 (탈해왕 원년) | "일식이 있었다(日有食之)" | 확인 |
| 187년 | 고구려 (고국천왕 9년) | "일식" | 확인 |
| 249년 | 백제 (고이왕 16년) | "일식" | 확인 |
| 381년 | 신라 (내물왕 26년) | "일식" | 확인 |
| 434년 | 고구려 (장수왕 22년) | "일식" | 확인 |
| 516년 | 백제 (무령왕 16년) | "일식" | 확인 |
| 601년 | 신라 (진평왕 23년) | "일식" | 확인 |
| 647년 | 신라 (선덕여왕 16년) | "일식" | 확인 |

### 3.2 일식의 정치적 의미

일식은 **하늘이 왕을 견책(譴責)하는 징조** 로 해석되었다:

- **음(陰)이 양(陽)을 침범**: 신하가 군주를 넘보거나, 왕비/외척이 전횡하는 징조
- **왕의 반성 의례**: 일식 발생 시 왕이 정전(正殿)을 피하고 소복(素服)을 입으며 근신
- **사면(赦免)**: 죄인 사면으로 하늘의 노여움을 풀려는 시도
- **정변의 명분**: "하늘이 노하였다" → 반대 세력의 정치 공세 근거

### 3.3 월식 기록

월식 역시 기록되었으나 일식보다 빈도가 낮게 기록됨:
- 월식은 "음이 밝음을 잃은 것"으로 왕비·후궁·여성 권력과 연결
- 정치적 해석은 일식보다 약하나, 불길한 징조로 취급

## 4. 기타 천변(天變) 기록

### 4.1 혜성(彗星, Comet)

| 연도 | 국가 | 기록 | 작중 의미 |
|------|------|------|-----------|
| 303년 | 고구려 | "혜성이 나타났다(彗星見)" | 전쟁·재난의 전조 |
| 467년 | 신라 | "혜성이 동쪽에 나타났다" | 변란의 징후 |
| 634년 | 백제 | "혜성이 나타났다" | 국운 쇠퇴의 암시 |

혜성은 **객성(客星)** 이라고도 하며, 이질적 존재의 출현 — 외적 침입, 반란, 왕조 교체의 전조로 해석되었다.

### 4.2 유성(流星, Meteor)

| 기록 유형 | 해석 |
|-----------|------|
| 큰 유성이 떨어짐 | 대인(大人)의 죽음 예고 |
| 유성이 왕궁 방향으로 | 왕실 변고의 전조 |
| 유성우(流星雨) | 하늘의 경고, 대변동 암시 |

### 4.3 오성(五星, Five Planets)

맨눈으로 관측 가능한 5행성과 그 의미:

| 행성 | 한자 | 오행 | 방위 | 상징 |
|------|------|------|------|------|
| 수성(水星) | 辰星 | 수(水) | 북 | 지혜, 형벌 |
| 금성(金星) | 太白 | 금(金) | 서 | 전쟁, 군사 — "태백(太白)이 낮에 보이면 전쟁" |
| 화성(火星) | 熒惑 | 화(火) | 남 | 재앙, 질병 — "형혹(熒惑)이 심수(心宿)에 들면 왕 교체" |
| 목성(木星) | 歲星 | 목(木) | 동 | 복, 풍년 |
| 토성(土星) | 鎭星 | 토(土) | 중앙 | 왕도(王道), 안정 |

#### 형혹수심(熒惑守心)
화성이 심수(心宿, 전갈자리 안타레스 부근)에 머무르는 현상은 **왕이 죽거나 교체되는 최흉의 천변** 으로 해석되었다. 삼국사기에도 관련 기록이 있으며, 작중에서 정치적 음모와 연결할 수 있는 강력한 서사 장치다.

|------|------|------|

| 흰 무지개가 해를 꿰뚫음 | 白虹貫日 | 신하의 반역, 역모의 징조 |

## 5. 천문과 정치

### 5.1 천명(天命) 사상

삼국시대의 정치 정당성은 **하늘의 뜻(天命)** 에 기반했다:

- **왕 = 하늘의 대리인**: 왕의 덕(德)이 충만하면 하늘이 상서(祥瑞)를 보내고, 부덕하면 재이(災異)를 내림
- **천변 = 왕의 책임**: 일식, 지진, 가뭄 등 모든 자연재해는 왕의 덕정 실패로 귀결
- **개혁의 명분**: "하늘의 경고"를 받들어 정치 개혁, 인사 쇄신, 사면의 명분

### 5.2 천문 해석의 정치 도구화

| 상황 | 천문 활용 |
|------|-----------|
| 왕위 정당화 | 즉위 전후 상서로운 천문 현상 기록(조작 가능) |
| 정적 제거 | "천변이 경고한다" → 특정 인물/세력 탄핵 |
| 전쟁 개시 | "별자리가 유리하다" → 출정 명분 |
| 반란 정당화 | "천명이 바뀌었다(革命)" → 새 왕조 수립 |
| 외교 | 천문 역법 공유 = 문화적 종속/독립 표현 |

### 5.3 일관(日官)의 역할

일관(日官)은 천문 관측과 해석을 담당하는 관리로, 정치적 영향력이 컸다:

- 천문 이상 관측 → 왕에게 보고 → 정치적 해석 제공
- 역서(曆書) 편찬 → 농업·의례 일정 결정
- 점성(占星) → 왕의 의사결정 보좌
- **위험**: 일관의 해석이 정파에 이용되거나, 왕과 충돌할 가능성

## 6. 작중 활용 가이드

### 6.1 예언과 천문

천문 현상을 예언 장치로 활용:

| 천문 현상 | 서사적 활용 |
|-----------|-------------|
| 일식 | 왕의 위기, 정변 직전, 전쟁 패배의 전조 |
| 혜성 출현 | 영웅 탄생, 외세 침입, 시대 전환의 신호 |
| 유성 낙하 | 대인의 죽음 예고, 운명적 사건의 시작 |
| 형혹수심 | 왕위 교체, 궁중 음모의 절정 |
| 오로라(北光) | 만주 북방에서 관측 가능 — 신비로운 전조 |
| 별똥별 | 소원/결심의 계기, 운명의 분기점 |

### 6.2 전쟁 개시 시점 결정

고대 전쟁의 출정일(出征日)은 천문 관측으로 결정했다:

1. **일관이 길일(吉日) 택일**: 별자리 배치, 오행 상생/상극 고려
2. **제천(祭天) 의례**: 출정 전 하늘에 제사, 승리 기원
3. **군기(軍旗) 방향**: 바람과 별자리에 따라 군기 방향 결정
4. **야간 기습의 판단**: 달의 위상(음력 그믐 = 어두운 밤 → 기습 유리)

#### 달의 위상과 군사 작전

| 음력 날짜 | 달의 상태 | 군사적 의미 |
|-----------|-----------|-------------|
| 1일(초하루) | 삭(朔), 달 안 보임 | 야간 기습 최적 |
| 7~8일 | 상현달(上弦) | 전반부 밝음, 후반부 어두움 |
| 15일(보름) | 망(望), 보름달 | 야간 행군 가능, 은밀 작전 불가 |
| 22~23일 | 하현달(下弦) | 새벽 밝아짐, 야습 후 철수 유리 |
| 29~30일 | 그믐 | 야간 기습 최적 |

### 6.3 의식(儀式) 날짜 결정

주요 국가 의례는 천문에 따라 날짜를 정했다:

| 의례 | 시기 | 천문 근거 |
|------|------|-----------|
| 제천(祭天) | 10월 (고구려 동맹/東盟) | 추수 후 + 별자리 배치 |
| 제천 | 10월 (백제) | 동일 |
| 제천 | 정월 (신라) | 세수(歲首) |
| 파종제(播種祭) | 춘분 전후 | 24절기 기준 |
| 수확제(收穫祭) | 추분~상강 | 24절기 기준 |
| 혼례(婚禮) | 길일 택일 | 신랑·신부 생년과 별자리 |
| 즉위(卽位) | 길일 택일 | 천문+오행 상합 |
| 장례(葬禮) | 49일 후 또는 길일 | 불교 영향 + 점성 |

### 6.4 캐릭터 유형 — 천문 관련

| 캐릭터 | 역할 | 서사적 기능 |
|--------|------|-------------|
| 일관(日官) | 왕의 천문 고문 | 예언자, 정치 참모, 진실의 해석자 |
| 승려 천문가 | 사찰 기반 관측 | 불교적 세계관 + 천문 지식 |
| 도사(道士) | 민간 점성가 | 민중의 예언자, 반체제적 |
| 왕 | 천명의 수행자 | 천변에 대한 책임과 반응 |

### 6.5 주요 서사 장면 예시

#### 장면 1: 선덕여왕과 첨성대
> 선덕여왕이 첨성대를 세우며 말한다: "하늘의 뜻을 읽는 자가 땅을 다스린다."
> 첨성대 꼭대기에서 일관이 별을 읽는다. 형혹(火星)이 심수에 접근하고 있다. 불안이 퍼진다.

#### 장면 2: 출정 전야
> 장수가 일관에게 묻는다: "내일 출정해도 되겠는가?"
> 일관이 밤하늘을 올려다본다. 태백성(금성)이 낮에 보인다. "전쟁의 별이 떴습니다. 싸울 때입니다."

#### 장면 3: 일식과 정변
> 조정에서 격론이 벌어진 날, 하늘이 어두워진다. 일식이다.
> "하늘이 왕을 버리셨다!" 반대파가 외친다. 왕은 침묵 속에 정전을 떠난다.

#### 장면 4: 혜성과 영웅 탄생
> 만주 벌판에 혜성이 꼬리를 드리운 밤, 한 아이가 태어난다.
> 마을 노인이 말한다: "객성(客星)이 뜬 날 태어난 아이는 천하를 뒤집는다."
