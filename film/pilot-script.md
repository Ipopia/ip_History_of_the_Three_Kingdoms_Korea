# 파일럿 에피소드 스크립트 개요 — 삼국(三國) IP

**참조 문서**: `master-plot.md`, `character-profiles.md`, `film-production-guide.md`, `cinematography-guide.md`
**작성**: 영상&애니본부 각본팀 (FILM-SCRIPT)
**적용**: 삼국(三國) IP 드라마 시즌 1 파일럿 에피소드 (EP01) 기준

## 파일럿 에피소드 개요

```
에피소드: S1 EP01 「강이 흐른다」
러닝타임: 70분 (파일럿 특별 연장)
시간 배경: AD 612년 봄 — 수나라 침략 직전
촬영 분량: 약 90분 촬영분 (편집 후 70분)

목표:
  4인 캐릭터를 효과적으로 소개
  세계관의 규모·분위기 수립
  첫 10분 안에 시청자 확보
  「강은 기억한다」슬로건 최초 발화
```

---

## 씬 구성 (Scene List)

### ACT 1 — 프롤로그 (00:00~08:00)

```
SCENE 001 — 강의 오프닝 (00:00~02:30)
  장소: 살수강 (청천강) / 시간: 이른 새벽

  촬영:
    드론 — 강 상류에서 하류 방향 이동
    수면 클로즈업: 물결·물안개
    강가 새벽 새소리 + 가야금 원거리 음 (OST 테마)

  자막: 「AD 612년 — 수나라 황제 양제, 113만 대군으로 고구려를 침략하다」

  나레이션 (니문 노년 목소리):
    「강이 흐른다. 오늘도 강이 흐른다.
     나라가 사라진 뒤에도 강은 흘렀다.
     이름이 잊힌 뒤에도 강은 기억했다.
     나는 그들을 기억한다 — 강이 기억하듯이.」

SCENE 002 — 수나라 대군 (02:30~05:00)
  장소: 요동 국경 / 시간: 이른 아침

  촬영:
    조감 드론: 수나라 대군 행렬 (디지털 군중 최대)
    저각도: 군마 발굽 + 군화 클로즈업
    수나라 깃발 펄럭임 + 북소리 SEQ-001

  대사: 없음 (순수 비주얼 + 사운드)

  감성: 위압감 — 고구려가 얼마나 불리한지 시각화

SCENE 003 — 고루, 보고 (05:00~08:00)
  장소: 고구려 최전방 망루

  고루 (32세) — 첫 등장:
    망원경 없이 육안으로 수나라 군 관측
    부하: 「장군, 저…저게 전부입니까?」
    고루: (침묵 5초) 「숫자가 중요한 게 아니다.」
    부하: 「그럼 무엇이 중요합니까?」
    고루: 「지형이다. 그리고 물.」

  카메라: 고루 뒷모습 → 살수강 원경 → 고루 눈 클로즈업

  음악: 고루 테마 첫 등장 (해금 저음)
```

### ACT 2 — 4인 소개 (08:00~35:00)

```
SCENE 004 — 아랑, 사비성 (08:00~16:00)
  장소: 사비성 왕궁 후원

  아랑 (20세) — 첫 등장:
    금동대향로 앞 자수 작업 중
    어머니: 「자수는 기록이야 — 잊지 않기 위해 새기는 것」
    아랑: 「…잊으면 사라지나요?」
    어머니: 「사라지지. 기억하는 사람이 없으면.」

  시녀 등장: 「수나라가 고구려를 쳤다 합니다」
  아랑: (자수 멈춤) 「고구려가…」(시선 멀어짐)

  카메라:
    자수 클로즈업 → 아랑 얼굴 → 금동대향로 → 아랑 손 (바늘 잡음)

  이 장면에서 확립:
    아랑의 섬세함·감각적 묘사
    「기억」테마 첫 대화
    백제의 아름다운 미장센

SCENE 005 — 하린, 왕경 (16:00~24:00)
  장소: 신라 화랑 훈련장

  하린 (20세) — 첫 등장:
    말을 타며 과녁 향해 달리기
    화살 3발 연속 명중 → 동료들 환호
    관창 (어린 소년, 8세): 「하린 형! 저도 할 수 있어요?」
    하린: (웃으며) 「10년 후에 물어봐라, 관창아.」

  김유신 등장: 「하린. 북쪽에서 소식이 왔다.」
  하린: 「수나라입니까?」
  김유신: 「고구려가 막을 것이다. 하지만 우리도 준비해야 한다.」
  하린: 눈빛 변함 — 처음으로 진짜 전쟁의 냄새를 맡음

  카메라:
    기마 궁사 역동적 추적 → 착지 순간 하이앵글
    관창 어린 얼굴 클로즈업 (복선)

SCENE 006 — 니문, 낙동강 (24:00~32:00)
  장소: 낙동강 변 (김해 근처)

  니문 (25세) — 첫 등장:
    낙동강 변 돌 위에 앉아 가야금 연주
    완전히 눈 감음 — 강물 소리와 가야금 소리 합주

  지나가는 어부: 「젊은 사람이 뭘 하는 거요?」
  니문: (눈 뜨지 않고) 「기억하는 중입니다.」
  어부: 「뭘요?」
  니문: (잠깐 멈춤, 눈 뜸) 「…아직 모르겠습니다.」

  멀리서 철 단조 소리 (가야 공방)
  니문: 가야금 12현 중 한 현 끊어짐
  니문: (줄 바라보며) 「나라는 없지만 소리는 있다.」(혼잣말)

  카메라:
    가야금 현 클로즈업 → 강물 흐름 → 니문 전신 → 낙동강 파노라마

SCENE 007 — 4인 교차 편집 (32:00~35:00)
  같은 시간 — 4인 각자의 공간

  고루: 살수강 바라보며 전략 구상
  아랑: 자수 한 땀 더 놓음
  하린: 활 쏘기 연습 계속
  니문: 끊어진 현 새로 묶음

  음악: 4인 테마 처음으로 동시 연주 (가야금+해금+대금+북)

  나레이션 (니문):
    「그들은 그날 서로를 몰랐다.
     고구려의 장군, 백제의 귀족, 신라의 화랑, 가야의 악사.
     하지만 같은 강 아래 살고 있었다.」
```

### ACT 3 — 살수 전야 (35:00~55:00)

```
SCENE 008 — 을지문덕 전략회의 (35:00~45:00)
  장소: 고구려 야전 본부

  을지문덕 첫 등장:
    지도 앞에 서 있는 뒷모습 → 천천히 돌아봄
    「모두 앉아라.」

  7번 후퇴 전략 발표:
    을지문덕: 「우리는 일곱 번 물러선다.」
    장수들: 웅성거림
    을지문덕: 「후퇴는 패배가 아니다. 우리는 물러서면서 끌어들인다.」
    고루: (침묵하며 지도의 살수강을 바라봄)
    을지문덕: 「고루. 네가 수문을 연다.」
    고루: 「…알겠습니다.」(단 세 마디)

  카메라: 을지문덕 얼굴 클로즈업 → 살수강 지도 → 고루 눈 → 수문 위치

SCENE 009 — 고루 전야 독백 (45:00~52:00)
  장소: 살수강가 / 시간: 밤

  고루 혼자:
    강물 바라봄 (거울같이 잔잔)

  고루 (낮은 목소리):
    「내일 이 강이 열린다.
     백만이 건너고 있을 때
     나는 문을 연다.
     …두려움이 없다고 말하면 거짓말이다.
     두려움이 있어도 간다.
     그것이 전사다.」

  강물 클로즈업 → 달 반영 → 고루 실루엣

SCENE 010 — 그날 밤, 4인 (52:00~55:00)
  교차 편집 몽타주:
    고루: 강가에 서 있음
    아랑: 금동대향로 앞에서 잠들어 있음 (자수 손에 쥔 채)
    하린: 훈련장에서 마지막 활시위 당기는 연습
    니문: 가야금 연주 (끊어진 현 수리 후 첫 소리)

  음악: 가야금 솔로 → 천천히 전체 오케스트라로
```

### ACT 4 — 살수대첩 클라이맥스 (55:00~70:00)

```
SCENE 011 — 1차 후퇴 (55:00~59:00)
  장소: 살수강 북쪽 전선

  빠른 편집: 전투 → 고구려군 후퇴 → 수나라 군 추격
  고루 (말 위): 「물러서라!」
  부하들: 혼란, 도망치는 것인지 전술인지 모름
  고루: (부하 붙잡으며) 「이것이 전략이다. 믿어라.」

  이 과정 7회 반복 (빠른 몽타주 — 30초씩)

SCENE 012 — 살수 도하 시작 (59:00~63:00)
  장소: 살수강 — 수나라 군 도하 시작

  긴장 고조:
    수나라 군 강을 건너기 시작
    고루: 언덕 위에서 바라봄
    봉화 준비하는 부하

  교차 편집 (아랑 시점):
    아랑: 사비성에서 자수하다가 멈춤
    왠지 모를 불안함
    금동대향로를 두 손으로 어루만짐

  음악: 긴장 고조 (타악 + 금관)

SCENE 013 — 댐 개방 (63:00~67:00) — 클라이맥스

  수나라 군 절반 강 한가운데:
    고루: (봉화 신호용 횃불 들고 서 있음)
    을지문덕 신호: 고개 한 번 끄덕
    고루: (눈 감음 — 3초 침묵) → (눈 뜨고 횃불 들어올림)

  봉화 2개 점화:
    수문 도르래 소리 — 목재 삐걱
    물이 흘러내리기 시작

  VFX 클라이맥스:
    급류 폭발 (SEQ-003 사운드)
    수나라 군 수몰 (간접 연출)
    고루: 눈 감지 않고 바라봄

  사운드: SEQ-004 (수몰음 + 고구려 함성 교차)

SCENE 014 — 승리, 그리고 침묵 (67:00~70:00)

  전투 후:
    조용해지는 강
    고루: 혼자 강가에 서 있음

  첫 번째 발화:
    고루 (거의 들리지 않는 목소리):
    「강은 기억한다.」

  카메라: 강물 클로즈업 → 하늘 → 고루 등 → 살수강 파노라마

  나레이션 (니문 노년):
    「그날 강은 기억했다.
     고루가 열었던 수문을.
     살아남은 자들의 숨소리를.
     그리고 잊혀진 자들의 이름을.」

  마지막 컷:
    강물이 조용히 흐름
    「삼국(三國) — 강은 기억한다」 타이틀 카드

  다음 화 예고: 아랑 금동대향로 장면 단편
  음악: 메인 테마 풀 버전 (엔딩 크레딧)
```

## 프로덕션 노트

```
VFX 필요 장면:
  SCENE 002: 수나라 대군 (디지털 군중)
  SCENE 013: 살수 댐 개방·급류 (Houdini FLIP)
  SCENE 007: 4인 교차 동시 편집 (색보정 4왕국 분리)

주요 로케이션:
  살수강: 국내 강가 + VFX 합성
  사비성 후원: 세트 제작 (백제 정원)
  화랑 훈련장: 야외 로케이션

캐스팅 주의:
  고루: 바리톤 음색, 50대 외모 (35세 분장)
  을지문덕: 권위·카리스마 (55~60대 배우)
  관창: 실제 아역 (8세) — 아동 노동 규정 준수
```
