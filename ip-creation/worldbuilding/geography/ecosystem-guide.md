# 생태계 도감 (Ecosystem Guide)

> 한반도 및 만주 4~7세기 동식물 — 삼국시대의 자연 세계

---

## 1. 포유류 (Mammals, 獸類)

### 1.1 호랑이 (Tiger, 虎)

| 항목 | 상세 |
|------|------|
| 학명 | *Panthera tigris altaica* (아무르호랑이/백두산호랑이) |
| 서식지 | 한반도 전역, 만주 산림 — 백두산, 태백산맥, 소백산맥 |
| 크기 | 체장 2.5~3.0m, 체중 180~300kg |
| 특성 | 단독 생활, 영역 동물, 최상위 포식자 |
| 삼국시대 의미 | **산신(山神)** 의 화신, 용맹과 위엄의 상징 |
| 기록 | 삼국사기에 호랑이 출현·피해 기록 다수. "호랑이가 궁성에 들어왔다"는 기록은 흉조(凶兆) |
| 작중 활용 | 무사의 상징, 시험/통과의례, 산중 조우 장면, 호피(虎皮) 갑옷/장식 |

### 1.2 곰 (Bear, 熊)

| 항목 | 상세 |
|------|------|
| 종류 | 반달가슴곰(*Ursus thibetanus*), 불곰(*Ursus arctos*) |
| 서식지 | 산림 전역, 특히 만주·백두산·지리산 |
| 특성 | 잡식성, 동면(冬眠), 봄철 활동 |
| 삼국시대 의미 | **단군신화(檀君神話)** 의 웅녀(熊女) — 곰이 인간이 되어 단군의 어머니가 됨 |
| 기록 | 고구려 벽화에 곰 형상, 만주 숲에서의 사냥 대상 |
| 작중 활용 | 건국 신화 연결, 인내와 변신의 상징, 약재(웅담) |

### 1.3 사슴 (Deer, 鹿)

| 항목 | 상세 |
|------|------|
| 종류 | 꽃사슴(*Cervus nippon*), 노루(*Capreolus pygargus*), 사향노루(*Moschus moschiferus*) |
| 서식지 | 산림과 초지 전역 |
| 특성 | 무리 생활, 수컷 뿔 성장/탈각 |
| 삼국시대 의미 | 사냥의 주요 대상, 왕실 수렵(狩獵) 의례 |
| 기록 | 고구려 무용총 수렵도에 사슴 사냥 장면 |
| 작중 활용 | 왕의 사냥 장면, 녹용(鹿茸) 약재, 가죽 갑옷/의복 |

### 1.4 늑대 (Wolf, 狼)

| 항목 | 상세 |
|------|------|
| 학명 | *Canis lupus* |
| 서식지 | 만주, 한반도 북부 산림 |
| 특성 | 무리 사냥, 야행성 |
| 삼국시대 의미 | 북방 유목 문화와 연결, 군사적 의미 |
| 작중 활용 | 만주 벌판의 위험, 겨울 여행의 위협, 고구려 전사의 비유 |

### 1.5 멧돼지 (Wild Boar, 猪)

| 항목 | 상세 |
|------|------|
| 학명 | *Sus scrofa* |
| 서식지 | 한반도 전역 산림 |
| 특성 | 잡식성, 힘이 세고 공격적 |
| 작중 활용 | 사냥 장면, 농경지 피해, 용맹함의 비유 |

### 1.6 군사적 중요 동물 — 말 (Horse, 馬)

| 항목 | 상세 |
|------|------|
| 종류 | 과하마(果下馬, 작은 말), 만주마(큰 말) |
| 산지 | 고구려·만주 초원 — 최고 품질의 전마(戰馬) 산출 |
| 특성 | 고구려 기병(騎兵)의 핵심 전력 |
| 규모 | 고구려는 수만 필의 기마 전력 보유 |
| 기록 | 광개토대왕비 "기병 5만", 고구려 벽화 기마무사도 |
| 왕국별 차이 | 고구려: 대규모 기병 / 백제: 기병+보병 혼합 / 신라: 보병 중심에서 점차 기병 확충 |
| 작중 활용 | 전투 장면의 핵심, 명마와 장수의 인연, 기마 훈련 |

### 1.7 군사적 중요 동물 — 소 (Cattle, 牛)

| 항목 | 상세 |
|------|------|
| 역할 | 농경(쟁기질), 운송(우차), 의례(제사 희생) |
| 특성 | 농업 생산력의 척도, 소의 수 = 마을의 부(富) |
| 기록 | 삼국사기에 "소를 죽여 제사하다" 다수 기록 |
| 작중 활용 | 농촌 풍경, 부의 상징, 전시 군량 운송 |

## 2. 조류 (Birds, 鳥類)

### 2.1 학 (Crane, 鶴)

| 항목 | 상세 |
|------|------|
| 종류 | 두루미(*Grus japonensis*), 재두루미(*Grus vipio*) |
| 서식지 | 한강, 임진강 하구, 습지 |
| 삼국시대 의미 | 장수(長壽)와 고결함의 상징, 선인(仙人)의 탈것 |
| 기록 | 백제·신라 금관·장식품에 학 문양 |
| 작중 활용 | 귀족·선인의 상징, 평화로운 습지 풍경, 시적(詩的) 장면 |

### 2.2 매 (Falcon/Hawk, 鷹)

| 항목 | 상세 |
|------|------|
| 종류 | 참매(*Accipiter gentilis*), 송골매(*Falco peregrinus*) |
| 서식지 | 산악 지대 전역 |
| 삼국시대 의미 | **응렵(鷹獵, 매사냥)** — 왕실과 귀족의 수렵 문화 |
| 군사적 용도 | 전장 정찰 보조, 통신 수단 (제한적) |
| 기록 | 삼국사기 "매를 바쳤다(獻鷹)" 기록, 왕의 사냥 의례 |
| 작중 활용 | 매사냥 장면, 무사의 동반자, 자유·용맹의 상징 |

### 2.3 삼족오 (Three-legged Crow, 三足烏)

| 항목 | 상세 |
|------|------|
| 실제 모델 | 까마귀(*Corvus*), 태양 속에 산다는 신화적 존재 |
| 삼국시대 의미 | **고구려의 상징** — 태양신 숭배와 연결 |
| 기록 | 고구려 고분벽화에 태양 안의 삼족오 도상(圖像) 다수 |
| 작중 활용 | 고구려 왕실 문장(紋章), 태양·왕권의 상징, 길조(吉兆) |

### 2.4 기러기 (Goose, 雁)

## 4. 식물 (Flora, 植物)

### 4.1 수목 (Trees, 樹木)

#### 소나무 (Pine, 松)
- **학명**: *Pinus densiflora* (적송), *Pinus koraiensis* (잣나무)
- **분포**: 한반도 전역의 산림 — 가장 흔한 수종
- **용도**: 건축 목재(궁궐·사찰), 관재(棺材), 소나무 숯, 솔잎(식량 대용), 송진(접착·방수)
- **상징**: 절개(節槪), 불변, 장수 — 세한삼우(歲寒三友) 중 하나
- **작중 활용**: 산림 풍경의 기본, 건축 장면, 겨울 생존

#### 대나무 (Bamboo, 竹)
- **분포**: 한반도 남부 (전라·경상 남부), 북방 한계선 존재
- **용도**: 무기(화살대, 창), 건축(담장), 생활용품(바구니, 부채), 식용(죽순)
- **상징**: 지조(志操), 고결, 군자(君子) — 세한삼우 중 하나
- **작중 활용**: 백제·신라 남부의 풍경, 화살 제작 장면

#### 느티나무 (Zelkova, 槐)
- **분포**: 한반도 전역 마을 입구
- **용도**: 고급 건축재, 가구재
- **상징**: 마을의 수호목, 정자나무, 회의 장소
- **작중 활용**: 마을 풍경, 회의 장면, 이별 장면

#### 은행나무 (Ginkgo, 銀杏)
- **분포**: 사찰·궁궐 경내
- **상징**: 장수, 불교와의 연결
- **작중 활용**: 가을 사찰 풍경, 시간의 흐름 상징

### 4.2 화초 (Flowers and Plants, 花草)

#### 연꽃 (Lotus, 蓮)
- **분포**: 연못, 습지 전역
- **상징**: 불교의 핵심 상징 — 진흙에서 피어나는 청정, 극락정토(極樂淨土)
- **기록**: 백제·신라 사찰 연지(蓮池), 금동대향로 연꽃 문양
- **작중 활용**: 사찰 장면, 불교 의례, 왕비·공주의 비유

#### 무궁화 (Rose of Sharon, 槿)
- **학명**: *Hibiscus syriacus*
- **분포**: 한반도 전역
- **기록**: 중국 기록에 신라를 "근화향(槿花鄕, 무궁화의 나라)"으로 호칭
- **작중 활용**: 신라의 상징, 국가 정체성 장면

#### 진달래 (Azalea, 杜鵑)
- **분포**: 한반도 산야 전역, 봄철 군락
- **용도**: 식용(화전), 약용
- **작중 활용**: 봄 풍경, 향수·고향의 정서

#### 모란 (Peony, 牡丹)
- **상징**: 부귀영화(富貴榮華)
- **기록**: 선덕여왕(善德女王) 일화 — 당 태종이 보낸 모란 그림에 나비가 없어 향기가 없을 것을 예지
- **작중 활용**: 선덕여왕 에피소드, 궁궐 정원

## 5. 신화적 의미를 가진 동식물

### 5.1 호랑이 (虎) — 산신(山神)

한국 신화에서 호랑이는 산의 신, 혹은 산신의 사자(使者)로 숭배되었다.
- 단군 신화: 호랑이와 곰이 함께 동굴 시험 → 호랑이는 인내하지 못해 탈락
- 산신도(山神圖): 호랑이를 동반한 산신의 도상
- **작중 상징**: 용맹하나 인내 부족, 무인(武人)의 양면성, 산중 수행자의 시험

### 5.2 곰 (熊) — 단군의 어머니

단군 신화의 웅녀(熊女)는 곰에서 인간으로 변환한 존재로, 한민족의 시조모(始祖母)이다.
- 100일 동안 쑥과 마늘만 먹고 인간이 됨
- **작중 상징**: 인내, 변신, 모성(母性), 민족적 근원

### 5.3 삼족오 (三足烏) — 태양

고구려 고분벽화에서 태양 안에 삼족오가 그려져 있다.
- 동아시아 태양 숭배의 보편적 상징
- 고구려 왕실은 태양의 후예를 자처
- **작중 상징**: 고구려 왕권, 태양신 숭배, 하늘의 뜻

### 5.4 용 (龍) — 왕권

용은 수신(水神)이자 왕권의 상징이다.
- 삼국 모두 왕의 탄생·죽음에 용 출현 기록
- 황룡(黃龍)은 최고 길상, 청룡·백룡도 기록
- 문무왕(文武王)은 죽어서 동해의 용(護國龍)이 됨
- **작중 상징**: 왕의 권위, 바다·강의 수호, 천명(天命)

### 5.5 거북 (龜) — 장수·예지

- 김수로왕(金首露王) 탄강 신화: 거북아 거북아 머리를 내어라(龜何龜何 首其現也)
- 거북 점(龜卜): 등껍질을 가열하여 금(裂紋)으로 점치는 방법
- **작중 상징**: 예언, 장수, 왕의 탄생과 관련된 신비

### 5.6 뱀 (蛇) — 토착 신앙

- 집의 수호신(업, 蛇神), 곳간의 지킴이
- 탈해왕(脫解王) 신화에 뱀 관련 요소
- **작중 상징**: 토착 신앙, 민간 신앙, 이중성(수호/위험)
