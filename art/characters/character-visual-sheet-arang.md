## 1. 기본 외형 사양

### 신체 정보

```
이름     : 아랑 (雅琅, Arang)
나이     : 20세 (시즌 1 기준, 612년)
성별     : 여성
신장     : 165cm
체중     : 약 50kg (문관·지식인 체형)
체형     : 날렵하고 균형 잡힌 — 실내 문서 작업 특화 체형
           과도한 근육 없음 / 우아한 곡선 실루엣
손       : 섬세하고 긴 손가락 — 붓 사용으로 발달된 오른손 필압 근육
           손가락 끝 옅은 먹물 자국 (문서관의 표식, 씻어도 안 지워짐)
자세     : 평소 허리 꼿꼿이 — 왕실 문서관 예의 / 앉을 때 두 손 무릎
```

### 얼굴 특징

```
전체 인상  : 총명하고 차분한 백제 귀족 문관 — 나이보다 성숙한 지적 분위기
얼굴형     : 계란형 — 부드럽되 뚜렷한 선
피부       : 백자(白磁) 같은 흰 피부 — 실내 문서 작업 (햇볕 차단)
             광택감 없는 고운 흰 피부 (#F0E8D8 베이지 화이트)
눈         : 쌍꺼풀 있는 부드러운 눈 / 홍채색 짙은 갈색에 황금빛 반점
             총명함과 깊이가 동시에 흐르는 눈빛
눈썹       : 가늘고 섬세한 아치형 — 백제 귀족 여성 전형
코         : 오뚝하고 단정한 코 — 고구려보다 부드러운 인상
입         : 작고 단정한 입술 / 감정 억제 시 굳게 다문 직선
             자주 약간 열어 무언가 생각하는 표정
이마       : 깨끗하고 넓은 이마 — 은비녀로 정리된 헤어라인

식별 특징:
  - 손가락 끝 먹물 자국 (오른손 검지·중지 안쪽 도드라짐)
  - 항상 붓을 품 안 또는 귀 옆에 꽂아둠
  - 문서를 읽을 때 눈을 살짝 가늘게 뜨는 습관
  - 왼쪽 귀 유리구슬 귀걸이 (상시 착용, 백제 유리 공예 특유의 청록색)
```

### 머리카락

```
색       : 깊은 흑갈색 (#1C1208)
질감     : 부드럽고 윤기 있음 — 매일 정돈

스타일 기준:
  기본    : 차분하게 올린 머리 (고계 高髻 변형)
            뒷통수 위쪽 고정 / 앞머리 없음 (이마 노출)
  고정    : 은비녀 (靑銀, 푸른빛 은 재질) — 봉황 문양 소형 양각
            추가 비녀: 백옥 소형 비녀 (의례 시)
  잔머리  : 귀 앞으로 한두 가닥 흘러내림 (완벽하지 않은 인간미)

시즌별 변화:
  S1      : 간결한 쪽머리 (견습 문서관 / 낮은 신분 표시)
  S2      : 정식 고계 + 은비녀 (정식 문서관 임명 후)
  S2 중반 : 관모 추가 착용 (여성 문관 공식 관모 — 검은 비단)
  S3      : 격동 속에서 헤어가 흐트러지는 씬 허용 (인간성 노출)
```

## 3. 복식 상세 사양

### A. 일상 / 문서관 복식 (기본)

```
상의    : 비취 (#2E8B57) 유(襦) — 고구려보다 긴 소매 / 우아한 라인
          소매 끝 왕실금 단 장식 (봉황 연속 문양 자수)
하의    : 군(裙) — 비취 바탕 / 긴 치마, 발끝까지
          주름 풍성 — 걸을 때 흘러내리는 실루엣
겉옷    : 반비(半臂) — 소매 없는 조끼형 상의 착용 (문서 작업 중)
          왕실금 (#B8960C) 비단 재질
허리    : 세요대(細腰帶) — 가는 왕실금 허리띠
          문서관 인장 장식 소형 패물 (오른쪽 허리)
신발    : 백자 비단 이(履) — 조용한 걸음새 (실내 전용)
장신구  : 왼쪽 귀 유리구슬 귀걸이 (청록, 상시 착용)
         : 오른손 검지 먹물 자국 (제거 불가)
         : 은비녀 (상투 고정)
소품    : 붓 (귀 옆 또는 품 안) / 두루마리 (품 안 상시 소지)
```

### B. 정식 문서관 복식 (S2 이후)

```
포(袍)   : 비취 → 왕실금 비단 포로 격상 (정식 임명 후)
           소매 넓어짐 — 문관 권위 표시
           깃 부분: 봉황 금사 자수 (향 오른쪽 깃)
관모     : 여성 문관 전용 관모 — 검은 비단 / 소형 금동 장식
           (남성 복두와 구별되는 낮은 납작한 형태)
허리     : 금동제 과대 — 문서관 인장 + 왕실봉황 버클
봉황 단검:
  위치   : 오른쪽 허리 (호신용, 문서관 정식 복식에 포함)
  길이   : 전장 35cm (위협용 아닌 호신용 — 단검 수준)
  장식   : 손잡이 봉황 두(頭) 조각 (금동)
  날     : 항상 광택 (실제 사용보다 상징적)
신발     : 흑색 비단 이(履) — 금동 버클 / 공식 행사용
```

### C. 외교 예복 (사절단 동행 시)

```
포(袍)   : 왕실금 최고급 비단 포 — 바탕 왕실금 / 봉황 전면 자수
           S2 외교 씬 최고급 등장
관모     : 관식(冠飾) — 금동 봉황 장식 관 (최고 등급)
장신구   : 금제 귀걸이 — 심엽형 백제 전통
           금팔찌 (오른쪽 손목) — 무령왕릉 기반 양식
           봉황 흉배 (가슴 중앙 수놓음)
신발     : 금동 장식 비단 이(履) — 발목 보이지 않는 길이

소품 (외교 시):
  두루마리 케이스: 금동제 케이스 (왕실 서신 보관)
  봉인 반지       : 오른쪽 약지 — 왕실 인장 반지 (왁스 봉인용)
```

## 4. 특징적 소품 상세

### 전용 무기 — 「봉황 단검 (鳳凰 短劍)」

```
공식명칭 : 봉황 단검 (Bphoenix Dagger)
용도     : 호신용 — 실전보다 위협 및 상징 목적
재질     : 날 철제 / 손잡이 금동 + 상아 기저
길이     : 전장 35cm (날 22cm)
날 형태  : 단면도 (單面刀) — 직선 날
손잡이   : 봉황이 날개를 펼치는 조각 (정면 시 봉황 날개가 손 보호대 역할)
칼집     : 검은 가죽 + 금동 장식 테두리
무게     : 약 0.4kg
보관     : 오른쪽 허리 / 외교 시 칼집 포함 공개 착용

시각적 포인트:
  - 봉황 조각: 두 눈 부분에 루비색 유리 눈 박힘
  - 날: 날 위 「雅琅之劍」한자 음각 (아랑의 검)
  - 칼집: 연꽃 문양 금동 장식 (백제 불교 상징)
  - 아랑이 꺼내는 장면은 위기의 신호 (희소성 = 임팩트)
```

### 보조 소품

```
붓과 묵통:
  붓      : 백호 털 붓 / 자루 대나무
  묵통    : 소형 흑칠 묵통 (오른쪽 허리 소품홀더)
  상태    : 약간 닳은 붓끝 — 수천 자 기록의 흔적
  의미    : 아랑의 정체성 = 기록하는 자

두루마리:
  재질   : 비단 두루마리 (품 안) — 중요 내용 암호화 기록
  겉보기 : 평범한 빈 두루마리처럼 보임 (위장)
  의미   : 포토그래픽 메모리 메모 / 왕실 기밀 메모리 보조

왕실 인장 반지:
  위치   : 오른쪽 약지 (외교·공식 씬)
  재질   : 금 + 봉황 인장면
  의미   : S2 문서관 승급 후 지급 → 귄위와 책임의 상징

유리구슬 귀걸이:
  위치   : 왼쪽 귀만 (오른쪽 없음 — 비대칭 의도)
  색     : 청록 (#1ABC9C) 반투명 유리구슬
  형태   : 구슬 3개 체인 (백제 전통 형태)
  의미   : 어머니 유품 — 감정 표출 억제 시에도 절대 빼지 않음
  창작   : 백제 무령왕릉 유리 구슬 출토 유물에서 영감
```

## 5. 표정·감정 스펙 (5종)

### 기본 표정 규칙

```
아랑의 표정은 계산되어 있다.
감정을 드러낼 때조차 어디까지 드러낼지 선택한다.
충동적 표정 = 캐릭터 파괴 (절대 금지).
분노도, 기쁨도, 슬픔도 — 항상 한 겹의 필터를 거친다.
```

### 표정 1 — 관찰 (Observation) ★기본값

```
눈      : 약간 가늘게 뜬 눈 — 모든 것을 스캔하는 총명한 눈빛
          홍채 황금빛 반점이 빛에 따라 가시화
눈썹    : 살짝 올라간 아치 — 흥미와 분석 사이
입      : 약간 열린 입 — 「다음 질문」을 준비하는 상태
          또는 굳게 다문 직선 (중립 상태)
자세    : 고개 5° 기울임 (왼쪽 방향) — 듣고 분석하는 자세
전체    : 「당신을 이미 파악했다」는 무언의 압박감

아트 디렉션:
  눈빛에 항상 「다음을 알고 있는 여유」유지
  문서를 읽는 것처럼 상대를 읽는 눈빛
```

### 표정 2 — 결의 (Resolve) ★핵심 표정

```
눈      : 완전히 뜬 눈 — 정면을 정확히 응시
눈썹    : 완전히 수평 — 아치 없이 직선화
입      : 굳게 다문 직선 / 입꼬리 아래로
자세    : 고개 약간 뒤로 — 물러서지 않는 자세
손      : 두루마리를 꽉 쥐거나 붓을 단단히 잡음
전체    : 「역사를 만들기로 결심한 기록자」

대표 장면: 의자왕에게 직언하는 순간 / 고루에게 첫 서신 발송 결심
```

### 표정 3 — 분노 (Controlled Fury) ★냉정한 분노

```
주의    : 아랑의 분노는 절대 폭발하지 않는다. 더 차가워진다.

눈      : 완전히 뜬 눈 + 홍채 수축 — 레이저 시선
눈썹    : 수평 완전 직선화 / 아치 완전 소멸
입      : 굳게 다문 / 입꼬리 완전히 수평 또는 아래
목소리  : (표정 외 지원) 낮아지고 느려지는 음성
자세    : 더 꼿꼿하게 — 완전한 문관 예의 자세로 역설적 분노 표현
손      : 붓을 조용히 내려놓는 동작 (분노의 신호)
전체    : 「가장 무서운 것은 목소리를 높이지 않는 것」

금지    : 고함, 눈물, 물건 던지기 — 아랑의 분노는 침묵과 정밀함
```

### 표정 4 — 슬픔 (Concealed Grief) ★숨기는 슬픔

```
눈      : 평상시보다 약간 더 넓게 열림 — 방어 무너지는 순간
눈빛    : 초점이 흐트러져 먼 곳을 향함
눈썹    : 중앙이 약간 위로 — 억제 직전 감정
입      : 굳게 다물려 하나 아랫입술 미세 떨림 (극도 절제)
동작    : 어머니 유품 귀걸이를 오른손으로 조용히 만짐
전체    : 표정보다 손 동작이 슬픔을 더 많이 말함

대표 장면: 어머니 기일 / 백제 멸망 예감 씬 / 고루 서신에서 솔직함을 느낄 때
아트 디렉션:
  눈물 허용 기준: S3 이후 단 한 장면 (백마강 씬)
  그 이전은 반드시 참음 — 귀걸이 만지는 손 동작으로 대체
```

### 표정 5 — 희미한 기쁨 (Subtle Joy) ★드물게 등장

```
빈도    : 전체 에피소드에서 15회 미만 (진짜 기쁠 때만)
```

## 6. 캐릭터 포즈 스펙 (기본 3종)

### 포즈 1 — 정면 기본 (Standard Front)

```
용도    : 캐릭터 카드 / 피규어 정면 기준 / 프로필

자세    :
  발    : 11자 발 — 발 모아 서기 (문관 예의 자세)
  무릎  : 곧게 — 긴장 없음
  허리  : 꼿꼿이 — 왕실 예의
  어깨  : 수평, 살짝 뒤로 당김 (자신감 있는 문관)
  팔    : 오른팔 — 두루마리 가슴 앞 수직 쥠
          왼팔 — 오른팔 아래를 받쳐 지지
  시선  : 정면 응시 / 관찰하는 눈빛
  턱    : 살짝 올림 (권위 있는 자세)
  표정  : 관찰 (표정 1번)

배경 기준 색: 왕실금 (#B8960C) 그라디언트 → 백자백 (#F5F5DC)
```

### 포즈 2 — 측면 독서 (Profile Reading)

```
용도    : 캐릭터 시트 측면 / 실루엣 확인 / 아랑 핵심 이미지

자세    :
  방향  : 오른쪽 측면 (90° — 오른쪽이 카메라)
  발    : 오른발 약간 앞 / 자연스러운 실내 서기
  허리  : 곧음
  팔    : 두 팔 앞으로 모아 두루마리 펼쳐 읽는 중
  고개  : 약간 숙여 두루마리 집중
  시선  : 두루마리 (카메라 밖) / 눈 살짝 가늘어짐
  표정  : 집중·관찰 (표정 1번 독서 변형)

실루엣 체크포인트:
  군(裙) 치마 흘러내리는 곡선 실루엣
  고계 머리의 우아한 높이
  두루마리 수평이 손에서 부드럽게 곡선
```

### 포즈 3 — 결의 동작 (Decisive Moment)

```
용도    : 드라마 포스터 / 게임 스플래시 / 아랑 핵심 키아트

자세    :
  기본  : 반 측면 (3/4 우측 앞 방향 — 카메라를 향하되 비틀림)
  발    : 오른발 한 발짝 앞 — 걷다가 멈춘 자세
  허리  : 약간 카메라 방향으로 비틀림
  어깨  : 오른어깨 앞 / 살짝 긴장
  팔    : 오른팔 — 봉황 단검 손잡이에 오른손이 닿아 있음 (뽑지 않은)
          왼팔 — 두루마리를 옆에 끼고 있음
  시선  : 카메라 정면 / 결의 눈빛 (표정 2번)
  표정  : 결의 (표정 2번)

전투 모드 비주얼 추가:
  의복  : 망토 아래 봉황 단검 칼집 가시화
  머리  : 약간 흐트러진 상태 허용 (S2 이후 행동 씬)
  배경  : 백마강 또는 사비성 왕실 문서고

카메라 앵글 제안:
  메인키아트: 약간 위 앵글 (눈높이 + 20cm) → 지적 권위감
  웹툰 컷   : 정면 또는 3/4 앵글
  게임 스플래시: 3/4 앵글 (오른쪽 앞 45°)
```

```
  키아트  : 사비성 외교 씬 / 고루 서신 장면

  키아트  : 백마강 씬 (눈물 허용 — S3 단 한 번)
```
