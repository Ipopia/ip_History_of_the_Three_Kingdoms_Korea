## 삼국시대 공통 문화

### 종교·신앙

```
불교 (佛敎):
고구려 수용: 372년 (전진 순도 — 삼국유사)
백제 수용: 384년 (동진 마라난타)
신라 공인: 527년 (이차돈 순교)
가야: 불교 기록 희박 — 수로왕 허황옥 불교 전설

불교의 사회적 역할:
- 왕실 권위 강화 (왕즉불 사상)
- 사찰 = 문화·교육 중심
- 불교 미술 발달 (불상·범종·금동 공예)

IP 적용:
드라마 사찰 씬: 황룡사·능산리 사찰 고증
아랑 씬: 백제 불교 의례 장면
고루 씬: 고구려 불교 (삼족오 + 불교 공존 문화)

토속 신앙 (무교·샤머니즘):
불교 이전부터 존재 — 이후에도 공존
무당(巫堂)·무격(巫覡): 왕실 제의 참여
천지신·강신·산신 숭배
선덕여왕 예언 = 무교적 예지 전통과 불교 혼합

도교 (道敎):
고구려: 영류왕 대 당나라 도사 초청 (연개소문 반발)
→ IP: 고루 씬 — 연개소문의 도교 배격이 쿠데타의 일부
```

### 의례·제천 행사

```
고구려 동맹 (東盟):
시기: 음력 10월
내용: 수렵 후 하늘에 제사
특징: 온 나라가 모여 음주·가무
기록: 삼국지 위서 동이전

백제 교천 (郊天):
시기: 봄·가을 2회
왕이 직접 하늘에 제사
의례 복식: 왕실 금동관 + 흰 포

신라 팔관회 (八關會):
불교 + 토속 혼합 제의
11월 개최 — 귀족·평민 참여

가야 구지가 제의:
구지봉 정상 — 수로왕 탄생 제의 재현
노래+춤+제물 — 매년 봄 거행

IP 활용:
드라마 절기 씬: 각 왕국 명절·제의 장면
게임: 절기 이벤트 (봄·가을·겨울) — 특수 유닛 등장
뮤지컬: 구지가 집단 제의 무대 장면
```

### 장례 풍속

```
고구려 묘제:
석실 고분 + 벽화 (귀족 전용)
순장: 초기 기록 있음 (후기 약화)
부장품: 마구·무기·식기

백제 묘제:
횡혈식 석실묘 (수평 통로형)
무령왕릉 = 벽돌묘 (중국 양나라 영향)
부장품: 금제 관식·대도·유리 장신구

신라 묘제:
적석목곽분 (자갈 + 나무 곽)
황남대총·금관총 = 신라 묘제 대표
금관·금귀걸이 다량 부장

가야 묘제:
수혈식 석곽묘 (수직 구덩이형)
판갑·철기 대량 부장
대성동 고분군 = 가야 묘제 집약

IP 활용:
드라마: 장례 씬 — 왕국별 묘제 차이
게임: 영웅 전사 시 왕국별 장례 이벤트
아트: 묘제 단면도 배경 일러스트
```

## 왕국별 생활문화

### 고구려 생활

```
일상 생활:
주거: 온돌 사용 (발굴 고고학 확인)
식사: 조·기장·콩 + 수렵 육류
복식: 유고(襦袴) — 유는 짧고 고는 폭 넓음
     철제 장신구, 좌임(左衽) 논쟁

군사 문화:
어릴 때부터 활쏘기·말타기 교육
경당(扃堂): 고구려 학교 — 미혼 자제 교육 기관
  학습: 경전·활쏘기
  의미: 문무 일체 교육

풍속:
사냥: 귀족 놀이이자 군사 훈련
격구(擊毬): 말 위에서 공 치기 (삼국유사 기록)
씨름: 평민 놀이 (무용총 씨름도)

언어·문자:
한자 사용 (공문서·비문)
고구려어: 현재 소수 단어만 전함
이두(吏讀) 전 단계 한자 활용

IP 고루 생활:
아침: 마구간 점검 → 기마 훈련
식사: 기장밥 + 수렵 고기
저녁: 성벽 순찰 + 전술 검토
```

### 백제 생활

```
일상 생활:
주거: 사비성 기와집 (귀족) / 초가 (서민)
식사: 쌀밥 + 서해 어물
복식: 비단 + 세련된 금동 장신구
     백제 특유의 우아한 선 (무령왕릉 유물)

귀족 문화:
한자 교육: 삼국 중 가장 발달 (왕인의 논어 일본 전파)
음악·예술: 백제 악무단이 일본에 파견 (일본서기)
외교 예법: 정교한 외교 의례 (다국 교류)

평민 생활:
농업: 금강 유역 곡창 지대
어업: 서해 어업 발달
시장: 사비성 상설 시장

IP 아랑 생활:
새벽: 문서관 등불 켜기 → 전날 기록 검토
아침: 왕실 조회 기록
낮: 외교 문서 번역·정리
밤: 새로운 정보 분석 + 개인 기록
```

### 신라 생활

```
일상 생활:
주거: 경주 분지 기와집 (귀족) / 초가 (서민)
식사: 쌀 + 경주 분지 농산물
복식: 황금 장신구 — 귀족의 일상 착용

화랑도 (花郞道):
구성: 화랑(花郞, 지도자) + 낭도(郎徒, 추종)
세속오계 (世俗五戒):
  ① 사군이충(事君以忠): 충성
  ② 사친이효(事親以孝): 효도
  ③ 교우이신(交友以信): 신의
  ④ 임전무퇴(臨戰無退): 용기
  ⑤ 살생유택(殺生有擇): 생명 존중

화랑 일상:
유람(遊覽): 산천 유람 → 심신 수련
음악·시: 향가(鄕歌) 창작·향유
무예: 활·검·마술 수련
불교: 원광법사 가르침

향가 (鄕歌):
신라 고유 시가 — 한자 이두 표기
현존: 삼국유사 수록 14수
예: 서동요(薯童謠)·헌화가(獻花歌)·처용가(處容歌)

IP 하린 생활:
새벽: 화랑 아침 수련 (활+검)
낮: 유람 + 또래 화랑과 교류
저녁: 향가 창작 (하린의 감성 면모)
```

### 가야 생활

```
일상 생활:
주거: 낙동강변 수상 또는 강변 주거 (반지하 + 목조)
식사: 어업 + 쌀·조
복식: 실용적 평민 복식 + 철제 장신구

제철 문화:
가야인의 자부심 = 철
대장간: 가야의 중심 산업
아이들: 제철 소리 들으며 성장
철 = 화폐이자 자존심

음악 문화:
가야금: 귀족~서민 향유
우륵 이후 12악곡 전국 보급 (562년 이전)
강변 음악 문화 — 낙동강변 연주

가야 정체성:
연합 왕국 — 여러 가야 소국 느슨한 연합
중앙집권 부재 → 신라·백제 압박에 취약
멸망 이후 가야 유민: 신라 편입 + 전통 유지

IP 니문 생활:
새벽: 낙동강 강변 가야금 연습
낮: 신라 궁중 악사 업무
저녁: 가야 유민 공동체 방문 (할아버지 기억)
밤: 12번째 악곡 작업
```

## 교육·지식 체계

```
고구려:
경당 (扃堂): 교육 기관 — 삼국 중 가장 이른 기록
태학 (太學): 귀족 자제 국립 학교 (소수수림왕 372년)
교육: 오경(五經)·사서(史書)·한문·무예

백제:
박사 제도 (博士制度): 유학·의학·역학 전문가 양성
왕인 박사: 논어·천자문 일본 전파 (일본서기)
의박사·역박사: 전문 분야별 박사

신라:
화랑도 교육: 세속오계 + 유람 + 무예
국학 (國學): 682년 설립 (IP 시대 이후)

가야:
문자 기록 희박 — 구전 전통 강함
악사 교육: 가야금 + 우륵 악곡 구전

IP 캐릭터와 교육:
고루: 경당 출신 (15세 이전) + 군사 교육
아랑: 백제 박사 문하 + 왕실 사관 수업
하린: 화랑도 + 원광법사 세속오계
니문: 할아버지 가야금 구전 교육
```

## 음식 문화 고증

```
공통 식재료:
곡식: 쌀·조·기장·보리·콩·팥
채소: 무·배추 전신·부추·마늘
단백질: 돼지·닭·소 (귀족) / 어패류 (서민)
음료: 탁주 (막걸리 전신) / 쑥차·국화차

왕국별 특색:
고구려: 수렵 고기 (사슴·멧돼지·토끼) 중심
백제: 어물 (조기·새우젓·갈치) + 농산물
신라: 쌀밥 + 경주 분지 과일·채소
가야: 낙동강 민물고기 + 남해 해산물

귀족 식사:
식기: 금동 식기 (백제 무령왕릉) / 토기 (일반)
좌식 문화: 상(床) 위에 식기 배치
상차림: 주식(밥) + 국 + 반찬 3~5종

IP 드라마 식사 씬:
왕궁: 금동 식기 + 비단 상보
문서관 (아랑): 소박한 나무 식기 + 밥+국
군진 (고루): 야전식 — 건반·소금·육포
강변 (니문): 토기 밥그릇 + 강에서 잡은 생선
```

## 언어·문자 문화

```
문자 체계:
한자 (漢字): 삼국 공통 공문서 언어
이두 (吏讀): 한자를 한국어 표기에 활용 (신라 발달)
구결 (口訣): 한문 독해 보조 표기

삼국별 언어:
고구려어: 부여계 언어 — 현재 소수 어휘만 전함
백제어: 마한계 + 고구려 영향 — 일본어와 유사 단어 있음
신라어: 진한계 — 한국어의 직접 조상
가야어: 변한계 — 신라어와 유사

문서 형식:
공문서: 세로 쓰기 + 한자
개인 서신: 두루마리 + 붓글씨
비문: 화강암·현무암 직접 각인

IP 캐릭터 언어 설정:
고루: 고구려어 + 한자 (군사 문서)
아랑: 백제어 + 6개 언어 능통 (외교관 설정)
하린: 신라어 + 향가 창작 (이두 활용)
니문: 가야계 억양 있는 신라어 + 음악 용어

캐릭터 간 언어 소통:
삼국 귀족: 한자 교육 공통 → 서면 소통 가능
구어 소통: 어휘 차이 있지만 의사소통 가능 (창작 설정)
아랑: 6개 언어 통역 역할 → 외교·소통 장면 활용
```

## 놀이·오락 문화

```
귀족 오락:
격구 (擊毬): 말 위에서 스틱으로 공 치기 (고구려)
수렵 (狩獵): 사냥 — 오락이자 훈련
향가 창작: 신라 귀족 문화
음주·가무: 전 왕국 공통 (동맹·팔관회)

서민 오락:
씨름 (相撲): 무용총 씨름도 — 고구려 서민 대중 놀이
줄다리기·그네: 여름 절기 놀이
공기놀이: 고대 형태 존재 추정

음악·공연:
가야금 연주: 귀족~서민 향유 (가야→신라)
향악 (鄕樂): 고구려·백제·신라 고유 음악
산악 (散樂): 잡기·놀이 (중국에서 전래)

IP 활용:
드라마 여흥 씬: 격구·씨름·음주·가무 장면
게임 수렵 미션: 격구·수렵 미니게임
체험관: 씨름 체험 (고구려 존)
```
