## 축제·풍속 개요

```
삼국시대 주요 의례:
  제천 의식: 하늘에 제사 (국가적 최대 의례)
  농경 의례: 파종·수확 (민간 최대 축제)
  불교 의례: 연등·법회 (불교 공인 후)
  전사 의례: 출전·개선 (군사 문화)

IP 활용 원칙:
  행사 = 캐릭터 내면을 드러내는 배경
  축제 = 전쟁 전·후의 대비 장치
  의례 = 각 왕국 문화 정체성 표현
```

## 고구려 축제·풍속

### 동맹 (東盟) — 최대 국가 제전

```
시기: 10월 (음력)
성격: 제천 의식 + 사냥 + 전사 능력 시험
규모: 전국 귀족·장군 집결

의례 순서:
  1일차: 국동대혈(國東大穴) 수신 제사
  2일차: 기마·궁술 경연
  3일차: 왕 주관 잔치

IP 활용:
  고루 등장 배경: 을지문덕이 고루를 동맹에서 처음 보고 발탁
  「창법보다 눈빛이 먼저였다」을지문덕 대사
  살수대첩 전 마지막 동맹: 고루의 내면 독백 장면

음식:
  맥적 (貊炙): 고기 구이 (현재 불고기 원형)
  서속 (黍粟): 조·기장 술
  야채: 순채·미나리 (산지 특산)
```

### 고구려 일상 풍속

```
주거:
  온돌 (溫突): 바닥 난방 시스템 (고구려 발명)
  고루 캐릭터: 온돌 방에서 전략 지도 펼치는 장면

복식:
  남성: 저고리+바지+포 (바지 기마용)
  군인: 찰갑 위에 포 착용
  색: 귀족 = 청·흑, 평민 = 백·회

혼례:
  서옥제 (婿屋制): 신랑이 신부 집에서 살다가 독립
  IP 활용: 고구려 배경 로맨스 서브플롯 설정 참고

장례:
  고분 문화: 석실 무덤 + 벽화 (삼족오 등)
  부장품: 철제 무기·금동 장식
```

## 백제 축제·풍속

### 소도 의례 (蘇塗 儀禮)

```
성격: 신성 구역 설치 + 하늘 신 제사
특징:
  소도 = 법 밖의 신성 공간 (도망자도 잡지 못함)
  천군 (天君): 제사 전담 사제

IP 활용:
  아랑 어머니: 소도 인근 귀족 → 무속 문화 친숙
  아랑의 자수 패턴: 소도 문양 포함 (삼각·원 결합)
  낙화암 장면: 소도 정신 — 「이곳은 신성하다」
```

### 백제 불교 의례

```
연등 (燃燈) 행사:
  시기: 음력 정월 보름
  형식: 왕궁 → 민간 등불 점화
  규모: 사비성 전체 등불

IP 활용:
  아랑 첫 등장 배경: 연등 행사 밤
  금동대향로 향기 + 연등 빛 = 백제 문명의 절정
  사비성 함락 직전 마지막 연등: 대비적 미장센

미래사 법회:
  80m 9층 목탑 앞 대규모 법회
  아랑의 정기 방문지 (종교+예술 공간)
```

### 백제 일상 풍속

```
복식:
  여성 귀족: 저고리+치마+대란치마 (비단)
  색: 황금·연지·비취 (귀족), 백·회 (평민)
  아랑: 연지색 비단 저고리 + 비취 치마 기준

음식:
  김치 전신: 소금 절임 채소 (삼국시대 존재)
  해산물: 서해 어패류 (백제 풍요)
  발효 음식: 장류·젓갈 (백제 기원)

공예:
  금세공: 백제 최고 수준
  칠기: 옻칠 목기 (일본에 기술 전수)
  아랑 자수: 이 공예 전통의 연장
```

## 신라 축제·풍속

### 화랑 입단식

```
시기: 봄 (매년)
성격: 화랑 낭도 신규 입단 의례
장소: 왕경 중심 광장

의례 순서:
  1: 풍월주 앞 맹세 (나라 위해 죽겠다는 서약)
  2: 검·활 소지 허가 의식
  3: 선배 화랑과 수련 맹약

IP 활용:
  하린 화랑 입단식: S1 첫 장면 후보
  관창 입단식: 하린 목격 → 복선
  「화랑이 된다는 것은 죽음을 각오하는 것」
```

### 팔관회 (八關會)

```
시기: 음력 11월 보름
성격: 불교 행사 + 국가 의례 혼합
특징: 전사한 병사 위령 + 풍요 기원

의례:
  황룡사 대법회
  전사자 위패 봉안
  음악·무용 공연 (가야금 포함)

IP 활용:
  황산벌 전투 후: 관창 위패 → 하린 참석
  하린의 죄책감 폭발 장면 배경
  니문이 팔관회에서 가야금 연주 → 4인 우연히 같은 자리 (S3 복선)
```

### 신라 일상 풍속

```
골품제 문화:
  신분에 따라 의복 색·가옥 크기 법으로 규제
  하린 = 6두품 → 진골 귀족 행사에 참가 제한적

화랑 생활:
  집단 수련: 명산 순례·시 짓기·음악
  「세속오계 (世俗五戒)」준수:
    事君以忠 (충으로 군주 섬기기)
    事親以孝 (효로 어버이 섬기기)
    交友以信 (신의로 벗 사귀기)
    臨戰無退 (전쟁에서 물러나지 않기)
    殺生有擇 (살생에 선택이 있다)
```

## 가야 축제·풍속

### 제철 의례

```
시기: 제철 작업 시작 전 (봄)
성격: 용광로 신(火神) 제사 + 철 품질 기원
특징: 가야 = 철이 곧 종교적 대상

의례:
  용광로 앞 돼지 제사
  첫 철정 (鐵鋌) 공물로 바침
  철장 장인의 노래 (구전 전통)

IP 활용:
  니문 어린 시절 기억: 아버지의 제철 의례
  가야금 12현 = 철사 → 철이 소리가 된 것
  「철을 두드리는 소리와 가야금 소리는 같다」
```

### 수로왕 제사 (수릉왕묘)

```
시기: 봄·가을 2회
성격: 가야 건국왕 김수로 제사 + 민족 정체성 확인
특징: 가야 멸망 후에도 신라 땅에서 유민들이 유지

IP 활용:
  니문 참석: 가야 유민 공동체 결속 행사
  「나라는 사라졌지만 제사는 남는다」
  니문의 죽간에 수릉왕묘 기록 포함
```

### 가야 일상 풍속

```
음악 문화:
  가야금 = 일상 의례·연회 필수 악기
  우륵 전통: 음악 = 나라를 위한 것
  니문의 연주: 일상 vs 의례 구분

복식:
  황토 삼베 (귀족도 소박)
  맨발 or 짚신 (니문 특징)
  장신구: 철제 팔찌·귀걸이 (가야 철 문화)

거주:
  낙동강 변 집락
  용광로와 인접 주거
  니문 가족: 음악인 + 철공 복합 생활
```
