## OST 개요

```
프로젝트명: 삼국(三國) OST — 「기억의 강 / River of Memory」
총 트랙 수: 시즌 1 기준 32곡 (보너스 포함 38곡)
장르: 시네마틱 오케스트라 + 국악 크로스오버
메인 테마: 「강은 기억한다 / THE RIVER REMEMBERS」
주요 악기: 가야금·해금·대금·피리 + 현악 오케스트라
제작: 사운드본부 음악팀 (SND-MUSIC) + 외부 오케스트라 협업
```

## DISC 1 — 메인 테마 & 왕국 테마

### 트랙 01 — 「기억의 강 / The River Remembers」(메인 테마)

```
장르: 시네마틱 오케스트라 + 가야금
길이: 4분 12초
편성: 풀 오케스트라 + 가야금 솔로 + 합창
조성: D단조 → D장조 (전환)

구성:
  00:00~00:45 — 가야금 솔로 도입 (니문 테마 변형)
  00:45~01:30 — 현악기 합류 (강물 모티프)
  01:30~02:30 — 오케스트라 전개 (4왕국 테마 제시)
  02:30~03:15 — 클라이맥스 (합창 + 전체 오케스트라)
  03:15~04:12 — 가야금 솔로 코다 (에필로그적 여운)

사용:
  드라마 오프닝 타이틀 시퀀스
  시즌 완결 엔딩
  콘서트 오프닝·피날레
```

### 트랙 02 — 「철과 하늘 / Iron Sky」(고구려 테마)

```
장르: 국악 + 타악 + 오케스트라
길이: 3분 28초
편성: 북·징·꽹과리 + 해금 + 금관악기
조성: E단조

특징:
  타악 리듬: 강하고 규칙적인 군사 행진 리듬
  해금 선율: 날카롭고 투지 넘치는 멜로디
  전개: 도입부 고요함 → 전투적 클라이맥스

사용:
  고구려 왕국 오프닝 씬
  살수대첩 전투 배경음
  고루 주요 결의 장면
```

### 트랙 03 — 「연등과 죽간 / Lantern & Bamboo」(백제 테마)

```
장르: 실내악 + 가야금 + 플루트
길이: 3분 55초
편성: 현악 사중주 + 가야금 + 피리
조성: G장조 (서정적·따뜻)

특징:
  선율: 유려하고 학구적 분위기
  리듬: 붓으로 글씨 쓰는 듯한 점진적 흐름
  중간부: 연등 모티프 (물결처럼 출렁이는 현악)

사용:
  백제 사비성 등장 씬
  아랑 기록 장면 배경음
  연등 행사 시퀀스
```

### 트랙 04 — 「황금 들판 / Golden Field」(신라 테마)

```
장르: 웅장한 오케스트라 + 해금
길이: 4분 02초
편성: 전체 오케스트라 + 해금 솔로
조성: A장조 (밝고 역동)

특징:
  도입: 해금 솔로 (하린 테마)
  전개: 오케스트라 팽창 (화랑 행진 리듬)
  클라이맥스: 황금빛 느낌의 금관 파열

사용:
  신라 금성(경주) 전경 씬
  하린 화랑 활약 장면
  황산벌 전투 전 긴장 빌드업
```

### 트랙 05 — 「소멸하는 소리 / Fading Sound」(가야 테마)

```
장르: 국악 미니멀리즘
길이: 4분 48초
편성: 가야금 솔로 + 소금 + 소편성 현악
조성: F#단조

특징:
  전체적 음량: 피아니시모 위주
  가야금 현 음: 길게 울리다 사라지는 잔향
  서서히 단순해지는 구조 (소멸 표현)

사용:
  가야 멸망 플래시백 씬
  니문 독주 장면
  시즌 피날레 에필로그
```

특징: 유려한 멜로디 — 지적·서정적 균형
사용: 아랑 죽간 기록 씬, 도서관 탐색

### 트랙 10 — 「을지문덕의 시 / Eulji's Verse」

```
길이: 3분 00초

## DISC 3 — 전투 & 액션

### 트랙 11 — 「살수대첩 / Battle of Salsu」

```
길이: 6분 45초
편성: 풀 오케스트라 + 타악 앙상블
구성:
  00:00~01:00 — 긴장감 (수나라 진군 모티프)
  01:00~03:00 — 전투 전개 (타악 폭발)
  03:00~04:30 — 수문 개방 (현악 급류 표현)
  04:30~06:45 — 승전 클라이맥스
사용: 살수대첩 전투 시퀀스 (에피소드 전체)
```

### 트랙 12 — 「황산벌 결전 / Last Stand at Hwangsanbeol」

```
길이: 7분 15초
편성: 오케스트라 + 군악 + 합창
특징: 5,000 결사대 비장함 표현
구성:
  도입: 느린 행진 (죽음을 각오한 진격)
  전투: 격렬한 타악 + 금관
  결말: 비탄의 현악 (패전 후 비가)
사용: 황산벌 전투 전편 배경음
```

### 트랙 13 — 「기벌포의 파도 / Waves at Gibeolpo」

```
길이: 5분 30초
편성: 오케스트라 + 타악 + 해금
특징: 해전 특유의 파도·바람 음향 통합
구성:
  22라운드 연속 해전 BGM용 모듈 구조
  각 모듈 30초 루프 가능
사용: 기벌포 해전 22연승 시퀀스
```

### 트랙 14 — 「관창의 돌격 / Gwanchang's Charge」

```
길이: 3분 20초
편성: 현악 + 타악 (급격한 템포)
특징: 16세 소년 화랑의 용기 — 짧고 강렬
사용: 관창 특공 씬 전용
```

### 트랙 15 — 「안시성 방어 / Defense of Ansi」

```
길이: 4분 55초
편성: 금관 + 타악 + 오르간
특징: 방어전 특유의 중후하고 완강한 느낌
사용: 고구려 안시성 전투 시퀀스
