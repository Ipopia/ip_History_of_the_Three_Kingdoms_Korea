## 환경 디자인 철학

```
핵심 원칙:
  「공간이 시대를 말한다」

3대 원칙:
  1. 역사 고증 우선: 7세기 실제 건축·자연 기반
  2. 왕국 차별화: 시각적으로 즉각 구별 가능
  3. 감정 공간: 배경이 캐릭터 심리 반영

참조 문화권:
  고구려: 중국 고분 벽화 + 북방 유목 문화 + 한국 토착
  백제: 불교 건축 + 황해 무역 문화 + 남방 세련미
  신라: 불교 + 골품제 왕권 문화 + 황금 장식
  가야: 남부 토착 + 철기 산업 + 자연 중심
```

## 왕국별 환경 디자인

### 고구려 환경

```
색채 팔레트:
  주색: 철회색 (#4A4A4A) + 청람 (#2F4F7F)
  보조: 흑색 (#1A1A1A) + 산색 (#5B7A6E)
  강조: 불꽃 주황 (#CC5500) — 봉화·횃불

건축 양식:
  성벽: 대형 석재 장방형 쌓기 (안악 고분 벽화 참조)
  지붕: 맞배지붕 + 치미 (鴟尾) 장식
  기둥: 원형 목주 + 붉은 단청 (간소한 문양)
  내부: 고구려 고분 벽화 문양 — 사신도(四神圖) 적용

자연 환경:
  지형: 산악 70% — 가파른 능선·계곡
  강: 압록강·대동강·살수 (청람 계통)
  식생: 침엽수 위주 (소나무·전나무)
  날씨: 안개·눈·서리 다용 (냉기 강조)

조명 설계:
  주 조명: 차가운 자연광 (5500K~6500K)
  새벽: 청백 역광 → 실루엣 강조
  봉화: 따뜻한 불꽃 대비 (냉랭함 속 온기)

대표 장소:
  평양성 내성 — 웅장한 석성 + 안학궁
  살수 강변 — 안개 낀 새벽 강물
  안시성 — 절벽 위 요새 (고립감)
```

### 백제 환경

```
색채 팔레트:
  주색: 황금 (#B8960C) + 담청 (#7BA7BC)
  보조: 연꽃 분홍 (#E8A0A0) + 오동나무 갈색 (#8B6914)
  강조: 등불 황색 (#FFD466) — 야경 장면

건축 양식:
  사원: 미래사 9층 목탑 (백제 목조 건축 최고봉)
  궁궐: 사비 왕궁 — 정제된 구조 + 금동 장식
  지붕: 팔작지붕 + 화려한 단청 (금동 치미)
  회랑: 연꽃 문양 기둥 받침

자연 환경:
  지형: 금강 유역 평야 + 완만한 구릉
  강: 금강·백마강 (담청~황금 계통)
  식생: 활엽수 (느티나무·버드나무) + 연꽃
  날씨: 따뜻한 빛 + 황혼 빈번 사용

조명 설계:
  주 조명: 따뜻한 황금빛 (4000K~4500K)
  연등 야경: 등불 수백 개 자연 조명
  황혼: 금강 수면 반사 황금빛

대표 장소:
  사비성 왕궁 — 황금빛 단청 + 금동 장식
  문서관 — 촛불 + 죽간 더미 + 향 연기
  미래사 목탑 — 사비성 스카이라인 중심
  낙화암·백마강 — 비극적 아름다움
```

### 신라 환경

```
색채 팔레트:
  주색: 금빛 (#FFD700) + 자주 (#7B2D8B)
  보조: 청동색 (#8B7355) + 기와 회색 (#9E9E9E)
  강조: 불꽃 + 황산벌 황토 (#C8A96E)

건축 양식:
  황룡사: 9층 목탑 (82m 추정) — 신라 최대 건축
  월성: 반월형 왕궁 (자연 구릉 활용)
  첨성대: 원형 석조 천문대 (독특한 형태)
  귀족 가옥: 기와 + 황금 장식 + 담장

자연 환경:
  지형: 경주 분지 (평지 + 낮은 산 둘러싸임)
  식생: 소나무 + 낙엽활엽수 혼재
  날씨: 밝고 맑은 날 선호 (신라 황금문명 표현)
  전장: 황산벌 황토 평야 (드라마 클라이맥스)

조명 설계:
  주 조명: 따뜻하고 밝은 황금빛 (4500K~5000K)
  훈련장: 이른 아침 역광 → 화랑 역동감
  황산벌: 황혼 전투 — 붉은 황금빛 극대화

대표 장소:
  경주 화랑 훈련장 — 밝고 역동적
  황룡사 경내 — 웅장한 신앙 공간
  황산벌 전장 — 광활한 황토 평야
  기벌포 해안 — 새벽 서해 (피날레)
```

### 가야 환경

```
색채 팔레트:
  주색: 황토 (#C8A96E) + 남색 (#2C3E50)
  보조: 갈대 갈색 (#A0785A) + 철회색 (#5A5A5A)
  강조: 낙동강 석양 주황 (#E8720C)

건축 양식:
  건물: 가야 고분 주변 소규모 부락 형태
  고분: 봉분형 무덤 (가야 정체성 상징)
  단순한 목조 가옥 (화려함 없이 기능 중심)
  철정 제련소 — 가야 산업 정체성

자연 환경:
  지형: 낙동강 중하류 — 강 + 갈대밭
  강: 낙동강 (황토빛 강물 — 석양 황금빛 반사)
  식생: 갈대·억새 + 대나무 군락
  날씨: 황혼 빈번 사용 (쓸쓸함·사라짐 감성)

조명 설계:
  주 조명: 황토빛 황혼 (3500K~4000K)
  연주 씬: 사이드 조명 → 가야금 현 반짝임
  고분 씬: 달빛 + 차가운 조명 (과거의 영광)

대표 장소:
  낙동강 강변 — 니문 연주 주요 무대
  대가야 고분군 — 사라진 나라의 흔적
  철정 제련소 유적 — 가야 산업 영광
  남해 포구 — 가야-왜 교역 무대
```

## 계절별 환경 설계

```
봄 (화랑 훈련·입단 시즌):
  벚꽃 + 연두빛 신록
  신라 훈련장: 벚꽃 날리는 장면
  색온도: 밝고 따뜻 (5000K + 분홍 파티클)

여름 (살수대첩·전투 시즌):
  깊은 녹음 + 습한 안개
  살수 강물: 여름 수위 최고 (전략 핵심 표현)
  색온도: 청록 + 습기 (청량감 + 위협)

가을 (황산벌·수확 시즌):
  붉은 단풍 + 황토 평야
  황산벌: 황금빛 수확 후 황토 → 피의 전장
  색온도: 황금 + 붉은 (아름다움 + 비극)

겨울 (고구려 방어·전략 시즌):
  눈 + 얼음 + 서리
  안시성 전투: 눈 속 방어전 (용기 극대화)
  색온도: 차갑고 청백 (고립·의지)

676년 기벌포 (피날레):
  새벽 직전 가장 어두운 시각 → 동틀 녘
  서해 수평선 위 금빛 선 등장
  「모든 왕국의 색이 하나로 합쳐지는 빛」
```

## 전투 환경 설계

```
살수 강변 전투 환경:
  안개 입자: 강물 위 새벽 물안개 (볼류메트릭)
  조명: 청백 역광 → 수나라 대군 실루엣
  수문 개방 후: 강물 범람 → 환경 급변

황산벌 전투 환경:
  황토 평야 + 먼지 파티클
  황혼 조명 → 황금빛 비극
  전투 후: 조용해진 벌판 + 바람 소리만

기벌포 해전 환경:
  서해 새벽 바다 + 안개
  함선 불꽃 → 수면 반사
  최종 승리 순간: 안개 걷히며 새벽 빛
```
