# 게임 서사 설계 — 삼국(三國) IP

**참조 문서**: `game-design-document.md`, `master-bible.md`, `character-profiles.md`, `chronicles.md`
**작성**: 게임본부 기획팀 (GAME-PLAN)
**적용**: 삼국(三國) IP 게임 서사 구조·분기·캐릭터 아크 설계 기준

## 게임 서사 철학

```
핵심 원칙:
  「역사는 사실, 선택은 당신의 것」

게임 서사 3원칙:
  1. 역사 결과 불변: 살수대첩·황산벌·기벌포 결과는 고정
  2. 경로 분기 가능: 어떻게 그 결과에 이르는가는 플레이어가 선택
  3. 캐릭터 성장 = 플레이어 성장: 4인 아크가 플레이어 윤리적 판단 반영

서사 장르:
  역사 전략 RPG + 비주얼노벨 하이브리드
  전략 맵 → 캐릭터 서사 → 전투 → 후일담 순환 구조
```

## 메인 캠페인 구조

### 캠페인 1 — 「살수의 전략가」(고루)

```
시대: AD 598~612년
메인 미션 수: 12개
서브 미션: 8개

서사 흐름:
  ACT 1 (미션 1~4): 요동 방어선 구축
    → 수나라 1차 침략 격퇴 (역사 사건 체험)
    → 고루: 을지문덕 만남 + 전략 수업 시작
    → 분기: 「정면 대응」vs「유인 작전」

  ACT 2 (미션 5~9): 살수 방어 준비
    → 수나라 2차 침략 (612년 113만 대군)
    → 을지문덕 오언시 사건 (역사 재현)
    → 수문 준비 미션: 타이밍 전략 결정

  ACT 3 (미션 10~12): 살수대첩 클라이맥스
    → 수문 개방 시점 선택 (최적 타이밍 미니게임)
    → 2,700명 귀환 결말 (고정)
    → 고루 엔딩 분기:
      A. 「전략가의 길」: 을지문덕 후계자로 성장
      B. 「강의 증인」: 전쟁의 허무함을 깨닫고 강변을 떠남

핵심 도덕적 선택:
  「수나라 항복 병사를 살려주는가?」
  → 살림: 정보 획득 + 고루 인간성 +
  → 죽임: 전력 소모 감소 + 고루 냉혹함 +
```

### 캠페인 2 — 「사비성의 기록자」(아랑)

```
시대: AD 641~660년
메인 미션 수: 10개
서브 미션: 10개 (기록 수집형)

서사 흐름:
  ACT 1 (미션 1~3): 백제 궁정 기록관
    → 의자왕 집권 초기 백제 전성기
    → 아랑: 공식 기록 vs 진실 기록 갈등
    → 외교 문서 필사 중 나당연합 밀약 발견

  ACT 2 (미션 4~7): 백제의 위기
    → 나제동맹 붕괴 후 신라의 공세
    → 아랑: 기록을 숨기기 vs 드러내기 선택
    → 사비성 함락 직전 탈출 준비

  ACT 3 (미션 8~10): 황산벌과 사비성의 마지막
    → 황산벌 전투 (측면 시점 — 아랑은 전투 참여 안함)
    → 사비성 함락 → 탈출 or 기록 보존 선택
    → 아랑 엔딩 분기:
      A. 「기억의 수호자」: 죽간 보존 → 후세에 전달
      B. 「증인의 길」: 포로로 잡혀 백제 기록을 신라에 전달

특수 미션: 「기록 수집」
  백제 각지 숨겨진 역사 문서 수집
  완전 수집 시: 비밀 아카이브 해금 (역사 자료 열람)
```

### 캠페인 3 — 「화랑의 맹세」(하린)

```
시대: AD 647~676년
메인 미션 수: 15개 (최다)
서브 미션: 12개

서사 흐름:
  ACT 1 (미션 1~5): 화랑 성장기
    → 선덕여왕 재위 말기 화랑 훈련
    → 관창과의 우정 심화
    → 진덕여왕 즉위 → 무열왕 (김춘추) 나당연합 결정

  ACT 2 (미션 6~10): 삼국 통일 전쟁
    → 660년 황산벌: 관창 사망 이벤트 (불가피)
    → 하린: 복수 vs 의무 갈등
    → 668년 고구려 멸망 참전
    → 분기: 「당나라를 신뢰한다」vs「당나라를 의심한다」

  ACT 3 (미션 11~15): 나당전쟁
    → 670년 나당전쟁 발발
    → 기벌포 22연승 (연속 해전 시퀀스)
    → 676년 최종 통일 완성
    → 하린 엔딩 분기:
      A. 「신라의 검」: 통일 영웅으로 귀환
      B. 「전쟁의 증인」: 승리했지만 모든 것을 잃은 전사

핵심 도덕적 선택:
  「나당연합 = 배신인가, 생존인가?」
  하린의 최종 철학 결정 → 결말 영향
```

### 캠페인 4 — 「가야의 소리」(니문)

```
시대: AD 650~676년
메인 미션 수: 8개 (최소, 서정 집중)
서브 미션: 15개 (탐험·음악 수집형)

서사 흐름:
  ACT 1 (미션 1~3): 유민의 방랑
    → 낙동강 유역 가야 유민 마을
    → 할아버지의 가야금 + 기억 전수
    → 신라 세금 문제 → 떠남 결정

  ACT 2 (미션 4~6): 전쟁의 목격자
    → 황산벌 근처 → 전쟁 목격
    → 하린과 아랑을 돕는 선택 (선택적)
    → 니문: 「왜 나는 싸우지 않는가?」내면 탐구

  ACT 3 (미션 7~8): 기벌포와 마지막 가야금
    → 676년 기벌포 해안 도착
    → 마지막 「676」가야금 연주
    → 니문 엔딩 (단일): 「소리는 기억한다」
      → 모든 캠페인 완료 시 해금되는 특별 결말

특수 미션: 「가야금 수집」
  한반도 각지 잊혀진 가야 멜로디 수집
  12곡 완성 시: 「676」풀 버전 가야금 연주 해금
```

## 4인 교차 서사 — 크로스오버 미션

```
교차 이벤트 (사전 지정):

CROSS-01 「처음 만난 강변」(3캠페인 완료 후):
  4인이 처음으로 같은 장소에 모이는 이벤트
  각자의 캠페인 달성도에 따라 대화 내용 변화

CROSS-02 「황산벌에서」(하린 ACT 2 + 아랑 ACT 3 동시 조건):
  황산벌 전투 후 하린과 아랑 만남
  아랑: 기록을 건네는 이벤트
  하린: 관창 죽음 슬픔 공유

CROSS-03 「676 피날레」(전 캠페인 완료):
  4인 기벌포 해안 집결
  니문 마지막 가야금
  「강은 기억한다」합동 엔딩 씬
  → 진 엔딩: 모든 캠페인 A 엔딩 달성 시만 해금
```

## 분기 시스템

```
선택지 구조:
  즉각 선택: 전투 중 전술 결정 (5초 제한)
  숙고 선택: 캠프 장면 대화 (제한 없음)
  누적 선택: 반복 선택이 캐릭터 성향 결정

성향 시스템 (각 캐릭터):
  고루: 「전략가(냉철)」↔ 「인간주의(온화)」
  아랑: 「기록자(객관)」↔ 「행동가(주체적)」
  하린: 「충성(신라 우선)」↔ 「정의(보편적)」
  니문: 「기억(과거)」↔ 「미래(새 시작)」

성향 영향:
  캐릭터 성향 → 대사 변화
  동료 캐릭터와의 관계도 변화
  최종 엔딩 결말 결정
```

## 역사 이벤트 재현

```
필수 재현 이벤트 (결과 고정):
  살수대첩 (612): 고구려 대승 — 변경 불가
  안시성 전투 (645): 당 패퇴 — 변경 불가
  황산벌 전투 (660): 백제 패배 — 변경 불가
  기벌포 22연승 (676): 신라 승리 — 변경 불가

플레이어 영향 가능 요소:
  아군 사상자 수 (전략 최적화에 따라)
  동맹 관계 강도 (선택에 따라)
  역사 인물 생존 (일부 서브 캐릭터)
  캐릭터 내면 성장 방향

역사 이탈 방지 시스템:
  역사와 모순되는 선택 시 경고 팝업
  「역사는 이 길을 선택했습니다」안내
  역사 보존 모드: 역사 정확도 최우선 설정 옵션
```

## 보조 캐릭터 서사

```
을지문덕 (고루 캠페인):
  고루의 스승 + 살수대첩 실제 지휘관
  플레이어가 직접 조종 불가 (NPC)
  대사: 한시 인용 다수 (고증)

계백 (아랑·하린 캠페인):
  황산벌 결사대 지휘관
  비극적 영웅 — 악인 아님
  하린 캠페인에서 최종 대결 (하린 승리 고정)

관창 (하린 캠페인):
  하린의 가장 친한 벗
  황산벌에서 반드시 사망 (역사 고정)
  사망 씬: 감정 최고조 연출
  이후: 하린의 동기 원천
```
