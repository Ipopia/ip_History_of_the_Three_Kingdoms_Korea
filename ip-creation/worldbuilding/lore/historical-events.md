```
표기 기준:

삼국(三國) IP 서사 시간 범위:
  주 서사: 612년 ~ 676년 (을지문덕 시대 ~ 기벌포 전투)
  배경 역사: BC 57년 ~ 676년 (삼국 건국 ~ 통일)
  스핀오프: 562년 ~ (가야 멸망) / 475년 ~ (백제 한성 함락)
```

## 삼국 건국 연표 (BC~4세기)

```
BC 57년: 신라 건국 (삼국사기 기준)
  - 박혁거세 거서간, 경주 일대
  - 6촌 연합 → 사로국(斯盧國) → 신라

BC 37년: 고구려 건국
  - 주몽(東明聖王), 졸본 부여 탈출
  - 비류수(沸流水) 유역 졸본성 건국

BC 18년: 백제 건국
  - 온조왕, 한강 유역 위례성
  - 고구려계 이민 집단 → 마한 지역 정착

~42년: 가야(伽耶) 건국
  - 수로왕(首露王) 금관가야 건국 (김해)
  - 6가야 연맹 형성

4세기:
  313년: 고구려 낙랑군 축출 (중국 군현 완전 제거)
  346년: 백제 근초고왕 즉위 → 전성기 시작
  371년: 백제 근초고왕 → 고구려 고국원왕 전사 (평양 전투)
  375년: 백제, 일본 문화 전수 시작 (불교·한자)
```

## 5~6세기 연표 — 삼국 각축

```
427년: 고구려 평양 천도 (장수왕)
  - 남하 정책 공식화
  - 백제·신라 압박 시작

433년: 나제동맹(羅濟同盟) 성립
  - 신라·백제 동맹 → 고구려 견제
  - 이후 120년간 유지

475년: 고구려, 백제 한성(漢城) 함락
  - 장수왕 3만 군대
  - 백제 개로왕 전사 → 백제 웅진(공주) 천도
  - 백제 위기 시작 (가야 스핀오프 활용 가능)

494년: 부여(夫餘) 고구려 흡수
  - 고구려 북방 완전 통합

512년: 신라 우산도(독도) 복속
  - 이사부 장군, 우산국 정벌

527년: 신라 불교 공인 (이차돈 순교)
  - 법흥왕, 불교 도입 → 왕권 강화

532년: 금관가야 신라 복속
  - 구형왕 자진 항복
  - 가야 연맹 분열 시작

538년: 백제 사비 천도 (성왕)
  - 웅진(공주) → 사비(부여) 이동
  - 백제 중흥 시도

551년: 나제동맹 → 한강 유역 탈환
  - 신라·백제 공동 한강 북쪽 고구려 축출

553년: 신라, 백제 배신 → 한강 유역 단독 점령
  - 나제동맹 사실상 붕괴
  - 이후 백제·신라 적대 관계

554년: 관산성 전투 — 백제 성왕 전사
  - 신라 기습 → 백제 성왕 전사
  - 백제·신라 깊은 원한 관계 시작

562년: ★ 가야(大伽耶) 신라 복속 — 가야 최종 멸망
  - 니문 조부 세대의 사건
  - 우륵(于勒): 신라로 귀화, 가야금 12곡 전수
  - 니문 서사의 출발점: 「562년부터였다. 50년이 흘렀다.」

589년: 수(隋) 중국 통일
  - 남북조 시대 종결 → 대규모 외침 위험 고조
  - 고구려: 수나라와 긴장 관계 시작
```

## 7세기 전반 — 수·당 침략 시대

```
598년: 수·고구려 1차 전쟁
  - 수 문제 30만 대군 → 고구려 침략
  - 고구려 방어 성공 (수군 폭풍·육군 보급 실패)
  - 을지문덕 등장 준비 시기 (배경)

612년: ★ 수·고구려 2차 전쟁 — 살수대첩(薩水大捷)
  IP 서사 시작점
  - 수 양제 친정: 113만 대군 (과장 포함)
  - 실제 전투 병력: 약 30~50만 추정
  - 을지문덕 전략: 7번 후퇴 → 보급 고갈 → 살수 유인
  - 결과: 수나라 대패 → 30만 중 수천만 생존 (기록)
  - IP 서사: 1권·시즌 1 Arc 1~2

613~614년: 수·고구려 3·4차 전쟁
  - 수나라 재침략 → 또 실패
  - 수나라 내부 반란 → 멸망 가속

618년: 수나라 멸망 → 당(唐) 건국
  - 이연(李淵) 당 고조 즉위
  - 고구려: 새로운 위협 등장

627년: 당 태종 이세민 즉위
  - 정관의 치(貞觀之治) — 당나라 전성기
  - 고구려에 대한 침략 야욕 시작

631년: 고구려, 천리장성(千里長城) 축조 시작
  - 연개소문 주도
  - 당나라 침략 대비 방어선 (16년 공사)

632년: 신라 선덕여왕 즉위 (27대)
  - 한국 역사 최초 여왕
  - 하린 서사 배경 시작

641년: 백제 의자왕 즉위
  - 초기: 용맹한 왕 (고구려·신라 공격 성공)
  - 이후 방탕 → 성충 직간 → 투옥

642년: ★ 연개소문 쿠데타
  IP 서사 시즌 2 시작점
  - 음력 10월, 평양성
  - 영류왕 시해 + 귀족 100여명 처단
  - 보장왕 옹립 → 연개소문 대막리지 취임
  - 고루 서사: 최대 딜레마 씬

645년: ★ 안시성 전투
  - 당 태종 30만 대군 친정
  - 요동성·개모성 함락 후 안시성 공략
  - 안시성 88일 방어 → 당 태종 철수 (9월)
  - 양만춘(추정) 성주 활약
  - 야사: 당 태종 화살에 눈 맞음
  - 고루 서사의 클라이맥스 (시즌 2)

647년: 신라 선덕여왕 사망
  - 비담의 난 진압 중 사망
  - 하린 서사: 최대 상실 씬 (하린의 첫 울음)
  - 진덕여왕 즉위 (신라 두 번째 여왕)

648년: 나당(羅唐) 동맹 체결
  - 김춘추(金春秋) 당나라 방문
  - 조건: 신라 조공 증가 ↔ 당 군사 지원
  - 하린 서사: 도덕적 갈등 최고조

654년: 신라 태종무열왕(김춘추) 즉위
  - 최초의 진골 왕
  - 나당 연합 실행 준비
```

## 7세기 후반 — 삼국 멸망 시대

```
655년: 고구려·백제·말갈, 신라 33성 공격
  - 신라 위기 고조 → 나당 연합 가속

656년: ★ 성충(成忠) 투옥
  - 의자왕에게 나당 연합 경고 직간
  - 의자왕 노여움 → 투옥
  - 아랑 서사: 스승과의 마지막 대면

659년: 성충 옥중 사망
  - 옥중 상소: 「나당 연합이 온다, 탄현과 기벌포를 지켜라」
  - 의자왕이 끝내 듣지 않음
  - 아랑 서사: 홀로 남겨진 기록자

660년: ★ 황산벌 전투 + 백제 멸망
  - 7월: 계백 5천 결사대 vs 신라 5만
  - 관창 전사 → 신라군 사기 반전
  - 계백 전사 → 백제군 붕괴
  - 8월: 나당 연합군 사비성 포위
  - 9월: 의자왕 항복 → 백제 멸망
  - 아랑·하린 서사 클라이맥스

661년: 나당 연합, 고구려 2차 공격 시작
  - 당나라 35만 + 신라군 북상
  - 고구려 방어 지속

662년: 나당 연합군 평양성 포위 실패 (1차)
  - 겨울 추위 + 보급 문제 → 철수

663년: 백강 전투(白江口 戰鬪)
  - 백제 부흥군 + 왜군 vs 나당 연합군
  - 백제 부흥 완전 실패 → 백제 역사 종결
  - 아랑 서사: 마지막 기록

666년: ★ 연개소문 사망
  - 아들 연남생·연남건·연남산 내전 시작
  - 연남생 당나라에 투항 → 고구려 붕괴 가속
  - 고루 서사: 연개소문의 예언이 실현되는 순간

668년: ★ 고구려 멸망
  IP 서사 최종 클라이맥스
  - 나당 연합군 평양성 포위·함락
  - 보장왕 항복 → 고구려 멸망
  - 당: 안동도호부(安東都護府) 설치 → 한반도 직할 시도
  - 고루 서사: 최종 독백 「강은 기억한다」

670년: 신라, 당나라에 반격 시작
  - 고구려 부흥 세력 지원 + 백제 고토 점령
  - 나당 전쟁 시작

676년: ★ 기벌포 전투 → 나당 전쟁 종결
  IP 서사 최종 완결
  - 신라 수군, 금강 하구에서 당 수군 격퇴
  - 당나라 군대 한반도에서 완전 축출
  - 신라 삼국통일 (대동강 이남)
  - 하린 서사: 「이제야 끝났다」

698년: 발해(渤海) 건국
  - 고구려 유민 대조영 → 만주에 발해 건국
  - 고구려의 계승 의식 (IP 시즌 3 이후 확장 가능)
```

## IP 서사 핵심 이벤트 요약

```
시즌 1 (소설 1권):
  ① 612년 살수대첩 → IP 서사 시작·클라이맥스

시즌 2 (소설 2권):
  ② 642년 연개소문 쿠데타
  ③ 645년 안시성 전투
  ④ 647년 선덕여왕 사망
  ⑤ 660년 황산벌·백제 멸망

시즌 3 (소설 3권):
  ⑥ 668년 고구려 멸망
  ⑦ 676년 기벌포·나당 전쟁 종결

가야 스핀오프:
  ⑧ 562년 가야 멸망 → 니문 조부 세대

외전 가능 이벤트:
  475년 한성 함락 (고구려·백제 관계)
  554년 관산성 전투 (백제·신라 원한)
  527년 이차돈 순교 (신라 불교 공인)
```
