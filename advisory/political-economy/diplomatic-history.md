## 7세기 동아시아 국제 질서

### 패권 구조

```
중심 세력:
  수나라 (581~618): 단기 패권 — 중국 재통일
  당나라 (618~907): 장기 패권 — 동아시아 최강국

주변 세력:
  고구려: 동아시아 중강국 (수·당과 직접 충돌)
  백제: 중강국 (황해 무역권)
  신라: 중소국 → 나당연합으로 도약
  가야: 소국 (일찍 멸망)
  왜(倭): 동방 소국 → 점차 성장
  돌궐: 북방 유목 강국 (당나라와 대립)

한반도 3국 국제 위상 (AD 600년경):
  고구려: 독립 강국 — 수·당의 주요 적
  백제: 교역 중심국 — 중국·왜 사이 중계자
  신라: 취약 동맹국 — 고구려·백제 양면 압박
```

### 동아시아 외교 원칙 (삼국시대)

```
조공책봉 체제 (朝貢冊封 體制):
  중국 황제 → 주변국 왕 책봉
  주변국 → 중국에 정기 조공
  실질 의미:
    형식적 복속 + 무역 독점권 확보
    전쟁 억제 외교적 도구

고구려 특수성:
  독자 연호 사용 (영락·延壽 등) → 사실상 황제국 자처
  수·당에 형식적 조공 → 실질 독립 유지
  「책봉」수용 vs 독자 연호 = 이중적 외교 전략

백제 외교 다변화:
  당·수나라 조공 → 외교 완충
  왜(倭) → 문화 전파 + 군사 동맹 가능성
  가야 → 철기 무역
  신라 → 동맹(나제동맹) → 적대 전환
```

## 삼국 양자 관계

### 고구려—백제 관계

```
기원:
  같은 부여계 → 혈연적 동질성
  고구려 건국 → 백제 분리 건국 (일설: 주몽의 자손)

전성기 고구려 vs 백제 충돌:
  371년: 근초고왕 → 평양성 공격, 고국원왕 전사
  → 고구려의 치욕, 이후 100년 적대

중기 협력:
  여제동맹(麗濟同盟): 신라 압박을 위한 고구려-백제 연대
  545년~655년 (단속적)
  한계: 과거 적대 → 신뢰 부족, 언제든 와해 가능

말기:
  연개소문 집권 후 외교 경직
  642년: 연개소문 정변 → 고구려 내부 혼란
  백제 독자 행동 증가 (나당연합 대응 실패 요인)

IP 활용:
  고루-아랑 관계: 적국이지만 인간적 연대
  「나라는 달라도 우리는 같은 시대를 살고 있다」
```

### 고구려—신라 관계

```
초기 (4~5세기):
  광개토대왕 남정 (400년): 신라 구원 → 고구려 영향력 확대
  신라 내물왕 = 고구려 속방(屬邦) 수준

중기:
  신라 자립 의지 강화 → 고구려 견제
  나당연합 이전: 고구려·백제 양면 공격에 신라 고립

말기:
  나당연합 vs 고구려 = 직접 전쟁
  668년 고구려 멸망 = 신라 주도 달성

IP 활용:
  고루—하린 관계: 전쟁에서는 적, 인간으로는 연대
  서로의 용기를 인정하는 장면 (나당전쟁 전후)
```

### 백제—신라 관계

```
나제동맹 (羅濟同盟, 433~553년):
  배경: 고구려 압박 → 양국 공동 대응
  120년 동맹 지속

554년 관산성 전투 (성왕 전사):
  신라 진흥왕의 배신 → 백제 한강 유역 빼앗김
  성왕(聖王) 전사 → 120년 동맹 붕괴
  → 이후 백제-신라 = 불구대천의 원수

660년 멸망까지:
  황산벌: 백제 계백 vs 신라 김유신
  나당연합 vs 백제 = 백제 멸망

IP 활용:
  아랑—하린 관계: 원수의 나라지만 개인적 연대
  「나라가 싸워도 사람이 미워할 이유는 없다」
```

### 가야 국제 관계

```
가야 연맹 특성:
  단일 통합 왕국 없음 → 대가야·금관가야 등 연맹
  독자 외교 능력 제한

주요 관계:
  왜(倭) → 가장 중요한 교역 파트너
  가야 철정 수출 → 왜 금·쌀 수입
  백제 → 정치적 우호 (대신라 공동 이익)
  신라 → 압박·흡수 대상

멸망 과정:
  400년: 광개토대왕 군사 원정 → 금관가야 타격
  532년: 금관가야 신라 항복
  562년: 대가야 신라에 멸망

IP 활용:
  니문 = 멸망 후 세대 유민
  가야 = 국가 없는 민족 → 기억으로만 존재
  니문과 신라인 하린 관계: 가해자—피해자 후손 관계 (미묘한 긴장)
```

## 한반도—중국 외교사

### 수나라와의 관계

```
4차에 걸친 수-고구려 전쟁:

1차 침략 (598년):
  계기: 고구려 영양왕의 요서(遼西) 선제 공격
  결과: 수나라 원정 실패 (보급 문제)

2차 침략 (612년) — 살수대첩:
  규모: 113만 대군
  결과: 고구려 완전 승리 (2,700명 귀환)
  영향: 수 양제 위신 실추 → 수 멸망 직결 원인

3차 (613년)·4차 (614년) 침략:
  모두 실패
  613년: 내부 반란으로 철수
  614년: 협상 철수

역사적 의의:
  고구려 = 수나라 멸망 원인 중 하나
  동아시아 세력 균형 재편
```

### 당나라와의 관계

```
당 태종과 3차례 전쟁:
  1차 (645년): 안시성 전투 — 당 패퇴
  2차 (647년): 소규모 원정 — 실패
  3차 (648년): 다시 실패

연개소문 사후 내분:
  666년 연개소문 사망
  아들들 권력 투쟁 → 연남생 당에 투항
  → 고구려 방어 체계 붕괴

668년 고구려 멸망:
  나당연합군 + 연남생 길잡이
  평양성 함락

나당전쟁 (670~676년):
  신라의 당 도전
  기벌포 해전 22연승 → 당군 철수
  676년: 사실상 한반도 신라 통일 완성
```

## 한반도—일본 외교사

### 백제—왜(倭) 관계

```
문화 전파 루트 (백제 → 왜):
  4세기 말~7세기:
  불교: 552년 성왕 → 긴메이 왕 불상·경전 전달
  한자: 4~5세기 박사(博士) 파견
  기술: 도기·칠기·농업 기술
  유학: 왕인(王仁) 천자문·논어 전달

군사 동맹 (선택적):
  663년 백강구 전투:
    왜군 27,000 + 선박 400척 → 백제 지원
    나당연합군에 패배 → 왜 대화(大化) 개신 직결

IP 활용:
  아랑의 자수 = 백제 문화가 왜에 전해진 루트
  「내 손의 문양이 바다 너머 섬나라에도 남을 것이다」
```

### 가야—왜 관계

```
철정 무역 루트:
  가야 철정 → 대마도 → 왜 각지
  왜 = 가야 철정 없으면 농기구·무기 생산 불가

「임나(任那)」논쟁:
  일본서기: 임나일본부(任那日本府) 존재 주장
  한국 학계: 강력 반박 — 실질 식민지 아님
  현재 학계 통설: 교역 거점·연락 사무소 수준

IP 방침:
  임나일본부설 내용 수용 금지
  표현: 「가야-왜 교역 거점」으로 표현
```

## 창작 외교 서사 활용 포인트

```
외교 장면 구성 시:

1. 조공사절 장면:
   백제 사절이 중국 황궁에 조공 → 「형식적 복속」긴장
   아랑의 시각: 「나라의 자존심을 꺾어서라도 살아남아야 하는가?」

2. 동맹 협상 장면:
   나당연합 협상 (648년 김춘추 입당):
   하린 시각: 「당나라를 불러들이는 것이 진정한 승리인가?」

3. 멸망 외교 장면:
   백제 의자왕 항복 협상 → 아랑 시각 서술
   고구려 보장왕 항복 → 고루 증언 서술

4. 나당전쟁 외교:
   신라의 당나라 배신 → 하린의 윤리적 갈등
   「동맹을 배신한 우리가 옳은가?」
```
