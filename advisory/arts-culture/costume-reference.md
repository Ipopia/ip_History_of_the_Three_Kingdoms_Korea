## 복식 고증 원칙

```
삼국(三國) IP 복식 3원칙:

1. 역사 고증 우선:
   고분 벽화·문헌·유물 기반 재현
   상상 가미 시 「창작 추가」표시

2. 왕국별 차별화:
   고구려: 무인 실용성 + 웅장함
   백제: 귀족 우아함 + 화려한 공예
   신라: 금 장식 + 화랑 상징성
   가야: 소박함 + 철 장신구

3. 계급 표시 철저:
   색상·소재·장식으로 신분 즉각 식별
   색상 코드 = 아트바이블 왕국 색 기준
```

## 고구려 복식

### 남성 복식 체계

```
기본 구성 (상류층):
  저고리 (赤古里):
    길이: 무릎 위 (짧고 기능적)
    깃: V자 또는 교령 (交領)
    색: 귀족 = 청·흑, 관리 = 홍·청, 평민 = 백·회
    소매: 좁고 직선 (기마에 적합)

  바지 (袴):
    특징: 넉넉한 통바지 (기마용)
    발목 결박: 행전(行纏)으로 고정
    색: 귀족 = 흑·청, 평민 = 백

  포 (袍):
    외투용 긴 겉옷
    귀족: 비단·모피 장식
    군인: 찰갑(札甲) 위에 착용

군인 복식 (고루 참조):
  찰갑 (札甲):
    소철판을 가죽끈으로 엮은 갑옷
    고루: 흑색 찰갑 + 삼족오 문양 (IP 창작 설정)
    실제 고증: 고분 벽화 기마 무사도 참조

  투구:
    변형 (弁形) — 앞이 넓고 뒤가 좁은 형태
    귀갑 장식 (귀족 장군만)
    고루: 투구 없음 (IP 설정 — 삼족오 나머지로 구분)

  환두대도 (環頭大刀):
    손잡이 끝에 고리 (環) 장식
    귀족만 소지 가능
    길이: 90~110cm
    고루: 왼손잡이 (미확정 → ART-CHAR 확정 후 적용)
```

### 여성 복식

```
귀족 여성:
  저고리 + 치마 기본 구성
  치마: 길고 풍성 (상체 낮음 → 치마 위)
  색: 황·홍·청 (비단)

고분 벽화 기준 (수산리 고분 등):
  머리: 쪽진 머리 + 금동 비녀
  목걸이: 금·옥 구슬
  허리띠: 금동 버클
```

## 백제 복식

### 귀족 복식 (아랑 참조)

```
여성 귀족 기본:
  저고리 (短衣):
    길이: 허리까지 (고구려보다 짧음)
    소매: 넓은 소매 (우아함 강조)
    깃: 둥근 깃 또는 교령
    색: 연지·비취·황금 (비단 필수)
    아랑: 연지색 비단 저고리 (IP 확정)

  치마 (裳):
    길이: 발끝까지 (풍성한 주름)
    대란치마 스타일: 여러 폭 연결
    색: 비취·연청·황금
    아랑: 비취 치마 (IP 확정)

  소품:
    금동 허리띠: 백제 귀족 필수 아이템
    금동 신발: 왕족·고위 귀족
    비녀: 금·은·옥 소재

아랑 전용 아이템:
  자수 저고리: 어머니 유산 패턴 포함 (삼각+원 결합)
  오른손 검지 굳은살: 자수 작업 흔적
  작은 자수 조각: 항상 소지 (연속성 필수)
```

### 남성 귀족·관리 복식

```
관복 (官服):
  관등별 색상 (백제 관등 16품):
    1품 佐平: 자색 비단
    2~6품: 비색 (붉은 계열)
    7~11품: 청색
    12~16품: 황색
    평민: 백색 (비단 사용 불가)

  관모 (冠帽):
    귀족: 오라관 (검정 비단 모자 + 금은 장식)
    일반 관리: 조관 (삿갓 모양)

  의 (衣):
    귀족: 포 형식 긴 외의
    소매: 귀족 = 넓음, 군인 = 좁음

  허리띠:
    금동 (귀족) / 은 (관리) / 가죽 (병사)
```

## 신라 복식

### 화랑 복식 (하린 참조)

```
화랑 정복:
  저고리: 청색 또는 백색 (신라 화랑 전통색)
  바지: 넉넉한 기마용
  포: 짧은 외투

특징 아이템:
  화관 (花冠): 꽃 장식 머리띠 (화랑 상징)
    → 낭도 수련 중 착용 (실전 시 제거)
  요령 (搖鈴): 의례용 소형 방울
  단궁 (短弓): 화랑 필수 무기

하린 복식:
  일상: 신라 청색 화랑복 + 활통
  S1: 충동적 → 복식 약간 흐트러진 느낌
  S3: 절제 → 정갈하게 갖추어 입음
  특징: 오른팔 흉터 (S3 이후 — 연속성 필수)

  기마 장비:
    마구 (馬具): 화려한 금동 장식 (신라 특기)
    활집: 오른쪽 허리 (오른손 활 확정)
    검집: 왼쪽 허리
```

### 여왕·왕실 복식

```
선덕여왕 복식 (참조):
  왕관: 금관 (금관총 실물 참조)
    세움 장식 (立飾): 출 자형 3개
    드리개: 곡옥(曲玉) 달림
  왕복: 황금 자수 + 금동 장식
  신발: 금동 이식

골품제 색 규정:
  진골 (眞骨): 자·적·청 (비단·금 장식)
  6두품: 청 (비단 제한적)
  5두품 이하: 황·백 (비단 일부 제한)
  하린 (6두품): 청색 가능, 금 장식 제한
```

## 가야 복식

### 일상 복식 (니문 참조)

```
소박한 복식 전통:
  저고리: 황토색 삼베 (귀족도 소박)
  바지: 넉넉한 삼베 바지
  포: 짧은 외투 (추울 때만)

니문 복식:
  저고리: 황토색 삼베 (IP 확정)
  바지: 넉넉한 삼베
  신발: 맨발 or 짚신 (IP 확정)
  장신구: 철제 팔찌 (가야 철 문화 상징)

장신구 특징:
  철제 팔찌·귀걸이: 가야 철공예 최고 수준
  구슬 목걸이: 남해 특산 구슬
  왕족도 금·은보다 철 장식 선호 (가야 정체성)
```

### 가야 의례 복식

```
제철 의례 복식:
  장인: 흰 삼베 제복 (신성함 표현)
  수장: 철제 관(冠) + 황토 포
  의례 시작 전 손 씻기 (정결 의례)

수로왕 제사 복식:
  제사장: 흰 마포 장의
  참가자: 정결한 일상복 (화려함 금지)
```

## 고증 참조 유물 목록

```
고구려:
  수산리 고분 벽화 — 귀족 남녀 복식 (5세기)
  안악 3호분 벽화 — 행렬도, 시녀 복식
  덕흥리 고분 벽화 — 기마무사, 무기 고증
  삼실총 벽화 — 씨름·생활 복식

백제:
  무령왕릉 출토품 — 금제 관식, 허리띠
  금동대향로 (국보 287호) — 문양 참조
  능산리 사지 출토 금동불 — 의상 표현
  나주 복암리 고분 출토 마구 — 장신구

신라:
  금관총 금관 (국보 87호) — 왕관 기준
  천마총 천마도 — 천마 표현 기준
  황남대총 출토품 — 장신구, 의복 관련 유물
  경주 출토 금동 신발 — 왕족 신발 고증

가야:
  대성동 고분 출토 철제 유물 — 철기 공예
  지산동 고분 출토 철제 갑옷 — 군사 복식
  칠산리 고분 출토 구슬 — 장신구
```

## IP 적용 가이드

```
캐릭터 복식 준수 사항:

고루:
  ☑ 흑색 찰갑 + 삼족오 문양 (IP 확정)
  ☑ 환두대도 소지 (왼/오른손 ART-CHAR 확정 대기)
  ☑ 투구 없음 (IP 설정)
  ☑ 신분 표시: 고구려 귀족 청색 저고리

아랑:
  ☑ 연지색 비단 저고리 + 비취 치마 (IP 확정)
  ☑ 어머니 자수 조각 항상 소지
  ☑ 오른손 검지 굳은살 (자수 흔적)
  ☑ 금동 허리띠 (백제 귀족 신분)

하린:
  ☑ 신라 청색 화랑복
  ☑ S3: 오른팔 흉터 추가 (연속성 필수)
  ☑ 오른손 활집 (확정)
  ☑ 금 장식 제한 (6두품)

니문:
  ☑ 황토색 삼베 저고리
  ☑ 맨발 or 짚신
  ☑ 철제 팔찌
  ☑ 가야금 항상 소지

공통 금지 사항:
  ✗ 현대적 재해석 과도 (애니 스타일 과도한 신체 노출)
  ✗ 흰 피부·파란 눈 (아시아 역사 배경)
  ✗ 왕국 색상 혼용 (고루가 황금 장식 착용 등)
  ✗ 시대 오류 (7세기 이후 복식 요소)
```
