## 8. 고대 한국어 어휘 (대사 작성 참고)

### 왕·귀족 호칭

```
왕 → 대왕(大王) / 상감(上監) / 전하(殿下)
왕비/왕후 → 왕후(王后) / 중전마마(中殿媽媽)
태자 → 태자(太子) / 세자(世子)
공주 → 공주(公主)
신하 → 신(臣) [자칭] / 경(卿) [왕이 부름]
장군 → 장군(將軍)
```

### 고어 표현 (대사 특색에 활용)

```
현대어 → 고어/문어체 (드라마 대사용)

"~입니다" → "~이옵니다" / "~이로소이다"
"그렇습니다" → "그러하옵니다" / "옳사옵니다"
"감사합니다" → "황감하옵니다" / "은혜 망극하옵니다"
"가겠습니다" → "물러가겠나이다"
"죽겠습니다" → "목숨을 바치겠사옵니다"
"왕이시여" → "주상전하" / "대왕마마"
"알겠습니다" → "분부 받들겠나이다"
"모르겠습니다" → "소신의 우견으로는…"
```

### 창작 대사 원칙

```
1. 지나친 고어 금지 — 현대 시청자 이해 불가
2. 적당한 문어체 — 품위와 가독성 균형
3. 왕국별 어투 차별화:
   고구려: 짧고 강함 / 군더더기 없음
   백제: 부드럽고 우아함 / 음절 여유
   신라: 암시적·신비로운 / 여운 있음
   가야: 솔직하고 직접적 / 장인 기질

4. 하급자 → 상급자: 경어 철저
5. 왕 → 신하: 하대(下待) — 단, 총애 신하는 약화
```

## 11. 고유명사 로마자 표기 원칙

```
기준: 국립국어원 로마자 표기법 (2000년 개정)

핵심 규칙:
ㄱ = g (어두) / k (어중·어말)
ㄷ = d (어두) / t (어중·어말)
ㅂ = b (어두) / p (어중·어말)

예시:
고구려 → Goguryeo (G)
백제 → Baekje (B)
신라 → Silla (S)
가야 → Gaya (G)

장음 표기: 생략 (현행 표기법)
받침 연음: 표기에 반영
예: 광개토 → Gwanggaeto (O)

예외:
- 이미 국제적으로 굳어진 표기는 유지
- 단, 삼국 IP 공식 표기는 위 원칙 준수
```
