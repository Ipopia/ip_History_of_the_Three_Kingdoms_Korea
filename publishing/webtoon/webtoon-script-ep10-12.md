## 10화 — 「새로운 강」

### 화 개요

```
시간: 618년, 수나라 멸망 직후
주인공: 고루 (고구려), 니문 (가야계)
키 씬: 고루가 을지문덕의 소식을 받고, 니문이 처음으로 12악곡에 도전
분위기: 서사적 전환점 — 새 시대의 문이 열린다
```

### 스크립트

**컷 1~5 (도입)**
```
[컷 1] 전경샷 — 대동강 전경. 봄.
캡션: 「618년 봄. 수나라가 무너졌다.」

[컷 2] 평양성 성벽 위. 고루(24세)가 서 있다.
고루 독백: 「6년이 지났다. 살수는 여전히 흐르고……」

[컷 3] 고루 클로즈업 — 살수 이후 성장한 얼굴.
고루 독백: 「장군은 이미 세상을 떠나셨다.」

[컷 4] 회상 컷 — 을지문덕의 뒷모습 (작고 희게).
을지문덕(회상): 「강은 기억한다. 너는 기억할 수 있겠느냐.」

[컷 5] 고루, 눈을 감았다 뜬다.
고루 독백: 「예, 장군. 기억합니다.」
```

**컷 6~15 (전환 — 니문)**
```
[컷 6] 장면 전환. 낙동강 강변.
캡션: 「같은 날. 가야 옛 땅.」

[컷 7] 니문(26세), 강가 바위 위에 앉아 가야금 앞에 두루마리를 펼쳐놓고.
캡션 박스: 「우륵 선생의 12악곡. 마지막 12번째만 기록이 없다.」

[컷 8] 니문이 가야금 줄을 고른다. 첫 음 도전.
효과음: 「뚱」(고음)

[컷 9] 니문의 손가락 클로즈업 — 힘줄이 드러난 연주자의 손.

[컷 10] 니문 표정 — 눈을 감고 집중.
니문 독백: 「12번째 곡. 우륵 선생은 왜 이것만 남기지 않으셨을까.」

[컷 11] 니문이 눈을 뜬다.
니문: 「……아니다. 남긴 것인지도 모른다.」

[컷 12] 니문이 허공을 바라본다. 강물 소리 효과.
니문 독백: 「사라진 것들의 소리는 기억하는 자가 새로 만드는 것이다.」

[컷 13] 니문이 첫 멜로디를 연주. 음표 이펙트 그래픽.
효과음: 「뚱, 뚱, 따~」

[컷 14] 강물에 파문이 생기는 이미지 (상징적).

[컷 15] 니문 미소. 조용하고 결연하게.
니문: 「이것이 12번째다.」
```

**컷 16~30 (메인 씬 — 고루, 당나라 소식)**
```
[컷 16] 고루 방. 전령이 문서를 들고 들어온다.
전령: 「대막리지 각하. 당나라 황제 이세민이 즉위했습니다.」

[컷 17] 고루, 문서를 받는다. 표정은 차분하지만 눈빛이 변한다.

[컷 18] 문서 클로즈업 — 「唐 武德九年 李世民 即位」(한자)

[컷 19] 고루 독백: 「이세민……」
[컷 20] 이세민 실루엣 삽입 (역광, 강렬한 이미지).
고루 독백: 「이 이름을 수나라 이후로 가장 두려운 이름이 될 것이다.」

[컷 21] 고루가 창문을 열고 대동강을 바라본다.
고루: 「장군, 이제 새로운 적이 옵니다.」

[컷 22~25] 고루의 결의. 갑옷에 손을 얹는 장면.
고루: 「살수가 기억하듯이, 나도 기억하겠다.」

[컷 26~30] 다시 니문 장면.
니문이 12번째 곡 연주. 음이 강물 위로 퍼지는 이펙트.

[컷 30] 두 인물 분할 컷 — 고루(북방) / 니문(남방).
캡션: 「같은 하늘 아래. 다른 강가에서. 다른 방식으로.」
```

**컷 31~45 (엔딩)**
```
[컷 31~35] 아랑 씬 삽입 (백제).
사비성 문서고에서 아랑이 밤을 새우며 글을 쓴다.
아랑: 「오늘 당나라가 섰다. 이 나라는 얼마나 갈 것인가.」

[컷 36~40] 하린 씬 (신라).
첨성대 공사 현장. 하린이 올려다보며.
하린 독백: 「이 탑이 완성될 때, 우리는 어디 있을까.」

[컷 41~45] 4분할 엔딩 컷:
고루 / 아랑 / 하린 / 니문

캡션: 「새로운 강이 흐른다.」
다음화 예고: [컷 45] 수나라 멸망 잔해 위 당나라 깃발.
```

## 11화 — 「연개소문의 칼」

### 화 개요

```
시간: 642년, 연개소문 쿠데타
주인공: 고루 (고구려)
키 씬: 영류왕 시해 후 연개소문이 고루를 만나다
분위기: 정치 스릴러, 도덕적 갈림길
총 컷: 48컷
```

### 스크립트 (핵심 씬)

**컷 1~10 (쿠데타 현장)**
```
[컷 1] 전경샷 — 밤의 평양성. 불길.
캡션: 「642년 가을. 연개소문의 날.」

[컷 2] 성 안 혼란. 병사들이 달린다.
[컷 3] 고루, 칼을 들고 복도를 달린다.

[컷 4] 고루가 멈춘다. 앞에 피가 보인다.
[컷 5] 바닥의 왕의 복식 (왕 자신은 그림자).
고루 독백: 「……폐하.」

[컷 6~8] 연개소문이 칼을 닦으며 나타난다.
연개소문: 「고루. 늦었구나.」
고루: 「……」

[컷 9] 고루와 연개소문의 눈싸움.
연개소문: 「네 칼을 내려라. 나는 적이 아니다.」
고루: 「……폐하를 지키지 못했습니다.」

[컷 10] 연개소문이 고루 옆을 지나치며.
연개소문: 「보장왕이 즉위했다. 고구려는 계속된다.
          너는 싸울 사람이 필요하지 않느냐.」
```

**컷 20~35 (핵심 대화)**
```
[컷 20] 연개소문의 집무실. 고루가 서 있다.
연개소문: 「당나라가 온다.」

[컷 21] 고루: 「알고 있습니다.」
연개소문: 「외교로는 막을 수 없다. 이세민은 전쟁을 원한다.」

[컷 22] 고루의 표정 — 반박하려다 멈춘다.
고루 독백: 「……틀리지 않을 수도 있다.」

[컷 23~27] 연개소문이 지도를 펼친다.
연개소문: 「당나라가 요동을 넘으면, 우리는 성에서 막는다.
          네가 필요하다. 안시성을 알고 있느냐.」

[컷 28] 고루가 지도를 내려다본다.
고루 독백: 「안시성……」

[컷 29] 고루 클로즈업. 결단의 표정.
고루 독백: 「이것이 내 첫 번째 타협이다.」

[컷 30] 고루: 「알겠습니다, 대막리지 각하.」

[컷 31~35] 연개소문이 고루에게 칼을 건넨다.
연개소문: 「이것은 을지문덕 장군의 칼이다.」
고루: (눈을 크게 뜨며) 「……」
연개소문: 「기억하라. 고구려를 위해.」

[컷 35] 고루가 칼을 받는다. 손이 떨린다.
```

**컷 36~48 (엔딩)**
```
[컷 36~40] 고루 혼자 밖에 서서 대동강 바라봄.
고루 독백: 「장군, 나는 지금 올바른 길에 있는 겁니까.」

[컷 41~45] 강물이 조용히 흐른다. 답 없음.

[컷 46] 고루가 칼을 허리에 찬다. 결연.
[컷 47] 전경샷 — 대동강과 성.

[컷 48] 캡션: 「3년 후, 당 태종이 온다.」
다음화 예고 이미지: 당나라 깃발 + 고루 뒷모습.
```

## 12화 — 「니문의 12번째 곡」

### 화 개요

```
시간: 642년~645년 사이
주인공: 니문 (가야계)
키 씬: 12번째 악곡 완성. 신라 궁중 공연.
분위기: 감성적, 가야 정체성의 승화
총 컷: 44컷
```

### 스크립트 (핵심 씬)

**컷 1~15 (연주 준비)**
```
[컷 1] 신라 왕궁 악사 준비실. 니문이 가야금을 무릎에 놓고.
캡션: 「오늘 진덕왕에게 연주를 올린다.」

[컷 2~5] 다른 악사들이 니문을 힐끔 본다.
악사 1: (작게) 「가야 놈이 궁에서 연주를 하다니.」

[컷 6] 니문 표정 — 듣고 있지만 반응하지 않는다.
니문 독백: 「가야가 없어진 지 80년. 우리 2세는 신라 사람도 가야 사람도 아니다.」

[컷 7~10] 니문이 가야금 줄을 고른다.
니문 독백: 「그러나 이 현이 울리는 한 — 가야는 여기 있다.」

[컷 11~15] 연주 시작 준비. 연습 컷. 손가락 훈련.
```

**컷 20~35 (궁중 공연)**
```
[컷 20] 신라 왕궁 연회장. 전경.
[컷 21] 진덕왕(여왕)이 상석에. 귀족들이 자리에.

[컷 22] 니문이 등장. 가야금을 들고.
귀족 웅성거림.

[컷 23] 니문이 무릎 꿇고 인사.
니문: 「가야의 후예 니문이 연주를 올립니다.」

[컷 24] 진덕왕: 「우륵의 악을 이은 자라 들었다. 연주하라.」

[컷 25] 니문이 가야금 앞에 앉는다.

[컷 26] 첫 음 — 「뚜웅」
[컷 27~30] 연주 장면 시리즈. 손가락 클로즈업. 현의 떨림. 음파 이펙트.

[컷 31] 귀족들이 조용해진다.
[컷 32] 진덕왕의 표정이 바뀐다. 눈빛이 멀어진다.

[컷 33] 니문 표정 — 눈을 감고 연주. 눈물 한 방울.

[컷 34] 가야 왕도 환영 — 음악 속 기억.
[컷 35] 낙동강, 구지봉, 우륵 노인 이미지 (회상 컷 연속).
```

**컷 36~44 (엔딩)**
```
[컷 36] 연주 끝. 정적.
[컷 37] 진덕왕: 「……이 곡의 이름이 무엇이냐.」

[컷 38] 니문이 눈을 뜬다.
니문: 「사라진 나라의 노래(亡國之歌)입니다.」

[컷 39] 잠시 침묵.
[컷 40] 진덕왕: 「사라진 나라의 노래가……이토록 아름다운가.」

[컷 41] 니문의 표정 — 슬프지 않은 미소.
니문 독백: 「나라는 사라졌다. 그러나 강은 기억한다.」

[컷 42] 전경 컷 — 왕궁 너머 형산강.
[컷 43] 형산강과 낙동강 교차 이미지. 두 강이 바다에서 만나는 상상도.

[컷 44] 마지막 캡션:
「가야의 음악은 사라지지 않았다.
 신라에, 그리고 우리에게 남아있다.」

다음화 예고: 고루 — 안시성 성벽 위.
```

---

**작가 노트:**
10화는 살수대첩(612년)~쿠데타(642년) 시간 점프를 다루며 고루와 니문을 병행 서술한다. 11화는 가장 어두운 고루의 순간이며, 12화는 전체 시리즈에서 가장 감성적인 화다. 3화 묶음의 정서적 흐름은 「전환 → 갈등 → 승화」.
