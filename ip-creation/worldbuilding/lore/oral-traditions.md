## 구전 문화 개요

```
7세기 한반도 구전 문화 특성:
  문자 기록: 귀족·승려 계층만 가능
  민간 지식 전달: 구전 (입에서 입으로)
  형식: 노래·이야기·수수께끼·격언

구전의 역할:
  1. 역사 기억 보존 (문자 없는 계층)
  2. 도덕·가치 교육 (아이들)
  3. 집단 정체성 유지 (왕국별 차별화)
  4. 예언·금기 전달 (신앙 체계)

IP 활용 목적:
  - 캐릭터 대사에 민담 요소 삽입
  - 장소 분위기 조성 (배경 요소)
  - 복선·예언적 서사 장치
  - 세계관 깊이 증가
```

## 고구려 구전 전통

### 건국 서사시: 「주몽가(朱蒙歌)」

```
내용:
  하늘의 아들 주몽이 부여에서 탈출
  강에 막혔을 때 물고기·자라가 다리를 놓음
  (「강은 기억한다」모티프의 원형)
  졸본에 고구려 건국

IP 연계:
  고루의 좌우명 「강은 기억한다」의 신화적 뿌리
  고루가 살수 전투 전 혼잣말로 읊는 구절:
  「주몽 대왕도 강에서 건짐을 받았지.
   강은 기억한다. 고구려의 피를.」

형식: 7음절 반복 리듬 (구연 가능)
전달자: 무사 계층 (밤 불 앞에서 구연)
```

### 삼족오(三足烏) 전설

```
내용:
  태양 속에 사는 발 셋 달린 까마귀
  고구려 왕실의 수호 존재
  삼족오가 울면 전쟁이 시작된다

격언 형태:
  「삼족오가 동쪽을 향하면 전진하라
   삼족오가 서쪽을 향하면 후퇴하라」
  → 군사 부대 깃발 방향의 민간 해석

IP 활용:
  고루가 전투 전 삼족오 깃발을 올려다보는 장면
  을지문덕이 「저 새가 기억할 것이다」대사
```

### 개마무사(鎧馬武士) 전설

```
내용:
  철갑 기병의 기원 신화
  「첫 개마무사는 하늘에서 내려온 말을 탔다
   그 말은 강에서 태어났고, 강물을 두려워하지 않았다」

교훈:
  두려움 없는 전사 = 고구려 무인의 이상
  물과 결탁한 전사 불사(不死) 모티프

IP 활용:
  고루의 전투 전 의식:
  말 목을 쓰다듬으며 「두려워하지 않는다」 속삭임
```

### 을지문덕 예언 격언

```
민간에 전해진 을지문덕 어록 (창작):
  「적을 이기려면 먼저 강을 이겨라」
  「싸우지 않고 이기는 것이 진정한 승리」
  「2,700이 살아 돌아왔다 — 강이 기억한다」

형식: 단문 격언 (5~7자)
전달: 고구려 군사 교육 구전
```

## 백제 구전 전통

### 아랑 기록 모티프: 「기억하는 여인」설화

```
원형 설화 (창작 IP용):
  「사비성에 글을 쓸 줄 아는 여인이 있었다
   그녀는 나라가 망해도 죽간을 버리지 않았다
   강에 던지려다 멈추고 말했다:
   '강이 기억한다면, 나도 기억해야 한다'」

→ 아랑 캐릭터의 원형 설화
   성격 형성의 근거로 활용

구연 주체: 백제 궁녀·귀족 여성 계층
```

### 연등 기원 전설

```
내용:
  「사비성의 첫 연등 행사는
   백마강이 넘칠 것을 두려워한 왕이
   강신(江神)에게 올린 제물이었다
   강신은 기뻐하며 물을 거두었다」

절기: 음력 1월 15일 연등 행사 기원
현재 IP:
  아랑의 연등 장면에 이 전설 삽입
  「강신에게 올리는 빛이야. 강은 기억해줄 거야.」

형식: 사제(司祭)가 제의 전 구연
```

### 낙화암 민담

```
원전 + IP 확장:
  「낙화암 바람은 떠나간 이들의 숨소리다
   백마강 물결은 그들의 기억이다
   꽃잎이 떨어지듯 사라진 것들이
   봄이 오면 다시 피어난다」

사용 목적:
  백제 멸망 장면의 배경 구전
  아랑이 낙화암에서 읊는 장면

형식: 4행 연 (애도가 형식)
```

### 무령왕의 꿈 전설

```
내용:
  「무령왕은 꿈에서 용을 보았다
   용은 백마강에서 나와 왕에게 말했다:
   '강이 나라를 기억하는 한 나라는 사라지지 않는다'
   왕은 꿈에서 깨어 무덤을 지하에 지었다
   강 아래에, 기억되기 위해」

역사 연계: 무령왕릉 특이한 지하 구조의 민간 해석
IP 활용: 아랑이 이 이야기를 죽간에 기록
```

## 신라 구전 전통

### 화랑 세속오계 구연

```
공식 계율 (원전):
  사군이충(事君以忠)
  사친이효(事親以孝)
  교우이신(交友以信)
  임전무퇴(臨戰無退)
  살생유택(殺生有擇)

IP 구연 방식:
  화랑 입단 의식 — 반복 낭독 형식
  하린이 처음 외울 때의 목소리 장면:
  「임전무퇴. 임전무퇴. 임전무퇴.
   소리가 몸에 스밀 때까지.」

전달: 풍월도(風月道) 교육 — 선배→후배
```

### 선덕여왕 예지 전설

```
민간 전설:
  「여왕은 세 가지 일을 미리 알았다:
   ① 모란꽃에 향기 없음 (당나라 그림 보고)
   ② 개구리 울음으로 적군 위치 파악
   ③ 자신의 죽음 날짜」

IP 활용:
  하린이 선덕여왕을 존경하는 이유
  「예언하는 왕」= 신라의 특수한 왕권 정당성

하린 대사:
  「여왕 폐하는 이미 알고 계실 것이다.
   우리가 이길지 질지.」
```

### 관창 전설

```
구전 형태 (역사 + 창작):
  「열여섯 살 화랑이 세 번 적진에 돌입했다
   첫 번에 살아 돌아왔고
   두 번째에도 살아 돌아왔다
   세 번째에 계백이 그의 목을 베었다
   그러나 신라군은 움직이기 시작했다
   관창의 피가 강보다 깊었기 때문이다」

→ 하린의 핵심 모티프
   「관창이 보고 싶다」이모티콘의 배경

구연: 신라 군사 부대 — 전투 전 사기 고양
```

### 김유신 어머니 교훈담

```
내용:
  「김유신이 기방을 방문하자
   어머니가 눈물로 훈계했다
   김유신은 그 날부터 기방에 가지 않았다
   그 의지로 삼국을 통일했다」

교훈: 의지·절제 = 신라 남성 이상
하린 연계:
  화랑 훈련 중 선생이 구연
  하린이 김유신을 존경하는 배경
```

## 가야 구전 전통

### 가야금 기원 설화

```
우륵(于勒) 전설:
  「가야국 가실왕이 우륵에게 명했다:
   '우리나라에도 음악이 있어야 한다'
   우륵은 12현 가야금을 만들고
   12달을 담은 12곡을 지었다
   나라가 망해도 소리는 남았다」

→ 니문의 가야금 = 우륵의 유산
   「나라는 사라졌어도 소리는 남는다」의 직접 근거

니문 대사:
  「우륵 선생이 만든 소리야.
   가야가 사라지기 전에 만든.
   강이 기억하듯, 소리도 기억해.」
```

### 김수로왕 건국 설화

```
원전 요약:
  「하늘에서 황금 상자가 내려왔다
   상자 안에 여섯 알이 있었다
   알에서 여섯 왕이 태어났다
   그 중 첫 번째가 김수로, 가야를 세웠다」

→ 가야 = 천손(天孫) 의식
   멸망해도 하늘의 뜻이 있었다는 위안

니문의 자기 인식:
  「나는 하늘에서 온 씨앗의 후손이야.
   땅에 떨어졌다고 씨앗이 사라지진 않아.」
```

### 낙동강 수신(水神) 전설

```
내용:
  「낙동강에는 나이를 알 수 없는 수신이 산다
   가야 철을 먹고 자랐기에
   그의 비늘은 철처럼 단단하다
   강이 가야를 기억하는 이유는
   수신이 잊지 않기 때문이다」

IP 활용:
  니문이 낙동강 변에서 연주하는 이유
  수신에게 가야를 기억해달라는 의식적 행위

형식: 가야금 연주와 함께 구연
전달: 가야 무속인 계층
```

### 철정(鐵鋌) 저주 전설

```
내용:
  「가야 철정은 저주를 가진다
   공정하지 않은 거래로 얻은 철은
   그것을 얻은 자에게 재앙을 돌려보낸다」

→ 가야-왜 무역의 공정성 강조 기제
   신라의 가야 흡수 = 저주의 이행이라는 민간 해석

니문 시각:
  「신라가 우리 땅을 빼앗았을 때
   철이 기억했을 것이다.」
```

## 구전 공통 패턴

```
삼국 공통 구전 테마:
  ① 강·물의 기억력: 「강은 기억한다」범삼국 모티프
  ② 하늘의 뜻: 천손 의식 (삼국 모두 보유)
  ③ 결사 영웅: 죽음을 두려워하지 않는 전사
  ④ 멸망 후 부활: 사라져도 기억으로 존재

서사 장치 활용:
  - 캐릭터가 위기 시 관련 구전 떠올림
  - 할머니·사제가 어린 캐릭터에게 구전 전달 장면
  - 적국 캐릭터가 같은 구전을 다른 방식으로 해석
  - 구전이 복선으로 작동 (초반 → 후반 실현)
```
