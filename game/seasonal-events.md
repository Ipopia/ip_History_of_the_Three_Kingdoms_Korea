# 게임 시즌 이벤트 — 삼국(三國) 게임

**참조 문서**: `game-design-document.md`, `character-unlock-guide.md`, `monetization-strategy.md`
**작성**: 게임본부 기획팀 (GAME-DESIGN)
**적용**: 삼국(三國) 전략 RPG — 연간 시즌 이벤트 캘린더 + 상세 기획

---

## 이벤트 설계 원칙

```
핵심 원칙:
  ① 역사 기념일 연동 (고증 + 흥미)
  ② IP 드라마·출판 방영 연동 (크로스 미디어 시너지)
  ③ 무과금 참여 가능 (유료 이벤트 배제)
  ④ 교육적 가치 포함 (역사 해설 연동)

이벤트 유형:
  A. 역사 기념 이벤트 (연 4회)
  B. 드라마 방영 연동 이벤트 (분기별)
  C. 시즌 한정 이벤트 (봄·여름·가을·겨울)
  D. 글로벌 PvP 대전 (월 1회)
  E. 왕국 대항전 (매주)
```

---

## 연간 이벤트 캘린더

### 1월: 「새해 봉화」이벤트

```
컨셉: 삼국시대 봉화 신년 의식
기간: 1월 1~14일 (2주)

내용:
  매일 봉화 퀘스트 완료 시 자원·캐릭터 조각 보상
  「신년 왕국 선언」: 새해 목표 왕국 선택
  왕국별 신년 메시지 (게임 내 이벤트 대화)

특별 보상:
  봉화 연속 7일: 삼족오 신년 스킨 (고루)
  봉화 연속 14일: 신년 한정 왕국 깃발 배경

교육 요소:
  봉화 시스템 역사 해설 팝업
  「삼거(三炬) — 최대 위기 신호」해설
```

### 3월: 「살수대첩 612주년」이벤트

```
컨셉: 실제 역사 기념 (612년 → 해당 연도)
기간: 3월 중 2주

메인 콘텐츠:
  「살수대첩 재현 특별 미션」한시적 해금
    - 이벤트 기간만 S등급 보상 2배
    - 최초 클리어 유저 1,000명: 한정 을지문덕 스킨
  「수나라 대군 격퇴 도전」:
    서버 전체 협동: 7일간 수나라 병력 1억 격퇴
    목표 달성 시 전 유저 프리미엄 보상

역사 해설 이벤트:
  매일 역사 퀴즈 (살수대첩 관련)
  정답 시 게임 내 역사 코인 획득
  역사 코인 교환소: 역사 인물 카드·해설 언락

특별 스킨 (이벤트 한정):
  고루 「살수의 전사」스킨 (강물 이펙트)
  을지문덕 「한시의 장군」스킨 (서예 이펙트)
```

### 5월: 「가야금 축제」이벤트

```
컨셉: 우륵 가야금 12곡 기념 + 니문 스토리 연동
기간: 5월 중 2주 (어린이날·스승의날 시즌)

메인 콘텐츠:
  「12악곡 완성 도전」:
    매일 니문 음악 미니게임 (리듬 게임 형식)
    12일간 1곡씩 → 전부 완성 시 최고 보상
  가야금 역사 해설 시리즈:
    우륵(于勒) 이야기 인게임 스토리
    가야 왕국 역사 해설 (5분 영상)

교육 연계:
  어린이날 특별: 역사 동화 형식 스토리 이벤트
  스승의날: 「스승과 제자」관계 스토리 (을지문덕-고루, 성충-아랑)

특별 보상:
  12악곡 전 완성: 니문 「완성의 순간」한정 스킨
  미니게임 전관왕: 가야금 레플리카 실물 경품 추첨 (100명)
```

### 7월: 「드라마 방영 연동」이벤트 (2026)

```
컨셉: 드라마 시즌 1 방영 기념 (2026 Q3)
기간: 드라마 방영 기간 전체 (약 10주)

메인 콘텐츠:
  「EP 연동 이벤트」:
    매주 방영 에피소드 = 게임 내 연동 미션 해금
    EP01 방영 주: 을지문덕-고루 첫 만남 미션
    EP07 방영 주: 살수대첩 재현 특별 미션

  「드라마 명장면 재현」:
    게임 내 드라마 씬 재현 컷씬 추가
    드라마 실제 대사 게임 내 삽입

  「실제 배우 콜라보」:
    배우 음성 녹음 이벤트 대사 추가 (한정)
    배우 사진 포토카드 인게임 수집 이벤트

특별 보상:
  드라마 방영 첫 주 로그인: 한정 드라마 포스터 배경
  전 에피소드 연동 미션 완료: 드라마 촬영 실물 소품 경품 (10명)
```

### 9월: 「안시성 88일」이벤트

```
컨셉: 안시성 공방전 역사 기념 (645년 기준)
기간: 9월 초~말 (88일을 2주로 압축)

메인 콘텐츠:
  「안시성 방어 챌린지」:
    88턴 버티기 미션 (시간 압축 버전)
    난이도: 쉬움(30턴)·보통(55턴)·어려움(88턴)
    88턴 클리어: 양만춘 A+ 카드 + 한정 스킨

  서버 전체 이벤트:
    전 서버가 당나라 대군 격퇴 도전
    서버 합산 방어 횟수 목표 달성 시 전원 보상

역사 해설:
  「이름 없는 영웅 양만춘」역사 영상
  안시성 실제 위치·현재 모습 소개
  고고학 발굴 현황 해설 (연동)

특별 스킨:
  양만춘 「성벽의 주인」한정 스킨
  고루 「안시성 방어」한정 스킨 (부상 표현)
```

### 10월: 「4왕국 대항전」이벤트

```
컨셉: 연간 최대 PvP 이벤트
기간: 10월 전체 (4주)

구조:
  주 1회: 왕국별 대표 PvP 토너먼트
  최종 주: 4왕국 챔피언 결전

리그 구성:
  고구려군 vs 백제군 (1주차)
  신라군 vs 가야군 (2주차)
  2승 왕국 결승 (3주차)
  최종 챔피언 결정전 (4주차)

보상:
  우승 왕국 전원: 왕국 챔피언 배지 + 자원 보상
  개인 최우수 선수 (MVP): 한정 캐릭터 스킨

역사 연동:
  이벤트 결과에 따라 「이번 달의 최강 왕국」역사 해설
  예: 신라 우승 시 → 나당 연합 전략 해설
  예: 고구려 우승 시 → 살수대첩 심층 해설
```

### 12월: 「강은 기억한다」연말 이벤트

```
컨셉: 연간 총결산 + 감사 이벤트
기간: 12월 전체

메인 콘텐츠:
  「올해의 기억」:
    유저 개인 연간 플레이 요약 (히스토리 카드)
    「내 왕국의 1년」통계 + 업적 정리
  「연말 4인 재결합」스토리:
    고루·아랑·하린·니문 연말 특별 스토리 챕터
    메인 테마 OST 연주 씬 (게임 내 애니메이션)

특별 보상:
  연간 접속 일수별 보상 (30일·60일·180일·365일)
  365일 개근: 「강의 증인」칭호 + 최고급 한정 스킨

새해 예고:
  다음 시즌 미리보기
  시즌 2 드라마 연동 예고 이벤트
```

## 월간 정기 이벤트

```
매주 왕국 대항전:
  월~일: 왕국별 점수 누적
  일요일 자정: 왕국 랭킹 확정 + 보상 지급
  1위 왕국: 왕국 전원 자원 2배 (월요일 하루)

월간 역사 퀴즈 대회:
  매월 마지막 주 토요일 개최
  삼국시대 역사 OX 퀴즈 (20문항)
  상위 1,000명: 게임 내 특별 보상
  1위: 실물 굿즈 (왕국 박스 1개)

월간 전략 토너먼트:
  매월 첫 주 금~일 (3일간)
  전략 랭크 기준 토너먼트
  챌린저급 우승: 한정 칭호 + 특별 스킨
```

## 글로벌 이벤트 (동시 진행)

```
한국·일본·동남아·글로벌 서버 동시 이벤트:

서버 간 교류 이벤트 (분기별):
  각 서버 대표 1,000명 → 인터서버 대전
  목적: 글로벌 유저 교류 + 홍보
  보상: 인터서버 우승 왕국 → 글로벌 1위 칭호

역사 교육 연동 이벤트:
  UNESCO 세계유산 등재 관련 역사 해설
  각국 서버에서 동일한 역사 퀴즈 진행
  목적: 한국 역사 글로벌 알리기

K-Heritage Week (연 1회):
  한국 전통 문화 주간 이벤트
  가야금·탈춤·한복 관련 게임 내 미니게임
  교육부·문화부 협력 가능성 검토
```
