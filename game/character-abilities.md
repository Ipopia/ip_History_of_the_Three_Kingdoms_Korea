# 캐릭터 능력치 & 스킬 시스템 — 삼국(三國) IP

**참조 문서**: `game-design-document.md`, `narrative-design.md`, `world-map.md`, `character-profiles/main-characters.md`
**작성**: 게임본부 기획팀 (GAME-PLAN)
**적용**: 삼국(三國) IP 게임 플레이어블 캐릭터 능력치·스킬·성장 시스템 기준

---

## 캐릭터 시스템 개요

```
캐릭터 유형:
  주인공 4인: 완전 조작 가능 (캠페인 전용)
  역사 영웅: 영웅 카드 시스템 (전술 보조)
  일반 유닛: 왕국별 병과 (전략 파트)

능력치 구조:
  기본 6대 스탯 + 왕국 고유 특성 + 개인 특기
  성장: 레벨업 + 스킬 트리 + 장비 보너스

밸런스 원칙:
  4인 각자 강점/약점 명확 (상호 보완 설계)
  Pay-to-Win 없음 — 스킬 효과는 전술 보조만
  역사 고증 기반 능력치 설정
```

## 주인공 4인 캐릭터 시트

### 고루 (高婁) — 고구려 전략가

```
기본 스탯 (최대 100):
  전투력   : ★★★★★ (95) — 근접 전투 최강
  방어력   : ★★★★☆ (80) — 개마무사 철갑 기반
  기동력   : ★★★☆☆ (60) — 중장비로 느림
  지략     : ★★★★☆ (82) — 전략적 판단력
  외교     : ★★★☆☆ (55) — 비언어적 소통
  지형이용 : ★★★★★ (90) — 산악·강 지형 특화

왕국 특성 — 「고구려의 철」:
  산악 지형 이동 패널티 없음
  강 지형 방어 +30%
  겨울 전투 패널티 없음
  요새 방어 시 전 유닛 공격력 +20%

패시브 스킬:
  「살수의 기억」: 강 지형 전투 시 추가 공격 기회 발동 (25% 확률)
  「개마무사의 후예」: 기병 유닛 지휘 시 돌격력 +15%
  「묵언의 전략」: 침묵 상태(대화 없음) 3턴 유지 시 전술 명중률 +10%

액티브 스킬 (4종):

  스킬 1 — 「살수대첩」(궁극기)
    효과: 강 지형에서 수공(水攻) 발동
    → 적 유닛 3열 범위 침수 피해 + 이동력 -50%
    쿨타임: 12턴
    조건: 강 지형 + 아군 유닛 2기 이상 배치

  스킬 2 — 「환두대도」
    효과: 근접 단일 적 최대 피해
    → 현재 HP의 40% 피해 + 방어력 무시
    쿨타임: 3턴

  스킬 3 — 「성벽 사수」
    효과: 요새·성벽 방어 시 아군 전체 방어력 +40% (3턴)
    쿨타임: 6턴

  스킬 4 — 「기다려라」(고루 전용)
    효과: 1턴 완전 방어 → 다음 턴 반격 피해 2배
    쿨타임: 4턴
    고루 시그니처 — 을지문덕 전술 오마주
```

### 아랑 (阿郞) — 백제 전략 지원

```
기본 스탯 (최대 100):
  전투력   : ★★☆☆☆ (35) — 전투 비전문
  방어력   : ★★☆☆☆ (40) — 낮음
  기동력   : ★★★★☆ (75) — 빠른 이동
  지략     : ★★★★★ (98) — 최고 수준 정보력
  외교     : ★★★★★ (95) — 외교 협상 특화
  지형이용 : ★★★☆☆ (65) — 도시·건물 특화

왕국 특성 — 「백제의 기록」:
  교역 수입 +25%
  외교 협상 성공률 +20%
  적 유닛 정보 자동 수집 (은신 유닛 탐지)
  문서 획득 시 추가 정보 보너스

패시브 스킬:
  「기록하는 자」: 전투 후 적 유닛 패턴 학습 → 다음 전투 대응력 +15%
  「사비성의 등불」: 야간 전투 시 아군 전체 명중률 +20%
  「죽간의 비밀」: 적 내부 정보 획득 확률 +30%

액티브 스킬 (4종):

  스킬 1 — 「마지막 기록」(궁극기)
    효과: 아군 전체에게 「역사에 기록될 것」버프
    → 5턴 동안 사망 유닛 1회 부활 (HP 30% 회복)
    쿨타임: 15턴
    스토리 연계: 백제 멸망 전 발동 시 특별 대사

  스킬 2 — 「정보 분석」
    효과: 적 3유닛의 스탯·스킬 완전 공개
    → 다음 2턴 해당 적에게 피해 +25%
    쿨타임: 4턴

  스킬 3 — 「연등 신호」
    효과: 아군 원거리 유닛 명중률 +40% (야간·3턴)
    쿨타임: 5턴

  스킬 4 — 「외교 서한」
    효과: 적 소규모 유닛(3기 이하) 일시 중립화
    → 2턴 동안 전투 불참
    쿨타임: 8턴
```

### 하린 (夏麟) — 신라 공격대장

```
기본 스탯 (최대 100):
  전투력   : ★★★★☆ (85) — 근접+원거리 균형
  방어력   : ★★★☆☆ (65) — 화랑 갑옷
  기동력   : ★★★★★ (95) — 기마 최속
  지략     : ★★★☆☆ (70) — 현장 판단력
  외교     : ★★★★☆ (80) — 나당동맹 대표
  지형이용 : ★★★★☆ (82) — 평야·기마 특화

왕국 특성 — 「신라의 화랑」:
  기병 유닛 이동력 +25%
  평야 지형 기병 공격력 +20%
  화랑 영웅 유닛 능력치 +20%
  동맹 유지 기간 +30%

패시브 스킬:
  「화랑의 맹세」: HP 30% 이하 시 공격력 +50%
  「기마 추격」: 후퇴하는 적 추격 시 추가 피해 +30%
  「선덕여왕의 신뢰」: 아군 사기 최대치 시 전체 방어력 +15%

액티브 스킬 (4종):

  스킬 1 — 「기벌포 돌격」(궁극기)
    효과: 기병 유닛 전체와 함께 적진 돌파
    → 범위 피해 + 적 방어선 붕괴 (3턴 방어력 -30%)
    쿨타임: 10턴
    조건: 기병 유닛 3기 이상 보유

  스킬 2 — 「각궁 연사」
    효과: 적 5유닛 원거리 공격 (연속 사격)
    → 각 유닛 이동력 -20% (2턴)
    쿨타임: 3턴

  스킬 3 — 「관창의 정신」
    효과: 아군 전체 사기 최대치 + 공격력 +25% (2턴)
    스토리 연계: 관창 이벤트 후 해금
    쿨타임: 8턴

  스킬 4 — 「나당동맹」
    효과: 동맹 세력 지원군 1턴 소환
    → 당나라 궁병 유닛 3기 (1턴 한정)
    쿨타임: 12턴
    주의: 나당전쟁 분기 이후 사용 불가
```

### 니문 (尼文) — 가야 지원·회복

```
기본 스탯 (최대 100):
  전투력   : ★☆☆☆☆ (20) — 비전투 캐릭터
  방어력   : ★★☆☆☆ (30) — 취약
  기동력   : ★★★★☆ (78) — 강변 이동 특화
  지략     : ★★★★☆ (80) — 직관적 통찰
  외교     : ★★★★☆ (75) — 음악으로 소통
  지형이용 : ★★★★★ (88) — 강·수변 특화

왕국 특성 — 「가야의 소리」:
  수변 지형 아군 회복력 +25%
  문화 가치 높은 지역 수입 +20%
  가야 고분 지역 탐험 보너스
  음악 이벤트 트리거 (니문 전용 퀘스트)

패시브 스킬:
  「나라는 사라져도」: 아군 유닛 사망 시 주변 유닛 사기 유지 (하락 없음)
  「강의 기억」: 수변 지형에서 매 턴 아군 HP +5% 자동 회복
  「676」: 676 이벤트 조건 달성 시 특별 궁극기 해금

액티브 스킬 (4종):

  스킬 1 — 「기억의 강」(궁극기)
    효과: 가야금 연주 → 전장 분위기 전환
    → 아군 전체 HP 완전 회복 + 사기 최대치
    → 적 유닛 전체 공격력 -20% (3턴)
    쿨타임: 18턴 (희소성 있는 궁극기)

  스킬 1-EX — 「676 피날레」(특별 궁극기)
    조건: 676 이벤트 완료 + 4인 모두 생존
    효과: 기벌포 최종 승리 연출 + 전투 즉시 종료
    → 최고 등급 보상 지급
    사용 횟수: 캠페인 1회

  스킬 2 — 「가야금 소리」
    효과: 적 유닛 3기 이동 정지 (2턴)
    → 「소리에 이끌려」상태 — 공격 불가
    쿨타임: 5턴

  스킬 3 — 「소멸하지 않는 것」
    효과: 사망한 아군 영웅 카드 1장 재활성화
    쿨타임: 10턴

  스킬 4 — 「낙동강 황혼」
    효과: 강 지형 전체에 치유 오라 생성 (3턴)
    → 아군 유닛 매 턴 HP +10%
    쿨타임: 6턴
```

## 영웅 카드 시스템

```
역사 영웅 카드 능력:

을지문덕 (★★★★★):
  패시브: 아군 전체 지략 +15%
  액티브: 「신책구천문」— 적 지휘관 유닛 이동력 -50% (3턴)
  발동: 살수 지형에서 효과 2배

계백 (★★★★★):
  패시브: HP 50% 이하 아군 공격력 +30%
  액티브: 「결사오천」— 아군 5유닛 사기 최대치 + 방어 불굴 (1턴)
  특수: 황산벌 지형에서만 발동 가능한 전용 스킬

선덕여왕 (★★★★):
  패시브: 외교 협상 성공률 +25%
  액티브: 「첨성대의 예언」— 다음 2턴 적 행동 미리 공개

김유신 (★★★★):
  패시브: 화랑 유닛 전체 능력치 +20%
  액티브: 「삼국통일의 검」— 단일 적 즉사 (보스 제외)
  조건: 기벌포 해전 이후 해금
```

## 성장 시스템

```
레벨업:
  최대 레벨: 50
  경험치: 전투 승리 + 역사 퀴즈 + 탐험

스킬 트리:
  각 캐릭터 3개 브랜치 (공격/방어/지원)
  레벨 10/20/30/40/50에 스킬 포인트 지급

장비 시스템:
  무기: 환두대도·각궁·가야금·죽간 (각 캐릭터 고유)
  방어구: 왕국별 갑옷 (스킨과 연동)
  악세서리: 왕국 엠블럼·역사 유물 (능력치 보조)

한계 돌파:
  영웅 카드 합성 → 카드 등급 상승
  고루·아랑·하린·니문 특별 장비 합성
  → 메인 캠페인 전용 최강 장비
```
