```

- "삼국시대 진짜 역사" 시리즈 (10~15분)
- 캐릭터 심층 분석 (8~12분)

- 배경: 왕국별 색상 그라디언트

- 인물: 캐릭터 일러스트 또는 배우 (허가 후)
- 영문 부제 소형 표기

SEO 키워드:
"삼국시대", "고구려 역사", "광개토대왕", "계백 장군",
"살수대첩", "Korean three kingdoms", "K-drama history"
```

### 트위터 / X

```

형식: 텍스트 우선 + 이미지 첨부

트윗 유형:

2. 캐릭터 어록: "을지문덕이 말했다: [대사]"
3. 퀴즈: "[질문]? A or B — RT로 답해주세요"
4. 드라마/게임 업데이트

스레드 활용:
- "삼국시대 5대 명전투 🧵" 형식
- 역사 사건 상세 설명 (10~15트윗)
```

### 틱톡

```
포스팅 빈도: 일 1~2회
길이: 15~60초

콘텐츠 유형:
1. "교과서가 가르쳐주지 않은 [주제]"
2. POV 시리즈: "당신이 [역사 인물]이라면"
3. Before/After: "삼국 통일 전 vs 후"
4. 트렌드 사운드 + 역사 비틀기

틱톡 전용 전략:
- 인기 사운드 + 역사 내용 결합
- 댓글 답변을 새 영상으로 제작
- 듀엣 기능 활용 — 팬과의 상호작용
```
