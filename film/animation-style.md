# 애니메이션 스타일 가이드 — 삼국(三國) IP

**참조 문서**: `art-bible.md`, `color-palette.md`, `character-design-sheets.md`, `storyboard-guide.md`
**작성**: 영상&애니메이션본부 애니팀 (FILM-ANI)
**적용**: 삼국(三國) IP TVA·OVA·극장판 애니메이션 비주얼 기준

## 애니메이션 스타일 개요

```
형식:
  TVA (TV 시리즈): 시즌 1 — 24화 × 23분
  OVA (특별편): 살수대첩·황산벌·기벌포 각 45분
  극장판: 시즌 완결 후 120분 (검토)

스타일 방향:
  세미 리얼리스틱 (극화 애니메이션)
  참조: 「빈랑드 사가」+ 「킹덤(Kingdom)」+ 「귀멸의 칼날」
  한국 애니메이션 정체성: 국악 사운드 + 한국 색채미

제작 방식:
  2D 작화 기본 + 3D CG 배경·전투 보조
  전투 대규모 씬: 3D 군중 + 2D 영웅 합성
  가야금 연주 씬: 로토스코핑 (실제 연주 기반)
```

## 캐릭터 디자인 (애니용)

### 기본 비율

```
주인공 4인: 8등신 (사실적 비율)
역사 인물: 8~8.5등신 (위엄 강조)
일반 병사: 7등신 (간략화)
코믹 릴리프 (있을 경우): 6등신 (제한적)

얼굴 스타일:
  눈: 사실적 크기 (일본 대형 눈 스타일 금지)
  코: 측면·정면 모두 묘사
  입: 감정에 따른 세밀 변화
  특징: 왕국별 얼굴 톤 차이 (피부색·골격)
```

### 캐릭터별 애니 디자인

```
고루:
  선 굵기: 두꺼운 외곽선 (존재감)
  동작: 절제된 움직임 (불필요한 동작 없음)
  표정 키프레임: 무표정 → 미세한 눈빛 변화
  전투 모션: 직선적·힘 있는 검격
  색상: 고구려 청람 (#2F4F7F) 기조

아랑:
  선 굵기: 가늘고 유려한 선
  동작: 섬세한 손동작 (붓·죽간 작업)
  표정 키프레임: 침착 → 걱정 → 눈물
  특수: 붓 쓰는 장면 — 실제 서예 모션 참조
  색상: 백제 황금 (#B8960C) + 담청

하린:
  선 굵기: 날카로운 외곽선 (역동성)
  동작: 빠르고 역동적 (화랑 기마 액션)
  표정 키프레임: 자신감 → 분노 → 후회
  전투 모션: 기마 활쏘기 — 활 연속 발사 시퀀스
  색상: 신라 황금 (#FFD700) + 화랑 적

니문:
  선 굵기: 가장 가는 선 (존재감 미묘)
  동작: 느리고 부드러운 (가야금 연주)
  표정 키프레임: 고요 → 깊은 슬픔 → 미소
  특수: 가야금 현 진동 — 프레임 바이 프레임 작화
  색상: 가야 황토 (#C8A96E)
```

## 배경 미술

### 왕국별 배경 스타일

```
고구려:
  화풍: 안악3호분 벽화 참조 — 거친 질감
  색조: 청람 + 회색 + 갈색
  배경 밀도: 높음 (석조 건축 디테일)
  하늘: 넓고 높은 하늘 (요동 평원)
  특수: 안개·눈·봉화 이펙트

백제:
  화풍: 섬세한 수채화 터치
  색조: 황금 + 크림 + 따뜻한 갈색
  배경 밀도: 중간 (우아한 건축)
  특수: 연등 빛 — 반투명 레이어 합성

신라:
  화풍: 선명한 채색 — 밝은 톤
  색조: 황금 + 적색 + 청동
  배경 밀도: 높음 (황룡사·금관 디테일)
  특수: 골든아워 역광 이펙트

가야:
  화풍: 미니멀 수묵화 터치
  색조: 황토 + 녹색 + 갈색
  배경 밀도: 낮음 (여백 강조)
  특수: 낙동강 수면 반사 — 수채 텍스처
```

### 3D CG 활용 기준

```
3D 사용 씬:
  대규모 전투 군중 (1,000명 이상 병력)
  성벽·건축물 외관 (카메라 회전 씬)
  배·전함 해전 씬 (기벌포)
  살수대첩 물 시뮬레이션

3D → 2D 합성 규칙:
  3D 군중: 셀룩 셰이더 적용 (2D 느낌 유지)
  카메라 무빙: 3D 배경 + 2D 캐릭터 합성
  이질감 방지: 3D 오브젝트에 2D 외곽선 후처리
  최종 합성: After Effects 컴포지팅
```

## 액션·전투 애니메이션

### 전투 스타일

```
고구려 전투:
  특징: 무겁고 강한 타격감
  검격: 크고 느린 스윙 → 임팩트 순간 스피드 업
  기마전: 말 달리기 16프레임 사이클 + 창 찌르기
  살수대첩: 물 이펙트 풀 애니메이션 (30초 시퀀스)

신라 전투:
  특징: 빠르고 날렵한 액션
  화랑 활쏘기: 활 연속 발사 — 3연사 시퀀스
  기마 질주: 빠른 컷 교차 편집
  황산벌: 군중 전투 3D + 하린 2D 액션 합성

백제 전투:
  특징: 비극적·아름다운 전투
  계백 결사대: 슬로모션 행진
  백강구 해전: 배 충돌 + 화염 이펙트
  낙화암: 절벽 장면 — 카메라 수직 이동

가야 전투 (과거 플래시백):
  특징: 짧고 슬픈 전투
  멸망 씬: 세피아 톤 + 잔상 효과
  가야금 사운드 오버레이 (전투 중 음악)
```

### 특수 액션 연출

```
살수대첩 수문 장면 (OVA 핵심 씬):
  프레임 수: 24fps 풀 애니메이션 (리미티드 금지)
  수문 레버: 고루 팔 근육 디테일 작화
  물 방류: 3D 유체 시뮬레이션 + 2D 이펙트 합성
  물살에 휩쓸리는 수나라군: 실루엣 + 잔상 처리
  소요: 약 60초 시퀀스 / 제작 기간: 3주

가야금 연주 장면 (TVA 매 에피소드 ED):
  로토스코핑: 실제 가야금 연주자 촬영 → 작화 트레이스
  손가락: 프레임 바이 프레임 (12현 각각 구분)
  현 진동: 2D 이펙트 (파동 라인)
  음파 시각화: 왕국 색상 파티클 이펙트
```

## 이펙트 & 후처리

```
전투 이펙트:
  검격 잔상: 2D 속도선 + 광선 효과
  혈흔: 검은색 잉크 스타일 (과도한 유혈 금지, 15세 등급)
  화염: 2D 전통 애니메이션 (3D 화염 금지)
  먼지·모래: 파티클 합성

자연 이펙트:
  강물: 수채 텍스처 + 움직이는 반사광
  눈: 2D 파티클 (고구려 겨울 씬)
  바람: 머리카락·옷 나부낌 (12fps 이상)
  연등: 발광 레이어 + 반투명 합성

감정 연출 이펙트:
  눈물: 리얼리스틱 (얼굴 위 흐름 작화)
  분노: 배경 적색 쉬프트 + 스피드 라인
  슬픔: 채도 저하 + 비네팅
  결의: 역광 + 광선 이펙트

후처리 (컴포지팅):
  그레인: 미세 필름 그레인 (역사물 질감)
  블룸: 금관·연등·화염에만 적용
  색보정: 왕국별 LUT 적용 (color-palette.md)
```

## 제작 사양

```
해상도: 1920×1080 (FHD) / 4K 업스케일 (극장판)
프레임: 24fps 기본 (리미티드 12fps + 핵심 씬 24fps)
색공간: sRGB (방송·스트리밍)
파일: TGA 시퀀스 → ProRes 4444 마스터

제작 공정:
  프리프로덕션: 콘티·레이아웃·설정 (3개월)
  프로덕션: 원화·동화·배경·CG (12개월)
  포스트프로덕션: 촬영·편집·음향 (3개월)

인력 (TVA 기준):
  감독: 1명
  작화감독: 2명 (액션·캐릭터)
  원화: 20~30명
  동화: 40~60명
  배경: 10~15명
  3D CG: 5~10명
  촬영·편집: 5명

스튜디오:
  국내 애니메이션 스튜디오 협업 (메인)
  일본 하청: 동화·배경 일부 (품질 기준 충족 시)
```
