## 고구려 역사 인물

### 을지문덕 (乙支文德)

```
생몰: 미상 (~612년 활동 확인)
직위: 대신 — 살수대첩 당시 총사령관
사료: 삼국사기 열전 / 수서 권 60

역사적 사실:
✅ 612년 살수대첩 주인공
✅ 수 우중문에게 한시 보냄 (삼국사기 수록)
✅ 7번 패퇴 전략 → 살수 결전 (수서 기록)
✅ 노장(老將) 이미지 (살수대첩 시 고령 추정)

IP 캐릭터 설정:
나이: 살수대첩 당시 60대 후반 추정
외형: 흰 수염·주름진 얼굴·형형한 눈빛
성격: 과묵·깊은 통찰·감정을 거의 드러내지 않음
       강물처럼 — 느리게 보이나 결정적 순간 압도

대표 대사 (한시):
「神策究天文 妙算窮地理
  戰勝功旣高 知足願云止」
(신책究천문 묘산궁지리
  전승공기고 지족원운지)
→ 표면: 「이겼으니 이제 그만 하시지요」
→ 내면: 「강이 이긴다. 나는 안내할 뿐이다」

고루와의 관계:
스승 — 고루는 을지문덕 직전제자 설정
살수대첩에서 고루에게 「강은 기억한다」전수
EP07 말미 쓰러짐 → 고루 혼자 남다

미디어 역할:
드라마: 시즌 1 EP01~07 주요 조연 (EP07 퇴장)
소설: 1~7장 주요 등장
게임: 한정 ★★★★★ 유닛 — 「살수의 노장」
뮤지컬: 1막 핵심 역할 「기억하는 자 / He Who Remembers」
```

### 연개소문 (淵蓋蘇文)

```
생몰: ~665년
직위: 대막리지 (642~665년) — 고구려 실권자
사료: 삼국사기 연개소문 열전 / 구당서

역사적 사실:
✅ 642년 영류왕 시해 + 귀족 180명 처단
✅ 보장왕 옹립
✅ 허리 5도(刀) 무장 (구당서 기록)
✅ 당나라 침략 3차례 격퇴 (645·647·648년)
✅ 665년 사망 → 아들 형제 분열 → 고구려 멸망 원인

IP 캐릭터 설정:
나이: 642년 쿠데타 당시 40대
외형: 강건한 체형·날카로운 눈·5자루 칼 허리에
성격: 냉철·결단·목적을 위한 수단 정당화
       그러나 고구려 수호를 위한 진심도 존재
       「복잡한 인물」— 영웅인가 반역자인가

묘사 원칙:
단순 악인 묘사 금지 (historical-accuracy-report.md)
항당(抗唐) 명분·애국심 부각
왕을 죽인 자의 내면 갈등 묘사

고루와의 관계:
주종 — 연개소문이 고루를 기용
고루는 왕이 아닌 「나라」를 위해 따른다
신뢰하되 두려운 관계 (상호 존중+긴장)

미디어 역할:
드라마: 시즌 1 EP08~ 주요 조연
소설: 19장 「연개소문의 칼」핵심 등장
게임: ★★★★★ 유닛 — 「대막리지」
뮤지컬: 2막 「칼의 논리 / Logic of the Blade」
```

## 백제 역사 인물

### 성충 (成忠)

```
생몰: ~656년
직위: 백제 좌평 (상위 귀족 관료)
사료: 삼국사기 의자왕기

역사적 사실:
✅ 의자왕에게 직간(直諫) → 투옥
✅ 옥중에서 나당 연합 경고 상소 (삼국사기 수록)
✅ 656년 옥중 사망

IP 캐릭터 설정:
나이: 아랑 스승 — 아랑보다 30년 연상 추정
성격: 원칙주의·충직·비극적 운명 수용
아랑과의 관계: 스승 — 아랑에게 기록의 사명 전수

대표 대사:
「왕이 듣지 않는 말을, 강이 듣는다」
→ 아랑에게 남긴 유언 (IP 창작 대사)

미디어 역할:
드라마: 시즌 1 EP08~10 / 시즌 2 EP01~02
소설: 17장·20장 핵심 등장
게임: ★★★★ 유닛 — 「충신의 무게」
```

### 계백 (階伯)

```
생몰: ~660년 황산벌 전투 전사
직위: 백제 장군 — 황산벌 결사대 5천 지휘
사료: 삼국사기 계백 열전

역사적 사실:
✅ 660년 황산벌에서 신라 5만에 맞서 5천 결사대 지휘
✅ 출전 전 가족 손수 처형 (재기 불능 시 포로 방지)
✅ 4번 싸워 4번 이겼으나 관창 이후 패배·전사

IP 캐릭터 설정:
나이: 660년 당시 50대 추정
외형: 굳은 표정·깊은 눈·비장한 분위기
성격: 극단적 충의·나라 위해 모든 것 희생
       「비극의 영웅」— 이길 수 없는 전투를 싸운 자

하린과의 관계:
적장 — 하린이 맞서 싸우는 상대
하린은 계백을 증오하지 않음 — 존경하는 적
전사 후 하린의 독백: 「용감한 자였다」

미디어 역할:
드라마: 시즌 2 EP03~04 핵심 조연
게임: ★★★★★ 유닛 — 「황산벌의 결사」(비극 영웅 타입)
```

## 신라 역사 인물

### 선덕여왕 (善德女王)

```
생몰: ~647년
직위: 신라 27대 왕 (632~647년 재위)
사료: 삼국사기·삼국유사

역사적 사실:
✅ 한반도 최초 여왕
✅ 황룡사 9층 목탑 건립 추진
✅ 첨성대 건립
✅ 3가지 예언 일화 (삼국유사 선덕왕 지기삼사)
   ① 모란꽃 그림 — 향기 없을 것 예언
   ② 개구리 울음 — 적군 숨은 곳 예언
   ③ 자신의 죽음 날짜 예언

IP 캐릭터 설정:
나이: 하린 활동기 (612~645년) 당시 40~50대
외형: 단아한 자태·그윽한 눈·왕의 품위
성격: 조용한 확신·예지와 정치력 결합
       「아는 것의 무게」— 예언이 짐이 되는 왕

하린과의 관계:
군주 + 정신적 스승 — 하린의 충성 대상
선덕여왕의 예언이 하린의 행동 동기

대표 대사:
「하린아. 나는 예언한다. 신라는 반드시 삼국을 통일한다.
  하지만 그 길에는 피가 있다.」

미디어 역할:
드라마: 시즌 1 EP10·15 주요 조연 (647년 사망)
소설: 21장 간접 등장 (하린 회상)
게임: ★★★★★ 유닛 — 「예언자 왕」
뮤지컬: 2막 「아는 것의 무게 / Weight of Knowing」
```

### 관창 (官昌)

```
생몰: 645년생 추정~660년 황산벌 전사
직위: 신라 화랑 — 품일 장군의 아들
사료: 삼국사기 관창 열전

역사적 사실:
✅ 660년 황산벌 전투에서 16세 나이로 출전
✅ 계백에게 생포 → 석방 → 재출전
✅ 재생포 후 전사 → 신라군 사기 전환 계기

IP 캐릭터 설정:
나이: 황산벌 당시 16세
성격: 두려움 없음·화랑 세속오계 체화
       죽음보다 비겁함을 두려워하는 아이
       「나이보다 오래된 영혼」

하린과의 관계:
스승 — 하린이 관창에게 출전 말리려 했으나 막지 못함
하린의 내면 갈등: 보내야 하는 것을 알면서도

미디어 역할:
드라마: 시즌 2 EP03~04 핵심 등장 (전사)
소설: 21장 「관창」핵심 씬
게임: ★★★★ 유닛 — 「황산벌의 화랑」(희생·전투력 부스터)
```

## 가야 역사 인물

### 우륵 (于勒)

```
생몰: 6세기 활동 (정확한 생몰 미상)
직위: 가야 악사 — 가야금 창시자
사료: 삼국사기 악지(樂志)

역사적 사실:
✅ 가야금 창제 또는 완성 (삼국사기 기록)
✅ 12악곡 작곡 (삼국사기 수록 12곡명)
✅ 562년 가야 멸망 직전 신라로 귀순
✅ 진흥왕의 보호 하에 신라에서 활동

IP 캐릭터 설정:
직접 등장: 없음 (니문의 할아버지가 우륵 제자 설정)
간접 존재: 니문의 가야금 = 우륵의 정신 계승
12번째 악곡: 우륵이 미완성으로 남긴 곡 → 니문이 완성

대표 대사 (니문 회상 속):
「음악은 나라보다 오래 산다」

미디어 역할:
드라마: 직접 등장 없음 (언급만)
소설: 니문 배경 서술에 등장
게임: ★★★★ 유닛 — 「가야금의 창시자」(지원·힐 특화)
```
