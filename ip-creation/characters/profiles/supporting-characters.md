## 조연 캐릭터 개요

```
분류:
  A급 조연: 서사 핵심 기여 (5~10회 이상 등장)
  B급 조연: 특정 시즌 중요 역할 (3~5회 등장)
  역사 인물: 실존 인물 창작 해석 (등장 제한)

원칙:
  역사 인물: 기록 기반 + 창작 해석 (왜곡 금지)
  창작 조연: 4주인공 서사 보완 역할
  모든 조연: 「악인 단순화」금지
```

## A급 조연 — 역사 인물

### 을지문덕 (乙支文德)

```
국적: 고구려
역할: 고루의 스승 + 살수대첩 실제 지휘관
등장: S1 전체 (10회+)

역사적 사실:
  살수대첩 612년 주도 — 수나라 113만 대군 격파
  오언시 작성 — 우중문에게 보낸 「신책구천문」
  실제 관직: 정확히 알려지지 않음 (장군급 추정)

창작 해석:
  고루의 직계 스승 설정
  「기다려라」전략 철학의 원천
  감정 절제된 노장 — 전쟁의 허무함 인지

캐릭터 어조:
  고루보다 더 절제됨 (말이 거의 없음)
  한시 인용 다수 (오언시 원문 활용)
  「때를 알아야 한다」반복 가르침

외형:
  연령: 50대 중반 추정
  인상: 날카로운 눈빛 + 흰 수염 시작
  복식: 고구려 고위 무장 갑옷 (간소·실용)
```

### 계백 (階伯)

```
국적: 백제
역할: 황산벌 결사대 지휘관
등장: S3 집중 (5회)

역사적 사실:
  660년 황산벌 전투: 5,000 결사대 이끌고 신라군에 맞섬
  전투 전 처자식 직접 처결 (역사 기록 논쟁)
  황산벌에서 전사 — 백제 마지막 저항의 상징

창작 해석:
  「악인 아님」— 나라를 지키려 한 비극적 무장
  아랑 시점: 「그도 백제를 사랑했던 사람」
  하린 시점: 「적이지만 존경할 수 있는 용기」
  처자식 처결 장면: 직접 묘사 금지 → 암시만

캐릭터 어조:
  단호하고 비장 (살 희망을 버린 사람)
  부하들에 대한 애정 표현
  「백제는 기억될 것이다」마지막 대사

외형:
  연령: 40대
  인상: 수척하고 결연한 표정
  복식: 백제 고위 무장 갑옷 + 흰 머리띠 (결사 표시)
```

### 선덕여왕 (善德女王)

```
국적: 신라
역할: 하린의 군주 + 화랑 정신의 후원자
등장: S1~S2 (8회)

역사적 사실:
  재위: 632~647년
  한국 최초 여왕
  황룡사 9층 목탑 건립 명령
  첨성대 건립 시기 (논쟁 있음)
  독자적 외교 — 당나라와 관계 유지

창작 해석:
  하린의 이상적 군주 이미지 → 이후 실망 가능성
  「지혜로운 지도자」— 「마녀」묘사 절대 금지
  여성 지도자 = 탁월한 통치 능력

캐릭터 어조:
  고상하고 지혜로운 말투
  하린에게: 따뜻하지만 원칙적
  「살아남아야 지킬 수 있다」핵심 철학

외형:
  연령: 40~50대
  인상: 강인함 + 우아함 공존
  복식: 신라 왕실 의례복 + 금관 (의례 장면)
```

### 연개소문 (淵蓋蘇文)

```
국적: 고구려
역할: 고구려 권력의 핵심 — 고루의 딜레마
등장: S2~S3 (7회)

역사적 사실:
  642년 정변: 영류왕 시해 + 보장왕 옹립
  막리지(莫離支) 취임 — 최고 실권자
  당나라에 강경 외교
  666년 사망 → 아들들 내분 → 고구려 멸망 가속

창작 해석:
  고루와의 긴장: 을지문덕 계승 노선 vs 연개소문 강경파
  「나쁜 사람이 아님」— 고구려 수호 방식의 차이
  독재적이지만 진정한 고구려 수호 의지
  고루의 갈등: 복종 vs 소신

캐릭터 어조:
  강압적이지만 논리적
  고루에게: 「네 스승 을지문덕은 죽었다」
  자신감 넘치는 권위

외형:
  연령: 40대 (S2 등장 시)
  인상: 압도적 존재감 + 삼첩 수염 (역사 기록)
  특징: 역사 기록 — 5개 칼 허리에 찬다 (창작 반영)
```

## A급 조연 — 창작 인물

### 관창 (官昌) — 하린의 벗

```
국적: 신라
역할: 하린의 가장 친한 벗 + 황산벌 희생
등장: S1~S3 초반 (15회) → S3 황산벌에서 사망

역사적 근거:
  실존 인물: 신라 화랑 관창
  황산벌 전투 소년 용사 — 돌격 + 포로 + 재돌격 + 전사
  화랑 정신의 상징

창작 해석:
  하린과의 어릴 때부터 우정 (창작)
  「10년 후에 물어봐」하린과 장난치는 소년
  성장: S1 소년 → S3 청년 무사
  황산벌 결정: 자발적 선택 (강요 아님)

캐릭터 어조:
  밝고 직설적 (하린보다 더 충동적)
  하린에게: 진심 어린 우정 표현
  마지막 장면: 무서움 인정 + 앞으로 나아감

외형:
  연령: 하린보다 2~3세 어림 (초등장 14~15세)
  인상: 밝은 눈빛 + 햇볕에 그을린 피부
  복식: 화랑 훈련복 → 이후 갑옷
```

### 아랑의 어머니 — 기억 전수자

```
국적: 백제
역할: 아랑에게 「기억의 의무」전수
등장: S1 초반 (플래시백 포함 5회)

설정:
  백제 문서관 수석 서기 (창작)
  「자수는 기록이다」가르침
  아랑이 어린 시절 사망 → 아랑의 동기 원천

캐릭터 어조:
  부드럽지만 확고한 원칙
  아랑에게: 「잊으면 사라진다」반복
  죽기 전: 미완성 자수 조각 전달

외형:
  연령: 30대 중반 (사망 시)
  인상: 아랑과 닮은 눈빛
  특징: 항상 자수 바늘 들고 있음
```

### 니문의 할아버지 — 마지막 가야 음악인

```
국적: 가야 유민 (신라 치하)
역할: 니문에게 가야금 + 가야 기억 전수
등장: S1 초반 (5회) → 사망

설정:
  대가야 마지막 악사 후예 (창작)
  「나라는 없지만 소리는 있다」가르침
  니문에게 가야금 + 12현 비밀 전수

캐릭터 어조:
  거의 말하지 않음 — 가야금으로 표현
  임종 씬: 마지막으로 가야금 12현 이름 알려줌
  「676」곡의 기원 전달

외형:
  연령: 70대
  인상: 주름진 손 + 현에 닳은 손가락
  특징: 항상 낡은 가야금 안고 앉아있음
```

## B급 조연

```
우중문 (于仲文) — 수나라 장군 (S1):
  을지문덕 오언시 수신자 (역사 기록)
  「악인 아님」— 명령에 충실한 직업군인
  고루 시점: 적이지만 용기 있는 자

김춘추 (金春秋) — 훗날 무열왕 (S2~S3):
  나당연합 주도 외교가
  하린 딜레마의 원천: 「당나라를 부른 사람」
  비극적 영웅 — 통일 이루었지만 수단 논란

흑치상지 (黑齒常之) — 백제 장군 (S3):
  660년 백제 멸망 후 당나라에 투항
  아랑 시점: 「살기 위해 적에게 붙은 자」vs「생존 전략」

연남생 (淵男生) — 연개소문 장남 (S3):
  고구려 멸망 원인 — 당나라 길잡이
  고루 시점: 극한의 배신감 + 이해 불가
```

## 캐릭터 관계도 요약

```
고루 ←스승→ 을지문덕
고루 ←갈등→ 연개소문
고루 ←적이지만 경쟁→ 하린 (나당전쟁 전)

아랑 ←기억 전수→ 어머니
아랑 ←왕국의 거울→ 계백
아랑 ←기록자→ 역사 전체

하린 ←우정·상실→ 관창
하린 ←군주·이상→ 선덕여왕
하린 ←외교 딜레마→ 김춘추

니문 ←가야금 전수→ 할아버지
니문 ←가해자 후손→ 하린 (미묘한 긴장)
니문 ←목격자→ 역사 전체
```
