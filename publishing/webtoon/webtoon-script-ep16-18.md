## EP16: 「마지막 서간」

```
화 정보:
  제목: 마지막 서간 (最後の書簡)
  영문: The Last Letter
  컷 수: 78컷
  주인공: 아랑 (1인칭 시점)
  배경: 백제 사비성, 660년 여름
  색조: 백제 왕실금 → 점점 어두워지는 LUT

시놉시스:
  백제 멸망 직전. 아랑은 성충의 유언을 이어받아
  나당 연합군 진격 경보 속에서 마지막 기록을 남긴다.
  기록할 수 없는 것을 기록하려는 아랑의 사투.
```

## EP17: 「첫 소절」

```
화 정보:
  제목: 첫 소절 (最初の節)
  영문: The First Note
  컷 수: 72컷
  주인공: 니문 (1인칭)
  배경: 가야 낙동강변 초가, 660년 여름
  색조: 가야 토황 → 석양빛 따뜻한 LUT

시놉시스:
  가야 멸망 98년 후. 신라에 편입된 가야 유민 니문.
  12번째 악곡의 첫 소절이 완성되는 밤.
  그리고 깨닫는다 — 12번째는 완성이 아니라 시작임을.
```

### 씬 구성 (요약)

```
[SCENE 1 — 낙동강변 초가 / 황혼] (컷 1~18)
  - 니문, 12번째 악곡 악보 앞에서 오래 침묵
  - 할아버지 회상: 「12번째는 우륵 선생이 남긴 것이다. 완성할 수 없었던 것.」
  - 니문의 손이 현 위에서 처음으로 움직임

대사 하이라이트:
  니문 (나레이션):
  「12번째는 우륵 선생이 시작하고 멈춘 곡.
   할아버지가 이어받아 멈추었고,
   내가 이어받아 멈추었다.
   오늘 밤, 나는 멈추지 않겠다.」

[SCENE 2 — 연주 시작] (컷 19~40)
  - 니문, 연주 시작 — 시각적 음악 표현 (현 파동 → 색 변화)
  - 음악이 가야 멸망의 기억을 불러옴 (플래시백)
  - 가야 멸망 씬: 쓰러지는 군기, 흩어지는 유민들
  - 할아버지의 마지막 모습

대사 하이라이트:
  니문 (연주 중, 눈 감고):
  「가야는 사라졌다.
   하지만 가야금은 남았다.
   음악은 나라보다 오래 산다.」

[SCENE 3 — 첫 소절 완성] (컷 41~60)
  - 새벽. 니문, 처음으로 12번째 악곡의 첫 소절 완성
  - 가야금 현이 완벽한 화음으로 울림
  - 니문, 눈 뜸 — 눈에 눈물
  - 악보에 첫 소절 완성 기록

대사 하이라이트:
  니문 (완성 순간):
  「...완성이 아니다.
   시작이다.
   12번째는 끝이 아니라 새로운 첫 소절.
   이 곡이 완성될 때, 뭔가가 시작될 것이다.」

[SCENE 4 — 엔딩] (컷 61~72)
  - 새벽 낙동강. 강물이 노래하듯 흐름
  - 니문, 강을 바라보며 악보 꽉 쥠
  - 나레이션: 「나는 12번째를 완성할 것이다. 그날까지 살아야 한다.」
  - 다음화 예고: 고루, 연개소문의 명령을 받는 장면
```

## EP18: 「대막리지의 명령」

```
화 정보:
  제목: 대막리지의 명령 (大莫離支の命令)
  영문: The Grand Marshal's Order
  컷 수: 80컷
  주인공: 고루 (3인칭)
  조연: 연개소문 (핵심 등장)
  배경: 고구려 평양성, 660년 겨울
  색조: 고구려 암청 — 긴장감 최대

시놉시스:
  백제 멸망 소식이 고구려에 전해진다.
  연개소문은 고루를 불러 특명을 내린다.
  「당나라 진격을 막아라. 고구려가 다음이다.」
  고루는 을지문덕의 가르침을 떠올린다 — 강은 기다린다.
```

### 씬 구성 (요약)

```
[SCENE 1 — 평양성 대막리지 집무실 / 새벽] (컷 1~20)
  - 연개소문, 5자루 칼을 허리에 차고 지도를 바라봄
  - 고루, 소환되어 들어옴
  - 연개소문: 「백제가 사라졌다. 신라가 다음이고, 그다음은 우리다.」

대사 하이라이트:
  연개소문:
  「고루야. 강가에 진을 쳐라.
   당이 오는 길목에. 그리고 기다려라.
   을지문덕이 살수에서 그랬듯이.」

  고루 (속으로): 「을지문덕 선생... 선생이 말씀하셨지.
                 강은 이긴다. 나는 안내할 뿐이라고.」

[SCENE 2 — 을지문덕 회상] (컷 21~45)
  - EP07 플래시백 연동 — 을지문덕의 가르침
  - 살수에서 을지문덕이 고루에게 전수한 것
  - 「강은 기억한다」말의 진짜 의미

대사 하이라이트 (플래시백):
  을지문덕 (노장 목소리):
  「고루야. 강은 이기지 않는다.
   강은 기다린다.
   그리고 적이 지칠 때, 강은 기억을 드러낸다.
   그 기억이 이긴다.」

  고루 (현재): 「선생은 기억을 무기로 삼으셨다.
               나는 그것을 물려받았다.」

[SCENE 3 — 명령 수락] (컷 46~65)
  - 고루, 연개소문에게 수락 의사 표명
  - 연개소문, 처음으로 고루를 인정하는 눈빛
  - 고루, 나가려다 돌아봄

대사 하이라이트:
```
