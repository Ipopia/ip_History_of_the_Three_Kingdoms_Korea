# 삼국시대 외교 역사 기록 — 전문자문본부

**참조 문서**: `chronicles.md`, `political-systems.md`, `glossary.md`
**자문**: 전문자문본부 — 역사 자문, 국제외교 자문
**원전**: 삼국사기(三國史記), 삼국유사(三國遺事), 일본서기(日本書紀), 수서(隋書), 구당서(舊唐書), 송서(宋書)

---

## 개요

삼국시대 외교는 단순한 국가 간 교섭이 아니었다. **생존·패권·문화 이식**을 동시에 수행하는 복합적 전략이었다. 고구려는 중국 왕조에 맞서거나 협력하며 독립성을 유지했고, 백제는 남중국·왜국과의 교류로 문화 중계자 역할을 수행했으며, 신라는 처음에 고구려·백제에 압박받다 결국 당나라와 연합해 삼국을 통일했다.

---

## 1. 고구려의 외교

### 1-1. 중국 왕조와의 관계

#### 전연(前燕)과의 충돌 — 4세기
```
342년: 전연 모용황(慕容皝)이 고구려 침략
       → 고구려 도성 함락, 미천왕 묘 도굴, 왕비·민 5만 포로
       → 고국원왕의 굴욕적 화의
창작 활용: 고국원왕의 치욕과 복수 다짐 — 서사 출발점
```

#### 수(隋)나라와의 전쟁 — 7세기
| 연도 | 사건 | 결과 |
|------|------|------|
| 598년 | 수 문제 30만 원정 | 고구려 격퇴 |
| 612년 | 수 양제 113만 원정 — 살수대첩 | 고구려 대승 |
| 613년 | 수 양제 2차 원정 | 내부 반란으로 철수 |
| 614년 | 수 양제 3차 원정 | 강화 후 철수, 수나라 멸망 가속 |

```
외교적 맥락:
- 고구려는 수나라와 전쟁 전까지 조공 외교 유지
- 영양왕이 말갈 병력으로 요서 선제 공격 → 전쟁 발발
- 수나라 멸망(618)으로 고구려 패권 절정기
창작 활용: 살수대첩 — 을지문덕의 위계 외교(시 전송 사건) 포함
```

**을지문덕의 외교적 시**
```
삼국사기 기록 — 을지문덕이 수나라 장수 우중문에게 보낸 시:
"신책구천문(神策究天文)
 묘산궁지리(妙算窮地理)
 전승공기고(戰勝功旣高)
 지족원운지(知足願云止)"

번역: "신기한 전략은 하늘의 이치를 꿰뚫고
      오묘한 계산은 땅의 지리를 다 알았으니
      전쟁에서 이기어 공이 이미 높은지라
      만족함을 알고 그만 물러가기를 원하노라"

→ 겉으로는 칭찬, 속으로는 '이미 졌으니 돌아가라'는 조롱
창작 활용: 을지문덕 캐릭터 — 칼보다 붓이 날카로운 지략가 이미지
```

#### 당(唐)나라와의 전쟁 — 7세기
| 연도 | 사건 | 결과 |
|------|------|------|
| 645년 | 당 태종 친정 — 안시성 전투 | 고구려 수비 성공 |
| 647년 | 당 2차 원정 | 소규모 공격, 성과 없음 |
| 648년 | 당 3차 원정 | 고구려 견제 |
| 661~668년 | 나당 연합 최종 공격 | 고구려 멸망 |

```
안시성 전투 외교적 의의:
- 당 태종이 안시성주(추정 양만춘)에게 비단 100필 선물 — 용맹 인정
- 고구려의 독립 의지를 전 동아시아에 과시
창작 활용: 안시성주의 정체성 — 이름조차 역사에 없는 무명 영웅의 비장함
```

### 1-2. 백제·신라와의 관계

```
고구려-백제 관계:
- 장수왕 427년 평양 천도 → 남진 정책 시작
- 475년 장수왕이 백제 한성(漢城) 함락 → 개로왕 전사
- 이후 고구려-백제는 기본적으로 적대 관계

고구려-신라 관계:
- 4~5세기: 신라가 고구려에 종속적 — 왕자를 볼모로 보냄
- 광개토왕이 신라를 도와 왜구 격퇴 (400년)
- 6세기: 신라의 성장으로 관계 역전 → 대립으로 전환
```

## 2. 백제의 외교

### 2-1. 남중국 왕조와의 교류

```
백제는 황해를 건너 중국 남조(南朝)와 적극적으로 교류했다.
- 동진(東晉)·유송(劉宋)·남제(南齊)·양(梁) 등 남조 역대 왕조와 조공 무역
- 불교·유교 경전, 의복, 악기, 공예 기술 수입
- 백제왕이 남조에서 "진동대장군(鎭東大將軍)" 등 작호 수여받음

외교적 의의:
- 고구려의 배후를 견제하기 위한 전략적 동맹
- 동시에 선진 문물 수입 창구
```

| 연도 | 왕조 | 외교 내용 |
|------|------|---------|
| 372년 | 동진 | 근초고왕 — 동진으로부터 작호 수여 |
| 5세기 | 유송 | 상표문(上表文) 외교 — 고구려 견제 요청 |
| 521년 | 양 | 성왕 즉위 — 양나라 불교 경전·승려 요청 |

### 2-2. 왜국(倭國, 일본)과의 교류

**백제-왜 관계는 삼국시대 최대의 문화 전파 사례**

```
주요 교류 기록:
- 369년: 칠지도(七支刀) 하사 — 근초고왕 → 왜왕
          (현재 일본 이소노카미 신궁 소장)
- 4~5세기: 아직기(阿直岐)·왕인(王仁) 파견 → 논어·천자문 전수
- 513년: 오경박사(五經博士) 파견 — 유교 경전 전수
- 554년: 음악인 5인 파견 — 백제 음악이 일본 궁중음악(雅楽) 원류
- 6세기: 노반박사(露盤博士)·와박사(瓦博士) 파견 → 건축 기술 전수
- 588년: 불교 공인 후 백제 불교문화 집중 전파

창작 활용:
- 왕인의 일본 파견 장면 — 지식이 국경을 넘는 감동
- 칠지도 장면 — 백제 전성기의 국제적 위상
```

**칠지도(七支刀) 명문 분석**
```
앞면: "泰和四年 □月十六日 丙午正陽 造百鍊鐵七支刀 □辟百兵 宜供供侯王"
뒷면: "先世以來 未有此刀 百濟王世□ 奇生聖音 故為倭王旨造 傳示後世"

의미: "백제왕이 왜왕에게 하사하는 신물(神物)"
논쟁: 하사냐 증정이냐 — 백제-왜 관계의 주종 논란
창작 활용: 칠지도를 둘러싼 외교 협상 장면
```

### 2-3. 신라·고구려와의 관계

```
나제(羅濟) 동맹 — 433~553년:
- 고구려의 남진에 맞서 신라-백제 동맹 체결
- 433년 눌지왕·비유왕 동맹 → 120년간 유지
- 551년: 나제 연합으로 한강 유역 수복 (백제 성왕, 신라 진흥왕)
- 553년: 진흥왕의 배신 — 신라가 백제 점령지 한강 하류 탈취
- 554년: 배신에 분노한 성왕 친정 → 관산성(管山城)에서 전사
창작 활용: 동맹-배신-전쟁의 극적 드라마
```

## 3. 신라의 외교

### 3-1. 초기 외교 — 종속에서 독립으로

```
초기 신라의 외교적 위치:
- BC 1세기~4세기: 한반도 최약소국
- 고구려에 왕자 볼모 파견 (실성왕이 고구려에 볼모)
- 왜의 침략을 고구려 광개토왕 도움으로 격퇴 (400년)
- 5세기: 나제 동맹으로 생존 기반 확보

신라의 성장 외교 전략:
"강한 자에게는 조공, 약한 자에게는 압박"
→ 6세기 진흥왕 때 전략 전환 — 한강 장악으로 외교 주도권 획득
```

### 3-2. 나당(羅唐) 동맹 — 삼국 통일의 열쇠

**648년 김춘추의 당나라 방문 — 삼국사기 기록**
```
김춘추(金春秋, 후의 태종무열왕)의 외교 활동:
- 647년: 고구려 연개소문에게 동맹 제안 → 거절
- 648년: 당나라 태종 방문
  → 당 태종: "신라를 도와 고구려·백제를 격파하면
             평양 이남은 신라에 준다"
  → 나당 동맹 체결 (군사 협정)
- 660년: 당 소정방 + 신라 김유신 → 백제 멸망
- 668년: 나당 연합 → 고구려 멸망

배신의 역전:
- 당나라는 한반도 전체 지배 시도 → 도독부 설치
- 신라 문무왕 → 나당 전쟁 (670~676년)
- 676년: 신라가 당나라 축출 → 삼국 통일 완성
창작 활용: 김춘추의 냉혹한 실용주의 외교 — 고구려까지 이용하려 한 책략
```

### 3-3. 일본과의 관계

```
신라-왜 관계:
- 초기: 왜구의 빈번한 해안 침략 → 적대적
- 삼국 통일 후: 점진적 외교 정상화
- 752년: 신라 사신 700명 파견 — 최대 규모 신라-일본 교류

문화 전파:
- 신라 불교 문화 → 일본 아스카(飛鳥) 문화 영향
- 원효(元曉)의 불교 사상 → 일본 불교에 영향
```

## 4. 가야의 외교

```
가야의 외교적 특성:
- 중앙집권 국가가 아닌 연맹체 → 외교도 분산적
- 철정(鐵鋌)을 화폐로 한 교역 중심 외교

주요 교역 파트너:
- 한(漢)나라: 낙랑·대방 군을 통한 교역
- 왜국(倭): 철기·토기 수출 → 일본 열도 발전에 기여
- 신라·백제: 경쟁과 협력 반복

가야 철의 국제성:
- 삼한지(三韓志, 위지동이전): "변한(弁韓)의 철을 낙랑·왜인이 가져간다"
- 가야 판갑옷 → 일본 고분에서 동일 형태 발견
- 창작 활용: 가야 상인이 왜·신라·백제를 오가는 해상 교역 장면
```

## 5. 외교 문서·의례 체계

### 5-1. 조공(朝貢) 체계

```
동아시아 조공 체계 이해:
- 형식: 소국이 대국(주로 중국)에 사신 파견 + 방물(方物) 헌납
- 대가: 대국이 작호(爵號) 수여 + 답례품 제공 + 안보 보장(명목상)
- 실질: 양측 모두 경제적 이익 + 명분 획득 추구

삼국의 조공 전략:
고구려: 중국 왕조에 형식적 조공, 실질적 대등 외교
백제: 남조에 적극 조공 → 문화 수입 + 고구려 견제 명분
신라: 초기 고구려 종속 → 648년 이후 당나라 활용
```

### 5-2. 사신(使臣) 파견 의례

```
사신 파견 절차 (삼국사기 기록 종합):
1. 국왕 명령 → 사신단 구성 (정사·부사·서장관)
2. 출발 전 종묘 제사 + 하늘에 고함
3. 상대국 도착 → 국서(國書) 전달
4. 연회·음악 교환 (음악은 외교의 핵심)
5. 답례품 수령 후 귀환

사신단 규모:
- 대외 사신: 수십~수백 명 (악사·의사·기술자 포함)
- 국내 사신: 10~20명
```

### 5-3. 국서(國書) 형식

```
삼국사기 기록 국서 예시:
- 제목: "○○국 왕신(王臣) ○○은 삼가 □□ 황제에게 상언(上言)하오니"
- 형식: 겸손체 (소방·신 등 자칭) + 상대 찬양
- 내용: 조공 물품 목록, 요청 사항, 우호 표명

창작 활용:
- 국서 작성 장면 — 문서 한 줄에 담긴 외교적 계산
- 국서를 받아 읽는 장면 — 행간을 읽는 통역관
```

## 6. 외교적 혼인 (왕실 혼인 외교)

| 연도 | 내용 | 의의 |
|------|------|------|
| 1세기 | 김수로왕 ← 허황옥 (인도) | 가야 국제성 상징 |
| 4세기 | 백제 왕실 ↔ 왜 왕실 혼인 교류 | 백제-왜 동맹 강화 |
| 392년 | 신라 실성왕 고구려 볼모 | 고구려-신라 종속 관계 |
| 648년 | 김춘추 딸 → 당나라 장수와 혼인 | 나당 동맹 강화 수단 |

```
혼인 외교의 특성:
- 왕녀·공주를 동맹국에 시집보내는 것 = 최고급 외교 수단
- 동시에 볼모 성격도 겸함
- 여성이 외교 수단으로 활용되는 비극적 현실
창작 활용: 정략 결혼한 공주의 정체성 갈등 서브 플롯
```

## 7. 창작 활용 외교 장면 가이드

### 핵심 외교 장면 시나리오

```
[고구려 — 을지문덕의 위계 외교]
시: 적장에게 철수를 권유하는 시 한 수
장면: 붓으로 전쟁을 끝내는 장면 — 칼보다 글이 강한 순간

[백제 — 칠지도 하사 장면]
왕실 연회장에서 왜국 사신에게 칠지도를 건네는 장면
음악: 백제 궁중 악단 연주
의미: 백제 전성기의 국제적 위상 과시

[신라 — 김춘추의 당나라 방문]
당 태종 앞에서 무릎 꿇되 눈빛은 대등한 김춘추
내면: "나는 신라를 살리기 위해 무엇이든 한다"
대사: "대국의 군사를 빌리되, 한반도는 신라의 것이다."
```

## 8. 자문단 고증 주석

**ADV-HISTORY 검수 의견**:
- 살수대첩 규모 "113만": 수서 기록이나, 실제 30~40만 추정 — 창작 시 과장 표현 가능하나 주석 권장
- 칠지도 연대: 369년 vs 408년 학설 대립 — 369년 채택 (일본서기 기준)
- 나당 동맹 조건: "평양 이남 신라 귀속" 약속의 진위 불확실 — 창작적 해석 가능

- 조공 체계는 착취가 아닌 상호 이익 교환 — 지나친 현대적 해석 주의
- 백제-왜 관계를 "식민지" 수준으로 묘사하면 한일 관계 논란 — 문화 전파 중심으로 표현 권장
- 나당 전쟁(670~676)은 삼국 통일만큼 중요 — 드라마 시즌7 핵심 소재로 활용 가능
