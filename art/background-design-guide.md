## 배경 디자인 철학

```
핵심 원칙:
  배경 = 서사의 감정을 담는 그릇
  역사 고증 + 서사 감성 = 「기억할 수 있는 장소」

3단계 진실성:
  L1 역사: 실제 발굴·기록 기반 구조물
  L2 창작: 서사를 위한 상상 보완
  L3 감성: 색·빛·분위기 감성 연출

금지 사항:
  현대 건물 실루엣 노출
  중국 당나라 건축 양식을 한국 건물에 혼용
  일본 에도 시대 건축 혼입
  서양 성(Castle) 형태 사용
```

## 고구려 배경 디자인

### 평양성

```
시대: 427년~668년
규모: 대도시 (인구 추정 10만+)
구조: 4중 성곽 (내성·중성·외성·북성)

비주얼 키워드:
  웅장·어둠·돌·강·힘

색채:
  주간: 군청 #2F4F7F 하늘 + 회색 석성
  야경: 횃불 오렌지 #FF6B35 + 군청 밤하늘
  강(대동강): 짙은 청록 #2E8B57

건물 특징:
  석축 성벽: 가공 화강암 층층이 쌓기
  왕궁: 고구려 식 목조 단청 (청색 계열 우세)
  민가: 반지하식 온돌방 (함토 + 목재)
  사찰: 평양 5사찰 (금강사·정릉사 등 참고)

원근법 적용:
  원경: 성벽 실루엣 + 대동강 반영
  중경: 시장·도로·민가군
  근경: 석재 포장 도로 + 행인

드라마 배경 리스트:
  고루 진영: 성벽 외부 야영지 (군사 텐트·모닥불)
  평양성 성문: 당나라 포위망 장면
  성벽 위 망루: 고루 최후 장면
```

### 안시성

```
시대: 645년 (당 태종 원정)
특징: 산지 요새 성곽

비주얼 키워드:
  고립·포위·불굴·고지

색채:
  여름 배경: 짙은 초록 산 + 회색 성벽
  야간: 당나라 진영 횃불 (성 주위 에워쌈)
  날씨: 구름 + 바람 (고지대 기상)

건물 특징:
  성벽: 산 능선 따라 구불구불
  치(雉): 성벽 돌출 방어 구조물 등간격
  망루: 성벽 꼭대기 목조 망루
  저수지: 성내 독립 수원 표시

주요 장면 배경:
  고루 망루: 성벽 위 → 당나라 진영 내려다봄
  당나라 토산(土山): 성벽 높이까지 쌓인 흙산
  88일차 아침: 안개 속 성벽 + 여명
```

## 백제 배경 디자인

### 사비성

```
시대: 538년~660년
규모: 중형 도시 (인구 5만 추정)
구조: 부소산성 + 도성 + 금강 해자

비주얼 키워드:
  아름다움·우아함·황금·비극

색채:
  봄: 황금 #B8960C + 연분홍 꽃
  여름: 연꽃 연못 초록 + 황금 하늘
  멸망 전후: 잿빛 연기 + 탁해진 금강

건물 특징:
  왕궁: 정교한 백제 목조 단청 (적·청·녹·황 풍부)
  미래사 9층 목탑: 스카이라인 랜드마크 (80m+)
  시장: 기와 처마 + 노점
  후원: 연꽃 연못 + 정자 + 화원

주요 장면 배경:
  아랑 거처: 왕궁 내 여성 구역 + 자수방
  금동대향로 보관실: 어둡고 신성한 내실
  낙화암: 백마강 절벽 (자연 + 사비성 조망)
  사비성 함락: 불길 + 연기 + 잿빛 전환
```

### 낙화암

```
지형: 부소산 백마강 절벽 (높이 약 10m)
비주얼:
  정상: 부소산 소나무 + 절벽 끝
  절벽: 수직 암벽 + 강 반영
  강면: 백마강 잔잔한 수면 + 꽃잎

감성 배경 연출:
  아랑 시점: 강 방향 + 꽃잎 날림
  금지: 낙화 직접 묘사 — 꽃잎·강·소리로만
  빛: 석양 황금빛 → 점점 어둠 (시간 경과)
```

## 신라 배경 디자인

### 왕경 경주

```
시대: 5~7세기
규모: 대도시 (삼국 통일 후 최대)
구조: 방격형 도로망 + 월성 중심

비주얼 키워드:
  밝음·금빛·별·화려

색채:
  낮: 금색 #FFD700 햇빛 + 흰 구름
  황룡사 탑: 스카이라인 랜드마크
  야경: 별밤 + 사찰 등불

건물 특징:
  월성: 반달 모양 왕궁 + 해자
  황룡사: 9층 목탑 (80m+ 추정)
  첨성대: 원통형 화강암 구조물 (독특)
  민가: 기와 + 초가 혼재 (계층별)

주요 장면 배경:
  하린 수련장: 황룡사 앞마당 + 화랑 훈련
  첨성대: 별 관측 + 선덕여왕 예언 장면
  황산벌 전야: 신라 진영 + 횃불 + 긴장
```

### 황산벌

```
지형: 충남 논산 평야 (충청도 평원)
시대: 660년 7월 (여름)

비주얼:
  광활한 평야 + 황금빛 보리밭
  지평선: 낮은 구릉
  날씨: 뜨거운 여름 + 강한 햇빛

전투 전:
  새벽 안개 + 양군 대치
  백제 500결사대 vs 신라군 5만

전투 중:
  황금빛 들판이 붉게 물드는 색 변화
  흙먼지 + 함성
  관창 돌격 장면: 단기 질주 + 넓은 들판

전투 후:
  붉은 황혼 + 적막
  승자(하린)와 패자(아랑) 같은 하늘 다른 공간
```

## 가야 배경 디자인

### 김해 금관가야

```
시대: 42년~532년
규모: 중소 왕도 (낙동강 하구)
구조: 목책 + 토축 방어 + 낙동강 수운

비주얼 키워드:
  황혼·철·강·소멸

색채:
  낮: 황토 #C8A96E + 낙동강 황록
  용광로: 오렌지 불빛 + 검은 연기
  황혼: 황토빛 석양 실루엣

건물 특징:
  왕궁: 소박한 목조 + 토축 담장
  제철단지: 용광로 집중 구역 + 연기
  민가: 반지하 수혈 + 목재 지붕
  부두: 낙동강변 + 목선 정박

주요 장면 배경:
  니문 탄생지: 용광로 인근 장인 마을
  낙동강변: 니문 유랑 출발점
  가야금 첫 연주: 강가 바위 위 + 황혼
```

## 공통 자연 환경 팔레트

```
계절별 색채:
  봄: 연분홍 #FFB7C5 + 연두 #90EE90
  여름: 짙은 초록 #228B22 + 청하늘 #87CEEB
  가을: 붉은 #CC4500 + 황금 #FFD700
  겨울: 흰 #F5F5F5 + 청회 #708090

날씨별 연출:
  맑음: 선명한 색채 + 강한 그림자
  흐림: 탈색 + 확산광 (그림자 없음)
  비: 채도 DOWN + 물결·물방울
  안개: 원경 흐림 + 근경만 선명

밤하늘:
  삼국시대 기준: 인공광 없음 = 은하수 선명
  별: 촘촘하고 밝게 (현대 도시 하늘 아님)
  달: 서사 타이밍 연출 (만월·초승·그믐)
```
