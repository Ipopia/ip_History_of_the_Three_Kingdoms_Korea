## 스핀오프 개요

```
타이틀: 삼국(三國) 외전 — 「12번째 현(絃)」
영문: THREE KINGDOMS Side Story — THE TWELFTH STRING
형식: 소설 (2권 완결) + 웹툰 (시즌 1, 40화) + 오디오드라마
시대: AD 530~580 (대가야 말기~멸망~우륵 귀화)
주인공: 니산 (尼山, 니문의 할아버지) + 우륵 (于勒) + 이진아시왕
톤: 서정 서사 + 소멸의 아름다움 + 음악

슬로건:
  「나라는 사라져도, 소리는 남는다.」
  "THE KINGDOM FADES, THE SOUND REMAINS."
```

## 서사 구조

### 제1부 — 「가야금의 아이」(AD 530~555)

```
Chapter 1~4: 니산의 탄생
  배경: 대가야 고령(高靈) — 낙동강 유역
  니산 (5세): 대장간 마을에서 태어남
  가야의 일상: 철 단야(鍛冶) + 교역 + 음악
  → 니산이 처음 가야금 소리를 듣는 날:
    대나무 숲 너머에서 들려오는 선율
    「이것이 무슨 소리예요?」
    어머니: 「우륵 어른의 가야금이다. 가야의 소리란다.」

Chapter 5~10: 우륵과의 만남
  니산 (12세): 우륵의 제자로 들어감
  우륵: 가야금 12곡 완성 단계
  가야금 12현 각 현의 이름과 의미:
    1현 — 상가라도(上加羅都): 대가야의 노래
    2현 — 하가라도(下加羅都): 금관가야의 노래
    ...
    12현 — 달이(達已): 이름 없는 자들의 노래
  니산의 재능: 12현 모두 자유롭게 연주
  우륵의 교훈: 「음악은 기억이다. 현을 튕기면 과거가 깨어난다.」

Chapter 11~18: 소멸의 전조
  가야 연맹 해체 진행: 신라 압박 증가
  금관가야 이미 멸망 (532년)
  대가야 이진아시왕(異腦王): 마지막 왕의 고뇌
    「나는 항복하면 살 수 있다. 가야는?」
  니산의 관점: 어른들의 표정이 달라진다
  우륵: 가야금을 안고 밤에 강을 바라본다
  → 우륵의 결단 준비: 「가야금을 가져가야 한다. 어디든.」
```

### 제2부 — 「강을 건너다」(AD 555~580)

```
Chapter 19~25: 대가야 멸망 (562년)
  신라 진흥왕 공격: 대가야 최후의 해
  이진아시왕: 항복 결정
  → 왕의 마지막 명령: 「우륵. 가야금을 가져가라. 어디든 좋다.」
  우륵·니산의 탈출: 가야금 12곡 악보 + 가야금 3대 지참
  낙동강 도하: 밤에 강을 건너는 씬
    니산: 「우리가 강을 건너면, 가야는 없는 건가요?」
    우륵: 「가야금이 있는 곳이 가야다.」

Chapter 26~32: 신라에서의 삶
  신라 진흥왕 앞 연주: 우륵·니산의 첫 공연
  진흥왕: 「이 소리는 무엇이냐?」
  우륵: 「가야(伽倻)의 소리입니다. 이제는 신라의 소리가 되어도 좋습니다.」
  니산의 정체성 갈등:
    신라 아이들: 「너는 가야 사람이잖아.」
    니산: 대답하지 못한다
  우륵의 가르침: 「네가 누구인지는 네가 어떤 소리를 내느냐로 결정된다.」

Chapter 33~38: 12곡의 전수
  우륵 노화: 니산에게 12곡 완전 전수
  각 곡의 의미와 기억:
    1곡: 대가야 왕궁의 새벽
    5곡: 낙동강 뱃노래
    7곡: 철을 두드리는 소리 (대장간)
    12곡: 이름 없는 자들 — 역사에 기록되지 않은 가야인들
  우륵의 마지막 연주:
    강변에서 12현을 모두 튕기고
    마지막 현이 울린 뒤
    우륵: 「이제 네 차례다.」

Chapter 39~40: 에필로그
  니산 (50세): 경주(금성) 변두리에서 가야금을 가르침
  제자들: 신라 아이들 — 가야를 모르는 세대
  니산의 독백:
    「아이들은 가야를 모른다.
     그러나 이 소리를 알고 있다.
     소리가 기억이다.
     나라는 사라졌다. 소리는 남았다.」
  마지막 씬: 낙동강이 보이는 언덕
    니산이 가야금을 연주한다.
    12현의 소리가 바람에 실려 간다.
    강물이 흐른다.
    끝.
```

## 캐릭터 상세

### 니산 (이 작품에서)

```
나이: 5세 (530) → 50세 (580 추정)
역할: 1인칭 시점 화자 / 주인공
성장 아크:
  순수한 음악 소년 → 멸망의 목격자 → 유민 → 기억의 보존자

핵심 갈등:
  가야인으로서의 정체성 vs 신라 사회 동화
  기억의 의무 vs 잊힘의 유혹
  소리(음악)로 무엇을 할 수 있는가

본편 연결:
  니산 = 본편 주인공 니문(尼文, 591년생)의 할아버지 (2세대 전)
  니산의 가야 멸망 경험과 우륵으로부터의 12곡 전수가
  손자 니문의 「조용한 결의」의 뿌리
  니산 → (아들) → 니문(591년생)으로 가야금 3대 계승
  니문은 할아버지 니산의 기억을 간직한 채 본편에 등장
```

### 우륵 (가야금의 아버지)

```
역할: 니산의 스승 — 가야 문화의 마지막 수호자
성격: 온화하고 시적 / 가야금을 칠 때만 눈빛이 날카로움
대사량: 적음 (음악으로 대화하는 인물)
핵심 대사:
  「현(絃)은 끊어져도, 소리는 공중에 남는다.」
  「기억을 손에 쥐지 마라. 소리로 놓아줘라.」
```

### 이진아시왕 (대가야 마지막 왕)

```
역할: 비극적 마지막 왕
성격: 선량하지만 무력한 / 항복의 고뇌
핵심 씬: 항복 결단 — 「백성이 사는 것이 나라가 사는 것이다.」
  → 그러나 가야는 역사에서 사라진다
  → 왕의 이름조차 잊혀져간다
```

## 제작 기준

```
소설:
  1권: 제1부 (300페이지) / 2권: 제2부 (280페이지)
  문체: 1인칭 니산 시점 — 시적·감각적 문체
  특징: 짧은 문장 + 여백 활용 (가야금 소리 표현)
  예시: 「현이 울렸다. / 강이 대답했다. / 아무도 듣지 않았다.」

웹툰:
  시즌 1: 40화 (전체)
  톤: 서정적·미니멀 (전투 씬 15% 이하)
  배경: 가야 환경 미니멀 수묵 터치 (art-bible.md)

오디오드라마:
  전 40화 × 25분 = 총 1,000분
  성우: 니산 전담 1인 + 우륵 1인 + 조연 3인
  가야금 연주: 전 화 라이브 녹음 삽입

역사 고증 필수:
  □ 대가야 562년 멸망 과정 (ADV-HISTORY)
  □ 우륵 12곡 역사적 근거 (삼국사기 악지)
  □ 가야금 형태·연주법 (ADV-ARTS / traditional-music.md)
  □ 가야-신라 관계 (ADV-POLIECON)
  □ 가야 고분 문화·철기 문화 (ADV-ARCHAEOLOGY)
```
