## 각본 기획 개요

```
시리즈 구조:
  총 3시즌 × 16화 = 48편
  편당 분량: 60~70분 (OTT 기준)
  특별 연장: 시즌 피날레 75~90분

각본 팀 구성:
  메인 작가 (총괄): 1명
  보조 작가: 시즌당 2~3명
  역사 고증 작가: 1명 (ADV-HISTORY 상시 연락)
  다이얼로그 감수: ADV-LINGUISTICS

각본 언어: 한국어 (영문 번역본 병행)
포맷: 파이널 드래프트 기준 (또는 한국 표준 극본 포맷)
```

## 각본 작성 원칙

### 핵심 5원칙

```
1. 역사는 배경, 인물은 주인공
   → 역사 사건이 서사를 이끌되
     감정과 선택은 반드시 인물 중심

2. 4인의 관점 균등 배분
   → 시즌 전체에서 고루·아랑·하린·니문
     각자의 시점 분량 25% ± 5% 유지

3. 침묵도 대사다
   → 니문 씬 특히: 말 없는 장면이 더 강력
   → 과도한 설명 대사(Exposition) 지양

4. 역사 팩트는 픽션으로 꾸미되 바꾸지 않는다
   → 살수대첩 결과, 황산벌 결과는 불변
   → 과정·감정·이면 = 창작 자유

5. 시청자를 가르치지 말 것
   → 역사 설명: 자연스러운 대화 속 녹아들게
   → 인포그래픽식 설명 대사 금지
```

## 각본 포맷 기준

### 씬 헤딩 (Scene Heading)

```
형식:
  INT./EXT. [장소] — [시간대] — [계절/연도]

예시:
  INT. 평양성 집무실 — 새벽 — 겨울, AD 611
  EXT. 살수 강변 — 낮 — 여름, AD 612
  INT. 사비성 문서관 — 밤 — 가을, AD 641

왕국 표기:
  고구려 장소: [고구려] 접두사 권장
  예) INT. [고구려] 안시성 성벽 — 황혼 — AD 645

역사 연도 표기:
  실제 사건 씬: 연도 필수 기재
  창작 씬: 연도 생략 가능 (시기 참조)
```

### 캐릭터 표기

```
주인공 4인 — 한국어 이름 사용:
  고루 / 아랑 / 하린 / 니문

역사 실존 인물:
  을지문덕 / 선덕여왕 / 계백 / 김유신 / 의자왕
  → 성+이름 최초 등장, 이후 성 또는 이름만 가능

외국 인물:
  수양제 / 이세민(당태종) / 설인귀
  → 한자명 병기: 수양제(隋煬帝)

장면 지문 언어:
  현재형 능동태 사용
  예) 을지문덕이 말을 멈추고 살수를 내려다본다.
      아랑의 붓이 잠시 멈춘다. 그녀는 알고 있다.
```

### 대사 작성 기준

```
시대 언어 처리:
  현대 한국어 기본 사용 (완전한 고어 사용 금지)
  고어 투: 약간의 격식체 + 한자어 선호
  예) 「아니되옵니다」→ 「그리할 수 없습니다」
       「마마」호칭: 왕족 대상만 사용

왕국별 어조:
  고구려: 간결·직접적 (군사 언어)
  백제: 부드럽고 품격 있음 (궁중 언어)
  신라: 열정적·패기 있음 (화랑 기상)
  가야: 조용하고 시적 (음악적 언어)

감탄사·욕설:
  시대 감탄사 권장: 「허」「아이구」→ 시대적 느낌
  현대 속어·욕설: 절대 금지 (역사 드라마 무게감)

역사 대사 원전 활용:
  을지문덕 한시: 원문 그대로 사용 필수
  「神策究天文 妙算窮地理
   戰勝功旣高 知足願云止」
  → 한문 원문 + 현대어 번역 자막 병행
```

## 시즌별 각본 기획

### 시즌 1 (AD 600~612) — 16화

```
화별 주요 각본가 배정 권장:
  EP01 (파일럿): 메인 작가 단독
  EP02~04: 메인 + 보조 1 (왕국별 서막)
  EP05~08: 메인 + 보조 2 (만남·갈등)
  EP09~12: 보조 1·2 분담 (위기 전조)
  EP13~15 (살수대첩): 메인 작가 복귀 (전투 각본)
  EP16 (피날레): 메인 작가 단독

에피소드 구조 권장:
  오프닝 훅: 첫 씬 5분 내 긴장 or 감정 절정
  1막 (15분): 이 화의 핵심 갈등 제시
  2막 (35분): 갈등 심화·전개
  3막 (15분): 해소 + 다음 화 복선
  엔딩 씬: 여운 or 클리프행어 교대

살수대첩 3화 연속 각본 (EP13~15):
  EP13: 수나라 진군 + 을지문덕 계략 시작
  EP14: 살수 수문 작전 + 전투 클라이맥스
  EP15: 승전 후 정산 + 생존자들의 침묵
  → 액션 씬 비율: EP14 기준 전체의 60%
```

### 시즌 2 (AD 630~655) — 16화

```
핵심 각본 이슈:
  나당연합 외교 씬: 정치적 섬세함 필수
  4인 이념 충돌: 각자의 논리가 모두 옳아야 함
  니문 가야 서사: 감정 과잉 경계 (절제가 강함)

외교 씬 작성 지침:
  김춘추·당태종 면담: ADV-POLIECON 검토 필수
  하린 시점: 「이것이 옳은 일인가」질문 반복
  고루 시점: 신라의 선택을 지켜보는 무력감
  → 어느 쪽도 악당이 아닌 구조 유지
```

### 시즌 3 (AD 660~676) — 16화

```
핵심 각본 과제:
  백제 멸망·낙화암: 아랑 서사 최고조
  계백 황산벌: 역사 비극 최대한 존중
  고루의 최후: 고구려인으로 마무리
  676 최종화: 니문의 가야금 + 4인 유산

최종화 (EP16, 90분) 각본 구조:
  0~20분: 기벌포 해전 클라이맥스
  20~50분: 전후 정산 (4인 각자의 결산)
  50~70분: 「676」— 니문의 마지막 가야금
  70~90분: 에필로그 (강물과 기억)

에필로그 원칙:
  현대와 연결하지 않는다 (과거는 과거로)
  강물 이미지로 마무리
  대사 최소화 (니문의 가야금이 대신)
```

```

   ↓
3단계: 대사 언어 → ADV-LINGUISTICS 검토 (3영업일)
   ↓
4단계: 전투 씬 → ADV-MILITARY 검토 (3영업일)
   ↓

   ↓
6단계: QA-CRITIC 소비자 관점 검토 (5영업일)
   ↓
7단계: 연출팀 (FILM-DIR) 촬영 가능성 검토
   ↓
8단계: 메인 작가 최종 수정 → 락픽처

오류 레벨:
  🔴 RED: 역사 왜곡 — 즉시 수정 필수
  🟡 YELLOW: 역사 개연성 부족 — 수정 권고
  🟢 GREEN: 창작 범위 내 — 메모만
```

## 각본 작성 금지 사항

```
서사 금지:
  ✗ 4인 중 1인이 악당화되는 구조
  ✗ 역사 전투 승패 변경 (살수 고구려 패배 등)
  ✗ 나당연합 = 신라의 배신으로 단순화
  ✗ 가야 = 무력한 피해자만으로 묘사
  ✗ 수·당 = 일방적 악역화

언어 금지:
  ✗ 현대 속어·슬랭
  ✗ 지나친 고어 (관객 소외)
  ✗ 임나일본부 관련 대사
  ✗ 동북공정 관점 표현
  ✗ 현대 정치 사안 연상 대사

연출 금지:
  ✗ 전쟁 미화 (살상 미학화)
  ✗ 성적 표현 (15세 등급 기준)
  ✗ 과도한 고어 묘사 (전투 장면 기준 ADV-MILITARY 승인)
```

## 특수 각본 유형

### 몽타주 씬

```
용도: 시간 경과·훈련·여정 압축
형식:
  MONTAGE — [제목/설명]
    씬 1. [장소] — [행동]
    씬 2. [장소] — [행동]
  END MONTAGE

가야금 몽타주 (니문 전용):
  음악이 화면을 이끄는 구조
  → 대사 없이 12현 각 현의 소리로 장면 전환
  → 사운드 디자이너(SND-COMP)와 사전 협의 필수
```

### 플래시백 씬

```
표기: [플래시백] 또는 [FLASHBACK] 씬 헤딩 앞
색보정: 채도 저하 + 약한 비네팅 (post 기준)
용도:
  가야 멸망 전 과거 (니문)
  살수대첩 이전 고루의 첫 전투
  아랑이 기록한 사건의 원본 장면

제한: 1화당 2회 이내 (남용 금지)
```

### 병렬 편집 각본

```
용도: 4인 동시 진행 씬 (살수·황산벌 등)
형식:
  INTERCUT BETWEEN:
  — [장소 A] / [장소 B] / [장소 C]

사용 지침:
  살수대첩 씬: 고루(전장) ↔ 아랑(사비성 기록) 병렬
  황산벌 씬: 하린(전투) ↔ 니문(가야금) 병렬
  → 연출팀과 편집 흐름 사전 협의 필수
```
