## 삼국시대 경제 개요

```
4~7세기 한반도 경제 특성:
- 자급자족 농업 경제 기반
- 철기 도구 보편화 → 농업 생산력 향상
- 교역 네트워크: 한반도 내부 + 중국·일본·동남아
- 화폐: 철정(鐵鋌, 덩이쇠) 주요 교환 수단
- 조세: 토지세 + 공납 + 노역 3종

핵심 경제 자원:
① 철 (鐵): 가야 중심 생산 — 동아시아 최고 품질
② 토지 (土地): 왕국 재정 핵심 — 귀족 소유 토지
③ 교역 (交易): 중국·일본 대외 교역
④ 공납 (貢納): 속민·복속 소국의 공물
⑤ 노역 (勞役): 공사·군역 등 인력 동원
```

## 가야 — 철 경제 (Iron Economy)

### 철정(鐵鋌) 시스템

```
가야 철정:
형태: 판형(板形) 또는 정(鋌)형 — 납작한 철 덩이
규격: 약 30~40cm, 450g~1kg
기능: 화폐·무기 재료·제물 3중 기능

유통 범위:
가야 국내: 일상 교환 수단
고구려·백제·신라 수출: 무기 재료 수입
일본 왜국 수출: 대성동 고분군 출토 일본 유물로 확인
중국: 중국 화폐와 교환

철정 교환 비율 (추정):
철정 1개 = 쌀 2~3말 (추정)
철정 5개 = 고급 비단 1필 (추정)
철정 50개 = 말 1마리 (추정)

IP 활용:
게임 자원 시스템: 「가야철」= 최고급 자원
니문 캐릭터 배경: 철정 거래 집안 → 철정 방패 제작
드라마 소품: 가야 장터에 쌓인 철정 더미
```

### 가야 제철 산업

```
생산 지역:
낙동강 유역 — 철광석 매장 + 목탄 연료
주요 거점: 김해(금관가야), 함안(아라가야), 고령(대가야)

생산 공정:
1. 철광석 채취 (인근 산지)
2. 목탄 제조 (벌채)
3. 용광로 제련 (1,200℃+)
4. 철정 제조 (교환 단위)
5. 도구·무기 단조 (수요에 따라)

생산량 (추정):
연간 수백 톤 이상 — 동아시아 최대 생산국 중 하나
주요 수출국: 신라·백제·왜

가야 철 품질 비교:
가야철 ▶ 최고급 — 탄소 함량·단조 기법 최적
고구려철 ▶ 고급 — 갑주·무기 특화
백제철 ▶ 중급 — 검·도구 특화
신라철 ▶ 중급 — 화살촉·농기구 특화
```

## 고구려 — 군사 경제 (Military Economy)

### 조세 구조

```
고구려 조세 3종:
① 인두세 (人頭稅): 1가구당 포(布) 5필 또는 곡식 5석
   단, 빈민 = 1인당 布 1필
② 공납 (貢納): 각 지역 특산물 헌납
   요동 지역: 철기·모피
   평야 지역: 곡식·삼베
   산악 지역: 약재·사냥감
③ 역 (力役): 성 축성·관개 등 공사 노역
   군역: 15세 이상 남성 군복무

귀족 경제:
고추가(古鄒加)·대가(大加) 등 귀족: 직접 지배 토지 + 예속민
대막리지: 국가 경제 실질 장악
을지문덕·연개소문 계열: 막대한 토지 재산
```

### 대외 교역

```
고구려 교역 루트:
북쪽: 부여·말갈 — 모피·가죽
서쪽: 중국 (수나라·당나라) — 비단·도자기
남쪽: 백제·신라 — 철·농산물
동쪽: 동예·읍루 — 어물·목재

주요 수출품:
철기·무기류 (요동 철 생산)
모피 (북방 수렵)
인삼·약재 (고구려 특산)

주요 수입품:
비단 (중국 당나라)
도자기 (중국)
곡식 (전쟁 시 부족분)

전쟁 경제:
수나라·당나라 전쟁 기간 — 경제 전시 체제
낙성 전리품: 적국 창고·가축·인력 포획
살수대첩 이후: 수나라 전쟁 물자 노획 (IP 드라마 에피소드)
```

## 백제 — 해양 교역 경제 (Maritime Trade Economy)

### 해상 교역 네트워크

```
백제 교역 강점:
서해 해상권 장악 — 한반도~중국 직항 루트
목포·군산·인천 등 서해안 항구 거점
일본 왜국 교역 독점 (한반도 창구)

주요 교역 루트:
A. 백제 → 중국 (동진·송·제·양·진·수·당)
   수출: 금·은·보물·칠기·특산물
   수입: 비단·도자기·불교 경전·기술자

B. 백제 → 왜국 (일본)
   수출: 불교·유교 문화 (왕인의 논어·천자문)
   수출: 기술자 (도예·직물·건축)
   수입: 원자재·노예

C. 백제 내부: 한강 → 금강 교역 루트
   사비성 백마강 — 물자 집산 거점

백제 화폐 경제:
곡식·포 + 금·은 병용
중국 화폐 유입 (교역 지역 제한적 유통)
```

### 사비성 경제

```
사비성 (泗沘城, 현 부여) 경제 중심:
왕실 수공업: 금동 공예·도자·직물 왕실 주도
시장 (市): 수도 상설 시장
  - 왕실 관리: 도량형 통일, 가격 규제
  - 외국 상인 거주 구역 (당나라·왜 상인)

백제 특산 수출품:
금동 공예품 (금동대향로 수준)
비단·직물 (고급 염색 기술)
칠기 (옻칠 제품)
인삼·약재

IP 활용:
아랑 배경: 왕실 문서관 = 교역 기록 관리도 포함
드라마 장면: 사비성 시장 국제 상인 장면
게임 자원: 「백제 비단」= 외교 자원 특화
```

## 신라 — 농업·금 경제 (Agricultural & Gold Economy)

### 경주(서라벌) 경제

```
신라 경제 특성:
농업 기반 — 경주 분지 풍요로운 토지
금 생산 — 경주 일대 사금 채취
화랑도 경제 — 귀족 인적 자원 군사화

토지 제도:
신라 녹읍(祿邑) 제도:
- 귀족·공신에게 특정 지역 수조권(收租權) 부여
- 조세 수취 + 노역 동원 권한
- 이후 관료제 강화로 녹읍 폐지·녹봉 전환 (IP 외 시대)

경주 시장:
동시(東市): 동방 상인·고구려 교역품
서시(西市): 서방 중국·백제 교역품
남시(南市): 왜국·가야 교역품

신라 대외 교역:
중국 직접 교역 — 한강 확보 전 한계 (육로 고구려 봉쇄)
고구려·백제 통과세 부담
→ 나당 연합의 경제적 배경: 직접 교역로 확보 필요
```

### 금관 경제

```
황금 = 신라 권력의 상징:
금관: 왕족 전용 — 생산·유통 왕실 독점
금귀걸이·팔찌: 귀족 일반 착용 — 신분 표시

금의 경제적 기능:
대외 조공: 중국 황제에 금·은 조공
외교 선물: 가야·고구려와 관계에 금 사용
불교 후원: 황룡사 등 사찰 건축 금 투입

IP 활용:
하린 배경: 귀족 집안 → 금 장신구 착용
게임 자원: 「신라 금」= 외교·종교 자원
드라마: 신라 왕궁 = 황금빛 공간 (황금 #FFD700)
```

## 게임 경제 시스템

```
자원 종류 (4왕국 특산):
고구려철 (GOGURYEO IRON): 갑주·무기 강화 특화
백제비단 (BAEKJE SILK): 외교·문화 자원 특화
신라금 (SILLA GOLD): 종교·외교 범용 자원
가야철정 (GAYA IRON): 전 무기 최고급 강화 가능

자원 생산 시설:
고구려: 철광산, 요동 목장 (군마 생산)
백제: 금강 항구 (교역소), 왕실 공방
신라: 경주 사금 채취장, 황룡사 (종교 건물 골드 생산)
가야: 낙동강 제철소, 구지봉 교역 광장

교역 시스템:
왕국 간 자원 교환 가능
외교 레벨에 따라 교환 비율 차등
전쟁 선포 시 교역 중단

전시 경제:
전쟁 상태 → 자원 소모 2배
점령지 → 자원 수탈 (상대 자원 10% 획득)
농성(籠城) → 자원 소모 최소화 전략
```

## 드라마 경제 묘사 기준

```
일반 서민 경제:
- 삼베·포를 주 화폐로 사용
- 곡식(쌀·조·보리) 현물 교환
- 시장(市): 5일장 형태 (고증)

귀족 경제:
- 비단 착용 = 신분 즉각 식별
- 금·은 소품 = 부의 상징
- 노비 = 생산력 기반 (단, 과도한 묘사 지양)

전쟁과 경제:
- 살수대첩 후: 수나라 군수물자 노획 → 고구려 단기 부유
- 안시성 농성: 성 안 식량 부족 (88일 한계) — 드라마 긴장감 소재

아랑의 경제 기록 역할:
- 사비성 문서관 = 백제 경제 기록 관리
- 당나라 교역 기록 변화 = 나당 연합 징조 포착
- 드라마 아랑 씬: 수치로 위기를 먼저 아는 장면
```
