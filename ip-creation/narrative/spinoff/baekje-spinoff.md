## 스핀오프 개요

```
타이틀: 삼국(三國) 외전 — 「연등은 꺼지지 않는다」
영문: THREE KINGDOMS Side Story — THE LANTERNS NEVER FADE
형식: 소설 (3권 완결) + 웹툰 (시즌 1, 60화)
시대: AD 600~663 (백제 전성기~멸망~부흥운동)
주인공: 아랑 (雅琅) + 계백 + 흑치상지
톤: 문화 서사 + 비극 + 기억의 의무

슬로건:
  「기록된 것은 사라지지 않는다.」
  "WHAT IS WRITTEN NEVER DIES."
```

## 서사 구조

### 제1부 — 「사비성의 빛」(AD 600~640)

```
Chapter 1~5: 아랑의 어린 시절
  배경: 백제 사비성(부여) — 문화의 중심
  아랑 (8세): 왕실 서고에서 자란 소녀
  아버지: 왕실 문서관 — 기록의 가문
  → 금동대향로를 처음 본 날: 「이것을 만든 사람의 이름은 기록되어 있나요?」
  → 아버지: 「기록되지 않은 것은 존재하지 않는다.」

Chapter 6~12: 문서관의 성장
  아랑 (16세): 왕실 문서관 견습
  백제 문화 전성기: 무왕(武王) 시대 미륵사 건설
  아랑의 재능: 기억력·관찰력·기록 속도 발군
  서동요 설화 기록 임무: 아랑이 민간 설화를 수집
  → 기록자의 딜레마 첫 경험: 「사실대로 쓸 것인가, 아름답게 쓸 것인가?」

Chapter 13~20: 연등의 시대
  아랑 (20대): 정식 왕실 문서관
  사비성 연등 축제: 백제 문화의 정수
  아랑의 기록 철학 확립:
    「나는 아는 자가 아니다. 남기는 자다.」
  일본 사신단 접대 기록: 칠지도·불교 전수 기록 정리
  → 국제 외교 문서 작성 경험
  무왕과의 대면: 「네가 쓰는 것이 백제의 얼굴이 된다.」
```

### 제2부 — 「균열의 기록」(AD 641~659)

```
Chapter 21~30: 의자왕 시대
  의자왕 즉위 (641년): 초기 개혁 의지
  아랑의 기록: 「의자왕 원년, 왕은 바뀌었다고 선언했다.」
  3,000궁녀 전설의 진실 조사: 아랑의 고증
    → 「3,000은 과장이다. 그러나 왕이 변한 것은 사실이다.」
  궁정 내부 균열 목격: 좌평들의 이간·궁정 투쟁
  아랑의 위치: 모든 것을 보고, 기록하되, 말할 수 없는 자

Chapter 31~38: 나당연합의 그림자
  신라·당 동맹 정보 입수 (648년 이후)
  아랑의 예감: 「이 기록이 마지막이 될 수 있다.」
  계백 장군과의 만남:
    계백: 「나는 검으로 지킨다. 너는 붓으로 지켜라.」
    아랑: 「검은 부러지지만 기록은 남습니다.」
  비밀 기록 시작: 「백제가 사라져도 이 기록은 남아야 한다.」
  죽간에 담는 백제의 모든 것: 문화·의례·음식·음악·건축
```

### 제3부 — 「낙화암 이후」(AD 660~663)

```
Chapter 39~45: 백제 멸망 (660년)
  황산벌 전투: 계백 5,000 결사대
  아랑의 위치: 사비성 문서관에서 성이 함락되는 소리를 듣다
  낙화암 사건: 아랑은 낙화암에 가지 않는다
    → 아랑의 선택: 「나는 죽을 수 없다. 기록해야 하니까.」
  사비성 함락: 나당연합군 진입
  아랑의 행동: 죽간 보따리를 들고 탈출
    → 「이것이 백제다. 내가 가져가지 않으면 사라진다.」

Chapter 46~52: 백제 부흥운동
  복신·도침의 부흥 운동 합류
  아랑의 역할: 부흥군 기록관 + 사기 담당
  왜국 원군 도착: 1,000척 함대
  아랑의 기록: 부흥운동의 희망과 절망

Chapter 53~60: 백강구 전투와 종결 (663년)
  백강구 전투: 나당연합 vs 왜·백제 부흥군
  대패: 왜국 함대 궤멸, 부흥 완전 실패
  아랑의 마지막 기록:
    「백제력 23년. 강은 불탔다.
     배 1,000척이 재가 되었다.
     그러나 이 죽간은 타지 않았다.
     기록된 것은 사라지지 않는다.」

  에필로그:
    아랑은 금강 변에 앉아 있다.
    죽간 보따리를 안고.
    연등 하나가 강물 위를 흐른다.
    끝.
```

## 캐릭터 상세

### 아랑 (이 작품에서)

```
나이: 8세 (600) → 71세 (663 추정)
역할: 1인칭 시점 화자 (소설) / 주인공 (웹툰)
성장 아크:
  호기심 많은 소녀 → 재능 있는 기록자 → 왕국의 증인 → 멸망의 기록자

핵심 갈등:
  알면서 막지 못하는 무력감
  기록의 객관성 vs 개인의 감정
  생존의 의무 vs 동포와 함께하는 의무

본편 연결:
  이 아랑 = 본편 시즌 1~3 아랑과 동일 인물
  사비성 문서관 경험이 아랑의 「기록 사명감」형성 배경
```

### 계백 (비극의 장군)

```
등장: 제2부~3부
역할: 아랑의 정신적 대척점 (검 vs 붓)
핵심 씬:
  가족 처형 결단: 아랑이 목격하고 기록
  황산벌 출전: 아랑에게 마지막 기록을 부탁
  「내 가족의 이름을 기록해라. 그것이면 된다.」
```

### 흑치상지 (부흥의 전사)

```
등장: 제3부
역할: 백제 부흥운동 지휘관
역사: 부흥 실패 후 당나라에서 장수로 활약 (역사적 아이러니)
아랑과의 관계: 부흥운동 기간 아랑을 보호하는 무장
핵심 대사: 「싸움이 끝나면 네 기록만 남는다. 잘 써라.」
```

## 제작 기준

```
소설:
  1권: 제1부 (380페이지) / 2권: 제2부 (350페이지) / 3권: 제3부 (420페이지)
  문체: 1인칭 아랑 시점 (기록체 — 죽간에 쓰는 듯한 문투)
  특징: 각 장 서두에 「아랑의 기록」인용문 삽입

웹툰:
  시즌 1: 60화 (제1부~2부)
  시즌 2: 50화 (제3부)
  톤: 서정적·비극적 (전투 씬 30% 이하)

역사 고증 필수:
  □ 사비성 궁궐 구조 (ADV-ARCHITECTURE)
  □ 백제 의례·축제 (ADV-ARTS)
  □ 황산벌·백강구 전투 상세 (ADV-MILITARY)
  □ 의자왕 궁정 내부 정치 (ADV-HISTORY)
  □ 백제-왜 관계 (ADV-POLIECON)
```
