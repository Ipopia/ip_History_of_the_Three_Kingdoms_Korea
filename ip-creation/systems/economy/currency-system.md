# 삼국시대 화폐 및 교환 체계

## 개요

삼국시대는 금속 주화가 보편화되지 않은 **현물 경제** 중심이었다. 그러나 교역 활성화에 따라 다양한 교환 매개물이 발전했다.

---

## 교환 수단의 종류

### 1. 곡물 화폐 (가장 보편적)
- **쌀·조·기장**: 세금 납부 + 노동 보수 + 물물교환 기준
- 1석(石) = 기준 단위 (약 60~80L)
- 봄: 귀함 → 가을: 흔함 → 계절에 따른 가치 변동
- **고구려 진대법**: 봄에 1석 빌려주면 가을에 1.5석 회수 (50% 이자)

### 2. 포(布) — 직물 화폐
- 삼베(麻布): 서민 거래의 표준 화폐
- 길이×폭 기준으로 가치 측정 (1필 = 약 40척 × 2척)
- 세금 납부에도 사용 — "조(調)" 납부 수단
- **비단(絲)**: 고급 교역 화폐 — 귀족·외교 거래

### 3. 철(鐵) — 가야의 화폐
- 철정(鐵鋌): 판 형태로 가공한 철 덩어리 — 사실상 가야의 화폐
- 중국 사서 기록: "변한(가야)의 철은 낙랑·대방·왜가 모두 가져간다"
- **철의 경제적 의미**: 가야 철정 = 현대의 달러권 기축통화
- 철정 크기·순도에 따라 가치 차등

### 4. 금·은 — 귀족·외교 화폐
- 금(金): 장신구 + 왕실 선물 + 사원 시주
- 은(銀): 외교 선물·고급 거래
- 금동(金銅): 도금 기술 → 불상·관식(冠飾) 제작 → 권위 상징
- 삼국 모두 금 세공 기술 보유 — 신라 금관, 백제 금동대향로 등

### 5. 포획물·희귀품
- 모피(毛皮): 고구려 특산 — 담비·여우 모피는 귀족 화폐
- 진주·산호: 남해안 특산 — 가야·신라 교역품
- 말(馬): 외교 선물의 표준 아이템 — "말 몇 필"이 동맹의 가격

## 왕국별 교환 경제 특징

### 고구려
| 항목 | 내용 |
|------|------|
| 주요 화폐 | 곡물·모피·철기 |
| 특징 | 정복 공납이 주요 수입 → 화폐 필요성 낮음 |
| 고급 거래 | 말·금속 공예품 |
| 외교 선물 | 모피·철제 무기 |

### 백제
| 항목 | 내용 |
|------|------|
| 주요 화폐 | 비단·도자기·삼베 |
| 특징 | 해상교역 발달 → 다양한 교환 매개물 보유 |
| 고급 거래 | 중국제 수입품(비단·도자)을 중계 교역 |
| 외교 선물 | 공예품·불상·서적 |

### 신라
| 항목 | 내용 |
|------|------|
| 주요 화폐 | 곡물·삼베·금제품 |
| 특징 | 가야 병합 후 철기 경제 흡수 |
| 고급 거래 | 금·금동 장신구 |
| 외교 선물 | 금제품·직물 |

### 가야
| 항목 | 내용 |
|------|------|
| 주요 화폐 | **철정(鐵鋌)** — 동아시아 기축 교역재 |
| 특징 | 철 생산·수출로 동아시아 무역망 장악 |
| 교역 대상 | 낙랑·대방·왜·신라·백제 |
| 몰락 원인 | 철 교역망 장악 실패 + 고구려 군사 압박 (400년) |

## 중국제 주화의 유입

### 반량전(半兩錢)·오수전(五銖錢)
- 중국 한나라 주화 → 낙랑군을 통해 유입
- 주로 낙랑·대방 지역 + 일부 교역 거점에서 유통
- 삼국 내부 거래보다 **대중국 교역** 결제 수단

### 개원통보(開元通寶)
- 당나라 주화 → 7세기 나당 교역 시 유입
- 통일신라 이후 주화 경제 전환의 단초

## 시장과 교환 장소

### 시장 (市)
- **경시(京市)**: 수도의 공설 시장
  - 고구려 국내성·평양 시장
  - 백제 사비성 시장
  - 신라 서라벌 시장 (동시·서시)
- 개장 시간: 주로 낮 시간 한정
- 관리: 국가가 도량형·가격 감독

### 신라 경주 동시(東市)
- 가장 잘 알려진 삼국시대 시장
- 동시전(東市典): 시장 관리 관청
- 신라 통일 전부터 운영 — 가장 체계적인 상업 시스템

### 물물교환 거점
- 사원(寺院): 불교 사원이 교역 중심지 역할 겸임
- 나루(津): 강 하구·교통 요지 — 자연발생적 장터
- 국경 교역소: 삼국 접경 지대 — 중립적 교환 장소

## 도량형

| 단위 | 내용 |
|------|------|
| 석(石) | 곡물 부피 단위 — 세금·거래 기준 |
| 필(匹) | 직물 길이 단위 |
| 근(斤) | 무게 단위 — 금속·약재 |
| 척(尺) | 길이 단위 — 건축·직물 |

**중요**: 삼국 간 도량형이 통일되지 않아 교역 시 분쟁 발생 — 협상의 여지이자 사기 가능성의 공간

| 전쟁 후 경제 붕괴 | 전쟁 직후 곡물 가격 폭등·유민 발생 — 민중 고통 리얼 묘사 |
