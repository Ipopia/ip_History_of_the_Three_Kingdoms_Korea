# VFX & 이펙트 가이드

## VFX 철학

> "이펙트는 보조자다. 관객이 이펙트를 의식하는 순간 실패다. 역사의 현장에 있다는 감각이 먼저다."

삼국시대 IP의 VFX는 세 가지 영역으로 구분된다:
1. **실재 VFX**: 전쟁·화재·자연 현상 — 역사적 리얼리즘 최우선
2. **신화 VFX**: 삼족오·사신도·신화 존재 — 고분 벽화 미학 기반
3. **감정 VFX**: 침묵의 순간·기억·죽음 — 최소한의 표현

---

## 전투 VFX

### 화살 이펙트

**대규모 화살 세례**
```
표현 원칙:
- 화살 궤적: 완만한 포물선 — 중력 반영
- 밀도: 하늘을 덮는 수준 (살수대첩·황산벌)
- 음향 연동: 발사→공기 가르는 소리→충돌
- 착지: 흙먼지 분산 + 방패 충돌

색채:
- 화살대: 목재 갈색 `#8B6040`
- 철촉: 금속 반사 `#B0B0B0`
- 깃: 검정·흰색 (왕국별 구분)
```

**고구려 맥궁(貊弓) 특화**
- 복합궁 발사 속도: 일반 궁보다 빠른 궤적
- 연속 발사: 빠른 리듬 → 연속 파동 효과

---

### 화재 이펙트

**성벽 화공(火攻)**
```
불꽃 레이어:
1. 기저 불꽃: 오렌지-적 `#E84020` — 크고 무거운 덩어리
2. 중간 불꽃: 황 `#F0A030` — 빠르고 날카로운 혀
3. 상단 불꽃: 흰-황 `#F8F060` — 가장 뜨거운 핵심
4. 연기: 짙은 흑-회 `#202828` — 두텁게 피어오름
5. 불티: 오렌지 파티클 — 흩어지며 소멸

조명 영향:
- 불꽃 반경 5m: 오렌지 리밍 라이트 필수
- 캐릭터 얼굴: 불꽃 빛 플리커 적용
```

**낙화암 화재 (660년)**
- 백마강 반사: 물 위에 비치는 불꽃
- 궁궐 화재 연기: 달빛+연기 — 독특한 야간 조명
- 불티 낙화: 꽃잎처럼 떨어지는 시각 언어

---

### 충돌·파괴 VFX

**성벽 파괴**
```
파괴 단계:
1단계: 균열 — 화강암 분진
2단계: 붕괴 시작 — 돌덩이 낙하
3단계: 완전 붕괴 — 먼지 구름 폭발
4단계: 잔해 정착 — 먼지 서서히 가라앉음
```

**방패 충돌**
- 목제+가죽: 나무 갈라지는 표현
- 철갑 vs. 철갑: 불꽃 + 금속음

## 자연 현상 VFX

### 물(水) 이펙트

**살수대첩 수문 개방**
```
핵심 장면:
1. 수문 열림: 댐 균열 → 물 흘러나옴
2. 파도 생성: 대규모 수괴 이동
3. 수나라군 휩쓸림: 물+인체 시뮬레이션
4. 혼돈 정점: 물·갑옷·병사 혼재
5. 잔잔해짐: 부유하는 잔해

색채: 청회+탁황 `#607080` `#C0A060` (토사 혼입)
파티클: 물방울 비산 + 물보라
```

**백마강 흐름**
- 평상시: 느리고 맑은 S자 흐름
- 멸망 당일: 빠르고 탁한 흐름 (폭우 설정)

---

### 바람 이펙트

**전장 먼지**
```
황토 평원 (황산벌):
- 기병 이동: 황토 먼지 기둥
- 돌격: 먼지 벽이 진격 방향 표시
- 전투 중: 먼지로 가시성 저하 → 혼돈 표현
색채: 황토 `#C09040` → 회색 `#A09080`
```

**산바람 운무**
- 산성 장면: 안개+바람으로 극적 등장 연출
- 새벽 운무: 수평 이동 — 시간 경과 표현

---

### 번개·뇌우

**역사적 전환점 장면**
- 연개소문 쿠데타: 번개 배경 권장
- 신라 황룡사 낙뢰: 역사 기록 반영
- 전투 전 뇌우: 불길한 징조

**번개 표현 원칙**
- 색채: 청백 `#D0E8FF` — 단순 흰색 금지
- 형태: 불규칙 분기 — 자연스러운 패턴
- 지속: 0.1초 이하 — 눈 부심 효과

## 신화 VFX

### 삼족오 이펙트

**등장 방식**
```
원칙: 직접적 신화 표현보다 암시적 표현 우선

권장:
- 태양 앞 새 실루엣 (역광)
- 까마귀 떼 → 형태가 삼족오로 모임
- 고분 벽화 스타일 플래시백

비권장:
- 실사 3D 삼족오 직접 등장 (CGI 과잉 위험)
- 발광하는 황금 삼족오 (판타지화 위험)
```

---

### 사신(四神) 이펙트

**고분 벽화 트랜지션**
- 실사 장면 → 고분 벽화 스타일 애니메이션 전환
- 사신이 등장하는 장면: 벽화 채색 기법 모방
- 색채: 벽화 원색 기반 — 청·백·주·흑

**현현 표현**
- 직접 등장: 최소화 — 꿈·환상 장면 한정
- 간접 표현: 구름 형태·물결 패턴으로 암시

---

### 구미호·도깨비 이펙트

**구미호**
```
등장 원칙:
- 여우 → 인간 형태 변환은 안개+달빛 활용
- 꼬리: 9개, 반투명 — 실체 없는 빛
- 눈: 황색 발광 (절제)
- 사라질 때: 빛 파티클 분산
```

**도깨비**
```
등장 원칙:
- 묵직한 실체감 — 비현실적 투명화 금지
- 타오르는 도깨비불: 청색 불꽃 `#4080F0`
- 방망이: 단순하고 거친 목봉+금속
```

## 감정 VFX

### 죽음 장면 VFX

**전투 전사**
```
원칙: 과도한 피 표현 지양 — 감정 집중
허용:
- 옷에 번지는 혈흔 (절제된 양)
- 쓰러지는 순간 슬로우 모션
- 배경 포커스 아웃

금지:
- 신체 절단 고어 장면
- 과잉 혈액 VFX
- 무기 관통 클로즈업
```

**왕의 죽음**
```
연출 VFX:
- 촛불 꺼짐 (실내)
- 바람 일어남 (야외)
- 배경 탈포화 — 색이 빠짐
- 음악과 연동 (VFX→사운드 핵심 포인트)
```

---

### 회상·기억 VFX

**과거 회상**
```
전환 방식:
- 현재 장면 → 화면 가장자리부터 탈포화
- 중심부만 남기며 과거로 디졸브
- 과거 장면: 따뜻한 색조+약한 비네트

금지:
- 현대 영화식 반짝임 전환
- 워프·왜곡 효과 (시대적 맥락 이탈)
```

### 특수 감정 VFX

| 감정 | VFX | 제한 |
|------|-----|------|
| 왕의 결단 | 배경 바람+촛불 흔들림 | 최소한 |
| 비극 절정 | 슬로우 모션+탈포화 | 10초 이내 |
| 신화적 탄생 | 빛 파티클+연기 | 30초 이내 |
| 전쟁의 공포 | 먼지+소음만 | 과잉 VFX 금지 |
| 통일의 공허 | VFX 없음 — 침묵 | 의도적 금지 |

## VFX 금지 규정

1. **현대 판타지 스타일 빔·에너지파 금지** — 삼국시대에 초능력 없음
2. **과잉 슬로우 모션 남용 금지** — 핵심 장면 한정
3. **과도한 혈액·고어 VFX 금지** — 감정 집중 방해
4. **CGI 티 나는 군중 금지** — 실제 엑스트라 + 자연스러운 군중 확장
5. **신화 존재의 직접 실사 표현 최소화** — 암시·벽화 스타일 우선
6. **렌즈 플레어 과잉 금지** — 현대 영화 감성 이탈
