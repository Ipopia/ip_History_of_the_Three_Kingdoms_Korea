### 왕권의 성격

| 왕국 | 왕권 유형 | 특징 | 제약 요소 |
|------|----------|------|----------|
| 고구려 | 강력한 전제왕권 → 후기 귀족 과두제 | 연개소문 집권 후 왕권 형해화 | 5부 귀족 연합 |
| 백제 | 중앙집권적 귀족 왕국 | 16관등제 체계적 관료 체계 | 8성 귀족 합의 |

## 고구려 정치 체계

### 5부(部) 체제

**5부 구성**
- 내부(內部): 왕실 직속 — 가장 강력
- 동부(東部)·서부(西部)·남부(南部)·북부(北部): 각 귀족 집단

**운영 방식**
- 각 부(部)가 독자적 군사력·영토 보유
- 왕은 5부 중 최강자 — 절대 권력 아님
- 대대로(大對盧): 수상 — 귀족 선출 (왕 임명 아님)

**연개소문 쿠데타의 의미 (642)**
- 영류왕 + 180명 귀족 시해
- 보장왕 옹립 → 왕은 허수아비
- 연개소문 = 대막리지(大莫離支): 행정·군사 전권 장악
- 사실상 군사 독재 — 왕권 완전 형해화

**정치적 결과**
- 연개소문 사후 (666) 아들들의 권력 투쟁
- 연남생 당에 투항 → 고구려 방어 붕괴
- "강한 독재가 나라를 강하게도, 약하게도 한다"

## 백제 정치 체계

### 16관등제

**상위 관등 (귀족)**
1. 좌평(佐平): 6명 — 각 분야 최고위
2. 달솔(達率)
3. 은솔(恩率)
...16. 극우(剋虞)

**좌평 6명의 역할**
| 좌평 | 담당 |
|------|------|
| 내신좌평(內臣佐平) | 왕명 출납 |
| 내두좌평(內頭佐平) | 재정 |
| 내법좌평(內法佐平) | 의례·예법 |
| 위사좌평(衛士佐平) | 왕실 호위 |
| 조정좌평(朝廷佐平) | 형벌·사법 |
| 병관좌평(兵官佐平) | 군사 |

**8성(姓) 귀족 체제**
- 사(沙)·연(燕)·협(협)·해(解)·진(眞)·국(國)·목(木)·백(苩) 8대 성씨
- 이들이 좌평 독점 → 사실상 귀족 과두제

**의자왕의 개혁 시도와 실패**
- 즉위 초: 귀족 세력 억제 시도
- 중기: 왕권 강화 성공 — 신라 공격 주도
- 후기: 귀족 세력 반발 + 사치 → 개혁 좌절
- 결과: 나당 침공 시 귀족 협력 체계 붕괴

## 신라 정치 체계

### 골품제(骨品制)

**골품 구조**
| 골품 | 해당 인물 | 최고 관직 |
|------|----------|----------|
| 성골(聖骨) | 왕족 — 부모 모두 왕족 | 왕위 |
| 진골(眞骨) | 왕족 방계 | 이찬(2등급) 이상 |
| 6두품 | 상위 귀족 | 아찬(6등급) 이하 |
| 5두품 | 중위 귀족 | 대나마(10등급) 이하 |
| 4두품 이하 | 하위 귀족·평민 | 제한적 |

**성골 소멸과 진골 왕위**
- 선덕여왕: 마지막 성골 왕
- 진덕여왕 사후 성골 단절
- 무열왕(김춘추): 최초 진골 출신 왕 → 신라 정치 혁명

**화백(和白) 제도**
- 진골 귀족 만장일치 합의
- 왕권 결정에도 화백 동의 필요
- 긍정적 기능: 독재 방지, 합의 정치
- 부정적 기능: 개혁 저항, 보수 귀족 기득권 유지

**6두품의 딜레마**
- 능력이 있어도 골품 한계 — 아찬 이상 불가
- 설총·최치원 같은 인재가 골품제 벽에 막힘
- 통일 후 6두품 지식인 대거 당나라 유학 → 인재 유출
- 신라 멸망의 구조적 원인

## 가야 연맹 정치 체계

### 연맹 왕국의 구조

**금관가야 중심기 (1~4C)**
- 김해 금관가야가 연맹 맹주
- 각 소국 자치 유지 + 철 교역 수익 분배
- 왜·낙랑·대방 교역망 통제

**대가야 중심기 (5~6C)**
- 400년 고구려 남정 이후 금관가야 쇠퇴
- 고령 대가야가 연맹 맹주로 부상
- 신라·백제와 이중 외교 — 균형 실패

**연맹체의 취약성**
- 중앙집권 불가 — 각 소국의 이해관계 충돌
- 신라의 분열 공략: 소국별 개별 회유·복속
- "뭉치면 살고 흩어지면 죽는다" — 가야는 결국 흩어졌다

## 정치 체계의 IP 서사 적용

### 권력 구조가 만드는 드라마

| 구조 | 서사 가능성 |
|------|-----------|
| 고구려 대대로 선출제 | 귀족들의 수상 자리 쟁탈전 |
| 백제 8성 귀족 | 귀족 간 정략 결혼·암투 |
| 신라 화백 | 만장일치 실패 → 정치 위기 |
| 골품제 | 능력 있는 6두품의 좌절과 반란 |
| 가야 연맹 | 맹주 교체를 둘러싼 소국 간 음모 |
| 연개소문 독재 | 혁명가의 타락 — 권력이 사람을 바꾼다 |

### 정치 개혁가 캐릭터 원형

- **을파소**: 고구려 — 진대법으로 가난한 자를 구한 재상
- **이사부**: 신라 — 실용주의 장군 겸 외교관
- **의자왕**: 백제 — 개혁을 시도했으나 좌절한 마지막 왕
- **연개소문**: 고구려 — 혁명가이자 독재자 (선악 이분법 거부)
- **김춘추**: 신라 — 외교로 역사를 바꾼 현실주의자
