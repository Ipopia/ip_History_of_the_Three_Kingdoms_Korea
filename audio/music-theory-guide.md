# 음악 이론 가이드 — 삼국(三國) IP

**참조 문서**: `ost-composition-guide.md`, `ost-concept.md`, `sound-bible.md`, `culture-bible.md`
**작성**: 사운드본부 음악이론팀 (AUDIO-THEORY)
**적용**: 작곡가·편곡가·음악 감독 공통 기준 — 삼국(三國) 음악 언어 확립

---

## 음악 철학

```
삼국(三國) 음악의 핵심 원칙:
「강이 흐르듯 — 음악은 끊기지 않고 이어진다」

① 한국 전통 악기의 소리로 시작한다
② 현대 오케스트라로 확장한다
③ 4왕국은 각자의 음악 언어를 가진다
④ 강(물) = 통합의 음악 모티프
⑤ 캐릭터 테마는 변주되되 정체성을 잃지 않는다
```

## 스케일 & 모드 체계

### 4왕국 조성 시스템

```
고구려 조성:
  기본 스케일: D 도리아 (D-E-F-G-A-B-C)
  특성: 단조 베이스이나 6음(B)이 밝음
  분위기: 강직하나 깊음 — 영웅적 비장
  전통 참조: 고구려 고취(鼓吹) 음악 — 타악 강조
  사용 악기: 해금·아쟁·북·징 + 현악 유니즌

백제 조성:
  기본 스케일: G 리디아 (G-A-B-C#-D-E-F#)
  특성: 장조 + #4음으로 몽환적·우아한 느낌
  분위기: 아름다우나 슬픔이 배인
  전통 참조: 백제 정재(呈才) — 궁중 음악
  사용 악기: 가야금·거문고·대금·피리 + 현악 소편성

신라 조성:
  기본 스케일: E 믹솔리디아 (E-F#-G#-A-B-C#-D)
  특성: 장조적 밝음 + b7음의 개방감
  분위기: 화려하고 당당한 — 황금 빛
  전통 참조: 향악(鄕樂) — 신라 고유 음악
  사용 악기: 신라 화랑 진군악 + 금속 타악 + 현악 풍성

가야 조성:
  기본 스케일: A 오음음계 (A-C-D-E-G)
  특성: 5음 펜타토닉 — 단순하나 깊은 울림
  분위기: 소박하고 쓸쓸한 — 사라지는 것의 아름다움
  전통 참조: 우륵 가야금 12곡 — 삼국사기 악지 기반
  사용 악기: 가야금 솔로 중심 + 최소 반주
```

### 강 모티프 조성

```
「강은 기억한다」통합 모티프:
  조성: F# 마이너 (메인 테마)
  이유: 4왕국 조성 모두에서 F# 포함 → 통합 연결고리

강 진행 코드:
  F#m → D → A → E → F#m
  (단조 토닉 → 장6도 → 장3도 → 장7도 → 회귀)
  의미: 흘러나가지만 결국 돌아오는 강물

에필로그 조성:
  F# 메이저로 전조 (비극에서 희망으로)
  마지막 해결: F#m → F#M (단조→장조 모달 전환)
```

## 리듬 & 박자

### 왕국별 리듬 DNA

```
고구려 리듬:
  기본 박자: 4/4 → 긴장 씬 3/4 전환
  특징: 강한 1박 + 2박 쉬고 + 강한 3박 (행진 패턴)
  북 패턴: 「둥-쿵-따-쿵」(기마병 패턴)
  빠르기: MM = 92~120 (전투) / 60~72 (서정)

  전투 리듬 패턴:
    [북] 4분음표×2 + 8분음표×4 + 쉼표×2 반복
    [징] 4마디마다 강조 타격
    의미: 질서정연한 고구려 군대 = 흔들리지 않는 박자

백제 리듬:
  기본 박자: 3/4 (우아한 왈츠 감성)
  특징: 첫 박 가볍고 2-3박 흐름 → 우아한 흐름
  가야금 패턴: 아르페지오 중심
  빠르기: MM = 76~96

  아랑 테마 리듬:
    16분음표 붓글씨 패턴 → 「쓰고 또 쓰는」느낌
    말이 빠른 아랑의 성격 반영

신라 리듬:
  기본 박자: 4/4 + 가끔 5/4 (예언적 불안정)
  특징: 강한 액센트 + 황금 파티클 같은 트레몰로
  빠르기: MM = 100~140

  화랑 행진 패턴:
    스네어 드럼 (현대 타악 대신 전통 북으로 대체)
    씩씩하고 절도 있는 패턴

가야 리듬:
  기본 박자: 자유 박자 (가야금 연주 특성)
  특징: 숨쉬는 박자 — 빠르게 달렸다 천천히 느려짐
  빠르기: 가변적 (루바토 허용)

  니문 연주 패턴:
    정박보다 약간 앞서거나 뒤서는 표현 허용
    「기다리는 음악」— 다음 음이 오기를 기다리는 느낌
```

### 전투 긴장 리듬

```
살수대첩 전투 리듬:
  박자: 7/8 (3+2+2 또는 2+2+3)
  의미: 예측 불가능한 전투의 불안정성
  전개: 7/8 → 점점 빨라지며 4/4 → 클라이맥스에서 통합

안시성 공방전:
  박자: 4/4 + 헤미올라 (2:3 리듬 교차)
  의미: 2개월 공방 = 지루하고 고된 반복
  전개: 단조로운 반복 → 갑작스러운 변화 (성벽 역습)
```

## 주제 선율 (라이트모티프)

### 메인 테마 — 「강은 기억한다」

```
선율 형태:
  4마디 기본 모티프:
    F#m: 라-도#-미-레-도# (강물처럼 흐르는 선율)
    특징: 올라갔다 내려오는 아치형

  변주 방식:
    V1: 가야금 솔로 (첫 등장 — 원형)
    V2: 현악 + 가야금 (발전)
    V3: 풀 오케스트라 (클라이맥스)
    V4: 피아노 솔로 (비극 씬 변형)
    V5: 코러스 (에필로그)

등장 시점:
  EP01 오프닝: V1 가야금
  살수대첩 직전: V2 현악
  EP07 을지문덕 퇴장: V4 피아노
  시즌 1 피날레: V3 풀 오케스트라 → V5 코러스
```

### 고루 테마 — 「철의 의지」

```
선율:
  D 도리아: 레-파-솔-라-도-라-솔 (하강 후 상승)
  특징: 강직한 4도 도약 → 결의

리듬 특성:
  점음표 리듬 (♩.+♪) = 무겁게 걷는 전사
  쉼표 없음 = 흔들리지 않는 의지

악기:
  첫 등장: 해금 유니즌 + 저음 타악
  성장: 현악 + 금관
  클라이맥스: 전 오케스트라 + 코러스
```

### 아랑 테마 — 「기록하는 손」

```
선율:
  G 리디아: 솔-라-시-도#-레 (올라가는 5음, 희망적)
  특징: 빠른 16분음표 → 붓글씨 같은 흐름

리듬 특성:
  트리플렛(셋잇단음표) 빈번 = 말이 빠른 아랑
  긴 음표는 「발견의 순간」에만

악기:
  가야금 아르페지오 + 플루트 선율
  비극 전환: 첼로 솔로 + 가야금

특별 기법:
  죽간에 글 쓰는 소리 = 타악 서브 리듬
  (리드 스틱으로 나무 표면 두드리기)
```

### 하린 테마 — 「화랑의 빛」

```
선율:
  E 믹솔리디아: 미-파#-솔#-라-시 (밝고 당당한 상승)
  특징: 4도 도약 + 황금 트레몰로

리듬 특성:
  당기는 리듬 (당김음) = 화랑의 용기 있는 돌진
  강한 1박 + 가벼운 2박 = 검을 휘두르는 느낌

악기:
  첫 등장: 트럼펫 + 황금 심벌즈
  서정 변주: 바이올린 솔로
  전투: 금관 풀 섹션 + 타악
```

### 니문 테마 — 「12번째 악곡」

```
선율 (미완성으로 시작):
  A 펜타토닉: 라-도-레-미-솔 (소박하고 깊은 5음)
  특징: 첫 4음만 반복 → 시즌 1 내내 완성 안 됨

미완성 표현:
  선율이 5음째에서 끊김 = 서사적 긴장
  끊긴 자리에 가야금 현 감음(減音) 소리

완성 순간 (EP24 / 시즌 1 피날레):
  마침내 5음 완성: 라-도-레-미-솔-라 (완전한 옥타브)
  전환: 가야금 솔로 → 풀 오케스트라 + 메인 테마 통합
  의미: 니문의 완성 = 삼국의 이야기가 완성됨

악기:
  항상 가야금 솔로로 시작
  완성 시: 현악 전체 + 합창 추가
```

## 오케스트레이션 가이드

### 편성 구성

```
전통 악기 섹션 (Front):
  현악: 가야금·거문고·아쟁·해금
  관악: 대금·단소·태평소·피리·생황
  타악: 장구·북·징·편경·편종

서양 오케스트라 (Back):
  현악: 바이올린×20·비올라×8·첼로×6·더블베이스×4
  관악: 플루트·오보에·클라리넷·바순 (각 2)
         호른×4·트럼펫×3·트롬본×3·튜바×1
  타악: 팀파니·심벌즈·스네어·마림바·피아노
  특수: 코러스 (20명, 혼성)

믹싱 원칙:
  전통 악기: 중심 선율·감성 주도
  오케스트라: 화성·음량·드라마 확장
  비율: 씬별 조정 (조용한 씬 = 전통 70% / 전투 = 오케스트라 70%)
```

### 왕국별 오케스트레이션

```
고구려 씬:
  전면: 해금 + 아쟁 (거친 음색)
  타악: 북 강조 + 징 강조
  오케스트라: 저음 현악 + 금관
  특이: 유니즌 많음 (단일 의지 표현)

백제 씬:
  전면: 가야금 + 대금 (맑고 우아한 음색)
  타악: 최소화
  오케스트라: 현악 소편성 (카메라타)
  특이: 폴리포니 (여러 선율 동시) = 복잡한 감정

신라 씬:
  전면: 태평소 + 편경 (화려하고 밝은 음색)
  타악: 편종 (황금 소리)
  오케스트라: 풀 현악 + 금관
  특이: 트레몰로 많음 (황금 빛 떨림 표현)

가야 씬:
  전면: 가야금 솔로 (거의 단독)
  타악: 없음 또는 최소
  오케스트라: 현악 피치카토만 (나머지 침묵)
  특이: 침묵 활용 = 사라진 것들의 공백
```

## 음악 제작 워크플로우

```
1단계 — 테마 스케치:
  작곡가가 각 캐릭터/왕국 테마 피아노 스케치 제출
  음악감독 검토 → IP창작본부 서사팀 감수 (서사 일관성)

2단계 — 편곡:
  전통악기 배치 → 국악 전문 편곡자
  오케스트라 배치 → 클래식 편곡자
  전통+현대 믹스 → 음악감독 통합

3단계 — 녹음:
  국립국악원 협력 → 전통 악기 녹음
  오케스트라 녹음 → 국내 주요 홀
  믹싱: Dolby Atmos (드라마) / 스테레오 (음원)

4단계 — 라이브러리화:
  게임용: 스테m 분리 파일 (FMOD 연동)
  애니용: 장면별 태깅
  뮤지컬용: 피아노 리덕션 버전 병행 제작
```
