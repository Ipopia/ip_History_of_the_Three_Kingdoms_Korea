# 중화권 시장 현지화 가이드 — 삼국(三國) IP

**참조 문서**: `localization-guide.md`, `international-market-strategy.md`, `content-localization-japan.md`, `ip-registration-plan.md`
**작성**: 글로벌사업본부 중화권팀 + 전문자문본부 ADV-POLIECON
**적용**: 대만·홍콩·싱가포르 (1단계) / 중국 본토 (2단계, 별도 협의)

---

## 중화권 시장 개요

```
시장 분류:
1단계 (직접 진출): 대만 / 홍콩 / 싱가포르 / 말레이시아
2단계 (별도 퍼블리셔): 중국 본토 (정치·규제 리스크로 신중 접근)

중화권 핵심 강점:
1. 삼국지(三國志) 친숙도 — 「삼국」 브랜드 인지도 레버리지
2. 한류(韓流) 수용도 — 대만·홍콩 K-드라마 팬층
3. 고구려·백제의 중국 역사 연결 — 교류사 각도
4. 화교 네트워크 — 동남아 중화권까지 확장

주의:
중화권에서 「삼국(三國)」은 삼국지(三國志)를 연상시킴
→ 명확한 차별화 필요: "한국 삼국시대 — 고구려·백제·신라"
```

## 현지화 원칙

### 브랜드 네이밍

```
중문 브랜드명:
공식 명칭: 「三國 — 江水長憶」(삼국 — 강은 기억한다)
간체자: 三国 — 江水长忆
번체자: 三國 — 江水長憶

주의사항:
- 「三國志」와 혼동 방지 — 항상 부제 병기
- 고구려(高句麗)·백제(百濟)·신라(新羅) 부각
- 「韓國三國時代」명시 — 중국 삼국지와 구분

슬로건 번역:
「강은 기억한다」→「江水長憶」(강물은 오래 기억한다)
「The River Remembers」→「江河有憶」(강물에 기억이 있다)

앱/게임명:
三国 — 江水长忆 (간체, 중국 본토)
三國 — 江水長憶 (번체, 대만·홍콩)
```

## 드라마 현지화

### 번역 방향

```
기본 방침:
- 자연스러운 현대 보통화(普通話)
- 고어 투는 사용하지 않음 (중국 고대극 어투 금지)
- 한국 역사 드라마임을 명확히 — 중국 역사극과 혼동 금지

왕의 대사:
"더 가라. 지평선이 끝날 때까지." (광개토)
→ 「前进。直到天边尽头。」
  (직접적이고 강한 표현)

여왕의 대사:
"모란꽃 그림에 나비가 없었다. 그게 전부다." (선덕)
→ 「牡丹画中无蝴蝶。仅此而已。」
  (담담하고 의미심장한 톤)

계백의 대사:
"다시 오지 않는다. 그것으로 충분하다."
→ 「此去不回。如此已足。」
  (비장하되 절제된 톤)
```

### 자막·더빙 전략

```
대만·홍콩:
Phase 1: 한국어 원음 + 번체 중문 자막
Phase 2: 주요 장면 더빙 검토
Phase 3: 넷플릭스·iQIYI 동시 배포

중국 본토:
별도 심의 필요 (NRTA 등록)
현지 공동 제작사 통해 진출 검토
더빙 의무: 중국 방영 시 보통화 더빙 필수

더빙 캐스팅 방향 (대만):
- 광개토대왕: 깊고 낮은 남성 성우
- 선덕여왕: 지적이고 차분한 여성 성우
- 계백: 중후하고 비장한 남성 성우
- 우륵: 서정적이고 음악적인 남성 성우
```

## 게임 현지화

### 텍스트 현지화

```
언어 버전:
- 번체자 (대만·홍콩·마카오)
- 간체자 (중국 본토·싱가포르·말레이시아)

번역 분량:
- UI 텍스트: 약 50,000자
- 시나리오: 약 200,000자
- 보이스 스크립트: 약 80,000자
- 총계: 약 330,000자

번역 품질 기준:
- 네이티브 중국어 작성 (대만·중국 각각)
- 한국사 전문 감수 필수
- 삼국지(三國志) 용어와 혼동 방지 용어 목록 작성

게임 용어 표기:
- 화랑(花郎): 花郎 — 「무사」와 명확 구분
- 골품제(骨品制): 骨品制 — 설명 팝업 필수
- 가야금(伽倻琴): 伽倻琴 — 古琴·琵琶와 구분
```

### 중화권 앱스토어 전략

```
앱스토어 최적화 (ASO):
앱명 (번체): 三國 — 江水長憶
앱명 (간체): 三国 — 江水长忆
키워드: 韓國歷史, 高句麗, 古代戰略, 朝鮮三國

스크린샷:
- 중화권 사용자 선호: 캐릭터 + 스토리 강조
- 역사 정보성 강조 (차별화)

중국 본토 게임 규제:
- 판호(版号) 취득 필수 — 별도 퍼블리셔 통해
- 미성년자 게임 시간 제한 준수
- 현지화 콘텐츠 심의 통과 필요

```

1. 고구려·당나라 관계 — 교류사 각도 (갈등 최소화)

3. 동아시아 공동 역사 유산 표현

## 민감 사항 관리

```
고구려 영토 문제:
→ 현재 중국 동북지역에 위치
→ 표현: "4~7세기 고구려 왕국의 역사적 중심지"
→ 절대 금지: 현재 영토 주장, 중국 역사 부정
→ 중국 현지 파트너에게 최종 표현 검토 위임

동북공정 관련:
→ 고구려를 중국 역사로 주장하는 시각 반박 금지
→ 단, "한국 삼국시대 역사"임은 명확히 표기
→ 분쟁 발생 시: ADV-POLIECON + 법무본부 즉시 대응

수나라·당나라 전쟁 묘사:
→ 살수대첩·안시성: 고구려 승리 사실 그대로 기술
→ 중국 측 장수(양제·태종) 단순 악역화 금지
→ 당 태종의 안시성 성주 예우 반드시 포함
→ "역사적 갈등 — 양측 다 인간이었다" 각도

백제·가야의 왜국 교류:
→ 중화권에서 민감도 낮음 (일본 관련 이슈)
→ 그러나 "일본에 문화를 가르쳤다" 표현 자제
→ "문화 교류" 중립 표현 사용

위기 대응 체계:
→ 중화권 현지 PR 에이전시 계약 필수
→ 역사 관련 논란: 24시간 내 성명서 발표
→ 중국어 성명서: ADV-POLIECON + 현지 법무법인 검토
```
