## 만화 전략 개요

```
포지셔닝:
  웹툰과 차별화: 웹툰 = 세로 스크롤 디지털
              만화 단행본 = 가로 페이지 오프라인/디지털

타깃:
  1차: 만화 단행본 수집 팬덤 (20~40대)
  2차: 일본 망가 팬 (일본 수출 특화)
  3차: 도서관·교육 기관 (역사 교육 만화)

형식:
  메인: 일본 망가 스타일 (B6 판형, 우에서 좌 읽기)
  한국판: B6 / 국판 (좌에서 우 읽기) 병행
  페이지: 권당 180~200페이지

시리즈 구성:
  메인: 「삼국(三國)」본편 — 드라마 동일 서사 만화화
  스핀오프: 「가야의 금」— 니문 외전
  교육: 「삼국사기 만화」— 어린이/청소년 역사 교육
```

## 메인 시리즈: 「삼국(三國)」

### 시리즈 구성

```
총권 예상: 30권 (시즌 1: 10권 / 시즌 2: 10권 / 시즌 3: 10권)
발행 주기: 격월 (2개월마다 1권)

권별 내용 (시즌 1):
  1권: 프롤로그 — 4왕국 소개, 수나라 침공 예고
  2권: 고루의 소개, 을지문덕과의 만남
  3권: 아랑의 소개, 백제 사비성의 풍요
  4권: 하린의 소개, 신라 화랑 입단
  5권: 니문의 소개, 가야금과 기억
  6권: 수나라 1차 침공 — 요동성 방어전
  7권: 7번 퇴각 — 청야전술의 시작
  8권: 4인 첫 교차 — 각자 다른 방식의 충돌
  9권: 살수 유인 전략 — 을지문덕의 계략
  10권: 살수대첩 클라이맥스 — 강이 기억한다
```

### 비주얼 스타일

```
화풍:
  주 스타일: 세밀한 역사 고증 선화 + 스크린톤
  참조: 이노우에 타케히코 (배가본드 수준 전투 묘사)
         오다 에이치로 (캐릭터 개성 강조)
  한국적 특성: 고구려 벽화 구도 차용

캐릭터 비율:
  성인 8등신 (일반 망가 7~8등신)
  액션씬: 비율 과장 허용 (7등신)
  표정 묘사: 세밀함 최우선

배경 처리:
  도시·성곽: 정밀 건축 묘사 (ADV-ARCH 감수)
  자연 배경: 강·산·전장 — 계절감 표현 필수
  전투씬: 속도선 + 효과음 배치

왕국별 화면 분위기:
  고구려: 굵은 선, 강한 대비, 어두운 톤
  백제: 섬세한 선, 부드러운 명암, 따뜻한 톤
  신라: 황금빛 하이라이트, 정제된 구도
  가야: 서정적 여백, 물결 같은 선
```

## 스핀오프: 「가야의 금(金)」

```
기획 의도:
  니문의 조부 세대 → 가야 멸망(562년) 외전
  일본 시장 공략 (가야금·전통 악기 = 일본 수요)

총권: 6권
타깃: 음악·서정 팬덤, 여성 독자

스토리 개요:
  1~2권: 가야 전성기 — 우륵(于勒)의 가야금
  3~4권: 진흥왕 침공 — 대가야의 마지막 날
  5권: 우륵의 신라 귀화 — 가야금을 신라에 전하다
  6권: 니문 조부의 탄생 — 「기억의 계승자」

화풍: 메인 시리즈보다 서정적
  수채화 질감 배경, 음악 표현 시각화 (소리=빛)
  감성 독자 배려 — 이모셔널 핀업 이미지 포함
```

## 교육 만화: 「만화로 읽는 삼국사기」

```
기획 의도:
  역사 교육 시장 공략 (초등~중등)
  학교 도서관·공공 도서관 납품

총권: 10권
가격: 일반 만화보다 낮게 (교육 보조 포지셔닝)
  권당 12,000~14,000원

구성:
  1~2권: 고구려 (광개토대왕~살수대첩)
  3~4권: 백제 (근초고왕~황산벌)
  5~6권: 신라 (진흥왕~기벌포)
  7권: 가야 (수로왕~가야 멸망)
  8권: 통일신라 성립
  9권: 외교 (중국·일본과의 관계)
  10권: 삼국의 문화·예술

화풍: 친근한 캐릭터 (6등신), 교육 보조 정보 박스 포함
역사 자문: ADV-HISTORY 전권 감수 필수
```

## 유통 전략

### 국내

```
출판사 파트너:
  1순위: 학산문화사·대원씨아이 (만화 전문)
  2순위: 자체 출판 (CREATE 출판 브랜드)

판매 채널:
  오프라인: 서점 (교보·영풍·알라딘)
  온라인: YES24·교보·알라딘·쿠팡
  만화 전문: 서울 만화 전문 서점 직납
  도서관: 전국 공공도서관 납품 (교육 만화)

특전:
  초판 한정 띠지 (캐릭터 일러스트)
  합본 특장판: 드라마 방영 기념 (OST CD 동봉)
```

### 일본

```
출판 모델: 일본 출판사 에이전트 계약 (번역 출판권)
목표 출판사: 쇼가쿠칸·슈에이샤·고단샤 (상위 3사)
  차선: 부침샤·아키타쇼텐 (역사 만화 강점)

연재 전략:
  잡지 선연재: 소년/청년 망가 잡지 타진
  단행본 전환: 연재 후 2권씩 단행본 발행

일본판 특이사항:
  역사 조항: 임나일본부 해석 삭제 (계약 명문화)
  번역 감수: 한국 역사 전문 일본 번역가 필수
  카나 표기: 고유명사 한국어 원음 기준 (가이드 제공)

목표: 만화 단행본 일본 누적 50만부
```

### 글로벌

```
영어권:
  Viz Media / Dark Horse Comics 타진
  영어 번역: 현지 한국 역사 이해 번역가

동남아:
  Comico / WebtoonCanada 온라인 디지털판
  태국·인도네시아·베트남 번역 우선

중국:
  현지 파트너 통해 정식 출판 (해적판 방지)
  역사 민감 부분: 현지 법무 검토
```

## 제작 파이프라인

```
기획 단계 (D-18개월):
  스토리 어시스턴트: IP-PLOT 시놉시스 제공
  네임 작업: 만화 전담 네임 작가 배정
  1차 네임 → IP-PLOT + ART-DIR 검토

작화 단계 (D-12개월):
  작화 팀 구성: 메인 작가 1 + 어시스턴트 2~3
  배경 팀: 건축 고증 배경 전담 1명
  채색 (컬러판): 디지털 채색 전담

감수 단계 (D-3개월):
  ADV-HISTORY: 전권 역사 고증 검토
  QA-CONTINUITY: 드라마·소설 연속성 점검
  IP-LEGAL: 저작권·표기 최종 확인

납품 기준:
  인쇄: 300dpi 이상, CMYK
  디지털: 72dpi, RGB (웹·앱 최적화)
  파일: PSD 원본 보관 의무 (IP-LEGAL)
```
