**적용 기간**: 출시 전 6개월 ~ 출시 후 12개월

---

## PR 전략 개요

삼국(三國) IP는 **역사·문화·엔터테인먼트 융합 콘텐츠**다. PR 전략은 단순 홍보가 아닌 **문화 담론 형성**을 목표로 한다. 언론이 "광고를 받았다"가 아닌 "가치 있는 이야기를 발굴했다"고 느끼도록 설계한다.

### 핵심 PR 메시지

```
주 메시지: "강은 기억한다 — 잊혀진 역사가 살아 돌아온다"
부 메시지 1: "한국 고대사 최초의 풀 크로스미디어 IP"
부 메시지 2: "삼국사기 원전에 충실한 역사 고증"
부 메시지 3: "고구려·백제·신라·가야 — 네 왕국의 동등한 이야기"

언론별 각도:
- 문화·예술 언론: "새로운 한국 문화 IP의 탄생"
- 역사·교양 언론: "삼국사기를 현대적으로 재해석한 역사 바이블"
- 엔터테인먼트 언론: "드라마·게임·뮤지컬 동시 론칭 사상 최대 규모"
- 글로벌 언론: "K-콘텐츠의 다음 챕터 — 고대 한국"
- 비즈니스 언론: "풀 IP 상품화 새로운 비즈니스 모델"
```

## PR 타임라인

### Phase 1 — 선제 포지셔닝 (D-12~D-8주)

```
목표: 언론이 프레임을 만들기 전에 우리가 먼저 프레임 설정

실행:
1. 역사 전문가 기고문 배포 (D-12주)
   제목: "삼국시대, 왜 지금인가" — ADV-HISTORY 집필
   매체: 중앙일보 오피니언, 한국일보 기획

2. 문화부 기자 백그라운드 브리핑 (D-10주)
   — 오프 레코드 설명회 (10명 이내 소규모)
   — 세계관 바이블 일부 공개
   — 역사 고증 과정 설명

3. "삼국시대 문화 르네상스" 담론 형성 (D-8주)
   — 삼국시대 관련 전시·강연과 연계
   — 국립중앙박물관 협업 가능성 타진
```

---

### Phase 2 — 공식 발표 (D-6~D-4주)

```
D-6주: 공식 기자간담회 개최
- 장소: 서울 프레스센터 또는 전통 문화 공간
- 규모: 국내 기자 100명 + 해외 기자 20명
- 구성:
  1부: IP 전체 소개 (30분)
  2부: 드라마·게임·뮤지컬 담당자 발표 (30분)
  3부: 역사 자문위원 특강 (20분)
  4부: Q&A (30분)
- 특전: 아트 북 + 굿즈 기자 선물

D-5주: 드라마 캐스팅 발표
- 방법: 공식 SNS + 동시 보도자료 배포
- 연계: 캐스팅 기자 단독 인터뷰 (매체별 로테이션)

D-4주: 게임·뮤지컬 동시 발표
- 게임: G-STAR 또는 지스타 연계 발표
- 뮤지컬: 공연계 전문 매체 우선 배포
```

---

### Phase 3 — 출시 모멘텀 (D-2주~D+2주)

```
D-2주: 드라마 1·2화 시사회
- 대상: 언론·인플루언서·VIP 500명
- 장소: CGV IMAX 또는 대형 시사회장
- 이후: 24시간 내 모든 리뷰 해금 (엠바고 해제)

D-day: 전 매체 출시 동시 보도
- 드라마 1화 스트리밍 플랫폼 공개
- 게임 앱스토어 출시
- 소설 1권 발매
- 보도자료 전 매체 동시 배포

D+1주: 출시 반응 PR
- 시청률·다운로드·판매 수치 즉시 배포
- 해외 반응 수집 + 번역 배포
- "반응 좋은 장면" 클립 2차 배포

D+2주: 심층 기획 지원
- 역사 해설 특집 기사 자료 제공
- 해외 K-콘텐츠 전문 언론 인터뷰 세팅
```

---

### Phase 4 — 지속 PR (D+1~6개월)

```
월별 PR 이슈 캘린더:

1개월차: 드라마 시청률 + 게임 유저 반응
2개월차: 머천다이즈 출시 보도
3개월차: 해외 시장 진출 뉴스
4개월차: 시즌 2 제작 확정 발표
5개월차: 어워드 시즌 — 드라마 시상식 PR
6개월차: 연간 IP 성과 결산 보고

위기 PR 대비:
- 역사 왜곡 논란 → 자문위원 즉각 입장문
- 캐스팅 논란 → 제작진 인터뷰로 해명
- 경쟁 IP 등장 → 차별성 강조 자료 배포
```

## 단독 보도 전략

```
단독 보도는 언론과의 관계 형성 최고 수단

단독 배분 계획:
- 캐스팅 발표: 매체별 순차 단독 (일간지 → 방송 → 온라인)
- 제작 비하인드: 전문 매체 단독 (씨네21, 게임메카 등)
- 해외 수출 계약: 경제지 단독
- 아트 공개: 미술 전문 매체 단독

단독 보도 조건:
- 엠바고 날짜·시간 명시
- 독점 이미지 또는 영상 제공
- 담당자 인터뷰 연결
```

## 기자 관계 관리

```
핵심 기자 DB 구축:
- 문화부 기자: 50명
- 엔터테인먼트 기자: 80명
- 경제지 기자: 30명
- 해외 한국 담당 기자: 40명
합계: 약 200명

관계 관리:
- 분기별 비공식 미팅 (기자단 소규모 식사)
- 독점 콘텐츠 우선 제공
- 생일·기념일 개인화 메시지
- 현장 취재 편의 최우선 지원

언론 윤리:
- 기사 수정 요청 금지 (팩트 오류만 교정 요청 가능)
- 광고와 기사 명확 분리
- 기자에게 부당한 혜택 제공 금지
```
