## 시즌 1 집필 원칙

```
집필 3원칙:
1. 「강은 기억한다」주제가 매 화에 하나 이상 반영
2. 4인 주인공 중 최소 2인이 매 화에 등장 (서사 교차)
3. 역사적 사실 = 변경 불가 / 캐릭터 감정 = 창작 자유

대사 원칙:
- 한자 직접 인용 최소화 → 현대적 감성 번역
- 을지문덕 한시 등 사료 대사는 원문 + 현대어 자막 병기
- 감정은 행동으로 보여주기 (설명하지 않기)

페이스 원칙:
- 화당 평균 분량: 60분 (±5분)
- 전투 씬: 화당 최대 15분 (집중력 유지)
- 인물 감정 씬: 화당 최소 10분 (서사 깊이)
```

## 시즌 1 에피소드 구성 요약

### Arc 1 — 오프닝 (EP01~03)

```
EP01: 「강이 시작된다」
  주요 인물: 을지문덕 + 고루 (첫 만남)
  사건: 수 침략군 정찰 첫 보고
  핵심 장면:
    - 오프닝: 압록강 새벽 전경 + 봉화 연기
    - 을지문덕이 고루에게 처음 말 건넴
    - 고루: 「장군님은 왜 강가에 서 계십니까?」
    - 을지문덕: 「강은 기억한다. 너도 곧 알게 될 것이다.」
  동시 컷: 아랑 (백제 서고에서 기록), 하린 (화랑 훈련),
           니문 (가야에서 가야금 연주)
  엔딩: 봉화 4개 → 최대 위기 신호

EP02: 「기록하는 자들」
  주요 인물: 아랑 + 성충
  사건: 나당 연합 첫 정보 입수
  핵심 장면:
    - 성충, 아랑에게 기록의 사명 전수
    - 아랑: 「이것을 기록하면 위험하지 않습니까?」
    - 성충: 「기록하지 않으면 더 위험하다.」
    - 성충 첫 직간(直諫) 시도 → 의자왕 외면

EP03: 「화랑의 맹세」
  주요 인물: 하린 + 선덕여왕
  사건: 하린 화랑 정식 임명
  핵심 장면:
    - 선덕여왕 첫 등장 — 왕의 품위 확립
    - 하린 맹세 씬: 「죽어도 물러서지 않겠습니다.」
    - 선덕여왕: 「그 말을 기억하겠다.」
    - 니문 소개: 신라 편입 직후 가야금 연주
```

### Arc 2 — 살수 (EP04~07)

```
EP04: 「수나라가 온다」
  사건: 수 양제 113만 대군 진격 시작
  핵심 장면:
    - 을지문덕의 정보망 가동 (봉화·파발)
    - 고루 첫 전투 (소규모 전초전)
    - 을지문덕 전략 설명 씬: 「7번 물러서라」

EP05: 「7번의 후퇴」
  사건: 고구려군 고의 패퇴 × 7회
  핵심 장면:
    - 병사들의 불만 → 고루가 달램
    - 을지문덕이 수 우중문에게 한시 보내는 씬
    - 한시 낭송: 「神策究天文 妙算窮地理...」
    - 아랑 시점 교차: 백제에서 수 침략 소식 기록 중

EP06: 「살수 전야」
  사건: 살수 결전 전날 밤
  핵심 장면:
    - 을지문덕 + 고루 단둘이 강가 씬
    - 을지문덕: 「이 강이 내일 이긴다. 우리가 아니라.」
    - 고루: 「강이 어떻게 이깁니까?」
    - 을지문덕: 「강은 기억한다. 수나라가 얼마나 탐욕스러웠는지.」
    - 밤하늘 + 강물 클로즈업 → 메인 테마 OST

EP07: 「살수」(클라이맥스)
  사건: 살수대첩 (612년) — 수나라 대군 격퇴
  핵심 장면:
    - 을지문덕의 댐 개방 신호
    - 살수 범람 → 수나라 군대 괴멸
    - 전투 후 을지문덕 고루에게: 「이제 네가 기억하거라.」
    - 을지문덕 쓰러짐 (고령으로 쓰러짐, 사망 암시)
    - 고루 혼자 남음 — 삼족오 하늘에 날아오름
    - 에필로그: 4인의 현재 동시 컷 (각자의 왕국에서)
```

### Arc 3 — 내부 갈등 (EP08~12)

```
EP08: 「연개소문의 칼」
  사건: 642년 연개소문 쿠데타
  핵심 장면:
    - 고루 시점: 평양성 혼란
    - 연개소문 첫 등장 — 5자루 칼 허리에
    - 귀족 처단 씬 (직접 묘사 최소화, 암시로)
    - 고루 딜레마: 쿠데타를 막아야 하나? 나라를 위해 따라야 하나?
    - 결국 고루: 「나는 왕이 아닌 나라를 따른다.」

EP09~10: 「성충의 마지막 서간」
  사건: 백제 성충 투옥 → 옥중 상소 → 사망 (656년)
  핵심 장면:
    - EP09: 성충 투옥 씬 — 아랑이 마지막으로 봄
    - 성충: 「아랑아. 왕이 듣지 않는 말을, 강이 듣는다.」
    - EP10: 성충 옥중 상소 — 나당 연합 경고
    - 성충 사망 → 아랑, 비밀 기록 시작
    - 선덕여왕 등장 (신라 시점): 「백제가 위험하다.」

EP11~12: 「안시성」전편
  사건: 645년 당태종 침략 → 안시성 공방전
  핵심 장면:
    - 고루 안시성 방어선 합류
    - 양만춘(安市城 성주) 소개 — 역사 인물
    - 안시성 성벽 위에서 고루: 「을지문덕 선생의 전략을 기억한다.」
    - 하린 시점 교차: 신라에서 안시성 소식 듣는 장면
```

### Arc 4 — 결전 준비 (EP13~17)

```
EP13~14: 「황산벌의 그림자」전편
  사건: 나당 연합 결성 확정 정보
  핵심 장면:
    - 아랑이 연합 정보를 기록
    - 하린, 김유신 군대에 합류
    - 니문, 가야금 12번째 악곡 연습 시작
    - 4인 각자의 전야: 각왕국 동시 컷

EP15: 「선덕여왕의 예언」
  사건: 647년 선덕여왕 사망 + 비담의 난
  핵심 장면:
    - 선덕여왕 마지막 예언 씬
    - 선덕여왕 → 하린: 「하린아. 신라는 반드시 통일한다. 하지만 피가 있다.」
    - 하린: 「저는... 그 피에 있을 것입니까?」
    - 선덕여왕: 「네가 있어야 그 뒤가 있다.」
    - 선덕여왕 사망 → 하린의 울음 (처음으로)
    - 다음화 예고: 황산벌

EP16~17: 「마지막 기록 / 첫 소절」
  (publishing/webtoon/webtoon-script-ep16-18.md 참조)
  아랑·니문 집중 에피소드

EP18: 「대막리지의 명령」
  연개소문이 고루에게 최후 방어선 명령
  (screenplay-treatment.md 상세 참조)
```

### Arc 5 — 피날레 (EP19~20)

```
EP19: 「황산벌」(클라이맥스 1)
  사건: 660년 황산벌 전투
  핵심 장면:
    - 계백 5천 결사대 vs 신라 5만
    - 계백 출전 전 가족 씬 (직접 묘사 없음, 계백 표정만)
    - 하린 vs 계백 대면 — 첫 만남
    - 관창 첫 돌격 → 생포 → 석방 → 재돌격
    - 하린: 「막아라!」(관창에게) → 막지 못함
    - 관창 전사 → 신라군 사기 전환
    - 계백 전사 → 하린의 독백: 「용감한 자였다.」
    - 백제 멸망 (아랑 시점: 멀리서 불길)

EP20: 「강은 기억한다」(시즌 1 피날레)
  사건: 668년 고구려 멸망 임박
  핵심 장면:
    - 4인 동시 서사 교차 (마지막 시퀀스)
    - 아랑: 두루마리를 품에 안고 어딘가로 감
    - 하린: 관창의 머리띠를 매며 걸어감
    - 니문: 12번째 악곡 마지막 현을 튕김 → 완성
    - 고루: 강가에서 압록강을 바라봄
    - 고루의 마지막 독백:
      「강은 기억한다.
       우리가 여기 있었음을.
       싸웠음을.
       기록했음을.
       노래했음을.
       그리고 살아있었음을.」
    - 강물 클로즈업 → 메인 테마 풀 오케스트라
    - 자막: 「668년. 고구려는 멸망했다. 하지만 강은 흘렀다.」
    - 에필로그: 현대 강물 (압록강·금강·낙동강·동해)
    - 시즌 2 예고 (10초)
```

## 반복 사용 씬 패턴

```
강 씬 패턴 (매 화 1회 이상):
  용도: 감정 전환·심리 표현·주제 강조
  촬영: 강물 클로즈업 + 캐릭터 뒷모습 or 반영
  OST: 메인 테마 약음

4인 교차 씬 패턴 (아크 전환마다):
  용도: 동시대 4왕국의 상황 병렬 보여주기
  편집: 빠른 컷 (각 5~10초) × 4인
  의미: 「모두 같은 강 앞에 서 있다」

기억 회상 패턴:
  색조: 세피아 or 채도 낮춤
  음악: 피아노 솔로 (메인 테마 단조 변주)
  빈도: 화당 최대 1회 (과다 사용 금지)
```

## 금지 표현 (드라마 집필 RED LINE)

```
역사:
  ❌ 임나일본부설 관련 내용
  ❌ 고구려를 중국 역사로 암시하는 대사
  ❌ 가야를 일본 속국으로 묘사
  ❌ 나당 연합을 미화 (신라의 자의적 선택 강조)

서사:
  ❌ 한 왕국을 절대 악으로 묘사
  ❌ 실존 인물의 역사적 결말 변경
  ❌ 4인 주인공 중 1인 과도한 주인공화 (균형 유지)

표현:
  ❌ 현대 슬랭·영어 직접 대사
  ❌ 과도한 폭력 묘사 (전투 = 암시 중심)
  ❌ 불필요한 선정성
```
