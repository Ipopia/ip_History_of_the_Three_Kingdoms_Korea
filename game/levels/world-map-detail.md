## 월드맵 개요

```
게임 배경 시대: AD 612년 (주 캠페인)
주요 플레이 지구: 5개 (살수 → 요동성 → 대동강 → 한강 → 경주 순서)
진행 방식: 선형 메인 스토리 + 지구별 사이드 퀘스트
총 예상 캠페인 시간: 40~50시간

지도 구성:
  전략 맵 (Strategic Map): 5개 지구 이동 및 선택
  지역 맵 (Regional Map): 지구 내 세부 구역 탐험
  전술 맵 (Tactical Map): 전투 진행 구역 (격자 기반)

지구 잠금 해제 순서:
  ① 살수 지구 → ② 요동성 지구 → ③ 대동강 지구 → ④ 한강 지구 → ⑤ 경주 지구
```

## DISTRICT 01 — 살수(薩水) 지구

### 배경 설명

```
위치: 청천강(薩水) 상류~하류 일대 / 현재 북한 청천강 유역
역사 배경: AD 612년 살수대첩의 무대
지형: 산악 협곡 + 강 + 협소한 평지 (방어 유리, 이동 불리)

분위기:
  짙은 안개가 상시 끼어 있음
  강 수위가 낮을 때와 높을 때가 교차 (계절 사이클 반영)
  버려진 마을들 — 주민 대피 흔적 (우물, 짐 보따리, 꺼진 아궁이)
  멀리 보이는 수나라 진영 횃불

스토리 역할:
  4인이 처음으로 을지문덕과 합류하는 지구
  고루의 댐 프로젝트 진행 구역
  살수대첩 메인 이벤트 발생지 (캠페인 클라이맥스)

배경 테마 음악:
  해금 + 대금 교차 / 북 저음 기저 / 긴장감 점층
```

### 주요 구역

```
구역 1-A: 살수 상류 협곡
  — 댐 건설 작전 구역 (고루 메인 미션)
  — 협곡 지형: 고지대 이점 있음, 아래 강물이 빠름
  — 탐험 포인트: 비어 있는 민가, 댐 예정지

구역 1-B: 살수 남안(南岸) 진영
  — 을지문덕 막사 위치 (NPC 인터랙션 중심)
  — 고구려 병사 훈련 구역 (부가 미션 제공)
  — 아랑의 기록 임무 시작점

구역 1-C: 살수 북안(北岸) 완충지대
  — 수나라 척후대 순찰 구역
  — 정찰 미션 (하린 특화)
  — 위험도: 높음 (발각 시 전투 즉시 발생)

구역 1-D: 살수 하류 도하 지점
  — 살수대첩 메인 전투 구역
  — 댐 방류 이벤트 발생 (고루 조작)
  — 컷씬 전환 다수
```

### 적 유형 (5종)

| 적 유형 | 분류 | 특성 | 대응 전략 |
|---------|------|------|----------|
| 수나라 보병(隋步兵) | 기본 적 | HP 중간, 창·방패 무장, 밀집 대형 | 범위 기술 / 대형 흩기 |
| 수나라 기병(隋騎兵) | 돌격형 | 이동 빠름, 직선 돌격 패턴, HP 높음 | 지형 이용 / 측면 공격 |
| 수나라 궁병(隋弓兵) | 원거리 | 원거리 고데미지, HP 낮음, 후방 배치 | 근접 접근 / 니문 방패 활용 |
| 수나라 척후대장(斥候隊長) | 엘리트 | HP 높음, 부하 강화 오라 보유, 탐지 범위 넓음 | 부하 제거 후 고립 → 집중 |
| 수나라 공성 기술자(攻城技術者) | 특수 | 투석기 조작, 공격력 최고, 직접 전투 약함 | 우선 처치 대상 |

### 주요 스토리 포인트

```
SP-01: 을지문덕과의 첫 대면 (EP05 연동)
  트리거: 살수 남안 진영 입장
  내용: 을지문덕 NPC 인터랙션 — 전략 브리핑 시퀀스
  보상: 「을지문덕의 눈」 패시브 스킬 해금 (전 파티원 지략 +5)

SP-02: 댐 건설 작전 (고루 전용)
  트리거: 살수 상류 협곡 도달
  내용: 목재 수집 + 협곡 방어 + 댐 건설 진행도 관리
  보상: 고루 궁극기 「살수 방류」 해금

SP-03: 아랑의 첫 강물 감지 (EP06 연동)
  트리거: 살수강변 밤 시퀀스
  내용: 아랑 조작 — 강물 터치 미니게임 (판타지 시퀀스)
  보상: 아랑 스킬 「수맥(水脈)」 해금

SP-04: 살수대첩 — 메인 전투 이벤트
  트리거: 을지문덕 신호 컷씬 후
  내용: 3페이즈 전투 + 댐 방류 타이밍 조작
  보상: 지구 01 클리어 / 스킬 포인트 대량 지급

SP-05: 니문의 새벽 연주 (EP06 연동)
  트리거: 전투 전날 밤 캠프 시퀀스
  내용: 컷씬 + 4인 유대도 +20 상승
  보상: 파티 유대 스킬 「네 개의 현」 첫 해금
```

## DISTRICT 02 — 요동성(遼東城) 지구

### 배경 설명

```
위치: 요동반도 남부 / 현재 중국 랴오닝성 일대
역사 배경: 고구려 요동성 (수나라 침공 전선 최전방)
지형: 평원 + 요새 도시 + 산악 방어선

분위기:
  거대한 성벽 도시 — 요동성의 웅장함
  전쟁의 흔적 (탄흔, 흙벽 수리 자국, 부서진 공성 장비 잔해)
  고구려 방어군의 굳건함 vs 수나라의 압도적 규모
  안개가 없는 곳 — 넓고 탁 트인 평원, 심리적 압박감

스토리 역할:
  4인이 을지문덕의 유인 작전을 지원하는 지구
  고루의 고구려 정체성 재확인 구간
  수나라의 압도적 병력을 직접 목격하는 장면 포함

배경 테마 음악:
  북 군악 (행진풍) + 해금 솔로 교차 / 장중하고 웅장하게
```

### 주요 구역

```
구역 2-A: 요동성 성문 외곽 — 평원 전장
  — 대규모 전투 가능 구역 (최대 규모 전술 맵)
  — 수나라 공성 장비 파괴 미션

구역 2-B: 요동성 성벽 위 — 수비 거점
  — 수성(守城) 방어 미션 (아군 유닛 지원)
  — 하린 특화: 성벽 위 이동 기반 전투

구역 2-C: 요동성 내부 — 민간 지구
  — 사이드 퀘스트 집중 구역 (주민 보호, 물자 수송)
  — 아랑 특화: 주민 인터뷰 기록 미션

구역 2-D: 요동 평원 북방 산악
  — 고구려 매복 준비 구역
  — 니문 특화: 음향 정찰 미션
```

### 적 유형 (4종)

| 적 유형 | 분류 | 특성 | 대응 전략 |
|---------|------|------|----------|
| 수나라 공성 부대(攻城部隊) | 공성형 | 공성탑·투석기 조작, 느림, 파괴 시 무력화 | 기동력으로 우선 접근·파괴 |
| 수나라 중갑 보병(重甲步兵) | 탱커 | HP 최고, 이동 느림, 범위 피해 無 | 고루 집중 딜 / 측면 공략 |
| 수나라 화공 전문병(火攻兵) | 화력 | 불화살 공격, 지형 화재 생성 | 물 지형으로 이동 / 아랑 수기술 |
| 수나라 공성 지휘관(攻城指揮官) | 보스급 | 부대 지휘, 강화 명령 패턴 | 지휘관 처치 시 주변 부대 혼란 |

### 주요 스토리 포인트

```
SP-01: 요동성 방어 지원 (고루 메인 미션)
  트리거: 요동성 성문 진입
  내용: 수나라 공성 1차 격퇴 전투
  보상: 고구려 병사 유닛 지원 해금

SP-02: 유인 작전 시작 (을지문덕 NPC 지시)
  트리거: 요동성 성벽 위 씬 도달
  내용: 7전 7패 유인 시퀀스 선택지
  분기: 유인 성공/실패에 따라 다음 미션 난이도 변화

SP-03: 아랑의 요동 기록
  트리거: 요동성 내부 민간 지구 도달
  내용: 피난민 5명 인터뷰 수집 (미니 비주얼 노벨 형식)
  보상: 「요동 증언록」 아이템 — 후반 대화 분기 해금
```

## DISTRICT 03 — 대동강(大同江) 지구

### 배경 설명

```
위치: 대동강 유역 / 현재 평양 일대
역사 배경: 고구려 수도 평양성 및 대동강 방어선
지형: 대형 강 + 농업 평야 + 고구려 최대 요새

분위기:
  고구려 수도의 풍요와 방어 의지
  대동강의 웅장함 (살수보다 큰 강)
  고루의 집 — 아버지의 기억이 있는 강
  전쟁 직전의 비일상적 평화 (농민들이 일하고 있다)

스토리 역할:
  고루 개인 서사의 절정 — 아버지의 강 앞에서
  4인이 처음으로 각자의 나라와 이별을 생각하는 지구
  대동강에서 아랑이 다시 강물을 읽는 장면

배경 테마 음악:
  해금 솔로 (고루 테마 완전 버전) / 대동강 물소리 배경음
```

### 주요 구역

```
구역 3-A: 평양성 외곽 — 대동강 서안
  — 수나라 차기 침공 대비 정찰 미션
  — 고루 아버지 기억 플래시백 트리거 지점

구역 3-B: 평양성 내부
  — NPC 인터랙션 최다 구역 (고구려 장수들, 민간인)
  — 을지문덕 추가 전략 브리핑

구역 3-C: 대동강 하류 — 보급로
  — 수나라 보급선 차단 미션
  — 아랑 강물 감지 고급 버전 활성화

구역 3-D: 대동강 상류 산악
  — 니문 사이드 퀘스트: 가야 유민 집단 만남
  — 하린 사이드 퀘스트: 신라 정보원과 접선
```

### 적 유형 (3종)

| 적 유형 | 분류 | 특성 | 대응 전략 |
|---------|------|------|----------|
| 수나라 선발대(先發隊) | 정찰형 | 빠름, HP 낮음, 발각 시 증원 호출 | 은신·선제 처리 |
| 수나라 강 도하 부대(渡河部隊) | 수상형 | 뗏목 이동, 강 위에서만 전투, 특수 지형 | 아랑 수기술 집중 |
| 수나라 보급 경비대(輜重警備隊) | 방어형 | 보급 수레 수호, 밀집 방진, 이동 없음 | 측면 우회 + 집중 공격 |

### 주요 스토리 포인트

```
SP-01: 고루의 아버지 기억 (대동강 강가)
  트리거: 대동강 서안 특정 지점 도달
  내용: 플래시백 컷씬 + 비전투 탐험 (아버지의 추억 장소 3곳 방문)
  보상: 고루 HP 최대치 +15% 영구 상승

SP-02: 아랑의 대동강 감지
  트리거: 대동강 하류 도달
  내용: 수나라 차기 침공 경로 예측 미니게임
  보상: 다음 전투 적 배치 정보 사전 공개

SP-03: 니문의 가야 유민 만남
  트리거: 대동강 상류 산악 탐험 완료
  내용: 가야 유민 마을 NPC 인터랙션 (컷씬 + 대화 선택)
  보상: 니문 스킬 「가야의 기억」 강화 / 가야금 레전더리 스킨
```

## DISTRICT 04 — 한강(漢江) 지구

### 배경 설명

```
위치: 한강 유역 / 현재 서울·경기 일대
역사 배경: 고구려·백제·신라 세 나라가 쟁탈한 역사의 강
지형: 넓은 강 + 평야 + 여러 소규모 요새 (3국 방어선 혼재)

분위기:
  세 나라의 색이 섞인 독특한 지역
  백제 옛 영토의 흔적 + 고구려 점령 흔적 + 신라의 잠식
  아랑에게는 어머니의 강 — 백제의 기억
  하린에게는 적지이자 연고지 — 신라의 수복 욕망

스토리 역할:
  아랑-하린 감정선 절정 구간
  4인 중 처음으로 가야 이후 나라 간 갈등이 표면화하는 지구
  4인이 '왜 함께 싸우는가'를 재확인하는 장면 포함

배경 테마 음악:
  대금 솔로 (아랑 테마) + 현악 대위 / 복잡하고 감정적으로
```

### 주요 구역

```
구역 4-A: 한강 하류 — 서해 방향
  — 백제 흔적 탐험 (아랑 특화 사이드 퀘스트)
  — 옛 백제 문서·유물 수집

구역 4-B: 한강 중류 — 평야 전장
  — 대규모 다국 충돌 전투 구역
  — 고구려·백제·신라 잔존 병력 혼재

구역 4-C: 한강 이북 — 고구려 점령지
  — 수나라 잔존 병력 소탕 미션
  — 을지문덕 추가 지시 수신

구역 4-D: 한강 상류 — 산악 경계선
  — 신라 영토와의 경계 (하린 긴장 구간)
  — 4인 내부 갈등 대화 이벤트 발생
```

### 적 유형 (4종)

| 적 유형 | 분류 | 특성 | 대응 전략 |
|---------|------|------|----------|
| 수나라 잔존 병(殘存兵) | 약화형 | HP 낮음, 전의 저하 상태, 항복 선택지 있음 | 비전투 해결 가능 |
