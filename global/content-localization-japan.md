## 일본 시장 전략 개요

일본은 삼국(三國) IP의 **1순위 해외 시장**이다. K-드라마 시청률 최상위권, 한국 역사 사극에 대한 기존 수요, 그리고 백제-일본 고대 연결고리라는 독보적 접점이 존재한다.

```
일본 시장 핵심 강점:
1. 한국 사극 기존 팬층 — NHK·WOWOW 한국 드라마 편성 증가
2. 가야금 관련 문화 연계 — 일본 雅楽(가가쿠)와의 역사적 연결
3. 백제 문화의 일본 전파 — 일본 역사 교과서 연관 콘텐츠
4. 역사 만화·게임 강국 — 타깃 수용성 높음
5. 한류(韓流) 2.0 시대 — 한국 문화 전반에 대한 수용도 최고치
```

## 드라마 현지화

### 번역 방향

```
기본 방침:
- 번역체 금지 — 자연스러운 현대 일본어
- 시대극 어투 사용 않음 — 친근하되 품위 있는 표현
- 존댓말 체계: 왕·귀족·평민 계층별 차별화

왕의 대사 문체:
"더 가라. 지평선이 끝날 때까지." (광개토)
→ 「進め。地平線が尽きるまで。」
   (딱딱하지 않되 권위 있는 표현)

여왕의 대사 문체:
"모란꽃 그림에 나비가 없었다. 그게 전부다." (선덕)
→ 「牡丹の絵に蝶がいなかった。それだけのことだ。」
   (담담하고 신비로운 톤)
```

   → 철저히 삼국시대(BC~668년)로 한정

→ 일본 법인 또는 현지 PR 에이전시를 통한 즉각 대응 체계 구축
