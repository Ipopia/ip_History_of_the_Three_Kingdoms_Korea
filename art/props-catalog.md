## Category A — 무기류

### A-01 환두대도 (環頭大刀) — 고루 전용

```
역사 근거: 삼국시대 전 왕국 사용, 고구려 무장 계층 대표 무기
외형:
  전체 길이: 약 90~95cm
  날: 단날 (외날) 직선형
  손잡이: 고리형 환두 (원형 또는 용·봉황 문양)
  칼집: 흑칠 + 금속 장식

고루 전용 디자인:
  환두: 삼족오 문양 양각 (고구려 정체성)
  칼날: 살수 강물 결무늬 (에칭)
  손잡이 감기: 흑색 가죽 + 금속 리벳

드라마/게임 사용:
  전투: 고루 주무기 (베기·찌르기 가능)
  상징 장면: 수직으로 세우고 응시 (「강은 기억한다」씬)
  보관: 왼쪽 허리 패용

참조: 국립중앙박물관 소장 삼국시대 환두대도
```

### A-02 각궁 (角弓) — 하린 전용

```
역사 근거: 신라·고구려 복합궁 (각재·뿔·힘줄·나무 복합)
외형:
  길이: 약 120cm (반궁 형태)
  소재: 물소뿔 + 뽕나무 + 힘줄 복합
  색상: 흑칠 + 금색 장식 (신라 왕실용)
  시위: 동물 힘줄 꼬임

하린 전용 디자인:
  궁 몸체: 금관 문양 각인 (화랑 신라 정체성)
  화살통: 신라 금빛 문양
  화살촉: 청동 삼각형

드라마/게임 사용:
  기마 사격: 달리는 말 위에서 사용 (하린 특기)
  훈련 씬: 100발 연속 사격
  상징 장면: 활 당기며 원거리 응시
```

### A-03 단검 — 아랑 호신용

```
역사 근거: 백제 귀족 여성 단검 사례 (고분 출토)
외형:
  전체 길이: 약 35cm
  날: 양날 직선형
  손잡이: 백제 봉황 문양 상아 손잡이
  칼집: 담청색 비단 + 금속 테두리

아랑 활용:
  주 용도: 자기 방어 (전투 참여 아님)
  상징: 「기록을 지키는 무기」
  드라마: 낙화암 장면 이전 복선 소품
```

### A-04 가야 소도검 (小刀劍) — 니문 소지

```
역사 근거: 가야 고분 출토 소형 철제 단검
외형:
  전체 길이: 약 45cm
  특징: 가야 특유의 직선 날 + 간결한 손잡이
  소재: 가야 철정 기술 (고품질 철)

니문 활용:
  주 용도: 가야금 줄 자르기·수리 도구
  상징: 「잊혀진 나라의 마지막 금속」
  장면: 가야금 줄 끊어질 때 새 줄 매는 씬
```

## Category B — 문구·기록 도구

### B-01 죽간 (竹簡) + 붓 세트 — 아랑 전용

```
죽간:
  재료: 오죽(烏竹) 또는 솜대
  크기: 폭 1.5cm × 길이 23cm (표준)
  표면: 불에 구워 기름기 제거
  결속: 검은 명주 실 엮기

아랑 전용 죽간 특징:
  첫 죽간: 어머니에게 물려받음 (헌 것, 낡음)
  나중 죽간: 백제 사비성 왕실 문서 공식 규격
  비밀 죽간: 일반 죽간 안쪽에 숨긴 내용 (암호)

붓:
  자루: 대나무 + 흑색 묵 침전
  털: 토끼털 (세필) — 아랑 전용
  보관통: 백제 금동 문양 붓통

드라마 소품 활용:
  아랑 필사 씬: 근접 촬영 필수 소품
  죽간 분실: 극적 갈등 소품
  마지막 죽간: 시청자 기억에 남는 상징
```

### B-02 을지문덕 한시 목간 (木簡)

```
내용: 을지문덕 오언시 원문 새김
재료: 경질 목재 (박달나무류)
크기: 폭 3cm × 길이 30cm
글씨체: 예서(隷書) 스타일 (7세기 적합)

드라마 활용:
  고루가 받아 소중히 간직
  「신책구천문(神策究天文)…」텍스트 클로즈업
  마지막 씬: 고루가 강물에 놓아보내는 장면 가능
```

## Category C — 음악 도구

### C-01 가야금 (伽倻琴) — 니문 전용

```
역사 근거: 대가야 가실왕 창제 (551년경), 우륵 완성
규격:
  전체 길이: 약 152cm (12현 표준)
  폭: 20~25cm
  두께: 10cm
  현(絃): 12현 (명주실)

니문 전용 디자인:
  공명판: 오동나무 (고품질)
  안족(雁足): 상아 또는 뿔 재질
  표면: 가야 철정 문양 칠화(漆畵) 장식
  특징: 마지막 현이 끊어진 상태 (극 초반)

색상 표현:
  오동나무 자연색 (#8B6914)
  칠화 장식: 황토 + 진사(辰砂)

드라마 음향 연동:
  실제 가야금 연주 음원 사용 (sound-design 연동)
  「기억의 강」멜로디 전용

역사 원물 참조:
  국립중앙박물관 소장 가야금
  국가무형문화재 25호 가야금산조
```

## Category D — 종교·의례 도구

### D-01 금동대향로 (金銅大香爐) — 백제 상징

```
역사 근거: 1993년 부여 능산리 출토 (국보 287호)
IP 내 역할: 백제 왕실 의례 + 아랑 관련 장면

원물 정보:
  높이: 61.8cm
  무게: 11.8kg
  시대: 백제 후기 (6~7세기)
  내용: 하단 용·상단 연화·봉황·신선 23인

드라마 소품 복제:
  실물 크기 1:1 레플리카 제작
  CG 합성 버전 별도 (근접 촬영용)
  아랑 필사실 배경 소품

참조: 국립부여박물관 소장 원물 도록
```

## Category E — 생활·장신구

### E-01 아랑 자수 조각 (刺繡)

```
외형:
  크기: 10cm × 10cm (손바닥 크기)
  문양: 봉황 날개 + 백제 당초문
  색상: 담청색 바탕 + 금사·홍사 자수

아랑 캐릭터 상징:
  어머니에게 받은 미완성 자수
  전 시즌 통해 아랑이 조금씩 완성
  676년 에필로그: 완성된 자수 = 기억의 완성

드라마 클로즈업:
  손바늘 씬: 매크로 촬영 필수
  자수 문양 확대: 역사 문양 고증 (ADV-ARTS 확인)
```

### E-02 신라 금관 미니어처

```
역사 근거: 신라 금관 (국보 87·191·193호 등)
IP 역할: 신라 왕실·선덕여왕 장면 배경 소품

드라마 소품:
  실물 크기 레플리카 2개 (촬영용)
  선덕여왕 착용 버전 (사이즈 조정)
  전시 소품 (exhibition-vr.md 연동)
```

### E-03 고루 철제 목걸이

```
외형:
  소재: 고구려 철정 단조
  문양: 삼족오 소형 펜던트
  끈: 흑색 가죽

상징:
  어린 고루가 을지문덕에게 받은 선물 (창작)
  전 시즌 착용 → 정체성 상징
  마지막 씬: 살수강에 놓아보내는 가능성
```

## 소품 제작 기준

```
고증 우선순위:
  1순위: 실제 출토 유물 참조 (국립박물관 도록)
  2순위: 삼국사기·삼국유사 기록
  3순위: 인접 시대 유물 참고
  4순위: 전문자문 ADV-ARTS 승인 창작

제작 방식:
  드라마: 실물 소품 제작 (주요) + CG 보조
  웹툰: 아트워크 벡터 일러스트
  게임: 3D 모델링 (props-3d.md 연동)
  머천다이즈: 실물 레플리카 (replica-weapons.md 연동)

금지:
  중국·일본 소품과 혼동 가능한 디자인
  고증 근거 없는 현대적 변형 (ADV-ARTS 미승인)
  역사 인물 소품 임의 변경
```
