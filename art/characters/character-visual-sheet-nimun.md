## 1. 기본 외형 사양

### 신체 정보

```
이름     : 니문 (尼文, Nimun)
나이     : 21세 (시즌 1 기준, 612년)
성별     : 남성
신장     : 176cm
체중     : 약 68kg (유민 생활 체형 — 날렵하나 단단함)
체형     : 가늘고 균형 잡힌 장신 — 연주자 체형
           넓지 않은 어깨 / 긴 팔 / 절제된 근육
           기마·전투보다 장거리 이동·생존에 최적화된 체형
체지방   : 낮음 (유민 생활로 인한 절식 흔적)
손       : 니문의 가장 중요한 신체 부위
           길고 섬세한 손가락 — 12현 가야금 연주로 발달
           손가락 끝 굳은살 (왼손 모든 손가락 안쪽 / 현 누르기)
           오른손 손가락 끝 굳은살 (튕기는 방향 — 가야 가락 방식)
           손 전체적으로 아름답고 정밀한 형태
```

### 얼굴 특징

```
전체 인상  : 과묵하고 깊은 가야 유민 — 많은 것을 겪은 조용한 눈빛
얼굴형     : 긴 타원형 — 부드럽되 선명한 윤곽 / 작은 얼굴
피부       : 유민 생활의 흔적이 있는 다소 그을린 황갈색 (#A0784A)
             건강하나 화려하지 않은 색조 — 검소한 자연색
눈         : 쌍꺼풀 없는 깊은 눈 / 홍채색 짙은 흑갈색
             감정을 거의 드러내지 않으나 보는 이가 깊음을 느끼는 눈빛
             가야금을 연주할 때만 눈빛이 완전히 달라짐
눈썹       : 자연스럽고 진한 직선형 — 감정 변화가 거의 없음
코         : 높고 단정한 코 — 날카롭지 않은 균형 잡힌 형태
입         : 가늘고 단정한 입 / 항상 굳게 다문 상태가 기본
             말수가 적음을 입이 말해줌
턱         : 부드럽게 각진 윤곽 — 의지가 담긴 선

식별 특징:
  - 왼쪽 손목 안쪽 가야금 현에 의한 선형 흉터 (0.5cm × 3개, 어린 시절 연습 중)
  - 가야금 연주 중에만 입이 약간 열림 (음악이 감정을 열어주는 증표)
  - 걸을 때 소리가 거의 나지 않음 — 유민 생활로 체득한 정숙 이동
  - 눈이 항상 중간 거리 어딘가를 향함 — 어디를 보는지 알 수 없는 시선
```

### 머리카락

```
색       : 짙은 흑색 (#0A0A0A) — 빛 반사 없는 무광 검정
질감     : 가늘고 부드러움 — 자연스럽게 흘러내림

스타일 기준:

  재질   : 삼끈 (麻繩) / 폭 0.3cm
  색     : 토갈색 (#7A5230) — 장식 일체 없음
  의미   : 가야 멸망 후 남은 모든 것의 소박함
  위치   : 뒷목 낮은 위치 묶음 (귀 아래 선)
```

## 3. 복식 상세 사양

### A. 유민 일상복 (기본)

```
상의    : 홍토 (#A0341C) 유(襦) — 소매 보통 넓이 / 낡은 듯 자연스러운 마감
          겉섶 오른쪽 여밈 (우임) / 수선 흔적 있음 (유민 생활)
          소매 끝 장식 없음 — 테두리만 황토로 바이어스 처리
하의    : 토갈 (#7A5230) 고(袴) — 이동 편의형 폭 / 무릎 아래 끈 묶음
허리    : 황토 삼끈 혁대 — 버클 대신 묶음 방식
          소품홀더 1개 (작은 칼 / 오른쪽)
겉옷    : 흑갈 (#3D1F0D) 짧은 포(袍) — 소매 좁음 / 방한용 기능 중심
          안감 없음 (유민 경량)
신발    : 토갈 가죽 짚신 형태 — 소박하고 단단한 형태
          발목 끈 묶음 (이동 최적화)
장신구  : 없음 (기본 상태) — 가야금만이 소품
소품    : 가야금 (등 대각선 / 가죽 끈 고정) — 이동 시 상시 동반
```

### B. 전투 복식 (소형 무장)

```
갑옷 본체:
  종류    : 없음 — 니문은 갑옷 착용 기피 (가야유민 자유인)
  대체    : 홍토 유(襦) 위 토갈 가죽 조끼 (어깨~흉부 보호 기능)
            가죽 두께: 중급 / 색처리: 토갈 (#7A5230) 무광
  어깨    : 가죽 어깨 보호패드 (단순, 장식 없음)
  팔      : 왼쪽 팔뚝 가죽 보호대 (가야금 연주 팔 보호 / 전투도 겸용)

무기 착용 위치:
  주무기  : 없음 — 니문은 공격 전투를 피함
  보조    : 작은 칼 (短刀) — 오른쪽 허리 (생존·호신 용도)
            길이: 전장 35cm / 장식 없는 실용 단도
  특기    : 가야금 현(絃) — 위기 시 현을 무기로 활용 (은밀 기술)

전투 시 특이사항:
  가야금은 전투 시 분리 보관 (안전 장소 또는 동료에게 위탁)
  전투보다 탈출·위장·정보 수집 역할 선호
```

상의    : 홍토 기본 유 — 소매 느슨하게 내려 연주 자유도 확보

## 4. 특징적 소품 상세

### 전용 소품 — 「가야금 (伽倻琴)」

```
공식명칭 : 가야금 (伽倻琴, Gayageum)
전수자   : 니문의 아버지 → 니문 (가야 멸망 전 직접 전수)
현       : 12현 — 명주실 / 가야 전통 조현법 유지
길이     : 150cm (공명통 포함)
공명통   : 오동나무 — 짙은 흑갈색 (#3D1F0D) 옻칠 마감
            표면: 가야 전통 문양 얕은 음각 (가야금 문양)
현 색    : 가야홍 (#C0392B) 명주실 — 일반 명주보다 붉은 가야 특유 색조
받침     : 흰 기러기발 (안족, 雁足) 12개 — 동(銅) 재질
줄감개   : 오동나무 / 동 장식 소형 핀
무게     : 약 2.8kg
보관     : 가죽 끈 대각선 등 착용 (이동) / 연주 시 무릎 위

시각적 포인트:
  - 공명통: 옻칠이 오래되어 깊은 광택 (수십 년 된 악기)
  - 현: 가야홍 명주가 빛을 받으면 붉은 빛 발산 (가야 유산의 생존 상징)
  - 니문이 현을 튕길 때 손가락 끝의 굳은살 클로즈업 = 핵심 연출
  - 가야금 소리 = 니문의 유일한 감정 해방 — 이것이 울 때 니문이 운다
  - 가야 멸망 후 살아남은 마지막 가야금 (극 중 설정)
```

### 보조 소품

```
작은 칼 (短刀):
  길이   : 전장 35cm (날 22cm)
  재질   : 날 철제 (무장식) / 손잡이 나무 + 가죽 그립
  칼집   : 토갈 가죽 — 장식 없음 / 마모된 흔적 다수
  의미   : 가야 멸망 탈출 시 지닌 유일한 호신 도구
  상태   : 날 실용 유지 / 전체적으로 낡고 수선 흔적

유민 끈 세트:
  재질   : 삼끈 (麻繩) 다양한 굵기
  용도   : 가야금 고정 끈 / 허리 끈 / 발목 끈 / 가죽 끈
  색     : 토갈 (#7A5230) 계열 통일
  의미   : 니문이 직접 꼬고 수선하는 물건들 (손재주의 표현)

가야금 천:
  재질   : 홍토색 (#A0341C) 거친 면 천
  용도   : 가야금 이동 시 보호 덮개
  상태   : 수선 흔적 다수 / 가야 전통 작은 문양 손바느질 자수
  의미   : 가야금을 보호하는 것 = 가야를 보호하는 것
```

## 5. 표정·감정 스펙 (5종)

### 기본 표정 규칙

```
니문의 얼굴은 항상 잠겨 있다.
감정을 드러내지 않는 것이 유민 생활로 체득한 생존 방식.
단 하나의 예외: 가야금을 연주할 때.
연주 중 니문의 표정은 다른 모든 규칙을 이탈한다.
```

### 표정 1 — 침묵 (Stillness) ★기본값

```
눈      : 반쯤 열린 눈 — 어딘가 중간 거리를 바라봄
          홍채 짙은 흑갈색 / 감정 읽기 불가능한 깊이
눈썹    : 완전히 수평 — 어떤 변화도 없는 기본값
입      : 굳게 다문 직선 — 말하지 않겠다는 의사 표시
턱      : 약간 아래 — 고개 약간 숙인 자세 (존재감 줄이기)
자세    : 어깨 살짝 안으로 모임 (유민의 조용한 자기 축소)
전체    : 「이 사람의 생각을 알 수 없다」는 불가독성

아트 디렉션:
  눈빛에 「멀리 있는 무언가를 보는 거리감」유지
  모든 근육이 최소 활성 — 완전히 이완되어 있되 경계
```

### 표정 2 — 연주 (Performance) ★핵심 표정 / 니문만의 표정

```
주의    : 이 표정은 니문의 다른 4개 표정과 완전히 다른 차원.
          가야금 앞에서만 나타나는 유일한 개방.

눈      : 반쯤 감김 — 내면으로 향하는 눈
          또는 완전히 감음 (몰입 최고조 시)
눈썹    : 평소 수평에서 중앙 위로 약간 모임 — 감정이 올라옴
입      : 자연스럽게 약간 열림 — 음악이 열어주는 유일한 순간
호흡    : 연주에 맞춰 흉곽 움직임 가시화
손      : 12현 위에서 움직이는 손가락 — 전신에서 가장 표현적인 부위
전체    : 평소의 니문과 완전히 다른 사람 — 감금된 자가 자유로워지는 순간

아트 디렉션:
  연주 씬에서 손 클로즈업 필수
  얼굴의 미세한 감정 변화가 가장 많이 허용되는 유일한 씬
  이 표정을 보는 장면에서 다른 캐릭터가 니문을 다시 보게 됨
```

### 표정 3 — 결의 (Quiet Resolve) ★내면의 결의

```
주의    : 니문의 결의는 소리가 없다. 표정보다 자세로 말한다.

눈      : 평소보다 약간 더 좁아진 눈 — 미세한 변화
눈썹    : 수평 유지 / 안쪽으로 1mm 모임 (감지 어려운 긴장)
입      : 굳게 다문 / 입꼬리 아주 미세하게 아래 (-0.5mm)
자세    : 등 완전히 펴짐 — 평소 약간 숙인 것에서 완전 직립
손      : 작은 칼 손잡이에 손이 닿음 (뽑지 않음)
전체    : 보는 이만 느끼는 결의 — 폭발 없이 가장 단단해지는 순간

대표 장면: 가야 유민 보호 결심 / S3 최후의 선택 / 동료를 지키는 순간
```

### 표정 4 — 슬픔 (Buried Grief) ★가야의 슬픔

```
주의    : 니문은 울지 않는다 — 눈물을 이미 다 써버렸다.
          대신 가야금이 운다.

눈      : 평소보다 약간 더 열림 — 방어가 잠깐 무너지는 순간
눈빛    : 초점 완전 소실 — 아무것도 보지 않는 공백
눈썹    : 중앙이 아주 미세하게 위로 — 감지하기 어려운 변화
입      : 굳게 다문 / 양 입꼬리 내려감 (표정 변화 최소화 노력)
목      : 약간 뒤로 젖힘 — 눈물을 삼키는 동작 (눈물 없음)
손      : 가야금 현을 가볍게 손으로 덮음 (연주 아닌 위로)
전체    : 표정보다 자세와 손이 슬픔을 말함

대표 장면: 가야 멸망 회상 / 아버지 기일 / 동료가 쓰러지는 장면
아트 디렉션:
  눈물 S3 이전 절대 금지
  가야금을 감싸는 손 클로즈업으로 슬픔 대체 연출
  S3 단 한 번 — 가야금 현이 끊어지는 장면에서 눈물 허용
```

### 표정 5 — 희미한 온기 (Faint Warmth) ★극히 드물게 등장

```
빈도    : 전체 에피소드에서 8회 미만 (최희소 = 최대 임팩트)

눈      : 눈꼬리가 0.5mm 내려감 — 관객만 감지하는 변화
눈빛    : 평소의 공백에서 「지금 이 사람을 보고 있음」으로 전환
입      : 굳게 다문 직선이되 양 끝이 0.3mm 올라감 (웃음이라 할 수 없는 온기)
자세    : 어깨가 아주 미세하게 이완
전체    : 마치 「오래 닫혀 있던 문이 1cm 열리는 순간」

대표 장면: 가야금이 완벽히 울릴 때 / S3 하린에게 가야를 이야기할 때 / 동료 신뢰 구축 씬
아트 디렉션:
  이 표정이 나오는 씬은 반드시 연출상 강조
  보는 이가 「니문이 웃었다」고 느끼게 하되 실제 웃음은 아닌 연출
```

## 6. 캐릭터 포즈 스펙 (기본 3종)

### 포즈 1 — 정면 기본 (Standard Front)

```
용도    : 캐릭터 카드 / 피규어 정면 기준 / 프로필

자세    :
  발    : 어깨 너비보다 좁게 (15°-15°) — 존재감 줄이는 자세
  무릎  : 곧게 — 긴장 없음
  허리  : 곧되 어깨 약간 안으로 — 완전히 펴지지 않은 자연 자세
  어깨  : 수평이되 약간 안으로 모임 (유민의 조용한 자기 축소)
  팔    : 양팔 — 자연스럽게 내려 옆구리 근처
          오른팔 — 작은 칼 칼집 위로 손이 가볍게 닿음 (습관적)
          왼팔 — 완전히 자연스럽게 내려옴
  시선  : 정면 응시 — 보는 이를 보되 감정을 드러내지 않는 눈빛
  턱    : 약간 아래 (위압적이지 않게)
  표정  : 침묵 (표정 1번)

배경 기준 색: 홍토 (#A0341C) 그라디언트 → 토갈 (#7A5230)
```

### 포즈 2 — 연주 정면 (Performance Front)

```
용도    : 니문 핵심 이미지 / 가야금 씬 / 프로필 B

자세    :
  위치  : 바닥 정좌 — 발을 겹쳐 무릎 안정 / 허리 완전히 곧게
  가야금: 무릎 위~앞에 수평으로 걸침 (공명통이 오른쪽)
  팔    : 양팔 — 가야금 현 위에 / 연주 시작 직전 자세
          오른손 — 현 위 3cm 위치 / 손가락 살짝 굽힘
          왼손 — 현 위 왼쪽 안족 근처 / 현 누를 준비
  고개  : 약간 숙여 가야금 집중
  시선  : 가야금 현 (또는 반쯤 감은 눈 — 내면)
  표정  : 연주 (표정 2번) — 이 포즈에서만 허용

실루엣 체크포인트:
  가야금의 긴 수평 라인이 포즈 핵심 구조
  손 클로즈업 연출 가능 구도
  정좌 자세의 허리 직립 — 평소와 다른 당당함
```

### 포즈 3 — 이동 동작 (Wanderer Dynamic)

```
용도    : 드라마 포스터 / 게임 스플래시 / 니문 핵심 키아트

자세    :
  기본  : 반 측면 (3/4 왼쪽 앞 방향 — 카메라 향하되 비틀림)
  발    : 오른발 앞 — 걷다가 멈춘 자세 (유민의 이동)
  허리  : 약간 카메라 방향으로 비틀림 (멈춰 돌아보는 순간)
  어깨  : 왼어깨 앞 / 오른어깨 뒤
  팔    : 오른팔 — 가야금 등 착용 끈 잡음 (이동 중 안정)
          왼팔 — 자연스럽게 내려 / 손끝 여유
  시선  : 카메라 약간 비껴 바라봄 — 어딘가를 향하는 시선
  표정  : 침묵 (표정 1번) — 이동 중 기본 표정

전투 모드 비주얼 추가:
  가야금  : 등에 대각선 착용 (핵심 실루엣)
  복식    : 이동 후 약간 먼지 묻은 상태 허용
  배경    : 가야 유민 이동 경로 — 산길 또는 강변
  효과    : 가야금 현이 바람에 약간 진동하는 이펙트 (가야의 존재감)

카메라 앵글 제안:
  메인키아트: 눈높이 앵글 — 평등하되 깊은 눈빛 강조
  웹툰 컷   : 측면 또는 3/4 앵글 (가야금 실루엣 강조)
  게임 스플래시: 3/4 앵글 (왼쪽 앞 45°) — 가야금과 작은 칼 동시 노출
```
