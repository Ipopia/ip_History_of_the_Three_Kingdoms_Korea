# 배경 아트 가이드

## 배경 아트 원칙

> "배경은 침묵하는 화자다. 대사 없이 시대를 말하고, 조명 없이 감정을 만든다."

배경 아트는 역사 고증과 시네마틱 효과의 균형점을 찾는다. 완벽한 역사 재현이 목적이 아니라, 관객이 그 시대에 실제로 있다는 감각을 주는 것이 목적이다.

## 건축 배경 상세 가이드

### 고구려 건축 배경

**특징**
- 고구려 목조 건축: 높은 기단 + 맞배지붕
- 주춧돌: 거칠게 다듬은 화강암
- 기둥: 붉은 칠 또는 무도장 목재
- 지붕: 기와 — 끝에 막새(수막새) 장식

**안학궁 정전 배경**
```
구성:
├── 전면: 넓은 돌계단 (인물을 작게 만드는 스케일)
├── 기둥: 12개 이상 — 웅장한 열주(列柱)
├── 지붕: 겹처마 — 하늘을 가르는 선
├── 내부: 어두운 내부 + 창문 빛 줄기
└── 주변: 성벽+산 — 압도적 배경 레이어
```

**색채 팔레트**
- 기단: 화강암 회색 `#8A8278`
- 기둥: 주홍 `#8B3020` (도장) 또는 목재 `#6B4A2C`
- 기와: 청회 `#5A6A7A`
- 하늘: 철흑 구름 또는 탁트인 청

---

### 백제 건축 배경

**특징**
- 백제 목조: 가장 정교한 목공 기술
- 지붕선: 완만한 곡선 — 우아함
- 기둥: 엔타시스(배흘림) — 중간이 약간 볼록
- 단청: 섬세한 문양 — 백제 고유 패턴

**사비 왕궁 정전 배경**
```
구성:
├── 전면: 정원+연못 — 여백 활용
├── 기둥: 백제 엔타시스 기둥
├── 지붕: 부드러운 곡선 처마
├── 내부: 칠기·비단 소품으로 채움
└── 창문: 백마강 뷰 — 풍경화 프레임
```

**색채 팔레트**
- 기단: 백토 `#E8E0D0`
- 기둥: 주홍 계열 `#CC4430`
- 단청: 비취록+청회 `#3D7A5B` `#8DB4C8`
- 기와: 회청 `#6A7A8A`

---

### 신라 건축 배경

**특징**
- 황룡사 9층 목탑: 높이 약 80m — 최고 도전 배경
- 석조 발달: 불국사·석굴암 형식
- 첨성대: 원통형 돌쌓기 — 독특한 형태

**황룡사 배경**
```
구성:
├── 원경: 경주 평원 위 솟은 탑 실루엣
├── 중경: 탑 주변 사원 건물군
├── 근경: 참배하는 민중 행렬
└── 탑 클로즈업: 9층 각 층 처마 상세
```

**첨성대 배경 (야간)**
```
구성:
├── 전경: 선덕여왕 인물
├── 근경: 첨성대 — 달빛에 빛나는 돌
├── 중경: 어두운 경주 도시
└── 원경+하늘: 별이 가득한 밤하늘
```

## 자연 배경 상세 가이드

### 강(江) 배경

| 강 | 특징 | 대표 장면 |
|----|------|---------|
| 대동강 | 넓고 유유한 — 평양의 생명선 | 고구려 왕의 사색 |
| 백마강 | 절벽+맑은 물 — 백제의 서정 | 낙화암 |
| 한강 | 넓고 전략적 — 패권의 상징 | 삼국의 쟁탈 |
| 청천강(살수) | 빠른 유속+갈대밭 | 살수대첩 |
| 낙동강 | 가야 생명선 | 가야 제철 |

**강 배경 구성 원칙**
- 반사: 하늘색을 강이 반사 — 2배 하늘 효과
- 흐름: 계절별 유속 차이 — 봄(빠름)/여름(황탁)/가을(맑음)/겨울(얼음)
- 안개: 새벽 강 — 수면 안개 필수 요소

---

### 산(山) 배경

**한반도 산악 특성**
- 화강암 봉우리 — 날카롭고 수직적
- 소나무 울창 — 상록 + 겨울에도 녹색
- 구름과 안개 — 산수화적 운무 활용

**고구려 산악 배경**
- 백두산 연결 — 건국 신화의 산
- 요동 평원+산맥 — 정복의 무대
- 산성 — 산 자체가 요새

**백제 산악 배경**
- 부소산 — 부드러운 구릉
- 계룡산 — 신화적 산
- 차령산맥 — 경계 역할

**신라 산악 배경**
- 토함산 — 석굴암 배경
- 남산 — 불상 가득한 신성한 산
- 태백산맥 — 신라 동쪽 장벽

## 시대별 배경 변화 가이드

### 시즌1 (건국기 — BC 1세기~1세기)

**도시**
- 소규모 — 목책과 토성
- 부족 집회소 수준의 건물
- 흙길, 허름한 주거

**자연**
- 개간되지 않은 원시림
- 야생 동물 흔적 (사냥감)
- 풍성한 자연 — 인간의 흔적 최소

---

### 시즌3 (전성기 — 4~5세기)

**도시**
- 대규모 궁궐·사원 완성
- 정비된 도로·배수 체계
- 시장 번성 — 외국 상인 존재

**건축**
- 최고 수준의 목조 건축
- 단청·장식 절정
- 귀족 저택 밀집

---

### 시즌6 (멸망기 — 7세기 중반)

**도시**
- 전쟁 피해 흔적
- 피난민으로 붐비는 거리
- 불탄 건물·허물어진 성벽

**분위기**
- 황폐함 속 잔존하는 아름다움
- 낙엽+재 — 혼재
- 연기와 먼지 — 항상 배경에 존재

## 배경 아트 제작 기술 가이드

### 원근법 적용

```
전경 (0~5m)   → 선명, 풍부한 텍스처, 강한 명암 대비
근경 (5~50m)  → 약간 선명, 중간 대비
중경 (50~500m) → 대기 원근 시작, 청회색 혼입
원경 (500m+)  → 강한 탈포화, 실루엣 수준
하늘 배경      → 대기층 색상, 구름 크기로 원근 표현
```

### 텍스처 레이어

| 재질 | 텍스처 방향 | 강조 포인트 |
|------|-----------|-----------|
| 화강암 | 수직 절리 | 거친 표면 + 이끼 |
| 목재 | 결 방향 | 나이테 + 마모 |
| 기와 | 반원 반복 | 경계 그림자 |
| 흙길 | 발자국 + 수레 자국 | 사람 흔적 |
| 강물 | 흐름 방향 | 반사 + 잔물결 |

### 조명 통합 원칙

배경 아트의 조명은 항상 해당 장면의 주 광원과 일치:
- 광원 위치 → 그림자 방향 → 배경과 인물 그림자 일치 필수
- 황혼 장면: 배경의 모든 수직면에 오렌지 리밍 라이트
- 실내 장면: 창문 방향 = 주 광원 방향
