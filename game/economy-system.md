```
핵심 원칙:
  역사 충실도: 삼국시대 실제 교역·세금·자원 체계 반영
  전략 깊이: 경제 관리가 군사 전략과 직결
```

## 기본 자원 체계

### 4대 기본 자원

```
食 (식량 — FOOD):
  생산: 농지 건설 + 인구 비례
  소비: 병사 유지 + 건설 작업
  계절: 봄 파종 → 가을 수확 (계절 사이클 반영)
  부패: 창고 용량 초과 시 자동 소실 (실시간 아님, 턴제)

鐵 (철 — IRON):
  생산: 제철소 건설 (가야 +50% 보너스)
  소비: 무기·갑옷·건설 재료
  희귀성: 중반 이후 병목 자원
  가야 특권: 철정(鐵鋌) 화폐 기능 — 외교 증여 가능

木 (목재 — TIMBER):
  생산: 벌목장 건설 (백제 +30% 보너스)
  소비: 선박·건물·공성 무기
  재생: 삼림 타일 인접 자동 회복 (느린 속도)

布 (포 — CLOTH):
  생산: 직조 공방 건설
  소비: 병사 피복·외교 선물·교역품
  교역: 가장 활발한 교역 자원 (외교 화폐 역할)
```

### 보조 자원

```
名望 (명망 — PRESTIGE):
  획득: 전투 승리 / 역사 이벤트 완수 / 외교 성공
  소비: 특수 유닛 소환 / 동맹 요청 / 반란 진압
  왕국별 초기값: 고구려 높음 / 가야 낮음

技術 (기술 — TECH POINT):
  획득: 연구 건물 + 자문관 배치
  소비: 기술 트리 언록
  특이: 기술점수 이월 불가 (분기별 초기화)

交易銀 (교역은 — TRADE SILVER):
  획득: 교역로 개설 + 항구 건설
  소비: 시장 거래 / 외국 용병 고용 / 희귀 자원 구매
  백제 특권: 해상 교역로 추가 개설 가능
```

## 왕국별 경제 특성

```
고구려:
  강점: 군수 물자 생산 효율 (철+목재 소비 -20%)
  약점: 농업 생산 불리 (북방 기후 — 식량 생산 -15%)
  특수 능력: 청야전술 — 후퇴 시 자원 소각 대신 회수 50%

백제:
  강점: 교역 수입 최대 (교역은 획득 +40%)
  약점: 군사 자원 효율 낮음 (철 소비 +10%)
  특수 능력: 해상 교역로 독점 개설 (타 왕국 블록 가능)

신라:
  강점: 농업 최강 (식량 생산 +25% — 경주 평야)
  약점: 초반 기술 발전 느림
  특수 능력: 화랑 제도 — 명망 소비 없이 특수 유닛 소환 가능

가야:
  강점: 철 생산 최강 (+50%) + 철정 화폐 외교 활용
  약점: 인구 성장 느림 (소국 연합 구조)
  특수 능력: 철정 외교 — 교역은 대신 철로 동맹 체결 가능
```

## 교역 시스템

### 내부 교역 (왕국 내)

```
시장 건설:
  도성 1개 + 지방 도시당 1개
  시장 레벨 1~5 (레벨당 교역 효율 +10%)

교환 비율 기본:
  식량 10 = 철 5 = 목재 7 = 포 8
  (시장 레벨·왕국 특성에 따라 변동)

교역 이벤트:
  풍년: 식량 가격 하락 (잉여 발생)
  기근: 식량 가격 폭등 (비상 구매 필요)
  철 고갈: 가야 철 수입 의존도 상승
```

### 외교 교역 (왕국 간)

```
교역로 개설:
  인접 왕국: 자동 개설 가능
  비인접: 사신 파견 (명망 10 소비)
  해상: 백제 전용 (항구 필요)

교역 조건:
  평화 관계 유지 중: 교역 가능
  전쟁 중: 교역 자동 중단
  동맹: 교역 보너스 +20%

역사 교역 이벤트:
  가야→신라 철 공급: 고정 이벤트 (560년대)
  백제→왜 문화 수출: 명망 +30 (고정 이벤트)
  고구려→수 조공 거부: 전쟁 트리거 이벤트
```

## 세금·조세 시스템

```
조세 3종 (역사 고증):
  租 (조 — 곡물세): 인구당 식량 수취
  調 (조 — 현물세): 지역 특산품 (철·포·목재) 수취
  庸 (용 — 역役): 성인 남성 연 15일 노동력 징발

세율 조정 (플레이어 선택):
  낮음 (10%): 민심 +20 / 자원 수입 적음
  보통 (20%): 민심 중립 / 자원 균형
  높음 (30%): 민심 -15 / 자원 풍부 / 반란 위험↑
  착취 (40%): 민심 -40 / 반란 확률 큰 폭 상승

민심(民心) 시스템:
  민심 80+: 징병 보너스 / 반란 없음
  민심 50~79: 정상 운영
  민심 30~49: 징병 거부 이벤트 발생
  민심 30 이하: 반란 이벤트 트리거
```

## 건설 경제

```
건물 유형 및 비용:
  농지 (레벨 1): 식량 50 + 목재 20 + 노동 10턴
  제철소 (레벨 1): 철 30 + 목재 50 + 노동 15턴
  시장 (레벨 1): 목재 40 + 포 20 + 노동 12턴
  성벽 (레벨 1): 철 60 + 목재 80 + 노동 20턴
  사찰 (불교): 목재 60 + 포 30 + 명망 20 → 민심 +15

건설 제한:
  동시 건설: 도성 3개 / 지방 도시 1개
  파괴: 전투 피해 시 건물 레벨 하락 (완전 파괴 드뭄)
  수리: 원래 비용 50%로 복구

역사 연동 건물:
  첨성대 (신라 전용): 선덕여왕 시대 이후 건설 가능
    효과: 계절 이벤트 1턴 선 예측
  미래사 (백제 전용): 목탑 9층 — 명망 +50
    조건: 사비 도성 레벨 5 이상
```

## 재정 붕괴 메커니즘

```
자원 고갈 단계:
  식량 0: 병사 사기 하락 (-5/턴) → 탈주 발생
  철 0: 신규 유닛 생산 불가 / 성벽 수리 불가
  명망 0: 동맹 해지 이벤트 / 특수 유닛 반란
  교역은 0: 시장 운영 중단 / 용병 계약 해지

역사 이벤트 연동:
  의자왕 향락 이벤트 (백제 655~660년):
    자동 발생 조건: 명망 80+ + 식량 풍부
    효과: 명망 급락 -40 / 민심 -20 / 군비 감소
    → 황산벌 전투 취약성 서사화

  연개소문 사후 권력 분열 (고구려 666~668):
    자동 발생: 연개소문 NPC 사망 이벤트
    효과: 왕국 행동력 -30% (내분 패널티)
    → 평양성 방어 약화 서사화
```
