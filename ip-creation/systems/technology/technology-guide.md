# 기술·무기 가이드 — 삼국(三國) IP

**참조 문서**: `military-organization.md`, `culture-bible.md`, `glossary.md`, `costume-reference.md`
**작성**: IP창작본부 기술팀 (IP-TECH) + 군사자문 (ADV-MILITARY)
**적용**: 전 미디어 기술·무기·건설·산업 묘사 기준

---

## 기술 개요

```
삼국시대 기술 수준 (4~7세기):
- 철기 기술: 완숙 단계 (가야·고구려 최고 수준)
- 건축 기술: 목조+석조 병용 (황룡사 목탑 80m 가능)
- 조선 기술: 백제·가야 해양 교역 선박
- 농업 기술: 우경(牛耕) + 수리 관개 발달
- 의료 기술: 본초의학 + 불교 의학 결합
- 문자·기록: 한자 + 이두 체계

IP 기술 묘사 원칙:
1. 현재 기술 기준이 아닌 7세기 수준으로 표현
2. 왕국별 기술 특화 분야 차별화
3. 과도한 판타지 기술 금지 (화약·화포 등 시대 오류)
```

## 왕국별 기술 특화

### 고구려 — 군사·건설 기술

```
군사 기술:
개마무사 (鎧馬武士) 제조:
  - 찰갑 소찰: 3~5mm 철판 수백 장 연결 기술
  - 마갑 (馬甲): 말 전신 철갑 — 고구려 독자 기술
  - 철촉 (鐵鏃): 3~4엽 삼각형 철제 화살촉
  - 쇠뇌 (弩): 기계식 원거리 발사 장치

성곽 건설 기술:
  - 야산 지형 이용 + 화강암 성벽
  - 안시성: 요동 평야 구릉 위 축성 — 수직 성벽 20m+
  - 천리장성: 631~647년 축조 — 요하~발해만 1,000리
  - 성문 구조: 이중 옹성 (甕城) — 적 진입 시 포위 격멸

수공 기술 (살수대첩 연관):
  - 살수 상류 임시 댐 축조 (전통 통설)
  - 흙+통나무 제방 급조 기술
  - 방류 타이밍 신호 체계 (봉화)

IP 적용:
고루 장면: 성벽 축성 감독 + 쇠뇌 배치 전술
게임: 고구려 건물 「철갑 대장간」— 개마무사 생산 건물
```

### 백제 — 공예·조선 기술

```
금속 공예:
금동대향로 (金銅大香爐):
  - 백제 공예 최고 기술 집약 (554년 이전 제작 추정)
  - 높이 61.8cm, 무게 11.8kg
  - 금동 도금 기법: 수은 아말감 도금
  - 뚜껑: 74개 산봉우리 + 봉황 장식

왕실 장신구:
  - 무령왕릉 유물 기반
  - 금제 관식: 불꽃+연꽃 복합 문양 세공
  - 유리 장신구: 수입+자체 제작 혼합

조선 기술:
  - 백제 서해 교역선: 평저형 목선 (평평한 바닥)
  - 나무못 + 대마 코킹 기술
  - 돛+노 병용 (계절풍 활용)

기록·문서 기술:
  - 두루마리 제작: 닥나무 종이 자체 생산
  - 붓 제작: 족제비·토끼털 붓
  - 먹 제작: 소나무 그을음 + 아교
  - 문서 보존: 기름 먹인 가죽 밀봉 기술

IP 적용:
아랑 장면: 두루마리 제작·보존 기술 묘사
게임: 백제 건물 「문서관」— 정보·외교 효율 +
```

### 신라 — 천문·불교 건축

```
천문 기술:
첨성대 (瞻星臺):
  - 632~647년 건립 (선덕여왕 시기)
  - 높이 9.17m, 원통형 화강암 구조
  - 362개 돌 사용 (1년 365일 상징)
  - 천문 관측: 동지·춘분 등 절기 측정 기능

황룡사 목탑 건축 기술:
  - 645년 완공 (IP 시대 내 완공)
  - 추정 높이 80~100m — 9층 목조 탑
  - 심주(心柱) 기법: 중심 기둥으로 구조 지지
  - 인도 승려 자장(慈藏)의 건립 제안 (삼국유사)

금 세공:
  - 신라 금관: 나뭇가지+나뭇잎 금 세공 기법
  - 금 섬세 가공: 영락(瓔珞) 장식 — 가는 금 실

IP 적용:
하린 장면: 첨성대 내부 천문 관측 묘사
게임: 신라 건물 「황룡사」— 정신력(士氣) 버프 건물
```

### 가야 — 제철 기술

```
가야 철 생산 기술:
제철 공정:
  1. 철광석 채굴 (김해 인근 광산)
  2. 목탄 제조 (소나무 숯)
  3. 고로(鼓爐) 제련: 1200°C+ 고온
  4. 단조(鍛造): 망치로 두드려 형태 성형
  5. 담금질(焠入): 물 또는 기름 냉각

주요 생산품:
판갑 (板甲): 철판 이어 만든 갑옷 — 삼국 최강 방어구
철정 (鐵鋌): 판형 철괴 — 화폐+무역품+무기 원료
철촉: 대량 수출 — 왜(倭)에 다수 공급
낫·호미: 농기구 수출 (한반도 전역)

가야 제철 DNA:
- 「쇠 다루는 민족」자부심
- 대장장이(鍛冶) = 사회적 존중받는 직업
- 철 생산량 = 왕국 국력의 척도

IP 적용:
니문 배경: 제철 소리 들으며 성장한 가야인 정체성
게임: 가야 건물 「제철 공방」— 철 자원 생산 특화
```

## 농업·생산 기술

```
삼국 공통 농업:
우경 (牛耕): 소를 이용한 밭갈이 — 생산성 2~3배
이앙법 (移秧法): 모내기 — 논 생산성 향상 (일부 지역)
수리 시설: 제천 의림지·김제 벽골제 — 저수지 관개

파종 작물:
주곡: 쌀·조·기장·보리·콩·팥
채소: 무·배추 전신·부추·마늘·파
섬유: 삼(麻)·모시 — 옷감 원료 자급

식품 가공:
발효: 장류(醬類) — 된장·간장 원형 (삼국시대 존재 추정)
건조: 건어물·포(脯) — 군량 보존
술: 탁주 — 막걸리 원형 (곡식 발효)
```

## 의료 기술

```
삼국 의학 체계:
본초의학: 약초 기반 치료 — 중국 의학 수입+발전
불교 의학: 사찰 내 시료원(施療院) — 서민 의료
왕실 의관: 전문 의박사(醫博士) 제도 (백제 기록)

주요 약재:
삼(蔘): 인삼 — 고구려 산지
황기·당귀·천궁: 한반도 자생 약초
침술·뜸: 중국에서 전래 + 자체 발전

외상 처치:
붕대: 삼(麻) 포 + 약초 즙
소독: 소금물·식초
부목: 나무 부목 + 천 결박

IP 적용:
전투 부상 묘사: 실제 고대 의료 기술 수준 반영
고루 부상 씬: 약초 습포 + 봉합 없는 압박 처치
```

## 통신·정보 기술

```
봉화 (烽火) 체계:
고구려 봉화망: 요하 → 평양 전선 전달 (약 2~3시간)
봉화 신호:
  1줄기: 평시
  2줄기: 적 출현
  3줄기: 적 접근
  4줄기: 적 침입 (총동원)

전령 (傳令) 체계:
기마 전령: 하루 200km+ 이동 가능
역(驛) 체계: 일정 거리마다 말 교체 가능 거점
긴급 문서: 왁스 밀봉 + 왕인(王印) 날인

첩보 체계:
상인 위장: 교역로 통한 정보 수집
외교 사절: 공식 방문 중 정보 수집 (아랑 역할)
내부 첩자: 사료 기록 있음 (삼국유사·삼국사기)

IP 적용:
아랑 업무: 외교 문서 + 첩보 분석 = 정보전 담당
게임: 「첩보망」건물 — 적 왕국 정보 공개
```
