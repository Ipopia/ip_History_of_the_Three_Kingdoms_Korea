## 군사 조직 개요

```
삼국시대 군사 체계 특징:
- 왕권 중심의 중앙 집권 군대 (7세기 기준)
- 귀족 → 무장 → 병사 위계
- 기병(騎兵) 비중 높음 (고구려 특히)
- 성곽 방어 전략 vs 야전 공세 전략 대립
- 수나라·당나라와의 전쟁이 군사 체계 개편 촉진

IP 시대 기준: 612년(살수대첩)~645년(안시성) 중심
```

## 고구려 군사 조직

### 중앙 군 체계

```
최고 지휘부:
대막리지 (大莫離支): 군사·행정 최고권 (연개소문 642~)
대성 (大城): 5개 부 수장 (귀족 연합 전통)
장수왕·영양왕 이후: 왕권 강화 → 직속 군 편성

중앙군 편제:
구당서 기록 기반 추정:
- 상비군: 3~5만 (수도 평양성 중심)
- 동원 가능 병력: 최대 30만+ (전시 총동원)
- 기병 비율: 30~40% (삼국 최고)

주요 군직:
대로 (對盧): 최고 귀족 관등 겸 군사 지휘
패자 (沛者): 5부 군사 지휘관
고추가 (古雛加): 왕족 계열 군사 지휘
선인 (先人): 중간 지휘 계층 (고루 직급)
```

### 부대 구성

```
5부 체계 (五部制):
내부 (內部/황부): 왕도 직속
동부 (東部/순노부): 동쪽 방어
서부 (西部/소노부): 서쪽 교역로
남부 (南部/관노부): 남방 접경
북부 (北部/절노부): 북방 유목민 대비

부별 군사 특성:
내부: 왕실 근위 + 중장 기병
북부: 경기병 + 원거리 정찰
남부: 수군 보조 + 성곽 수비

병종 구성:
기병 (騎兵): 개마무사(鎧馬武士) — 인마 모두 철갑
         경기병 — 정찰·기동
보병 (步兵): 창·검 보병 — 성벽 방어 주력
궁병 (弓兵): 고구려식 각궁 (사거리 300m+)
공성 (攻城): 포차·운제 — 수나라 전쟁에서 역으로 활용
```

### 전략 교리

```
고구려 전략 3원칙:
1. 청야입보 (淸野入保): 들판 비우고 성으로 집결
   - 수나라 30만 원정 무력화의 핵심
   - 보급선 차단 + 장기 농성 결합

2. 강 방어선 (江防 戰略):
   - 대동강·살수·요하를 자연 방어선으로 활용
   - 적 도하 시 측면 공격 + 수공(水攻) 병행

3. 기마 역습 (騎馬 逆擊):
   - 적 보급·후방 교란 전문 경기병 운용
   - 살수대첩: 퇴각 가장 → 살수 역류 + 기마 추격

IP 전술 묘사:
고루 전술 특기: ① 지형 분석 ② 기만 작전 ③ 소수 정예 야습
을지문덕 전략: 7차례 소규모 패배 → 적 전력 소진 → 살수 결전
```

### 무기·장비

```
개마무사 장비:
- 찰갑 (札甲): 금속 소찰 수백 개 연결 — 철·청동
- 철투구 (鐵胄): 면갑 포함형 (고구려 고분벽화)
- 환두대도 (環頭大刀): 80~90cm 곡검
- 창 (槍): 3m급 철창 — 기마 돌격용
- 방패 (盾): 원형 목방패 (청동 장식)

기마 장비:
- 등자 (鐙子): 철제 등자 — 기마 안정성
- 마갑 (馬甲): 말 전신 철갑 (개마무사)
- 안장: 목제 안장 + 가죽

원거리:
- 각궁 (角弓): 복합궁 — 사거리·관통력 최강
- 철촉 (鐵鏃): 철제 화살촉 (3~4엽 삼각형)
- 쇠뇌 (弩): 중형 기계식 — 성벽 방어 활용
```

## 백제 군사 조직

### 중앙 군 체계

```
왕실 직속군:
좌평 (佐平) 겸 군사 지휘: 5좌평 중 내법좌평이 군사 총괄
달솔 (達率): 2품 — 야전 지휘관 (고루 상대역)
은솔 (恩率): 3품 — 부대장급
한솔·덕솔: 4~5품 — 중대장급

백제군 특성:
- 상비군: 2~3만 (사비성 기준)
- 수군 (水軍) 비중 높음: 왜·중국 교역 호위 + 해전
- 보병 중심: 방어적 포진 전술
- 기병: 소규모 (지형상 평야 전투 제한)
```

### 부대 구성

```
22담로 (二十二擔魯) 체계:
지방 22개 거점 — 왕족·귀족 파견 통치
각 담로 → 지방군 유지 의무
비상시 중앙군 편입

병종:
수군 (水軍): 백제 최강 전력
  - 서해 + 남해 제해권
  - 선박: 판옥선 전신 (고대형)
  - 수병: 노·돛 조종 + 전투 겸임

보병: 창·검·방패 방어 전열
궁병: 활 + 단거리 화살
공성: 포차·사다리차 (방어용)
```

### 전략 교리

```
백제 전략:
외교+군사 복합 전략:
- 왜(倭) 동맹 유지 → 후방 안전
- 신라 견제 → 가야 통로 확보
- 고구려 압박 → 한강 유역 방어

아랑 역할:
외교 문서 작성 → 적국 첩보 수집 → 전략 정보 제공
성충(成忠)·흥수(興首) 장군과 협력

642년 위기 분석 (아랑 예감):
의자왕의 신라 공격 강행
→ 당나라 개입 명분 제공
→ 아랑: 이 전쟁은 이길 수 없다 (문서로 기록)
```

## 신라 군사 조직

### 화랑도 군사 체계

```
화랑도 (花郞道) 군사적 기능:
- 귀족 자제 엘리트 전사 양성
- 화랑 1인 + 낭도 수백~수천 명
- 세속오계 = 군인 윤리 코드

주요 화랑 출신 장군:
김유신 (金庾信): 가야계 → 신라 최고 명장
관창 (官昌): 황산벌 전투 희생 — 신라군 사기 전환
품일 (品日): 645년 이전 활약

하린 설정:
낭두 (郎頭): 하린 — 화랑 아래 1급 지휘관
600명 낭도 통솔
살수대첩 시기 → 612년 하린 26세
```

### 중앙 군 편제

```
서당 (誓幢): 왕실 직속 근위대
  - 초기: 1개 서당 (왕도 방어)
  - 이후: 9서당 확대 (통일 이후)

6정 (六停): 지방 군단
  - 대당·상주정·하주정·신주정·우수정·하슬라정
  - IP 시대: 3~4개 정 운용 추정

관직 체계:
이벌찬·이찬 → 장군 (대장군)
파진찬 → 부장군
아찬 → 낭장 (여단장급)
일길찬 → 적십 (연대장급)

신라 기병:
- 화랑 엘리트 기병 소수
- 경기병 중심 — 기동·정찰
- 경주 분지 → 평야 전투 적합
```

## IP 전투 장면 묘사 가이드

```
전투 묘사 원칙:
1. 역사 기록 우선 (삼국사기·구당서·수서)
2. 병종·무기·전술 고증 (costume-reference.md 연동)
3. 개인 영웅 서사 + 집단 전투 균형

주요 전투 묘사 포인트:

살수대첩 (612년) 클라이맥스:
- 을지문덕 7번 패퇴 → 수군 피로·분산 유도
- 살수 상류 댐 막기 → 수군 강 중앙 위치 시 방류
- 기마 역습: 강물+기마 동시 → 수군 30만 궤멸
- 고루 역할: 살수 우안(右岸) 기병대 지휘

안시성 전투 (645년) 클라이맥스:
- 당나라 60일+ 포위 → 토산 축조 (성벽 제압 시도)
- 양만춘(梁萬春) 수비 전략: 성문 걸어 잠금 + 역습
- 고루 역할: 야습 특수부대 — 토산 점령 → 붕괴 유도
- 결과: 당 태종 철수 (보급 한계 + 겨울 임박)

게임 적용:
전투 단위: 부대(部隊) 단위 이동
영웅 능력치: 고루 - 야습 특기 / 하린 - 기병 돌격 / 아랑 - 외교 전술
```

## [병합] 전술·전략 자문 — tactics-guide.md 고유 콘텐츠

### 삼국시대 전쟁 원칙

```
고대 전쟁 일반론 (적용 기준):

1. 지형이 전쟁을 결정한다:
   산성 = 소수가 다수를 막는 핵심 전술
   강 = 방어선이자 공격 수단 (살수의 역할)
   평원 = 기병 위주 전투

2. 보급이 전투력이다:
   원정군의 치명점 = 보급선
   을지문덕 전략 = 보급 차단 + 심리 소진

3. 심리전이 먼저다:
   싸우기 전 상대 의지를 꺾는 것이 최선
   을지문덕 오언시 = 고대 심리전의 정수

4. 숫자보다 전의(戰意)다:
   계백 5천 vs 김유신 5만 — 4번 승리
   각오가 무기보다 강한 경우
```

### 주요 전투 전술 분석

#### 살수대첩 (612년) — 유인·섬멸 전술

```
배경:
  수나라 별동대 30만 5천 vs 고구려 방어군
  보급선 차단된 수군 + 장기전 소진 전략

을지문덕의 전술 단계:

Phase 1 — 적 진영 침투 (정보 수집):
  목적: 적 전력·사기·보급 상태 직접 확인
  방법: 거짓 항복 사절 — 위험 부담 vs 정보 가치
  결과: 수군 내부 분열·우중문 판단 착오 확인

  전술 원칙: 「知彼知己 百戰不殆」(손자병법)
  → 을지문덕은 이를 문자 그대로 실천

Phase 2 — 七戰七退 (소진 전술):
  하루 7번 교전 → 7번 패주
  목적: 수군을 깊숙이 유인 + 심리적 과신 유도
  결과: 보급 없이 평양성 30리까지 진격

  전술 원칙:
  → 적의 강점(수적 우위)을 무력화
  → 적의 약점(보급·피로·과신)을 극대화

Phase 3 — 오언시 심리전:
  수나라 장군 우중문에게 한시 전달
  「싸워 이긴 공이 높으니, 만족하고 돌아가시지」
  실제 의미: 「더 오면 죽는다」
  효과: 철수 유도 (직접 격멸 없이)

Phase 4 — 살수 수문 개방:
  상류 임시 댐 사전 구축 (준비된 함정)
  철수하는 수군이 강 건너는 순간 개방
  매복군 동시 공격 → 섬멸

  기술적 고증:
  → 청천강 상류 협곡 = 댐 구축 가능
  → 7~8월 장마 직후 = 수위 최고
  → 도강 중 = 기동력 0, 방어 불가 상태
```

#### 황산벌 전투 (660년) — 결사 전술

```
배경:
  계백 결사대 5천 vs 김유신 5만
  나당연합군 작전에서 신라 5만의 선봉 제압이 목표

계백의 전술 구조:

사전 조치 — 가족 살해:
  목적: 병사들의 「생존 욕구」제거
  결과: 5천 병사 전원 이미 죽음 각오
  전술 심리학: 생존 포기 → 전투력 극대화

지형 선택 — 황산벌:
  좁은 골짜기 입구 = 대군 전면 전개 불가
  5만 vs 5천의 수적 열세 상당 부분 상쇄
  → 테르모필레 전투와 동일 원리 (기원전 480년)

4번 승리의 원리:
  1~4차: 결사대의 집중 기습 → 신라 전위 붕괴
  신라군: 넓은 평야 전술 준비 → 협곡 지형 부적응
  계백: 방어선 + 역공 반복

5번째 전투의 패인:
  관창의 2회 돌격 → 신라군 전의 역전
  수적 열세 한계 + 누적 소모 = 전멸
  → 결사 전술의 본질적 한계: 인력 보충 불가
```

#### 안시성 전투 (645년) — 거점 방어 전술

```
배경:
  당 태종 15만 vs 안시성 (병력 미상, 추정 1~2만)

성주(양만춘)의 방어 전술:

거점 방어 선택:
  당군 장기전 유도 = 보급선 약화 전략
  안시성의 지리: 험한 바위산 위 → 공성 어려움
  주민·병사 일체 동원: 군민 합동 방어

토산 대응:
  당군 토산 축조 시도: 성벽보다 높이 쌓아 내려보기
  안시성 대응: 내부 토루(土壘) 동시 증축
  토산 붕괴: 지반 불안 + 안시성 터널 공작 추정 [창작 가능]

심리전 역전:
  88일 버팀 → 당 태종의 과신 + 보급 소진
  겨울 접근 = 당군에게 치명적 (보급·혹한)
  철수 시 절을 함 → 적장의 용기 인정 = 도덕적 승리

전술적 의의:
  소수 거점 방어로 대군 저지 = 이후 산성 전술의 교본
  일본 후대 성곽 전술에도 영향
```

### 왕국별 군사 전술 특성

#### 고구려 전술

```
핵심 병과: 개마무사 (철기 기병) + 중보병

전술 특징:
  1. 종심 방어: 다층 산성 방어선 (국내성→평양→안시성)
  2. 기동 역습: 개마무사 철기 기병 역공
  3. 유인 전술: 을지문덕 식 후퇴 유인 + 섬멸
  4. 장기 농성: 산성 중심 거점 방어

약점:
  장기 공세전 불리 (방어 위주 전략)
  연개소문 사후 지도부 분열 = 방어 체계 붕괴

대표 무기 조합:
  개마무사: 철찰갑 + 환두대도 + 기마궁술
  보병: 철방패 + 창 + 석궁
  공성: 투석기 + 화공
```

#### 백제 전술

```
핵심 병과: 수군 + 기마 귀족병

전술 특징:
  1. 해상 기동: 황해 수군력 (일본·중국 교역 노선)
  2. 보병 밀집: 단단한 보병 대형
  3. 외교 연합: 왜군 + 고구려 연대 전략
  4. 기습 강습: 대야성 함락 등 빠른 공세

약점:
  말기 의자왕 지도력 부재 → 전략 부재
  방어 종심 얕음 (한반도 남서부에 밀집)

대표 무기:
  수군: 선박 돌격 + 궁병
  보병: 창 + 방패 + 철도
  귀족: 철기·환두대도
```

#### 신라 전술

```
핵심 병과: 화랑 정예기병 + 대규모 보병

전술 특징:
  1. 화랑 결사대: 소수 정예가 돌파구 형성
  2. 연합 전략: 나당연합으로 수적 우위 확보
  3. 소모전: 압도적 병력 + 장기전 전략
  4. 기마 궁사: 하린 스타일 — 이동 사격

약점:
  독자 전투력 한계 (당 의존도 높음)
  나당전쟁 초기: 수적 열세 경험

대표 무기:
  화랑: 향비파검 + 단궁
  기마: 활 + 환두대도
  보병: 창 + 방패
```

#### 가야 전술

```
핵심 병과: 철제 중장비 보병

전술 특징:
  1. 철기 우위: 최고급 철제 무기·갑옷
  2. 교역로 방어: 낙동강 수로 통제
  3. 분산 왕국: 통일된 군사 지휘 없음 = 약점

약점:
  통일 왕국 체제 없음 → 연대 전술 부재
  고구려 광개토대왕 남정(400년) 후 쇠퇴
  562년 대가야 멸망 = 신라에 흡수

군사적 유산:
  가야 철기 → 신라 군사력 강화에 기여
  가야 장인 → 신라·백제 무기 제조 기술 전수
```

### 공성·수성 전술 고증

```
산성 방어 원칙:
  지형 = 1차 방어선 (성벽보다 중요)
  저수지 내장 = 장기 농성 필수
  이중 성벽: 외성(外城) + 내성(內城)

고구려 산성 시스템:
  방어 깊이: 수도 평양까지 3~4개 방어선
  안시성 역할: 후방 보급선 차단 포인트
  성벽 높이: 5~8m (돌 쌓기)

공성 장비 (당나라 기준):
  투석기 (투포): 100kg 돌 500m 투사
  충차 (衝車): 성문 파쇄
  토산 구축: 성벽 높이 초과 시 사격 가능
  터널 굴착: 성벽 기초 약화

방어 대응:
  방화 화살: 투석기 파괴
  역굴: 터널 탐지 + 역습
  끓는 기름: 성벽 등반 저지
  토루 증축: 토산 대응
```

### IP 창작 가이드 (전투 장면)

```
전투 장면 작성 시 고증 체크리스트:

□ 계절 고증: 해당 전투 실제 계절과 날씨 확인
  살수대첩: 9월 (음력 7월) — 장마 직후
  황산벌: 7월 (음력 6월) — 여름 무더위
  안시성: 7~9월 공격, 겨울 전 철수

□ 병력 고증:
  수나라 원정군: 별동대 30만 5천 (전체 113만)
  계백 결사대: 5천 (원 병력 5만→5천 감축)
  당 태종 안시성: 15만 (추정)

□ 지형 고증:
  살수 = 현 청천강 (협곡 있음)
  황산벌 = 현 충남 논산 (넓은 평야)
  안시성 = 현 요령성 해성 추정 (바위산)

□ 무기 고증:
  고구려: 철찰갑 + 환두대도 + 기마궁술 (확인)
  백제: 철갑 + 창 (확인) / 화려한 장식 가능
  신라: 향비파 계열 검 + 단궁
  가야: 고급 철제 무기 (당대 최고 품질)

창작 가능 범위 (「창작」표시 필수):
  을지문덕 살수 댐 사전 구축 — 사서 미기록
  당 태종 안시성 눈 부상 — 한국 측 기록만
  계백 살해 가족 수 — 사서에 수 불명확
```
