# 의상 & 소품 디자인 가이드

## 의상 고증 원칙

> "옷은 신분이고, 시대이고, 왕국이다. 관객은 옷 하나로 모든 것을 읽는다."

**고증 우선 순위**
1. 고고학 출토 유물 — 직물·금속 장신구·관모
2. 고구려 고분 벽화 — 삼국시대 유일한 직접 시각 기록
3. 삼국사기·삼국유사 기록
4. 중국·일본 사서의 삼국 복식 기술
5. 현대 고증 연구 (국립박물관 복식 재현 참조)

## 왕국별 의상 체계

### 고구려 의상

#### 기본 복식 구조

| 구성 | 명칭 | 특징 |
|------|------|------|
| 상의 | 유(襦) | 좌임(左衽) — 왼쪽 여밈, 북방 유목 영향 |
| 하의 | 고(袴) | 통이 넓은 바지 — 승마 적합 |
| 겉옷 | 포(袍) | 소매 좁음 — 활동성 우선 |
| 신발 | 화(靴) | 가죽 장화 — 기마 민족 |
| 허리띠 | 대(帶) | 가죽·금속 — 신분 표시 |

#### 신분별 색상 기준

| 신분 | 상의 | 하의 | 포 | 장식 |
|------|------|------|-----|------|
| 왕 | 황색·주색 | 白 | 흑·주 | 금 전체 |
| 장군 | 주색 | 흑 | 흑 | 금 부분 |
| 귀족 | 청·주 | 白·황 | 청 | 은·동 |
| 병사 | 적·갈 | 흑·갈 | — | 철 |
| 민중 | 白·갈 | 白·갈 | — | 없음 |

#### 관모(冠帽) 체계

| 명칭 | 착용 계층 | 형태 |
|------|---------|------|
| 조우관(鳥羽冠) | 왕·귀족 | 새깃털 장식 — 2개 이상 |
| 절풍(折風) | 무관 | 고깔형 모자 |
| 책(幘) | 문관 | 머리 감싸는 헝겊 |
| 두건(頭巾) | 민중 | 단순 천 두름 |

#### 갑옷 (고구려 군사)

| 유형 | 구조 | 착용 계층 |
|------|------|---------|
| 종장판갑(縱長板甲) | 세로 철판 이어붙임 | 기병·장군 |
| 어린갑(魚鱗甲) | 물고기 비늘형 소철판 | 근위·정예 |
| 가죽갑(革甲) | 경화 가죽 | 일반 병사 |
| 면갑(棉甲) | 두꺼운 면포 | 하급 병사 |

**갑옷 색채**: 철색 기본 / 장군: 철흑+혈홍 포인트

### 백제 의상

#### 기본 복식 구조

| 구성 | 명칭 | 특징 |
|------|------|------|
| 상의 | 저고리 | 우임(右衽) — 중국 한족 방식 도입 |
| 하의 | 바지·치마 | 여성: 주름 치마, 남성: 통바지 |
| 겉옷 | 포 | 소매 넓음 — 우아함 강조 |
| 신발 | 이(履) | 비단·가죽 — 장화보다 얕음 |
| 허리띠 | 혁대(革帶) | 정교한 금속 장식 버클 |

#### 신분별 색상 기준

| 신분 | 주조색 | 포인트 | 특이사항 |
|------|--------|--------|---------|
| 왕 | 백토+황금 | 주홍 | 용문양 자수 필수 |
| 왕비 | 백+비취록 | 주홍 | 봉황문양 자수 |
| 귀족 | 비취록·청회 | 황금 | 관등별 색 차등 |
| 관료 | 청·황 | 은 | 홀(笏) 필수 |
| 민중 | 白·갈 | — | 마포(麻布) |

#### 관등별 공복(公服) 색상

백제는 16관등 — 색으로 신분을 즉시 구분:

| 등급 | 색상 |
|------|------|
| 1~6품 | 자색(紫色) |
| 7~11품 | 비색(緋色/적색) |
| 12~16품 | 청색(靑色) |

#### 관모 체계

| 명칭 | 착용 계층 | 형태 |
|------|---------|------|
| 금동관(金銅冠) | 왕·최상위 귀족 | 화려한 금동 장식 |
| 흑책(黑幘) | 관료 일반 | 검은 두건형 |
| 건(巾) | 민중 | 단순 |

### 신라 의상

#### 기본 복식 구조

| 구성 | 특징 |
|------|------|
| 상의(袖衣) | 우임, 소매 길이 중간 |
| 하의 | 남: 바지 / 여: 긴 치마 |
| 겉옷 | 포 — 비단 고급 계층, 마포 하층 |
| 신발 | 비단 이(履) — 화랑은 가죽화 |
| 허리띠 | 금·은·동·철 — 골품 표시 |

#### 골품제(骨品制) 의상 규정

신라는 골품에 따라 의상 재질·색상이 법제화:

| 골품 | 재질 | 금지사항 |
|------|------|---------|
| 성골(聖骨) | 비단 최고급 | 제한 없음 |
| 진골(眞骨) | 비단 | 보라·자색 금지 |
| 6두품 | 비단·마 혼용 | 특정 색 제한 |
| 5두품 이하 | 마포 위주 | 색 극히 제한 |

**IP 적용**: 등장인물의 의상으로 골품을 즉시 인식 가능하도록 설계

#### 화랑(花郞) 의상

| 요소 | 세부 |
|------|------|
| 기본 | 신라 청년 복식 + 단정함 |
| 색상 | 청+황금 계통 |
| 장식 | 금 이식(耳飾) 필수 — 남성도 착용 |
| 무기 | 단검+궁시 — 화랑 세트 |
| 특이점 | 화장(化粧) — 화랑은 미모 중시, 얼굴 분(粉) 바름 |

#### 관모 체계

| 명칭 | 착용 계층 | 형태 |
|------|---------|------|
| 금관(金冠) | 왕 | 출자형 세움+달개 |
| 금동관 | 왕족·최상위 | 금동 세움 |
| 관(冠) | 일반 귀족 | 등급별 소재 차등 |
| 화랑 두건 | 화랑 | 단정한 흰 두건 |

### 가야 의상

#### 기본 복식 구조

| 구성 | 특징 |
|------|------|
| 상의 | 좌임, 소매 좁음 — 작업 편의성 |
| 하의 | 바지 — 철 작업자는 더 두꺼운 소재 |
| 겉옷 | 철 작업 중 없음 / 의례 시 간단한 포 |
| 신발 | 가죽화 기본 — 작업 현장 |

#### 계층별 의상

| 계층 | 특징 |
|------|------|
| 왕실 | 철색+왕실금 — 간결하나 금 장식 |
| 장인 | 그을린 색 작업복 — 실용 우선 |
| 상인 | 각 지역 영향 혼합 — 개방적 |
| 민중 | 가야토기 색상 — 토갈+철색 |

## 소품 카탈로그

### 무기류

#### 삼국 공통 무기

| 무기 | 형태 | 왕국별 차이 |
|------|------|-----------|
| 철검(鐵劍) | 외날·양날 | 고구려: 긴 환두대도 / 백제: 정교한 단검 / 신라: 긴 직도 |
| 궁시(弓矢) | 각궁+화살 | 고구려: 소형 복합궁 / 백제·신라: 중형궁 |
| 창(槍/矛) | 장병기 | 철촉+나무 자루 — 길이 2~3m |
| 도끼(斧) | 철제 | 하급 병사 다용도 |
| 방패(盾) | 목제+가죽 | 고구려: 원형 / 백제·신라: 직사각 |

#### 고구려 특수 무기

| 무기 | 특징 |
|------|------|
| 기병창(騎兵槍) | 말 위에서 사용 — 더 긴 버전 |
| 맥궁(貊弓) | 고구려 특산 복합궁 — 수출품 |
| 투구(兜鍪) | 볏 있는 철투구 — 벽화 기반 |

#### 연개소문 다섯 자루 칼 설계

| 검 번호 | 위치 | 의미 | 디자인 |
|---------|------|------|--------|
| 1번 | 좌 허리 | 왕을 향한 칼 | 가장 오래된 — 쿠데타 당시 |
| 2번 | 우 허리 | 당나라를 향한 칼 | 가장 실전적 |
| 3번 | 등 좌 | 반대파를 향한 칼 | 날이 가장 예리 |
| 4번 | 등 우 | 미래를 향한 칼 | 가장 새것 |
| 5번 | 등 중앙 | 자신을 향한 칼 | 가장 짧음 — 진검 |

### 장신구류

#### 고구려 장신구

| 명칭 | 소재 | 착용 위치 |
|------|------|---------|
| 환두대도 자루 장식 | 금동 | 칼 자루 |
| 이식(耳飾) | 금·은 | 귀 |
| 경식(頸飾) | 옥·금 | 목 |
| 요패(腰牌) | 금동·옥 | 허리띠 |

#### 백제 장신구 (최고 정밀도)

| 명칭 | 소재 | 특징 |
|------|------|------|
| 금동관식(金銅冠飾) | 금동 | 꽃·봉황 문양 |
| 이식(耳飾) | 금+옥 | 태환(太環)+수식(垂飾) |
| 금제 관(冠) | 순금 | 무령왕릉 출토형 |
| 과대(銙帶) | 금동 장식 허리띠 | 사각 금동 판 이어붙임 |

**백제 공예 특이사항**: 누금(鏤金) 기법 — 금실을 땋아 만든 섬세한 장식. IP 클로즈업 필수.

#### 신라 장신구 (황금 최다)

| 명칭 | 소재 | 특징 |
|------|------|------|
| 금관(金冠) | 순금 | 출자형 세움+달개 수백 개 |
| 금제 이식 | 순금 | 태환+하트형 수식 |
| 곡옥(曲玉) | 비취·유리 | 쉼표형 — 신라 정체성 |
| 금제 경식 | 금+곡옥 | 목걸이 형태 |
| 금동 신발 | 금동 | 무덤 부장 — 실제 착용 여부 논란 |

## 의상 시대별 변화

| 시기 | 변화 포인트 |
|------|-----------|
| BC 1C~1C | 부족 복장 → 왕국 공복 형성기 |
| 4~5C | 불교 도입 → 승복·불교 장식 추가 |
| 5~6C | 삼국 전성기 — 각 왕국 의상 최고 정제 |
| 7C 전반 | 전시 체제 → 갑옷·군복 비중 증가 |
| 7C 후반 | 통일 후 → 당나라 영향 복식 혼입 |

## 의상 제작 주의사항

### 반드시 낡게 표현해야 하는 경우
- 전투 중·후 의상 — 흙·혈흔·찢김
- 민중 일상 의상 — 세탁 많이 된 탈색
- 포로·피난민 의상 — 극도의 훼손

### 깨끗하게 표현하는 경우
- 왕의 공식 의례 장면만 — 완전 신품
- 외교 접견 장면 — 최선의 차림

### 절대 금지
1. 지나치게 새것 같은 민중 의상
2. 현대적 패턴·프린트 적용
3. 왕국 DNA 위반 색상 배정
4. 실제 착용 불가능한 비현실적 구조
5. 일본 사극·중국 무협 의상 차용
