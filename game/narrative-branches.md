## 서사 분기 설계 철학

삼국(三國) 게임의 서사는 **역사의 결과는 고정, 과정은 플레이어가 선택**한다.

광개토대왕은 반드시 영토를 넓힌다. 백제는 반드시 멸망한다. 그러나 **그 과정에서 어떤 선택을 했는가**에 따라 엔딩의 감정적 색채가 달라진다.

```
분기 원칙:
1. 역사적 사실 (결과) — 변경 불가
2. 역사적 과정 (방법) — 플레이어 선택
3. 창작 인물 서사 — 완전 자유 분기
4. 각 선택은 다음 장의 대사·연출에 반영
```

## 메인 캠페인 분기 구조

### 고구려 캠페인 — 광개토의 유산

#### Chapter 1: 즉위 (BC 391년)

**선택 1 — 첫 원정 대상**

```
상황: 광개토왕 즉위 직후. 세 방향으로 위협이 존재한다.

[A] 백제 국경 공격 → 복수의 길
    결과: 백제 서브 캐릭터 '아신왕'과 조기 적대 관계
          BUT 고구려 병사 사기 +20%, 백제 국경 안정화

[B] 거란 방면 정벌 → 영토 확장의 길
    결과: 북방 영토 확보, 그러나 백제가 숨 돌릴 시간 확보
          기병 유닛 강화 트리 해금

[C] 내정 안정 우선 → 민심의 길
    결과: 귀족 지지도 +30%, 초반 전투 능력 -10%
          후반 '을파소식 재상' 특수 유닛 해금 가능

각 선택에 따른 분기 대사:
[A] "복수는 지금이다. 고국원왕의 치욕을 내가 씻겠다."
[B] "영토는 사방으로 넓어야 한다. 먼저 북을 잡자."
[C] "강한 왕은 전쟁만 하지 않는다. 백성이 먹어야 전쟁도 한다."
```

#### Chapter 3: 신라 구원 (400년)

**선택 2 — 신라 구원 조건**

```
상황: 신라 내물마립간이 왜구 격퇴를 요청한다.

[A] 무조건 구원 → 의리의 길
    결과: 신라 호감도 +50, 고구려 군사 자원 -15%
          신라 특수 이벤트 해금 (박제상 에피소드 선공개)

[B] 조건부 구원 → 실리의 길
    조건 입력창: "신라 북쪽 국경 지역을 고구려에 양도하라"
    결과: 영토 확장, 신라 호감도 -30, 가야 불안도 증가

[C] 거절 → 고립의 길
    결과: 신라가 백제와 밀착, 남방 균형 붕괴
          후에 나제동맹 강화로 고구려 남진 어려워짐
          BUT 내정 자원 집중 가능

숨겨진 선택 [D] — 구원하되 아무 조건도 없이 (특정 캐릭터 호감도 조건)
    결과: "동명성왕의 후예" 업적 달성
          모든 신라 캐릭터 호감도 최대치
```

#### Chapter 5: 광개토의 유언 (413년)

**선택 3 — 유언의 내용**

```
상황: 병상의 광개토왕. 장수왕에게 유언을 남긴다.

[A] "더 가라. 바다까지." → 팽창 유언
    결과: 장수왕 캠페인에서 공격적 플레이 가능
          남진 정책 가속 — 475년 한성 함락 이벤트 조기 해금

[B] "지킨 것을 지켜라." → 수성 유언
    결과: 장수왕 캠페인 방어 특화
          고구려 내정 안정도 최대, 영토 확장 속도 감소

[C] "백성을 기억해라." → 민심 유언
    결과: 고구려 민중 호감도 최대
          특수 '을파소 개혁' 정책 트리 해금
          백성 반란 이벤트 원천 차단

엔딩 분기:
- [A] 엔딩: "광개토대왕릉비가 세워졌다. 그의 이름은 영원히 살았다."
- [B] 엔딩: "장수왕은 98세까지 살았다. 아버지의 유언을 지켰다."
- [C] 엔딩: "백성이 왕의 이름을 기억했다. 그것이 진짜 유산이었다."
```

#### Chapter 1: 근초고왕의 선택 (346년)

**선택 1 — 백제의 방향성**

```

[A] 군사 팽창 → 전투 특화 루트
    결과: 371년 고구려 공격 이벤트 활성화

[B] 문화 외교 → 문화 특화 루트

          왜국·중국 관계 최상, 전투력 -15%
          일본 수출 수익 +40%

[C] 균형 전략 → 밸런스 루트 (기본)
    결과: 모든 능력치 표준, 이후 선택에서 가장 많은 옵션 열림
```

#### Chapter 4: 나제 동맹과 배신 (553년)

**선택 2 — 한강 탈환 전략**

```
상황: 신라와 연합하여 한강을 탈환하는 시점.
     신라가 배신할 것을 암시하는 정보가 입수됨.

[A] 그래도 신라와 협력한다 → 신뢰의 길
    결과: 한강 탈환 성공, BUT 신라가 배신
          553년 배신 이벤트 강제 발생
          성왕: "믿었기에 더 아프다."

[B] 단독 작전으로 한강 공격 → 자립의 길
    결과: 성공률 50% (랜덤 요소)
          성공: 신라 없이 한강 확보 — "백제 최강" 엔딩 루트
          실패: 국력 소모, 이후 방어전 불리

[C] 한강 포기, 문화 강국 집중 → 평화의 길
    결과: 영토 손실, BUT 백제 문화 점수 최대
          일본·중국 교류 이벤트 최다 해금
          특수 엔딩: "백제는 땅이 아닌 문화로 영원했다."
```

```
     아내와 자녀들의 처분 문제. (역사 기록 기반)

[A] 역사대로 — 가족을 직접 처리한다
    결과: 병사 사기 최대, 처절한 비장함

[B] 가족을 피신시킨다 — 창작 루트
    결과: 병사 일부 이탈, 전투력 -15%
          계백 내면 갈등 심화
          가족 생존 엔딩 해금 (창작)

[C] 가족과 함께 항복을 선택 — 평화 루트
    결과: 계백 실각, 다른 장수로 황산벌 전투
          백제 멸망 과정 변형, 의자왕과의 갈등 심화

중요 안내: [A]는 역사적 사실에 근거한 선택입니다.
           게임 내 역사 설명 팝업 자동 표시.
```

```
          백성 신뢰 최대, 귀족 저항 중간

```

**선택 3 — 통일의 방식**

```
[A] 완전 정복 → 힘의 통일

    결과: 나당 전쟁 먼저 발생
```

### 가야 캠페인 — 잊혀진 왕국 (DLC)

#### 특수 구조: 가야는 멸망이 확정된 캠페인

```
설계 의도:
가야는 역사적으로 멸망한다. 이를 플레이어가 알면서도 진행하는
"비극을 알면서도 사랑하게 되는" 감정 경험 설계.

목표: 점수가 아닌 "가야가 남긴 것"을 극대화하는 것
```

**핵심 선택 — 우륵의 결단**

```
상황: 가야 멸망이 임박. 우륵에게 선택지.

[A] 신라에 귀순하여 음악을 전한다 → 역사적 선택
    결과: 가야금이 신라에 전수됨
          계고·법지·만덕 제자 이벤트 해금
          엔딩: "가야는 사라졌다. 그러나 소리는 영원했다."

[B] 가야와 함께 최후를 맞이한다 → 비극적 선택
    결과: 우륵 사망, 가야금 행방불명
          숨겨진 엔딩: 수백 년 후 가야금이 발굴되는 장면
          (현대 고고학 오마주)

[C] 제3국으로 탈출한다 → 생존 선택 (창작)
    결과: 왜국 또는 중국으로 망명
          가야금이 동아시아로 전파되는 엔딩
          "가야의 소리가 세계로 퍼졌다" 특수 업적
```

## 공통 시스템 — 선택 기억 메커니즘

```
누적 선택 결과 시스템:
모든 선택이 "강의 기억(River Memory)" 수치에 반영됨

강의 기억 지수:
- 역사적 선택: +10~30점
- 창작적 선택: 점수 없음, 대신 숨겨진 콘텐츠 해금
- 비극적 선택: 감정 포인트 최대, 게임 내 메달 획득

최종 엔딩 분류:
- 강의 기억 80+: "역사가 기억하는 왕" 엔딩
- 강의 기억 50~79: "민중이 기억하는 왕" 엔딩
- 강의 기억 30~49: "이름 없는 왕" 엔딩 (가장 많은 숨겨진 콘텐츠)
- 강의 기억 29 이하: "강이 잊은 왕" 엔딩 (비밀 해금 — 완전한 반역 플레이)
```
