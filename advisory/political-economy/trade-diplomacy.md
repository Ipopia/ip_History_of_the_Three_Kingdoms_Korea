## 삼국 국제 관계 개요

```
4~7세기 동아시아 국제 질서:
  중심: 중국 왕조 (후한 → 위진남북조 → 수 → 당)
  주변: 고구려·백제·신라·가야 + 왜(日本)

조공 체계 (朝貢體制):
  구조: 주변국 → 중국에 조공 → 중국 → 책봉(冊封) 회신
  의미: 외교적 승인 + 무역 권리 획득
  실질: 형식적 복속 ≠ 실질 지배 (고구려는 실질 독립 유지)

삼국 각자의 외교 전략:
  고구려: 강경 독립 + 주변국과 등거리 외교
  백제: 남조(南朝) + 왜와 연대 (고구려 견제)
  신라: 초기 고립 → 나당 연합으로 반전
  가야: 왜와 긴밀한 교류 (철기 수출 중심)
```

## 고구려 외교

```
대중국 관계:
  원칙: 조공 형식 유지 + 실질 독립 고수
  충돌: 수나라 4차 침략 (598·612·613·614) → 모두 격퇴
  수 멸망 후: 당나라와 초기 우호 → 642년 이후 대립
  고구려 외교 전술:
    - 한 번에 여러 중국 왕조와 동시 조공 (등거리)
    - 서방 돌궐(突厥)과 연대 (당나라 견제)
    - 백제와 연대 → 신라 고립 시도

대백제 관계:
  5세기: 고구려 장수왕 → 백제 한성 함락 (475년)
  이후: 고구려-백제 만성적 적대
  6~7세기: 고구려·백제·왜 3자 연대 (신라 포위)

대신라 관계:
  5~6세기: 고구려가 신라 보호
  나제동맹(羅濟同盟) 이후: 신라와 적대 전환

외교 핵심 인물 (창작 활용):
  고루 역할: 을지문덕 사후 외교 전령 역할 가능
  을지문덕의 수 우중문 한시 = 심리전 외교
```

## 백제 외교

```
대중국 관계:
  남조(南朝) 우선: 동진 → 송·제·양·진과 조공
  이유: 고구려 견제를 위한 중국 후원 필요
  백제 외교 특기: 문화 전파 (불교·한자·예술 → 왜로 중계)

대왜(倭) 관계:
  백제-왜 특수 관계: 동아시아에서 가장 긴밀한 동맹
  교류 내용:
    - 백제 → 왜: 불교·한자·기술(야철·도기) 전파
    - 왜 → 백제: 군사 지원 (백제 멸망 시 왜군 참전)
  문화 사절: 왕인(王仁) 박사 논어·천자문 전달 (5세기)
  백강 전투 (663년): 백제 부흥군 + 왜군 vs 나당 연합

대고구려 관계:
  5세기 한성 함락 후 만성 적대
  나제동맹 (433년) → 고구려 견제 공동 전선

아랑 서사 연결:
  아랑의 정보 수집 = 수나라·당나라 동향 정리
  성충의 외교 조언 = 나당 연합 경고 (역사 사실)
  백제 외교 실패 서사: 의자왕이 성충 말을 듣지 않음
```

## 신라 외교

```
초기 외교적 고립:
  한반도 동남부 → 중국과 직접 교류 어려움
  고구려 경유 → 중국 문물 수입
  5세기: 고구려의 영향권 아래

나당 연합 형성 (648년):
  배경: 고구려·백제·왜 3자 연대에 포위된 신라
  김춘추(金春秋) 당나라 방문 → 나당 동맹 체결
  조건:
    - 당: 병력 지원 + 고구려 협공
    - 신라: 조공 증가 + 대동강 이남 영토 인정
  결과: 백제 660년 멸망, 고구려 668년 멸망

신라 통일 후 대당 갈등:
  당: 한반도 전체 직할 지배 시도 (안동도호부)
  신라: 무력으로 당군 축출 (676년 기벌포 전투)
  결과: 대동강 이남 신라 통일 확정

하린 서사 연결:
  나당 연합 = 하린의 최대 도덕적 딜레마
  「동맹을 위해 이웃 나라를 침략한다」
  하린의 질문: 「이것이 옳은가?」→ 시즌 2 핵심 서사
```

## 삼국 교역 체계

```
교역 품목:

고구려 수출:
  - 모피 (담비·여우·곰)
  - 인삼 (고급 약재)
  - 말 (군마·교역마)
  - 금·은 (압록강 유역 광산)
  수입: 비단·도자기 (중국), 불교 경전

백제 수출:
  - 금공예품 (금동대향로 수준)
  - 비단 직물 (왕실 품질)
  - 불교 문물 (경전·불상·승려)
  - 한자 문화 (왜로 수출)
  수입: 중국 도자기·비단, 왜 진주·산물

신라 수출:
  - 금(金) (경주 지역 금 풍부)
  - 황금 공예품 (금관·금귀고리)
  수입: 불교 문물, 중국 문물 (6세기 이후 직접 교역)

가야 수출 (전성기):
  - 철(鐵) — 동아시아 최고급 철 생산
  - 철제 무기·농기구·갑옷
  - 가야 도기(陶器)
  수입: 왜 목재·진주, 중국 문물 (고구려·백제 경유)

교역 루트:
  육상: 요동 → 압록강 → 평양 → 한강 (고구려 경유)
  해상: 서해 横断航路 (백제 ↔ 중국 남조)
  남해: 가야 ↔ 왜 (낙동강 하구 ↔ 북규슈)
```

## 외교 의식 & 사절

```
조공 사절 구성:
  정사(正使): 왕족 or 고위 귀족
  부사(副使): 외교 전문가
  수행원: 통역관·서기·호위 무사 50~200명
  공물: 특산품 + 왕실 서신 (한문)

중국 황제 접견 의식:
  삼고두례(三叩頭禮): 3번 무릎 꿇고 머리 조아림
  고구려: 형식적으로만 이행 (실질 복속 거부)
  백제: 성실히 이행 (외교 이익 추구)

왜 사절 (백제→왜):
  문화 전파 목적: 승려·기술자 파견
  오경박사(五經博士): 유교 경전 교사 파견
  사절 빈도: 수년에 1회 → 관계 긴밀 시 매년

아랑 서사 활용:
  아랑이 사절단 기록을 정리하는 씬
  외국 사절의 언어·의복·태도 기록
  성충: 「사절단의 말이 아니라 눈빛을 기록해라」
```

## 창작 활용 가이드

```
외교 씬 시나리오:
  고루 관련:
    수나라 우중문과의 심리전 (을지문덕 한시)
    연개소문 외교 강경화 목격 씬

  아랑 관련:
    백제 사비성에 오는 당나라·왜 사절 기록
    성충이 외교 정보를 아랑에게 전달하는 씬

  하린 관련:
    나당 연합 협상 장면 목격 (김춘추 출발 배웅)
    「우리가 중국에 무릎을 꿇는다」딜레마

주의 사항 (역사 오류 방지):
  ❌ 고구려가 당나라에 복속했다는 표현 금지
  ❌ 백제-왜 관계를 「일본 지배」로 묘사 금지
  ❌ 신라 통일을 「외세 의존」으로만 폄하 금지
  ✅ 모든 외교는 생존을 위한 선택으로 묘사
  ✅ 역사적 결과와 일치하는 외교 흐름 유지
```
