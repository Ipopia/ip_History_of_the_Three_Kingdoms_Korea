## 문화 체계 개요

삼국시대 축제와 의례는 단순한 행사가 아닌 **왕국의 정체성 선언**이었다. 하늘에 드리는 제사, 강에 바치는 공물, 전사들의 귀환 의식 — 이 모든 것이 왕국의 세계관을 담는다.

```
문화 체계 분류:
TYPE 1 — 국가 제사: 왕이 주관, 하늘·강·조상에 드림
TYPE 2 — 계절 축제: 농경·수렵 주기에 따른 공동 축제
TYPE 3 — 전쟁 의례: 출정·귀환·전승 의식
TYPE 4 — 통과 의례: 탄생·성인·결혼·장례
TYPE 5 — 왕실 의례: 즉위·대관·외교 의식
```

## 고구려 축제·의례

### 동맹(東盟) — 고구려 최대 국가 제사

```
[원전: 삼국지 위서 동이전]

시기: 10월 (음력)
장소: 국동대혈(國東大穴) — 왕도 동쪽 동굴
목적: 하늘·강신에게 제사 + 공동체 결속

의식 진행:
1일차: 왕이 하늘에 첫 제사 (새벽)
       삼족오 문양 제기 사용
2일차: 부족장·귀족 공동 의식
       국동대혈에서 수신(水神)에게 제사
3일차: 공동 향연 + 음악·가무
       민간도 참여 가능
4일차: 씨름·말타기·활쏘기 경연

제물:
- 말(최상품) / 소·돼지 / 오곡
- 철기 제품 (가야에서 수입한 철정)

드라마 활용:
→ 동맹 축제 중 정치 음모 장면
→ 고루가 축제 경연에서 을지문덕을 처음 만남
→ 광개토대왕 즉위 후 첫 동맹 연출

게임 연동:
동맹 이벤트: 10월마다 발생
효과: 전체 생산력 +20%, 외교 보너스
선택: 성대하게 치르기(비용) vs 간소화(절약)
```

### 수렵제(狩獵祭) — 봄 사냥 의식

```
시기: 3월 (음력)
장소: 왕도 인근 산야
목적: 전사들의 무예 단련 + 하늘 기도

의식:
- 왕이 직접 사냥에 참여 (상징적)
- 개마무사들의 기마 시범
- 최고 사냥꾼에게 왕이 직접 포상
- 사냥 결과로 다음 한 해 길흉 점복

드라마 활용:
→ 광개토대왕의 수렵 실력 과시 장면
→ 고루가 사냥에서 이상한 새(삼족오 연상)를 봄
```

### 개선의례(凱旋儀禮) — 전쟁 귀환

```
목적: 원정 군대 귀환 + 전승 기념

의식:
1. 선봉대 평양성 입성 (북·나팔)
2. 전리품 행진 (적국 깃발·무기·포로)
3. 왕이 성문 밖에서 영접
4. 전사자 추모 의식 (강에 꽃 띄우기)
5. 대연회

살수대첩 귀환 의식 [창작]:
을지문덕이 귀환 시 아무 말 없이 강물에 들어감.
강물이 그를 씻겨내는 것처럼 묘사.
→ 전쟁의 무게를 씻는 상징
```

## 백제 축제·의례

### 사비 연회(泗沘宴會) — 궁중 계절 연회

```
시기: 춘분·하지·추분·동지 (연 4회)
장소: 사비성 대전 + 정원
목적: 왕실 권위 과시 + 귀족 결속

의식:
사전 준비:
- 금동대향로에 향 피우기 (3일 전부터)
- 봉황 문양 도자기 배열
- 악사단 배치 (가야금·거문고·피리)

본 의식:
1. 왕 입장 (봉황 수놓인 곤룡포)
2. 하늘과 조상에 공물 (술·음식)
3. 왕과 귀족 순서대로 착석
4. 악사 연주 + 무용 공연
5. 외교 사절 접견 (있을 경우)
6. 만찬 + 시가 낭독

특별 연회:
- 외교 사절 접견 시: 칠지도 전시
- 전승 후: 전리품 전시 + 무훈 낭독
- 왕자 탄생 시: 7일 연속 연회

드라마 활용:
→ 의자왕의 마지막 사비 연회 (멸망 전야)
→ 소서노 관련 초기 연회 장면
→ 금동대향로 클로즈업 시퀀스
```

### 낙화암제(落花岩祭) — 백마강 제사

```
[창작 의례 — 역사적 낙화암 사건 기반 신화화]

시기: 매년 가을 (사비 천도 기념일 주변)
장소: 백마강(白馬江) 강변 + 낙화암
목적: 강신(江神)에게 제사 + 왕국 번영 기원

의식:
1. 왕비 또는 고위 여인이 강가에서 제사 주관
2. 연꽃 꽃잎을 강물에 띄움
3. 봉황 문양 백자 항아리를 강에 봉납
4. 악사들의 강변 연주

신화적 의미:
강은 백제를 기억한다.
연꽃 꽃잎이 흘러가는 방향으로 그 해 운세를 봄.

660년 백제 멸망 후:
낙화암에서 백제 궁녀들이 몸을 던진 전설과 연결.
이후 백마강은 백제의 기억을 담는 성소(聖所)가 됨.

게임 연동:
낙화암제 이벤트 → 백제 외교 보너스 + 강 수비력 강화
멸망 루트: 낙화암제 중단 시 사기 하락 이벤트 발생
```

## 신라 축제·의례

### 화랑 선발식(花郎 選拔式)

```
[원전: 삼국사기 신라본기 기반]

시기: 3년마다 (정기적)
장소: 경주 화랑도 훈련장 + 황룡사
목적: 화랑 조직 정예 선발 + 정신 무장

의식:
1일차 — 신체 시험
- 말타기 / 활쏘기 / 씨름
- 천 명 중 최상위 선발

2일차 — 지식 시험
- 세속오계(世俗五戒) 구술
- 역사·예법 시험

3일차 — 황룡사 서약
- 황룡사에서 부처와 왕에게 충성 서약
- 화랑 휘장 수여 (꽃 문양)

4일차 — 원화(源花) 의식
- 여성 화랑 지도자 원화 임명 (있을 경우)
- 화랑도 전체 출정 행진

드라마 활용:
→ 선덕여왕이 화랑 선발식 주관
→ 젊은 유신(창작화) 화랑 선발 장면
→ 세속오계 낭독 장면
```

### 천문 관측 의례(天文 觀測 儀禮)

```
[선덕여왕 특화 신라 고유 의례]

시기: 동지 전날 밤
장소: 첨성대(瞻星臺)
목적: 다음 해 운세 관측 + 농경 예측

의식:
저녁: 왕 또는 천문관이 첨성대 입장
       금관 착용 (하늘과 연결 상징)
자정: 핵심 별자리 관측 기록
       그믐·보름달 위치 기록
새벽: 관측 결과 왕에게 보고
       다음 해 농업·전쟁 운세 발표

선덕여왕의 예언:
모란꽃 씨앗 그림에서 향기 없음을 예언
영묘사 우물 개구리에서 백제 침공 예언
→ 천문 의례 + 예언 능력의 신화화

게임 연동:
천문 관측 이벤트: 매년 동지
효과: 다음 시즌 적국 행동 일부 사전 공개
선덕여왕 보유 시: 공개 정보 2배 증가
```

### 화백회의(和白會議) — 신라 귀족 합의제

```
[원전: 삼국사기 기반]

성격: 축제가 아닌 제도이나 의례적 성격 강함
시기: 중대사 발생 시 (전쟁·왕위 계승·외교)
장소: 경주 남산 천석(天石) 또는 왕궁

의식:
1. 화백 구성원 (6부 대표) 원진(圓陣) 착석
2. 안건 낭독
3. 각 부 대표 발언 (위계 없이 동등)
4. 「만장일치」원칙 — 1인이라도 반대 시 부결
5. 결의 내용 돌판에 새김

선덕여왕과 화백:
여왕 즉위 자체가 화백 만장일치.
전쟁 선포도 화백 결의 필요.
→ 왕권과 귀족권의 긴장 관계 극화 가능

드라마 활용:
→ 신라 정치 논쟁 장면의 핵심 배경
→ 당나라 연합 결정 화백 장면
```

## 가야 축제·의례

### 구지가제(龜旨歌祭) — 가야 건국 기념 제사

```
[원전: 삼국유사 가락국기 기반]

시기: 매년 봄 (수로왕 탄생 기념)
장소: 구지봉(龜旨峰) — 가야 건국 성지
목적: 건국 신화 재현 + 공동체 결속

의식:
1. 구지봉에 9부족 대표 집결
2. 구지가(龜旨歌) 합창
   "거북이여 거북이여 머리를 내밀어라"
3. 제물 봉헌 (철정·가야금·곡물)
4. 가야금 연주 (12악곡 중 일부)
5. 씨름·무예 경연

우륵의 역할:
가야금 연주는 가야의 최고 예술가가 담당.
우륵은 구지가제 공식 악사.
→ 우륵이 신라로 가는 것 = 구지가제 악사 이탈 = 상징적 소멸

게임 연동:
구지가제 이벤트: 매년 봄
효과: 가야 전체 사기 +30%, 철 생산 +25%
우륵 귀화 이후: 이벤트 발생 불가 (사기 -20%)
```

### 철기 축제(鐵器 祭典)

```
시기: 추수 후 (10~11월)
장소: 김해 철 단조 구역
목적: 철 생산 풍요 기원 + 장인 포상

의식:
1. 가야 최고 장인의 새 철기 시범 제작
2. 완성된 철기를 구지봉에 봉납
3. 한 해 최고 철정(鐵鋌) 경매 (왜·신라 상인 참여)
4. 장인에게 수로왕 문양 포상

드라마 활용:
→ 가야 장인과 왜 상인 거래 장면
→ 우륵이 축제 음악 담당하며 철 교역 관찰
→ 가야 멸망 전 마지막 철기 축제 (비장함)
```

## 공통 통과의례

### 탄생·유아 의례

```
삼국 공통:
- 탄생 3일: 하늘에 신생아 보고 (향 피움)
- 100일: 가족 잔치 + 이름 확정
- 돌: 돌잡이 (고대 버전)
  고구려: 활·말·검
  백제: 붓·금·공예품
  신라: 금·옥·책
  가야: 철정·가야금·낚시

왕자 탄생:
- 고구려: 삼족오 깃발 게양 + 성내 방면령
- 백제: 봉황 문양 비단 선물 배포
- 신라: 황룡사 타종 (탄생 수만큼)
- 가야: 구지봉에 봉화
```

### 성인 의례

```
고구려:
- 15세: 「장수」칭호 수여 (남성)
- 활 쏘기 통과 의례
- 머리 결발(結髮) — 상투 틀기

백제:
- 16세: 「관례(冠禮)」
- 왕실: 금관 형태 관 착용
- 귀족: 비단 띠·관 수여

신라:
- 화랑 입단 (15~16세)
- 황룡사 서약
- 꽃 문양 장식 착용

가야:
- 철 단조 첫 제품 완성 = 성인
- 수로왕릉에 철기 봉납
```

### 장례 의례

```
고구려 귀족:
- 3년 복상
- 고분 조성 (평양 인근 대형 고분)
- 벽화 제작 (죽은 자의 생애 그림)
- 순장 폐지 후: 토우(土偶) 대체

백제 왕실:
- 무령왕릉 양식 (전돌 무덤)
- 지석(誌石) — 묘지명 기록
- 금·은 부장품

신라 왕실:
- 적석목곽묘 (큰 돌무더기)
- 금관·금제 장신구 부장
- 말 부장 (말 껍질·뼈)

가야:
- 순장 풍속 (왕 사망 시 순장자 동행)
  게임에서는 PG-13 수위로 처리
- 철정 대량 부장 (부의 상징)
```

## 머천다이즈 연동 — 현대 기념일 창작

```
[삼국 IP 공식 기념일 — 마케팅 활용]

3월 「비류수의 봄」기념 (고구려 건국 축제 연동):
- 고구려 한정 컬렉션 출시
- 수렵제 테마 상품

5월 「봉황의 날」(백제 천도 기념일 연동):
- 백제 사비 천도 기념
- 금동대향로 한정 레플리카

6월 「구지가의 날」(가야 건국 신화 연동):
- 가야 한정 컬렉션
- 가야금 음악 무료 스트리밍

10월 「동맹의 달」(고구려 동맹제 연동):
- 삼국 통합 컬렉션
- 팝업 스토어 + 문화 행사

12월 「별의 밤」(신라 천문 관측 연동):
- 신라 금관·첨성대 테마 상품
- 별자리 패키지
```
