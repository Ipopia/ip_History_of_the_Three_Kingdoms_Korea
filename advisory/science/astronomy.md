## 자문 범위

```
핵심 영역:
  1. 삼국시대 천문 관측 체계 (천문관·첨성대)
  2. 별자리·천상열차분야지도 계보
  3. 역법 (태음태양력) 운용
  4. 천문 현상의 정치적 해석 (천인감응설)
  5. 기상·계절 표현 정확성
  6. 일식·월식·혜성 등 천문 이벤트 고증

적용 매체:
  드라마·영화: 하늘 씬 천문 정확성
  소설·웹툰: 천문 묘사 감수
  게임: 계절·시간대·하늘 표현
  VR 체험: 별자리 체험 콘텐츠
  전시: 첨성대·천문도 해설 패널
```

## 삼국시대 천문 체계

### 천문 관측 기관

```
고구려:
  천문관: 일관(日官) — 천문·역법·기상 담당
  관측 방식: 맨눈 관측 + 혼천의(渾天儀) 추정
  기록: 고구려 천문 기록 → 삼국사기 천문지 반영
  특이사항: 고분 벽화 별자리 (덕흥리 고분·강서대묘)
    → 북두칠성·28수 별자리 묘사 확인
    → 별자리 배치: 적도좌표계 기반

백제:
  천문관: 일관부(日官部)
  역법: 원가력(元嘉曆) → 수나라에서 도입
  일본 전수: 백제 천문학 → 일본 전래 (554년 역박사 파견)
  기록: 백제 천문 독자 관측 기록 (삼국사기)

신라:
  천문관: 천문박사(天文博士)·누각전(漏刻典)
  첨성대: 632~647년 건립 (선덕여왕)
    → 동아시아 현존 최고(最古) 천문 관측대
    → 높이 약 9.17m / 362개 석재 (음력 1년 일수)
    → 27단 석단 (선덕여왕 = 신라 27대 왕)
    → 기능: 관측대 / 규표(해시계) / 상징물 (해석 논쟁)
  역법: 선명력(宣明曆) 도입 (당나라 계통)

가야:
  독자 천문 기록: 없음 (가야 관련 사서 부족)
  추정: 신라·백제 계통 역법 사용
  IP 창작: 가야 대장장이 철기 생산 시 계절·별 관측 설정 가능
```

### 별자리 체계 (동아시아)

```
체계: 3원 28수(三垣 二十八宿)

3원(三垣):
  자미원(紫微垣): 북극 주변 — 왕궁·황제
  태미원(太微垣): 춘분점 부근 — 조정·관료
  천시원(天市垣): 은하수 부근 — 시장·백성

28수(二十八宿): 4방위 × 7수(宿)
  동방 청룡 7수: 角·亢·氐·房·心·尾·箕
  북방 현무 7수: 斗·牛·女·虛·危·室·壁
  서방 백호 7수: 奎·婁·胃·昴·畢·觜·參
  남방 주작 7수: 井·鬼·柳·星·張·翼·軫

IP 적용:
  4방위 = 4왕국 대응 가능 (서사적 상징)
    동방 청룡 → 고구려 (동방의 용)
    남방 주작 → 백제 (남방의 새)
    서방 백호 → 신라 (서방의 호랑이 — 변형)
    북방 현무 → 가야 (정립 필요)
  ※ 역사적 방위와 정확히 일치하지 않으므로 「상징적 대응」임을 명시

고구려 고분 벽화 별자리:
  덕흥리 고분 (408년): 천장 별자리 그림 확인
  강서대묘: 사신도(四神圖) + 별자리
  진파리 고분: 별자리 배치도
  → 콘텐츠 시각화 직접 참조 가능
```

## 주요 천문 이벤트 (콘텐츠 활용)

### 역사적 천문 기록 (삼국사기 천문지)

```
일식 기록 (서사 활용 가능):
  612년 (영양왕 23년): 수나라 침공 해 — 일식 발생
    → 살수대첩 전후 불길한 징조로 활용 가능
    → 「하늘이 경고한다」 (을지문덕 대사 가능)

  647년 (선덕여왕 16년): 선덕여왕 말기 — 정치적 불안
    → 비담의 난 전조로 활용

혜성 기록:
  삼국시대 혜성 출현 다수 기록
    → 왕조 교체·전쟁 전조의 전통적 해석
    → 「빗자루별이 나타났다」 — 민간 불안 묘사

유성우:
  대규모 유성우 기록 다수
    → 전장 하늘 연출에 활용 (시각적 드라마)

월식:
  기벌포 해전(676년) 전후 월식 기록 확인 필요
    → 해전 밤하늘 연출 가능
```

### 창작 활용 가이드

```
천문 이벤트 = 서사 전환점:
  원칙: 실제 천문 기록이 있는 해에는 해당 현상 반영
  허용: 기록이 없는 해에 일반적 천문 현상(유성·달무리) 추가 가능
  금지: 실제 기록과 모순되는 천문 현상 배치

  예시:
    ✅ 612년 일식 → 살수대첩 전야 불길한 하늘
    ✅ 가야 멸망 밤 유성우 → 창작 허용 (기록 부재)
    ❌ 645년 개기일식 → 기록에 없으면 배치 금지

선덕여왕 3대 예언 (천문 관련):
  1. 모란꽃에 향기가 없다 → 나비가 없다 → 남편이 없는 여왕
  2. 영묘사 옥문지에 개구리 → 백제군 매복 예측
  3. 자신의 죽음 예언 → 도리천에 묻어달라
  → 천문 직접 관련은 아니나, 「선견지명」이미지와 첨성대 연결
  → IP에서 선덕여왕의 천문 지식을 예언 능력의 근거로 확장 가능
```

## 첨성대 상세 고증

```
위치: 경주 인왕동 (현재 위치)
건립: 632~647년 (선덕여왕 재위)
구조:
  기단부: 정사각형 기단 (약 5.35m)
  원통부: 27단 원통형 석축 (362개 석재)
  정자석(井字石): 상부 정자 형태 석재 (관측 기기 거치대 추정)
  창(窓): 남동향 창 1개 (남중 고도 관측 가능)
  내부: 하부 막힘·상부 빈 공간 (사다리 설치 추정)

천문 기능 해석 (학설 병존):
  학설 1 — 관측대: 상부에서 맨눈 관측 (전통적 해석)
  학설 2 — 규표: 그림자 측정으로 절기 관측
  학설 3 — 상징물: 천문학적 수비학 기념물
  학설 4 — 복합 기능: 관측 + 규표 + 상징 복합

IP 적용:
  하린 스핀오프: 첨성대 건설 장면 포함
  게임: 첨성대 = 신라 기술 트리 특수 건물
  전시: 첨성대 1:1 스케일 VR 체험
  드라마: 선덕여왕이 첨성대에서 별을 보는 씬
    → 「별은 미래를 알려준다.」

수비학적 해석:
  362개 석재 ≈ 음력 1년 일수
  27단 ≈ 선덕여왕 (27대 왕)
  12단 기단 ≈ 12달
  24절기 대응 가능성
  → 창작에서 이 수비학을 시각적으로 강조 가능
```

## 역법 (시간 체계)

### 삼국시대 역법

```
태음태양력(太陰太陽曆):
  기본: 달(月)의 삭망 주기 기준 (29.5일)
  보정: 19년에 7번 윤달 삽입 (19년 7윤법)
  1년: 12개월 (354~355일) + 윤달 시 13개월

사용 역법:
  고구려: 중국 역법 수용 + 독자 운용
  백제: 원가력(元嘉曆, 443년~) → 대명력(大明曆)
  신라: 당나라 역법 수용 (선명력)

하루 시간 체계:
  12시진(十二時辰):
    子時(자시) 23:00~01:00 — 쥐
    丑時(축시) 01:00~03:00 — 소
    寅時(인시) 03:00~05:00 — 호랑이
    卯時(묘시) 05:00~07:00 — 토끼
    辰時(진시) 07:00~09:00 — 용
    巳時(사시) 09:00~11:00 — 뱀
    午時(오시) 11:00~13:00 — 말
    未時(미시) 13:00~15:00 — 양
    申時(신시) 15:00~17:00 — 원숭이
    酉時(유시) 17:00~19:00 — 닭
    戌時(술시) 19:00~21:00 — 개
    亥時(해시) 21:00~23:00 — 돼지

  → 대사 예: 「인시에 출전한다」 = 새벽 3~5시 출전
  → 게임: 시간대별 전투 보너스 (야습 = 자시~인시)
```

### 24절기

```
봄: 입춘·우수·경칩·춘분·청명·곡우
여름: 입하·소만·망종·하지·소서·대서
가을: 입추·처서·백로·추분·한로·상강
겨울: 입동·소설·대설·동지·소한·대한

IP 적용:
  게임 계절 턴: 4계절 × 6절기 = 24턴/1년 (세분화 시)
  드라마: 절기 자막 삽입 (시간 경과 표현)
  서사: 절기별 농업·군사 활동 연동
    → 봄 파종 → 여름 장마 → 가을 추수·전쟁 → 겨울 대비
```

## 기상·자연 표현 기준

```
한반도 4~7세기 기후:
  현재보다 약간 온난 (중세 온난기 전)
  고구려(요동·만주): 대륙성 기후 — 혹한(-20℃ 이하)·건조
  백제(충청·전라): 온대 습윤 — 온화·장마
  신라(경상): 온대 — 비교적 온화·해양 영향
  가야(낙동강): 온대 — 하천 주변 안개·습기

계절별 하늘:
  봄: 안개·황사(사막 황사 고대에도 존재) — 연한 하늘
  여름: 장마·적란운 — 어두운 하늘 + 번개
  가을: 맑고 높은 하늘 — 가장 밝은 별
  겨울: 건조·투명 — 별이 가장 선명

전투 기상 조건:
  살수대첩(612, 여름): 장마철 → 수공(水攻) 가능
  황산벌(660, 7월): 무더위 → 병사 체력 소모
  기벌포(676, 11월): 늦가을 → 서해 강풍·파도
  안시성(645, 여름~가을): 여름 시작 → 가을 퇴각 (조기 동절기)
```

## 자문 프로세스

```
A형 자문 (필수 — 핵심 천문 씬):
  대상: 첨성대 관련 씬, 일식/월식 연출, 역법 대사
  절차: 초고 → 천문학 감수 → 수정 → 최종 확인
  기준: 삼국사기 천문지 기록 대조

B형 자문 (권장 — 하늘 배경):
  대상: 전투·감정 씬 하늘 표현, 별자리 배경
  절차: 초고 → 천문학 확인 → 피드백
  기준: 계절·시간대에 맞는 천체 배치

C형 자문 (참고 — 일반 배경):
  대상: 일반 하늘 묘사, 날씨 표현
  절차: 가이드라인 문서 참조 (자문 불요)
  기준: 본 문서 기상 섹션 참조

참고 문헌:
  □ 삼국사기 천문지 (三國史記 天文志)
  □ 삼국유사 관련 기사
  □ 천상열차분야지도 (조선 — 고구려 계승 추정)
  □ 한국천문학사 (나일성, 2000)
  □ 첨성대 연구 논문집 (국립경주박물관)
  □ 고구려 고분벽화 천문도 연구
```
