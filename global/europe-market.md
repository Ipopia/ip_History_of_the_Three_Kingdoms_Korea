## 유럽 시장 개요

```
타깃 시장 우선순위:
  1순위: 프랑스 — K-콘텐츠 열기 높음, 만화/애니 문화 강함
  2순위: 독일 — 게임 시장 규모, 역사물 관심층 두터움
  3순위: 영국 — 영어권 + 아시아 문화 친화적 도시 다수
  4순위: 스페인·이탈리아 — 남유럽 K-팝 팬덤 성장세
  5순위: 스웨덴·네덜란드 — 스트리밍 초기 진입 거점

유럽 K-콘텐츠 현황 (2025 기준):
  K-드라마: 넷플릭스 유럽 Top 10 정기 진입
  K-팝: 프랑스·독일 콘서트 매진 사례 증가
  K-역사: 「킹덤」계기로 한국 역사물 유럽 관심 상승
  게임: PC 게임 유럽 판매 증가 (스팀 유럽 서버 비중)
```

---

## 프랑스 시장 전략

```
시장 특성:
  BD(방데시네) 문화 강국 — 그래픽 노블·만화 친화적
  한국 문화원 (Centre Culturel Coréen de Paris) 운영 중
  파리 한국 문화제 매년 성황
  애니메이션 페스티벌 (Annecy) 세계적 권위

진입 전략:
  웹툰/그래픽 노블 우선 진입 (BD 시장 친화성 활용)
  Annecy 애니메이션 페스티벌 출품
  France.tv·Canal+ OTT 제휴 협상
  파리 팝업 전시 (한국문화원 협력)

현지화:
  언어: 프랑스어 번역 필수 (자막·더빙 모두)
  더빙: 프랑스어 더빙 제작 권장 (프랑스 시청자 더빙 선호)
  고유명사: Romanization + 프랑스어 발음 표기 병기
    예: Goguryeo (고구려) → 발음 가이드 제공

파트너십 후보:
  Dargaud / Dupuis (BD 출판사) — 웹툰 프랑스판 출판
  France Télévisions — 드라마 방영 협의
  Fnac — 굿즈·소설 오프라인 유통
```

## 독일 시장 전략

```
시장 특성:
  유럽 최대 게임 시장 (gamescom 개최국)
  역사 콘텐츠 높은 관심 (독일 역사극 강세)
  오디오북·팟캐스트 문화 강함
  아시아 역사에 대한 학문적 관심층 두터움

진입 전략:
  게임 우선 진입 (PC/콘솔 스팀 독일 출시)
  gamescom 2026 출전 (부스 + 시연)
  역사 다큐 채널 협력 (ZDF·ARD 역사 프로그램)
  독일어 유튜브 채널 「K-History Explained」

현지화:
  언어: 독일어 번역 (자막 + 게임 현지화)
  게임 등급: USK 심사 (독일 게임 등급 기관)
  게임 폭력 수위: 독일 기준 적용 (혈액 표현 조정 옵션 제공)

파트너십 후보:
  Koch Media (독일 게임 퍼블리셔) — 물리 패키지 유통
  Carlsen Verlag (만화 출판사) — 웹툰 독일판
  Netflix DE — 드라마 스트리밍
```

## 영국 시장 전략

```
시장 특성:
  영어권 — 글로벌 콘텐츠 테스트 베드
  BBC·Channel 4 역사 드라마 강세 문화
  런던 K-팝 팬덤 규모 유럽 최대
  옥스퍼드·케임브리지 아시아학 연구 거점

진입 전략:
  넷플릭스 UK·Prime Video UK 스트리밍 우선
  런던 팝업 스토어 (한인타운 New Malden + 중심부)
  BFI(British Film Institute) 상영 이벤트
  BBC Asia 파트너십 협의

현지화:
  영어 자막: 이미 제작 (British English 표기 적용)
  고유명사: 표준 Romanization (영국 학계 기준)
  역사 주석: 영국 독자 대상 동시대 유럽 역사 비교 콘텐츠

파트너십 후보:
  BBC Studios — 공동 제작 또는 방영권
  Titan Comics (영국 만화 출판) — 웹툰 영어판
  SEGA Europe — 게임 유럽 퍼블리싱 협의
```

## 유럽 민감성 고려사항

```
역사 표현:
  고구려-수나라·당나라 전쟁: 중립적 묘사 유지
    (유럽 중국계 커뮤니티 반발 방지)
  일본 관련 표현: 백제-왜 관계는 「문화 교류」강조
  현대 정치 연결: 절대 금지 (남북 분단 등)

등급 기준:
  PEGI (유럽 게임 등급): 12+~16+ 목표
  영상: 각국 방송 등급 적용 (독일 FSK, 프랑스 CSA)

GDPR 준수:
  유럽 사용자 개인정보: GDPR 완전 준수
  쿠키 동의·데이터 저장 유럽 기준 적용
  디지털 콘텐츠·앱: EU 개인정보 보호 인증 필요
```
