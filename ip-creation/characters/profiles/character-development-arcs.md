## 캐릭터 발전 철학

```
핵심 원칙:
  「역사는 바꿀 수 없지만, 인간은 바꿀 수 있다」

4인 발전 구조:
  각자가 결핍(缺乏) → 시련(試鍊) → 선택(選擇) → 변화(變化)
  결핍: 캐릭터 초기 상태의 내적 공백
  시련: 역사적 사건과 충돌하는 개인 위기
  선택: 윤리적 딜레마 → 진짜 자아 발현 계기
  변화: 전보다 깊어진 인간, 그러나 역사는 진행

발전 원칙:
  ① 선형(線形) 성장 금지: 퇴보·실수·후회 필수 포함
  ② 역사와 개인의 충돌: 역사 흐름 ≠ 개인의 바람
  ③ 4인 상호 영향: 서로가 서로의 거울
```

## 고루 (高婁) 발전 아크

### 초기 상태 (시즌 1 전반)

```
나이: 26세
신분: 고구려 하급 무장 → 을지문덕 부장
결핍: 「나는 누구를 위해 싸우는가」
  - 전쟁 기계로 훈련된 삶 → 전쟁의 의미 모름
  - 부친 전사 → 원수 갚기 위해 무장이 됨
  - 복수심 = 동력, 그러나 동시에 공허함

초기 행동 패턴:
  명령에 충실, 감정 억제
  동료의 죽음에 무덤덤한 척
  을지문덕만을 스승으로 인정
```

### 시즌 1 발전 (612년 살수대첩)

```
전환점 1: 청야전술 명령 (EP07)
  마을 주민 소개(疏開) 명령 → 노인·아이 쫓아냄
  「나는 백성을 지키는가, 전략의 도구로 쓰는가」
  처음으로 을지문덕에게 질문 던짐

전환점 2: 살수 매복 (EP11)
  수나라 병사들의 죽음 → 동류 인간 공감
  「적도 누군가의 아들이었다」
  복수심 ≠ 전쟁의 의미 깨달음

시즌 1 말 상태:
  살수대첩 승리 → 영웅이 됨
  그러나 내면: 처음 품었던 복수심이 공허해짐
  새로운 질문: 「고구려는 이 승리로 무엇을 얻는가」
  성장 지표: 분노 → 질문
```

### 시즌 2 발전 (642~660년)

```
나이: 56세 (30년 후)
위기: 연개소문 쿠데타 (642년)
  영류왕 시해 → 고루가 섬기던 왕 암살
  연개소문의 권력 찬탈 → 충성 대상의 소멸

딜레마: 「연개소문을 따를 것인가, 거부할 것인가」
  따르면: 고구려 존속, 그러나 부당한 권력에 복종
  거부하면: 고구려를 떠남, 그러나 나라를 잃음
  선택: 내부에서 저항 → 안시성으로 배치 자원

안시성 88일 (EP05~08):
  성주와 함께 수비 → 노병의 용기
  고루의 무기: 더 이상 분노가 아닌 「지켜야 할 것」
  아랑·하린·니문의 소식 → 4인의 각자 길 확인

시즌 2 말 상태:
  안시성 방어 성공 → 당 태종 격퇴
  고루의 결론: 「왕국이 아닌 사람을 지킨다」
  성장 지표: 질문 → 확신
```

### 시즌 3 완결 (660~676년)

```
나이: 70세
충격: 고구려 멸망 (668년)
  「지켜야 할 것」이 사라짐 → 정체성 붕괴 위기
  고구려 부흥운동 참여 vs 포기 갈등

최종 선택: 부흥운동 참여 → 패배 예감하면서도
  「기억되지 않는 저항은 없다」
  니문에게 구전 부탁: 「강은 기억한다」

피날레:
  676년 기벌포 → 신라 통일 직전
  고루는 살아있지만 고구려는 없음
  기억의 강 씬: 4인 재회 → 고루의 마지막 말
  「내가 살았다는 것을, 강이 기억할 것이다」
  성장 완결: 분노 → 질문 → 확신 → 초월
```

## 아랑 (雅朗) 발전 아크

### 초기 상태

```
나이: 22세
신분: 백제 사택씨 귀족 여인 → 외교 사절단 수행원
결핍: 「아름다운 세상을 왜 전쟁이 부수는가」
  - 예술·문화 속에서 자란 백제 귀족 감수성
  - 전쟁 = 이해 불가, 아름다운 것의 파괴
  - 아버지의 외교 노선 추종 → 스스로 판단 미숙

초기 행동 패턴:
  아름다운 것을 보존하려는 집착
  직접 행동보다 설득 선호
  고루를 이해하려 하지만 거리감
```

### 시즌별 발전

```
시즌 1:
  백제-고구려 공동 외교 → 수나라 견제
  살수대첩 소식 → 전쟁의 실체 첫 대면
  「아름다운 백제가 살아남으려면 더러운 선택도 필요한가」

시즌 2:
  의자왕의 타락 목격 → 왕에 대한 환멸
  「왕의 나라 ≠ 백성의 나라」 깨달음
  나당연합 정보 입수 → 어떻게 할 것인가

시즌 3:
  황산벌 전투 → 계백의 죽음 목격
  백제 멸망 (660년) → 사비성 함락
  최대 위기: 아름다운 모든 것이 불타는 장면
  선택: 기억을 보존하는 자가 되겠다
  → 니문과 함께 기록·구전 작업
  완결: 「나라는 사라져도 문화는 사라지지 않는다」
```

## 하린 (霞麟) 발전 아크

### 초기 상태

```
나이: 20세
신분: 신라 화랑 → 선덕여왕 근위
결핍: 「나는 무엇을 위해 강한가」
  - 가장 빠르고 강한 화랑 → 승리에 집착
  - 여왕 섬기는 것 = 자신의 전부
  - 선덕여왕이 죽으면 자신은 무엇인가

시즌 1: 살수대첩 → 고구려의 강인함에 충격
시즌 2: 선덕여왕 사망 (647년) → 정체성 붕괴 위기
  「여왕 없는 나는 누구인가」
  진덕여왕 → 무열왕 섬기는 과정의 내면 갈등

시즌 3: 황산벌 → 기벌포
  관창의 희생 → 「죽음으로만 이기는가」에 의문
  기벌포 완승 → 신라 통일
  완결: 「강함은 누군가를 지키기 위해 존재한다」
```

## 니문 (尼文) 발전 아크

### 초기 상태

```
나이: 19세
신분: 가야 유민 음악가
결핍: 「사라진 것은 기억되어야 하는가」
  - 가야 멸망 (562년) 이전 세대의 후손
  - 음악으로만 살아남은 문화 계승자
  - 기억하는 것이 고통인지, 의무인지 모름

발전 특성:
  가장 수동적으로 시작 → 가장 적극적 기억자로 완결
  4인 중 유일하게 싸우지 않음 → 모든 것을 기록

시즌 1~3 아크:
  살수대첩 목격 → 소리로 기록
  고구려 멸망 → 고루의 마지막 부탁 수행
  「강은 기억한다」주제가 완성
  완결: 「나는 기억이 된다」
  → 4인 중 유일한 생존자, 모든 것을 노래로 남김

피날레:
  기벌포 이후 신라 땅에서 노래 부름
  고루·아랑·하린의 이야기를 가야금에 담아
  「이것이 강이 기억하는 방식이다」
```

## 4인 관계 발전 궤적

```
시즌 1 관계:
  고루-아랑: 대립 (전쟁 vs 문화)
  고루-하린: 경쟁 (고구려 vs 신라)
  고루-니문: 무관심 → 호기심
  아랑-하린: 동류 감각 (귀족 여성)
  아랑-니문: 공감 (아름다움을 지키려는 자)
  하린-니문: 보호자 본능 (화랑의 약자 보호)

시즌 2 관계:
  고루-아랑: 존중 (서로의 방식 이해)
  고루-하린: 경쟁 → 인정
  4인 모두: 각자의 왕국 위기 → 처음으로 서로 필요 인식

시즌 3 관계:
  고루 고립: 고구려 멸망 → 3인의 위로
  아랑 상실: 백제 멸망 → 고루·니문의 지지
  하린 갈등: 통일 신라의 승자 → 죄책감
  니문 완결: 3인의 이야기를 담아 노래로

최종 씬 (기벌포):
  4인이 강가에 모임
  역사상 처음이자 마지막 전원 집결
  각자 다른 방향으로 떠남 → 그러나 강은 흐름
```
