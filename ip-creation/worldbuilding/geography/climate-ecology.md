## 시대 기후 개요

삼국시대(BC37~AD935)의 한반도 기후는 현재와 유사하지만 **소빙하기 이전**으로 전반적으로 현대보다 약 1~2°C 온난했다. 삼림 피복률은 현대보다 높았고, 야생 동물 개체수도 풍부했다.

```
기후 특징 (4~7세기 기준):
- 대륙성 + 해양성 기후 혼합
- 사계절 명확 (현대와 유사)
- 강수량: 현대보다 10~15% 많음 (삼림 풍부)
- 겨울: 더 혹독 (특히 고구려 북부)
- 태풍: 백제 서해안 + 신라 동해안 연 2~3회
- 황사: 봄 (중국 내륙에서 유입)
```

## 왕국별 기후·지형 상세

### 고구려 — 대륙의 기후

```
영역: 만주 + 한반도 북부 (현 압록강~두만강 이북)
기후 유형: 대륙성 한대 기후 (북부) / 온대 기후 (남부)

계절별 특성:
봄 (3~5월):
- 해빙·녹설 → 강물 범람 (군사 이동 제약)
- 북방 초원 꽃 (무속 의례 계절)
- 황사 심함 (시야 제한 — 전투 불리)

여름 (6~8월):
- 단기 고온 다습 (장마 7~8월)
- 개마고원: 서늘 (이상 현상 — 7월에도 서리 가능)
- 강 수위 최고 (교량·도강 위험)

가을 (9~11월):
- 전투 최적기 — 건조·서늘·수확 후 병력 충원
- 단풍: 압록강 유역 황적색 절경
- 10월: 동맹(東盟) 제사 계절

겨울 (12~2월):
- 최저 -30°C (만주 북부)
- 압록강 결빙 → 도강 가능 (군사 위기/기회)
- 눈: 깊게 쌓임 → 개마무사 기동력 저하

군사적 의미:
- 최적 원정 시기: 9~10월 (수확 후, 결빙 전)
- 수나라 침공: 여름 장마 중 → 고구려 유리

드라마 연출:
→ 겨울 요동성 장면: 숨 연기·눈보라
→ 살수대첩: 9월 — 서늘하고 건조한 전투 환경
→ 광개토대왕 원정: 가을 단풍 배경
```

### 백제 — 강과 바다의 기후

```
영역: 한반도 서남부 (한강~금강~영산강 유역)
기후 유형: 온대 해양성 기후 (서해 영향)

계절별 특성:
봄 (3~5월):
- 서해에서 해무(海霧) 자주 발생
- 백마강 벚꽃 + 연꽃 개화 (백제 예술 영감)
- 황해 교역 재개 (겨울 항해 중단 후)

여름 (6~8월):
- 고온 다습 (장마 뚜렷)
- 금강 범람 위험
- 황해 항해 최적기 (계절풍 활용)
- 낙화암 주변: 안개 자욱 (신비로운 분위기)

가을 (9~11월):
- 수확 축제 계절
- 사비성 주변 단풍
- 황해 교역 마지막 시기 (10월 이후 항해 위험)

겨울 (12~2월):
- 상대적으로 온화 (서해 영향)
- 눈: 드물게 (한강 이남은 특히)
- 금강 결빙: 부분적 (완전 결빙은 드묾)

자연 특산물:
- 백마강 민물고기 (잉어·붕어·쏘가리)
- 부여 연꽃 (금동대향로 연꽃 문양의 실제 배경)
- 서해 조기·꽃게 (외교 선물 용도)
- 계룡산 약초 (인삼·오미자)

드라마 연출:
→ 사비 연회: 초가을 단풍 배경
→ 낙화암: 여름 안개 + 금강 수면
→ 황해 교역: 봄 순풍 출항 장면
```

### 신라 — 동해와 소백산맥의 기후

```
영역: 한반도 동남부 (경주 분지 + 소백산맥 동쪽)
기후 유형: 온대 대륙성 기후 (산맥 차단 효과)

계절별 특성:
봄 (3~5월):
- 경주 분지: 따뜻하고 건조 (산맥 차단)
- 동해에서 난류 유입 → 상대적 온화
- 황룡사 국화 개화 (의례 계절)

여름 (6~8월):
- 소백산맥 동쪽: 비 적음 (오호츠크해 기단)
- 첨성대 천문 관측 최적기 (맑은 밤 많음)
- 동해 해수욕·어업 풍성

가을 (9~11월):
- 경주 분지 선선하고 쾌청
- 소백산맥 단풍 (고구려보다 늦게 시작)
- 화랑 훈련·수련 최적기

겨울 (12~2월):
- 소백산맥 서쪽은 눈, 동쪽(경주)은 비교적 건조
- 동해 눈 많음 (동해안 한설)
- 첨성대 별 관측: 겨울 최적 (대기 맑음)

자연 특산물:
- 황금 (경주 금·은 광산)
- 동해 명태·청어 (식품·외교 선물)
- 경주 국화 (황룡사 의례용)
- 소백산 철광석 (철기 생산)

드라마 연출:
→ 첨성대 별 관측: 겨울 맑은 밤 (별 선명)
→ 선덕여왕 즉위: 봄 (황룡사 국화 배경)
→ 화랑 훈련: 가을 소백산맥 단풍
```

### 가야 — 낙동강과 남해의 기후

```
영역: 한반도 남부 (낙동강 유역 + 남해안)
기후 유형: 온대 해양성 기후 (남해 영향, 가장 온화)

계절별 특성:
봄 (3~5월):
- 가장 일찍 따뜻해짐 (삼국 중 최온화)
- 벚꽃·진달래 일찍 개화
- 낙동강 철 교역 재개

여름 (6~8월):
- 고온다습 (남해안 몬순)
- 태풍: 연 1~2회 직접 영향 (교역 중단)
- 낙동강 수위 최고 (철 운반 선박 활발)

가을 (9~11월):
- 가장 온화한 계절 (교역·농경 황금기)
- 남해 어업 풍성
- 철정 수출 최대 시기

겨울 (12~2월):
- 삼국 중 가장 온화 (영하 드묾)
- 낙동강 결빙 없음
- 대마도 항로 유지 가능 (겨울에도)

자연 특산물:
- 철광석 (가야 최대 자원)
- 낙동강 은어·연어 (수출품)
- 남해 전복·해산물 (왜 수출)
- 가야산 약초 (교역품)

드라마 연출:
→ 우륵의 강변 연주: 가을 (낙동강 단풍 + 선선함)
→ 철 교역 장면: 여름 (뜨거운 단조 + 습한 공기)
→ 가야 멸망: 겨울이 없는 땅 (계절과 운명의 역설)
```

## 야생 동물 도감

### 고구려 특산 동물

```
말(馬):
- 종류: 몽골계 단단한 소형마
- 특징: 내한성 강함 / 장거리 이동 적합
- 용도: 개마무사 군마 / 교역품
- 서식지: 개마고원·압록강 평원

범(호랑이):
- 한반도 전역이지만 고구려 북부 밀도 높음
- 산신 동반 동물 (신화적 의미)
- 왕실 수렵 대상 (용맹 상징)

독수리:
- 삼족오 신화의 실존 모델
- 요동 평원 상공 쌍독수리 → 전승 예조 (창작)
- 고구려 군기 문양 원형

늑대:
- 북방 유목민과 연계
- 고구려 북부 위협 + 경비 역할
- 말갈 병사들의 늑대 토템 (창작)
```

### 백제 특산 동물

```
봉황(불사조):
- 실존 아님, 신화적 존재
- 오동나무에 산다는 전설 → 백제 오동나무 숲 [창작]

학(두루미):
- 백마강 주변 서식
- 귀족 정원 사육
- 백제 도기·금속 문양의 빈번한 모티프

잉어:
- 금강·백마강 특산
- 백제 왕실 연못 사육 (귀족 식품)
- 비단잉어 → 외교 선물

사슴:
- 부여 부근 밀집 서식
- 사슴 뿔 약재 (교역품)
- 백제 벽화 모티프
```

### 신라 특산 동물

```
천마(天馬):
- 신화적 존재 / 실존 모델: 제주 흑마
- 신라 천마총 그림의 원형
- 왕실 전용 (민간 소유 금지 창작 설정)

매(鷹):
- 신라 귀족 매사냥 문화
- 화랑 훈련에 매 사육 포함
- 적 정찰 용도 [창작]

거북이:
- 동해 앞바다 + 낙동강 하구
- 신라 신화에서 왕의 수호 (처용 설화)
- 귀갑(龜甲) → 점복 도구
```

### 가야 특산 동물

```
왜가리:
- 낙동강 전 유역 서식
- 우륵의 가야금 소리가 왜가리를 부른다는 전설 [창작]
- 가야 문양 모티프

이무기:
- 낙동강 깊은 곳 전설의 존재
- 실존 모델: 대형 구렁이
- 가야 멸망 전야 이무기 출현 전설 [창작]

가오리:
- 남해 특산
- 왜와의 교역 기념 선물
- 가야 가죽 공예 재료
```

## 식물·작물 세계관

### 왕국별 특산 식물

```
고구려:
- 주식: 기장·조·콩 (냉량 기후 적합)
- 특산: 인삼(人蔘) — 최고급 교역품
- 약용: 오미자·당귀·황기
- 목재: 소나무·낙엽송 (성벽 건축)

백제:
- 주식: 쌀·보리 (온난한 금강 유역)
- 특산: 연꽃 (금동대향로·의례용)
- 과일: 배·복숭아 (사비성 정원)
- 향료: 오동나무 (봉황 신화 연결)

신라:
- 주식: 쌀·콩
- 특산: 국화(菊花) — 황룡사 의례용
- 약용: 경주 소금 + 동해 미역·다시마
- 목재: 참나무 (황룡사 9층탑 건축)

가야:
- 주식: 쌀·기장 (비옥한 낙동강 유역)
- 특산: 가야산 차(茶) — 원시 녹차
- 과일: 감·무화과 (온난한 남해안)
- 약용: 참나리·맥문동
```

## 기후와 전쟁 연동

### 계절별 전쟁 전략

```
봄 (해빙기):
- 강 범람 → 도강 불가
- 공격 불리 / 방어 유리
- 보급 재건 시기

여름 (장마기):
- 진흙탕 → 기병 약화 (보병 우세)
- 전염병 위험 (대군 집결 시)
- 살수대첩: 장마 후 수위 높을 때 활용

가을 (황금기):
- 수확 완료 → 보급 충분
- 기병 기동 최적 (건조·단단한 땅)
- 삼국 주요 전투 대부분 가을 발생

겨울 (결빙기):
- 압록강 결빙 → 수나라·당나라 도강 가능
- 고구려 최대 군사 위기 계절
- 산성 농성전 유리 (눈으로 접근 제한)
```

### 날씨 이벤트 (게임 연동)

```
랜덤 날씨 이벤트:
1. 황사 — 시야 -50%, 원거리 유닛 약화 (봄)
2. 장마 — 이동력 -30%, 기병 페널티 (여름)
3. 태풍 — 해상 루트 차단 (여름~초가을)
4. 첫서리 — 보급 감소 시작 경보 (가을)
5. 압록강 결빙 — 고구려 북부 도강 가능 (겨울)
6. 봄 해빙 — 강 도강 불가 (2~3턴 제약)

왕국별 날씨 적응:
고구려: 혹한 패널티 없음 / 황사 패널티 없음
백제: 장마 패널티 없음 / 해상 날씨 적응
신라: 황사 패널티 없음 / 동해 항해 적응
가야: 태풍 패널티 없음 / 온난한 기후 패시브
```

## 환경 미학 — 아트 가이드

### 계절별 배경 팔레트

```
고구려 봄: 회청·연두·황사 갈색
고구려 여름: 진녹·청·강회색
고구려 가을: 황적·단풍·철흑
고구려 겨울: 설백·빙청·연기색

백제 봄: 연분홍·새연두·해무白
백제 여름: 금녹·강청·연무
백제 가을: 금황·주홍·진갈색
백제 겨울: 은회·연갈·강물청

신라 봄: 황금·옅은 노랑·연분홍
신라 여름: 하늘청·짙은 녹·별빛
신라 가을: 국화색·진황·보라
신라 겨울: 새벽灰·별빛·설백

가야 봄: 연두·토황·봄빛
가야 여름: 철색·열기·강물청
가야 가을: 토황·낙동강·단풍
가야 겨울: 온화灰·강청·철색
```

### 대표 배경 장면

```
고구려:
- 압록강 겨울 결빙 (말발굽 자국·눈)
- 요동성 봄 안개 속 (새벽 정찰)
- 개마고원 가을 단풍 (원정대 행군)

백제:
- 금강(백마강) 여름 안개 (사비성 아침)
- 낙화암 절벽 + 강 (어느 계절이든)
- 황해 봄 출항 (교역선·계절풍)

신라:
- 첨성대 겨울 밤 (별빛 가득)
- 경주 분지 가을 (황금빛 들판)
- 동해안 여름 (화랑 수련)

가야:
- 낙동강 가을 강변 (우륵 연주)
- 김해 여름 철 단조 현장 (열기·불꽃)
- 남해 봄 교역 출항 (왜행 선박)
```
