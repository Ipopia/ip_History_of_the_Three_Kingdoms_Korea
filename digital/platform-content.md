```
  - 넷플릭스 오리지널 다큐 「고구려의 전쟁」검토

  - 영어·일본어·중국어 자막 제공

콘텐츠 규격:
드라마: 4K HDR / Dolby Atmos
애니: 1080p / 스테레오 + 5.1채널
썸네일: 16:9 기본 / 2:3 모바일 최적화
```

## 숏폼 콘텐츠 전략

```
틱톡 / 유튜브 쇼츠 / 인스타그램 릴스 통합 전략:

포맷:
길이: 15~60초
세로형: 9:16
텍스트 오버레이: 핵심 정보 자막 (한/영)
BGM: OST 클립 활용 (권리 내부 보유)

시리즈 콘텐츠:
[오늘의 삼국 역사] — 매일 15초
  - 역사 사실 1개 + 캐릭터 일러스트
  - 예시: 「오늘 612년, 을지문덕이 살수에서 수나라 30만을 수장시켰다」

[삼국 퀴즈 60초] — 주 3회
  - 역사 퀴즈 4지선다
  - 정답 발표 + 해설

[왕국 비교] — 주 1회
  - 고구려 vs 백제 vs 신라 vs 가야 비교 카드
  - 예시: 「4왕국의 수도, 어디가 제일 클까?」

[팬아트 feature] — 주 1회
  - 팬아트 타임랩스 편집 + 작가 소개

바이럴 챌린지:
#왕국선택챌린지: 내 왕국 선언 + 이유 15초 영상
#살수챌린지: 강물 관련 영상 + 태그 (여름 시즌)
#가야금챌린지: 악기 연주 영상 + 태그 (니문 연동)
```
