## 고구려 스핀오프

### 「광개토대왕 — 정복의 계절」

```
미디어: OVA 2부작 (각 45분) + 단행본 만화
시대: 391~413년 (광개토대왕 재위 전 기간)

스토리 개요:
17세에 즉위한 고구려 19대 왕 담덕(談德).
아버지 고국양왕의 죽음 이후 왕위에 오른 젊은 왕이
22년간 정복 군주로 성장하는 이야기.

에피소드 1 「첫 번째 전쟁」:
즉위 첫해, 백제 진사왕과의 전쟁.
담덕은 아직 경험 없는 왕이다.
을지문덕의 선조가 조연으로 등장 (고루와 연결).

에피소드 2 「광개토의 이름」:
「광개토(廣開土)」— 영토를 넓게 개척한다는 뜻.
이 묘호(廟號)가 붙여지는 순간.
마지막 전쟁, 그리고 38세의 죽음.

핵심 주제:
정복의 영광 vs 정복의 대가
왕이 된다는 것 — 고독과 책임
고구려가 「정복의 나라」가 된 역사적 의미

메인 시리즈 연결:
고루가 을지문덕에게 광개토대왕 이야기를 듣는 장면과 연동
→ 「우리는 그 분의 후예다」
```

### 「을지문덕 — 살수 이전」

```
미디어: 웹소설 20화
시대: 562~612년 (을지문덕 청년기~살수대첩 전)

스토리 개요:
을지문덕이 어떻게 고구려 최고 전략가가 되었는가.
아버지는 누구였는가. 어떻게 문무를 겸비했는가.
수나라가 고구려를 1차·2차 침략할 때 그는 무엇을 했는가.

창작 방향:
역사 기록 없는 을지문덕의 성장 과정 → 창작 극대화
살수대첩의 전략이 어디서 비롯되었는지 「기원」이야기
그를 을지문덕으로 만든 스승과의 만남
```

## 백제 스핀오프

### 「소서노 — 나라를 세운 여자」

```
미디어: 단편 소설 + OVA 1편 (60분)
시대: BC 18년 전후 (백제 건국기)

스토리 개요:
역사 기록 속 소서노(召西奴).
온조의 어머니이자 백제 건국의 실질적 주역.
고구려에서 탈출, 위례성에 나라를 세우다.

소서노의 관점:
고구려 주몽의 아내였다가 버려진 여인
두 아들 비류·온조를 이끌고 남하
비류가 실패하고 온조가 성공하는 과정을 어머니로서 겪다

핵심 주제:
건국의 이면 — 화려한 건국 신화 뒤의 피와 눈물
어머니의 희생 — 역사에서 지워진 여성 건국자
아랑의 정체성과 연결: 「백제를 만든 것은 여자였다」
```

### 「무령왕 — 바다의 왕」

```
미디어: 게임 DLC 스토리 + 웹소설 10화
시대: 501~523년 (무령왕 재위)

스토리 개요:
일본서기에도 기록된 백제 무령왕 (斯摩王).
무령왕릉 발굴(1971년) — 실제 지석(誌石) 발견으로 유일하게
신원 확인된 삼국시대 왕.

스토리:
가야계·왜계 혈통을 가진 무령왕의 정체성
일본과의 외교 — 아직기·왕인의 후예
바다를 통한 동아시아 교역 제국 건설

아랑 선조 연결:
무령왕 시대 문서관 집안이 아랑 가문의 기원
「우리 집안은 그때부터 백제의 역사를 기록했다」
```

## 신라 스핀오프

### 「화랑세기 — 미실의 시대」

```
미디어: 단행본 만화 3권
시대: 6세기 후반 (진흥왕~진평왕)

스토리 개요:
화랑세기(花郞世記) — 김대문 저서 (현재 필사본만 존재, 진위 논쟁)
화랑 제도의 실질적 창시자 미실(美室).
신라 왕실 권력의 핵심에 있던 여성 정치가.

미실의 이야기:
화랑 제도를 만든 배경
세 명의 왕을 섬기며 권력을 유지한 방법
선덕여왕의 선조가 극복해야 할 「과거」로 묘사

하린 연결:
하린의 스승 계보가 미실 시대 화랑까지 연결
「화랑의 근원을 알아야 화랑을 이해한다」

주의:
화랑세기 진위 논쟁 → 「창작」명시 필수
역사 사실과 소설적 상상의 경계 명확히
```

### 「선덕여왕 — 별을 보는 사람」

```
미디어: 단편 소설 + 유튜브 미니시리즈 5화 (각 10분)
시대: 선덕여왕 재위 전(공주 시절) ~ 즉위 초기

스토리:
어린 선덕 공주가 처음으로 첨성대를 구상하는 순간
「모란꽃 향기 없음」예언 사건의 선덕 시점 서술
왕위 계승 논의에서 받은 압박과 극복
여왕 즉위 전날 밤의 독백

미디어 특성:
유튜브 미니시리즈: 선덕여왕 독백 중심 (모노드라마)
애니메이션 스타일: 수채화 → 감성적 서정
SNS 바이럴 목적
```

## 가야 스핀오프

### 「수로왕 — 구지봉의 노래」

```
미디어: OVA 1편 (45분) + 단편 소설
시대: 42년 (가야 건국)

스토리:
구지가(龜旨歌) — 「거북아 거북아 머리를 내놓아라……」
수로왕이 하늘에서 내려온다는 신화
허황옥(許黃玉) — 인도 아유타국 공주와의 결혼

역사 vs 신화:
수로왕 신화 = 인도·동남아 해상 교역 루트의 기억?
허황옥 이야기 = 가야의 국제적 기원?
학술적 논의를 판타지로 승화

니문 연결:
구지가를 가야금으로 재현하는 니문
「이 노래가 우리 왕국의 시작이었다」
```

### 「우륵 — 가야금의 탄생」

```
미디어: 단행본 만화 2권
시대: 6세기 (우륵 활동기)

스토리:
우륵이 가야금 12현을 만드는 과정
가야의 멸망을 예감하며 신라로 귀화를 결심하는 여정
진흥왕에게 가야금을 선보이는 장면
가야금 12곡 각각의 탄생 이야기

니문 연결:
우륵의 마지막 제자가 니문의 선조
12곡 중 마지막 곡만 전해지지 않는다
→ 니문이 그 12번째 곡을 완성하는 것이 메인 시리즈

주제:
예술가는 나라보다 오래 산다
문화 유산의 전승과 책임
```

## 크로스오버 스핀오프

### 「4인의 만남 — 장안에서」

```
미디어: 단편 소설 + 웹툰 3화
시대: 643~644년 (EP.10 장안 장면 확장)

스토리:
고루(고구려 사신), 하린(신라 김춘추 수행원)이
장안에서 우연히 만나는 3일간의 이야기.
아랑의 편지가 하린을 통해 고루에게 전해진다.
니문의 가야금 소리가 장안에서 들린다 (우연의 일치).

콘셉트:
4인이 같은 공간에 처음으로 모이는 순간
각자 다른 이유로 장안에 온 4인
「적국의 사람」이지만 「같은 시대의 사람」

수익 모델:
팬 수요 최고 — 크로스오버 콘텐츠
웹툰 유료 단독 에피소드 (2,000원)
```
