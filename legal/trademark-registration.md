## 상표 등록 전략 개요

```
목적:
  1. IP 핵심 자산 법적 보호
  2. 유사 상품·무단 복제 차단
  3. 글로벌 라이선싱 기반 확립
  4. 투자자·파트너사 신뢰 확보

등록 우선순위:
  Priority 1 — 출시 전 필수 (D-180 이전)
  Priority 2 — 출시 동시 (D-Day)
  Priority 3 — 사업 확장 시 추가 등록

담당 기관:
  국내: 특허청 (KIPO)
  미국: USPTO
  일본: JPO
  EU: EUIPO
  중국: CNIPA
  국제: WIPO 마드리드 협정 (국제 일괄 등록)
```

## Priority 1 — 핵심 상표 등록

### KR-TM-001: 「삼국(三國)」

```
등록 대상:
  한글: 삼국
  한자: 三國
  병기: 삼국(三國)

지정 상품·서비스 (니스 분류):
  9류: 소프트웨어·게임·앱·전자 출판물
  16류: 출판물·서적·만화·스티커
  25류: 의류·코스튬·악세서리
  28류: 완구·피규어·게임기기
  41류: 오락 서비스·교육·공연·영상 제작

출원 기한: Priority 1 (출시 D-180)
예상 비용: 약 200만원 (국내 전 분류)
주의: 「삼국지」「삼국시대」는 보통 명칭 — 식별력 강화 필요
  → 「삼국(三國) IP」또는 로고와 결합 출원 권장
```

### KR-TM-002: 「강은 기억한다」

```
등록 대상:
  한글: 강은 기억한다
  영어: THE RIVER REMEMBERS

지정 분류: 9·16·25·28·41류 (동일)

출원 기한: Priority 1
식별력: 높음 (조어적 표현 — 등록 가능성 높음)
활용: 핵심 슬로건 = 상업적 가치 최고
```

### KR-TM-003: 캐릭터명 4종

```
등록 대상:
  ① 고루(高婁) / Goru
  ② 아랑(阿郞) / Arang
  ③ 하린(夏麟) / Harin
  ④ 니문(尼文) / Nimun

지정 분류: 9·16·25·28·41류
출원 방식: 한국어 + 영어 병행 출원
주의: 「아랑」은 전통 설화 존재 — 선행 상표 조사 필수
```

### KR-TM-004: 로고 상표

```
등록 대상:
  삼국(三國) 공식 로고 (도형 + 문자 결합)
  삼족오 심볼 (도형 단독)
  4왕국 엠블럼 각각 (4종)

등록 유형: 도형 상표
출원 기한: Priority 1
특이사항: 삼족오 = 역사 유물 문양이나 현대적 재해석 버전은 등록 가능
```

## Priority 2 — 출시 동시 등록

### 국제 상표 등록 (마드리드)

```
마드리드 협정 국제 출원:
  기준국: 대한민국 (KIPO 기본 출원)
  지정국:
    미국 (US): 15류·25류·28류·41류
    일본 (JP): 전 분류
    EU (EM): 전 분류
    중국 (CN): 9류·16류·25류·28류 (문화 콘텐츠 41류 별도)
    싱가포르 (SG): 글로벌 거점 등록

예상 비용: 약 2,000만원 (전 지정국 합산)
소요 기간: 국제 등록 완료까지 12~18개월
  → 출시 전 D-180 출원 = 출시 시점 심사 진행 중
```

### 중국 별도 대응

```
중국 특이사항:
  마드리드 경유 + CNIPA 직접 출원 병행 권장
  이유: 중국 내 선점 출원 위험
    「삼국」관련 중국 상표 선점 가능성 → 조기 출원 필수

중국 출원 전략:
  ① 핵심 상표 긴급 출원 (D-360 이전)
  ② 현지 중국어 표현도 추가 등록:
     「三国：江水铭记」(간체) — 중국 출시 슬로건
  ③ 현지 법률 사무소 선임 필수
```

## 저작권 등록

```
저작권 등록 대상:
  ① 스토리 바이블·시놉시스 (어문 저작물)
  ② 캐릭터 디자인 시트 (미술 저작물)
  ③ 음악 OST 전곡 (음악 저작물)
  ④ 게임 소프트웨어 (컴퓨터 저작물)
  ⑤ 로고·엠블럼 (미술 저작물)

국내 등록:
  한국저작권위원회 저작권 등록
  비용: 건당 30,000~100,000원

해외:
  미국: 미국 저작권청 (LOC) 등록 — 소송 시 유리
  일본: 불요 (베른협약 자동 보호)
  중국: 국가판권국 등록 권장 (집행력 강화)

중요:
  저작권 자동 발생 (등록 불요)
  → 단, 등록 시 증거력 강화 + 소송 손해배상 유리
```

  무단 사용 → 내용증명 발송 → 협의 → 소송 단계별 대응
  선점 상표 → 이의신청 or 무효심판 청구

도메인 선점 현황:
  samguk-official.com → 선점 필수 (D-180 이전)
  threekingredoms.com → 확인 필요
  samguk.jp / samguk.cn → 각국 담당자 확인

## 역사 유물·문화 관련 주의사항

```
역사적 공공 영역:
  삼국시대 역사 사실 = 공공 영역 (상표 등록 불가)
  실존 역사 인물명: 단독 출원 불가
    (을지문덕·계백·선덕여왕 = 역사 공공 영역)
  → 창작 캐릭터(고루·아랑·하린·니문)만 등록 가능

박물관 협약:
  국립중앙박물관·부여박물관 등 유물 이미지 활용 시
  → 별도 사용 허가 계약 필수
  → 저작권 없는 유물도 박물관 촬영분 = 박물관 권리 존재

유사 상품:
  「가야금」「화랑」= 보통 명칭 (단독 등록 불가)
  → 디자인·로고와 결합하여 출원
```
