## 가야 핵심 연대기

```
BC 42: 금관가야 건국 전설 (수로왕)
1세기~: 철정 생산·수출 → 동아시아 교역 장악
3~4세기: 가야 전성기 — 낙동강 유역 소국 연맹
400: 광개토대왕 남정 → 가야 세력 약화
532: 금관가야 신라에 투항 (구형왕·김구해)
562: 대가야 신라 진흥왕에 멸망 → 가야 연맹 완전 소멸 [★ IP 핵심]

가야 음악:
  551년: 우륵 신라 진흥왕에 귀순 → 가야금 12곡 헌상
  → 니문의 정신적 선조 설정의 역사적 근거

IP 설정:
  니문 = 562년 이후 가야 유민 3~4세대
  가야 철기 문화 → 낙동강 유역 소규모 공동체 유지
  니문 시대 (612~676년): 이미 가야 멸망 50~110년 후
```

## IP 주요 역사 사건 상세

### 살수대첩 (AD 612년)

```
배경:
  수양제 113만 대군 (실제 기록: 수서 기준)
  별동대 30만 5천 → 평양 직공
  고구려 : 방어군 + 게릴라 전술

을지문덕 한시:
  「신기묘산계(神機妙算計) / 천문지리지(天文地理知) ...」
  → 살수대첩 직전 수나라 우중문에게 보낸 시
  → IP에서 고루가 암송하는 장면 등장

전과:
  수나라 별동대 30만 5천 → 살수 이후 2,700명 귀환
  수나라 사실상 국력 소진 → 618년 멸망 원인
```

### 안시성 전투 (AD 645년)

```
배경:
  당태종 이세민 직접 지휘 + 10만 여 대군
  요동 방어선 돌파 → 안시성 포위

성주 양만춘 (楊萬春):
  성명: 조선시대 문헌 기록 (삼국사기에는 익명)
  88일 수성 → 당나라 혹한 전 철수 결정

당태종 눈 부상 전설:
  일부 문헌: 안시성 활에 눈 맞았다는 기록
  학계: 불확실 — IP 창작 연계 시 [창작] 표기 필요
```

### 황산벌 전투 (AD 660년 7월 9일~10일)

```
배경:
  김유신 5만 vs 계백 5,000 (→ 최후 500)

관창 (官昌) 나이:
  삼국사기: 「나이 16세」명기
  IP 준수: 16세 설정 (아역 캐스팅 고려)

4전 4승 후 5차:
  계백 4번 신라군 격퇴 (역사 기록 일치)
  관창 1차 포로→방면→2차 돌격→전사 (삼국사기 기록)
  계백 최후 전투 → 신라군 결집 → 백제 전멸
```

### 기벌포 해전 (AD 676년)

```
배경:
  신라 수군 vs 당나라 설인귀 함대
  나당전쟁 최종 결전

22전 22승:
  삼국사기 기록: 「22번 싸워 4천 명 베었다」
  IP 준수: 22전 22승 설정 유지

의의:
  당나라 한반도 지배 포기 → 철수
  676년: 삼국통일 완성 (역사 공인)
  → IP 피날레 시간 배경
```

## 역사 고증 주의사항

```
민감 사항:
  고구려 귀속 문제 (한국 vs 중국 동북공정)
    → IP 입장: 「한국 역사의 일부」명확히
    → 중국 버전: 영토 표시 수정 별도 제작

  가야-일본 관계 (임나일본부설)
    → 절대 연관 짓지 않음
    → 「가야 문화가 일본에 전해졌다」수준

  낙화암 사건 연출
    → 직접 투신 묘사 자제
    → 역사 감수 필수

창작과 역사 구분 표기:
  역사 사실: 그대로 사용
  창작 설정: [창작] 각주
  불명확 역사: [학계 논쟁] 각주
```
