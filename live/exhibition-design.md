## 전시 전략 개요

```
전시 유형:
  A. 순회 전시: 국내외 주요 도시 순회 (2027~2028)
  B. 상설 전시: 테마파크 연계 (2028+)
  C. 팝업 전시: 이벤트·론칭 연계 (2026~)

포지셔닝:
  역사 교육 + 엔터테인먼트 = 「에듀테인먼트 전시」

목표 관람객:
  1차: 삼국 IP 팬덤
  2차: 역사 관심 일반인 (20~50대)
  3차: 가족 단위 (어린이 체험 섹션 운영)

매출 목표:
  순회 전시 1회 (3개월): 입장 + 굿즈 = 10억원
  글로벌 (도쿄·방콕): 각 7억원
```

## 메인 순회 전시 구성

### 전체 구조

```
전시명: 「강이 기억하는 것들 — 삼국의 흔적」
총 면적: 1,500㎡ / 관람 시간: 60~90분
입장: 시간대 예약제 (시간대 50명 이하)

섹션 구성:
  Section 0: 프롤로그 홀 (엔트런스)
  Section 1: 고구려 — 북방의 철과 하늘
  Section 2: 백제 — 금강의 꽃과 바람
  Section 3: 신라 — 황금의 별과 빛
  Section 4: 가야 — 사라진 소리와 기억
  Section 5: 살수 — 강이 기억한다 (메인)
  Section 6: 삼국 IP 세계 (팬덤 공간)
  Section 7: 에필로그 + 굿즈숍
```

### Section 0: 프롤로그 홀

```
면적: 150㎡
인스톨레이션:
  「강은 기억한다」LED 워터 커튼 (물처럼 흐르는 텍스트)
  바닥: 살수 강물 프로젝션 매핑 (걸으면 물결 이펙트)
  BGM: 가야금 솔로 — 앰비언트

입구 텍스트:
  「나라가 사라져도 강은 흐른다.
   이름이 흩어져도 강은 기억한다.
   우리가 여기 있었다는 것을.」

오디오 가이드: QR 코드 → AI 동반자 4인 중 선택
```

### Section 1: 고구려

```
면적: 200㎡ / 테마: 군청색 #2F4F7F / 저조도 파란빛

전시 요소:
  ① 개마무사 실물 크기 조형물 (포토 포인트)
  ② 고구려 벽화 복원 파노라마 (길이 10m, 인터랙티브)
  ③ 안시성 1:100 모형 + LED (88일 방어전 연출)
  ④ 살수대첩 전략 지도 + 7번 후퇴 애니메이션
  ⑤ 고루 VO 오디오 스테이션
```

### Section 2: 백제

```
면적: 200㎡ / 테마: 황금 #B8960C / 따뜻한 황금빛

전시 요소:
  ① 사비성 왕궁 재현 + VR 뷰어 (360도 체험)
  ② 백제 금동대향로 정밀 복제품
  ③ 백제 교역 인터랙티브 지도
  ④ 황산벌 마지막 날 4면 영상 + 아랑 VO
```

### Section 3: 신라

```
면적: 200㎡ / 테마: 금색 #FFD700 / 밝은 황금빛

전시 요소:
  ① 신라 금관 복제품 갤러리 (6종)
  ② 화랑 무예 5종 인터랙티브 미니게임
  ③ 첨성대 1:20 모형 + AR 천문 관측 체험
  ④ 선덕여왕 의상 대여 포토존
```

### Section 4: 가야

```
면적: 150㎡ / 테마: 황토 #C8A96E / 황혼빛

전시 요소:
  ① 가야금 체험 스테이션 (12현 4대 — 기초 연주)
  ② 가야 12국 지도 + 각 소국 특산 전시
  ③ 우륵 기념 공간 + 가야금 12곡 돌 새김
  ④ 방문객 메모 보드: 「내가 기억하고 싶은 것」
```

### Section 5: 「살수 — 강이 기억한다」

```
면적: 300㎡ / 몰입형 미디어아트 (하이라이트)

6면 프로젝션 (바닥·천장 포함):
  관람 회당 30명 / 10분 간격 입장

15분 프로그램:
  1분: 살수 강 역사 내레이션
  5분: 살수대첩 전투 전개 (에픽 영상)
  3분: 전투 후 강의 고요함
  6분: 「강은 기억한다」— 4인 VO + 가야금

바닥 효과:
  관람객 발밑 물결 이펙트 → 마지막 동시 파문 확산

엔딩 메시지:
  「이 강은 지금도 흐릅니다.
   당신도 기억의 일부입니다.」
```

### Section 6: 삼국 IP 세계

```
면적: 200㎡ / 팬덤 공간

전시 요소:
  ① 드라마 제작 비하인드 스크린 (4분 루프)
  ② 캐릭터 원화 전시 (ART-DIR 원본 스캔)
  ③ 게임 시연 스테이션 (10대)
  ④ OST 청음 부스 (4인용, 4왕국 테마)
  ⑤ 팬아트 갤러리 (공모전 수상작)
  ⑥ 왕국 선택 투표 → 실시간 집계 모니터
```

### Section 7: 에필로그 + 굿즈숍

```
굿즈숍 (전시 한정):
  아트북 (전시 작품 + 드라마 설정화): 15,000원
  엽서 세트 (4왕국 12장): 8,000원
  가야금 미니 키링: 5,000원
  전시 한정 에코백: 12,000원
  레플리카 미니 피규어 (개마무사): 25,000원
```
