## 개요

본 시트는 삼국(三國) IP의 주연 외 주요 조연 및 단역 인물 프로필을 정리한다. 역사적 인물과 창작 인물을 병기하며, 각 캐릭터의 서사 기능을 명시한다.

## 고구려(高句麗) 조연

### 1. 을파소 (乙巴素) — 고구려 재상

| 항목 | 내용 |
|------|------|
| 시대 | 고국천왕 재위기 (179~197 AD) |
| 신분 | 고구려 국상(國相) — 최고 재상 |
| 역사 | 삼국사기 기록, 진대법(賑貸法) 설치 주도 |
| 모티프 색 | 청회(#4A5568) + 백(#F5F5F5) |

**성격**: 원칙주의 행정가 + 백성 중심 실용주의
- 귀족 반발 무릅쓰고 빈민 구제 제도 관철
- 왕에 대한 충성보다 국가에 대한 충성 우선
- 대표 대사: *"왕의 나라가 아니라 백성의 나라다. 진대법이 없으면 고구려도 없다."*

**서사 기능**: 고구려 내정·복지 정책 설명, 귀족 vs 민중 갈등 구현

### 2. 명림답부 (明臨答夫) — 고구려 군주 시해자

| 항목 | 내용 |
|------|------|
| 시대 | 2세기 |
| 신분 | 고구려 연나부 귀족, 실권자 |
| 역사 | 차대왕을 시해하고 신대왕 옹립 — 삼국사기 |
| 모티프 색 | 심흑(#1A1A2E) + 혈홍(#8B0000) |

**성격**: 냉혹한 정치 현실주의자
- 폭군 제거라는 명분과 권력욕의 경계에 선 인물
- 113세까지 살았다는 전설 — 불멸의 노회한 책략가
- 대표 대사: *"왕을 죽인 것이 아니다. 폭군을 제거한 것이다. 그것이 어찌 역모인가."*

**서사 기능**: 고구려 정치 격변·귀족 권력의 양면성 표현

- 대표 대사: *"나는 바보라 불렸다. 그래서 더 열심히 했다. 그것이 전부다."*

**서사 기능**: 신분 제도 비판·계층 이동의 가능성·로맨스 서브 플롯

## 백제(百濟) 조연

### 6. 근초고왕 (近肖古王) — 백제 전성기의 왕

| 항목 | 내용 |
|------|------|
| 시대 | 4세기 (재위 346~375) |
| 신분 | 백제 13대 왕 |
| 역사 | 고구려 고국원왕 전사시킴, 일본 왜국 교류 |
| 모티프 색 | 금(#B8960C) + 호박(#FF7F00) |

**성격**: 정복군주 + 문화 외교의 선구자
- 동아시아 최강국 시기 백제를 이끈 팽창주의 왕
- 칠지도(七支刀)를 왜국에 하사 — 문화 외교의 절정
- 대표 대사: *"백제의 칼은 북으로 고구려, 동으로 신라, 서로는 바다를 건넌다."*

**서사 기능**: 백제 전성기 구현, 삼국 패권 경쟁의 중심축

- 대표 대사: *"신라가 배신했다. 그러나 백제는 그래도 꽃처럼 아름다워야 한다."*

**서사 기능**: 신라-백제 동맹 파기·관산성 비극·불교 문화 심화

## 외국(外國) 인물

### 15. 수양제 (隋煬帝) — 수나라 황제

| 항목 | 내용 |
|------|------|
| 시대 | 7세기 (재위 604~618) |
| 신분 | 수나라 제2대 황제 |
| 역사 | 고구려 3차 원정 실패, 살수대첩 패배 |
| 모티프 색 | 황(#FFD700) + 혈홍(#8B0000) |

**성격**: 오만한 제국주의자 — 패배가 예약된 대왕
- 113만 대군을 이끌고 고구려를 침략한 오만함
- 을지문덕의 전략에 참패 — 수나라 멸망의 원인
- 대표 대사: *"천하는 짐의 것이다. 고구려 따위가 어찌 저항하는가."*

**서사 기능**: 살수대첩 대결 상대·제국의 오만과 패배·고구려 영웅성 부각
