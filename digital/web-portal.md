## 핵심 페이지 설계

### 홈페이지

```
섹션 구성:
  [HERO] 풀스크린 영상 배경
    → 드라마 트레일러 자동 재생 (음소거 기본)
    → 「강은 기억한다 / THE RIVER REMEMBERS」슬로건
    → CTA: 「드라마 보기」「웹툰 읽기」

  [SECTION 1] 4왕국 소개
    → 가로 스크롤 / 왕국별 색상 배경
    → 호버 시 왕국 테마 음악 재생 (3초)

  [SECTION 2] 최신 소식
    → 신규 에피소드 / 굿즈 출시 / 이벤트 피드

  [SECTION 3] 캐릭터 스포트라이트
    → 이번 주 캐릭터 (요일 연동)

  [SECTION 4] SNS 피드
    → 인스타그램·유튜브 최신 콘텐츠

  [FOOTER]
    → 회사 정보 / 법적 고지 / 소셜 링크
```

### 캐릭터 상세 페이지

```
고루 캐릭터 페이지 예시:

레이아웃:
  좌측: 캐릭터 일러스트 (풀샷 + 표정 변화 호버)
  우측: 캐릭터 정보

정보 구성:
  이름: 고루(高婁) / Goru
  왕국: 고구려(高句麗)
  직위: 을지문덕 참모, 살수대첩 생존자
  성격: 과묵한 전략가 / 강직한 신념
  명대사: 「살수는 기억한다. 나도 기억한다.」

인터랙션:
  캐릭터 테마 음악 재생 버튼
  「고루가 사는 세상」왕국 연결
  관련 에피소드 목록 (드라마/웹툰)
  팬아트 보기 → 커뮤니티 연결

색상:
  배경: 고구려 색조 #2F4F7F
  텍스트: 백색 + 금속광
```

### 역사 아카이브

  → 인터랙티브 타임라인

  학생용 역사 퀴즈 시리즈
