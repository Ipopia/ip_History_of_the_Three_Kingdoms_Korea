## 4권 개요

```
권호: 제4권 「잿빛 강」
시대: 660년~668년 (백제 멸망~고구려 멸망)
분량: 380~400페이지 (원고지 1,500매)
POV: 4인 복수 시점 (장별 교차)
드라마 대응: 시즌 3 EP01~EP08

핵심 주제:
  「사랑하는 것을 잃은 자는 어떻게 살아가는가」
  백제·고구려 멸망 → 4인 각자의 상실 처리 방식

제목 의미:
  잿빛 강: 전쟁으로 재가 된 것들이 강에 흘러들어
         강의 색이 변해가는 이미지
         고루(군청)·아랑(황금)·하린(금색) 각자의
         색이 재로 변해가는 서사 상징
```

## 구성 개요

```
1부 「황산벌의 재」(1~7장) — 660년
  백제 멸망 서사 (아랑 시점 중심)

2부 「안시성 이후」(8~14장) — 660~661년
  고루의 고구려 존속 위기 인식

3부 「두 개의 강」(15~20장) — 661~668년
  고루·하린 첫 직접 대면 + 공동 전선

4부 「고구려는 지금」(21~25장) — 668년
  고구려 멸망 — 고루 최대 위기

에필로그 「잿빛 속의 소리」
  니문, 살아남은 기억 수집 시작
```

## 1부 「황산벌의 재」

### 제1장: 660년 봄, 사비성

```
POV: 아랑
시간: 황산벌 전투 직전

사비성의 분위기:
  의자왕의 향락 — 아랑이 목격하는 왕실의 부패
  나당연합 소식 → 귀족들의 탈출 준비
  아랑의 선택: 사비성에 남는다

내면 독백:
  「아름다운 것들이 있다. 금동대향로, 미래사 탑,
   어머니가 수놓은 자수. 이것들이 불타면
   나는 무엇이 되는가.」

복선:
  니문이 사비성에 잠시 머무름 → 아랑과 첫 만남
  「당신의 이름은 무엇입니까?」— 두 사람의 첫 대화
```

### 제4장: 황산벌

```
POV: 하린 + 아랑 (교차)

하린 시점 — 황산벌 전진:
  김유신 군 선봉 화랑 하린
  4번의 패퇴 → 관창의 결사 돌격 목격
  「16세 아이가 앞으로 갔다. 나는 왜 멈추었나.」

아랑 시점 — 사비성 관망:
  멀리서 들리는 전투 소리
  백제 장수들 하나씩 전사 소식 입수
  계백 전사 소식 → 아랑의 무너짐

두 시점 합류:
  황산벌이 끝났다. 백제가 끝났다.
  하린은 승자로 멈추고, 아랑은 패자로 무너진다.
  같은 사건을 보는 두 개의 눈
```

### 제7장: 사비성 함락

```
POV: 아랑

낙화암:
  궁녀들의 낙화암 장면 → 직접 묘사 아닌 소리·연기로 처리
  (잔혹 묘사 최소화 — 감성적 접근)
  아랑: 「그들이 날고 있다. 꽃처럼.」

금동대향로 반출:
  당나라 병사들이 가져가는 장면
  아랑: 「봉황이 날아가지 못하고 잡혔다.」

아랑의 결단:
  사비성을 떠난다
  손에 든 것: 어머니의 자수 한 조각
  「이것만은 빼앗기지 않겠다.」
```

## 2부 「안시성 이후」

### 제10장: 고구려, 645년 기억

```
POV: 고루
시간: 661년 — 안시성 전투 회고

플래시백: 645년 안시성
  당 태종 직접 원정 → 60만 군
  88일 수성 → 고루와 성주의 대화
  「우리가 이긴 것인가, 버틴 것인가.」

현재 661년:
  당나라 2차 원정 소식
  「안시성은 지켰다. 그러나 고구려는?」
  고루의 나이: 55세 — 몸이 무거워졌다

연개소문 사망 (666년) 복선:
  「막리지가 죽으면 고구려는 무엇으로 하나가 되는가.」
```

### 제14장: 연개소문의 죽음

```
POV: 고루
시간: 666년

연개소문 사망 후 권력 공백:
  세 아들 (남생·남건·남산) 분열
  남생의 당나라 투항 → 고루의 충격
  「나라를 지킨다는 것이 이런 것인가.」

고루의 선택:
  평양성 수비 합류
  「나는 나라를 지키는 자인가, 기억하는 자인가.」
  처음으로 두 가지가 다를 수 있음을 인식
```

## 3부 「두 개의 강」

### 제16장: 고루와 하린의 만남

```
POV: 고루
시간: 667년 — 전장 인근

첫 직접 대면:
  신라군 김유신의 진영 근처 고구려 정찰대
  하린과 고루, 중립 지대에서 우연히 조우
  서로 무기를 들지 않은 짧은 대화

대화 핵심:
  하린: 「당신들은 왜 계속 싸웁니까?」
  고루: 「당신들은 왜 우리를 치러 옵니까?」
  침묵 — 서로가 같은 질문을 하고 있음을 깨달음

고루 내면:
  적 신라 화랑 → 같은 하늘 아래 같은 고민을 하는 자
  「이 사람도 기억하려는 자일 것이다.」
```

## 4부 「고구려는 지금」

### 제22장: 668년 평양성 함락

```
POV: 고루
시간: 668년 가을

평양성 최후:
  나당연합군의 포위
  보장왕의 항복 결정 → 고루의 내면 붕괴
  「왕이 항복한다. 고구려가 항복한다.」

마지막 수성:
  고루 홀로 성벽에 남음
  「지금 이 순간을 기억하는 자가 있어야 한다.」
  니문에게 쪽지를 써 보냄: 「이 날을 기억해 다오.」

항복 장면:
  보장왕이 성문을 연다
  고루는 뒤돌아서지 않는다 — 강 쪽을 바라본다
  「강은 기억한다. 나도 기억한다.」
```

### 제25장: 4권 마지막

```
POV: 니문
시간: 668년 겨울

고루의 쪽지를 받은 니문:
  「고구려가 사라졌다. 고루 형이 보낸 마지막 말.」
  가야금을 꺼낸다
  아직 이름 없는 곡을 연주하기 시작한다

5권 복선:
  니문의 곡이 「기억의 강」원형이 됨
  멀리서 하린의 진영 불빛이 보임
  아랑의 소식이 들려옴 — 어딘가에서 살아있다
  고루는 — 아직 어딘가에 있다
```

## 에필로그 「잿빛 속의 소리」

```
POV: 니문 (1인칭 편지 형식)

「고루에게, 아랑에게, 하린에게.

 나는 기억합니다.
 고구려가 사라졌습니다.
 백제가 사라졌습니다.
 가야는 이미 오래전에 사라졌습니다.

 하지만 강은 흐릅니다.
 나는 이 강가에서 당신들의 이야기를 노래합니다.
 강이 기억하듯, 나도 기억합니다.

 — 니문, 668년 겨울」
```
