# 전투 액션 안무 가이드 — 삼국(三國) IP

**작성**: 아트&디자인본부 액션팀 (ART-ACTION)
**적용**: 삼국(三國) IP 드라마·애니메이션·웹툰·게임 전투 액션 연출 기준

## 액션 설계 철학

```
핵심 원칙:
  「전투는 캐릭터다」— 싸우는 방식 = 인물의 본질

  역사 고증 기반 실전 무술:
    한국 전통 무예 (택견·국궁·기마술)
    삼국시대 실전 검술 (호신술 아닌 전장 기술)
    무기별 물리적 특성 반영 (환두대도 vs 단검 vs 창)

  캐릭터별 고유 전투 스타일:
    전투 방식 = 성격·배경·심리 상태의 투영
    S1 vs S3: 같은 캐릭터도 성장에 따라 전투 변화

  시각적 차별화:
    4인이 같은 공간에서 싸워도 즉시 식별 가능
    왕국별 색채와 무기 = 화면 내 즉각 판독
```

## 캐릭터별 전투 스타일

### 고루 (高婁) — 고구려 무장

```
기본 무기: 환두대도 (직검, 날 70cm)
보조 무기: 투척용 단창 (상황별)
전투 유형: 지휘 전투 (개인 격투 < 부대 지휘)

동작 특성:
  [힘] 최우선 — 강한 단타, 최소 동작으로 최대 효과
  [경제성] 불필요한 움직임 없음 (에너지 절약)
  [직선] 우회하지 않고 직진 타격
  [침묵] 전투 중 대사 없음 (기합 없음)

시그니처 무브:
  「살수 차단」: 적의 공격선을 몸으로 차단 + 역타
  「기다림」: 적이 오게 만들고 카운터 — 을지문덕에게 배운 전술
  「한 방」: 긴 예비 동작 후 단일 강타 (암시 있는 필살기)

성장 변화:
  S1 (22세): 빠르고 공격적 — 젊은 무관의 에너지
  S2 (35세): 침착·계산적 — 전장 경험 축적
  S3 (50세+): 최소 동작·최대 위력 — 절제의 극치

연출 주의:
  고루 전투 = 화려함 배제
  「강하고 조용한」미학
  배경음: 칼 소리 + 바람 (음악 최소)
```

### 하린 (夏麟) — 신라 화랑

```
기본 무기: 신라 단검 (직검, 날 40cm) + 활 (기마 시)
보조 무기: 비상 시 단검 2자루 (양손)
전투 유형: 기동전 (속도·민첩·기습)

동작 특성:
  [속도] 최우선 — 적이 반응하기 전 끝냄
  [입체] 뛰고·구르고·벽을 활용 (3차원 전투)
  [연속] 단타가 아닌 연속 타격 콤보
  [감정] 전투 중 표정 변화 있음 (감정형 전투)

시그니처 무브:
  「화랑 돌격」: 말 위에서 활 + 하마 시 즉각 검 전환
  「관창의 기억」: 위험 순간 관창 생각 → 두 배 분노 출력
  「임전무퇴」: 후퇴 불가 돌격 — 부상에도 전진

성장 변화:
  S1 (15세): 충동적·감정적 — 자세 불완전하나 빠름
  S2 (25세): 기술 완성 — 속도 + 정확성
  S3 (36세): 화랑 정신 체화 — 죽음도 두려워하지 않는 안정감

대비 포인트 (고루 vs 하린):
  고루: 직선·침묵·힘
  하린: 곡선·감정·속도
  같은 전투에 등장 시 = 시각적 대조 극대화
```

### 아랑 (阿郞) — 백제 문서관

```
전투 원칙: 비전투 (직접 격투 없음)

예외 상황 (1회 한정):
  S2 위기: 자수 바늘로 적의 눈 찌름 (1회 허용)
  → 이후 트라우마로 남음 (아랑은 싸우는 인물이 아님)

비전투 생존 기술:
  [회피] 공간 파악 — 전투 공간에서 탈출 루트 계산
  [은신] 기둥·천·연기 뒤 숨기
  [속임] 죽은 척·기절한 척 (지능적 생존)

연출 지침:
  아랑이 전투 중 = 항상 위협받는 상황
  직접 싸우지 않음 = 캐릭터 일관성 최우선
  아랑의 용기 = 물리적 싸움 아닌 기록의 지속
  전투 씬에서 아랑 = 관찰자·증언자 포지션
```

### 니문 (尼文) — 가야계 음악가

```
전투 원칙: 비전투 (아랑과 동일)

예외 상황 (1회 한정):
  S1 위기: 가야금 케이스로 방어 (도구 방어 허용)
  → 음악가의 최후 수단

비전투 존재감:
  전투 씬에서 니문 = 부상자 돌봄·후방 지원
  가야금 연주 = 전투 전 사기 부여 (전장 음악가)
  「676」연주 = 전투 클라이맥스 BGM 기여

연출 지침:
  전투 장면 + 니문 가야금 연주 교차 편집 = 감동 극대화
  니문의 손 = 무기가 아닌 악기를 쥔 손
  단, 전투 중 니문 손에 피가 묻는 장면 허용 (전쟁의 비극)
```

## 주요 전투 연출 가이드

### 살수대첩 전투 (612년)

```
규모: 대형 전투 (수만 vs 수만)

연출 레이어:
  Layer 1 — 거시: 강물 범람 + 수나라군 혼란 파노라마
  Layer 2 — 중시: 고루와 고구려 부대 지휘
  Layer 3 — 미시: 을지문덕 클로즈업 (표정 + 손짓)

고루 전투 스타일 적용:
  개인 격투 최소화 (지휘관은 싸우지 않는다)
  「기다려라」명령 후 수문 개방 = 비물리적 승리
  고루의 마지막 검 한 번 = 전투 종료를 알리는 상징

음향:
  강물 범람 3D 서라운드 → 점진적 침묵 → 「강은 기억한다」
```

### 황산벌 전투 (660년)

```
규모: 5,000 vs 50,000

연출 컨셉: 수적 열세의 비극적 아름다움

하린 전투 스타일 적용:
  기마 돌격: 슬로우모션 + 음악 없음 (침묵의 용기)
  관창 첫 돌격 장면: 하린 POV — 작은 소년이 보임
  관창 전사 장면: 하린 표정 클로즈업 → 얼굴에 눈물 없음 (너무 충격)

계백 전투:
  「다섯 번」구조 — 승리 × 4 + 패배 × 1
  5차 전투: 슬로우모션 전환
  계백 최후: 카메라 멀리 → 먼지 속으로 사라짐 (직접 묘사 절제)

하린 vs 백제 장수 (창작):
  하린의 가장 격렬한 전투
  감정 최고조 (관창 전사 직후)
  전투 후: 하린 혼자 주저앉음 → 처음으로 울음
```

### 기벌포 해전 (676년)

```
규모: 해상 전투 (22전 22승)

연출 컨셉: 30년의 여정이 수렴되는 클라이맥스

4인 위치:
  고루: 신라 함대 지휘 (고구려인이 신라를 돕는 아이러니)
  하린: 최전선 전투
  아랑: 함선 위 기록 (마지막 전투를 기록)
  니문: 함선 후방 가야금 연주 (「676」시작)

22번째 승리 순간:
  당나라 마지막 함선 침몰
  4인 모두 함선 앞으로 나옴
  바다를 바라봄
  → 대사 없음
  → 니문 가야금만 지속
  → 고루: (속삭임) 「강은 기억한다.」
  → 암전
```

## 무기별 액션 물리학

```
환두대도 (고루):
  실제 무게: 1.2~1.5kg
  양손 또는 한손 사용
  특성: 무겁기 때문에 연속 동작 불리
  → 강타 1회 + 간격 (실전 반영)

단검 (하린):
  실제 무게: 400~600g
  한손 사용 + 다른 손 균형
  특성: 가벼워 빠르나 관통력 낮음
  → 급소 겨냥 필수 (현실적 단검 전투)

활 (하린 기마):
  기마 시: 달리면서 조준 어려움
  화랑 훈련: 목표물 10m 이내 집중
  → 기마 궁사 = 중거리 기습 (장거리 스나이퍼 아님)

창 (가야 병사):
  길이 2~2.5m
  1대1 근접전 불리
  → 대열 전투에서 진가 발휘 (밀집 창병)
```

## 전투 씬 QA 체크리스트

```
□ 고루 전투 = 화려한 연속기 없는가
□ 아랑이 직접 싸우는 장면 없는가 (1회 예외 제외)
□ 니문이 직접 싸우는 장면 없는가 (1회 예외 제외)
□ 무기 사용법이 역사 고증과 일치하는가
□ 전투 씬에 왕국별 색채 구분이 적용되었는가
□ 하린 전투: 관창 관련 감정선과 연동되는가
□ 살수대첩: 물 이펙트가 클라이맥스인가
□ 기벌포: 4인 집결 최종 장면으로 끝나는가
```
