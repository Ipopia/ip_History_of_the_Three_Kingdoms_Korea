## IP 권리 체계 개요

```
삼국(三國) IP 권리 구조:

저작권 (Copyright): 창작과 동시 자동 발생
상표권 (Trademark): 각 국가별 출원 등록
특허 (Patent): 게임 메커니즘·기술적 혁신
디자인권: 로고·캐릭터 외형·상품 디자인
```

## 상표 출원 계획

### 한국 (특허청)

```
출원 브랜드:
1. 삼국(三國)
2. THREE KINGDOMS
3. 강은 기억한다 / THE RIVER REMEMBERS
4. 삼족오 로고 도형

니스 분류:
Class 9: 게임 소프트웨어·앱·전자 출판물
Class 16: 출판물·만화·도서·포스터
Class 25: 의류·신발·모자
Class 28: 완구·피규어·게임
Class 38: 방송·OTT 스트리밍 서비스
Class 41: 교육·오락·공연 서비스
Class 42: 게임 개발 및 서비스

Phase 1 (즉시): Class 9, 16, 28, 41
Phase 2 (3개월): Class 25, 38, 42
예상 비용: 약 50만원
```

### 일본 (特許庁)

```
출원 브랜드:
1. 三国 (サムグク)
2. 三国 ―江は記憶する―
3. THREE KINGDOMS
4. 삼족오 로고 도형

주의사항:
코에이「三國志」시리즈 선행상표 충돌 검토 필수
「三国」단독 등록 → 선행상표 조사 先행

예상 비용: 약 300만원 (현지 변리사 대리 포함)
```

### 중국 (国家知识产权局)

```
출원 브랜드:
1. 三国 (간체) / 三國 (번체)
2. 삼족오 로고 도형

리스크:
「三国」기존 등록 상표 충돌 위험 높음
고구려 관련 명칭 → 거절 위험
우회 전략: 도형상표 + 문자상표 세트 전략
대만·홍콩 먼저 등록 → 본토 교섭력 확보

예상 비용: 약 200만원 (대만·홍콩 포함)
```

### 미국 (USPTO)

```
출원 브랜드:
1. THREE KINGDOMS: THE RIVER REMEMBERS
2. SAMGUK
3. 삼족오 로고 도형

분류:
Class 9·16·25·28·41 (한국과 동일)
```

## 저작권 등록

### 한국저작권위원회

```
등록 대상:
① 마스터 서사 바이블
② 캐릭터 디자인 시트 (20종)
③ 왕국 상징 로고 (4종)
④ OST 음원
⑤ 웹툰 에피소드 (회차별)
⑥ 소설 초고

등록비: 1건당 26,000원
우선순위: 바이블→캐릭터→출판물
```

### 해외 저작권

```
베른협약: 가입국 170개+ 자동 보호

미국 Copyright Office 등록 권장:
소송 시 법정 손해배상 청구 가능
등록비: 35~65 USD

추가:
WIPO 국제 분쟁 해결 채널 확보
중국 내 저작권 침해 모니터링 서비스 계약
```

## 라이선싱 프레임워크

### 라이선스 종류

```
독점 라이선스:
게임·드라마 OTT — 지역별·플랫폼별 독점
조건: 최소 보장금(MG) + 러닝 로열티

비독점 라이선스:
머천다이즈·출판 — 복수 파트너 허용
조건: 로열티율 적용
```

### 로열티 기준

```
피규어·완구: 10~15%
의류·패션: 8~12%
출판물: 7~10%
게임 퍼블리셔: 25~35%
식음료·카페 콜라보: 5~8%
```

## IP 등록 일정

```
Phase 1 (D-180):
□ 한국 상표 출원 완료
□ 마스터 바이블·캐릭터 저작권 등록
□ 일본 상표 출원 착수

Phase 2 (D-90):
□ 미국·EU 상표 출원
□ 일본 등록 완료
□ 중국 출원 착수

Phase 3 (D-30):
□ 게임 관련 특허 출원
□ OST·드라마 시나리오 저작권 등록
□ 라이선싱 표준 계약서 완성

Phase 4 (출시 후):
□ 위조품 모니터링 가동
□ 분기별 IP 현황 보고서
```
