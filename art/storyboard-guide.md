## 스토리보드 철학

```
핵심 원칙:
  「콘티 한 장이 천 마디 연출 지시를 대신한다」

3대 목표:
  1. 시각 언어 통일 — 감독·촬영감독·VFX 팀 동일 비전 공유
  2. 왕국별 시각 DNA 반영 — 컷 구성에서 왕국 정체성 표현
  3. 서사 흐름 시각화 — 편집 리듬·감정선 사전 확인
```

## 스토리보드 포맷 기준

### 기본 프레임

```
화면비: 2.39:1 (드라마 기본) / 1.85:1 (인물 집중 씬)
프레임 크기:
  A4 기준: 195mm × 82mm (2.39:1)
  디지털: 1920px × 803px

프레임 당 정보:
  ┌────────────────────────────────────────┐
  │ EP.01  SC.003  SH.007   [CUT #]       │
  │                                        │
  │         [그림 영역]                     │
  │                                        │
  └────────────────────────────────────────┘
  액션:  [인물/카메라 동작 설명]
  대사:  [해당 대사 또는 O.S.]
  SFX:   [음향 효과 메모]
  시간:  [컷 예상 길이, 예: 3"~5"]
  특기:  [VFX·특수촬영·조명 특이사항]
```

### 컷 번호 체계

```
형식: EP##-SC###-SH####
  EP: 에피소드 번호 (01~16)
  SC: 씬 번호 (001~)
  SH: 쇼트 번호 (001~)

예시:
  EP01-SC003-SH007 — 1화 3씬 7번째 쇼트
  EP03-SC045-SH001 — 3화 45씬 첫 쇼트
```

## 카메라 기호 표기법

```
샷 사이즈:
  ECU — Extreme Close Up (눈·입 등 극단 클로즈업)
  CU  — Close Up (얼굴)
  MCU — Medium Close Up (가슴 위)
  MS  — Medium Shot (허리 위)
  MLS — Medium Long Shot (무릎 위)
  LS  — Long Shot (전신)
  ELS — Extreme Long Shot (환경 광각)

카메라 앵글:
  HA — High Angle (하이앵글)
  LA — Low Angle (로우앵글/저앙각)
  EYE — Eye Level (아이레벨)
  BEV — Bird's Eye View (버드아이뷰)
  WOR — Worm's Eye View (웜아이뷰)

카메라 무빙:
  → 화살표: 카메라 이동 방향
  ○ 원: 카메라 회전 지점
  Z+ : 줌인 / Z- : 줌아웃
  T↑ : 틸트업 / T↓ : 틸트다운
  P→ : 팬 우 / P← : 팬 좌
  CRANE↑/↓: 크레인 업/다운
  DRONE: 드론 촬영 표시
  HH: 핸드헬드
```

## 왕국별 스토리보드 스타일

### 고구려 씬 콘티 기준

```
구도 패턴:
  ① 저앙각(LA) 위주 → 인물 위압감
  ② 수평선 강조 구도 → 광활한 평야 스케일
  ③ 대칭 구도 → 요새·성벽 장면

컷 길이:
  기본 컷: 6초 이상 (묵직한 롱 테이크)
  전투 클라이맥스: 1~2초 (긴박감)

필수 요소:
  강변·강물 샷 반드시 포함
  삼족오 깃발 배경 배치
  청람 색조 메모

콘티 채색:
  연필 스케치 기본
  청람 계열 컬러 힌트
```

### 백제 씬 콘티 기준

```
구도 패턴:
  ① 느린 달리 → 아랑 시점 추적
  ② 크레인 업/다운 → 연등 규모 표현
  ③ 극단적 클로즈업 → 죽간·붓·문자

컷 길이:
  기본 컷: 7초 (서정적)
  연등 야경: 10초 이상 롱 테이크

필수 요소:
  연등 파티클 표기 (배경 흩날림)
  황금 광원 명시
  촛불·등불 위치 메모

콘티 채색:
  황금·주황 계열 컬러 힌트
```

### 신라 씬 콘티 기준

```
구도 패턴:
  ① 역동적 대각선 → 액션·전투
  ② 드론 추적 → 기마 시퀀스
  ③ 핸드헬드 → 화랑 훈련·전투

컷 길이:
  기본 컷: 3~4초 (역동)
  슬로모션 삽입 표기 필수

필수 요소:
  황금 시간대 광원 메모
  말 이동 경로 화살표
  화랑 오계 씬 특기 표시

콘티 채색:
  금색·황색 계열
```

### 가야 씬 콘티 기준

```
구도 패턴:
  ① 니문 중앙 + 주변 빈 공간 → 고독감
  ② 극단적 클로즈업 → 가야금 현·손가락
  ③ 수평 슬라이드 → 강변 풍경

컷 길이:
  기본 컷: 9초 (정적)
  가야금 연주: 롱 테이크 권장

필수 요소:
  침묵 표기 (대사 없음 명시)
  가야금 현 진동 시각 메모
  황혼 시간대 명시

콘티 채색:
  황토·세피아 계열
```

## 전환 기호 표기

```
CUT    — 일반 컷
DIS    — 디졸브 (장면 전환)
FADE IN/OUT — 페이드 인/아웃
WIPE   — 와이프
FLASH  — 플래시 컷 (회상·예시)
MATCH CUT — 매치 컷 (유사 형태 연결)
JUMP CUT — 점프 컷 (시간 경과)
```

## 스토리보드 납품 기준

```
드라마 본편:
  A컷 (필수): 모든 씬 전 쇼트 스케치
  B컷 (중요 씬): 컬러 콘티
  VFX 씬: 별도 VFX 스토리보드 (프레임 단위)

납품 형식:
  디지털: PDF + PSD (레이어 분리)
  해상도: 300dpi (인쇄용)
  파일명: EP##_SC###_SH####.psd

일정:
  에피소드 촬영 D-21: A컷 납품
  에피소드 촬영 D-7: B컷 + VFX 콘티 완성
```
