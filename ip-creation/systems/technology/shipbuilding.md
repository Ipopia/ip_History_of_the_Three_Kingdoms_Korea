## 개요: 삼국시대 해양 기술

삼국시대 한반도는 **해양 강국의 시대**였다. 고구려의 대동강·압록강 수군, 백제의 황해 횡단 교역선, 신라의 동해 해양 진출, 가야의 대외 교역 항만 — 각 왕국은 서로 다른 목적과 방식으로 조선 기술을 발전시켰다.

```
삼국 조선 기술 핵심 키워드:
고구려 — 강하(江河) 수군선 / 병선(兵船) 중심
백제   — 황해 횡단 / 교역선·사신선 / 원양 항해
신라   — 동해 어선·병선 / 후기 해양 진출
가야   — 한일 교역 / 철기 운반선 / 남해안 항만
```

## 1. 고구려 조선 기술

### 1-1. 수군(水軍) 체계

```
고구려 수군 구성:
├── 전선(戰船) — 주력 전투함
├── 맹선(猛船) — 돌격용 소형선
├── 수송선(輸送船) — 병력·물자 수송
└── 척후선(斥候船) — 정찰·정보 수집

주요 작전 수역:
- 압록강(鴨綠江): 중국 국경 방어
- 대동강(大同江): 평양 방어선
- 서해(黃海) 북부: 수나라·당나라 해상 위협 대응
- 살수(薩水): 수양제 원정군 격퇴 (612년)
```

### 1-2. 전선(戰船) 설계

```
고구려 주력 전선 제원 (추정 복원):
- 길이: 15~25m
- 폭: 4~6m
- 흘수선: 1.2~1.8m
- 승선 인원: 50~120명
- 추진: 노(櫓) 주력 + 돛(帆) 보조

선체 구조:
┌─────────────────────────────┐
│  갑판 — 전투 공간           │
│  노 공간 — 양측면           │
│  화물·군수품 수납 선창      │
└─────────────────────────────┘

목재 재료:
- 선체: 소나무(松木) — 한반도 주산
- 용골: 참나무(橡木) — 강도 확보
- 돛: 마포(麻布) — 내구성
```

### 1-3. 살수대첩의 수군 전술 (612년)

```
수나라 수군 규모: 전선 수백 척 추정
고구려 수군 전술:
1단계: 후퇴 유인 — 살수 상류 봉쇄
2단계: 살수 방류 — 강물 급류 조성
3단계: 전선 급습 — 혼란 속 공격

을지문덕의 역할:
- 육군 작전과 수군 작전 동시 지휘
- 편지(詩)로 수양제 혼란 유도
  "神策究天文 妙算窮地理
   戰勝功旣高 知足願云止"
- 수군의 거짓 항복 → 실제 총공세

역사적 결과:
- 수나라 113만 대군 중 살아 돌아간 자 2,700명
- 고구려 살수의 물이 핏빛이었다는 기록
```

### 1-4. 창작 활용 (고구려 수군)

```
드라마 장면 활용:
- 전선 건조 현장 — 제철 기술과 연계
- 살수 방류 직전 — 을지문덕의 결단
- 압록강 수군 훈련 — 계절별 장면

게임 기술 트리:
[수군 기초] → [전선 강화] → [화공선] → [살수 전술]
- 화공선(火攻船): 불화살 발사 능력 + 충각 공격
- 살수 전술 스킬: 강 지형 보너스 300% 발동
```

## 2. 백제 조선 기술

### 2-1. 황해 항로 개척

```
백제의 해양 전략:
목표 — 중국 남조(南朝)와 직접 교류
경쟁자 — 고구려가 육상 통로 차단
해결책 — 황해 횡단 항로 독자 개발

주요 항로:
사비성(부여) → 한강 하구 → 황해 → 산동반도(山東) → 양쯔강 하류
거리: 약 700~900km
소요 시간: 순풍 시 7~14일

주요 기항지:
- 한성(漢城): 황해 출항 기지
- 덕적도(德積島): 중간 기착
- 흑산도(黑山島): 남해 기착
```

### 2-2. 백제 교역선 설계

```
백제 대형 교역선 (사신선) 제원:
- 길이: 20~30m
- 폭: 7~8m
- 흘수선: 2.0~2.5m
- 적재량: 20~40톤
- 승선: 40~80명 (선원 + 사신단)

추진 방식:
- 황해 항해: 계절풍(季節風) 적극 활용
  - 여름: 남서풍 → 중국으로
  - 겨울: 북동풍 → 귀환
- 갑판 돛대: 2~3개 복합 돛 구조

항법(航法) 기술:
- 별자리 항법 (야간)
- 조류·계절풍 지식 (경험 항법)
- 해안선 관측 (연안 항법)

화물:
왕래 수출: 금속제품·도자기·직물·서책
수입: 비단·동전·서적·불교 문물
```

### 2-3. 칠지도(七支刀)와 외교 항해

```
칠지도 전달 루트:
백제 사비성 → 왜국(倭國) / BC 369년 추정

백제→왜 해상 항로:
사비성 → 금강 하구 → 남해 → 대마도(對馬島) → 큐슈(九州)
거리: 약 300~400km / 소요: 3~7일

왜국과의 교역:
- 백제 → 왜: 선진 문물 (불교·한자·기술)
- 왜 → 백제: 병력 지원 (군사 동맹)
  "백강전투(白江口 戰鬪) 663년: 왜군 지원"

칠지도 창작 해석:
→ 단순 하사품이 아닌 동맹의 상징
→ 바다를 건넌 문화 외교의 증거
→ 게임: 칠지도 외교 아이템 → 왜 동맹 이벤트
```

### 2-4. 백제 조선소

```
주요 조선소 위치:
1. 한강 하구 (한성 시기)
2. 금강 하구 — 웅진·사비 시기 핵심
3. 서해 남부 해안 — 교역 거점

조선소 시설:
- 건선거(乾船渠): 배 건조·수리 도크
- 목재 보관소: 소나무·삼나무 건조
- 포구(浦口): 출항·귀항 관리
- 관세 창고: 교역품 보관·검사
```

## 3. 신라 조선 기술

### 3-1. 동해 어업과 군선

```
신라 해양 활동:
초기 — 동해 연안 어업 중심
중기 — 왜구 방어 병선 필요
후기 — 당나라 항로 + 해상 팽창

동해 환경:
- 조류 복잡 — 쿠로시오 해류 영향
- 겨울 풍랑 — 항해 제한
- 독도(于山島) 인식 — 영토 관리

신라 어선·병선:
- 소형 어선: 길이 8~12m / 5~15명
- 병선: 길이 12~18m / 30~60명
- 군호(軍壺): 유사시 병선 전환 어선
```

### 3-2. 나당전쟁의 해전 (676년)

```
기벌포(伎伐浦) 해전:
위치: 현재 충청남도 서천 앞바다
참전: 신라 수군 vs 당나라 수군(薛仁貴)

신라 수군 전술:
- 22회 연속 해전 — 당 수군 격파
- 소형 고속선 + 화공 전술
- 지형 활용 — 서해 남부 조류

결과: 당나라 수군 대패 → 당의 한반도 철수 결정
역사적 의미: 신라의 삼국 통일 완성

게임 구현:
기벌포 해전 시나리오:
- 신라 수군 병과 선택
- 22라운드 연속전 도전 업적
- 역사적 결과 달성 시 골든 엔딩
```

### 3-3. 문무대왕의 수중릉

```
문무대왕릉(文武大王陵):
위치: 경주 앞바다 대왕암(大王岩) — 수중 바위섬
역사: 681년, 문무왕 수중 장사(水中葬事) 기록
유언: "죽어서 용이 되어 나라를 지키겠다"

창작 활용:
- 드라마 엔딩: 동해 수중 납골 장면
- 게임: 수중 왕릉 맵 + 용신 전설
- 웹툰: 수중장 의식 — 신비로운 비주얼
```

## 4. 가야 조선 기술

### 4-1. 가야의 해양 교역

```
가야의 지리적 이점:
- 남해안 최적 위치 — 한반도-왜국 중간
- 낙동강 수계 — 내륙 연결
- 철기 생산 — 수출 핵심 품목

주요 교역 루트:
[가야] ↔ [왜국 큐슈]
- 거리: 200~300km
- 빈도: 연 수회 (계절 항해)

[가야] ↔ [낙랑·중국]
- 황해 북부 항로
- 동한(東漢) 이후 교역 지속

가야 수출품:
- 철정(鐵鋌): 화폐 기능 철 덩어리
- 철제 갑옷·무기
- 가야 도기(陶器)

가야 수입품:
- 왜국: 금·은·진주·목재
- 중국: 동경(銅鏡)·도자기·서책
```

### 4-2. 가야 교역선

```
가야 소형 교역선 제원:
- 길이: 10~15m
- 폭: 3~4m
- 적재: 5~15톤 (철기 중심)
- 승선: 15~30명

구조적 특징:
- 평저형(平底型): 낙동강 내륙 운항 적합
- 강화된 선저: 철기 중량 탑재
- 낮은 흘수: 연안·하천 겸용

가야 항만:
- 김해(金海): 수로왕 시대 핵심 항구
- 고령(高靈): 내륙 수계 집산
- 합천(陜川): 낙동강 수로 허브
```

### 4-3. 가야 멸망과 해양 유산

```
신라 가야 병합(562년) 이후:
- 가야 철기·조선 기술 → 신라 흡수
- 가야 선박 기술자 → 신라 조선소 편입
- 가야 항만 → 신라 남해 거점

우륵과 바다:
"가야금 소리는 바다를 건너지 못한다—
 하지만 배는 건넌다."
→ 창작 장면: 우륵이 귀화 전 남해를 바라보는 장면

게임 DLC:
가야 해상 교역 시나리오:
- 왜국 교역 루트 개척
- 철정(鐵鋌) 물류 관리
- 멸망 전 최후 교역 — 감성 엔딩
```

## 7. 드라마 연출 가이드

```
해양 장면 촬영 지침:
□ 전선: CG + 실물 소형 모형 병행
□ 항해 장면: 실제 바다 로케이션 (전남·충남 해안)
□ 살수대첩 수전: 강 로케이션 + VFX 합성
□ 황해 횡단: 석양·일출 장면 집중

소품 고증:
□ 삼국시대 돛: 마포(麻布) 재질 재현
□ 노(櫓): 참나무 재질
□ 갑판 무기: 시대별 구분 (고구려/백제 차이)
□ 선원 의복: 색채 가이드 참조 (왕국별 구분)

역사 해설 삽입:
- 살수대첩 수전 장면: "612년 살수…" 자막
- 백제 황해 항로: 지도 삽입 권장
- 기벌포 해전: 22회 연속전 자막 강조
```
