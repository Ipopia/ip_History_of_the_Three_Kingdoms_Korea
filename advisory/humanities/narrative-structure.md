## 자문 개요

삼국(三國) IP의 서사는 **역사적 사실의 틀 안에서 작동하는 창작 서사**다. 역사가 서사의 한계가 아닌 서사의 강점이 되어야 한다. 본 자문서는 인문학적 서사 이론을 적용하여 삼국 IP 전반의 서사 설계를 지원한다.

```
핵심 서사 과제:
1. 결말이 정해진 서사 — 역사는 알고 있다
   → 독자는 결말을 알면서도 감동받아야 한다
2. 다중 주인공 서사 — 4왕국 동시 진행
   → 파편화 없이 통합된 서사 경험
3. 실존 인물 창작화 — 역사와 픽션의 경계
   → 인물의 인간성을 훼손하지 않으면서 창작
4. 크로스미디어 서사 — 미디어마다 다른 깊이
   → 어느 매체에서 진입해도 완전한 경험
```

## 서사 구조 이론 적용

### 1. 비극적 순환 구조 (Tragic Cycle)

```
삼국 IP의 근본 서사 구조:
탄생 → 성장 → 절정 → 쇠락 → 소멸 → 기억

적용 왕국:
고구려: 주몽 건국 → 광개토 절정 → 668년 소멸
백제: 온조 건국 → 근초고·성왕 절정 → 660년 소멸
신라: 혁거세 건국 → 선덕·태종무열 절정 → 935년 소멸
가야: 수로왕 건국 → 문물 절정 → 562년 소멸

역설적 서사 가치:
독자는 결말을 안다. 그래서 더 슬프다.
비극은 결말이 아니라 과정에서 발생한다.
→ 각 인물의 선택, 관계, 성장이 감정의 핵심

참조: 그리스 비극 (소포클레스·아이스킬로스)
삼국 IP 차이: 멸망이 끝이 아니라 기억으로 이어진다
```

### 2. 다성 서사 (Polyphonic Narrative)

```
바흐친(Bakhtin)의 다성 소설 이론 적용

삼국 = 4개의 목소리 (왕국)
각 목소리는 독립적이며 대등하다.
어느 왕국이 주인공이 아니다. 모두가 주인공이다.

실천 방법:
- 각 왕국 시점 챕터를 독립 서사로 설계
- 동일 사건(살수대첩)을 각 왕국 시점으로 중복 서술
- 독자가 어느 왕국에서도 감정이입 가능하도록
- 적대적 왕국도 그 왕국 내부에서는 영웅

적용 사례:
황산벌 전투:
  신라 시점: 승리의 서사 (진군·해방)
  백제 시점: 비극의 서사 (계백·멸망)
→ 같은 전투, 다른 감정. 둘 다 진실.
```

### 3. 기억 서사 (Memory Narrative)

```
주제 「강은 기억한다」의 서사 이론화

기억 서사의 구조:
현재의 기억자 → 과거의 사건 → 의미의 재구성

삼국 IP에서:
기억자: 강(江) — 비류수·백마강·낙동강·형산강
기억 내용: 각 왕국의 건국·전쟁·멸망
의미: 소멸해도 기억 속에 살아있다

문학적 장치:
1. 강의 내레이션: 강이 1인칭으로 기억을 서술
2. 시간 역행: 현재에서 과거로 거슬러 올라가는 구조
3. 반복 모티프: 같은 장면이 다른 맥락에서 반복 등장

구체 적용:
소설: 각 챕터 도입부에 강이 해당 장소를 기억하는 단락
드라마: 오프닝 강물 이미지 + 회당 다른 강의 내레이션
게임: 스테이지 설명에 강의 시점 텍스트
```

### 4. 캐릭터 호 (Character Arc)

```
변화 호 vs 정적 호 설계 가이드

변화 호 (Transformational Arc):
캐릭터가 근본적으로 변화하는 서사

고루 (창작): 순진한 청년 → 전쟁을 아는 어른
아랑 (창작): 충성스러운 관리 → 체제에 의문을 품는 자
니문 (창작): 스승 그림자 → 독립적 예술가

정적 호 (Flat Arc):
캐릭터가 변하지 않고 세상을 변화시키는 서사

광개토대왕: 시작부터 끝까지 정복자·수호자
을지문덕: 변함없는 지략가·애국자
선덕여왕: 시작부터 예언자·지도자
계백: 변함없는 충신 (변화는 세상이 함)

역사 인물 원칙:
실존 인물의 핵심 정체성은 정적 호로 유지.
창작 인물이 변화 호를 통해 독자의 감정이입 담당.
```

## 삼국 IP 주제 체계

### 핵심 주제

```
PRIMARY THEME: 기억과 소멸
"모든 것은 사라진다. 하지만 강은 기억한다."

강의 기억 = 역사의 영속성
왕국은 사라졌지만 그들의 선택, 노래, 건축, 철기는 남았다.

SECONDARY THEMES:

1. 선택의 무게
   소서노의 선택: 주몽을 돕느냐, 자신의 왕국을 세우느냐
   우륵의 선택: 가야에 남느냐, 신라로 가서 음악을 지키느냐
   계백의 선택: 도망치느냐, 명예롭게 싸우다 죽느냐
   → 역사는 선택의 연속이다

2. 문화의 생존
   왕국은 멸망해도 문화는 살아남는다.
   가야금은 신라에서 연주됐다.
   백제 기술자는 왜로 갔다.
   고구려 벽화는 지금도 남아있다.
   → 군사적 패배 ≠ 문화적 소멸

3. 강의 연결
   비류수·백마강·낙동강은 다른 강이지만 바다에서 만난다.
   삼국의 사람들은 적이었지만 같은 한반도를 살았다.
   → 분열과 통합의 변증법

4. 역사 속 개인
   역사는 왕들의 이야기지만, 살았던 건 평범한 사람들.
   고루·아랑·니문은 역사에 이름 없는 사람들.
   → 역사의 이면, 기록되지 않은 기억
```

### 주제별 서사 배치

```
소설/드라마 (심층):
- 기억과 소멸: 全편에 걸쳐 (강의 내레이션)
- 선택의 무게: 챕터별 인물 분기점에서 집중
- 역사 속 개인: 창작 인물(고루·아랑) 챕터 전담

웹툰 (시각화):
- 선택의 무게: 「선택지」컷으로 시각화
- 문화의 생존: 유물·악기 클로즈업 컷

게임 (체험):
- 선택의 무게: 분기 선택지 시스템으로 직접 체험
- 강의 연결: 지도 시스템에서 강이 왕국 연결
- 역사 속 개인: 창작 인물이 플레이어 아바타

애니메이션 (감각):
- 기억과 소멸: 오프닝·엔딩 강물 이미지
- 문화의 생존: 유물·음악 시퀀스로 감각화
```

## 서사 금기 및 주의사항

### 역사 서사 금기

```
절대 금기:
× 역사적 결말 임의 변경 (고구려가 생존 등)
× 실존 인물 부정적 희화화 (광개토대왕 악당화 등)
× 현대 민족주의·영토 주장 직접 투영
× 타 국가(중국·일본·북한) 현재 체제 공격성 서사

허용 범위:
○ 역사 기록의 공백 창작 (기록 없는 부분)
○ 실존 인물 내면 심리 창작 (기록된 행동 기반)
○ 역사적 적대 관계 서사화 (현재 악감정 자극 금지)
○ 창작 인물 자유 설정 (역사 사실과 충돌 없을 때)
```

### 인문학적 주의점

```
고증 vs. 창작 경계:
역사 기록 있는 사건: 기록 우선, 창작은 공백만
역사 기록 없는 부분: 창작 자유 (단 시대 맥락 준수)
실존 인물 심리: 행동 기록 기반 추론, 과도한 비틀기 금지

문화 감수성:
중국 역사와 관계: 동북공정 직접 반박 삼가
  → "4~7세기 고구려는 고구려" 명확히, 논쟁은 학술영역
일본 역사와 관계: 임나일본부 완전 배제
  → 가야-왜 관계는 「상호 교류」로만 서술
현대 한국 민족주의: 과도한 영웅화 자제
  → 인물의 복잡성·인간성 유지가 더 감동적
```

## 미디어별 서사 전략

### 소설: 심층 내면 + 역사 재현

```
장점: 내면 독백·상세 묘사 가능
전략:
- 인물 내면 심리 최대 발휘 (관찰 불가한 것 서술)
- 역사 현장의 감각적 재현 (냄새·소리·촉감)
- 복수 시점 교차 (챕터별 왕국 이동)
- 강의 내레이션: 챕터 도입 단락 고정 장치

권장 분량:
왕국별 챕터: 50~70페이지
강 내레이션 도입: 챕터당 1~2페이지
인물 내면 독백: 챕터당 10~15페이지
```

### 드라마: 시각 + 감정 직접 전달

```
장점: 배우 연기·음악·미장센으로 감정 직접 전달
전략:
- 대사보다 행동으로 감정 표현
- 강(江) 장면 반복 삽입 (주제 시각화)
- 왕국별 색감·카메라 스타일 차별화
- 역사 사건은 배경, 인물 관계가 전경

권장 구조:
에피소드당 2~3개 왕국 교차 (최대)
강 삽입 장면: 에피소드당 1회
클라이맥스: 단일 왕국 집중 (분산 금지)
```

### 게임: 선택 + 결과 체험

```
장점: 플레이어가 선택을 직접 체험
전략:
- 역사적 선택지를 플레이어에게 위임
- 결과는 역사와 같되 과정은 다양하게
- 창작 인물(고루·아랑)의 선택이 역사를 보조
- 실패해도 역사가 이어지는 구조 (게임오버 없음)

금기:
× 역사 결말을 바꾸는 엔딩 (고구려 생존 등)
○ 허용: 개인 인물(고루·아랑)의 운명 선택
```

### 웹툰: 시각 압축 + 임팩트

```
장점: 컷 단위 시각 임팩트
전략:
- 핵심 장면만 압축 (소설 서브플롯 생략 가능)
- 왕국별 채색 차별화 (색만으로 왕국 구분)
- 대사 최소화 → 그림이 말하게
- 강 장면: 양면 풀페이지로 강조

분량 기준:
에피소드당 50~70컷
강 삽입: 에피소드당 1회 (풀페이지)
클라이맥스: 무대사 컷 연속
```
