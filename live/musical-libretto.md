## 뮤지컬 개요

```
공연명: 뮤지컬 삼국(三國) — 「강은 기억한다」
영문명: MUSICAL SAMGUK — THE RIVER REMEMBERS

장르: 역사 서사 뮤지컬
러닝타임: 2시간 40분 (인터미션 20분 포함)
구성: 2막 (1막 75분 / 2막 65분)

목표 공연장:
  국내: 세종문화회관 대극장 (서울, 3,022석)
  투어: LG아트센터, 블루스퀘어, 성남아트센터
  글로벌: 도쿄 제국극장, 뉴욕 브로드웨이 오프

초연 목표: 2027 Q1

제작 규모:
  배우: 주역 6인 + 앙상블 30명
  악단: 피트 오케스트라 30명 + 한국전통악기 4인
  스태프: 연출·안무·무대·조명·음향·의상 각 팀
```

## 등장인물

### 주역

```
고루 (바리톤/테너)
  음역: 바리톤 ~ 테너 경계
  핵심 넘버: 「강은 기억한다」「기다려라」「700년」
  성격: 과묵, 무게감. 대사 적고 노래가 감정 표현

아랑 (메조소프라노)
  음역: 메조소프라노
  핵심 넘버: 「기록하는 자」「선생님 어디에」「마지막 죽간」
  성격: 빠르고 지적. 말이 많지만 노래는 슬프다

하린 (소프라노/메조)
  음역: 소프라노
  핵심 넘버: 「화랑의 맹세」「선덕 여왕」「이것이 옳은가」
  성격: 강하지만 감성적. 2막에서 감정 폭발

니문 (테너, 가야금 연주)
  음역: 테너
  핵심 넘버: 「가야금 소리」「완성하지 못해도」「기억의 강」
  특기: 실제 가야금 연주 + 노래 동시 (또는 배우 + 연주자 분리)
  성격: 침묵이 많다. 노래로만 말한다

을지문덕 (베이스)
  음역: 베이스
  핵심 넘버: 「신책구천문」「기다려라, 고루야」
  등장: 1막 집중 (살수대첩 이후 퇴장)

선덕여왕 (소프라노)
  음역: 소프라노
  핵심 넘버: 「살아남아야」「별이 지는 날」
  등장: 1막 말 ~ 2막 초 (647년 사망)
```

## 1막 구성

### 프롤로그 — 「네 왕국의 노래」

```
무대:
  어두운 무대 — 4방향에서 각 왕국 상징 조명
  4인 주인공 각자의 자리에서 소개 아리아

넘버: 「네 왕국」
  4인 각자 테마 → 마지막에 화음으로 합창
  가사 키워드: 강·불·금관·가야금

가사 (초안):
  고루: 「철벽 같은 산 위에 고구려는 서 있다
         수나라의 물결도 막아낸 이 땅에
         나는 장군의 제자로 서 있다
         강은 기억한다—」

  아랑: 「금강 위 사비성 기록관 창가에서
         나는 오늘도 붓을 든다
         역사는 기록하는 자의 것
         나는 기억한다—」

  하린: 「화랑의 맹세 가슴에 새기고
         선덕 여왕의 눈빛을 따라
         나는 검을 쥔다
         강은 기억한다—」

  니문: (침묵 + 가야금 멜로디)
        「...사라진 나라의 소리로
         나는 여기 있다—」

합창: 「강은 기억한다 / THE RIVER REMEMBERS」
```

### 1막 1장 — 살수 (612년)

```
무대: 압록강 → 살수 강변 (프로젝션 맵핑)

Scene 1-1: 수나라 113만 대군 행진
  앙상블 30명 수나라 군복 → 압도적 군세 표현
  넘버: 「113만」(합창) — 웅장하고 위협적

Scene 1-2: 을지문덕과 고루
  을지문덕: 고루에게 전략 설명
  넘버: 「기다려라, 고루야」(베이스 아리아)
  가사 키워드: 강을 믿어라, 때를 기다려라

Scene 1-3: 7번 후퇴
  마임 + 빠른 앙상블 안무 — 전투·후퇴 반복
  넘버: 「일곱 번째 후퇴」(고루 + 앙상블)
  가사: 「한 번, 두 번, 세 번 물러선다
         수나라의 칼날이 등에 닿을 때
         나는 을지문덕 선생의 목소리를 듣는다
         — 기다려라」

Scene 1-4: 살수 클라이맥스
  무대 전체 물 이펙트 (LED + 프로젝션)
  살수 범람 → 수나라 군 붕괴
  넘버: 「살수여, 흘러라」(고루 + 합창)
  을지문덕 한시 원문 노래: 「신책구천문(神策究天文)...」
```

### 1막 2장 — 사비성 (642년~647년)

```
Scene 1-5: 아랑의 기록
  무대 전환: 사비성 문서관
  아랑 아리아: 「기록하는 자」
  성충과 아랑의 스승-제자 듀엣: 「무엇을 쓸 것인가」

Scene 1-6: 연개소문 쿠데타 (642년)
  평양성 장면 병렬
  고루: 목격자 독백 넘버 「배신인가, 혁명인가」
  연개소문의 아리아 (조역): 「나는 고구려다」

Scene 1-7: 선덕여왕과 하린
  신라 금성 궁전 무대
  선덕여왕 등장: 아리아 「살아남아야」
  하린과의 듀엣: 「여왕의 검」
  가사: 「나는 별을 읽는다 / 너는 검을 쥐어라
         신라는 아직 살아있다」

1막 피날레:
  3개 왕국 동시 무대 (삼분할)
  넘버: 「1막 피날레 — 선택의 시간」
  3인 각자의 결단 아리아 → 합창
  인터미션 전 클리프행어
```

## 2막 구성

### 2막 1장 — 안시성과 황산벌 (645년~660년)

```
Scene 2-1: 안시성 88일
  무대: 안시성 성벽 위
  고루의 전쟁 독백 + 앙상블 방어전 안무
  넘버: 「88일」(고루 + 앙상블)
  가사: 「하루, 또 하루
         성벽은 버텼다
         토산이 무너질 때
         나는 처음으로 웃었다」

Scene 2-2: 선덕여왕 사망 (647년)
  하린: 선덕여왕 임종 장면
  넘버: 「별이 지는 날」(선덕여왕 + 하린 듀엣)
  선덕: 「살아남아야 지킬 수 있다
          하린, 네가 지켜라」
  하린, 처음으로 울다 — 감정 폭발 넘버: 「여왕이 없는 나라」

Scene 2-3: 황산벌 (660년)
  무대: 황산벌 결전
  계백 아리아: 「결사오천」(조역)
  넘버: 「관창」— 16세 화랑의 마지막 돌격
  아랑: 먼 곳에서 봉화를 보며 기록
  아랑 아리아: 「선생님 어디에」
```

### 2막 2장 — 멸망 (660년~668년)

```
Scene 2-4: 백제 멸망
  아랑의 마지막 기록 씬
  넘버: 「마지막 죽간」(아랑 아리아 — 2막 최고 감동 포인트)
  가사: 「660년, 9월
         사비성이 열렸다
         나는 기록한다
         백제는 여기 있었다
         660년간 여기 있었다
         강은 기억한다」

Scene 2-5: 고구려 멸망 (668년)
  고루의 최후 아리아: 「700년」
  가사: 「700년이 오늘로 끝났다
         을지문덕 선생이 지킨 강도
         오늘은 슬프게 흐른다
         하지만 강은 기억한다—」
  니문: 가야금 연주 시작 (반주)

Scene 2-6: 나당 전쟁 & 기벌포 (676년)
  하린의 마지막 전투 장면
  넘버: 「기벌포」(하린 + 합창)
  승리 후 하린 독백: 「이제야 끝났다」
```

### 피날레 — 「기억의 강」

```
전 배우 무대 집결

니문: 가야금 「기억의 강」 전주 시작

4인 독백 → 아리아:
  고루: 「강은 기억한다」
  아랑: 「기록은 남는다」
  하린: 「신라는 살아남았다」
  니문: 「가야금 소리는 사라지지 않는다」

4인 + 앙상블 대합창: 「강은 기억한다」
  1막 프롤로그 테마 완전한 형태로 귀환
  가야금 + 오케스트라 풀 편성

커튼콜:
  「기억의 강」앙코르 버전 (관객 떼창 유도)
```

## 무대 연출 가이드

```
무대 장치:
  주 무대: 턴테이블 + 승강 장치 (3단계)
  배경: LED 스크린 (프로젝션 맵핑 — 4왕국 풍경)
  강 표현: 바닥 조명 + 안개 이펙트

각 왕국 조명 테마:
  고구려: 철청색 (#2F4F7F) + 백색 강조
  백제: 황금색 (#B8960C) + 따뜻한 주황
  신라: 금색 (#FFD700) + 보라
  가야: 황토색 (#C8A96E) + 녹색

안무 스타일:
  전투: 현대 무용 + 무예 동작 결합
  의례: 한국 전통 무용 베이스
  감정 씬: 발레 영향 받은 현대 무용
  앙상블: 군무 (군사 행진·전투)

가야금 처리:
  옵션 A: 니문 역 배우가 실제 연주 (선호)
  옵션 B: 별도 가야금 연주자 + 연기 배우 분리
  권장: 옵션 A (일체감), 단 배우 역량 확인 필수
```
