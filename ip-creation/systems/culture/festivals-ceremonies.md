**참조 문서**: `culture-bible.md`, `glossary.md`, `mythology.md`, `political-systems.md`

---

## 축제·의례 체계 개요

```
삼국시대 의례의 특징:
  농경 사이클 기반 계절 의례
  천신(天神) + 조상신 복합 숭배
  불교 도입 후 불교 의식 병행 (4~7세기)
  왕권 강화 = 의례의 국가화

4왕국 의례 특성:
  고구려: 제천(祭天) 의식 중심, 수렵 의례
  백제: 불교 의례 + 중국 남조식 예법 혼합
  신라: 제천 + 불교 + 화랑 의례 복합
  가야: 제철·수로왕 숭배 + 해상 안전 기원
```

## 고구려 의례 체계

### 동맹(東盟) — 10월 제천대제

```
시기: 음력 10월
성격: 고구려 최대 국가 제천 의례
장소: 국내성 → 평양성 (천도 후)

의례 구성:
  ① 왕의 하늘 제사 (天祭):
     제단: 성 밖 높은 지점
     제물: 소·말·돼지 (牛馬豕)
     복식: 왕 = 백라관 + 대례복

  ② 조상 제사:
     시조 주몽(동명성왕) 사당 참배
     역대 왕 위패에 제사
     「동명왕릉」 참배 (평양 천도 후)

  ③ 공동 축제:
     귀족·백성 모두 참여
     가무(歌舞) — 집단 노래·춤
     씨름·활쏘기 경연
     상품: 관직·포상·식량 배분

  ④ 수렵 의례:
     왕 주도 사냥 (상무(尙武) 정신)
     사냥 성과 = 제물·군사력 과시

창작 활용:
  을지문덕: 동맹 제전에서 전략 회의 참가 가능
  고루: 수렵 의례 참가 → 을지문덕에게 발탁 배경
```

### 유두(流頭) — 6월 물맞이

```
시기: 음력 6월 15일
성격: 물을 통한 정화 의식 + 풍요 기원

의례:
  동쪽 흐르는 물에 머리 씻기 (액막이)
  음식 제조: 유두면(流頭麵) + 유두전(煎)
  수신(水神) 제사

창작 활용:
  고루 = 살수 전투 전 유두 의식 장면 (정화·각오)
```

## 백제 의례 체계

### 교천(郊天) 의례 — 봄·가을

```
시기: 음력 1월·7월 (계절 제사)
성격: 왕이 하늘에 올리는 국가 제사

의례 구성:
  왕 + 대신(좌평 이상) 참여
  제단: 사비성 남쪽 교외 (郊)
  중국 남조(南朝) 예법 영향 반영

창작 활용:
  성충: 교천 의례에서 의자왕에게 간언하는 장면
  아랑: 의례 기록자로 참석
```

### 불교 의례 — 연등회·팔관회 (6세기 후)

```
연등회(燃燈會):
  시기: 음력 1월 15일 (상원上元)
  불교 도입 후 백제 전역 확산
  등불 밝히기 → 부처 공양

  창작 활용:
    아랑: 연등회에서 성충 스승과 마지막 대화
    사비성 전체가 등불로 밝혀지는 배경 묘사

팔관회(八關會):
  시기: 음력 10·11월
  살생금지·금식 8계 실천 기간
  이후 신라에서도 채택 → 고려 발전

  창작 활용:
    백제·신라 공통 의례 → 양국 문화 교류 장면
```

### 백제 무속 의례

```
산신제(山神祭):
  사비성 주변 산신에게 풍요·전쟁 승리 기원
  무당(巫堂) 주도
  의자왕 재위: 전쟁 패배 후 산신제 강화

  창작 활용:
    아랑: 전투 전야 산신제 → 불길한 조짐 묘사
```

## 신라 의례 체계

### 화랑 입문 의식 (花郞 入門 儀式)

```
성격: 신라 특유의 화랑도 입문 의례
참여: 낭도(郞徒) → 화랑(花郞) 승급

의례 구성:
  ① 세속오계 낭독:
     「사군이충(事君以忠)」 — 충성으로 임금을 섬겨라
     「사친이효(事親以孝)」 — 효도로 어버이를 섬겨라
     「교우이신(交友以信)」 — 믿음으로 벗을 사귀어라
     「임전무퇴(臨戰無退)」 — 전투에서 물러나지 마라
     「살생유택(殺生有擇)」 — 살생에는 가려서 하라

  ② 맹세 의식:
     화랑 명부(名簿)에 이름 올리기
     칼 받기 (낭두에게서)

  ③ 집단 훈련:
     금강산·지리산 등 산천 유람 수련
     노래·음악·무예 복합 수련

창작 활용:
  하린의 화랑 입문 씬 (어린 시절 회상)
  세속오계 = 하린 평생의 가치관 기준
  임전무퇴 → 황산벌 돌격의 근거
```

### 제천 의례 — 신라 천제(天祭)

```
선덕여왕 특수 의례:
  첨성대 완성 후 → 천문 관측 의례
  여왕이 직접 별자리 읽기 (역사 기록)
  「천명(天命)」확인 의례 → 왕권 정당화

  창작 활용:
    선덕여왕: 첨성대에서 하린에게 「신라의 별이 보인다」
    예언 능력의 근거로 활용
```

## 가야 의례 체계

### 수로왕 건국 제사

```
시기: 수로왕 탄강일 (음력 3월 3일, 야사)
성격: 금관가야 시조 수로왕 기림

의례:
  김해 구지봉(龜旨峰) 제사
  「구지가(龜旨歌)」제창:
    「거북아 거북아 머리를 내어라
     내어놓지 않으면 구워먹겠다」
  수로왕 사당 참배

창작 활용:
  니문 조부 세대: 수로왕 제사 → 가야 정체성의 근간
  562년 가야 멸망 후 제사 금지 → 니문의 상실 장면
```

### 가야 제철 의례

```
시기: 첫 제련 전 (봄·가을)
성격: 화신(火神)·철신(鐵神)에게 안전·품질 기원

의례:
  풀무 앞 제물 올리기 (닭·돼지)
  불 피우기 의식 (불씨 전수)
  제련 성공 시 신에게 첫 철정 바치기

창작 활용:
  니문 가족 = 가야 제철 장인 설정 가능
  562년 멸망 = 제철 의례 중단 → 가야 소멸 상징
```

## 공통 계절 의례

### 세시풍속 달력

```
음력 1월 (정월):
  정초: 조상 제사 + 귀신 쫓기 의례
  상원(15일): 달맞이 + 연등회 (불교 전래 후)

음력 3월:
  삼짇날(3일): 수로왕 제사, 봄맞이 들놀이
  청명(4월초): 불씨 교체 의례

음력 5월:
  단오(5일): 씨름·그네·창포 목욕
  수리취떡 (쑥떡) 제조
  무예 경연 (화랑 + 각 왕국 공통)

음력 7월:
  백중(15일): 조상 영혼 달래기
  농경 의례: 가을 수확 기원

음력 10월:
  상달: 4왕국 공통 제천 의례
  고구려 동맹, 백제 교천, 신라·가야 유사 의례

동지(음력 11월):
  팥죽 먹기 (귀신 쫓기)
  연말 국가 결산 의례
```

## 창작 활용 종합 가이드

```
드라마 활용:
  의례 장면 = 왕권·국가 정체성 시각화
  의례 중단 = 국가 위기 상징 (백제 의례 중단 = 멸망 전조)
  캐릭터별 의례 참여 = 성격 표현

소설 활용:
  의례 준비 장면 = 일상 묘사 + 역사 정보 전달
  의례 중 사건 = 드라마틱 배경 활용

게임 활용:
  계절 이벤트 연동: 동맹·연등회 시기 = 특별 보너스
  의례 수행 = 왕국 사기·충성도 증가 메커닉
  의례 건물 건설: 제단·사당 = 국가 능력치 향상

주의:
  의례 장면 = ADV-MYTH + ADV-HISTORY 이중 검토
  야사·전설 기반 의례 = 「야사 기반」표기
  창작 의례 추가 시 = 시대 고증 범위 내 설계
```
