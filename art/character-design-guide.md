## 디자인 철학

```
삼국(三國) 캐릭터 디자인 3원칙:

1. 역사적 진정성 (Historical Authenticity)
   고구려 고분벽화·백제 금동대향로·신라 금관·가야 철기
   실제 유물에서 비주얼 언어를 추출한다.

2. 현대적 가독성 (Modern Readability)
   복잡한 역사 디테일을 압축·단순화하여
   현대 콘텐츠 소비자에게 직관적으로 읽힌다.

3. 왕국별 차별화 (Kingdom Identity)
   색상·실루엣·디테일 패턴으로
   어떤 왕국 소속인지 한눈에 식별 가능.
```

## 왕국별 비주얼 DNA

### 고구려 (高句麗)

```
색채 팔레트:
- 메인: 암청(暗靑) #2F4F7F — 북방의 하늘, 철의 차가움
- 서브: 주홍(朱紅) #CC3300 — 전쟁의 불꽃, 삼족오의 색
- 포인트: 황동(黃銅) #B8860B — 갑옷 장식, 왕실 상징
- 배경: 검회(黑灰) #2C2C2C — 북방의 어둠, 강인함

실루엣 특성:
- 가로 넓은 어깨 — 북방 전사의 체격
- 직선·각진 형태 — 단호함·강경함
- 무거운 하체 — 기병 전사 체형
- 투구·갑주 비율이 높음

패턴 & 문양:
- 삼족오(三足烏): 왕실·영웅 캐릭터 전용
- 소용돌이 구름 문양: 고분벽화에서 추출
- 기하학적 직선 격자: 철제 갑옷 표면
- 용 문양: 왕·장군급 전용

헤어 & 페이스:
- 강하고 뚜렷한 이목구비
- 무장: 상투 또는 투구 착용
- 여성: 고계(高髻) — 높이 올린 머리
- 눈매: 날카롭고 직선적
```

## 주요 캐릭터 디자인 시트

### 고루 (창작 인물 — 고구려 주인공)

```
기본 정보:
나이: 시즌 1 초반 17세 → 시즌 2 말 29세
신장: 178cm (고구려 무장 평균)
체형: 역삼각형 — 단단한 어깨, 날씬한 허리
왕국: 고구려 / 을지문덕 직속 참모

의상 변화 (시즌별):
S1 초: 하급 병사 — 단순 가죽갑옷, 암청색 기본 의복
S1 말: 을지문덕 제자 — 개인 문양 (소용돌이) 추가
S2 초: 외교관 겸 전략가 — 문관 복식 + 무장 요소 혼합
S2 말 (안시성): 야전 지휘관 — 완전 전투 갑주

색상 코드:
기본: 암청 #2F4F7F + 황동 #B8860B (장식)
전투 모드: 주홍 #CC3300 포인트 추가 (전투 의지)
외교 모드: 상아 #FFFDD0 안감 노출 (유연함 표현)

특징적 디자인 요소:
- 오른쪽 어깨의 작은 삼족오 문양 (을지문덕에게 받은 표식)
- 손목 가죽 보호대 — 항상 착용 (살수대첩의 기억)
- 눈 아래 흉터 (얕은) — S2 안시성 전투 이후 추가
- 시즌별 머리 길이 변화: S1 단발 → S2 상투

표정 가이드:
평상시: 사려깊고 조금 긴장된 표정
전투 중: 냉정하고 집중된 눈빛 (감정 억제)
을지문덕 앞: 존경과 배움의 눈빛
내면 갈등: 눈을 내리깔고 입을 굳게 다문 모습
```
