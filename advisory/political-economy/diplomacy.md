## 동아시아 국제 질서 (4~7세기)

### 조공·책봉 체제

```
체제 개요:
  중국 황제 = 동아시아 천하의 중심
  주변국 = 조공(朝貢)을 바치고 책봉(冊封)을 받음
  책봉 = 「OO국왕」호칭 + 관작 수여 → 정치적 정당성

삼국의 대중 외교:
  고구려:
    수·당과 경쟁 관계 (독자 천하관)
    조공하되 실질 독립 유지
    「고구려왕」책봉 수용 → 그러나 내부적으로 왕=천제(天帝) 칭호

  백제:
    남조(南朝) 중심 외교 (고구려 견제 목적)
    황해 횡단 항로로 직접 교류
    「백제왕」+ 「대방군왕」등 중국 작위 적극 활용
    왜국에는 역으로 상위 외교 (문화 전수)

  신라:
    초기: 고구려·백제 사이 이중 외교
    648년: 당나라와 나당연합 체결
    김춘추의 당 방문 → 「신라왕」책봉 + 군사 동맹
    → 삼국 통일의 결정적 외교 성과

  가야:
    왜국과 「동등 파트너」교역 외교
    철정(鐵鋌) 수출 = 외교 카드
    고구려·신라 압박 → 독자 외교 공간 소멸
```

### 수나라 침략의 국제정치

```
배경:
  수문제(隋文帝): 중국 통일 후 고구려 복속 시도
  고구려: 독자 외교권 수호 → 거부
  → 598년, 612년, 613년, 614년 4차 침략

수양제 612년 원정 (살수대첩):
  수나라 측 목표:
    고구려 복속 → 동아시아 패권 완성
    조공 체제 강제 편입

  고구려 측 대응:
    을지문덕의 전술: 7전 7패 거짓 후퇴
    살수 수문 전술 → 113만 대군 격퇴
    → 수나라 내부 반란 촉발 → 수 멸망 원인 중 하나

외교 씬 자문 포인트:
  수나라 사신 장면: 조공 요구 vs 고구려 거부
  을지문덕의 시(詩) 외교: 시로 시간 벌기
    「神策究天文 妙算窮地理 / 戰勝功旣高 知足願云止」
  → 드라마에서 이 시 장면 자문: 역사 원전 그대로 사용
```

## 나당연합 (648년) 분석

### 형성 배경

```
신라의 위기:
  642년: 대야성 전투 — 백제 의자왕에게 40성 함락
  김춘추 딸·사위 사망 → 개인적 복수심 + 국가 위기
  고구려에 지원 요청 → 거절 (연개소문 강경 노선)
  → 당나라와의 동맹 필사적 추진

김춘추의 당 방문 (648년):
  당태종 면담: 「신라가 당 복속 = 백제·고구려 함께 정복」제안
  협의 내용:
    신라 → 당에 조공·복속 약속
    당 → 신라에 군사 지원 약속
    통일 후: 대동강 이남 신라 영토 인정 (구두 합의)
    → 실제로 당은 한반도 전체 통치 시도 → 나당전쟁 원인

드라마 자문 포인트:
  하린 시점: 나당연합 = 신라 생존을 위한 불가피한 선택
  고루 시점: 신라의 외세 끌어들이기 = 배신
  → 4인의 이념 충돌 설정 역사적으로 유효
```

### 나당연합의 성과와 한계

```
성과:
  660년: 백제 멸망 (황산벌·백강구 전투)
  668년: 고구려 멸망
  → 삼국시대 종결

한계·모순:
  당나라의 야심: 「웅진도독부」「안동도호부」설치
  → 한반도 전체를 당의 영토로 편입 시도
  신라의 반발: 나당전쟁 (670~676년)
  → 기벌포 해전 신라 승리 → 당 철수

자문 포인트:
  하린의 딜레마: 동맹을 맺었지만 배신당함
  「죗값을 치를 것」의 의미: 나당전쟁 예고
  역사적 아이러니 서사로 활용 가능
```

## 백제·왜국 관계

### 백제-왜 동맹 구조

```
관계 성격:
  백제 → 왜: 선진 문화·기술 전수 (불교·한자·건축·의술)
  왜 → 백제: 군사 지원 (병력·선박)
  → 「문화 보호자와 군사 동맹」비대칭 관계

칠지도(七支刀) 외교:
  백제 근초고왕(369년 추정) → 왜왕에게 하사
  의미: 백제가 상위 위치에서 하사하는 의전품
  vs 일본서기 해석: 왜왕에게 헌상품

  드라마 자문:
    「백제가 일본에 무엇을 주었는가」시퀀스
    아랑 시점: 문화 전수 = 기억의 연장
    칠지도 = 바다를 건넌 기억의 물건
```

### 백강구 전투 (663년)

```
배경:
  660년 백제 멸망 후 백제 부흥운동
  왜국 군사 지원: 수군 1,000여 척 (대규모 원군)
  나당연합군 vs 왜·백제 부흥군

결과:
  나당연합 압도적 승리 → 백제 부흥 완전 소멸
  왜국: 한반도 개입 포기 → 이후 내향적 발전
  → 일본 고대 국가 형성 전환점

드라마 자문:
  아랑의 백강구 목격: 문서 기록자 시점
  「나는 이 날을 기록해야 한다」
  역사 기록의 의무 vs 개인적 비통함
```

## 고구려·돌궐 관계

```
돌궐(突厥)과의 연대:
  고구려: 수·당 견제를 위해 돌궐과 외교
  수·당: 고구려-돌궐 연대 차단 전략

군사 협력 가능성:
  고구려 기병 전술에 돌궐 영향
  요동 평원 기마 문화 교류
  → 고루 캐릭터 배경: 요동 지역 돌궐 교역로 경험 가능

드라마 자문:
  고루가 수나라 침략 이전 돌궐과 접촉하는 씬 가능
  「고구려의 외교는 모든 방향으로 열려 있다」
```

## 외교 씬 자문 프로세스

```
자문 의뢰 유형:
  A. 대사 검토: 외교 씬 대사 역사적 타당성
  B. 설정 검토: 외교 제도·의전·사신 행동 방식
  C. 창작 검토: 역사 외교와 창작 서사 충돌 여부

검토 기준:
  삼국사기·삼국유사 원전 확인 (1차)
  중국 정사(수서·구당서·신당서) 교차 확인 (2차)
  일본서기 관련 장면 (3차, 임나일본부 제외)
  현대 학술 연구 반영 (4차)

검토 소요:
  A형 (대사): 2영업일
  B형 (설정): 3영업일
  C형 (창작): 5영업일

금지 표현:
  동북공정 관점 (고구려=중국사) 수용 표현
  임나일본부설 반영 대사
  수·당 침략을 중화 문명 전파로 미화하는 표현
  역사적 조공을 현대적 종속 관계로 단순화하는 표현
```

## 게임 외교 시스템 자문

```
외교 메커닉 검토 항목:
  ① 조공·책봉 시스템 구현 방식
  ② 동맹·배신 이벤트 역사성
  ③ 나당연합 이벤트 트리거 조건
  ④ 왜국·돌궐 교섭 옵션
  ⑤ 역사 이벤트 분기 허용 범위

허용 창작 범위:
  역사 결과(승패)는 유지
  외교 협상 과정: 창작 가능
  가상 외교 루트: 「만약 고구려가 신라와 연합했다면」DLC 가능

금지 창작:
  나당연합 없이 신라 단독 삼국통일
  고구려가 수나라에 항복하는 루트
  → 역사 왜곡 기준 (critic-review.md 참조)
```
