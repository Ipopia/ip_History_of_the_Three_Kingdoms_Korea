## 1. 고구려 (Goguryeo, 高句麗)

### 1.1 왕권의 성격

고구려의 왕권은 **절대 왕정이 아닌 귀족 합의제적 왕정**이었다. 초기에는 5부 연맹장 중 하나가 왕으로 추대되는 형태였으며, 점차 왕권이 강화되었으나 귀족 세력과의 권력 균형이 유지되었다.

- **초기(건국~3세기)**: 5부 연맹체 대표로서의 왕
- **중기(4~5세기)**: 광개토대왕·장수왕 시기 왕권 전성기
- **후기(6~7세기)**: 귀족 권력 비대화, 대막리지(大莫離支) 출현

### 1.2 제가회의 (諸加會議)

고구려 최고 귀족 합의 기구. 국가 중대사를 결정하는 **귀족 대표자 회의**이다.

| 항목 | 내용 |
|------|------|
| 명칭 | 제가회의(諸加會議) |
| 구성원 | 각 부(部)의 대가(大加), 고추가(古雛加) 등 고위 귀족 |
| 의결 사항 | 왕위 계승, 전쟁·화친, 중대 형벌, 외교 방침 |
| 의장 | 대대로(大對盧) 또는 막리지(莫離支) |
| 특징 | 왕도 회의의 결정을 무시하기 어려움 |

### 1.3 5부 체제 (五部體制)

고구려는 **5개의 부(部)**로 구성된 부족 연맹 국가에서 출발했다.

| 부(部) | 한자 | 방위 | 비고 |
|--------|------|------|------|
| 계루부(桂婁部) | 桂婁部 | 중앙 | **왕족 소속**, 국내성 기반 |
| 소노부(消奴部) | 消奴部 | 서 | 초기 왕족, 비류국 계통 |
| 절노부(絶奴部) | 絶奴部 | 북 | 군사적 강세 |
| 순노부(順奴部) | 順奴部 | 동 | 농업·생산 기반 |
| 관노부(灌奴部) | 灌奴部 | 남 | 교역·대외 접촉 |

- 초기에는 소노부에서 왕을 배출했으나, **주몽(朱蒙) 이후 계루부가 왕위를 독점**
- 각 부는 독자적 군사력과 행정력을 보유
- 5부 체제는 이후 행정 구역으로 재편 (동부·서부·남부·북부·내부)

### 1.5 대막리지(大莫離支) 제도

기존 관등 체계를 초월한 **비상 최고 권력직**.

- **막리지(莫離支)**: 본래 고구려 고위 관직의 하나
- **대막리지(大莫離支)**: 연개소문(淵蓋蘇文, Yeon Gaesomun)이 642년 정변을 통해 영류왕을 시해하고 **자칭**한 직위
- 성격: 군사·행정·외교 전권을 장악한 **독재적 최고 권력자**
- 연개소문 사후 아들 남생(男生)·남건(男建)·남산(男産)이 세습하며 내분 → 고구려 멸망의 직접 원인

| 대막리지 | 기간 | 비고 |
|----------|------|------|
| 연개소문(淵蓋蘇文) | 642~666 | 영류왕 시해, 보장왕 옹립, 당 침략 격퇴 |
| 연남생(淵男生) | 666~? | 장남, 동생들과 내분 → 당에 투항 |
| 연남건(淵男建) | 666~668 | 차남, 최후까지 항전 |

### 1.6 지방 통치: 성주(城主) 제도

고구려는 광대한 영토를 **성(城)** 단위로 통치했다.

- **성주(城主)**: 각 성의 최고 지방관. 군사·행정·사법권 보유
- **처려근지(處閭近支)**: 성주 아래 실무 행정관
- 주요 성: 국내성(國內城), 평양성(平壤城), 안시성(安市城), 요동성(遼東城), 비사성(卑沙城)
- 전략적 요충지에는 **욕살(褥薩)**을 파견 (군관구 사령관 성격)

## 2. 백제 (Baekje, 百濟)

### 2.1 왕권의 성격

백제의 왕권은 **왕족(부여씨/扶餘氏)과 대성팔족(大姓八族) 귀족의 권력 균형** 위에 성립했다.

- **한성(漢城) 시기(~475)**: 왕권 비교적 강력
- **웅진(熊津) 시기(475~538)**: 피난 이후 귀족 세력 비대, 왕권 약화
- **사비(泗沘) 시기(538~660)**: 성왕의 개혁으로 왕권 재강화 시도

### 2.2 정사암 회의 (政事巖會議)

백제 최고 귀족 합의 기구.

| 항목 | 내용 |
|------|------|
| 명칭 | 정사암 회의(政事巖會議) |
| 장소 | 호암사(虎巖寺) 부근 바위(정사암) |
| 방식 | 재상 후보자 이름을 바위 위에 놓고 **봉인 후 개봉** → 이름 위에 도장이 찍힌 자를 재상으로 선출 |
| 의결 사항 | 재상 선출, 국가 중대사 |
| 특징 | **하늘의 뜻(천의)** 형식을 빌린 귀족 합의 |

### 2.6 담로(擔魯) 제도

백제 고유의 **왕족 파견 지방 통치 제도**.

- **담로(擔魯)**: '성읍(城邑)' 또는 '읍락(邑落)'을 뜻하는 백제어
- 전국 22개 담로에 **왕족(왕자·왕족)을 직접 파견**하여 지방을 통제
- 목적: 지방 귀족의 자립 방지, 왕권 강화
- 양직공도(梁職貢圖) 기록: "旁小國有叛, 遣子弟鎮之, 號爲擔魯" (곁의 소국이 반란하면 자제를 보내 진압하고 담로라 함)
- 해외(일본 열도·중국 남해안 교역 거점)에도 담로 설치 가능성 제기

## 3. 신라 (Silla, 新羅)

### 3.1 왕권의 성격

신라의 왕권은 **골품제(骨品制)**라는 독특한 혈통 기반 신분 제도와 **화백회의(和白會議)**라는 귀족 합의체에 의해 규정되었다.

- **초기(~6세기)**: 박·석·김 3성 교대 왕위. 왕호도 거서간→차차웅→이사금→마립간 변천
- **중기(6~7세기)**: 법흥왕~진덕여왕, 왕권 강화·율령 반포
- **통일기(7세기~)**: 왕권 절정, 전제왕권 지향

### 3.2 골품제 (骨品制, Bone-Rank System)

신라의 핵심 사회·정치 체제. **혈통에 따라 사회적 지위·관등 상한·일상생활까지 규정**하는 폐쇄적 신분 제도.

| 골품 | 한자 | 자격/특징 |
|------|------|-----------|
| **성골(聖骨)** | 聖骨 | 부모 **모두** 왕족 혈통. **왕위 계승 독점권**. 진덕여왕(654) 이후 소멸 |
| **진골(眞骨)** | 眞骨 | 부모 **한쪽**이 왕족 혈통. 성골 소멸 후 왕위 계승. 최고 관등(이벌찬)까지 승진 가능 |
| 6두품(六頭品) | 六頭品 | 관등 6위(아찬)까지. 학식 높으나 정치적 한계 → 불만 계층 |
| 5두품(五頭品) | 五頭品 | 관등 10위(대나마)까지 |
| 4두품(四頭品) | 四頭品 | 관등 12위(대사)까지 |
| 3~1두품 | — | 기록 드묾, 평민층으로 추정 |
| 평민(平民) | 平民 | 일반 백성 |

**골품에 따른 제한 (예시)**:

| 항목 | 진골 | 6두품 | 5두품 | 4두품 |
|------|------|-------|-------|-------|
| 가옥 넓이 | 제한 없음 | 24자 이하 | 21자 이하 | 18자 이하 |
| 수레 장식 | 금·은 허용 | 은만 허용 | 동(銅) | 불가 |
| 복식 | 비단·자색 | 비단 일부 | 제한 | 제한 |
| 최고 관등 | 1위(이벌찬) | 6위(아찬) | 10위(대나마) | 12위(대사) |

### 3.3 화백회의 (和白會議)

신라 최고 귀족 합의 기구. **만장일치**를 원칙으로 한다.

| 항목 | 내용 |
|------|------|
| 명칭 | 화백회의(和白會議) |
| 의장 | 상대등(上大等) |
| 구성원 | 대등(大等) — 진골 귀족 대표들 |
| 장소 | 신성(神聖)한 장소 4곳을 돌아가며 개최 (청송·오지·피전·금강) |
| 의결 방식 | **만장일치(滿場一致)** — 한 명이라도 반대하면 부결 |
| 의결 사항 | 왕위 계승, 전쟁·화친, 중요 관직 인사, 불교 수용 등 |

> **화백의 만장일치제**: 민주적으로 보이나 실제로는 **진골 귀족 소수의 과두정치**. 소수가 합의하면 결정되는 구조.

| 역사 | 법흥왕(531) 때 설치. 왕권과 귀족권의 조율자 역할 |

### 3.6 화랑도 (花郎徒, Hwarangdo)

신라의 **엘리트 청년 무사 집단**이자 교육·수양 기관.

| 항목 | 내용 |
|------|------|
| 설립 | 진흥왕(眞興王) 시기 (576년경) |
| 구성 | 화랑(花郎, 지도자 1명) + 낭도(郎徒, 수백~수천명) |
| 신분 | 화랑은 주로 **진골·6두품** 귀족 자제 |
| 활동 | 산천 유람, 무술 수련, 학문, 가악(歌樂) |
| 이념 | **세속오계(世俗五戒)** — 원광법사 제정 |

**세속오계 (世俗五戒)**:
1. 사군이충(事君以忠) — 임금을 충성으로 섬기라
2. 사친이효(事親以孝) — 부모를 효도로 섬기라
3. 교우이신(交友以信) — 벗을 신의로 사귀라
4. 임전무퇴(臨戰無退) — 싸움에 임하여 물러서지 마라
5. 살생유택(殺生有擇) — 살아있는 것을 함부로 죽이지 마라

**유명 화랑**:
- 관창(官昌) — 황산벌 전투에서 16세에 장렬히 전사
- 사다함(斯多含) — 대가야 정벌에서 활약
- 김유신(金庾信) — 삼국통일의 영웅 (가야계)
- 김흠운(金歆運) — 대야성 전투에서 전사

## 4. 가야 (Gaya, 伽倻)

### 4.1 연맹 체제의 성격

가야는 **통일 왕국을 형성하지 못한 연맹체**였다. 각 가야국이 높은 자치권을 유지하면서 맹주국을 중심으로 느슨하게 연합했다.

### 4.2 전기 가야 연맹 (1~4세기): 금관가야(金官伽倻) 중심

| 항목 | 내용 |
|------|------|
| 맹주 | 금관가야(金官伽倻) — 현 경남 김해 |
| 시조 | 수로왕(首露王) |
| 기반 | 철(鐵) 생산·교역. 낙동강 하구의 해상 교역 거점 |
| 쇠퇴 | 4세기 광개토대왕의 남정(400년)으로 타격 |

### 4.3 후기 가야 연맹 (5~6세기): 대가야(大伽倻) 중심

| 항목 | 내용 |
|------|------|
| 맹주 | 대가야(大伽倻) — 현 경북 고령 |
| 전성기 | 5세기 후반~6세기 전반 |
| 멸망 | 562년 신라 진흥왕에게 멸망 |

### 4.5 가야의 정치 구조

- **왕(王)/한기(旱岐)**: 각 가야국의 수장. '한기'는 고유어 칭호
- **귀족 합의**: 각국 독자적 귀족 회의 운영
- **맹주국의 한계**: 다른 가야국에 대한 강제력 부족, 내정 간섭 어려움
- 중앙집권화 실패가 **멸망의 근본 원인**
