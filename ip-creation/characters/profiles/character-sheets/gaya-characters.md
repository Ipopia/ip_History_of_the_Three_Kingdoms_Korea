## 1. 김수로왕 (金首露王) — 가야 건국 군주

### 기본 정보
| 항목 | 내용 |
|------|------|
| 생몰 | 42~199 AD (전설 기준) |
| 신분 | 금관가야 초대 왕 |
| 별칭 | 수로(首露), 하늘에서 내려온 자 |
| 모티프 색 | 왕실금(#B8960C) + 토적(#8B4513) |

### 역사·신화적 배경
삼국유사 가락국기(駕洛國記)에 기록된 건국 신화의 주인공. 하늘에서 내려온 황금 알 여섯 개 중 첫 번째로 태어났으며, 구지봉(龜旨峯)에서 구지가(龜旨歌)를 부르는 백성들 앞에 현현했다. 아유타국(인도)의 공주 허황옥(許黃玉)과 혼인하여 가야의 국제적 성격을 확립했다.

### 성격 프로필
**핵심 성격**: 카리스마적 창업자 + 실용주의적 통치자

- **강점**: 탁월한 통합력, 백성의 신뢰 구축, 철 생산과 교역의 국제화
- **약점**: 후계 문제의 소홀, 가야 연맹체의 분열 씨앗을 방치
- **내면 갈등**: 하늘의 뜻과 땅의 현실 사이 — "나는 신으로 왔으나 인간으로 늙어간다"

### 대표 대사
```
"구지봉에서 노래가 들렸다. 나는 그 노래에 응답했을 뿐이다.
 왕은 백성이 부르는 것이다."

"허황옥이 바다를 건너 왔다. 가야는 바다를 두려워하지 않는다.
 철이 세상을 묶듯, 우리는 바다로 세상과 연결된다."
```

### 서사 아크
- **건국기**: 구지봉 신화, 6가야 연맹 형성, 허황옥과의 혼인
- **치세**: 철 생산 체계 확립, 왜·중국·신라와의 교역 외교
- **노년**: 후계 구도 고민, 가야의 영원성에 대한 성찰

## 2. 우륵 (于勒) — 가야금의 아버지

### 기본 정보
| 항목 | 내용 |
|------|------|
| 생몰 | 6세기 추정 |
| 출신 | 가야 (금관가야 또는 대가야) |
| 직위 | 악사·음악가, 후기 신라 귀화 |
| 모티프 색 | 청동(#4A7C6F) + 해변사(#C8B898) |

### 역사적 배경
삼국사기에 기록된 가야금(伽倻琴) 창시자. 가야 멸망 직전 신라로 귀화하여 12악곡을 신라에 전수. 진흥왕의 명으로 신라 음악의 초석을 놓았다. 가야의 문화적 유산을 신라를 통해 후세에 전한 음악의 구원자.

### 성격 프로필
**핵심 성격**: 내면 지향적 예술가 + 문화 전도사

- **강점**: 음악적 천재성, 문화를 통한 경계 초월, 변화 앞의 유연성
- **약점**: 정치적 무감각, 가야 왕실에 대한 죄책감
- **내면 갈등**: "나는 가야를 버린 것인가, 아니면 가야를 살린 것인가"
- **외면적 특징**: 항상 가야금을 등에 짊어짐 / 조용하고 느린 걸음 / 먼 곳을 바라보는 눈

### 대표 대사
```
"가야가 사라진다. 그러나 가야금 소리는 사라지지 않는다.
 나는 소리를 지킨다. 소리가 곧 나라다."

"왕은 신라에 항복했다. 나는 신라에 가야를 심었다.
 누가 이겼는가? 나는 아직 모른다."
```

### 서사 아크
- **가야 시절**: 12악곡 창작, 왕실 악사, 가야 멸망의 예감
- **귀화 결단**: 악기와 음악을 품고 신라 진흥왕에게 귀순
- **신라에서**: 계고·법지·만덕에게 음악 전수, 신라 문화에 흡수
- **최후**: 고향 가야 방향을 바라보며 마지막 악곡 연주

## 3. 허황옥 (許黃玉) — 바다를 건넌 왕비

### 기본 정보
| 항목 | 내용 |
|------|------|
| 출신 | 아유타국(인도 아요디아 추정) |
| 신분 | 금관가야 왕비, 김수로왕의 배우자 |
| 별칭 | 보주태후(普州太后) |
| 모티프 색 | 해변사(#C8B898) + 왕실금(#B8960C) |

### 역사적 배경
삼국유사에 기록된 가야의 왕비. 인도에서 붉은 돛배를 타고 가야에 도착하여 수로왕과 혼인. 파사석탑(婆娑石塔)을 지참하여 항해 중 파도를 진정시켰다는 전설. 가야의 국제성과 해상 교역망을 상징하는 인물.

### 성격 프로필
**핵심 성격**: 독립적 결단력 + 문화 교류의 가교

- **강점**: 비범한 용기(대양 횡단), 외교적 지혜, 두 문화 융합 능력
- **약점**: 고향에 대한 그리움, 이방인으로서의 고독
- **내면 갈등**: 왕비로서의 권위와 이방인으로서의 정체성 혼란

### 대표 대사
```
"파도가 높았다. 그러나 나는 가야가 기다린다는 것을 알았다.
 운명은 바다보다 강하다."

"나는 인도에서 왔다. 그러나 내 뼈는 가야 땅에 묻힐 것이다.
 그것으로 충분하다."
```

## 4. 이진아시왕 (伊珍阿豉王) — 대가야의 마지막 저항

### 기본 정보
| 항목 | 내용 |
|------|------|
| 시대 | 6세기 |
| 신분 | 대가야 왕 |
| 재위 | ?~562 AD |
| 모티프 색 | 저녁불(#D44828) + 탄흑(#282828) |

### 역사적 배경
대가야(大伽耶)의 마지막 왕. 562년 신라 이사부(異斯夫)와 사다함(斯多含)의 공격으로 대가야가 멸망할 때 끝까지 저항. 가야 연맹 최후의 보루. 역사 기록에 그의 이름과 최후가 간략하게만 남아 있어 창작적 재구성이 가능한 인물.

### 성격 프로필
**핵심 성격**: 비극적 마지막 왕 + 자존의 수호자

- **강점**: 불굴의 의지, 가야 정체성 수호, 백성에 대한 책임감
- **약점**: 현실 감각 부족, 고집스러운 항전 — 더 많은 희생 초래
- **내면 갈등**: "항복은 치욕인가, 백성을 살리는 지혜인가"

### 대표 대사
```
"금관가야가 무너졌다. 아라가야가 무너졌다.
 대가야는 마지막이다. 나는 마지막을 지킨다."

"신라는 가야의 땅을 원한다. 그러나 가야의 혼은 가져가지 못한다."
```

### 서사 아크
- **절박한 치세**: 고구려·백제 멸망 후 신라의 팽창 목격
- **최후의 연맹 결집**: 남은 가야 소국들을 규합하려는 시도
- **562년의 멸망**: 신라 공격, 사다함의 기병대, 대가야 함락
- **최후**: 왕궁에서 최후를 맞이하거나 투항 — 두 결말 버전 설정

## 5. 가야 장인(匠人) — 철의 사람들

### 캐릭터 유형 (창작 인물)
**이름**: 철웅(鐵雄) — 가야 제철 장인 대표 캐릭터

### 기본 정보
| 항목 | 내용 |
|------|------|
| 신분 | 금관가야 왕실 소속 제철 장인 |
| 특기 | 가야 판갑옷 제작, 철정(鐵鋌) 주조 |
| 모티프 색 | 철(#3C3C3C) + 불꽃(#E84C1E) |

### 성격 프로필
**핵심 성격**: 장인 정신의 화신 + 침묵의 자부심

- 말보다 일로 말하는 사람
- 가야의 경쟁력이 철에 있음을 본능적으로 이해
- 신라·백제·왜 상인들에게 철정(국제 화폐)을 납품하는 현실적 교역인
- 가야가 멸망하면 자신의 기술이 적국으로 넘어간다는 두려움

### 대표 대사
```
"쇠는 거짓말하지 않는다. 두들기면 강해지고,
 불에 달구면 모양이 잡힌다. 사람도 그래야 한다."

"신라가 우리 철을 원한다. 그러나 철을 만드는 손은
 가야의 것이다. 손을 잃으면 철도 없다."
```
