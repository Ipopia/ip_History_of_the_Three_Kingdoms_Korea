## 수익화 철학

삼국(三國) 게임의 수익화는 **"역사와 존중"**을 기반으로 한다. 플레이어가 역사를 배우고 서사에 몰입하는 경험에 값을 지불하는 구조. 과금 강요 없이 IP의 품격을 유지하며 지속 가능한 수익을 창출한다.

```
수익화 3원칙:
1. Pay-to-Win 금지 — 과금이 전투 승패 직결 금지
2. 역사 콘텐츠 유료화 — IP 가치 기반 과금 설계
3. 장기 운영 — 단기 수익보다 5년 이상 생태계
```

## 수익 모델 구성

### 모델 A: F2P + 프리미엄 배틀패스

```
기본 구조:
- 게임 자체: 무료 다운로드·플레이
- 수익원 1: 배틀패스 (월 9,900원)
- 수익원 2: 코스메틱 상점
- 수익원 3: DLC 캠페인 팩
- 수익원 4: 가챠 소환 (코스메틱 한정)

배틀패스 구성:
무료 트랙 — 기본 보상 (재화·소모품)
유료 트랙 (9,900원/월):
  - 왕국별 전용 의상 1종
  - 역사 해설 콘텐츠 3편
  - 특수 아이콘 + 칭호
  - 보너스 재화 2배
```

### 모델 B: 유료 캠페인 DLC

```
DLC 패키지:
기본 게임: 무료 (모바일) / 29,900원 (PC)

DLC 목록:
DLC-01 북방의 매 (광개토 스핀오프): 14,900원
DLC-02 백제의 황혼 (계백 캠페인 확장): 12,900원
DLC-03 가야의 소리 (우륵 전용 캠페인): 12,900원
DLC-04 나당전쟁 (기벌포 해전 시나리오): 9,900원
DLC-05 삼국 통합팩 (DLC 1~4 번들): 39,900원

DLC 가치 구성:
- 전용 캠페인 6~10챕터
- 역사 해설 영상 3~5편
- 전용 코스튬 2~3종
- 전용 음악 5~8곡
- 업적 10~15개 추가
```

### 모델 C: 코스메틱 상점

```
판매 품목 (전투력 영향 없음):
캐릭터 코스튬:
- 일반 코스튬: 3,300원

- 배경 테마: 3,300원
- 효과음 팩: 2,200원
```

## 가챠(ガチャ) 시스템

### 소환 시스템 설계

```
소환 대상: 코스메틱 카드 (전투력 영향 없음)
소환권 획득: 게임 플레이로만 / 직접 구매

소환 확률 (공개 의무):
일반 소환:
- 5성 코스메틱: 1.5%
- 4성 코스메틱: 8%
- 3성 이하: 90.5%

천장 시스템:
- 70회 소환 내 5성 미획득 시 → 보장 1회
- 140회 소환 내 동일 미획득 → 픽업 보장

소환권 가격:
1회: 1,500원 (인게임 코인 1,500개)
10회: 13,500원 (10% 할인)
30회: 37,800원 (16% 할인)
```

### 가챠 규제 준수

```
국내 규정:
- 확률 공개 의무 (게임산업진흥법 준수)
- 미성년자 월 결제 한도 설정
- 중복 보상 시스템 필수

일본 규정:
- 컴플리트 가챠(完全ガチャ) 금지
- 확률 표시 화면 필수
- 아이템 교환소 제공

중국 규정:
- 랜덤박스 확률 공시 의무
- 미성년자 제한 (22시~8시 접속 금지)
- 실명 인증 연동
```

## 수익 구간별 전략

### Phase 1 — 출시 (1~3개월)

```
목표: 초기 이용자 확보 + 과금 전환율

전략:
- 출시 기념팩: 9,900원 (일주일 한정)
  구성: 스타터 코스튬 3종 + 소환권 20회
- 무료 소환권 30회 제공 (신규 가입)
- 첫 구매 보너스: 50% 추가 재화
- 7일 로그인 보상: 소환권 7회

KPI:
- DAU 목표: 50만 (국내)
- ARPPU: 18,000원/월
- 전환율: DAU의 3% 이상
```

### Phase 2 — 안정기 (4~12개월)

```
목표: 배틀패스 구독자 확보

전략:
- 시즌 배틀패스 도입 (월 9,900원)
- 시즌 1: 고구려 테마 (3개월)
- 시즌 2: 백제 테마 (3개월)
- 시즌 3: 신라 테마 (3개월)
- 시즌 4: 가야 테마 (3개월)

배틀패스 리텐션:
- 완료 시 다음 시즌 티켓 10% 할인
- 3시즌 연속 구매 시 전용 아이템

KPI:
- 배틀패스 구독율: DAU의 15%
- MAU 대비 배틀패스: 8%
```

### Phase 3 — 성장기 (12개월~)

```
목표: DLC 판매 + 크로스미디어 연동

전략:
- DLC-01 출시: 드라마 방영 시즌 연계
- 드라마 방영 → 게임 플레이 유도 번들
  "드라마 시청자 팩": 드라마 OTT + 게임 DLC 묶음
- 굿즈 연동: 피규어 구매 시 인게임 코드 제공

크로스미디어 수익:
- 드라마 방영 주간: 인게임 이벤트 동시 진행
- 웹소설 연독 완료: 게임 소환권 5회 증정
- 웹툰 구독: 게임 칭호 제공
```

## 반(反) Pay-to-Win 보장 체계

```
전투력 관련 아이템 — 전부 게임 플레이로만 획득:
- 영웅 스탯 업그레이드: 게임 내 재화만
- 전투 유닛 강화: 경험치·재화 (구매 불가)
- 기술 트리: 게임 시간 투자

과금 아이템 종류:
- 코스메틱 100% (외형만)
- 역사 해설 콘텐츠 (정보 가치)
- 편의 기능 (인벤토리 확장 등)
- 진행 가속 (소량 허용 — 월 한도)

진행 가속 한도:
- 월 최대 구매 가능 가속: 72시간분
- (= 무과금 플레이 3일치)
- 초과 구매 차단 (월 한도 시스템)
```
