# 시즌 2 아웃라인 — 삼국(三國) IP

**시리즈**: 삼국(三國) — 강은 기억한다
**시즌 2 부제**: 패권의 시대 (覇權의 時代)
**시대 배경**: 3~5세기 — 삼국 성장·팽창기
**에피소드**: 14부작
**참조**: `master-outline.md`, `chronicles.md`, `arc-structure.md`

---

## 시즌 2 개요

시즌 1이 삼국의 건국(建國)을 다뤘다면, 시즌 2는 **패권 경쟁의 본격화**다. 고구려는 동아시아 강국으로 성장하고, 백제는 전성기의 황금빛을 뿜어내며, 신라는 생존 전략으로 동맹과 배신을 오간다. 가야는 세 나라 사이에서 독자 생존을 모색한다.

**시즌 2 핵심 테마**: *"강한 자가 옳은가, 아름다운 자가 오래 남는가"*

## 에피소드 구성

### E01 — 광개토의 탄생 (391년)

```
씬 구성:
- 오프닝: 고구려 평양성 — 17세 광개토가 즉위하는 장면
- 첫 선언: "내 치세에 고구려의 영토를 세 배로 넓힌다"
- 배경 설명: 전연(前燕) 침략의 상처, 고국원왕의 치욕
- 클라이맥스: 광개토왕이 첫 전투에서 백잔(백제) 국경을 공격

핵심 대사: "할아버지가 무릎을 꿇었던 땅을 내가 되찾겠다."

복선: 왕비가 아들을 임신 중 — 장수왕 탄생 예고
```

### E02 — 백제의 황금기 (346~371년, 시간 역행)

```
씬 구성:
- 시점: 광개토 즉위 전 — 근초고왕 전성기 회상 구조
- 백제 사비성 궁중 연회 장면 — 화려한 문화 구현
- 칠지도(七支刀) 제작·하사 장면 — 왜국 사신과의 외교
- 클라이맥스: 근초고왕이 북으로 고구려 원정 결정

핵심 대사 (근초고왕): "백제의 칼은 북으로 고구려,
                      동으로 신라, 서로는 바다를 건넌다."

OST: 백제 궁중 테마 — 가야금·피리 합주
```

### E03 — 평양성의 함락 (371년)

```
씬 구성:
- 고구려 고국원왕의 시점 — 패배를 감지하는 왕
- 백제 근초고왕의 군대 — 3만 기병 평양성 공격
- 고국원왕의 최후 — 성벽 위에서 화살에 맞아 전사
- 백제 병사들의 침묵 — 적왕의 죽음 앞에서

핵심 대사 (고국원왕): "왕이 도망친다면 백성이 어디로 가겠는가.
                      나는 여기 있다."

연출: 왕의 죽음을 직접 보여주지 않음 — 화살이 날아오는 소리만
```

### E04 — 광개토의 복수 (392~396년)

```
씬 구성:
- 광개토왕 즉위 1년차 — 백제 국경 58성 공략
- 광개토대왕릉비 첫 문장 기록 시작 (서기관 시점)
- 백제 아신왕의 항복 — "영원히 신(臣)이 되겠습니다"
- 광개토: 항복을 받아내되 백제를 멸망시키지 않음

핵심 대사: "더 가라. 지평선이 끝날 때까지."

지도 VFX: 고구려 영토 확장 애니메이션 — 릉비 문자와 연동
```

### E05 — 신라를 구하다 (400년)

```
씬 구성:
- 신라 내물마립간의 절박한 사신 파견 — 왜구 침략
- 광개토왕의 결단: "신라를 돕겠다. 그러나 그 대가는 크다."
- 5만 고구려 군 남하 — 금관가야·왜군 격퇴
- 광개토대왕릉비 "任那加羅從拔城" 기록 연동

신라 파트:
- 내물마립간의 안도와 불안 교차
- "우리는 고구려의 도움을 받았다. 이것은 빚이다."

핵심 장면: 고구려 기병이 신라 도성 서라벌에 입성하는 장면
          — 해방인가 점령인가 모호한 감정
```

### E06 — 박제상의 충절 (402~417년)

```
씬 구성:
- 내물마립간 사후 — 눌지마립간 즉위
- 왕제 미사흔(未斯欣)이 왜국 볼모로 잡혀 있음
- 박제상(朴堤上) 파견 — 목숨 걸고 왕제 탈출 계획
- 박제상의 계략으로 왕제 구출 — 자신은 왜에 남겨짐
- 박제상 고문·처형 — 아내가 치술령(鵄述嶺)에서 기다림

핵심 대사 (박제상): "나는 신라의 신하다. 왜의 노예가 아니다."

후일담: 박제상의 아내가 치술령에서 돌이 되었다는 전설 — 치술령 신모(神母)
감성 포인트: 가장 많은 시청자 눈물 예상 장면
```

```
씬 구성:

- 64성 1,400촌 점령 완료 — 릉비 기록 완성

핵심 장면: 광개토대왕릉비 건립 장면 — 거대한 돌 위에 글자 새김
           "國岡上廣開土境好太王"

감정 기조: 위대한 생의 아쉬운 마무리 — 짧은 생, 긴 기록
```

### E08 — 가야의 시련 (400년 이후)

```
씬 구성:
- 금관가야 — 광개토왕의 공격 후 국력 쇠퇴
- 가야 연맹 내부 분열 — 금관가야 vs 대가야 패권 다툼
- 가야 철의 독점력 약화 — 고구려·백제·신라 모두 철 기술 습득
- 가야 장인 집단의 고뇌 — 기술을 어느 나라에 팔 것인가

핵심 대사 (가야 장인): "쇠는 거짓말하지 않는다.
                       그러나 쇠를 사는 자들은 거짓말한다."

복선: 우륵의 증조부 세대 — 가야금 원형 악기 등장 (시즌 3 복선)
```

### E09 — 백제의 위기 (475년)

```
씬 구성:
- 장수왕의 남하 정책 — 평양 천도 후 백제 압박
- 백제 개로왕(蓋鹵王) — 위기를 감지하지 못한 왕
- 도림(道琳) 스파이 사건 — 고구려 승려가 백제에 잠입
  (바둑으로 개로왕의 신임 얻고 국력 낭비 유도)
- 한성(漢城) 함락 — 개로왕 전사, 백제 한강 상실

핵심 장면: 도림이 백제를 떠나는 밤 — "나는 백제를 좋아했다"

감정의 복잡성: 도림 캐릭터 — 스파이이지만 백제 문화에 매료된 인물
```

```
                 강이 방향을 바꿔도 백제는 흐른다."

OST: 백제 중흥 테마 — 고난 속 아름다움
```

### E11 — 신라의 도약 (500년대)

```
씬 구성:
- 지증왕(智證王) — 국호 "신라" 확정, 왕호 "왕" 채택
- 이사부(異斯夫) — 우산국(울릉도) 정벌 (목사자 전략)
- 법흥왕(法興王) — 불교 공인 (528년)
  → 이차돈(異次頓)의 순교 장면 — 목에서 흰 피가 흐름
- 신라 삼국 중 가장 늦게 발전했으나 가장 체계적

핵심 장면: 이차돈 순교 — "내 목을 치십시오. 부처가 증명할 것입니다"

감성 포인트: 신앙과 정치의 충돌 — 불교 공인의 역사적 순간
```

### E12 — 진흥왕의 야망 (540~553년)

```
씬 구성:
- 진흥왕(眞興王) 즉위 — 화랑도 창설
- 나제(羅濟) 동맹으로 한강 회복 공동 작전
- 배신의 순간 — 신라가 백제 몫 한강 하류 탈취
- 성왕의 분노 — 친정 결정
- 화랑 첫 세대 — 사다함 소년 등장 (시즌 3 복선)

핵심 장면: 진흥왕이 지도 위에 손을 올리는 장면
"한강은 신라의 것이다."

도덕적 딜레마: 동맹 배신이 정당화될 수 있는가
              — 진흥왕을 악역으로 단순화하지 않음
```

### E13 — 관산성의 비극 (554년)

```
씬 구성:

- 관산성(管山城) 전투 — 신라 매복

                      그러나 백제는 그래도 꽃처럼 아름다워야 한다."

연출: 성왕의 죽음 — 화려했던 백제 황금기의 종언
```

### E14 — 강은 기억한다 (시즌 2 피날레)

```
씬 구성:
- 3개국 동시 편집 — 각국의 현재 상태

클라이맥스 OST: 메인 테마 "강은 기억한다" 오케스트라 풀 버전
```

## 시즌 2 제작 메모

```
고증 핵심:
- 광개토대왕릉비 실제 문장 직접 활용 권장 (한자 자막 처리)
- 근초고왕 시대 백제 복식 — 중국 동진 영향 + 백제 고유 혼합
- 이차돈 순교 — "흰 피" 전설 그대로 표현 (불교 기적 신화)

캐스팅 주의:
- 광개토대왕: 카리스마와 지성 동시 — 20대 후반~30대 초반 배우
- 근초고왕: 중후한 위엄 — 40대 중반 배우 권장
- 박제상: 내면 깊이 — 30대 중반 정극 배우

OST 방향:
- 고구려 파트: 대편성 오케스트라 + 거문고
- 백제 파트: 가야금·피리 + 현악 앙상블
- 신라 파트: 대금 + 범종 울림
- 가야 파트: 독주 가야금 + 제철 리듬 퍼커션
```
