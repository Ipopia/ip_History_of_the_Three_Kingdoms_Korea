## 패키징 디자인 철학

```
핵심 원칙:
  「패키지 자체가 굿즈다」
  개봉 경험(언박싱) = 콘텐츠의 연장

디자인 방향:
  왕국별 색채 아이덴티티 반영
  전통 문양 + 현대 미니멀리즘 혼합
  환경: 재활용 가능 소재 우선 (FSC 인증 종이)

불법 복제 방지:
  공식 QR 인증 코드 (패키지 내부)
  홀로그램 정품 스티커 (한정판)
  일련번호 레이저 각인 (프리미엄 라인)
```

---

## 패키징 등급 체계

```
TIER 1 — 스탠다드 (일반 굿즈):
  소재: 350g 아트지 박스
  마감: 무광 UV 코팅
  인쇄: 4도 오프셋
  예산: 단가 500~1,500원

TIER 2 — 프리미엄 (한정 굿즈):
  소재: 2mm 회색 합지 + 아트지 래핑
  마감: 부분 UV + 엠보싱
  특수: 자석 개폐 또는 리본 개봉
  예산: 단가 3,000~8,000원

TIER 3 — 럭셔리 (컬렉터블):
  소재: 원목 케이스 (오동나무·흑단목·자작나무)
  마감: 옻칠 또는 왁스 코팅
  특수: 레이저 각인 + 지문 방지 처리
  예산: 단가 15,000~50,000원
```

## 왕국별 패키징 디자인

### 고구려 패키징

```
기본 색상: 군청 #2F4F7F (배경) + 은회색 (텍스트)
문양: 삼족오 (세 발 까마귀) 윤곽선 패턴
폰트: 고딕 계열 굵고 각진 서체
레이아웃: 좌측 정렬 + 여백 최소화 (힘·밀도)

TIER 1 예시 (고루 아크릴 스탠드):
  박스 정면: 군청 배경 + 고루 일러스트 (은박)
  측면: 삼족오 반복 패턴
  내부: 검정 스펀지 + 제품 고정

TIER 3 예시 (고루 스태추):
  자작나무 케이스 (군청 염색)
  뚜껑: 삼족오 레이저 각인
  내부: 회색 벨벳 라이닝
  동봉: 번호 인증서 (한지 + 붓글씨 서체)
```

### 백제 패키징

```
기본 색상: 황금 #B8960C (배경) + 진한 갈색 (텍스트)
문양: 봉황·연꽃 당초문 패턴
폰트: 명조 계열 우아한 서체
레이아웃: 중앙 정렬 + 충분한 여백 (우아함)

TIER 1 예시 (금동대향로 미니어처):
  박스 정면: 황금 배경 + 봉황 금박
  측면: 연꽃 문양 양각 엠보싱
  내부: 금색 새틴 리본 + 면장갑 동봉

TIER 3 예시 (아랑 스태추):
  흑단목 케이스 (황금 테두리 장식)
  뚜껑: 봉황 24K 금도금 장식
  내부: 아이보리 벨벳 라이닝
```

### 신라 패키징

```
기본 색상: 금색 #FFD700 (배경) + 흰색 (텍스트)
문양: 신라 금관 곡옥(曲玉) 패턴
폰트: 세리프 계열 밝고 선명한 서체
레이아웃: 대칭·균형 (화려하고 정돈된 느낌)

TIER 1 예시 (신라 금관 키링):
  박스: 투명 아크릴 윈도우 박스 (금색 프레임)
  배경: 금색 카드지 + 곡옥 패턴

TIER 2 예시 (하린 피규어):
  클램셸 박스 (금색 + 흰색)
  창문형 디스플레이 (제품 보임)
  자석 개폐 + 내부 별지 캐릭터 설명
```

### 가야 패키징

```
기본 색상: 황토 #C8A96E (배경) + 진갈색 (텍스트)
문양: 가야금 현(絃) 직선 패턴 + 철정 문양
폰트: 손글씨 느낌 서체 (온기·서정성)
레이아웃: 비대칭·자연스러운 구성 (가야 소박함)

TIER 1 예시 (니문 가야금 키링):
  크라프트 박스 (무漂白 재생지)
  황토색 리본 + 손글씨 태그
  내부: 천연 마대 포장재

TIER 3 예시 (니문 스태추):
  오동나무 케이스 (자연 목재 그대로)
  뚜껑: 가야금 현 레이저 각인 (12줄)
  내부: 황토색 린넨 라이닝
```

## 4왕국 공통 패키징

### 한정 박스 세트

```
4인 스태추 세트 박스 (100세트 한정):
  소재: 특대형 오동나무 케이스 (60cm × 40cm × 25cm)
  외부: 검정 옻칠 + 살수 강물 금박 레이저
  뚜껑 내부: 4인 일러스트 아트프린트 (A3)
  내부 구획: 4칸 분리 (왕국별 색 벨벳)
  동봉:
    번호 인증서 (서예가 친필)
    4왕국 왕국 인장 왁스씰 4개
    「강은 기억한다」소형 아트북 (100페이지)

언박싱 경험 설계:
  1단계: 외부 박스 → 리본 절단
  2단계: 뚜껑 오픈 → 아트프린트 발견
  3단계: 아트프린트 들어올리기 → 4칸 스태추 노출
  4단계: 각 스태추 개별 포장 해제
  목표: 언박싱 영상 15분 이상 콘텐츠 유도
```

### 시즌 한정 박스

```
시즌 드라마 DVD/블루레이 박스:
  TIER 2 (자석 개폐 하드커버 박스)
  측면: 시즌별 핵심 장면 일러스트
  내부: 디스크 + 아트북 + 포토카드 6장
  특전: 극장판 포스터 (A2)

방영 기념 굿즈 박스:
  시즌 1 방영 기념 박스 (500개 한정):
    드라마 클립 USB + 포토카드 + 키링 + 스티커
    테마: 살수대첩 — 군청 배경 패키징
```

## 환경·지속가능성 기준

```
소재 기준:
  종이류: FSC 인증 재활용지 우선 (70%+)
  플라스틱: 생분해 PLA or 재활용 PET만 허용
  잉크: 수성 잉크 (VOC 최소화)
  접착제: 수성 접착제

럭셔리 패키징 예외:
  원목 케이스: FSC 인증 목재 필수
  금속 장식: 재활용 금속 우선
  옻칠: 천연 옻 수지 사용

환경 인증 목표:
  2026년: 스탠다드 라인 100% FSC 달성
  2027년: 전 라인 플라스틱 사용 50% 감축
  포장재에 친환경 인증 마크 표시 의무화

과잉 포장 금지:
  스탠다드 제품: 제품 부피 대비 2배 이하
  불필요한 내부 포장재 최소화
  충전재: 종이 완충재 (스티로폼 금지)
```

## 제작 협력사 기준

```
국내 협력사:
  인쇄: ISO 9001 + FSC 인증 보유 업체
  원목 케이스: 전통 공예 협력사 (국가 인증 장인 우선)
  금속 장식: 국내 귀금속 가공 협력사

해외 협력사:
  중국: 품질·환경 기준 동일 적용 (별도 QC 파견)
  일본: JIS 인증 업체 우선

QC 기준:
  인쇄 색상: 브랜드 팬톤(Pantone) 기준 ±2% 이내
  원목 케이스: 함수율 12% 이하 (변형 방지)
  금박·레이저: ADV-ARCH 문양 정확도 확인
  최종 승인: ART-DIR + MERCH-PKG 공동 확인
```
