# 인플루언서 전략 — 삼국(三國) IP

**참조 문서**: `brand-identity.md`, `sns-content-calendar.md`, `campaign-plan.md`, `press-kit.md`
**작성**: 마케팅본부 SNS팀 + 글로벌사업본부
**적용 기간**: 출시 전 3개월 ~ 출시 후 6개월

---

## 전략 개요

삼국(三國) IP는 **역사·문화·엔터테인먼트**가 결합된 프리미엄 콘텐츠다. 인플루언서 전략은 단순 홍보가 아닌 **IP 세계관의 자연스러운 확산**을 목표로 한다. 역사 교육 채널부터 K-드라마 팬덤까지, 타깃 오디언스별 맞춤 인플루언서를 선별한다.

### 핵심 전략 원칙

```
1. 진정성 우선: 상업적 느낌 최소화 — 인플루언서가 진심으로 좋아하는 콘텐츠
2. 세계관 몰입: 단순 광고가 아닌 스토리텔링 참여
3. 교육 + 오락: "알고 보면 더 재밌는" 역사 콘텐츠
4. 글로벌 동시 확산: 한·일·중·영어권 동시 공략
5. 장기 앰배서더: 일회성 광고보다 지속적 파트너십
```

**역할**: 초기 인지도 폭발적 확산
**목표**: 출시 전 15일 내 500만+ 도달

| 카테고리 | 채널 유형 | 팔로워 | 콘텐츠 형식 | 예산(건당) |
|--------|---------|--------|-----------|----------|
| K-드라마 리뷰 | YouTube | 200만+ | 시즌 예고 분석 영상 | 3,000만 원 |
| 한국 역사 | YouTube | 150만+ | "삼국시대 진짜 역사" 교육 | 2,500만 원 |
| K-컬처 전반 | Instagram | 300만+ | 비주얼 화보 협업 | 2,000만 원 |
| 게임 스트리머 | Twitch/YouTube | 200만+ | 게임 사전 체험 스트리밍 | 2,500만 원 |

**Tier 1 선정 기준**:
- 역사·문화 콘텐츠 진성 관심 확인
- 이전 광고 콘텐츠 반응률 3%+
- 브랜드 세이프티 이슈 없음

### Tier 3 — 마이크로 인플루언서 (팔로워 1만~10만)

**역할**: 커뮤니티 밀착 + 바이럴 씨앗 심기
**목표**: 팬덤 자생적 확산 생태계 구축

```
마이크로 인플루언서 특성:
- 팔로워 신뢰도 최고 (친구 같은 관계)
- 전환율 메가 인플루언서의 3~5배
- 특정 니치 커뮤니티 장악

선정 영역:
□ 한국 고대사 스터디 채널 (유튜브/블로그) × 20개
□ 삼국시대 관련 작가/작가 지망생 × 15개
□ 한복·전통문화 체험 채널 × 10개
□ K-드라마 덕후 (해외) × 30개
□ 게임·RPG 소규모 유튜버 × 20개
□ 뮤지컬·공연 팬 계정 × 10개

총 마이크로 인플루언서: 약 105개 채널
예산: 채널당 100~300만 원 (제품 협찬 + 소정 원고료)
```

**역할**: 진성 팬 확보 + UGC 생성
**전략**: 공식 팬 클럽 프로그램 연동

```
팬클럽 앰배서더 프로그램:

- 혜택: 독점 콘텐츠 선공개, 굿즈 키트, 간담회 초청
- 의무: 월 4회 이상 자발적 콘텐츠 포스팅

UGC (User Generated Content) 캠페인:
- 해시태그: #삼국이기억한다 #TheRiverRemembers
- 이벤트: "내가 고른 삼국의 명장면" 팬아트 공모

## 카테고리별 인플루언서 전략

### A. 역사·교육 채널 전략

**목표**: "삼국(三國) IP = 정확한 역사 + 재미있는 서사" 포지셔닝

```
콘텐츠 방향:
1. "살수대첩, 실제로 어떻게 싸웠나?" — 역사 팩트체크 형식
2. "을지문덕이 시를 보낸 이유" — 역사 속 숨겨진 이야기
3. "가야금 창시자 우륵, 그는 배신자인가?" — 역사적 재해석
4. "광개토대왕 진짜 영토는?" — 지도 시각화

협업 형식:
- 6~15분 YouTube 영상 (중간 광고 아님, PPL 형식)
- 영상 마지막: "더 알고 싶다면 삼국(三國) IP로" 자연스러운 유도
- 자문: IP 역사 자문본부가 팩트체크 지원 제공
```

---

### B. K-드라마·엔터 채널 전략

**목표**: K-드라마 팬덤의 기대감 폭발

```
콘텐츠 방향:
1. 드라마 캐스팅 발표 전: "삼국 드라마, 이 역할에 누가 어울릴까?"
2. 캐스팅 발표 후: "배우 분석 + 실제 역사 인물 비교"
3. 티저 공개: "장면 하나하나 뜯어보기"
4. 방영 중: "이번 화 역사 사실 vs 창작 구분"

해외 K-드라마 팬덤 공략:
- 영어권: "Three Kingdoms drama explained" 시리즈
- 일본: 한국 사극 소개 특화 채널 (일본에서 한국 사극 인기 높음)
- 동남아: Vlog 형식 체험기 (현장 방문·굿즈 개봉)
```

---

### C. 게임·스트리머 전략

**목표**: 게임 출시와 동시에 스트리밍 생태계 형성

```
콘텐츠 방향:
1. 사전 체험단 스트리밍 (출시 전 2주)
2. 왕국별 공략 영상 경쟁 ("고구려 vs 백제 어느 나라가 강한가")
3. 전설 등급 영웅 리뷰 (광개토대왕·을지문덕·계백 등)
4. 게임 내 역사 이벤트 해설 + 실제 역사 비교

스트리머 협업 이벤트:
- 스트리머 4명이 각 왕국 담당 → 4국 전쟁 토너먼트 방송
- 시청자 참여형: "내 나라를 골라라" 투표 연동
```

---

### D. 전통문화·한복 채널 전략

**목표**: 삼국시대 의상·문화의 현대적 매력 발산

```
콘텐츠 방향:
1. "삼국시대 왕의 옷 재현해봤다" — 고증 의상 체험
2. "가야금 연주해봤다" — 전통 악기 체험
3. "삼국시대 음식 만들어봤다" — 전통 음식 재현
4. 한국 관광 연계: 경주·공주·부여 성지 순례 Vlog

해외 연계:
- 일본 내 한국 전통문화 팬층 공략
- "Korean historical fashion vs Japanese period drama fashion" 비교 콘텐츠
```

## 캠페인 타임라인

### Phase A — 시크릿 버즈 (출시 전 8~6주)

```

성과 목표:
- 24시간 내 포털 실시간 검색어 등재

```

  코스플레이 공식 포토 세션 초청

```

### 특화 캠페인 — 「역사 크리에이터 동맹」

```
목적: 역사 정확성 + 교육 마케팅

참여 대상:
  역사 유튜버 10명 모집
  「삼국(三國) IP 역사자문단 크리에이터」공식 타이틀 부여

콘텐츠 시리즈:
  「삼국사기 속 진짜 이야기」— 역사 고증 해설
  「을지문덕은 실존 인물인가」— Q&A형
  「안시성 전투의 진실」— 드라마 vs 역사 비교

협업 혜택:
  ADV-HISTORY 자문단과 직접 인터뷰 기회
  드라마 사전 시사 초청
  역사 자문 명예 크레딧 (드라마 엔딩 크레딧)
```

### 특화 캠페인 — 「가야금 챌린지」

```
목적: 니문 캐릭터 + 음악 바이럴

챌린지 내용:
  「기억의 강」멜로디 가야금·악기 커버
  악기 없어도 허밍·피아노·기타 OK
  #기억의강챌린지 태그

인센티브:
  베스트 10: 공식 SNS 공유
  1위: 니문 캐릭터 S급 아트북 + 게임 DLC1 코드
  참여자 전원: 앱 무료 구독 1개월

글로벌 확장:
  영어·일어·중어 챌린지 별도 운영
  K-POP 팬들이 즐기는 챌린지 포맷 적용
```

### 특화 캠페인 — 「화랑 코스플레이 페스티벌」

```

파트너십:
  코스플레이 용품 브랜드 협찬
  코믹콘 코리아·코스파 이벤트 연계 부스
```
