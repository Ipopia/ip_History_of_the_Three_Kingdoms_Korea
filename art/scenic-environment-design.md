# 시네마틱 환경 디자인 가이드

## 환경 설계 철학

> "삼국의 땅은 살아있다. 산이 전략이고, 강이 국경이고, 계절이 운명이다."

각 환경은 단순한 배경이 아니라 서사의 능동적 참여자로 설계한다. 장소가 감정을 만들고, 지형이 전략을 결정하며, 계절이 시대를 암시한다.

---

## 3대 수도 환경 설계

### 평양성 (고구려)

**역사 기반**
- 427년 장수왕 천도 — 이후 고구려 최후 수도
- 대동강 유역, 낮은 구릉+평지 조합
- 안학궁: 동서 622m×남북 620m — 동아시아 최대급

**시네마틱 설계 원칙**

| 요소 | 설계 방향 |
|------|---------|
| 성벽 | 화강암 기반 — 거칠고 육중한 질감 |
| 궁궐 | 안학궁 규모 — 인물은 점, 건물이 압도 |
| 거리 | 넓은 대로 + 시장 밀집 구역 분리 |
| 강 | 대동강 — 평화 시 서정, 전쟁 시 방어선 |
| 산 | 모란봉 — 성 뒤 배경 실루엣 |

**핵심 공간 목록**
- 안학궁 정전: 왕 알현 장면
- 성문(城門): 원정 출발·귀환 장면
- 대동강변: 사색·밀담 장면
- 저잣거리: 민중 일상 장면
- 모란봉 정상: 전략 회의·조망 장면

**조명 설계**
- 기본: 역광+짧은 그림자 — 웅장감
- 전쟁 직전: 어두운 구름+적색 황혼
- 멸망 장면: 연기+역광 — 실루엣만 남음

---

### 사비성 (백제)

**역사 기반**
- 538년 성왕 천도 — 백제 마지막 수도
- 금강(백마강) 변 — 3면이 강과 산
- 정림사지·부소산성 기반

**시네마틱 설계 원칙**

| 요소 | 설계 방향 |
|------|---------|
| 성벽 | 낮고 우아한 — 방어보다 도시미 |
| 궁궐 | 목조 건축 정수 — 곡선 지붕선 |
| 강 | 백마강 — 가장 중요한 공간 |
| 탑 | 정림사지 5층석탑 — 도시 스카이라인 |
| 숲 | 부소산 — 부드러운 녹색 |

**핵심 공간 목록**
- 사비 왕궁 정전: 의자왕 장면
- 정림사지 앞: 외교·의례 장면
- 백마강 강변: 서정적 장면, 낙화암 연결
- 낙화암 절벽: 멸망 클라이맥스
- 부소산 산책로: 왕과 신료의 밀담

**조명 설계**
- 기본: 부드러운 산란광 — 흐린 날 분위기
- 전성기: 봄·가을 황금빛 오후
- 멸망 전야: 강 반사광+연기

---

### 서라벌 (신라)

**역사 기반**
- BC 57년부터 935년까지 신라 수도
- 경주 분지 — 평탄한 지형
- 황룡사·첨성대·계림 등 밀집

**시네마틱 설계 원칙**

| 요소 | 설계 방향 |
|------|---------|
| 황룡사탑 | 약 80m — 도시 어디서나 보임 |
| 첨성대 | 선덕여왕 장면 필수 배경 |
| 고분군 | 도시 내 왕릉 — 삶과 죽음의 공존 |
| 계림 | 김알지 탄생 숲 — 신화의 공간 |
| 평원 | 경주 평지 — 광활한 지평선 |

**핵심 공간 목록**
- 황룡사 대웅전: 종교·왕권 의례
- 첨성대: 선덕여왕 밤 관측 장면
- 계림 숲: 신화적 장면
- 고분 사이 길: 역사의 무게 표현
- 금성(月城) 궁궐: 왕실 일상

**조명 설계**
- 기본: 청명한 하늘+강한 햇살 — 황금이 빛남
- 황금 시간대: 금관 클로즈업 필수
- 밤 첨성대: 달빛+별빛 — 신비

## 주요 전장 환경

### 살수(薩水) — 고구려 vs. 수나라 (612년)

**지형 설계**
- 청천강 추정 — 강폭 100m+
- 양안: 경사진 언덕 + 갈대밭
- 고구려: 상류 댐 통제 포지션

**시네마틱 설계**
| 단계 | 환경 | 조명 |
|------|------|------|
| 수군 진격 | 광활한 강 + 안개 | 아침 저시정 |
| 수 침공 | 강 건너는 100만 대군 | 밝은 낮 |
| 결정적 순간 | 수문 개방+물 쏟아짐 | 혼돈+빛 |
| 패주 | 익사·도주 | 황혼+붉은 강물 |

---

### 안시성(安市城) — 고구려 vs. 당나라 (645년)

**지형 설계**
- 요동 산지 — 험준한 절벽 위 성
- 당 대군: 성 주위 포위망 완성
- 성벽: 자연 암반 + 인공 석벽

**시네마틱 설계**
| 장면 | 환경 포인트 |
|------|-----------|
| 당군 도착 | 성이 산처럼 작아 보이다 → 가까워질수록 거대해짐 |
| 포위망 | 지평선 전체를 덮는 당군 — 인물은 점 |
| 성벽 전투 | 수직 공간 활용 — 상하 구도 |
| 성주 눈 부상 | 클로즈업 → 배경 흐릿 |
| 당 철수 | 성에서 내려보는 고구려 병사들 |

---

### 황산벌 — 신라 vs. 백제 (660년)

**지형 설계**
- 충남 논산 — 넓은 평원
- 백제 결사대 5,000 vs. 신라 5만
- 여름 — 뜨거운 열기, 황토 먼지

**시네마틱 설계**
| 장면 | 환경 포인트 |
|------|-----------|
| 계백 진격 | 뜨거운 황토 평원 — 먼지 구름 |
| 수적 대비 | 신라군이 지평선을 가득 채움 |
| 관창 돌격 | 양 진영 사이 공간 — 허무함 강조 |
| 계백 최후 | 황토 위 — 혈흔+황색 |

---

### 낙화암 (660년)

**환경 설계**
- 백마강 절벽 — 높이 약 30m
- 야간 장면 — 달빛+횃불+강 반사
- 바람: 꽃잎처럼 보이는 물체의 낙하

**시네마틱 설계**
- 절벽 아래서 올려다보는 앵글 필수
- 인물 낙하: 실루엣+슬로모션+음악만
- 강물 반사: 달빛이 흔들림

## 계절별 환경 가이드

### 봄 (시즌1 건국기)
| 요소 | 표현 |
|------|------|
| 식물 | 연두 새잎 + 진달래·벚꽃 |
| 하늘 | 부드러운 봄 하늘 — 옅은 구름 |
| 땅 | 촉촉한 흙 — 생명의 기운 |
| 물 | 봄 해빙 — 빠른 흐름 |
| 빛 | 따뜻하나 아직 강하지 않음 |

### 여름 (시즌3~4 전성·격변기)
| 요소 | 표현 |
|------|------|
| 식물 | 짙은 녹음 — 숲의 압도감 |
| 하늘 | 강렬한 파란 하늘 + 뭉게구름 |
| 땅 | 건조한 황토 (전장) / 습한 진흙 (강변) |
| 물 | 범람 위험 — 황색 탁류 |
| 빛 | 강렬 — 강한 그림자 |

### 가을 (시즌5~6 전쟁·멸망기)
| 요소 | 표현 |
|------|------|
| 식물 | 단풍 + 낙엽 — 쇠락의 아름다움 |
| 하늘 | 높고 차가운 하늘 — 투명한 공기 |
| 땅 | 낙엽으로 뒤덮임 |
| 물 | 맑고 차가운 강물 |
| 빛 | 낮은 각도 — 긴 그림자 |

### 겨울 (시즌6~7 멸망·통일기)
| 요소 | 표현 |
|------|------|
| 식물 | 앙상한 가지 + 눈 |
| 하늘 | 납빛 하늘 또는 눈 내리는 하늘 |
| 땅 | 눈·얼음 — 차가운 침묵 |
| 물 | 결빙 또는 느린 검은 강 |
| 빛 | 차갑고 납빛 — 최소한의 따뜻함 |

## 환경 레이어 구조 (원근 설계)

모든 주요 배경은 5개 레이어로 구성:

| 레이어 | 내용 | 선명도 |
|--------|------|--------|
| 전경 | 인물·소품 | 100% 선명 |
| 근경 | 건물·나무·지형 | 95% |
| 중경 | 성벽·숲·강 | 80% |
| 원경 | 산·지평선 | 60% — 대기 원근 |
| 하늘 | 구름·하늘 | 50% — 탈포화 |

**대기 원근 원칙**: 멀어질수록 청회색으로 탈포화 + 명도 상승

## 도시 vs. 야외 환경 전환

| 공간 | 음향 | 밀도 | 조명 |
|------|------|------|------|
| 왕궁 내부 | 침묵+발소리 | 높음 | 촛불+창문 |
| 도성 거리 | 시장 소음 | 중간 | 자연광 |
| 성벽 위 | 바람+원거리음 | 낮음 | 하늘광 |
| 야전 | 자연음+군소리 | 변화 | 강한 자연광 |
| 산야 | 바람+새 | 최저 | 여과된 숲 광 |

## 금지 사항

1. 지나치게 깨끗한 도시 — 삼국시대는 흙먼지와 냄새의 시대
2. 현대적 정리된 거리 — 골목의 혼잡함 필수
3. 식물 배치의 부자연스러움 — 인공 조경 금지
4. 역사적 건축물의 크기 축소 — 스케일 가이드 준수
5. 계절 무시한 식물 표현
