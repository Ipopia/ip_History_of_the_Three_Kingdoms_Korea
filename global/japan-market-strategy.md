## 일본 시장 개요

일본은 삼국(三國) IP의 **최우선 해외 시장**이다. K-콘텐츠 수요 확고, 애니·만화·게임 문화 기반, 한국 역사에 대한 잠재적 관심이 높다. 동시에 역사 민감 이슈(임나일본부·칠지도)가 존재하므로 세심한 접근이 필요하다.

```
일본 시장 매력:
- K-드라마 팬덤: 넷플릭스 재팬 K-콘텐츠 상위권 지속
- 애니·만화 시장: 세계 최대 (삼국 IP 애니 진출 최적)
- 역사 IP 선호: 전국시대·삼국지 역사 IP 강세
- 머천다이즈 구매력: 일본 피규어·굿즈 시장 세계 2위
- 게임 시장: 스마트폰 RPG·전략게임 최강 시장

일본 시장 위험:
- 역사 민감성: 임나일본부·칠지도 해석 차이
- 「三国志」혼동: 중국 三国志와 브랜드 차별화 필수
- 반한 정서: 일부 층 존재 — 역사 논쟁 유발 금지
- 경쟁: 일본 자체 역사 IP 강세 (센고쿠·에도 시대)
```

## 역사 민감 이슈 대응

### 임나일본부 (任那日本府)

```
배경:
일본 일부 역사 해석에서 가야 지역을
「임나(任那)」라 칭하며 왜의 지배 지역으로 주장.
현재 한국·일본 학계 모두 이를 부정 또는 대폭 수정.

삼국 IP 방침:
1. 임나 표기 일절 사용 금지 (계약서·콘텐츠 모두)
2. 가야는 항상 「加耶(カヤ)」단독 표기
3. 가야-왜 관계: 「対等な交易関係」(대등한 교역 관계)
4. 칠지도: 「百済の外交的贈り物」(백제의 외교적 선물)
   → 종주·종속 관계 언급 금지

위기 대응 시나리오:
일본 역사 커뮤니티에서 임나 관련 논쟁 발생 시:
→ 공식 성명: 「학술적 논의는 존중하며, 본 작품은 4~7세기 역사 기록에 충실한 창작물입니다」
→ 소셜 논쟁 직접 개입 금지 (연료 공급 효과)
→ 역사 자문단(ADV-HISTORY) 통해 학술 대응
```
