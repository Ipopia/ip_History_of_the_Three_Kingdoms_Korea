# IP & 법무 프레임워크 — 삼국(三國) IP

## IP 보호 전략 개요

### 핵심 원칙

> "역사는 공공재다. 그러나 우리가 창조한 표현은 우리의 것이다."

삼국시대 역사 자체는 저작권 보호 대상이 아니다. 그러나 이 IP가 창조한 **캐릭터 디자인·스토리 구성·아트워크·세계관 설정**은 강력히 보호한다.

## 저작권 (著作權) 등록

### 등록 대상 목록

| 분류 | 등록 대상 | 우선순위 |
|------|---------|---------|
| 어문 저작물 | 마스터 바이블, 캐릭터 설정집, 소설 초고, 각본 | 즉시 |
| 미술 저작물 | 캐릭터 디자인, 로고, 심볼, 아트워크 | 즉시 |
| 영상 저작물 | 파일럿 영상, 트레일러, 뮤직비디오 | 제작 후 즉시 |
| 음악 저작물 | OST 전곡, 테마곡 | 녹음 후 즉시 |
| 컴퓨터프로그램 | 게임 소스코드, AI 챗봇 | 개발 후 즉시 |

### 등록 기관

- **국내**: 한국저작권위원회 저작권 등록
- **국제**: 베른협약 자동 보호 (170개국) + 미국 저작권청 등록 (소송 시 유리)
- **중국**: 중국판권보호중심(CPCC) 별도 등록 (강력 권장)

## 라이선싱 프레임워크

### 라이선스 등급 체계

**티어 1 — 코어 라이선스** (최고 등급)
```
대상: 드라마·영화 제작사, 대형 게임사
조건:
- 아트 바이블 100% 준수 의무
- QA팀 검수 필수
- 역사 고증 자문 비용 별도
- 수익 배분: 순수익의 15~25%
- 계약 기간: 5년 (갱신 가능)
```

**티어 2 — 스탠다드 라이선스** (일반 상업)
```
대상: 출판사, 중소 게임사, 머천다이즈 업체
조건:
- 스타일 가이드 준수
- 제품 출시 전 승인 필요
- 수익 배분: 순수익의 8~15%
- 계약 기간: 3년
```

**티어 3 — 마이크로 라이선스** (소규모)
```
대상: 인디 게임, 소규모 공예, 팬아트 상업화
조건:
- 비영리 팬아트: 무료 (가이드라인 준수)
- 소규모 상업: 정액 라이선스 피
- 연 매출 1,000만 원 미만
- 계약 기간: 1년
```

## 국가별 법무 전략

### 한국

**주요 이슈**
- 역사 인물 초상권: 삼국시대 인물은 사망 후 70년+ → 초상권 소멸, 활용 가능
- 역사 유물 이미지: 국립박물관 소장 유물 — 상업 사용 시 사용료 협약 필요
- 방송 심의: KCSC 심의 — 역사 왜곡 방지 조항 주의

**권장 조치**
- 국립중앙박물관과 공식 협약 체결 (유물 이미지 사용)
- 문화재청 고증 자문 공식 계약
- 한국콘텐츠진흥원(KOCCA) 지원사업 연계

---

### 미국

**주요 이슈**
- 저작권법: 미국 저작권청 등록 — 소송 시 법정손해배상 청구 가능
- 상표 출원: USPTO — 사용 의사 기반 출원(ITU) 활용
- 엔터테인먼트 계약: WGA(작가조합)·SAG-AFTRA 규정 준수 (미국 제작 시)

**권장 조치**
- 미국 엔터테인먼트 전문 로펌 현지 계약
- 저작권 등록: 작품 발표 후 3개월 이내

---

### 일본

**주요 이슈**
- 한국 역사 콘텐츠 민감성: 일제 관련 내용 없으나 역사 해석 차이 주의
- 상표 등록: 일본 특허청(JPO) — 한자 상표 별도 검토
- 만화·게임 시장: 현지 파트너사와 공동 출원 권장

**권장 조치**
- 현지 에이전트 계약 (일본어 상표 포함)
- 역사 해석 관련 자문단 구성 (한일 역사학자 균형)

---

### 중국

**주요 이슈**
- 역사 귀속 논쟁: 고구려사 동북공정 → 가장 민감한 시장
- 저작권 보호: 중국 내 저작권 집행 불확실 — 등록 필수
- 심의: 국가라디오텔레비전총국(NRTA) 심의 통과 필요

**권장 조치**
- 중국 전문 IP 로펌 계약
- "한국의 역사" 명확히 표기 — 영토 분쟁 내용 최소화
- 중국 현지 파트너 공동제작 구조 검토 (심의 통과율 향상)
- 中 시장 진입 전 법무 리스크 평가 필수
