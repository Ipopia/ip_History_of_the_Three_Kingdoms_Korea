# 삼국시대 기술 트리

## 기술 발전 개요

삼국시대(BC 1세기~AD 7세기)는 중국 기술의 적극적 수용과 자체 기술 혁신이 공존한 시대였다. 왕국별 지리·환경에 따라 특화 기술 분야가 달랐다.

---

## 금속·제철 기술

### 기술 계보
```
청동기 (BC 10C~) → 철기 도입 (BC 4~3C) → 철기 보급 (BC 1C~) → 제철 기술 완성 (AD 3~5C)
```

### 단계별 발전

**1단계: 초기 철기 (BC 3~1C)**
- 중국제 철기 수입 단계
- 농기구 중심 — 쟁기날·낫·호미
- 무기: 철촉(鐵鏃)·단검 등장

**2단계: 자체 생산 (BC 1C~AD 3C)**
- 가야: 철광석 대량 채굴 + 제련 기술 확립
- 철정(鐵鋌) 생산 → 동아시아 수출
- 고구려: 요동 철광 장악 + 군사용 철기 특화

**3단계: 고급 야금 (AD 3~6C)**
- 강철(鋼鐵) 제조: 탄소 함량 조절 기술
- 판금 기술: 갑옷·투구 대량 생산
- 금동(金銅) 도금: 불상·장신구 제작
- 고구려 철갑기병(개마무사): 말+기사 완전 철갑 — 동아시아 최강 기병

**4단계: 정밀 공예 (AD 5~7C)**
- 신라 금관: 정밀 금 세공 — 누금(鏤金) 기술
- 백제 금동대향로: 복잡한 주물+세공 복합 기술
- 칠지도(七支刀): 상감 기술 — 금속에 글자 새김

### 왕국별 철기 특화
| 왕국 | 특화 | 기술적 강점 |
|------|------|------------|
| 고구려 | 군사 철기 | 갑옷·무기·마구(馬具) |
| 백제 | 공예 금속 | 금동공예·상감기술 |
| 신라 | 금 세공 | 금관·금귀걸이·금 허리띠 |
| 가야 | 철 생산 | 제련·철정 대량 생산 |

## 건축·토목 기술

### 토성(土城) → 석성(石城) 기술 발전
```
흙 + 나무 토성 → 석축 기단 → 완전 석성 → 산성(山城) 체계
```

**고구려 석성 기술**
- 장방형 석재 정밀 가공 + 쐐기 방식 결합
- 성벽 단면: 외벽 석재 + 내부 토석 혼합
- 산성: 자연 지형 활용 — 험한 산세가 방어선
- 대표: 환도산성·국내성·안학궁·평양성

**백제 건축 기술**
- 중국 남조 건축 수용 + 자체 발전
- 목조 건축 정밀도 최고 수준
- 기단부 정교한 석재 가공
- 일본 전파: 백제 기술자가 아스카데라(飛鳥寺) 건축 주도

**신라 석조 기술**
- 통일 후 정점: 불국사·석굴암 (8세기)
- 석굴암: 인공 석굴 — 돔 구조의 수학적 정밀 설계

### 수리(水利) 토목
- 벽골제(碧骨堤): 백제 — 한국 최초 대규모 저수지 (330년)
- 수산제(守山堤): 신라 — 경주 인근 대형 저수지
- 의림지(義林池): 삼한시대 → 삼국시대 유지·확장
- 기술: 제방 경사 계산 + 수문(水門) 설치 + 배수로 설계

## 농업 기술

### 농기구 혁신
- 철제 쟁기날 → 깊은 경작 가능 → 생산성 증가
- 철제 낫·호미: 수확 효율 향상
- 소 이용 우경(牛耕) 보급: 노동력 절감

### 농법 발전
- 휴한농법(休閑農法) → 연작(連作) 기술 발전
- 시비법(施肥法): 인분·퇴비 활용 — 지력 유지
- 이앙법(移秧法, 모내기): 후기 삼국 일부 지역 도입
- 저습지 개간: 저수지+배수로 결합 — 논 확대

### 작물 다양화
- 주곡: 쌀·조·기장·보리
- 채소: 무·오이·마늘·부추
- 섬유: 삼(대마)·모시 재배 확대

---

## 조선(造船) 기술

### 백제 조선술 (동아시아 최고 수준)
- 평저선(平底船): 서해 조류·갯벌 적합
- 대형 교역선: 중국·왜 항해 가능
- 군선: 수군 운용 — 수전 가능

### 고구려 조선술
- 하천용 전투선: 패수(浿水)·요하 수전 운용
- 서해 연안 항해 능력

### 신라 조선술
- 초기: 상대적으로 열세
- 통일 이후: 장보고 시대 동아시아 최강 해양력

## 천문·역법

- **첨성대(瞻星臺)**: 신라 선덕여왕 (632~647년 추정) — 동아시아 현존 최고(最古) 천문대
- **역법**: 중국 역법 수입 → 자체 운용
- **농업 연계**: 파종·수확 시기 결정에 천문 활용
- **군사 연계**: 일식·월식 = 전쟁 길흉 판단

## 문자·기록 기술

| 단계 | 내용 |
|------|------|
| 한자 수용 | 중국 한자 전면 채용 |
| 이두(吏讀) | 한자 음·훈을 빌려 한국어 표기 — 신라 발전 |
| 향찰(鄕札) | 향가(鄕歌) 표기 시스템 |
| 종이 생산 | 백제·고구려에서 제지(製紙) 기술 생산 시작 |
| 일본 전파 | 담징(曇徵): 고구려 승려 — 일본에 종이·먹 제조법 전파 (610) |

## 기술 전파 방향

```
중국 ──→ 고구려 ──→ (일부) 신라
         ↓
중국 ──→ 백제 ──→ 왜(일본)
              ↓
            가야 ──→ 왜(철기)
```

**핵심**: 삼국은 중국 기술의 단순 수용자가 아니라 **자체 발전 + 일본 전파**의 중간 허브
