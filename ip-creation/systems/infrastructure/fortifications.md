# 삼국 방어 시설

## 방어 체계 개요

삼국의 방어 전략은 **산성 중심 종심방어** 체계였다. 평지에서 대규모 야전보다 지형을 활용한 지구전이 기본 전략이었다.

---

## 산성(山城) 체계

### 고구려 산성 — 동아시아 최고의 산성 국가

**설계 원칙**
- 능선 + 계곡 이용 — 자연 지형이 성벽의 일부
- 성내 수원(水源) 확보 필수 — 장기 농성 전제
- 주요 목 지점 통제 — 교통로 차단

**주요 산성**
| 산성 | 위치 | 특징 |
|------|------|------|
| 오녀산성(五女山城) | 환인 | 천연 절벽 요새 — 고구려 발상지 |
| 환도산성(丸都山城) | 집안 | 국내성 배후 피난성 |
| 안시성(安市城) | 요동 | 당 태종 88일 저지 — 역사상 가장 유명한 산성 |
| 요동성(遼東城) | 요양 | 요동 방어 핵심 거점 |
| 백암성(白岩城) | 요동 | 요동 방어선 보조 |
| 건안성(建安城) | 요동 | 서해 연안 방어 |

**안시성 전투의 의의 (645년)**
- 당 태종 이세민 직접 지휘 — 10만 이상 대군
- 88일 포위 — 수공·토산(土山)·공성 총동원
- 성주(양만춘 추정) 결사 수비 — 당 태종 철수
- "고구려를 이기지 못한 당 태종" — 역사의 반전

### 백제 산성

**특징**: 평지성 + 배후 산성 이중 체계

| 산성 | 위치 | 특징 |
|------|------|------|
| 공산성(公山城) | 공주 | 웅진 천도 후 왕성 = 산성 |
| 부소산성(扶蘇山城) | 부여 | 사비성 배후 — 낙화암 포함 |
| 임존성(任存城) | 예산 | 백제 부흥운동 거점 |
| 주류성(周留城) | 부안 추정 | 백제 부흥운동 최후 거점 |

### 신라 산성

| 산성 | 위치 | 특징 |
|------|------|------|
| 명활산성(明活山城) | 경주 | 서라벌 방어 배후 |
| 관문성(關門城) | 경주 외곽 | 통일 후 외적 방어 |
| 삼년산성(三年山城) | 보은 | 축성에 3년 걸린 난공불락 |

## 장성(長城) 체계

### 고구려 천리장성

**건설**
- 추진: 연개소문 주도
- 기간: 631~647년 (16년 공사)
- 구간: 부여성(현 농안) → 비사성(현 대련) — 동서 약 1,000리(400km+)
- 목적: 당나라 침공 대비

**구조**
- 흙+돌 혼합 토석성(土石城)
- 요충지에 성보(城堡) = 중간 거점 산성 배치
- 수비 병력 상주 + 봉화망 연결

**역사적 의의**
- 중국의 만리장성과 비교 — 동아시아 최대 방어선
- 건설에 동원된 민중의 고통 → 연개소문 독재 비판의 빌미
- 실제 효과: 당군의 요동 진입은 막지 못함 (산성 방어가 더 효과적)

## 성벽 구조 상세

### 외벽 구조

**고구려식 석성**
- 정밀 가공 장방형 석재 — 쐐기 방식 결합
- 외벽: 수직 또는 약간 안쪽으로 기울기
- 내벽: 토석 다짐
- 두께: 하부 5~8m, 상부 2~3m

**백제식 토성**
- 판축(版築): 흙을 층층이 다져 쌓는 기법
- 풍납토성: 판축 + 외벽 목재 보강
- 한성 시기: 목책(木柵) + 토루 병용

**신라식 석성**
- 고구려 기술 영향 수용
- 통일 후: 화강암 정밀 가공 석성

### 방어 시설

| 시설 | 기능 |
|------|------|
| 치(雉) | 성벽 돌출부 — 측면 공격 가능 |
| 옹성(甕城) | 성문 앞 반원형 추가 성벽 — 이중 방어 |
| 해자(垓字) | 성 외곽 수로 — 접근 지연 |
| 목책(木柵) | 성 외곽 목재 장애물 |
| 망루(望樓) | 관측 + 궁수 진지 |
| 성문루(城門樓) | 성문 위 지휘·방어 누각 |

## 봉화(烽火) 통신망

### 체계

- 전국 산 정상에 봉화대 배치
- 평시: 1개 연기 = 이상 없음
- 적 발견: 2개 이상 — 숫자로 규모 전달
- 야간: 불빛 신호

### 전달 속도
- 봉화: 하루 수백 km 정보 전달 가능
- 파발(擺撥): 말+인간 릴레이 — 구체적 문서 전달

### 약점
- 안개·비: 봉화 불가
- 적의 봉화 차단: 봉화대 선제 점령
- "봉화가 꺼진 밤" = 정보 차단 = 공격 개시 기회

## 공성 vs. 수성 기술

### 공성 기술

| 기술 | 내용 |
|------|------|
| 충차(衝車) | 성문 파괴용 — 목재+철제 |
| 운제(雲梯) | 사다리차 — 성벽 등반 |
| 투석기 | 대형 돌 투척 — 성벽 파괴 |
| 토산(土山) | 성벽 높이까지 흙산 쌓기 — 안시성 전투에서 사용 |
| 화공(火攻) | 불화살 + 불 붙인 투석 |
| 수공(水攻) | 수로 차단 또는 범람 유도 |
| 장기 포위 | 식량 고갈 대기 — 가장 확실하나 느림 |

### 수성 기술

| 기술 | 내용 |
|------|------|
| 역습(逆襲) | 성문 열고 기습 — 공성군 교란 |
| 화전(火箭) | 불화살 — 공성 장비 소각 |
| 끓는 기름·모래 | 성벽 등반 저지 |
| 돌 투척 | 성벽 위에서 낙석 |
| 수원 사수 | 성내 우물 확보 — 장기전 필수 |
| 토산 대응 | 안시성: 성벽 높여 대항 |
