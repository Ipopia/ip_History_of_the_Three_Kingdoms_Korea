## 개요

```
7세기 한반도 정보 전달 체계:
  문자 기록: 한자(漢字) 독점 — 귀족·관료·승려 한정
  구전 전달: 민간·군사 정보 주요 경로
  봉화 신호: 군사 긴급 정보
  전령 체계: 말·도보 릴레이
  불교 네트워크: 사찰 간 정보 공유

정보의 희소성:
  문맹률: 민간 95%+ (문자 해독 불가)
  정보 지연: 수도 간 7~15일 소요
  정보 왜곡: 전령 단계별 변형
  → 창작에서 정보 비대칭·오해·지연이 극적 긴장 도구
```

## 왕국별 통신 체계

### 고구려 통신망

```
군사 봉화 체계:
  안시성~평양성 봉화선: 약 300km
  봉화 단계:
    1화 (낮 연기 / 밤 불빛): 적 접근
    2화: 적 접근 확인
    3화: 적 공격 시작
    4화: 긴급 지원 요청
    5화: 최고 위기 — 수도 방어 발령

전령 체계:
  역참(驛站) 간격: 약 30리 (12km)
  말 교체 방식: 릴레이 승마
  평양성~압록강: 약 2일 (긴급)
  평양성~안시성: 약 4일 (긴급)

고구려 특수 체계:
  삼족오 깃발 신호: 왕명 전달 전용
  깃발 색상 코드:
    적색: 전투 명령
    청색: 철수 명령
    백색: 협상 신호
    흑색: 상(喪) 발생

기록 체계:
  왕실 사관: 「유기(留記)」100권 (현존 불가)
  군사 기록: 작전 개요 죽간 보관
  전쟁 포로 심문 기록: 별도 문서
```

### 백제 통신망

```
해상 통신:
  황해 교역선 = 정보 운반선 겸용
  백제 항 → 중국 산동: 약 3~5일 (순풍)
  백제 항 → 왜 규슈: 약 2~3일

내륙 전령:
  금강 수로 활용 (배로 이동)
  사비성~웅진: 약 1일 (수로)
  사비성~한강 하류: 약 3일

백제 기록 체계:
  사관 제도: 박사(博士) — 역사 기록 전담
  「서기(書記)」: 백제 역사서 (소실)
  국가 문서: 죽간(竹簡) + 목간(木簡)
  외교 문서: 한문 정식 문서

아랑의 기록 활동:
  죽간 필사: 살아남은 자의 증언 기록
  자수 부호: 비밀 정보 암호화 가능성 (창작 설정)
  연등 의식: 사자(死者) 이름 구술 전달
```

### 신라 통신망

```
화랑 정보망:
  화랑도 = 군사 + 정보 수집 조직 겸용
  전국 순행(巡行): 지형·민심 정보 수집
  화랑 서신망: 경주 ↔ 지방 거점

봉화 체계:
  동해안선: 왜 침입 감지
  낙동강선: 가야·백제 방면
  북방선: 고구려·백제 연합 감지

신라 기록 체계:
  「국사(國史)」: 거칠부 편찬 (545년)
  삼국사기 원자료 일부 포함
  화랑 행적 기록: 「화랑세기」(일부 전해짐)
  선덕여왕 지덕논리: 미래 예측 기록 (창작 활용)

당나라와의 통신:
  648년 김춘추 입당: 직접 외교 통신
  나당 연합 협정: 문서 기반 약정
  당항성(黨項城): 대당(對唐) 통신 전용 거점
```

### 가야 통신망

```
가야 연맹 통신:
  연맹 회의: 대가야 주도 소집
  통신 한계: 단일 왕권 없음 → 연맹 내 정보 공유 느림
  철정(鐵鋌) 교역선: 정보 운반 겸용

왜(倭)와의 통신:
  가야-왜 교역로 = 상시 통신 루트
  철정 교역 상인: 정보 중계인 역할
  수로 통신: 낙동강 → 남해 → 대마도

가야 기록:
  기록 극히 희소 (멸망 후 소실)
  가야금 악보: 구전 전수 (문자 기록 없음)
  니문의 죽간: 창작 설정 — 사라져가는 가야 기록

IP 활용:
  니문: 사라져가는 가야 이야기를 가야금 선율로 기록
  「소리가 곧 기록이다」— 니문의 창작 신념
```

## 정보 전달 매체

### 죽간 (竹簡)

```
재료: 대나무 쪽 (폭 1~2cm, 길이 20~30cm)
용도: 군사 명령·외교 문서·일상 기록
제작: 대나무 불에 굽기 → 표면 처리 → 칼로 글씨
보관: 줄로 엮어 두루마리형

한계:
  무게·부피 큼 → 대량 운반 어려움
  습기에 약함 → 장기 보관 문제
  → 창작에서 아랑이 죽간을 소중히 다루는 이유

IP 활용:
  아랑의 죽간: 사건 기록 + 감정 일기
  죽간 분실 사건: 극적 긴장
  죽간 발굴: 현대 고고학 에필로그 가능
```

### 목간 (木簡)

```
재료: 나무판
용도: 물품 꼬리표·간단한 메모·이정표
발굴 현황:
  부여 궁남지 목간: 백제 행정 기록
  경주 월성 해자 목간: 신라 행정 기록
  → 실제 고고학 발굴물 → 창작 신뢰도 제공

IP 활용:
  아랑이 발견하는 목간 단서
  전사한 병사의 이름 목간
  교역 물품 기록 목간 (역사 교육 요소)
```

### 봉화 (烽火)

```
체계:
  낮: 연기 신호 (건습 재료로 색깔 조절)
  밤: 불빛 신호 (횃불 수량)

봉화대 간격: 20~30리 (약 8~12km)
신호 도달 시간: 수도 ↔ 변경 약 2~4시간 (이론상)

한계:
  날씨 영향: 비·안개 시 불통
  신호 단순: 복잡한 정보 전달 불가
  → 긴급 상황과 오해 유발 가능 (창작 갈등 요소)

IP 활용:
  살수대첩 직전: 봉화 오신호 → 긴장 고조
  고구려 봉화 장면: 「5화(火)」발령 — 전쟁 시작
```

### 전령 (傳令)

```
말 전령 (기마 전령):
  속도: 하루 약 150~200리 (60~80km)
  왕국 간: 3~7일 소요
  위험: 암살·포획 위협

도보 전령:
  속도: 하루 약 50~60리 (20~25km)
  일반 행정 문서 운반

비둘기 사용:
  7세기 한반도: 확인 기록 없음
  → IP에서는 사용하지 않음 (고증 준수)

IP 활용:
  전령 포획 → 적에게 정보 노출 (긴장)
  전령 사망 → 지원군 불통 (비극)
  아랑의 전언: 문서보다 기억 의존 선택
```

## 불교 정보 네트워크

```
사찰 간 승려 이동:
  왕국 간 자유 이동 가능 (종교적 중립성)
  → 사실상 비공식 정보 통신망

주요 거점:
  황룡사 (경주): 신라 불교 중심
  미래사 (부여): 백제 불교 중심
  금강사 (평양): 고구려 불교 중심

정보 공유 내용:
  왕실 동향·귀족 관계·자연재해 정보
  외국 승려 통해 당나라 정세 입수

IP 활용:
  아랑 ↔ 승려 네트워크: 사비성 소식 수집
  고루: 승려를 통한 당나라 군사 정보 접수
  하린: 원효 접촉 → 철학적 고민 심화 가능
```

## 정보 비대칭 — 창작 활용 포인트

```
드라마·소설 갈등 구조:

1. 지연된 정보:
   「황산벌 패배」소식이 아랑에게 닿기까지 5일
   → 아랑은 승리를 기다리다 결국 진실과 마주침

2. 차단된 정보:
   당나라와의 밀약을 고루는 모른다
   → 동맹인 줄 알았던 당이 적이 된 순간

3. 잘못된 정보:
   「고루 전사」오보 → 하린의 잘못된 판단
   → 실제로 살아있던 고루와 재회 시 극적 반전

4. 기록된 정보:
   아랑의 죽간 = 미래를 위한 시간 캡슐
   현대 고고학자 발굴 에필로그 연결 가능

5. 음악으로 전달된 정보:
   니문의 가야금: 「676」한 음 = 모든 것의 끝과 시작
   → 언어를 초월한 정보 전달
```
