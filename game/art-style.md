## 게임 아트 철학

```
핵심 원칙:
  「역사의 무게 + 현대 게임의 몰입감」
  고증 기반 비주얼 → 플레이어가 실제 삼국시대에 있는 느낌
  왕국별 시각적 차별화 → UI/UX부터 캐릭터·환경까지 일관성

참조 스타일:
  Three Houses (Fire Emblem): 캐릭터 아트 완성도
  Total War: Three Kingdoms: 역사 전략 비주얼
  Ghost of Tsushima: 동아시아 역사 환경 표현
  Crusader Kings III: UI 역사성 + 현대적 가독성
```

## 아트 스타일 방향

### 전반 스타일

```
2D/3D 혼합 구조:
  메인 게임플레이: 3D (전략 맵·전투)
  캐릭터 초상화: 2D 일러스트 (고품질)
  UI: 2D 플랫 + 전통 문양 장식
  컷씬: 3D 인게임 + 2D 일러스트 혼합

전반 색조:
  사실적이되 약간 강조된 채도
  왕국별 색상 코드 일관 적용 (art-bible.md 기준)
  전투 중: 대비 강화 (긴박감)
  외교·대화: 차분하고 따뜻한 톤

해상도 목표:
  PC: 4K UHD 지원
  모바일: FHD (1920×1080) 최적화
  콘솔: 4K 30fps / 1080p 60fps
```

## 캐릭터 아트

### 초상화 (Portrait)

```
스타일: 세미 리얼리스틱 2D 일러스트
해상도: 1024×1024px (기본) / 2048×2048px (확대 시)

구성:
  얼굴: 상반신 + 배경 왕국 색상
  표정: 기본 5종 (기본·기쁨·분노·슬픔·결의)
  복식: 고증 의상 정밀 표현

왕국별 초상화 스타일:
  고구려: 강렬한 조명 + 어두운 배경 + 삼족오 문양
  백제: 따뜻한 조명 + 연등 배경 + 금빛 장신구
  신라: 황금빛 역광 + 황룡사 배경 + 금관 광채
  가야: 황혼빛 조명 + 낙동강 배경 + 가야금 실루엣

선 처리:
  외곽선: 약한 검정 (1~2px)
  음영: 셀 쉐이딩 + 소프트 그라데이션 혼합
```

### 3D 캐릭터 모델

```
폴리곤 수:
  주인공 4인: 30,000~50,000 폴리곤 (하이폴리)
  주요 조연: 20,000~30,000
  일반 유닛: 5,000~10,000

텍스처:
  주인공: 4K PBR 텍스처
  (Albedo + Normal + Metallic/Roughness + AO)
  일반 유닛: 2K 텍스처

리깅:
  얼굴: 60+ 본 (표정 세밀 표현)
  신체: 표준 70본 리그
  무기 착탈: 별도 소켓 시스템
```

## 환경 아트

### 왕국별 환경 스타일

```
고구려 환경:
  색조: 청람 (#2F4F7F) 기조 + 석회 회색
  특징:
    - 거대한 성벽·요새 구조물
    - 화강암 질감 강조
    - 안개·구름 대기 효과 (요동 평원)
    - 겨울: 설경 + 청람 빙설 반사
  주요 맵: 평양성·안시성·살수강·요동 평원

백제 환경:
  색조: 황금 (#B8960C) + 따뜻한 크림
  특징:
    - 정교한 목조 건축 (연등·처마)
    - 야경 연등 파티클 시스템
    - 금강·백마강 수면 반사
    - 봄·여름 꽃잎 파티클
  주요 맵: 사비성·웅진성·백마강·낙화암

신라 환경:
  색조: 황금 (#FFD700) + 청동
  특징:
    - 황룡사·첨성대 랜드마크
    - 골든아워 강렬한 역광
    - 화랑 훈련장 야외 광장
    - 신라 금관 문양 건축 장식
  주요 맵: 금성(경주)·황산벌·기벌포·황룡사

가야 환경:
  색조: 황토 (#C8A96E) + 대나무 녹색
  특징:
    - 낙동강 강변 자연 환경
    - 대나무 숲 바람 효과
    - 고분군 (구릉) 지형
    - 철 단야 공방 연기 파티클
  주요 맵: 금관가야·대가야·낙동강 유역
```

### 공통 환경 기준

```
조명 시스템:
  시간대별 동적 조명 (새벽·낮·황혼·밤)
  왕국 색조 연동 환경광 (IBL)
  날씨: 맑음·흐림·비·눈·안개

물 표현:
  실시간 물 시뮬레이션
  강·바다: FFT 기반 파동
  살수대첩 수문 개방: 특수 유체 시뮬레이션

초목:
  SpeedTree 기반 실시간 식물
  계절별 자동 변화 (봄→여름→가을→겨울)
  전투 후: 불탄 초목 변화 셰이더

LOD (Level of Detail):
  3단계 LOD 적용 (High / Medium / Low)
  원거리: 임포스터 시스템
  성능: 60fps 목표 (PC 미드레인지 기준)
```

## UI/UX 디자인

### UI 비주얼 언어

```
디자인 컨셉: 「죽간·비단에 새긴 현대적 UI」

공통 UI 요소:
  프레임: 대나무·목재 질감 테두리
  배경: 반투명 비단 텍스처 (왕국색 적용)
  아이콘: 한자 획 스타일 픽토그램
  폰트: 전통 서예체 + 현대 가독성 혼합

전략 맵 UI:
  배경 지도: 7세기 한반도 스타일 지도 도안
  왕국 영토: 색상 오버레이 (반투명)
  유닛 아이콘: 왕국별 상징 (삼족오·백제봉황·신라금관·가야철정)
  정보 패널: 죽간 두루마리 UI

전투 UI:
  체력바: 검기(劍氣) 스타일 그래픽
  스킬 아이콘: 전통 문양 프레임
  피해 수치: 서예체 숫자 + 왕국 색상
  승패 연출: 「大勝(대승)」「敗退(패퇴)」한자 연출
```

### HUD (Heads-Up Display)

```
전략 맵 HUD:
  상단: 자원 현황 (식량·철·금·인구)
  좌측: 왕국 정보 + 계절·연도 표시
  우측: 이벤트 알림 피드
  하단: 액션 버튼 (이동·공격·외교·건설)

전투 HUD:
  미니맵: 우하단 (왕국 색상 유닛 표시)
  유닛 선택: 상세 스탯 좌측 패널
  스킬바: 하단 중앙
  회전 카메라: 마우스 우클릭·터치 드래그
```

## VFX (시각 효과)

```
전투 이펙트:
  검격: 파란빛 (고구려) / 황금빛 (신라) / 흰빛 (백제) / 황토빛 (가야)
  화살: 궤적 선 + 착탄 먼지
  기마 돌격: 지면 충격 파티클 + 카메라 셰이크
  화공: 불꽃 시뮬레이션 (GPU 파티클)

스킬 이펙트:
  고루 「살수 전술」: 강물 급류 이펙트 (파란 유체)
  아랑 「역사 기록」: 황금 죽간 문자 파티클
  하린 「화랑 돌격」: 황금빛 기마 충격파
  니문 「가야금 화음」: 음파 시각화 (토황빛 파동)

환경 이펙트:
  봉화: 연기·불꽃 실시간 시뮬레이션
  연등: 반짝임 파티클 야경
  전투 후 연기: 전장 스모크 볼류메트릭

성능 최적화:
  GPU 인스턴싱 (유닛 대규모 렌더링)
  파티클 LOD (원거리 감소)
  모바일 전용 경량 이펙트 세트
```

## 아트 제작 파이프라인

```
단계:
  1. 컨셉 스케치 (ART + GAME-ART 협업)
  2. ART-CHAR 승인 (art-bible.md 준수 확인)
  3. 3D 모델링 (ZBrush → Blender)
  4. 텍스처링 (Substance Painter)
  5. 리깅·애니메이션 (Maya)
  6. 게임 엔진 임포트 (Unreal Engine 5)
  7. 최적화 (LOD·텍스처 압축)
  8. QA 비주얼 검증 (QA-CONTINUITY)

툴체인:
  컨셉: Procreate / Clip Studio
  3D: ZBrush + Blender
  텍스처: Substance 3D Painter
  애니메이션: Maya
  엔진: Unreal Engine 5
  버전 관리: Perforce (대용량 에셋)
```
