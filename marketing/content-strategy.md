## 콘텐츠 전략 개요

```
핵심 메시지:
  「강은 기억한다 — 잊혀진 역사를 되살리다」

콘텐츠 목표:
  인지도 확장: IP 브랜드 인지도 구축
  팬덤 형성: 충성 팬 커뮤니티 성장
  교육적 가치: K-역사 관심층 유입
  구매 유도: 굿즈·게임·공연 전환

콘텐츠 유형:
  영상 (Video): 쇼트폼·트레일러·비하인드
  이미지 (Image): 캐릭터 카드·아트워크·인포그래픽
  텍스트 (Text): 역사 스토리·캐릭터 에세이
  인터랙티브: 퀴즈·테스트·필터
  라이브: 실시간 Q&A·팬미팅 스트리밍
```

---

## 콘텐츠 필러 (5대 축)

### 필러 1 — 「역사 스토리텔링」

```
목적: 삼국시대 역사 대중화 + IP 신뢰도 구축
타깃: 역사 관심층, 교육 관심 학부모·교사

포맷:
  [카드뉴스] 「오늘의 역사」시리즈
    → 역사적 날짜 기념 (AD 612 살수대첩 7월 등)
    → 4컷 인포그래픽 (한·영 병행)
    → 주 2회 발행

  [숏폼] 「60초 삼국사」
    → TikTok·Reels·Shorts 최적화
    → 전투·인물·문화 1개 주제
    → 주 3회 발행

  [롱폼] 「삼국 깊이 읽기」
    → YouTube 8~15분 다큐 스타일
    → ADV-HISTORY 자문 포함
    → 월 2회 발행

내용 예시:
  「살수대첩: 113만 vs 2,700」
  「백제가 일본에 준 것」
  「화랑도란 무엇인가」
  「가야금은 어떻게 태어났나」
```

### 필러 2 — 「캐릭터 스포트라이트」

```
목적: 4주인공 캐릭터 친밀감 형성
타깃: 드라마·웹툰 팬, 신규 유입 관심층

포맷:
  [이미지] 「캐릭터 데이」시리즈
    → 각 캐릭터 전용 요일 지정
    → 고루:월 / 아랑:화 / 하린:목 / 니문:금
    → 주 4회 캐릭터 아트 + 대사 카드

  [숏폼] 「캐릭터가 살던 세상」
    → 캐릭터 시점의 왕국 소개 (60초)
    → TikTok 인물 소개 포맷 차용

  [인터랙티브] 「어느 왕국 사람?」결과 공유
    → 결과 카드 SNS 자동 생성
    → 팬들 결과 공유 → 자연 바이럴

  [이모티콘] 새 이모티콘 공개 티저
    → 이모티콘 세트 출시 전 1개씩 선공개
```

### 필러 3 — 「팬 커뮤니티 참여」

```
목적: 팬덤 참여 유도 + UGC 생산
타깃: 기존 팬·창작 커뮤니티

포맷:
  [챌린지] 「#강은기억한다 챌린지」
    → TikTok 댄스·코스프레·그림 챌린지
    → 매달 테마 변경
    → 우수작 공식 계정 리그램

  [팬아트 콘테스트]
    → 월 1회 공모
    → 수상: 공식 굿즈 + 작품 공식 포스터화
    → 참여작 모아보기 (웹사이트 갤러리 연동)

  [팬픽 이벤트]
    → 분기 1회 팬픽 공모
    → 비상업적 창작 허용 범위 내
    → IP 운영진 감수 후 추천작 공식 소개

  [Q&A 라이브]
    → 월 1회 Instagram Live
    → 운영진 + 역사 자문 출연
    → 「역사 속 4인을 만나면 뭐라고 할 것인가?」등
```

### 필러 4 — 「신상품 & 론칭」

```
목적: 굿즈·게임·공연 출시 마케팅
타깃: 소비자, 구매 의향층

포맷:
  [티저] 신상품 출시 D-7 부터 카운트다운
    → 매일 1컷 힌트 이미지 공개
    → 최종 D-Day 전체 공개

  [리뷰] 공식 굿즈 언박싱 영상
    → YouTube 15~20분 상세 리뷰
    → 품질·디자인 고증 설명 포함

  [이벤트] 출시 기념 구매 이벤트
    → 구매 인증샷 공유 → 추첨 사은품
    → 한정판 수량 공개 → 희소성 마케팅

  [콜라보 공개]
    → 브랜드 협업 발표 콘텐츠
    → 콜라보 배경 스토리 설명 (역사 연결)
```

### 필러 5 — 「글로벌 K-히스토리」

```
목적: 글로벌 팬 유입 + K-역사 브랜딩
타깃: 해외 K-콘텐츠 팬, 역사 관심 글로벌 층

포맷:
  [영문 콘텐츠] 「K-History Explained」
    → 영어 자막 + 영어 캡션 병행
    → 한국 역사 초보자 대상 쉬운 설명
    → YouTube·TikTok 동시 발행

  [비교 콘텐츠] 「East Asian History」
    → 삼국시대 vs 동시대 중국·일본·유럽 비교
    → 글로벌 역사 팬 흥미 유발

  [번역 챌린지]
    → 팬들이 자막 번역 → 공식 확인 후 공유
    → 다국어 팬 자연 유입

  [현지화 콘텐츠]
    → 태국어·인니어·일어 전용 콘텐츠
    → 현지 인플루언서 공동 제작
```

## 콘텐츠 캘린더 요약 (월간)

```
매주 정기 발행:
  월: 고루 캐릭터 카드 (아트워크)
  화: 아랑 캐릭터 카드 (아트워크)
  수: 역사 스토리 카드뉴스
  목: 하린 캐릭터 카드 (아트워크)
  금: 니문 캐릭터 카드 + 가야금 숏폼
  토: 웹툰 연재일 → 에피소드 소개
  일: 팬 커뮤니티 콘텐츠 (리그램·이벤트)

매월 1회:
  역사 깊이 읽기 YouTube 롱폼
  팬아트 콘테스트 개최/결과 발표
  신상품 티저 또는 론칭 이벤트
  라이브 Q&A (Instagram)

분기 1회:
  팬픽 이벤트
  대형 챌린지 캠페인
  글로벌 콘텐츠 특집 (SEA/JP/NA)
```
