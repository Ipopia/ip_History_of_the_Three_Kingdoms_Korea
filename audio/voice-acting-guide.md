
## 캐릭터별 성우 디렉션

### 고루 (高婁) — 고구려

```
목소리 프로필:
  음역: 중저음 (바리톤 경계)
  음색: 굵고 건조함. 군더더기 없음
  말속도: 느리고 신중함
  감정: 극도로 절제 (눈물은 단 1회)

대사 연기 지침:
  짧은 대사: 여운을 두고 끊기
    예: 「강은 기억한다.」— 마지막 「다」 살짝 낮춤
  감정 씬: 목소리 무게로 전달 (높이 아닌 무게)
  전투: 짧은 명령 + 기합 (과장 없이)
  독백: 혼잣말처럼 — 독자에게가 아니라 자신에게

발음 주의:
  「을지문덕(乙支文德)」— 을-지-문-덕 (또렷하게)
  「살수(薩水)」— 살-수 (끊어 읽기)
  「대막리지(大莫離支)」— 대막-리지 (4음절 자연스럽게)

NG 패턴:
  ❌ 감정 폭발 (고루는 내면에서 삭임)
  ❌ 빠른 말투 (느리고 신중)
  ❌ 높은 음성 (저음 유지)

참고 레퍼런스 톤:
  조용하지만 존재감 있는 장수형
  「침묵이 말보다 무거운」 캐릭터
```

### 아랑 (阿郞) — 백제

```
목소리 프로필:
  음역: 중고음 (메조소프라노)
  음색: 맑고 지적. 약간 빠른 리듬
  말속도: 빠름 (생각이 말보다 앞선다)
  감정: 풍부하게 표현 (단 히스테릭 금지)

대사 연기 지침:
  질문 많은 대사: 끝을 올려서 자연스럽게
    예: 「선생님, 이것이 사실입니까?」
  분석 대사: 또렷하고 논리적인 리듬
  슬픔 씬: 목소리 약간 갈라짐 허용 (단 억제)
  마지막 기록 씬: 느리고 무겁게 (평소와 대비)

발음 주의:
  「성충(成忠)」— 성충 (초성 정확히)
  「좌평(佐平)」— 좌평 (발음 명확히)
  「죽간(竹簡)」— 죽-간 (단어 전달 중요)

NG 패턴:
  ❌ 단답형 (아랑은 말이 많다)
  ❌ 무뚝뚝한 톤 (아랑의 지적 열정 필수)
  ❌ 울부짖는 슬픔 (절제된 비극)

아랑 감정 아크:
  1막: 밝고 빠름 → 2막: 무게감 증가 → 클라이맥스: 느리고 단호함
```

### 하린 (夏林) — 신라

```
목소리 프로필:
  음역: 중고음 (소프라노 경계)
  음색: 맑고 강인함. 감성적 여운
  말속도: 보통 ~ 상황에 따라 빠름
  감정: 강인하지만 내면 감성 표출 가능

대사 연기 지침:
  전투 명령: 단호하고 강하게 (단 히스테릭 아님)
  도덕적 갈등 독백: 스스로에게 묻는 톤
    예: 「이것이 옳은가.」— 혼잣말처럼
  선덕여왕 대화: 존경 + 사랑 (감정 레이어 깊게)
  클라이맥스 울음 씬: 억눌린 울음 → 터짐 (단 1회)

발음 주의:
  「화랑(花郞)」— 화-랑 (선명하게)
  「세속오계(世俗五戒)」— 세속오계 (강조)
  「선덕여왕(善德女王)」— 선덕-여왕 (존경 담아)

하린의 감정 범위:
  평소: 70% 강인함 + 30% 감성
  클라이맥스: 30% 강인함 + 70% 감성 (역전)
```

### 니문 (泥文) — 가야계

```
목소리 프로필:
  음역: 중저음 테너
  음색: 부드럽고 약간 쉰 듯한 (가야 유민 고독감)
  말속도: 매우 느림 + 침묵 빈번
  감정: 음색으로 표현 (가사보다 소리)

대사 연기 지침:
  침묵 사용: 「...」 충분히 살리기 (최소 2초)
  짧은 대사: 더 짧게 느껴지도록 여운
    예: 「...잊히지 않도록.」— 끝을 흘리듯
  가야금 연주 씬: 대사 없이 감정 표현
  정체성 씬: 목소리 약간 흔들림 허용

발음 주의:
  「가야(伽耶)」— 가야 (그리움 담아)
  「우륵(于勒)」— 우-륵 (정중하게)
  「가야금(伽耶琴)」— 가야-금 (특별하게)

니문 연기의 핵심:
  대사가 적을수록 목소리 하나하나에 무게
  가야 = 사라진 나라 → 소리 자체가 유산
```

### 을지문덕 (乙支文德)

```
목소리 프로필:
  음역: 깊은 베이스
  음색: 산처럼 무겁고 고요함
  말속도: 매우 느림. 단어와 단어 사이 여백
  감정: 거의 없음. 있어도 미세한 변화

대사 연기 지침:
  가르침 대사: 마치 자연의 법칙처럼
    예: 「강은 기억한다.」— 사실 진술처럼
  한시 낭독: 고전적 낭독법 (현대 드라마 과장 없이)
  마지막 등장: 평소보다 더 느리게

발음 주의:
  한시 「神策究天文」— 신책구천문 (또렷하게)
```

### 선덕여왕 (善德女王)

```
목소리 프로필:
  음역: 중고음
  음색: 품위 있고 따뜻함. 지혜로운 울림
  특징: 왕의 권위 + 여성의 섬세함

핵심 대사:
  「살아남아야 지킬 수 있다.」
  연기 지침: 위로이자 명령. 강하지만 따뜻함
```

## 일본어 더빙 가이드

```
기본 방침:
  오리지널 한국어의 감정·뉘앙스 최우선
  일본 시대극 (時代劇) 문체 참조
  직역 대사 사용 금지 (자연스러운 일본어 흐름)

역사 용어 처리:
  한국식 고유명사: 원음 가타카나 유지
    을지문덕 → ウルジ·ムンドク
    살수대첩 → 薩水の大捷
  일본인 친숙 용어: 병용 가능
    고구려 → 高句麗 (こうくり)
    화랑 → ファラン (花郞 표기 병용)

성우 캐스팅 기준:
  고루: 일본 시대극·무사 전문 성우
  아랑: 지적·활발한 여성 캐릭터 전문
  니문: 조용하고 내면 깊은 캐릭터 전문
```

## 녹음 세션 가이드

```
세션 준비:
  대본 사전 배포: 녹음 3일 전
  캐릭터 디렉션 시트 제공
  레퍼런스 클립 (캐릭터 목소리 방향) 제공

부스 환경:
  방음: -40dB 이상
  마이크: Neumann U87 또는 동급
  샘플레이트: 48kHz/24bit

디렉션 프로세스:
  1차: 성우 자유 해석 녹음
  2차: 감독 디렉션 + 재녹음
  3차: 픽 셀렉션 + 편집
  QA: ADV-HUMANITIES 톤 검토

감정 씬 특별 지침:
  클라이맥스 씬: 성우에게 충분한 준비 시간
  1~2회 워밍업 런 허용
  최종 테이크 후 별도 대안 테이크 보관
```
